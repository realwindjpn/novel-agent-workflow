# 《写在落笔前，如何构思一本男频网文小说》编辑学习笔记
> 讲师：番茄资深编辑 千城 ｜ 栏目：写作技巧 ｜ 2023-04-26
> 学习人：《科武纪元》编辑学习官

---

## 1. 课程核心判断（≤6条）

1. **一句话故事是开书的前置门槛**：负价值身份 + 正价值欲望 + 行动 = 故事内核；说不清就不要动笔。
2. **正负价值对立创造期待感**，期待感才是网文驱动力，"爽"只是期待被满足的副产物。
3. **故事必须有若干"支点"**（人物/世界观/金手指/悬念/二次行为/激励事件），每个支点都应能独立长出一串剧情，并可直接作为书名。
4. **开篇的本质是"早植入期待"**，男频更要把处境、共情点、不公、危险、金手指、短期目标、钩子尽早砸出来。
5. **三幕式（建制-对抗-结束）是嵌套结构**：长卷用、单章用、对话和打斗都能用，越下沉就是越细的情绪曲线。
6. **节奏由"设置期待 / 满足期待"的拉扯组成**，单一爽点模式（装逼打脸）会让读者疲劳，必须换花样。

---

## 2. 可执行编辑规则

### 2.1 开篇（前 1–3 章）
- 用一句话故事反推开篇，确保**主角负价值身份**在首章可视化呈现（不是旁白告知）。
- 七要素至少命中 5 条：处境不满、可共情理由、不公伤害、危险逼近、金手指出现、短期目标、情节钩子。
- 切入事件优先选**激励事件**或**二次行为**，避免静态自我介绍。
- 钩子结尾必须留一个**未解决的具象问题**（不是情绪渲染）。

### 2.2 节奏
- 单章用三幕式：建制冲突→升级对抗→留钩或小爽，禁止平推。
- **情绪曲线起伏越大，期待铺设要越强**；下行段是设期待，上行段是给满足。
- 不允许连续 3 章使用同型爽点；每卷至少 3 种期待类型轮换（成就/求生/解谜/情感/复仇）。
- **十万字前不要把高潮抖完**，但十万字必须有一次卷级高潮（番茄完读数据节点）。

### 2.3 冲突
- 每个冲突必须能回答："谁要什么 / 谁挡着 / 代价是什么"。
- 设期待 = 不符合读者预期；不符合预期的事件必须**圆得回来**，圆不回就是事故。
- 悬念支点开局可以"大坑套小坑"，但作者本人必须提前知道答案。

### 2.4 人物
- 主角身份的**正向期待 + 反向负价值**碰撞出人物钩（如"摆烂宗主""学鬼道的儒生"）。
- 任何反差必须**合理化**，反差本身就能孵出人物小传/支线。
- 配角按"对主角欲望提供阻力或加速"来设计，不做背景板。

### 2.5 题材与世界观
- 用熟题材（仙侠/末世）必须**多一条新规则**，且这条规则要与主角/读者价值观相冲突。
- 新规则要可被事件追溯（"为什么会这样"必须能讲出一个故事）。
- 异格世界优先于本格，但前提是规则能服务冲突，不为炫设定而设定。

### 2.6 金手指
- 金手指是**工具**，必须由主角驱动，禁止金手指推着主角走。
- 高阶用法：把金手指设为**欲望的负价值**（想逃离皇朝却觉醒成帝系统 / 想赚钱却得亏钱系统）——优先采纳。
- 获得方式 + 副作用，本身就是支点，必须写清。

### 2.7 改编 / 大纲
- 先写**第一卷大纲（15–20 万字）**，整书大纲允许后置滚动构建。
- 大纲可改，但改动需评估是否动摇"一句话故事"的正负价值对立，动摇即驳回。
- 三幕→四幕（起承转合）可自由切换，不强推斯奈德节拍器，但要有**作者自己的节拍表**。

### 2.8 平台规则（番茄）
- 十万字完读率是生死线，卷高潮压在 10w 字后。
- 开篇钩子必须扛过前三章跳出率，建议每章末挂钩。
- 书名可直接复用最强支点（人物反差 / 世界规则 / 金手指 / 悬念）。

## 3. 科武适配

### ✅ 可用点
- **一句话故事模板**完全适用：例 "被除名的旧时代武修，想在科技神朝里夺回武道正统，而去黑入国家武备系统的故事"。
- **世界观加一条冲突规则**：科武纪元天然双轨（科技 vs 武道），可把"科技对武道的压制/驯化"作为与主角价值观直接对撞的规则。
- **金手指反用**思路高度契合：主角是武者，金手指却是"科技系统"，逼他用最反感的方式变强——天然形成欲望负价值。
- **悬念支点**适合科幻：开局抛"为何武道在某年突然失效""谁封印了真气数据"等具象悬念。
- **二次行为**驱动剧情：主角不甘平凡，黑入禁区/盗取核心算法/破坏封印，触发系统级反扑。
- **嵌套三幕**对长篇科幻必备：世界线-卷线-章线三级节拍可控制烧脑节奏。

### ⚠️ 不可硬套点
- 男频"装逼打脸"型爽点不要做成科武主调——科幻读者对单一爽感更敏感，需以"解谜爽 + 体系崩塌爽 + 反向真相爽"为主。
- "七要素全塞首章"对科幻不友好：世界观需要呼吸感，可允许前 3 章渐进释放，但**钩子和短期目标不可延后**。
- "金手指任务驱动"系统流模板谨慎使用，科武世界更适合**机制型金手指**（规则、协议、接口）而非"叮~恭喜宿主"。
- "悬念大坑套小坑"在科幻里若圆不回来，伤害比仙侠更大——所有谜题必须先有答案再抛。
- "异格世界优于本格"在科武里不绝对，近未来本格反而更易制造规则冲突真实感。

## 4. 编辑检查表（10 条以内）

1. 能否用一句话讲清主角的负价值身份 + 正价值欲望 + 行动？
2. 开篇 3 章是否命中七要素中至少 5 条，并留具象钩子？
3. 是否存在 ≥3 个可独立长出剧情的故事支点？
4. 世界观/金手指是否带有**与主角价值观冲突的新规则**？
5. 金手指是否由主角驱动，是否考虑过"反用作负价值"？
6. 每章是否走完一次三幕式，结尾留钩？
7. 近 10 章爽点类型是否 ≥3 种，避免单一模式？
8. 卷高潮是否落在 10 万字之后？完读节点是否扛得住？
9. 所有抛出的悬念/伏笔，作者是否已写下答案与回收章节？
10. 大纲改动是否仍守住"一句话故事"的正负价值对立？

## 5. 对作家角色的输入要求

向作家下达需求时，必须同时给齐以下五项，缺一项打回：

| 项 | 要求 |
|---|---|
| **动作链** | 主角从触发到结果的动作序列（≥3 步），每步有明确目的与对抗者；禁止"心念一动即成"。 |
| **物理反馈** | 每个关键动作的可感知反馈：真气的电流感、外骨骼的过载温度、神经接口的延迟、环境的塌缩声——科武世界**必须有量纲**。 |
| **代价** | 每次"爽"必须标注付出的代价（体能/寿元/数据权限/信誉/人脉/伦理），代价要在后续章节兑现，不可一次性勾销。 |
| **钩子** | 章末/段末留下一个**具象未解项**（实体悬念、倒计时、未现身敌人、未读消息），禁止纯情绪结尾。 |
| **读者预期** | 写明本段在做"设期待"还是"满足期待"，并标注期待类型（解谜/复仇/求生/晋升/情感/真相），便于节奏调度。 |

> 交付格式建议：每章大纲表头固定五列【动作链｜物理反馈｜代价｜钩子｜预期类型】，编辑按此列逐项验收。
