# 第 64 章：暗线追踪

太行山基地的地图室里，巨大的电子地图占据了整面墙。

陈思琪把李国强手机里提取到的那个“注册地”坐标投射在地图上。

红点闪烁。

**波斯湾沿岸，查巴深水港。**

“查巴港。”赵刚盯着那个红点，“波斯湾东侧，紧邻外海。那是那个国家唯一的深水港，也是他们绕过海峡制裁的生命线。”

“对。”陈思琪放大地图，“铁幕把壳公司的注册地选在这里，非常聪明。查巴港的物流吞吐量巨大，每天有成千上万个集装箱进出。要把一批芯片或者资金混在里面运出去，简直是大海捞针。”

“而且，”方宁指着地图上的另一条线，“从查巴港往东，就是隔壁邻国的瓜达尔港。两条线连起来，正好是那条著名的陆路经济走廊的出海口。”

“你是说，他们可能通过陆路把东西运回国内？”林星辰问。

“有这个可能。”方宁点头，“但如果走陆路，风险太大。边境检查站不是吃素的。更有可能的是，他们在查巴港有一个秘密的中转仓。先把货卸在那里，然后利用当地复杂的走私网络，分批次运往迪拜或者卡拉奇。”

陈思琪调出一张卫星图。

“这是查巴港 3 号泊位的卫星照片。拍摄于三天前。”

照片上是一片繁忙的码头景象。起重机正在装卸巨大的集装箱，远处停着几艘散货船。

“我对比了李国强提供的‘北极星咨询’公司的物流单号。”陈思琪把单号输入数据库，“这个单号对应的集装箱，昨天刚进港。箱号是 MSKU-7749201。”

她在卫星图上圈出了一个红色的集装箱。

“就是它。堆放在 3 号泊位的 C 区。周围全是普通的日用商品集装箱，伪装得很好。”

“里面是什么？”赵刚问。

“不知道。”陈思琪摇头，“海关的 X 光扫描显示，里面装的是‘机械配件’。但那个密度分布……不太像普通的配件。更像是某种精密仪器。”

“铁幕的中转站。”林星辰看着那个红点，“如果我们要查清他们到底在运什么，就必须有人去那个码头看一看。”

“我去。”方宁主动请缨，“我对机械配件最熟悉。只要让我靠近那个箱子五十米，我就能用便携光谱仪扫出里面的成分。”

“不行。”赵刚摇头，“那边的情况很复杂。查巴港虽然是自由贸易区，但实际上被几股势力控制着。有当地的地方武装，有走私家族，还有铁幕安插的私人安保。你一个搞技术的过去，不出半小时就会被当成商业间谍扣下来。”

“那怎么办？”

“让专业的人去。”赵刚看向林星辰，“星辰小队有外勤经验，而且……你们有‘特殊手段’。”

林星辰明白了他的意思。

“你要我们去查巴港？”

“对。”赵刚在地图上画了一条线，“从这里出发，飞往邻国首都，然后租车进入俾路支山区。从陆路翻过边境，潜入查巴港。这条路线虽然险，但比坐飞机直接去迪拜要隐蔽得多。”

“俾路支山区……"陈思琪皱了皱眉，“那里是武装分子和走私贩的天堂。我们的通讯在那边可能会完全中断。”

“所以，这次行动没有后援。”赵刚看着林星辰的眼睛，“一旦越境，你们就是孤军深入。如果遇到危险，只能靠自己。”

林星辰看着地图上那条曲折的路线。

从太行山到查巴港，直线距离超过三千公里。中间隔着高山、沙漠、还有无数未知的危险。

但那个红色的集装箱里，藏着铁幕的核心秘密。

“我们去。”林星辰说。

“什么时候出发？”

“今晚。”林星辰转身，“方宁，准备便携光谱仪和伪装身份。苏雨晴，检查装备。陈思琪，把那个集装箱的所有周边监控都给我扒下来。”

“是。”

赵刚点了点头。

“记住。”他在林星辰出门前叫住了他，“在查巴港，你们面对的不是普通的罪犯。铁幕在那里经营了至少五年。那里的每一双眼睛，可能都在盯着你们。”

“我知道。”林星辰推开门，“所以，我们会比他们更狠。”

门关上。

地图室里，红点依然在闪烁。

像是一只在黑暗中窥视的眼睛。
