## 一、写作前任务卡字段更新

> **开始本章前，必须在文档备注区填完以下字段。空白项不得开写。**

### 必填字段（5项）

| 字段名 | 填写要求 | 验证标准 |
|:---|:---|:---|
| **本章情绪交付物** | 从【爽/虐/燃/疑/爆/暖】六选一，明确读者此刻该感受到什么 | 能用一句话向编辑解释清楚 |
| **人物此刻核心诉求** | 主角"想要什么"，必须是具体可见的动作/物件/关系状态，非抽象概念 | 能拍成3秒短视频画面 |
| **本章因果链起点** | 明确"什么在前"，前因必须有上文锚点 | 能回溯到前3章内的具体事件 |
| **视觉化高光预留** | 本章核心场景中，列出≥1个可拍成海报画面的元素 | 描述时脑中能浮现镜头语言 |
| **代价预付/兑现** | 明确本章会消耗什么（生理/资源/信任/情感），禁止无代价推进 | 代价与主角动机构成张力 |

### 科武长篇专属字段（+3项）

| 字段名 | 填写要求 |
|:---|:---|
| **战力锚点** | 本章战斗/突破后，主角与主要对手的相对实力差距变化 |
| **设定服务验证** | 本章引入的科武元素是否直接服务于人物/冲突，标记"关系推进/代价支付/悬念铺设" |
| **平台断点预判** | 预判读者可能弃读的节点，提前布置情绪锚点 |

## 二、可执行动作清单

> **每个动作都是写作时必须完成的操作，不是建议。**

### 开篇3章动作链

```
[ ] 场景切入：禁止纯设定说明，必须以"关系行为"开场
       ✅ 协议签署、物资交割、伤痕暴露、旧敌重逢
       ❌ "这是一个星际时代，机甲横行..."

[ ] 核心诉求暴露：主角想要什么必须在第3章前明确
       操作：在章节结尾让主角做出一个代价选择

[ ] 潜在裂痕埋入：关系锚点必须包含对立隐患
       操作：每段"靠近"场景中植入一个"误会/缺陷/秘密"
```

### 段落级动作（每500字必须执行）

```
[ ] 具象化替代抽象
       操作：删除所有"感到"、"觉得"、"心情沉重"
       替换：具体生理反应/环境反馈

[ ] 意图链完整
       操作：每个动作必须包含"为什么要做→受阻→变招→结果"
       验证：删掉旁白后，读者仍能看懂人物在做什么

[ ] 设定嵌入对话
       操作：世界观信息必须通过角色"有目的的说话"传递
       禁止：旁白解释科武设定
```

### 科武专属动作

```
[ ] 战力合理化检查
       操作：每次战斗结束，重新计算双方实力对比并记录

[ ] 代价即时化
       操作：突破/胜利后，3段内必须出现身体/资源/关系的具体损耗

[ ] 环境干涉战斗
       操作：每个战斗场景必须包含地形/重力/温度/介质对战术的影响
```

## 三、反馈系统

> **写完后对照检查，每项都是即时信号。**

### 达标信号（写对了）

| 信号类型 | 具体表现 |
|:---|:---|
| **读者视角可复述** | 用"一个人想要XX但因为YY所以ZZ"能说清本章剧情 |
| **生理反应具体** | 主角紧张时写的是"指甲陷进掌心"而非"他很紧张" |
| **冲突有内因** | 所有对立都能追溯到人物缺陷或信息差 |
| **设定可删除** | 假设把科武外壳全删，情感逻辑链仍然成立 |
| **视觉画面可达** | 本章任意场景能在5分钟内画出分镜草图 |

### 失败信号（写错了）

| 警告标志 | 说明 |
|:---|:---|
| 旁白超过200字 | 说明你用解释代替了行动 |
| 情绪词出现超过5次/章 | 说明你告诉了读者感受，而非呈现 |
| "于是...后来...紧接着..."连接 | 说明因果链断裂，用时间词掩盖 |
| 主角没做选择就成功了 | 说明缺少代价 |
| 反派突然变强/变弱 | 说明战力系统未锁定 |

## 四、代价机制

> **每次推进必须支付代价。代价是叙事的燃料。**

### 代价类型表（可直接调用）

| 代价类型 | 科武适用场景 | 调用句式 |
|:---|:---|:---|
| **生理损伤** | 突破、战斗、透支 | "他的左臂在第三次过载后失去了知觉" |
| **资源枯竭** | 消耗战、交易、赎买 | "这一局的筹码是他三个月的配给额" |
| **信任破裂** | 欺骗、隐瞒、背刺 | "她知道了真相后，眼神里的光灭了" |
| **道德妥协** | 两难选择、牺牲他人 | "他按下开关时，手在抖" |
| **关系倒退** | 冲突、误会导致 | "他们之间的距离从三步变成了整个银河" |
| **秘密暴露** | 背叛、意外、审讯 | "那张全息照片在会议室的大屏上展开" |

### 代价使用规则

```
规则1：代价必须与诉求构成张力
       ✅ 想要救她→代价是放弃晋升资格
       ❌ 想要救她→代价是打了一架

规则2：代价必须即时兑现，不能"之后再说"
       ✅ 第7章突破，第8章立刻出现经脉灼痛
       ❌ 第7章突破，第20章才提后遗症

规则3：主角必须付出过"真实代价"才能赢
       无损耗升级→信任崩塌
```

## 五、失败模式清单

> **每章写完后必须扫描。高亮项必须修改。**

### 致命失败（必须修改）

| 失败模式 | 自检问题 | 修复方向 |
|:---|:---|:---|
| **动机悬浮** | 主角做的事能换人做吗？性格特征明显吗？ | 增加决策限制条件 |
| **机械降神** | 困境解决是因为"突然出现新因素"吗？ | 让主角用已有能力/资源变通 |
| **战力通胀** | 主角胜利是否越来越容易？ | 重新设计代价体系 |
| **人设偏移** | 当前主角行为是否符合前10章建立的性格？ | 回溯人物核心缺陷定义 |
| **平台断点** | 章末是否在"情绪悬置+行动中断"点？ | 重写最后200字 |

### 中度失败（影响追读）

| 失败模式 | 自检问题 |
|:---|:---|
| **设定喧宾** | 科武元素是否比人物关系占更多篇幅？ |
| **文戏冗长** | 非冲突对话是否超过3段？目的是否明确？ |
| **情绪跳档** | 主角情绪是否有合理铺垫？还是突然从"平静"跳到"暴怒"？ |
| **钩子疲软** | 章末是"且听下回"式悬念还是"情绪悬置"？ |

### 科武专项失败

| 失败模式 | 典型症状 |
|:---|:---|
| **科武逻辑崩塌** | 读者能指出设定前后矛盾 |
| **战斗过程空洞** | 打斗只剩"火花四溅/能量波冲击" |
| **升级无感** | 突破境界后没有新的能力展示或限制说明 |

## 六、人物口吻设计表

> **每个人物开口前必须确认：他说的话换不了别人说。**

### 口吻四维检测

| 维度 | 问题 | 操作 |
|:---|:---|:---|
| **词汇偏好** | 这个角色会用专业术语/口语/古风词汇？ | 列出该角色专属词汇表（10-15个） |
| **句式节奏** | 短促质问型？长句分析型？犹豫重复型？ | 标注该角色的标点习惯 |
| **回避模式** | 什么话题他会绕开/沉默/撒谎？ | 建立"不愿提"清单 |
| **情绪触发器** | 什么词/事会让他瞬间破防？ | 设定"核心伤口词汇" |

### 科武人物口吻模板

```
[ ] 科学家型
    说话结构：现象描述→数据支撑→结论
    口语标志：数据化表达、"概率"、"偏差值"
    情绪标志：失控时语速加快、出现术语错误

[ ] 武道强者型
    说话结构：结论先行→简短解释
    口语标志：省略主语、单字应答、"本座"/"小子"
    情绪标志：沉默、动作代替语言

[ ] 指挥官型
    说话结构：任务目标→资源盘点→执行指令
    口语标志：军事代号、量化表达
    情绪标志：刻意冷静、压抑下属面前的情绪
```

```

【假设成型】200字
    主角形成判断，但留有逻辑漏洞
```

## 十、平台规则转换表

> **编辑规则→作家执行操作**

|:---|:---|:---|

| "被动发酵"→"主动节点" | 每10章必须设置一个"阶段性目标/战力节点"强制推动 | 大纲层面执行 |

## 十一、科武长篇借用指南

### 直接迁移（与短篇通用）

```
✅ 人物动机前置 → 主角每章必须做选择
✅ 冲突内化 → 对立根源是性格缺陷，非外部机械降神
✅ 情绪浓度决定留存 → 战斗场景必须有情感核心
✅ 视觉名场面预留 → 核心场景设计时考虑"定格画面"
✅ 钩子类型库 → 直接使用行动中断/信息揭露型
```

### 必须改造（不可照搬）

| 原规则 | 科武改法 |
|:---|:---|
| "慢节奏细水长流" | 在文戏中嵌入"悬念/探索/战力验证"锚点，每章必须有进度感 |
| "全靠情绪驱动" | 情绪必须包裹在"逻辑/规则/设定"框架内，读者需要"道理上成立" |
| "纯情感书剧分离" | 战斗/突破必须有清晰机制解释和可执行的动作设计 |

### 科武长篇独有（必须执行）

```
✅ 每卷设置"战力锚定期"：明确主角此时能打谁、打不过谁
✅ 设定必须有"代价体系"：某种能力的使用门槛/副作用
✅ 每20章设置"世界观揭示点"：让读者感到世界观在扩展
✅ 主角必须有"成长检验场景"：用新对手/旧敌复出来验证实力变化
```
