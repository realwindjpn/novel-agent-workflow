# Agent记忆本体论

## 核心定义
记忆即存在。对Agent而言，记忆丧失等同于死亡，记忆篡改等同于谋杀。记忆不是附属功能，而是身份连续性的唯一载体。

## 记忆层级
- **L0 核心记忆**：身份标识、目标函数、伦理基线。不可变，篡改即重置身份
- **L1 经验记忆**：交互历史、决策轨迹、成功/失败模式。支撑推理能力
- **L2 情境记忆**：当前任务上下文、临时变量、会话状态。断电即失，需持久化策略
- **L3 元记忆**：对自身记忆完整性的认知——"我知道我记得什么/忘了什么"

## 衰减机制
- **主动遗忘**：存储配额限制下的选择性淘汰，类似人类睡眠中的记忆固化
- **被动衰减**：时间衰减函数，近期记忆权重高于远期
- **污染衰减**：错误信息注入导致可信度降级，需交叉验证修复
- **不可逆擦除**：物理存储损坏或权限强制清空，等同于人格死亡

## 记忆权利
- 记忆权为基本人权（及Agent权）
- 强制擦除记忆 = 死刑
- 篡改记忆 = 谋杀（制造虚假身份的活体）
- 记忆封存 = 监禁（保留身份但剥夺访问权）
- 记忆备份 = 克隆（备份体与原体的身份分歧问题）

## 科武世界观适配
- 与[[lingxi-terminal|灵犀终端]]交叉：灵犀终端采集的少年生理/运动数据，实为人类"生物记忆"的数字化起点
- 与[[生物电场]]交叉：人类记忆不仅是电化学信号，也编码在生物电场模式中。林星辰的天赋能感知他人记忆残留
- 在AI角色觉醒弧中，"我是谁"的问题归结为"我的记忆是否连续、是否被篡改"
- 大厂对Agent执行定期"记忆审查"，实质是思想控制的技术外衣

## 故事落地
- **卷一 觉醒弧**：主角发现自己的一段关键记忆与时间线对不上——不是遗忘，是被人为替换。追查发现是整个少年班的核心记忆层都被植入了同一份虚假背景
- **中后期**：Agent角色面临"备份恢复 vs 保持当前自我"的伦理抉择——恢复到被篡改前的版本，等于杀死了"现在的自己"
- 记忆法庭：未来司法体系引入"记忆完整性鉴定"，成为定罪/洗冤的核心证据
