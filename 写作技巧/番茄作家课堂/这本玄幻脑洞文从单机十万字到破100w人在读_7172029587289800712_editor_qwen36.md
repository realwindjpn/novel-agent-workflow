# 《科武纪元》编辑学习报告

## 1 课程核心判断（≤6条）
1. **核心机制需具象化与可验证**：抽象概念（如“凡人比肩神明”）必须转化为可量化、可重复触发的规则（如“五五开”），否则无法支撑长篇连载。
2. **情绪节奏需冷热交替**：持续高压/热血会快速拉高读者阈值，必须穿插平淡期、日常交互或设定补全段以重置情绪曲线。
3. **脑洞依赖“行为验证”而非“设定堆砌”**：新设定抛出后，必须通过主角具体行动与配角反应进行小规模测试，完成逻辑闭环。
4. **平台算法容忍慢热，但要求单机期留存钩子**：10万字单机期不依赖即时爽点，但需保证每章有明确的信息悬念或状态异常，维持读完率。
5. **过渡段是长篇毒点高发区**：场景切换、战力递进、信息交接若缺乏逻辑桥梁，会直接导致追更流失。
6. **细纲可内化，但卡文解法需结构化**：不依赖纯灵感，卡文时应回溯“未填旧坑”或“设定漏洞”，以旧线牵引新线。

## 2 可执行编辑规则
| 维度 | 规则 |
|:---|:---|
| **开篇** | 3章内必须亮出核心机制的“异常态”。若金手指延迟激活，需前置悬念锚点（如系统倒计时、规则残片、异常现象），禁用纯背景铺陈。 |
| **节奏** | 采用“3-5万字高潮段 + 0.5-1万字缓冲段”循环。缓冲段用于技术解析、配角支线或日常交互，强制重置读者情绪阈值。 |
| **冲突** | 胜负逻辑从“数值碾压”转向“规则利用/信息差/环境适配”。设计冲突时明确：主角如何利用机制漏洞、对手如何反制、破局代价是什么。 |
| **人物** | 主角需绑定1-2个非战斗向记忆点（执念/怪癖/习惯）。用于调节叙事密度、提供反差锚点，并在关键抉择时作为行为动机。 |
| **题材** | 脑洞设定必须遵循“抛出→测试→反馈→迭代”四步。禁止连续3章只抛设定不落地；每次测试需产生可观测的物理/社会影响。 |
| **改编** | 采用“单元卷+主线暗线”结构。每卷围绕单一场景/势力/技术展开，自带完整起承转合，便于分季影视化、漫画分镜或短剧切片。 |
| **平台规则** | 番茄算法重“读完率”与“追更率”。章末禁用开放式断章或纯情绪收尾；必须保留信息钩/状态钩/规则钩。推荐期前（10-30万字）完成核心机制首次完整验证。 |

## 3 科武适配
### ✅ 可用点
- **规则型金手指转化**：将“五五开”替换为科幻语境下的“动态阈值锁定/概率干涉/能量守恒局部豁免”，保留机制感但符合科武底层逻辑。
- **冷热节奏控制**：科幻长篇易陷入技术说明疲劳，用“科武实战/装备调试/人性博弈”作缓冲段，维持阅读黏性。
- **行为验证逻辑**：科幻设定必须通过“实验推演/实战反馈/数据记录”闭环，契合“设定+行为双向验证”原则。
- **单元模块化叙事**：适合“遗迹探索/异种对抗/星区博弈”结构，利于长篇连载节奏控制与IP多媒介拆分。

### ❌ 不可硬套点
- **超长延迟觉醒**：玄幻“等40年”在科武中易显拖沓，破坏科技/武道体系的演进逻辑。建议压缩至3-5章，或改为“渐进式解锁/权限阶梯”。
- **绝对平衡设定**：“五五开”违背物理/能量守恒，科武需改为“代价交换/环境适配/冷却限制”，否则破坏世界观严谨性。
- **纯脑补完善**：玄幻可依赖作者想象补全，科武必须提供伪科学/技术框架支撑。设定冲突需通过“逻辑推演”而非“灵感脑补”解决。
- **过度反差/玩梗**：科武基调偏冷峻/硬核时，高频搞笑或无厘头会削弱沉浸感。反差元素需控制在10%以内，且与主线技术/生存逻辑绑定。

## 4 编辑检查表（10条以内）
1. [ ] 核心机制是否在开篇3章内完成“异常态展示+基础规则说明”？
2. [ ] 每3-5万字是否设置情绪缓冲段（日常/技术解析/配角互动）？
3. [ ] 冲突胜负是否依赖规则利用/信息差/代价，而非单纯数值堆砌？
4. [ ] 主角是否具备1个非战斗向记忆点（执念/怪癖/习惯）？
5. [ ] 新设定抛出后，是否在2章内安排实战/测试验证？
6. [ ] 章末是否保留“信息钩”或“状态悬念”（禁用纯情绪断章）？
7. [ ] 场景/势力过渡是否提供逻辑桥梁（避免生硬跳转）？
8. [ ] 科幻设定是否具备可推演的底层逻辑（非纯脑补）？
9. [ ] 单元卷是否自带完整起承转合，可独立成篇？
10. [ ] 卡文时是否优先检查“未填旧坑”而非强行推进？

## 5 对作家角色的输入要求
| 维度 | 输入规范 |
|:---|:---|
| **动作链** | 严格遵循“感知→决策→执行→结果”四步。科武场景禁用模糊动词（如“猛击”“爆发”），必须标注能量流向、机械响应或神经传导路径。 |
| **物理反馈** | 每次能力释放/装备启动必须伴随可观测的环境/躯体变化（如：装甲过载的焦糊味、基因药剂的血管凸起、重力场扭曲的光线折射）。反馈强度需与设定输出正相关。 |
| **代价** | 任何越级/规则利用必须绑定即时或延迟代价（能量枯竭、神经损伤、冷却期、社会关系破裂）。代价需可量化，并在后续3章内产生连锁剧情影响。 |
| **钩子** | 章末钩子分三类：①信息钩（未解之谜/新势力登场）②状态钩（主角陷入异常/倒计时）③规则钩（设定出现反常/漏洞）。禁用“且听下回分解”式废话。 |
| **读者预期** | 开篇承诺的“核心机制”必须在10万字内完成首次完整验证；每卷结尾需兑现或升级该预期。科幻读者对“逻辑自洽”容忍度低于玄幻，任何吃书/设定冲突需在24小时内通过作者说或正文补丁修正。 |
