## 一、执行动作库（Action Library）

### A. 陌生化执行动作（6组）

| 动作名 | 触发条件 | 执行步骤 | 验收标准 |
|:---|:---|:---|:---|
| **物象剥皮** | 任何涉及武学/科技/器物的描写 | ① 列出该物象的3个工具属性 → ② 剥离全部工具属性 → ③ 追问"第一次见到它的人会注意什么" → ④ 写那个"不该写"的细节 | 读者反馈："我从没这样想过XX" |
| **感官优先** | 设定释放/能力展示/战斗场景 | ① 禁止先写效果/数值/等级 → ② 先写执行者的身体反应（瞳孔收缩/味觉/重力感知错位） → ③ 再接环境物理反馈 → ④ 最后才允许概念性描述 | 读者感受到"真实疼痛"，而非"设定很强" |
| **视角叛逃** | 描写主角/核心角色时 | ① 先用主角视角写一遍 → ② 切换到其对手/旁观者/物象视角重写同一场景 → ③ 保留"不兼容"的观察结果 → ④ 合并时保留裂痕 | 冲突双方视角信息不对等，形成张力 |
| **代价显影** | 武学修炼/科技升级/获得能力时 | ① 追问"这个力量/知识/关系会让我失去什么" → ② 选一个"难以开口说"的失去 → ③ 用生理细节具象化 → ④ 禁止用"代价是XX点经验值"等抽象描述 | 读者产生"我不想让他获得这个能力"的矛盾感 |
| **常识绞杀** | 写任何"理所当然"的情节推进时 | ① 列出3个读者可能预期的"正常走向" → ② 选那个最反直觉但逻辑自洽的走向 → ③ 让冲突在此处形成 | 读者预测失败但承认合理 |
| **碎片刺穿** | 需要快速交代世界观/势力关系时 | ① 禁止直接说明 → ② 用一个具体的物象/动作/残留痕迹展示 → ③ 让读者自己拼出关系图 | 读者"我懂了但我不确定"→翻页确认 |

### B. 冲突触发动作（4组）

| 动作名 | 操作步骤 | 禁用项 |
|:---|:---|:---|
| **立场对撞** | ① 列出冲突双方各自坚信的"正确" → ② 确认双方逻辑自洽 → ③ 找出双方逻辑的"共用前提" → ④ 破坏那个前提 → ⑤ 重构双方立场 | 禁止"我打你就因为你坏" |
| **信息绞杀** | ① 角色A知道的 ≠ 角色B知道的 → ② 写角色A基于不完整信息的决策 → ③ 让读者看到角色B的实际处境 → ④ 制造认知撕裂 | 禁止让读者上帝视角知情 |
| **动机质疑** | ① 写角色行为前先自问"换成我会这样做吗" → ② 如果答案是"会"，则强制换一个更隐蔽的动机 → ③ 检查最终动机是否源于角色自身经验而非作者植入 | 禁止"因为这是主角所以他选择善良" |
| **立场软化** | ① 写反派先写其"合理恐惧/渴望" → ② 写主角先写其"盲区/自私/亏欠" → ③ 让双方都有"说得过去的苦衷" → ④ 冲突在"两难"而非"正邪"层面展开 | 禁止脸谱化善恶 |

## 二、反馈系统（每章必须交付）

### 反馈类型矩阵

| 章节承诺类型 | 必须在章内交付的反馈 | 验收句式 |
|:---|:---|:---|
| **悬念钩子** | 线索碎片+冲突升级+未解疑问 | "读者翻页是因为想知道XX" |
| **情感冲击** | 具体感官细节+人物关系震动+情感后果 | "读者记住的是XX画面，不是情节" |
| **认知刷新** | 意外信息+逻辑重构+读者预期落空但合理 | "读者之前理解错了，因为XX" |
| **升级兑现** | 能力展示+代价确认+下一阶段目标锁定 | "读者确认主角变强了，且付出了XX代价" |

### 反馈密度要求

```
每3章 = 1次认知刷新 + 1次情感冲击 + 1次悬念升级
每10章 = 1次"预期落空"（读者预测失败但情节合理）
每30章 = 1次"世界观重构"（读者对核心设定认知颠覆）
```

## 三、代价清单（违反规则的系统惩罚）

| 违反类型 | 系统惩罚 | 触发条件 |
|:---|:---|:---|
| **同质化填充** | 标记「水章」，纳入风险门禁 | 连续2章无陌生化细节；连续3章无新冲突触发 |
| **作者越界** | 标记「自我代入」，强制重构 | 人物决策逻辑可归结为"作者本人会这样选择"；作者借角色之口输出价值观超过200字 |
| **代价缺失** | 标记「零成本」，削弱悬念 | 任何力量获取/关键决策未附不可逆代价；升级后无生理/关系/认知代价 |
| **预期欺诈** | 标记「烂尾预兆」，触发平台风险 | 铺垫宏大但机械收尾；承诺悬念但用降神解决；读者预期落空但情节不合理 |
| **工具性残留** | 标记「设定说明」，降推荐权重 | 武学/科技描写包含"效果是XX，冷却XX秒"等说明书式描述；物象仅承担功能性角色 |
| **单声垄断** | 标记「视角失真」，触发留白不足 | 单一角色垄断真相输出；冲突双方缺乏信息不对等；读者可轻易判断"作者站哪边" |

## 四、失败模式识别（预警系统）

### 高频失败模式清单

| 模式名称 | 典型症状 | 自检句式 |
|:---|:---|:---|
| **悬浮爽感** | 主角强大但无代价；反派弱智；战斗无生理反馈 | "如果去掉所有数值，这个武学还剩什么？" |
| **自我代入** | 主角决策过于正确；配角都是工具人；反派缺乏逻辑 | "如果主角不是我，这个决定还合理吗？" |
| **说明书堆砌** | 世界观用大段直接说明；能力用属性表呈现；背景用旁白交代 | "这段能用一个物象/动作替代吗？" |
| **同质循环** | 升级路径可预测；冲突解决依赖打脸；情感线套路化 | "读者能猜到下一步吗？能猜到的话怎么破？" |
| **快热冷死** | 前3章张力拉满，后续靠惯性推进；伏笔回收靠机械降神 | "第10章的冲突密度比第3章高还是低？" |
| **留白缺失** | 读者无需思考任何信息拼图；所有设定一目了然 | "读者有任何'我不确定'的时刻吗？" |

## 五、口吻模板（人物说话校验）

### 对话自检三问

```
① 这句话是角色说的，还是"作者想说的"？
② 如果把这个角色换成完全相反立场的人，这句话还能成立吗？
③ 这句话有没有说出"读者自己没想过但认同"的观点？（如果有→删）
```

### 口吻类型库

| 角色类型 | 口吻特征 | 禁用句式 |
|:---|:---|:---|
| **觉醒者** | 带有旧经验烙印的新认知；说话时会突然"卡住"；用旧世界的词描述新事物 | "作为穿越者，我当然知道..." |
| **秩序维护者** | 规则优先于情感；用规定/协议/系统语言；会忽略"不应该存在"的异常 | "按规定这不可能发生..." |
| **边缘者** | 用"不正常"的参照系；观察被中心视角忽略的细节；说话带物象而非概念 | "它让我想起..."（用一个完全无关的物象） |
| **觉醒反派** | 逻辑自洽的"正确"；用"常识"语言掩盖不可告人的目的；会在关键时刻"失语" | "我只是做了应该做的事..." |

## 六、段落节奏模板

### 节奏单位：冲击-缓冲-重建

```
[冲击] 异质性事件触发（认知/情感/关系撕裂）
    ↓ 生理细节锚定（禁止纯心理描写）
[缓冲] 角色基于自身经验的反应/决策
    ↓ 禁止"正常反应"，要求"可理解但意外"
[重建] 新状态确认 + 章末钩子（不是收尾，是下一章的起爆点）
```

### 节奏速度对照

| 节奏类型 | 适用场景 | 每千字允许的"安静段"数量 |
|:---|:---|:---|
| **快节奏** | 战斗/对峙/危机爆发 | 0-1段（每段不超过3句） |
| **中节奏** | 调查/博弈/情感铺垫 | 2-3段（每段不超过5句） |
| **慢节奏** | 内心独白/背景交代/伏笔铺陈 | 5段以上（必须带物象/陌生化细节，不能纯感想） |

## 七、章末钩子模板

### 钩子公式

```
[反常细节/违背预期] + [未解的物理/情感后果] + [迫使翻页的即时悬念]
```

### 钩子类型库

| 类型 | 结构 | 示例 |
|:---|:---|:---|
| **认知撕裂** | "我以为XX，但XX实际上是XX" | "我以为那把刀是假的，但它切开了我的手——用的是我的记忆" |
| **关系震动** | "我信任的人做了XX，但XX揭示了XX" | "他说他不会来，但他来了。来的方式是——杀死我唯一相信的那个人" |
| **代价显影** | "我得到了XX，但XX正在XX" | "第三段基因锁打开了。我看见了——我丢失的那段记忆。但同时，我的左眼永久失明了" |
| **时间裂隙** | "现在发生的事，与过去的XX矛盾" | "地图上标注这里什么都没有。但我站在的地方，和三十年前那场屠杀的遗址——是同一个坐标" |
| **立场松动** | "我必须XX，但XX让我XX" | "我必须杀死他。但杀他的方法，是用我最讨厌的那个人的武学" |

### 钩子禁用清单

- ❌ 信息预告型："想知道接下来发生了什么？敬请期待下一章"
- ❌ 空洞威胁型："危险即将来临"（没有具体威胁对象/时间）
- ❌ 机械降神型："但他不知道，命运即将改变"（无具体转折点）
- ❌ 纯悬念堆砌型："他发现了真相，但真相是——"（无实质内容）

## 九、章节自检清单

### 快速过检（每章写完必查）

```
□ 陌生化：本文出现了≥1个物象/视角的陌生化处理？
□ 代价锚定：本文的冲突/升级是否附有不可逆代价（生理/关系/认知）？
□ 立场碰撞：冲突双方是否各有自洽逻辑？主角是否面临两难选择？
□ 自我代入：人物决策是否可归结为"作者本人会这样做"？（有→改）
□ 反馈验收：本文承诺的反馈类型（悬念/情感/认知/升级）是否兑现？
□ 钩子有效性：章末钩子是否携带情感振动或认知撕裂？（不是信息预告）
□ 同质化检测：本文是否有"读者可以预测的下一步"？（有→破）
□ 口吻校验：对话是否可替换为"作者想说的话"？（是→删）
□ 说明书残留：武学/科技描写是否包含属性/数值/冷却说明？（有→改）
□ 留白检测：读者是否有"我不确定"的时刻？（无→加碎片刺穿）
```

### 深检清单（每10章/每卷必查）

```
□ 认知刷新：本卷是否有≥1次"读者对核心设定的认知颠覆"？
□ 节奏曲线：第10章的冲突密度是否比第3章更高？
□ 代价累积：主角当前拥有的力量/关系/知识，是否付出了相应的代价？
□ 阵营博弈：各方势力的立场是否都有可理解的自洽逻辑？
□ 复调张力：核心冲突是否包含"双方都有道理但无法共存"的结构？
□ 预期管理：本文承诺的升级/悬念是否都有合理兑现？有无"预期欺诈"？
```

## 十、场景适配标注

### 🔥 短故事/狼人篇可借点

| 理论要点 | 借用方式 | 操作动作 |
|:---|:---|:---|
| **陌生化物象** | 单场景陌生化植入 | 「物象剥皮」：选1个核心道具，剥离工具属性，写"第一次见"的细节 |
| **认知撕裂钩子** | 结尾反转 | 「常识绞杀」：列出3个预期走向，选最反直觉但合理的那个 |
| **代价显影** | 短篇冲击感 | 「代价显影」：力量/选择必须有具体生理代价，禁用抽象代价 |
| **口吻校验** | 对话质量 | 「对话自检三问」：防止作者借角色之口输出观点 |
| **感官优先** | 场景质感 | 先写身体反应，再写效果，最后才允许概念描述 |

### ⚔️ 科武长篇可借点

| 理论要点 | 借用方式 | 操作动作 |
|:---|:---|:---|
| **复调碰撞** | 势力博弈线 | 「立场对撞」：各方势力逻辑自洽，冲突在两难而非正邪层面展开 |
| **代价累积系统** | 升级体系重构 | 每一次基因锁开启/武学突破必须有生理/关系/认知代价，代价累积形成张力 |
| **物象陌生化链** | 世界观构建 | 「碎片刺穿」：用物象/痕迹展示势力关系，禁止直接说明 |
| **信息绞杀** | 多视角叙事 | 读者与角色共享不完整信息，制造认知撕裂 |
| **代价显影** | 苦难诚实 | 不回避主角的失败/残缺/失去，拒绝"零成本升级" |
| **认知刷新节点** | 长篇节奏管理 | 每30章设计1次"世界观重构"，让读者对核心设定认知颠覆 |

### 🚫 平台规则转化（发布/包装/风险门禁）

| 理论保护点 | 平台风险点 | 转化方案 |
|:---|:---|:---|
| **留白/复调** | 慢热导致跳出率飙升 | 将"多元碰撞"压缩进单章强冲突；留白仅限章末悬念，不做纯文学式慢热 |
