# 素材卡：美国官方UAP资料释放、舆论烟幕与异常数据治理

日期：2026-05-13
来源：AARO / NASA / NARA / Congress.gov / CIA / FBI 等美国官方公开资料
类型：技术政治/情报烟幕/异常数据治理/空天监测
可信度：primary（官方报告/官方档案页）；congressional-record（听证证词需区分“记录存在”与“事实成立”）

## 一句话
美国UAP公开资料最有用的不是“外星人”，而是官方如何用不完整数据、传感器误差、历史档案、国会听证和透明话术来管理公众注意力；这可转译为《科武纪元》中“真实资料烟幕”和“异常数据治理”素材。

## 关键事实
- AARO 是美国国防部全域异常解决办公室，维护 UAP Records、官方影像、案例解释、年度报告、Kona Blue等公开记录。
- NASA 2023 UAP Independent Study 强调：核心障碍不是缺现象，而是缺高质量、校准、带元数据、可复现的数据；AI/ML 只有在 FAIR 数据基础上才有效。
- NASA 建议把地球观测卫星、商业遥感、NEXRAD、GOES、未来多光谱/高光谱传感器、智能手机多传感器报告纳入前瞻性调查框架。
- NARA Project BLUE BOOK 记录：1947-1969 共 12,618 起报告，701 起仍为 unidentified；美国空军结论称未发现国家安全威胁证据、超出现有科学技术证据或外星飞行器证据。
- NARA 明确：档案馆认证副本真实性，不认证文件内容真实性；这对“官方收录≠官方确认事实”很重要。
- Congress.gov UAP 听证资料属于官方记录，但证人说法、惊人断言、项目名需要降级使用，只能作为“公开政治叙事/透明压力/烟幕舞台”。
- AARO UAP Records 中包含卫星耀斑、强制透视、视差等解释性论文，说明很多异常可由传感器/观测几何解释。

## 可用细节
- 屏幕字段：`SENSOR_CALIBRATION: MISSING`、`METADATA_GAP: TRUE`、`CASE_STATUS: UNCHARACTERIZED`、`PUBLIC_RELEASE_LEVEL: DECLASSIFIED_SUMMARY`。
- 机构冲突：NASA要开放数据，DoD强调国家安全，国会要求透明，情报机构维持模糊。
- 舆论操作：不伪造UAP，只集中释放真实但不完整、可解释、带争议的档案，让公众和媒体自发填空。
- 调查误差：红外目标锁定、雷达轨迹、视差、星链耀斑、气球、无人机、高空平台、秘密试飞。
- 档案陷阱：官方档案页证明“档案存在”，不证明“档案中的每句传闻成立”。

## 小说映射
- 可映射章节/卷：卷五技术政治线、白盾/星穹舆论战、月球/深空异常信号线、后续外层威胁线。
- 对应变量：异常数据治理、官方透明烟幕、多机构权限壁垒、传感器误差、公众注意力转移、真实资料制造的谎言。
- 使用建议：
  1. 写一场“UAP档案公开听证”吸走舆论，实际掩盖轨道节点/深空信号/铁幕实验事故。
  2. 让主角团发现公开资料中90%可解释，真正有价值的是剩下10%的元数据缺口。
  3. 把NASA式科学框架转成流云调查流程：多源传感器校准、元数据补全、背景模型、异常点筛选。
  4. 把NARA免责声明转成台词：“公开，不等于承认；收录，不等于真实。”

- 不把国会证人证词写成官方确认事实。
- 不把“官方收录某文件”写成“官方承认文件内容属实”。
- 不用阴谋论站、自媒体、播客当事实主源。
- 现实机构名用于小说时需虚构化处理，避免直接指控。
