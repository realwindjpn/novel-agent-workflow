## 0. 总执行口令

> **任何一章都不能只是“从A走到B”。**  
> 每章必须让读者获得：  
> **一个新信息 + 一个新危机/期待 + 一笔未来要清算的账。**

# 1. 写作前任务卡字段更新

以后开写每章前，任务卡必须补齐以下字段。

## 1.1 章节功能字段

```text
本章类型：
[ ] 过渡章
[ ] 冲突章
[ ] 高潮章
[ ] 结算章
[ ] 改文补强章

本章不能被跳过的理由：
1.
2.
3.
```

要求：  
如果本章删掉后，后文仍能顺畅理解，说明本章无效，必须重写。

---

## 1.2 期待感字段

```text
本章制造/推进的期待：

[ ] 敌方布局
[ ] 主角防范
[ ] 科技模块升级
[ ] 武道境界突破
[ ] 阵营态度变化
[ ] 旧伤/反噬爆发
[ ] 文明级危机逼近
[ ] 信息差扩大
[ ] 代价即将兑付

具体期待一句话：
读者看完本章后，会期待：
```

示例：

```text
读者看完本章后，会期待：
主角刚拿到的“星核骨骼”是否会在三章后烧毁他的脊髓神经。
```

---

## 1.3 冲突字段

```text
主角必须做什么：
主角不能退让的理由：
如果失败，具象代价：

对手必须阻止/争夺什么：
对手不能退让的理由：
如果失败，具象代价：

双方目标是否互斥：
[ ] 是
[ ] 否，需重设冲突
```

禁止写：

```text
为了正义。
为了变强。
为了保护大家。
```

必须改成：

```text
如果我不在十二分钟内夺回反应炉，地下城三十七万人会被冷冻剂倒灌。
如果我让他带走星核，我的武道根基会被联盟判定为异种污染，终身剥夺晋升资格。
```

## 1.5 动作链字段

```text
触发事件：
物理执行：
反作用：
二次决策：

每一步涉及：
科技模块：
武道法门：
能量消耗：
可观测反馈：
```

最低标准：

```text
触发 → 执行 → 反作用 → 二次决策
```

不能只写：

```text
主角冲上去，一拳打败敌人。
```

必须写成：

```text
触发：敌方纳米锁链封住主角右臂经脉。
执行：主角强行启动“雷骨增幅”，用崩山拳震断锁链。
反作用：锁链未断，反而把雷骨频率反馈进心脏，心律失控。
二次决策：主角放弃右臂爆发，改用左腿踏碎地面磁轨，制造敌方算法误判。
```

---

## 1.6 章末钩子字段

```text
本章章末钩子类型：

[ ] 敌方布局钩
[ ] 代价兑付钩
[ ] 信息差钩

章末最后三句话：
1.
2.
3.
```

要求：  
章末不能只是“他们出发了”。  
必须是“他们出发了，但读者知道路上有账”。

# 2. 作家OS执行规则

---

## 2.1 过渡章执行补丁

### 原错误模式

```text
主角赶路。
主角开会。
主角听解释。
主角换地图。
主角休息。
```

这些都不是章节，只是素材。

---

## 正确执行动作

每个过渡章至少塞入以下一项：

```text
1. 新期待
2. 新危机
3. 新信息差
4. 对手布局
5. 主角防范
6. 旧代价反噬
7. 高潮后结算
```

---

## 过渡章段落节奏

推荐节奏：

```text
第1段：承接上一章结果，不超过300字。
第2段：展示结果带来的物质变化。
第3段：展示配角/阵营反应。
第4段：插入新信息或异常反馈。
第5段：主角做出下一步防范/判断。
第6段：章末钩子，告诉读者下一笔账在哪里。
```

---

## 过渡章动作模板

```text
【承接】
上一战/上一事件结束后，主角获得了什么，失去了什么。

【结算】
物质奖励：
情感反馈：
阵营态度：
配角反应：

【异常】
奖励/身体/装备/情报中出现一个不对劲的细节。

【判断】
主角用科技逻辑 + 武道经验推演这个异常。

【防范】
主角做一个主动动作：
加密、闭关、试验、派人、拆解、伪装、设伏。

【钩子】
敌人已经知道/误判/准备利用这个异常。
```

---

## 科武示例

```text
战后，主角拿到异种晶核。

结算：
军部给他三级功勋，武道院却拒绝记录他的战绩。

异常：
晶核在靠近他丹田时，出现与他心跳同步的频率。

判断：
这不是能源共鸣，而是某种寄生协议。

防范：
主角没有立刻炼化晶核，而是把它接入废弃机甲的反应堆，模拟自己的气血波动。

钩子：
三百公里外，异种母巢睁开复眼：“他没有吃下去。”
```

---

## 过渡章失败模式

```text
失败1：纯赶路
修复：赶路途中加入追踪、旧伤、敌方监控、未知信号。

失败2：纯开会
修复：会议必须产生立场冲突、资源分配、责任甩锅、隐藏交易。

失败3：纯解释设定
修复：设定必须影响主角下一步选择，并制造代价。

失败4：配角闲聊过多
修复：配角话题必须回流主线，提供情报、态度、误导或资源。

失败5：高潮后无结算
修复：补一章奖励、损失、态度翻转、后遗症、敌方反应。
```

# 3. 冲突章执行补丁

---

## 3.1 冲突核心口令

> 冲突不是“打起来”。  
> 冲突是：**双方都有不能退让的理由，并且彼此目标互斥。**

---

## 3.2 冲突章必填动作

```text
主角口吻：
“我必须 X，否则 Y。”

对手口吻：
“我必须阻止/夺走/毁掉 X，否则 Z。”

Y/Z必须是具体损失。
```

---

## 人物口吻模板

### 主角口吻

```text
“我可以输一场，但不能让他们拿走反应炉。地下城的热循环只剩十八分钟，断供后，先死的是外城三万七千个孩子。”
```

### 对手口吻

```text
“你以为我想炸掉这里？不炸，母巢坐标就会暴露。到时候死的不是三万人，是整个第七码头星域。”
```

### 配角口吻

```text
“你们两个都在算大账，可我妹妹就在冷冻舱里。谁敢关电，我先杀谁。”
```

### 反派口吻

```text
“别跟我谈人命。人命是燃料，文明才是结果。”
```

---

## 3.3 冲突段落节奏

推荐节奏：

```text
1. 目标亮明：双方争夺同一资源/人/时间窗口。
2. 不能退让：双方各说或各做一次证明。
3. 第一轮行动：主角按计划出手。
4. 违反预期反馈：计划失效，代价出现。
5. 对手升级：对手亮出更深动机或底牌。
6. 主角二次决策：主角付出具体代价换突破。
7. 临时结果：胜/败/半胜。
8. 代价挂账：身体、资源、关系或信息差留下后患。
9. 章末钩子：下一场冲突的爆点。
```

---

## 3.4 冲突章模板

```text
【目标】
主角要：
对手要：
目标互斥点：

【不能退让】
主角失败代价：
对手失败代价：

【第一动作链】
触发：
执行：
反馈：
二次决策：

【物理反馈】
声音：
光：
热：
震动：
辐射/污染：
身体损伤：

【违反预期】
主角以为：
实际发生：

【代价】
本章付出：
是否可逆：
何时清算：

【临时胜负】
主角得到：
主角失去：
对手得到：
对手失去：

【章末钩子】
敌方布局/代价兑付/信息差：
```

---

## 科武冲突示例

```text
目标：
主角要夺回星舰中枢，阻止跃迁失败。
对手要强行跃迁，把舰队带进异种伏击圈。

主角不能退让：
跃迁失败，舰上九千二百人会被空间潮汐切成碎片。

对手不能退让：
不跃迁，他体内的异种孢子会在十分钟后暴露，他会被军法处活体解剖。

动作链：
触发：对手锁死中枢权限。
执行：主角用“脊骨雷纹”强行接入舰桥神经接口。
反馈：接口承载不足，烧毁主角左臂12%运动神经。
二次决策：主角放弃手动夺权，改为用武道气血模拟舰长生物密钥。

违反预期：
主角以为敌人只是叛徒。
实际发现：对手也是被异种寄生的幸存者，正在用全舰生命赌自己的清白。

代价：
左臂神经损伤12%，三章内若不修复，将影响刀法爆发。

章末钩子：
舰船成功脱离，但医疗舱里，对手尸体的瞳孔重新聚焦。
```

# 4. 高效改文执行补丁

---

## 4.1 改文优先级

```text
1. 毒点
2. 动机
3. 代价
4. 钩子
5. 节奏
6. 文笔
```

不要先修辞藻。  
数据差通常不是句子不美，而是章节没用、人物没动机、代价不疼。

---

## 4.2 数据差章节诊断

每个差章只问五个问题：

```text
1. 有没有明确毒点？
2. 有没有新信息？
3. 有没有新期待？
4. 有没有具体代价？
5. 跳过本章会不会影响后文？
```

---

## 4.3 毒点处理动作

```text
小毒点：
直接删。

中毒点：
保留功能，替换表达。

大毒点：
整段重写，重新设计动机和代价。

结构毒点：
前后章顺序调整，提前铺垫，延后解释。
```

---

## 常见毒点与修复

```text
毒点1：主角突然降智
修复：补一段动机预告，让他知道风险但有更大代价逼迫。

毒点2：反派突然送人头
修复：给反派不能退让的理由，让他不是蠢，而是赌不起。

毒点3：配角抢戏
修复：删掉与主线无关的情绪戏，只保留情报、资源、态度变化。

毒点4：设定解释太长
修复：把设定拆进动作反馈里，让读者边看后果边理解原理。

毒点5：转折生硬
修复：在转折前补≤200字动机性内心独白。

毒点6：爽点不爽
修复：爽点前先打压，明确别人不看好、资源不足、时间不够、代价极高。
```

---

## 4.4 改文模板

```text
【原章节问题】
毒点：

跳章风险点：

【保留功能】
本章必须留下的信息：

【补强动作】

```

# 5. 人物内心独白补丁

---

## 5.1 可保留的内心独白

科武长篇允许保留两类内心：

```text
1. 设定推演
2. 动机预告
```

---

## 5.2 必删的内心独白

```text
1. 重复表达痛苦
2. 反复强调愤怒
3. 作者替人物讲道理
4. 不影响选择的感慨
5. 和下一步行动无关的情绪反刍
```

---

## 5.3 动机性内心独白模板

```text
主角看见/感知到：
他根据科技/武道规则推断：
如果不做某事，会产生具体代价：
所以他决定：
```

示例：

```text
林烬看着掌心逐渐发黑的雷纹。

雷骨不是在恢复，而是在反向充能。刚才那一击没有打散异种孢子，反而让它记住了他的气血频率。

如果现在退，三小时后，整支小队的生命监测都会被母巢截获。

所以他不能回城。

他要带着这枚孢子，反向找到母巢的位置。
```

# 6. 段落节奏补丁

---

## 6.1 高潮前

执行动作：

```text
1. 打压主角。
2. 堆时间限制。
3. 堆资源不足。
4. 堆他人不信任。
5. 堆敌方优势。
6. 堆信息差。
```

目标：  
让读者觉得“主角必须赢，但很难赢”。

---

## 6.2 高潮中

执行动作：

```text
1. 主角按计划出手。
2. 计划被敌人破解。
3. 付出具体代价。
4. 换方案。
5. 用前文伏笔破局。
6. 得到半胜或惨胜。
```

目标：  
胜利必须像是挣来的，不是作者送的。

---

## 6.3 高潮后

执行动作：

```text
1. 发奖励。
2. 报损失。
3. 写配角反应。
4. 写阵营态度。
5. 写身体后遗症。
6. 写敌方下一步。
```

目标：  
让爽点落地，让下一段剧情自然启动。

---

# 7. 章末钩子模板

---

## 7.1 敌方布局钩

```text
主角以为事情结束。
切到敌方/暗线。
敌人确认主角已落入下一层布局。
```

示例：

```text
林烬关闭了反应炉。

同一时间，三光年外，黑箱里的第二枚反应炉悄然亮起。

有人低声道：“他果然选择救城。那就说明，他还不够像一个文明领袖。”
```

---

## 7.2 代价兑付钩

```text
本章行动暂时成功。
身体/装备/关系出现异常。
提示代价即将爆发。
```

示例：

```text
他终于拔出了刀。

可刀柄上没有血。

只有一层从他掌纹里渗出的银色金属，正沿着手腕，缓慢爬向心脏。
```

---

## 7.3 信息差钩

```text
读者知道，主角不知道。
或者主角知道，其他人不知道。
制造下一章紧张感。
```

示例：

```text
林烬没有告诉任何人，刚才他听见的不是异种嘶鸣。

而是一句人类古语。

“欢迎回家。”
```

# 9. 短故事/狼人篇可借点

适合短篇、狼人杀、悬疑小篇章使用。

## 可借点1：信息差钩子

狼人篇最适合用：

```text
读者知道有人说谎，但不知道谁。
主角知道规则异常，但不能公开。
配角知道身份秘密，但误导主角。
```

套用模板：

```text
本章结束时，让读者多知道一条信息，或者让主角少知道一条关键信息。
```

---

## 可借点2：身份冲突

狼人篇冲突不要只写“投票”。  
要写每个人为什么不能退。

```text
狼人不能退：退了身份暴露，今晚必死。
预言家不能退：退了好人阵营失去唯一验人信息。
平民不能退：投错一次，人数差进入狼队屠边线。
```

---

## 可借点3：短章章末钩

短故事章末适合三种钩子：

```text
1. 某人发言前后矛盾。
2. 死者留下的信息被误读。
3. 主角发现规则和主持人说的不一样。
```

示例：

```text
所有人都以为昨晚死的是猎人。

只有林烬看见，尸体的手指并不是指向狼人牌。

而是指向天花板上的摄像头。
```

---

## 可借点4：压缩过渡

短篇不写长过渡。

```text
赶路 = 一句话。
会议 = 只留冲突发言。
解释规则 = 放在投票动作中展示。
```

# 10. 科武长篇可借点

适合《科武纪元》主线长期使用。

## 可借点1：星域转场必须带账

错误：

```text
舰队跃迁三天后抵达边境星。
```

正确：

```text
舰队跃迁期间，主角旧伤复发，舰载AI发现他的气血频率与异种信号重叠。
```

转场必须挂载：

```text
敌方布局
旧伤反噬
科技异常
阵营争议
武道推演
文明危机预告
```

---

## 可借点2：科技派 vs 武道派长期互斥动机

不要只写理念争吵。

要写具体代价：

```text
科技派：
如果不改造人体，人类舰队将在三年内被异种数量压垮。

武道派：
如果全面改造，人类气血根基会被算法接管，百年后再无自主突破者。
```

---

## 可借点3：代价数字化

科武长篇的代价要可记录、可升级、可清算。

```text
寿元减少7年。
丹田裂纹增加3道。
左臂神经损伤12%。
战舰损毁17艘。
第九卫星城死亡4216人。
军部信用评级下降两级。
异种污染指数升至39%。
```

---

## 可借点4：结算章是爽点，不是水字数

战后必须写：

```text
主角获得什么技术/功法/权限。
主角失去什么身体资源/政治信用/队友。
别人如何重新评价主角。
敌人如何调整下一步计划。
```

---

## 可借点5：设定推演必须变成行动

错误：

```text
解释三页量子武道原理。
```

正确：

```text
主角在战斗中发现量子武道的缺陷：
每次折叠气血，都会在骨髓里留下不可逆热斑。
于是他决定只折叠左半身，把右半身留给下一次爆发。
```

---

# 11. 最终自检清单

每章写完后直接勾：

```text
[ ] 本章有新信息。
[ ] 本章有新期待。
[ ] 本章有具体代价。
[ ] 本章有不能退让的双方动机。
[ ] 本章没有纯赶路/纯交代。
[ ] 本章配角服务主线。
[ ] 本章设定影响行动。
[ ] 本章转折前有动机预告。
[ ] 本章章末有钩子。
[ ] 本章被跳过后，后文会断。
```

如果有三项以上没勾，重写。  
如果“本章被跳过后，后文不会断”，整章重构。
