# 《科武纪元》编辑学习官｜平台规则拆解报告

## 1 课程核心判断（≤6条）
1. **流量入口转移**：书末双列是核心转化场，算法按“点击率×互动率”决定二次推荐权重。
2. **内容去硬广化**：社区分发排斥硬广与无意义水贴，偏好“活人感”与真诚讨论。
3. **标签即路由**：`#话题标签`+`带书卡`是精准匹配潜在读者的标准配置，缺一不可。
4. **官方活动是冷启动杠杆**：参与「番茄掌柜」指定话题可定向获取曝光与资源倾斜。
5. **封面/标题定生死**：长图封面+悬念标题决定CTR，正文信息密度决定赞评留存。
6. **二创/讨论是长效引擎**：剧情/角色/设定讨论类内容天然具备高互动率与长尾推荐价值。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则（基于平台发帖机制） |
|:---|:---|
| **平台规则** | ①发布需App≥7.0.3；②封面禁无意义/低质图，审核不通过直接拦截；③正文必须关联书卡+添加#标签；④分发逻辑=CTR×互动率，水贴无推荐权重。 |
| **开篇（帖子微开篇）** | 标题与首段需在3秒内抛出核心议题或悬念，替代传统小说开篇的“世界观铺陈”，直接切入可讨论点。 |
| **节奏（互动与分发）** | 放弃长篇铺叙，采用“抛题-留白-引导站队/补充”的短结构；发布后2小时内高频回复评论，拉升初始互动权重以触发算法推荐。 |
| **冲突（话题设置）** | 主动设置可辩论议题（如设定合理性、角色抉择、路线对比），利用观点对立激发评论区盖楼，制造数据冲突点。 |
| **人物/题材** | 聚焦高人气角色或核心设定拆解；短故事/热点稿需绑定当期社会/科幻热点#标签，实现跨圈层精准引流。 |
| **改编（二创接口）** | 预留开放设定（如配角背景、未公开草图、分支剧情），鼓励读者UGC，反哺原著热度并积累IP改编素材库。 |

## 3 科武适配
### ✅ 可用点
- **硬核设定可视化**：利用长图/AI生图工具输出“科武能量流转图”“机甲/武学结构拆解”，降低科幻阅读门槛，提升书末停留时长。
- **世界观深度讨论**：发起“物理法则与武道融合的合理性”“第X纪元科技树推演”等议题，筛选高粘性、高付费意愿的科幻核心读者。
- **官方活动借势**：精准参与`#科幻脑洞` `#硬核设定` `#完结推演`等官方标签，获取定向流量池与资源位。

### ❌ 不可硬套点
- **饭圈化CP炒作**：《科武纪元》重逻辑与格局，过度娱乐化/拉踩讨论会稀释科幻严肃基调，导致核心读者流失与追读断崖。
- **碎片化水贴引流**：长篇科幻依赖连贯叙事，用短平快段子/无意义图骗点击，会破坏书末转化信任，拉低整体账号权重。
- **AI生图滥用**：科幻需严谨美学，低质/违和AI图易被判定“无意义”或引发读者出戏，必须人工精修或明确标注“概念草图”。

## 4 编辑检查表（≤10条）
- [ ] 封面是否为高清长图/社区风？（非硬广排版、非模糊/拉伸）
- [ ] 标题是否含明确议题/悬念词？（≤20字，无废话）
- [ ] 正文是否已准确关联《科武纪元》书卡？
- [ ] 是否添加≥2个精准#话题标签（含1个官方/热点）？
- [ ] 内容是否具备“活人感”？（作者视角/幕后/设定拆解，非机器文案）
- [ ] 是否设置明确互动钩子？（如“你支持A路线还是B路线？评论区见”）
- [ ] 是否@番茄掌柜或参与当期官方活动？
- [ ] 发布后24h是否跟进高赞评论并引导二创/补充设定？
- [ ] 数据复盘：CTR＜5%或赞评比＜1:10，是否优化标题/封面重发？

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 严格遵循SOP：`选题定位 → 封面/标题打磨 → 正文带卡/标签 → 发布 → 2h内高频互动 → 48h数据复盘 → 迭代下一帖`。断链即失效。 |
| **物理反馈** | 所有讨论必须具象化输出（战力对比表、场景分镜、能量流转示意图、设定参数），拒绝纯文字抽象描述；以“点赞/盖楼/二创投稿数”为可量化反馈指标。 |
| **代价** | 硬广/水贴 = 算法降权+书末曝光清零；过度剧透/敷衍回复 = 核心读者信任破产；标题党跨类型 = 高跳出率+账号权重受损。违规成本不可逆。 |
| **钩子** | 标题/首段必须植入“可验证/可反驳”的争议点或悬念（例：“科武第三阶突破为何需要反物质？”“主角放弃X选择Y，是败笔还是伏笔？”），强制触发点击与评论。 |
| **读者预期** | 发帖前明确内容属性（推书/设定讨论/二创征集/完结感言），内容密度与形式必须严格匹配该预期。科幻长篇读者预期为“逻辑自洽+硬核拓展”，短故事/热点稿预期为“情绪共鸣+即时互动”，严禁错位交付。 |
