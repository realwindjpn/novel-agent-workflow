# 《科武纪元》编辑学习官｜平台规则提炼报告

## 1 课程核心判断（≤6条）
1. **收益逻辑绑定留存**：长篇靠“广告+免费”模式分成，短故事靠多端（番茄/头条/抖音）阅读解锁量分成，内容必须服务于“防跳出、促翻页”。
2. **体裁分轨明确**：长篇走连载签约（2万字申请，8万字推荐底线）；短故事走单篇完结（200-3万字，必须完本上传）；出版走独立通道且明确排除科幻。
3. **短故事结构铁律**：强冲突钩子开篇→大开大合反转→快速解决矛盾→情绪升华收尾，一镜到底不拖沓。
4. **题材包容但有限制**：长篇含科幻合规；短故事以言情/悬疑/现实为主，科幻需嫁接强情绪；出版业务一票否决科幻/奇幻/悬疑等架空题材。
5. **多端分发即流量池**：签约长篇同步APP+SDK（头条/抖音），内容需预留短视频切片爆点；短故事收益直接挂钩跨端解锁数据。
6. **福利与数据挂钩**：全勤/连载/完本奖为基础保障，魁星/星火等计划激励高数据作品，创作需以“稳定更新+核心指标达标”为前提。

## 2 可执行编辑规则
| 维度 | 规则提炼（基于原文） |
|:---|:---|
| **开篇** | 短故事强制要求“强剧情冲突+强矛盾内容钩子吸睛开头”；长篇虽未明写，但结合广告分成逻辑，前3章必须抛出核心危机/金手指/世界观锚点，3000字内完成读者代入。 |
| **节奏** | 短故事“节奏紧凑，快速拉开故事，解决矛盾”；长篇需维持“广告曝光-留存”循环，每3-5章设置阶段性爽点/悬念爆点，严禁无推进的设定堆砌或日常水文。 |
| **冲突** | 短故事依赖“大开大合的反转剧情和浓烈的情感氛围”；长篇需构建阶梯式矛盾链（生存危机→资源争夺→势力博弈→规则颠覆），每卷设明确冲突峰值与解决路径。 |
| **人物** | 短故事多用一/三人称限知视角强化“代入感沉浸感”；长篇主角需目标明确、成长线可量化，配角功能化服务于主线推进，避免群像失焦稀释广告留存。 |
| **题材** | 科幻属长篇合规赛道；短故事若写科幻需强化“现实映射+强情绪张力”以适配平台基本盘；出版明确拒收科幻，放弃传统出版幻想，专注线上流量与IP衍生。 |
| **改编** | 长篇同步SDK（头条/抖音），关键场景需预留“高视觉冲击/强情绪张力”名场面，适配短视频切片与解说引流；短故事标题/简介需具备强传播性与话题性，直接拉动解锁量。 |
| **平台规则** | 长篇：≥2万字申请签约，≥8万字触发推荐分发；短故事：200-3万字，完结状态一次性上传或邮箱内投；收益与广告展示/点击、跨端解锁量强绑定，断更/水文直接断流。 |

## 3 科武适配：《科武纪元》专项
### ✅ 可用点
- **长篇主赛道**：完全契合“免费长篇+广告分成”路径，按2万/8万节点推进即可触发平台推荐机制。
- **单元剧节奏嫁接**：可借鉴短故事“强钩子开篇→快速解决矛盾”结构，用于长篇单卷/副本设计，提升前期完读率与广告收益。
- **多端视觉化适配**：“科武”设定（机甲/武道/星际战场/能量体系）天然具备高概念视觉属性，易转化为抖音/头条短视频切片，反哺长篇流量。
- **热点稿转化**：将长篇中的“高概念设定+强冲突片段”拆解为1-3万字独立短故事/热点稿，投短故事专区或头条号，测试市场反馈并导流主书。

### ❌ 不可硬套点
- **出版路径**：原文明确“不包含科幻、悬疑、灵异、奇幻等架空题材”，科武长篇不可走出版向慢节奏/纯文学路线，需彻底转向网文商业化逻辑。
- **短故事单篇完结逻辑**：长篇不可压缩为“快速拉开故事，解决矛盾”的短故事结构，科武需维持长线伏笔、体系升级与世界观展开，避免主线提前崩盘。
- **纯情绪流主导**：短故事依赖“浓烈情感氛围”，科武长篇必须以“设定推演+武力升级+势力博弈”为骨架，情绪仅作为节奏调节剂，不可本末倒置。

## 4 编辑检查表（10条以内）
1. 前2万字是否完成核心设定抛出与主角初始危机建立？（签约门槛）
2. 第8万字前是否完成首个大高潮/世界观初显？（推荐分发底线）
3. 每3-5章是否设置明确悬念/冲突爆点或阶段性奖励？（广告留存逻辑）
4. 开篇3000字内是否包含强动作/强矛盾钩子？（短故事节奏借鉴）
5. 科幻/武道设定是否具备可解释的物理/能量逻辑？（科武基调）
6. 主角行动是否具备明确短期目标与长期驱动力？（防水文）
7. 章节末尾是否预留“断章钩子”（未解危机/反转预告/新势力介入）？（促翻页）
8. 是否规避出版向的“纯文学慢节奏/意识流”写法？（平台适配）
9. 关键场景是否预留“高视觉冲击/强情绪张力”片段？（短视频切片适配）
10. 全文是否严格遵循“冲突-行动-代价-升级”循环？（长篇节奏铁律）

## 5 对作家角色的输入要求
- **动作链**：禁止静态描写堆砌。每个场景必须包含“触发条件→决策→执行动作→结果反馈”完整链条。科武战斗需拆解为“起手式/能量运转→交锋轨迹→环境破坏→胜负判定”，动作必须推动剧情或暴露信息。
- **物理反馈**：所有超自然/科幻设定必须落地于物理/能量规则。武道发力需体现肌肉负荷/骨骼承压/空气爆鸣；机甲/武器需标注能耗/冷却/材质损耗/后坐力。禁用“毫无代价的爆发”与“无视物理法则的悬浮描写”。
- **代价**：每次越级战斗、突破境界、使用禁忌科技/功法，必须支付明确代价（寿命折损/经脉暗伤/资源枯竭/势力追杀/道德困境）。代价需写入后续剧情账本，成为新冲突的燃料，而非一次性消耗品。
- **钩子**：每章结尾必须设置“信息差钩子”（新线索/身份反转/规则漏洞）或“生存钩子”（倒计时/致命威胁逼近/资源断供）。开篇前3章需完成“世界观锚点+主角核心诉求+首个不可逆危机”三重钩子，确保首屏跳出率<30%。
- **读者预期**：严格遵循“承诺-兑现-升级”契约。开篇承诺的“科武体系/金手指/复仇目标”必须在10万字内给出首次实质性兑现；后续每卷需兑现新承诺并拔高预期阈值。禁止“画饼不填”“机械降神破局”或“战力通货膨胀失控”，预期管理直接决定广告分成天花板。
