# 中文 README 改写设计

## 目标

把根目录 README 改为一份自然、第一人称的中文项目说明：承认项目源于
`realwindjpn/novel-agent-workflow`，同时连贯地说明我在后续迭代中参与的
网页运行器、本地 MCP、自由创作工作台、书库和可恢复回收区。

## 范围

- 只改 `README.md`。
- 保留项目的启动命令、端口用途、目录约定和安全边界。
- 不逐条复述提交、不把历史计划复制进 README，也不改运行代码、测试、
  `web/README.md` 或历史文档。

## 叙述方式

README 以“这个项目原本解决什么、我接手后想把它用起来、现在能怎样用”
为主线。开头用一段简短的第一人称说明参与范围；正文以连贯的小节介绍
浏览器工作台、本地 MCP 与双端口隔离、自由创作的两次确认和浮动对话、
本地书库与回收区。技术限制直接写在对应功能旁边，避免单独堆砌功能清单。

README 还应有一个短的“怎么用”段落，采用截图所示的直观风格：先给出
启动命令和应打开的地址，再用少量步骤说明选书、自由创作、文件抽屉与
回收区。它只解释日常操作，不重复 `web/README.md` 的协议细节。

## 验收

- 全文主要内容为中文，保留必要的命令、路径、协议与标识符英文原文。
- 能区分原项目工作流核心与我参与的产品化/本地化扩展，不暗示我独自创作
  原项目全部能力。
- 新用户能找到启动入口、应访问的本地地址，以及公网演示端不写磁盘的限制。
- 日常使用入口以短命令和步骤呈现，读者无需先理解 MCP 协议即可开始使用。
- `git diff --check` 通过。
