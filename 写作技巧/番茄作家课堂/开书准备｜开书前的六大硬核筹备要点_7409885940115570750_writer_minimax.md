## 一、执行原则（3条铁律）

> 原文转化逻辑：编辑规则 → 可验证的操作动作

### 铁律01｜动作先于理论
**编辑原文**：“主线极简：全书驱动力必须能用一句话（≤15字）精准概括”
**作家OS转化**：
```
在写任何场景之前，先填入任务卡的【一句话主线】字段。
如果填不出来，说明核心驱动力还没找到，继续推演直到能用大白话说清楚。
禁止进入正文写作，直到该字段完成。
```

### 铁律02｜代价绑定资源
**编辑原文**：“金手指是放大器非代打器”
**作家OS转化**：
```
每次金手指激活，必须同时触发一个【资源消耗】字段更新。
资源类型：能量/寿命/仇恨值/阵营信用/神经负荷/冷却时间
执行标准：消耗量必须占角色当前持有量的≥5%，否则爽感不足。
```

### 铁律03｜物理即承诺
**编辑原文**：“禁止跨级无逻辑越阶、意念秒杀或跳过物理交互过程”
**作家OS转化**：
```
战斗/对抗场景必须包含以下五个节点：
感知（对手状态/环境变量）→ 决策（选择战术）→ 发力（能量/力量输出）→ 命中（效果展示）→ 反制（对手应对）
缺少任一节点，视为未完成场景，写完必须回溯补全。
```

## 四、章节自检清单（逐章执行）

> **执行时机**：每章写完后、提交审核前
> **通过标准**：10项全部√，若有×需回溯修改

### 基础检查（5项）

```
□ 01｜主线存在感
本章节是否推进【一句话主线】？
若无推进，本章是否作为必要铺垫（需标注原因）？
若既无推进又非必要铺垫，本章需删除或并入其他章节。

□ 02｜力量体系一致性
本章涉及的力量/科技/武道表现是否符合【力量体系量化表】？
禁止：临时升级未标注门槛、越阶无代价、能力超出设定上限。
若发现不一致，回溯至【力量体系量化表】重新校准。

□ 03｜金手指边界合规
本章金手指激活是否标注"放大边界"与"非替代区"？
主角是否在金手指辅助下仍需自己完成核心决策/意志/技术？
若金手指替代了主角核心能力，本章需重构。

□ 04｜物理反馈存在性
本章每次力量对抗/体系跃升后是否有可观测的物理/生理变化？
禁止：纯数值播报（"战力提升30%"）、意念秒杀（"我赢了"）、跳过过程。
若缺失物理反馈，补充场景描写。

□ 05｜代价结算完整性
本章主角是否因行动支付了明确代价？
代价类型：能量消耗/寿命折损/仇恨值累积/冷却时间/神经磨损/阵营信用/资源透支
代价是否≥角色当前持有量的5%？
若代价未标注，本章需补入代价结算。
```

### 进阶检查（5项）

```
□ 06｜反派逻辑链验证
本章反派行为是否基于独立逻辑链？
禁止：为衬托主角而临时降智、决策前后矛盾、行为缺乏利益动机。
若发现降智，回溯反派人设，重新推导决策逻辑。

□ 07｜人物功能补位
本章是否有角色补位了主角的短板？
补位角色是否明确功能（如：情报分析、技术支持、情感锚点、战力补充）？
若人物无功能补位，需评估该角色是否存在必要性。

□ 08｜卷纲闭环验证
本章是否为"目标-破局-BOSS-线索"闭环的某个节点服务？
本章行动是否推进了闭环完成？
若本章偏离卷纲，回溯卷纲，确认是否需要调整本章走向。

□ 09｜章末钩子合规
本章末是否有钩子？
钩子类型：信息差悬念/资源倒计时/转场接口（至少一种）
钩子是否绑定下一章/下卷可兑现承诺？
若钩子为开放式留白或纯情绪收尾，本章需补入有效钩子。

□ 10｜平台适配验证
本章前300字是否完成"核心爽点类型"锚定？
本章是否符合目标平台节奏要求（如：番茄需快节奏/飞卢需高密度爽点）？
若节奏拖沓，压缩至每1000字至少包含一个冲突/转折。
```

## 五、标记说明（可借点分类）

### 🐺 短故事/狼人篇可借点

```
1.【金手指边界】- 短篇需在极短篇幅内建立爽点逻辑，金手指克制模板可直接套用。
   格式：激活金手指→有限放大→代价即时结算→爽点兑现

2.【章末钩子】- 短篇单章节需完成闭环，钩子可转化为"下一章追读承诺"或"付费节点"。
   格式：信息差悬念/资源倒计时→下章必须兑现

3.【人物功能补位】- 短篇角色≤3个核心，功能互补模板确保人物不冗余。
   格式：主角+短板→配角A补位功能B→反派独立逻辑链

4.【力量体系快速量化】- 短篇无法展开长设定表，需用"对比锚定法"：主角能打X个普通敌人。
   格式：境界A vs 境界B → 量化换算（如：武师级=能硬抗轻型脉冲炮）

5.【代价即时化】- 短篇代价需在本章/本故事内兑现，不可留长线伏笔。
```

### 🚀 科武长篇可借点

```
1.【体系量化防崩】- 长篇力量体系复杂，需严格按量化表执行跨境界对抗。
   格式：境界-门槛-战力-待遇四要素全标注，能量护盾衰减率/神经负荷阈值需明确。

2.【卷纲控场】- 长篇易发散，每卷必须有独立闭环，防止设定堆砌导致节奏失速。
   格式：每卷聚焦一个星区/势力/科技树节点→完成"目标-破局-BOSS-线索"闭环→转场

3.【反派镜像构建】- 长篇反派需多层次、多势力，每派需独立逻辑链与主角形成资源/规则博弈。
   格式：正派体系→逻辑推导对立势力→共存/对抗硬性理由→单卷可独立成副本

4.【世界观模块化】- 长篇需预留IP改编接口，技能/装备/势力需具象化便于视觉转化。
   格式：势力地图/科技树/修炼树模块化→单卷可独立成副本→后期可拆分短剧/游戏

5.【金手指克制升级】- 长篇金手指需持续克制，不可越界替代主角核心能力。
   格式：古武神经同步数据库→提供路径/演算→战斗决策/肉身苦修/资源调度仍主角自决
```

└── 风险门禁：禁用"穿越""系统""无脑爽"等低质标签，主线需有差异化定位

包装建议：
├── 书名需包含核心卖点（如：武道/星际/科技/升级）
├── 简介需包含主线驱动力+第一阶段敌人+金手指类型
└── 封面需视觉化力量体系（如：机甲/基因改造/古武vs科技对照）

【飞卢平台】
发布门禁：
├── 首屏高密度：前500字需包含冲突+爽点承诺+钩子
├── 更新节奏：每日至少2更，单章≥2000字
└── 风险门禁：主线需快速推进，禁止慢热铺垫超过3章

包装建议：
├── 书名直给爽点（如：无敌/暴击/碾压/逆袭）
└── 简介前三句必须包含"核心爽点+金手指+第一战"

【起点平台】
发布门禁：
├── 卷纲灵活性：卷纲可随推荐流动态调整，大纲仅留主线防偏航
├── 金手指克制：不可喧宾夺主，需保持主角核心能力独立性
└── 风险门禁：避免与已有爆款同质化过重，需有差异化标签

包装建议：
├── 书名需有辨识度，标签组合（如：科幻+武道+星际+升级）
└── 简介需包含世界观差异点+主角独特能力+核心矛盾

## 六、场景失败模式速查

```
【失败模式01：主角光环过重】
症状：金手指替代主角完成核心决策，读者感受主角无脑躺赢
诊断：检查金手指激活时是否标注"非替代区"
修复：主角必须在金手指辅助下自己完成关键判断/意志/技术

【失败模式02：反派降智衬托】
症状：反派决策前后矛盾，为衬托主角强行降智
诊断：检查反派是否有独立逻辑链，利益动机是否清晰
修复：重新推导反派决策链，确保反派行为符合其利益最大化逻辑

【失败模式03：战斗场景无物理反馈】
症状：战斗结果靠数值播报或意念秒杀，读者无法感知力量对抗
诊断：检查每场战斗是否包含感知→决策→发力→命中→反制五个节点
修复：补充物理反馈描写（护盾衰减/肌肉撕裂/神经过载/环境变化）

【失败模式04：越阶无代价】
症状：主角越阶打败强敌后无任何代价，后续升级失去紧张感
诊断：检查越阶成功后的代价结算（身体损伤/能量透支/仇恨累积）
修复：补入代价，且代价需关联后续剧情（如：伤势影响下一场战斗）

【失败模式05：卷纲散射】
症状：单卷内出现多个无关联支线，读者无法判断主线进度
诊断：检查每章是否服务于"目标-破局-BOSS-线索"闭环节点
修复：删除非必要的支线章节，所有内容服务于卷纲闭环

【失败模式06：章末钩子失效】
症状：章末留悬念但下一章未兑现，读者失去追读信任
诊断：检查钩子是否绑定"可兑现承诺"，而非开放式留白
修复：将开放式留白改为信息差悬念或资源倒计时，确保下章必然兑现

【失败模式07：体系战力崩坏】
症状：力量体系前后矛盾，高等级角色被低等级轻易击败
诊断：检查力量体系量化表与实际场景表现是否一致
修复：回溯量化表，重新校准跨境界对抗门槛与代价

【失败模式08：主角人设功能缺失】
症状：主角无明确短板，配角无补位功能，角色群像冗余
诊断：检查人设卡是否包含"1长板+1短板"，配角是否补位
修复：为主角增加功能性短板，重新推导配角存在必要性
```

## 七、执行流程（开书前必读）

```
【阶段一：任务卡填写】—— 约2-3小时
1. 提炼【一句话主线】（≤15字）
2. 填充【力量体系量化表】（境界-门槛-战力-待遇四要素）
3. 填写【金手指定义卡】（功能边界+非替代区+代价类型）
4. 构建【正派体系】与【反派镜像】（镜像对照+独立逻辑链）
5. 填写【主角人设卡】（核心长板+功能性短板+配角色补位）
6. 规划【卷纲闭环】（目标-破局-BOSS-线索四节点）
7. 设计【章末钩子类型】（信息差/倒计时/转场三选一）
8. 标注【平台适配】（目标平台+首屏抓人点+完读率锚定）

【阶段二：试写验证】—— 约1-2小时
1. 根据任务卡，写一个完整战斗场景（套用模板01）
2. 验证力量体系量化是否可用
3. 验证金手指边界是否合规
4. 验证物理反馈是否完整
5. 验证代价结算是否有效
若任一环节失败，回溯任务卡重新调整

【阶段三：章节自检】—— 每章完成后执行
1. 执行【章节自检清单】10项检查
2. 标记失败模式（如有）
3. 回溯修复
4. 提交审核
```
