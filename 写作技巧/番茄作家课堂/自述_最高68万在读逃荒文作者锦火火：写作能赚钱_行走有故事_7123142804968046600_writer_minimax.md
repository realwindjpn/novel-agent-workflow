| **平台算法** | 完读率 > 30 % → 章节保持 **完整叙事**（不在章节中设大段背景）<br>追读连续性 → **日更** ≥ 2000 字（断更≤1 天） |
| **站内活动** | 参加“科幻征文”“机甲大赛”等，获取 **推荐位** 与 **额外流量** |
| **风险门禁** | - **禁用词库**（政治、极端、血腥、违禁）需在章节完成后 **一键扫描** <br> - 限制 **过度血腥**（如描写血液飞溅需加“血雾”代替） <br> - 禁止 **暴露现实政治**（如现实国家、政党） <br> - 确认 **年龄分级**（轻度/全年龄） |

## Ⅷ、日常写作流程（快速参考）  

1. **写前**：打开任务卡 → 填写/检查 9‑15 项 → 确认章节目标、动作链、代价、钩子。  
2. **写作**：按段落节奏（第 1‑2 段冲突/危机 → 第 5‑7 段行动链 → 第 8‑9 段代价/小高潮 → 第 10 段钩子）。  
3. **写后**：章节自检清单 12 项全部通过 → 检查动作链/反馈/代价完整性。  
4. **发布**：封面+标签+标题 → 平台违禁词扫描 → 上传 → 记录段评/追读数据。  
5. **反馈**：每日/每 3 章回顾一次段评 → 如有异常（追读下降 > 10 %） → 立即调整后续章节的 **解释密度** 或 **冲突强度**。
