## 一、核心执行框架（五要素闭环）

### 1. 代价驱动引擎（科武底线）
> 每项能力/突破/金手指必须附带等效损耗。

| 类型 | 损耗示例 |
|:---|:---|
| 战力跃升 | 超频算力→神经突触不可逆灼伤；机甲过载→关节密封老化加速 |
| 科技突破 | 跃迁引擎→定位坐标暴露概率+300%；量子通讯→意识同步延迟后遗症 |
| 势力扩张 | 殖民舰队→补给线倍增风险；AI指挥链→情感模块侵蚀 |
| 主角光环 | 预知能力→每次使用触发记忆碎片化；生物改造→寿命折损系数=使用次数×1.7 |

**检查点**：本章出现的能力展示，是否同步完成损耗落地？读者能否预测下次使用代价？

---

### 2. 四步动作闭环（禁止跳步）

```
感知层 → 决策层 → 执行层 → 结果层
```

| 层级 | 科武场景示例 |
|:---|:---|
| 感知 | 神经接驳反馈：敌方电子干扰侵入视觉皮层，系统提示音出现0.3秒延迟 |
| 决策 | 心率监测强制启动战术协议：手动切断主通讯回路，切换备用频段 |
| 执行 | 手指划过全息面板2.7秒，指关节惯性压下三枚物理开关（备用系统不依赖电子层） |
| 结果 | 通讯恢复，但敌方锁定我方能量特征——坐标暴露，倒计时开始 |

**检查点**：你的战斗/操作场景是否完成四步？是否有任何一步被"直接成功/失败"跳过了？

## 三、章节自检清单（终稿前必查）

### 逻辑层（3项）
- [ ] **战力闭环**：本章展示的能力是否附带等效损耗？下次使用代价是否被读者预期？
- [ ] **物理自洽**：科技场景是否提供五感反馈？是否有抽象表达需要替换为具体感官描写？
- [ ] **伏笔合规**：本章引入的新设定/变量是否可被前文伏笔解释？是否新增了未标记的伏笔？

### 人物层（3项）
- [ ] **语言指纹**：对话中是否混杂了角色职业特征（术语/语气/微动作）？是否能抽离情境单独辨认？
- [ ] **决策合理**：角色选择是否符合其背景/能力/当前处境？是否有"主角降智"或"配角强行送死"？
- [ ] **关系张力**：关键人物互动是否提供新变量（而非重复旧冲突）？

### 节奏层（2项）
- [ ] **四步闭环**：战斗/操作场景是否完成感知→决策→执行→结果？是否有跳步？

### 数据层（2项）
- [ ] **字数合规**：终稿是否在4000-5000区间？是否出现"水文"段落（可删减且不影响叙事）？
- [ ] **钩子质量**：章末是否提供"情感满足+逻辑新变量"双要素？是否属于禁止类型（纯情绪/强行设悬）？

### 包装规则
| 维度 | 执行标准 |
|:---|:---|

### 风险门禁（禁止项）
| 风险类型 | 门禁规则 |
|:---|:---|
| **逻辑风险** | 禁止"机械降神"（能力突破无前置伏笔）；禁止"战力通胀"（反派实力突然跃升无解释）；禁止"设定失忆"（前期建立的限制后期消失） |

## 六、快速执行入口（5分钟内上手）

### 动笔前（3分钟）
1. 打开任务卡 → 填写章节编号/字数目标/情绪基调
2. 确认主线进度 → 标记伏笔回收节点
3. 检查灵感库 → 本章是否需要激活废弃灵感？

### 写作中（实时）
1. 每完成一个战斗/操作场景 → 自问：损耗在哪里？四步闭环了吗？五感有几种？
2. 每完成一段对话 → 自问：语言指纹对了吗？抽离情境能辨认吗？
3. 每完成一个情节转折 → 自问：逻辑自洽吗？有前置伏笔支撑吗？

### 完稿后（5分钟）
1. 对照自检清单 → 逻辑层3项 + 人物层3项 + 节奏层2项 + 数据层2项
2. 检查伏笔回收表 → 本章引入的新变量是否已标记待回收？
3. 检查章末钩子 → 是否提供"情感满足+逻辑新变量"双要素？
