# 变量注入推演模板

## 用法
将 `{{变量}}`、`{{实体列表}}`、`{{势力列表}}`、`{{约束}}` 替换为 `test_case.json` 中的值，作为单次 LLM prompt。

---

## Prompt

你是一个小说冲突推演引擎。以下是世界观和一个突发变量，请完成推演。

### 世界观摘要
《科武纪元》：近未来2045年，中美欧三极竞争下，"武"（物理强化）与"科"（AI/算力）两大路线交织。核心矛盾是算力主权、基因改造伦理、人机边界。已有多股势力：国家队（华夏超算局）、企业联盟（星渊集团）、地下改造者（锈铁帮）、学术派（脑机派）、国际组织（UN-AI 委员会）。

### 注入变量
{{变量}}

### 涉及实体
{{实体列表}}

### 涉及势力
{{势力列表}}

### 约束条件
{{约束}}

### 输出要求
按以下结构输出：

1. **受影响实体/势力**（列出 + 简述影响路径）
2. **第一层直接反应**（变量发布后 0-72 小时内各势力反应）
3. **第二层连锁**（1-4 周内的连锁事件，至少 3 条链）
4. **赢家与输家**（各势力损益排序）
5. **章节冲突钩子**（3 个可直接写入正文的冲突点，含涉及角色、张力来源、反转可能）
6. **角色 OS 影响**（哪些角色的世界观/立场/情绪会因此改变）
7. **反模式 / 禁忌**（哪些写法会显得假、老套、AI味重）
8. **是否需进入六角色会议**（是/否 + 理由）

保持冷峻叙事风格，避免抒情。
