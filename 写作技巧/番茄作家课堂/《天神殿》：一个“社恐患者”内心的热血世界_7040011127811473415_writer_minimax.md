## 一、动作执行包：开篇即筛选器

### 【开篇三版迭代协议】

**执行动作**：
1. 每部作品开篇写≥3个版本，仅保留动机最清晰/情绪代入最强的一版
2. 前3章必须完成：核心动机抛出 + 首个小高潮

**自检提问**：
- [ ] 第一段是否有明确主角？（名字+处境+核心诉求）
- [ ] 读者能否在30秒内知道"主角要什么/怕什么"？
- [ ] 是否有强情绪场景？（恐惧/愤怒/渴望/绝望）

**失败模式识别**：
- ❌ 纯说明书式设定堆砌（机甲参数、武道境界列表）
- ❌ 背景交代超过2段
- ❌ 开篇无冲突的日常流水账

## 二、科武反馈矩阵：物理限制+能量流转

### 【战斗/操作四步链】

```
感知 → 决策 → 执行 → 结果
  ↓       ↓       ↓       ↓
传感器   战术判断  能量释放  量化反馈
```

**每步必须包含**：
| 步骤 | 科武要素 | 示例 |
|:---|:---|:---|
| 感知 | 神经/机甲传感器/战场态势 | "冷却管温度飙至97℃" |
| 决策 | 战术博弈/资源权衡 | "必须弃守左翼" |
| 执行 | 能量/武技/机甲联动 | "暗劲第七重催发" |
| 结果 | 可量化生理/环境反馈 | "右臂骨裂，碎片刺入肺叶" |

**禁止写法**：
- ❌ "一招秒杀"（跳跃四步链）
- ❌ "无损耗施法"（无代价释放）
- ❌ "主角光环碾压"（无博弈过程）

### 【能量释放反馈清单】

**机甲类**：
- [ ] 冷却液沸腾/泄漏
- [ ] 神经链路负荷超标（视野闪烁）
- [ ] 能量核心过载预警
- [ ] 机甲关节磨损/锁定
- [ ] 驾驶员生理指标（心率、肾上腺素）

**武道类**：
- [ ] 骨骼/经脉承压阈值
- [ ] 真气/暗劲消耗速度
- [ ] 脏器微裂/隐伤累积
- [ ] 意识模糊/神识透支
- [ ] 反噬延迟发作（当下没事，伏笔埋设）

**科技武器类**：
- [ ] 能量枪管过热熔毁
- [ ] 护盾折射率衰减
- [ ] 后坐力导致的位移
- [ ] 弹药/能源储备消耗
- [ ] 电磁干扰/自毁协议触发

## 三、代价设计矩阵：能力/剧情/选择三重门禁

### 【代价类型速查表】

| 能力获取代价 | 剧情推进代价 | 阵营选择代价 |
|:---|:---|:---|
| 寿命折损（暗劲透支） | 时间成本（错过节点） | 人际关系破裂（被追杀） |
| 资源枯竭（机甲报废） | 机会成本（放弃备选） | 道德困境（无辜者牺牲） |
| 身体损伤（不可逆） | 盟友代价（必须牺牲某人） | 身份代价（被原阵营标记） |
| 系统反噬（副作用延迟） | 信息代价（暴露底牌） | 立场代价（站队后无退路） |

**执行标准**：
- 任何能力提升必须有可见代价
- 任何关键选择必须有可见损失
- 代价必须**可量化、可感知、可追责**

**禁止写法**：
- ❌ 主角能力突飞猛进但"没什么代价"
- ❌ 关键选择后"一切顺利"
- ❌ 配角死亡"对剧情无影响"

## 四、失败模式识别清单：长篇崩坏预警

### 【战力崩坏前兆】

- [ ] 主角30章内实力跨越超过3个大境界
- [ ] 反派实力随剧情需要随意浮动
- [ ] 战斗结果与前面铺垫的实力差距不符
- [ ] 配角实力被主角光环覆盖（工具化）

### 【逻辑崩坏前兆】

- [ ] 设定前后矛盾（武道规则被临时修改）
- [ ] 势力版图随嘴炮变化（无铺垫扩张/收缩）
- [ ] 科技树/武道体系随意添加（临时救场设定）
- [ ] 关键伏笔遗忘或强行圆回

### 【读者流失前兆】

- [ ] 章节结尾无钩子/无效断章
- [ ] 超过5章无明确主线推进
- [ ] 配角长期消失（20章+无高光）
- [ ] 设定说明超过叙述500字

## 五、人物口吻设计指南：科武角色声线库

### 【主角型口吻特征】

| 角色类型 | 说话特点 | 示例句式 |
|:---|:---|:---|
| 武道修炼者 | 沉稳、留白、惜字如金 | "还能动。" |
| 机甲师/技术型 | 精确、数据化、略带紧张 | "能量余量12%，撑不过下一轮齐射" |
| 指挥官型 | 果断、强命令式、承担压力 | "三十秒后撤离，不等任何人" |
| 觉醒期主角 | 克制中带锋芒、成长性 | "我不接这一掌，但我接这一拳" |

### 【配角/反派口吻特征】

| 角色类型 | 说话特点 | 情绪触发点 |
|:---|:---|:---|
| 导师型 | 引导式、反问式 | "你以为这就到头了？" |
| 盟友型 | 直接、可靠、有限幽默 | "命还在就还有得玩" |
| 对手型 | 压迫式、嘲讽式 | "蝼蚁也配与我同台？" |
| 神秘型 | 留白、预言式 | "你选的路，三年前就已标记" |

**执行动作**：
- 每章对话前标注说话者身份+当前情绪状态
- 对话不超过连续3段，插入动作/感知描写
- 核心冲突对话必须≥5轮交锋才能有结论

## 六、段落节奏模板：科武长篇四幕节拍

### 【单章结构模板】

```
┌─────────────────────────────────────┐
│ 钩子回响（承接上章，1-2段）           │
│   → 上章危机/悬念延续               │
├─────────────────────────────────────┤
│ 核心冲突展开（60%篇幅）              │
│   → 感知：情报/态势/限制             │
│   → 决策：战术/资源/代价权衡         │
│   → 执行：能量释放/战斗/操作          │
│   → 结果：量化反馈/局势变化           │
├─────────────────────────────────────┤
│ 转折/意外（20%篇幅）                 │
│   → 新变量介入/底牌暴露/计划外状况     │
├─────────────────────────────────────┤
│ 章末钩子（收尾1-2段）                │
│   → 信息差/危机逼近/情感反转          │
│   → 必须与下章首段形成逻辑咬合        │
└─────────────────────────────────────┘
```

### 【节奏违规警告】

- ❌ 冲突段（3000字章节）超过2000字
- ❌ 设定说明单段超过300字
- ❌ 连续3段纯对话无动作嵌入
- ❌ 章末无钩子或钩子与下章无关

---

## 七、章末钩子库：科武叙事断点设计

### 【钩子类型矩阵】

| 类型 | 特征 | 科武场景示例 |
|:---|:---|:---|
| **信息差钩** | 读者知道但角色不知道 | "他不知道，暗劲第七重的代价..." |
| **危机逼近钩** | 时间压力/死亡威胁 | "三分钟后这片区域将被清空" |
| **情感反转钩** | 关系/信任崩塌 | "他举枪对准的，是救过他三次的人" |
| **抉择悬停钩** | 两难选择已呈现 | "按下去，机甲将永远失去这只手" |
| **伏笔引爆钩** | 前文细节此刻呼应 | "就像师父当年死在他怀里的姿势" |

**执行标准**：
- 每章必须从五型中选≥1个
- 钩子必须与下章首段强逻辑咬合
- 禁止"且听下回分解"式无效断章

## 九、章节自检清单（出稿前必过）

### 【一级门禁（必须通过）】

- [ ] **钩子完成度**：本章结尾是否从五型中选≥1个钩子？与下章首段是否咬合？
- [ ] **代价完成度**：主角行动/能力使用是否伴随可量化代价？
- [ ] **反馈完成度**：能量释放/战斗是否包含物理/生理/环境三维度反馈？
- [ ] **四步链完成度**：感知→决策→执行→结果是否完整？有无跳跃？

### 【二级门禁（建议通过）】

- [ ] 配角是否有≥1句独立台词/高光动作？
- [ ] 对话是否超过连续3段无动作嵌入？
- [ ] 设定说明单段是否超过300字？
- [ ] 核心冲突是否与人物情感诉求绑定？（非纯武力/科技碾压）

### 【三级门禁（长篇健康度）】

- [ ] 大纲是否覆盖本章后续3-5章主要节点？
- [ ] 伏笔是否记录到伏笔库？（防止遗忘）
- [ ] 战力体系是否前后一致？（无临时修改）

### 【短故事/狼人篇可借点】★

| 模块 | 借点内容 | 适用场景 |
|:---|:---|:---|
| 四步链反馈 | 感知→决策→执行→结果+物理限制 | 所有战斗/操作场景 |

### 【平台规则→发布/包装/风险门禁转换】

| 原平台规则 | 转换后：发布门禁 | 转换后：包装要点 | 转换后：风险门禁 |
|:---|:---|:---|:---|
| 标签匹配+完读率 | 投稿前检查标签精准度 | 简介突出核心卖点（武道+科幻+热血） | 跨标签乱投→推荐降权 |
| 算法流量池 | 新书期（30万字内）不换赛道 | 封面/书名符合科武品类调性 | 断更直接降权，需提前报备 |
| 爆更杠杆（日更1万+） | 建立稳定更新计划（日更≥6000） | 章节标题突出本章爆点 | 爆更期偶发断更伤害最大 |
| 题材风口 | 顺势而为但保留个人擅长 | 简介/前5章突出差异点（硬核+情感） | 盲目追风口导致风格割裂 |
| 编辑协同 | 出稿前自检清单必须通过 | 向编辑提交的亮点摘要（钩子位置/名场面） | 格式不规范→审核延迟 |
