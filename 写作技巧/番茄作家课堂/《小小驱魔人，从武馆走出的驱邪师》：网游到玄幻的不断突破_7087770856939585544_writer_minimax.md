## 二、动作链执行标准

所有战斗/操作段落必须闭环：

```
环境感知 → 战术决策 → 肢体/装备执行 → 介质交互 → 结果反馈
   ↓            ↓              ↓              ↓           ↓
 感知威胁    计算选项    执行动作/装备激活  与目标/环境互动  量化后果
```

**禁止模式：**
- ❌ “意念秒杀”“气沉丹田直接灭杀”
- ❌ “喊出技能名→敌人倒地”
- ❌ “主角想了想→问题解决”

**科武化转译示例：**

| 玄幻模式 | 科武执行 |
|:---|:---|
| 蓄力三秒→释放火球 | 主伺服响应+热循环启动+瞄准解算→弹丸出膛→目标装甲形变+破片反馈 |
| 主角用真气护体 | 姿态调节喷口微调+力场发生器预热+能量余量显示 |
| 反派放技能被躲开 | 弹道预测+规避路径计算+机甲惯性补偿 |

## 三、代价体系（强制执行）

**触发条件：** 越级突破 / 超载使用 / 高风险战术 / 道德抉择

| 代价类型 | 科武化呈现 | 后续影响 |
|:---|:---|:---|
| **物理损耗** | 神经负荷超载→神经过载；骨骼超出承受→微裂纹累积 | 战斗能力暂时下降/永久性数据 |
| **资源枯竭** | 能量核心过载→充能时间延长；弹药基数耗尽 | 战术选择受限/需补给链 |
| **信任破裂** | 牺牲队友换取撤退窗口 | 人际关系重构/指挥权威动摇 |
| **道德困境** | 攻击平民设施/使用违禁武器 | 立场标签改变/敌方策略调整 |
| **数据代价** | AI过载→记忆碎片丢失/推理模型降级 | 战术计算能力下滑/失去关键信息 |

**代价书写要求：** 代价需在2章内显现，推动后续剧情；禁止“爽完不付账”。

## 六、段落节奏控制

| 节奏型 | 适用场景 | 结构 | 字数参考 |
|:---|:---|:---|:---|
| **压缩型** | 战斗/危机/追逐 | 短句+感官细节+即时决策 | 200-400字/段 |
| **释放型** | 情感爆点/牺牲/传承 | 长句+氛围+细节堆叠 | 500-800字/段 |
| **交替型** | 日常/信息传递 | 压缩→释放→压缩循环 | 视场景需要 |

**节奏红线：**
- 开篇前3章禁用超过500字的纯世界观说明
- 战斗段落禁止连续超过3段无结果反馈的交锋
- 日常章节必须在结尾前15%插入下一个情节点

## 七、章末钩子执行标准

| 钩子类型 | 判定标准 | 违规示例 |
|:---|:---|:---|
| **未解危机** | 与主线直接关联，读者可预期后续冲突 | “某角色突然打了个喷嚏” |
| **身份反转** | 角色立场/阵营/目标发生颠覆性变化 | “某人似乎有点可疑” |
| **倒计时** | 明确时间节点+失败后果 | “还有三天就是期限” |
| **关键参数缺失** | 读者与角色共同面临的信息黑箱 | “那个信号从哪里来的？” |

**钩子书写要求：**
- 必须在前5句内抛出
- 与本章核心剧情强相关
- 禁止纯情绪断章（“他心中涌起复杂的情绪”）
- 禁止无效悬念（与主线无关的次要线索）

## 八、章节自检清单（写后执行）

**开篇自检（1-3章）：**
- [ ] 是否在第1章明确主角“生存危机”
- [ ] 是否在第3章内抛出“短期目标”
- [ ] 是否避免大段世界观说明书（≤200字）
- [ ] 动作链是否闭环（感知→决策→执行→反馈）
- [ ] 金手指是否仅作“加速器”而非“答案”

**战斗/操作自检：**
- [ ] 是否具备空间感（距离/方位/遮挡）
- [ ] 是否有物理反馈（动能/形变/损伤量化）
- [ ] 是否有战术逻辑（判断依据/选项对比/风险评估）
- [ ] 是否有代价兑现（物理损耗/资源消耗/关系影响）

**节奏自检：**
- [ ] 每50-80章是否有情绪锚点（牺牲/突破/背叛/共鸣）
- [ ] 章末钩子是否与主线强相关
- [ ] 是否存在连续3段以上无进展的“水文”风险

**人物自检：**
- [ ] 主角行为是否始终受核心信念驱动
- [ ] 感情/羁绊线是否符合标签承诺
- [ ] 对话是否体现角色类型口吻

**设定自检：**
- [ ] 科幻设定是否遵循内部物理自洽
- [ ] 战力膨胀是否有明确上限机制
- [ ] 名场面是否预留分镜接口

**承诺自检：**
- [ ] 标签承诺是否兑现（硬核/轻科幻/无CP等）
- [ ] 升级节奏是否与读者预期匹配
- [ ] 感情线/群像比重是否与简介一致

## 十、平台规则转化

| 平台指标 | 转化为作家行动 | 风险门禁 |
|:---|:---|:---|
| **完读率** | 开篇前3章强制钩子密度；每10章设置小节点 | ❌ 开篇500字内无冲突→完读率预警 |
| **追更密度** | 章末钩子必须与主线强关联；日更需匹配剧情密度 | ❌ 断更超过3天→算法降权 |
| **首秀期（20万字）** | 前20章用生存危机绑定读者；稳定日更喂养算法 | ❌ 首月断更→推荐资源回收 |

| **IP改编潜力** | 预留2-3个“场景集中、人物清晰、视觉冲击强”名场面 | ❌ 无分镜接口→版权价值降级 |

**发布节奏建议：**
- 日更≥6000字（番茄免费流算法偏好）
- 重要节点（首秀/上架/完结）前提前存稿20章
- 单卷字数控制在30-50万字，便于完结与分卷运营
