# 《科武纪元》编辑学习官：番茄专访《咬一口甜梨》规则提炼

## 1 课程核心判断（≤6条）
1. **大纲前置是底线**：开书前必须完成人设、背景框架、故事线、书名简介的完整搭建，杜绝“边写边想”。
2. **开篇定留存**：短篇/现言需在开篇迅速亮出核心人设与初始动机，避免抽象背景铺垫；长篇同理，首章必须抛出具体事件。
3. **画面感决定文字质感**：新人通病是“文字干、无画面”，需通过影视分镜思维与优秀文本反哺场景构建。
4. **情绪工具可量化调用**：写作状态依赖环境隔离与情绪锚点（如特定歌单切入对应情绪），非纯靠灵感。
5. **题材核心决定主线权重**：甜宠重情绪陪伴与单一感情线；职业/现实向重社会切片与人生百态，爱情线退居观察视角。
6. **平台逻辑优于个人偏好**：书名/简介需服从算法推荐与编辑市场判断，作者需保持沟通信任，不盲目坚持文艺化表达。

---

## 2 可执行编辑规则（按文章实际内容取舍）

| 维度 | 规则 |
|:---|:---|
| **开篇** | 3章内必须完成“核心人设亮相+初始动机触发+首个具象场景”；禁用大段世界观说明，改用动作/物件/对话带出设定。 |
| **节奏** | 感情线/主线需设置明确推进节点（如“求助→介入→依赖→反转”）；短篇砍掉冗余支线，长篇采用“事件串/单元卷”维持持续推力。 |
| **冲突** | 冲突不依赖宏大设定堆砌，而源于“内在需求与外在规则/敌对势力的碰撞”；利用信息差、预知/悬念制造持续张力。 |
| **人物** | 人设需绑定“反差标签+行为锚点”（如甜妹+体弱/高冷+腹黑+医生）；用具体物件、习惯动作、口头禅强化记忆点，禁用抽象形容词堆砌。 |
| **题材** | 明确题材核心卖点：情绪治愈类重“陪伴与选择”；职业现实类重“社会切片与人性观察”；爱情线仅作为视角或催化剂，不喧宾夺主。 |
| **改编** | 强画面感、单元化事件、鲜明人设天然适配短剧/影视；开篇具象场景需具备直接分镜转化能力；保留“名场面”供剪辑与二创传播。 |
| **平台规则** | 番茄重“开篇3章留存率”与“情绪直给”；书名/简介需符合算法抓取逻辑（关键词明确、卖点前置）；短篇需快速完读，长篇需稳定日更与大纲支撑。 |

## 3 科武适配

### ✅ 可用点
- **大纲前置与体系搭建**：科武长篇必须提前划定力量体系边界、科技/武道融合逻辑、升级路径与核心悬念回收表。
- **开篇事件化**：首章直接切入“科武冲突现场”或“核心危机触发”（如基因改造暴走/古武遗迹开启），用动作带设定。
- **画面感与分镜思维**：将影视/偶像剧的“场景调度”转化为科武战斗的“空间站位-能量轨迹-环境交互”描写。
- **情绪锚点植入**：在硬核设定中保留“人性羁绊/阵营抉择/师徒传承”，作为长线粘性支撑。
- **单元卷结构**：采用“副本/危机推进”模式，每卷解决一个科武命题，维持节奏与完读率。

### ❌ 不可硬套点
- **慢热陪伴节奏**：科武需生存压力与硬核冲突，照搬“甜宠慢热”会导致前期张力流失。
- **日常社会切片**：科幻武道需聚焦“力量进化/文明博弈”，过度生活化会稀释题材核心。
- **纯情绪线支撑**：百万字长篇不能仅靠单一感情/治愈线推进，必须绑定体系升级与主线悬念。
- **文艺化书名/简介**：科武需突出“力量标签/核心悬念/世界观关键词”，避免抽象抒情导致算法误判。

## 4 编辑检查表（10条以内）
1. 开篇3章是否亮出核心人设、初始动机与首个具体事件？
2. 世界观/力量体系是否通过情节自然展现，而非大段说明？
3. 主线推进是否有明确节点（每10-15章一个阶段性目标/冲突）？
4. 人物是否有“行为锚点”或“反差标签”支撑记忆点？
5. 冲突是否源于角色内在需求与外部规则/敌对势力的碰撞？
6. 场景描写是否具备影视化画面感（动作轨迹、环境交互、感官细节）？
7. 情绪线/感情线是否服务于主线推进，而非喧宾夺主？
8. 书名/简介是否直给核心卖点，符合平台算法推荐逻辑？
9. 长篇大纲是否包含力量升级路径、核心悬念回收表与卷纲？
10. 是否存在“文字干瘪/抽象抒情”段落，需替换为具象动作或对话？

## 5 对作家角色的输入要求

| 维度 | 输入标准（写作/改稿强制项） |
|:---|:---|
| **动作链** | 必须拆解为“起势-发力-接触-反作用-收势”连续逻辑；禁用“一招秒杀”“瞬间爆发”等模糊表述，需明确发力源、轨迹与落点。 |
| **物理反馈** | 每次能量释放/武道交锋必须伴随可观测反馈：环境破坏（裂痕/电离/金属扭曲）、躯体负荷（骨骼震颤/神经灼痛/肌肉撕裂）、感官变化（耳鸣/失重/热浪）。 |
| **代价** | 任何能力使用、境界突破或战术选择必须支付明确代价（如基因崩溃阈值、资源枯竭、阵营信任破裂、寿命折损），杜绝无代价开挂。 |
| **钩子** | 每章结尾必须埋设“未解悬念/突发危机/信息反转”，且与下一章核心事件强关联；禁用情绪性断章或纯心理描写收尾。 |
| **读者预期** | 开篇需明确承诺题材类型（科武升级/悬疑探案/阵营博弈），并在前30章内兑现至少3个核心看点；严禁“文不对题”或“设定欺诈”导致预期断裂。 |
