## 二、章节自检清单

```
【章节自检·标签兑现版】

1️⃣ 主分类对齐
□ 本章力量体系/世界观是否与主分类100%对齐？
□ 是否出现与主分类冲突的元素？（如：科幻贴玄幻标签却写修仙设定）

2️⃣ 标签承诺兑现
□ 本章是否兑现该章节所在的"情节标签"承诺？
  例：标"逆袭"→ 本章是否进入反击阶段？
  例：标"智斗"→ 本章是否发生策略博弈/信息差逆转？
□ 若承诺"爽"，本章情绪弧是否完成"压抑→释放"？
□ 若承诺"燃"，本章是否出现≥1个高光时刻（角色/战斗/认知）？

3️⃣ 物理反馈具象化
□ 科技装备是否展示具体参数/损毁/能耗？
□ 武道招式是否明确威力阈值/代价/克制关系？
□ 环境破坏/生理负荷是否可量化？

4️⃣ 代价合规性
□ 力量获取是否伴随明确代价？
□ 代价是否与标签类型匹配？（升级→资源消耗，热血→牺牲/风险）

5️⃣ 钩子有效性
□ 章末悬念是否与主标签强关联？
□ 悬念是否为"认知缺口"或"情绪断点"而非单纯信息堆砌？
□ 读者能否在下一章找到答案？（避免无限吊胃口）

6️⃣ 失败模式排查
□ 是否存在"未写先标"？（标打脸但只写压抑期）
□ 是否存在"标签-正文基调割裂"？（硬核标签配龙傲天文风）
□ 是否存在"蹭标签"？（末世/甜宠与主线无关）

7️⃣ 平台合规
□ 标签用词是否为官方词库词？
□ 本章是否有触发审核风险的内容？（擦边/敏感设定）
□ 读完率预期：本章读完率≥上一章？□是/□否（需调整节奏）

━━━ 短故事/狼人篇速查 ━━━
□ 主分类+1最强情节标签，禁用多标签铺陈
□ 开篇即兑现标签承诺（前500字必须出现核心情绪/设定）
□ 钩子密度：每500字1个有效悬念点

━━━ 科武长篇速查 ━━━
□ 标签体系是否支撑100章+的世界观扩展？
□ 副标签是否按剧情阶段动态调整？（如前期"机甲/升级"→后期"星际战争/群像"）
□ 标签承诺兑现是否有节奏规划？（避免前期过度消耗标签承诺）
```

## 四、人物口吻·段落节奏·章末钩子模板

```
【口吻节奏模板】

□ 科武硬核型口吻：
  "这枚核心的能量密度只有0.7，却要承受1.2级的负荷——"
  → 节奏：参数在前，情感在后；对话精简，动作具象

□ 热血逆袭型口吻：
  "三年了。今天，轮到你们抬起头看着我。"
  → 节奏：情绪爆发在前，行动在后；金句收尾，高光定格

□ 悬疑推进型口吻：
  "基因序列的错误，不是bug——是设计。"
  → 节奏：信息压缩，真相倒置；章末钩子用认知缺口


【章末钩子3型】

1️⃣ 认知缺口型（硬核/悬疑）
  "他说他来自第三纪元。但档案显示——第三纪元从未存在过人类。"
  → 公式：陈述+矛盾点+留白

2️⃣ 情绪断点型（热血/逆袭）
  "裁判宣布结果的声音还在回荡，他的右手已经按在了腰间的武器柄上。"
  → 公式：冲突场景+动作暗示+留白

3️⃣ 伏笔触发型（长篇布局）
  "控制台上，那行从未被注意过的代码，正在自动执行。"
  → 公式：细节激活+进程暗示+悬念延伸


【段落节奏校验】

□ 高频事件型（快节奏/每300字1事件）：
  标签承诺快节奏 → 正文必须≥章3事件
  例：打脸文3000字章节 → 压抑300字+反击300字+高光2400字

□ 情绪累积型（中节奏/章内1核心事件）：
  标签承诺慢热 → 正文必须用细节替代事件推进
  例：科幻文3000字章节 → 世界观500字+角色500字+伏笔500字+核心事件1500字

□ 密度公式：
  章内有效信息量 = 标签承诺兑现×章节字数÷1000
  （标签"硬核" → 章均≥3个技术细节/设定验证）
  （标签"爽" → 章均≥1个情绪释放点）
```
