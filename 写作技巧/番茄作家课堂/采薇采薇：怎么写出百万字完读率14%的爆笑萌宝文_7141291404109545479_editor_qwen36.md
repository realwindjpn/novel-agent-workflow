# 《科武纪元》编辑学习官：采薇采薇专访规则提炼

## 1 课程核心判断（≤6条）
1. **稳定输出＞爆发开局**：日更6k、全年无断更是百万字14%完读率的底层支撑，低预期+持续迭代优于短期数据焦虑。
2. **情绪价值驱动留存**：解压、共鸣、爽感是核心钩子，复杂设定必须让位于“读者现实困境的戏剧化映射”。
3. **完读率铁三角**：强代入感 + 人物形象鲜明 + 剧情流畅不拖沓，三者缺一即导致长篇流失。
4. **作者人格即文本辨识度**：现实性格（欢脱/犀利/细腻）直接转化为语言风格与互动模式，拒绝模板化人设。
5. **平台机制是创作骨架**：全勤打卡、评论反馈、奖励节点需内化为写作纪律，而非外部干扰。
6. **质量底线靠“真情实感+珍惜羽毛”**：拒绝水文稀释口碑，单章高光（如第82章骂渣男）可反哺整体数据。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 3章内完成核心人设亮相与情绪基调确立；禁用背景堆砌，用日常互动/微冲突切入，快速建立“欢脱/犀利/细腻”的文本辨识度。 |
| **节奏** | 按6k/日模块化拆解，每章必须有明确情节推进点；剧情“流畅不拖沓”，过渡段压缩至≤15%，无效日常直接删减。 |
| **冲突** | 设计“压抑-爆发-爽感”闭环；冲突需锚定目标读者现实压力（家庭/情感/职场），爆发点需具备独立传播性（如单章名场面）。 |
| **人物** | 人设需具反差标签（表面欢脱脑补，关键时通情达理/细腻）；言行必须有现实原型或逻辑支撑，禁用纯功能化工具人。 |
| **题材** | 优先作者最熟练类型，在成熟框架内做微创新（如“洗白/反套路”）；不盲目追新，用情绪共鸣替代设定猎奇。 |
| **改编** | 预留影视化接口：单元式爽点、高情绪浓度场景、清晰的人物关系网；单章高光需具备独立成片潜力。 |
| **平台规则** | 严格日更打卡；将读者高频评论纳入下阶段剧情微调；利用平台全勤/推荐机制倒推大纲排期，断更即断流。 |

## 3 科武适配
### ✅ 可用点
- **情绪优先原则**：科武长篇易陷设定堆砌，需将“生存压力/技术焦虑/文明冲突”映射为读者现实困境，用解压与共鸣维持完读。
- **模块化节奏控制**：6k/日拆解法完全适用，科武战斗/探索/研发需按“目标-执行-结果-反馈”切分，杜绝拖沓。
- **人格化语言注入**：主角可保留“高智商吐槽/反套路破局”的欢脱特质，增强科武硬核背景下的文本辨识度。
- **平台纪律内化**：日更打卡、评论校准、全勤排期直接移植至科武连载运营。

### ❌ 不可硬套点
- **“萌宝/古言洗白”框架**：科武需硬核逻辑与世界观自洽，不可照搬“日常陪伴/岁月静好”的慢节奏，需替换为“危机-破局-进化”的科武主线。
- **“无波澜只有爱”基调**：科武纪元核心是冲突与迭代，“平静”只能作为战后休整/技术突破的缓冲期，不可作为叙事主轴。
- **家庭伦理映射**：科武读者关注技术伦理、资源争夺、个体进化，需将“为人女/妻/母”困境升维为“人机共生/阵营信任/文明存续”命题。

## 4 编辑检查表（8条）
- [ ] 开篇3章是否完成核心人设亮相与情绪基调确立？
- [ ] 单章（3k）是否包含≥1个明确情节推进点或情绪释放点？
- [ ] 冲突是否形成“压抑-爆发-爽感”闭环，且过渡段≤15%？
- [ ] 人物言行是否具备鲜明标签与反差感，无工具人痕迹？
- [ ] 设定/背景说明是否严格嵌入剧情缝隙，无独立科普段落？
- [ ] 是否预留独立高光场景（单章爽点/名场面）供读者传播？
- [ ] 日更排期是否按6k/日模块化拆解，有无断更风险？
- [ ] 核心情绪价值（解压/共鸣/爽感）是否每10章至少强化1次？

## 5 对作家角色的输入要求
| 维度 | 强制输入要求（科武向） |
|:---|:---|
| **动作链** | 必须呈现“触发-决策-执行-结果”四步闭环；科武战斗/技术操作需拆解为可视觉化的连续动作，禁用“他打赢了/他突破了”等概括性叙述。 |
| **物理反馈** | 每次科武交互（机甲碰撞/能量释放/基因改造/轨道机动）必须附带环境破坏、生理负荷或装备损耗的具象描写，强化物理真实感。 |
| **代价** | 任何能力跃升或战术胜利必须支付明确代价（资源枯竭/神经负荷/信任损耗/时间窗口关闭/技术反噬），杜绝无成本开挂。 |
| **钩子** | 章末必须埋设“未解技术谜题/敌情逼近/道德抉择/资源倒计时/阵营背叛”之一，强制读者翻页；禁用开放式抒情结尾。 |
| **读者预期** | 开篇承诺的“科武爽感/智斗破局/硬核进化”必须在3-5章内兑现首次验证；后续每卷需升级预期阈值，严禁降智、战力崩坏或情绪断档。 |
