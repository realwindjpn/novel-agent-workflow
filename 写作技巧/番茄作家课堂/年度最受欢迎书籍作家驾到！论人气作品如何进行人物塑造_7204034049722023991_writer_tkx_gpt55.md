# 《科武纪元》作家OS补丁：人物塑造执行版

补丁名：`Character_Anchor_Conflict_Cost_v1.0`  
适用：科武长篇 / 狼人短故事 / 热点短稿 / 平台发布包装  
核心指令：**人物不是一堆设定，而是“一个稳定标签 + 一个被卡住的追求 + 一组会反复付出的代价”。**

---

## 0. 总执行口令

写任何人物前，先问 6 句：

1. 他最突出的一个标签是什么？
2. 他现在最想要什么？
3. 谁或什么正好卡住他？
4. 他被卡后会怎么掀桌？
5. 掀桌以后他失去什么？
6. 读者下次见他时，期待他再次做什么？

不能回答，就不要让他出场。

---

# 1. 人物首秀补丁

## 1.1 首次出场动作

每个有戏份角色首次出场，只允许用：

> **1 个动作特征 + 1 个标志物 + 1 句能暴露立场的话**

禁止：

- 从头到脚白描。
- “他英俊冷酷，气质不凡”。
- 一口气塞身世、境界、履历、家族背景。

### 可执行模板

```text
【动作】他先做了什么？
【物件】读者能记住他身上的什么？
【台词】他说了哪句话，暴露他的欲望/恐惧/阵营？
```

### 科武长篇可借点

- 标志物优先用：义体部件、旧伤、护腕、旧弹壳、残缺武器、门派徽记、芯片烧痕、实验编号。
- 动作优先用：扣护腕、擦刀刃、摸义眼、调整呼吸阀、检查弹匣、按压旧伤。

### 示例方向

```text
他没看台上的长老，只低头把护腕扣了三下。
第三下时，护腕里那枚旧弹壳轻轻一响。
“比完这场，实验室欠我的编号，该还了。”
```

这个首秀同时给出：

- 动作：扣护腕。
- 标志物：旧弹壳。
- 追求：讨回编号/身份。
- 阵营伤口：实验室旧账。

# 2. 人物标签补丁

## 2.1 一人一主标签

每个角色只允许一个主标签。

可用格式：

```text
角色 = 一个放大的特征 + 一条卡住的追求
```

例：

- 林烬：冷静到残酷 + 想证明科武融合不是禁忌。
- 旧城改造人：护短 + 想保住贫民窟最后一条能源线。
- 世家天才：优雅傲慢 + 想摆脱家族操控。
- 狼人篇村长：慈祥控制狂 + 想让全村永远守住秘密。

## 2.2 禁止标签堆叠

不要写：

```text
他冷酷、温柔、腹黑、疯批、重情重义、杀伐果断、偶尔可爱。
```

改成：

```text
他冷酷。
他的温柔只通过“给她的那枚止痛芯片多留了半小时电量”表现。
```

## 2.3 反差不是换人格

反差必须落在人设逻辑内。

可用反差：

- 冷面工程师私下写诗。
- 杀伐武修偷偷养猫。
- 顶级女战力是路痴。
- 贫民窟改造人讨厌浪费食物。
- 狼人凶手每次杀人前都会把孩子的门锁好。

不可用反差：

- 正义男突然无理由下毒。
- 慈悲导师突然虐徒取乐。
- 贫民窟角色忽然花钱不心疼。
- 高智商科学家关键时刻无脑莽。

# 3. 三次出场强化补丁

## 3.1 前三次出场必须重复放大标签

角色不能只在设定表里成立，必须在前 3 次出场里反复证明。

### 执行公式

```text
第1次：用动作立标签。
第2次：用选择强化标签。
第3次：用代价证明标签。
```

### 示例：护短型改造人

第1次出场：

```text
他把能源管从自己胸口拔下来，先接到孩子的保温舱上。
```

第2次出场：

```text
他拒绝进入主城治疗，因为那意味着贫民窟今晚停电。
```

第3次出场：

```text
他赢了，但义肺烧毁，之后每说三句话都要咳出黑血。
```

读者记住的不是“他很护短”，而是：

> 他每次都把别人的命接在自己身上。

# 4. 追求 × 障碍 = 掀桌子补丁

## 4.1 每章必须有小掀桌

人物追求被卡住后，必须做出反弹行动。

公式：

```text
追求 × 障碍 = 掀桌子
```

如果本章没人被卡，没有人反弹，这章就是水章。

## 4.2 掀桌动作分级

### 小掀桌

适合日常章节、过渡章。

- 拒绝命令。
- 当众改方案。
- 把奖励让给别人。
- 私下调换装备。
- 隐瞒一次伤情。
- 越级递交资料。

### 中掀桌

适合章节高潮。

- 违抗师命。
- 单挑强敌。
- 抢夺实验权限。
- 公开揭穿阴谋。
- 和盟友翻脸。
- 暴露隐藏能力。

### 大掀桌

适合卷末/大高潮。

- 叛出阵营。
- 毁掉实验室。
- 公开禁忌科技。
- 杀死旧导师。
- 放弃原身份。
- 牺牲寿命或记忆换胜利。

## 4.3 科武长篇可借点

科武主线可反复用：

```text
科学追求 vs 武道秩序
个人进化 vs 阵营控制
底层求生 vs 世家垄断
文明真相 vs 官方禁令
师门忠诚 vs 技术伦理
```

每一卷至少安排一次“大掀桌”。

# 5. 代价补丁

## 5.1 没有代价的胜利不写

角色每次重大行动后，必须失去某样东西。

代价优先量化：

- 寿命：减少几年。
- 义体：烧毁几组神经束。
- 信用：欠下多少贡献点。
- 关系：被谁除名。
- 阵营：失去哪个权限。
- 身体：左手失去触觉。
- 记忆：忘掉某个人的名字。
- 名声：被全网通缉。
- 资源：耗尽最后一支药剂。

## 5.2 代价要反复记账

不要写完就忘。

### 复用方式

- 之后战斗时旧伤拖后腿。
- 之后谈判时信用评级下降。
- 之后见旧友时对方不再信他。
- 之后升级时因为记忆缺口出错。
- 之后亲密关系里，对方发现他少了一段共同回忆。

### 科武长篇可借点

能力释放不要只写“燃烧”。

要写具体反馈：

```text
过载三秒后，他右臂义体开始反向震颤。
第五秒，指骨接口渗出银色冷却液。
第七秒，他听不见自己的心跳了。
```

# 6. 失败模式补丁

写人物时最常见的崩坏点如下。

## 6.1 人设漂移

表现：

- 前面谨慎，后面无理由莽。
- 前面护短，后面看队友送死。
- 前面贫穷，后面随手挥霍。
- 前面高智，后面为剧情降智。

修复：

```text
如果人物要改变，必须安排剧情级事件。
```

可触发改变的事件：

- 亲人死亡。
- 被最信任者背叛。
- 亲眼见证文明毁灭。
- 世界观真相崩塌。
- 身份被彻底剥夺。
- 亲手造成无法挽回的后果。

## 6.2 反差变分裂

表现：

- 冷酷角色突然撒娇。
- 正义角色突然残忍。
- 傻白甜突然算无遗策。
- 老谋深算者突然中低级骗局。

修复：

```text
反差只能补充人味，不能推翻标签。
```

## 6.3 配角工具人化

表现：

- 出场只为解释设定。
- 出场只为送装备。
- 出场只为被主角打脸。
- 没有自己的压力和欲望。

修复：

每个配角至少补一层压力：

```text
对上：他怕谁/欠谁/受谁控制？
对中：他和同级竞争什么？
对下：他要保护谁/压迫谁/隐瞒谁？
```

## 6.4 科幻设定压过人物

表现：

- 连续几段解释科技原理。
- 没有人因此做选择。
- 设定不改变人物关系。

修复：

每个设定必须落成一句：

```text
因为这个科技点，某个人做了某件事，并付出某个代价。
```

# 7. 人物口吻补丁

## 7.1 口吻必须服务标签

不同人物说话不能一个腔。

### 冷静科学型

特点：短句、数字、因果、少情绪。

```text
“成功率三成。你退后，我来承担剩下七成。”
```

### 贫民窟改造人

特点：算账、实用、警惕、少废话。

```text
“别跟我谈荣誉。荣誉能换几度电？”
```

### 世家武修

特点：讲规矩、面子、血统、传承。

```text
“你赢我可以，但不能用这种不入谱的东西赢。”
```

### 老导师

特点：慢、压迫、留半句。

```text
“我教过你怎么出刀。没教过你，把刀对准谁。”
```

### 疯批反派

特点：跳跃、亲昵、逻辑自洽但价值观扭曲。

```text
“别怕，痛只是身体在确认你还属于自己。”
```

### 狼人篇可借点

狼人短故事里，口吻要更锋利、更少解释。

村民：

```text
“夜里别开门。听见谁叫你名字，都别应。”
```

狼人嫌疑人：

```text
“你数错了。昨晚少的不是一只羊，是一个知道路的人。”
```

# 8. 段落节奏补丁

## 8.1 人物段落不写散

人物塑造段落按这个节奏：

```text
动作 → 细节 → 选择 → 反馈
```

### 示例

```text
林烬扣了三下护腕。

第三下，旧弹壳在护腕里轻轻撞响。

他没有接长老递来的通行令，反而把自己的实验编号推到桌面中央。

义手指节过热，桌面留下五个焦黑的点。
```

这个段落完成：

- 动作锚定。
- 物件记忆。
- 选择冲突。
- 身体反馈。

## 8.2 战斗段落节奏

```text
目标 → 阻碍 → 代价启动 → 反击 → 后遗症
```

不要只写招式名。

### 示例结构

```text
他要在十秒内切断兽化者的脊控芯片。
但对方的骨甲已经覆盖后颈。
林烬把义臂功率推到红线以上。
刀锋进去半寸，右臂神经束先烧断三根。
他赢了。
但之后整整一章，他再也握不住杯子。
```

## 8.3 感情/师徒段落节奏

```text
统一待遇 → 唯一差异 → 被发现 → 不解释
```

### 示例

```text
每个弟子都分到一枚修复片。

只有她那枚背面多刻了一行小字：过载后再用。

她抬头看向导师。

导师已经转身，只说：“别误会，废品仓里多出来的。”
```

用细节偏爱，不写“他很关心她”。

# 9. 章末钩子补丁

## 9.1 章末钩子必须挂在人身上

不要只用世界观钩子：

```text
远古文明的秘密即将揭开。
```

改成：

```text
林烬终于解开了远古芯片的第一层密码。
屏幕上跳出的，却是他母亲二十年前的实验编号。
```

钩子要让读者问：

- 他是谁？
- 他为什么骗我？
- 他会失去什么？
- 他下一章怎么掀桌？
- 这个关系要怎么爆？

## 9.2 可用章末钩子类型

### 身份钩

```text
通缉令上的照片不是反派，而是主角十年前的脸。
```

### 旧账钩

```text
导师看见那枚旧弹壳，第一次喊错了他的名字。
```

### 代价钩

```text
系统提示：本次过载扣除记忆三小时。
他却想不起，自己为什么站在她的病床前。
```

### 反差钩

```text
众人离开后，那个杀人不眨眼的监察官蹲下来，把死者口袋里的糖纸叠好。
```

### 阵营钩

```text
他刚救下的小队，枪口同时对准了他。
队长低声说：“抱歉，主城命令更新了。”
```

### 狼人篇可借点

短故事章末/段末钩子要更直接：

```text
他终于看清窗外那张狼脸。
那张脸，白天刚给他递过婚帖。
```

# 10. 短故事 / 狼人篇可借点

## 10.1 人物数量限制

狼人篇、短故事最多保留：

```text
1 主角 + 1 反派 + 1 反差配角
```

有名字的人最好不超过 3 个。

## 10.2 狼人篇人物配置

### 主角

标签：谨慎但心软。  
追求：活到天亮 / 找出狼人 / 救某个人。  
障碍：村规、谎言、熟人嫌疑。  
代价：信任崩塌、亲手杀错人、暴露秘密。

### 反派/狼人

标签：温柔伪装者 / 秩序维护者 / 被诅咒的守护者。  
追求：继续隐藏 / 完成献祭 / 保护某个更大的秘密。  
障碍：主角追查。  
代价：每次变身失去一段人性记忆。

### 反差配角

标签：胆小但知道真相。  
追求：逃离村子。  
障碍：没人信他。  
作用：提供误导、证词、死亡钩子。

## 10.3 狼人篇可直接套用的段落动作

- 夜里敲门，门外人叫主角小名。
- 老人反复擦同一把银刀。
- 小孩说：“昨晚的狼，是穿鞋的。”
- 白天最热心的人，夜里门槛前没有脚印。
- 村长数羊时，永远少数一个人。

# 11. 科武长篇可借点

## 11.1 角色建档必须加入科武字段

每个重要角色补充：

```text
阵营：
出身星域/城区：
武道流派：
科技改造等级：
核心能力：
能力代价：
身体现实反馈：
上中下压力：
```

## 11.2 科武人物与身份自洽

贫民窟出身：

- 对资源敏感。
- 不浪费食物、电力、药剂。
- 不轻信制度。
- 对世家子弟天然警惕。

世家出身：

- 熟悉规则。
- 在意体面和传承。
- 习惯指挥。
- 对底层技术路线有偏见。

实验体出身：

- 对编号、权限、观察、记录敏感。
- 不习惯被当作普通人对待。
- 身体反应比情绪反应更快。
- 追求身份归还或彻底摆脱身份。

武道宗门出身：

- 重师承、招式谱系、名分。
- 抗拒“非正统”的科技改造。
- 可能看不起芯片辅助战斗。
- 但危急时会被迫使用科技。

## 11.3 科武长篇重点门禁

允许短期憋屈，但必须同卷兑现。

```text
本卷压主角 → 本卷让主角以更高代价反杀/翻盘/掀桌。
```

不能让读者长期只看主角吃亏。

# 12. 平台规则转译：发布 / 包装 / 风险门禁

## 12.1 发布门禁

发布前检查：

- 主角前 3 章是否明确“想要什么”？
- 首章是否有记忆点动作/物件？
- 是否有可截图传播的爽点或反差点？
- 男频向是否避免长时间憋屈？
- 女频/感情线是否有细节偏爱？
- 新角色是否过多？
- 本章是否有掀桌行为？

不满足则不发，先改。

## 12.2 包装门禁

简介、书名、章节名要突出人物标签和冲突，不要只包装设定。

弱包装：

```text
这是一个科武融合时代，少年探索宇宙真相的故事。
```

强包装：

```text
被实验室抹去姓名的贫民少年，靠一条报废义臂，掀翻了垄断武道的九大世家。
```

章节名可走：

- 《他把实验编号拍在长老桌上》
- 《这一刀，烧掉三年寿命》
- 《她那块能源饼里，多了一枚芯片》
- 《主城命令：杀死林烬》
- 《狼人白天来参加了葬礼》

## 12.3 风险门禁

### 风险1：主角太憋屈

处理：

- 可以输，但必须让他拿回一样东西。
- 可以被羞辱，但必须埋下反击。
- 可以被压制，但不能无行动。

### 风险2：人物太多

处理：

- 单章新有名角色 ≤ 2。
- 功能重复者合并。
- 没有上中下压力者删戏。

### 风险3：设定太硬

处理：

- 每 300 字设定，必须插入人物行动。
- 每个科技点都要改变一次选择。
- 每场解释都要有人因此获利或受损。

### 风险4：反派无脑恶

处理：

给反派补：

```text
他怕谁？
他要赢谁？
他保护/控制谁？
他作恶能得到什么？
他不作恶会失去什么？
```

# 13. 写作前任务卡字段更新

每章开写前，任务卡新增以下字段。

## 13.1 章节人物任务卡


# 14. 章节自检清单

每章写完后按以下清单检查。

```text
[ ] 本章核心人物的追求是否清楚？
[ ] 本章是否有人被障碍卡住？
[ ] 被卡住后是否发生掀桌行为？
[ ] 掀桌之后是否产生代价？
[ ] 代价是否具体、可追踪，而不是一句“很痛”？
[ ] 本章是否用动作/物件强化人物标签？
[ ] 新出场有名角色是否不超过2个？
[ ] 每个有名角色是否至少有一层上中下压力？
[ ] 人物言行是否符合出身、阵营、技术等级？
[ ] 是否有设定堆砌但无人行动的段落？
[ ] 是否用细节表达关系，而不是直接说“他对她很好”？
[ ] 反差是否仍在人设逻辑内？
[ ] 若人物性格变化，是否有剧情级事件触发？
[ ] 男频向：读者是否不会憋屈到弃章？
[ ] 科武向：本章科技/武道设定是否落到了某个人的选择和代价上？
[ ] 章末钩子是否挂在人身上，而不是空泛世界观？
```

# 15. 最小执行版

如果时间紧，只执行这 5 条：

1. **人物首秀 = 动作 + 物件 + 追求。**
2. **前三次出场反复放大同一个标签。**
3. **每章必须有追求被卡后的掀桌。**
4. **每次赢都要付可见代价。**
5. **章末钩子必须挂在人物秘密、关系或代价上。**

一句话补丁：

> 单标签立人，三层压力立场，追求被卡掀桌，胜利必须付账，反差只能加味不能换魂。
