## 一、写作前任务卡字段更新

> 以下字段为**必填项**，每章开写前须完成填充。未填充者视为任务未启动，禁止动笔。

| 字段 | 触发条件 | 填写标准 | 示例 |
|:---|:---|:---|:---|
| **本话承诺** | 每次动笔前 | 用≤15字描述本章核心交付物（能力验证/冲突解决/伏笔触发） | "神经同步率突破85%阈值" |
| **代价注入** | 承诺交付后 | 列出本话代价清单，格式：`代价类型→显性化时间节点` | "神经灼痛累积→下章战斗发作" |
| **爽点接口** | 冲突设计前 | 标注本话爽点类型及触发位置 | "类型A：反杀预埋（章末前200字）" |
| **节奏阀值** | 日常段落 | 标注每500字必须出现一次"轻喜剧/反讽/解压"元素 | "实验室日常第2段插吐槽" |
| **章末钩子** | 章节收尾前 | 必须是**未完成动作链**+**代价未兑现**的组合，禁止纯情绪断章 | 见下方钩子模板 |

## 二、章节自检清单（动笔后/发布前双重验证）

### 【动笔中验证点】——每500字触发一次

```
□ 本段是否有可量化的物理反馈？（温度/压力/能量读数/神经信号）
□ 冲突是否携带情绪释放属性？（解压/反讽/爽感补偿）
□ 日常段落是否触发节奏阀值？（轻喜剧/吐槽/反差萌）
□ 主角选择是否具备"非妥协性"？（拒绝安全路径/常规方案）
□ 代价是否已显性化或已标注兑现节点？
□ 是否存在"叶短刀"风险？（动作链未完成处断更）
```

### 【发布前验证点】——全章完成后触发

```
□ [ ] 本章承诺是否已兑现？承诺字≤15字
□ [ ] 代价是否在3章内显性化？代价清单已录入
□ [ ] 章末钩子是否为"未完成动作链+未兑现代价"组合？
□ [ ] 硬核段落是否配置轻喜剧/反讽接口？（≤1500字/次）
□ [ ] 开篇3章是否仅保留核心设定+主线钩子？冗余背景已删/后置
□ [ ] 伏笔/爽点是否已录入"学习数据库"？
□ [ ] 科武设定是否通过物理序列验证？（感知→决策→发力→反馈）
□ [ ] 读者预期兑现进度条：开局承诺5章内首次验证通过
```

## 三、执行动作清单（按写作场景分类）

### 场景A：开篇设计

**执行动作序列：**

```
1. 锁定核心设定（金手指/科技树/武道阶位三选一，不超过1个）
2. 输出"开头大纲"：核心设定 + 金手指 + 首个冲突
   → 不追求世界观完整，仅提供入口
3. 前3章必须完成"能力/体系首次验证"
   → 验证失败=承诺未兑现，需在章评公开补丁
4. 冗余背景判定：
   - 需要2段以上解释的设定 → 后置
   - 需要跨章节铺陈的设定 → 删除或归并
5. 植入轻喜剧节奏节点：
   → 位置：每800字日常段落后插入
   → 形式：AI吐槽/系统弹窗/搭档反讽/意外反差
```

**失败模式识别：**

| 失败类型 | 触发特征 | 修复动作 |
|:---|:---|:---|
| 设定过载 | 前3章出现3个以上独立概念 | 删除最晚出现的一个，后续用类比引入 |
| 承诺画饼 | 5章内无验证 | 紧急插入"能力测试"章节，最迟第6章交付 |
| 压抑无解压 | 连续1500字无爽感补偿 | 插入"反讽对话"或"意外转折" |
| 背景倒灌 | 开篇出现超过200字的设定说明 | 强制改为场景动作，用疑问替代说明 |

---

### 场景B：冲突设计

**执行动作序列：**

```
1. 冲突必须携带"情绪释放"属性
   → 禁用：纯虐主、无意义打压、权威无脑碾压
   → 启用：反讽式对抗、意外联盟、降维打击、不对称优势
2. 每次受挫后触发"爽感补偿链"：
   受挫发生 → 1-2章内 → 反杀/破局/认知升级（三选一）
3. 冲突设计需绑定"代价"
   → 格式：冲突目标 + 代价类型 + 代价触发时机
   → 示例：突破防线 → 神经同步率过载 → 第X章战斗发作
4. 科武逻辑冲突替代"老祖劝阻"：
   → "数据模型警告" vs "伦理委员会否决" vs "资源配额限制"
   → 保持理性推演质感，禁止降智压制
```

**人物口吻模板（科武向）：**

```
【主角型】——"非妥协性"锚定
- 拒绝安全路径："这个方案稳妥，但你算过成功率吗？我的数据是不带情绪的。"
- 强推高难功法："代价我看过了。比我预估的低。"
- 不解释型："你问为什么？因为我能。"

【配角型】——理性/系统化语调
- 数据型："根据现有参数，成功率上调至12.7%。"
- 警示型："警告：当前方案存在34项未知变量，建议重新评估。"
- 对抗型："你的逻辑有漏洞。我来补。"

【反派型】——科武化傲慢
- 技术压制："你的认知还在上一代。我已经淘汰了那个版本。"
- 资源碾压："你以为这是赌局？不，这是预算问题。"
- 降维打击："你想用战术弥补战略失误。有意思。继续。"
```

### 场景C：段落节奏控制

**段落节奏模板：**

| 段落类型 | 长度上限 | 节奏阀值 | 示例触发器 |
|:---|:---|:---|:---|
| 战斗/修炼 | 800字/段 | 无需解压 | 物理序列+代价反馈 |
| 日常/训练 | 500字/段 | 每段必须插入 | 系统弹窗/搭档吐槽/意外故障 |
| 冲突/对抗 | 600字/段 | 每300字需有节奏切换 | 反讽/意外联盟/数据反转 |
| 伏笔/揭示 | 400字/段 | 需配置悬念尾 | 未完成动作链收尾 |

**轻喜剧接口库（可直接调用）：**

```
1. 系统弹窗型
   "【警告】检测到使用者心率异常。是否切换至'安全模式'？[Y/N]
   → 选择N。系统回复：'已记录。您的死亡概率上调至89%。'"

2. 搭档反讽型
   "你刚才那招的数据很漂亮。漂亮到我的传感器以为你在表演。
   → 搭档停顿0.3秒
   → '但你落地的时候左膝偏差3度。还要我继续吗？'"

3. 意外反差型
   "战斗结束。机甲静默。
   → 通讯频道弹出：'您的外卖已送达。请至3号停机坪取餐。'"

4. 技术吐槽型
   "这不是故障。这是'设计余量'。
   → 注释：即开发者留下的、为数不多的正常功能。"
```

### 场景D：章末钩子模板

**合格钩子公式：**

```
章末钩子 = 未完成动作链 + 未兑现代价

❌ 错误示范（情绪断章）：
"他握紧拳头，眼中满是愤怒。明天，一切都会不同。"
→ 无动作链，无代价，无钩子

✅ 正确示范（动作链+代价）：
"能量阀值突破临界，但冷却循环已断裂，舱内温度正以每秒2℃攀升。
→ 未完成动作链：能否在舱内温度抵达阈值前完成修复？
→ 未兑现代价：冷却液耗尽后神经同步率将强制熔断

✅ 正确示范（冲突升级型）：
"他关闭通讯频道。走廊尽头，三道新的热源信号正在逼近。
→ 未完成动作链：能否在合围形成前找到出路？
→ 未兑现代价：刚才强行同步的代价值得吗？"
```

**钩子类型对照表：**

| 类型 | 触发条件 | 模板句式 |
|:---|:---|:---|
| 能力临界型 | 战斗/修炼高潮后 | "功率突破阈值，但[反馈链断裂]，下一章[代价发作]" |
| 追踪逼近型 | 冲突/逃亡场景 | "热源信号数量：X，在[x时间]后将完成合围" |
| 伏笔触发型 | 剧情关键节点 | "屏幕闪过一行代码：[未识别命令]，他的瞳孔骤缩" |
| 抉择倒计时型 | 核心选择前 | "剩余决策时间：[倒计时]，选项A的风险是[已知代价]" |

### 场景E：代价与失败模式

**代价设计清单（每章必选一项）：**

| 代价类型 | 科武化表达 | 显性化时限 |
|:---|:---|:---|
| 神经损伤 | "神经灼痛评分：7.3/10，持续时间未知" | 1章内 |
| 资源枯竭 | "冷却液剩余：23%，维护窗口：0" | 即时 |
| 寿命折损 | "同步超时导致细胞端粒缩短0.7%，不可逆" | 3章内 |
| 伦理风险 | "伦理委员会调查令已触发，下次审查：第X章" | 3章内 |
| 系统惩罚 | "因违规操作，您的B级权限已降为C级，功能锁定：[列表]" | 即时 |
| 关系代价 | "您的搭档申请解除同步协议，理由：'风险评估不合格'" | 下章触发 |

**失败模式识别与修复：**

| 失败模式 | 识别信号 | 强制修复动作 |
|:---|:---|:---|
| 无代价开挂 | 连续3次压倒性胜利无损耗 | 下一章强制插入"隐性代价"，延迟发作但必须发作 |
| 战力崩坏 | 段评出现"战力崩了"关键词≥2次 | 紧急发布"战力说明"章节，重新校准参数 |
| 设定漏洞 | 段评出现逻辑矛盾 | 3章内补丁，通过"数据更新/版本迭代"合理化 |
| 承诺画饼 | 开局承诺10章内未兑现 | 紧急触发"验证章节"，最迟第12章交付 |
| 断更卡点 | 连续2章在动作链中段断更 | 下章必须完成当前动作链，强制补充200字收尾 |

## 四、平台规则 → 发布/包装/风险门禁 转换

| 编辑规则 | 作家执行转换 | 风险门禁 |
|:---|:---|:---|
| 章评监控-大纲补丁 | 每周末提取Top3高频偏好词、Top3毒点词 | 高频偏好词 → 下一章剧情微调；毒点词 → 3章内补丁 |
| 数据驱动调优 | 追读率<阈值、完读率下滑、段评互动量下降 | 触发"节奏自检"，需在下一章完成调整 |
| 改编逻辑剥离 | IP改编方向需提前准备"主线独立版本" | 依赖段评互动的碎片化梗需在正文去重 |
| 更新量对冲期待值 | 关键卡点章节需额外提供500字"额外交付"（番外/注释/设定补完） | 未达标时需提前告知读者并提供补偿更新 |
| 读者反馈-大纲迭代 | 建立"反馈-补丁"双周循环机制 | 连续2周期无迭代 → 自动触发编辑介入 |

## 六、核心警示（作家OS优先级）

```
⚠️ 优先级1：承诺必须兑现
   → 开篇承诺5章内验证，否则读者流失不可逆

⚠️ 优先级2：代价必须发作
   → 代价未兑现=无代价开挂，直接破坏读者信任

⚠️ 优先级3：禁止"叶短刀"式断更
   → 动作链中段断更=追读率崩盘，需用更新量对冲

⚠️ 优先级4：科武设定必须通过物理序列验证
   → 跳过物理反馈=设定悬浮，段评将出现逻辑质疑

⚠️ 优先级5：节奏阀值必须触发
   → 每500字日常段落未插入轻喜剧=压抑累积，读者留存率下降
```
