# 可拖动 AI 自由对话入口设计

## 目标

把桌面端自由对话入口从固定的“对话”按钮升级为可拖动、可持久化位置的“AI”圆形按钮，并加入克制的悬停反馈和静止呼吸效果。自由对话窗打开后保持常驻，点击窗外不关闭或最小化。

## 范围

- 仅覆盖桌面端 `#creative-float-launcher` 的文字、位置、拖动与动效。
- 保持现有自由对话窗的拖动、缩放、最小化、关闭和会话恢复行为不变。
- 不增加第三方依赖，不修改模型、会话、MCP 或书库协议。
- 不承诺移动端触摸布局，但 Pointer Events 必须避免多指切换导致位置跳变。

## 交互设计

### 默认状态

- 按钮内容为 `AI`，保持 52×52 圆形尺寸。
- 首次使用位于视口右下角，距离右侧和底部各 24px。
- 按钮静止时以约 3 秒周期进行轻微上下浮动和柔和光晕呼吸。
- 呼吸动画只使用 `transform` 和 `box-shadow`，不得影响页面布局。

### 悬停与按下

- 仅在 `hover: hover` 且 `pointer: fine` 的设备启用悬停效果。
- 悬停时按钮轻微放大，边框、文字和光晕增强，反馈时长不超过 180ms。
- 按下但未拖动时缩小到约 0.97，松开后立即恢复。
- 不使用 `transition: all`，只声明实际变化的属性。

### 拖动

- 使用 Pointer Events，并在按下后捕获当前 pointer。
- 位移超过 5px 才进入拖动态；低于阈值仍作为普通点击打开对话窗。
- 同一时刻只接受一个 pointer，忽略后续触点，直至当前 pointer 结束或取消。
- 进入拖动态后暂停呼吸动画，按钮直接跟随指针。
- 拖动位置限制在视口内，按钮四周至少保留 12px 安全边距。
- 松开或取消时保存最终位置，不在每次 pointermove 时写存储。

### 位置持久化

- 使用独立键 `nwa.float-launcher.position.v1` 保存 `{left, top}`。
- 首次没有存储时使用右下角默认位置。
- 页面刷新后恢复保存的位置。
- 窗口尺寸变化时重新夹取位置，确保按钮不会落在屏幕外，并保存修正后的结果。
- 存储不可用或内容无效时静默回退到默认位置，不影响打开对话窗。

### 对话窗常驻

- 点击 AI 按钮继续调用现有 `floatChat.open()`。
- 点击自由对话窗以外的页面区域不得关闭、隐藏或最小化对话窗。
- 只有现有的最小化按钮和关闭按钮可以主动收起对话窗。
- 拖动 AI 按钮不得改变对话窗当前显示状态。

## 动效与可访问性

- 呼吸效果应低振幅、低频率，不使用弹跳或大幅缩放。
- 拖动期间停止呼吸；拖动结束后恢复。
- `prefers-reduced-motion: reduce` 下取消呼吸、上下浮动和缩放位移，只保留颜色与边框反馈。
- 按钮保留 `aria-label="打开自由对话"`，可通过键盘聚焦并按 Enter/Space 打开。
- 键盘触发不播放拖动或按压位移动画。

## 组件边界

- `web/floating-chat.js`：新增独立的 launcher position reducer、存取方法与 `bindLauncher()`；不把按钮位置混入对话窗几何对象。
- `web/app.js`：把 AI 按钮交给 `floatChat.bindLauncher()`，保持现有打开回调。
- `web/index.html`：把按钮文字改为 `AI`，增加呼吸、悬停、按下、拖动态和 reduced-motion 样式。
- `tests/js/test_floating_chat.mjs`：验证阈值、位置夹取、拖动持久化、刷新恢复、resize 修正和点击/拖动互斥。
- `tests/js/test_workbench_chat_integration.mjs`：验证 AI 文案、常驻契约、样式与绑定存在。

## 错误处理

- Pointer capture 失败时仍通过 document 级 pointermove/pointerup 完成拖动。
- `pointercancel` 与 `lostpointercapture` 必须结束拖动并保存最后一个合法位置。
- localStorage 读取、解析或写入异常不得向用户抛错。
- 拖动结束后必须清除拖动态 class 和 pointer 状态，避免按钮永久停在 busy 外观。

## 验收标准

- 按钮显示为 `AI`，首次位于右下角。
- 鼠标悬停、按下和静止呼吸效果清晰但克制。
- 拖动超过 5px 不会误开对话窗；普通点击仍能打开。
- 拖动位置在刷新后保持，窗口缩小时仍位于 12px 安全区内。
- 点击对话窗外部不会关闭或最小化对话窗。
- 打开、最小化、恢复和既有会话功能无回归。
- reduced-motion 环境中没有持续位移动画。
- JS 全量测试、发布检查与真实桌面浏览器验收通过。
