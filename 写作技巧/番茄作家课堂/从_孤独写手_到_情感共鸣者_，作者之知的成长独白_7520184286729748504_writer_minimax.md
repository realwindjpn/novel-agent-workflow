# 《科武纪元》作家OS可执行补丁 v2.0

*——从“孤独写手”到“情感共鸣者”的实操工作流*

---

## 【补丁概述】

本补丁将编辑学习报告转化为**可直接嵌入写作流程的操作指令集**，适用于：
- 单章节创作即时调用
- 每日写作任务卡填充
- 章节完成后自检核验

---

## 一、写作前任务卡字段更新

> **使用方式**：每日写作前填写以下字段，形成“任务卡→执行→自检”闭环

### 🔧 基础任务卡（必填）

| 字段 | 填写模板 | 示例 |
|:---|:---|:---|
| **本章目标** | 本章要完成什么事？（情节推进/人物弧光/设定铺设） | 主角完成第一次机甲神经接驳，暴露其与青梅竹马的身份冲突 |
| **核心情绪锚点** | 本章结束后读者应感受到什么？ | 痛感（接驳灼烧）+ 愧疚（隐瞒身份）+ 悬念（对方认出我了？） |
| **动作闭环** | 意图→发力→受阻→变招→结果 | 接驳→神经过载→强忍→切换手动模式→接驳成功但手臂暂时失能 |
| **代价注入点** | 本章哪个胜利必须付出代价？ | 神经接驳成功 = 24小时感官迟钝 = 错过后续关键情报 |
| **章末钩子设计** | 悬念+情绪悬置双条件 | （悬念）敌人已锁定我方坐标；（情绪）但通讯器里传来妹妹的哭声 |
| **配角高光时刻** | 哪个配角在本章有自己的欲望/行动？ | 反派：我有独立动机（救女儿），非纯工具人；青梅：本章需展示“误解主角”的自主选择 |

### 📊 数据预判字段（科武长篇）

| 字段 | 填写模板 | 说明 |
|:---|:---|:---|
| **设定密度预警** | 本章预计有多少字用于科幻/武道设定说明？ | 目标≤20%，超标则拆至下章 |
| **爽点节点位置** | 本章哪个段落应触发“小节点爽感”？ | 通常在章中40%-60%区间 |
| **读者预期管理** | 前文承诺了什么？本章兑现/延后？ | 承诺“机甲过载有代价”，本章兑现：代价 = 视野雪花 |
| **AI辅助清单** | 哪些部分计划用AI生成？（星图/经脉图谱/势力树/装备参数） | 仅背景辅助，禁止AI生成人物情感抉择 |

- [ ] **短故事/狼人篇可借点**：适用于单篇情感向创作（≤2万字）

## 二、创作执行指令集

> **使用方式**：写作时逐条对照执行，发现偏离立即修正

### ⚡ 【动作链指令】（科武长篇核心）

**命令**：每个战斗/探索/决策场景必须包含五要素闭环。

```
意图 → 发力 → 受阻 → 变招 → 结果
```

**禁止模式**：
- ❌ 意图→瞬发→胜利（无逻辑跳跃）
- ❌ 发力→纯特效描写→对手认输（无代价）
- ❌ 结果→自动后续剧情（无角色决策）

**正确示例**（科武）：

> “他启动神经接驳**（意图）**，能量涌入经脉**（发力）**，但敌方EMP击中机甲胸口**（受阻）**，他强忍神经灼烧切换手动操控**（变招）**，成功闪避但右臂接驳端口烧毁**（结果+代价）**。”

**失败成本**：动作链断裂 = 读者出戏 = 追更率下滑

---

### 🔥 【物理反馈指令】（科武长篇核心）

**命令**：所有力量体系必须具象化，禁止抽象形容词。

| 力量类型 | 具象化要求 | 错误示范 | 正确示例 |
|:---|:---|:---|:---|
| **机甲过载** | 神经/物理双重反馈 | “威力惊人” | “视野雪花，冷却液从颈管喷出，肋骨传来钝痛” |
| **武道突破** | 骨骼/肌肉/能量三重反馈 | “气势如虹” | “指骨末端骨裂，肌肉纤维撕裂又重组，经脉温度骤降” |
| **AI辅助** | 必须伴随认知副作用 | “超智能决策” | “逻辑链压缩选项至2个，情感判断模块被强制休眠” |
| **势力博弈** | 资源/关系/信息三重代价 | “敌方阴谋得逞” | “情报泄露导致三座殖民卫星失去补给，盟友信义值-15” |

**失败成本**：抽象描写 = 设定可信度崩塌 = 读者无法代入

---

### 💔 【代价注入指令】（全类型核心）

**命令**：每次力量获取/战术胜利必须明确代价，禁止“白嫖爽点”。

**代价类型清单**：

| 代价类型 | 适用场景 | 示例 |
|:---|:---|:---|
| **生理代价** | 武道/机甲/改造 | 突破境界 = 寿命折损3年 |
| **情感代价** | 羁绊/亲情/信任 | 选择战斗 = 错过妹妹成人礼 |
| **资源代价** | 装备/经济/时间 | 使用禁忌武器 = 本卷弹药耗尽 |
| **关系代价** | 阵营/盟友/立场 | 揭示真相 = 师门将我除名 |
| **认知代价** | AI/记忆/自我 | 接入共享神经网 = 自我边界模糊 |

**强制规则**：
- 一个爽点 ≥ 一个代价（配平原则）
- 代价必须在结果段落**明确呈现**，不得暗示或延后

**失败成本**：无代价爽点 = 读者价值判断失灵 = 长期留存率崩塌

---

### 🎣 【章末钩子指令】（全类型核心）

**命令**：章末必须同时满足**悬念悬置**与**情绪悬置**。

| 元素 | 定义 | 正确示例 | 错误示例 |
|:---|:---|:---|:---|
| **悬念悬置** | 留下未解信息缺口 | “他低头看见手背浮现的纹路——这是觉醒征兆，还是诅咒？” | “他离开房间，准备迎接下一场战斗”（纯信息预告） |
| **情绪悬置** | 触动读者普世情感 | “通讯器里妹妹的呼吸声断断续续，但坐标已偏离安全区”（焦虑+无力感） | “欲知后事如何，请看下回”（废话） |

**快速自检**：读到这里，我自己想追更吗？

---

### 🗣️ 【人物口吻指令】（情感共鸣核心）

**命令**：主角台词必须承载**真心**，即普世痛点/欲望/恐惧。

**真心检测三问**：
1. 这句话是否映射人类共通情感？（孤独/认同/归属/被爱/被看见）
2. 读者能否在非科武情境下理解这句话？
3. 这句话是否推动人物弧光或揭示核心动机？

**反面教材**：
> “我是联邦第一机甲师，肩负人类存亡之责！”（宣传口号，无真心）

**正面教材**（科武情感转译）：
> “每次接驳时我感觉不到疼痛了，我怕的不是死，是有一天连愤怒都感觉不到。”（技术异化下的情感缺失 = 真心）

**配角独立动机检测**：
- 配角有自己的欲望吗？（非“帮主角”）
- 配角有自己的高光时刻吗？（独立行动并成功/失败）
- 配角的情感动机是否可被普通读者理解？

---

### 📐 【段落节奏指令】（全类型核心）

**命令**：遵循“套路骨架”节拍器。

| 节拍 | 位置 | 内容要求 | 数据验证 |
|:---|:---|:---|:---|
| **小节点** | 每3章 | 悬念/微爽/情绪断点 | 完读率应在章尾回升 |
| **中节点** | 每10章 | 阶段目标达成/代价显现 | 追更率应在章尾峰值 |
| **大节点** | 每卷结尾 | 核心伏笔回收/阵营重组 | 需完成≥1伏笔闭环 |

**节奏自检**：
- 本章中段是否有“微爽”？（让读者喘口气再虐）
- 情绪是否有起伏曲线？（禁止全程高能/全程压抑）
- 断点处是否留情绪悬置？（禁止情绪戛然而止）

---

### 🛡️ 【平台规则转化指令】（发布门禁）

> **使用方式**：章节完成后转化为发布准备

| 规则类型 | 执行标准 | 违规风险 |
|:---|:---|:---|
| **开篇门槛** | 前3章必须“世界观入口+情绪钩子+首个行动目标”三合一 | 弃书率飙升 |
| **承诺兑现** | 科幻设定承诺≤3章兑现；武道升级承诺≤10章兑现 | 违约≥2次触发弃书阈值 |
| **评论区响应** | 差评拆解为“情绪断点/设定门槛/节奏拖沓”，48小时内输出修改方案 | 用户流失 |
| **改编预留** | 每卷设置2-3个强情绪名场面；台词需“可截图传播” | 长尾价值损失 |

## 三、章节自检清单

> **使用方式**：章节完成后逐条核验，√通过 / ✗需返工

### 【必检项】（任一✗需返工）

- [ ] **动作链闭环**：本章战斗/探索/决策场景是否包含“意图→发力→受阻→变招→结果”？
- [ ] **物理反馈具象化**：力量体系是否有明确的感官/物理表现？（禁止抽象形容词）
- [ ] **代价注入**：本章的胜利是否支付了明确代价？（生理/情感/资源/关系/认知任一）
- [ ] **章末钩子**：是否同时包含悬念悬置+情绪悬置？（双条件缺一不可）
- [ ] **主角真心**：核心台词是否映射普世情感？（孤独/认同/归属/被爱/被看见）
- [ ] **配角独立性**：配角是否拥有独立于主角的欲望与高光时刻？（非纯工具人）
- [ ] **设定密度**：科幻/武道说明性段落是否≤20%？（超标需拆至下章）
- [ ] **承诺兑现**：本章是否完成前文承诺的设定验证或升级兑现？

### 【推荐项】（2项以上✗需优化）

- [ ] **AI辅助边界**：AI生成内容是否仅用于背景/设定？（核心情感/抉择必须人工）
- [ ] **情绪曲线**：本章是否有起伏？（禁止全程高能或全程压抑）
- [ ] **节奏节拍**：小节点（3章）/中节点（10章）是否嵌入？
- [ ] **改编潜力**：核心台词/场景是否具备“可截图传播”或视觉化改编可能？
