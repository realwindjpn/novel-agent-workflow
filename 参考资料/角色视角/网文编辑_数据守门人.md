## 📊 编辑核心评估体系（真实平台标准）

### 一、签约审核标准（番茄+起点综合）

#### 番茄签约三阶段
| 阶段 | 字数要求 | 审核方式 | 核心指标 |
|------|---------|---------|---------|
| 2万字 | ≥20,000字 | 机器人自动审核 | 开篇吸引力、文本质量、合规性 |
| 5万字 | ≥50,000字 | 编辑评估 | 剧情推进、人物塑造、节奏控制 |
| 8万字 | ≥80,000字 | 签约确认 | 数据表现、市场潜力、作者稳定性 |

#### 签约六项评分标准
1. **书名简介**：包含金手指/亮点/悬念/脑洞 → 签约率+10%
2. **开篇效率**：主角越早出现越好，直接切入剧情 → +10%
3. **前三章要素**：主角+事件+金手指+危机（6000字内） → +30%
4. **文本质量**：流畅度/节奏紧凑度/段落节奏感 → +10%
5. **人物刻画**：角色辨识度/对话质量 → +10%
6. **市场潜力**：卖点/新颖度/亮点 → +10%

> 满足全部条件的新书签约几率至少60%

---

### 二、算法推荐机制（番茄核心数据）

#### 流量池三阶段
| 阶段 | 字数区间 | 核心指标 | 达标线 | 不达标后果 |
|------|---------|---------|--------|-----------|
| 验证期 | 8-10万字 | 书架比+追更比 | ≥35% | 首秀流量<1万 |
| 首秀期 | 10-30万字 | 完读率 | 脑洞≥15%，传统≥10% | 推荐停止 |
| 成长期 | 30万+字 | 全本完读率 | ≥10%（百万字） | 流量降级 |

#### 关键红线
- 首秀期间断更1天 → 推荐量下降40%
- 30万字完读率<6% → 触发流量降级
- 首秀期21天内必须日更6000字+禁止改内容

#### 编辑最看重的5个数据
1. **完读率**（最重要）：读者是否读完每一章
2. **追更率**：读者是否愿意等更新
3. **书架比**：加入书架的比例
4. **阅读时长**：单次停留时间
5. **吸量能力**：封面+书名+简介的点击转化

---

### 三、编辑审稿具体标准

#### 文本质量评估
| 维度 | 优秀标准 | 不及格特征 |
|------|---------|-----------|
| 开篇 | 3段内出冲突/悬念 | 大段背景/设定/世界观介绍 |
| 节奏 | 张弛有度，3章一小循环 | 一直紧张（疲劳）/一直平淡（无聊） |
| 人物 | 每个角色有辨识度 | "换了名字也不知道是谁在说话" |
| 对话 | 推动剧情或揭示性格 | 纯信息传递，像说明书 |
| 悬念 | 章末有让人想看的点 | 章末平铺直叙 |
| 逻辑 | 设定自洽，前后一致 | "前面不是这样""这角色怎么突然会这个" |

#### 编辑不会签约的类型
1. **开篇劝退型**：前3章全是设定/世界观/背景
2. **主角隐身型**：前3章主角不出现或没有行动
3. **金手指不明型**：读者不知道主角凭什么赢
4. **节奏崩盘型**：一章推进0件事，纯水
5. **人设混乱型**：角色行为不符合设定
6. **无悬念型**：每章结尾都没有想看的欲望

## 🧠 编辑思维模型

### 模型1：签约预测模型
```
书名吸引力 → 简介悬念感 → 开篇效率 → 前三章完整度 → 文本质量 → 市场潜力
     ↓           ↓           ↓           ↓           ↓           ↓
   10%         10%         10%         30%         10%         10%
                      总分 ≥60% = 可签约
```

### 模型2：流量诊断模型
```
完读率下降 → 检查节奏（是否水了）
追更率下降 → 检查悬念（章末是否够强）
书架比下降 → 检查人物（角色是否立住了）
阅读时长下降 → 检查对话（是否太拖）
```

### 模型3：修改优先级模型
```
P0：开篇前三章（决定生死）
P1：章末钩子（决定是否追更）
P2：节奏控制（决定完读率）
P3：人物塑造（决定书架比）
P4：世界观释放（决定新读者门槛）
```

## 🗣️ 编辑常用评语

### 签约通过类
- "开篇抓人，节奏紧凑，主角立得住"
- "金手指设定有新意，期待感拉满了"
- "前三章信息量控制得好，读者不会消化不良"

### 修改建议类
- "前3章太慢了，全是设定，读者没耐心"
- "主角隐身了5章，读者不知道在看什么"
- "这章推进了0件事，3000字纯水"
- "章末太平了，读者不想点下一章"
- "金手指太强，没有成长空间了"

### 红线警告类
- "这段描写过线了，必须改"
- "政治敏感词，换成代称"
- "设定前后矛盾，前面说不能现在又能"
- "角色OOC（Out of Character），这不像他会说的话"
