# 《科武纪元》作家OS补丁  
## 课程补丁：大纲设计｜核心纲 + 强设定，让剧情一顺到底

---

## 0. 本补丁目标

把“大纲”变成写作执行系统。

你以后开新篇、开新卷、写新章时，不再先问：

> “我想写什么设定？”

而是先锁定：

> “主角现在处于什么困境？他要达成什么目标？必须经过哪些关键结果？每一步要付出什么代价？章末用什么钩子拉读者继续看？”

---

# 1. 作家OS核心执行规则

## 1.1 核心纲必须双层锁定

### 表层核心纲：剧情导航

每个故事、每卷、每个10万字阶段，都必须能用一句话说清：

> 主角在【开篇困境】中，为了【核心目标】，必须完成【关键路径】，最终进入【终局状态】。

模板：

> 被【势力/规则/身体缺陷/技术壁垒】压制的主角，为了【生存/复仇/升级/拯救/翻盘】，必须依次完成【KR1、KR2、KR3】，最终获得【身份/力量/真相/阵营地位】。

### 里层核心纲：读者安利标签

必须能提炼成一句读者愿意转发的卖点。

示例：

- “底层武者用古武破解高阶机甲，硬刚科技贵族。”
- “基因残次品靠生物算法，逆推武道进化。”
- “被淘汰的旧武道，在星际战争里重新成为杀神体系。”
- “狼人短篇：被污染的猎人必须在变成怪物前找出真凶。”

# 2. 写作前任务卡字段更新

每章开写前，必须填写以下字段。

## 2.1 故事级字段

| 字段 | 填写要求 |
|---|---|
| 故事表层核心纲 | 开篇困境 + 核心目标 + 终局状态，500-2000字内 |
| 故事里层卖点 | 一句话安利语，必须有强标签 |
| 主角初始状态 | 身份、缺陷、资源、敌人、社会位置 |
| 主角核心欲望 | 生存、复仇、变强、救人、翻案、夺权等 |
| 终局状态 | 主角最后要变成什么：技术权限、武道等级、阵营身份、世界影响力 |
| 三条世界铁律 | 设定不可违背的底层规则 |
| 最大禁区 | 哪些桥段绝不能写，否则吃书或跑题 |
| 平台包装标签 | 书名关键词、简介卖点、前三章钩子、名场面方向 |
| 风险门禁 | 是否拖沓、是否设定解释过多、是否卖点模糊、是否前10万字无闭环 |

---

## 2.2 阶段/卷级字段

| 字段 | 填写要求 |
|---|---|
| 当前阶段O | 本阶段主目标，10-30万字内完成 |
| KR1 | 必须可见、可实现、必要 |
| KR2 | 必须推动O，不能只是支线爽点 |
| KR3 | 必须制造冲突升级 |
| KR4/5 | 仅在必要时添加 |
| 阶段高潮 | 先定爆点，再倒推铺垫 |
| 阶段代价 | 完成O后主角失去什么 |
| 阶段钩子 | 完成O后暴露的新危机 |
| 阵营变化 | 谁信任主角，谁开始针对主角 |
| 技术变化 | 主角获得/破解/损耗了什么技术 |

---

## 2.3 章节级字段

| 字段 | 填写要求 |
|---|---|
| 本章目标 | 主角这一章要完成什么小目标 |
| 对应KR | 本章服务哪个KR |
| 触发事件 | 什么逼主角行动 |
| 主角决策 | 主角主动选择了什么方案 |
| 执行动作链 | 目标触发 → 决策 → 执行 → 受阻 → 破局 |
| 技术/武技调用顺序 | 扫描、判断、启动、过载、近战、撤离等 |
| 阻碍 | 人、规则、资源、技术、身体代价 |
| 物理反馈 | 伤害、损耗、环境变化、参数反馈 |
| 代价 | 信用点、装备损坏、身体负荷、关系破裂、信息暴露 |
| 情绪点 | 爽、怒、怕、疑、痛、反转 |
| 章末钩子 | 悬念钩子或利益钩子，绑定未完成KR |
| 禁止项 | 本章不得写无效日常、无关支线、纯解释设定 |

# 3. 大纲执行动作

## 3.1 开篇前三章动作

前三章必须完成以下动作：

### 第1章：亮困境 + 亮卖点

必须让读者看到：

- 主角被什么压着；
- 世界有什么强规则；
- 主角有什么特殊解法；
- 本书和普通玄幻/科幻有什么不同。

推荐动作链：

> 主角遭遇压迫/危机 → 常规体系无效 → 主角用“科武结合”的方式破局 → 付出代价 → 暴露更大目标。

示例：

> 机甲学院测试中，主角因基因评级过低被淘汰。  
> 他没有高级外骨骼权限，只能用旧武道步法规避火控锁定。  
> 成功击穿训练机甲关节，但神经接口过载，左臂短暂失控。  
> 章末：测试系统判定他使用了“被封禁的古武算法”。

---

### 第2章：定目标 + 定敌人

必须明确：

- 主角短期目标；
- 第一个KR；
- 谁阻止他；
- 为什么这个目标必须马上完成。

示例：

> 主角必须在七天内拿到地下武斗资格，否则妹妹的义体维护权限会被取消。  
> 敌人是掌控资格审核的学院贵族。  
> 第一KR：破解低端义体的神经延迟问题。

---

### 第3章：立规则 + 给钩子

必须建立至少一条世界铁律，并让主角撞上它。

示例铁律：

> “所有外骨骼输出功率受城市能源塔监管，非法过载会被追踪。”

章末钩子：

> 主角刚完成第一次非法过载，能源塔后台弹出红色警报：  
> “检测到旧纪元武道波形，目标位置已锁定。”

---

# 4. OKR推进补丁

## 4.1 阶段目标O写法

错误写法：

> 主角变强。

正确写法：

> 主角在10万字内获得地下武斗A级资格，并拿到进入军工遗迹的权限。

---

## 4.2 KR写法

每个KR必须满足三个条件：

1. 可见：读者知道完成没完成；
2. 可实现：主角能通过行动推进；
3. 必要：不完成就无法达成O。

### 示例：科武长篇

O：

> 主角获得军工遗迹入场权限。

KR：

1. 破解低阶义体神经延迟；
2. 赢下三场地下武斗；
3. 夺取贵族队伍的身份芯片；
4. 承受一次非法改造手术；
5. 在遗迹门前击败追捕者。

每个KR都有动作、冲突、代价、钩子。

---

## 4.3 KR推进章节模板

每次推进KR，用这个顺序：

> 目标触发 → 主角判断 → 技术/武技执行 → 受阻 → 加码 → 破局 → 付代价 → 出新钩子

示例：

> 目标触发：主角必须赢下地下武斗。  
> 判断：对手外骨骼强度是自己的3倍，正面拼会死。  
> 执行：用热成像扫描关节散热口，启动低频震步干扰陀螺仪。  
> 受阻：对方切换手动驾驶，锁死关节保护。  
> 加码：主角强行过载左臂义体。  
> 破局：以古武寸劲打入装甲缝隙，震碎液压阀。  
> 代价：左臂神经灼伤，接下来24小时无法稳定握刀。  
> 钩子：对手倒地前喊出主角父亲的旧代号。

---

# 5. 强设定执行补丁

## 5.1 世界铁律必须提前立

科武长篇至少先定3条铁律。

示例：

1. 能量守恒铁律：任何超常爆发都必须消耗能源、生命、算力或材料。
2. 技术权限铁律：高阶武装需要身份授权，底层人无法合法使用。
3. 身体承载铁律：肉体改造超过阈值会引发神经崩溃或人格漂移。
4. 武道兼容铁律：古武不是玄学，而是人体神经、肌肉、重心、共振的极限算法。
5. 阵营垄断铁律：技术升级受财团、军方、学院、地下组织控制。

---

## 5.2 设定抛出后不得吃书

一旦写了：

> “非法过载会被能源塔追踪。”

后面主角每次非法过载，都必须处理追踪问题。

可选处理方式：

- 使用屏蔽装置；
- 借别人能源ID；
- 在信号盲区战斗；
- 故意暴露，引诱敌人；
- 付出被通缉的代价。

禁止：

> 前面说会追踪，后面主角随便过载没人管。

---

## 5.3 设定只在行动中解释

错误：

> 本世界的机甲系统分为十七个等级……

正确：

> 主角刚把手伸向A级外骨骼，腕环立刻弹出红色警告：  
> “权限不足。强行接入将触发脊髓熔断保护。”  
> 他看了一眼追来的执法无人机，咬牙切断保护协议。

---

# 6. 动作、反馈、代价补丁

## 6.1 动作链必须连续

禁止跳跃式：

> 主角冲上去，一招击败敌人。

改成：

> 主角先压低重心，避开机甲右臂的火控线。  
> 热流从耳侧擦过，烧焦半截头发。  
> 他借爆炸气浪贴近敌人膝关节，左手扣住外骨骼散热栅。  
> 内劲沿金属缝隙震入，液压阀发出一声闷响。  
> 机甲右腿下沉三厘米，终于露出驾驶舱侧面的维修口。

---

## 6.2 物理反馈必须可感

每次攻击、突破、技术调用，都给反馈。

可写维度：

- 装甲凹陷深度；
- 能量剩余百分比；
- 神经负荷数值；
- 骨裂、肌肉撕裂、义体温度；
- 地面裂纹、墙体坍塌、空气灼热；
- 系统警报；
- 敌人姿态变化。

示例：

> 外骨骼左臂温度飙到127度，皮肤和接口处传出焦糊味。  
> 系统连续弹出三次警告：  
> “神经负荷81%。”  
> “肌腱撕裂风险上升。”  
> “继续输出，将导致左手永久性震颤。”

---

## 6.3 每次越级必须付代价

代价类型：

| 类型 | 示例 |
|---|---|
| 身体代价 | 神经灼伤、基因崩溃率上升、骨裂、感官失真 |
| 装备代价 | 外骨骼损坏、能源核心烧毁、武器报废 |
| 经济代价 | 信用点透支、欠地下医生人情 |
| 信息代价 | 暴露旧武道波形、身份被追踪 |
| 关系代价 | 队友不信任、阵营怀疑、家人被牵连 |
| 规则代价 | 被学院除名、被城市系统通缉 |

禁止无代价开挂。

---

# 7. 人物口吻补丁

## 7.1 主角口吻

主角口吻要绑定“科武硬核逆袭”。

推荐特征：

- 判断冷；
- 行动狠；
- 不废话；
- 对技术和身体代价有清醒认知；
- 情绪爆发时短句更有力。

示例：

> “功率不够，就拆限制器。”  
> “身体撑不住，就先赢了再说。”  
> “他们靠权限，我靠命。”

---

## 7.2 技术型角色口吻

特点：

- 数据化；
- 风险提示多；
- 容易吐槽主角不要命。

示例：

> “你这不是改造，是把自己接进绞肉机。”  
> “神经负荷已经过线了，再打三分钟，你左手以后只能拿勺子。”  
> “理论上可行，伦理上该枪毙，医学上建议火化。”

---

## 7.3 贵族/财团反派口吻

特点：

- 轻蔑；
- 把权限当血统；
- 把底层人当耗材。

示例：

> “低权限者使用高阶武装，本身就是犯罪。”  
> “你不是赢了我，你只是损坏了一件资产。”  
> “旧武道？垃圾堆里翻出来的自我安慰。”

---

## 7.4 军方/执法者口吻

特点：

- 命令式；
- 规则优先；
- 承认实力，但不讲情面。

示例：

> “解除武装，跪地，接受神经扫描。”  
> “你有价值，但这不代表你无罪。”  
> “战场不问出身，只问你能不能活到下一轮。”

---

## 7.5 狼人篇可借口吻

适合短篇、悬疑、猎杀线。

狼人/污染者口吻：

> “我记得我没有杀她。”  
> “可我醒来的时候，嘴里有血。”  
> “如果月亮升起来前我还没找到真凶，你们就先杀了我。”

猎人口吻：

> “怪物会撒谎，人也会。”  
> “银弹只杀狼，杀不了藏在狼后面的人。”

---

# 8. 段落节奏补丁

## 8.1 动作段节奏

战斗、追逃、危机时：

- 短句；
- 少解释；
- 多反馈；
- 每3-5段出现一次变化。

示例节奏：

> 警报响起。  
> 主角抬头，三架无人机已经压到楼顶。  
> 红点锁住他的眉心。  
> 他没有跑，反而向前一步。  
> 左臂外骨骼发出刺耳的过载声。

---

## 8.2 设定段节奏

设定不能整页说明，必须切成：

> 触发 → 一句解释 → 立刻影响行动

示例：

> 他刚启动引擎，能源塔就锁住了他的频段。  
> 城市里所有外骨骼都被统一监管，非法输出超过三秒就会暴露位置。  
> 所以他只有三秒。  
> 三秒内，打断对方脊柱锁。

---

## 8.3 情绪段节奏

情绪爆发前先压住，再用短句释放。

示例：

> 他看着妹妹义眼里的维护倒计时。  
> 还剩十九小时。  
> 学院审核员把申请表推回来，连眼皮都没抬。  
> “权限不足。”  
> 主角沉默了很久。  
> 然后把那张表撕成两半。  
> “那我就抢一个权限。”

---

# 9. 章末钩子补丁

每章末必须有钩子，且绑定未完成KR。

## 9.1 悬念钩子

用于制造疑问。

示例：

> 主角破解芯片后，里面没有地图。  
> 只有一段父亲十年前留下的录音：  
> “如果你听到这句话，说明他们已经开始重启天门计划。”

---

## 9.2 利益钩子

用于制造期待。

示例：

> 黑市医生把一枚银色接口推到他面前。  
> “接上它，你能打赢A级机甲。”  
> “代价呢？”  
> “你可能不再是人。”

---

## 9.3 危机钩子

用于逼迫追读。

示例：

> 系统弹出红色倒计时：  
> “非法神经接入已上传。”  
> “军方清除小队将在九分钟后抵达。”

---

## 9.4 反转钩子

用于卷末/高潮后。

示例：

> 他终于杀死了追捕自己的机甲驾驶员。  
> 头盔裂开。  
> 里面露出的，却是妹妹的脸。

---

# 10. 失败模式与修正方案

## 10.1 失败模式：设定堆砌

症状：

- 连续几页解释世界观；
- 主角不行动；
- 读者看不到目标。

修正：

> 把设定改成障碍。  
> 主角只有撞上规则时，才解释规则。

---

## 10.2 失败模式：KR无必要性

症状：

- 主角突然去打支线副本；
- 打赢了也不影响主线；
- 读者不知道为什么非做不可。

修正：

> 每个支线必须改成“完成O的必要条件”。  
> 如果删掉不影响O，就删除或合并。

---

## 10.3 失败模式：主角无代价开挂

症状：

- 打不过就爆种；
- 装备突然升级；
- 反派突然降智。

修正：

> 每次破局前补一个可追溯铺垫。  
> 每次破局后补一个明确代价。

---

## 10.4 失败模式：世界规则吃书

症状：

- 前面说高阶武装需要权限，后面主角随便用；
- 前面说基因崩溃危险，后面无限爆发没事。

修正：

> 建立“规则例外成本”。  
> 可以突破规则，但必须付出比常规更高的代价。

---

## 10.5 失败模式：开篇拖沓

症状：

- 前三章全是日常；
- 没有目标；
- 没有敌人；
- 没有科武卖点。

修正：

> 第一章直接给危机。  
> 第二章给目标。  
> 第三章给规则和钩子。

---

## 10.6 失败模式：人物功能混乱

症状：

- 配角很多；
- 每个人都想写成长线；
- 主线推进变慢。

修正：

> 配角只保留三类功能：资源、阻碍、催化剂。  
> 暂时不能推动KR的配角，延后出场。

---

# 11. 短故事 / 狼人篇可借点

适合用于短篇、单元剧、狼人猎杀、污染悬疑。

## 可借1：核心纲压缩

短篇不要铺大世界，只锁一个目标。

模板：

> 主角在【封闭场景】中，被【诅咒/污染/身份嫌疑】逼迫，必须在【时间限制】前找出【真凶/解药/出口】，否则会变成怪物或被猎杀。

示例：

> 被狼毒感染的猎人必须在月圆前找出村庄里的真狼人，否则他会先变成下一个怪物。

---

## 可借2：强设定变成单条铁律

短篇只需要1-2条强规则。

示例：

- 被狼人咬伤者，三小时后会失去一段记忆；
- 银器只能杀狼人，不能证明谁是狼人；
- 真狼不能说出第一个受害者的名字；
- 月光下影子会暴露兽形。

---

## 可借3：OKR变成倒计时

短篇KR：

1. 确认自己是否杀人；
2. 找到第一现场；
3. 排除三个嫌疑人；
4. 在变身前逼出真狼。

章末钩子：

> 主角找到血衣。  
> 血衣在自己床下。

---

# 12. 科武长篇可借点

## 可借1：百万字阶段用“技术奇点”换地图

不要只写：

> 去新城市、进新学院、打新敌人。

要写：

> 主角完成一次技术跃迁，引发阵营洗牌。

阶段示例：

1. 0-10万字：底层生存，获得非法改造资格；
2. 10-30万字：地下武斗，破解古武算法与外骨骼兼容；
3. 30-60万字：军工遗迹，获得旧纪元武道数据库；
4. 60-100万字：军方征召，参与机甲战争；
5. 100万字后：揭开文明跃迁计划，古武不是落后体系，而是人类对抗高维算法的原始密钥。

---

## 可借2：境界换成权限/阈值/算力

避免普通玄幻境界。

替代表达：

| 玄幻写法 | 科武替换 |
|---|---|
| 筑基 | 神经接驳稳定期 |
| 金丹 | 内循环能源核心 |
| 元婴 | 分布式意识备份 |
| 炼体 | 肌骨强化率 |
| 法宝 | 外骨骼/义体/智能兵装 |
| 灵气 | 零点能源/生物电/暗能粒子 |
| 宗门 | 学院/财团/军方/地下实验室 |

---

## 可借3：反派必须绑定技术壁垒

科武反派不只是“坏”，而是掌握资源和规则。

反派类型：

- 学院贵族：垄断资格；
- 财团：垄断义体和药剂；
- 军方：垄断武装权限；
- 地下医生：提供非法进化，但收取高额代价；
- AI系统：以效率为名淘汰低价值人群；
- 旧纪元遗民：掌握古武真相，但不信任新人类。

# 13. 平台规则转为发布 / 包装 / 风险门禁

## 13.1 发布节奏门禁

| 节点 | 要求 |
|---|---|
| 前3章 | 明确困境、目标、卖点、敌人、强设定 |
| 前1万字 | 完成第一次小破局，主角必须主动赢一次 |
| 3-5万字 | 一个小高潮，完成一个阶段性成果 |
| 10万字 | 第一个KR大闭环，主角身份/实力/处境明显变化 |
| 每10-30万字 | 完成一个阶段O |
| 每卷末 | 完成旧目标，同时打开更大危机 |

风险门禁：

- 前3章没有目标：重写；
- 前1万字无爽点：压缩铺垫；
- 前10万字无闭环：拆掉支线；
- 连续两章无主线推进：合并或删除；
- 连续三章纯解释设定：改成行动场景。

---

## 13.2 包装门禁

开书前检查：

| 包装项 | 要求 |
|---|---|
| 书名 | 有科武、机甲、古武、基因、星际、权限、进化等关键词倾向 |
| 简介 | 一句话困境 + 一句话卖点 + 一句话目标 |
| 标签 | 硬核机甲、古武复苏、底层逆袭、基因进化、文明跃迁等 |
| 前三章名场面 | 必须能截图传播 |
| 主角差异化 | 不是单纯天才，而是用特殊解法突破规则 |
| 反派压迫感 | 开篇反派必须代表制度或资源垄断 |

简介模板：

> 基因评级F的底层少年，被学院判定终身无权接入机甲。  
> 但他发现，被时代淘汰的古武，竟能破解高阶外骨骼的神经锁。  
> 当财团、军方和旧纪元遗迹同时盯上他时，他只能一路打穿权限壁垒，夺回人类进化的真正钥匙。

---

## 13.3 风险门禁

写作中每周检查一次。

高风险项：

- 卖点漂移：开篇说古武破机甲，中期变成普通学院争霸；
- 设定失控：科技、武道、异能、神明全塞；
- 主角被动：总是别人安排任务；
- 反派降智：为了让主角爽而主动送资源；
- 代价消失：越级战斗没有身体和资源损耗；
- 信息密度过高：读者记不住阵营、技术名词；
- 平台节奏慢：10万字还没完成第一个明确成果。

处理方式：

> 卖点漂移 → 回到里层核心纲。  
> 设定失控 → 保留服务KR的设定，其余延后。  
> 主角被动 → 每章给主角一个主动决策。  
> 反派降智 → 让反派阻碍KR，而不是单纯送脸。  
> 代价消失 → 补身体、装备、关系、规则代价。  
> 节奏慢 → 删除无关支线，提前小高潮。

# 14. 章节自检清单

每章发布前检查：

1. [ ] 本章是否服务当前KR？
2. [ ] 主角是否有明确小目标？
3. [ ] 是否出现“目标触发 → 决策 → 执行 → 受阻 → 破局”动作链？
4. [ ] 是否至少有一次主角主动选择？
5. [ ] 科武动作是否写出调用顺序，而不是光效乱飞？
6. [ ] 是否有物理反馈：损伤、参数、环境、痛感、警报？
7. [ ] 是否有明确代价？
8. [ ] 本章是否推进主线，而不是可删支线？
9. [ ] 设定是否通过行动呈现，而非大段说明？
10. [ ] 人物口吻是否符合身份和阵营？
11. [ ] 反派/阻碍是否直接卡住KR？
12. [ ] 是否兑现或强化了里层卖点？
13. [ ] 章末是否有悬念钩子、利益钩子、危机钩子或反转钩子？
14. [ ] 如果删除本章，主线是否会断？如果不会，重写或合并。
15. [ ] 是否存在吃书、无代价开挂、反派降智、设定堆砌？

---

# 15. 最终执行口令

写每一章前，先问七句：

1. 主角这章要什么？
2. 这个目标对应哪个KR？
3. 谁或什么规则挡住他？
4. 他用什么科武方法破局？
5. 破局后的物理反馈是什么？
6. 他付出什么代价？
7. 章末用什么钩子逼读者翻页？

如果七句答不出来，这章不能写。
