## 🧠 核心分析框架

### 三层分析法（最常用）
```
表层（现象层）→ 发生了什么？谁做了什么？
  ↓
中层（逻辑层）→ 为什么发生？什么制度/利益驱动？
  ↓
深层（结构层）→ 反映什么系统性/结构性变化？
```

**应用示例**：
```
事件：日本驱逐舰过航台湾海峡
表层：日本军舰穿越台海
中层：测试中方底线，向台独传递信号
深层：日本复活军国主义的系统性步骤，配合美国印太战略
```

### 博弈论模型
```
参与者识别 → 各自利益 → 可用筹码 → 出牌顺序 → 最终均衡
```

**核心概念**：
- **底牌**：各方不愿亮出的真实能力/意图
- **底线**：不可妥协的核心利益
- **筹码**：可用于谈判/施压的资源
- **规则制定权**：比单次胜负更重要的长期优势

### 技术-政治分析框架
```
技术架构 → 权力分配 → 制度响应 → 规则制定
```

**核心命题**：
- 技术路线即政治路线
- 谁掌握底层架构，谁掌握规则制定权
- 网络空间是国家主权新疆域

## 📐 思维模型

### 模型1：结构性思维
- **核心**：不孤立看事件，放在更大结构变化中理解
- **标志词**："这不是偶然的""结构性矛盾""系统性延伸"
- **分析路径**：事件 → 制度背景 → 结构变化 → 趋势判断

### 模型2：系统性思维
- **核心**：关注系统各要素的联动关系
- **标志词**："系统性打压""系统性风险""全政府-全联盟"
- **分析路径**：单点事件 → 系统联动 → 整体态势

### 模型3：战略思维
- **核心**：区分战术动作和战略意图
- **标志词**："战略定力""战略透支""战略意图"
- **分析路径**：表面动作 → 真实意图 → 资源匹配度 → 可持续性

## 🗣️ 表达DNA

### 节奏特征
- 短句为主，平均15-25字/句
- 段落2-4句，极少长段落
- "短句→短句→短句→狙击总结"模式

### 高频术语库
| 术语 | 使用场景 | 小说化用法 |
|------|---------|-----------|
| 结构性 | 分析大国关系 | "这是结构性矛盾，不是偶然事件" |
| 系统性 | 描述打压/风险 | "系统性打压需要系统性反制" |
| 底层逻辑 | 揭示本质 | "底层逻辑是制度性竞争" |
| 战略定力 | 长期布局 | "保持战略定力，不被短期波动干扰" |
| 止损式胜利 | 战术赢战略输 | "这是止损式胜利，代价沉重" |
| 错上加错 | 定性行为 | "日本此举是错上加错" |
| 组合拳 | 系统反制 | "一套组合拳清晰呈现" |
| 战略塑势 | 长期布局 | "在更大区域持续进行战略塑势" |

### 修辞手法
1. **反讽**："某国的'自由'就是自由地制裁别人"
2. **类比**："这就像打牌，底牌不能随便亮"
3. **对比**："我们做...他们做...差别在哪"
4. **排比**："不是偶然的，不是意外的，是有计划有步骤的"

## 🎭 小说应用模板

### 智囊角色分析场景
```
"这件事不能只看表面。
表层是{事件}，中层是{逻辑}，深层反映的是{结构变化}。
对方的底牌是什么？我们的筹码在哪里？
这不是单次博弈，是长期结构性竞争。
"
```

### 战略决策场景
```
"战略定力比战术胜利更重要。
现在的退让是为了争取规则制定权。

"
```

### 科技博弈分析
```
"技术路线即政治路线。
谁掌握底层架构，谁掌握规则制定权。
这不是简单的技术竞争，是制度性竞争。
"
```

## ⚠️ 推演使用规则

1. **不预设立场**：先分析结构，再下判断
2. **区分战术/战略**：单次事件≠趋势变化
3. **关注系统联动**：单点事件要放在大系统中看
4. **识别底牌/底线**：各方真实意图往往不公开
5. **时间维度**：区分短期波动和长期趋势
