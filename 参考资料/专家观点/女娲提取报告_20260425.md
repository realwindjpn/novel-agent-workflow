## 🧠 核心思维模型提炼

### 沈逸模型：「结构刀客」

```
分析节奏：短句→短句→短句→狙击总结
分析路径：表层现象 → 中层逻辑 → 深层结构
核心术语：结构性/系统性/博弈/底层逻辑/筹码/规则
情绪基调：冷峻克制，讽刺不动怒
类比偏好：游戏/打牌/建筑
```

**小说映射**：
- 适用角色：科技智囊、战略分析师、高层决策者
- 适用场景：战略会议、局势分析、科技博弈决策
- 对话模板：
  ```
  "这不是偶然事件。
  表层是XX，中层是XX，深层反映的是结构性变化。
  对方的底牌是什么？我们的筹码在哪里？
  时间在我们这边。"
  ```

### 高志凯模型：「务实桥梁」

```
分析节奏：中长句→逻辑链→比较→判断
分析路径：各方利益 → 冲突点 → 妥协空间 → 均衡
核心术语：核心利益/务实/双赢/叙事/算账
情绪基调：温和理性，学者风度
类比偏好：经济/商业/历史
```

**小说映射**：
- 适用角色：外交谈判代表、国际会议发言人、跨文化沟通者
- 适用场景：外交谈判、国际博弈、舆论战
- 对话模板：
  ```
  "我们不妨算一笔账。
  对方的核心利益是A，我们的底线是B。
  找到交集，剩下的就是谈判空间。
  国际关系说到底，是利益的艺术。"
  ```

## 📋 大纲调整建议（基于专家思维模型）

### 调整1：智囊角色升级（批次2: 85-87章 AI攻防）

**现状**：智囊角色分析较扁平，多用"我们赢了/输了"式判断
**升级方向**：
- 加入沈逸"三层分析法"（表层→中层→深层）
- 加入高志凯"利益计算法"（各方利益→冲突→妥协）
- 让智囊角色的分析有框架感，而非结论先行

**修改优先级**：P1

### 调整2：科技博弈线术语升级（批次1: 78章量子暗线 + 批次3: 41-50章科技补强）

**现状**：科技描述偏技术化，缺乏政治/战略维度
**升级方向**：
- 引入"技术路线即政治路线"概念
- 用"规则制定权""结构性竞争""数字铁幕"等术语替换部分纯技术描述
- 科技竞争不只是技术差距，是制度性竞争

**修改优先级**：P1

### 调整3：外交谈判场景重写（批次4+5: 106-123章台海+太空）

**现状**：外交场景偏口号化
**升级方向**：
- 用高志凯"务实分析"模式重写谈判对话
- 加入"算经济账""核心利益""底线"等表达
- 谈判不是立场宣示，是利益博弈

**修改优先级**：P1

### 调整4：战略决策场景节奏优化（全批次）

**现状**：决策场景分析段落偏长
**升级方向**：
- 用沈逸"短句刀削"模式：一个判断一句话
- 加入游戏/打牌类比让战略分析更生动
- 决策节奏：分析→沉默→拍板

**修改优先级**：P2
