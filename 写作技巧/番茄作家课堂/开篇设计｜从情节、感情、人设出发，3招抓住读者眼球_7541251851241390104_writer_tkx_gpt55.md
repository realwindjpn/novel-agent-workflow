# 《科武纪元》作家OS补丁  
## 开篇设计补丁｜情节×感情×人设三招抓眼球

> 安装目标：开篇不讲道理、不铺设定，直接让读者看到——**有人被逼到死角，必须做一个有代价的选择，并暴露他绝不妥协的底色。**

---

## 01｜开篇执行指令：前三章必须完成什么

### 第1章：上锁，逼人动起来

**动作要求：**

- 开场300字内给出一个“锁”：
  - 时间锁：倒计时、毒素扩散、氧气耗尽、考核截止、追杀抵达。
  - 空间锁：密闭舱、隔离区、擂台、废墟地下层、封锁舰桥。
  - 身份反差：强者被迫做低贱事；小人物突然卷入大灾难。

**开篇不要写：**

- 不要先写世界观历史。
- 不要先写主角感慨人生。
- 不要先写功法体系说明。
- 不要用“他很愤怒、他很绝望、他很震惊”。

**改成这样写：**

```text
警报第三次响起时，维修舱的氧气余量只剩7分钟。

林烬咬开手套接缝，血珠被低温冻成暗红色颗粒，漂在失重舱里。
他面前有两条线路：
一条接向逃生舱。
一条接向仍困着三十七名矿工的主供氧阀。

通讯器里，主管的声音断断续续：
“林烬，别管他们。你只要修好逃生舱，我保你进内城。”

林烬没回话。
他把逃生舱线路一刀切断。
```

**本章必须交付：**

- 一个危机。
- 一个选择。
- 一个代价苗头。
- 一个主角信条。

---

### 第2章：加压，让选择变脏

**动作要求：**

- 让主角的第一选择产生坏后果。
- 危机不能被轻松解决。
- 必须出现“非完美解”。

**可用结构：**

```text
主角救A → 导致B恶化  
主角守信条 → 损失资源/身体/信任  
主角获得机会 → 机会要求他背叛底线
```

**示例：**

```text
林烬救回矿工，却导致逃生舱彻底断电。
氧气余量变成4分钟。
矿工们看着他，没人说谢。
因为所有人都知道——他刚才切断的，是唯一能离开的线路。
```

**本章必须交付：**

- 危机升级。
- 群体压力。
- 主角信条受到挑战。
- 第一次明确代价。

---

### 第3章：释放一次爽点，再抛新钩子

**动作要求：**

- 给读者一次情绪回报：
  - 打脸。
  - 破局。
  - 反杀。
  - 证明主角不是废物。
  - 暴露隐藏身份/能力。
- 但章末必须抛出更大的锁。

**可用章末钩子：**

```text
他刚修好供氧阀，系统却弹出新警报：
【检测到非法武道核心启动。】
【处决协议已上传。】
【倒计时：十分钟。】
```

**本章必须交付：**

- 一次小爽点。
- 一个更大危机。
- 一个身份/信息差钩子。
- 一个让读者继续点下一章的未解问题。

# 02｜三招执行法

---

## 第一招：从情节出发——给开篇上锁

### 执行动作

每个开篇场景必须回答：

| 问题 | 必填答案 |
|---|---|
| 谁被困住？ | 主角/队友/平民/仇人 |
| 困在哪里？ | 舱室/擂台/隔离区/战场/贫民层 |
| 还剩多久？ | 分钟、小时、三招、一次呼吸、一次跃迁窗口 |
| 不行动会怎样？ | 死亡、暴露、失去资格、背叛信条 |
| 行动要付什么代价？ | 伤身、损装备、失信任、犯禁令、透支寿命 |

### 科武可用锁库

**时间锁：**

- 氧气剩余7分钟。
- 机甲核心过热，180秒后熔毁。
- 武道经脉逆行，只能撑九息。
- 跃迁引擎冷却前，敌舰将在3分钟后锁定。
- 基因毒素扩散到心脏还剩12分钟。
- 擂台结界开启后，不死一人不解除。

**空间锁：**

- 废弃殖民舰维修舱。
- 异星生态隔离区。
- 地下武馆死斗笼。
- 军校重力训练室。
- 机甲驾驶舱。
- 被封锁的贫民层供氧站。

### 失败模式

| 失败写法 | 问题 | 修正动作 |
|---|---|---|
| 开头三千字介绍星际历史 | 无即时危机 | 改成“历史遗物正在杀人” |
| 主角站着想人生 | 没有动作 | 给他一个必须立刻处理的物理问题 |
| 危机太大但不具体 | 读者无感 | 换成氧气、血量、倒计时、门锁、弹药 |
| 没有代价 | 像白送外挂 | 每次破局必须掉血、掉资源、掉关系 |
| 全都能救 | 没有张力 | 逼主角二选一 |

## 第二招：从感情出发——用原始冲动抓人

### 开篇只能先打一种情绪

不要同时写太多：

- 复仇。
- 守护。
- 求生。
- 逆袭。
- 夺回尊严。
- 被冤后自证。
- 被抛弃后反杀。

### 一句话情绪契约

写作前先填：

```text
这本开篇要让读者爽的是：________。
主角一定会为________付出代价。
读者期待看到________被兑现。
```

**例：**

```text
这本开篇要让读者爽的是：底层维修工在星际权贵面前证明自己不是废料。
主角一定会为守住无辜者的命付出身体和前途代价。
读者期待看到压迫者被当场打脸。
```

### 情绪不能说，要演

| 禁用句 | 改写为动作/反馈 |
|---|---|
| 他很愤怒 | 指节压裂操纵杆，机甲掌纹识别报错 |
| 他很害怕 | 呼吸频率飙到每分钟42次，面罩内壁起雾 |
| 他很痛苦 | 义体神经接口爆出蓝白电弧，左臂延迟0.7秒 |
| 他很绝望 | 氧气余量归零后，他仍在拧最后一颗阀栓 |
| 他热血沸腾 | 心率越过安全阈值，武脉图谱亮到刺眼 |

### 人物口吻要求

开篇人物说话要短、硬、有立场。

**主角口吻：**

- 少解释。
- 少喊口号。
- 用行动压过语言。
- 关键台词体现“不妥协”。

**可用台词：**

```text
“我修机器，不修人命的账本。”

“机甲可以报废，人不能被当耗材。”

“武道不斩无辜。你让我赢，我也不认。”

“数据可以改，誓言不能改。”

“你们算成本，我算还活着的人。”
```

**反派/压迫者口吻：**

- 用规则压人。
- 用资源羞辱人。
- 用大局逼人牺牲底层。

```text
“贫民层三十七条命，不值一次跃迁燃料。”

“你救他们，谁救你？”

“规则不是给你这种人解释的。”

“签字。承认事故，家属还能领赔偿。”
```

## 第三招：从人设出发——开局亮出“不妥协”

### 主角必须有一个硬信条

信条格式：

```text
主角绝不________，哪怕________。
```

**例：**

```text
林烬绝不弃机，哪怕机甲核心会烧穿他的神经。
林烬绝不斩无辜，哪怕放过对方会失去破境机会。
林烬绝不让底层人被当耗材，哪怕自己会被逐出内城。
林烬绝不篡改战友遗言，哪怕真相会毁掉他的前途。
```

### 信条必须被开篇危机直接攻击

| 信条 | 攻击方式 |
|---|---|
| 不弃机 | 上级命令他抛弃损毁机甲逃生 |
| 不斩无辜 | 破境需要夺取平民灵脉 |
| 不背誓言 | 系统要求他修改死亡记录 |
| 不让弱者当耗材 | 权贵要求封死贫民层供氧 |
| 不跪规则 | 军校考核逼他承认作弊 |

### 人设动作链模板

每次主角出手，按这个顺序写：

```text
触发信号 → 生理/系统反馈 → 判断 → 执行动作 → 物理结果 → 代价
```

**示例：**

```text
【触发信号】
供氧阀后的哭声突然断了。

【生理/系统反馈】
林烬耳后的义体接口跳出红色警告，神经温度逼近烧毁阈值。

【判断】
逃生舱线路还能保他一个人离开。
主供氧线路能救三十七个人，但会反向烧穿他的左臂义体。

【执行动作】
他把逃生舱保险栓掰断，将裸露电缆按进主供氧接口。

【物理结果】
整条走廊的灯一盏盏亮起，通风口喷出白雾。

【代价】
他的左手五指同时失去反馈，掌心传来焦肉味。
```

# 03｜段落节奏补丁

## 开篇段落长度

### 推荐节奏

- 危机段：短句，1—3行。
- 动作段：连续动词，少解释。
- 信息段：最多3句，必须服务当前危机。
- 情绪段：不用形容词，用身体/环境反馈。
- 章末钩子：单独成段，留白。

### 节奏模板

```text
1. 警报/倒计时/伤口/追杀开场。
2. 主角正在处理一个具体问题。
3. 外部压力插入。
4. 反派/规则给出诱惑或威胁。
5. 主角做选择。
6. 选择造成代价。
7. 局面暂时破开。
8. 更大的危机出现。
```

### 每章至少出现2次加压提示

可用句式：

```text
氧气余量：7分钟。
氧气余量：4分钟。
氧气余量：47秒。

机甲核心温度：91%。
机甲核心温度：107%。
机甲核心温度：系统拒绝显示。

重力倍数：3G。
重力倍数：7G。
重力倍数：训练舱锁死。
```

# 04｜章末钩子库

## A. 未解危机钩子

```text
门开了。
门外不是救援队。
是三台挂着内城徽记的处刑机甲。
```

## B. 信息差钩子

```text
死者的终端自动解锁。
最后一条记录里，林烬看见了自己的名字。
时间是十年前。
```

## C. 倒计时逼近钩子

```text
系统提示音响起：

【非法武道核心已暴露。】
【清除程序启动。】
【倒计时：十分钟。】
```

## D. 道德抉择钩子

```text
他终于拿到了破境药剂。

标签下面，还有一行小字：
原料来源——贫民层儿童基因样本。
```

## E. 信条挑战钩子

```text
军官把枪塞进他手里。

“杀了这个无辜的人，你就能救整座城。”
```

# 05｜代价系统补丁

## 每次爽点必须绑定代价

| 爽点 | 必须付出的代价 |
|---|---|
| 越级反杀 | 骨裂、经脉损伤、暴露底牌 |
| 开启外挂 | 寿命扣减、精神污染、AI寄生风险 |
| 救下队友 | 失去逃生机会、资源耗尽 |
| 打脸权贵 | 被封杀、通缉、失去资格 |
| 破境升级 | 伤害不可逆、道德债、失控风险 |

## 禁止

- 系统白送。
- 老爷爷无条件帮忙。
- 主角随便突破。
- 打完没有后果。
- 救人不损失任何东西。

## 推荐代价写法

```text
他赢了。

但视野右上角的寿命读数，从【31年】跳成了【30年零11个月】。
少掉的一个月，正好换来这一拳。
```

# 06｜失败模式总表

| 失败模式 | 读者感受 | 立刻修补 |
|---|---|---|
| 设定开头 | 像说明书 | 把设定变成正在杀人的东西 |
| 情绪形容词堆砌 | 假燃、假虐 | 改成动作、伤口、数据、环境反应 |
| 主角太犹豫 | 不爽 | 给他一个“不妥协信条” |
| 冲突无代价 | 廉价 | 每次破局扣资源/身体/关系 |
| 反派太蠢 | 爽点弱 | 反派用规则、资源、制度压主角 |
| 开局场景太散 | 不聚焦 | 改成密闭空间+倒计时 |
| 道德困境太轻 | 没张力 | 让两个选项都伤人 |
| 科幻设定乱飞 | 失真 | 所有巧合必须有信息/物理逻辑 |
| 章末没钩子 | 不追读 | 结尾必须有未解危机/信息差/倒计时 |
| 主角口号太多 | 中二空喊 | 让他少说，直接动手付代价 |

# 07｜短故事/狼人篇可借点

适合短篇、单元剧、狼人杀式密闭推理篇。

## 可借点1：单一密闭场景

**用法：**

- 一艘失联运输舰。
- 一个封闭武馆。
- 一座被污染的矿井。
- 一个重力训练舱。
- 一个无法退出的虚拟战场。

**狼人篇适配：**

```text
空间锁：所有人困在隔离舰舱。
时间锁：每30分钟死一人。
身份锁：其中一人被敌对AI寄生。
道德挑战：杀错人，全员失去唯一解药。
```

## 可借点2：原始情绪简单直给

短故事不要复杂主题，先抓一种：

- 谁在撒谎？
- 谁会死？
- 谁必须被牺牲？
- 谁才是真怪物？
- 主角要不要杀一个可能无辜的人？

## 可借点3：章末/段末反转

短篇每一节末尾都要有小翻转：

```text
他们以为狼人藏在人群里。
直到监控回放显示——昨晚死去的人，自己打开了舱门。
```

## 可借点4：人物信条做投票压力

```text
主角信条：不杀无证之人。
场景压力：所有证据都指向一个孩子。
群体压力：其他人要求立刻处决。
钩子：孩子的血检结果显示，他不是人类。
```

# 08｜科武长篇可借点

适合《科武纪元》主线长篇。

## 可借点1：开篇危机绑定长期主线

不要只做一次性事故，要让开篇危机连到大阴谋。

**示例链条：**

```text
贫民层供氧事故
→ 主角救人暴露非法武道核心
→ 内城开始追捕
→ 主角发现事故不是意外
→ 供氧系统背后是基因筛选计划
→ 武道核心来自旧纪元战争遗产
```

## 可借点2：信条成为长期冲突发动机

```text
主角信条：人不能被当作进化耗材。
长期敌人：用底层人口做基因武道实验的星际财阀。
长期爽点：主角一次次打碎“资源决定人命价值”的规则。
```

## 可借点3：科幻与武道都必须服务冲突

| 元素 | 不要这样用 | 要这样用 |
|---|---|---|
| 机甲 | 炫参数 | 机甲即将熔毁，主角仍不弃机 |
| 武道 | 背境界表 | 经脉逆行九息，九息内必须破局 |
| AI | 白送外挂 | AI给战力，但会篡改主角记忆 |
| 基因药剂 | 随便升级 | 原料来自无辜者，逼主角选择 |
| 星际战争 | 宏大背景 | 战争制度压到主角身上，逼他反抗 |

## 可借点4：长期钩子层级

- 小钩子：这场事故怎么活下来？
- 中钩子：谁制造了事故？
- 大钩子：为什么主角体内有旧纪元武道核心？
- 终极钩子：科武纪元的进化体系是不是建立在屠杀之上？

# 09｜发布/包装/风险门禁

## 发布门禁

发布前检查前三章：

| 门禁项 | 通过标准 |
|---|---|
| 第1章是否有危机 | 300字内出现具体危险 |
| 第1章是否有动作 | 主角必须在处理问题，不是旁观 |
| 第1章是否有信条 | 主角做选择时暴露底线 |
| 第2章是否加压 | 第1章选择导致更坏后果 |
| 第3章是否释放爽点 | 至少一次打脸/破局/反杀/身份反差 |
| 第3章是否有新钩子 | 章末出现更大危机或信息差 |

## 包装建议

### 标题/简介要直给底层爽点

**方向：**

- 废柴逆袭。
- 底层反抗。
- 机甲武道。
- 旧纪元遗产。
- 被权贵当耗材后反杀。
- 守护无辜者付出惨烈代价。

**简介模板：**

```text
贫民层维修工林烬，在一次供氧事故中，为救三十七名矿工切断逃生舱线路。

他因此暴露体内的旧纪元武道核心，被内城判定为“非法进化体”。

所有人都说，底层人的命不值一次跃迁燃料。

林烬只回了一句：

“那我就把你们的规则拆了。”
```

## 风险门禁

### 禁止踩雷

- 不写低俗化七宗罪。
- 不把“繁衍欲望”写成擦边卖点。
- 不用血腥虐杀堆刺激。
- 不写无逻辑反社会爽点。
- 不把道德困境写成主角随意屠戮的借口。
- 不让科幻设定为剧情硬拗服务，导致常识崩坏。
- 不用平台敏感表达包装违法犯罪合理化。

### 风险替换

| 高风险写法 | 替换为 |
|---|---|
| 欲望支配 | 基因配额、繁衍许可证、阶级资源垄断 |
| 血腥虐杀 | 战斗损伤、机体破坏、战术反制 |
| 反社会报复 | 申冤、反抗制度压迫、守护无辜 |
| 无差别杀戮 | 精准打击责任人 |
| 低俗诱惑 | 技术异化、AI控制、资源交易 |

# 11｜章节自检清单

发布前逐条打勾。

## 开篇与节奏

- [ ] 300字内是否出现具体危机？
- [ ] 3000字内是否建立时间锁/空间锁/身份反差？
- [ ] 本章是否至少2次提示倒计时、资源衰减或状态恶化？
- [ ] 是否避免开头大段世界观说明？
- [ ] 场景切换是否伴随危机升级或信息差揭露？

## 冲突与代价

- [ ] 主角是否面临非完美选择？
- [ ] 是否有“物理危机+道德抉择”双轨压力？
- [ ] 主角破局是否付出明确代价？
- [ ] 是否避免“全都要”式无损解决？
- [ ] 反派/规则方是否用资源、制度、信息优势压人？

## 人设与情绪

- [ ] 主角是否亮出一个“不妥协信条”？
- [ ] 本章危机是否直接攻击该信条？
- [ ] 主角是否用行动证明信条，而不是喊口号？
- [ ] 是否剔除“他很愤怒/绝望/害怕”等直白情绪词？
- [ ] 情绪是否转化为动作、伤口、数据、环境变化？

## 科武适配

- [ ] 科幻/武道设定是否只释放当前危机需要的部分？
- [ ] 机甲、AI、基因、武道是否服务冲突，而非炫设定？
- [ ] 巧合是否符合物理、信息或系统逻辑？
- [ ] 升级是否有寿命、身体、资源、信任或道德代价？
- [ ] 是否避免把七宗罪写成低俗欲望？

## 章末钩子

- [ ] 章末是否有未解危机、信息差、倒计时或道德抉择？
- [ ] 钩子是否绑定本章的“锁”或主角信条？
- [ ] 是否避免无关支线强行截断？
- [ ] 最后一段是否足够短、硬、清晰？
- [ ] 读者是否会产生“下一章必须看”的问题？

# 12｜最小可执行开篇模板

```text
【第一段】
具体危机直接砸脸：倒计时/警报/伤口/封锁。

【第二段】
主角正在做一件具体动作，别解释身份。

【第三段】
外部压力出现：上级命令、反派威胁、系统警告、群众逼迫。

【第四段】
给出两难选择：救自己还是救别人；赢下去还是守底线。

【第五段】
主角选择“不妥协”，立刻付出代价。

【第六段】
危机暂时破开，读者得到一次小爽。

【章末】
更大的危机/身份秘密/倒计时出现。
```

**一句话记忆：**

> 开篇别解释世界，先把主角关进笼子，给他一把会割手的钥匙，让他当场证明自己是谁。
