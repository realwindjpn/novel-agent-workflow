# 《科武纪元》编辑学习官：钩子设计实操指南

## 1 课程核心判断（≤6条）
1. **钩子本质是“九连环”结构**：大钩子定主线终极目标，小钩子控1-3章章节悬念，环环相扣是防剧情崩盘的唯一解。
2. **精彩钩子=情绪烘托+剧情反转**：利用“不确定性”与“欲求不满”制造心痒感，拒绝结果可预测的平铺直叙。
3. **节奏控制靠“震荡上升”**：用连环小麻烦替代一路高歌猛进，以“解旧钩-抛新钩”循环根治“高开低走”。
4. **冲突设计需叠加“限制条件”**：天赋/时间/规则/对手等多维限制，逼迫角色进入两难选择，钩子张力由此产生。
5. **开篇零废话**：首千字决定平台推荐生死，必须剔除背景堆砌与无效心理描写，精准投放核心悬念。
6. **创新优先于跟风**：番茄算法极度内卷，跨界素材积累与反套路设计是破局关键，钩子需具备“意料之外，逻辑之内”的特质。

## 2 可执行编辑规则
| 维度 | 规则要求 |
|:---|:---|
| **开篇** | 前1000字必须完成“极端情境抛出+核心悬念建立”。禁用世界观说明书、冗长环境描写、无冲突日常。首章结尾必须留断点。 |
| **节奏** | 采用“解钩-抛新钩”循环。每章末设置状态悬停或信息留白；主线大目标拆解为3-5个阶段性小目标，保持剧情“起-伏-起”震荡曲线，严禁连续3章无新变量介入。 |
| **冲突** | 冲突必须伴随“两难选择”或“同目标异手段竞争”。禁止单方面碾压，每次交锋需改变局势参数（资源/立场/信息差），为下一钩子铺路。 |
| **人物** | 角色行动必须受硬性条件限制（生理阈值/资源枯竭/规则束缚）。人设需通过钩子逐步揭露“隐秘动机”或“反差面”，禁止开局全知全能。 |
| **题材** | 科幻/短故事/热点稿钩子需分层：长篇重“技术悬念+势力博弈+人性抉择”嵌套；短故事重“单线闭环+末段反转”；热点稿重“情绪共鸣+现实映射+反预期解法”。 |
| **改编** | 钩子需预留“视觉化/听觉化”接口。关键悬念需具备强动作性、高辨识度符号（如特定能量频率、机甲残骸、倒计时界面），便于后续IP转化。 |
| **平台规则** | 番茄重“读完率”与“追更率”。前3章钩子密度最高；每章结尾留“信息缺口”而非“情绪宣泄”；避免信息过载导致跳出，单章核心悬念不超过2个。 |

## 3 科武适配
### ✅ 可用点
- **九连环结构**：完美契合《科武纪元》“技术突破→武道体系迭代→宇宙真相揭露”的多层主线推进逻辑。
- **限制条件转化**：可直接映射为科幻硬设定（能量阈值、物理法则锁、AI逻辑悖论、基因崩溃倒计时、时间膨胀窗口）。
- **竞争钩设计**：适配“武道流派 vs 科技武装”或“不同阵营争夺同一核心技术/星域资源”的对抗框架。
- **情绪+反转**：适用于硬科幻软化，用技术困境包裹人性/文明抉择（如：牺牲个体保全舰队 vs 违背指令寻找生路）。

### ⛔ 不可硬套点
- **女频情感狗血案例**：原文“前夫炸弹/小三跑路/暧昧欲求不满”等情绪钩，科武需剥离纯情感纠葛，转为“理念冲突/生存博弈/技术伦理”。
- **纯情绪流钩子**：若缺乏科幻逻辑与物理规则支撑，会显得儿戏。科武钩子必须遵循“设定自洽+因果链完整”前提。
- **无代价爽感**：原文提及“爽文易高开低走”，科武体系严禁“无损耗升级/无逻辑越级”，所有破局必须支付对等代价，否则破坏硬核基调。

## 4 编辑检查表（10条以内）
- [ ] 开篇前1000字是否已抛出核心悬念/极端情境？有无冗余背景说明？
- [ ] 当前章节结尾是否留有明确悬念（小钩子）？能否自然引出下一章？
- [ ] 钩子是否包含“不确定性”或“两难选择”？结果是否可预测？
- [ ] 角色行动是否受至少1项硬性限制（时间/资源/规则/生理）？
- [ ] 大钩子（主线目标）是否已拆解为可执行的阶段性小目标？
- [ ] 冲突是否伴随明确代价？胜利/失败是否影响后续剧情走向？
- [ ] 情绪渲染是否服务于悬念推进？有无脱离剧情的无效抒情？
- [ ] 科幻设定是否作为钩子的一部分而非说明书？逻辑是否自洽？
- [ ] 连续3章是否保持“解钩-抛新钩”节奏？有无剧情停滞或一路平推？
- [ ] 钩子设计是否避开平台同质化套路？有无反预期反转？

## 5 对作家角色的输入要求
| 维度 | 输入标准 |
|:---|:---|
| **动作链** | 必须呈现“触发→决策→执行→受阻→变轨”完整逻辑链。禁止跳跃式推进，每个动作需有明确动机与物理/规则依据，断链处即为钩子埋设点。 |
| **物理反馈** | 科武体系下，所有交互必须具象化。能量释放、机甲损耗、肉体创伤、环境异变需有可量化的反馈描写（如：护盾衰减率、骨骼微裂、重力参数偏移），杜绝“意念流”战斗。 |
| **代价** | 每次破局/升级必须支付对等代价（资源枯竭、基因崩溃、信任破裂、时间窗口关闭、规则反噬）。无代价的胜利视为无效钩子，需在章末明确标注代价结算状态。 |
| **钩子** | 每章末必须设置“断点型钩子”。要求：①信息留白（已知A，未知B）；②状态悬停（危机未解/选择未做）；③预期违背（常规解法失效）。禁止用抒情或总结性语句收尾。 |
| **读者预期** | 明确标注本章试图满足的预期类型（爽感/悬疑/智斗/探索）。钩子需“给一半藏一半”：满足表层预期（如战术执行成功），同时颠覆深层预期（如引发更大维度危机），制造“意料之外，情理之中”的追读动力。 |
