## 10条写法规则｜作家OS补丁

1. **开篇三件套必须落地**  
   200字内写出：身份/处境定位 → 一次具体冒犯 → 主角反常反应。  
   - 短故事/狼人篇可借：导语直接给“被踩+不哭+反杀预告”。  
   - 科武长篇可借：边缘弟子/研究员/舰队副官被压制，反向宣告目标。  
   - 发布门禁：禁止开篇铺世界观、谱系、设定说明。

2. **立项先锁爽感合同**  
   只能选四类之一：高位碾压 / 底层逆袭 / 复仇重生 / 脑洞信息差。  
   写作前任务卡字段更新：  
   - 类型归属：____  
   - 目标读者期待一句话：____  
   - 本篇主爽点：碾压 / 智斗 / 复仇 / 信息差  
   - 禁止中途切换合同。

3. **每场冲突必须有可抢资源**  
   不写空吵，必须争一个具体标的：位份、地契、管家权、密钥、名额、功法权限、舰队指挥权。  
   - 失败模式：只写“她们互相看不顺眼”，没有输赢物。

4. **反派诉求与主角诉求要正交死锁**  
   反派要宠、名分、垄断、继承权；主角要权、自由、开源、翻案。  
   形成“我赢你必输”。  
   - 人物口吻：反派说“规矩如此”，主角说“那就改规矩”。

5. **爽点按类型给反馈**  
   高位类：≤300字一个压制反馈，用阶级差/规则差/权力差直接打脸。  
   底层类：允许拉长，但每回合必须有收益：拿证据、换盟友、夺资源、反扣罪名。  
   - 平台包装：短故事标题/导语突出“她不争宠，她夺权”。

6. **动作链不少于三步**  
   每个关键场景写：触发 → 主角反应 → 物理反馈 → 反派误判 → 主角收束。  
   例：对方夺笔 → 主角松手让墨泼账册 → 当众露出假账 → 借长老口定罪。  
   - 失败模式：禁止“她略施小计就赢了”。

7. **抽象情绪必须落到身体/物件**  
   写鞭痕、碎杯、撕纸、夺印、断袖、烧毁芯片、装备过热、经脉反噬。  
   - 科武长篇可借：功法/科技代价必须可见。  
   - 失败模式：只写“她心中震怒”。

8. **每次爽都要付代价或开风险口**  
   求情=背骂名；保位=失自由；重生=记忆负担；系统=冷却/反噬；越级开甲=经脉损伤。  
   - 读者反馈规则：爽可以强，但不能无伤无损。

9. **人物标签+反差一章内立住**  
   女主一句话标签：清醒独美 / 黑莲花 / 扮猪吃虎 / 摆烂掌权者。  
   再给一处反差：冷面长老爱甜食、温柔底层女修擅黑客、病弱嫡女下手最狠。  
   - 短故事/狼人篇可借：标签越快越好，反差用于记忆点。

10. **章末只留一个具体钩子**  
   不写“危机来了”，要写清：谁来了、什么物件出现、哪句话兑现、哪道门被打开。  
   章末句模板：  
   - “可那枚本该烧毁的密钥，正躺在她袖中。”  
   - “今晚来审我的，不是长老，是我前世亲手救过的人。”  
   - “凭什么让给外人？”

## 10条章节自检清单

1. □ 200字内是否有：身份定位 + 具体冒犯 + 反常反应/目标宣告？  
2. □ 本章属于哪种爽点：高位碾压 / 底层智斗 / 复仇兑现 / 信息差反杀？  
3. □ 本章争夺的资源是否具体可量化？  
4. □ 反派是否有明确诉求，而不是单纯恶毒？  
5. □ 主角与反派是否形成“我赢你输”的结构冲突？  
6. □ 关键场景是否有3步以上动作链，而非一句话跳过？  
7. □ 冲突是否落到身体、物件、装备、权限、证据上？  
8. □ 主角赢后是否付出代价、暴露风险或埋下后患？  
9. □ 是否弱化恋爱脑，男主只做尊重型助攻/同盟，不替主角破局？  
10. □ 章末是否留下一个具体未决问题，而不是空泛悬念？

## 3条科武落地

1. **把宫宅封闭场改成科武封闭场**  
   后宫/后宅 → 门派内院、封锁飞船、研究所、军校、科武世家、舰队指挥层。  
   资源争夺 → 功法权限、实验名额、能源核心、继承权、舰队指挥权、基因序列。

2. **把礼法碾压改成功法/科技代差碾压**  
   高位压制不用绕：长老一句门规、AI一条权限、战甲一次锁定、功法等阶一压，直接形成打脸。  
   但长篇门禁：不能全书300字一爽，只用于宅斗式支线/单元卷；主线仍按科技-武道升级推进。

3. **把重生/穿书改成信息差工具**  
   重生 → 时间线回溯；系统 → 战斗模拟器；弹幕 → 群体预警频道；玄学 → 量子预测/数据库残片。  
   短故事可直接给答案；科武长篇必须给机制、冷却、反噬、误差率，避免毁世界观。
