# 《科武纪元》编辑学习报告：基于《小山河》创作方法论提炼

## 1 课程核心判断（≤6条）
1. **结构定生死**：“糖葫芦串”（单元事件+主线贯穿）是长篇连载维持追读与逻辑自洽的最优解，单篇闭环保爽感，暗线串联保粘性。
2. **主次配比防崩盘**：“核心主线/危机为主，情感/日常为辅”是硬核题材的生存法则。感情线仅作节奏缓冲剂，占比超20%必稀释悬疑/科幻张力。
3. **人设落地即信任**：去“完美悬浮化”，赋予主角职业锚点、性格缺陷与生活质感。读者对“接地气”角色的容忍度与代入感远高于“龙傲天”。
4. **资料前置+大纲留白**：硬核题材必须建立素材库与细纲，但大纲需保留20%弹性空间供角色自驱。过度准备会扼杀创作冲动，完全裸写必导致逻辑断裂。
5. **避短扬长策略**：作者需清醒识别自身逻辑短板（如复杂数学/时间诡计），主动规避并强化擅长维度（心理博弈/社会议题/动作场面）。不硬碰短板即不崩盘。
6. **数据与出版双轨逻辑**：连载期靠“稳定更新+高密度信息”养算法推荐；出版/改编潜力取决于“单元结构完整性+社会议题共鸣+视觉化高光场景”。

## 2 可执行编辑规则（按模块）
| 模块 | 编辑执行规则 |
|:---|:---|
| **开篇** | 3章内必须抛出首个核心危机/异常事件；世界观设定必须“剧情化植入”，禁止连续2章以上纯设定说明。首章结尾需留明确悬念钩子。 |
| **节奏** | 采用“一案/一副本一结+主线推进”结构。每单元结尾必须遗留1-2个未解线索或关系进展，强制衔接下一章。日更字数依内容完整度浮动，严禁注水日常。 |
| **冲突** | 核心冲突必须围绕“危机破解/体系碰撞”展开。人际/情感冲突仅作为破局辅助或代价体现。驳回“为虐而虐”“狗血误会”等无效冲突。 |
| **人物** | 主角需具备明确职业/体系身份与性格缺陷。配角/反派需有独立动机链，禁止工具人化。对话需符合身份语境，禁用现代网络梗破坏沉浸感。 |
| **题材** | 科幻/高武设定必须“资料前置”。编辑需核查核心设定（物理法则/武道体系/科技树）是否自洽。社会热点需进行“戏剧化转译”，禁止写成科普报告或新闻拼贴。 |
| **改编** | 单元结构需天然适配短剧/影视。每个单元必须具备独立起承转合，并预留视觉冲击强、台词可传播的“高光场景”。长线伏笔需标注回收节点。 |
| **平台规则** | 番茄系重“完读率”与“追更粘性”。开篇3万字定生死，需保持高密度信息输出；稳定更新（日更6k+）是算法推荐基础；数据平稳期依赖编辑节点（推荐位/征文/出版）拉升。 |

## 3 科武适配（长篇/短故事/热点稿）
### ✅ 可用点
- **长篇《科武纪元》**：“糖葫芦串”结构完美契合“星际/高武副本探索”模式。每个遗迹/星球/试炼可作为独立单元，主线（科武体系升级/宇宙阴谋/阵营博弈）贯穿。资料前置机制可直接迁移至“科武设定集”管理。
- **短故事**：单元闭环特性适合1-3万字短篇。聚焦单一科武现象/伦理困境，快速完成“悬念抛出-推演-反转-代价”闭环，便于投稿征文或平台短篇频道。
- **热点稿**：将现实科技前沿（AI觉醒、基因编辑、深空探测、脑机接口）包装为“科幻悬疑单元”。利用社会情绪共鸣快速测试市场，数据好则扩写为长篇支线。

### ❌ 不可硬套点
- **“感情为辅”配比**：男频/硬核科武题材中，感情线需进一步压缩或转化为“羁绊/阵营/理念冲突”。科武核心是“道争/体系碰撞/生存博弈”，感情占比过高会削弱硬核质感。
- **“避开复杂逻辑”**：科幻核心常涉及时空、维度、概率计算、能量守恒。不能因作者短板放弃硬核推演，需借助“设定补丁/辅助AI/团队智囊”弥补，否则将丧失科幻品类基本盘。
- **“字数不定/日更2更”**：番茄长篇科幻需稳定字数（日更6k-8k）维持算法热度。不能以“内容未写完”为由断更或大幅缩水，否则直接触发推荐降权。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章内是否抛出核心危机？世界观是否融入剧情而非大段说明？
- [ ] 单元结构是否完整（起承转合）？结尾是否预留主线钩子或线索碎片？
- [ ] 主角行动是否具备明确动机与体系逻辑？是否存在“机械降神”破局？
- [ ] 感情/支线占比是否≤20%？是否仅作为节奏缓冲或代价体现？
- [ ] 科武设定是否经过“资料前置”验证？是否存在前后矛盾或“吃书”？
- [ ] 冲突是否推动主线/揭示设定？有无为水字数添加的无效日常？
- [ ] 每章结尾是否设置“微钩子”（悬念/反转/危机逼近）保障追读率？
- [ ] 人物是否具备“物理反馈”与“成长代价”？升级是否伴随明确限制？
- [ ] 语言是否去悬浮化？对话与动作是否符合角色身份与当前情境？
- [ ] 伏笔回收率是否≥80%？未回收伏笔是否有阶段性解释或明确标注？

## 5 对作家角色的输入要求（写作指令模板）
提交稿件前，作者需按以下维度自检并附注说明，否则退回修改：

| 维度 | 输入要求（硬性约束） |
|:---|:---|
| **动作链** | 必须呈现“触发条件→决策依据→执行过程→连锁结果”完整闭环。禁止跳跃式行动或无铺垫的突发行为。关键动作需有前置伏笔与后续影响。 |
| **物理反馈** | 所有超自然/高武/科幻行为必须伴随可感知的物理/生理反馈（如肌肉撕裂、能量过载、环境破坏、重力异常、神经负荷）。禁用“意念一动，万物臣服”式虚写。 |
| **代价** | 任何能力使用、情报获取、阵营选择必须支付明确代价（寿命折损、资源枯竭、信任破裂、肉体损伤、道德困境）。无代价即无张力，禁止“零成本开挂”。 |
| **钩子** | 每章末尾必须设置“信息差钩子”或“危机倒计时钩子”。禁止以日常对话、风景描写或心理独白收尾。钩子需直接关联下一章核心冲突或设定揭示。 |
| **读者预期** | 严格管理开篇承诺的题材基调（硬核/悬疑/热血），中途不可偏移。伏笔回收率需≥80%，未回收需有阶段性解释。禁止“为反转而反转”破坏逻辑自洽；所有设定变更需提前3章埋设过渡线索。 |
