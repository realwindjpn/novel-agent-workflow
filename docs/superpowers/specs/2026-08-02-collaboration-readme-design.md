# 协作分支 Codex README 设计

## 目标

让接手 `realwindjpn/novel-agent-workflow` 的
`codex/local-mcp-library-plan` 分支的 Codex，在只阅读根目录 README 后就能
安全启动项目、理解本地网页与 MCP 的关系、定位主要代码、运行验证，并避免
误推或误合并到合作仓库 `main`。

## 范围

- 只改协作分支根目录 `README.md`。
- 以中文写给维护/实现代理，而不是面向普通读者的产品简介。
- 明确项目来自原仓库核心，当前分支包含网页运行器、Windows 启动器、本地
  MCP 书库、自由创作工作台、章节账本与可恢复回收区。
- 明确番茄等平台投稿、平台账号管理和自动上传不在实现范围内。

## 内容结构

1. 分支身份与 Git 边界：只推送 `codex/local-mcp-library-plan`，不改合作
   仓库 `main`。
2. 运行架构图：浏览器、本地 API、每本书独立的 MCP 子进程、书籍文件目录。
3. 快速启动与端口替代方案。
4. 接手阅读路径：核心状态机、MCP 服务、本地桥接、启动器、网页模块与测试。
5. 日常验证命令与本地/公网隔离、路径防护、书库与回收区约束。
6. 已实现与未实现能力，避免代理误把本地 `release` 当成平台投稿。

## 验收

- README 能独立说明接手顺序、运行方式、验证入口和禁止事项。
- 所有 Git 说明只针对合作分支，不要求或暗示改动合作仓库 `main`。
- 文档中的命令、端口、文件路径与当前代码一致。
- `git diff --check` 通过。
