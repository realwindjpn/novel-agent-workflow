## 二、章节自检清单（写完即检）

**每章写完后强制过筛：**

```
□ 章节末钩子 = [未解信息] + [迫近威胁] 组合？
□ 钩子是否在3章内兑现或升级？
□ 本章是否有实质性推进？（战力/认知/关系/资源）
□ 连续第[ ]章无实质推进？→ 触发危机警告
□ 冲突解决是否伴随[具体代价]？
□ 代价是否具象化、可追踪？（不能写"休息一下"）
□ 人物决策是否符合其当前[认知层级]？
□ [ ]场景是否出现"作者强行降智/开挂"痕迹？
□ 科技/武道动作是否有[感知→演算→执行→反馈]闭环？
□ 本章数据预期（完读/追更）是否匹配章末钩子强度？
```

## 三、可执行动作集

### 3.1 开篇动作（前三章必杀项）

```
动作01：第1章必须在500字内抛出核心设定碎片
   → 禁止：先写环境描写再抛设定
   → 执行：从主角当前危机切入，用战斗/逃跑/对话带出1个核心规则
   
动作02：第1章结尾必须设置"主角陷入绝境"锚点
   → 绝境 = 死亡威胁 / 资源枯竭 / 背叛 / 信息差陷阱
   → 禁止：情绪留白、日常过渡
   
动作03：第2章必须完成主角首次反击或关键信息获取
   → 反击逻辑：基于当前资源/能力，不依赖外部援助
   → 信息获取：必须改变主角对世界的认知或解锁新能力
   
动作04：第3章必须引出首个"伏笔级"悬念
   → 伏笔要求：读者在第3章看到时觉得"莫名其妙"
   → 伏笔兑现：必须在第15-20章触发，引发剧情回溯
```

### 3.2 节奏动作

```
节奏01：每章结尾强制悬念生成器
   → 公式：AI提示[异常数据] + 环境[已知威胁升级] + 人物[未知变量]
   → 案例："能量仅剩3%，但闸门已开启——身后传来未知生物的锁定警报"
   
节奏02：每10-15章设置"信息释放节拍"
   → 执行：揭示一个改变主角策略的关键信息
   → 要求：信息释放后主角必须有行动逻辑改变
   
节奏03：禁止连续3章"无实质推进"
   → 无实质推进 = 无战力升级 / 无认知改变 / 无关系变化 / 无资源增减
   → 触发条件：连续3章平淡期 → 立即插入次级冲突或信息差
```

### 3.3 冲突动作

```
冲突01：冲突必须有"代价兑现"
   → 执行：冲突解决后立即呈现可量化的损失清单
   → 示例：能量耗尽25% / 左臂神经损伤 / 阵营好感度-20
   
冲突02：禁止"机械降神"清单
   → 禁用：突然获得前辈传承 / 敌人突然失误 / 队友神兵天降
   → 替代方案：用前期埋设的伏笔+当前困境制造"意料之外情理之中"
   
冲突03：冲突必须服务于当前卷核心期待
   → 每个冲突结束后自问：这次对抗是否强化了[核心期待]的紧迫感？
```

### 3.4 人物动作

```
人物01：摒弃"证明型"人设
   → 检查：删除所有为炫技/高光设计的角色行为
   → 替代：用"本能型"驱动——人物按自身认知+生存逻辑行动
   
人物02：决策溯源表
   → 每当人物做出重要决策，填写：
     [角色] + [当前认知层级] + [信息缺口] + [行动动机]
   → 禁止：跳过上述链条直接写结果
   
人物03：科武主角成长弧光
   → 阶段1：生存本能（被威胁→反击）
   → 阶段2：武道/科技信仰（发现规则→遵守规则→利用规则）
   → 阶段3：体系重构（发现规则漏洞→挑战/重写规则）
   → 写作时检查：主角当前处于哪一阶段？是否匹配剧情节奏？
```

## 四、代价系统（强制执行）

### 4.1 越级代价矩阵

| 越级类型 | 代价类型 | 具象化要求 |
|:---|:---|:---|
| 武力越级 | 身体损伤/资源枯竭 | 必须在下章立即呈现生理症状 |
| 认知越级 | 信息反噬/判断失误 | 必须导致一次重大决策错误 |
| 关系越级 | 阵营敌对/信任破裂 | 必须有具体NPC产生敌意或背叛 |
| 捷径代价 | 系统反噬/隐性债务 | 必须在5章内产生"利息"型后果 |

### 4.2 代价兑现检查

```
每次代价触发后检查：
□ 代价是否具象化？（能量剩余量/神经损伤程度/关系数值）
□ 代价是否可追踪？（必须有记录，用于后续剧情触发）
□ 代价累积是否推动剧情转折？（第3次小代价=大转折触发）
□ 代价是否与越级幅度成正比？（小越级=轻度代价，大越级=不可逆代价）
```

## 五、失败模式清单（避坑指南）

### 5.1 开篇失败模式

```
❌ 失败：慢热铺垫（超过3章无危机）
❌ 失败：设定说明书式科普（连续500字无剧情动作）
❌ 失败：主角被动等待（无主动行动，无危机逼迫）
❌ 失败：章末情绪留白（"他陷入沉思"类结尾）
```

### 5.2 节奏失败模式

```
❌ 失败：钩子不兑现（钩子在3章后消失，无后续）
❌ 失败：预期跳跃（升级→解谜→复仇→阵营战→升级，逻辑断裂）
❌ 失败：连续平淡期（超过3章无实质推进，读者流失）
❌ 失败：数据下滑不启动自检（完读率下降后无应对动作）
```

### 5.3 冲突失败模式

```
❌ 失败：无代价解决（打完BOSS，毫发无损，什么都没变）
❌ 失败：机械降神（突然获得前辈传承/敌人强行失误）
❌ 失败：情绪化妥协（冲突解决靠"算了/原谅他"，无逻辑支撑）
❌ 失败：引入脱离世界观的极端对立（引发审核风险）
```

### 5.4 人物失败模式

```
❌ 失败：作者强行降智（角色做出不符合当前认知的蠢事）
❌ 失败：作者强行开挂（角色获得不符合代价矩阵的能力）
❌ 失败：证明型人设（为高光强加行为，割裂角色逻辑）
```

### 5.5 科武特有失败模式

```
❌ 失败：科技/武道规则打架（前后设定矛盾）
❌ 失败：动作描写无闭环（意念秒杀，无感知→演算→执行→反馈）
❌ 失败：战力膨胀失控（主角升级速度远超副本难度）
❌ 失败：设定堆积（超过3章无战斗/探索，纯设定说明）
```

## 六、人物口吻模板（科武向）

### 6.1 主角口吻切换器

| 成长阶段 | 口吻特征 | 句式模板 |
|:---|:---|:---|
| 生存本能期 | 短促、直接、拒绝废话 | "跑不掉就打。打不赢就死。" |
| 规则信仰期 | 谨慎、试探、敬畏系统 | "这个副本的难度……有异常。数据不支持我进入。" |
| 体系重构期 | 冷静、质疑、敢于挑战 | "这个规则的底层逻辑有漏洞。我可以利用它。" |

### 6.2 配角口吻模板

```
导师型："你的身体记住了规则。但你的大脑还没有。"
        → 交付信息时伴随警告

战友型："我帮你挡这一下，但下次我不会再帮你了。"
        → 交付资源时伴随关系代价

对手型："你以为你的计划很聪明？"
        → 制造压迫感时暴露主角的信息缺口

系统/AI型："[警告] [建议] [数据]"
        → 交付数据时保持中性，避免情感渲染
```

### 6.3 科武场景口吻

```
机甲启动："神经链接率97%——同步完成。动力核心预热中……能量储备足够战斗23分钟。"
战斗反馈："左臂液压系统超载，气缸温度临界值。继续输出会触发熔断保护。"
科技解析："这个遗迹的能量波形……和我们的标准协议不匹配。它不属于已知的任何体系。"
```

## 七、段落节奏模板

### 7.1 战斗段落节奏（每场战斗必须包含）

```
[感知层] → 敌人/环境数据输入
[演算层] → AI/战术系统计算，输出可选方案
[决策层] → 主角选择方案，说明理由
[执行层] → 具体动作描写（发力支点/协同动作/能量消耗）
[反馈层] → 即时后果（装备耐久/生理损伤/环境变化）
[代价层] → 代价兑现声明（剩余资源/时间压力/关系变化）
```

### 7.2 剧情推进段落节奏

```
[钩子兑现] → 上章悬念在本章触发
[冲突升级] → 压力增大，主角必须做出选择
[代价结算] → 选择后立即呈现代价
[信息释放] → 主角获得改变策略的关键数据
[新钩子生成] → 章末悬念（未解信息+迫近威胁）
```

### 7.3 信息释放节拍

```
每10-15章必须执行一次：
Step 1：揭示改变主角认知的关键信息
Step 2：主角重新评估当前局势
Step 3：主角调整战略/目标/关系
Step 4：新冲突/新威胁出现，与新战略产生矛盾
Step 5：新钩子生成
```

## 八、章末钩子生成器（公式版）

### 8.1 标准钩子公式

```
章末钩子 = [未解信息] + [迫近威胁] + [时间/资源压力]

未解信息：主角发现了什么异常数据/线索/背叛迹象？
迫近威胁：什么力量正在接近/锁定/瞄准主角？
时间压力：能量/生命/援军/闸门开启的倒计时？

示例："能量仅剩3%，但前方闸门已开启——身后传来未知生物的锁定警报"
       未解信息：能量异常/闸门异常
       迫近威胁：未知生物锁定
       时间压力：能量耗尽+生物接近
```

### 8.2 钩子兑现检查

```
钩子检查清单：
□ 钩子是否在3章内兑现或升级？
□ 兑现时是否伴随[代价]而非轻松解决？
□ 兑现后是否产生新的[未解信息]？
□ 新未解信息是否指向当前卷核心期待？
```
