# 《科武纪元》编辑学习报告：洛宝儿创作路拆解

## 1 课程核心判断（≤6条）
1. **算法逻辑**：推荐期前数据无参考价值，断更/请假对推荐权重打击致命，稳定更新是算法喂养前提。
2. **爆款公式**：擅长类型基底 + 热门元素重组 + 反套路微创新 = 差异化原创。拒绝纯跟风与元素堆砌。
3. **节奏铁律**：核心冲突/误会/清障必须“短平快”（如三章解决），拒绝拉长注水；拖沓是留存杀手。
4. **人设避雷**：以读者视角做减法，剔除明确毒点（虐主、降智反派、拖沓误会），反套路设计可形成记忆点。
5. **生产纪律**：存稿是生命线（≥8万字），保障稳定交付、预留未发布章节精修空间、防剧情歪楼。
6. **反馈闭环**：评论区是实时质检仪，BUG需即时修正并反哺后续大纲；虚心接纳编辑/读者意见是迭代核心。

## 2 可执行编辑规则（按原文内容提炼）
| 维度 | 可执行规则 |
|:---|:---|
| **开篇** | 精修至无冗余标点/废话；前3章必须亮出核心卖点与元素组合；避开饱和跟风题材，做差异化切入。 |
| **节奏** | 推荐前屏蔽数据焦虑；核心冲突/信息差/小反派3-5章内必须收束或反转；拒绝“误会拖几百章”式注水。 |
| **冲突** | 采用“短平快清障法”；冲突必须服务于主线推进与人设塑造，不靠拉长情绪水字数；反套路破局（快速打脸/领盒饭/阵营反转）。 |
| **人物** | 站在读者视角做“避雷设计”（剔除毒点人设）；利用男女视角差异进行头脑风暴校准；主角动机清晰，不虐主、不降智。 |
| **题材** | “擅长基底+2-3个热门元素”缝合；元素重组而非照搬；避开同类型视觉疲劳区，做独家标签。 |
| **改编** | 预留短剧/影视接口：单元化冲突结构、快节奏清障、人设鲜明不拖沓、每卷结尾留明确悬念钩子。 |
| **平台规则** | 番茄算法首秀前数据无效；断更直接降权；存稿应对算法波动；评论区高频词影响后续推荐池分发。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（结构/生产/运营层）
- **存稿与稳定更新**：科幻长篇需严密世界观铺垫，存稿可防设定崩坏、预留逻辑精修窗口。
- **“三章清障”节奏法**：转化为科幻/武斗中的“小副本/阴谋/支线反派”快速收束，不拖主线进度。
- **元素重组策略**：科武设定（机甲/基因/星际航道）+ 武道体系 + 热门情绪（逆袭/复仇/群像），做差异化缝合。
- **评论区BUG修复**：科幻设定易出逻辑漏洞/战力失衡，需建立“读者反馈-设定集修正”闭环。
- **避雷设计**：剔除“降智反派”“机械降神”“战力崩坏”“无代价开挂”等科武赛道明确毒点。

### ❌ 不可硬套点（题材/情绪层）
- **现言核心元素**：追妻火葬场/萌宝/替嫁/甜宠等情感驱动元素，与科武的硬核/力量体系/生存博弈基因冲突，不可直接移植。
- **情感误会梗**：科武中的“信息差/阵营博弈”需快速破局，但不可套用现言“情感误会三章解决”的轻喜剧处理，需保持世界观严肃性。
- **轻松诙谐基调**：女频幽默文风可适度点缀，但不可硬套至硬核科武主线，力量体系与科技树需保持逻辑自洽与压迫感。
- **首秀数据无视**：科幻读者留存极度依赖开篇信息密度与设定自洽，首秀数据仍有强预警价值，不可完全照搬“推荐前不看数据”的现言策略。

## 4 编辑检查表（10条以内）
1. 开篇前3章是否剔除所有冗余设定/背景说明，直击核心冲突或生存危机？
2. 是否完成“擅长基底+2-3个热门元素”的差异化缝合，而非纯跟风？
3. 核心误会/信息差/小反派是否在3-5章内完成收束或反转？
4. 人设是否已剔除目标读者明确厌恶的毒点（降智、虐主、拖沓、机械降神）？
5. 存稿量是否≥8万字，能否支撑突发断更与未发布章节精修？
6. 推荐期前是否屏蔽数据焦虑，专注内容交付与节奏控制？
7. 是否建立“评论区BUG收集-设定集/大纲修正”的闭环机制？
8. 战力/科技树/世界观规则是否在前10万字内完成基础锚定，无越级无代价？
9. 更新频率是否绝对稳定（日更/固定时间），无随意请假或断更？
10. 每卷/每副本结尾是否预留明确钩子（资源争夺/阵营异动/技术突破），衔接下一推荐周期？

## 5 对作家角色的输入要求
| 维度 | 输入要求（科武向） |
|:---|:---|
| **动作链** | 战斗/操作必须呈现“意图-发力-传导-结果”四步闭环。禁用模糊形容词（如“威力巨大”“速度极快”），改用具体参数/轨迹/破坏面/能量流向描述。 |
| **物理反馈** | 每次能量释放/机甲碰撞/武技施展，必须附带≥2项可观测反馈（如装甲形变率、重力场扭曲读数、神经负荷阈值、地面裂纹深度、大气电离痕迹）。 |
| **代价** | 力量体系必须有明确损耗。每次越级/爆发/使用高阶科技，必须绑定即时代价（冷却期、基因崩溃阈值、资源枯竭、战术暴露、装备过载），禁止无代价开挂。 |
| **钩子** | 每章末尾必须抛出“信息差悬念/资源争夺/阵营异动/技术瓶颈”之一，禁用纯情绪留白。钩子需在3-5章内兑现或反转，保持“短平快”清障节奏。 |
| **读者预期** | 开篇明确力量体系规则与主角核心目标；承诺“不降智、不拖沓、不机械降神”；用评论区高频词（硬核、逻辑自洽、爽点密集、设定严谨）校准后续行文，预期管理前置。 |
