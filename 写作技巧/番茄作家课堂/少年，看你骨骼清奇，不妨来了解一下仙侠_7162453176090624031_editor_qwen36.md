# 《科武纪元》编辑学习手册：基于番茄仙侠品类指南的规则提炼

## 1 课程核心判断（≤6条）
1. **品类定义双核**：明确的力量/科技升级体系 + 核心驱动力（长生/进化/生存）构成品类基石。
2. **冲突底层逻辑**：核心驱动力必然导向资源依赖，资源稀缺性直接生成人际/阵营/文明级矛盾。
3. **子品类决定叙事模型**：古典/凡人流重目标推进与情绪控制；日常风重氛围与轻量化节奏；洪荒/神话风重设定重构与预期颠覆。
4. **凡人流成功要件**：微末开局、资质平庸、机缘驱动、节奏紧凑、环环相扣、情绪精准投放。
5. **平台流量隔离机制**：有无“系统/金手指/强外挂”直接决定投稿分组与算法推荐池，错投即断流。
6. **情绪价值前置**：读者留存不依赖设定堆砌，而依赖“努力/机缘→资源获取→阶层跃迁”的确定性反馈。

---

## 2 可执行编辑规则（按栏目取舍）

### 开篇
- 前3章必须亮出核心升级体系（科武阶位/能量阈值/基因锁等）与主角初始资源状态。
- 首章钩子需直接绑定“资源缺口”或“体系门槛”，禁止纯背景铺陈。

### 节奏
- 凡人流/古典流：采用“目标-受阻-破局-结算”循环，单章必有进度推进或信息增量。
- 日常流：以单元剧结构承载主线，每3-5章需完成一次情绪释放或体系小升级，避免流水账。

### 冲突
- 所有冲突必须可追溯至资源分配（能源配额、算力权限、武学残卷、殖民星域）。
- 冲突升级路径：个体争夺 → 组织博弈 → 体系规则对抗。禁止无源头的“为战而战”。

### 人物
- 主角行为逻辑需与“资源获取效率”强绑定。凡人流主角需具备“信息差利用+风险对冲”特质。
- 配角/阵营需代表特定资源分配立场，避免脸谱化善恶。

### 题材/改编
- 明确子品类标签后，全文基调、叙事密度、爽点分布需严格对齐该标签读者预期。
- 传统仙侠“四艺”（丹符阵兽）需完成科武转译（如：基因编译、神经回路、引力场域、机械共生体）。

### 平台规则
- **分组隔离**：无系统/纯科武推演 → 投“科幻/高武”池；含系统/AI托管/强外挂 → 投“脑洞/系统”池。
- **标签精准**：首章标签需与正文核心机制100%匹配，算法冷启动期标签错误将导致推荐断层。

## 3 科武适配：可用点 vs 不可硬套点

| 维度 | 可用点（直接迁移） | 不可硬套点（需重构） |
|:---|:---|:---|
| **体系** | 等级划分、突破门槛、资源消耗模型 | 道教玄学/灵气/天道感悟（需替换为物理法则/能量守恒/神经可塑性） |
| **动机** | 资源争夺驱动冲突、阶层跃迁诉求 | “追求长生”作为唯一动机（科武需叠加“文明存续/技术奇点/基因进化/生存阈值”） |
| **结构** | 凡人流“微末-机缘-滚雪球”模型、日常风单元剧缓冲 | 传统宗门架构（替换为企业财阀、研究院、军方序列或AI主脑管辖） |
| **节奏** | 环环相扣的因果链、情绪精准投放、不拖沓 | 纯“悟道闭关”式慢节奏（科武需保持技术迭代或实战验证的可见进度） |
| **平台** | 系统/外挂分组隔离原则、标签决定流量池 | 仙侠专属标签（需建立科武专属标签矩阵：如#硬科幻武学 #赛博修真 #基因武道） |

## 4 编辑检查表（≤10条）
- [ ] 前3章是否明确展示科武升级路径与初始资源状态？
- [ ] 核心冲突是否可量化追溯至具体资源/权限/技术缺口？
- [ ] 单章是否包含至少1次有效进度推进或信息增量？
- [ ] 主角破局手段是否符合已设定的科武物理/技术逻辑？
- [ ] 有无系统/AI外挂？投稿分组是否与正文机制严格对应？
- [ ] 情绪投放是否匹配子品类预期（凡人流紧凑/日常风松弛）？
- [ ] 阵营/组织是否代表明确的资源分配立场？
- [ ] 传统仙侠元素是否已完成科武逻辑转译，无玄学悬浮感？

## 5 对作家角色的输入要求

| 模块 | 编辑验收标准（作家必须提供/明确） |
|:---|:---|
| **动作链** | 提交“刺激→决策→执行→结果→体系反馈”完整闭环。禁止跳跃式升级或机械降神。每一步需符合科武世界底层规则。 |
| **物理反馈** | 力量/技术释放必须伴随可感知的物理/生理代价（如：神经负荷、动能反冲、代谢衰竭、材料疲劳）。禁用“气势暴涨”“威压弥漫”等虚写。 |
| **代价** | 每次突破/破局必须标注明确成本（资源消耗、时间折损、身体损伤、信用降级、道德妥协）。无代价的升级视为无效爽点。 |
| **钩子** | 章末/卷末钩子必须直接关联“资源缺口”或“体系瓶颈”。禁止纯悬念或情感拉扯。钩子需在3章内给出阶段性解答或新路径。 |
| **读者预期** | 开篇需声明目标子品类（如：硬核凡人流/轻科幻日常/赛博武斗）。前10章必须兑现该品类的核心承诺（节奏密度、爽点类型、情绪基调）。偏离预期需提前预警或平滑过渡。 |
