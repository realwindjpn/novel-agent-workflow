## 一、开篇技巧（网文"生死线"）

### 开篇五步走（可直接套用）
| 步骤 | 核心要点 | 示例 |
|:---|:---|:---|
| **1. 定场景** | 选冲突感强的场景，避免平淡日常 | 主角被欺负、发现秘密、面临危机 |
| **2. 亮身份** | 300字内说清主角是谁 | "废柴少爷""穿越医生" |
| **3. 抛危机** | 给主角必须解决的紧迫问题 | "3天内不还钱就被赶出家门" |
| **4. 出金手指** | 危机中给出解决方案 | 觉醒系统、获得异能 |
| **5. 留钩子** | 结尾抛出下一个期待 | "系统说还有更厉害的奖励..." |

> 关键原则：开篇是"敲门砖"——编辑看开篇定签约，读者看开篇定是否追读

## 二、核心吸引力构建

### 1. 期待感制造（两大方法）

**① 信息不对称法**
- 读者知道："反派要在明天陷害主角"
- 主角不知道："主角还在计划明天的事"
- 效果：读者产生"追更焦虑"，期待主角如何发现/反击

**② 对比法**
- 过去：主角被富二代嘲笑"一辈子买不起车"
- 现在：主角用金手指买了更好的车，在他面前"不经意"开过
- 效果：期待反派的反应

### 2. 三大核心情绪公式

| 情绪类型 | 写作公式 | 经典案例 |
|:---|:---|:---|
| **憋屈情绪** | 被欺负场景 + 主角隐忍 + 读者共情 | 《斗破苍穹》萧炎被退婚 |
| **爽感情绪** | 憋屈铺垫 + 金手指发力 + 反派打脸 | 萧炎让纳兰嫣然后悔 |
| **感动情绪** | 主角付出 + 他人真心反馈 | 《雪中悍刀行》徐凤年为老黄报仇 |

## 三、人物塑造技巧

### "低成本塑人"三技巧

1. **加记忆点标签**
   - 动作："配角紧张时摸鼻子"
   - 口头禅："主角赢了就说'小菜一碟'"
   - 外貌："反派脸上有刀疤，说话时摸刀疤"

2. **给小缺点**
   - 主角很厉害，但怕蟑螂
   - 配角是学霸，但路痴

3. **用"小事"体现性格**
   - ❌ 直接说"主角很善良"
   - ✅ 写"主角看到流浪猫，会分一半面包给它"

### 人物刻画三要素（对话/动作/内心）

| 要素 | 核心要点 | 注意 |
|:---|:---|:---|
| **对话** | 自我意识 + 情绪 + 对他（主题） | 避免平板，要有互动感 |
| **动作** | 姿势 + 态度 + 表情 | 不止于"走站跑跳" |
| **内心** | 感情描述 + 内心独白 | 以景写情或直接述情 |

## 四、情节与结构设计

### 桥段设计三法

| 方法 | 原理 | 示例 |
|:---|:---|:---|
| **反差法** | 人物对比衬托主角 | 败家子 vs 充满希望的主角 |
| **堆栈法** | 先布局到高度，再将主角叠上去 | 传说剑客被流浪汉击败→少年是流浪汉师傅 |
| **陷阱法** | 逼主角入绝境→大反转 | 主角"大智若愚"，后期反杀 |

### 伏笔使用原则
1. **紧扣主题**——无关伏笔削弱故事力量
2. **数量适中**——过多让读者混乱
3. **及时呼应**——埋设与呼应不宜隔太久
4. **高潮爆发**——伏笔在高潮点揭晓最佳

## 五、增强代入感实用技巧

| 技巧 | 操作方法 |
|:---|:---|
| **矛盾激怒法** | 卡文时设计气死人的对手，保持怒火写作 |
| **人物代入法** | 现实中找喜欢的人（明星/动漫角色）代入 |
| **精细描写法** | 逐步扩写：我家门前有条狗 → 刚下过雨，满是泥水的草丛里躺着受伤的流浪狗 |
| **夸张用词法** | "老太太饿得只剩一张皮，像株枯死的老树桩" |
| **情绪带动法** | 笑时写开心事，哭时写悲伤事 |

## 六、新手避坑指南

| ❌ 常见误区 | ✅ 正确做法 |
|:---|:---|
| 只写不看热门作品 | 定期分析爆文开篇节奏、人设、故事核 |
| 初稿追求完美 | 先写出来，再改好它 |
| 频繁换题材 | 选定方向，完成5万字短篇训练 |
| 开头冗长、节奏拖沓 | 一铺一垫，快速推进 |
| 忽略更新节奏 | 保持日更，固定字数输出 |

## 七、核心心法（来自猫腻《庆余年》经验）

> "70分以上文笔 + 套路文，关键是节奏，更关键的是安全感"

- **安全感来源**：大背景、金手指（范闲：皇帝父亲+众多"爸爸"撑腰）
- **可控的不安全感**：让保护者暂时离开/互相猜疑，但随时能回归
- **人物特质丰富**：给主角多种可展开的特质，易出剧情
