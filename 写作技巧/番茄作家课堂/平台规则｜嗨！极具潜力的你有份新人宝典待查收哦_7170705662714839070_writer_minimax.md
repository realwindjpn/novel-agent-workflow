# 《科武纪元》作家OS｜平台规则补丁 v1.0

---

## 【动作卡】开篇三秒触发器

**触发条件**：签约评估 / 推荐算法 / 读者留存  
**核心动作序列**（3选1执行）：

| 动作类型 | 科武长篇执行 | 短故事/狼人篇执行 |
|:---|:---|:---|
| **标签亮明** | 首章首段抛出题材关键词（机甲/武道/基因），≤100字完成世界观坐标定位 | 标题+首段嵌入热点标签（事故/复仇/觉醒），适配搜索流量 |
| **设定抛出** | 第1-3章内完成核心科武体系1个「能力-原理-限制」闭环 | 单篇内完成「危机-对抗-反转」闭环，≤5000字 |
| **卖点展示** | 明确交付承诺：「硬核科武升级」/「机甲战术推演」/「基因武道复仇」 | 热点向冲突贴合当期社会情绪，30字内可概括核心卖点 |

**失败模式**：文不对题（卖点与内容错配）→推荐标签错配→跳出率飙升→推荐权重清零

## 【反馈卡】科武物理反馈矩阵

**规则来源**：平台改编评估（影视向要求视觉化可分镜）  
**执行标准**：禁止纯概念堆砌，所有设定需附量化物理反馈

| 维度 | 量化反馈字段 | 短故事可借点 | 科武长篇必填 |
|:---|:---|:---|:---|
| **机体损耗** | 关节磨损率（%）、能量核心温度、冷却周期 | ✓ 事故场景可简化 | ✓ 需建立损耗累计表 |
| **能力代价** | 代谢周期、出力衰减曲线、反噬触发阈值 | ✓ 单次爆发即可 | ✓ 需规划长期衰减弧 |
| **环境互扰** | 重力加速度对出拳速度的影响系数、磁场对感知的影响范围 | ✓ 背景设定留白 | ✓ 需前后一致 |
| **阵营资源** | 补给存量、指挥链响应时间、通信延迟 | ✓ 危机转折点可用 | ✓ 需动态消耗记录 |

**失败模式**：设定前后矛盾（战力崩坏）→分成断崖→改编评估出局

## 【代价卡】能力/决策代价锚点

**触发条件**：任何关键能力首次使用 / 阵营重大决策  
**代价类型清单**（强制标注）：

| 代价类型 | 科武长篇执行 | 短故事/狼人篇执行 |
|:---|:---|:---|
| **资源枯竭型** | 能量块储量、稀有材料消耗、药剂配给 | ✓ 单次爆发即耗尽 |
| **寿命折损型** | 基因药剂副作用累积、神经负荷上限 | ✓ 爆发后衰竭即可 |
| **规则反噬型** | 违反机甲三大定律的后果、武道流派禁忌 | ✓ 禁忌触发即反转 |
| **信任破裂型** | 队友/阵营关系损耗、指挥权限降级 | ✓ 冲突后即时分裂 |

**强制规则**：每章≥1个代价锚点标注，长篇需建立「代价累计表」追踪衰减曲线

## 【节奏卡】段落呼吸节点

**平台福利要求**：日更稳定 + 连载权重保护  
**节奏执行标准**：

| 段落类型 | 字数区间 | 科武长篇 | 短故事 |
|:---|:---|:---|:---|
| **冲击段** | 300-500字 | 战斗/冲突场景，高密度动作描写 | 危机爆发，冲突升级 |
| **喘息段** | 200-300字 | 能力代价/战术复盘 | 情感/关系转折 |
| **伏笔段** | 100-200字 | 设定埋设/道具暗示 | 悬念钩子植入 |
| **钩子段** | 50-100字 | 章末强制钩子 | 篇末强制反转 |

**更新节奏门禁**：
- 保底考核：≥6000字/周（强制日更时需预留存稿）
- 断更惩罚：推荐权重清零→需从零爬升
- 全勤奖触发：连续更新30天/自然月满勤

## 【借点速查】短故事/狼人篇 vs 科武长篇

| 模块 | 短故事/狼人篇借点 | 科武长篇必填 |
