# 《科武纪元》编辑学习官｜课程拆解与执行手册

## 1 课程核心判断（≤6条）
1. **网文底层即“爽文”**：所有故事均可拆解为不同形态的爽点（逆袭/打脸/复仇/嗑CP等），创作者需先掌握套路，再隐藏套路，最后反套路。
2. **“黄金三章”本质是权重提示**：非字数/标点模板，而是强调开篇必须完成“危机建立+情绪抓人”，否则直接流失。
3. **张力公式=时间锁+空间锁+道德挑战**：倒计时制造紧迫感，密闭空间合理化巧合，道德困境逼迫人物亮出底色。
4. **情绪共鸣依赖原始冲动**：有效情绪必须能跨越物种理解（生存/繁衍/领地/复仇），七宗罪与七美德是同一情绪音量条的上下调节。
5. **人设核心是“不妥协”**：新人放弃灰度刻画，将单一信仰/执念推向极致，冲突中绝不退让即为人物记忆点。
6. **描写铁律：禁用情绪形容词**：用环境、动作、物理反馈、情节推进“演”出情绪，而非用词汇“说”出情绪。

## 2 可执行编辑规则（按栏目分类）
| 维度 | 编辑规则（基于原文逻辑） |
|:---|:---|
| **开篇** | 前3000字必须抛出明确“锁”（时间/空间）或身份反差；禁止世界观说明书式铺陈，设定必须随危机同步释放。 |
| **节奏** | 以“时间锁”为节拍器推进；每章至少2次强调时间流逝/资源衰减；场景切换需伴随危机升级或信息差揭露。 |
| **冲突** | 采用“物理危机+道德抉择”双轨制；冲突必须迫使主角在核心利益/底线间做非完美选择，禁止“全都要”解法。 |
| **人物** | 开局亮出1个“不妥协”信条；所有行为必须围绕该信条展开；用动作链与环境细节替代心理独白。 |
| **题材** | 强制套用“大人物遇小事/小人物遇大事”反差模型；科幻/武道设定仅作为放大冲突的工具，不喧宾夺主。 |
| **改编** | 优先设计“单一密闭场景+强道德困境”单元，降低影视/短剧场景调度成本；保留“狗能听懂”的原始情绪主线。 |
| **平台规则** | 契合番茄推荐算法：开篇3章内完成“钩子建立-情绪释放-新钩子抛出”；禁用文青抒情，直给生存/复仇/守护等底层爽点。 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **时间/空间锁科幻化**：氧气存量倒计时、跃迁引擎冷却期、重力舱故障、异星生态隔离区、武道经脉逆行时限。
- **道德挑战升维**：科技伦理（是否植入敌对AI换取战力）、武道底线（为破境是否掠夺平民基因/灵脉）、集体与个体存亡抉择。
- **反差模型落地**：星际战神退役当底层机甲维修工（大人物遇小事）；拾荒少年意外绑定上古武道核心（小人物遇大事）。
- **不妥协信条**：契合武道精神与科幻纪律，如“机甲师绝不弃机”“武道不斩无辜”“数据可篡改，誓言不可覆写”。

### 🚫 不可硬套点
- **七宗罪直白化**：科幻语境下不可降维为低俗欲望，需包装为“技术异化/阶级资源垄断/生存配额争夺”等合理化动机。
- **小空间巧合反逻辑**：星际/高武尺度下，巧合必须符合物理/信息逻辑（如量子纠缠、系统推演、情报网覆盖），禁止为戏剧性牺牲设定严谨性。
- **情绪描写软科幻化**：禁用“他感到绝望/热血沸腾”，必须替换为“心率突破阈值/神经突触灼烧痛感/机甲液压管爆裂/灵压读数超载”等硬核反馈。

## 4 编辑检查表（10条以内）
- [ ] 开篇3000字内是否已建立明确“时间锁”或“空间锁”？
- [ ] 主角是否面临至少一项“道德/利益抉择”且无完美解？
- [ ] 是否采用“大人物遇小事”或“小人物遇大事”制造身份/环境反差？
- [ ] 核心情绪是否已剥离形容词，改用动作/环境/数据/物理反馈呈现？
- [ ] 主角是否具备一个贯穿始终、绝不妥协的单一核心信条？
- [ ] 冲突场景是否控制在有限空间内，避免无效宏大叙事？
- [ ] 故事动机能否用1句话让非目标读者（或“狗”）听懂原始冲动？
- [ ] 科幻/武道设定是否随情节推进释放，而非开篇堆砌说明书？
- [ ] 节奏是否通过“倒计时/资源消耗/状态恶化”持续加压？
- [ ] 是否已全文剔除“他感到XX”“他非常XX”等直白情绪词？

## 5 对作家角色的输入要求
| 维度 | 输入标准（编辑验收口径） |
|:---|:---|
| **动作链** | 必须提供完整物理序列：`触发信号→生理/神经反应→决策判断→执行动作→物理结果`。禁止跳跃式心理描写或“意念一动”式模糊处理。 |
| **物理反馈** | 所有情绪/状态必须转化为可观测指标。例：恐惧=瞳孔缩放/冷汗浸透作战服/机甲警报频闪；痛苦=骨骼微裂声/视野数据乱码/灵压读数暴跌。 |
| **代价** | 每次破局/升级必须支付明确代价（寿命/资源/信任/道德底线/身体损伤）。代价需在首次冲突中明示，禁止“零成本开挂”或“系统白送”。 |
| **钩子** | 每章结尾必须埋设“未解危机/信息差/倒计时逼近/道德抉择悬念”。钩子需与核心“锁”或“不妥协”信条直接绑定，禁止无关支线截断。 |
| **读者预期** | 开篇需明确交付“原始情绪契约”（如：复仇必血偿、守护必死战、逆袭必打脸）。后续情节必须严格兑现或合理反转该预期，禁止中途切换核心情绪赛道。 |
