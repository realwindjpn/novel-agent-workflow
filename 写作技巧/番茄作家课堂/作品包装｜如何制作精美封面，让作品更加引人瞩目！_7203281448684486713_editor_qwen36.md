# 《科武纪元》封面包装与编辑规则提取

## 1 课程核心判断（≤6条）
1. 封面是作品首层流量漏斗，直接决定点击转化率（CTR），非纯装饰。
2. 信息层级必须严格遵循“书名＞作者名”，长书名需做视觉权重切割与断句。
3. 视觉风格必须与平台题材分类强绑定（男频偏冷暗/硬核，女频偏暖亮/情绪）。
4. 封面关联元素需提取作品核心符号，禁止无逻辑的装饰性堆砌。
5. 平台对自定义封面有明确尺寸、安全边距与审核规范，违规将阻断推荐。
6. 包装需兼顾移动端缩略图可读性，静态画面必须能暗示动态张力。

## 2 可执行编辑规则（按原文实际内容取舍）
*注：原文仅聚焦“封面包装与平台规范”，节奏/冲突/人物写法未涉及，依“按实际内容取舍”原则剔除，仅保留可映射的编辑规则。*
- **题材/平台规则**：封面主色调、字体风格必须严格对齐平台分类标签（科幻/男频采用冷色调、高对比度、几何/机械线条）；上传前核对PC/APP端官方尺寸，预留安全边距防系统裁切。
- **开篇/信息释放**：封面“书名突出、元素精简”的排版逻辑直接映射至正文开篇：前3章仅释放1个核心设定+1个强冲突，禁止背景设定倾泻；信息密度需与封面视觉复杂度成反比。
- **改编/视觉资产**：封面需预埋1-2个高辨识度视觉符号（如机甲结构、能量回路、武道图腾），该符号需在正文前10章内完成首次具象化描写，为后续漫画/短剧/影视改编提供标准化视觉锚点。

## 3 科武适配：可用点、不可硬套点
- **可用点**
  - 采用冷蓝/暗灰/金属银为主色调，契合“科幻+武道”的硬核质感与男频受众预期。
  - 书名排版采用“科武”二字放大加粗、“纪元”缩小衬底，强化类型辨识度与视觉重心。
  - 提取单一核心意象（如断裂的机甲臂缠绕武道绷带/能量刃），避免多元素拼贴导致移动端糊成色块。
- **不可硬套点**
  - 禁止套用女频暖色/手写体/柔光滤镜，会严重偏离科幻男频受众的3秒扫视预期。
  - 封面不可过度追求“电影级海报”细节，缩略图下丧失可读性即等于无效包装。
  - 包装不能替代正文逻辑，封面再精美若开篇无钩子或设定自相矛盾，留存率仍会断崖下跌。

## 4 编辑检查表（10条以内）
- [ ] 书名在1:1缩略图下是否清晰可辨（字号占比≥40%）？
- [ ] 作者名是否严格小于书名，且未遮挡核心视觉区？
- [ ] 主色调是否符合男频科幻分类（冷色/高对比/低饱和度）？
- [ ] 关联元素是否≤3个，且与正文核心设定直接对应？
- [ ] 长书名是否完成视觉断句与权重分级（无拥挤感）？
- [ ] 尺寸是否严格匹配番茄官方规范（含安全边距）？
- [ ] 字体/素材是否具备商用授权或原创证明？
- [ ] 移动端预览是否无文字溢出、无关键元素被裁切？
- [ ] 是否通过平台AI/人工审核（无敏感/违规元素）？

## 5 对作家角色的输入要求
- **动作链**：提交封面方案时，需同步提供“核心动作序列”（例：能量充能→肌肉绷紧→武器出鞘），确保封面静态构图能暗示动态发力轨迹，而非摆拍式站桩。
- **物理反馈**：封面材质/光影需严格对应正文设定的物理规则（例：能量过载的灼烧痕迹、金属疲劳的应力裂纹、重力环境下的姿态偏移），禁止无逻辑的悬浮/发光特效。
- **代价**：明确封面视觉符号在正文中的“使用代价”（例：该机甲涂装仅主角可激活，但每次启动消耗神经负荷/稀有燃料），包装需与设定代价绑定，避免“视觉诈骗”导致读者预期落差。
- **钩子**：封面必须预留1个未解视觉悬念（例：背景中半掩的未知文明图腾/断裂的制式武器残片），该悬念需在正文第5章内完成首次回收或升级，形成包装-正文的流量闭环。
- **读者预期**：提交前需标注目标读者画像（例：20-35岁男频科幻/机甲/硬核武道受众），封面所有元素必须通过该画像的“3秒扫视测试”，剔除任何偏离类型预期或干扰核心卖点的装饰性设计。
