# 《科武纪元》作家OS补丁  
## Patch：落笔前构思男频网文执行版

---

## 0. 本补丁目标

把“构思一本男频网文”转成写作时可执行的规则：

> 每章必须让读者知道：  
> **主角是谁被压着 → 他想要什么 → 他做了什么 → 谁挡他 → 付出什么代价 → 章末还有什么没解决。**

---

# 1. 核心运行指令

## 1.1 开书前必须先过“一句话故事门”

格式：

> **负价值身份 + 正价值欲望 + 主动行动 + 阻力/世界规则**

《科武纪元》推荐句式：

> 被科技神朝除名的旧武修，想夺回武道正统，却只能黑入他最厌恶的神经武备系统，在科技与真气双重追杀下撕开纪元真相。

不合格示例：

> 一个少年变强的故事。  
> 一个武者在未来世界冒险的故事。

合格检查：

- 主角当前处境低。
- 主角欲望明确。
- 主角会主动做事。
- 世界/敌人会挡他。
- 这句话能长出至少一卷剧情。

### 可借点标注

- **短故事/狼人篇可借点**：一句话故事必须更锋利，直接锁死“身份反差 + 目标 + 杀局”。例如：被村民怀疑的守夜人，必须在天亮前找出狼人，否则自己先被处决。
- **科武长篇可借点**：一句话故事要能支撑多卷扩展，最好包含“世界规则冲突”。例如：科技压制武道、真气被数据化、武者被系统驯化。

# 2. 写作前任务卡字段更新

每一卷、每一章开写前，任务卡必须补齐以下字段。

## 2.1 全书任务卡

| 字段 | 填写要求 |
|---|---|
| 一句话故事 | 负价值身份 + 正价值欲望 + 主动行动 + 核心阻力 |
| 主角负价值身份 | 他为什么被看不起、被剥夺、被限制 |
| 主角正价值欲望 | 他真正想夺回/守住/证明什么 |
| 世界核心规则 | 本世界最能制造冲突的一条新规则 |
| 规则与主角冲突 | 这条规则怎样羞辱、压制或诱惑主角 |
| 金手指类型 | 机制型/协议型/接口型/遗物型/系统型 |
| 金手指反噬 | 使用它会损失什么 |
| 三大支点 | 人物支点、世界支点、悬念支点/金手指支点 |
| 第一卷终点 | 15—20万字内要完成的卷级高潮 |
| 10万字节点 | 10万字后安排一次大满足/大反转/大胜利 |
| 伏笔答案表 | 所有悬念先写答案，再决定何时抛出 |

---

## 2.2 单章任务卡

每章开写前填写：

| 字段 | 执行要求 |
|---|---|
| 本章目标 | 主角本章想得到什么，必须具体 |
| 本章阻力 | 谁/什么规则挡他 |
| 动作链 | 至少3步动作，每步有目的 |
| 物理反馈 | 每个关键动作给出可感知反馈，科武必须有量感 |
| 爽点类型 | 解谜/求生/复仇/晋升/打脸/情感/真相/体系崩塌 |
| 代价 | 体能、寿命、权限、名誉、关系、道德、装备损耗 |
| 本章钩子 | 一个具象未解决问题 |
| 读者预期 | 本章主要是“设期待”还是“满足期待” |
| 失败后果 | 主角如果失败，会失去什么 |
| 下一章推力 | 读者为什么会点下一章 |

# 3. 开篇1—3章执行模板

## 3.1 前三章必须命中至少5项

| 要素 | 执行动作 |
|---|---|
| 处境不满 | 让主角在现场被压制，不要旁白说惨 |
| 共情理由 | 让读者看到他不是无能，而是被规则卡死 |
| 不公伤害 | 给出一次具体剥夺：除名、断供、罚款、通缉、吊销资格 |
| 危险逼近 | 倒计时、追捕、失控实验、兽潮、审判令 |
| 金手指出现 | 不是“叮”，而是异常接口、禁用协议、残缺武碑、神经回声 |
| 短期目标 | 活过今晚、拿回权限、救一个人、通过试炼、逃出封锁区 |
| 情节钩子 | 章末留下具象未解项 |

---

## 3.2 《科武纪元》前三章建议结构

### 第1章：压迫现场 + 短期目标

动作：

1. 主角被旧武修身份羞辱/剥夺资格。
2. 科技规则当场碾压武道。
3. 主角发现异常接口或真气数据残影。
4. 章末出现危险倒计时。

物理反馈：

- 神经接口刺入脊柱，有0.3秒延迟。
- 外骨骼液压杆过热，温度飙到83℃。
- 真气在经脉里像断续电弧，无法成环。
- 武备系统警报声压过心跳。

章末钩子：

> 禁用武备舱自动开启，屏幕上弹出一行旧纪元文字：  
> “第九武脉，仍有生命反应。”

---

### 第2章：主角主动违规 + 金手指负价值

动作：

1. 主角为了活命/救人/夺回资格，主动黑入系统。
2. 金手指响应，但方式违背主角价值观。
3. 他获得短暂力量，同时暴露位置。
4. 敌方系统锁定他。

代价：

- 神经烧灼。
- 武者尊严受损：他必须借科技才能动用武道。
- 数据权限被标红。
- 被监察系统列为异常个体。

章末钩子：

> 他刚关掉接口，腕骨下方却浮出一串倒计时：  
> 【武脉归零：23:59:59】

---

### 第3章：小爽 + 更大危机

动作：

1. 主角用新机制赢下一场不可能赢的小冲突。
2. 读者获得第一次满足。
3. 胜利留下副作用。
4. 更高层敌人或更深真相露面。

代价兑现：

- 赢了对手，但暴露旧武脉。
- 救了人，但被全城系统追踪。
- 获得权限，但权限来自敌方核心。

章末钩子：

> 监察司的黑车停在巷口。  
> 车门打开，走下来的不是执法者，而是三年前亲手废掉他武籍的老师。

# 4. 支点生成规则

每本书至少准备3个能独立长剧情的支点。

## 4.1 人物支点

格式：

> 正向期待 + 反向负价值

示例：

- 旧时代武修，却只能靠科技接口续命。
- 最强武道天才，却被系统判定“无修炼价值”。
- 憎恨神朝的人，却觉醒了帝国核心协议。

可生成剧情：

- 身份暴露。
- 被迫合作。
- 尊严与生存冲突。
- 旧武道与新科技融合。

### 短故事/狼人篇可借点

人物支点要更短更狠：

- 最像狼人的人其实是守卫。
- 最沉默的村民掌握验人线索。
- 被全村投票的人必须在一夜内自证。

### 科武长篇可借点

人物支点要能升级：

- 个体身份冲突 → 阵营冲突 → 纪元真相冲突。

---

## 4.2 世界规则支点

《科武纪元》可用规则：

1. 真气必须经过神经芯片登记，否则视为非法能量。
2. 武者不能私自突破，突破需要科技神朝批准。
3. 所有武技都被拆成算法专利，民间修炼即侵权。
4. 旧武修的经脉被判定为“低效生物线路”。
5. 科技可以模拟武道，但无法解释“武意”。

执行要求：

- 每条规则都必须制造具体冲突。
- 规则不能只摆设定，要进入考试、战斗、交易、追捕、伦理选择。

---

## 4.3 金手指支点

优先采用“负价值金手指”。

示例：

| 主角欲望 | 金手指反向设置 |
|---|---|
| 想证明纯武道不输科技 | 金手指是科技武备接口 |
| 想逃离神朝控制 | 金手指绑定神朝核心协议 |
| 想守住人性 | 金手指要求他不断删除情绪模块 |
| 想救旧武者 | 金手指需要吞噬旧武脉数据升级 |

执行规则：

- 金手指只能提供工具，不替主角做决定。
- 每次使用必须有副作用。
- 金手指升级必须靠主角冒险、推理、牺牲或战斗。

---

# 5. 单章节奏OS

每章按“三段式”执行。

## 5.1 建制：让读者知道局面

段落功能：

- 主角在哪。
- 他要什么。
- 限制是什么。
- 敌人/规则在哪里。

段落节奏：

- 2—4段内进入事件。
- 不超过300字解释背景。
- 用动作带设定。

写法示例：

> 训练舱门合上的瞬间，林烬听见锁死声。  
> 不是普通的机械锁。  
> 是监察司的军用磁锁。  
> 他看向舱外，那名考官正在删除他的考核记录。

---

## 5.2 对抗：动作升级，反馈升级

段落功能：

- 主角连续尝试。
- 每次尝试都遇到更硬阻力。
- 每个动作都有反馈。
- 代价开始显形。

动作链模板：

1. 主角尝试A，想达成目标。
2. 阻力出现，A失败或半成功。
3. 主角改用B，付出代价。
4. 敌人升级。
5. 主角用C反制，获得局部胜利或打开新坑。

物理反馈模板：

- 温度：接口升温、装甲过热、皮肤灼伤。
- 时间：倒计时、延迟、冷却、心跳频率。
- 压力：骨骼承压、气压变化、能量阈值。
- 声音：警报、金属撕裂、经脉嗡鸣。
- 视觉：蓝白电弧、红色权限锁、数据雪花。

---

## 5.3 结束：小满足或大钩子

章末禁止纯情绪句。

不合格：

> 林烬知道，一切才刚刚开始。

合格：

> 林烬刚拔掉接口，舱门外的广播响起：  
> “异常武脉确认，编号K-009，立即回收。”  
> 他低头，看见自己的名字出现在“回收名单”第一行。

---

# 6. 期待调度规则

每章标注：本章是“设期待”还是“满足期待”。

## 6.1 期待类型轮换

近10章内至少出现3种：

| 类型 | 写法 |
|---|---|
| 求生期待 | 能不能活下来、逃出去、扛过倒计时 |
| 解谜期待 | 禁区里藏着什么、旧武道为何失效 |
| 晋升期待 | 夺回资格、突破等级、获得权限 |
| 复仇期待 | 打回压迫者、揭穿陷害者 |
| 情感期待 | 救师友、守同伴、与宿敌关系变化 |
| 真相期待 | 神朝为何封锁武道、金手指是谁留下的 |
| 体系崩塌爽 | 主角用事实证明官方体系有漏洞 |

## 6.2 禁止连续3章同型爽点

错误节奏：

- 第1章打脸考官。
- 第2章打脸同学。
- 第3章打脸队长。
- 第4章打脸监察员。

修正节奏：

- 第1章：求生，逃出训练舱。
- 第2章：解谜，发现武脉倒计时。
- 第3章：小打脸，赢下不可能考核。
- 第4章：真相，老师知道旧武脉秘密。
- 第5章：代价，主角被系统通缉。

# 7. 冲突执行公式

每个冲突必须回答：

> 谁要什么？  
> 谁挡着？  
> 如果失败，损失什么？  
> 如果成功，要付出什么？

示例：

| 项 | 内容 |
|---|---|
| 谁要什么 | 林烬要拿回武籍数据 |
| 谁挡着 | 监察司AI和昔日老师 |
| 失败损失 | 永久失去修炼资格，被送进回收所 |
| 成功代价 | 暴露旧武脉，欠下黑市人情，神经接口受损 |

---

# 8. 人物口吻补丁

## 8.1 主角口吻

适合《科武纪元》主角：

- 克制。
- 不嘴碎。
- 有旧武者的硬骨头。
- 对科技有抵触，但不会无脑拒绝。
- 爽点来自“我看穿规则漏洞”，不是单纯狂吼。

主角台词示例：

> “你们把武道拆成了算法。”  
> “可惜，算法能算力，算不了骨头。”

> “我不信神朝。”  
> “但我会用它的刀，砍开它的门。”

避免：

> “哈哈哈，你们这些蝼蚁，都给我跪下！”

---

## 8.2 反派口吻

科技神朝类反派：

- 冷静。
- 制度化。
- 不承认自己邪恶。
- 喜欢用效率、秩序、风险评估压人。

反派台词示例：

> “旧武修不是罪犯。”  
> “只是高风险低产出的落后资产。”

> “你的愤怒没有登记，林烬。”  
> “所以在系统里，它不存在。”

---

## 8.3 配角口吻

配角必须有功能：

| 类型 | 作用 | 口吻 |
|---|---|---|
| 黑市技术员 | 提供工具，也制造债务 | 嘲讽、现实、价格优先 |
| 旧武师 | 提供武道信念，也隐藏旧伤 | 简短、沉重、有旧时代气 |
| 神朝考官 | 制度压迫 | 公文式、轻蔑 |
| 同伴新人 | 提供情感锚点 | 直接、害怕但不退 |
| 宿敌 | 推动主角升级 | 精准、骄傲、认可强者 |

---

# 9. 代价系统

每次爽点后必须留下一个可追踪代价。

## 9.1 可用代价库

| 代价类型 | 示例 |
|---|---|
| 身体代价 | 神经烧伤、经脉裂纹、反应延迟、寿命扣减 |
| 科技代价 | 权限暴露、接口污染、设备过热、芯片损毁 |
| 社会代价 | 被通缉、资格吊销、信用归零 |
| 情感代价 | 连累同伴、误伤旧友、被师长误解 |
| 道德代价 | 必须使用敌人技术、牺牲少数救多数 |
| 信息代价 | 得到答案，但暴露自己的坐标 |
| 阵营代价 | 借黑市力量，欠下未来无法拒绝的人情 |

## 9.2 代价兑现规则

- 小代价：1—3章内兑现。
- 中代价：5—10章内兑现。
- 大代价：卷高潮兑现。
- 禁止代价写完就忘。
- 禁止“睡一觉全恢复”。

---

# 10. 失败模式门禁

写完大纲或章节后，检查是否踩雷。

## 10.1 构思失败模式

| 失败模式 | 表现 | 修正 |
|---|---|---|
| 一句话故事模糊 | 只知道主角要变强 | 加入负价值身份和具体行动 |
| 主角被金手指推着走 | 系统发任务，主角照做 | 改成主角主动利用机制 |
| 世界观空转 | 一堆设定不进剧情 | 让规则进入考试、追捕、交易、战斗 |
| 悬念无答案 | 写到哪算哪 | 先写答案，再抛谜题 |
| 爽点单一 | 连续打脸 | 加入求生、解谜、真相、体系崩塌 |
| 没代价 | 主角赢了就完 | 胜利后立刻留下副作用 |
| 章末无钩 | 情绪收尾 | 改成具象未解项 |
| 前三章太慢 | 介绍世界观太久 | 用事件展示设定 |
| 主角太被动 | 被抓、被救、被安排 | 给他违规动作和主动选择 |
| 科技感不足 | 名词像贴皮 | 增加反馈、量纲、设备逻辑 |

---

# 11. 章末钩子库

## 11.1 具象钩子类型

| 类型 | 示例 |
|---|---|
| 倒计时 | 武脉归零：23:59:59 |
| 未读消息 | 来自已故师父的加密邮件 |
| 敌人现身 | 废他武籍的人站在门口 |
| 实体悬念 | 舱底有一截仍在跳动的机械经脉 |
| 身份暴露 | 系统广播他的旧纪元编号 |
| 任务反转 | 他救出的人其实是通缉源头 |
| 地点开启 | 禁区地图自动解锁第九层 |
| 权限异常 | 他获得了只有皇室才有的Root权限 |
| 道德困境 | 要救同伴，必须删除一城旧武者档案 |
| 真相碎片 | 官方历史里不存在的“第零次武道灭绝” |

# 12. 段落节奏补丁

## 12.1 男频科武推荐段落节奏

- 一段尽量短。
- 重要动作单独成段。
- 反转句单独成段。
- 设定不要连续堆超过3段。
- 打斗中每3—5段给一次结果反馈。
- 解谜中每500—800字给一个新线索或新阻力。

## 12.2 段落功能排序

推荐顺序：

1. 动作。
2. 反馈。
3. 判断。
4. 选择。
5. 代价。
6. 新问题。

示例：

> 林烬把掌心按上接口。  
>   
> 冰冷的针束刺入皮下，神经延迟瞬间飙到0.7秒。  
>   
> 太慢。  
>   
> 他咬断舌尖，用痛觉强行拉回反应。  
>   
> 下一秒，右臂经脉传来撕裂声。  
>   
> 屏幕却亮了。  
>

# 13. 发布 / 包装 / 风险门禁

平台规则不直接写进剧情，转成发布动作和风险门禁。

## 13.1 发布门禁

| 节点 | 门禁要求 |
|---|---|
| 开书前 | 一句话故事过关；前三章钩子明确 |
| 1—3章 | 每章末必须有具象钩子 |
| 3万字 | 至少完成一次小高潮，确认主角核心卖点 |
| 5万字 | 金手指机制、世界规则、主角欲望全部清楚 |
| 10万字 | 完读生死线，必须准备卷级高潮前置拉力 |
| 10万字后 | 安排一次大满足/大反转/大胜利 |
| 15—20万字 | 第一卷收束，完成阶段性目标，同时打开更大卷钩 |

---

## 13.2 包装门禁

书名、简介、前三章要复用最强支点。

可包装方向：

| 支点 | 包装方式 |
|---|---|
| 人物反差 | 《旧武修的我，被迫接入神朝系统》 |
| 世界规则 | 《武道违法后，我黑进了神朝武库》 |
| 金手指 | 《我的真气能篡改科技协议》 |
| 悬念 | 《第九武脉为何仍在跳动》 |
| 阵营冲突 | 《科技神朝里的最后武夫》 |

简介必须包含：

- 主角负价值身份。
- 世界压迫规则。
- 主角主动行动。
- 一个强钩子。

---

## 13.3 风险门禁

| 风险 | 检查方式 | 处理 |
|---|---|---|
| 前三章跳出 | 是否太多设定、太少事件 | 删设定，提前危机 |
| 10万字疲软 | 是否没有卷级目标 | 提前布置大敌、大谜、大代价 |
| 科幻谜题崩坏 | 悬念是否无答案 | 建立伏笔答案表 |
| 爽点疲劳 | 是否连续同类爽点 | 轮换解谜/求生/晋升/真相 |
| 主角工具人 | 是否系统推着走 | 改为主角主动违规、破解、选择 |
| 金手指太万能 | 是否无代价解决问题 | 增加冷却、暴露、副作用、伦理损耗 |
| 设定太硬 | 是否连续解释 | 用冲突展示设定 |
| 卷尾无余味 | 是否只赢不变局 | 赢一场，打开更大敌人或真相 |

# 14. 章节自检清单

每章写完后逐项打勾。

## 14.1 基础自检

- [ ] 本章主角有明确目标。
- [ ] 本章存在具体阻力。
- [ ] 主角至少主动行动3次。
- [ ] 每个关键动作有物理反馈。
- [ ] 冲突能回答“谁要什么 / 谁挡着 / 代价是什么”。
- [ ] 本章不是纯设定说明。
- [ ] 本章不是纯过渡。
- [ ] 本章至少完成一次期待设置或期待满足。
- [ ] 本章爽点类型已标注。
- [ ] 近3章没有重复同一种爽点。

## 14.2 科武质感自检

- [ ] 科技元素不是贴皮，参与了冲突。
- [ ] 武道元素不是口号，参与了动作和代价。
- [ ] 至少出现一种可感知反馈：温度、压力、延迟、声响、光效、疼痛、数据异常。
- [ ] 金手指没有替主角做决定。
- [ ] 使用金手指后留下副作用。
- [ ] 世界规则对主角造成具体限制。
- [ ] 设定通过事件展示，而不是连续讲解。

## 14.3 章末钩子自检

- [ ] 章末有一个具象未解问题。
- [ ] 钩子不是纯情绪。
- [ ] 钩子能自然推动下一章。
- [ ] 钩子与本章冲突有关。
- [ ] 读者能立刻明白“下一章要看什么”。

## 14.4 代价自检

- [ ] 本章胜利不是白拿。
- [ ] 代价已记录到后续兑现表。
- [ ] 代价不会被立刻无条件抹平。
- [ ] 代价会影响人物关系、身体状态、权限、资源或阵营。

# 15. 作者交稿强制格式

之后《科武纪元》每章大纲建议按此表交付：

| 字段 | 内容 |
|---|---|
| 章节名 | 例如：非法武脉 |
| 本章目标 | 林烬要从训练舱逃出并保住武籍数据 |
| 阻力 | 监察司AI锁舱，考官删除记录 |
| 动作链 | 1. 强接接口；2. 用真气干扰识别；3. 黑入备份端口；4. 反锁舱门 |
| 物理反馈 | 神经延迟0.7秒；接口升温83℃；右臂经脉撕裂 |
| 爽点类型 | 求生 + 体系漏洞爽 |
| 代价 | 暴露旧武脉编号；右臂暂时失控 |
| 本章钩子 | 系统广播“K-009异常武脉，立即回收” |
| 伏笔 | K-009对应第九武脉 |
| 后续兑现 | 3章内监察司追捕；卷尾揭开第九武脉来源 |

# 16. 最终执行口令

写《科武纪元》时，每章默认问自己：

> 主角这章主动做了什么？  
> 世界规则怎样压他？  
> 他用什么办法破局？  
> 身体和系统给了什么反馈？  
> 他赢了什么？  
> 他付出了什么？  
> 读者下一章想看哪个具体问题的答案？

只要其中任意一项答不上来，本章打回重构。
