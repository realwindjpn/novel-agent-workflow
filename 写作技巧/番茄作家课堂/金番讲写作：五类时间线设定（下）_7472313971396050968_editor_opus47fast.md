# 《金番讲写作：五类时间线设定（下）》编辑学习笔记

> 来源：番茄作家课堂 / 任欢游 / 2025-02-18
> 适用：长篇科幻《科武纪元》、短故事、热点稿
> 本文只覆盖"下篇"的两类时间线：**纯循环** + **多线并行**

---

## 1. 课程核心判断（6条）

1. **循环时间线 = 低门槛高戏剧密度工具**：不需要复杂世界观，只要"周期 + 主角目标 + 逻辑自洽"三件套即可成立。
2. **循环 ≠ 读档**：循环是整段周期重置，读档是节点跳跃；二者节奏感和悬念结构不同，不能混用同一套写法。
3. **循环要给主角一个"必须解开的死结"**（被害、出轨、记忆错乱），否则循环只是重复，不是戏。
4. **"多线并行"在本文里被重新定义**：不是过去/现在交叉叙事，而是**两种时间线机制并存于同一世界观**（顺叙×循环、顺叙×读档等的排列组合）。
5. **双线世界必须制造"身份/资源/权力反差"**（现实社畜 vs 梦中首富），反差越大可写情节越多。
6. **多线 + 马甲 = 情感拉扯放大器**：同一角色在两条线上拥有两个身份，是制造误会、暗恋、敌对反转的最高效结构。

---

## 2. 可执行编辑规则

### 开篇
- 循环类开篇必须在**第一章末或第二章头**完成首次"死亡/失败/重置"，让读者立刻知道游戏规则。
- 多线并行类开篇要在**前3章内交代两条线的时间机制差异**（流速、是否重置、是否互通），否则读者会按顺叙阅读，造成认知错位。

### 节奏
- 单次循环时长建议 **1日 / 5日 / 7日**，超过会让读者记不住节点。
- 每次循环必须**新增1条线索 + 推翻1条旧判断**，否则视为水文。
- 多线并行：现实线与异界线**章节比例不要劣于 2:3 或 3:2**，一边塌陷读者会弃。

### 冲突
- 循环里"阻止失败"要**升级式**：劝说 → 强行阻拦 → 极端手段 → 反向加害（女主为救老公而杀老公）。
- 反转点放在"主角以为找到真相"之后，而不是循环初期。
- 多线并行的核心冲突应源于**两条线的目标互斥**（解开异界 vs 留住异界身份）。

### 人物
- 循环主角必须背负**信息不对称特权**（只有TA记得），其他人物的"无知"是戏剧燃料，不要轻易让配角也进入循环。
- 多线主角需要**两套行为逻辑**：现实人格 + 异界人格，二者差异要在文本里被显性写出（说话方式、风险偏好）。

### 题材
- 循环 + 悬疑言情：适合中短篇/热点稿，结构干净。
- 循环 + 纯言情：靠"误会—线索—和解"驱动，适合女频。
- 多线 + 科幻/游戏：适合长篇，可承载马甲、阵营、装备体系。

### 改编（衍生 / 短剧 / 热点稿适配）
- 循环结构天然适配**短剧切片**：每个循环=一集，结尾死亡=钩子。
- 热点稿可截取"单次循环"做独立小故事，不依赖前情。
- 多线并行结构难做短剧切片，建议保留给长篇主线。

### 平台规则（番茄向）
- 循环类要**前3章给出"为什么循环"的钩子**（哪怕是伪答案），否则留存差。
- 多线类要**避免开篇大段世界观倾倒**，用人物动作把规则演出来。
- 双线反差越极端（首富↔1500月薪），点击数据越好，但要在前10章内完成两线交汇预告。

## 3. 科武适配

### ✅ 可用点
- **"武道闭关周期"=天然循环载体**：一次闭关=一次循环，失败则吐血重来，记忆保留——非常契合"科技+武道"设定。
- **科技副本/模拟器训练舱**做读档或循环：主角在舱内反复推演杀招，舱外时间正常推进 → 直接落地"多线并行"。
- **双身份反差**：现实科研体制内底层研究员 ↔ 模拟器内武道宗师，强烈反差适合长线连载。
- **马甲机制**：科武世界里"实战编号"与"现实姓名"分离，可复用本文情感拉扯模型用于战友/对手关系。
- 循环升级链（劝阻→阻止→极端）可直接套用在**阻止某次科武实验事故**的支线上。

### ⚠️ 不可硬套点
- **纯爱向"老公出门必死"模板** → 与硬核科武调性冲突，不要照搬。
- **"初恋五十次"式失忆循环** → 偏女频言情，科武主线不适合，可放在感情副线点到为止。
- **删档/重新攻略**这种轻量化游戏梗，会稀释"科武"严肃感，慎用。
- 多线并行如果两条线都是高强度战斗线，会让读者疲劳，必须有一条是"低烈度生活/科研线"做呼吸。
- 循环时长不宜超过7日：科武体系里招式/功法演化复杂，太长读者会失焦。

## 4. 编辑检查表（10条）

1. [ ] 循环规则是否在前3章被明确告知读者？
2. [ ] 每个循环是否新增≥1条线索，并推翻≥1条旧结论？
3. [ ] 主角的"循环目标"是否一句话能说清？
4. [ ] 阻止/解谜行为是否呈**升级链**而非平铺？
5. [ ] 是否设置了至少一次"主角自以为破局却失败"的反转？
6. [ ] 多线并行的两条线机制差异（流速/重置/互通）是否文本显性化？
7. [ ] 双线人物是否有可辨识的两套行为/语言模式？
8. [ ] 双线反差强度是否足以支撑后续30+章情节？
9. [ ] 结局是否锁定？（循环类必须先想结局再倒推线索）
10. [ ] 是否有"短剧/热点稿"可切片的最小故事单元？

---

## 5. 对作家角色的输入要求

> 提交科武章节时，作家需在大纲/章纲里提供以下5项，缺一项编辑可打回。

- **动作链**：主角在本次循环/本条线里的关键动作序列（≥3步，含决策点），例如"潜入实验室 → 触发警报 → 启用武道身法逃脱 → 被记录 → 下次循环规避"。
- **物理反馈**：每个关键动作的身体/环境代价——内力反噬几许、护具损耗、设备过热、时间流速差导致的生理紊乱，必须可量化或可感知。
- **代价**：循环/穿越/多线行为的**不可逆损失**（记忆缺片、寿元、信任值、阵营敌意），代价必须随循环次数累积，否则读者会觉得"无敌"。
- **钩子**：本章末必须留 **1悬念 + 1预告**（悬念指向当前循环未解，预告指向下一循环/另一条线的变化）。
- **读者预期管理**：明确写出本章"读者会以为发生X，实际发生Y"——若没有错位，章节视为信息流而非情节。

---

**一句话总结**：循环给戏剧密度，多线给世界纵深；《科武纪元》宜用"训练舱循环 + 现实顺叙"双线结构，把武道修炼的"重来"与科技体制的"不可逆"做成主冲突。
