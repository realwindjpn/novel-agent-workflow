# 《科武纪元》编辑学习官｜课程提炼与执行手册

## 1 课程核心判断（≤6条）
1. **数据透明化即创作指挥棒**：番茄后台的完读率、跟读率、追更数据已取代主观判断，成为内容迭代的唯一客观基准。
2. **方法论反噬风险**：过度依赖“写作公式”会扼杀创作本能；基础框架+作者惯性/激情才是维持长篇生命力的底层逻辑。
3. **新书零和博弈**：历史成绩不产生流量继承，每次开书均为冷启动，开局即进入平台算法考核期。
4. **争议题材的叙事反噬**：为追求现实映射或情绪对立引入极端冲突，易导致读者撕裂、被迫改文、破坏主线连贯性。
5. **持续输出＞单本爆发**：长篇核心竞争力是“滔滔不绝”的稳定产能与节奏控制，而非依赖单本运气。
6. **外部引流权重衰减**：算法推荐时代，内容自身的“钩子密度”与“数据留存”决定初始流量池，自媒体运营无法替代正文质量。

## 2 可执行编辑规则
| 维度 | 执行规则（基于原文提炼） |
|:---|:---|
| **开篇** | 前3章必须完成“核心设定抛出+主角动机确立+首个强危机”。放弃慢热铺垫，直接切入首秀数据考核期（10万字内定生死）。 |
| **节奏** | 以“完读率”为节拍器。每章结尾强制留悬念（断章技巧）；每10-15章设置一次信息释放或小高潮，严禁连续3章无实质性推进。 |
| **冲突** | 冲突必须服务于主线推进，禁止为制造话题引入脱离世界观的极端对立。冲突解决需伴随明确代价，禁用机械降神或情绪化妥协。 |
| **人物** | 摒弃“证明型”人设（为炫技强加高光），采用“本能型”驱动（人物按自身认知与生存逻辑行动）。保留作者擅长的心理/行为惯性，减少模板化套用。 |
| **题材** | 科幻/科武类需“设定轻量化”。核心规则在前5万字内完成自洽，后续以剧情带设定，避免大段说明书式科普拖慢跟读率。 |
| **改编** | 预留“视觉化锚点”（标志性武器/机甲/功法/场景）。剧情结构采用“单元副本+主线推进”模式，便于后期分季/分集拆解与IP转化。 |
| **平台规则** | 严格遵循番茄数据逻辑：追更率>60%、完读率>40%为健康线。数据下滑立即自查三要素：钩子失效？节奏拖沓？人设OOC？不依赖外部推广，聚焦正文留存。 |

## 3 科武适配
### ✅ 可用点
- **设定轻量化+剧情带设定**：完美契合《科武纪元》“科技树+武道体系”双线，避免硬核科普劝退，用战斗/探索自然释放设定。
- **数据驱动迭代**：适用于长篇连载的战力膨胀控制、地图切换节奏与副本难度曲线调整。
- **本能型人物驱动**：适合科武主角的成长弧光（从生存本能→武道/科技信仰→体系重构），减少“作者强行安排”的割裂感。
- **单元剧+主线结构**：天然适配科武的“遗迹探索/战区推进/机甲升级”模式，便于控制单卷篇幅与读者预期。

### ⛔ 不可硬套点
- **“别被方法束缚/激情创作”**：科武长篇需严谨的“力量体系/科技树/物理规则”底层逻辑，不能完全依赖直觉，必须前置大纲、设定集与战力换算表。
- **“规避争议防反噬”**：科武题材本身偏中性/硬核，无需刻意回避思想碰撞，但需将争议严格限制在“世界观内自洽”范畴，避免现实情绪投射引发审核风险。
- **“自媒体引流”**：原文提及的早期社媒推广在番茄算法时代已失效，科武作者不应分散精力至外部运营，应聚焦章说互动、段评维护与平台内推荐逻辑。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章内是否明确主角核心目标与首个生存/战斗危机？
- [ ] 每章结尾是否设置有效悬念或信息增量（非情绪断章）？
- [ ] 核心科幻/武道设定是否已融入剧情动作，而非独立说明段落？
- [ ] 连续3章是否无实质性剧情推进或战力/认知升级？（是则预警）
- [ ] 冲突解决是否伴随明确代价（资源损耗/身体损伤/阵营关系变化）？
- [ ] 人物决策是否符合其当前认知与性格逻辑，无“作者强行降智/开挂”？
- [ ] 数据面板（完读/跟读）是否出现连续下滑？下滑节点是否对应剧情平淡期？
- [ ] 是否预留了可视觉化的标志性元素供后续改编？
- [ ] 新书开局是否已清空“过往成绩”心态，按零流量冷启动标准执行？
- [ ] 争议性情节是否已做“世界观内自洽”处理，避免现实情绪投射？

## 5 对作家角色的输入要求
| 维度 | 执行标准（科武向） |
|:---|:---|
| **动作链** | 战斗/操作必须遵循“感知输入→神经/AI演算→肌肉/机械执行→环境反馈”闭环。禁止“意念一动直接秒杀”。科武融合需体现“科技辅助（外骨骼/义体/战术AI）+武道发力（筋骨/气血/呼吸法）”的协同逻辑，动作描写需有先后次序与发力支点。 |
| **物理反馈** | 每次高强度对抗必须留下可量化的痕迹（装备耐久下降、肌肉撕裂、能量过载、环境破坏、重力/气压影响）。反馈需即时呈现，并作为下一章状态调整、战术切换或资源补给的前置条件。 |
| **代价** | 任何越级挑战、底牌释放或捷径获取，必须支付对等代价（寿命折损、神经负荷、资源枯竭、阵营敌对、系统反噬）。代价需具象化、可追踪，不可用“休息一下/喝瓶药”模糊处理。代价累积需推动剧情转折。 |
| **钩子** | 每章末钩子需为“未解信息+迫近威胁”组合（例：AI提示能量仅剩3%，但前方闸门已开启/未知生物已锁定坐标）。禁用纯情绪宣泄、日常过渡或开放式留白。钩子必须在3章内兑现或升级。 |
| **读者预期** | 明确本阶段核心期待（升级/解谜/复仇/阵营战/体系突破）。每10章必须兑现一次预期（小高潮/信息释放），同时抛出下一阶段新预期。严禁“画饼不兑现”或“预期频繁跳跃”。预期管理需与平台数据节点（首秀/推荐位）强绑定。 |
