# 《科武纪元》编辑学习官｜《开书准备》硬核规则提取

## 1 课程核心判断（≤6条）
1. **主线极简**：全书驱动力必须能用一句话（≤15字）精准概括，禁止多线并行稀释焦点。
2. **世界观镜像构建**：先立正派体系，再按逻辑推演反派势力、地图与资源树，共存/对抗需有硬性理由。
3. **体系量化防崩**：晋级门槛、战力差、待遇跃升必须前置设定，用实战数据锚定读者认知。
4. **金手指边界**：金手指是“放大器”非“代打器”，主角核心能力（智谋/意志/技术）不可替代。
5. **人设功能化**：主角带明确短板，配角补位；反派需高智商决策链；新手期严禁群像与作者价值观输出。
6. **卷纲控场**：卷纲＞大纲。以“目标-破局-小BOSS-新线索”为单元切割剧情，大纲仅留主线防偏航。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提取） | 长篇/短故事/热点稿适配说明 |
|:---|:---|:---|
| **开篇** | 首卷/首章必须亮出主线目标、第一阶段敌人与金手指基础规则；3章内完成核心冲突建立。 | 短故事/热点稿压缩至1章内完成“冲突+规则+钩子”闭环。 |
| **节奏** | 以卷纲为节拍器，每单元完成“锁定目标→组队/破局→击败小BOSS→解锁新线索”闭环，严禁跨单元拖沓。 | 短故事按“起承转合”4节点切分；热点稿按“事件爆发→介入→反转→落点”切分。 |
| **冲突** | 冲突源于势力/资源博弈；反派决策需独立逻辑链，禁止降智衬托；胜负靠体系规则与主角能力兑现。 | 热点稿冲突需绑定现实情绪锚点（如公平/生存/阶层），避免架空悬浮。 |
| **人物** | 主角“1长板+1短板”；配角功能互补；反派强则主角爽；砍掉冗余支线与作者私货。 | 短故事/热点稿人物≤3个核心，其余工具化；人设靠行为而非台词立住。 |
| **题材** | 体系设定前置量化（如等级换算、资源门槛）；晋级需明确硬性条件与待遇跃升。 | 科幻/现实题材均需“规则可视化”，杜绝模糊升级或机械降神。 |
| **改编** | 势力地图、科技/修炼树模块化；单卷可独立成副本；技能/装备需具象化便于视觉转化。 | 预留“单元剧接口”，便于后期IP拆分、短剧改编或热点二创。 |
| **平台规则** | 番茄重快节奏与明确爽点；大纲仅留主线，卷纲灵活适配推荐流；金手指不喧宾夺主保追读。 | 短故事/热点稿需首屏抓人（前300字定调），完读率＞留存率，钩子密度按平台推荐周期设置。 |

## 3 科武适配
### ✅ 可用点
- **主线精简**：直接套用“底层武者融合古武与星舰科技，突破财阀封锁，重定星际武道秩序”类单核驱动。
- **体系量化**：武道境界与机甲/基因改造等级严格换算（例：武师级肉身可硬抗轻型脉冲炮，需明确能量阈值/护甲穿透参数）。
- **金手指克制**：如“古武神经同步数据库”或“算力增幅义体”，仅提供路径/演算，战斗决策、肉身苦修、资源调度仍靠主角。
- **卷纲控场**：每卷聚焦一个星区/势力/科技树节点，闭环推进，避免科幻设定堆砌导致节奏失速。

### ⛔ 不可硬套点
- **封建权谋模板**：原文“朝廷vs江湖/皇子夺权”需升级为“星际财阀/联邦/深空遗迹/异星生态”多维博弈，科幻核心是资源、规则与技术代差，非人情世故。
- **纯冷兵器战力换算**：“1武者打2士兵”在科武语境会显得儿戏。必须引入能量护盾衰减率、重力环境、神经负荷、弹药/冷却周期等变量。
- **商会遗孤复仇**：需替换为“技术垄断/基因序列/航道控制权/算力霸权”争夺，避免用传统武侠人情逻辑驱动科幻主线。

## 4 编辑检查表（10条以内）
1. [ ] 主线是否可用15字以内一句话清晰表述？
2. [ ] 力量体系是否已量化晋级门槛、战力差与对应待遇/权限？
3. [ ] 金手指是否明确“辅助边界”，主角剥离金手指是否仍具破局能力？
4. [ ] 首卷/首章卷纲是否包含“目标-破局-小BOSS-新线索”完整闭环？
5. [ ] 主角是否具备1个核心长板与1个功能性短板？
6. [ ] 反派决策是否具备独立逻辑链，无降智衬托主角？
7. [ ] 势力/地图/科技树是否完成正反派镜像对照与共存逻辑？
8. [ ] 是否已剔除新手期群像线与作者个人价值观说教？
9. [ ] 每章末/卷末是否预留明确钩子与下一阶段转场接口？
10. [ ] 开篇3章内是否已亮出核心冲突、体系基础与金手指规则？

## 5 对作家角色的输入要求
- **动作链**：战斗/破局必须拆解为“感知→决策→发力→命中→反制”连贯步骤。禁止跨级无逻辑越阶、意念秒杀或跳过物理交互过程。
- **物理反馈**：每次体系跃升、金手指激活或越阶对抗，必须伴随可观测的物理/生理变化（如肌肉纤维撕裂重组、神经突触过载灼痕、机甲接口熔毁、重力环境下的骨骼承压）。杜绝纯数值播报或“突然变强”。
- **代价**：金手指使用、越阶战斗、势力结盟必须支付明确代价（如寿命折损、信用点/能源透支、阵营仇恨值累积、基因排异、义体神经磨损）。代价需直接推动下一卷纲节点或制造新冲突。
- **钩子**：每章末/卷末必须设置“信息差悬念”或“资源/目标倒计时”。禁止纯情绪收尾或开放式留白。钩子需直接关联下一卷纲目标，且具备可兑现性。
- **读者预期**：开篇需明确承诺“核心爽点类型”（如硬核升级/智斗破局/科技碾压/武道重构）。后续剧情兑现率需≥80%，严禁中途切换题材基调、稀释主线或临时追加未铺垫的设定。短故事/热点稿需在首屏完成预期锚定，后续严格按承诺交付。
