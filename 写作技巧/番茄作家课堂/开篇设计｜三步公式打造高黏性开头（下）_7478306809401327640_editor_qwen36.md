# 《科武纪元》编辑学习官：开篇设计规则提炼

## 1 课程核心判断（≤6条）
1. **零冗余原则**：开篇所有描写、人物、对话必须直接推动剧情或立人设，无推动性文字一律删除。
2. **反预期留存**：打破读者惯性预测，通过认知失衡与反套路转折制造追读黏性。
3. **强绑定驱动**：核心人物间需预设天然矛盾或强关联（血仇/利益/理念对立），提供持续剧情推力。
4. **感官与锚点记忆**：五感沉浸描写+数字/道具锚点，是快速建立作品辨识度与IP符号的核心手段。
5. **动态极简切入**：以动作/危机开场，首章出场人物≤3，避免信息过载导致焦点涣散。
6. **缺陷即引擎**：拒绝完美人设，性格/身份/能力缺陷是制造冲突、推动剧情与增强趣味性的底层燃料。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 编辑执行标准 |
|:---|:---|
| **开篇** | 首段必须为动态场景（动作/危机/强对话）；禁用纯景物/背景铺陈；前300字内抛出核心悬念或失衡点。 |
| **节奏** | 每1-2万字设置一次反套路转折；利用数字锚点（倒计时/期限/阈值）制造天然紧迫感；段落信息密度需与剧情推进严格匹配。 |
| **冲突** | 开篇即制造“10%表象+90%暗线”的认知失衡；冲突必须具象化（物理/利益/认知层面），禁用抽象情绪对抗。 |
| **人物** | 首章聚焦1个核心人设，带明确缺陷/执念；用标志性道具/外貌特征强化记忆；人物动机需与开篇危机直接挂钩。 |
| **题材** | 科幻/悬疑类需压缩世界观说明，将设定拆解为“危机中的道具/规则/代价”自然露出；避免开篇大段设定科普。 |
| **改编** | 五感爆破描写需具备影视分镜转化潜力（声/光/触觉具象化）；数字/道具锚点需具备视觉符号化特征；人物强关系网降低支线删改成本。 |
| **平台规则** | 番茄重“黄金三章”与追读率，开篇需直给核心卖点；短故事/热点稿首段即爆点，禁用慢热铺垫；长篇需预留“钩子-转折-新钩子”循环结构。 |

## 3 科武适配
### ✅ 可用点
- **动态危机切入**：机甲暴走、基因锁过载、武道考核生死战、星舰跃迁故障等，天然契合“动作+悬念”开篇。
- **反套路设计**：传统武道升级反转为“科技降维打击”或“武道反噬义体”；打破“强者碾压”预期，引入规则杀/逻辑杀。
- **数字/道具锚点**：如“基因崩溃倒计时72小时”“武道碑文残片”“神经接驳阈值99%”，强化科幻硬核感与追读紧迫感。
- **五感沉浸**：金属摩擦高频音、能量灼烧神经的刺痛感、失重眩晕、义体排异的肌肉痉挛，提升科武世界观真实度。
- **人物强绑定**：科武理念冲突（纯肉体进化 vs 机械飞升）、阵营对立、师徒理念决裂，天然提供长线矛盾。

### ❌ 不可硬套点
- **纯情感替身/虐恋模板**：科武主线重力量体系与世界观演进，情感线需服从主线逻辑，不可喧宾夺主。
- **过度依赖“对话切入”**：科幻需设定支撑，纯对话易显空洞，必须结合环境/动作/物理反馈同步展开。
- **为转而转破坏自洽**：长篇科幻的转折需服从科学/武道底层逻辑，不可牺牲设定严谨性换取短期爽感。
- **缺陷人设泛化**：“绿茶/躁郁”等网文标签需转化为科武语境下的“基因缺陷/义体排异/武道心魔”，否则违和。

## 4 编辑检查表（10条以内）
1. [ ] 首段是否为动态动作/危机/强对话切入？（静态景物描写直接标红）
2. [ ] 前2000字出场人物是否≤3人？（超员需合并或延后出场）
3. [ ] 是否删除所有不推动剧情/不立人设的背景/设定说明？
4. [ ] 是否包含至少1个明确悬念或认知失衡点？
5. [ ] 主角是否带明确缺陷/执念，且与开篇危机直接绑定？
6. [ ] 是否设置数字/道具锚点（倒计时/标志性物品/生理阈值）？
7. [ ] 核心人物间是否存在强关联/天然矛盾（非偶然相遇）？
8. [ ] 前3章是否预留至少1次反套路转折或信息反转？
9. [ ] 五感描写是否服务于沉浸感而非辞藻堆砌？
10. [ ] 科武核心卖点（力量体系/主线目标/世界观规则）是否在首章清晰露出？

## 5 对作家角色的输入要求
| 维度 | 编辑强制输入标准 |
|:---|:---|
| **动作链** | 必须提供“触发→生理反应→决策→执行→结果”的连贯序列。禁用静态心理独白替代动作。例：`警报频闪→瞳孔收缩/肾上腺素飙升→切断安全协议→能量过载→规避/反击`。 |
| **物理反馈** | 所有能力使用/环境交互必须附带肉体/机械的直接作用描写（痛觉、温度、重力、神经刺痛、肌肉撕裂、义体排异）。禁用“他感到害怕/强大”等抽象情绪词。 |
| **代价** | 每次关键行动/能力突破必须标注即时或延迟代价（能量枯竭、寿命折损、基因崩溃、社会性死亡、信任破裂）。禁止无代价开挂或“唯心突破”。 |
| **钩子** | 每章末尾/关键节点必须设置“未解信息+行动受阻”双钩子。禁用开放式抒情/总结性结尾。钩子需直接关联下一章核心动作。 |
| **读者预期** | 开篇前500字必须明确承诺类型标签（硬核科幻/武道升级/悬疑解谜），并在前3章兑现至少1个核心设定展示。禁止“文不对题”或“设定隐身”。 |
