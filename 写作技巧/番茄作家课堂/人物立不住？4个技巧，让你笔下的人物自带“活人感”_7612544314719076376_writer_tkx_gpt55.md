# 《科武纪元》作家OS补丁  
## 补丁名：人物活人感 v1.0  
用途：把人物从“剧情工具”升级为“有过往、有欲望、有反应、有代价的活人”。

---

## 0. 本补丁执行原则

写人物时，不再问：

> “这个人接下来要干什么？”

改问：

> “他为什么只能这样干？他这样干会失去什么？读者凭什么相信他是活人？”

---

# 1. 核心执行动作

## 1.1 人物出场：必须带“过往钩子”

### 执行动作

角色第一次正式出场时，至少安排：

1. 一个异常动作  
2. 一个拒绝解释  
3. 一个可复用物件/习惯/身体反应  

### 可直接套用格式

```text
他看到【物件/场景】时，手指停了一瞬。
旁人问：“你认识这个？”
他把【物件】推回去，只说：“不重要。”
但他的【身体反应/HUD/内息/机械接口】已经暴露了异常。
```

### 科武可用物件

- 断裂芯片
- 旧纪元军牌
- 烧毁的义体接口
- 失效的武道铭牌
- 祖传断剑
- 基因锁编号
- 冷冻舱编号
- 母体录像残片
- 神经接驳疤痕
- 禁武区通行证

### 禁止写法

```text
他其实小时候经历过一场事故，所以现在很痛苦。
```

这是说明书，不是人物。

---

## 1.2 情绪表达：禁用“他很生气/很难过/很害怕”

### 替代动作

每次关键情绪，至少写下面三项中的两项：

| 项目 | 写法 |
|---|---|
| 动作微反应 | 指尖收紧、瞳孔缩小、肩膀僵住、刀柄被攥出响声 |
| 生理/物理反馈 | 呼吸断拍、HUD闪烁、义体过载、内息逆冲、温度下降 |
| 反差台词 | 明明愤怒却说“没事”；明明害怕却笑；明明心软却下令开火 |

### 可执行句式

```text
他没有立刻回答。
HUD上的心率红线跳了一下，又被他强行压回绿色。
“继续。”他说。
```

```text
她笑了一声。
可握枪的手指白得像是刚从冷冻舱里拔出来。
```

---

## 1.3 关键选择：必须能追溯到过往

任何人物做出重大选择前，先补一条“过往因”。

### 写作流程

```text
当前事件刺激 → 触发旧伤/执念 → 人物产生本能反应 → 他做出选择 → 付出代价
```

### 示例

错误：

```text
林曜突然决定救下敌人。
```

修正：

```text
敌人的少年兵摘下面罩时，露出一枚旧纪元童兵编号。
林曜的视线停在编号后三位。
那是他弟弟死前的编号段。
他沉默两秒，收刀。
代价：敌方主将借此逃脱。
```

# 2. 人物成长补丁

## 2.1 成长必须走四段闭环

每次人物成长，不允许直接“顿悟”。

必须按顺序写：

```text
困境 → 挣扎 → 改变 → 沉淀
```

### 四段写法

| 阶段 | 章节表现 | 禁区 |
|---|---|---|
| 困境 | 人物旧方法失效 | 不要一上来就成功 |
| 挣扎 | 他想退、想逃、想维持原样 | 不要省略痛苦 |
| 改变 | 他做出违背旧习惯的新选择 | 不要突然开挂 |
| 沉淀 | 新选择留下后果/代价/新认知 | 不要打完就忘 |

### 科武能力跃迁规则

凡出现以下内容：

- 修为突破
- 科技觉醒
- 数据进化
- 义体升级
- 血脉解锁
- 武道顿悟
- 系统权限提升

必须同步写一次心理变化。

### 执行模板

```text
外在升级：他获得【能力/等级/权限】。
内在代价：他失去【身体稳定/人际关系/旧信念/秘密安全】。
心理变化：他不再相信【旧观念】，但也无法完全接受【新责任】。
```

---

## 2.2 主角成长线

### 必须有主弧

建议《科武纪元》主角弧线：

```text
自保/复仇/求生 → 被迫承担小队 → 承担一城 → 承担文明代价
```

### 每卷至少推进一次

每卷结束时，主角至少完成一个心理台阶：

| 卷段 | 主角变化 |
|---|---|
| 新手卷 | 从“只管自己活”到“愿意救一个人” |
| 小队卷 | 从“独行”到“承认同伴价值” |
| 城市卷 | 从“救熟人”到“救陌生人” |
| 文明卷 | 从“赢”到“接受胜利也有代价” |

---

## 2.3 配角成长线

配角不是主角挂件。

每个重要配角必须有：

```text
1个核心标签 + 1个独立欲望 + 1个隐秘过往 + 1个和主线的冲突点
```

### 配角四步法

```text
立标签 → 给欲望 → 绑主线 → 留白
```

### 示例

```text
标签：嘴毒机械师
独立欲望：想修复父亲留下的旧纪元黑箱
主线联动：黑箱里藏着反派军团坐标
留白：她每次听到“归零协议”都会切断通讯
```

### 禁止

- 配角只负责吐槽
- 配角只负责送装备
- 配角只负责牺牲煽情
- 配角永远围着主角转

---

## 2.4 反派成长线

反派不必洗白，但必须有逻辑。

### 反派设计最低配置

```text
伤口：他曾经失去什么？
信念：他因此相信什么？
行动：他如何把信念推到极端？
复杂瞬间：他有一次不像怪物的表现。
代价：他最终为自己的选择付出什么？
```

### 科武反派适配

适合类型：

- 旧纪元守墓人
- 被系统污染的武道宗师
- 坚信人类必须机械化的科学领袖
- 以文明延续为名牺牲个体的统帅
- 被基因记忆驱动的复制体

### 反派复杂瞬间写法

```text
他下令屠城前，先关闭了儿童区的监控。
不是仁慈。
是不敢看。
```

# 3. 动作链补丁

每个关键场景必须写“触发→反应→后果”。

## 3.1 标准动作链

```text
触发：某物/某句话/某个场景踩中人物痛点
反应：人物出现动作、神态、身体或能力反馈
后果：人物做出选择，并产生代价
```

### 示例

```text
触发：敌人拿出林曜母亲的旧纪元芯片。
反应：林曜右手义体出现0.3秒延迟，刀锋偏了一寸。
后果：敌人逃脱，但林曜确认母亲数据仍存活。
```

---

# 4. 反馈补丁：情绪必须外化

## 4.1 身体反馈

可选：

- 指尖颤动
- 呼吸变浅
- 后颈发冷
- 伤口重新裂开
- 瞳孔短暂失焦
- 喉结滚动
- 手背青筋暴起

## 4.2 科技反馈

可选：

- HUD警报
- 神经接驳延迟
- 义体散热异常
- 芯片温度升高
- 纳米修复中断
- 数据流雪花屏
- 心率被系统强制标红

## 4.3 武道反馈

可选：

- 内息逆冲
- 丹田刺痛
- 经络灼烧
- 刀意失稳
- 拳劲散乱
- 真气回落
- 杀意压不住

---

# 5. 代价补丁

人物每一次获得、选择、成长，都要付出代价。

## 5.1 代价类型

| 类型 | 可写内容 |
|---|---|
| 身体代价 | 伤势加重、义体过载、寿命损耗、精神污染 |
| 情感代价 | 同伴误解、亲人疏远、旧友决裂 |
| 信念代价 | 发现自己坚持的东西不纯粹 |
| 道德代价 | 救一人导致多人受害 |
| 战略代价 | 暴露底牌、失去据点、反派得到时间 |
| 身份代价 | 暴露血脉、数据身份、旧纪元继承权 |

### 执行规则

如果本章主角获得了东西，结尾必须失去另一样东西。

```text
获得力量 → 失去身体稳定
获得真相 → 失去信任
获得胜利 → 失去退路
获得同伴 → 暴露软肋
```

# 6. 失败模式补丁

写完章节后，重点排查以下失败模式。

## 6.1 木偶人失败

表现：

- 人物只是为了推动剧情行动
- 没有自己的欲望
- 选择没有过往依据

修复：

```text
给他补一个独立目标，并让这个目标与主线发生冲突。
```

---

## 6.2 说明书失败

表现：

- 大段介绍人物童年
- 一次性倒完身世
- 回忆没有触发器

修复：

```text
把身世拆成3-5次，用物件/动作触发。
```

---

## 6.3 突然成长失败

表现：

- 人物被骂一句就醒悟
- 战斗中莫名突破
- 懦弱者突然无畏

修复：

```text
补“挣扎”和“沉淀”。
让他不是立刻变强，而是先做一次很小但违背旧习惯的选择。
```

---

## 6.4 工具人配角失败

表现：

- 配角只给主角送情报/装备/牺牲
- 没有自己的欲望
- 主角不在时配角就像不存在

修复：

```text
给配角一个即使主角死了也会继续做的目标。
```

---

## 6.5 脸谱反派失败

表现：

- 反派坏得没原因
- 只会狂笑
- 行为只为给主角制造困难

修复：

```text
补反派的伤口、信念和复杂瞬间。
```

---

# 7. 人物口吻补丁

## 7.1 主角口吻

建议：

- 克制
- 短句
- 不轻易解释
- 情绪藏在动作里
- 越痛越冷静

示例：

```text
“撤。”
“可他们还在里面！”
林曜看着燃烧的穹顶，手指按进掌心伤口。
“我知道。”
```

---

## 7.2 嘴毒机械师口吻

特征：

- 技术词压情绪
- 嘲讽替代关心
- 关键时刻话变少

示例：

```text
“你这条胳膊再这么用，明天就能申请文物保护。”
她低头焊接，声音很稳。
焊枪却在第三秒偏了一毫米。
```

---

## 7.3 老派武者口吻

特征：

- 少废话
- 讲规矩
- 讲债
- 情绪压在礼数下

示例：

```text
“刀可以断，债不能断。”
老人把断刃推回鞘里。
“你父亲欠的，我替他还一半。剩下的，你自己活着还。”
```

---

## 7.4 数据型角色口吻

特征：

- 理性表达
- 偶尔暴露不合逻辑的情绪
- 用数据掩盖人性

示例：

```text
“根据计算，你的存活率是11.7%。”
“那你为什么还跟来？”
“因为……样本不能丢失。”
它停顿了一下。
“你也是样本。”
```

---

## 7.5 反派口吻

特征：

- 逻辑自洽
- 不解释太多
- 把残酷说成必要
- 偶尔露出旧伤

示例：

```text
“我不是要毁掉人类。”
他看着玻璃舱里沉睡的孩子。
“我是要毁掉人类继续犯错的资格。”
```

---

# 8. 段落节奏补丁

## 8.1 高潮章节奏

高潮章允许细节密度提高。

推荐节奏：

```text
短动作句 → 身体反馈 → 对话反差 → 选择 → 代价
```

示例：

```text
林曜收刀。
太晚了。

芯片已经插进主控台。
他的义眼里闪过一片雪花，母亲的声音在噪声里响起。

“别回头。”

他回头了。
```

---

## 8.2 过场章节奏

过场章不堆细节，只保留辨识标签。

```text
人物标签动作 + 一句有信息量的台词 + 一个小留白
```

示例：

```text
机械师照旧蹲在机甲脚踝旁，嘴里咬着扳手。
“归零协议不是传说。”
她顿了一下。
“至少我爸不是因为传说死的。”
```

---

## 8.3 回忆插入节奏

单章限制：

```text
大回忆 ≤ 1次
小闪回 ≤ 2次
连续两章不回忆同一段往事
```

### 回忆写法

不要：

```text
他想起了小时候发生的一切。
```

要：

```text
芯片贴上皮肤的瞬间，林曜闻到一股烧焦的塑料味。
十年前，冷冻舱爆炸前，也是这个味道。
```

# 9. 章末钩子补丁

每章至少有一个人物钩子。

## 9.1 钩子类型

| 类型 | 写法 |
|---|---|
| 过往钩子 | 某人看到物件失态，但不解释 |
| 欲望钩子 | 配角私下做了与主线无关却重要的事 |
| 身份钩子 | 系统识别出角色隐藏编号 |
| 关系钩子 | 反派认识主角父母/师门/旧身份 |
| 代价钩子 | 本章胜利后，身体/系统出现异常 |
| 道德钩子 | 主角救下的人，导致更大危机 |

## 9.2 章末句模板

```text
直到通讯切断前，林曜才听见那个人叫出了他的旧名。
```

```text
系统日志自动刷新。
【检测到旧纪元合法继承人。】
```

```text
她把黑箱藏进衣服里。
屏幕亮起的瞬间，上面出现了父亲死亡当天的坐标。
```

```text
林曜赢了。
代价是，他的心跳从系统记录里消失了三秒。
```

# 11. 章节自检清单

交稿前逐项检查。

## 11.1 人物活人感检查

- [ ] 本章核心人物是否有明确外在目标？
- [ ] 本章核心人物是否有内在痛点？
- [ ] 关键选择是否能追溯到过往？
- [ ] 是否至少出现一个具体触发器？
- [ ] 是否避免凭空插入回忆？
- [ ] 是否有动作微表情或身体反馈？
- [ ] 是否少用“他很愤怒/难过/害怕”这类形容？
- [ ] 人物变化是否经过“困境→挣扎→改变→沉淀”？
- [ ] 人物获得东西后，是否付出代价？
- [ ] 本章人物是否仍符合自身底色？

## 11.2 配角检查

- [ ] 有名字的配角是否有独立欲望？
- [ ] 配角是否有一个核心辨识标签？
- [ ] 配角是否有1-2个细节，而不是标签堆砌？
- [ ] 配角是否不是单纯服务主角？
- [ ] 配角是否留下一个未解释点？
- [ ] 作用结束的配角是否安排退场或降频？

## 11.3 反派检查

- [ ] 反派行动是否有自身逻辑？
- [ ] 反派的狠是否来自某个伤口/信念？
- [ ] 是否有复杂瞬间？
- [ ] 是否避免强行洗白？
- [ ] 反派给主角造成的冲突是否踩中人物痛点？

## 11.4 节奏检查

- [ ] 单章大回忆是否不超过1次？
- [ ] 单章小闪回是否不超过2次？
- [ ] 是否避免连续两章解释同一段往事？
- [ ] 高潮章是否增加细节反馈？
- [ ] 过场章是否控制笔墨，只保留辨识标签？
- [ ] 章末是否有可追更钩子？

## 11.5 科武适配检查

- [ ] 科技/武道物件是否替代了普通狗血物件？
- [ ] 能力升级是否同步心理变化？
- [ ] 修为提升是否不等于人物成长？
- [ ] 世界观信息是否通过人物欲望释放？
- [ ] 旧纪元设定是否通过物件/身体/选择体现，而不是说明书堆设定？

# 12. 短故事 / 狼人篇可借点

## 12.1 可借点

### 1. 狼人身份触发器

适合用：

- 月光
- 血腥味
- 银器
- 旧项圈
- 兽化伤疤
- 猎人徽章
- 被撕裂的童年照片
- 失控时留下的爪痕

### 2. 狼人角色活人感

狼人不能只写“野性”。

要写：

```text
人性欲望 + 野性冲动 + 失控代价
```

示例：

```text
他闻到血味时，第一反应不是扑上去。
而是后退一步，把自己的手腕咬出了血。
他怕自己先咬的是她。
```

### 3. 短故事适合结构

```text
开头：异常动作露出身份疑点
中段：触发器导致失控
反转：失控原因来自过往伤口
结尾：保留人性或彻底兽化
```

### 4. 狼人篇章末钩子

```text
她终于看清了他锁骨下的编号。
那不是狼人的编号。
是猎人的。
```

# 13. 科武长篇可借点

## 13.1 主角

可借：

- 旧纪元事故作为童年印记
- 科技义体作为身体反馈
- 武道内息作为情绪外化
- 文明级选择作为成长代价

主角建议锚点：

```text
童年印记：冷冻舱爆炸/实验区逃亡
原生创伤：亲人被旧纪元科技吞噬
执念遗憾：没能救下某个编号少年
成长转折：第一次为了陌生人违背求生本能
```

---

## 13.2 配角

适合发展的人设：

| 配角类型 | 独立欲望 |
|---|---|
| 机甲师 | 修复父亲遗留黑箱 |
| 数据修士 | 证明自己不是系统残次品 |
| 宗门残党 | 找回失传武道源代码 |
| 军方女队长 | 阻止城市被战略牺牲 |
| 旧纪元AI | 获得一次“不按程序”的选择权 |
| 克隆少年 | 证明自己不是原体替代品 |

## 13.3 反派

适合设计：

```text
旧纪元守墓人：为了保存文明样本，牺牲活人城市。
机械神教领袖：认为肉身是人类灾难源头。
武道宗师：被数据污染后，把飞升理解为格式化。
军方统帅：用冷酷手段换取文明存活率。
```

### 反派不能只说：

```text
我要毁灭世界。
```

要说：

```text
“世界早就毁过一次了。”
“我只是拒绝让你们用同样的方法，再毁第二次。”
```

# 14. 平台规则转化：发布 / 包装 / 风险门禁

## 14.1 发布规则

适合番茄/追更型平台：

1. 每章至少一个人物钩子  
2. 3-5章兑现一次重要留白  
3. 主角可惨，但不能长期自怜  
4. 配角要有可催更的人设  
5. 章末优先断在“身份、代价、反转、选择前”  
6. 不要一章倒完人物身世  
7. 世界观信息必须绑人物命运释放  

---

## 14.2 包装规则

### 章节标题可用关键词

- 旧纪元
- 继承人
- 禁武区
- 黑箱
- 归零协议
- 神经接驳
- 数据污染
- 断剑
- 冷冻舱
- 文明火种
- 失控
- 编号
- 义体过载

### 标题模板

```text
第X章 旧纪元黑箱启动

第X章 归零协议不是传说
第X章 这次突破，要他的命

```

## 14.3 风险门禁

发布前检查以下风险。

### 人设风险

- [ ] 主角是否过度自怜？
- [ ] 主角是否长期被动挨打？
- [ ] 主角是否没有明确目标？
- [ ] 配角是否喧宾夺主？
- [ ] 副CP是否抢主线节奏？

### 节奏风险

- [ ] 是否连续多章回忆？
- [ ] 是否一章塞完整身世？
- [ ] 是否过场章信息太密？
- [ ] 是否高潮章缺少身体反馈？
- [ ] 是否章末没有追更点？

### 平台风险

- [ ] 是否出现过度血腥细节？
- [ ] 是否出现不可控阴暗价值导向？
- [ ] 是否反派洗白过度导致价值混乱？
- [ ] 是否主角选择过于冷血且无代价反思？
- [ ] 是否大段设定说明导致阅读流失？

### 包装风险

- [ ] 标题是否太抽象？
- [ ] 爆点是否不清楚？
- [ ] 章末是否没有悬念？
- [ ] 人物钩子是否没有后续兑现计划？

# 15. 最终执行口令

写人物时，按这七步走：

```text
1. 给他一个过往锚点。
2. 用物件或动作触发。
3. 写身体/科技/武道反馈。
4. 让他做一个符合底色但带变化的选择。
5. 让选择产生代价。
6. 留一个没解释完的钩子。
7. 在3-5章内兑现或升级钩子。
```

一句话版本：

> 人物不是来推动剧情的。人物是带着旧伤撞进剧情，做出选择，付出代价，然后把读者拖到下一章。
