## 一、10条写法规则（作家OS补丁）

1. **开篇动作：直接切入“异常已发生”**
   - 不从世界观讲起，先写：尸体异常、武器失控、信号倒计时、主角被追杀、实验爆炸。
   - 设定只露10%，剩下靠人物反应和物理反馈带出。

2. **每章必须有“动作链”**
   - 写作前标注：  
     **触发条件 → 主角动作 → 直接结果 → 新问题**
   - 没有新问题的动作，删。

3. **钩子必须绑定明确目标**
   - 短线目标：逃出实验室、抢到芯片、撑过三分钟、突破一层基因锁。
   - 长线目标：查清文明信号、复仇、救人、阻止星门开启。
   - 目标模糊，读者不追。

4. **兑现必须给正反馈**
   - 每个钩子兑现时，至少给一种回报：  
     **实力提升 / 资源获得 / 信息揭露 / 阵营优势 / 情感推进**
   - 不能只折磨主角不回报。

5. **兑现必须付代价**
   - 科武篇尤其要写清：能量消耗、神经损伤、骨骼裂纹、身份暴露、时间窗口缩短。
   - 没代价的升级=廉价爽点。

6. **悬念靠信息差，不靠装神秘**
   - 读者知道、角色不知道：制造“快掉马/快发现”的期待。
   - 角色知道、读者不知道：制造“他到底藏了什么”的期待。
   - 禁止只写“他露出神秘微笑”。

7. **人物口吻服务钩子**
   - 强者口吻：少解释，多下判断。  
     例：“别碰那道光，它不是辐射，是门。”
   - 弱者口吻：多感官，多恐惧。  
     例：“我的手在抖，仪表盘却显示我已经死了。”
   - 反常人物必须留下解释空间。

8. **段落节奏：短句推危机，长句补信息**
   - 打斗、逃亡、倒计时：短句、快切、强动作。
   - 解释设定：夹在动作后，用一两句补。
   - 一段只承担一个功能：动作 / 反馈 / 信息 / 情绪。

9. **章末必须留“指向性钩子”**
   - 章末不要空泛留白。
   - 推荐句式：  
     **“他终于看清了信号源——那是自己的脑电波。”**  
     **“舱门打开，里面坐着三年前死去的师父。”**
   - 章末钩子要指向下一章行动。

10. **写作前任务卡字段更新**
   - 每章开写前填写：  
     ①本章主钩/副钩  
     ②钩子类型：开篇钩 / 结构钩 / 悬念钩  
     ③触发条件  
     ④主角动作链  
     ⑤物理反馈  
     ⑥兑现回报  
     ⑦付出代价  
     ⑧信息差配置：读者知道什么，角色知道什么  
     ⑨章末钩子  
     ⑩预计兑现章节  
   - **短故事/狼人篇可借点**：开局直接死人、身份错位、阵营误判、夜晚倒计时。  
   - **科武长篇可借点**：基因锁突破、文明信号、古武残篇、实验失败、星门倒计时。  
   - **发布/包装/风险门禁**：3000字内必须抛核心钩；连续3章无新钩或旧钩推进，判定为留存风险。

## 二、10条章节自检清单

1. [ ] 本章是否在前300字内出现动作、异常或冲突？

2. [ ] 世界观说明是否压到必要最低？有没有“设定集式开头”？

3. [ ] 本章主角有没有明确目标？读者能否知道他下一步要干什么？

4. [ ] 本章是否至少推进一个旧钩子，或抛出一个新钩子？

5. [ ] 钩子有没有兑现一部分？是否给了实力、信息、资源或关系进展？

6. [ ] 兑现是否有代价？有没有伤、耗能、暴露、失去时间或阵营压力？

7. [ ] 信息差是否清楚？  
   - 是读者比角色知道多？  
   - 还是角色比读者知道多？

8. [ ] 科幻/武学设定是否转化成可感知反馈？  
   - 光、热、痛、震动、血压、重力、仪表数值、神经负荷。

9. [ ] 章末钩子是否具体指向下一章？有没有“无意义神秘感”？

10. [ ] 连续三章检查：  
   - 有没有新目标？  
   - 有没有小兑现？  
   - 有没有长线钩推进？  
   - 若没有，需补一个事件型钩子。

## 三、3条科武落地

1. **把硬设定改成生存危机**
   - 不写：“量子纠缠发生异常。”  
   - 改写：“主角挥刀前，三秒后的伤口已经出现在他胸口。”
   - 设定必须变成角色能看见、摸到、受伤的东西。

2. **升级=突破+反馈+代价**
   - 例：主角强行开启第二基因锁。  
   - 反馈：视野出现热流轨迹，拳速突破音障。  
   - 代价：视网膜灼伤，心率超过极限，身份被军方监控捕捉。  
   - 这样结构钩才能长期成立。

3. **长篇用“短钩套长钩”推进**
   - 短钩：抢芯片、赢擂台、逃实验室、解开一页古武残篇。  
   - 中钩：找到信号来源、查清师父死亡、突破武道阶段。  
   - 长钩：星门背后的文明、纪元重启真相、人类武道与高维科技的关系。  
   - 每3—5章小兑现，每10—20章大兑现。
