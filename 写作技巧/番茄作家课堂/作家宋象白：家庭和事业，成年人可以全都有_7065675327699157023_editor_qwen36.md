# 《科武纪元》编辑学习官：番茄作家课堂《作家宋象白》规则提炼

## 1 课程核心判断（≤6条）
1. **情感真实＞辞藻堆砌**：读者共鸣源于作者对角色投入的真实情感投射，而非修辞技巧。
2. **画面感开篇适配碎片阅读**：快节奏环境下，首段需以具象场景替代抽象设定，快速建立沉浸锚点。
3. **情绪愉悦是核心诉求**：网文本质是提供正向情绪价值，作品需明确交付“爽/暖/燃/释然”等体验。
4. **风格定位需扬长避短**：作者应聚焦擅长的微观细节与轻快节奏，回避不擅长的宏大权谋/复杂算计。
5. **数据决策遵循“多数原则”**：平台反馈以正向评论与完读率为基准，过滤少数主观差评，不轻易因个评改主线。
6. **连载惯性优先于完美主义**：卡文期以“硬写保更+次日精修”维持更新节奏，稳定输出优于单章打磨。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 编辑执行规则 |
|:---|:---|
| **开篇** | 首章前300字必须呈现可视觉化的场景/动作/环境，禁用纯世界观说明或人物小传；以“景/物/微动作”带出氛围。 |
| **节奏** | 保持“事件推进+情绪反馈”的轻快循环；单章静态描写占比≤15%；卡文处用过渡情节或视角切换填补，严禁断更。 |
| **冲突** | 弱化宏观权谋，聚焦微观人际摩擦、生存抉择与情感细节；冲突解决需符合角色动机，禁用机械降神。 |
| **人物** | 角色行为必须绑定真实情感逻辑；允许“不完美但鲜活”的特质；避免作者强行替角色做决定。 |
| **题材** | 优先“小而美”切口（日常流、微科幻、生活化叙事）；宏大背景需拆解为具体人物可感知的局部事件。 |
| **改编** | 文本需具备“分镜直译”潜力：场景干净、动作明确、对话精炼；减少心理独白，增加外化行为与交互。 |
| **平台规则** | 番茄系重情绪价值与追读率；重视章说互动，但内容调整以“多数正向反馈+完读数据”为准；不因单条差评推翻核心设定。 |

## 3 科武适配
### ✅ 可用点
- **情感落地**：长篇科幻易“设定大于人物”，需将科武体系（机甲、异能、星际法则）绑定于角色的真实情感（羁绊、恐惧、信念、代价），维持共鸣。
- **画面感开篇**：用具体科武场景（如引擎点火震颤、异星大气折射光、实验室冷光）替代干瘪的编年史说明，快速抓人。
- **轻快节奏控制**：科武长篇易陷入设定堆砌，需以“任务/危机/升级”为驱动，保持章节推进密度，避免大段科普水文。
- **多数原则应用**：科幻读者重逻辑，但平台读者重情绪；需在“科学自洽”与“阅读爽感”间找平衡，以完读率与正向评论为调整依据。

### ❌ 不可硬套点
- **“不擅长权谋/只写细小美”**：《科武纪元》必然涉及势力博弈、文明冲突、硬核战力体系，纯走“田园/萌暖”路线会导致格局塌陷，需补充宏观架构与多线叙事能力。
- **“冲动型创作/一句话起书”**：长篇科幻需严密大纲、科技树推演与战力平衡表，单凭灵感起书极易中后期逻辑崩盘或战力通胀。
- **“忽略逻辑bug”**：科幻题材对物理规则、技术原理、时间线要求极高，逻辑漏洞是致命伤，绝不可用“情感细节”或“读者包容”掩盖。

## 4 编辑检查表（10条以内）
1. 开篇300字内是否建立强画面/场景，而非纯设定说明？
2. 本章核心情绪是否明确（愉悦/紧张/共鸣），有无无效水文？
3. 人物动机是否基于真实情感/利益，而非作者强行推动？
4. 科幻设定是否已转化为具体动作或感官反馈，而非大段科普？
5. 冲突是否聚焦微观可感层面（人际/生存/抉择），避免空泛宏大？
6. 逻辑链条（科技/战力/时间线）是否自洽，有无明显硬伤？
7. 章节结尾是否留有明确钩子（悬念/反转/情绪断点）？
8. 读者评论正向率是否＞70%，差评是否属“核心设定/人设”问题？
9. 更新节奏是否稳定，卡文处是否已用过渡情节或精修预案填补？
10. 文本是否具备“分镜化”潜力（场景干净、动作明确、对话精炼）？

## 5 对作家角色的输入要求
| 维度 | 输入规范（作家交稿前必须自检） |
|:---|:---|
| **动作链** | 必须提供连贯的“触发→决策→执行→结果”序列；科武战斗/操作需拆解为可追踪的步骤，禁止跳跃式推进或“意念完成”。 |
| **物理反馈** | 所有超现实/科幻元素必须附带感官反馈（如重力变化导致的骨骼压迫感、能量过载的灼痛、机械关节的摩擦声、护盾破裂的冲击波），杜绝“无介质生效”。 |
| **代价** | 任何能力使用、科技跃迁或关键抉择必须支付明确代价（体力透支、资源损耗、道德困境、关系破裂、系统反噬），禁止“零成本开挂”。 |
| **钩子** | 章末必须设置可验证的预期断点（如未解之谜、倒计时、敌我态势反转、情感临界点、装备/技能解锁提示），禁用开放式抒情或平淡收尾。 |
| **读者预期** | 每章需明确交付一项“情绪/信息/进度”承诺（如爽点兑现、伏笔回收、战力升级、关系推进），并在章说/作话中引导验证，维持追读惯性；预期落空需提前铺垫或下一章立即补偿。 |
