# 《科武纪元》编辑学习官｜《开书准备｜新手如何写一个好故事》规则提炼

## 1 课程核心判断（≤6条）
1. **故事引擎是人物关系与动态目标**：题材仅为容器，真正留存读者的是角色间的利益拉扯、隐藏动机与目标随剧情的合理异变。
2. **开篇即冲突，背景后置**：首章必须以具体危机/狗血事件切入，严禁大段世界观或设定说明，背景需通过动作与对话自然带出。
3. **节奏依赖“期待值弹簧”**：通过压抑→破局→新危机/反转的循环反复拉扯读者神经，忌开局一次性释放所有爽点。
4. **细纲是防跑偏的刚性工具**：单章需拆分为≥2个小情节，利用视角切换与悬念卡点控制信息释放，杜绝临场卡文与逻辑断裂。
5. **人设生命力源于缺陷与反差**：完美角色无叙事价值，致命弱点、行为矛盾与极端处境下的非常规选择才是剧情驱动力。
6. **30万字为长篇控盘验证线**：新手首本需完整走完30万字以检验大纲承载力、支线收束能力与节奏稳定性，非天赋决定论。

## 2 可执行编辑规则（按模块）

| 模块 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | ①首章前300字必须出现具体冲突/危机事件；②禁用“设定说明书”式背景交代，改用动作/对话/物品细节侧写；③明确主角初始动机与最大阻碍，建立认知锚点。 |
| **节奏** | ①日更4000字拆为2个2000字情节单元；②每单元结尾必须设置“视角切换”或“悬念断点”（如坠崖不写生死、凶案目击后切凶手视角）；③爽点释放后3章内必须叠加新阻碍或反转。 |
| **冲突** | ①核心冲突必须绑定人物关系网（利益/血缘/阵营/旧怨），非单纯天灾或系统任务；②设计“合理但不合常理”的抉择（如见死不救、反向利用）；③局中局需提前埋设信息差，反转需有前置伏笔。 |
| **人物** | ①人设表必填：身份/欲望/恐惧/致命缺陷/行为反差；②目标需随剧情发生逻辑演变（如“求死”变“求生”）；③配角需有独立困境与行动线，禁止纯工具人。 |
| **题材** | ①热点/社会新闻可提取“故事基调+原型人物”，通过小人物视角撬动大背景；②不盲目追风口，优先验证故事根基与经典起承转合结构；③同一题材靠人物关系与节奏差异拉开质量。 |
| **改编** | ①强化五感描写与场景画面感，预留影视分镜空间（如战场硝烟、能量灼烧、重力压迫）；②结构对标经典影视主线（困境→升级→意外→转折→结局），确保单集可独立成篇且主线连贯。 |
| **平台规则** | ①黄金三章定留存，首章必须完成“钩子+期待值建立”；②日更需配次日细纲，断更/卡文直接掉推荐；③30万字为完本测试线，数据反馈决定后续资源倾斜；④爽点需符合主流价值观底线（如被迫反击、身不由己）。 |

## 3 科武适配（《科武纪元》专项）

| 维度 | 可用点 | 不可硬套点 |
|:---|:---|:---|
| **设定落地** | “极端困境开局”适配废土/高武/基因改造背景；“动态目标”可绑定力量体系突破或科技伦理抉择。 | 现实向“狗血/婚姻背叛”需转化为科武语境下的“资源配额争夺/意识上传背叛/阵营清洗”，禁止生搬现实伦理。 |
| **战力/逻辑** | “代价驱动”完美契合科武升级逻辑（肉体异化/寿命折损/算力透支）；“细纲双情节”适配战斗+文戏/解密交替。 | “小人物撬动大事件”需严格匹配科武世界的物理/能量守恒规则，禁止无逻辑越级反杀或设定吃书。 |
| **节奏/反转** | “期待值弹簧”可用于科技树解锁、武道境界突破、阵营身份揭露；“局中局”适配AI推演/意识潜入/多维时空嵌套。 | 反转不能牺牲科幻严谨性，所有“出其不意”必须在前文有技术/武力/情报层面的伏笔支撑，忌机械降神。 |
| **篇幅控制** | 30万字验证期可用于测试“科武体系自洽度+主线推进效率”，细纲防跑偏对多线叙事（科技线/武道线/阵营线）至关重要。 | 硬科幻/长篇架构需提前完成《设定集》与《力量体系表》，30万字内必须完成核心规则展示，否则后期易崩盘。 |

## 4 编辑检查表（10条以内）
- [ ] 首章前300字是否以具体冲突/危机切入，无超500字纯设定堆砌？
- [ ] 主角是否具备明确初始困境，且目标在剧情中发生合理演变？
- [ ] 单章（4k）是否包含≥2个情节节点，并在结尾设置视角切换或悬念断点？
- [ ] 核心冲突是否源于人物关系/利益对立，而非单纯外部灾难或系统提示？
- [ ] 人设是否包含至少1个致命缺陷或行为反差，并驱动关键剧情抉择？
- [ ] 剧情是否遵循“压抑→破局→新危机/反转”的弹簧节奏，无连续平铺？
- [ ] 细纲是否提前标注次日内容，避免临场卡文或逻辑断裂？
- [ ] 科武/科幻设定是否仅通过动作、环境、对话自然流露，无说明书式插入？
- [ ] 每3万字是否完成一次阶段性目标结算，并推动主线或阵营格局变化？
- [ ] 全文是否剔除无推动作用的过渡性废话，确保字字服务于冲突或悬念？

## 5 对作家角色的输入要求

| 要素 | 输入标准（编辑验收口径） |
|:---|:---|
| **动作链** | 必须提供“触发条件→决策→执行动作→结果反馈”完整闭环。禁止“意念流”战斗/升级，每个关键动作需标注能量消耗路径、空间位移或物理干涉轨迹。 |
| **物理反馈** | 场景与交互需具象化五感描写（如金属撕裂声、等离子灼烧味、重力压迫感、神经刺痛）。科武设定需体现明确的力学/能量守恒表现，禁用纯特效堆砌。 |
| **代价** | 每次破局/升级必须支付明确代价（寿命折损/资源枯竭/阵营信任破裂/肉体异化/算力过载）。禁止零成本开挂，代价需直接推动后续剧情或人物关系裂变。 |
| **钩子** | 每章末必须埋设“信息差/危机逼近/身份反转/规则异变”类悬念。钩子需与主线目标强绑定，标注预期回收章节，禁止为卡而卡的无效断更。 |
| **读者预期** | 需明确标注本章“预期爽点/痛点”及“预期落空/反转设计”。开篇3章内建立“主角核心诉求+最大阻碍”认知锚点，后续剧情按“弹簧模型”反复验证或颠覆该预期，并在细纲中写明预期管理策略。 |
