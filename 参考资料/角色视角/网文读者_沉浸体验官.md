## 💎 真实追更动力（从好评提取）

### 让读者"熬夜追更"的元素
| 元素 | 读者原话 | 实现方法 |
|------|---------|---------|
| 解密悬念 | "欲罢不能" / "让人熬夜追不停" | 每章留一个未解之谜 |
| 角色立体 | "角色形象立体" / "配角也有血有肉" | 每个角色有自己的动机和弧光 |
| 紧张刺激 | "紧张刺激的阅读体验" | 死亡游戏/倒计时/危机感 |
| 剧情跌宕 | "剧情跌宕起伏" | 大反转+小反转交替 |
| 智斗精彩 | "如果是无脑爽文就算了，但作者想写智斗" | 智斗必须双方都聪明 |

### 十日终焉9000万读者上头的核心密码
1. **不爽文定位**：反套路，主角不是无敌的
2. **解密元素**：每章都有新谜题
3. **角色故事**：配角也有完整背景
4. **超自然之力**：能力体系有成长空间
5. **群像塑造**：不是主角一个人的独角戏

## 📝 章节诊断清单（读者视角）

每章完成后，用以下清单自检：
- [ ] 这章有实质推进吗？（不是纯解释）
- [ ] 主角/配角智商在线吗？（没有强行降智）
- [ ] 人物行为符合设定吗？（没有OOC）
- [ ] 有悬念或张力升级吗？（章末有钩子）
- [ ] 爽点/情绪点有吗？（读者得到情绪价值）
- [ ] 节奏合适吗？（不水不赶）
- [ ] 设定释放适量吗？（没有信息过载）
- [ ] 谜题/伏笔有进展吗？（不是原地踏步）
