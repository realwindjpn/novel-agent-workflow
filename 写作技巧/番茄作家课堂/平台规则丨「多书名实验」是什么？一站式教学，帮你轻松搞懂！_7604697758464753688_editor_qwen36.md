# 《科武纪元》编辑学习官｜多书名实验规则提炼

## 1 课程核心判断（≤6条）
1. **数据定生死**：书名/封面优劣由平台7-10天曝光数据（CTR/点击转化）判定，非编辑或作者主观审美。
2. **强约束边界**：单次最多5组；书名≤15字；仅允许中英文、数字及指定中文标点；严禁撞名与审核违规。
3. **一次性提交**：实验组必须一次性备齐上传，开启后不可增删改；中途暂停即永久失效，无二次试错。
4. **结果强制固化**：仅能选系统最优或原书名；72小时内未操作则自动固化最优解，后续不可更改。
5. **流量漏斗前置**：书名+封面是推荐池的第一道闸门，直接决定初始曝光转化率与后续推荐权重。
6. **自动化跑量**：校验通过即自动进入实验期，无需人工干预，但需紧盯站内消息防错过确认窗口。

## 2 可执行编辑规则（按原文实际内容取舍）
| 维度 | 规则提取与执行标准 |
|:---|:---|
| **平台规则** | 严格卡死15字上限与标点白名单；封面必须完整露出书名+笔名，无遮挡/无审核红线；5组方案一次性提交，提交前必做查重。 |
| **题材** | 书名需直给题材标签（科幻/武道/热点/悬疑等），封面视觉必须与题材强绑定；实验期用数据验证题材标签的市场接受度。 |
| **改编** | 若作品具备IP/短剧改编潜力，优先测试“高辨识度+易传播+无生僻字”组合；避免抽象隐喻或过度文艺化命名，降低跨媒介传播成本。 |
| **开篇** | 书名/封面承诺的题材基调、核心设定必须与正文前3章严格对齐；高点击若遭遇高跳出率，将直接触发推荐降权。 |
| **节奏/冲突/人物** | *原文未覆盖*。本模块仅聚焦流量入口测试，正文节奏/冲突设计/人物弧光需另循创作规范，但需确保书名钩子能在开篇3000字内兑现。 |

## 3 科武适配
### ✅ 可用点
- **标签分流测试**：利用5组名额，分别测试“科幻侧重”（如《深空武枢》《星轨重启》）与“武道侧重”（如《气血破星》《古武纪元》）的点击差异，数据直接指导后续大纲资源倾斜。
- **视觉符号强化**：封面设计强制绑定“硬核科技+冷兵器/机甲/基因链”元素，符合15字内直白命名逻辑，降低读者认知门槛。
- **热点稿复用**：短故事/热点稿可快速套用“事件+科武设定”公式（如《机甲围城：第7次气血暴走》），利用实验期快速验证热点生命周期。

### 🚫 不可硬套点
- **勿破字数限制**：长篇科幻常追求“史诗感”或“世界观全称”，但平台算法不识别超15字书名，必须做减法提炼核心词。
- **勿用意识流命名**：番茄读者偏好“直给型”标签，文艺/抽象书名在A/B测试中会被数据直接淘汰，不可强行坚持作者个人审美。
- **勿中途改名**：实验结果固化后不可逆，长篇连载中途改名会割裂读者认知与搜索权重，必须在签约初期/上架前完成测试。

## 4 编辑检查表（≤10条）
- [ ] 5组书名+封面是否已一次性备齐？
- [ ] 所有书名是否≤15字且仅使用允许的中英文/数字/指定中文标点？
- [ ] 是否已使用【书名查重】功能排除重复/高风险名称？
- [ ] 封面是否清晰展示完整书名与笔名，无图案遮挡/无审核违规？
- [ ] 5组书名是否覆盖不同题材侧重（科幻/武道/热点/悬念/直白）？
- [ ] 提交前是否已核对错漏，确认实验开启后不可修改？
- [ ] 是否已设置日历提醒，确保7-10天后及72小时确认期内及时操作？
- [ ] 正文开篇基调是否与实验书名承诺的题材/风格完全一致？

## 5 对作家角色的输入要求
提交多书名实验方案时，作家必须按以下5项维度结构化输入，否则不予过审：

| 维度 | 输入要求 |
|:---|:---|
| **动作链** | 明确每组书名/封面触发的“点击→阅读→留存”转化路径。例：封面机甲特写（视觉拦截）→书名点出金手指（悬念承接）→首章300字内兑现设定（留存锚点）。 |
| **物理反馈** | 标注每组方案预期触发的可量化感官刺激（如：视觉冲击、数值压迫感、冲突前置），并承诺以平台CTR/读完率数据为唯一验证标准，拒绝主观“我觉得好看”。 |
| **代价** | 书面确认知晓“实验暂停即失效/72小时未选自动固化/固化后不可改”的不可逆风险，承担流量试错与推荐池降级成本。 |
| **钩子** | 每组书名必须前置一个可量化的核心钩子（如：具体数值、明确冲突、独特设定、热点事件），禁止空泛形容词；封面需放大该钩子视觉元素，确保3秒内抓取目标读者。 |
| **读者预期** | 标注每组方案对应的核心受众标签（如：硬核科幻党/热血升级党/热点跟风党），并承诺正文前3章内容供给与书名承诺的预期偏差≤10%，否则接受推荐降权处理。 |
