## 一、10条写法规则（作家OS补丁）

1. **章钩切法：只写到“起手/临界/抉择”，不写结果。**  
   动作链固定：`发现异常 → 主角出手/被迫选择 → 结果未落定断章`。  
   禁止：本章内打完、解释完、真相全交代。

2. **每章至少1个弱钩，每3-4章1个强钩。**  
   弱钩：一句异常对话、一个未解释感官、一件道具反应。  
   强钩：生死危机、身份反转、战力突破、阵营背刺、科技失控。  
   平台门禁：避免章章大卡文，读者会疲劳反噬。

3. **钩子必须带“反馈”，不能只写悬念。**  
   写法：`钩子触发 → 身体/环境/设备出现可见反应`。  
   例：义体发烫、目镜雪花、空气焦糊、精神波耳鸣、骨骼震颤。

4. **钩子必须带“代价”，且3-5章内兑现。**  
   道具越强，副作用越具体。  
   例：基因药剂临时破境，但神经排异；遗迹门开启，但高维扫描锁定主角。

5. **藏九露一：本章只露10%异常，不解释90%真相。**  
   作者自己必须知道答案；读者只看到现象。  
   失败模式：作者也不知道答案＝未知坑，高危禁术。

6. **对话钩不讲说明书，只放预警/误导/威胁。**  
   人物口吻要带立场：  
   - 上位者：轻描淡写透露危险。  
   - 敌人：说半句真话，藏半句杀招。  
   - 队友：用误判制造信息差。  
   短故事/狼人篇可借点：投票前一句“昨晚死的不是人”，立刻形成身份钩。

7. **场景钩必须异常化，不能纯风景。**  
   普通废墟无效；要写“违背常识的物理现象”。  
   例：雨水倒流、尸体悬空、终端倒计时、机甲被锁链钉在半空。  
   科武长篇可借点：遗迹场景天然承载世界观伏笔。

8. **道具钩一出现，就要登记回收。**  
   道具不是装饰，必须服务战力/真相/身份/阵营。  
   例：残缺芯片、未激活义体、反噬功法、染血刀、失效通讯器。  
   失败模式：写了神秘物件却长期不用＝读者判定水文。

9. **段落节奏用“三短一断”。**  
   前段交代现状，中段加速冲突，末段压缩句子。  
   章末多用短句、动作句、感官句。  
   例：  
   `倒计时归零。`  
   `门开了。`  
   `里面传来主角自己的声音。`

10. **写作前任务卡字段更新：每章开写前先填钩子表。**  
   必填字段：  
   - 本章核心期待：战力/生存/真相/阵营/情感  
   - 本章满足什么期待  
   - 本章新增钩子类型：道具/场景/对话/感官/章断  
   - 钩子物理反馈  
   - 触发代价  
   - 预期回收章数  
   - 章末断点位置  
   - 下章首段释放哪20%信息  
   - 发布风险门禁：是否违规血腥、低俗、恶意卡文、虚假标题

## 二、10条章节自检清单

1. [ ] 章末是否停在“动作起手/危机爆发/关键选择”，而不是事件结束？  
2. [ ] 本章是否至少有1个明确钩子，并指向下一章或后续主线？  
3. [ ] 钩子是否有可见反馈：声音、气味、疼痛、设备异常、环境变化？  
4. [ ] 钩子是否有代价，并规划在3-5章内兑现？  
5. [ ] 是否做到“露现象，不全解释”？  
6. [ ] 本章有没有无用道具、无用场景、无用感官描写？有则删。  
7. [ ] 对话是否带潜台词、威胁、误导或阵营信息，而非纯说明？  
8. [ ] 本章是否既满足旧期待，又制造新期待？  
9. [ ] 字数是否服从断章结构，而不是为凑整破坏节奏？  
10. [ ] 发布包装是否准确：标题/简介不夸大、不诈骗、不靠违规擦边吸引点击？

## 三、3条科武落地

1. **短故事/狼人篇可借点：把“身份钩”改成“信息差钩”。**  
   狼人篇的好用结构是：表面阵营明确，实际身份未明。  
   科武可改为：队友通讯延迟、战术系统误判、监控记录被剪辑、义体识别码伪造。  
   章末句：  
   `系统提示：击杀目标为友军。`  
   但主角明明看见，对方先拔了刀。

2. **科武长篇可借点：道具钩+代价钩做长期期待轴。**  
   适合长线道具：残缺高维功法、未知义体、旧纪元黑匣子、反噬型基因药剂。  
   每次使用都推进一点真相，同时增加一点代价。  
   模板：  
   `道具激活 → 主角变强 → 身体/世界异常 → 敌方势力察觉 → 下个危机升级。`

3. **平台规则转发布/包装/风险门禁。**  
   - 发布：章末必须有承接点，提升追读和次日留存。  
   - 包装：标题突出危机/反转/升级，不写虚假噱头。  
   - 风险：不靠恶意断章、无意义卡文、血腥猎奇、低俗擦边拉点击。  
   - 节奏：允许字数小幅浮动，优先保证钩子完整。
