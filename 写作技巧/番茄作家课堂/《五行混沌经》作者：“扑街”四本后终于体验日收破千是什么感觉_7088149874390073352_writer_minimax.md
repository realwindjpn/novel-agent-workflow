## 二、写作时执行模块（可直接套用）

### 模块A：开篇三刀

| 步骤 | 执行动作 | 禁忌 |
|:---|:---|:---|
| **第一刀：直白定调** | 第一段内必须出现：①当前核心矛盾 ②主角当前处境 ③可用资源/限制 | ❌ 禁止设定堆砌超过3句 ❌ 禁止悬念式开篇玩弄读者 |
| **第二刀：生理代入** | 主角必须有物理层面的即时反应（神经负荷/机甲震动/能量波动） | ❌ 禁止主角冷静旁观自己的危机 |
| **第三刀：短线期待** | 第三章内必须出现一个读者可预判的兑现目标（破译/战斗/逃生/谈判） | ❌ 禁止开篇无目的漂流 |

**开篇自检快问**：
- 读者能在3分钟内说出主角遇到了什么、要解决什么、为什么现在必须行动？

### 模块B：冲突四层（替换纯武力碾压）

```
第1层：环境压迫
  → 科武场景示例：能量舱剩余12%、敌方舰队切入感知范围、
    基因稳定剂药效倒计时30分钟

第2层：立场碰撞
  → 科武场景示例：改造派要销毁胚胎保存战力，
    主角认为这是出卖人类底线

第3层：认知陷阱
  → 科武场景示例：系统建议的最优解违反主角既有价值观
    （杀一人救百人/牺牲数据换取情报）

第4层：代价兑现
  → 科武场景示例：突破武道阈值导致神经回路不可逆损耗，
    系统弹出"记忆碎片丢失率17%"警告
```

**冲突升级检查**：每一章冲突是否至少覆盖其中2层？未达标则重设。

### 模块C：节奏脉冲表（每章必须完成一轮）

```
触发事件 → 读者预期形成（段落1-3）
    ↓
主角决策过程 → 读者焦虑值上升（段落4-6）
    ↓
执行过程 → 读者屏息（段落7-12）
    ↓
结果+新状态 → 期待兑现+新困惑生成（段落13-15）
    ↓
章末钩子 → 未闭合信息环抛出（段落16-18）
```

### 模块D：配角争议写法模板

```
【争议配角写法规律】

1. 给TA一个读者能理解的立场
   → 激进派：资源枯竭下必须改造，否则全灭
   → 保守派：武道是人类最后的尊严，不可机器化

2. 让TA的行为符合立场逻辑
   → 主角做出"正确"选择时，配角指出代价的不对称性
   → 不是为了让配角"赢"，而是为了让冲突有纵深

3. 在关键时刻给TA一个"人性裂隙"
   → 激进派私下给某个小孩保存了生物胚胎
   → 保守派的徒弟其实是改造者

4. 让转变代价明确
   → 不是"被说服"，而是"亲眼看到了代价后做出新选择"
```

### 模块E：章末钩子五式（科武纪元专用）

|:---|:---|:---|

## 四、平台规则转译为发布/包装/风险门禁

### 4.1 发布门禁（番茄算法适配）

| 门禁项 | 规则内容 | 执行动作 |
|:---|:---|:---|
| **首秀期完读率保卫** | 前8章完读率决定流量池分配 | 开篇直白定调+3章内给短线期待，防止读者在首秀期流失 |
| **日更稳定性** | 断更即断流，算法降权不可逆 | 保持存稿≥7天量；意外断更要提前发通知维护读者预期 |
| **节奏控制** | 剧情失控时优先完结，不注水 | 每50万字做一次"失控评估"：设定是否自洽？战力是否崩坏？若失控，果断收束而非强行续命 |
| **字数管理** | 千万字目标需匹配架构承载力 | 科技树迭代频率：≤每80万字一次大迭代；地图切换：≤每150万字一次；防后期设定膨胀/枯竭 |

### 4.2 包装门禁（简介/标题/封面）

```
【包装自检】
□ 简介是否直白定调核心矛盾？（仙侠写"修仙界险恶"，科武写"武道+科技+文明抉择"）
□ 简介与正文卖点是否一致？（禁止标题党导致首秀完读暴跌）
□ 封面是否传递题材调性？（科武封面需有"科技感+武道张力"视觉锚点）
□ 书名是否包含类型关键词？（"纪元/机甲/武道/星图"等触发算法分类标签）
```

### 4.3 风险门禁

| 风险类型 | 触发条件 | 处理方案 |
|:---|:---|:---|
| **设定吃书** | 前后设定矛盾读者指出≥3处 | 启动"设定补丁"机制：在下一章借角色之口做自洽解释，不冷处理 |
| **战力崩坏** | 主角升级速度超出读者预期容忍阈值 | 严格代价兑现：每次升级必有不可逆折损，用生理描写建立"升级痛感" |
| **平台推荐降级** | 日收连续3天低于基准线 | 启动"章节钩子强化"：每章增加一个悬念锚点；提高短线期待频率 |
| **争议失控** | 配角行为引发读者大规模负面情绪 | 配角的争议行为必须有逻辑闭环；在评论区主动引导讨论方向，不冷处理 |

## 五、跨场景借点标注

### ✅ 短故事/狼人篇可借用点

| 借点 | 具体用法 | 示例 |
|:---|:---|:---|
| **高频试错开篇法** | 先写3-5版开头再融合，狼人篇同样适用 | 第一章写3个版本的"觉醒"场景，选择张力最强的一版 |
| **末世人性嫁接** | 用末世的"险恶环境+底线互助"替换狼人篇常见的狗血套路 | 狼人社会中的"排斥异类+守护小群体" |
| **生理反应验证代入** | 让角色在极端情境下产生可测量的生理反应（心跳、肌肉紧绷、视线颤抖） | 变身时的心率失控、失控后的肌肉酸痛 |
| **争议配角运营** | 争议角色引发高净值打赏 | 让反派的行为逻辑在特定粉丝群中形成"情有可原"讨论 |
| **章末钩子五式** | 任意章节适用 | 狼人篇的"血月降临倒计时""狼群通讯截获" |

### ✅ 科武长篇可借用点

| 借点 | 具体用法 | 示例 |
|:---|:---|:---|
| **长线主线+短线期待结构** | 科幻的"技术突破/宇宙谜题"天然适配此结构 | 每20万字设一个技术突破小高潮，每100万字设文明抉择大高潮 |
| **反推架构法** | 先定科武体系（神经接驳/武道算法/能量矩阵），再反推剧情与伏笔 | 先设计"武道回路超载机制"，再设计主角何时触碰这条红线 |
| **配角立场矩阵** | 激进改造派/保守纯血派/AI伦理派设置 | 在科武纪元中构建多方势力，让主角在各方之间做价值选择 |
| **代价系统建设** | 每次突破/战斗/技术跃迁必须支付明确代价 | 神经芯片植入导致情感模块衰减；武道突破引发基因链断裂风险 |
| **数据面板叙事** | 用系统/面板实时反馈强化"科幻质感" | 能量利用率突破120%但来源未知；面板显示执行者已死亡但通讯仍在 |
| **首章/第五章埋坑规律** | 首章和第五章必埋中后期对立伏笔 | 第一章埋"人类武道实验体编号000"的设定；第五章埋"对方舰队认识主角母亲"的对立关系 |

### ⛔ 科武长篇慎用/禁用的点

| 禁用项 | 原因 | 替代方案 |
|:---|:---|:---|
| **新媒体仇恨套路** | 科幻冲突应源于理念代差/技术垄断/资源分配，纯仇恨打脸破坏科幻质感 | 用"认知分歧+立场碰撞"替代"拉仇恨-打脸"循环 |
| **千万字无规划目标** | 科幻设定易膨胀或枯竭，无架构支撑的长篇必然崩坏 | 每80万字做一次科技树迭代评估；每150万字做一次地图/势力重置 |
| **末世/都市情绪套路直接套用** | 科幻需要硬核逻辑自洽，生搬情绪套路会破坏设定可信度 | 借鉴"人性刻画结构"，但做科武本土化改造（资源争夺→技术伦理困境） |
