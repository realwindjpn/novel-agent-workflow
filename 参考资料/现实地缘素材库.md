## 八、算力修行体系（兰道原理）

### 核心公式
- E_min = k_B × T × ln 2
- 能效比 = 算力 / 能耗
- T越低→E_min越小→效率越高

### 小说化
- 太空低温环境=修行加速（天然散热）
- 方宁散热系统=降低T=提升能效比
- 境界提升=能效比提升
- 续作"词元"单位=兰道极限的文学化表达

### 贯穿逻辑
```
地球常温修行（效率低）
→ 月球真空/低温（效率提升）
→ 火星极端环境（再次提升）
→ 太空深处接近绝对零度（终极效率）
→ 戴森球=恒星级算力基础设施
```
