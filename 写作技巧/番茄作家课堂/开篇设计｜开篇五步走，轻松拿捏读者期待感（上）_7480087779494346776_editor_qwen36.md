# 《科武纪元》编辑学习官｜《开篇设计》课程提炼

## 1 课程核心判断（≤6条）
1. **开篇三要素定锚**：人物（动作显化处境）+背景（时空+冲突定位）+场景（连续动作引发价值转折），三者缺一不可。
2. **期待感=未满足的情绪落差**：开篇必须制造“危机下行→微解上行”的波浪线，且章末保留余量，禁止一次性兑现爽感。
3. **危机锚定马斯洛底层**：生理/安全/归属/尊重需求越基础，读者渴求越迫切；高层需求（自我实现）需在下层满足后递进。
4. **金手指介入时机**：必须在主角遭遇重大危机/转折后释放，且仅部分化解困境，保留成长与升级空间。
5. **拒绝信息倾销**：一切背景、设定、世界观必须拆解进“连续场景动作”中，静态说明直接削弱期待感。
6. **冲突层面绑定核心梗**：开篇冲突定位必须与书名/简介承诺完全一致，偏题即流失首波流量。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） | 长篇/短故事/热点稿适配 |
|:---|:---|:---|
| **开篇** | 首章必须完成“人物处境显化+冲突定位+价值转折”闭环。禁用编年史/设定集式起笔。 | 长篇：3章内完成转折；短故事/热点稿：前1500字必须完成一次完整转折。 |
| **节奏** | 情绪曲线按“受挫↓→微解↑→留白”循环。金手指/破局点卡在情绪谷底后1/3处释放。 | 长篇：每3-5章一个情绪循环；短故事：单章内完成2次微循环；热点稿：首段即抛落差，3000字内完成主循环。 |
| **冲突** | 冲突必须对应马斯洛底层需求，且具备时间/资源压迫感（如限时、不可逆损失）。 | 长篇：冲突可分层递进；短故事/热点稿：冲突必须单点极致，禁用多线并行。 |
| **人物** | 禁用外貌/背景/性格的静态描写。用“动作链+环境互动”折射人设锚点（如被孤立、被剥夺、被碾压）。 | 全体裁通用：人物动机必须通过“物理行为”外化，心理活动占比≤15%。 |
| **题材** | 核心梗决定冲突场景。无限流切副本生死，重生切复仇首战，科幻切生存规则/技术代差。 | 长篇：题材元素可逐步展开；短故事/热点稿：题材标签必须在首段动作中具象化。 |
| **改编** | 影视/短剧向需强化“连续时空内的动作序列”与“价值转折可视化”，弱化内心独白。 | 科武长篇改编：机甲/基因/武道动作需具备镜头可拍性；短故事改编：冲突需压缩至单一场景。 |
| **平台规则** | 番茄算法重“完读率”与“追更率”。开篇3章必须完成“危机建立-转机初现-悬念钩子”闭环。 | 长篇：卡点留钩；短故事/热点稿：首章完读率决定推荐池，前300字必须出现明确危机。 |

## 3 科武适配
### ✅ 可用点
- **动作显化人设**：科武重“体术/机甲/基因/算力”，用训练超载、装备调试、实战闪避的动作链替代“他很强/天赋异禀”的说明。
- **底层危机转化**：马斯洛需求可无缝转为科武语境（生理=氧气配额/辐射病；安全=义体排异/星区封锁；尊重=基因评级/武道考核羞辱）。
- **金手指时机控制**：“古武传承/高维算法/未知基因锁”必须在主角面临生死/阶级碾压时激活，且仅解锁初级权限（如临时过载/单次推演）。
- **场景价值转折**：开篇直切“机甲考核失败/星盗劫掠/基因检测异常/武道规则颠覆”等引发身份/命运剧变的连续事件。

### ❌ 不可硬套点
- **女频情绪模板平移**：追妻火葬场、真假千金宅斗等“人际情感憋屈”不可直接套入硬核科武。科武的压抑应源于“技术代差/资源垄断/规则碾压”。
- **唯心类金手指**：读心术、福运、反读心等易破坏科武“逻辑自洽与力量体系”。科武外挂需符合“科学推演/武道逻辑/物理规则”，避免玄学化。
- **世界观倾销**：科武设定庞大，但开篇严禁抛出星图/势力谱系/科技树。必须将设定拆解为“场景道具/战斗反馈/生存代价”，用动作带出设定。

## 4 编辑检查表（10条以内）
1. [ ] 首章是否仅通过“动作+场景互动”交代主角处境，无大段静态设定/背景说明？
2. [ ] 开篇冲突层面（生存/尊严/阶级/规则）是否与书名/简介核心梗完全一致？
3. [ ] 是否发生明确的“价值转折/不可逆变化”（如身份剥夺、生死危机、规则颠覆）？
4. [ ] 危机是否锚定马斯洛底层需求，具备时间或资源压迫感？
5. [ ] 情绪曲线是否呈现“受挫下行→微解上行→留有余量”的未满足落差？
6. [ ] 金手指/外挂是否在危机峰值后介入，且仅部分化解困境，保留升级空间？
7. [ ] 连续场景是否构成完整“动作链”，无无效过渡或视角跳跃？
8. [ ] 前3章是否完成“危机建立-转机初现-悬念钩子”闭环，符合平台完读率逻辑？
9. [ ] 科武元素（机甲/基因/武道/科技）是否以“物理反馈/使用代价”形式呈现？
10. [ ] 结尾钩子是否直接指向下一章的核心冲突或金手指进阶，而非开放式抒情？

## 5 对作家角色的输入要求
| 维度 | 输入要求（编辑审核标准） |
|:---|:---|
| **动作链** | 必须提供连续、具象、有因果递进的动作序列（例：警报响→强行超载义体→肌肉撕裂出血→反杀/逃脱）。禁用“他想了想/他决定”等心理跳跃，情节推进必须依赖物理动作。 |
| **物理反馈** | 科武世界需明确力量/科技作用的具象结果（例：能量过载导致神经灼痛、机甲关节卡顿、重力场压迫骨骼）。反馈必须可量化或可感知，替代“很强/很弱/很快”的形容词。 |
| **代价** | 任何破局/金手指使用必须伴随明确代价（例：消耗寿命/信用点/引发排异反应/暴露坐标/冷却期）。代价需与马斯洛需求挂钩，制造“获得即失去”的张力，禁止无损耗开挂。 |
| **钩子** | 章末必须抛出“未解决的次级危机”或“金手指的隐藏限制/副作用”。钩子需直接关联下一章动作链的起点，禁用情绪收尾或开放式留白。 |
| **读者预期** | 明确标注本章承诺的“情绪价值类型”（如：生存压迫→技术反杀/尊严践踏→规则破局）。预期必须与简介/书名强绑定，并在章末给出“已兑现30%，剩余70%待解锁”的进度暗示，确保追更动机。 |
