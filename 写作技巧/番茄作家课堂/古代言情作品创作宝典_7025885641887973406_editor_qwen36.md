# 《科武纪元》编辑学习官｜《古代言情作品创作宝典》规则提炼

## 1 课程核心判断（≤6条）
1. **开篇即事件**：1-3章必须抛出核心危机/目标，背景与设定需碎片化嵌入情节，忌说明书式堆砌。
2. **金手指必设限**：外挂/系统/天赋需明确边界与冷却，服务于主线推进与人物成长，忌“一键通关”破坏积累感。
3. **冲突源于欲望对立**：明确主角诉求与反派阻挠，采用“欲扬先抑+绝境给挂”结构，制造情绪起伏。
4. **长篇靠阶梯递进**：等级/地图/阶段任务需呈金字塔式升级，小目标串联大主线，防节奏拖沓或战力崩坏。
5. **人设标签需贯穿**：主角核心特质（果断/智谋/坚韧）决定行为逻辑；反派中前期极端化拉仇恨，后期可补全动机。
6. **平台算法重直给**：快节奏、强情绪、标签明确、书名直白带元素；慢热、文青、大段环境/外貌描写直接拉低留存。

## 2 可执行编辑规则
| 维度 | 规则要点 |
|:---|:---|
| **开篇** | 主角视角切入，首章亮出初始困境+核心金手指/能力；3章内完成第一次“受挫-破局”闭环；人物出场≤3个核心，忌群像乱入。 |
| **节奏** | 事件推进快，叙述去冗余；每3-5章设小高潮/爽点/悬念；连续10章无主线进展即判为“水剧情”；地图/副本切换需有明确触发条件。 |
| **冲突** | 基于资源/地位/生存/理念对立；反派动机清晰、手段递进、不降智；打脸需围绕主角优势展开，忌被碾压后靠天降外力翻盘。 |
| **人物** | 主角行为严格对齐核心标签；搭档/男主实力可高但不抢戏，强调战术互补；配角功能化（情报/辅助/副线）；反派中前期不摇摆。 |
| **题材** | 明确主线权重（升级/探险/基建/解谜）；金手指与题材强绑定（如科武侧重科技树/武道体系/遗迹破解）；世界观需有底层逻辑与天花板。 |
| **改编** | 书名直白带题材+看点（忌文艺）；简介突出核心爽点/悬念；连载期稳大纲防崩；结局伏笔全回收，主线闭环，不强制大团圆。 |
| **平台规则** | 番茄推荐机制重“开篇留存+追读率”；标签精准匹配算法池；忌现代网络梗乱入、忌大段静态描写、忌感情线喧宾夺主冲淡主线。 |

## 3 科武适配
### ✅ 可用点（直接迁移）
- **金字塔升级逻辑**：武道境界/科技代差/星域地图完美契合“底层→换图→登顶”结构。
- **金手指设限原则**：AI算力阈值/机甲能源/功法反噬/系统冷却，防战力通货膨胀。
- **阶段性任务串联**：收集星图碎片/破解遗迹密码/突破基因锁，天然适配长线连载。
- **反派极端化+配角功能化**：拉仇恨效率高，便于拆分副本与拉长故事线。
- **快节奏+碎片化设定**：完全匹配番茄算法推荐与移动端阅读习惯。

### ⛔ 不可硬套点（需替换/重构）
- **古言伦理冲突**（嫡庶/宅斗/男尊女卑）→ 替换为科武矛盾：阶级固化/AI伦理/资源垄断/文明存亡/技术垄断。
- **萌宝/团宠/甜宠模式** → 替换为战友羁绊/理念共鸣/利益同盟/战术信任，忌恋爱脑削弱主线。
- **古言职业线**（医术/厨艺/经商） → 替换为硬核技能：机甲改装/星舰指挥/基因编辑/遗迹破解/能量回路设计。
- **男主“无脑宠/强绑定”** → 科武搭档需实力对等/战术互补/理念碰撞，情感推进服从主线逻辑。
- **古风文风/辞藻堆砌** → 科武需冷峻/数据化/动作化描写，用物理反馈替代抽象形容词，忌拖慢节奏。

## 4 编辑检查表（10条）
1. 开篇3章内是否出现核心危机，并亮出主角初始目标与金手指？
2. 世界观/设定是否碎片化融入情节，无连续2章以上纯背景说明？
3. 金手指是否有明确限制/冷却/代价，未出现“一键解决”破坏期待感？
4. 每3-5章是否设置小高潮/爽点/悬念，主线推进无卡顿？
5. 冲突是否源于明确欲望对立，反派动机合理且手段递进？
6. 主角行为是否始终符合核心人设标签，无OOC或圣母/降智？
7. 等级/地图/科技树是否呈阶梯式递进，无战力/设定前后矛盾？
8. 感情线/副线是否穿插不喧宾夺主，未连续10章以上无主线进展？
9. 语言是否贴合科武基调（动作/数据/逻辑），无现代梗乱入或辞藻堆砌？
10. 阶段任务是否清晰串联大目标，伏笔/暗线在卷末/结局有明确回收？

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 必须呈现“触发→决策→执行→结果”闭环。科武战斗/操作需分步拆解（例：锁定目标→充能→规避→反击→命中），忌“意念一动秒杀”或跳过过程。 |
| **物理反馈** | 强调环境/装备/肉体的真实交互。机甲受损需报损率/火花/延迟；功法运转需经脉负荷/体温骤变；爆炸需冲击波/耳鸣/掩体碎裂。用感官细节替代抽象形容词。 |
| **代价** | 金手指/突破/胜利必须伴随明确代价（例：算力过载致脑神经灼伤/越级战斗折寿/资源消耗导致补给断档）。无代价的爽感=情绪通货膨胀，直接拉低追读。 |
| **钩子** | 章末必留悬念/危机/信息差（例：未知信号接入/队友背叛伏笔/系统提示异常/强敌降临倒计时）。忌平铺直叙收尾，断章需制造“不点下一章睡不着”的生理冲动。 |
| **读者预期** | 开篇承诺核心看点（升级/解谜/复仇/基建），后续每卷兑现并升级预期。情绪曲线严格遵循“压抑→释放→新危机”循环。简介/标签与正文必须100%对齐，忌“挂羊头卖狗肉”。 |
