# 网文创作核心技巧

## 一、开篇三章（生死线）

### 黄金300字
- 第一段必须出现**冲突或悬念**
- 禁止：天气描写、风景铺陈、自我介绍式开头
- 公式：**动作+困境+一个问题**

```
❌ 天很蓝，阳光洒在林星辰脸上，他深吸一口气。
✅ 门被踹开的瞬间，林星辰握紧了桌下的刀。
```

### 第一章铁律
- 3000字内完成：主角出场、核心困境展示、至少一次反转
- 读者不知道为什么要继续读 = 失败

## 二、节奏控制

### 三拍节奏
每章遵循「张→弛→张」或「起→承→转」：
1. **起**：切入场景，抛出问题或动作
2. **承**：推进、展开、加入新信息
3. **转**：反转/悬念/意外，驱动翻页

### 章末钩子类型
| 类型 | 示例 | 使用频率 |
|------|------|---------|
| 悬念型 | "他推开门，愣住了。" | 常用 |
| 反转型 | 真相与预期相反 | 适度 |
| 危机型 | 倒计时/威胁逼近 | 适度 |
| 伏笔型 | 一个不起眼的细节 | 少用 |
| 情感型 | 角色做出意外选择 | 少用 |

**注意**：钩子必须从场景动作中自然生长，不要硬贴末尾。

### 禁止的节奏错误
- 连续三章以上无冲突（拖沓）
- 连续三章都是打斗（疲劳）
- 每章结尾都是悬念（读者麻木）
- 信息倾倒超过500字（说教）

## 三、人物塑造

### 区分角色的三个维度
1. **语言习惯**：口头禅、句式长短、用词风格
2. **行为模式**：遇到危机的第一反应（冲/逃/算/忍）
3. **价值观**：在关键抉择时暴露真实立场

### 对话技巧
- 每人说的话必须能**被认出是谁**（去掉名字标签后）
- 对话推进剧情或暴露性格，**至少满足一项**
- 禁止「说明书式对话」（借角色嘴给读者科普超过3句）

```
❌ "这个量子芯片采用了3纳米工艺，功耗降低了40%，算力提升了三倍……"
✅ "别问我原理，我只知道——插上这东西，他快了三倍。"
```

### 群像管理
- 每卷核心角色≤6人，超过则轮换登场
- 配角每次出场至少一个**辨识动作或特征**
- 不要让所有配角围主角转，给他们自己的事做

## 四、冲突设计

### 冲突层次
| 层级 | 例子 | 驱动力 |
|------|------|--------|
| 生存 | 被追杀、缺资源 | 本能 |
| 利益 | 争地盘、抢技术 | 贪欲 |
| 信念 | 路线之争、善恶抉择 | 价值观 |
| 命运 | 对抗预言/宿命 | 意志 |

每章至少涉及一层冲突。连续无冲突 = 注水。

### 反派设计原则
- 反派必须有自己的**合理动机**（站在他的角度说得通）
- 反派的智商决定作品的质感
- 禁止「为坏而坏」的纸片反派

## 五、世界观呈现

### 冰山法则
读者看到的只是冰山一角，但作者必须知道整座冰山。

- 设定写进文档，**不写进正文**
- 正文中通过**角色行为和结果**暗示设定
- 每次解释世界观不超过3句，分散在不同章节

```
❌ "灵境体系分为九重，每重又有初阶、中阶、高阶三个小境界……"（百科词条）
✅ "他出拳的速度比上周快了一截——突破灵境二重后，肌肉反应阈值降了三成。"（融入动作）
```

### 信息释放节奏
- 前10章：只释放主角生存必需的设定
- 10-30章：逐步展开世界规则
- 30章后：才允许出现系统性说明（仍然要短）

## 六、感官与细节

### 五感调用
每章至少调用**两种以上感官**：
- 视觉：颜色、光影、动作
- 听觉：环境声、对话语气、沉默
- 触觉：温度、质感、疼痛
- 嗅觉：场景氛围（血腥味、机油味、泥土味）
- 味觉：特殊时刻（紧张时嘴里的铁锈味）

### 细节选择原则
- 选**不寻常**的细节（所有人都能想到的 = 废话）
- 一个精准细节 > 三段形容词
- 细节服务于情绪或暗示，不是装饰

```
❌ 她很漂亮，长发飘飘，眼睛像星星。
✅ 她咬笔帽的次数和方案的漏洞数成正比。
```

## 七、情感共鸣

### 情绪曲线
- 高潮前必须有**压抑**（反弹高度取决于下压深度）
- 不要让角色始终处于高亢状态
- 安静时刻比爆发时刻更难写、也更打动人

### 催泪技巧（克制使用）
- **反差**：硬汉的脆弱瞬间
- **遗憾**：差一点就……
- **认同**：读者在角色身上看到自己
- **牺牲**：为信念/他人付出的代价

### 禁止的情感操作
- 强行卖惨（密集悲惨事件堆砌）
- 滥用内心独白解释情绪（"他感到无比悲伤"）
- 死亡当作廉价催泪工具

## 八、修改与打磨

### 自检清单
- [ ] 删掉所有「微微」「淡淡」「不禁」「缓缓」
- [ ] 检查对话：去掉名字后能认出说话人吗？
- [ ] 检查节奏：连续两段无动作/对话 = 可能注水
- [ ] 检查钩子：末尾悬念是从场景生长的吗？
- [ ] 检查信息量：本章删掉后，后续有影响吗？没有 = 废章

### 精简原则
- 能用一句话说清的不用两句
- 能用动作展示的不用心理描写
- 能用对话暗示的不用旁白说明
- 每删一个词，问：删了影响理解吗？不影响 = 该删

## 九、网文特有技巧

### 断章艺术
- 在**最高潮处断**，不要在总结处断
- 在**选择瞬间断**，不要在选择之后断
- 在**信息半透明断**（读者知道有事，不知道什么事）

### 期待管理
- 每5章制造一个中期期待
- 每20章制造一个大期待
- 期待必须兑现，否则透支信任

### 日更节奏（如适用）
- 每更至少一个完整场景
- 不在场景中间断更（读者体验极差）
- 今天的钩子 = 明天的开头素材

## 十、常见病与药方

| 病症 | 表现 | 药方 |
|------|------|------|
| AI味 | 微微、淡淡、不禁 | 全文搜索替换，改用具体动作 |
| 注水 | 3000字说了1000字的事 | 删减30%，压缩到核心动作 |
| 说教 | 大段设定解释 | 拆散到行为和对话中 |
| 脸谱化 | 好人全好、坏人全坏 | 给反派加合理动机 |
| 节奏平 | 每章情绪一样 | 画情绪曲线图，调整起伏 |
| 悬念过载 | 每章结尾都留钩子 | 3章一个大钩子，中间用小收束 |
| 对话同质 | 换名字看不出区别 | 给每个角色写语言样本 |
