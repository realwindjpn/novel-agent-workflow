# 作家OS补丁：完结操作系统 v1.0

## 一、核心操作链（必须单向执行）

```
开篇钩子铺设 → 8万字推荐阈值 → 主线收束 → 伏笔闭环 → 番外定稿 → 提交审核 → 3工作日等待 → 状态锁定
```

**注意**：不可逆向操作，不可边更边改。

---

## 二、写作前任务卡字段更新

### 【开篇期·强制字段】

| 字段 | 要求 | 科武长篇 | 短故事/狼人 |
|:---|:---|:---|:---|
| 核心悬念 | 必须在第1章抛出，可支撑完整结局 | 武道体系起源/人类进化主线钩子 | 单线悬念闭环即可 |
| 世界观锚点 | 3章内建立不可逆的核心设定 | 科武融合规则、基因链锁机制 | 场景规则自洽即可 |
| 人物弧光起点 | 主角目标必须明确指向终局 | 武道觉醒→文明抉择双线 | 单角色动机清晰即可 |

**❌ 禁止项**：开篇设悬念但不打算在结局回收（触发审核驳回）。

---

### 【8万字节点·任务卡检查】

| 检查项 | 操作 |
|:---|:---|
| 推荐池状态 | 确认已进入推荐池，否则永久损失长尾流量 |
| 主线进度 | 核心冲突已触发并进入收束阶段（非拖沓注水） |
| 番外预案 | 列出所有需要番外补充的设定，标记完成优先级 |

---

### 【完结前·任务卡锁定】

| 字段 | 操作 |
|:---|:---|
| 主线闭环 | 核心冲突已解决，无悬而未决的废线 |
| 伏笔回收 | 所有埋设伏笔已落地或明确废弃说明 |
| 人物落地 | 主要角色弧光有明确终点，无中途崩塌 |
| 番外定稿 | 所有番外/补充设定已完成并定稿 |
| 设定冻结 | 科幻设定/武道体系逻辑自洽，参数已冻结 |

**❌ 禁止项**：未写完番外就申请完结（正文锁定后无法补坑）。

## 三、章节自检清单（每章提交前必核）

```
□ 本章是否推进主线冲突？
□ 本章是否埋设/回收伏笔？（标记伏笔编号）
□ 本章人物行为是否符合已建立的人设？
□ 本章是否存在机械降神/逻辑断裂？
□ 本章是否产生新悬念但未计划回收？（❌禁止）
□ 本章字数是否因凑字数而注水？（❌禁止）
□ 本章是否为完结前章？（若是，执行完结前专项检查）
```

### 完结前专项（倒计时3章触发）

```
□ 核心冲突是否进入最终解决阶段？
□ 所有伏笔是否已回收或主动废弃？
□ 结局是否逻辑闭合，无机械降神？
□ 番外是否已完成并定稿？
□ 正文是否已冻结？（❌完结后不可修改）
□ 人物结局是否已明确呈现？
```

## 四、风险门禁（平台规则→作家可执行指令）

### 【提交前·硬性门禁】

| 门禁项 | 触发条件 | 后果 | 操作指令 |
|:---|:---|:---|:---|
| 字数门槛 | <8万字申请完结 | 永久损失推荐流量池 | 确认字数≥8万且已入推荐池 |
| 状态锁定 | 提交后正文不可修改 | 永久关闭编辑权限 | 提交前完成所有修改 |
| 不可撤销 | 申请完结后 | 状态不可逆 | 确认完结意愿后再提交 |
| 无完结推 | 依赖完结冲流量 | 无额外推流 | 靠内容质量维持推荐 |
| 多书名实验限制 | <100万字开启实验 | 永久丧失实验资格 | 确认字数≥100万再申请实验 |
| 驳回成本 | 烂尾/仓促被驳回 | 需补全内容，期间不可正常更新 | 提前自检，避免驳回 |

### 【状态异常·强制重置】

| 原状态 | 操作风险 | 正确流程 |
|:---|:---|:---|
| 断更 | 直接申请完结 | 先恢复更新，再申请完结 |
| 隐藏 | 直接申请完结 | 先公开作品，再申请完结 |

**注**：申请成功后，强制解除断更/隐藏状态并公开。

## 五、代价与失败模式

### 【触发条件与后果】

| 失败模式 | 触发条件 | 即时后果 | 长期代价 |
|:---|:---|:---|:---|
| 流量损失 | 未达8万字提前完结 | 推荐池永久关闭 | 长尾流量归零 |
| 正文锁定 | 提交完结申请 | 编辑权限永久关闭 | 无法修改、无法新增章节/番外 |
| 烂尾判定 | 核心冲突未闭环/逻辑断裂/人物弃线 | 审核驳回 | 补全期间不可正常更新，消耗推荐期 |
| 实验资格丧失 | <100万字开启多书名实验 | 资格永久取消 | 无法测试标签流量转化 |
| 设定冻结失败 | 完结后修改正文 | ❌不可操作 | 所有逻辑错误永久留存 |

### 【规避指令】

```
核心冲突 → 必须闭环
伏笔 → 必须回收或主动废弃
番外 → 必须先写完再申请
字数 → 必须≥8万字
状态 → 必须正常（无断更/隐藏）才能申请
```

## 六、借点标注

### 📌 短故事/狼人篇可借点

| 模块 | 借点说明 |
|:---|:---|

**注意**：短故事通常<8万字，不建议申请平台完结，可选择完本但不申请完结状态。

### 📌 科武长篇可借点

| 模块 | 借点说明 |
|:---|:---|
| 任务卡·开篇期 | 世界观锚点（科武融合规则）3章内建立，参数冻结 |
| 任务卡·8万字节点 | 确认进入推荐池，规划番外预案 |
