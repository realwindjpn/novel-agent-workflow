# 代入感设计｜塑造代入感的六大核心技巧｜作家OS转译稿

model: gpt-5.5
source: https://fanqienovel.com/writer/zone/article/7514519759442935832

## 一、10条写法规则｜作家OS补丁

1. **开篇100字打钉子**  
   写清：谁 / 在哪 / 正在遭遇什么 / 一个记忆标签。  
   禁止空泛开场，禁止先讲世界观。

2. **用动作或台词带出人设**  
   不写“他很倔”。  
   改写成：“他把断掉的义肢插回接口，咬着牙说：‘还没判我输。’”

3. **每章必须有一个情绪缺口**  
   读者要明确想看：打脸、揭穿、反杀、逃出生天、真相曝光、关系破裂。  
   缺口没释放前，不要松节奏。

4. **释放要比预期多一档**  
   读者期待主角赢，就让他不仅赢，还暴露隐藏底牌 / 反坑对方 / 拿到关键情报。  
   只完成70%，等于没爽到。

5. **主角选择必须让读者站队**  
   冲突不是为了吵架，是为了逼主角选择。  
   选择要贴近目标读者价值观：不跪、不怂、有底线、有反击。

6. **人物标签五件套必填**  
   外貌 / 身份 / 口头禅或动作癖 / 生理特征 / 微缺点。  
   微缺点选懒、馋、嘴硬、怕疼、社恐等共性缺点，别破坏核心魅力。

7. **能力描写必须有动作链**  
   每次出手写：起手 → 发力 → 命中/失败反馈。  
   禁止“他一拳秒杀”。  
   要写身体、武器、环境如何参与。

8. **每次收益必须有代价**  
   升级、胜利、拿情报、救人，都要付出伤、债、时间、关系、名声或道德压力。  
   无代价 = 无张力。

9. **大场景强插五感**  
   至少放1—2个可感知细节：焦味、耳鸣、汗湿短袖、铁皮震颤、消毒水味、皮肤电麻。  
   设定必须翻译成身体感受。

10. **章末只留一个强钩**  
   明钩：提出悬念问题。  
   暗钩：读者知道危险，主角不知道。  
   写作前任务卡新增字段：  
   - 本章情绪缺口：  
   - 读者期待一句话：  
   - 预计释放章节：  
   - 主角动作链：  
   - 能力物理反馈：  
   - 本章收益与代价：  
   - 章末钩子类型：明钩/暗钩：  
   - 人物微缺点暴露场合：  
   - 主要五感细节：  
   - 风险门禁：是否涉平台敏感/过度血腥/低俗擦边/价值观反向。  


## 二、10条章节自检清单

1. 开篇100字内是否出现：主角、地点、事件、记忆点？  
2. 本章有没有一个明确情绪缺口？读者知道自己在等什么吗？  
3. 情绪释放是否超过读者预期，而不是刚好完成？  
4. 主角是否做出选择？这个选择是否能让读者站他？  
5. 主角行动是否有三步以上动作链，而不是跳步秒杀？  
6. 能力、武道、科技施展后，是否有身体反馈或环境反馈？  
7. 本章主角获得的好处，是否付出了对应代价？  
8. 人物标签是否稳定？微缺点有没有在非主场景、反差场暴露？  
9. 大场景是否至少有一种五感？术语是否转化成可感知画面？  
10. 章末是否有钩子，并标明预计释放点？是否通过发布/包装/风险门禁？  


## 三、3条科武落地

1. **科武长篇可借点**  
   首章100字内交代：科技段位 / 武道根骨 / 阵营 / 外显特征。  
   用“科技派轻视武者、武者藏科技底牌”做信息差，打出憋屈→扬眉吐气。

2. **短故事 / 狼人篇可借点**  
   用熟悉情绪切入：被排挤、被误解、被迫站队、身份藏不住。  
   狼人篇可用“众人不知道他是狼人/他不知道猎人已锁定他”的暗钩制造代入。

3. **发布包装与风险门禁**  
   标题、简介、开篇要低门槛、强标签、白话冲突。  
   科幻设定保留精度，冲突对白下沉。  
   发布前检查：不堆术语、不血腥猎奇、不低俗擦边、不让主角价值观塌。
