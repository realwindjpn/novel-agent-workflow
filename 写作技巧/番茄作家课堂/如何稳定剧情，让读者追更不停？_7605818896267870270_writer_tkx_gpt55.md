# 《科武纪元》作家OS补丁  
## Patch：稳定剧情 / 提升追更 / 防中期塌陷

版本：`Plot-Stability_追更不停_v1.0`  
适用：科武长篇 / 短故事 / 狼人篇 / 热点稿  
核心指令：**不要解释世界，先制造问题；不要展示金手指，先让它推动动作；不要平章收尾，每章必须留下未完成感。**

---

# 01. 开篇执行补丁：第一页必须抓人

## 1）第一页动作规则

### 必须执行

第一页内必须出现：

```text
主角处在一个具体压力场景中。
主角正在做一件反常动作。
页尾出现一个反预期问题 / 反预期声明 / 规则反转。
```

### 禁止执行

第一页禁止：

```text
世界观说明
势力介绍
修炼等级说明
主角身世长篇回忆
系统面板自我介绍
“我叫XXX，是一个普通人”
华丽空景开头
```

---

## 2）科武长篇可借点

科武世界再大，第一页也不许先讲纪元史。

### 推荐开法

```text
科研所 / 武院 / 战场 / 隔离舱 / 黑市手术台 / 外骨骼测试场
```

让主角第一幕就处在“科学规则”和“武道规则”冲突点上。

### 示例方向

```text
主角在军方实验室偷偷练气。
监控AI检测到异常能量波动。
主角以为自己要被抓。
结果AI弹出一句：

“别停。你的呼吸频率，和三百年前失踪的第一武祖一致。”
```

章页尾问题：

```text
AI为什么认识武祖？
主角练的到底是不是禁术？
科研所到底在监控人，还是在筛选人？
```

---

## 3）短故事 / 狼人篇可借点

短故事和狼人篇可以更狠、更快、更反差。

### 可用开法

```text
第一句就给死亡倒计时。
第一段就给身份错位。
第一页结尾直接抛出“狼人不是敌人”的反转。
```

### 示例方向

```text
村里每晚都死一个人。
所有人都怀疑我是狼人。
但只有我知道——

真正的狼人，白天会主持审判。
```

短故事可借重点：

```text
反差身份
死亡倒计时
第一页反转
少设定，多审判现场
```

# 02. 金手指补丁：不是面板，是剧情发动机

## 1）金手指使用原则

金手指不能只是：

```text
属性面板
等级说明
任务发布
奖励结算
```

金手指必须完成：

```text
逼主角做决定
改变战斗结果
揭露错误信息
制造新代价
打开下一层冲突
```

---

## 2）科武长篇可借点

《科武纪元》的金手指建议无形化、低说明、高反馈。

### 推荐形态

```text
异常感知
战斗预判
数据污染识别
身体极限短暂解锁
古武功法与科技仪器共鸣
敌方能量模型反推
```

### 禁止写法

```text
【宿主：林辰】
【力量：10】
【速度：10】
【精神：10】
【任务：打败敌人】
```

除非面板本身会骗人、会污染、会收费、会反噬。

---

## 3）金手指每次出现必须绑定四件事

每次使用金手指，正文必须写出：

```text
动作：主角用它做了什么？
反馈：身体 / 环境发生什么变化？
代价：失去了什么？
后果：引出了什么新问题？
```

### 示例

```text
动作：主角用异常感知锁定敌方外骨骼弱点。
反馈：右眼毛细血管破裂，视野变成红色。
代价：接下来三分钟无法判断距离。
后果：敌人发现他能读取机甲频率，开始怀疑他不是普通武徒。
```

---

## 4）金手指升级阶梯

必须分级释放，禁止一步到位。

### 科武长篇建议五级

```text
Level 1：异常直觉
只能感到“不对劲”。

Level 2：局部识别
能看出敌方动作 / 设备 / 能量读数的异常点。

Level 3：短时预判
能提前0.5秒判断攻击轨迹，但严重消耗神经。

Level 4：规则反推
能从一次现象反推背后科技或武道规则。

Level 5：主动干涉
短暂修改自身能量循环 / 设备频率 / 战斗节奏。
```

每一级升级必须付费：

```text
身体损伤
寿命折损
记忆污染
设备报废
身份暴露
同伴牺牲
被高层盯上
```

---

# 03. 章节节奏补丁：每章必须有钩子

## 1）章末钩子标准

每章最后300字必须存在一个：

```text
未完成动作
未回答问题
身份反转
规则揭示
角色危机
```

如果章末可以概括为：

```text
大家休息了。
主角回家了。
明天再说。
这一战结束了。
```

则判定为：**平章，需重写。**

---

## 2）钩子五类轮换

每章章末标注钩子类型，避免疲劳。

```text
【对白反差】
角色说出和读者预期相反的话。

【动作未完成】
门刚打开、刀刚落下、信号刚接通，章断。

【信息反转】
读者以为A是真相，章末告诉他A只是表层。

【角色危机】
重要人物濒死、失踪、背叛、被污染。

【规则揭示】
世界规则突然多出一条更残酷的限制。
```

---

## 3）科武长篇可借点

科武钩子不要只靠喊话，要多用技术反转。

### 可用钩子

```text
监测仪显示主角不是人类标准样本。
敌方机甲识别主角为“旧纪元遗产”。
主角打赢后，战斗记录被自动上报到最高权限。
队友死前说出的坐标，竟然是主角出生地。
古武招式触发了实验室封存三百年的警报。
```

---

## 4）短故事 / 狼人篇可借点

狼人篇章末可以更直接：

```text
今晚要投票处决的人，突然指认主角是狼。
死者尸体上，有主角白天留下的标记。
预言家验出主角是好人，但预言家下一秒死了。
狼人杀人规则被改写：今晚死两个。
```

短故事钩子优先级：

```text
身份反转 > 死亡威胁 > 规则变化 > 证据翻盘
```

---

# 04. 中期防塌补丁：不要强换地图，用伏笔和配角换剧情

## 1）中期推进合法手段

中期卡住时，只允许优先使用：

```text
伏笔回收
配角冲突
配角死亡
旧规则反转
旧敌人升级
主角代价追债
```

谨慎使用：

```text
突然换城市
突然换星球
突然开新副本
突然来一个更大的组织
```

如果换地图不能回收前文伏笔，就是逃避主线。

---

## 2）伏笔埋设要求

前10万字必须埋至少三类伏笔：

```text
语言伏笔：某个NPC随口一句异常话。
环境伏笔：某个地点、设备、尸体、墙上标记。
数据伏笔：时间、坐标、能量读数、实验编号、频率。
```

### 科武长篇可借点

科幻题材最适合数据伏笔。

示例：

```text
第12章：实验舱温度一直是17.4℃。
第58章：敌方遗迹也保持17.4℃。
第91章：揭示17.4℃是旧纪元武者脑死亡前的恒温保护值。
```

这种伏笔比单纯“某人神秘一笑”更硬。

---

## 3）配角使用规则

配角不是库存，是燃料。

每个重要配角建立时必须预设：

```text
功能：他推动哪条剧情？
秘密：他隐藏什么信息？
羁绊：他和主角有什么情感/利益连接？
消失节点：他在哪个阶段离队、背叛、死亡或升格？
死亡价值：如果死，他换来什么设定推进？
```

---

## 4）配角死亡限制

可以死，但不能乱死。

配角死亡必须至少完成一项：

```text
揭示世界规则
逼主角升级
引爆派系冲突
暴露敌方底牌
让主角承担不可逆代价
清理长期未使用角色的逻辑负债
```

禁止：

```text
为了虐而死
为了刺激而死
刚出场没建立关系就死
死后不改变任何剧情结构
```

---

# 05. 人物口吻补丁

## 1）主角口吻

科武长篇主角建议：

```text
少喊口号
少解释自己
多用判断句
多用行动压过情绪
受伤时先处理局面，再暴露情绪
```

### 示例口吻

不推荐：

```text
“我一定要变强，我绝不会让任何人再伤害我的同伴！”
```

推荐：

```text
“止血带给我。三十秒后他们会第二次冲锋。”
```

这种口吻更稳、更硬。

---

## 2）金手指 / AI / 系统口吻

如果有AI，不要像客服。

不推荐：

```text
“叮！恭喜宿主获得奖励！”
```

推荐：

```text
“你的右肺已经无法承受第二次共振。继续运行，存活率31%。”
```

或者：

```text
“检测到旧纪元武道协议。权限错误。你不该还活着。”
```

---

## 3）反派口吻

反派不要只会狂笑。

推荐：

```text
冷静宣布规则
用数据压迫主角
把主角当样本、资产、污染源
```

示例：

```text
“别杀他。他不是武徒，是一段活着的旧纪元参数。”
```

---

## 4）短故事 / 狼人篇口吻

狼人篇可以更锋利、更短句。

示例：

```text
“昨晚死的是猎人。”
“他说过，死后会带走一匹狼。”
“可他开枪打死了预言家。”
```

短故事原则：

```text
短句
强信息
少解释
每段都推进身份判断
```

---

# 06. 段落节奏补丁

## 1）科武长篇段落节奏

建议一章内部使用：

```text
动作段 → 反馈段 → 信息段 → 冲突升级段 → 代价段 → 钩子段
```

### 每段职责

```text
动作段：主角做事，不许只想。
反馈段：写痛感、声音、温度、能耗、设备变化。
信息段：只给当前动作必须知道的信息。
冲突升级段：敌人/环境/规则反扑。
代价段：主角拿到东西，同时失去东西。
钩子段：留下未完成感。
```

---

## 2）段落长度控制

```text
战斗/危机段：短句，1-3行一段。
设定说明段：不超过5行，且必须夹在动作中。
情绪段：不超过3段，且必须被动作打断。
系统/数据段：不超过3段，超过则压缩为一句结果。
```

---

## 3）水字数警报

出现以下内容，直接删或改成动作：

```text
主角反复震惊
主角反复感慨
旁白重复解释等级
系统重复播报奖励
人物站着聊天超过一页
战斗中停下来讲设定
章末用总结句收尾
```

---

# 07. 动作 / 反馈 / 代价执行模板

每章至少写清楚一条完整链路：

```text
目标：主角本章要拿到什么？
动作：主角采取什么物理行动？
阻碍：谁/什么规则阻止他？
能力：他如何使用能力？
反馈：身体或环境产生什么反应？
代价：他失去什么？
结果：是否达成目标？
钩子：结果引出什么更大问题？
```

### 科武示例

```text
目标：盗取实验室旧纪元数据。
动作：潜入→屏蔽监控→贴近冷冻舱→读取芯片→撤离。
阻碍：安保AI识别到他的呼吸频率异常。
能力：主角用异常感知找到监控死角。
反馈：耳膜刺痛，鼻腔出血，冷冻舱温度下降。
代价：外骨骼电池报废，身份被记录。
结果：数据拿到一半。
钩子：数据末尾出现主角自己的出生编号。
```

# 08. 发布 / 包装 / 风险门禁

平台规则不写成抱怨，转成操作门禁。

## 1）书名门禁

发布前检查：

```text
书名是否一眼看出题材？
是否有核心卖点？
是否避免过度文艺化？
是否能让男频读者知道主角会变强？
```

科武长篇书名方向：

```text
科武
纪元
旧神
武道协议
机械飞升
神经武装
禁区
序列
```

避免：

```text
太抽象
太诗化
太像纯文学
看不出爽点
```

---

## 2）简介门禁

简介必须包含：

```text
主角身份
异常开局
核心金手指/能力
主要冲突
升级期待
一句钩子
```

禁止简介写成世界观百科。

### 简介结构

```text
第一句：主角遭遇异常事件。
第二句：能力出现，但带代价。
第三句：敌人/组织/世界规则压迫。
第四句：主角要走的升级路线。
第五句：最大悬念。
```

---

## 3）前10万字门禁

前10万字必须完成：

```text
第一页抓人
前三章连续钩子
金手指推动剧情
主角完成第一次主动选择
出现明确敌人或压迫系统
埋下至少3个中期伏笔
完成一次小高潮
展示至少一次代价
重要配角至少2名有功能
```

如果首秀差，优先倒查：

```text
第一页是否劝退
金手指是否水
前三章是否没有动作
章末是否平
前10万字是否只铺设定
```

不要第一时间归因：

```text
平台不推
算法问题
读者不懂
题材冷
```

---

## 4）风险门禁

以下情况不发布，先返修：

```text
第一章第一页全是背景。
金手指首次出现没有推动动作。
前三章没有明确冲突。
章末没有悬念。
主角只被动挨打，没有主动选择。
设定说明连续超过一页。
配角出场无功能。
前10万字没有中期伏笔。
```

# 10. 章节自检清单

写完后逐条打勾。

```text
[ ] 第一页是否出现具体压力场景？
[ ] 第一页页尾是否有反预期问题或声明？
[ ] 第一页是否砍掉了多余背景介绍？
[ ] 主角本章是否至少完成3个物理动作？
[ ] 主角是否有主动选择，而不是全程被推着走？
[ ] 金手指/能力是否推动了具体剧情动作？
[ ] 能力使用后是否写出身体或环境反馈？
[ ] 主角本章是否“得到一样东西，同时失去一样东西”？
[ ] 本章是否有敌人、规则或环境反扑？
[ ] 本章是否兑现了上一章章末承诺？
[ ] 本章是否新埋或回收了一个伏笔？
[ ] 数据、坐标、温度、编号等科武元素是否服务剧情，而非装饰？
[ ] 配角出场是否有功能？
[ ] 是否有重要配角连续5章未出现？需要使用、转移或折损。
[ ] 是否存在超过一页的站桩聊天？
[ ] 是否存在超过3段的系统/面板独白？
[ ] 是否存在战斗中停下来讲设定？
```

# 11. 失败模式与修复指令

## 失败模式1：开篇像设定集

症状：

```text
第一页讲纪元背景、势力划分、科技等级。
主角迟迟不行动。
```

修复：

```text
把背景改成现场压力。
把纪元史压缩成一句环境细节。
让主角第一页就犯规、逃命、测试、潜入或被识别。
```

---

## 失败模式2：金手指像说明书

症状：

```text
系统讲了很多。
主角没因此做出新动作。
```

修复：

```text
删面板。
改成一次危机中的短暂提示。
提示必须让主角改变动作。
使用后必须付出代价。
```

---

## 失败模式3：章末平掉

症状：

```text
打完了。
睡了。
散会了。
明天继续。
```

修复：

```text
把结局提前300字。
最后300字新增反扑、反转、异常读数或未接通通讯。
```

---

## 失败模式4：中期靠换地图续命

症状：

```text
原地图没写透，突然去新城、新星球、新学院。
旧人物和伏笔全部丢失。
```

修复：

```text
先回收一个旧伏笔。
让旧配角带来新冲突。
让旧敌人升级。
让主角之前的代价开始追债。
```

---

## 失败模式5：配角太安全

症状：

```text
队友都在，但都没用。
谁也不死，谁也不背叛，谁也不推进剧情。
```

修复：

```text
给每个配角标注功能。
连续5章不用的配角，要么派任务，要么折损，要么离队。
重要配角死亡必须换来设定推进。
```

# 12. 最终执行口令

写《科武纪元》时，每章只问七个问题：

```text
主角这章做了什么？
能力推动了什么？
身体付出了什么？
剧情失去了什么？
伏笔埋下或回收了什么？
配角燃烧了什么？
章末让读者想知道什么？
```

一句话补丁：

```text
首页抓人，动作推进，能力收费，反馈落地，伏笔续命，配角燃烧，章末不许平。
```
