## 一、写作前任务卡（字段更新）

> **每次开篇/章节启动前必填**

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **核心脑洞** | ≤15字，1句话说清创意核心 | "废土拳手以寿命兑换基因觉醒" |
| **现实欲望锚点** | 主角当前最迫切的人性需求 | "被公司除名、女儿医疗费、证明自己不是废物" |
| **本章爽点类型** | 确定性爽感/不确定性探索二选一 | 确定性：战力碾压✅ / 不确定性：规则真相浮现❌ |
| **代价注入点** | 本章使用了何种力量，代价几何 | "第二次觉醒+10年寿命，触发早期认知污染" |
| **章末钩子** | 必须与核心脑洞强关联的信息差/临界点 | "功法反噬倒计时：剩余3次/基因编译界面异常闪烁" |
| **留白预留** | 本章不解释、留给后续爆点的内容 | "师父为何禁用这套功法——未解释" |
| **类型溢出伏笔** | 爽感之外暗示深层命题的细节 | "觉醒者瞳孔泛蓝、瞳孔识别系统无法读取" |

## 二、可执行动作库（写作时直接调用）

### 2.1 开篇动作链（前三章必做）

```
动作1 → 抛出脑洞/金手指（≤第1章第3段）
动作2 → 绑定主角现实欲望（生存/尊严/守护/复仇）
动作3 → 完成一次"能力验证"（金手指首次生效，打脸/脱困/逆袭）
动作4 → 留下核心悬念（规则/代价/威胁/真相）
```

**禁止动作**：
- ❌ 前三章出现大段设定说明书
- ❌ 主角无现实困境，纯"系统附身我要变强"开场
- ❌ 能力验证后立即无敌，爽感断崖

### 2.2 科武战斗描写动作链

```
[意图层] 战意凝聚/动机激活
    ↓
[发力层] 丹田/灵能回路/神经接口启动
    ↓
[轨迹层] 能量输出路径（经脉/管线/量子通道）
    ↓
[命中层] 打击点确认 + 环境介质交互（空气/护盾/重力场）
    ↓
[反馈层] 对方躯体/装备响应 + 视觉/听觉/嗅觉/触觉反馈
    ↓
[代价层] 自身代价触发（体温/骨骼/神经/意识）
```

**示例模板**：
> 林岳右腿股四头肌猛然绷紧，灵力经督脉倒灌入右拳——不是挥出，是**轰**出去。拳锋突破空气的瞬间，前方三米范围内的氧分子被瞬间电离，刺鼻的臭氧味弥漫开来。护盾碎裂的脆响与李昊闷哼同时传来。林岳感到右手食指传来一阵刺痛，低头看见皮肤下灵纹过载的蓝光正在消退。

### 2.3 钩子设置动作（每章必须）

**四选一，不得空白**：

| 钩子类型 | 动作描述 | 示例 |
|:---|:---|:---|
| **信息差** | 抛出读者不知道、主角也不知道的关键信息 | "数据库中，关于'甲子号遗民'的记录被人为删除" |
| **临界点** | 设置倒计时/资源耗尽/濒临突破的紧迫状态 | "心魔劫还剩72小时，而她的理智值已跌破40%" |
| **选择悖论** | 抛出一个没有正确答案的两难抉择 | "救队友还是拿钥匙——钥匙只有一把" |
| **真相碎片** | 暗示深层规则的异常/矛盾 | "为什么所有高维觉醒者都是孤儿？" |

### 2.4 节奏调控动作（防断更疲劳）

**触发条件**：连续≥3章纯设定/纯修炼/无冲突推进

**执行动作**：
```
动作A → 插入"现实映射缓坡"（人性困境/社会讽刺/情感羁绊）
动作B → 切线至敌方视角/配视角，展示另一利益方诉求
动作C → 插入"代价可视化"场景（角色为此前的力量付出真实代价）
动作D → 释放一个小目标（支线任务/资源争夺/关系推进）恢复追读
```

## 三、代价系统（力量-代价动态平衡表）

> **力量获取必须绑定代价，代价随剧情指数级放大**

| 力量类型 | 初期代价（1-30章） | 中期代价（31-100章） | 高阶代价（100章+） |
|:---|:---|:---|:---|
| **基因觉醒** | 体能暂时下降/适应期疼痛 | 遗传缺陷风险/外貌异变/身份识别失效 | 子代基因污染/人类定义动摇 |
| **金手指使用** | 灵力/体力透支 | 神经回路损耗/短期记忆模糊 | 意识碎片化/情感剥离 |
| **规则破解** | 认知污染（轻微幻视） | 认知污染（时空感知错位） | 存在根基动摇（不再是"人类"） |
| **资源获取** | 经济/社会代价 | 人际关系断裂 | 核心价值崩塌 |

**禁止模式**：无代价升级、无理由顿悟、能力无限叠加

## 四、失败模式识别（自检警示）

### 4.1 开篇失败模式

| 失败症状 | 判断标准 | 修复动作 |
|:---|:---|:---|
| **脑洞延迟** | 第1章结束读者仍不知道核心创意 | 重写前3段，强制插入脑洞场景 |
| **欲望缺位** | 主角行为缺乏人性动机 | 增加现实困境场景（妻女/债务/尊严） |
| **能力未验证** | 前3章主角未用金手指解决任何问题 | 插入1次能力验证战斗/脱困场景 |
| **设定说明书** | 单章出现≥2段纯背景解释 | 改为对话/冲突/情景带出 |

### 4.2 节奏失败模式

| 失败症状 | 判断标准 | 修复动作 |
|:---|:---|:---|
| **连续三章无冲突** | 3章内无正反对抗/目标未推进 | 插入支线冲突或揭示威胁 |
| **爽感断崖** | 段评/追读数据连续下滑≥2章 | 快速切线回收伏笔或插入爆点 |
| **代价缺位** | 连续升级无代价触发 | 插入代价可视化场景 |
| **预期欺诈** | 铺垫科技侧却转玄幻/铺垫实力却突然无敌 | 重写转场逻辑，确保类型一致 |

### 4.3 人物失败模式

| 失败症状 | 判断标准 | 修复动作 |
|:---|:---|:---|
| **工具人配角** | 配角仅在需要时出现，无独立诉求 | 增加配角独立视角场景 |
| **绝对理性主角** | 主角所有决策都是"最优解" | 插入情感失误/冲动决策场景 |
| **反派扁平** | 敌人仅作为战力数值存在 | 增加反派动机场景 |

### 4.4 科武设定失败模式

| 失败症状 | 判断标准 | 修复动作 |
|:---|:---|:---|
| **战力崩坏** | 前期Boss被后期主角秒/设定前后矛盾 | 重建战力逻辑树 |
| **悬浮设定** | 无法用现实/科学逻辑解释的现象 | 增加"可感知但不可理解"的具象化描写 |
| **设定吃书** | 因段评反馈推翻前期设定 | 设定变更需逻辑过渡，核心不可动 |

## 五、人物口吻模板库

### 5.1 主角口吻特征

**底层逻辑**：现实欲望驱动，行为符合人类经验

**口吻特征**（根据性格选择）：

| 类型 | 口吻关键词 | 示例对白 |
|:---|:---|:---|
| **草根逆袭型** | 自嘲+不服+市井智慧 | "又让人踩？行，踩完我再爬回来。" |
| **精英算计型** | 冷静+利己+信息优势 | "他们以为我在赌，实际上我在算。" |
| **情感羁绊型** | 柔软+守护执念+牺牲倾向 | "这东西能换她一条命，值。" |
| **疯批突破型** | 偏执+极限试探+不顾后果 | "代价？等死了再算，先干。" |

### 5.2 配角口吻差异化

**核心原则**：每个配角必须有独立利益诉求，说话方式体现其身份/立场

| 角色定位 | 口吻特征 | 示例 |
|:---|:---|:---|
| **财阀代理** | 利益计算、话术精密、表面礼貌 | "这是双赢方案，何必弄得大家难看。" |
| **底层同伴** | 直白生存逻辑、方言/俚语、守望互助 | "哥，我这条命今天就押你身上了。" |
| **规则守护者** | 教条、冷峻、后果警告 | "你触碰的是不该触碰的边界。" |
| **敌对势力** | 自信威胁、利益诱惑、揭示黑暗 | "你以为这是意外？不，这是筛选。" |


### 6.2 战斗场景节奏

```
[开场] 双方态势/环境/各自意图（1段）
    ↓
[试探] 首次交手/技能试探（1-2段）
    ↓
[升级] 压力递增/代价初现/悬念揭示（2-3段）
    ↓
[逆转/突破] 金手指/底牌/规则破解（1-2段）
    ↓
[收尾] 结果+代价可视化+新悬念（1段）
```

### 6.3 缓坡/情感场景节奏

```
[日常切入] 细腻环境/感官描写（1-2段）
    ↓

    ↓
[现实映射] 社会隐喻/人性困境（1段）
    ↓
[钩子] 回归主线/埋入新伏笔（1段）
```

## 七、平台规则转化（发布/包装/风险门禁）

### 7.1 发布门禁（发布前检查）

| 门禁项 | 检查标准 | 违规处置 |
|:---|:---|:---|
| **标题合规** | 不含敏感词/违规导向词/夸大宣传词 | 改标题/删违规词 |
| **封面合规** | 无露点/血腥/政治元素 | 换图/裁切 |
| **简介合规** | 无虚假宣传/抄袭/违规内容 | 重写简介 |
| **章节命名** | 不含剧透/低俗/与内容不符 | 重命名 |

### 7.2 包装门禁（吸引读者）

| 门禁项 | 执行标准 | 效果预期 |
|:---|:---|:---|
| **首章留存** | 前3章必须完成：脑洞+能力验证+现实欲望绑定 | 提升首读留存率 |
| **章节卡点** | 每章≥1个钩子，禁止情绪断崖 | 提升追读率 |
| **段评触发点** | 在情绪高点/反转处预留讨论空间 | 引导段评互动 |
| **章节节奏标签** | 在章节末尾简述本章核心事件/下章预告 | 提升读者期待 |

### 7.3 风险门禁（防审查/防封）

| 风险类型 | 识别特征 | 规避动作 |
|:---|:---|:---|
| **政策风险** | 涉及政治/历史/领土/宗教敏感议题 | 模糊化处理/转移至虚构文明 |
| **内容风险** | 过度血腥/暴力/色情描写 | 删改描写段落/降低感官刺激 |
| **抄袭风险** | 与已有作品相似度过高/直接套用设定 | 差异化改造/原创重构 |
| **数据异常** | 刷票/买数据/违规引流 | 停止违规行为/自查整改 |

### 7.4 数据反馈响应规则

```
段评激增 + 追读上升 → 保留并放大该类型爽点
段评激增 + 追读下降 → 分析原因（可能是爽点节奏问题），微调支线
段评平静 + 追读下降 → 快速切线或回收伏笔，插入爆点
追读断崖 → 立即检查：是否战力崩坏/期待落空/节奏拖沓
核心主线数据下滑 → 不可动摇核心，优先调整支线节奏
```

**底线不可触碰**：力量体系核心逻辑、主角人设底线、前期核心伏笔

## 八、章节自检清单（完成后打勾）

> **每章完成后逐一检查**

### 基础检查（必须项）

- [ ] **脑洞明确**：读者读完能说出本章核心创意
- [ ] **能力验证**：主角在本章使用/展示了金手指/能力
- [ ] **欲望锚点**：主角行为动机符合人类经验逻辑
- [ ] **冲突存在**：本章有正反对抗/目标障碍/危机
- [ ] **代价触发**：力量使用后有明确代价/代价伏笔
- [ ] **钩子存在**：章末有信息差/临界点/两难/真相碎片
- [ ] **节奏合规**：无连续3章纯设定/纯修炼/无冲突
- [ ] **战力自洽**：本章战力表现与前期设定一致

### 进阶检查（提升项）

- [ ] **留白预留**：本章有不解释、留给后续的内容
- [ ] **类型溢出**：本章隐含对"人类定义/生命进化/社会结构"的思考
- [ ] **感官丰富**：战斗/场景有视觉/听觉/嗅觉/触觉多维描写
- [ ] **人物差异**：配角色有独立口吻/立场，不沦为工具人
- [ ] **逻辑可追**：科武设定/战斗能用"现实逻辑"解释

### 发布前门禁（最后一道）

- [ ] **无违规内容**：标题/正文/简介合规
- [ ] **字数达标**：章节字数符合平台要求（通常≥2000字）
- [ ] **格式正确**：章节标题/分段/标点规范
