# 《科武纪元》作家OS补丁  
## 模块：单章修改与节奏调控 v1.0

> 用途：写新章、改旧章、排查读完率下滑。  
> 原则：不凭感觉改文，先定位，再动刀。章节可改“肉”，骨架坏了必须动大纲。

---

# 0. 总执行口令

每章写完或修改前，先跑一遍：

```text
本章是否让读者：
1. 看见主角在做事？
2. 感到能力释放有反馈？
3. 看见胜利或失败有代价？
4. 明确知道下一章想看什么？
5. 没被设定、废话、毒点台词劝退？
```

若任意一项为“否”，本章不得发布。

---

# 1. 单章修改触发器

## 1.1 数据触发

当出现以下情况，启动改章流程：

```text
章节读完率出现明显下滑；
整体完读曲线在某章后转差；
评论集中吐槽某句、某人、某段剧情；
跟读率在某段剧情后变弱。
```

## 1.2 定位规则

```text
不要先改下滑章。
先改“下滑章的前一章”。
```

原因转成执行判断：

```text
读者通常是在前一章被劝退，下一章才表现为数据下滑。
```

## 1.3 改文观察期

```text
改完后至少观察7天。
前1—2天数据受字数变化、系统波动影响，不作为判断依据。
```

# 2. 骨肉分离规则

## 2.1 可单章修改的“肉”

以下问题可以直接改章节：

```text
节奏太快 / 太慢；
对话生硬；
描写过多；
情绪不到位；
设定解释太干；
毒点台词；
配角戏过长；
章末无钩子；
战斗缺反馈；
胜利无代价。
```

## 2.2 必须动大纲的“骨”

以下问题不能靠单章补救：

```text
主线逻辑断裂；
主角人设前后矛盾；
科技体系与武道体系互相打架；
题材漂移；
重大目标突然改变；
核心敌人动机崩坏；
全书头重脚轻，后续接不住。
```

## 2.3 《科武纪元》骨架定义

```text
科技 + 武道双体系 = 骨；
主角能力跃迁 = 骨；
文明/势力冲突 = 骨；
单次任务、试炼、实验、战斗、支线人物 = 肉。
```

执行判断：

```text
如果修改不影响“科技武道双体系”和“主角长期跃迁”，可单章改。
如果修改会改变体系规则、主角底层性格、主线敌我关系，必须回大纲。
```

# 3. 单章节奏判定器

## 3.1 读者总结法

写完后问：

```text
读者能用几句话总结本章？
```

判定：

```text
1句话就能概括：太慢。
3—5句话能概括：正常。
10句以上才能讲清：太快 / 信息过载。
```

示例：

```text
太慢：
“主角调试了一下新装备。”

正常：
“主角调试新装备，发现武道真气会干扰芯片，冒险强行同步，结果激活隐藏模式，同时引来监察队。”

太快：
“主角调试装备、遇敌、升级、救人、发现内鬼、揭开旧文明线索、击败反派、又接新任务。”
```

# 4. 节奏太慢时：砍、合、挂钩子

## 4.1 砍剧情规则

发现本章慢，按顺序砍：

```text
1. 砍与主角无关的配角闲聊。
2. 砍不推动科武能力跃迁的设定解释。
3. 砍不制造冲突的环境描写。
4. 砍没有情绪变化的训练过程。
5. 砍与主线敌我关系无关的小支线。
```

保留标准：

```text
只保留能推动以下至少一项的内容：
主角变强；
主线敌人推进；
科武体系暴露新规则；
人物关系发生变化；
危机倒计时逼近；
伏笔被埋下或回收。
```

## 4.2 合并规则

如果连续几章都在写同一件小事：

```text
3章以上无主线推进：进入合并模式。
5章以上仍在同一小事件：强制压缩。
10章以上写无关小剧情：高危冗杂，必须大砍。
```

## 4.3 慢章补救钩子

如果本章必须慢，比如训练、设定、实验、调查，则章末必须挂钩：

钩子类型：

```text
新威胁：
“检测屏忽然跳红：有未知武道波动正在反向入侵装甲核心。”

旧伏笔回响：
“他终于看清芯片底层代码，那行签名，竟和父亲遗物上的编号完全一致。”

反派动作：
“同一时间，地下实验室里，有人按下了处决名单，第一行就是他的名字。”

时间倒计时：
“三小时后，天穹武馆会公开处决所有实验失败者。”

信息反转：
“导师没有救他，导师才是把他送进实验场的人。”
```

执行口令：

```text
慢章不是不能写。
慢章必须让读者误以为：这不是拖，这是铺垫。
```

# 5. 节奏太快时：补情绪、补反馈、补代价

## 5.1 太快的表现

```text
战斗像流水账；
主角一招接一招，读者没感觉；
设定一股脑扔出；
人物反应来不及消化；
胜负变化太多，重点不突出；
读者十几句话才能讲完本章。
```

## 5.2 太快的修法

不要单纯加字数，要补以下四类内容：

### A. 补情绪锚点

每个高密度动作段，至少给一个情绪锚：

```text
恐惧：他第一次意识到，武道宗师的杀意能让义体神经冻结。
愤怒：对方踩碎的不只是芯片，还有他三年翻身的唯一机会。
羁绊：如果他退，身后的妹妹会被实验室带走。
羞辱：监察官没有出刀，只用一根手指压得他跪下。
决心：他咬碎止痛片，把过载阈值推到红线之外。
```

### B. 补物理反馈

科武战斗不能只写“很强”“很快”，必须可感知：

```text
身体反馈：骨缝发热、经脉刺痛、义眼短暂失焦、耳膜嗡鸣。
装备反馈：外骨骼关节冒烟、能量槽跳红、刀刃纳米层剥落。
环境反馈：地砖蛛裂、空气焦臭、墙体磁场扭曲、雨水被蒸成白雾。
敌人反馈：护体罡气破开一线、机械臂反折、瞳孔收缩。
```

### C. 补代价

主角不能无损爽过。

可用代价：

```text
身体代价：骨裂、内伤、神经烧灼、精神过载。
装备代价：芯片烧毁、装甲报废、武器失效、能源耗尽。
关系代价：暴露秘密、欠人情、被组织盯上、同伴误解。
时间代价：错过撤离窗口、敌人完成布置、任务倒计时缩短。
规则代价：违规使用禁术、突破安全阈值、留下追踪痕迹。
```

### D. 补伏笔回扣

快章中插一句短回扣，能让信息不散：

```text
他终于明白，三章前导师说的“别让真气进入芯片底层”是什么意思。
```

# 6. 冲突章修补规则

## 6.1 冲突章下滑，不要先重写整章

优先找：

```text
一句让读者反感的台词；
一个配角过分降智的行为；
一个主角违背人设的选择；
一个科学/武道硬伤；
一个过度冒犯的表达；
一个无代价开挂瞬间。
```

处理方式：

```text
能删就删；
能换就换；
不要为毒点辩解；
不要用后文洗白前文毒点。
```

## 6.2 冲突没张力时

加字数无效，按顺序加：

```text
1. 危机：失败会损失什么？
2. 对峙：谁阻止主角？
3. 倒计时：多久内必须解决？
4. 救人/保物：主角必须保护什么？
5. 代价：赢了也要失去什么？
6. 反转：主角以为解决，其实触发更大危机。
```

# 7. 人物口吻补丁

## 7.1 主角口吻

《科武纪元》主角建议保持：

```text
理性计算 + 武道血性 + 不轻易认输。
```

可用句式：

```text
“胜率不高，但不是零。”
“芯片算不出这一刀，我自己来。”
“代价我知道，按钮给我。”
“你们把它叫实验事故，我把它叫机会。”
```

禁止频繁出现：

```text
无脑嘴硬；
明知必死还空喊热血；
前面杀伐果断，后面突然圣母；
前面谨慎理性，后面毫无理由莽撞。
```

## 7.2 科技侧人物口吻

特点：

```text
精确、冷静、带指标。
```

句式：

```text
“神经同步率跌到47%，再打三十秒，你会失去右臂控制权。”
“这不是突破，是硬件自杀。”
“数据不支持你赢，但数据也没记录过你这种怪物。”
```

## 7.3 武道侧人物口吻

特点：

```text
压迫、经验、讲境界和生死。
```

句式：

```text
“机器能替你算招，不能替你受死。”
“你这一刀有形无胆。”
“真气入骨，才算登门；敢拿命换，才算入道。”
```

## 7.4 反派口吻

避免单纯废话嘲讽，给压迫感：

```text
“我不是来杀你的，我是来验证你能撑到第几次重启。”
“你以为自己在进化？不，你只是我们淘汰线上的样本。”
“放心，你的失败数据会比你本人活得更久。”
```

# 8. 段落节奏补丁

## 8.1 过渡段：短

过渡是“脖子”，不能长瘤。

执行：

```text
地点转换：1—3段解决。
任务说明：不超过半页。
普通赶路：能一句带过就一句。
无冲突训练：压缩成结果 + 异常。
```

示例：

```text
删前：
他走过长长的通道，墙壁上有许多灯，每一盏灯都泛着冷光……

改后：
十分钟后，他抵达地下七层。门一开，所有检测仪同时亮红。
```

## 8.2 高光段：慢

主线高光是“躯干”，要详写。

必须展开：

```text
主角第一次使用新能力；
关键战斗反杀；
重要人物死亡/背叛；
体系规则被打破；
主角身份暴露；
势力格局改变。
```

高光段写法：

```text
动作 → 反馈 → 情绪 → 代价 → 敌人反应 → 新变化
```

## 8.3 设定段：包进剧情

禁止：

```text
连续大段讲科技原理；
连续解释武道境界；
用角色对话背设定说明书。
```

改成：

```text
设定必须伴随动作暴露。
```

示例：

```text
不要写：
“真气同步芯片的原理是……”

改写：
他刚把真气压进芯片，义眼画面瞬间撕裂成十二层。导师脸色骤变：“停！真气同步率超过60%，芯片会反向烧你的神经！”
```

# 9. 章末钩子生成器

每章结尾必须回答：

```text
读者下一章想看什么？
```

## 9.1 钩子模板

### 模板一：危机升级

```text
他刚赢下这一场，腕表却弹出一行红字：
【第二轮实验，提前开始。】
```

### 模板二：身份暴露

```text
监控室里，有人放大他的战斗录像。
“确认了，他体内有旧纪元武核。”
```

### 模板三：敌人现身

```text
门外传来掌声。
那个本该死在三年前的人，站在雨里看着他笑。
```

### 模板四：胜利反噬

```text
他终于打通第七条经脉。
下一秒，义体核心开始倒计时自毁。
```

### 模板五：选择困境

```text
屏幕上同时亮起两个坐标。
一个是任务目标。
一个是妹妹的求救信号。
```

### 模板六：旧伏笔回响

```text
他翻开父亲留下的芯片日志。
最后一条记录只有六个字：
“不要相信武院。”
```

# 10. 失败模式库

## 10.1 设定灌输过载

表现：

```text
本章30%以上篇幅都在讲原理、历史、体系、势力。
```

修法：

```text
砍解释；
把设定拆到战斗、实验、对话、失败反馈里；
章末加威胁钩。
```

## 10.2 主角无代价开挂

表现：

```text
敌人很强，但主角轻松赢；
新能力突然出现；
没有伤、损耗、暴露、后患。
```

修法：

```text
加代价；
加限制；
加副作用；
加敌人记录/追踪；
加下一章反噬。
```

## 10.3 配角抢主线

表现：

```text
配角连续占用大量篇幅；
主角只是旁观；
剧情不推动主角跃迁。
```

修法：

```text
配角戏必须服务主角选择；
配角冲突必须逼主角行动；
否则砍或合并。
```

## 10.4 人设断裂

表现：

```text
理性主角突然无脑；
杀伐果断者突然拖泥带水；
重情人物突然冷血且无解释。
```

修法：

```text
不要单章硬圆；
回查前后章节；
补动机、补压力、补代价；
必要时改大纲。
```

## 10.5 题材漂移

表现：

```text
科武热血突然变纯悬疑；
升级战斗突然变日常恋爱；
科技武道主轴长时间消失。
```

修法：

```text
拉回主角能力跃迁；
拉回科技/武道冲突；
拉回势力压迫；
支线必须绑定主线。
```

# 11. 写作前任务卡字段更新

以后每章开写前，任务卡必须新增/填写以下字段：

```text
【章节编号】
【本章功能】推进主线 / 能力跃迁 / 情绪爆发 / 设定嵌入 / 过渡 / 高光 / 伏笔回收

【本章一句话目标】
主角本章要完成什么？

【动作链】
A因 → B做 → C果，至少3环。
例：被监察队堵截 → 强行同步真气芯片 → 装甲过载反杀一人 → 暴露旧纪元武核。

【物理反馈点】
身体反馈：
装备反馈：
环境反馈：
敌人反馈：

【主角代价】
伤势：
装备损耗：
关系损失：
时间损失：
暴露风险：

【本章信息密度】
读者预计几句话能总结本章？
1句 / 3—5句 / 10句以上

【设定占比】
是否超过30%？
是 / 否

【人物口吻】

【本章冲突】
谁阻止主角？

是否有倒计时？

【章末钩子】
悬念 / 反转 / 新威胁 / 伏笔回响 / 时间倒计时 / 选择困境

【读者下一章预期】
读者读完应期待下一章发生什么？

【风险门禁】
是否有科学硬伤？
是否有武道体系崩坏？
是否有政治/敏感/冒犯性表达？
是否有毒点台词？
是否有无代价开挂？
```

# 12. 章节自检清单

发布前逐条打勾。

```text
□ 1. 本章有明确动作链，不只是心理活动和设定说明。

□ 2. 主角至少做了一个改变局势的动作。

□ 3. 本章推动了主线、能力体系、人物关系、敌我冲突中的至少一项。

□ 4. 科技/武道能力释放有身体、装备、环境或敌人反馈。

□ 5. 主角胜利或失败都有代价。

□ 6. 本章设定解释没有超过总篇幅30%；若超过，已拆进动作和冲突。

□ 7. 读者用3—5句话能总结本章；若只能1句，已加冲突/钩子；若超过10句，已减信息。

□ 8. 过渡段短，高光段详。

□ 9. 配角戏没有抢走主角主线。

□ 10. 主角行为符合既有人设，没有突然降智、圣母、莽撞或冷血。

□ 11. 冲突有危机、阻力、倒计时或不可承受后果。

□ 12. 本章没有明显科学硬伤或武道规则崩坏。

□ 13. 本章没有容易引发毒评的单句台词、冒犯表达或恶心读者的配角行为。

□ 14. 章末有强钩子。

□ 15. 读者读完能明确期待下一章。

□ 16. 若本章是慢章，结尾已用威胁、伏笔、反转包装成铺垫。

□ 17. 若本章是快章，已补情绪、反馈、代价。

□ 18. 若读完率下滑，本次修改从下滑章前一章开始查。

□ 19. 修改后不在1—2天内反复判断数据，至少观察7天。

□ 20. 若发现骨架级问题，已回大纲，不用单章硬补。
```

# 13. 短故事 / 狼人篇可借点

适合短篇、单元故事、狼人篇借用：

```text
1. 读完率拐点法：
短故事节奏更敏感，掉点通常就是上一段信息、台词、反转出了问题。

2. 毒点直删：
狼人篇若某个角色发言让读者反感，不要解释，直接换表达或删除。

3. 章末钩子：
短故事每节结尾都要有“下一个疑问”。
例：谁是狼？谁撒谎？谁被感染？谁在伪装？

4. 节奏总结法：
一节只能一句话概括，说明太水；
十几句话才能说清，说明线索太乱。

5. 冲突修补：
狼人篇冲突没张力时，优先加：
身份怀疑、投票倒计时、误杀代价、证词矛盾、隐藏阵营动作。

6. 人物口吻：
狼人篇角色口吻要有身份痕迹。
猎人说话硬；
预言家说话谨慎；
狼人说话过度合理；
平民说话带恐惧和自保。
```

不宜照搬：

```text
科武长篇的体系铺垫不能直接搬到短故事。
短故事不适合长时间解释世界观，必须用冲突带出规则。
```

# 14. 科武长篇可借点

《科武纪元》重点执行：

```text
1. 章节读完率拐点法：
世界观铺设期最容易掉读者，优先查前一章是否设定过载。

2. 骨肉分离：
科技武道双体系、主角能力跃迁、文明冲突是骨；
任务、试炼、实验、对手是肉。

3. 3—5章一剧情：
一个实验副本、一次武馆冲突、一场科技战，尽量控制在3—5章内完成核心变化。

4. 慢章钩子化：
训练、调试、原理解释、势力介绍，结尾必须挂威胁或伏笔。

5. 快章情绪化：
科技vs武道大战不能只堆招式，要写代价、羁绊、压力、装备反馈。

6. 支线保留标准：
支线只要服务主角科武能力跃迁、主线敌我冲突、世界体系展开，就可以保留；
否则砍。

7. 体系崩坏优先级最高：
科武读者能接受慢一点，但很难接受规则崩。
设定矛盾优先修，必要时停更整理。
```

# 15. 发布 / 包装 / 风险门禁

平台规则不写成理论，转成门禁。

## 15.1 发布门禁

发布前必须通过：

```text
□ 章节读完率历史数据已查看。
□ 若有下滑，已检查下滑章前一章。
□ 本章不是纯设定说明。
□ 本章章末有钩子。
□ 本章无明显毒点台词。
□ 本章无敏感、冒犯、容易引战表达。
□ 本章无无代价开挂。
□ 本章无体系硬伤。
```

未通过：

```text
不得发布。
```

## 15.2 包装门禁

章节标题、章末预期、剧情包装要一致。

可用标题方向：

```text
危机型：
《同步率100%，装甲开始自毁》

反转型：
《导师给他的，不是救命芯片》

压迫型：
《武道宗师，只出了一指》

选择型：
《任务目标和妹妹，只能救一个》

伏笔型：
《父亲日志里的第七个名字》
```

避免标题：

```text
《训练开始》
《新的装备》
《一次实验》
《前往基地》
```

原因：

```text
标题不能只描述事件，要制造期待。
```

## 15.3 风险门禁

以下内容进入高危池，优先删除或改写：

```text
科学硬伤被角色当成严肃设定；
武道境界前后矛盾；
主角无理由降智；
重要胜利无代价；
配角强行恶心读者；
嘲讽现实群体；
过度血腥、低俗、敏感表达；
长篇政治化争论；
与主线无关的争议话题。
```

处理：

```text
能删则删；
不能删则改成剧情功能；
无法确定是否安全，则换表达。
```

# 16. 单章改稿流程

每次改章按这个顺序，不要乱改。

```text
第一步：看数据
找读完率下滑点，从前一章开始查。

第二步：判骨肉
如果是节奏、台词、描写、情绪，单章改。
如果是主线、人设、题材、体系，回大纲。

第三步：测节奏
用“几句话总结本章”判断快慢。

第四步：查毒点
找评论集中吐槽的句子、角色、行为，优先删。

第五步：补动作链
确保主角有3环以上可视化行动。

第六步：补反馈
身体、装备、环境、敌人至少出现两类反馈。

第七步：补代价
胜利、突破、逃脱都要留下损耗。

第八步：调段落
过渡压短，高光展开，设定包进动作。

第九步：补钩子
章末必须让读者期待下一章。

第十步：发布后观察
至少等7天再判断改文效果。
```

# 17. 最短执行版

写章前看这张即可：

```text
本章目标是什么？
主角做了哪三步？
敌人或阻力是谁？
失败会损失什么？
科武能力有什么可感知反馈？
主角付出什么代价？
本章有没有设定过载？
配角戏是否服务主角？
结尾钩子是什么？
读者下一章想看什么？
```

如果答不出来，本章还不能写。
