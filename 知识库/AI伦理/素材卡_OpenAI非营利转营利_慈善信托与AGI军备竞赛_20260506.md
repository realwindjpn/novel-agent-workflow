## 事实摘要

- 文章称，OpenAI 总裁 Greg Brockman 在庭审中承认：其在 OpenAI 营利性实体中拥有权益，投入现金为 0 美元，按估值可能接近 300 亿美元。
- 马斯克方核心指控：早期 OpenAI 借非营利/造福人类承诺吸引捐赠、声誉和人才，后续转向营利，将原本公共承诺下积累的资产变为私人权益，涉嫌不当得利。
- 文章还提到 Cerebras 关联交易：Brockman/Altman 被称拥有个人投资，同时 OpenAI 后续给出巨额订单和贷款，可能构成利益冲突或自我交易。
- Stuart Russell 的证词被用于表达 AGI 军备竞赛担忧：追求 AGI 与安全之间存在天然张力，胜者通吃心理会弱化对齐要求。
- OpenAI 方抗辩逻辑：AGI 所需算力和人才成本极高，引入营利结构是“必要的恶”。

## 核心概念

| 概念 | 解释 | 小说化用途 |
|---|---|---|
| 非营利转营利 | 公益承诺下积累资产，转入商业实体 | 公器私有化、理想破产 |
| 慈善信托/受托义务 | 管理公共资产的人不得自我交易 | 受托人背叛公共目标 |
| 自我交易 | 决策者推动组织购买自己持股公司的产品/服务 | 技术基金会扶持私人算力公司 |
| AGI军备竞赛 | 技术公司为抢先控制AGI牺牲安全 | “必要的恶”压倒安全边界 |
| 算力依赖 | H100/数据中心/订单绑定形成权力结构 | 算力即权力，授权即主权 |

## 短故事转化

### 题名候选

1. 《我爸捐给公益AI的钱，变成了别人的三百亿股份》
2. 《我举报的公益AI基金会，正在给自己下订单》
3. 《系统说这是必要的恶，可死的是我妈》
4. 《那家免费救命的AI医院，后来开始挑病人》

### 现实推演短故事模型

- 主角父亲早年参与/捐助一个“公益AI医疗/救援平台”。
- 平台承诺永久免费、开源、用于救人。
- 数年后平台改制，核心数据和模型进入商业公司。
- 主角母亲/父亲因系统评分被拒绝救助。
- 主角追查发现：平台采购的算力公司由受托人秘密持股，公益数据被拿去推高估值。
- 结尾：主角用公开账本/日志/订单证明“公益AI”已变成封闭权力机器。

## 写作注意

- 必须虚化现实公司名和真实人物。
- 不直接写 OpenAI/马斯克/Cerebras，改为“启明AI基金会”“白塔算力”“星穹实验室”等架空名。
- 不作法律断言，写成“涉嫌/被质疑/证据链显示”。
- 技术解释采用生活类比：
  - 非营利转营利 = 用大家捐的砖盖公共图书馆，最后把门票卖成私人股票。
  - 自我交易 = 食堂管理员让学校高价买自己家的菜。
  - 算力军备竞赛 = 谁先买下全城发电机，谁就能决定哪些灯亮。
