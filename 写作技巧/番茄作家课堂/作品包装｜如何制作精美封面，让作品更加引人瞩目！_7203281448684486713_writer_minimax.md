## 三、执行动作/反馈/代价/失败模式

### 动作链执行标准
**执行动作**：提交封面方案时，同步提供"核心动作序列"，确保静态构图暗示动态发力轨迹

**正确反馈**：能量充能→肌肉绷紧→武器出鞘形成连贯发力链，读者可在3秒内感知张力

**失败模式（静态摆拍）**：站桩式pose缺乏发力轨迹，读者感知"摆拍"而非"战斗中"，点击欲降低

**短故事/狼人篇可借**：动作链可简化，适用于短篇节奏（1-2个关键动作即可）

**科武长篇可借**：动作链需完整，需展示"充能→传导→释放"完整链路

### 物理反馈执行标准
**执行动作**：封面材质/光影严格对应正文物理规则

**正确反馈**：能量过载灼烧痕迹、金属疲劳应力裂纹、重力环境下姿态偏移

**失败模式（无逻辑特效）**：悬浮发光、无限能量、无重力失衡感——读者感知"假"，世界观可信度下降

**短故事/狼人篇可借**：物理反馈可抽象化，符号性表达即可（如：狼瞳发光=力量激活）

**科武长篇可借**：物理反馈需精细化，与机甲/武道设定深度绑定（如：神经负荷反馈、金属疲劳累积）

### 代价绑定执行标准
**执行动作**：视觉符号必须有"使用代价"，与正文设定绑定

**正确反馈**：机甲涂装仅主角可激活，每次启动消耗神经负荷/稀有燃料

**失败模式（视觉诈骗）**：封面炫酷但正文无代价对应，读者预期落差导致差评/弃读

**短故事/狼人篇可借**：代价可简化（如：狼人力量激活=失控风险）

**科武长篇可借**：代价需多层级（神经负荷+燃料+冷却时间），形成系统化设定

### 视觉悬念执行标准
**执行动作**：封面预留1个未解视觉悬念

**正确反馈**：背景中半掩未知文明图腾/断裂制式武器残片——在第5章完成首次回收或升级

**失败模式（悬念未回收）**：悬念铺了但正文无对应，读者感知"骗点击"，权重下降

**短故事/狼人篇可借**：悬念可在章节内回收（短篇节奏更快）

**科武长篇可借**：悬念需设计"回收周期"（第5章/第20章/第50章），形成长线钩子

## 四、人物口吻适配包装

### 科武硬核风封面口吻
**书名处理**：
- 强化类型辨识度："科武"二字放大加粗，"纪元"缩小衬底
- 视觉重心：书名占主视觉40%+，移动端1:1缩略图可辨

**元素克制**：
- 单一核心意象（断裂机甲臂缠绕武道绷带/能量刃）
- 禁止多元素拼贴导致移动端糊成色块

**口吻示例**：
- ❌ "星际武神崛起：机甲与武道交织的命运交响"
- ✓ "科武纪元"（简洁硬核，类型一目了然）

**失败口吻（女频柔光风）**：
- 手写体、暖色、柔光滤镜 → 严重偏离科幻男频受众3秒扫视预期

## 五、段落节奏·章末钩子联动

### 封面→正文节奏映射

**封面视觉悬念 → 第1章钩子类型**：
- 视觉悬念：断裂制式武器残片
- 第1章钩子类型：遗留物钩子（主角捡到/继承/被追杀）

**封面动作链 → 第3章冲突节奏**：
- 视觉动作链：能量充能→肌肉绷紧→武器出鞘
- 第3章节奏：能量泄露危机→主角被迫出手→首次代价触发

**封面核心符号 → 第10章具象化完成**：
- 视觉符号：能量刃
- 第10章检查点：该符号是否完成首次完整描写（外观+运作原理+代价+首次使用）

### 章末钩子·封面联动规则
**钩子类型1：视觉悬念未解**
- 封面悬念：未知文明图腾
- 章末钩子：主角发现图腾在特定场景激活
- 回收节点：第5章

**钩子类型2：动作代价预埋**
- 封面符号：机甲涂装
- 章末钩子：主角首次尝试激活，感受到神经负荷
- 回收节点：第5章

**钩子类型3：读者预期校准**
- 封面视觉：冷蓝/暗灰/金属银硬核风
- 章末钩子：正文风格与封面一致（禁止暖色/柔光/手写体混入正文）

## 六、平台规则·风险门禁

### 发布前风险门禁清单

**门禁1：尺寸/格式门禁**
- [ ] 严格匹配番茄官方规范（含安全边距）
- [ ] PC端/APP端双端预览确认
- [ ] 无文字溢出、无关键元素被裁切

**门禁2：内容审核门禁**
- [ ] 无敏感/违规元素（AI+人工双审）
- [ ] 字体/素材具备商用授权或原创证明
- [ ] 主色调符合平台分类标签（科幻/男频=冷色+高对比+几何线条）

**门禁3：包装-正文一致性门禁**

**门禁4：读者预期校准门禁**
- [ ] 通过目标读者画像"3秒扫视测试"
- [ ] 无装饰性元素干扰核心卖点
- [ ] 无偏离类型预期的设计

### 违规代价
**触发风险**：封面违规→阻断推荐→流量断崖

**规避动作**：
1. 上传前核对官方尺寸规范
2. 预留安全边距（防止系统裁切）
3. 人工+AI双审检查敏感元素
4. 授权素材/原创素材复核

| **科武长篇可借** | 代价需多层级（神经负荷+燃料+冷却时间），形成系统化设定 |

| **科武长篇可借** | 悬念需设计"回收周期"（第5章/第20章/第50章），形成长线钩子 |

## 六、平台规则·风险门禁

### 发布前四重门禁

```
门禁1：尺寸/格式门禁 ──→ 阻断推荐风险最高
门禁2：内容审核门禁 ──→ AI+人工双审
门禁3：包装-正文一致性门禁 ──→ 读者预期校准
门禁4：读者预期校准门禁 ──→ 3秒扫视测试
```

### 门禁详细清单

**【门禁1】尺寸/格式门禁**
- [ ] 严格匹配番茄官方规范（含安全边距）
- [ ] PC端/APP端双端预览确认
- [ ] 无文字溢出、无关键元素被裁切

**【门禁2】内容审核门禁**
- [ ] 无敏感/违规元素（AI+人工双审）
- [ ] 字体/素材具备商用授权或原创证明
- [ ] 主色调符合平台分类标签（科幻/男频=冷色+高对比+几何线条）

**【门禁3】包装-正文一致性门禁**
- [ ] 封面视觉符号在正文前10章内有具象化描写
- [ ] 符号使用代价在正文内有建立
- [ ] 视觉悬念在正文第5章内有回收或升级

**【门禁4】读者预期校准门禁**
- [ ] 通过目标读者画像"3秒扫视测试"
- [ ] 无装饰性元素干扰核心卖点
- [ ] 无偏离类型预期的设计

### 违规代价

> **触发风险**：封面违规 → 系统阻断推荐 → 流量断崖

**规避动作**：
1. 上传前核对官方尺寸规范
2. 预留安全边距（防止系统裁切）
3. 人工+AI双审检查敏感元素
4. 授权素材/原创素材复核
