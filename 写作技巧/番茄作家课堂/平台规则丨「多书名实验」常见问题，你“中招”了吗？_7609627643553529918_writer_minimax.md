# 《科武纪元》作家OS补丁 v1.0
**基于平台规则·多书名实验课程**
**状态：直接可执行**

---

## 一、核心运作原理（极简版）

```
书名 = 流量入口阀门（只管“点击”）
正文 = 留存转化引擎（决定“追更”）
错位 = 平台降权 + 跳出率飙升
```

**三句话规则**：
1. 书名换词序不破圈，必须换卖点方向
2. 标题承诺的，正文3000字内必须兑现
3. 实验优化入口，不能补救烂文

---

## 二、写作动作指令集

### 【A】开篇动作指令（强制）

| 书名含… | 首章必须出现 |
|:---|:---|
| 机甲/星舰/战舰 | 启动/对接/受损/操控动作链（禁止纯背景介绍） |
| 武道/升级/修炼 | 交锋/压制/突破/损耗动作链（禁止纯能力罗列） |
| 科技/系统/进化 | 异常触发/协议冲突/参数崩溃（禁止纯概念阐述） |
| 悬疑/解密/谜团 | 线索碎片/认知冲突/关键信息断点 |
| 热血/复仇/爽文 | 逆袭/碾压/打脸/张力释放节点 |

**物理反馈替代抽象描述**：
- ❌ “能量剧烈波动”
- ✅ “能量管壁温度骤升47%，液冷回路进入旁通模式，驾驶员心率同步攀升至警戒线”
- ❌ “武器很锋利”
- ✅ “刀刃切入脊椎第三节至股骨头的切割阻力消失，液压机构发出过载警报”

### 【B】代价嵌入规则（每战必检）

```
能力跃升/战斗胜利 → 必须触发以下至少一项：
├── 装备折旧率（具体数值，如“护盾充能周期延长23%”）
├── 寿命/健康损耗（可量化指标）
├── 资源消耗（弹药/能源/特殊材料库存下降）
└── 能力代价（神经负荷/意识侵蚀/不可逆损伤）
```

**禁止模式**：无限升级/无损耗战斗/无代价翻盘

### 【C】章末钩子绑定规则

| 当前实验书名方向 | 钩子类型 |
|:---|:---|
| 硬核科幻侧重 | 设定谜团/技术悖论/逻辑断点 |
| 武道升级侧重 | 战力临界点/压制性对手/突破预告 |
| 悬疑解谜侧重 | 线索断点/身份反转暗示/关键信息缺失 |
| 热血爽感侧重 | 情绪高点/爽感释放/下一章预兆 |

## 三、人物口吻模板

### 科武主角标准腔调

**危机应对型**：
> “……管子破了。我还剩两分钟。要么补上，要么——先切断这条腿的痛觉神经。”

**技术解读型**：
> “这个频段不该有信号。除非有人在外层空间同步广播。那意味着——我们不是唯一的目标。”

**武道碾压型**：
> “刚才那招叫'星陨'。第二招叫'灭度'。你还有一次机会看星星。”

**代价感知型**：
> “赢了。但右臂的神经传导效率降到62%。这个代价……下一场还来得及恢复吗？”

## 四、段落节奏速查

```
标准章节节奏（2000-3000字）：
│ 开篇钩子 │← 承接上章断点，≤200字进入当前事件
│ 事件发展 │← 书名承诺方向的核心场景
│ 转折/冲突│← 代价触发点或预期落差
│ 小高潮   │← 能力展现或关键信息揭示
│ 代价呈现 │← 本章代价量化（如有）
│ 断点收尾 │← 与书名卖点绑定的下章悬念
```

## 六、章节自检清单

**发布前逐项确认**：

```
□ 书名承诺的核心意象/动作/情绪在正文前三章已出现
□ 首章动作链≥1个可感知物理反馈细节
□ 每次能力跃升有明确代价（装备/健康/资源）
□ 章节断点与当前实验书名卖点方向一致
□ 无跨题材引流词（重生/校草/霸总/甜宠等）
□ 无平台敏感词/夸大承诺词（顶级/最强/无敌等）
□ 人物口吻符合科武设定（非古风/非现代言情腔）
□ 段落节奏符合“开篇-发展-冲突-代价-断点”结构
□ 本章数据目标清晰（点击→读完→追更转化预期）
□ 老读者告知机制已激活（作话/书友圈说明）
```

| 代价闭环 | 短篇单章内代价-收益需形成完整弧线 |
| 物理反馈密度 | 短篇用1-2个精准物理细节替代长篇堆砌 |
| 章末钩子 | 短篇结尾断点需更强的情绪张力 |

**狼人篇适配**：实验“狼人复仇”vs“狼人生存”书名卖点差异，代价可借“变身损耗/月圆诅咒”科武化呈现。

### 🔖 科武长篇可借点

| 要素 | 借用方式 |
|:---|:---|

| 分层显示利用 | 实验期间老读者锁定原书名，避免追更断层 |
| 代价累积系统 | 长篇代价需建立追踪表（如“神经损耗累计已达临界”） |

| SEO权重维护 | 正文更新频率+完读率是搜索流量核心，书名测试期间保持更新节奏 |

### ⚠️ 平台规则→发布/包装/风险门禁

| 平台规则 | 转化为 | 执行要求 |
|:---|:---|:---|
| 违规书名自动替换 | **发布门禁** | 发书前逐字核对平台审核提示词库，禁用系统敏感词清单 |
| 跨题材引流词触发降权 | **包装风险门禁** | 封面/标签/简介必须与书名方向严格一致，禁止蹭无关热词 |

| 实验期新读者分层锁定 | **包装门禁** | 最优书名固化后，封面/简介/标签必须同步迭代匹配新定位 |
| 搜索缓存干扰展示 | **验证门禁** | 书名更换后用新设备/新账号验证前端显示是否正确 |

## 八、失败模式预警

| 失败模式 | 触发条件 | 应对策略 |
|:---|:---|:---|
| **标题党反噬** | 书名承诺内容3000字内未出现 | 立即在下一章兑现或调整书名 |
| **代价缺失疲劳** | 连续3章无代价升级/战斗无损耗 | 强制插入代价事件，重新激活追更张力 |
| **卖点漂移** | 书名测武道，正文越来越科幻 | 重新对齐书名方向或调整正文卖点 |
| **实验污染基本盘** | 跨题材引流词引发科幻老读者差评 | 删除引流词，发布道歉作话补救 |
| **章末钩子断联** | 断点与书名卖点无关 | 每章结尾必须检查“悬念是否服务当前实验方向” |
