# 《科武纪元》编辑学习报告：基于《作家惜若黄》专访的规则提炼

## 1 课程核心判断（≤6条）
1. **算法即编辑**：番茄以大数据推荐替代传统人工审稿，日更数据与收益实时绑定，作品生死由“留存率-转化率”决定。
2. **爆款可逆向工程**：任何爆款均有可拆解的底层结构（情绪钩子、节奏模板、设定外壳），集中扫榜是新人冷启动的最优路径。
3. **数据波动=剧情故障**：追读/读完率断崖式下跌必对应具体章节的冲突失效或节奏拖沓，需24小时内定位并修正。
4. **长篇天然卡点**：50万/100万字是读者疲劳阈值，必须提前规划体系跃迁、地图切换或主线换挡。
5. **圈层留存＞泛受众通吃**：放弃“全年龄/全圈层”幻想，精准服务目标读者群即可实现商业闭环。
6. **输入输出强绑定**：长期闭门码字必致设定枯竭与逻辑断裂，需建立“生活体验-爆款拆解-大纲迭代”的循环机制。

## 2 可执行编辑规则（按原文内容取舍）
| 维度 | 规则 |
|:---|:---|
| **开篇** | 前3章必须抛出核心金手指/核心冲突/情绪钩子；首日读完率＜30%直接判定开篇失效，需重写钩子密度。 |
| **节奏** | 以“日更数据”为节拍器。追读连续3日下滑即触发节奏审查；每10万字必须安排一次阶段性高潮或信息释放。 |
| **冲突** | 冲突设计需严格对齐目标圈层爽点预期；禁用作者自我感动式铺垫，冲突必须导向明确的情绪释放或资源获取。 |
| **人物** | 人物动机需与平台读者预期强绑定（逆袭/碾压/破局）；避免复杂多线群像，聚焦1-2个核心视角降低阅读门槛。 |
| **题材** | 题材选择依赖平台实时风向；通过拆解头部作品提取“情绪模板+设定外壳”，禁止脱离市场验证的纯自嗨设定。 |
| **平台规则** | 严格执行“日更+数据日清”；收益与留存直接挂钩，断更或数据异常需当日复盘；50万/100万字节点需提前报备大纲换挡方案。 |
| **改编** | 原文未涉及IP改编路径，暂不纳入本规则库。 |

## 3 科武适配
| 维度 | 可用点 | 不可硬套点 |
|:---|:---|:---|
| **长篇科幻《科武纪元》** | ① 用留存数据强制砍掉无效支线与设定堆砌，保持“科技推演+武道升级”双线紧凑。<br>② 50万/100万字节点规划“科技树跃迁/武道境界突破/星域地图升维”，天然契合长篇卡点。<br>③ 锁定“硬核逻辑+爽文节奏”交叉受众，放弃泛娱乐通吃，提升核心圈层黏性。 | ① **情绪模板直接套用**：科幻需底层物理/科技规则自洽，不能为短期爽点牺牲逻辑链条。<br>② **日更数据即时改文**：长篇科幻伏笔多、设定耦合度高，频繁按单日数据改主线会导致世界观崩塌。<br>③ **爆款跟风**：科幻热点周期长，盲目追短平快热点会破坏《科武纪元》的史诗感与技术演进连贯性。 |

## 4 编辑检查表（8条）
- [ ] 开篇3章是否明确核心金手指/冲突钩子？（首日读完率≥30%为达标线）
- [ ] 是否建立“数据-章节”映射表？追读跌破阈值能否精准定位到具体情节？
- [ ] 50万/100万字节点是否有明确的大高潮或体系/地图切换预案？
- [ ] 目标读者画像是否清晰？是否因试图讨好全圈层导致主线失焦？
- [ ] 设定展开是否遵循“剧情驱动”而非“说明书式堆砌”？
- [ ] 日更节奏是否稳定？断更/存稿不足是否触发预警机制？
- [ ] 是否定期拆解平台同类爆款，提取可复用的情绪节奏模板？
- [ ] 收益/追读波动是否触发24小时内剧情复盘与微调？

## 5 对作家角色的输入要求
| 要素 | 执行标准 |
|:---|:---|
| **动作链** | 战斗/科技操作必须拆解为“感知→决策→执行→反馈”四步闭环。禁止跳跃式描写（例：机甲启动→能量回路充能→神经接驳同步率→武器锁定→开火→后坐力传导）。 |
| **物理反馈** | 所有超规格能力/科技必须附带可量化的环境或机体反馈（如：过载发热、重力扭曲、材料疲劳、神经负荷、辐射衰减）。杜绝“无消耗施法/无代价跃迁”。 |
| **代价** | 每次关键突破/越级战斗必须支付明确代价（资源枯竭、寿命折损、阵营仇恨、技术反噬、坐标暴露）。代价需直接转化为下一阶段的剧情推力，禁止“打完就清零”。 |
| **钩子** | 章末必须留“信息差钩子”或“状态危机钩子”（如：未知信号接入/能量临界/敌对坐标锁定/技术漏洞暴露）。禁用纯抒情、日常流水账或开放式留白收尾。 |
| **读者预期** | 每卷开篇明确告知核心目标（突破X境界/夺取Y技术/破解Z危机）；每3-5章提供一次阶段性正反馈（资源获取/战力验证/伏笔回收）；严禁长期压抑无释放或偏离主线承诺。 |
