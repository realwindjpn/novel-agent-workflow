# 《科武纪元》作家OS补丁  
## 课程补丁：电费异常揭开隐情｜男频悬疑爽文执行版

---

## 0. 补丁目标

把“日常异常物 → 信息差 → 反向碾压”的超短爽文打法，写入作者执行流程。

适用场景：

- 短故事 / 狼人篇：可直接套用。
- 《科武纪元》长篇：用于单元案、番外、支线爽点、章节钩子。
- 平台投流稿：用于标题、简介、开篇包装。

---

# 1. 写作前任务卡字段更新

以后提交人物卡 / 章节大纲 / 单元案，必须补以下字段。

## 1）核心异常物

> 一个具体、可视化、能贯穿全文的小物件或数据。

填写格式：

- 异常物：
- 正常数值 / 正常状态：
- 异常数值 / 异常状态：
- 谁最先发现：
- 谁试图掩盖：
- 最终如何反咬反派：

示例：

- 短故事：电费账单、购物卡、暖气费、监控视频、快递签收单。
- 狼人篇：月圆夜异常电表、狼毛堵住下水道、冷库耗电暴涨、血袋库存对不上。
- 科武长篇：灵能表异常、机甲耗材多出三倍、护符灵压记录、灵植耗水量、训练舱损耗日志。

---

## 2）身份势能差

> 主角必须先被低估，反派必须先占高位。

填写格式：

- 主角表面身份：
- 主角隐藏能力 / 旧身份：
- 反派表面优势：
- 反派低估主角的原因：
- 读者何时知道主角不简单：
- 反派何时知道主角不简单：

示例：

- 主角：下岗中年、租客、库管、废品站修理工、边缘武徒。
- 反派：房东、老板、豪门弟子、宗门管事、战队队长、执法署关系户。

---

## 3）三层钩子

每章 / 每篇必须至少有两层，最好三层齐全。

| 钩子层级 | 要写什么 | 回收方式 |
|---|---|---|
| 事件钩 | 到底发生了什么？ | 异常物第一次爆出 |
| 手法钩 | 反派怎么做到的？ | 主角查证、复盘、抓现行 |
| 情绪钩 | 真相揭晓时谁崩溃？ | 反派当众失态、求饶、破防 |

填写格式：

- 事件钩：
- 手法钩：
- 情绪钩：
- 本章新增钩：
- 本章回收钩：
- 未回收钩数量：不超过 2 个。

---

## 4）动作链

禁止写“他决定反击”。

必须写成 5—8 个具体动作。

格式：

> 动词 + 对象。

示例：

- 查电费 App
- 截图账单
- 翻旧监控
- 询问保安
- 静默打包
- 拆走自己装的家具
- 换锁留证据
- 当众开门验房

科武版示例：

- 调取灵能表
- 拆开旧阵盘
- 对照机甲耗材编号
- 诱导灵压过载
- 录下管事私接灵脉
- 封存能源舱
- 当众启动废弃机甲
- 逼豪门弟子跪签赔偿令

---

## 5）物理反馈

每个关键动作后面必须有可见反应。

填写格式：

- 动作：
- 环境反馈：
- 他人反馈：
- 主角身体反馈：

示例：

- 动作：主角亮出账单截图。  
  环境反馈：楼道瞬间安静。  
  他人反馈：房东脸色发白，保安把烟按灭。  
  主角身体反馈：手指还在抖，但声音稳了。

科武版：

- 动作：主角拆开灵能表。  
  环境反馈：蓝色灵光喷出，墙面阵纹亮起。  
  他人反馈：宗门管事后退半步。  
  主角身体反馈：掌心被灵流烫出血线。

---

## 6）代价

反击必须付出代价，否则爽点悬浮。

填写格式：

- 金钱代价：
- 时间代价：
- 身体代价：
- 名誉代价：
- 关系代价：
- 科武资源代价：

示例：

- 短故事：押金没了、搬家费、被群里网暴、丢工作、被亲戚误会。
- 狼人篇：暴露族群气味、消耗银弹、失控伤人风险、月圆前体力透支。
- 科武长篇：灵力耗尽、机甲核心报废、暴露古武传承、得罪豪门、失去宗门名额。

---

## 7）反派“既要又要”

反派不能只写坏。

填写格式：

- 反派既要：
- 又要：
- 所以他做了：
- 他认为自己有理的理由：
- 他破防的瞬间：

示例：

- 房东既要高租金，又要租客替他养房，所以偷偷接线。
- 老板既要员工感恩，又要克扣福利，所以把购物卡换成过期券。
- 豪门弟子既要灵脉修炼，又要凡人区名声，所以把污染转嫁给旧城区。
- 宗门管事既要业绩，又要不担责，所以把机甲损耗栽给边缘修理工。

---

## 8）章节情绪曲线

每章必须标注读者情绪位置。

填写格式：

- 本章起点情绪：
- 中段情绪：
- 末尾情绪：
- 本章爽点是否释放：
- 如未释放，延迟到第几章：

常用曲线：

1. 疑虑 → 愤怒 → 期待反击  
2. 同情 → 憋屈 → 发现主角不简单  
3. 愤怒 → 揭晓 → 爽感释放  
4. 爽感释放 → 更大黑手露头 → 期待下一章

# 2. 章节执行补丁

## A. 开篇 200 字动作

前 200 字必须完成三件事：

1. 身份  
2. 异常物  
3. 反派态度 / 身份反差暗示

### 可直接套用模板

#### 短故事版

> 我被厂里裁掉那天，房东把电费单拍在我脸上。  
>   
> “三千六，你自己看看，别装穷。”  
>   
> 我盯着账单上那个刺眼的数字，忽然想起，上个月我只在这间出租屋住了七天。

#### 狼人篇版

> 月圆前三天，我家冷库的电费翻了六倍。  
>   
> 物业经理把账单甩给我：“养狗也不能这么费电吧？”  
>   
> 我看着他鞋底沾着的灰白狼毛，没说话。

#### 科武长篇版

> 我在机甲废库当了三年修理工。  
>   
> 今天，三号能源井的灵能损耗突然暴涨了七倍。  
>   
> 管事把报废清单丢到我怀里：“签了，是你检修失误。”

---

## B. 段落节奏

执行规则：

- 每段 1—3 行。
- 每 300—500 字必须有一个推进。
- 推进只能是以下四种之一：

1. 新证据出现。
2. 对抗升级。
3. 身份反差露出。
4. 反派破防一层。

禁用：

- 单独写环境铺陈。
- 连续心理独白。
- “我想了很多”“我决定忍一忍”“事情没那么简单”这种空句。
- 没有动作的过渡段。

---

## C. 对话口吻补丁

## 1）被低估男主

特点：

- 话少。
- 不急着解释。
- 先确认事实，再出手。
- 反击时用证据说话。

口吻：

- “你确定这账是我的？”
- “这句话我录下来了。”
- “别急，还有一张单子。”
- “你刚才说，谁签字谁负责？”
- “门开了，你自己看。”

科武版：

- “这台阵盘，不是昨天坏的。”
- “灵压记录不会撒谎。”
- “你让我签，可以。先把能源井打开。”
- “这枚螺钉，是战前型号。你们谁碰过？”
- “现在还觉得我是废库修理工吗？”

---

## 2）反派

特点：

- 站在规则 / 道德 / 权力高处。
- 嘴上有理，实际心虚。
- 前期得意，后期失控。

口吻：

- “大家都这么交，怎么就你事多？”
- “你一个租客，还想查房东？”
- “别给脸不要脸。”
- “你闹大了，对谁都不好。”
- “我也是为了大家方便。”

科武版：

- “一个废库杂役，也配查灵能账？”
- “宗门规矩，不是给你质疑的。”
- “签了，对你对我都好。”
- “豪门的事，你最好少问。”
- “你以为会修几块废铁，就能翻案？”

---

## 3）旁观配角

功能：

- 提前暗示真相。
- 制造耻感。
- 让读者知道“有人知道，但没人帮主角”。

口吻：

- “你还是别问了。”
- “这事以前也有过。”
- “我什么都没看见。”
- “他惹不起。”
- “哥，你要真查，先把东西收好。”

科武版：

- “三号井不是第一次这样。”
- “你别碰，那是内门的线。”
- “昨晚有人进过废库，但我没看清。”
- “管事背后有人。”
- “你要查，就别在白天查。”

# 3. 冲突升级链

必须按这个顺序推进：

## 1）日常细节

从小事起跳。

- 电费异常。
- 月饼少了。
- 购物卡不能用。
- 灵能表跳数。
- 机甲耗材对不上。
- 狼人冷库电费异常。

## 2）利益冲突

主角要承担损失。

- 要赔钱。
- 要背锅。
- 要搬走。
- 要签字。
- 要丢工作。
- 要交出灵脉权限。

## 3）尊严 / 公平冲突

反派当众羞辱。

- “穷就别租。”
- “一个下岗的，装什么懂法？”
- “废库修理工，也配质疑宗门？”
- “狼人就该夹着尾巴做人？”

## 4）身份 / 认知崩塌

主角展示隐藏能力。

- 他懂线路。
- 他懂法律。
- 他会调监控。
- 他是前高级工程师。
- 他能读古武阵纹。
- 他知道狼人族群的血契规则。

## 5）反制

主角让反派承担具体后果。

- 房子变毛坯。
- 账单反追责。
- 购物卡被员工堵门换。
- 灵脉被封。
- 管事被当众验账。
- 反派被迫承认偷接能源。

# 4. 反向碾压画面库

结尾不能只写“他后悔了”。

必须写画面。

## 短故事可用画面

- 房东打开门，看到屋里只剩毛坯墙。
- 老板被员工堵在办公室门口要求换卡。
- 亲戚群里原本骂主角的人集体撤回消息。
- 网暴者直播间当场被警方敲门。
- 物业经理看着电表倒查记录，手里的烟掉在地上。

## 狼人篇可用画面

- 反派打开冷库，看到自己藏的银链和血袋全被直播拍下。
- 月圆夜，诬陷主角的人被狼群围在停车场。
- 物业经理低头看见自己鞋底狼毛，脸色惨白。
- 女巫验出血契，旁观者集体后退。
- 反派以为能驱狼，结果发现主角才是族群审判者。

## 科武长篇可用画面

- 管事当众打开能源井，偷接的豪门灵线全部亮起。
- 废弃机甲在主角手里重新启动，全场武徒失声。
- 豪门弟子手里的灵契反噬，跪在试炼台边。
- 宗门长老原本要罚主角，结果看到战前阵纹后站起身。
- 反派想销毁证据，机甲核心自动投影出昨夜监控。

# 5. 失败模式门禁

写完后对照以下问题，命中即改。

## 失败模式 1：开篇太大

错误：

> 开头先讲世界观、宗门历史、科技武道体系。

修正：

> 先写一个异常物。  
> 世界观藏在异常物背后。

科武修正例：

- 不写：三百年前，灵能复苏。
- 改写：我手里的灵能表，第一次在断电状态下跳了数。

---

## 失败模式 2：反派纯坏

错误：

> 反派就是坏，就是想害主角。

修正：

> 写出“既要又要”。

例：

- 既要吞灵脉收益，又要维持宗门清廉名声。
- 既要把狼人赶出社区，又要利用狼人夜巡保护房价。
- 既要员工感恩，又要压缩福利成本。

---

## 失败模式 3：主角开挂无代价

错误：

> 主角随手破解，随手打脸。

修正：

> 每次反击付出可见代价。

例：

- 查账花掉最后三百块。
- 搬走损失押金。
- 强行启动机甲烧毁经脉。
- 暴露身份后被豪门盯上。
- 狼人强行变身后失去一晚记忆。

---

## 失败模式 4：只有误会，没有信息差

错误：

> 大家误会主角，最后解释清楚。

修正：

> 必须有证据链、手法链、旁观者。

证据链示例：

- 账单异常 → 监控缺口 → 保安偷笑 → 接线位置 → 反派承认。

科武证据链：

- 灵能表异常 → 耗材编号不符 → 废库阵盘被动过 → 管事夜间出入 → 豪门灵线亮起。

---

## 失败模式 5：结尾没有具体画面

错误：

> 反派终于得到了报应。

修正：

> 写他在哪、看见什么、身体怎么反应、旁人怎么反应。

例：

> 房东推开门时，脸上的笑还没收。  
>   
> 下一秒，他僵在门口。  
>   
> 客厅空了。  
>   
> 我装的灯、柜子、地板、热水器，全拆了。  
>   
> 只剩他当年交给我的毛坯墙。

---

# 6. 短故事 / 狼人篇可借点

## 可直接借

1. 异常物开篇  
   - 电费、冷库、监控、血袋、物业账单。

2. 被低估主角  
   - 中年租客、保安、维修工、狼人边缘族人、混血狼人。

3. 反派高位压人  
   - 房东、物业、社区主任、猎狼人、女巫审判者。

4. 旁观者细节  
   - 保安偷笑。
   - 邻居闭门。
   - 族群长老装没看见。
   - 女巫助手偷偷提醒。

5. 结尾反向碾压  
   - 开门傻眼。
   - 直播翻车。
   - 血契反噬。
   - 族群审判。

## 狼人篇特殊借法

把“电费异常”换成“月圆异常”。

可用异常物：

- 冷库电费暴涨。
- 银器库存减少。
- 血袋数量对不上。
- 监控每到凌晨 3 点黑屏。
- 宠物医院夜间耗电异常。
- 地下停车场出现狼爪划痕。

狼人篇情绪抓手：

- 被当怪物歧视。
- 为保护人类社区背锅。
- 族群内部有人出卖。
- 主角明明能撕碎反派，却必须忍到证据齐。

# 7. 《科武纪元》长篇可借点

## 1）单元案结构

每个小单元可套：

> 科武日常异常物 → 主角被迫背锅 → 查手法 → 牵出势力 → 小碾压 + 大黑手露头。

示例：

- 灵能表异常 → 主角被罚 → 查出豪门偷接灵脉 → 当众封井 → 发现背后是战前遗迹坐标。
- 机甲耗材异常 → 主角被控盗卖 → 查出内门弟子改装禁器 → 废机甲重启打脸 → 禁器来源指向古武军工遗产。
- 灵植耗水异常 → 药园弟子背锅 → 查出有人催熟毒株 → 主角反向炼药救人 → 毒株来自敌国科武实验室。

## 2）主角人设强化

可借“被低估修理工”母题。

适合《科武纪元》的人设标签：

- 废库修理工。
- 古武机甲维护员。
- 灵能线路临时工。
- 战前遗物鉴定员。
- 被宗门边缘化的技修。
- 会修没人看懂的旧时代武器。

执行重点：

- 主角不是无脑强。
- 主角强在“看懂别人看不懂的细节”。
- 他的思维定势来自职业习惯。

例如：

> 别人看灵压强弱。  
> 他先看螺丝磨损。  
> 别人看武技。  
> 他先看能源回路。  
> 别人以为机甲坏了。  
> 他知道是有人故意让它“看起来像坏了”。

---

## 3）长篇不能硬套处

禁止：

- 每章都一爽到底。
- 每个反派都当场死。
- 每次打脸都无代价。
- 用现实中年职场语气污染少年主角。
- 没立设定就让读者猜科武规则。

长篇改法：

- 小反派可以当场碾压。
- 大势力只能撕开一角。
- 每次爽点后增加新代价。
- 证据链必须绑定世界观设定。
- 反派失败后留下更大问题。

示例：

> 管事被当众拿下，是小爽点。  
>

>   
> 当晚，豪门密探出现在废库外。

# 8. 发布 / 包装 / 风险门禁

平台规则不进入正文理论，转为发布检查。

## A. 标题包装门禁

标题必须包含三件事：

1. 具体名词。
2. 行为反差。
3. 对方崩溃态。

公式：

> 触发事件 + 主角反差行为 + 对方崩溃结果

示例：

- 电费暴涨三千六，我直接搬空全屋，房东开门傻眼了
- 老板发过期购物卡，我反手让全公司堵门，他当场慌了
- 冷库电费翻六倍，我查出银链密室，猎狼人跪了
- 灵能表暴涨七倍，我拆开能源井，宗门管事脸白了

禁用标题：

- 《真相》
- 《背叛之后》
- 《我的反击》
- 《科武风云》
- 《废柴逆袭》

原因：没有具体名词，没有反差，没有崩溃画面。

---

## B. 简介包装门禁

简介前三行直接复用正文前三段。

要求：

- 不解释设定。
- 不写作者感想。
- 不写“这是一个关于……的故事”。
- 第一行就给身份或异常物。

示例：

> 我在机甲废库当了三年修理工。  
>   
> 今天，三号能源井的灵能损耗突然暴涨了七倍。  
>   
> 管事把报废清单丢到我怀里：“签了，是你检修失误。”

---

## C. 题材溯源门禁

提交短故事 / 热点稿必须回答：

- 这个异常物来自哪里？
- 作者是否见过 / 拍过 / 能描述真实细节？
- 是否有具体生活凭据？
- 是否只是在蹭热点？
- 是否能落到可视化画面？

高风险：

- 纯网传事件。
- 无生活细节。
- 只有情绪，没有物件。
- 只有热点，没有人物。
- 只有反转，没有证据链。

---

## D. 风险门禁

以下内容发布前必须二次检查：

1. 现实机构、公司、学校、物业名称是否虚构。
2. 金额、账单、截图类内容是否避免伪造现实指控。
3. 狼人 / 科武设定是否与现实群体歧视脱钩。
4. 复仇行为是否避免鼓励现实违法。
5. 主角反制是否保留合法 / 规则内路径。
6. 暴力爽点是否转化为证据、规则、审判、公开揭露，而不是无差别伤害。

# 9. 章节自检清单

写完每章，对照以下清单。

## 开篇检查

- [ ] 200 字内出现主角身份。
- [ ] 200 字内出现核心异常物。
- [ ] 200 字内出现反派态度或身份压迫。
- [ ] 没有大段世界观说明。
- [ ] 没有空泛环境描写。

## 钩子检查

- [ ] 本章有事件钩。
- [ ] 本章有手法钩或情绪钩。
- [ ] 新增钩子不超过 2 个。
- [ ] 至少回收 1 个旧钩或推进 1 个旧钩。
- [ ] 章末有明确下一步问题。

## 动作检查

- [ ] 主角有 3 个以上具体动作。
- [ ] 没有用“决定反击”替代动作。
- [ ] 每个关键动作后有物理反馈。
- [ ] 主角反击付出了代价。
- [ ] 代价可见、可量化或可感知。

## 人物检查

- [ ] 主角被低估的理由清楚。
- [ ] 主角隐藏能力有前置暗示。
- [ ] 反派不是纯坏。
- [ ] 反派能写成“既要 X 又要 Y”。
- [ ] 至少一个配角知道部分真相但不明说。

## 节奏检查

- [ ] 段落多为 1—3 行。
- [ ] 每 300—500 字有推进。
- [ ] 没有独立过渡段。
- [ ] 对话推动冲突。
- [ ] 心理独白没有连续堆叠。

## 爽点检查

- [ ] 本章有压迫感。
- [ ] 本章有反击迹象。
- [ ] 如释放爽点，必须有画面。
- [ ] 如延迟爽点，章末必须给更强钩子。
- [ ] 结尾不是抽象总结。

## 科武专项检查

- [ ] 异常物已科武化。
- [ ] 规则先立，再反转。
- [ ] 爽点后增加新代价。
- [ ] 小反派可碾压，大势力留尾巴。
- [ ] 主角语气符合年龄、身份、世界观。

## 短故事 / 狼人篇

2. 反派破防型钩子  
   > 房东脸上的笑没了。  
   >   
   > 他盯着我手机里的截图，声音第一次发抖：“你从哪弄来的？”

3. 旁观者提醒型钩子  
   > 保安把烟掐灭，低声说：“哥，你要真查，就别查电表，查地下室。”

   > 他们不知道。  
   >   
   > 十年前，我就是给这栋楼设计电路的人。

1. 设定反转钩子
