# 《科武纪元》编辑学习官：三风11专访核心提炼

## 1 课程核心判断（≤6条）
1. **反英雄＞完美主角**：市井气、贪小便宜但有底线的缺陷型主角，代入感与商业留存率显著高于传统伟光正。
2. **“离谱”需情绪锚点**：脑洞设定必须绑定明确的情感驱动（兄弟情/亲情/生存底线），否则易沦为纯设定堆砌。
3. **数据反馈＞个人偏好**：慢热传统题材在免费推荐流中极易流失，快节奏、强钩子、短周期验证是起量基础。
4. **短板果断舍弃**：不擅长感情线或复杂群像时，直接砍掉或功能化处理，聚焦核心主线与人物关系网。
5. **无存稿需强牵引**：动态细纲+随性推翻可行，但必须依赖明确的主线目标与阶段性危机，否则长篇必崩。
6. **运气是放大器，坚持是底座**：首秀期数据平庸不致命，持续稳定输出情绪价值与更新量，算法会给予二次推荐。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 首章3000字内必须抛出核心设定/金手指/反常事件；3章内完成主角“缺陷+底线”人设锚定，拒绝背景说明书。 |
| **节奏** | 放弃长线蓄力，采用“单元事件+主线推进”结构；每3-5万字设数据验证点（追读/完读），卡文即砍支线保主线。 |
| **冲突** | 冲突围绕“反差感”设计（弱配强/市井扛大旗）；用“道德选择/生存代价”替代纯战力碾压，制造张力。 |
| **人物** | 主角必须带可感知的缺点；配角功能化（如死党触发主线危机）；不擅长感情线则直接不写，用战友/阵营关系替代。 |
| **题材** | 现代基底+超现实设定；世界观随剧情展开而非开篇硬塞；危机升级必须与主角能力/认知成长强绑定。 |
| **改编** | 预留高视觉化场景（契约/战斗/名场面）；对话网感化（埋梗/吐槽/反套路），便于漫画/短剧分镜转化。 |
| **平台规则** | 番茄重“完读率+追读”，日更6k-8k为基准；首秀期高频钩子+低阅读门槛；无存稿需靠细纲防断更，断更必掉推荐。 |

## 3 科武适配
### ✅ 可用点
- **主角定位**：科武底层/边缘人（如基因适配失败者/废机甲师），保留市井生存逻辑与明确底线，增强科幻语境下的代入感。
- **节奏控制**：放弃硬核设定慢热，采用“科技奇观+武道突破”快节奏；每卷一个核心危机（AI叛乱/异星入侵/资源枯竭），匹配免费流阅读习惯。
- **冲突包装**：用“科学逻辑+离谱脑洞”制造反差（如基础物理定律反制高阶异能），强化“合理性”叙事外壳。
- **关系网替代感情线**：聚焦战友羁绊、师徒传承、阵营博弈，用功能性配角推动科技树解锁或武道路线选择。

### ❌ 不可硬套点
- **无存稿+随意推翻大纲**：科武题材依赖严密科技树与世界观逻辑，随性推翻易导致设定自相矛盾、战力崩坏。
- **纯“离谱”脱离科学基底**：脑洞必须受限于《科武纪元》的物理/能量规则，不可用系统降智或玄学解释，否则破坏“科武”核心调性。
- **过度网感稀释科幻质感**：玩梗需克制，不能以牺牲硬核氛围为代价；科幻读者对逻辑自洽的容忍度低于纯都市脑洞。

## 4 编辑检查表（10条以内）
- [ ] 首章是否3000字内抛出核心设定/金手指/反常事件？
- [ ] 主角是否具备明确缺陷与不可逾越的行为底线？
- [ ] 每3-5章是否设置至少一个情绪钩子或剧情转折？
- [ ] 冲突是否依赖“代价/选择”而非纯战力碾压？
- [ ] 世界观是否通过剧情自然展开，无大段说明书式设定？
- [ ] 感情线/配角是否服务于主线，无冗余支线拖慢节奏？
- [ ] 场景描写是否具备视觉化潜力（便于改编分镜）？
- [ ] 更新节奏是否匹配平台推荐期（日更6k+，首秀期不断更）？
- [ ] “离谱”设定是否有底层逻辑/科学/规则自洽支撑？
- [ ] 细纲是否明确标注本卷核心目标与数据验证节点？

## 5 对作家角色的输入要求
- **动作链**：战斗/操作必须呈现“感知→决策→执行→结果”完整链路；禁用“一键秒杀”或模糊描写；科武交互需体现装备、能量、武技的物理衔接。
- **物理反馈**：能力释放/机甲启动/基因激活必须伴随明确感官反馈（后坐力、神经刺痛、能量过载警报、环境破坏痕迹），强化真实感与沉浸度。
- **代价**：任何越级战斗/金手指使用必须支付明确代价（寿命折损、装备损毁、阵营暴露、道德困境），杜绝无成本开挂；代价需推动后续剧情。
- **钩子**：章末必留悬念（未解危机/身份反转/新线索）；每卷结尾采用“阶段性目标达成+更大危机降临”双钩结构，维持追读惯性。
- **读者预期**：明确本卷核心爽点（科技碾压/武道突破/智斗反杀），不偏离主线承诺；避免“设定堆砌”替代“情绪释放”，确保每10万字完成一次预期兑现与数据验证。
