## 三、动作-反馈-代价-失败模式库（科武专项）

### 3.1 动作链标准模板

**长篇科武战斗（4步链）：**

```
【感知】传感器/义眼/第六感捕获敌方能量波动/动作预判
  ↓
【决策】算力分析→最优解输出→神经下达指令
  ↓
【执行】外骨骼/真气/基因锁激活→技能释放
  ↓
【反噬】算力过载/经脉超载/神经负荷→生理警告→战术调整
```

**短故事/狼人篇切片（3步链）：**

```
【触发】主角遭遇设定边界困境
  ↓
【爆发】科技/武道能力首次展示（降维打击）
  ↓
【收束】代价即时兑现+新悬念埋设
```

### 3.2 物理反馈对照表

| 能力类型 | 物理反馈（必写） | 量化指标（选写） |
|:---|:---|:---|
| 算力/AI能力 | 脑温升高、神经刺痛、视网膜过载 | CPU占用率、延迟毫秒数 |
| 武道真气 | 筋膜撕裂、血管膨胀、气息紊乱 | 真气存量、恢复周期 |
| 基因强化 | 细胞超载、代谢紊乱、免疫风暴 | 强化等级、耐受阈值 |
| 外骨骼/机甲 | 神经接驳延迟、关节磨损、能量枯竭 | 电池百分比、载重上限 |
| 空间/时间能力 | 重力异常感知、因果紊乱、存在稀释 | 稳定时长、冷却倒计时 |

### 3.3 代价设计模板

**代价类型：**

```
【一次性代价】→ 单次消耗，如弹药/能量块（用于小冲突）
【累积型代价】→ 跨章显现，如经脉损伤累积/算力永久损耗（用于核心升级）
【延迟型代价】→ 埋设→发酵→清算，如基因强化后遗症发作（用于主线伏笔）
【对等价交换】→ 重大抉择，如牺牲XX获得XX（用于剧情转折点）
```

**代价落地检查：**
- [ ] 代价是否在能力使用后3章内出现？（延迟过长读者遗忘）
- [ ] 代价是否影响后续战斗/决策？（不能是无关痛痒的惩罚）
- [ ] 代价是否可以解决/缓解？（提供升级/修炼路径，非死胡同）

### 3.4 失败模式清单

| 失败类型 | 触发条件 | 后果设计 |
|:---|:---|:---|
| **战术失败** | 算力误判/敌方情报缺失 | 物理反馈触发→被迫撤退/重伤→代价显现 |
| **认知失败** | 伏笔未回收/逻辑漏洞被敌方利用 | 主角被动→新冲突触发→补救性代价 |
| **道德失败** | 代价波及无辜/配角牺牲 | 情感线震动→主角动机重构→长期心理代价 |
| **系统失败** | 科技/武道能力失控 | 反噬升级→能力降级/封印→阶段性目标重置 |
| **资源失败** | 能量/资源枯竭 | 生存压力→战术降级→弱势翻盘钩子 |

## 五、段落节奏速查

### 节奏型谱（长篇适用）

```
【快节奏段落】→ 短句连发，动作密集
  格式：主语+动词+结果。禁止超过2行的长句。
  示例：
  他侧身。刀锋擦过肋骨。血珠飞溅。真气倒灌入经脉。
  痛。但够用。

【慢节奏段落】→ 场景铺设/情感转折/伏笔埋设
  格式：可使用较长复合句，但必须每段≤4行。
  节奏心法：慢→慢→慢→爆。连续3段慢必接一个快。

【高潮段落】→ 战斗/对决/真相揭示
  格式：短句+感官描写+代价触发
  节奏心法：压迫→喘息→突破→反噬。4个阶段缺一不可。
```

### 章节节奏公式（1800-3000字章节）

```
【黄金分割】
  开篇（200字内）：冲突/悬念入场
  中段（1000-1800字）：发展/升级/代价埋设
  收尾（300-500字）：钩子+代价/悬念未解

【每500字必有一“钩”】
  钩子类型：信息差/倒计时/伏笔触发/预期违背
```

## 六、章末钩子设计手册

### 钩子类型（按强度排序）

```
【S级钩子】→ 反直觉+逻辑闭环
  例：本章主角获胜，下章开头敌方使用主角的技术反击
  公式：成功→成功的原因变成新的弱点

【A级钩子】→ 伏笔触发+悬念升级
  例：本章提到的古武残页，下章出现匹配的敌方势力
  公式：埋设→条件触发→规模升级

【B级钩子】→ 信息差+倒计时
  例：主角不知道敌人已经布下陷阱，倒计时3章引爆
  公式：隐藏信息+显性危机+时间压力

【C级钩子】→ 情绪悬念（最低级，慎用）
  例：主角遭遇背叛/重大损失，下章揭秘原因
  注意：纯情绪断章无信息增量，仅限情感线章节使用
```

### 钩子埋设频率

```
长篇：每章≥1个钩子，每3章≥1个A级以上钩子
短故事/狼人篇：每章≥2个钩子，结尾必须S级
热点稿：开篇即钩，信息密度压缩50%
```

## 九、平台规则→发布/包装/风险门禁

### 发布门禁

```
【发布前必查】
□ 章节字数≥1800字（番茄推荐门槛）
□ 无敏感词/违规内容（宗教/政治/过于血腥描写）
□ 标签精准（科武+科幻+进化+热血，禁用无关标签）
□ 封面/简介是否匹配当前标签？（流量分发依据）

【发布时机】
□ 避开平台维护/大促期间（流量分发不稳定）
□ 建议固定更新时间（读者习惯养成）
□ 新章节发布后1小时内是否有互动？（影响初期推荐）
```

### 包装门禁

```
【简介包装】
□ 前50字是否抛出核心卖点？（科武融合/神级计算机/进化）
□ 是否包含“冲突预期”或“悬念钩子”？（“当右眼觉醒……”）
□ 是否规避过时标签？（赘婿/战神/总裁已降权）

【章节包装】
□ 章节标题是否包含关键词？（利于搜索流量）
□ 每5章是否设置“小高潮”？（完读率维持）
□ 章节之间是否有“剧情连续性提示”？（减少跳订流失）
```

### 风险门禁

```
【内容风险】
□ 能力设定是否过于“唯心/玄幻”？（硬科幻标签下需物理锚点）
□ 是否涉及“基因改造/克隆人”等敏感母题？（需弱化伦理争议）
□ 战斗描写是否控制血腥尺度？（番茄审核趋严）

【数据风险】
□ 完读率连续3章下滑→立即检查：爽点断档/节奏拖沓/期待感未兑现

□ 评论区负面反馈→区分“情绪发泄”和“逻辑漏洞”，后者优先修复

【版权风险】
□ 是否存在与现有IP过度相似的设定？（避免侵权投诉）
□ 文中技术/名词是否原创？（避免引用未授权的专利/论文）
```
