# 《科武纪元》编辑学习官：王自律《我右眼是神级计算机》拆解报告

## 1 课程核心判断（≤6条）
1. **开篇容错率极低**：早期“烂头神作”属时代红利残留，当前算法下前期留存决定生死，不可依赖后期质量拉升。
2. **大纲宜“骨”忌“肉”**：300万字体量需粗线条主干，拒绝过度细纲，为长期连载保留灵感弹性与动态调整空间。
3. **数据是节奏的硬指标**：完读率直接挂钩剧情密度，数据下滑必查节奏拖沓或爽点断档，平台算法公平但残酷。
4. **伏笔即核心资产**：硬核科幻需“走一步看百步”，伏笔设计必须跨章闭环，以逻辑自洽对抗同质化。
5. **完读率权重公式**：创新度＞期待感＞人物鲜明度＞节奏快慢＞爽点力度。科幻文必须以设定创新与推演严谨为第一驱动力。
6. **动笔抗内耗机制**：启动速度决定写作流状态，长篇连载需建立“快速进入”SOP，过度筹备必导致卡文与状态衰减。

## 2 可执行编辑规则（按实际内容取舍）

| 模块 | 规则（长篇/短故事/热点稿通用） |
|:---|:---|
| **开篇** | 首章必须抛出核心设定/悬念，禁用过时套路（如早期战神/赘婿模板）；短故事/热点稿需在3000字内完成“设定抛出+首次冲突+钩子”闭环。 |
| **节奏** | 以10万字为数据检验节点；长篇采用“粗纲+动态复盘”，每5万字核对完读率波动；短故事/热点稿采用“单线推进+高频反转”，压缩铺垫，3章内必见核心冲突。 |
| **冲突** | 冲突需源于“设定边界与人性/物理法则的碰撞”；伏笔建立“埋设-发酵-回收”台账，跨章逻辑必须自洽；热点稿冲突需绑定当下社会/科技情绪锚点。 |
| **人物** | 主角命名/身份可服务前期策略，但需预留真实动机长线伏笔；配角（含女性）需具备独立功能线，禁用纯工具人/烟雾弹堆砌；短故事人物需“标签化+单弧光”快速立住。 |
| **题材** | 硬核科幻需“设定严谨+想象力突破”，以现实科技为锚点推演；拒绝修仙套皮，专注物理/空间/AI等元素的逻辑自洽；热点稿需提取“科技伦理/生存危机”等强共鸣母题。 |
| **改编** | 预留视觉化接口（如黑科技具象、空间场景、科武战斗分镜）；结局避开套路化，设计“反直觉但逻辑闭环”收束，便于影视/漫画二创拆解。 |
| **平台规则** | 核心盯“完读率”与“跳出率”；算法依赖数据池跃迁，公平但要求高；利用书荒广场标签/评论反哺创作；10万/30万/完结为三大流量节点，需提前埋设对应爆点。 |

## 3 科武适配

### ✅ 可用点
1. **粗纲+动态调整**：《科武纪元》体系庞大，粗纲可锁定“科武融合主线+核心科技树”，避免设定过早锁死导致后期崩盘。
2. **伏笔跨章回收机制**：直接用于“古武基因/未来科技/宇宙规则”三线交织，建立伏笔台账，确保科武升级逻辑严密。
3. **完读率权重公式**：完全适用。科武文需以“科武融合逻辑创新”替代纯数值升级，以“武道反哺科技”的期待感维持长线追读。
4. **数据驱动节奏**：科武战斗/科技突破需卡准推荐流量池，避免长篇水文；短故事/热点稿可提取单场科武对决做高密度切片。

### ❌ 不可硬套点
1. **“钛合金直男+女主数百章后出场”**：科武题材需情感/羁绊线更早介入以维持长篇粘性，纯事业线易流失泛读者，需调整情感线投放节奏。
2. **“前期烂头后期神作”**：当前番茄算法对前期留存要求极高，低开高走风险极大。《科武纪元》开篇必须“设定+冲突”双强，不可依赖后期补救。
3. **“无修仙/纯科技飞升”**：《科武纪元》核心是“科武融合”，需保留武道修炼的爽感节奏与肉身突破反馈，不能完全照搬纯硬科幻的慢热推演。
4. **“日更5k靠状态/灵感”**：长篇科武需稳定更新机制，不能依赖“灵感精灵”，需建立标准化写作SOP与防卡文预案。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章内是否抛出核心科武设定/悬念？有无过时套路残留？
- [ ] 粗纲是否仅保留“世界规则+主线目标+核心伏笔”？是否预留≥30%动态调整空间？
- [ ] 每10万字节点是否完成数据复盘（完读率/跳出率）？节奏是否匹配当前推荐池？
- [ ] 伏笔是否建立“埋设-发酵-回收”台账？跨章逻辑是否自洽无硬伤？
- [ ] 主角动机与身份伏笔是否贯穿全文？配角是否具备独立功能线？
- [ ] 科武升级/战斗场景是否具备“物理反馈+代价设定”？有无纯数值堆砌？
- [ ] 创新点是否优先于爽点投放？设定推演是否符合基础科学/武道逻辑？
- [ ] 平台标签是否精准匹配？是否利用书荒广场/评论反哺剧情调整？
- [ ] 结局是否避开套路化？是否预留反直觉但逻辑闭环的收束？
- [ ] 动笔前是否完成“快速启动”准备？是否建立防卡文/防内耗机制？

## 5 对作家角色的输入要求

| 维度 | 输入标准（科武/科幻向） |
|:---|:---|
| **动作链** | 科武战斗/科技操作必须拆解为“感知→决策→执行→反噬”四步链，禁止跳跃式描写。例：启动外骨骼→神经接驳延迟→肌肉负荷超载→战术规避。短故事需压缩为“触发→爆发→收束”单链。 |
| **物理反馈** | 所有超规格能力必须附带可量化的物理/生理反馈（如重力异常导致血管破裂、算力过载引发脑温升高、武道真气撕裂筋膜）。拒绝“唯心爆发”与无代价开挂。 |
| **代价** | 每次科武跃迁/黑科技使用必须支付明确代价（寿命折损、资源枯竭、伦理反噬、系统降级、武道根基受损）。代价需与剧情推进强绑定，非一次性消耗，且需跨章显现。 |
| **钩子** | 章末钩子遵循“悬念+预期违背”原则。禁用纯情绪断章，改用“设定反转/伏笔触发/物理危机未解”。每3章必埋1个可回收钩子；热点稿需采用“信息差+倒计时”强钩子。 |
| **读者预期** | 明确管理“科武融合”预期：前期重“科技降维打击”，中期重“武道反哺科技”，后期重“规则重构”。每卷开篇需重置预期锚点，避免审美疲劳。数据下滑时优先检查“预期兑现率”与“爽点投放密度”。 |
