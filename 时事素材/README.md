# 科武纪元·每日时事素材采集

> 服务500章大纲，以现实推演2035-2040
> 核心目标：让读者觉得"我正在参与和见证历史"
> 采集标准：只收2030年前可能落地的事件/技术，标注可信度+世界观映射

## 采集方向→卷章映射

| 方向 | 映射 | 涉及卷 |
|------|------|--------|
| AI军事化/算力军备 | 铁幕联盟技术基础、智能机器战争 | 卷一~二、卷七 |
| 脑机接口进展 | 算力入体、修行体系现实依据 | 卷一~四 |
| 量子计算突破 | 算力武器、量子攻防 | 卷四~六 |
| 核聚变/氦-3 | 月球能源、戴森球技术链 | 卷四~六、卷九 |
| 太空竞赛（登月/火星/太空军） | 卷三登月铺垫~卷六火星 | 卷三~六 |
| 地缘变局（台海/中东/中亚/非洲） | 各卷冲突背景 | 卷一~五 |
| UFO/外星信号Disclosure | 暗线推进 | 卷二~十 |
| 能源/芯片/供应链 | 供应链战争、算力垄断 | 卷一~三 |
| 太空法/月球协定 | 国际博弈、太空治理 | 卷三~五 |

## 素材格式
每条标注：
- 来源+日期
- 可信度（已验证/高概率/推测）
- 预估落地时间
- 直接映射到哪卷哪章/哪个设定
- 可优化大纲的具体建议（如有）
- **爽点映射**：该事件如何让角色成为历史亲历者

## ⛔ 番茄平台红线
- 不写具体领导人姓名
- 台海只走和平路线
- 铁幕=跨国军工复合体，不绑定单一国家
- 不渲染民族对立
- 敏感事件用隐喻/化名处理
