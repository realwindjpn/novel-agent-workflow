## 一、写作前任务卡字段更新

启动新章节前，必须完成以下字段填写。缺失任何一项，视为任务卡未通过，禁止动笔。

### 基础信息层

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **章节编号** | 第X章/第X卷·第X节 | 第3章·破晓 |
| **字数目标** | 区间值：最低-理想 | 3500-4500字 |
| **时间节点** | 相对主线进度（X%） | 主线15%，距BOSS战还有5章 |

### 核心驱动层

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **本章核心冲突** | 一句话描述正在发生的矛盾 | 主角必须在24小时内破解信号源，否则全员暴露 |
| **冲突类型** | 只能选一：危机破解/体系碰撞/资源争夺/信息不对等/阵营抉择 | 体系碰撞 |
| **代价预设** | 本章必须付出的成本（至少一项） | 能量透支导致三天内无法使用核心能力 |
| **信息差设计** | 谁知道什么？读者知道多少？差距在哪？ | 读者知道信号源是诱饵，但主角不知道 |

### 悬念钩子层

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **章末钩子类型** | 只能选一：危机逼近/真相碎片/关系裂痕/身份揭露/时间倒计时/伏笔回收触发 | 危机逼近 |
| **钩子具体内容** | 不可模糊描述，必须是完整的一句话 | 主角发现自己的生物特征数据已被上传至敌方数据库 |
| **下章衔接点** | 钩子对应的下一个冲突是什么 | 下章进入逃亡/反追踪副本 |

### 人设校验层

| 字段 | 填写要求 | 示例 |
|:---|:---|
| **主角当前状态** | 生理/心理/资源/社会关系四维度 | 左臂骨折（生理-3）；处于信任危机（心理-2）；能量储备23%（资源-2）；与搭档产生路线分歧（关系-1） |
| **角色行动逻辑自洽性** | 本章行动是否符合人物性格缺陷与能力边界？标注YES或触发修改 | YES |
| **配角/反派动机链** | 他们的核心诉求是什么？本章如何受阻或推进？ | 反派：获取主角基因样本，本章行动：启动生物追踪器 |

## 二、章节自检清单（动笔后核查）

写完本章后，逐条核验。未通过项需修改后重新提交。

### 动作链验证（3项）

- [ ] **触发条件存在**：主角行动是否有外部事件触发？禁止无中生有的行为。
- [ ] **决策依据可查**：主角如何判断行动方案？是否依赖已知信息/性格逻辑/技能储备？禁止“直觉驱动”。
- [ ] **连锁结果可感**：行动后果是否影响物理环境/他人状态/后续选择？禁止“点了无回响”。

### 物理反馈验证（3项）

- [ ] **感官描写到位**：超自然/高武/科幻行为是否伴随视觉/听觉/触觉/嗅觉描写？禁止“意念施法”。
- [ ] **代价即时呈现**：能力使用后是否有即时损耗（疼痛/疲劳/资源消耗/功能限制）？禁止“无消耗开挂”。
- [ ] **环境连锁响应**：主角行为是否改变环境状态（破坏/震动/温度/光影/电磁干扰）？禁止“独立于世界之外”。

### 节奏验证（3项）

- [ ] **首屏信息密度**：前300字内是否抛出核心悬念或冲突？禁止“慢热铺设定”。
- [ ] **中段节奏控制**：每个1000字区间内是否至少包含一个“推进点”（新信息/转折/代价/升级）？禁止“水文”。
- [ ] **钩子位置精确**：章末最后150字内是否包含明确钩子？禁止“自然收尾”或“情绪收尾”。

### 人物验证（2项）

- [ ] **对话身份校验**：人物说话方式是否符合职业/性格/当前情境？禁止“AI腔调”或“网感词”。
- [ ] **缺陷/成长可追溯**：本章是否暴露主角性格缺陷或能力短板？是否通过行动/代价/失败展现？禁止“完美主角”。

### 伏笔验证（1项）

- [ ] **回收率检查**：本章是否触发至少1个伏笔回收？新埋设伏笔是否标注回收节点（标注于任务卡）？

**通过率标准**：10项全部通过视为合格；通过9项可小修提交；通过8项以下需大改。

## 三、可执行动作库（直接调用）

### 【结构执行】糖葫芦串操作模板

**每单元必须完成以下动作序列：**

1. **起**：抛出独立事件/副本/谜题（≤500字）
2. **承**：主角进入处理流程（遭遇障碍/获取部分信息）
3. **转**：遭遇意外/伏笔触发/关系裂痕（设置分支悬念）
4. **合**：事件解决但遗留代价/新谜题/主线推进
5. **挂**：章末钩子强制衔接下章

**长篇《科武纪元》适配**：每个遗迹/星球/试炼作为独立“山楂”，科武体系升级/宇宙阴谋/阵营博弈作为“竹签”。每3-5章完成一颗山楂，主线推进10-15%。

### 【冲突执行】核心冲突触发器

**有效冲突检查（全部满足才可写）：**

| 检查项 | 标准 |
|:---|:---|
| 是否威胁核心目标 | 冲突必须涉及主角的生存/升级/阵营/核心关系 |
| 是否有时间限制 | 必须在有限时间内完成，否则产生不可逆损失 |
| 是否有多方博弈 | 至少两方势力参与，各有信息差和资源限制 |
| 是否产生代价 | 解决冲突必须付出资源/关系/健康/道德代价 |

**禁止写入的冲突类型：**

- 为虐而虐：无逻辑的误会/失忆/三角关系
- 情绪宣泄：无建设性的争吵/冷战/哭诉
- 工具人冲突：配角制造冲突仅为给主角制造爽点

### 【人物执行】缺陷触发机制

**主角必须具备以下缺陷之一（开篇即锁定，不可中途更改）：**

- 能力缺陷：擅长某技能但对另一领域完全无力（如：战斗天才但社交白痴）
- 性格缺陷：过度理性/冲动/多疑/轻信/控制欲/逃避倾向
- 背景缺陷：身份原罪/家族诅咒/组织背叛/价值观撕裂
- 资源缺陷：物质匮乏/情报缺失/时间债务/社会孤立

**缺陷使用规则：**

- 每章至少一次因缺陷导致的困境/失误/代价
- 缺陷不可被轻易克服，必须通过代价或牺牲换取阶段性弥补
- 配角/反派同样必须具备独立缺陷与动机链，禁止工具人化

### 【设定执行】资料前置检查表

**写任何科武设定前，必须完成以下验证：**

| 验证项 | 操作要求 |
|:---|:---|
| 物理自洽性 | 该能力/技术是否符合已知物理法则或明确标注“例外设定” |
| 前后一致 | 该设定是否与前文已建立的规则冲突？冲突则需打补丁或废弃 |
| 视觉化可行 | 该设定是否可描述为读者可想象的场景？（禁止“概念展示”） |
| 代价匹配 | 该设定使用时是否伴随明确损耗？（禁止无限使用） |
| 层级合理 | 该设定在科武体系中处于哪个层级？是否与主角当前段位匹配？ |

**科武长篇借点**：建立“科武设定集”文档，每次动笔前检索关键词，确保物理自洽。

### 【钩子执行】章末钩子五型模板

**每章必须选择以下钩子类型之一：**

| 类型 | 触发条件 | 示例 |
|:---|:---|:---|
| **时间倒计时** | 存在明确deadline | “倒计时还剩6小时，氧气罐已经开始报警” |
| **信息炸弹** | 新揭露颠覆已有认知 | “通讯器里传出的声音，是他自己三秒后发出的” |
| **危机逼近** | 威胁已到达感知范围 | “走廊尽头传来金属刮擦声，频率与重量成正比” |
| **身份揭露** | 某角色真实身份/目的暴露 | “她终于承认：自己就是当年下令屠杀的指挥官” |
| **关系裂痕** | 信任/同盟出现裂缝 | “他选择按下那个按钮，意味着放弃她” |

**禁止使用的章末收尾**：风景描写、情绪独白、日常对话、无信息增量的感慨。

## 四、失败模式速查表

**遇到以下情况，立即触发修改预案：**

| 症状 | 诊断 | 解决方案 |
|:---|:---|:---|
| 主角行动无阻碍 | 缺少障碍设计 | 引入“信息不对等”或“资源限制”或“第三方干扰” |
| 章节读完后没有记忆点 | 缺少高光场景 | 插入视觉冲击强的单场景（动作/情感/揭示三选一） |
| 读者问“这章在干嘛” | 核心冲突不明确 | 重写起承转合，明确每1000字的推进点 |
| 配角存在感低 | 缺少独立动机链 | 为配角设计专属目标，与主线产生交集或冲突 |
| 情节与设定打架 | 物理自洽性崩溃 | 回查设定集，补打补丁或废弃冲突段落 |
| 更新后追读下降 | 钩子位置/密度不足 | 将章末钩子前移至最后150字，增加信息差密度 |
| 读者质疑主角动机 | 行动逻辑缺失 | 补充决策依据，确保“触发→判断→行动”闭环完整 |

## 五、平台规则转译（发布/包装/风险门禁）

### 发布节奏门禁

| 平台要求 | 作家执行动作 | 触发条件 |
|:---|:---|:---|
| 番茄追读率 | 每章必须包含钩子，章末不可断在情绪高点 | 追读率连续3天下降≥15%即触发结构调整 |
| 算法推荐基础 | 日更≥6000字（章节完整前提下可波动） | 断更超过48小时即触发推荐降权，需联系编辑重排 |
| 数据平稳期拉升 | 主动对接编辑节点（推荐位/征文/征文） | 达到以下标准可申请：日均追读≥5000；完读率≥30%；伏笔回收率≥80% |

### 包装风险门禁

| 风险类型 | 触发条件 | 执行动作 |
|:---|:---|:---|
| 题材偏移 | 开篇硬核但中段转言情/系统流 | 立即修正基调，或在第3章前标注题材声明 |
| 设定吃书 | 后续章节与已发布内容冲突 | 必须通过“补丁章”或“角色解释”圆回，禁止硬删 |
| 版权雷区 | 使用未授权IP/真实企业/真实事件 | 全面虚化处理，改用虚构设定 |
| 敏感词/高风险场景 | 涉及政策红线（政治/暴力/色情） | 主动查敏感词库，或降低描写密度改用暗示 |

### 出版/改编潜力评估（提前预埋）

| 维度 | 操作要求 |
|:---|:---|
| 单元结构完整性 | 每个副本/事件必须具备独立起承转合，可拆分为独立短篇投稿 |
| 社会议题共鸣 | 科武设定需关联现实议题（AI伦理/基因边界/星际殖民/资源分配） |
| 高光场景预埋 | 每个单元必须设计1-2个可视觉化的强场景（动作/情感爆发/真相揭露） |
| 长线伏笔标注 | 在大纲中标注所有伏笔的回收节点（第X章），按节点检查回收率 |
