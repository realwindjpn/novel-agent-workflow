# 《科武纪元》编辑学习官｜平台规则拆解报告

## 1 课程核心判断（≤6条）
1. **签约是流量分发的绝对门槛**：未完成实名认证与签约流程的作品无法进入推荐池，平台以签约为第一道筛选闸口。
2. **福利与数据强绑定**：千字保底（30-150元）、分成比例激励、全勤/完本奖均依赖作品质量与留存数据，非普惠制。
3. **征文是精准流量入口**：平台通过定向征文（影视向、出版向、热点短故事、女频等）集中投放亿级流量，赛道选择决定初始曝光量级。
4. **自助解决率要求≥90%**：帮助中心覆盖签约/审核/福利/账号等核心问题，未查阅规则直接反馈将被视为低效沟通。
5. **原创红线即生死线**：涉嫌抄袭/洗稿将直接触发“停止推荐分发/下架”，平台提供明确举报路径与证据提交标准。
6. **反馈需标准化**：问题描述必须包含书名、章节、站内信、截图等结构化信息，非工作时间顺延处理，时效预期需匹配平台工单量。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则提取（基于原文平台逻辑） |
|:---|:---|
| **开篇** | 原文未直接教授技法，但签约评估与推荐算法要求：前3章必须完成题材标签亮明、核心设定抛出、商业卖点展示，否则无法通过签约初审或进入流量池。 |
| **节奏** | 原文未涉及，但全勤奖/连载奖励机制要求：日更产能必须稳定，长篇需按“保底字数/更新频率”倒推章节断点，避免断更导致推荐权重清零。 |
| **冲突** | 原文未涉及，但【热点向短故事】征文导向要求：冲突需贴合当期社会/平台热点，单篇内完成“危机-对抗-反转”闭环，适配短周期完读率考核。 |
| **人物** | 原文未涉及，但影视/出版征文赛道要求：人物关系需清晰可辨、动机明确、少群像堆砌，预留视觉化呈现空间，否则无法进入改编评估池。 |
| **题材** | 原文明确：必须精准对标平台现有征文赛道或分类流量池（如科幻/悬疑/女频/出版），模糊定位将导致推荐标签错配、流量流失。 |
| **改编** | 原文明确：芒果TV影视征文、出版向征稿要求作品具备强情节主线、低敏感设定、场景可分镜化、版权链条清晰，签约前需自查改编兼容性。 |
| **平台规则** | 原文明确：实名→创建→签约流程不可跳过；福利阶梯按数据动态调整；审核问题优先查帮助中心；抄袭零容忍；反馈需带结构化证据。 |

## 3 科武适配（《科武纪元》长篇科幻）
| 维度 | 可用点 | 不可硬套点 |
|:---|:---|:---|
| **长篇连载** | 平台分成激励+全勤奖适合长篇科武的慢热世界观铺陈；原创红线保护硬核科幻设定不被融稿。 | 不可为赶全勤牺牲科武逻辑严密性；科幻长篇需提前规划“设定回收表”，避免后期战力崩坏导致分成断崖。 |
| **短故事/热点稿** | 可拆分科武世界观中的“单点事件”（如机甲试飞事故、武道基因暴走）投热点短故事赛道，测试读者反馈。 | 不可将长篇主线压缩为单篇热点稿；千字650保底/1.5万奖励仅针对独立短故事，长篇套用将导致结构断裂。 |
| **改编潜力** | 科武体系（机甲/外骨骼/能量武道）天然适配影视分镜；可预留“视觉化名场面”对接芒果TV影视征文。 | 不可硬套女频/出版向征文调性；科武男频的硬核推演与出版向的文学性要求存在赛道错位。 |

## 4 编辑检查表（10条以内）
- [ ] 实名认证与作家后台账号设置是否100%完成？
- [ ] 书名/简介是否精准匹配目标征文赛道或分类标签？
- [ ] 前3章是否已亮明核心科武设定与商业卖点？
- [ ] 更新计划是否对齐全勤/保底考核字数要求？
- [ ] 核心情节/设定是否完成原创自查（无洗稿/融梗）？
- [ ] 是否预留影视化接口（场景可分镜、人物关系清晰、无敏感设定）？
- [ ] 遇到问题是否已优先检索帮助中心并留存站内信/截图？
- [ ] 反馈提交是否包含书名、章节、问题类型、证据附件？
- [ ] 福利档位（保底/分成比例）是否与当前作品数据匹配？
- [ ] 是否避开周末/节假日提交紧急工单，合理预期处理时效？

## 5 对作家角色的输入要求
提交稿件至编辑端时，必须附带以下结构化输入，否则退回修改：
1. **动作链**：标注单章/单篇核心动作序列（如：侦察→接敌→能量过载→战术撤退），确保动作逻辑闭环，适配平台“强情节”推荐权重。
2. **物理反馈**：科武设定需量化物理反馈（如：机甲关节损耗率、重力环境对出拳速度的衰减、基因药剂代谢周期），禁止纯概念堆砌，提升影视化/短故事改编可行性。
3. **代价**：每次关键能力使用/阵营决策必须明确标注代价（资源枯竭、寿命折损、规则反噬、信任破裂），支撑长篇留存率与短故事完读率。
4. **钩子**：每章末尾或短故事开篇必须设置明确钩子（悬念/倒计时/反转/危机升级），直接对齐平台“完读率”考核指标。
5. **读者预期**：简介与前3章必须明确交付承诺（例：“硬核科武升级”“赛博武道复仇”“科幻悬疑热点”），严禁文不对题导致推荐流量错配与跳出率飙升。
