## 三、动作执行模块（强制）

### 3.1 动作链标准模板

所有战斗、技能、关键决策场景必须遵循以下结构：

```
【触发】→【决策】→【准备动作】→【执行动作】→【环境反制】→【结果】

① 触发：外部事件或对手行动打破现状
② 决策：主角基于当前状态做出选择（含权衡）
③ 准备动作：为执行动作做的物理准备（如蓄力、调整姿态、启动系统）
④ 执行动作：具体的技术动作（需符合物理逻辑）
⑤ 环境反制：环境或对手的即时响应（不可让主角无敌）
⑥ 结果：成功/失败/代价/新状态
```

### 3.2 科武动作链示例

```
【触发】
敌方破甲弹命中机甲左臂关节，连接处出现可见裂痕，液压系统开始漏油。

【决策】
能量剩余28%，不足以同时维持防御护盾和机动推进。
选项A：维持护盾→坐以待毙
选项B：弃臂保命→失去战斗能力
选项C：主动过载左臂能量回路，制造局部爆炸反制近身敌人
选定C。

【准备动作】
① 切断左臂神经连接（疼痛反馈：灼烧感从肩部向脊椎蔓延）
② 开启左臂紧急能量阀（物理反馈：金属臂表面开始泛红，散热格栅喷出蒸汽）
③ 调整姿态，将左臂对准敌方机甲腹部（目标核心位置）

【执行动作】
0.3秒内完成能量过载（超出安全阈值280%），机甲发出刺耳的高频啸叫，在0.7秒后将左臂作为定向炸弹投向敌方。

【环境反制】
敌方机甲反应速度超出预期，提前0.2秒侧身规避，但爆炸冲击波仍命中其右侧推进器。

【结果】
敌方推进器损毁，机动能力下降60%。我方左臂永久丧失，但获得局部战术优势。
代价：能量消耗加速，剩余能量降至11%；爆炸冲击波反噬导致驾驶舱防护玻璃出现裂纹。
```

### 3.3 禁用动作模式

| 禁用模式 | 示例 | 后果 |

### 4.3 反馈延迟原则

| 类型 | 延迟时长 | 适用场景 |
|-----|---------|---------|
| 即时反馈 | 0-2秒 | 所有能力使用、重要动作 |
| 累积反馈 | 5-10秒 | 大招、拼死一击 |
| 延后反馈 | 后续场景 | 暗伤、隐患、未显现的代价 |

**示例：**
- 即时："经脉在能量冲击下出现细微裂痕，剧痛让他的动作出现0.3秒迟滞"
- 累积："连续三次爆发后，经脉灼烧感逐渐从刺痛变为钝痛，再变为麻木——这是身体在强制屏蔽过度疼痛信号，意味着损伤已经接近临界"
- 延后："三个月后，他才意识到当时的能量过载导致了视网膜的永久性损伤——在强光环境下，他的视觉会出现瞬间的白盲"

## 五、代价系统（强制）

### 5.1 代价类型矩阵

所有能力突破、科技解锁、战术胜利必须附带以下至少一种代价：

| 代价类型 | 短期代价 | 长期代价 | 科武示例 |
|---------|---------|---------|---------|
| 资源消耗 | 即时能量/物资减少 | 可持续性下降 | 机甲核心寿命折损，武道修行速度减缓 |
| 身体损伤 | 即时疼痛/功能下降 | 永久性损伤/隐患 | 经脉瘢痕化，右眼视野缺失 |
| 道德妥协 | 即时心理负担 | 阵营关系/价值观转变 | 牺牲平民保全队友，为获情报动用酷刑 |
| 关系破裂 | 即时信任危机 | 长期阵营对立 | 暴露身份导致线人死亡 |
| 情报暴露 | 即时信息泄露 | 敌方针对性反制 | 暴露核心能力导致被研究 |
| 设定代价 | 即时副作用 | 能力上限锁死/路径关闭 | 能量过载协议使用次数限制 |

### 5.2 代价叠加规则

```
【代价叠加公式】
单次行动代价 = 基础代价 × 紧急程度系数 × 熟练度系数

基础代价：由能力本身属性决定
紧急程度系数：1.0（常规）→ 2.0（危机）→ 3.0（绝境）
熟练度系数：1.5（首次）→ 1.0（熟练）→ 0.8（精通）

【示例：能量过载】
首次紧急使用：基础代价100 × 2.0（危机）× 1.5（首次）= 300点代价
熟练后常规使用：基础代价100 × 1.0（常规）× 0.8（精通）= 80点代价
```

### 5.3 代价必须推动后续剧情

```
❌ 错误示范：主角付出代价，但代价在下一章就消失了
"他在战斗中右臂受伤，但第二天醒来发现伤已经好了。"

✅ 正确示范：代价直接影响后续决策和剧情走向
"他在战斗中右臂受伤，经脉连接损伤导致：
- 即时：接下来3章内无法使用右手进行精密操作（如机甲维修、密码破解）
- 延后：需要寻找专门的武道医者（引入新支线）
- 埋伏笔：某特定类型攻击会触发旧伤（为后续伏击埋线）
"
```

## 八、段落节奏模板

### 8.1 万能节奏模型

```
【标准节奏单元 × 2000-3000字】

├── 钩子回顾（100字）← 上章钩子的即时兑现或延宕
├── 场景建立（300字）← 地点、氛围、即时状态
│   └── 埋入本章节的第一个小钩子（信息差/气氛铺垫）

│   ├── 触发事件
│   ├── 决策过程（含内心权衡）
│   ├── 执行动作（含物理反馈）
│   └── 结果/代价
├── 意外转折（300字）← 超出预期的变化
│   └── 埋入本章节的第二个钩子（悬念/反转）
├── 高潮处理（500字）← 情绪/冲突的峰值
│   ├── 主角的关键选择
│   ├── 代价的即时/预期反馈
│   └── 章末钩子（必须强于开篇钩子）

```
【战斗专用节奏 × 3000-4000字】

├── 战术态势（200字）← 双方站位、能量/状态对比
├── 试探交锋（500字）← 双方初次交手，试探对方底牌
│   └── 第一波试探结果（含小代价）

│   ├── 敌方反制
│   ├── 主角代价
│   └── 物理反馈（含至少3个感官维度）
├── 战局逆转（400字）← 非预期变量介入（环境/第三方/主角觉醒）
│   └── 埋入悬念钩子（设定悬念/阵营反转）

## 九、失败模式库

### 9.1 高频失败模式与规避

| 失败模式 | 表现 | 规避方法 |
|---------|-----|---------|
| 设定通胀 | 世界观越写越大，新设定覆盖旧设定 | 每引入1个新设定，必须明确2个旧设定已失效或升级 |
| 节奏塌陷 | 章节内缺乏起伏，平淡如水 | 每1000字必须有1个"信息增量"或"情绪转折" |
| 代价失忆 | 付出代价后下一章就当没发生过 | 在任务卡中明确标注代价，在后续章节的第一稿中必须体现代价 |
| 能力通胀 | 主角能力随篇幅无限增长 | 设置能力上限锁死机制，突破必须附带永久性代价 |
| 情感脱节 | 读者对角色无感，只关心剧情 | 每3章必须有1个角色内心独白/情感抉择场景 |
| 互动沉默 | 段评/想法数据持续低迷 | 检查是否有可推理/可玩梗的互动点，在任务卡中预设互动点 |
| 数据失焦 | 纠结于自我怀疑而非数据反馈 | 设定"数据节点"（如5万字、10万字、30万字），在节点前禁止重写 |

### 9.2 危机预警信号

| 信号 | 触发条件 | 应对策略 |
|-----|---------|---------|
| 设定通胀预警 | 连续3章出现新设定 | 暂停新设定引入，回顾已有设定，合并冗余设定 |
| 节奏平淡预警 | 单章无明显起伏 | 引入意外变量（环境变化、第三方介入、角色背叛） |
| 读者流失预警 | 段评/追读连续3章低于基准 | 检查开篇承诺是否兑现，调节奏而非改大纲 |
| 创作瓶颈预警 | 连续2天无法完成每日任务卡 | 降低当日任务量，回顾已完成的章节，寻找可延伸的支线 |

□ 6. 章末钩子是否强于开篇钩子？
□ 7. 钩子是否在3-5章内被兑现或合理延宕？
□ 8. 总字数是否符合平台/编辑要求（2000-3000字）？
□ 9. 是否有至少1个可引发段评互动的"玩梗点"或"推理点"？

### 10.2 创作中自检（建议）

```
□ A. 主角的行动是否符合其性格/价值观设定？
□ B. 配角是否有独立的动机和立场（非工具人）？
□ C. 场景描写是否有空间感和时间感（而非纯心理描写）？
□ D. 对话是否符合角色身份和当前情绪状态？
□ E. 是否有"过于完美"的情节（主角占尽优势无代价）？
□ F. 设定是否前后一致（禁止"吃书"）？

```

## 二、动作执行链（强制）

### 2.1 标准动作链模板

```
【触发】→【决策】→【准备动作】→【执行动作】→【环境反制】→【结果】

① 触发：外部事件打破现状
② 决策：主角基于当前状态选择（含权衡）
③ 准备动作：为执行动作做的物理准备
④ 执行动作：符合物理逻辑的时序动作
⑤ 环境反制：环境或对手的即时响应
⑥ 结果：成功/失败/代价/新状态
```

### 2.2 科武动作链示例

```
【触发】
敌方破甲弹命中机甲左臂关节，连接处出现可见裂痕，液压系统开始漏油。

【决策】
能量剩余28%，不足以同时维持防御护盾和机动推进。
选项A：维持护盾→坐以待毙
选项B：弃臂保命→失去战斗能力
选项C：主动过载左臂能量回路，制造局部爆炸反制近身敌人
选定C。

【准备动作】
① 切断左臂神经连接
② 开启左臂紧急能量阀
③ 调整姿态，将左臂对准敌方腹部

【执行动作】
0.3秒内完成能量过载，0.7秒后左臂作为定向炸弹投出。

【环境反制】
敌方反应速度超出预期，提前0.2秒侧身规避，但冲击波仍命中其右侧推进器。

【结果】
敌方推进器损毁，机动能力下降60%。我方左臂永久丧失，但获得局部战术优势。
代价：能量降至11%；冲击波反噬导致驾驶舱防护玻璃出现裂纹。
```

## 三、物理反馈系统（强制）

### 3.1 反馈维度矩阵

**每次能力使用/战斗动作后，必须在以下至少3个维度给出反馈：**

| 维度 | 视觉 | 听觉 | 触觉 | 嗅觉 | 环境连锁 |
|-----|-----|-----|-----|-----|---------|
| 必选 | ✅ | ✅ | ✅ | — | ✅（重大动作） |

**类型化反馈示例：**

```
【能量过载类】
视觉：能量回路泛出危险的蓝光→白炽过渡，散热格栅喷出高温蒸汽
听觉：能量回路超载的低频嗡鸣→尖锐警报，伴随电容爆裂噼啪声
触觉：神经连接处灼烧感，脊椎传导剧痛

【机甲损伤类】
视觉：装甲层可见熔穿/撕裂，液压系统泄漏形成油雾
听觉：金属疲劳呻吟→结构断裂脆响，警报分级蜂鸣
触觉：驾驶舱震动传导，神经连接反馈疼痛，座椅安全系统收紧

【武道反噬类】
视觉：经脉可见的青黑纹路扩散/光芒异常
听觉：真气流转轰鸣中断或变调，骨骼细微噼啪声
触觉：经脉灼烧/冰寒/麻木感，脏器隐痛
```

### 3.2 反馈延迟原则

| 类型 | 延迟时长 | 适用场景 |
|-----|---------|---------|
| 即时反馈 | 0-2秒 | 所有能力使用、重要动作 |
| 累积反馈 | 5-10秒 | 大招、拼死一击 |
| 延后反馈 | 后续场景 | 暗伤、隐患、未显现代价 |

**示例：**

- 即时：*"经脉在能量冲击下出现细微裂痕，剧痛让他的动作出现0.3秒迟滞"*
- 累积：*"连续三次爆发后，经脉灼烧感逐渐从刺痛变为钝痛，再变为麻木——这是身体在强制屏蔽过度疼痛信号"*
- 延后：*"三个月后，他才意识到当时的能量过载导致了视网膜的永久性损伤——在强光环境下，他的视觉会出现瞬间白盲"*

## 四、代价系统（强制）

### 4.1 代价类型矩阵

**所有能力突破、科技解锁、战术胜利必须附带以下至少一种代价：**

| 代价类型 | 科武示例 |
|---------|---------|
| 资源消耗 | 机甲核心寿命折损，武道修行速度减缓 |
| 身体损伤 | 经脉瘢痕化，右眼视野缺失 |
| 道德妥协 | 牺牲平民保全队友，为获情报动用酷刑 |
| 关系破裂 | 暴露身份导致线人死亡 |
| 情报暴露 | 暴露核心能力导致被敌方研究 |
| 设定代价 | 能量过载协议使用次数限制，突破附带永久上限锁死 |

### 4.2 代价叠加公式

```
单次行动代价 = 基础代价 × 紧急程度系数 × 熟练度系数

基础代价：由能力本身属性决定
紧急程度系数：1.0（常规）→ 2.0（危机）→ 3.0（绝境）
熟练度系数：1.5（首次）→ 1.0（熟练）→ 0.8（精通）

【示例】
首次紧急使用：100 × 2.0 × 1.5 = 300点
熟练后常规使用：100 × 1.0 × 0.8 = 80点
```

### 4.3 代价闭环原则

```
❌ 错误：代价下一章就消失
"他在战斗中右臂受伤，第二天醒来发现伤已经好了。"

✅ 正确：代价直接推动后续剧情
"他在战斗中右臂受伤，经脉连接损伤导致：
- 即时：未来3章无法进行精密操作（机甲维修、密码破解）
- 延后：需寻找专门武道医者（引入新支线）
- 埋伏笔：某类型攻击会触发旧伤（为后续伏击埋线）"
```
