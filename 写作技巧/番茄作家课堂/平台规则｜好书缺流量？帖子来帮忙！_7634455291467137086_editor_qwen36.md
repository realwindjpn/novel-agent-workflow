# 《科武纪元》编辑学习官｜平台帖子运营规则提炼

## 1 课程核心判断（≤6条）
1. **帖子是独立流量池**：社区讨论不依赖正文推荐流，3亿日活流量可直接反哺书籍曝光。
2. **自来水是破圈核心**：读者自发讨论、二创、安利是提升热度的杠杆，作者需主动“点火”而非被动等待。
3. **时机决定参与度**：高光章、节点（开书/完结/生日/纪念日）、伏笔/爽点/关系推进是发帖黄金窗口。
4. **作者下场享加权**：作者亲自发帖+规范格式（书卡/话题/AI封面/>10字正文）可获平台额外曝光倾斜。
5. **互动是留存闭环**：翻牌（回复/点赞）读者帖子直接拉升追更粘性与发帖意愿，形成数据正循环。

## 2 可执行编辑规则（按原文内容取舍）
| 维度 | 规则（基于帖子运营逻辑） |
|:---|:---|
| **开篇** | 新书预热/首发禁用纯简介。必须抛出核心人设/世界观卖点，用“征集愿望/站队提问”制造参与感（例：`新角色剧透：女主有双重身份，你们猜是什么？`）。 |
| **节奏** | 平淡章节前1-2章发布“伏笔预告帖”，明确提示后文关联点，用悬念对冲阅读疲劳；名场面前发布“预警帖”拉高期待阈值。 |
| **冲突** | 冲突爆发前设置“押注/站队型”话题（例：`宿敌PK，你觉得谁能胜利？`）；冲突结束后24小时内发布“Reaction复盘帖”，引导情绪释放与名场面截图传播。 |
| **人物** | 聚焦“角色魅力沉淀”与“关系进展”。定期整理金句/玩梗/人性高光，引导二创；CP/阵营线推进前做情绪预埋，推进后开放合规二创征集。 |
| **题材** | 利用书城/搜索个性化推荐，帖子文案必须精准挂载品类标签（如`#科幻#星际战争`）。用设定解析、战力推演、手绘同人等多元素材替代传统推书。 |
| **改编/衍生** | 原文未涉IP影视/游戏改编，聚焦**社区二创衍生**：开放合规同人图、设定考据、角色生日物料征集，将读者UGC转化为书籍种草素材。 |
| **平台规则** | ①必带书卡+精准话题词+正文>10字；②优先使用AI生成封面（等待10秒）；③作者帖享额外曝光；④书末/书城/搜索三端分发，互动数据计入社区权重。 |

## 3 科武适配（《科武纪元》长篇科幻）
| 可用点 | 不可硬套点 |
|:---|:---|
| ✅ **硬核设定解析帖**：武力体系（基因锁/灵能回路/机甲参数）、科技树、物理法则推演，天然适合长帖讨论与考据。 | ❌ **强CP/修罗场模板**：若《科武》偏硬核群像/事业线，需将“情感拉扯”替换为“阵营理念冲突/战术路线分歧”。 |
| ✅ **战役/名场面预警**：星际跃迁、重力井死斗、机甲合体等视觉化场景，极易触发段评激增与截图传播。 | ❌ **纯情绪鼓动文案**：科幻读者重逻辑自洽。禁用“好虐/好甜”等空泛情绪词，需替换为“物理规则推演/战术代价分析”。 |
| ✅ **节点转化**：将“生日/纪念日”转化为“星历节点/战役周年/舰队成立日”，维持仪式感且不违和。 | ❌ **过度依赖AI封面**：科幻需严谨视觉。AI生成后必须人工校对机甲结构/星图逻辑，避免“伪科幻感”劝退核心受众。 |
| ✅ **伏笔回收互动**：时间线闭环、暗物质线索、角色身份反转，适合“预言家翻牌”与“暗线复盘”帖。 | ❌ **剧透式预告**：科幻悬疑伏笔严禁在帖子中泄露核心机制，仅做方向引导（例：`“下一章的轨道参数异常，后面有大用”`）。 |

## 4 编辑检查表（10条以内）
- [ ] 关键剧情节点（开书/高潮/完结/设定揭露）是否提前1-3章规划了对应帖子话题？
- [ ] 帖子文案是否包含明确互动钩子（站队/预测/征集）而非单向陈述？
- [ ] 是否规范挂载书卡、精准品类话题词，且正文字数>10字？
- [ ] 封面是否使用AI生成或定制，视觉符合《科武》科幻调性且无逻辑硬伤？
- [ ] 伏笔章是否配套发布“悬念预告帖”，平淡期是否用帖子拉高期待？
- [ ] 名场面/战力爆发章后，是否24小时内跟进“Reaction复盘帖”？
- [ ] 作者是否保持每周≥1次亲自发帖，并翻牌高赞/高质量读者评论？
- [ ] 帖子内容是否严格避免剧透核心反转，仅做情绪/方向引导？
- [ ] 是否将科幻设定（武力体系/科技树）转化为可讨论的“二创/解析”素材？
- [ ] 数据监控：帖子阅读量/互动率是否反哺书籍追更率与加入书架率？（需周复盘）

## 5 对作家角色的输入要求
提交章节/规划节点时，必须同步提供以下5项结构化输入，用于匹配帖子运营与读者预期管理：

| 输入项 | 定义与交付标准 | 平台映射 |
|:---|:---|:---|
| **动作链** | 战斗/探索/交互的连贯步骤拆解（例：`充能→跃迁→锁定→打击→反冲`）。需明确步骤节点，便于读者截图拆解与二创。 | 对应“名场面预警/复盘帖”素材锚点 |
| **物理反馈** | 能力释放或环境交互的具象化描写（例：`装甲形变率、重力失衡阈值、能量过载灼痕、真空爆震波`）。禁用抽象形容词。 | 提供段评激增触发器与硬核讨论切入点 |
| **代价** | 每次能力使用/阵营选择必须伴随明确损耗（寿命/资源/信任/道德底线/系统冷却）。需量化或具象化。 | 制造“站队/押注”空间，驱动读者发帖辩论 |
| **钩子** | 章末预留1个未解变量（异常读数/神秘信号/角色反常/参数偏差）。需与下章核心剧情强关联。 | 直接对接“预测押注型”帖子模板，拉升追更 |
| **读者预期** | 提前在作者说/帖子中声明本章属性（例：`“下章进入深空死斗，硬核物理战预警，非感情线”`）。 | 管理期待阈值，避免题材错位导致差评与流失 |

> **执行原则**：所有输入项需在正文定稿前同步至运营排期表。帖子不是正文的附属品，而是**流量调度器**。科幻长篇需以“逻辑自洽+视觉锚点+代价明确”为底层，用帖子放大讨论半径，而非用情绪替代设定。
