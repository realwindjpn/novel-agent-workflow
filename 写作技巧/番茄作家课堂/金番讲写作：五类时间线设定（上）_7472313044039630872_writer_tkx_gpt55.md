## 一、10条写法规则｜作家OS补丁

1. **开篇别从“第一次”写，直接切第N轮。**  
   开场动作：主角已带伤、已失误、已知道某人会死。  
   章末钩子：这不是第一次。  
   【短故事/狼人篇可借】直接写“上一轮狼人杀错人”。  
   【科武长篇可借】第N+1次文明轮回开局。

2. **读档必须先写“失败/死亡/崩盘”，再给重来。**  
   动作链：选择 → 触发错误 → 死亡/团灭/任务失败 → 身体反馈 → 回档。  
   失败不能只给信息，必须丢人、丢资源、丢信任。  
   【平台门禁】失败后下一章必须立刻反爽，不能连续憋屈。

3. **每次时间切换都要有可见动作，不准靠一句“时间倒流”。**  
   可用动作：按下装置、运转功法、血符碎裂、意识坠落、经脉逆冲。  
   反馈：耳鸣、血腥味、肌肉记忆错位、装备损伤不一致。

4. **每3—5节必须出现一次“选择节点”。**  
   标准节奏：  
   选择 → 错选失败 → 得到新信息但付代价 → 下一轮改选 → 爽点兑现。  
   不能一直调查、赶路、解释设定。

5. **圆环时间线要三线轮换，但每章当下主线≥60%。**  
   三线：过去伏笔 / 当下行动 / 未来预警。  
   每章只能让一条副线露头，不能三条一起讲。  
   章末必须给读者当章能懂的小钩子。

6. **人物记忆可清零，读者记忆不能白费。**  
   上一轮救主角而死的人，本轮被提前救下，是固定爆点。  
   反差口吻要明显：  
   - 冷静者说短句。  
   - 失控者重复关键词。  
   - 隐瞒者只说结果，不说原因。

7. **每个循环只服务一个核心问题。**  
   例：这一轮只查“谁打开了门”；下一轮才查“门后是谁”。  
   禁忌：一轮里同时换副本、换敌人、换规则。

8. **代价账本要写在文中。**  
   可扣：寿元、真气、记忆碎片、同伴信任、武器耐久、功法层数。  
   每次使用时间机制后，至少出现一次“代价反馈”。  
   例：他记得敌人的刀路，却忘了妹妹的声音。

9. **章末钩子用“双层钩”。**  
   第一层：当章可懂的悬念。  
   第二层：跨循环暗钩。  
   例：当章钩——死去队友提前说出暗号。  
   暗钩——这个暗号本不该出现在这一轮。

10. **写作前任务卡字段更新。**  
   每章开写前补齐：  
   - 本章时间线类型：顺叙 / 圆环 / 读档  
   - 本章选择节点：谁做选择，错选会怎样  
   - 回档/循环触发动作  
   - 身体反馈  
   - 本章代价  
   - 当章爽点  
   - 当章明钩  
   - 跨循环暗钩  
   - 兑现伏笔编号  
   - 平台风险：是否连续憋屈、是否伏笔欠账过长、是否信息过载  


## 二、10条章节自检清单

1. [ ] 前3章内，读者是否已经知道本卷存在特殊时间结构？  
2. [ ] 本章有没有明确动作推动时间切换，而不是心理独白跳转？  
3. [ ] 回档/循环后，有没有身体级反馈：痛感、耳鸣、错位记忆、装备异常？  
4. [ ] 本章失败是否付出了信息以外的代价？  
5. [ ] 本章主线行动是否占60%以上，没有被设定解释拖垮？  
6. [ ] 是否有一个清晰选择节点：选A会怎样，选B会怎样？  
7. [ ] 上一轮获得的信息，本轮有没有立刻用于反杀、救人或避坑？  
8. [ ] 章末是否同时有“当章能懂的小悬念”和“跨循环暗钩”？  
9. [ ] 伏笔欠账是否控制在30章内，重要问题是否有阶段性兑现？  
10. [ ] 平台发布门禁是否通过：前3章有爽点，第10章有兑现，卷末不是纯伏笔？  


## 三、3条科武落地

1. **文明圆环：科技纪元↔武道纪元交替崩塌。**  
   主角进入的不是第一次纪元，而是第N+1次重启。  
   远古遗迹=过去线，当前科武融合=现在线，未来终局预演=未来线。

2. **读档科幻化，不写廉价外挂。**  
   不叫“存档”，改成：意识回溯装置、量子武脉、逆熵功法、遗迹试炼协议。  
   限制必须明确：次数封顶、真气反噬、记忆丢失、功法降阶、同伴不再信任。

3. **副本试炼用读档，势力博弈用顺叙托底。**  
   试炼塔、秘境、武道关卡适合反复错选回档。  
   大势力战争、学院排名、文明推进不能全靠回档，否则削弱大局真实感。  
   可切短故事：单独截取一次失败循环，做番外/活动稿/狼人篇变体。
