## 一、快速执行卡（5分钟上手版）

### 核心铁律（违反即死）

| 优先级 | 规则 | 违规代价 |
|:---:|:---|:---|
| 🔴最高 | 单次提交≤5组，书名≤15字 | 提交失败，浪费实验名额 |
| 🔴最高 | 一次备齐，提交后不可增删改 | 中途暂停=永久失效，无二次机会 |
| 🔴最高 | 72小时未操作→自动固化最优解 | 固化后不可更改，接受降权 |
| 🟡高优 | 封面必须完整露出书名+笔名 | 遮挡=曝光量腰斩 |
| 🟡高优 | 书名/封面承诺→正文前3章必须兑现 | 高点击+高跳出=推荐降权 |

### 多书名实验三步走

```
第一步：备齐5组（封面+书名），覆盖不同题材侧重
         ↓
第二步：查重过滤，剔除撞名/违规/超字
         ↓
第三步：一次性提交，设置双闹钟（7-10天实验结束 + 72小时确认窗口）
```

## 三、章节自检清单

> **每次提交正文前，必须逐项核验**

### 基础合规层

- [ ] **字数合规**：书名≤15字，无超长命名
- [ ] **标点白名单**：仅中英文、数字、指定中文标点
- [ ] **查重确认**：已使用【书名查重】功能，无撞名
- [ ] **封面合规**：书名+笔名完整露出，无遮挡，无审核红线
- [ ] **封面视觉**：机甲/基因链/硬核科技元素是否与题材强绑定

### 内容对齐层

- [ ] **钩子兑现**：书名承诺的核心钩子，是否在正文前3章3000字内出现
- [ ] **题材一致性**：书名/封面标注的科幻/武道/热点标签，正文前3章是否一致呈现
- [ ] **数据绑定**：书名中的数值（如气血999）是否在正文中有对应体现
- [ ] **受众匹配**：书名吸引的受众类型， 正文前3章是否满足其阅读期待

### 风险预警层

- [ ] **降权红线**：是否存在"高点击+高跳出"风险（点击进来留存极低）
- [ ] **跨媒介风险**：若具备IP改编潜力，书名是否过于抽象/生僻
- [ ] **读者预期偏差**：承诺与正文偏差是否≤10%

## 四、失败模式库（踩坑即死，慎入）

### 致命型失败

| 失败模式 | 触发条件 | 后果 |
|:---|:---|:---|
| **提交中断** | 实验开启后中途暂停 | 永久失效，无法重启，无二次机会 |
| **固化失手** | 72小时内未手动确认最优解 | 系统自动固化，可能固化非最优解，固化后不可改 |
| **超字违规** | 书名超过15字 | 提交失败，直接浪费名额 |
| **撞名撞车** | 未查重，与高权重书名重复 | 新书曝光被稀释，进入低流量池 |
| **封面遮挡** | 书名/笔名被图案遮挡 | 曝光量腰斩，读者无法搜索到作品 |

### 慢性型失败

| 失败模式 | 触发条件 | 后果 |
|:---|:---|
| **题材错位** | 书名标榜科幻，正文开篇是言情 | 高点击低留存，推荐降权 |
| **钩子悬空** | 书名承诺"气血999"，正文前3章无对应设定 | 读者预期落空，跳出率飙升 |
| **文艺孤芳** | 抽象隐喻型书名（如《星际残阳》） | 数据直接淘汰，算法不识别审美 |
| **中途改名** | 长篇连载中强行改名 | 读者认知割裂，搜索权重清零 |

### 踩坑急救指南

```
一旦发现失败模式，按以下优先级处理：

🔴 已提交实验 → 无法撤销，只能等固化后重新开实验
🟡 实验进行中 → 确保72小时内盯紧消息，及时确认
🟡 封面有风险 → 立即下架整改，重新上传
🟢 尚未提交 → 严格按自检清单核查后再提交
```
