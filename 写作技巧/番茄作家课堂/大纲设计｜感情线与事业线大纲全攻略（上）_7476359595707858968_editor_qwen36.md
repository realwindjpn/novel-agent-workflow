# 《科武纪元》编辑学习官｜大纲设计课程提炼报告

## 1 课程核心判断（≤6条）
1. **题材定锚**：开书前必须明确“题材类型+读者核心诉求”，大纲所有节点必须围绕该诉求展开，偏离即散。
2. **双线缠绕**：感情线与事业线不可平行割裂，必须通过“事件互推”实现交织，避免在事业攻坚期插入无关情感戏。
3. **地图结构**：大纲本质是“公交站地图”，以关键剧情点为站点，通过细化子节点填充过渡，确保主线不偏航、不卡文。
4. **模块复用**：情感状态（单恋/误会/背叛/追妻火葬场等）是标准化剧情模块，可按需嵌入不同阶段的大站点中。
5. **节奏管控**：预置大纲是控制连载节奏、管理伏笔回收、防止中期崩盘的核心工具，尤其适用于悬疑/长线题材。
6. **降维拆解**：大剧情点必须向下拆解为3-5个小剧情点，小剧情点再绑定具体事件，形成可执行的写作路径。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则（长篇/短篇/热点稿通用） |
|:---|:---|
| **开篇** | 前3章必须亮出题材核心钩子与读者预期。长篇需完成“初识站点”搭建；短篇/热点稿需直接切入“冲突站点”，省略铺垫。 |
| **节奏** | 采用“站点压缩法”。长篇每10-15章完成1个小站点闭环；短篇/热点稿将“起承转合”压缩至3-5个站点内，禁止跨站跳跃或注水过渡。 |
| **冲突** | 每个大站点内必须设置≥1次“预期违背”（反转/立场碰撞/信息差）。冲突需依附于剧情模块，禁止为冲突而冲突。 |
| **人物** | 人物弧光由“具体事件”推演。细化节点时必须写明“事件触发→角色决策→行为结果”，禁止静态人设堆砌或作者强行干预。 |
| **题材** | 明确题材后，剔除与该题材读者诉求无关的支线。如科武文剔除纯日常恋爱，种田文剔除无关联的权谋暗线。 |
| **改编** | IP向/影视化大纲需提前标注“高视觉化场景”与“情感/战力高潮点”，确保剧情具备分镜转化潜力与商业落地性。 |
| **平台规则** | 番茄算法重完读率与追更。大纲需按“章末留钩、卷末收伏笔”设计；连载中期（30-50万字）必须预设“主线收紧/节奏提速”强制站点。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移）
- **地图架构**：将“科技突破/武道晋升/阵营战/世界观揭秘”设为大站点，完美契合长篇科武的卷章结构。
- **双线缠绕逻辑**：科武的“事业线”=科研攻关/功法迭代/资源争夺；“感情线”=战友羁绊/阵营博弈/理念碰撞。两者必须通过“获取材料触发冲突→冲突中建立信任→信任反哺突破”实现互推。
- **状态模块化**：将言情情感模块替换为科武特化模块（如：理念分歧→并肩试炼→道心裂痕→生死托付→阵营抉择），保持结构张力。

### ❌ 不可硬套点（需规避）
- **狗血情感模板**：“追妻火葬场/男二上位/成婚生子/强制暧昧”等强情绪模块硬套进硬核科武，会严重拖慢科技/武道设定展开节奏，破坏世界观严肃性。
- **线性情感推进**：“初识→升温→确定关系”不适用于冷峻科幻或群像科武。科武关系演进应以“利益绑定→理念碰撞→生存试炼→立场抉择”为驱动。
- **过度细化过渡**：在长篇科武中，若将“暧昧期/日常互动”拆解过多小节点，会导致核心设定（战力体系/科技树/宇宙观）展开不足，需以“技术/战力迭代”为第一优先级。

## 4 编辑检查表（10条以内）
1. [ ] 题材核心诉求是否已在开篇3章内明确抛出并贯穿首卷？
2. [ ] 感情线与事业线是否形成“事件互推”而非“平行割裂”？
3. [ ] 大纲是否严格采用“大站点→小节点→具体事件”三级结构？
4. [ ] 相邻大剧情点之间是否填充了≥3个逻辑连贯的过渡子节点？
5. [ ] 每个小节点是否包含明确的“冲突触发点”与“状态转变”？
6. [ ] 伏笔埋设是否在后续3-5个站点内安排了对应回收路径？
7. [ ] 连载中期是否预设了“节奏收紧/主线聚焦”的强制站点？
8. [ ] 人物行为是否由“具体事件”驱动，杜绝机械降神与主观强推？
9. [ ] 是否已剔除与科武基调冲突的冗余情感/日常模块？
10. [ ] 每章结尾是否预留了符合平台算法的“悬念钩子”或“状态断点”？

## 5 对作家角色的输入要求
基于课程“细化剧情点”与“读者预期管理”原则，作家提交大纲/细纲时必须包含以下硬性字段：

| 输入项 | 编辑要求标准 |
|:---|:---|
| **动作链** | 必须写明完整逻辑链：`触发事件 → 角色决策依据 → 执行动作 → 结果反馈`。禁止跳跃式推进或依赖外部巧合。 |
| **物理反馈** | 科武场景需标注动作的“能量/物理/环境反馈”。例：武器击打护甲的动能衰减、功法运转的经脉负荷、重力/辐射参数对战斗的制约。确保设定可量化、可感知。 |
| **代价** | 每个关键节点必须明确“获得与失去”。突破境界需付出资源/寿命/理智代价；关系推进需伴随信任损耗/立场牺牲。无代价的升级/情感线视为无效节点。 |
| **钩子** | 每章/每卷结尾必须预设钩子类型（悬念/反转/战力压制/情感抉择/信息差），并标注预计回收章节。禁止开放式断更或情绪断崖。 |
| **读者预期** | 开书前提交《核心爽点/痛点预期表》。明确本卷读者最想看的“技术突破/战力碾压/阵营反转/羁绊深化”是什么，并在大纲对应站点加粗标注，确保写作不偏离核心诉求。 |
