# 素材卡：USAF Project Able Baker——海上油气平台改火箭回收站

日期：2026-05-19
来源：https://www.defensenews.com/industry/techwatch/2026/05/18/us-air-force-looks-to-convert-offshore-oil-rigs-into-rocket-recovery-platforms/
类型：军事/深空工程
可信度：primary

## 一句话
美国空军SBIR项目"Able Baker"寻求将退役海上油气平台改造为海基火箭回收站，以降低发射成本、提升发射频率、分散军事与商业太空基础设施。

## 关键事实
- Project Able Baker：美空军SBIR小额创新研究项目
- 目标：将退役海上油气平台改造为"Sea-Based Recovery Stations"
- 适用火箭：SpaceX Falcon 9、ULA Vulcan、Blue Origin New Glenn
- 成本节省：传统报废拆除每平台>16亿美元；海基回收可利用现有平台
- 环境协同：与联邦"Rigs to Reefs"计划一致，报废平台转为海洋栖息地
- 战略驱动：中国已在建设海上重型火箭回收平台；美国需保持竞争力
- SBIR Phase 1：技术经济可行性、Structural Load Analysis、环境影响评估
- SBIR Phase 2： inert-mass drops 10-25吨验证、plume/strain/vibro-acoustic数据采集

## 可用细节
- 需承受火箭羽流、振动、高强度点荷载
- 被动/主动火焰偏转系统
- 远程消防能力
- 自主着陆精密导航
- 可选VTOL或驳船系统将火箭转移至运输船
- 支持Tactically Responsive Space（战术响应太空）作战
