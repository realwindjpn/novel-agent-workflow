# 1. 写作执行补丁

## 1.1 开篇补丁：前300字必须完成“三件套”

### 必写动作

开篇300字内必须出现：

1. **身份反差**
   - 表面身份：低级武修、临时研究员、废弃实验体、外城区维修工、被退学学员。
   - 隐藏身份：前线总工程师、禁区幸存者、武道宗师、核心专利持有人、旧纪元权限继承者。

2. **被冒犯事件**
   - 被夺研究成果。
   - 被抢能源密钥。
   - 被当成实验耗材。
   - 被嘲讽武道废人。
   - 被联盟机构除名。
   - 被财阀子弟羞辱。
   - 被昔日队友背刺。

3. **主角冷反应**
   - 不怒吼，不哭诉，不解释太多。
   - 用一句冷静短句压住场面。

### 可直接套用句式

- “你们确定，要把这份专利登记在他名下？”
- “很好，三分钟后，实验室会自己关门。”
- “我没意见。只是你们动的那枚密钥，不属于这个时代。”
- “继续签。签完，我好收回权限。”
- “你们叫它废稿？那就让边境防线也一起废掉。”

### 短故事/狼人篇可借点

- 开篇直接用**错发消息、系统播报、群聊截图、监控录像、告示文件**引爆。
- 可写成：
  - “狼人审判群里，长老错发了一张处决名单。”
  - “我刚被逐出族群，月神系统弹出提示：检测到唯一真王血脉。”
  - “未婚狼王带着白月光来退婚，我当场开启族契撤资。”

### 科武长篇可借点

- 开篇可以用：
  - 全球公告。
  - 实验录像泄露。
  - 战场黑匣子重启。
  - 身份权限认证失败。
  - AI系统误判主角为“已死亡最高权限者”。

### 禁用

- 禁止用大段环境描写开头。
- 禁止先讲千年历史。
- 禁止主角内心碎碎念三页。
- 禁止开篇只写日常训练，没有冲突。

# 2. 反击场景动作链补丁

## 2.1 每个反击场景必须写满四步

标准动作链：

> 取证 → 留存 → 出手 → 收尾

### 示例：现实/短故事模板

1. **取证**
   - 录音。
   - 截图。
   - 调监控。
   - 留合同。
   - 查转账记录。

2. **留存**
   - 上传云端。
   - 发给律师。
   - 交给公证处。
   - 同步给媒体/族群/联盟数据库。

3. **出手**
   - 撤资。
   - 冻结账户。
   - 公布证据。
   - 解除契约。
   - 申请仲裁。
   - 当众验明权限。

4. **收尾**
   - 反派失去资源。
   - 围观者倒戈。
   - 主角拿回资产。
   - 留下下一章钩子。

### 科武场景模板

> 启动 → 传导 → 命中 → 代价

1. **启动**
   - 芯片亮起。
   - 内息逆转。
   - 机甲核心点火。
   - 神经接口接入。
   - 旧纪元权限唤醒。

2. **传导**
   - 能量沿脊柱攀升。
   - 纳米线路烧红。
   - 武脉出现裂光。
   - 磁场压弯地面金属。

3. **命中**
   - 护盾碎裂。
   - 对手膝盖砸地。
   - 机械臂被震断。
   - 实验舱玻璃爆开。
   - AI防火墙被贯穿。

4. **代价**
   - 主角寿元扣减。
   - 旧伤复发。
   - 武脉过载。
   - 身份暴露。
   - 关系网断裂。
   - 核心能源减少一格。

### 禁用失败写法

- “他冷冷一笑，敌人全跪了。”
- “她随手一挥，所有问题解决。”
- “系统突然奖励无敌力量。”
- “反派无理由降智，把证据自己送上门。”

# 3. 物理反馈补丁

## 3.1 反派崩溃必须落到身体和动作

### 必写反馈类型

1. **脸色变化**
   - 脸色惨白。
   - 嘴唇发灰。
   - 额角冒冷汗。
   - 瞳孔骤缩。

2. **手部动作**
   - 手指发抖。
   - 抓碎杯子。
   - 指节发白。
   - 文件掉在地上。
   - 死死攥住衣角。

3. **身体失控**
   - 膝盖一软。
   - 后退半步撞到桌角。
   - 嗓音劈裂。
   - 呼吸急促。
   - 当场干呕。

4. **环境反馈**
   - 屏幕炸出红色警报。
   - 门禁锁死。
   - 地面裂开。
   - 电流烧焦墙面。
   - 机甲关节冒烟。

### 短故事/狼人篇可借点

- 狼人变身反馈要视觉化：
  - 爪尖缩回。
  - 狼耳垂下。
  - 族纹熄灭。
  - 狼王威压反噬。
  - 银链烫穿皮肤。

  - 当场撤婚契。
  - 当场验血脉。
  - 当场剥夺族徽。

### 科武长篇可借点

  - 经脉爆出青光。
  - 骨节发出金属摩擦声。

- 科技反馈：
  - 仪器读数飙红。
  - 服务器风扇尖啸。
  - 机械义肢过载冒烟。
  - 量子锁链自动断裂。

# 4. 代价补丁

## 4.1 每次胜利必须标价

主角不能白爽。每次赢，都要付出或埋下代价。

### 可选代价库

#### 资源代价

- 能源核心消耗。
- 专利权限暴露。
- 资金链被迫断开。
- 重要设备损毁。
- 药剂库存归零。

#### 身体代价

- 旧伤复发。
- 武脉裂开。
- 神经接口烧伤。
- 寿命扣减。
- 精神污染加深。

#### 关系代价

- 与旧队友彻底决裂。
- 被联盟列入观察名单。
- 财阀开始围剿。
- 导师误会加深。
- 亲族断绝关系。

#### 世界观代价

- 禁区坐标泄露。
- 旧纪元AI苏醒。
- 边境防线权限变更。
- 主角隐藏身份被部分识破。
- 更高阶敌人开始关注。

### 示例句

- “权限收回的一瞬间，他左眼的机械虹膜暗了一格。”
- “她赢了这场仲裁，也彻底失去了进入中央城的资格。”
- “那一拳打碎了对方的机甲，也让他的武脉裂纹扩大到第三根肋骨。”
- “实验室重新听命于他，可联盟监察部的红色名单上，也多出了他的名字。”

### 禁用

- 禁止无消耗开大。
- 禁止主角永远不受伤。
- 禁止所有人无条件崇拜。
- 禁止每次打脸后世界完全无反噬。

# 5. 人物口吻补丁

## 5.1 主角口吻：冷、短、准

### 适合《科武纪元》的主角说话方式

- 少解释。
- 不求饶。
- 不情绪化争辩。
- 每句话都带信息量或压迫感。

### 可用口吻

#### 冷静型

- “证据够了。”
- “现在轮到我执行协议。”
- “你们的问题不是贪，是不懂权限。”
- “我给过你一次校验机会。”

#### 降维型

- “这套算法，是我十七岁写废的版本。”
- “你们管这个叫武技？”
- “别启动第三层护盾，它会先烧死你。”
- “你偷走的不是成果，是引爆器。”

#### 克制愤怒型

- “我不解释，是因为你们没有读取权限。”
- “这笔账，我按联盟法算。”
- “别急，名单上还有你。”

### 短故事/狼人篇可借点

- 口吻可以更狠、更短、更有传播性：
  - “退婚可以，族矿留下。”
  - “狼王印？假的。”
  - “你护她，我撤族契。”
  - “跪什么？刚才不是说我血脉低贱吗？”

### 科武长篇可借点

- 避免土味霸总腔。
- 多用技术、权限、规则、战场经验形成压迫：
  - “你的机甲不是坏了，是被我从协议层拒绝了。”
  - “武者靠血气，你靠药剂。差别很大。”

# 6. 段落节奏补丁

## 6.1 爽点段落标准节奏

每个关键段落按以下节奏写：

> 短句起冲突 → 反派压迫 → 主角冷反应 → 动作链展开 → 物理反馈 → 代价/钩子

### 段落模板

1. **短句起冲突**
   - “门禁响起红灯。”
   - “他的名字被从项目名单上划掉。”
   - “狼族审判台上，族契开始燃烧。”

2. **反派压迫**
   - “你只是个临时工。”
   - “你不过出过一点力。”
   - “没有我们，你什么都不是。”

3. **主角冷反应**
   - “那就按协议来。”
   - “你确定要这么说？”
   - “好，我撤回授权。”

4. **动作链**
   - 主角调出证据。
   - 连接权限。
   - 启动核心。
   - 公开记录。

5. **物理反馈**
   - 反派脸白。
   - 设备爆红。
   - 地面震裂。
   - 围观者安静。

6. **代价/钩子**
   - 主角身份暴露。
   - 更高级权限被唤醒。
   - 敌方后台出现。
   - 新任务倒计时开始。

# 7. 章末钩子补丁

## 7.1 每章结尾必须留一个待解信息

### 四类必选钩子

#### 1. 身份揭露钩

- “系统播报：欢迎归来，零号总工程师。”
- “审判官看清他的基因编号后，手里的枪掉了。”
- “她的族纹不是银色，而是早已灭绝的黑月纹。”

#### 2. 关键道具钩

- “盒子里不是芯片，而是一截还在跳动的机械脊骨。”
- “能源密钥自动指向了禁区深处。”
- “族契烧尽后，露出了第二份婚契。”

#### 3. 反派下一步钩

- “中央城的监察令，在同一秒发出。”
- “财阀会议上，有人按下了清除按钮。”
- “狼王没有追来，他去了母亲的墓前。”

#### 4. 信息差倒计时钩

- “距离边境防线失守，还剩六小时。”
- “权限将在十分钟后彻底转移。”
- “三天后，所有人都会知道他没死。”

### 短故事/狼人篇要求

- 每800字至少一个小反转。
- 章末钩子要狠、直、短：
  - “可验血结果出来，跪下的是狼王。”
  - “我撤掉族契后，整座狼城断电了。”
  - “他们不知道，那个被他们献祭的孩子，是月神本人。”

### 科武长篇要求

- 每章一个待解信息即可。
- 不必每章都大打脸，但必须有：
  - 新信息。
  - 新危机。
  - 新权限。
  - 新代价。
  - 新敌人动作。

# 8. 失败模式门禁

写完一章后，发现以下情况，必须返工。

## 8.1 情绪失败

- 主角哭闹超过行动。
- 主角靠别人救场。
- 主角被羞辱很久才反击。
- 反派只是嘴贱，没有结构性压迫。
- 爽点释放太晚。

## 8.2 人设失败

- 男主恋爱脑。
- 女主无意义圣母。
- 主角卑微讨好反派。
- 为了误会强行不解释。
- 高智角色突然降智。

## 8.3 科武失败

- 科技设定无规则。
- 武道力量无代价。
- 科技和武道只是名词，没有动作表现。
- 主角开挂不消耗。
- 世界观被爽点打穿。

## 8.4 改编失败

- 没有可截图台词。
- 没有画面记忆点。
- 场景全靠解释，没有动作。
- 标题看不出冲突。
- 前300字没有爆点。

# 9. 短故事/狼人篇可借点

## 9.1 可直接使用的结构

### 结构一：退婚/撤资/撤族契

适合狼人篇。

流程：

1. 狼王或未婚夫当众羞辱。
2. 女主/主角不争辩。
3. 拿出族契、矿权、血脉证明。
4. 当场解除绑定。
5. 对方资源崩塌。
6. 章末揭示主角更高身份。

可用标题：

- 《狼王带白月光退婚，我撤走整座族矿》
- 《他们说我血脉低贱，验血后全族跪了》
- 《未婚夫与她结契当天，我收回月神印》

## 9.2 可借人物

- 清醒女主。
- 黑莲花阶段性面具。
- 护崽母亲。
- 嘴硬狼王反派。
- 凶人变护崽狂魔配角。

## 9.3 可借爽点

- 当众验身份。
- 当场撤资源。
- 族群断电/断粮/断防御阵。
- 背叛者被规则反噬。
- 主角冷处理，不哭不闹。

## 9.4 不建议放入长篇主线

- 替婚。
- 白月光争宠。
- 婆媳掀桌。
- 纯家庭伦理吵架。
- 为了虐而虐的误会。

# 10. 科武长篇可借点

## 10.1 可长期吸收的结构

### 1. 满级大佬回新手村

主角表面低位，实际握有：

- 旧纪元权限。
- 核心技术专利。
- 禁区生还经验。
- 失传武道传承。
- 战场指挥记录。
- 能源密钥。

### 2. 结构性冲突

用以下冲突替代普通吵架：

- 专利归属。
- 权限继承。
- 武道传承合法性。
- 能源矿控制权。
- 实验伦理审判。
- 联盟法理漏洞。
- 财阀垄断技术。

### 3. 科武双体系动作

每次战斗都要体现：

- 科技如何启动。
- 武道如何传导。
- 二者如何互相限制。
- 胜利付出什么代价。

### 4. 势均力敌CP

如果写感情线：

- 一人偏科技。
- 一人偏武道。
- 双方互相补位。
- 不写单方拯救。
- 不写恋爱脑拖主线。

## 10.2 科武长篇禁止硬套

- 不为劳动节强行改主线。
- 不把豪门短剧桥段硬塞中央城。
- 不让女主长期疯批黑莲花。
- 不用无脑退婚推动主线。
- 不用狗血误会替代世界观冲突。

# 11. 平台规则转化：发布/包装/风险门禁

## 11.1 发布策略

### 短故事/狼人篇

优先发布方向：

- 退婚撤资。
- 血脉反转。
- 族契反噬。
- 女性清醒反击。
- 母女/族群互助。
- 当众打脸。
- 现实痛点狼人化。

节点可借：

- 劳动节：职场压榨、项目署名、打工人反击。
- 家庭现实：母亲离婚、族群压迫、女性财产权。
- 乡村邻里：可转成边境聚落、狼人族村、外城区生活区。

### 科武长篇

发布不追热点硬改，但章节包装可强调：

- 科技权限。
- 武道打脸。
- 主角硬底牌。
- 反派结构性压迫。
- 每章强钩子。

---

## 11.2 包装策略

### 标题公式

> 行为 + 反差结果

可用公式：

- 《他们夺我专利，我让整座实验城停机》
- 《被联盟除名后，我重启旧纪元权限》
- 《未婚妻抢我项目，我撤回边境防线算法》
- 《狼王退婚当天，我收回月神契》
- 《他们说我是废武者，检测仪当场爆表》

### 简介公式

1. 主角被冒犯。
2. 反派理直气壮。
3. 主角拥有硬底牌。
4. 一句话承诺爽点。

示例：

> 陆沉被逐出实验室那天，所有人都说他只是个挂名研究员。  
> 直到边境防线失控，联盟才发现，核心算法的最高权限，从来只认他一个人。

## 11.3 风险门禁

### 内容风险

- 解气可以，不能反社会。
- 复仇可以，不能无差别伤害。
- 黑化可以，不能宣扬恶意屠杀。
- 主角冷酷可以，不能失去正向价值底线。
- 现实议题可以写，但不能煽动极端对立。

### IP风险

- 如果借经典IP配角视角：
  - 尊重原角色属性。
  - 不强行OOC。
  - 不恶搞核心设定。
  - 不把原人物写成工具小丑。

### 科武风险

- 科技逻辑不能随便变。
- 武道等级不能临时改。
- 权限系统必须前后一致。
- 开挂必须付代价。
- 不能为了爽点破坏世界观规则。

# 13. 章节自检清单

交稿前逐项检查。

## 13.1 开篇检查

- [ ] 前300字内是否出现强冲突？
- [ ] 是否有身份反差？

- [ ] 主角是否用一句冷反应压场？

## 13.2 爽点检查

- [ ] 本章是否有明确爽点？
- [ ] 爽点是否释放及时？
- [ ] 反击是否不是纯嘴炮？
- [ ] 反派是否有“理直气壮”的压迫理由？

## 13.3 动作链检查

- [ ] 是否写出取证？
- [ ] 是否写出留存？
- [ ] 是否写出出手？
- [ ] 是否写出收尾？
- [ ] 科武技能是否写出启动、传导、命中、代价？

## 13.4 主角检查

- [ ] 主角是否清醒理性？

- [ ] 是否没有无意义隐忍？

## 13.5 世界观检查

- [ ] 科技逻辑是否自洽？
- [ ] 武道体系是否有规则？
- [ ] 爽点是否没有打穿世界观？

# 14. 可直接调用的章节模板

## 14.1 科武长篇章模板

```text
【开篇】
用系统播报/实验事故/权限异常/战场录像引爆冲突。

【压迫】
反派用专利、权限、法理、等级、能源控制权压主角。

【冷反应】
主角一句短句回应，不解释太多。

【动作链】
取证/调权限/启动装置/释放武技。

【反馈】
反派身体失控，设备爆红，环境受损。

【代价】
主角旧伤、能源、身份、关系网出现损失。

【章末钩子】
更高权限苏醒/反派后台出手/禁区倒计时/关键道具出现。
```

## 14.2 短故事/狼人篇模板

```text
【开篇】
当众羞辱、退婚、错发消息、族契审判。

【压迫】
反派理直气壮：“你不过是低阶血脉/你只是出力/没有我你什么都不是。”

【冷反应】
主角：“退可以，族矿留下。”

【反击】
验血脉、撤族契、公开证据、收回资源。

【反馈】
狼王脸白，族纹熄灭，围观者倒戈。

【代价】
主角被逐出族群/暴露月神身份/引来更强敌人。

【钩子】
真正的王印亮起，或下一份契约出现。
```
