# 《科武纪元》编辑学习报告｜基于番茄爆款短故事作者专访

## 1 课程核心判断（≤6条）
1. **数据驱动迭代**：逐章数据监控（追读/完读/章评）+编辑精修是突破留存瓶颈的唯一路径，非凭感觉改文。
2. **大纲颗粒度定生死**：10万字细纲（含每章情节点、情绪爆点、数据预期）是过测与稳定收入的基建。
3. **结构底层逻辑**：长短篇均需“强冲突开篇→快速推高潮→意料之外转折→余韵结局”，起承转合不可缺失。
4. **题材垂直与情绪锚点**：放弃泛写，深耕单一情绪赛道（如BE/女性觉醒/亲情遗憾），情绪浓度直接决定爆款率。
5. **改编前置思维**：短剧/IP偏好“人物极简、主线清晰、场景集中、情绪爆点密集”的树干型结构，需在动笔前预留接口。
6. **平台规则反哺创作**：书名/标签/首秀/书测机制需在动笔前规划，短篇需对标爆款书单拆解结构，非完稿后补救。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 前3章必须抛出核心矛盾/生存危机；短故事首段即切入冲突，禁用世界观/背景铺垫。 |
| **节奏** | 长篇按“3章小高潮/10章大转折”切分；短篇“长驱直入”，删减所有过渡性描写，直奔主线。 |
| **冲突** | 冲突需单一且极致。长篇可多线交织但需有主轴牵引；短篇冲突必须闭环于单篇内，不拖沓。 |
| **人物** | 长篇构建“网状关系”但需明确核心驱动力；短篇“砍枝叶留树干”，主角+核心配角≤3人，动机纯粹。 |
| **题材** | 垂直深耕，结合平台热点（如女性觉醒/亲情BE）；以“情绪释放+现实映照”为内核，避免盲目跟风甜文。 |
| **改编** | 预留短剧接口：对话驱动、场景≤3个/章、每章末留情绪爆点或反转；结局留白或强反转，适配二创传播。 |
| **平台规则** | 严格遵循10万字书测机制，前10万字大纲完整度≥90%；短篇需研究爆款书单结构；书名/简介由编辑/市场数据优化。 |

## 3 科武适配（《科武纪元》）
### ✅ 可用点
1. **强冲突开篇**：科幻设定（如星舰跃迁故障/武道基因崩溃/能量潮汐）直接作为开篇危机，不堆设定。
2. **细纲基建**：科武体系（科技树/武道境界/能量守恒/资源分配）必须写入10万字细纲，避免后期战力/逻辑崩坏。
3. **情绪锚点**：硬核科幻易冷，需注入“人性抉择/牺牲/遗憾”等高浓度情绪，提升追读与IP价值。
4. **改编接口**：科武视觉奇观+单元剧结构，天然适配短剧/动漫化，可设计“主线贯穿+单元副本”模式。

### ❌ 不可硬套点
1. **纯BE/虐文套路**：科武需逻辑自洽与希望感，不能为虐而虐；悲剧需源于“科学规律/武道代价/资源博弈”而非狗血误会。
2. **人物极简**：长篇科幻需群像与势力博弈，不可强行套用短篇“≤3人”规则，需平衡“网状世界观”与“主线聚焦”。
3. **短平快节奏**：科武设定（原理/境界/装备）需合理篇幅铺陈，不可完全照搬短篇“爆发式”节奏，需预留“设定消化期”（每卷1-2章专用于规则展示与读者预期校准）。

## 4 编辑检查表（10条以内）
- [ ] 开篇前3章是否已抛出核心危机/世界观冲突？
- [ ] 10万字内大纲是否细化至每章情节点、情绪爆点与数据预期？
- [ ] 人物关系是否主次分明（长篇核心势力≤5，短篇核心人物≤3）？
- [ ] 节奏节点是否达标（每3-5章小高潮，每10章大转折/卷末钩子）？
- [ ] 题材标签是否垂直且情绪指向明确（如“科幻+女性觉醒/科武+代价美学”）？
- [ ] 是否预留短剧/动漫改编接口（场景集中、台词驱动、视觉化强）？
- [ ] 书名/简介是否含核心钩子+情绪词，并经市场/编辑验证？
- [ ] 是否建立数据监控机制（追读/完读率/章评，低于阈值立即改文）？
- [ ] 设定是否仅作为冲突催化剂（科技/武道不堆砌，服务剧情推进）？
- [ ] 结局是否留有余韵或逻辑反转（禁用机械降神，伏笔回收率≥80%）？

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 严格遵循“触发条件→决策逻辑→执行动作→物理/能量结果”闭环。科武战斗/科技操作需符合设定内的物理法则，禁用“意念流”或无逻辑瞬发。 |
| **物理反馈** | 所有能力释放/招式/科技应用必须伴随具象反馈（环境破坏、肌肉撕裂、能量过载、设备过热、感官剥夺）。用五感描写替代抽象形容词，强化沉浸感。 |
| **代价** | 每次核心能力突破/越级战斗/科技跃迁必须支付明确代价（寿命折损/理智侵蚀/资源枯竭/情感剥离）。代价需前置预告并在剧情中兑现，驱动人物弧光与BE美学。 |
| **钩子** | 章末必留悬念（信息差/危机倒计时/情感反转/设定伏笔）。短篇采用“一句话钩子”（单句制造认知颠覆），长篇采用“卷末大钩”（多线收束+新危机开启）。 |
| **读者预期** | 建立“承诺-兑现-升级”循环。开篇明确核心卖点，每10章兑现一次预期爽点/泪点，随后立即拔高预期阈值。避免情绪疲劳，用“代价兑现”替代“无脑爽”。 |
