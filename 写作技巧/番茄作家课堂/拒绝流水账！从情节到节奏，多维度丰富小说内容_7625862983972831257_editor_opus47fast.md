# 《拒绝流水账》编辑提炼 · 科武纪元适配版

> 来源：番茄作家课堂 · 未小兮 · 2026-04-07 · [原文](https://fanqienovel.com/writer/zone/article/7625862983972831257)
> 用途：长篇《科武纪元》主线 / 短故事 / 热点稿编辑准绳

---

## 1 课程核心判断（6条）

1. **"丰富"≠"堆字"**：判定标准是"有层次、有质感"，超过100字的环境/情绪描写默认怀疑为水文。
2. **每个核心情节必须三段式**：铺垫 → 过程 → 余波。缺任一段即判定为"跳跃式流水账"。
3. **过程章节靠"递进+反转的层数"撑场**，不是靠细节密度。主角应有"陷入劣势→出牌→再陷劣势→再出牌"的多轮节拍。
4. **环境描写是功能件**，必须同时承担"画面"与"情绪"两项功能，单独写景=水文。
5. **节奏=张弛比**，紧张冲突后必须给读者喘息位（日常/独处/回忆），但日常严禁出现在追杀、对峙等强张力段落里。
6. **人物逻辑是丰富度的天花板**：所有扩写都不能违反角色性格与动机；冷漠者突然热情必须有可见的转变事件。

## 2 可执行编辑规则

### 开篇（铺垫）
- 重大转折前，至少埋 **3 个可回看的细节**（动作迟疑、物件、语言回避）。例：男主反派身份前，需有"看旧照躲闪+提车祸转话题+抽屉里铜纽扣"三条线。
- 铺垫细节必须服务后续揭示，**无回收的细节删**。

### 节奏
- **大高潮场景**：写细，写满，但只围绕"核心目的物"展开。无关支线一律压后或砍。
- **高潮之间**：插一段轻量日常或独处，长度≤一章的1/3。
- **反转密度**：单卷不超过 2 次大反转，否则读者麻木。
- **延伸 vs 拖沓判定**：同一目标若被反复"再试一次"超过 3 轮且无新信息，判定为原地踏步，必须引入新变量（新人物/新规则/新代价）。

### 冲突
- 单次冲突需 **多轮交手**（至少 3 轮：劣势→翻盘→再劣势→杀手锏），每轮换"牌"，每张牌都有前文出处（"之前历练所得"），禁止凭空掉宝。
- 每次冲突结束必写"余波"：情绪变化 / 关系变化 / 新隐患 / 新矛盾，至少命中其一。

### 人物
- 情绪禁用直白形容词（"她哭了""他很温柔"），改写动作链：眼底泛红→转身→指尖攥衣角。
- 同一人设标签不可用同一句式重复表达，需变换载体（动作、对白、第三方视角）。
- 配角出场不能是巧合，至少与主线有一条暗线挂钩（身世/秘密/任务）。

### 题材（环境侧重）
- 科幻在原文未列，按其方法论补：**侧重技术异象、文明压迫感、人体/机械触感**（金属低频共振、护盾形变、能量味觉化）。
- 切忌玄幻式"灵气弥漫"挪用到科武场景。

### 改编（短故事/热点稿）
- 短故事保留"铺垫—过程—余波"三段，砍掉支线与日常；过程段保留 2 轮反转即可。
- 热点稿允许跳过铺垫，但**余波必须保留**（一句话情绪/关系扣题）。

### 平台规则（番茄向）
- 单段景物+情绪描写 **>100字 触发水文警报**，强制压缩。
- 日常对白以**短句+语气词+小动作**为单元，禁止两人"你一言我一语"连续 5 轮无停顿。
- 紧张段落（追杀、对峙、生死关）**禁止**插入温馨日常。

## 3 科武适配

### 可用点
- **三段式情节结构**：与"武道闯关+科技阴谋"双线极契合，每次突破/任务都跑铺垫—过程—余波。
- **多轮翻盘节拍**：科武对战天然适合"功法A→对策→功法B→底牌→杀手锏"的递进，每张牌对应前文夺得的科技/功法资源，强化金手指合理性。
- **余波联动**：一场战斗后引发派系反应、舆论、能量后遗症、肉身代价，可直接驱动下一卷。
- **环境作情绪**：科武世界的实验室、废墟战场、星港、宗门数据中心，按"画面+情绪"双功能写。
- **配角伏笔**：科研伙伴、神秘旁观者、组织内线，出场即埋钩。

### 不可硬套点
- **言情式温馨日常**：科武主线偏硬核冒险，过量"揉头、撇嘴、傲娇"会拉低题材调性，保留但稀释。
- **玄幻式宗门景物模板**：直接套"飞檐翘角+灵气弥漫"会让科武丢失科技感，改写为"力场环绕的悬浮道场+合金檐角"。
- **"暗中调查"式女频铺垫节奏**：科武读者耐心更短，三条铺垫线建议在同一章内交付，不要拖三章。
- **回忆杀做喘息**：科武适合用"实验数据复盘/师门训诫"代替言情式回忆，避免节奏闷。

## 4 编辑检查表（10条以内）

- [ ] 本章每个核心事件是否齐备 **铺垫 / 过程 / 余波**？
- [ ] 出现的关键道具/能力，是否在前文有出处？
- [ ] 冲突是否有 **≥3 轮**翻转节拍，每轮换牌？
- [ ] 情绪是否用动作链表达，**避免**"很/十分+形容词"？
- [ ] 单段景物+情绪是否 **≤100 字**？
- [ ] 高潮章后是否安排了喘息段？喘息段是否被错误放进强张力情节？
- [ ] 新增配角/支线是否与主线有可见钩子？
- [ ] 本卷反转次数是否 **≤2**？
- [ ] 人物行为是否符合既定性格；若反常，是否有触发事件？
- [ ] 是否存在"同一目标反复试 3 轮以上无新变量"的原地踏步？

## 5 对作家角色的输入要求

写手交稿前，必须在每个核心场景提供以下五件套：

1. **动作链**（≥3 步）
   _不写"他很愤怒"，写：颌肌绷紧 → 指节按上腰侧能量刃 → 视线锁向对方瞳孔反光。_
2. **物理反馈**
   科武场景必须给出身体/装备/环境的可感数据：护盾过载后的耳鸣、肌纤维撕裂感、合金地面的低频震动、空气里的臭氧味。
3. **代价**
   每次出牌写明消耗：寿元、灵能、信用点、关系、把柄、肉身损伤。无代价的胜利一律退稿。
4. **钩子**
   章末或场景末必须给出至少一个未解项：新出场的影、未解释的术语、对手未尽的话、读者已知而主角不知的信息差。
5. **读者预期管理**
   提交章节时附一行说明：本章 **兑现了什么预期**（兑现）+ **种下了什么预期**（拉动）+ **打破了什么预期**（反转）。三者至少命中两项。
