# 素材卡片：哈勃拍摄LH 95星云——白蓝恒星点缀赤红云气

## 元信息

- **来源**: NASA 官方 (science.nasa.gov)
- **日期**: 2026-07-03
- **机构**: NASA / ESA / 弗吉尼亚大学 / ESA-ESTEC / 海德堡大学
- **处理**: Gladys Kober (NASA/天主教美国大学)
- **置信度**: 官方验证

## 核心事实

- **对象**: LH 95，大麦哲伦云（环绕银河系的矮星系）内的恒星形成区
- **组成**: 一个「星协」（stellar association），低质量幼星与高质量蓝巨星共存
- **最亮蓝星**: 质量 ≥ 3 倍太阳质量；发出紫外辐射和恒星风
- **机制**: 紫外辐射 + 恒星风加热并塑造周围氢气的形态
- **结构**: 暗色纤维结构环绕明亮恒星，气体云被雕刻出类似烟花绽放的景观
- **成像**: 哈勃空间望远镜拍摄

## 科学意义

展示年轻恒星系统如何通过辐射与风相互作用，在星际介质中雕刻出复杂的气体结构。LH 95 是大麦哲伦云中众多星协之一，为理解星系演化中恒星形成过程提供样本。
