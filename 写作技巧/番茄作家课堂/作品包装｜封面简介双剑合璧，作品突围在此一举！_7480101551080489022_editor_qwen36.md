# 《科武纪元》编辑学习报告：作品包装规则提炼

## 1 课程核心判断（≤6条）
1. **功能分工明确**：封面负责“视觉拦截”（点击率），简介负责“阅读转化”（留存率），二者必须同频共振。
2. **排版服从受众**：书名长度与字号分级需匹配目标读者习惯（快节奏/脑洞向可长书名，品质/慢节奏宜短书名）。
3. **简介结构铁律**：300字内必须完成“核心梗定调→高能冲突开场→主线/人设亮点→悬念钩子收尾”闭环。
4. **避雷三公式**：文艺病→`人设标签+动词+目标`；流水账→`已知危机×未知变数`；自嗨式→`痛点共情×解决方案`。
5. **题材一致性红线**：封面视觉、简介关键词、正文题材必须严格对齐，错位包装直接导致目标读者流失。
6. **平台硬性节点**：签约后需替换默认封面（≥8万字解锁自定义），尺寸600×800，≤5MB，格式jpg/png/jpeg。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则提取（基于原文） |
|:---|:---|
| **开篇** | 简介首行必须直给核心梗/世界观冲突，禁用环境描写、抒情铺垫或作者自述。 |
| **节奏** | 简介严格控制在300字内；砍掉50%以上形容词，每句仅保留1个核心动作，用“已知危机×未知变数”控制悬念释放密度。 |
| **冲突** | 采用反套路金句、核心对立或灵魂拷问开场；简介结尾必须设置1个未解谜团（身世/阴谋/超自然力量），严禁剧透结局。 |
| **人物** | 禁用抽象性格描述（如“坚韧不拔”），改用“人设标签+动词+目标”具象化（例：基因改造者×撕裂旧秩序）。 |
| **题材** | 封面配色与元素必须与分类强绑定（男频/科幻倾向深冷色调）；封面与简介需满足“元素呼应/情绪同频/信息互补”三公式之一。 |
| **改编** | 原文未涉及IP改编包装逻辑，暂不纳入本阶段规则。 |
| **平台规则** | 新书期用平台模板过渡；满8万字立即上传自定义封面；封面文字层级：书名＞作者名；长书名需通过色彩/字号分级防版面拥挤。 |

## 3 科武适配（《科武纪元》长篇科幻）
### ✅ 可用点
- **深冷视觉锚定**：科幻+武道题材天然契合“深冷/金属/能量光效”封面配色，可直接套用男频冷色调方案。
- **设定降维表达**：300字简介限制倒逼科幻设定“去说明书化”，强制用“已知危机（如：灵能潮汐枯竭）×未知变数（如：古武基因复苏）”替代世界观堆砌。
- **节点运营规划**：利用平台“≥8万字解锁自定义封面”规则，将前8万字设为“世界观试水+核心钩子铺设期”，达标后立刻换装拉升推荐池点击。
- **钩子结构复用**：简介结尾的“开放式提问/高能预告”可直接转化为正文每卷的卷末悬念，维持长线追读。

### ⛔ 不可硬套点
- **长书名策略**：原文“快节奏长书名”不适用于硬核科幻。长篇科武需兼顾史诗感与辨识度，避免过度玩梗导致调性廉价化。
- **小剧场对话**：原文“小剧场式对话”易破坏科幻/科武的严肃氛围。应替换为“高概念场景切片”或“系统/机甲指令日志/武道碑文残句”。
- **情绪同频陷阱**：原文示例偏重言情/悬疑情绪。科武题材需将“情绪”转化为“物理压迫感/战力代差/文明存亡”，避免软性情绪稀释硬核基调。

## 4 编辑检查表（10条以内）
- [ ] 封面书名是否＞作者名？长书名是否做色彩/字号分级防拥挤？
- [ ] 封面尺寸是否为600×800，格式jpg/png，≤5MB？
- [ ] 简介首行是否3秒内点明核心梗/世界观冲突？
- [ ] 简介是否≤300字？形容词是否砍掉50%以上？
- [ ] 是否严格使用“人设标签+动词+目标”结构？
- [ ] 结尾是否设置1个未解谜团/开放式钩子？（零剧透）
- [ ] 封面视觉元素与简介关键词是否同频或互补？（无题材错位）
- [ ] 是否满8万字已替换平台默认封面？
- [ ] 简介是否用“已知危机×未知变数”替代流水账？
- [ ] 整体包装是否精准指向科幻/科武/男频目标读者？

## 5 对作家角色的输入要求
| 维度 | 交付标准（作家需在简介/开篇3章内落实） |
|:---|:---|
| **动作链** | 禁用静态心理描写。必须呈现连续物理动作序列：`触发事件→肢体/装备反应→战术/武技应对→结果反馈`。简介中每句至少绑定1个可视觉化的动作。 |
| **物理反馈** | 科武设定必须具象化。禁用“威力巨大/境界突破”等虚词，改用可量化的物理反馈（例：`拳风撕裂复合装甲/反冲力震裂虎口/能量回路过载冒蓝烟/骨骼密度提升12%`）。 |
| **代价** | 简介钩子必须绑定明确代价。公式：`获取XX力量/突破XX瓶颈 → 支付XX（寿命折损/理智侵蚀/基因崩溃风险/社会性抹杀）`。无代价的升级视为无效包装。 |
| **钩子** | 严格遵循“信息互补”原则。封面埋视觉悬念（如：断裂的机甲臂+古剑残影），简介填逻辑钩子（如：`当武道基因序列覆盖机械义体，人类进化是跃迁还是退化？`）。钩子必须可被正文前3章验证。 |
| **读者预期** | 包装即契约。科幻读者预期“逻辑自洽+硬核设定”，科武读者预期“战力升级+爽感反馈”。简介首行定调后，正文前3章必须交付对应类型的核心体验（首战立威/金手指激活/世界观冲击），严禁“文不对题”导致预期违约。 |
