# 《科武纪元》作家OS补丁  
## 课程：题材选择｜写作之路千千万，选对题材好开篇！

版本：`WriterOS_Patch_TopicChoice_001`  
适用：短故事 / 狼人篇 / 《科武纪元》长篇 / 热点包装稿  
核心目标：**选题材时不飘，开篇时不讲课，章节里必须有冲突、选择、代价、钩子。**

---

## 一、作家OS执行总则

### 1. 题材选择执行令

写作前先回答一句话：

> 我这本/这篇到底卖给读者什么？

必须明确主赛道，不允许“什么都想要”。

#### 可执行判断

| 判断项 | 执行动作 |
|---|---|
| 我熟不熟这个题材？ | 只选自己读过、写起来有直觉画面的题材。 |
| 这个题材有没有明确爽点？ | 开篇3章内必须兑现一次爽点。 |
| 热点元素是否喧宾夺主？ | 重生、系统、狼人、AI、末世等只能服务主线。 |
| 是否能持续写？ | 至少能拆出30个冲突单元，才适合长篇。 |
| 标签是否混乱？ | 主标签最多1个，辅助标签最多1个。 |

## 二、题材定位补丁

### 《科武纪元》默认题材定位

```txt
主赛道：科武升级 / 科幻战斗 / 武道成长
核心卖点：科技规则下的武道突破，硬核战斗中的升级与抉择
辅助元素：AI、基因锁、星际战争、财阀军方博弈
禁止偏移：纯科普、纯权谋、纯校园、纯都市伦理、无代价开挂
```

### 题材契约句

开篇必须让读者感受到：

> 主角身处科技压迫的武道时代，他必须通过危险升级，打破阶层、战争或命运封锁。

## 三、开篇执行补丁

### 开篇禁止项

- 禁止先讲世界观历史。
- 禁止先介绍十个阵营。
- 禁止主角站着想人生超过300字。
- 禁止第一章只有训练、参观、说明。
- 禁止没有危机、没有目标、没有选择。

### 开篇必须完成

3000字内完成以下闭环：

```txt
危机出现 → 主角被迫介入 → 做出选择 → 付出代价 → 阶段目标抛出
```

### 《科武纪元》可用开篇模板

#### 模板A：技术危机型

```txt
触发信号：训练舱异常，初代基因锁失控。
主角决策：不等导师批准，强行接入神经链。
执行动作：以武道气血反向压制基因暴走。
物理反馈：神经灼烧、骨骼震颤、视网膜炸出血线。
局势结果：救下队友，但系统记录他拥有禁忌适配率。
代价：暴露隐藏天赋，被军方和财阀同时盯上。
章末钩子：AI提示——“你的基因序列，不属于本纪元。”
```

#### 模板B：资源争夺型

```txt
触发信号：小队补给只够一人突破。
主角决策：放弃安全分配，赌命抢夺敌方跃迁核心。
执行动作：短时开启过载武脉，冲入重力乱流。
物理反馈：内脏下坠、膝骨开裂、机甲关节发出疲劳尖鸣。
局势结果：夺回核心，小队暂时活命。
代价：主角经脉撕裂，七日内无法再次突破。
章末钩子：核心内藏着失踪父亲的战场坐标。
```

#### 模板C：伦理抉择型

```txt
触发信号：战舰即将坠毁，只能保平民舱或武道火种库。
主角决策：违抗军令，先救平民。
执行动作：切断火种库能源，转接到逃生舱推进器。
物理反馈：舰体失衡，重力反噬压碎护甲，气血逆流。
局势结果：平民获救，火种库数据丢失。
代价：主角被军部定为叛令者。
章末钩子：被毁火种库里，竟封存着主角母亲的意识备份。
```

## 四、动作链补丁

以后写科武战斗、升级、危机时，必须使用动作链。

### 标准动作链

```txt
触发信号 → 战术/武道决策 → 执行动作 → 物理/生理反馈 → 局势结果 → 代价 → 新钩子
```

### 示例

```txt
触发信号：敌方无人机群突破防线。
战术决策：主角放弃远程火控，改用近身武道破阵。
执行动作：他将外骨骼功率推到红区，踏碎甲板冲入机群。
物理反馈：膝关节传来错位声，神经接驳针像烧红的铁线扎进脊髓。
局势结果：无人机阵型被撕开，队友获得撤离窗口。
代价：外骨骼核心过载报废，主角失去下一战的机甲支援。
新钩子：残骸中弹出一段加密讯息——“击杀目标不是你，是你身后的AI。”
```

### 写作提醒

每次主角强行变强，都要问：

> 他拿什么换？

可用代价池：

- 身体损伤：骨裂、经脉撕裂、神经烧灼。
- 资源消耗：药剂、能量核心、机甲部件、积分。
- 信任损失：队友怀疑、导师失望、军方监控。
- 道德污染：牺牲少数、隐瞒真相、使用禁术。
- 阵营后果：被财阀招揽、被军部通缉、被AI绑定。
- 时间压力：突破失败倒计时、感染倒计时、战舰坠毁倒计时。

## 五、冲突补丁

### 冲突必须具体

不要写：

```txt
人类命运危在旦夕。
宇宙即将毁灭。
主角要拯救世界。
```

改成：

```txt
这支小队只有一枚修复针，给主角就能突破，给队友就能活命。
```

或：

```txt
跃迁核心只能启动一次，是送平民离开，还是让军方带走武道火种？
```

### 三类可执行冲突

| 类型 | 写法 | 科武例子 |
|---|---|---|
| 资源冲突 | 不够分，必须抢或舍弃 | 一枚基因药剂，两个人都需要。 |
| 立场冲突 | 都有理由，但方向相反 | 军方要保火种，主角要救平民。 |
| 道德冲突 | 正确选择也有代价 | 杀感染者能保基地，不杀会扩散。 |

## 六、人设剧情化补丁

### 禁止人设说明书

不要写：

```txt
林烬性格坚毅，重情重义，不畏强权。
```

改成动作：

```txt
导师命令他放弃受困队友，林烬却直接拔掉军方监控芯片，转身冲进辐射区。
```

### 人设必须通过选择暴露

| 人设底色 | 对应选择 |
|---|---|
| 重情 | 放弃突破机会，救队友。 |
| 狠辣 | 为赢切掉自己被感染的手。 |
| 不服权威 | 当众违抗军令，但承担后果。 |
| 冷静 | 队友崩溃时，他先锁死舱门再救人。 |
| 有底线 | 不用平民做实验，哪怕会输。 |
| 成长型 | 前期冲动犯错，后期学会计算代价。 |

### 配角也要有自己的算盘

同一事件下至少三方动机：

```txt
主角：想救队友并完成突破。
军方：想保住实验数据。
财阀：想夺走基因锁样本。
AI：想借主角身体验证旧纪元算法。
队友：想活下去，但不想成为累赘。
```

## 七、人物口吻补丁

### 《科武纪元》主角口吻

特点：短句、克制、行动导向，不喜欢解释自己。

示例：

```txt
“给我十秒。”
“你们撤，我断后。”
“命令我听见了，但我不执行。”
“代价我付，结果你们拿走。”
“如果突破要靠牺牲他们，那这条武道，我不要。”
```

### 军方角色口吻

特点：冷硬、命令式、结果优先。

```txt
“战场不需要你的同情。”
“火种库优先级高于三百名平民。”
“你可以恨我，但你必须执行。”
“编号K-17，从现在起，你归军部管控。”
```

### 财阀角色口吻

特点：温和、交易感、把人命当资产。

```txt
“别紧张，我们只是想买下你的未来。”
“你的伤，我们能治。你的敌人，我们能清理。”
“天赋不该浪费在军方的棺材里。”
“价格可以谈，底线也可以谈。”
```

### AI角色口吻

特点：理性、冰冷、偶尔反讽。

```txt
“检测到你正在进行低概率自杀行为。”
“纠正：这不是勇气，是资源浪费。”
“你的痛觉阈值已超过安全线，建议立即昏迷。”
“旧纪元记录显示，你这种人通常死得很快。”
```

### 狼人篇人物口吻可借点

【短故事/狼人篇可借点】

狼人题材适合强化：

- 本能冲动。
- 身份隐瞒。
- 群体排斥。
- 月夜失控。
- 爱与杀的矛盾。

可迁移到科武：

```txt
狼人失控 → 基因锁暴走
族群排斥 → 武道实验体被歧视
月圆变身 → 星核辐射周期触发狂化
狼人血脉秘密 → 旧纪元武脉遗传
猎人与狼人对立 → 军方与禁忌武者对立
```

## 八、段落节奏补丁

### 单章节奏建议

每章尽量按这个比例：

```txt
开头10%：直接接上危机/抛新问题
中段60%：冲突推进、动作链、人物选择
后段20%：结果兑现、付出代价
结尾10%：反转/新目标/新危机
```

### 段落长度控制

| 场景 | 段落写法 |
|---|---|
| 战斗 | 短句、快切、强反馈。 |
| 选择 | 放慢半拍，突出代价。 |
| 设定 | 夹在动作里，不单独讲课。 |
| 反转 | 句子短，信息尖。 |
| 章末 | 留白，卡在新危机出现处。 |

### 战斗段落节奏示例

```txt
警报炸响。

林烬没有回头。

左臂外骨骼弹开，三枚锁扣同时咬入皮肉。神经接驳的瞬间，痛感像烧红的钢针，从腕骨一路钉进肩胛。

“功率百分之一百三十。”

AI的声音冷得没有起伏。

“警告，你的左臂会废。”

林烬踏前一步，脚下甲板凹陷。

“够用就行。”
```

## 九、章末钩子补丁

### 钩子必须和主线目标相关

不允许无关悬念。

弱钩子：

```txt
门外突然传来声音。
```

强钩子：

```txt
门外传来军方审判官的声音：“林烬，你私自开启的不是基因锁，是旧纪元叛军武脉。”
```

### 九连环结构

每章结尾遵守：

```txt
解决一个问题 → 暴露更大的问题
完成一个目标 → 付出新的代价
赢下一场战斗 → 引来更强敌人
得到一个答案 → 发现答案是陷阱
```

### 可直接使用的章末钩子

1. `AI沉默三秒后说：“你的基因序列，和敌方主舰数据库完全一致。”`
2. `军方封锁令下达：林烬不再是学员，而是可回收实验资产。`
3. `跃迁核心启动失败，屏幕上浮现一行旧纪元文字：欢迎回来，第一武神。`
4. `队友醒来后第一句话是：“刚才救我的，不是你。”`
5. `主角突破成功，但检测仪显示，他的寿命少了十年。`
6. `导师拔出枪，对准林烬：“从现在开始，不许相信任何AI，包括你脑子里的那个。”`
7. `财阀代表微笑递来合同：“签下它，你妹妹今晚就能活。”`
8. `战场残骸中，出现了主角早已死亡父亲的战斗记录。`

## 十、短故事 / 狼人篇可借点

【短故事/狼人篇可借点】

### 适合直接借的结构

```txt
单事件 → 强冲突 → 身份秘密 → 情绪爆点 → 反转收尾
```

### 狼人篇可借到科武的元素

| 狼人篇元素 | 科武转化 |
|---|---|
| 月圆失控 | 星核辐射周期导致基因锁暴走 |
| 狼人身份暴露 | 禁忌武脉被检测出来 |
| 猎人追杀 | 军方清除实验体 |
| 族群召唤 | 旧纪元AI唤醒同类 |
| 爱人与怪物冲突 | 队友发现主角可能不是纯人类 |
| 野性本能 | 武脉暴走、战斗欲失控 |

### 短故事执行模板

```txt
开场：主角正在隐藏某种危险身份。
触发：危机迫使他暴露力量。
冲突：救人就会暴露，不救就违背底线。
代价：他救了人，也失去正常身份。
反转：被救的人其实早知道他的秘密。
结尾钩子：更大的猎杀/招募/实验开始。
```

## 十一、《科武纪元》长篇可借点

【科武长篇可借点】

### 卷结构循环

每一卷都按这个模型跑：

```txt
新地图/新规则 → 小目标 → 资源争夺 → 阵营博弈 → 主角突破 → 代价爆发 → 更大真相
```

### 长篇主线建议

```txt
第一阶段：学员/底层武者，发现自身异常。
第二阶段：军方试炼，卷入基因锁与战场资源争夺。
第三阶段：财阀与AI博弈，主角被当作旧纪元钥匙。
第四阶段：星际战争扩大，武道体系真相暴露。
第五阶段：主角决定重写科技与武道的规则。
```

### 长篇每10章检查

必须至少完成：

- 1次明确升级。
- 1次严重代价。
- 1次阵营关系变化。
- 1个旧钩子解答。
- 1个新钩子抛出。
- 1次主角认知变化。
- 1次配角独立行动。

## 十二、平台规则转译：发布 / 包装 / 风险门禁

### 发布门禁

| 项目 | 执行标准 |
|---|---|
| 首章留存 | 第一章必须有危机、选择、代价、目标。 |
| 前3章 | 必须兑现题材承诺：科武战斗/升级/科技奇观至少出现一次。 |
| 前10章 | 主角必须完成一次阶段性胜利，但留下更大麻烦。 |
| 更新节奏 | 每章结尾留钩，下一章开头立即承接，不断层。 |
| 数据差时 | 不先改世界观，先加快冲突密度和章末钩子。 |

### 包装门禁

| 包装项 | 要求 |
|---|---|
| 书名 | 突出科武、纪元、升级、战争、禁忌力量。 |
| 简介 | 一句话讲清主角身份、危机、金手指/核心能力、目标。 |
| 标签 | 主标签：科幻/科武/升级；副标签：AI/星际/热血。 |
| 卖点 | “科技压迫下的武道突破”“禁忌基因锁”“AI与武道融合”。 |
| 开篇承诺 | 不要写“宏大世界观”，要写“他第一次违规突破，付出代价”。 |

### 风险门禁

| 风险 | 处理 |
|---|---|
| 设定太多 | 每章设定不超过3个新名词，且必须绑定动作或冲突。 |
| 开局太慢 | 删除背景，提前危机，把说明移到战斗中。 |
| 标签混乱 | 明确武道升级是主线，科幻是规则与资源池。 |
| 主角无代价 | 每次胜利必须损失身体、资源、信任或关系。 |
| 反派扁平 | 反派也要有利益逻辑，不做纯工具人。 |
| 爽点不足 | 每3章至少一次小兑现：打脸、突破、反杀、拿资源、揭秘密。 |
| 悬念空转 | 每个悬念必须影响主角目标，不能只吊胃口。 |

# 十三、写作前任务卡字段更新

每次开新篇、开新卷、开新章前，填写以下任务卡。

## 写作前任务卡

```txt
【作品/篇章名称】：
【本章序号】：
【主赛道】：
【辅助标签】：

【本章核心事件】：
一句话写清：谁为了什么，在什么压力下，和谁发生冲突。

【本章阅读承诺】：
本章给读者什么？
□ 战斗爽点
□ 升级突破
□ 科技奇观
□ 阵营博弈
□ 身份秘密
□ 情绪爆点
□ 反转信息

【开场触发信号】：
警报/追杀/检测异常/资源不足/命令冲突/身份暴露等。

【主角阶段目标】：
本章主角想达成什么具体结果？

【阻碍力量】：
敌人/军方/财阀/AI/队友分歧/身体副作用/时间倒计时。

【冲突类型】：
□ 资源冲突
□ 立场冲突
□ 道德冲突
□ 身份冲突
□ 时间冲突

【主角关键选择】：
主角在极端情境下选择什么？这个选择暴露什么性格？

【设定投放】：

【本章结尾钩子】：
```

# 十四、章节自检清单

写完一章后逐条检查。

## 基础门槛

- [ ] 本章开头是否直接承接危机或抛出新问题？
- [ ] 本章是否有明确核心事件？
- [ ] 主角是否有具体目标，而不是被动看戏？
- [ ] 3000字内是否完成至少一次冲突推进？
- [ ] 是否避免大段背景说明和纯设定科普？

## 动作与反馈

- [ ] 关键行动是否有完整动作链？
- [ ] 科技/武道交互是否有物理反馈？
- [ ] 战斗是否不仅是招式堆叠，而是改变了局势？
- [ ] 主角是否付出明确代价？
- [ ] 代价是否会影响后续剧情？

## 人物与冲突

- [ ] 主角性格是否通过选择表现？
- [ ] 配角是否有自己的利益诉求？
- [ ] 反派是否有合理动机？
- [ ] 冲突是否具体可感？
- [ ] 是否存在资源、立场、道德中的至少一种冲突？

## 节奏与爽点

- [ ] 本章是否推进主线或升级冲突？
- [ ] 是否删除无效打斗、无效走路、无效寒暄？
- [ ] 是否至少兑现一个阅读承诺？
- [ ] 是否保持科武题材感：科技压迫、武道突破、硬核反馈？
- [ ] 是否没有让热点元素抢走主线？

## 章末钩子

- [ ] 章末是否有新危机、新信息或目标升级？
- [ ] 钩子是否与主线目标相关？
- [ ] 是否做到“解旧钩，出新钩”？
- [ ] 下一章是否有明确承接点？
- [ ] 读者是否会知道“下一章必须看什么”？
