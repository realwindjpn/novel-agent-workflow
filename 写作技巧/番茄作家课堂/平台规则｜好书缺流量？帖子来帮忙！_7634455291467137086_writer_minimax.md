# 《科武纪元》作家OS执行补丁 v1.0

## 一、核心执行逻辑（新手必读）

```
帖子 ≠ 正文附属品
帖子 = 流量调度器
正文 = 逻辑自洽 + 视觉锚点 + 代价明确
帖子 = 放大讨论半径 + 管理读者预期
```

**失效模式**：用情绪替代设定，用空泛文案替代硬核锚点。

## 二、写作前任务卡字段更新

每章定稿前必须填完以下字段，对应帖子运营排期：

### 【必填·动作链】
| 字段 | 填写标准 | 用途 |
|:---|:---|:---|
| 核心动作序列 | 用箭头拆解到≥3步（如：`锁定→跃迁→打击→反冲灼痕`） | 提供截图素材 + 二创锚点 |
| 视觉锚点 | 每章至少1个具象化场景描写（机甲结构/星图逻辑/能量场视觉） | 触发段评激增 |
| 异常读数 | 描述1个设备/环境的具体参数偏差（例：`重力读数+0.003G，舱壁应力超标12%`） | 直接用作帖子悬念钩子 |

### 【必填·物理反馈】
| 字段 | 填写标准 | 禁用 |
|:---|:---|:---|
| 能力释放反馈 | 量化物理量（形变率/灼痕面积/真空爆震半径）而非“好强/好虐” | 抽象形容词 |
| 环境交互描写 | 写明物理法则自洽性（能量守恒/动量守恒/热力学限制） | 超纲设定 |

### 【必填·代价系统】
| 字段 | 填写标准 | 效果 |
|:---|:---|:---|
| 能力代价 | 明确量化（例：`灵能回路过载0.7秒，造成神经滞后2.3秒`） | 制造“站队押注”讨论空间 |
| 阵营代价 | 资源损耗/信任损耗/道德底线/系统冷却任选其一 | 驱动辩论型帖子 |
| 伏笔代价 | 本章埋入的线索需在下章或后续产生连锁损耗 | 章末钩子 |

### 【必填·钩子设计】
| 字段 | 填写标准 | 错误示范 |
|:---|:---|:---|
| 未解变量 | 章末留1个强关联变量（参数异常/神秘信号/角色反常） | 无关痛痒的日常描写 |
| 下章预告 | 明确指向下一章核心剧情，不剧透核心机制 | 剧透式泄露 |
| 情绪方向 | 作者说声明本章属性（例：`下章重装接战，非感情线`） | 题材错位导致差评 |

### 【选填·读者预期管理】
| 字段 | 填写标准 | 时机 |
|:---|:---|:---|
| 预警声明 | 高光/硬核/平淡章提前1-2章在作者说/帖子中预告 | 高冲突章前1-2章 |
| 节点转化 | “生日/纪念日”→星历节点/战役周年/舰队成立日 | 开书/完结/周年 |

## 三、章节自检清单（完稿后逐项打勾）

### 基础层（不过审风险）
- [ ] **无核心机制剧透**：伏笔仅做方向引导，不泄露关键反转
- [ ] **物理自洽**：能力释放/环境交互符合已建立法则，无超纲设定
- [ ] **代价明确**：每次能力使用/阵营选择有明确损耗，无“白嫖爽点”
- [ ] **冲突有代价**：战斗结果有资源/人员/后续代价，不是一战全清

### 钩子层（追更粘性）
- [ ] **章末钩子**：留1个未解变量，与下章强关联
- [ ] **视觉锚点**：本章有≥1个可截图传播的具象化场景
- [ ] **动作拆解**：核心战斗/探索有≥3步可拆解的动作序列
- [ ] **异常读数**：章内出现≥1个具体参数偏差，可用于帖子悬念

### 互动层（流量转化）
- [ ] **作者说预埋**：声明本章属性（硬核/平淡/高光），管理读者预期
- [ ] **冲突前后**：冲突爆发前有“押注/站队”空间，冲突后24h内跟进复盘
- [ ] **关系推进**：CP/阵营线推进前有情绪预埋，推进后开放二创征集

### 包装层（平台加权）
- [ ] **书卡完整**：发布时附带书卡
- [ ] **话题精准**：挂载≥1个精准品类标签（`#科幻#星际战争`）
- [ ] **正文字数**：正文>10字
- [ ] **封面适配**：AI封面或定制图，无机甲结构/星图逻辑硬伤（科幻调性）

## 四、发帖时机矩阵（可直接对照执行）

| 章节类型 | 发帖时机 | 帖子类型 | 文案要点 |
|:---|:---|:---|:---|
| **平淡/过渡章** | 前1-2章 | 伏笔预告帖 | 提示后文关联点，悬念对冲疲劳 |
| **高光/名场面章** | 前1-2章 | 预警帖 | 拉高期待阈值（例：`轨道参数异常预警`） |
| **冲突爆发章** | 冲突前 | 押注/站队帖 | `宿敌PK，你觉得谁能赢？` |
| **冲突结束章** | 结束后24h内 | Reaction复盘帖 | 情绪释放+截图传播 |
| **伏笔揭露章** | 揭露前1章 | 预言家帖 | `之前埋的暗线要回收了` |
| **设定揭露章** | 揭露前 | 考据帖 | 武力体系/科技树解析 |
| **开书/完结** | 节点日 | 仪式感帖 | 节点转化（星历纪念日/战役周年） |

## 五、失败模式速查（踩坑即死）

| 类型 | 错误操作 | 后果 | 修正方案 |
|:---|:---|:---|:---|
| **剧情泄露** | 帖子提前剧透核心反转 | 读者流失，丧失悬念价值 | 仅做情绪/方向引导，禁止机制描述 |
| **包装失败** | 纯简介文案，无互动钩子 | 帖子石沉大海，无流量 | 必须包含站队/预测/征集元素 |
| **视觉违和** | AI封面出现机甲结构错误/星图逻辑漏洞 | 核心受众流失，口碑崩塌 | 科幻类AI封面必须人工校对 |
| **节奏错位** | 高冲突章不预告，平淡章无钩子 | 读者预期错位，差评激增 | 严格对照“发帖时机矩阵” |
| **成本失衡** | 能力使用无代价，导致战力崩盘 | 读者失去讨论兴趣（无法押注） | 每章必填“代价系统”字段 |
| **互动断链** | 读者发帖无作者翻牌 | 互动数据下滑，平台降权 | 每周≥1次亲自发帖+翻牌高赞评论 |
| **标签失准** | 话题词挂错/缺失 | 搜索推荐失效，曝光断崖 | 每帖必挂精准品类标签（`#科幻#`） |
| **长篇自嗨** | 硬核设定无情绪锚点，普通读者看不懂 | 讨论半径收窄，仅核心粉自嗨 | 设定解析必须附“读者可参与的问题” |

## 六、科武长篇专供（仅适用于长篇科幻）

### ✅ 可直接借用
| 场景 | 借用方式 | 示例 |
|:---|:---|:---|
| **武力体系解析** | 帖子：战力推演/设定考据 | `基因锁开启阈值从0.7提升到0.85，意味着什么？` |
| **战役名场面** | 帖子：预警+复盘 | 星际跃迁前发布`重瞳级跃迁预警`，后发布`跃迁事故复盘` |
| **暗线伏笔** | 帖子：预言家翻牌 | `你们还记得第三章的异常信号吗？下一章要回收了` |
| **阵营理念冲突** | 帖子：辩论押注 | `激进派 vs 稳健派，你觉得这条路线能走通吗？` |
| **星历节点** | 帖子：仪式感运营 | `舰队成立十周年庆典，各阵营暗流涌动` |
| **科技树推演** | 帖子：二创考据 | `如果把灵能回路功率提升30%，会产生哪些连锁反应？` |

### ❌ 禁止硬套
| 原模板 | 禁用原因 | 替代方案 |
|:---|:---|:---|
| 强CP/修罗场 | 科幻读者重逻辑，情感拉扯需有物理/战术代价支撑 | 用“阵营路线分歧/战术方案冲突”替代 |
| 纯情绪鼓动文案（好虐/好甜） | 科幻受众不吃这套 | 用“物理规则推演/战术代价分析”替代 |
| 剧透式预告 | 悬疑伏笔直接泄露核心机制 | 仅做方向引导（`下一章轨道参数异常，后面有大用`） |

## 七、平台规则→发布/包装/风险门禁

### 【门禁一·发布前必过】
| 检查项 | 标准 | 违规后果 |
|:---|:---|:---|
| 书卡 | 必须附带 | 曝光降权 |
| 精准话题词 | ≥1个品类标签 | 搜索推荐失效 |
| 正文字数 | >10字 | 曝光降权 |
| 封面 | AI生成需等10秒，或定制 | 违规下架 |

### 【门禁二·内容合规】
| 检查项 | 标准 | 违规后果 |
|:---|:---|:---|
| 剧透红线 | 核心机制/关键反转不得提前泄露 | 读者流失+平台降权 |
| 物理自洽 | 能力设定需符合已建立法则 | 口碑崩塌，核心受众流失 |
| 代价底线 | 能力使用必须有损耗 | 战力崩盘，讨论空间消失 |

### 【门禁三·运营加分项】
| 操作 | 效果 |
|:---|:---|
| 作者亲自发帖 | 平台额外曝光倾斜 |
| 翻牌读者评论 | 拉升追更粘性+发帖意愿 |
| 24h内跟进复盘帖 | 数据正循环 |
| 每周≥1次发帖 | 维持社区权重 |
