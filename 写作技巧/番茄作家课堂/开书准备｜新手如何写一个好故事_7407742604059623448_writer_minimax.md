# 一、写作前任务卡字段更新

每次开新章节前，必须填充以下字段。未完成的字段视为任务卡未解锁，禁止动笔。

## 【任务卡001：章节基础信息】

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| 章节编号 | 按卷-章顺序（例：卷二-第三章） | 卷一-第十二章 |
| 字数目标 | 日更4000字=2个2000字情节单元 | 4000字 |
| 情节点A | 本章第1个核心事件，必须有冲突结果 | 主角被迫接受血脉觉醒仪式 |
| 情节点B | 本章第2个核心事件，必须与A有因果或反转关联 | 觉醒后发现自己成为追杀目标 |
| 章末钩子类型 | 从4选1：信息差/危机逼近/身份反转/规则异变 | 身份反转 |

## 【任务卡002：预期爽点管理】

| 字段 | 填写要求 |
|:---|:---|
| 本章预期爽点 | 用一句话描述读者将在本章获得什么满足感 |
| 预期落空设计 | 本章哪个预期会被打破或延迟？ |
| 反转触发机制 | 预期落空后，读者情绪如何被重新锚定？ |
| 爽点回收章节 | 该爽点在第几章正式兑现？（必须在前文埋设伏笔） |

**示例**：
```
预期爽点：主角击败宿敌，血债血偿
预期落空：宿敌临死前揭露主角身份真相
反转触发：主角杀的不是仇人，是救命恩人的儿子
爽点回收章节：第三十五章
```

## 【任务卡003：代价系统】

| 字段 | 填写要求 |
|:---|:---|
| 本章主角付出代价 | 必须在情节中出现具体代价（禁止零成本破局） |
| 代价类型 | 从中选择：寿命折损/资源枯竭/阵营信任破裂/肉体异化/算力透支/情感债务/情报泄露 |
| 代价副作用 | 该代价将在未来哪3章内引发连锁反应？ |
| 代价叙事权重 | 该代价占本章情节推进的百分比（需≥30%） |

**硬性规则**：每章必须有至少一个明确代价。若主角未付出代价，则敌人必须付出同等代价；若无代价，则该情节需删除。

## 【任务卡004：人设校验】

| 字段 | 填写要求 |
|:---|:---|
| 本章主角缺陷触发点 | 角色致命缺陷在哪个场景中被暴露或激化？ |
| 缺陷导致的选择偏差 | 主角因缺陷做出了什么"合理但不合常理"的决策？ |
| 配角困境线 | 本章哪个非主角角色也有自己的独立困境？（禁止纯工具人） |
| 配角困境结果 | 配角困境如何影响主线？（推进/阻碍/揭示新线索） |

## 【任务卡005：物理反馈层（科武专用）】

⌘ **强制填写**

| 字段 | 填写要求 |
|:---|:---|
| 本章核心动作的物理轨迹 | 攻击/防御/移动的能量消耗路径？空间位移多少？ |
| 五感细节 | 该动作产生的声音/气味/触感/视觉变化？ |
| 力学/能量守恒表现 | 该动作后，世界规则发生了什么变化？ |
| 信息差来源 | 读者知道什么？角色知道什么？差距在哪？ |

# 二、可执行动作集

## 2.1 开篇执行序列（首章专用）

**触发条件**：当你准备写一本新书的开头时，按以下顺序执行。

```
Step 1 ⌘：找到"第一滴血"
→ 原则：首章第一个句子必须出现具体冲突或危机
→ 操作：在稿纸上写："因为____，主角正处于____的危险中"
→ 禁止：描述天气、介绍背景、发表感慨、介绍设定

Step 2 ⌘：锁定"认知锚点"
→ 原则：300字内建立主角核心诉求+最大阻碍
→ 操作：让读者知道主角想要什么，以及什么在阻止他
→ 检验：能否用一句话概括"谁要什么，为什么难"？

Step 3 ⌘：切断"说明书模式"
→ 原则：背景设定通过动作/对话/物品侧写，禁止直接说明
→ 操作：检查本章是否出现超过200字的纯设定段落
→ 修正：设定说明必须嵌入角色行动或对话中

Step 4 ⌘：埋设"章末钩子"
→ 原则：章节最后一句必须制造信息差或危机
→ 操作：在写完情节后，追加一句让读者"想知道后面发生什么"
→ 禁止：为断章而断章，钩子必须与主线强绑定
```

### ☆ 科武长篇开篇特供

```
Step 5 ☆：技术约束展示
→ 原则：前3章内必须展示科武世界的核心物理/能量规则
→ 操作：让主角的行动受限于某种技术约束，而非随意突破
→ 示例：机甲能量有限、意识同步有延迟、基因觉醒需冷却期

Step 6 ☆：阵营格局暗示
→ 原则：开篇需暗示至少有2个以上阵营存在，且利益冲突
→ 操作：让主角行动影响或被卷入阵营博弈
```

### ★ 短篇/狼人篇开篇特供

```
Step 5 ★：单场景极致化
→ 原则：开篇聚焦单一核心冲突，无支线干扰
→ 操作：所有背景板信息必须在第一个场景内完成
→ 时间控制：前500字必须完成冲突建立与目标锁定

Step 6 ★：情绪钩优先
→ 原则：短篇读者更在意"情绪冲击"而非"世界观完整"
→ 操作：开篇第一个句子直击情绪痛点
```

## 2.2 节奏控制执行序列

**触发条件**：当你写日常情节、过渡段落、或者感觉节奏平淡时执行。

### 【弹簧节奏模型】

```
⓪ 压抑阶段
→ 操作：让主角陷入困境，读者感受到"压力"
→ 时长：章节前30%
→ 失败模式：压抑太久变成水文，压抑太短没有张力

① 破局阶段
→ 操作：主角找到突破口，读者感受到"希望"
→ 触发：必须在压抑阶段埋设的"线索/工具/人脉"在此刻出现
→ 失败模式：无铺垫的破局=开挂；破局后无新阻碍=烂尾

② 新危机/反转阶段
→ 操作：破局后立即出现更大阻碍或意外反转
→ 触发：最晚在破局后第3章内必须出现
→ 失败模式：破局后连续3章无新危机=读者流失

⓫ 循环
→ 操作：重复⓪→①→②直到本章情节单元结束
```

### 【双情节单元控制】

```
日更4000字 = 2个2000字情节单元

单元1结构：
  节点头（200字）：上一章钩子回应 + 本章新危机
  情节中（1200字）：主角应对 + 代价付出
  单元尾（600字）：悬念断点/视角切换

单元2结构：
  节点头（200字）：承接单元1断点
  情节中（1400字）：新冲突建立 + 配角困境介入
  单元尾（400字）：章末钩子（与单元1钩子类型不同）
```

### 【视角切换规则】

```
断点类型A：坠崖不写生死
→ 操作：主角危机时刻，切换到另一角色视角
→ 效果：制造信息差，读者不知道主角生死

断点类型B：目击后切凶手
→ 操作：配角目睹关键事件，立即切换到凶手视角
→ 效果：读者知道凶手身份，但不知道凶手下一步

断点类型C：悬念卡点
→ 操作：在关键信息揭露前切换视角
→ 效果：读者急于知道真相，但被迫等待下一章
```

## 2.3 冲突构建执行序列

**触发条件**：当你设计新情节、规划反派行为、设计关键抉择时执行。

### 【核心冲突绑定检查】

```
冲突必须源于人物关系网络，而非单纯外部灾难

检查清单：
□ 冲突是否涉及至少2个角色？
□ 角色之间是否有利益/血缘/阵营/旧怨关系？
□ 冲突是否会导致角色关系发生变化？
□ 是否有"隐藏信息"导致双方决策产生偏差？

禁止：
✗ 主角VS地震/洪水/系统任务（无人物关系）
✗ 反派只是"因为邪恶所以作恶"
✗ 冲突可以被单方面力量碾压解决
```

### 【"合理但不合常理"抉择设计】

```
典型选项（按强度排列）：

选项A：见死不救
→ 主角有救人能力，但救人会导致自己目标失败
→ 读者反应：理解但不安

选项B：反向利用
→ 主角借力打力，利用敌人或盟友的弱点达成目的
→ 读者反应：惊叹但警惕主角的人格

选项C：出卖盟友
→ 主角用盟友换取关键优势
→ 读者反应：冲击但可能理解

选项D：自毁式破局
→ 主角用放弃核心诉求的方式解决危机
→ 读者反应：震撼但可能反感

禁止：
✗ 主角选择"正确答案"而无任何代价
✗ 抉择后无需承担后果
✗ 反派做出"不合常理"选择而无动机解释
```

### 【局中局设计】

```
前置伏笔标注：
→ 在反转发生前至少3章埋设"反常细节"
→ 反常细节必须可以用多种解释，但真相只有一个
→ 反转时必须回溯前文伏笔，让读者恍然大悟

检验标准：
→ 把反转章节给未参与写作的人读
→ 问："你之前有没有觉得哪里不对劲？"
→ 有→合格；无→伏笔埋设不足

禁止：
✗ 没有任何伏笔的机械降神式反转
✗ 反转后故事逻辑无法自洽
✗ 反转是为了反转而反转
```

## 2.4 人物构建执行序列

**触发条件**：当你创建新角色、设计角色行动、检验人设时执行。

### 【人设表必填字段】

| 字段 | 填写要求 | 作用 |
|:---|:---|:---|
| 身份 | 角色在故事中的社会/职业/阵营定位 | 建立行为边界 |
| 欲望 | 角色最想要的东西（可量化/可感知） | 驱动行动 |
| 恐惧 | 角色最害怕失去/遭遇的东西 | 制造弱点 |
| 致命缺陷 | 性格/能力/背景中的致命弱点 | 推动剧情 |
| 行为反差 | 角色在不同处境下的行为矛盾 | 制造深度 |

**示例**：
```
角色：林深
身份：科武学院三年级生/实验体017号
欲望：活着离开学院
恐惧：失去最后的人性记忆
致命缺陷：对"被需要"有病态依赖
行为反差：
  → 平时沉默寡言，关键时刻会为陌生人拼命
  → 对敌人冷酷，对实验体同伴却有强烈保护欲
```

### 【目标演变校验】

```
静态目标→动态目标检验：
→ 开篇目标是否在故事中期被证明"不够"或"错误"？
→ 主角是否因为新信息/新经历而修正目标？
→ 修正后的目标是否与初始目标有逻辑关联？

典型演变路径：
"活着" → "活得有尊严" → "让所有人活得有尊严"
"复仇" → "复仇后发现真相" → "选择原谅或彻底毁灭"
"求死" → "求生" → "为他人而死"（悲剧闭环）
```

### 【配角独立性校验】

```
每章必须出现的非主角角色：
→ 有自己的困境（独立于主角主线）
→ 有自己的行动线（不为推动主角而行动）
→ 有自己的结局（不能只被主角影响）

检验方式：
→ 移除主角，该配角的困境是否仍然成立？
→ "是"→合格配角；"否"→工具人，需重写
```

# 三、失败模式与代价标注

## 3.1 常见失败模式清单

### 【开篇失败模式】

| 失败模式 | 症状 | 修正方案 |
|:---|:---|:---|
| 说明书式开篇 | 大段世界观/设定说明，300字内无冲突 | 立即切入具体事件，设定融入行动 |
| 背景板主角 | 主角没有具体行动，只是"在场" | 给主角一个立即需要解决的问题 |
| 预期不明 | 读者不知道主角想要什么、为什么重要 | 前300字建立"谁要什么，为什么难" |
| 无危机感 | 章节太平，读者感受不到压力 | 检查是否每个场景都有冲突；增加阻碍强度 |

### 【节奏失败模式】

| 失败模式 | 症状 | 修正方案 |
|:---|:---|:---|
| 压抑过度 | 连续5章主角没有胜利，读者疲劳 | 增加小胜利/盟友支持/喘息空间 |
| 破局无伏笔 | 主角突然解决问题，读者质疑 | 在破局前3章埋设线索，让胜利"合理" |
| 爽点一次性释放 | 开篇高潮后持续平淡 | 把大高潮拆分为3-5个小高潮，保持期待 |
| 平铺无起伏 | 章节从头平到尾 | 检查每个场景是否都有冲突；加入新阻碍或反转 |

### 【人物失败模式】

| 失败模式 | 症状 | 修正方案 |
|:---|:---|:---|
| 完美角色 | 角色无缺陷、无弱点、无选择困难 | 强制添加一个致命缺陷；设计角色必须做抉择的场景 |
| 工具人配角 | 配角只为主角服务，无独立行动 | 给配角自己的困境和目标 |
| 角色崩人设 | 角色行为与已有设定矛盾 | 检查是否因剧情需要而牺牲人设；改写情节而非妥协人设 |
| 动机不明 | 角色行动无法解释 | 给角色一个可量化的欲望/恐惧 |

### 【科武设定失败模式】

| 失败模式 | 症状 | 修正方案 |
|:---|:---|:---|
| 设定吃书 | 前后设定矛盾，规则被临时修改 | 在细纲中标注核心设定；避免为情节牺牲逻辑 |
| 无代价升级 | 主角突破无消耗，越级战斗无解释 | 每一次突破必须有明确代价；战力提升需有上限 |
| 机械降神 | 问题被"新技术/新能力"一次性解决 | 技术/能力必须有局限性；在解决问题前先制造问题 |
| 物理/能量不守恒 | 战斗效果违反自己设定的规则 | 标注能量消耗路径；战斗后标注环境变化 |

### 【冲突失败模式】

| 失败模式 | 症状 | 修正方案 |
|:---|:---|:---|
| 无人物关系的冲突 | 冲突只是"VS天灾/VS任务" | 将冲突绑定到人物关系上（谁的利益被影响？） |
| 反派无动机 | 反派只是"因为邪恶" | 给反派一个合理的动机（即使与主角对立也合理） |
| 零成本破局 | 主角解决问题没有任何代价 | 每一次破局必须付出代价（资源/关系/身体/时间） |
| 局中局无伏笔 | 反转没有前置线索，读者觉得被骗 | 在反转前3章埋设"反常细节"；检验方式：让未参与写作的人读 |

## 3.2 代价系统标注（科武专项）

每章主角破局/升级时，必须标注以下代价类型之一：

| 代价类型 | 科武语境表现 | 副作用设计 |
|:---|:---|:---|
| 寿命折损 | 基因觉醒加速衰老/能量抽取生命力 | 在未来章节中体现健康恶化/早逝风险 |
| 资源枯竭 | 能量块消耗/稀有材料使用/资金耗尽 | 影响后续战斗/升级能力 |
| 阵营信任破裂 | 行动被误解/盟友背弃/被标记为叛徒 | 在关键时刻孤立无援 |
| 肉体异化 | 觉醒导致身体部分机械化/变异 | 影响人际关系/触发歧视/能力失控 |
| 算力透支 | 意识接入消耗精神力/AI辅助有后遗症 | 在关键时刻思维卡顿/出现幻觉 |
| 情感债务 | 为救人付出代价/背叛盟友/牺牲关系 | 关系线断裂后影响情节发展 |
| 情报泄露 | 行动暴露敌人知道主角计划 | 在关键时刻被针对性反击 |

# 四、章节自检清单

每次完成章节初稿后，按以下清单逐项检查。标记❌的项需要修改后才能进入下一章。

## 【章节基础校验】

- [ ] **冲突密度**：本章前300字是否出现具体冲突/危机？
- [ ] **认知锚点**：读者是否知道主角想要什么、阻碍是什么？
- [ ] **设定植入**：是否通过动作/对话/物品侧写设定？有无超过200字的纯设定段落？
- [ ] **章末钩子**：最后一页/段是否制造了信息差或危机？
- [ ] **钩子有效性**：该钩子是否与主线强绑定？还是为断而断？

## 【节奏校验】

- [ ] **双情节单元**：4000字章节是否包含2个≥1500字的情节节点？
- [ ] **弹簧节奏**：是否遵循"压抑→破局→新危机/反转"的节奏模型？
- [ ] **爽点管理**：本章爽点释放后，是否在3章内设置了新阻碍？
- [ ] **预期落空**：是否有设计读者预期被打破或延迟的场景？
- [ ] **视角切换**：单元结尾是否设置了悬念断点或视角切换？

## 【人物校验】

- [ ] **主角缺陷触发**：角色致命缺陷是否在本章被暴露或激化？
- [ ] **抉择设计**：主角是否做出了"合理但不合常理"的决策？
- [ ] **配角困境**：是否有非主角角色展示了自己的独立困境？
- [ ] **目标演变**：主角目标是否在本章有合理变化或深化？
- [ ] **关系变化**：核心人物关系是否在本章发生可感知的变化？

## 【代价校验】

- [ ] **代价出现**：本章主角是否付出了明确代价？
- [ ] **代价类型**：代价是否属于8种代价类型之一？
- [ ] **代价权重**：代价是否占本章情节推进的≥30%？
- [ ] **代价副作用**：该代价是否会影响未来3章的情节？
- [ ] **零成本检验**：是否有"无代价破局"的场景？（如有，删除或修改）

## 【科武专项校验】☆

- [ ] **物理轨迹**：核心动作是否有明确的能量消耗路径/空间位移？
- [ ] **五感细节**：是否有关于声音/气味/触感/视觉的具体描写？
- [ ] **物理守恒**：动作后世界规则是否发生变化？是否符合逻辑？
- [ ] **信息差**：读者知道的 vs 角色知道的，差距是否明确标注？
- [ ] **设定一致性**：本章是否与之前设定的物理/能量规则一致？

## 【平台规则校验】

- [ ] **黄金三章**：首3章是否完成了"钩子+期待值建立"？
- [ ] **次更衔接**：本章结尾是否提供了足够衔接次日内容的悬念？
- [ ] **价值观底线**：爽点是否符合"被迫反击/身不由己"的主流价值观？
- [ ] **字数控制**：单章是否控制在3500-4500字？（平台推荐区间）

## 【无效内容校验】

- [ ] **过渡段清理**：是否有超过300字的无冲突过渡段落？
- [ ] **工具人台词**：配角是否有"只为主角服务"的无效台词？
- [ ] **信息注入**：设定说明是否强行插入而非自然带出？
- [ ] **情绪断点**：读者情绪是否在某个段落被无故中断？

# 五、平台规则转化

编辑稿中的平台规则需转化为作者可执行的发布/包装/风险门禁。

## 5.1 发布规则门禁

| 平台规则 | 作者执行口径 | 风险等级 |
|:---|:---|:---|
| **黄金三章定留存** | 首3章必须完成：①钩子（悬念/冲突）②期待值建立（主角目标+阻碍）③主角魅力展示（能力/性格/独特性） | 🔴 高 |
| **日更要求** | 每日更新需在00:00-02:00之间发布；需配次日细纲避免断更 | 🟡 中 |
| **断更惩罚** | 断更超过3天，推荐位掉光；卡文时必须提前发请假条 | 🟡 中 |
| **30万字完本线** | 首本需完整走完30万字以验证大纲承载力；提前完本会影响后续推荐 | 🔴 高 |
| **数据反馈** | 前10万字追读率/留存率决定后续资源倾斜；需关注后台数据 | 🟡 中 |

## 5.2 包装规则门禁

| 包装要素 | 执行口径 | 影响 |
|:---|:---|:---|
| **书名** | 前5秒抓住读者；避免过于文艺/抽象；科武类可用"关键词+冲突"结构 | 点击率 |
| **简介** | 必须包含：主角+目标+阻碍+悬念；避免剧情剧透 | 转化率 |
| **封面** | 风格匹配平台调性；科武类需突出"科幻/战斗/异世"元素 | 点击率 |
| **章节标题** | 可用悬念式/事件式/情绪式；避免过于平淡 | 追读率 |
| **标签** | 选择2-3个精准标签；避免过于小众或过于大众 | 推荐精准度 |

## 5.3 内容风险门禁

| 风险类型 | 管控口径 | 违规后果 |
|:---|:---|:---|
| **价值观红线** | 主角行为需有"被迫/无奈/被动反击"的前提；禁止主动作恶 | 屏蔽/下架 |
| **色情擦边** | 亲密描写不超过脖子以下；避免过多身体细节 | 限流/警告 |
| **政治敏感** | 避免涉及现实政治/宗教/领土争议 | 屏蔽/封号 |
| **抄袭/融梗** | 核心情节需原创；可借鉴设定框架但需差异化 | 下架/追责 |

# 六、借点标注

## 6.1 ★ 短篇/狼人篇可借点

以下规则适用于短篇故事或狼人篇等单线叙事、聚焦情绪冲击的内容：

| 模块 | 可借点 | 说明 |
|:---|:---|:---|
| **开篇** | ★情绪钩优先 | 短篇读者更在意"情绪冲击"而非"世界观完整"；首句直击情绪痛点 |
| **节奏** | ★单场景极致化 | 聚焦单一核心冲突，无支线干扰；前500字必须完成冲突建立与目标锁定 |
| **节奏** | ★三幕结构简化 | 背景→冲突→结局，可压缩至单章完成 |
| **冲突** | ★情绪对立取代利益对立 | 用情感纠葛（背叛/误会/牺牲）替代利益冲突 |
| **人物** | ★高光时刻集中 | 不需要完整人设表，但需要在关键场景中展示角色的极致选择 |
| **代价** | ★情感代价优先 | 角色付出的是情感代价（失去爱人/背叛信任/放弃理想），而非物理代价 |
| **钩子** | ★情绪悬念 | 用"角色的选择是什么？"替代"谁会死？"的悬念 |
| **节奏** | ★结局反转收束 | 短篇结尾需要有反转或情感升华；避免平淡收尾 |

**狼人篇特别提示**：
```
狼人篇本质是"情绪+冲突"的快节奏叙事
借点优先级：
1. 人设反差（表面身份vs真实身份）
2. 强制抉择（必须在两个都重要的东西中选择）
3. 高频反转（每500字制造一个情绪波动点）
4. 情感代价（主角为某件事放弃了什么？）
5. 章末钩子（每章结尾制造"我需要知道"的冲动）
```

## 6.2 ☆ 科武长篇可借点

以下规则适用于《科武纪元》等多线叙事、设定复杂、需要长期铺陈的长篇内容：

| 模块 | 可借点 | 说明 |
|:---|:---|:---|
| **开篇** | ☆技术约束展示 | 前3章内展示科武世界核心物理/能量规则；主角行动受限而非随意突破 |
| **开篇** | ☆阵营格局暗示 | 开篇暗示≥2个阵营存在且利益冲突；主角行动影响或被卷入阵营博弈 |
| **设定** | ☆力量体系表 | 提前完成《力量体系表》并标注每个境界的限制/代价/进阶条件 |
| **设定** | ☆科技树解锁节奏 | 每个科技突破必须有前置条件（资源/研究/代价）；不能随意跳跃 |
| **节奏** | ☆文戏/战斗/解密交替 | 避免连续战斗造成疲劳；通过文戏揭示信息、通过解密推动情节 |
| **节奏** | ☆支线收束能力测试 | 在30万字节点测试：支线是否收束？伏笔是否回收？阵营格局是否清晰？ |
| **冲突** | ☆局中局多层嵌套 | AI推演/意识潜入/多维时空嵌套中设计层层反转；每层反转需有伏笔 |
| **人物** | ☆动态目标网 | 科技线（探索真相）+武道线（突破境界）+阵营线（争夺资源）三线交织 |
| **代价** | ☆代价连锁反应 | 代价需在后续章节引发连锁反应；资源枯竭影响武道线，阵营背叛影响科技线 |
| **设定** | ☆世界观自洽验证 | 每10万字检查一次：设定是否吃书？规则是否被破坏？物理是否守恒？ |

**科武长篇特别提示**：
```
30万字=控盘验证线
验证内容：
1. 大纲承载力：初始设定是否能支撑30万字剧情？
2. 支线收束：支线是否在30万字内完成收束？未收束的支线是否影响主线？
3. 节奏稳定性：是否存在前期快后期拖？是否存在中期疲劳点？
4. 设定自洽度：核心规则是否被破坏？是否有机械降神？
5. 人物演变：主角目标是否从"求活"升级到更高的追求？

细纲防跑偏：
科武长篇多线叙事（科技线/武道线/阵营线），必须通过细纲控制：
→ 每条线单独写细纲
→ 标注各线交叉点
→ 交叉点前需完成伏笔铺设
```

# 七、快速执行手册

## 每日写作流程

```
【动笔前】（5分钟）
□ 打开上章细纲，确认本章衔接点
□ 打开任务卡，确认情节点A/B、代价类型、章末钩子
□ 确认当日目标字数（4000字）

【写作中】（按模块执行）
□ 开篇（前300字）：完成冲突建立，不写设定
□ 情节点A（1000字）：主角应对+代价付出+配角介入
□ 悬念断点A（500字）：视角切换或悬念卡点
□ 情节点B（1500字）：新冲突建立+人设校验+新阻碍
□ 代价标注：确认本章代价已写入
□ 章末钩子（200字）：制造信息差/危机/反转

【完稿后】（10分钟）
□ 执行章节自检清单
□ 检查代价权重（≥30%）
□ 检查钩子有效性（与主线绑定？）
□ 检查设定一致性（有无吃书？）
□ 写次日细纲（避免明日卡文）

【发布前】（2分钟）
□ 检查字数（3500-4500字）
□ 检查价值观底线
□ 检查标题（悬念式/事件式）
□ 确认发布时间（00:00-02:00）
```

---

## 紧急情况处理

**卡文时**：
```
1. 检查任务卡：情节点A/B是否清晰？
2. 检查代价：本章需要付出什么代价？
3. 增加阻碍：还有什么阻止主角实现目标？
4. 引入配角困境：非主角角色是否可以有独立行动？
5. 回溯钩子：上一章的钩子是否已回应？是否需要制造新悬念？
```

**节奏平淡时**：
```
1. 检查弹簧模型：是否缺少"破局"或"新危机"？
2. 增加代价强度：主角付出的代价是否太小？
3. 引入身份反转：是否有角色身份可以揭露？
4. 增加时间压力：是否有截止时间/追兵/即将发生的危机？
```

**设定吃书时**：
```
1. 停止当前章节，标记矛盾点
2. 检查核心设定表，决定保留哪个版本
3. 修改已写章节，确保一致性
4. 在后续情节中避免再次冲突
```
