# 《科武纪元》编辑学习官｜《写作避雷｜新手写作五大避雷针》规则提炼

## 1 课程核心判断（≤6条）
1. **人称决定篇幅上限**：第一人称强代入但视角局限，难撑长篇；第三人称视角自由，为长篇连载与新手首选。
2. **流水账本质是缺期待**：无因果链、无情绪压差的日常叙述必流失读者，需前置动机或叠加压力。
3. **开篇忌“砌砖”与“堆人”**：必须从高概念/强冲突切入；首三章限1-3个场景、≤3个核心人物，禁用设定说明书。
4. **人设靠事件立而非形容词**：角色行为逻辑必须前后统一，性格转变需有剧情节点支撑，忌脸谱化与OOC。
5. **网文是大众消费品**：辞藻堆砌是阅读毒药，精准白描（1-2形容词/句）+章末悬念钩子才是留存核心。
6. **书名简介即流量入口**：需精准匹配题材、提炼主线冲突/高概念；简介即“产品宣传语”，决定首秀点击率。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 编辑规则 |
|:---|:---|
| **开篇** | 首章必须抛出“炸楼级”核心事件；场景≤1，新人物≤3；世界观/设定必须通过冲突动作自然带出，禁止独立段落堆砌背景。 |
| **节奏** | 每章结尾必设悬念钩子（卡点/危机/反转）；过渡情节需注入“前因后果”或“情绪加压”，单章内至少完成1次期待感建立与1次部分释放。 |
| **冲突** | 所有行为必须有明确动机（前因）与预期结果（后果）；冲突需阶梯式升级（如资源争夺→规则反噬→生死抉择），杜绝平铺直叙。 |
| **人物** | 建立人物行为档案（固定语气/应激模式/底线）；人设转变必须伴随关键剧情节点；用“事件中的选择”代替外貌/性格形容词堆砌。 |
| **题材** | 题材标签需与书名/简介强绑定；简介采用“高概念设定+核心冲突+悬念留白”结构；短故事/热点稿可试第一人称，长篇强制第三人称。 |
| **改编** | 简介/书名需预留“影视化/短剧化”视觉锚点（强动作、强反差、强悬念）；核心情节需具备“单集可独立成篇+主线强牵引”的单元结构。 |
| **平台规则** | 严格遵循番茄流量逻辑：20-50万字、100万字后各有一次书名测试机会；文风必须通俗化，适配下沉市场阅读习惯；禁用生僻词与长难句。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **第三人称多视角切换**：适合展现科武体系下的多势力博弈、科技树演进与武道传承线。
- **开篇“炸楼”逻辑**：直接从科武冲突/危机事件切入（如：机甲暴走/功法反噬/异星降临），而非从修炼等级/科技原理讲起。
- **钩子设置**：每章末卡在“科技突破临界点/武道对决胜负手/悬念揭晓前”，维持长篇追读率。
- **通俗化降维**：硬核科幻/武道概念必须用生活化比喻或动作链解释（如：用“液压阀爆鸣”类比经脉过载）。

### ❌ 不可硬套点（需类型化改造）
- **第一人称长篇**：《科武纪元》需多线叙事与宏大世界观铺陈，第一人称视角局限会导致设定交代生硬、篇幅受限。
- **纯生活化强情绪**：原文“挨骂/丢手机/噎住”属都市情绪模板。科武题材需转化为“资源断供/功法反噬/异星危机/阵营背叛”等类型化高压情绪，否则调性割裂。
- **简介纯热点词堆砌**：科幻/科武需保持设定严谨性与硬核质感，过度迎合下沉热词易破坏“科武”世界观沉浸感，应保留高概念冷峻基调。

## 4 编辑检查表（10条以内）
- [ ] 人称是否全程统一？有无第一/三人称混用或视角越界？
- [ ] 首章是否直接切入核心冲突/危机？有无超过3个场景或3个新人物？
- [ ] 是否存在无动机/无后果的流水账日常？是否已添加因果链或情绪压力？
- [ ] 每章结尾是否设置明确悬念/卡点（钩子）？
- [ ] 角色对话语气与应激反应是否具备差异化？有无OOC或前后矛盾？
- [ ] 人设是否通过“事件选择”展现？单句形容词是否≤2个？
- [ ] 书名/简介是否精准匹配题材？简介是否包含高概念+核心冲突+悬念？
- [ ] 科武设定是否通过动作/冲突自然带出？有无大段说明书式设定堆砌？
- [ ] 冲突是否呈阶梯式升级？读者期待感是否被持续牵引？
- [ ] 文风是否通俗流畅？有无刻意炫技、辞藻堆砌导致阅读卡顿？

## 5 对作家角色的输入要求
| 维度 | 输入指令（写作执行标准） |
|:---|:---|
| **动作链** | 禁止孤立动作。每个行为必须包含`触发条件→执行动作→连锁反应`，用连续动词推进剧情；禁用静态心理描写替代行动。 |
| **物理反馈** | 科武/科幻设定必须落地。力量释放、科技运转、环境变化需伴随可感知的物理反馈（如骨骼摩擦声、能量过载焦糊味、重力失衡眩晕感）；杜绝“唯心式”空泛描写。 |
| **代价** | 所有收益/突破必须支付明确代价（体力透支、资源枯竭、规则反噬、道德抉择）。无代价的升级即流水账；需前置“代价预警”，后置“代价兑现”。 |
| **钩子** | 章末必须卡在“信息差临界点”或“行动中断点”。提供3种模板：①危机逼近（倒计时/破门声/能量警报）；②认知颠覆（发现设定漏洞/身份反转）；③选择悬置（按下按钮/挥出武器但结果未知）。 |
| **读者预期** | 每章开篇需明确本章“核心任务/悬念”，行文全程牵引该预期；禁止偏离主线的支线灌水。预期兑现必须“意料之外、逻辑之中”，兑现后300字内必须抛出新预期。 |
