# 《科武纪元》编辑学习报告：基于《十二日谈》的实操规则提炼

## 1 课程核心判断（≤6条）
1. **创作底线**：“大事不虚，小事不拘”。核心逻辑/史实/设定不可颠覆，日常细节必须精准可考。
2. **共鸣内核**：所有题材本质是“借壳浇块垒”。历史/现实/科幻均需承载当代价值观与情感诉求。
3. **细节可信度**：宏观靠编年/文献/科学推演，微观靠田野调查/亲历访谈/生活肌理还原。
4. **载体倒逼节奏**：竖屏阅读要求“短段落、快节奏、小高潮不断”，传统慢热铺垫必流失读者。
5. **人物聚焦原则**：复杂事件/宏大背景必须收束到1-2个核心人物抓手上，避免群像失焦与设定淹没。
6. **网文护城河**：连载黏性、读者互动、情感联结是AI无法替代的核心壁垒，作品需为“人写”而非“产品生成”。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 摒弃长篇幅世界观/背景说明。首章必须用“具体事件+细节”切入，3章内抛出核心悬念或生存困境，建立明确阅读预期。 |
| **节奏** | 适配手机端竖屏阅读：单段≤3行，信息密度前置。每3000-5000字设置一个小高潮/反转，主线推进不断档，禁用“纯说明性过渡章”。 |
| **冲突** | 冲突需符合世界观内在逻辑。将宏大矛盾（文明博弈/技术伦理/资源争夺）具象化为1-2个核心人物的具体利益/情感/生存博弈，避免空谈理念。 |
| **人物** | 建立“现实观察档案”。从真实人物言行提取原型，赋予符合身份/阶层的行为逻辑。主角需有明确的时代/世界观烙印，言行不可脱离设定语境。 |
| **题材** | 考据支撑+虚构留白。核心规则/科技树/社会结构需有科学文献或现实推演依据；生活细节（器物、空间、物价、流程）必须精准，增强质感。 |
| **改编** | 影视/短剧改编前置：情节需“可视化、强动作、少内心独白”。复杂背景转化为具象道具/场景冲突，保留核心情感线，确保“好看”优先于“深刻”。 |
| **平台规则** | 尊重连载生态，保持日更稳定性。利用章评/段评收集反馈但不盲从；核心主线不因人气波动随意更改；利用“争议点/选择困境”激活互动。 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **设定自洽即“大事不虚”**：科幻底层物理法则、科技树演进、社会运行规则不可随意吃书或机械降神，需建立内部逻辑闭环。
- **细节考据平移**：将“历史文献调研”替换为“前沿论文/技术白皮书/工业标准研读”，增强近未来/硬科幻质感。
- **节奏与平台规则完全适用**：科幻长篇极易陷入“设定说明书”陷阱，必须强制切割为“事件驱动+短段落+高频悬念”。
- **人物聚焦**：将宇宙级/文明级冲突收束到主角团的生存抉择与能力成长上，用具体行动承载宏大命题。
- **现实映射**：科幻内核需锚定当下议题（AI伦理、技术异化、阶层固化、资源分配），实现“借科幻之壳，浇现实之块垒”。

### ⛔ 不可硬套点
- **历史“正统/定性”思维**：科幻鼓励颠覆性想象，无需拘泥于“主流历史定性”或“传统礼仪考据”，但需保证内部逻辑自洽。
- **田野调查/老物件依赖**：科幻侧重技术推演与未来场景构建，需替换为“实验室/工业场景采风+技术逻辑沙盘推演”。
- **传统“情景交融”慢热写法**：科幻开篇若用大段宇宙/环境描写铺垫，极易劝退网文读者。必须改为“危机切入+设定随剧情释放”。
- **历史“新闻通稿”叙事惯性**：科幻不追求“官方定论式”的平铺直叙，需强化多视角博弈与信息差悬念。

## 4 编辑检查表（10条以内）
- [ ] 核心设定/物理法则是否自洽？有无前后矛盾或“机械降神”？
- [ ] 开篇3章是否已抛出明确主线悬念/生存危机？有无冗长背景说明？
- [ ] 段落长度是否适配手机阅读（单段≤3行）？信息密度是否达标？
- [ ] 每章/每3000字是否包含至少1个情节推进点或情绪爆点？
- [ ] 科技/社会细节是否有现实依据或合理推演？（非纯幻想堆砌）
- [ ] 冲突是否具象化到人物具体行动/利益博弈？有无“空谈理念”？
- [ ] 主角行为逻辑是否符合其身份/世界观设定？有无“现代思维硬套”违和感？
- [ ] 宏大背景是否已转化为可视化的场景/道具/动作？（改编友好度）
- [ ] 是否埋设了可引发章评互动的“争议点/选择困境/悬念钩子”？
- [ ] 价值观是否提供现实参照或精神向上？有无为黑而黑/低俗渲染？

## 5 对作家角色的输入要求
| 维度 | 执行标准（写作指令） |
|:---|:---|
| **动作链** | 禁止“意念驱动”。所有决策/战斗/交互必须拆解为`感知→判断→执行→结果`的物理步骤。例：不写“他启动了机甲”，写“他拉动液压阀，听到气压嘶鸣，操纵杆反馈阻力，推进器喷出蓝焰”。 |
| **物理反馈** | 环境/科技/武技必须产生可感知的物理后果。重力变化、能量过载、金属疲劳、神经负荷需有具体描写（如耳鸣、肌肉撕裂感、仪表盘报警、地面龟裂、护甲灼痕）。 |
| **代价** | 任何能力使用/战术胜利必须支付明确代价（资源消耗、身体损伤、道德妥协、时间窗口、信任流失）。禁止“零成本开挂”，代价需推动后续剧情。 |
| **钩子** | 章末必须留“未完成态”。采用`危机逼近/信息反转/选择困境/关键道具出现`四选一。禁用“本章完，明日继续”式无效断章，钩子需与下一章首段直接咬合。 |
| **读者预期** | 每卷/每阶段开篇需明确“本阶段核心目标与失败后果”。过程中通过`小目标达成→新变量介入→预期升级`维持追读黏性。定期回收伏笔，兑现“设定承诺”，避免预期落空。 |
