# 《科武纪元》编辑学习官：天香瞳专访规则提炼

## 1 课程核心判断（≤6条）
1. **更新稳定性是算法推荐与读者留存的绝对底线**，断更直接触发流量降权。
2. **题材选择必须扬长避短**，强行迎合平台热点或切换不擅长文风，必然导致叙事割裂与数据滑坡。
3. **多元素融合的唯一标准是“服务主线”**，设定必须经得起逻辑推敲，否则极易成为败笔。
4. **重设定题材需建立“认知锚点”**（如历史类必用穿越视角），以最大化读者代入感。
5. **卡文期停笔优于硬写**，作者写作状态直接决定文本流畅度与读者追读体验。
6. **编辑的核心职能是“专业纠偏与数据诊断”**，而非代笔或盲目催更；作者需保持开放沟通。

## 2 可执行编辑规则（按模块）
| 模块 | 规则 |
|:---|:---|
| **开篇** | 禁止盲目堆砌平台流行梗或强行制造“伪爽点”。首章必须明确主角初始身份、核心诉求与第一重困境；3万字内完成世界观基础规则展示。 |
| **节奏** | 采用“危机建立→能力/智谋破局→新危机升级”的波浪结构。中期（约10-15万字）必须设置一次体系级转折（如新秩序建立后的反噬），维持完读率。 |
| **冲突** | 核心矛盾需通过“身份/立场/信息差”制造反差（如敌对阵营的血缘绑定、技术路线的互斥）。冲突解决必须依赖前文已铺垫的设定或能力，严禁机械降神。 |
| **人物** | 复杂人设（如多重立场、心理异变）必须附带现实逻辑支撑与资料考证。人物行为严格服从其核心利益诉求，禁止为推剧情强行降智或OOC。 |
| **题材** | 科武/科幻类必须建立“内部自洽规则库”。任何超现实设定（灵能、机甲、基因改造）需在首卷内给出基础原理或明确边界，禁止纯设定堆砌。 |
| **改编** | 关键情节需预留“视觉化强冲突”节点（如能量过载爆裂、机甲关节断裂、武道招式拆解），便于后续短视频切片、漫画分镜与影视化评估。 |
| **平台规则** | 番茄算法重“首章点击率→3万字留存→10万字完读率”。每章末尾必须留悬念钩子；断更超24小时将中断推荐池；作者需按固定时段更新以培养读者生物钟。 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **认知锚点平移**：将“历史必穿越”转化为科武语境下的“高维观测者/记忆复苏者/地球技术降维者”，快速建立读者理解坐标系。
- **多元素防疲劳**：科武主线可嵌入悬疑探案（如灵能犯罪现场还原）、技术博弈（如外骨骼迭代路线竞争），用“设定反差”拉升追读。
- **设定服务剧情**：所有科武体系（如基因锁、灵能回路、反重力引擎）必须直接推动主线或解决当前冲突，禁止脱离剧情的“说明书式”描写。
- **合理性考证**：科幻/武道设定需符合基础物理/生物学逻辑，或明确标注“推演边界”。遇有技术盲区，必须查阅论文/工程资料，避免“伪科学”引发读者出戏。

### ❌ 不可硬套点
- **“必须穿越”铁律**：科武题材可接受纯土著/原生文明视角，重点在于“技术代差/认知壁垒”而非穿越身份。
- **强心理设定（如三重人格）**：科武更重“物理反馈/系统规则/技术代价”。心理描写需转化为可观测的生理指标、机械故障或能量波动，避免纯意识流拖慢节奏。
- **300万字长篇结构**：短故事/热点稿需压缩为“单线高潮+即时反馈”，不可套用长篇的“中期铺垫-后期爆发”结构；热点稿需在首章直接切入核心冲突。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章内是否明确主角核心目标与初始困境？
- [ ] 科武体系/世界观规则是否在首卷内完成基础逻辑闭环？
- [ ] 每10万字是否设置至少1个强悬念/反转/高潮节点以拉升完读率？
- [ ] 新增人物/设定是否直接推动主线或解决当前冲突？（剔除无效支线）
- [ ] 冲突解决是否依赖前期铺垫？有无机械降神或战力崩坏？
- [ ] 科幻/武道设定是否附带明确“使用代价/物理限制”？
- [ ] 作者是否避开不擅长的文风/题材强行跟风？
- [ ] 卡文段落是否已标记并替换为过渡/支线，而非硬凑字数？
- [ ] 关键情节是否预留“视觉化/短视频化”改编接口？
- [ ] 更新计划是否稳定？有无断更风险预警？

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 严格遵循“触发条件→执行动作→环境/对手反应→结果”四步闭环。科武打斗/技术操作需标注能量流转、机械咬合或肌肉发力步骤，禁止跳跃式瞬移或无逻辑连招。 |
| **物理反馈** | 所有超常能力/科技装备必须伴随可观测的物理现象（如金属疲劳、热辐射、重力畸变、神经刺痛、灵能过载）。用感官细节（声/光/热/痛）替代抽象形容词。 |
| **代价** | 每次越级战斗/使用核心设定必须支付明确代价（体力透支、装备损毁、寿命折损、社会关系破裂、系统惩罚）。代价需累积并直接影响后续剧情走向，禁止“无消耗开大”。 |
| **钩子** | 章末必须留“未解变量”（如：敌人未死透、新势力介入、设定反噬、关键道具缺失、数据异常）。禁止用纯抒情、日常对话或总结性陈述收尾。 |
| **读者预期** | 开篇承诺的“核心爽点/悬念类型”必须在中前期兑现。科武题材读者预期为“规则内的智斗/战力成长/技术碾压”，禁止中途切换为纯感情流、玄幻修仙或脱离设定的唯心爆发。 |
