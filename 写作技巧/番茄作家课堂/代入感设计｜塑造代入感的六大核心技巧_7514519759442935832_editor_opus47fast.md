# 《代入感设计｜塑造代入感的六大核心技巧》学习笔记
来源：番茄作家课堂 / 煮熟的来福鸽 / 2025-06-11
对象：《科武纪元》编辑规则提炼（长篇 + 短故事 + 热点稿）

---

## 1. 课程核心判断
1. **代入感 = "我正在经历某事" + "与角色共鸣"**，缺一不可。
2. 共鸣分两层：**认知共鸣**（选择/价值观同频）与**情绪共鸣**（开篇憋屈/愤怒/兴奋）。
3. 故事框架优先于文笔；故事不行，五感再细也救不了。
4. **主动欲望（期待感）** 必须由作者刻意制造"情绪缺口"，并且释放点要**超出读者预期 30%**才解渴。
5. 人设禁止"十全十美"——**微缺点 + 接地气共性** 是拉近距离的硬通货。
6. 转折词与"了"字过多 = 读者被"强行认同"，伤代入。

---

## 2. 可执行编辑规则

### 开篇（前 500–800 字硬指标）
- 100 字内完成"谁 / 在哪 / 正在经历什么 / 一个标签特质"四要素。
- 用一句台词或一个动作交代身份+性格+冲突（参考"镇南府世子林峰"句式）。
- 情绪基调优先选：**亲情压制 / 憋屈 / 不劳而获 / 兴奋**，不要从平静起笔。
- 场景必须**可视化具体**：写"教学楼后小树林的夕阳"，不写"某个安静的地方"。

### 节奏
- 每章至少埋一个"情绪缺口"（读者想看的释放点），未释放前不要松。
- 释放强度 ≥ 读者预期；70% 释放等于扑街。
- 危机紧迫感（灾难片节奏）可在笔力不足时硬拉读者走。

### 冲突
- 冲突必须服务于"主角的选择"——选择是否与读者重叠决定共鸣。
- 制造对立情绪对：憋屈↔扬眉吐气、被误解↔真相揭穿、装弱↔露强（信息差爽点）。
- 信息差（李大牛不知道主角已拜师云岚宗）= 期待感主要来源。

### 人物
- 标签五件套：**外貌 / 身份 / 一句口头禅或动作癖 / 一个生理特征 / 一个微缺点**。
- 缺点要"共性"（懒、馋、宅、社恐、嘴硬），不影响人设核心特质。
- 缺点暴露场合要选：私下/反差场，**不在主场景翻车**。
- 人物小传必须包含"过往故事"，前后人设零漂移。

### 题材（男频向，本课定位）
- 接地气白话优先于华丽文笔；新人慎用大段心理描写与比喻。
- 大场景描写中**强制插入 1–2 种五感**（潮短袖、消毒水味、铁皮瓦雨声）。

### 改编 / 短稿 / 热点稿
- 短稿用"熟悉感"切入（高考、加班、相亲、童年场景），代入即时生效。
- 热点稿用"共性缺点 + 共性选择"做共鸣锚点，避免精英视角。

### 平台规则（番茄男频）
- 开篇标签化、白话化、低信息密度门槛。
- 章节钩 + 悬念钩搭配（课程末尾推荐的延伸课方向）。

## 3. 科武适配

### 可用点 ✅
- **基础信息标签化**：科武主角首章 100 字内交代"科技段位 / 武道根骨 / 阵营 / 一个外显特征（义体/伤疤/口头禅）"。
- **可视化五感**：把"赛博修炼""能量护体"翻译成读者熟悉的感觉——电流过皮肤的麻、芯片过热的焦味、护体罡气如冷雾。
- **主动欲望/信息差**：科技派看不起武者、武者藏着科技底牌——典型憋屈→扬眉吐气结构。
- **微缺点**：高阶武者怕打针、顶级科学家不会用智能家居等反差。
- **危机紧迫感**：灾难片式开篇（机甲坠落 / 灵气逆流）适用于章节钩。

### 不可硬套点 ❌
- "夕阳教室分手"式纯日常熟悉感——科武世界观陌生，硬塞校园场景会割裂。需要**用熟悉情绪（被欺压、被误解）包裹陌生设定**，而非搬熟悉场景。
- 男频白话风若全盘照搬，会稀释科幻设定的硬度——**设定段保留精度，冲突段下沉白话**，分层处理。
- "亲情压制开篇"在科武长篇可用，但短稿/热点稿慎用，易套路化。
- 转折词限制对硬科幻解释段不适用——逻辑链必须保留"因为/所以"，仅在叙事段克制。

## 4. 编辑检查表（10 条）
1. 开篇 100 字内是否齐：谁 / 哪 / 在做什么 / 一个记忆点？
2. 主角是否有 ≥1 个共性微缺点，且未在主场景翻车？
3. 本章是否制造或推进了一个"情绪缺口"？
4. 缺口若释放，强度是否 > 读者预期？
5. 主角面临选择时，是否与目标读者群价值观同频？
6. 大场景描写是否插入了至少 1 种五感？
7. 设定/术语是否被翻译为读者可具象的对照物？
8. 转折词（虽然/但是/然而/却）密度是否过高（建议 < 每 500 字 3 个）？
9. "了"字是否泛滥，可删则删？
10. 人设标签前后是否一致，无崩塌？

---

## 5. 对作家角色的输入要求

> 提交《科武纪元》章节/短稿时，作家须随稿附以下五项（缺项打回）：

- **动作链**：主角关键动作分解为 ≥3 步连续动作（起手→发力→收势/反馈），禁止"他出手秒了对方"式跳步。
- **物理反馈**：每次能力/武道/科技施展，写出至少 1 项身体反馈（震麻、耳鸣、过载发热、灵力反噬、视野残影）。
- **代价**：本章主角获得任何收益（升级 / 胜利 / 信息），必须标注付出代价（伤、债、关系、时间、道德）。无代价 = 无张力。
- **钩子**：章末提交 1 个明示钩（悬念问题）或 1 个暗钩（读者已知主角不知的信息差），并标注预计释放章节。
- **读者预期管理**：本章想让读者"期待什么"用一句话写明；释放章节须超出该预期一档（情绪强度 / 信息量 / 反差度任选其一）。
