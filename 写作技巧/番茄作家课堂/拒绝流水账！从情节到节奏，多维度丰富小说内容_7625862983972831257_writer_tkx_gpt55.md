# 《科武纪元》作家OS补丁  
## 补丁名：拒绝流水账——情节三段式 + 多轮节奏 + 余波驱动

适用对象：  
- 《科武纪元》长篇主线  
- 短故事 / 狼人篇  
- 热点稿 / 平台发布稿  

---

## 0. 核心执行口令

写任何核心场景前，先问一句：

> 这场戏有没有“铺垫—过程—余波”？  
> 过程里有没有“劣势—出牌—再劣势—杀手锏”？  
> 赢了之后有没有代价和新麻烦？

如果没有，默认判定为流水账。

# 1. 作家OS新增执行模块

## 模块A：核心情节三段式

每个核心情节必须拆成三格。

```text
【铺垫】
埋3个可回看的细节：
1. 动作异常
2. 物件异常
3. 对白回避 / 信息缺口

【过程】
至少3轮交手：
1. 主角陷入劣势
2. 主角出第一张牌
3. 敌方反制 / 更大劣势
4. 主角付代价打出杀手锏

【余波】
至少命中1项：
1. 情绪变化
2. 关系变化
3. 身体 / 装备后遗症
4. 新隐患
5. 新矛盾
6. 新情报
```

### 失败模式

| 失败写法 | 判定 | 修正动作 |
|---|---|---|
| 主角直接发现真相 | 跳跃流水账 | 前面补3个细节 |
| 主角一招秒杀 | 爽点过薄 | 加敌方反制和代价 |
| 打完就进下一场 | 没余波 | 补伤势、派系反应、舆论、关系裂痕 |
| 线索出现后不回收 | 假伏笔 | 删除或绑定后续揭示 |
| 同一目标反复试3次 | 原地踏步 | 引入新变量：新规则、新人物、新代价 |

# 3. 动作链补丁

## 禁止直接写

```text
他很愤怒。
她很害怕。
他很温柔。
他非常震惊。
```

## 改成动作链

### 愤怒

```text
颌肌绷紧 → 指节按上能量刃 → 视线锁住对方瞳孔里的反光
```

### 恐惧

```text
呼吸漏了一拍 → 后脚跟抵上金属墙 → 手指在通讯器上按错两次
```

### 隐忍

```text
他垂下眼 → 拇指擦过旧伤疤 → 把已经亮起的战术界面关掉
```

### 心软

```text
他本来已经转身 → 听见咳血声后停住 → 把药剂扔回对方脚边
```

### 杀意

```text
他没再说话 → 护臂上的温控线一格格变红 → 脚下合金地面浮起蛛网裂纹
```

# 4. 科武反馈补丁

科武场景不能只写“光芒大盛”“气势爆发”，必须给身体、装备、环境反馈。

## 必须从以下类别中至少选2类

### 1）身体反馈

```text
耳膜刺痛
肌纤维撕裂
骨缝发烫
义体接口发麻
视网膜浮现雪花噪点
心脏像被机械爪攥住
```

### 2）装备反馈

```text
护盾过载报警
外骨骼关节锁死
能源槽瞬间见底
刀刃边缘出现热熔卷曲
战术面板弹出红色错误码
```

### 3）环境反馈

```text
合金地面低频震动
空气里有臭氧味
墙面力场像水膜一样凹陷
灯带一排排熄灭
远处无人机群短暂失控
```

### 4）文明压迫感

```text
监控塔无声转向
城市广播切入审判倒计时
数据神殿的穹顶投下万人档案
星港上空的轨道炮缓慢校准
```

# 5. 出牌代价补丁

无代价胜利一律削弱。

## 每次主角出牌，至少绑定一个代价

```text
体能代价：肌肉撕裂 / 旧伤复发 / 神经灼烧
资源代价：能源块耗尽 / 信用点清零 / 药剂用完
关系代价：暴露秘密 / 得罪派系 / 欠下人情
精神代价：记忆污染 / 杀戮冲动 / 情绪失控
时间代价：错过救援 / 延误任务 / 敌方完成布置
身份代价：暴露底牌 / 被系统标记 / 进入通缉名单
```

## 示例

流水账写法：

```text
林烬开启玄核模式，击败了敌人。
```

补丁后：

```text
林烬咬碎舌尖，血腥味压住神经接口的烧灼感。玄核模式启动的瞬间，护臂能源槽从47%跌到3%。

敌人的重锤被他一拳砸偏，可他的右臂也传来骨裂般的脆响。

战术面板弹出红字：

【警告：玄核波形已被城防主脑记录。】

他赢了。

也被这座城记住了。
```

# 6. 多轮冲突补丁

## 标准战斗节拍

```text
第一轮：主角判断错误，吃亏
第二轮：主角用已知能力翻回一点
第三轮：敌人亮出新规则，主角再陷劣势
第四轮：主角付代价，使用前文伏笔中的底牌
第五轮：胜利不完整，留下隐患
```

## 写作指令

每轮必须换牌，不能一直重复“再快一点”“再用力一点”。

### 可换的牌

```text
功法牌
科技牌
地形牌
情报牌
心理牌
队友牌
规则漏洞牌
敌方弱点牌
牺牲牌
```

### 失败模式

| 问题 | 风险 | 修复 |
|---|---|---|
| 主角一直硬刚 | 单调 | 加地形、情报、装备限制 |
| 敌人只会变强 | 空洞 | 给敌方明确规则和弱点 |
| 主角凭空开挂 | 掉宝感 | 前文补训练、道具、伤痕、数据伏笔 |
| 打赢无后果 | 爽点廉价 | 加代价或更大敌人注意 |

# 7. 环境描写补丁

## 环境必须同时承担两件事

```text
1. 给画面
2. 给情绪 / 压力 / 信息
```

## 单段不得超过100字

超过100字，默认触发水文警报。

### 可执行公式

```text
环境画面 + 角色感受 + 情节信息
```

### 示例

水文版：

```text
夜色很深，城市很安静，远处的高楼像沉默的巨兽，空气中弥漫着一种压抑的感觉……
```

科武版：

```text
星港灯带一排排熄灭，只剩轨道炮的红色校准线扫过街面。林烬听见自己义体接口里细小的电流声，像有人在骨头里磨刀。
```

# 8. 人物口吻补丁

人物不能都说作者腔。

## 林烬类主角口吻

特点：克制、短句、判断优先，少废话。

```text
“说重点。”
“你骗我的地方有三个。”
“我不信命令，我信代价。”
“这不是机会，是诱饵。”
```

## 科研伙伴口吻

特点：数据、兴奋、冷幽默。

```text
“恭喜，你的右臂还有百分之十三的概率不报废。”
“从科学角度看，你刚才那一下很蠢。但很有效。”
“别动，我在给你缝神经，不是在织毛衣。”
```

## 军方 / 执法者口吻

特点：命令式、规则化、压迫感。

```text
“编号，身份，权限。”
“你有十秒解释自己为什么还活着。”
“根据第七管制条令，你现在属于可回收资产。”
```

## 反派口吻

特点：不解释太多，用判断压人。

```text
“你以为自己赢的是我？”
“年轻人总把底牌叫奇迹。”
“你身上的东西，本来就是我们的。”
```

## 狼人篇可借口吻

适合短句、压迫、怀疑链。

```text
“昨晚你在哪？”
“你身上有血味。”
“别看月亮。看我。”
“我们中间，有人换了心跳。”
```

# 9. 段落节奏补丁

## 紧张段落

使用短句、断行、动作优先。

```text
警报响了。

不是一声。

是整座地下城的警报，同时响起。

林烬抬头，看见穹顶上的轨道炮编号亮了。

目标锁定：他。
```

### 禁止

- 长篇回忆
- 温馨日常
- 解释世界观
- 双人连续闲聊5轮以上

---

## 喘息段落

高潮后允许喘息，但长度≤本章1/3。

### 可写内容

```text
修装备
包扎伤口
复盘战斗数据
短暂吃饭
师门训诫
队友争吵后沉默
独处看旧物
处理战斗后遗症
```

### 禁止

```text
追杀中突然调情
对峙中插回忆杀
生死关头解释童年
强敌压境时闲聊五轮
```

# 10. 章末钩子补丁

每章结尾至少放一个钩子。

## 钩子类型

### 1）信息差钩子

读者知道，主角不知道。

```text
而在他离开三分钟后，手术台下方的备用屏亮起。

【样本林烬：二次苏醒成功。】
```

### 2）身份钩子

```text
老人摘下手套，掌心赫然是失踪十年的武院徽记。
```

### 3）代价钩子

```text
林烬刚想抬手，右臂却没有回应。

战术面板弹出一行字：

【神经权限已转移。】
```

### 4）敌人钩子

```text
通讯频道里传来陌生男人的笑声。

“终于找到你了，零号。”
```

### 5）规则钩子

```text
排行榜刷新。

林烬的名字没有上升。

而是被标成了红色。

【违规进化体。】
```

# 12. 章节自检清单

交稿前逐项勾选。

```text
[ ] 本章核心事件是否具备：铺垫—过程—余波？
[ ] 铺垫是否至少有3个可回看的细节？
[ ] 每个关键道具/能力是否有前文出处？
[ ] 冲突是否至少3轮，并且每轮换牌？
[ ] 主角每次出牌是否付出代价？
[ ] 科武场景是否写出身体/装备/环境反馈？
[ ] 情绪是否用动作链表达，而不是“很愤怒/很害怕”？
[ ] 单段景物+情绪描写是否≤100字？
[ ] 高潮后是否有余波或喘息？

[ ] 新配角是否和主线有钩子，而不是巧合路过？

[ ] 章末是否有未解项或下一章钩子？
```

# 13. 短故事 / 狼人篇可借点

## 可借

### 1）三段式必须保留

短故事也不能只有事件流水。

```text
铺垫：谁可疑
过程：怀疑转移 / 身份反转
余波：真相后的人性刺痛
```

### 2）过程保留2轮反转即可

短篇不需要长篇多轮战斗，可用：

```text
第一轮：大家怀疑A
第二轮：证据指向B
结尾：真正的狼人是叙述者 / 死者 / 最安静的人
```

### 3）狼人篇重点借“动作链”和“信息差”

```text
他说自己没出门。
可鞋底的泥还没干。

她说没听见狼嚎。
可她的手一直捂着左耳。
```

### 4）章末 / 篇末钩子

```text
所有人都松了口气。

直到天亮后，村口又多了一具尸体。

而昨晚被处决的那个人，尸体不见了。
```

## 不建议借

```text
过长科技设定
多支线派系
复杂装备数值
长篇升级节奏
```

# 14. 科武长篇可借点

## 强借

### 1）每次突破都跑三段式

```text
突破前：身体异常 / 数据异常 / 老师回避
突破中：失控 / 敌袭 / 系统反噬
突破后：能力提升 + 后遗症 + 被势力盯上
```

### 2）每场战斗必须多轮翻盘

适合科武天然牌组：

```text
武技牌
义体牌
数据牌
环境牌
敌方规则漏洞牌
团队配合牌
隐藏血脉/实验体牌
```

### 3）余波驱动下一章

战斗后不要只写“众人震惊”。

改成：

```text
武院改排名
军方发通缉
反派回收战斗数据
主角旧伤恶化
队友发现他不是正常人类
舆论把他推成怪物
```

### 4）环境必须科武化

不要：

```text
灵气弥漫，仙山缥缈。
```

改成：

```text
悬浮道场外侧包着三层力场，合金檐角下垂着冷蓝色数据流。每一次钟声响起，林烬的义眼都会短暂失焦。
```

## 慎借

```text
言情式揉头、撇嘴、傲娇日常
长篇回忆杀
玄幻宗门景物模板
慢热暗中调查三章不揭示
```

# 15. 平台规则转为发布 / 包装 / 风险门禁

## 发布门禁

```text
[ ] 单段景物+情绪描写是否超过100字？
超过：压缩或拆分。

[ ] 紧张段落是否插入温馨日常？
有：删除或移到高潮后。

[ ] 两人对白是否连续5轮无动作/信息变化？
有：加入动作、打断、信息推进，或删减。

[ ] 同一目标是否反复尝试3次无新变量？
有：加入新人物、新规则、新代价。

[ ] 本章是否有无代价胜利？
有：补身体、资源、关系、身份代价。
```

## 包装门禁

章节标题和简介要突出：

```text
目标
冲突
代价
钩子
```

### 标题方向

弱标题：

```text
第32章 战斗
```

强标题：

```text
第32章 玄核启动，林烬被城防主脑标记
```

弱标题：

```text
第45章 真相
```

强标题：

```text
第45章 老师留下的芯片里，藏着林烬的死亡记录
```

## 风险门禁

```text
[ ] 是否水文感过重？
风险：环境、心理、设定连续堆叠。
处理：改成动作+反馈+信息。

[ ] 是否节奏断裂？
风险：追杀中回忆，生死关头闲聊。
处理：回忆挪到战后喘息。

[ ] 是否反转过密？
风险：单卷超过2次大反转，读者麻木。
处理：小反差保留，大反转压后。

[ ] 是否人物崩坏？
风险：冷漠者突然热情，谨慎者突然莽撞。
处理：补触发事件或改行为。
```

# 16. 可直接套用的章节骨架

## 科武战斗章骨架

```text
1. 开场给目标
林烬必须在十分钟内夺回核心芯片。

2. 铺垫三个异常
敌方没有追击。
```

开写前念一遍：

```text
不堆字。
要层次。

每张牌都要出处。
```
