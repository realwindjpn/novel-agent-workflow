## 二、章节执行模块（可直接套用）

### 动作链模板

```
【标准节拍】
触发事件（不超过200字，必须具体）
→ 主角生理/心理反应（100字内，具象化）
→ 决策窗口（给读者思考时间）
→ 执行（步骤化，禁止跳跃）
→ 结果（外化可见）
→ 代价显性化
→ 章末钩子（未解悬念+情绪断点）

【科武增强版节拍】
触发事件
→ 能量波动/气血损耗数值化
→ 武学/机甲反馈具象化（肌肉记忆/神经链接/装备损耗）
→ 决策（锚定利益权衡，非情绪化）
→ 执行（招式/战术可视化）
→ 代价（基因反噬/记忆剥离/同伴风险）
→ 章末钩子（悬念+伏笔激活）
```

### 段落节奏模板

```
【高冲突段】（适用于战斗/对峙/揭露）
短句×3（节奏急促）→ 长句（情绪释放）→ 短句×2（代价确认）→ 悬念收尾

【情绪铺垫段】（适用于感情推进/救赎场景）
环境描写（感官优先）→ 心理独白（不超过50字）→ 动作细节（手部/眼神/呼吸）
→ 对话（口语化，禁止书面腔）→ 沉默/留白（情绪回甘）

【信息释放段】（适用于设定揭秘/战力展示）
已知信息×1 → 未知冲突×1 → 悬念钩子×1
（禁止一次性倾倒设定，保持信息梯度）
```

## 三、章节自检清单

```
【必检项】（任一缺失，本章打回重写）
□ 动作链完整性：触发→决策→执行→结果，缺步即补
□ 物理反馈存在：情绪必须外化为可感知生理/环境反应
□ 代价已兑现或已激活：本章收获必须对应明确代价
□ 钩子存在且有效：与主线关联度≥3

【数据项】（可量化评估）
□ 字数区间：章节字数____（建议3000-5000）
□ 信息密度：核心信息释放点____个（建议2-4个）
□ 悬念层级：本章悬念____级（1=读者已知，5=完全未知）
□ 情绪锚定：承诺类型一致率____%

【风险门禁】
□ 平台敏感词扫描（完成后截图存档）
□ 三观导向自检（独立/救赎/成长正向率≥80%）
□ 版权接口完整性（高光场景≥1个可独立提取）

【长尾预埋】（完本后数据爬坡关键）
□ 本章是否埋设可二刷的细节/伏笔？____
□ 该伏笔距激活点____章（本卷/跨卷）
□ 伏笔激活时是否有情绪爆点支撑？

【衍生空间】
□ 副CP/配角是否有独立剧情线？____
□ 该支线是否可拆分为短篇/番外？____
```

## 四、平台规则→风险门禁映射

| 平台逻辑 | 转换为 | 执行动作 |
|---------|-------|---------|
| 番茄重完读率 | 完本长尾推荐触发 | 前10章完读率必须≥60%；章节结尾留钩子，降低弃文率 |
| 书名/简介情绪标签 | SEO流量入口 | 书名必须含核心情绪词（热血/救赎）+核心题材词（机甲/武道） |
| 评论区造梗传播 | 免费流量裂变 | 每3章预设1个可提取标签（如特定台词/名场面），供读者传播 |
| 短视频日常运营 | 内容即招商 | 自运营内容需转向“设定解析/战力推演/高光切片”，非碎碎念 |
| 出版/影视改编 | 版权变现门槛 | 预留单元式高光场景+清晰成长弧光+可独立提取副线 |
| 平台导向合规 | 内容安全线 | 避免无意义虐主；价值观导向需积极（独立/救赎/成长） |

## 五、可借用点标注

### 🎯 短故事/狼人篇可借用

```
【可直接套用】
□ 开篇反常识钩子模板（身份反差+处境颠覆）
□ 情绪代偿功能角色设计（小太阳/理想型→狼人受创后的救赎锚点）
□ 冲突锚定社会议题（原生家庭/资源分配→狼人歧视/血脉压制）
□ 救赎弧光结构（受创→救赎→独立，本章可闭环）
□ 章末情绪断点（悬念+情感余韵，可独立成篇）

【需改编适配】
□ 篇幅压缩：从3000-5000章压缩至2000-3000字
□ 冲突烈度：提升对立强度（狼人世界观压迫感需高于校园背景）
□ 节奏加速：单章完成度≥80%，短篇需快速交付情绪承诺
```

### 🎯 科武长篇可借用

```
【可直接套用】
□ 议题映射（基因阶级/资源垄断/门派倾轧替代重男轻女）
□ 反常识开篇（武道高考交白卷/底层激活上古协议）
□ 物理反馈层（能量消耗/基因反噬/记忆剥离替代情绪描写）
□ 代价体系（成长/胜利必须支付代价，杜绝无成本开挂）
□ 长尾运营（完本后设定集解析/副线番外/战力推演）
□ 细节真实感（查证武学逻辑/科技树，避免设定悬浮）

【不可硬套】
□ 校园甜宠基调（需替换为生存压力+世界观压迫）
□ 日更字数导向（设定复杂优先逻辑自洽，4k-8k可灵活调整）
□ 短视频碎碎念内容（需转为干货+高光切片）
□ 单本完结依赖（需规划单元剧/系列化，非单本数据）
```

## 六、失败模式速查表

| 症状 | 诊断 | 处置 |
|-----|------|-----|
| 读者反馈"太水" | 信息密度不足/动作链跳步 | 补全物理反馈层，增加代价兑现 |
| 读者反馈"太虐" | 无意义虐主/代价无价值 | 检查价值观导向，确认救赎路径存在 |
| 读者反馈"看不懂" | 设定堆砌/信息梯度失序 | 拆分信息释放点，单章≤4个核心信息 |
| 数据持续下滑 | 钩子失效/情绪承诺未兑现 | 重审前5章钩子，补设情绪断点 |
| 完本后数据未爬坡 | 中后期伏笔缺失/无二刷钩子 | 补埋跨卷伏笔，激活时配套情绪爆点 |
