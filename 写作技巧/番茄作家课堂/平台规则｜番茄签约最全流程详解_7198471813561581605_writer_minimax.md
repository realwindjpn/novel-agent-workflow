# 《科武纪元》作家OS｜v1.0 补丁包

## 一、写作前任务卡字段更新

每次开写前逐项确认，完成打✓，未完成不得动笔。

| 字段 | 科武长篇要求 | 短故事/狼人篇要求 |
|:---|:---|:---|
| **本次字数目标** | 3000-5000字/章 | 1500-3000字/章 |
| **节点绑定** | 明确属于哪个签约节点（2W/5W/8W） | 独立闭环，2万字内必须完成 |
| **核心悬念钩子** | 本章结尾留下未解悬念 | 单章节内必须有转折 |
| **主角当前能力值** | 精确定义：基因锁阶位/义体型号/能量储备 | 主角能力在开篇30%内必须定义完毕 |
| **代价预设** | 能力提升/战术选择/阵营站队的代价已设定 | 单次冲突代价必须在冲突结束后兑现 |
| **科武场景具体化** | 替换理论说明：用义体过载/基因锁开启/星舰跃迁故障等具象场景 | 战斗/冲突必须有物理感官反馈 |
| **类型标签兑现** | 开篇承诺的升级/悬疑/热血路径清晰 | 标签明确，结尾必须兑现 |

**⚠️ 未完成上述字段不得开写，违者触发签约失败风险**

## 二、章节自检清单（发布前必须通过）

### 【安全门禁·一票否决项】

- [ ] 无低俗描写（性暗示/血腥过载/暗黑低智）
- [ ] 无现实敏感映射（政治/疫情/领土争议）
- [ ] 无侵权（抄袭/融梗/撞设定）
- [ ] 分段合规（每段≤150字，禁止长段堆砌）
- [ ] 言语通顺（无逻辑断裂/对话无意义堆砌）

### 【签约评估项·核心考核】

- [ ] **开篇1-3章**：核心悬念抛出 + 主角明确动机 + 基础世界观落地
- [ ] **每1-2万字**：至少1次剧情/情绪小高潮
- [ ] **5万字前**：完成首次主线阶段性收束
- [ ] **主角行为**：符合当前科武阶段能力与资源限制
- [ ] **冲突具象化**：对话与行动直接推动剧情，禁止心理独白替代动作推进
- [ ] **主线清晰**：一句话概括核心目标与走向

### 【科武长篇专用项】

- [ ] 科武场景具象化（感官反馈而非抽象数值）
- [ ] 体系突破绑定节点（2/5/8万字与能力进阶同步）
- [ ] 多线伏笔预留（8万字推荐前数据爬坡支撑）
- [ ] 更新稳定性确认（断更=数据断崖=推荐池剔除）

### 【章末钩子·追读率强制项】

- [ ] 每章结尾必须埋设未解悬念或危机预告
- [ ] 示例格式：`警报骤响，舱门外传来非人频率的敲击声`
- [ ] 禁止以总结式/感慨式/风景描写式收尾

## 三、失败模式速查表

### 【签约申请前·必避雷区】

| 失败类型 | 触发条件 | 科武长篇后果 | 短故事/狼人篇后果 |
|:---|:---|:---|:---|
| **机会浪费** | 2万/5万/8万各仅一次机会，失败即永久封签 | 三次全败需精修达标重新爬字 | 同样三节点限制，结构不同但标准一致 |
| **安全审核红灯** | 低俗/敏感/言语不通/侵权 | 直接进入黑名单 | 作品下架+账号风险 |
| **题材错配** | 非大众化/易读性弱/纯设定流 | 题材适配度第一维度，文笔再好也白搭 | 同标准，需类型化改造 |
| **故事性薄弱** | 逻辑断裂/冲突不具象/对话无推动 | 评估失败，阻断签约 | 短故事闭环感更严苛 |
| **节奏失控** | 慢热铺垫/设定堆砌/无高潮节点 | 错过推荐节点，后续无流量扶持 | 追读率断崖，平台算法降权 |

## 四、动作链执行规范（强制）

**每场戏必须遵循闭环：`触发→决策→执行→结果`**

| 阶段 | 禁止写法 | 正确写法 |
|:---|:---|:---|
| **触发** | 环境描写空转、心理独白铺垫 | 具体事件触发：`义体右臂过载警报响起，火光中敌方机甲残骸正在重组` |
| **决策** | 内心纠结超过200字、旁白解释 | 直接决策：`林野拔掉义体散热片，放弃右臂机动性换取瞬时爆发` |
| **执行** | 招式名称堆砌、无感官反馈 | 具象化执行：`能量涌出右臂的瞬间，剧痛从肘部灼烧至肩胛，视野出现雪花` |
| **结果** | 总结式收尾、意义升华 | 悬念收尾：`敌方机甲没有倒下，反而抬起炮口，对准了他的能源核心` |

## 五、代价兑现清单（强制）

**每次能力突破/战术选择/阵营站队必须在下一章内兑现代价**

| 类型 | 科武长篇示例 | 短故事/狼人篇示例 |
|:---|:---|:---|
| **资源代价** | 破解第三段基因锁后能量储备归零，下场战斗必须依赖外骨骼 | 狼人变身后体力透支，逃跑时崴脚无法反抗 |
| **身体代价** | 义体过载导致神经系统不可逆损伤，战斗时出现0.3秒延迟 | 主角使用禁术后失去部分记忆，结局时认不出重要人物 |
| **信任代价** | 选择帮助机械派系，人类阵营盟友永久关闭 | 主角为救狼人同伴暴露位置，整个狼群被猎杀 |
| **时间窗口代价** | 突破消耗时间过长，错过星舰撤离窗口，被困战场 | 变身时间仅够10分钟，追逐战中必须在最后一秒做出选择 |

**⚠️ 代价未兑现 = 故事张力断裂 = 代入感失效 = 签约评估扣分**

## 六、平台规则→风险门禁转换

| 原规则 | 执行补丁 |
|:---|:---|
| **签约是流量唯一前置** | 未签约=推荐池绝缘=稿费绝缘。2万字前必须完成签约申请准备 |
| **3次机会不可逆** | 每次申请前完成精修+自检清单全过。失败后精修达标方能进入下一节点 |
| **安全审核先行** | 每章发布前通过安全门禁清单。7天工作日审核期，预留缓冲 |
| **编辑评估双轨** | 安全通过后编辑评估：题材/节奏/人物/开篇/代入感/主线/故事性 |
| **题材适配度优先** | 类型标签明确（升级/悬疑/热血），科幻需做"可读性降维"包装 |
| **签约后稳定更新** | 签约后日更≥4000字，承接8万字推荐节点流量，断更=推荐池剔除 |
