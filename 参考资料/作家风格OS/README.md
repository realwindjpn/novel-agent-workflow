# 科武纪元·作家风格OS

用途：把“去AI味”从禁词检查升级为作家风格培养。

## 原则

- 去AI化只是底线。
- 作家风格是目标。
- 素材卡负责事实和细节。
- 作家风格OS负责表达方式。
- 作者角色写正文前必须读入本目录核心卡。

## 四件事

1. `voice_rules.md`：风格规则。
2. `bad_phrases.md`：禁用词/替代表达。
3. `scene_method.md`：场景展开方法。
4. `author_prompt_patch.md`：给作者角色注入的短提示。

## 与素材/学习关系

- SenseNova/采集资料：提供“写什么”。
- 知识库素材卡/RAG：提供事实、数字、来源。
- 写作角色OS：把采集学习经验蒸馏为动作、反馈、代价、失败模式、口吻。
- 作家风格OS：规定小说“怎么写”。
- 六角色审核：判断“能不能过”。

## 技法层与执行层的关系（2026-09-26 补）

`写作技巧/写作技法蒸馏.md` 是**技法层**（莫仁3/6、姬叉5、黄易、凡尔纳等）。
本目录是**执行层**（作者席真正被注入的风格卡）。

审计实证：技法层的三条关键技法——莫仁3 围-撤-围、莫仁6 智斗多方博弈、姬叉5 对话随关系定制——**只活在技法层，从未下沉到 `author_prompt_patch.md`**，而 `author_prompt_patch.md` 的前置读取与项目资料喂养层都没有列 `写作技法蒸馏.md`。结论：作者席没有任何强制路径读到它，三条技法在体系里是**孤岛**。

**规则**：技法层的每一条，若要真正约束作者席，必须同时满足：

1. 在 `author_prompt_patch.md` 的前置读取或风格铁律里有对应条目；
2. 在确定性扫描器或九信号审稿表里有对应判定项。

只满足第 1 条 → 靠席自觉，会漏。只满足第 2 条 → 判据无定义，查不了。
