# 《科武纪元》时事驱动连载弹性大纲机制

> 版本：v1.0  
> 日期：2026-04-29  
> 目标：在每日时事持续进入创作的情况下，保证“已发表正文不被打脸、未发表大纲可灵活吸收、长线主干不被短期热点拖偏”。

---

## 1. 基本原则

1. **正文优先于大纲**：已投稿/已发布正文视为最高事实层，后续大纲必须解释它，不能推翻它。
2. **已投稿锁定，未投稿可改**：锁定章节只做勘误、伏笔解释、后文补丁；未投稿章节可调整事件、顺序、人物承担功能。
3. **时事只做映射，不做照搬**：现实事件进入小说时必须经过“抽象化、架空化、剧情化”，避免新闻复述。
4. **主线不因热点改航道**：火星/外星技术/铁幕/南天门等主干优先级高于每日热点。
5. **宁可记伏笔，不强改正文**：若时事素材与已写事实冲突，优先转为后文伏笔、舆论背景、情报误判或支线回声。
6. **每卷保留弹性槽**：每卷预留1—3章“弹性槽”，用于吸收每日时事、修补伏笔、做卷间过渡。弹性槽只定义功能，不提前写死剧情。写到该章前，再依据最新素材命名与落地。
7. **弹性槽不使用非整数章号**：番茄正文只能用整数章号。弹性通过大纲功能位实现，不使用A/B/C章，也不临时插号。

---

## 2. 章节状态分层

| 状态 | 定义 | 可改范围 | 处理原则 |
|---|---|---|---|
| S0 已发布/已投稿 | 已交付平台或读者可见 | 不改剧情事实；仅可改错字、病句、格式 | 绝对锁定 |
| S1 已定稿未投稿 | 正文完成但未发出 | 可做小修：加伏笔、改细节、补一句新闻背景 | 不改核心事件和结局 |
| S2 草稿中 | 正在写或已有半成稿 | 可中修：调整场景、人物任务、冲突来源 | 保留章节功能 |
| S3 大纲章节 | 只有章节梗概 | 可大改：重排事件、替换素材、合并拆分 | 服从主线与节奏 |
| S4 素材池 | 只有时事/灵感/设定 | 可任意筛选、延后、废弃 | 不承诺进入正文 |

**执行规则**：每次引入时事前，先标记目标章节状态。S0/S1 只能“补解释”，S2/S3 才能“改结构”。

---

## 3. 素材分层机制

每日时事素材进入项目后，先分为四层：

### A层：主线级素材
- 影响世界格局、科技路线、战争形态、国际组织、太空战略。
- 可改变未投稿大纲的阶段目标。
- 例：AI算力管制升级、太空军事化、能源路线重大变化。

### B层：章节级素材
- 可支撑1—3章的冲突、任务、反转或爽点。
- 不改变大主线，只增强某段剧情的现实质感。
- 例：无人机蜂群、芯片黑市、算力券、国际会议博弈。

### C层：细节级素材
- 用于台词、新闻屏幕、情报简报、背景噪音、人物判断。
- 不改变章节结构。
- 例：某类设备涨价、舆论热词、技术参数、市场传闻。

### D层：伏笔/备忘素材
- 目前不能安全写入正文，或与已写内容存在潜在冲突。
- 只记录，不立刻改文。
- 后续可转为“旧事件真相”“二次爆雷”“情报反转”。

## 4. 每卷弹性槽设计

### 标准卷结构

| 模块 | 建议章数 | 功能 |
|---|---:|---|
| 卷首承接 | 1—3章 | 处理上一卷余波，切换战场，重置读者预期 |
| 主线推进 | 40—45章 | 技术线、政治线、战斗线、人物线交替推进 |
| 弹性槽 | 1—3章 | 吸收每日时事、补强伏笔、修补新旧大纲冲突 |
| 卷尾收束 | 2—4章 | 回收本卷核心矛盾，给下一卷钩子 |

### 弹性槽命名规则

大纲阶段可写：
- `第X章 弹性槽1：时事吸收/产业补强`
- `第X+1章 弹性槽2：伏笔回收/人物补强`
- `第X+2章 弹性槽3：卷间过渡/危机预埋`

正文阶段必须改成正式标题，例如：
- `第251章 算力券黑市`
- `第252章 泛际会议暗战`
- `第253章 归途前夜`

### 使用边界

1. 弹性槽不能承载主线唯一关键事件，避免未来删除/替换时伤主干。
2. 弹性槽只服务三件事：时事吸收、伏笔补强、卷间过渡。
3. 弹性槽用完后，不再临时插章；新素材进入下一卷或伏笔池。
4. 如果某卷时事冲击过大，最多启用3章弹性槽；超过3章，说明大纲需要升版本，而不是继续塞补丁。

## 5. 每日时事进入大纲/正文流程

### Step 1：记录原始素材
建立每日条目，至少写清：

```text
日期：YYYY-MM-DD
现实素材：一句话概括
来源/可信度：高/中/低
关键词：AI、芯片、太空、能源、舆论、军事、金融……
可映射对象：铁幕/南天门/星穹/泛际会议/黑市/普通人
风险：政治敏感、技术硬伤、与正文冲突、节奏拖慢
建议层级：A/B/C/D
```

### Step 2：抽象成小说事件
不要直接写“现实某国某公司某事件”，而是转换为：

| 现实素材 | 小说化处理 |
|---|---|
| 出口管制 | 铁幕联盟技术封锁升级 |
| 算力涨价 | 黑市算力券、地下GPU租赁、渔船算力走私 |
| 太空竞赛 | 星穹公司/月球资源/轨道防御争夺 |
| 舆论战 | 海外媒体抹黑南天门计划 |
| AI安全争议 | 铁幕AI伦理模块失控或被利用 |

### Step 3：匹配章节状态
- 命中 S3：可直接修改大纲。
- 命中 S2：先确认章节功能不变，再调整冲突来源。
- 命中 S1：只加一两处伏笔或背景，不改结局。
- 命中 S0：禁止回改，改用后文解释。

### Step 4：更新映射表
所有被采用的时事素材必须登记到“时事—剧情映射表”，避免重复使用或前后矛盾。

### Step 5：生成变更补丁
每次大纲变化不直接覆盖旧逻辑，先写补丁记录：

```text
补丁编号：P-YYYYMMDD-序号
影响章节：第X章—第Y章
素材层级：A/B/C/D
改动类型：新增/替换/延后/废弃/伏笔化
原因：为什么要改
风险：与哪些正文或大纲冲突
处理：如何消除冲突
版本号：大纲 vX.Y -> vX.Y+1
```

## 5. 冲突检测清单

每次改大纲前，必须检查以下项目：

### 5.1 硬事实冲突
- 人物是否已经在正文中死亡、失踪、离队、受伤？
- 技术是否已经被设定为不可行、已失效或已被破解？
- 组织关系是否已写死？例如敌友、上下级、背叛、合作。
- 时间线是否矛盾？例如同一天人物不可能同时在月球和地球。

### 5.2 人物动机冲突
- 新时事是否强行改变角色立场？
- 是否让主角团为了配合热点而降智？
- 是否破坏既有人物成长线？

### 5.3 主题冲突
- 是否偏离“科技救国、武道入科、现实驱动、文明竞速”的核心？
- 是否变成新闻评论或口号输出？
- 是否削弱小说冲突和人物行动？

### 5.4 节奏冲突
- 是否连续多章都在开会、看新闻、讲政策？
- 是否打断当前战斗/任务/悬念？
- 是否导致卷末目标后移太久？

### 5.5 设定冲突
- 新技术是否压过已建立的南天门体系？
- 是否让旧危机显得没必要？
- 是否让敌方能力忽强忽弱？

**判定结果**：
- 无冲突：可进入大纲/正文。
- 轻冲突：改名词、改时间、改承担人物。
- 中冲突：放入未投稿章节，改为支线或背景。
- 重冲突：只记伏笔，不改正文。

## 6. 时事—剧情映射表模板

| 编号 | 日期 | 现实素材摘要 | 小说映射 | 层级 | 目标章节 | 状态 | 冲突等级 | 处理方式 | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| M-YYYYMMDD-01 | 2026-04-29 | 例：算力出口受限 | 铁幕升级AI算力封锁 | B | 第X章 | 待写入 | 轻 | 改为黑市线背景 | 避免直写现实名称 |

**状态可选**：待评估 / 已入大纲 / 已入正文 / 伏笔化 / 延后 / 废弃。

## 7. 补丁优先级

| 优先级 | 适用情况 | 允许动作 |
|---|---|---|
| P0 连续性修复 | 已写正文与大纲冲突、章节编号错位、人物事实错误 | 立即修大纲；正文只修未投稿部分 |
| P1 主线增强 | 强时事素材能强化核心主线 | 调整未投稿大纲，必要时重排章节 |
| P2 爽点/冲突增强 | 能增强单章可读性但不影响主线 | 加入章节任务、反转、对抗场景 |
| P3 细节质感 | 增加现实感、技术感、生活感 | 加新闻屏、简报、台词、背景道具 |
| P4 备忘伏笔 | 暂时无法安全使用 | 只进素材池，不改正文 |

**优先级规则**：P0 > P1 > P2 > P3 > P4。  
当 P1/P2 与 S0 正文冲突时，自动降为 P4 或改为后文解释补丁。

## 8. 版本号规则

采用“主版本.次版本.补丁号”：

```text
大纲 v8.0.0：当前主大纲
v8.1.0：主线级调整，如卷结构、阶段目标、关键反派变化
v8.0.1：连续性修复、章节编号修正、错字或表述修补
v8.0.1-p20260429a：单日时事补丁，不一定立刻合并主版本
```

### 升级标准
- **主版本 +1**：卷结构重排、主线方向变化、核心设定变化。
- **次版本 +1**：10章以上大纲调整、关键事件顺序变化、角色线重排。
- **补丁号 +1**：局部章节修正、时事映射、小范围冲突修复。

### 记录要求
每次版本变化写明：

```text
版本：v8.0.1
日期：YYYY-MM-DD
原因：
影响范围：
锁定章节：
可变章节：
回滚方案：
```

## 9. 已投稿锁定机制

### 9.1 锁定内容
S0章节锁定以下内容：
- 事件结果
- 人物去向
- 重大台词承诺
- 技术能力上限/下限
- 敌我关系
- 时间地点
- 卷末钩子

### 9.2 可动内容
若平台允许修改，只能动：
- 错别字
- 标点
- 明显病句
- 不影响剧情的技术措辞

### 9.3 冲突补救方式
若新时事与 S0 冲突，按以下顺序补救：

1. **后文解释**：旧信息是误判、假情报、遮蔽层。
2. **视角限制**：当时角色不知道全貌。
3. **敌方伪装**：此前事件由铁幕/星穹故意制造假象。
4. **技术迭代**：旧设定在当时成立，新设定是后来突破。
5. **平行支线**：把新素材给另一个地区/组织/人物承担。
6. **伏笔化**：只记入素材池，等待合适窗口。

## 10. 未投稿可改机制

S1—S3 可改，但必须保留章节功能。每章至少明确一个“不可丢功能”：

```text
第X章：功能 = 揭露铁幕新动作 / 推进月球线 / 强化苏雨晴能力 / 埋火星坐标伏笔
可替换元素 = 新闻背景、敌方手段、行动地点、配角任务
不可替换元素 = 角色成长节点、卷末钩子、主线因果
```

改动优先顺序：
1. 先替换背景素材。
2. 再替换冲突手段。
3. 再调整场景位置。
4. 最后才调整章节顺序。
5. 不轻易改角色关键抉择。

---

## 11. 何时只记伏笔，不改正文

出现以下情况，时事素材只进入 D层，不改正文：

1. 与已投稿章节硬事实冲突。
2. 会导致主角团已有胜利失效。
3. 需要连续重写超过3章才能成立。
4. 只是短期热点，三天后可能失去价值。
5. 现实指向过于具体，容易变成新闻复述。
6. 技术逻辑未确认，可能造成硬科幻漏洞。
7. 会打断当前战斗、任务、情感爆点或卷末收束。
8. 与作品核心主题无关，只是“看起来很热”。

伏笔记录格式：

```text
伏笔编号：F-YYYYMMDD-01
素材摘要：
暂不使用原因：
未来可用窗口：第X卷/某类会议/敌方反扑/民间支线
可转化方向：误判真相/敌方新技术/舆论战/黑市线/普通人视角
```

## 13. 单次变更标准流程

```text
1. 收集今日时事
2. 分层：A/B/C/D
3. 查正文锁定表：目标章节是否 S0/S1/S2/S3
4. 做冲突检测：硬事实/人物/主题/节奏/设定
5. 决策：写入大纲 / 写入正文 / 伏笔化 / 延后 / 废弃
6. 更新映射表
7. 写补丁记录
8. 更新版本号
9. 回看相邻前后3章，确认因果顺畅
```

## 15. 一句话执行准则

**已发正文是地基，未发大纲是脚手架，时事素材是可替换零件；先查锁定，再查冲突，能增强主线就写入，不能安全吸收就伏笔化。**
