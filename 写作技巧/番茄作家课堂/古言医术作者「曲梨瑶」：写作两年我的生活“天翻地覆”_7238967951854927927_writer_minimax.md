## 一、核心执行原则（作家OS底层协议）

> 情绪价值是唯一的产品规格。设定复杂度是负债，不是资产。

曲梨瑶两年写作“天翻地覆”的本质，是完成了一次**从“自我表达”到“读者交付”**的职业化跃迁。以下补丁将此原则分解为可量化、可执行、可校验的操作系统指令。

## 二、写作前任务卡字段更新

你在开篇前必须完成以下字段校验，未通过的不得进入正文写作：

### 2.1 核心承诺校验

| 字段 | 问题 | 不通过标准 |
|:---|:---|:---|
| **爽点类型** | 我的核心卖点是？（爽感/治愈/逆袭/名场面/世界观揭秘） | 未在3000字内亮出 |
| **成长路径** | 主角从什么状态→到什么状态？（弱→强/废→巅/孤→羁） | 路径模糊或读者无法预判 |
| **世界观基调** | 整体是硬核升级/轻松团宠/还是残酷生存？（必须选一） | 多重基调混杂 |
| **金手指类型** | 空间/医术/基因锁/战术AI/外骨骼？（必须唯一） | 同时存在两个以上金手指 |
| **目标赛道** | 番茄科幻/科武/狼人/短故事？（决定推荐权重） | 未定位或跨赛道未验证数据 |

### 2.2 金手指绑定校验

```
金手指 = [具体名称] 
绑定基调 = [轻松/团宠/弥补遗憾/硬核升级]
绑定方式 = [降维打击+可视化反馈+明确使用限制]

示例（科武）：
金手指 = 基因锁觉醒序列
绑定基调 = 硬核升级+阵营羁绊
绑定方式 = 每次突破消耗神经负荷+解锁反噬期+阵营追杀风险
```

**校验标准**：金手指与基调必须形成因果链。读第一章时，读者应能说出“我读这篇是为了看_____”。

### 2.3 章节任务卡（每章开写前填写）

| 字段 | 填写项 |
|:---|:---|
| **本章目标** | 推进哪条主线？（战力成长/世界观揭秘/阵营羁绊/名场面） |
| **爽点交付** | 本章给读者的“情绪满足”是什么？（逆袭/共鸣/震撼/治愈） |
| **代价伏笔** | 本章埋下什么代价？（寿命折损/神经负荷/资源枯竭/关系破裂） |
| **章末钩子** | 结尾悬念类型？（未解危机/身份反转/资源争夺/战术抉择） |
| **字数基线** | 2000-2500字（含钩子150字） |

## 三、动作链执行标准（科武版）

所有能力释放、战斗场景、科技应用必须遵循以下闭环，禁止跳过中间过程：

### 3.1 触发条件
```
触发条件 = [客观威胁/主动选择/被动卷入]
标准化描述：威胁等级+时间窗口+不可逆后果
```

**错误示例**：
> "面对敌人的围攻，林修决定突破境界。"

**正确示例**：
> "第三层甲板上还有47秒就会坍塌，而追兵的热源信号正以12米/秒的速度逼近。林修的神经接口显示：肾上腺素过载，基因锁解锁窗口剩余3次。"

### 3.2 能力/技术释放

```
释放格式 = [能力名称] + [载体] + [操作方式] + [生效延迟]
```

**示例（基因锁突破）**：
> "林修咬破舌尖，将三枚神经增幅贴片按入颈椎接口。基因锁第二序列在瞳孔中亮起红光——解码过程需要7.2秒，期间他的视觉系统将完全失灵。"

**示例（外骨骼启动）**：
> "他将右手插入战术臂环，钛合金骨架在0.3秒内完成自检包裹。小腿助推器待命，但过载保护机制要求他必须在启动后15秒内结束战斗，否则关节伺服将永久熔毁。"

### 3.3 物理/环境反馈

```
反馈层级 = 视觉+听觉+触觉+危机代价
```

**错误示例**：
> "强大的力量爆发出来，敌人被打败了。"

**正确示例**：
> "基因锁解锁的瞬间，林修的视网膜被过载信号烧灼成一片雪花噪点。能量波从他的右臂倾泻而出，将三具追踪甲兵的合金外壳融化成熔岩滴落地面——但同时，他的左眼视野永久丢失了30%的分辨率。"

### 3.4 结果/代价闭环

```
结果 = 即时胜负/资源消耗/关系变化/伏笔埋设
代价 = 必须可量化、可感知、影响后续叙事
```

**代价类型库（科武）**：

| 代价类型 | 量化方式 | 叙事功能 |
|:---|:---|:---|
| **神经负荷** | 百分比/恢复时间/后遗症 | 限制金手指滥用，保持升级稀缺感 |
| **装备损耗** | 耐久度/冷却时间/不可修复 | 增加资源管理维度 |
| **阵营仇恨** | 势力态度值/追杀等级 | 将战斗结果与世界观联动 |
| **生理代价** | 寿命折损/感官永久损失/基因序列损伤 | 提升突破的史诗感与代价感 |
| **关系代价** | 信任裂痕/情感负债/牺牲代价 | 将个人成长与羁绊绑定 |

## 四、段落节奏控制（科武版）

### 4.1 开篇节奏（前3000字）

```
第一刀（0-500字）：建立核心锚点
├── 身份锚点：主角当前处境/社会定位/核心困境
├── 金手指锚点：能力来源/限制条件/读者可预判的爽感类型
└── 基调锚点：全文是硬核升级/轻松团宠/残酷生存？

第二刀（500-1500字）：亮出第一个小爽点
├── 建立第一个可战胜的对手（测试金手指/展露能力边界）
├── 给予读者“确认购买”的满足感（逆袭/解压/技术秀）
└── 同时埋设代价/限制（不可滥用，需要成长）

第三刀（1500-2500字）：埋下第一个钩子
├── 外部威胁升级/更大势力介入/身世谜团触发
├── 金手指暴露引发连锁反应（新敌人/旧敌报复/阵营分化）
└── 主角面临二选一困境（展示决策魅力）

收尾钩子（2500-3000字）：悬念三选一
├── A类：未解危机（追兵逼近/资源枯竭/时间窗口）
├── B类：身份反转（敌人是盟友/盟友是卧底/身世揭露）
└── C类：资源争夺（核心道具/传承争夺/阵营席位）
```

### 4.2 章末钩子类型（科武版）

| 钩子类型 | 描写公式 | 示例 |
|:---|:---|:---|
| **未解危机** | 威胁+时间窗口+不可逆后果 | "装甲裂缝中渗出的不是血，而是基因崩解的前兆——他的生命还有6小时。" |
| **身份反转** | 关系+裂痕+新信息冲击 | "通讯器那头的命令不是来自联盟指挥部——而是三年前死去的师父的声纹。" |
| **资源争夺** | 稀缺物+多方势力+道德困境 | "那管基因优化剂是最后一份，但注射后他就永远无法离开这座监狱。" |
| **战术抉择** | 方案A代价/方案B代价/隐藏方案C | "左边的通道有95%概率通向出口，但那里等着的是他刚杀死之人的家属。" |

### 4.3 章节内节奏模板

```
[开篇场景建立] → [冲突触发] → [能力测试] → [危机升级] → [代价显现] → [悬念收尾]
     200字              300字        600字         400字        300字      200字

[情绪节奏]
高压场景（战斗/危机）→ 低压场景（恢复/羁绊/日常）→ 过渡场景（伏笔/信息）→ 新高压预告
```

## 五、失败模式识别（科武高发区）

### 5.1 开篇失败模式

| 失败类型 | 症状 | 自检问题 |
|:---|:---|:---|
| **身穿式无锚点** | 主角背景模糊，无法建立读者共情 | "读者知道主角是谁、在哪、要什么吗？" |
| **慢热陷阱** | 3000字内无爽点/无期待感 | "前3000字让读者想追更的理由是什么？" |
| **设定堆砌** | 前三章出现超过3个未解释的新术语 | "能否用一句话解释这个设定？" |
| **金手指失焦** | 能力展示后读者无法复述主角的核心优势 | "读者能用三个词描述主角的独特能力吗？" |
| **基调摇摆** | 前三章在硬核和轻松之间反复横跳 | "第三章的叙事节奏和第一章一致吗？" |

### 5.2 中期失败模式

| 失败类型 | 症状 | 自检问题 |
|:---|:---|:---|
| **爽点断供** | 连续5章无明显爽点/情绪高潮 | "最近五章给读者最大的满足是什么？" |
| **代价通胀** | 金手指使用无代价，或代价可忽略 | "主角突破境界后需要承担什么？" |
| **支线迷失** | 伏笔超过3个未回收，读者遗忘 | "三个月前埋的伏笔现在是否该回收？" |
| **敌人工具化** | 反派无动机、无智力、无成长 | "反派为什么是敌人？他们的核心诉求是什么？" |
| **节奏坍塌** | 章节内无冲突，沦为流水账 | "这一章能删吗？删了会损失什么信息？" |

### 5.3 结尾失败模式

| 失败类型 | 症状 | 自检问题 |
|:---|:---|:---|
| **机械降神** | 用意外事件解决冲突，非能力/决策/代价 | "这个结局是因为主角的能力/决策/牺牲，还是因为运气？" |
| **核心卖点中途更换** | 硬核科武突转日常种田/纯恋爱 | "读者追这篇的核心理由还在吗？" |
| **伏笔烂尾** | 结局前10%未回收关键伏笔 | "所有核心伏笔是否在结局前10%有交代？" |

## 六、人物口吻控制（科武版）

### 6.1 主角声纹塑造

| **残酷生存型** | 简洁/利益导向/情感隔离 | "不需要信任，只需要结果。" |

### 6.2 对话节奏控制

```
对话公式 = 立场差异→信息交换→利益博弈→关系变化

示例（科武谈判场景）：
A方："这份基因序列值多少？"（立场展示）
B方："比你的命值钱。"（信息压制）
A方："但你缺它。"（利益博弈）
B方："……七三分，额外加条件。"（关系变化）
```

## 八、平台规则转化（发布/包装/风险门禁）

### 8.1 番茄算法适配门禁

| 阶段 | 核心指标 | 作家执行动作 |
|:---|:---|:---|
| **冷启动期（0-10万字）** | 完读率/追更率/新书数据 | 日更≥4000字，不断更，章末引导互动 |
| **推荐期（10-30万字）** | 读后留存/章节评论/分享率 | 强化名场面密度，情绪高潮每5章出现一次 |
| **精品期（30万字+）** | 长效追读/IP转化潜力/版权价值 | 视觉化设定+预留改编接口+配角版权意识 |

### 8.2 发布前风险门禁

| 风险类型 | 检测项 | 通过标准 |
|:---|:---|:---|
| **政治风险** | 涉军/涉政/涉黑描写 | 主角不为军政府/黑帮核心成员 |
| **版权风险** | 品牌/专利/现实人物关联 | 使用虚构设定，不绑定现实品牌 |
| **涉暴风险** | 血腥描写/酷刑/软色情 | 限制阈值：血腥可用“能量灼伤”替代“断肢”，避免直描 |
| **平台违规** | 敏感词/违规桥段/标题党 | 通过平台敏感词检测工具自查 |

### 8.3 包装转化规则

```
标题公式 = 核心爽点 + 类型标签 + 期待感

示例（科武）：
《基因锁觉醒：我在废土杀成至强者》
《我在星际战场养成了SSS级机甲》
《师尊留给我的战术AI黑化了》

简介公式 = 世界观锚点 + 主角困境 + 核心卖点 + 情绪承诺

示例：
"林修的基因锁每次解锁都会折损寿命，但十二小时后联邦审判厅将宣判他的死刑。
要么逃亡，要么——用仅剩的解锁次数，杀穿整个星系。
这是一场用命换命的豪赌。"
```

## 九、可借点标注

### 9.1 短故事/狼人篇可借点

| 原课程点 | 转化方案 |
|:---|:---|
| **情绪价值>设定复杂度** | 狼人篇聚焦“身份认同/情感羁绊/逆袭爽感”，设定服务于情绪而非堆砌世界观 |
| **编辑拒稿=质量校准** | 短篇投稿被拒后优先检查开篇300字是否有核心钩子，而非自我怀疑 |
| **金手指绑定基调** | 狼人金手指（如血脉觉醒/异能）必须与“甜宠/爽文/治愈”情绪强绑定，避免黑暗写实偏移 |
| **章节自检清单** | 直接套用7.1节清单，短篇仅需检查前5项 |
| **代价闭环** | 狼人变身代价（如失控风险/社会排斥）需明确量化，不可无限滥用 |

### 9.2 科武长篇可借点

| 原课程点 | 科武转化方案 |
|:---|:---|
| **情绪缓冲带设计** | 硬核战斗段后插入“机甲维护/战友羁绊/基因恢复”低压场景，调节读者疲劳 |
| **金手指逻辑平移** | 将“空间/医术”替换为“基因锁/外骨骼/灵能科技/战术AI”，保留“降维打击+可视化反馈+明确限制”爽感结构 |
| **拆解阅读法** | 编辑要求的开篇/伏笔/转场拆解直接用于科幻设定铺陈、战力体系构建、世界观揭秘节奏控制 |
| **平台算法适配** | 稳定日更+前3万字强钩子+章末互动引导，对番茄科幻/科武频道推荐权重同样有效 |
| **10万字冷启动** | 科武长篇需更强的开篇期待感（推荐值更高），建议前3章内至少2次小爽点测试 |
| **名场面密度** | 科武长篇需更密集的“机甲对决/基因突破/战术博弈”名场面，建议每5-8章一个高光时刻 |

## 十、作家OS补丁执行流程

```
开篇前 → 填写任务卡字段（2.1/2.2/2.3）→ 校验通过 → 进入正文

写作中 → 每章遵循动作链闭环（第三章） → 段落节奏（第四章） → 人物口吻（第六章）

完稿后 → 执行章节自检清单（第七章） → 不通过则打回重写 → 通过则检查平台规则（第八章）

发布后 → 监控数据反馈（完读率/追更率） → 根据数据迭代下一卷结构 → 拆解同赛道爆款持续优化
```

---

> **核心提醒**：曲梨瑶两年“天翻地覆”的本质是完成了一次认知跃迁——从“我想写什么”到“读者需要什么”。作家OS补丁的目标是将这种认知固化为可执行、可校验、可迭代的系统操作，而非依赖灵感或情绪。
> 
> **执行优先级**：爽点交付>设定完整>文笔精致。任何情况下，读者情绪满足优先于作者表达欲。
