## 一、写作前任务卡字段更新

每次开写新章节前，完成以下字段填写：

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **本章目标** | 一句话，主角要完成什么具体动作 | 主角尝试用三代神经接驳破解防线，却发现带宽不足 |
| **核心阻碍** | 三选一：技术瓶颈/资源缺口/信息差 | 算力配额被临时冻结，需在90分钟内完成 |
| **代价预设** | 写前列明本次行动将付出的明确代价 | 神经负荷超标→短期无法再使用接驳；信用点透支→下月装备维护费无法支付 |
| **反馈设计** | 本章必须出现的物理感官细节≥3处 | 视网膜边缘出现青色雪花点；散热系统发出金属疲劳的吱嘎声；后颈神经接口传来灼烧刺痛 |
| **章末钩子** | 本章结束前必须埋入的元素 | 破解成功但数据包里出现不属于目标系统的加密层 |
| **矛盾索引** | 当前卷矛盾链位置 | 本章收尾旧矛盾（A线：配额争夺），已埋设新矛盾（B线：异常数据源追踪） |

## 二、章末钩子配方卡（可直接套用）

> 每章结尾从以下配方中选一种，确保钩子与主线强关联

| 钩子类型 | 执行动作 | 科武语境示例 |
|:---|:---|:---|
| **未解矛盾暴露** | 本章结尾让新信息推翻主角原有判断 | 破解成功后发现对方是故意开放的后门 |
| **技术反噬预警** | 成功行动后立即出现负面连锁反应 | 接驳破解成功，但系统已记录MAC地址 |
| **盟友倒计时** | 信任对象出现背叛或立场动摇信号 | 搭档突然要求查看刚获取的数据包 |
| **资源代价浮现** | 前期忽略的代价以滞后方式呈现 | 三小时后神经接口开始异常放电 |
| **外部变量闯入** | 与主线无关的异常事件打断当前节奏 | 频道里突然出现从未登记过的加密信号 |
| **规则漏洞暴露** | 现有秩序出现可利用/不可逆的裂痕 | 发现配额冻结是上层派系斗争的结果 |

## 三、段落节奏模板（每千字结构）

```
【第1-300字：行动启动】
- 主角明确目标+简短阻碍描述
- 激活感官细节（视觉/听觉/触觉三选二）
- 禁止：长篇设定说明

【第300-600字：执行受阻】
- 第一次阻碍出现（技术/资源/信息三选一）
- 主角尝试推演解决方案
- 伴随物理反馈（装备/身体/环境）

【第600-900字：代价支付】
- 主角选择承担某种明确代价换取进展
- 代价必须是可量化的（时间/金钱/身体/关系）
- 代价立即引发连锁反应

【第900-1000字：章末钩子】
- 旧矛盾收尾
- 新矛盾/变量植入
- 以悬念性动作/信息收束
```

## 五、失败模式警示灯（写前必检）

> 出现以下模式，本章/本卷大概率数据下滑

| 失败模式 | 判定标准 | 修复动作 |
|:---|:---|:---|
| **机械降神** | 主角破局依赖外部突然介入（系统赠送/高人指点/运气逆转） | 删除该段落，改为技术推演+代价交换 |
| **代价真空** | 技术突破/胜利后无任何代价记录 | 补写资源消耗/身体反馈/关系代价 |
| **设定堆砌** | 单段落出现≥3个新科武术语而无感官反馈 | 拆分术语，每术语配一感官细节 |
| **工具人反派** | 反派动机全为"阻挠主角"而非现实利益逻辑 | 重写反派背景，给予独立利益诉求 |
| **矛盾断层** | 章末无钩子/钩子与主线无关 | 按"章末钩子配方卡"补写 |
| **节奏跳步** | 关键推演/决策环节被"省略"或"直接跳过" | 拆解为具体操作步骤，补写推演过程 |
| **无敌流倾向** | 主角连续三章无代价突破 | 强制插入资源缺口或身体预警 |
