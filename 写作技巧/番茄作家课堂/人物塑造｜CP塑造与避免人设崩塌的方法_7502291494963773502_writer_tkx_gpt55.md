# 《科武纪元》作家OS补丁  
## 补丁名：CP/核心关系塑造与人设防崩塌执行包

适用范围：  
- 《科武纪元》长篇主线人物、阵营、师徒、双雄、男女主、宿敌关系。  
- 短故事/狼人篇中的身份对抗、阵营误判、反转关系。  
- 发布包装、人物标签、风险门禁。

---

# 0. 本补丁写作目标

写人物时，不再问：

> “这个人是好是坏？”

改问：

> “他想要什么？”  
> “他站在哪边？”  
> “他为了什么可以越线？”  
> “他和另一个人为什么必然冲突，又为什么离不开彼此？”

所有核心关系必须同时具备：

1. **天然冲突**：不靠临时误会，而是人设结构自带矛盾。  
2. **致命吸引**：不是硬贴感情，而是对方拥有自己无法绕开的价值。

# 1. 作家执行原则：关系先行

## 1.1 新建角色前，先建“关系单位”

不要先写：

> A是冷面科学家，B是热血武者。

要先写：

> A和B是什么关系？  
> 他们为什么必然互相否定？  
> 他们为什么又必须合作？

### 可执行格式

```text
关系单位：
A × B

关系类型：
宿敌 / 师徒 / 同门异道 / 阵营敌对 / 共同求生 / 互为实验对象 / 互为唯一验证者

天然冲突：
A相信____，B相信____。

致命吸引：
A只有通过B才能____。
B只有通过A才能____。

本关系第一场戏必须看见：
1. 冲突动作：____
2. 吸引证据：____
```

# 2. 《科武纪元》关系拓扑表

## 2.1 科武长篇可借点

| 关系组合 | 天然冲突 | 致命吸引 | 可写爽点 |
|---|---|---|---|
| 科学家 × 武者 | 科技可复制 vs 武道不可替代 | 对方是自己理论盲区 | 实验破武道，武道反证科学 |
| 联邦军官 × 宗门传人 | 秩序优先 vs 传承优先 | 必须联手对抗域外危机 | 战术与秘法互补 |
| 纪元前遗民 × 纪元后新人类 | 旧文明创伤 vs 新时代野心 | 彼此掌握断代真相 | 世界观揭露 |
| 主角 × 反派导师 | 救文明 vs 筛文明 | 反派掌握主角升级钥匙 | 师徒反杀、理念交锋 |
| 双雄 | 底线不同 | 互为唯一对手 | 一战定道心 |
| 男主/女主 | 理性极端 vs 直觉极端 | 对方能补全认知模型 | 共同破局、克制糖点 |

# 3. 短故事/狼人篇可借点

狼人篇适合借用“身份冲突 + 致命吸引 + 立场误判”。

## 3.1 可直接使用的关系模型

### 模型一：猎人 × 狼人

```text
天然冲突：
猎人职责是清除狼人。
狼人必须隐藏身份求生。

致命吸引：
猎人发现狼人没有失控，反而掌握真正凶手线索。
狼人发现猎人是唯一不会立刻告发自己的人。

段落动作：
1. 猎人发现异常。
2. 狼人暴露半个破绽。
3. 猎人拔刀但没有杀。
4. 狼人救下猎人或提供关键线索。
5. 章末留下身份钩：猎人要不要上报？
```

### 模型二：村民领袖 × 被怀疑者

```text
天然冲突：
领袖要维护集体安全。
被怀疑者要证明自己不是怪物。

致命吸引：
领袖需要被怀疑者的夜视/嗅觉/禁忌知识。
被怀疑者需要领袖压住暴民。

失败模式：
如果只写“村民无脑恶毒”，人物扁平。
应改成：
村民害怕孩子被咬，领袖必须牺牲少数保多数。
```

### 模型三：狼人 × 真凶

```text
天然冲突：
狼人背负怪物名声。
真凶利用狼人身份嫁祸。

致命吸引：
真凶知道狼人失控原因。
狼人必须接近真凶找解药或真相。

章末钩子：
狼人发现真凶身上有自己的血。
```

# 4. 人物卡补丁：每个有名字角色必须补三项

## 4.1 禁止定义

禁止这样写：

```text
她是坏女人。
他是好人。
这个反派很邪恶。
这个女配嫉妒女主。
```

## 4.2 必须改成

```text
底层行为逻辑：
他/她永远优先保护____。

核心欲求：
他/她当前最想得到____。

当前立场：
他/她站在____一边，反对____。

底线：
他/她绝不会____，除非____。

越线条件：
当____发生时，他/她会做出看似反常的选择。
```

# 5. 人设标签执行规则

## 5.1 标签数量

每个主要角色只保留 **2—3个标签**。

### 示例

```text
主角：
1. 理性极端
2. 不信神秘
3. 文明保全执念

女主/搭档：
1. 直觉极端
2. 武道感知天才
3. 不服联邦规训
```

## 5.2 爽点必须落在标签上

如果主角标签是“理性极端”，爽点就要写：

- 他用模型拆穿神迹。  
- 他用数据预判宗门秘术。  
- 他把敌人的武学当成可复现实验。

不要突然写：

- 他靠热血大吼赢了。  
- 他临时顿悟神秘力量。  
- 他无理由相信玄学。

除非提前埋过“理性崩塌后重建”的代价链。

# 6. 冲突生成器：每对重要关系至少占2层

写冲突时，从下面六层选至少两层。

```text
1. 三观：
科技观 vs 武道观
个体自由 vs 文明存续
牺牲少数 vs 拯救所有人

2. 立场：
联邦 vs 宗门
人类本土 vs 域外势力
旧纪元遗民 vs 新纪元政权

3. 社会身份：
军官 vs 散修
实验体 vs 研究员
宗门继承人 vs 联邦通缉犯

4. 伦理身份：
师徒
血亲
救命恩人
仇人之子

5. 阶级：
修者 vs 凡人
基因优化者 vs 普通人
核心城居民 vs 废土流民

6. 人生经历：
经历过文明湮灭
亲人死于武者暴乱
童年被联邦实验室收容
从小被宗门当容器培养
```

## 6.1 执行例

```text
角色A：联邦科学官
角色B：宗门武道天才

冲突层：
三观：A认为武道可被拆解，B认为武道不可被亵渎。
立场：A服务联邦，B守护宗门秘传。
人生经历：A亲眼见过宗门失控屠城，B见过联邦实验害死同门。

致命吸引：
A需要B证明“武道感知场”真实存在。
B需要A破解体内旧纪元武印。
```

# 7. 场景写法补丁：冲突必须物理化

不要只写心理独白：

> 他很愤怒。  
> 她感到被冒犯。  
> 两人的理念发生冲突。

必须写成可观察反馈。

## 7.1 物理反馈库

### 表情反馈

```text
瞳孔收缩
嘴角压平
下颌绷紧
笑意消失
视线避开又立刻钉回去
```

### 动作反馈

```text
按住刀柄
关闭实验舱
撕掉授权书
把芯片捏碎
把药剂推回去
停止疗伤
后退半步
挡在某人身前
```

### 科武反馈

```text
义体过载报警
武脉震颤
纳米修复液变黑
精神力场出现噪点
战甲自动进入防御模式
实验屏幕数据暴涨
灵能纹路逆流
```

### 环境反馈

```text
舱室灯光闪烁
低温舱结霜
训练场地面裂开
宗门钟声无风自响
警报红光扫过两人的脸
```

# 8. 段落节奏补丁

## 8.1 单章关系节奏建议

一章内不要只有吵架，也不要只有发糖/合作。

推荐结构：

```text
1. 目标段：角色带着欲求进入场景。
2. 冲突段：关系矛盾爆出。
3. 物理反馈段：动作/科技/武道反应证明冲突真实存在。
4. 选择段：角色按底层逻辑做决定。
5. 代价段：选择造成损失。
6. 缓冲段：给一点互相理解、信息交换或共同危机。
7. 钩子段：留下关系/立场问题。
```

## 8.2 冲突与缓冲比例

### 科武长篇

```text
主线推进：50%
冲突/关系：25%
世界观/解谜：20%
轻微糖点/缓冲：5%
```

### 短故事/狼人篇

```text
身份悬疑：35%
关系张力：35%
危机动作：20%
反转钩子：10%
```

# 9. 代价补丁：每次选择必须付费

角色不能白拿成长、白得信任、白赢冲突。

## 9.1 代价类型

```text
关系代价：
被同伴怀疑、被导师放弃、与宗门决裂。

资源代价：
失去药剂、芯片、战甲能源、实验权限、修炼名额。

身体代价：
武脉受损、义体烧毁、精神污染、基因崩坏。

信念代价：
承认敌人是对的、承认自己理论有漏洞、放弃“不牺牲任何人”的承诺。

身份代价：
暴露狼人身份、暴露旧纪元遗民身份、暴露联邦卧底身份。
```

## 9.2 执行句式

```text
他选择____，因此失去____。
她为了守住____，不得不牺牲____。
这次胜利让他们得到____，但关系变成____。
```

# 10. 失败模式与修复方案

## 10.1 失败模式一：冲突靠误会硬塞

### 症状

- 两人明明可以解释，却偏不解释。
- 冲突只为拖剧情。
- 读者觉得角色降智。

### 修复

把误会改成立场冲突。

```text
错误：
她误会男主杀了师兄。

修复：
她知道男主不是凶手，但男主的实验技术会让宗门秘法公开化。
所以她必须阻止他。
```

---

## 10.2 失败模式二：反派只会添堵

### 症状

- 反派每章出现只为阻止主角。
- 没有自己的目标。
- 行为像剧情工具。

### 修复

给反派欲求与底层逻辑。

```text
反派底层逻辑：
文明不能靠怜悯延续，只能靠筛选。

当前欲求：
启动“火种淘汰计划”。

与主角冲突：
主角要保存所有文明样本。
反派只保留高适应样本。
```

---

## 10.3 失败模式三：人设反差变崩塌

### 症状

- 冷静角色突然恋爱脑。
- 理性角色突然无脑冲。
- 善良角色突然残忍无解释。

### 修复

每个反差行为前后补“底层逻辑”。

```text
看似崩塌：
理性主角冲进爆炸区救人。

自洽解释：
他救的不是一个人，而是唯一能证明域外污染模型的人。
他不是热血冲动，而是在保全关键证据。
```

---

## 10.4 失败模式四：女性角色冲突变雌竞

### 症状

- 女配只因嫉妒女主而作恶。
- 女性角色互害只围绕男人。
- 平台读者容易反感。

### 修复

改成资源、立场、理念冲突。

```text
错误：
女配嫉妒女主被男主喜欢。

修复：
女配认为女主的武道方案会害死整支小队。
她阻止女主，是因为她选择“稳定存活率”，不是因为争宠。
```

---

## 10.5 失败模式五：糖点过密，稀释科武主线

### 症状

- 主线暂停，只剩暧昧。
- 世界观推进断档。
- 读者觉得题材变味。

### 修复

糖点必须服务破局。

```text
错误：
两人单独谈心三千字。

修复：
两人在修复战甲时交换伤痕信息。
女主一句话点破武脉异常。
男主借此修正模型。
关系升温，同时推进解谜。
```

# 11. 人物口吻补丁

人物口吻要贴底层逻辑，不要所有人都像作者。

## 11.1 理性极端者

```text
“我不需要你相信我，我需要数据闭环。”
“愤怒不会改变误差值。”
“如果牺牲不可避免，至少别让它变成无效样本。”
```

## 11.2 武道直觉者

```text
“你的仪器没错，但它太慢了。”
“我不是感觉到危险，我是听见骨头在害怕。”
“道理可以明天讲，人现在要活。”
```

## 11.3 联邦秩序派

```text
“个人意志必须让位于防线。”
“我可以同情你，但授权不会因为同情改变。”
“你救一个人，我要负责一座城。”
```

## 11.4 宗门传承派

```text
“秘法不是技术，是祖师拿命换来的边界。”
“你可以质疑我，但不能拆我宗门的骨。”
“传承断了，人还活着也只是空壳。”
```

## 11.5 反派筛选派

```text
“我没有毁灭文明，我只是在删除无法延续的版本。”
“怜悯是旧纪元失败的原因。”
“你救下他们，只是让他们死在下一次潮汐里。”
```

## 11.6 狼人篇狼人角色

```text
“我怕的不是月亮，是你们看见月亮后的眼神。”
“如果我是怪物，为什么每次死的都不是我想杀的人？”
“别靠近。锁链不是困住我的，是保护你们的。”
```

# 12. 章末钩子补丁

章末不要只留事件钩：

> 门开了。  
> 爆炸了。  
> 怪物来了。

要升级成关系钩或立场钩。

## 12.1 关系钩

```text
她终于发现，救她的人正是她奉命要杀的人。
```

```text
男主把唯一解药推给敌人，自己关上了隔离舱。
```

```text
猎人没有上报狼人身份，只在档案上写下：目标已死亡。
```

## 12.2 立场钩

```text
联邦命令下达：销毁宗门全体感染者。
而主角刚刚确认，其中三人还有逆转可能。
```

```text
反派递来完整模型：
“你看，按照你的算法，也该牺牲他们。”
```

```text
女主拔刀挡在宗门门前：
“你再往前一步，我就不再是你的队友。”
```

## 12.3 认知钩

```text
实验屏幕上，主角的理论被彻底验证。
唯一的问题是，验证者不是人类。
```

# 14. 章节自检清单

提交章节前，逐条检查。

## 14.1 人物自检

```text
1. 本章每个有名字角色，是否能说清：
   底层行为逻辑 / 核心欲求 / 当前立场？

2. 是否有人只被写成“好人”“坏人”“恶毒”“圣母”？
   如果有，改成“欲求+立场+选择”。

3. 角色做出反常行为时，是否能回溯到底层逻辑？

4. 人物标签是否超过3个？
   如果超过，删除不服务本卷爽点的标签。

5. 本章爽点是否落在人物标签上？
```

## 14.2 关系自检

```text
6. 核心关系是否同时有：
   天然冲突 + 致命吸引？

7. 冲突是否来自三观/立场/身份/阶级/经历？
   还是靠误会、巧合、临时吵架硬塞？

8. 本章关系是否发生了可感知变化？
   信任+1 / 信任-1 / 身份暴露 / 立场转向 / 合作破裂？

9. 副CP或副线关系，是否和主关系有结构差异？
   不要全都是“嘴硬互怼”。
```

## 14.3 场景自检

```text
10. 冲突是否有物理反馈？
    表情、动作、科技反应、武道反应、环境变化至少一种。

11. 是否有大段纯心理解释？
    如有，改成动作、对话、物理现象。

12. 本章选择是否付出代价？
    代价是否由本人承担，而不是配角无偿买单？

13. 冲突段与缓冲段是否失衡？
    是否吵太久，或甜太久，或解释太久？
```

## 14.4 章末自检

```text
14. 章末是否有关系钩或立场钩？
    不能只有“怪物来了”。

15. 读者下一章想看的是否是：
    “他/她会怎么选？”
    而不仅是：
    “接下来发生什么？”

16. 本章是否兑现了一个旧预期，并埋下一个新预期？
```

## 14.5 平台风险自检

```text
17. 女性角色冲突是否容易被读成雌竞？
    如是，改为立场、资源、理念冲突。

18. 是否出现无脑恶毒女配？
    如是，补她的欲求、立场、底线。

19. 是否出现强绑恋爱设定？
    如血液救命、命定唯一、无理由绑定。
    科武主线慎用，尽量改成理念/能力/认知互需。

20. 是否有伦理梗稀释科武调性？
    如伪骨科、叔嫂恋、强制恋爱。
    主线禁用，最多番外/支线谨慎处理。
```

# 15. 发布/包装/风险门禁

平台规则不直接当剧情写，要转成发布、包装、风险控制。

## 15.1 发布包装可用

人物标签要清晰，方便读者识别。

### 可包装标签

```text
理性疯批科学家
武道直觉天才
联邦冷面军官
宗门叛逆继承人
旧纪元幸存者
文明保全执念者
反派导师
双强宿敌
理念互杀型搭档
```

### 不建议包装

```text
恶毒女配
恋爱脑女主
无脑反派
傻白甜
靠血绑定
霸总式强控
```

## 15.2 简介/标题风险门禁

避免把女性角色冲突包装成争宠、撕逼、雌竞。

### 错误包装

```text
两个女人为男主反目成仇。
恶毒师姐嫉妒女主天赋，处处陷害。
```

### 安全包装

```text
她们一个要保全宗门，一个要公开秘法。
当文明危机降临，二人必须在传承与真相之间做选择。
```

# 16. 《科武纪元》禁用/慎用清单

## 16.1 主线禁用

```text
1. 为恋爱强行降智。
2. 为冲突制造不解释误会。
3. 反派无欲求，只负责送经验。
4. 女配只因嫉妒女主而作恶。
5. 血液/体质救命式强绑定。
6. 傻白甜 × 高冷总裁式低适配模板。
7. 高密度撒糖压过科武主线。
```

## 16.2 可支线慎用

```text
1. 由恨生爱：
   可用于敌对阵营合作，但必须先有理念互需。

2. 强身份伦理：
   可用于师徒、救命恩人、仇人之子，不建议写擦边伦理恋。

3. 甜点：
   可作为战后缓冲、共同破局后的关系回报，不可变成本章主梁。
```

# 17. 一章执行样板

```text
本章核心关系：
主角 × 宗门女武者

天然冲突：
主角认为武道秘法必须公开建模，才能抵御域外污染。
女武者认为秘法公开会毁掉宗门根基。

致命吸引：
主角需要她的武道感知捕捉污染源。
她需要主角的模型救被污染的师弟。

动作链：
目标：主角进入宗门禁地取样。
受阻：女武者拔刀阻止。
选择：主角公开自己旧伤数据，证明污染已扩散。
代价：暴露自身曾被域外污染，失去联邦监察官信任。
新状态：女武者暂时放行，但要求全程监视。

物理反馈：
她拔刀时，刀身上的武纹逆流。
主角义眼报警，显示污染频率与她师弟一致。
禁地铜钟无风自鸣。

章末钩子：
女武者发现主角体内的污染源，和宗门祖师遗骸完全同频。
她问：
“你到底是来救我们，还是来唤醒他？”
```

# 18. 最小执行版

如果赶稿，只记这七条：

```text
1. 先定关系，再写个人。
2. 每组核心关系必须有天然冲突 + 致命吸引。
3. 每个有名字角色必须有底层逻辑、欲求、立场。
4. 冲突从三观/立场/身份/阶级/经历里长出来。
5. 角色每次选择都要付出代价。
6. 冲突必须物理化，别全靠心理独白。
7. 章末留“他/她会怎么选”的钩子。
```
