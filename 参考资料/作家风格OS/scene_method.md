# 场景展开法

## 一场戏最少四层

1. 环境压力：噪声、温度、光、空间、时间限制。
2. 行动链：角色做了什么，失败了什么，再试什么。
3. 反馈链：仪表、日志、身体、对手反应。
4. 代价：体力、资源、时间、信誉、伤亡、暴露风险。

## 技术段落展开

- 先写操作：插线、开权限、跑脚本、调频、换电池。
- 再写反馈：延迟、错误码、波形、温度、丢包率。
- 再写判断：谁看懂，谁不信，谁承担后果。

## 战斗段落展开

- 视距
- 掩体
- 火力方向
- 通讯延迟
- 误判代价
- 撤退路线

## 情绪与爆点

写情绪不写标签。
路径固定：身体反应 → 意识误差 → 外界反馈 → 行为选择。

三级爆点：
- A级：代价揭示/误判兑现/关系断裂，读者需要停一下。
- B级：伏笔回响、权限变化、名单变化、坐标变化。
- C级：仪表、停顿、对话空白、身体反馈。

## 章末钩子

不是口号。
必须给一个可见变化：
- 新告警亮起。
- 某个权限被打开。
- 一条名单多出一个名字。
- 无人机失联。
- 通讯延迟突然变短/变长。
- 话说一半。
- 动作停住。
- 视角反转。
- 屏幕出现新字段。
