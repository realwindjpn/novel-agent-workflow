# 《科武纪元》作家OS补丁：书名驱动写作模块

## Patch ID
**TITLE-ENGINE-001｜书名即契约补丁**

## 适用范围
- 《科武纪元》长篇主线
- 短故事 / 狼人篇 / 热点稿
- 章节名、简介、封面文案、推荐语、短视频钩子

---

# 一、核心执行指令

## 1. 书名不是装饰，是“读者契约”

每次起书名、章名、短篇标题时，必须回答：

> 读者点进来，是为了看什么被兑现？

书名必须在正文中形成：

```text
书名承诺 → 前3章兑现 → 章节反复强化 → 章末继续欠账
```

如果书名里写了：

- 数字：正文必须出现对应的可见数量、读数、倒计时、计量单位。
- 金手指：主角必须实际使用，不可只解释设定。
- 反差：必须让读者看到两种力量/身份/秩序正面碰撞。
- 情绪词：第一幕就要有该情绪，不可拖到后面。
- 题材词：前3章必须让读者确认这是对应题材。

# 二、可执行动作链

## A. 起书名前动作

### Step 1：锁定读者筛选词

从以下四类里至少选两类：

| 类型 | 可选词方向 | 科武适配 |
|---|---|---|
| 题材词 | 科武、废土、星际、武道、机甲、基因、灾变 | 必选或强暗示 |
| 身份词 | 学徒、武者、研究员、军校生、流民、实验体 | 推荐 |
| 核心梗 | 数据化丹田、公式练武、纳米经脉、战甲入圣 | 强推荐 |
| 人设词 | 废柴、冷血、疯批、天才、底层、叛逆 | 至少命中一个 |

### Step 2：确定一个主视觉锚点

每个书名只选一种，不要全塞：

```text
数字 / 冒号 / 感叹号 / 反差短语 / 金手指名词
```

科武长篇优先：

```text
冒号 + 核心梗
数字 + 科学单位
反差短语
```

短故事 / 狼人篇可用：

```text
救命！
出大事了！
具体身份反差
猎杀倒计时
```

---

## B. 书名落地动作链

每个标题必须能反推一条主角动作链：

```text
触发 → 执行 → 反馈 → 代价 → 新钩子
```

### 示例：科武长篇

标题方向：

> 《科武纪元：我的丹田有物理引擎》

动作链：

1. 触发：主角丹田被宗门判定为废脉。
2. 执行：他用旧实验室设备扫描经脉共振频率。
3. 反馈：丹田出现可计算转速、热量、能量转化率。
4. 代价：每运行十分钟烧毁一枚能量芯片，并损伤神经传导。
5. 新钩子：仪器显示，他的丹田不是废脉，而是“未授权引擎”。

### 示例：短故事 / 狼人篇

标题方向：

> 《救命！我验尸的狼人还在呼吸》

动作链：

1. 触发：主角接到一具狼人尸体。
2. 执行：切开胸腔做死亡确认。
3. 反馈：银刀熔化，心脏重新跳动。
4. 代价：主角被咬伤，感染倒计时开始。
5. 新钩子：监控显示，狼人死前喊的是主角名字。

# 三、物理反馈模块

## 强制规则

科武世界里，能力不能只写：

```text
他感觉气息流转。
他感到灵魂震颤。
他隐约悟了。
```

必须补一层可观察反馈：

```text
仪器读数
温度变化
电流噪声
肌肉撕裂
骨骼应力
能量损耗
光谱偏移
机械报警
```

## 可直接套用的反馈句式

### 科武长篇可借点

```text
腕表上的心率从九十跳到一百八。
丹田区域的热成像亮成白色。
检测仪连续三次报错：未知能量源。
金属地面被他的步伐踩出蛛网裂纹。
经脉扫描图上，原本断裂的线条开始按公式重连。
```

### 短故事 / 狼人篇可借点

```text
银针刚刺入皮肤，针尖立刻变黑。
尸袋内部传来第二次呼吸声。
月光照进来时，伤口边缘长出灰毛。
验血仪没有显示血型，只显示：非人类。
门外的狗群同时停止吠叫。
```

# 四、代价模块

## 强制规则

标题越夸张，代价越要清楚。

不能只写：

```text
他变强了。
他付出了很多。
他有些疲惫。
```

必须写成：

```text
消耗什么？
单位是什么？
多久恢复？
如果透支会怎样？
```

## 代价字段

每个金手指 / 爽点必须绑定至少一项代价：

| 代价类型 | 单位 | 后果 |
|---|---|---|
| 能源 | 焦耳、晶核、电量、芯片数 | 无法连续战斗 |
| 身体 | 心率、骨密度、肌肉撕裂率、寿命 | 反噬、残疾、死亡 |
| 精神 | 注意力时长、记忆损耗、梦境污染 | 失控、人格分裂 |
| 社会关系 | 信任值、通缉等级、债务 | 被追捕、被背叛 |
| 材料 | 合金、药剂、实验体样本 | 卡升级、引发争夺 |
| 时间 | 倒计时、冷却期、恢复周期 | 错过救援或战机 |

## 可执行句式

```text
这一次运转只持续了七秒。
代价是三枚能量芯片烧穿，左臂神经传导下降百分之十二。
如果十二小时内再次启动，他的手会先于敌人报废。
```

# 五、失败模式库

## 1. 标题党失败

### 症状

书名写了金手指，但前三章只在解释背景。

### 修复

第一章必须出现一次小规模使用。

```text
哪怕只能点亮仪器、打碎一块测试钢板、救下一人，也要让读者看到“标题是真的”。
```

---

## 2. 热词污染失败

### 症状

为了流量硬塞：

```text
赘婿、四合院、甜宠、年代、霸总、真假千金
```

导致科武读者误判题材。

### 修复

科武长篇标题禁用不匹配热词。

可以使用：

```text
废土、星际、武道、基因、机甲、实验体、灾变、纪元
```

---

## 3. 数字无兑现失败

### 症状

标题写：

```text
三秒成神
五分钟无敌
十万倍增幅
```

正文没有计时、没有读数、没有代价。

### 修复

数字必须落地成物理事件。

```text
三秒内发生了什么？
仪器如何记录？
敌人如何反应？
主角损失了什么？
```

---

## 4. 书名与正文节奏不匹配

### 症状

书名很爽，正文慢热五章。

### 修复

标题越夸张，升级反馈越密。

```text
每章至少兑现一个小反馈。
每3章必须完成一次“承诺偿还”。
```

---

## 5. 抽象搞怪削弱史诗感

### 症状

长篇主线标题过于口水化：

```text
我这么练武很合理吧？
```

会削弱《科武纪元》的纪元级质感。

### 修复

这类标题只给番外、短篇、热点稿使用。

长篇主线保持：

```text
科武感
纪元感
硬设定感
命运压迫感
```

# 六、人物口吻补丁

## 科武长篇人物口吻

### 主角口吻

关键词：

```text
冷静、计算、压抑、克制、反骨
```

句式：

```text
“别叫它气感，叫能量泄漏。”
“心法可以错，读数不会。”
“如果神明存在，那它也该遵守热力学。”
```

### 科研型配角口吻

```text
“你的丹田不是坏了，是我们现有模型解释不了。”
“别动。你现在每呼吸一次，骨骼应力都在上升。”
“这不是突破，这是一次未经批准的人体实验。”
```

### 武道宗门角色口吻

```text
“武道靠悟，不靠这些铁疙瘩。”
“你把祖师传下来的经脉图，改成了电路图？”
“异端。可偏偏这异端赢了。”
```

---

## 短故事 / 狼人篇人物口吻

### 主角口吻

关键词：

```text
紧张、直接、带惊悚感、口语化
```

句式：

```text
“尸体刚才是不是眨眼了？”
“别开灯。月光已经够亮了。”
“报告上写他死了，可他的心脏不同意。”
```

### 狼人 / 怪物口吻

```text
“你闻起来不像医生。”
“今晚不是满月，是审判。”
“别验我的尸。验你自己的血。”
```

# 七、段落节奏补丁

## 科武长篇节奏

每个关键段落按这个顺序写：

```text
动作 → 数据反馈 → 人物判断 → 代价暴露 → 冲突升级
```

### 段落模板

```text
他把最后一枚旧芯片按进检测槽。

屏幕黑了一秒，随后跳出一串红色数值：经脉共振率，百分之一百三十七。

导师脸色变了：“正常人到八十就会内出血。”

主角低头，看见掌心皮肤正在裂开，血珠被高温蒸成白雾。

下一秒，武馆大门被人踹开。
```

---

## 短故事 / 狼人篇节奏

每段更短，反馈更快：

```text
动作 → 异常 → 恐惧 → 新危险
```

### 段落模板

```text
我把银针刺进尸体心口。

针弯了。

不是扎不进去。

是里面有什么东西，握住了针尖。
```

# 八、章末钩子补丁

## 章末钩子必须与书名同构

如果书名是：

```text
科武纪元：我的丹田有物理引擎
```

章末钩子就要持续围绕：

```text
丹田异常
物理引擎
武道与科技冲突
未知授权
```

## 章末钩子类型

### 1. 数字型钩子

```text
检测仪显示：他的丹田转速，还不到安全阈值的百分之一。
```

### 2. 反差型钩子

```text
宗门长老沉默了很久，低声说：“这不是废脉，这是兵器。”
```

### 3. 代价型钩子

```text
他赢了。
但医疗舱提示，他的左臂神经只剩下三次启动机会。
```

### 4. 身份型钩子

```text
档案最后一页写着：实验体编号001，禁止接触武道心法。
```

### 5. 危机型钩子

```text
远处的军用卫星重新校准轨道，锁定了他的丹田热源。
```

---

## 短故事 / 狼人篇章末钩子

```text
我终于看清尸检报告的最后一行。

死者姓名，是我。
```

```text
狼人咬了我一口后，没有逃。

它跪了下来，叫我王。
```

```text
月亮升到正中时，我的影子先站了起来。
```

# 十、章节自检清单

每章完成后检查。

## 基础自检

- [ ] 本章标题与主书名至少共享一个关键词或同类钩子。
- [ ] 本章兑现了一个旧承诺。
- [ ] 本章新欠下一个读者想追的承诺。
- [ ] 新欠承诺标注了预计偿还章号。
- [ ] 没有连续三页只讲设定不发生动作。
- [ ] 主角至少完成一个可见动作，而不是只听别人解释。
- [ ] 本章至少出现一次物理反馈：声、光、热、压、数据、伤害、仪器读数。
- [ ] 金手指或爽点绑定了明确代价。
- [ ] 代价有单位或可感知后果。
- [ ] 章末钩子能用一句话转述。

## 科武长篇专用自检

- [ ] 出现科技与武道的冲突、融合或误判。
- [ ] 没有用纯玄学词糊弄关键能力。
- [ ] 至少一个能力现象可被仪器记录。
- [ ] 数字、单位、公式、设备至少出现一项。
- [ ] 主角的胜利不是免费获得。
- [ ] 书名承诺在前3章内有明确兑现。
- [ ] 标题没有混入甜宠、年代、市井、赘婿等污染词。
- [ ] 章末钩子保持纪元级压迫感，而不是纯搞笑。

## 短故事 / 狼人篇专用自检

- [ ] 标题情绪在第一屏兑现。
- [ ] 开头三段内出现异常。
- [ ] 每个场景都有可见危险。
- [ ] 狼人/怪物设定通过动作暴露，不靠大段解释。
- [ ] 章末或结尾有反转：身份、感染、死亡、月亮、血统、猎人。
- [ ] 可以使用“救命！”“出大事了！”等情绪词，但不可带回科武长篇主标题。

# 十一、可借点标注

## A. 短故事 / 狼人篇可借点

可借：

```text
情绪词开头
惊悚具象冲突
身份反差
尸检、感染、倒计时
月亮、银器、血液、咬痕等视觉锚点
短句高频反馈
结尾反转
```

适用标题模板：

```text
救命！我验尸的狼人还在呼吸
出大事了！我的病人今晚会变狼
满月前夜，我发现猎人档案写着我的名字
我被狼人咬后，猎人开始保护我
```

不适合带回主线的点：

```text
过度口语化标题
强情绪感叹号
纯猎奇噱头
不解释规则的怪物爽点
```

---

## B. 科武长篇可借点

可借：

```text
题材前缀：科武、纪元、灾变、星际、废土
金手指入题：数据化丹田、物理引擎经脉、公式武道
反差结构：实验室 vs 宗门，公式 vs 心法，科技 vs 神通
具体数字：纳米、光年、G值、瓦特、心率、倒计时
标题、简介、章名关键词统一
```

适用标题方向：

```text
科武纪元：我的丹田有物理引擎
科武：从废脉到星舰武神
科武纪元：我用公式拆了神通
科武纪元：一拳打出核聚变
科武：经脉扫描仪说我不是人
```

慎用：

```text
救命！
出大事了！
很合理吧？
离谱！
```

这些更适合番外或短篇引流稿。

# 十二、发布 / 包装 / 风险门禁

平台规则不直接写进正文，要转成发布前门禁。

## 1. 发布门禁

发布前检查：

- [ ] 书名不超过15字，副标题可辅助但不能冗长。
- [ ] 无生僻字，能口播。
- [ ] 命中题材 / 身份 / 核心梗 / 人设至少两类。
- [ ] 标题中的钩子前3章必兑现。
- [ ] 书名、简介首句、封面文案、前5章章名关键词一致。
- [ ] 章节名不要和正文内容脱节。
- [ ] 推荐语不另起一套卖点，必须拆书名关键词。

---

## 2. 包装门禁

封面、简介、章名统一使用同一组关键词。

### 示例

书名：

```text
科武纪元：我的丹田有物理引擎
```

封面主词：

```text
丹田引擎
公式练武
废脉启动
```

简介首句：

```text
林烬被判定为废脉那天，实验室检测仪却显示：他的丹田正在启动一台未知物理引擎。
```

前5章章名示例：

```text
第1章 废脉启动
第2章 丹田转速
第3章 公式练武
第4章 引擎过载
第5章 宗门判定：异端
```

---

## 3. 风险门禁

以下情况禁止发布或必须重改：

### 标题风险

- [ ] 标题承诺正文无法兑现。
- [ ] 标题热词吸引的是错误读者。
- [ ] 标题像女频甜宠 / 年代 / 赘婿，但正文是科武。
- [ ] 标题用了夸张数字，却没有物理解释。
- [ ] 标题超过15字且不顺口。
- [ ] 标题里同时塞数字、冒号、感叹号，视觉锚点过载。

### 正文风险

- [ ] 前3章没有兑现书名钩子。
- [ ] 金手指只被解释，没有被使用。
- [ ] 爽点没有代价。
- [ ] 代价没有单位。
- [ ] 能力全靠“感觉”“顿悟”“灵识”。
- [ ] 章末没有追读钩子。
- [ ] 读者欠账超过5章未偿还。

# 十四、一句话总规则

> 书名负责筛人，正文负责兑现，章末负责继续欠账。  
> 科武长篇要用数据和代价兑现爽点；短故事 / 狼人篇要用情绪和异常兑现点击。
