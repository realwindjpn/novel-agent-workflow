## 一、作家任务卡·字段更新协议

> **填写规范**：每次动笔前须完成以下字段更新，禁止“凭感觉开写”。

### 1.1 当前章节任务卡（单章级）

| 字段 | 填写内容 | 触发条件 |
|:---|:---|:---|
| **本章核心动作** | [ ] 执行哪个具体动作链？（感知→决策→执行→反馈四步缺一不可） | 必填 |
| **代价绑定** | [ ] 本章消耗什么？下一章能否转化为新的剧情推力？ | 主角关键决策时必填 |
| **物理反馈校准** | [ ] 本章涉及的超规格能力/科技是否有量化反馈？（过载/扭曲/衰减/疲劳） | 涉及机甲/能量/科技时必填 |
| **情绪钩子位置** | [ ] 章内第几段埋设？章末钩子类型（信息差/状态危机/坐标锁定）？ | 必填 |
| **数据预期** | [ ] 本章完成后追读/读完率预期是多少？触发审查的阈值是多少？ | 日更时必填 |

**示例模板**：
```
章节编号：第47章
核心动作：林枫神经接驳同步率突破85%临界点，尝试越级操控战术机甲
代价绑定：同步时长超过180秒将导致神经不可逆损伤，本章结束时埋设“左臂痉挛+视野雪花点”伏笔
物理反馈校准：机甲能量回路过载预警、关节驱动单元温度红线、神经负荷指数82%
情绪钩子：章末——通讯频道接入未知加密信号，坐标指向导师消失的星域
数据预期：追读较上章提升3%，读完率≥75%为合格线
```

## 二、章节自检清单（写作后/发布前执行）

> **使用时机**：草稿完成后、发布前、存稿审核时。

### 2.1 通过门禁（全部通过方可发布）

- [ ] **动作链闭环**：战斗/科技操作是否完成“感知→决策→执行→反馈”四步？是否有跳跃式描写？（如：机甲启动→开火，中间缺省步骤）
- [ ] **代价显化**：本章关键突破/越级战斗是否支付明确代价？代价是否在下一章可追踪？
- [ ] **物理反馈存在**：超规格能力/科技是否附带可量化环境或机体反馈？（禁止无消耗施法/无代价跃迁）
- [ ] **钩子有效性**：章末钩子是否为“信息差钩子”或“状态危机钩子”？禁止纯抒情/日常流水账/开放式留白收尾。

### 2.2 数据预警门禁（触发任一条需24小时内复盘）

- [ ] 本章较上章追读下跌超过5%？
- [ ] 读完率低于75%？
- [ ] 连续3章数据未回升？

### 2.3 平台规则门禁（发布前必查）

- [ ] 日更节奏是否稳定？存稿是否≥5章？
- [ ] 是否出现平台风险词/敏感题材跨界？（科武题材注意：武器描写/战争场景/政治隐喻边界）
- [ ] 50万/100万字节点前是否已报备大纲换挡方案？

## 三、可执行动作模块库

### 3.1 开篇模块（科武长篇适用）

**触发条件**：新书/新卷/新地图开篇

```
动作序列：
1. 前300字：抛出核心金手指（如：神经同步率异常/机甲能量回路觉醒/武道感知异变）
2. 前1000字：建立核心冲突（主角当前困境与目标差距）
3. 前3章：至少完成一次“冲突→行动→代价→反馈”小闭环
4. 第3章章末：埋设信息差钩子（未知信号/新势力浮现/技术漏洞暴露）
```

**失败模式识别**：
- 开篇堆砌设定说明书 → 触发“剧情驱动检测”，强制改为角色视角切入
- 金手指展示过晚（超过第5章） → 触发“钩子密度重写”
- 冲突与金手指脱节 → 触发“动机对齐检查”

**数据校准**：首日读完率<30%直接重写前3章钩子

---

### 3.2 升级爽点模块（科武长篇适用）

**触发条件**：主角境界突破/机甲升级/科技解锁

```
动作序列：
1. 铺垫阶段：3-5章内完成“旧体系不适配→寻找突破路径→资源/线索获取”链路
2. 突破执行：至少2000字描写“感知→决策→执行→反馈”四步，不可跳跃
3. 代价显化：突破后必须附带量化代价（如：神经负荷/能量过载/寿命折损/阵营仇恨值上升）
4. 战力验证：突破后24小时内安排一次“越级战斗胜利”或“资源获取”，让读者感受到“值了”
5. 下一阶段推力：代价必须转化为新困境（如：神经损伤限制后续操作/能量枯竭暴露坐标）
```

**失败模式识别**：
- 突破后无代价/代价清零 → 触发“代价追踪缺失”警告
- 突破与验证脱节（突破后还在日常练功） → 触发“爽点延迟”警告
- 代价未转化为新推力 → 触发“剧情断档”警告

---

### 3.3 战斗场景模块（科武长篇适用）

**触发条件**：任何机甲战斗/武道对决/科技对抗场景

```
动作序列：
1. 感知层：对手能力/战场环境/变量因素的即时感知（如：敌方机甲同步率/能量波动特征/地形优势）
2. 决策层：主角快速判断与战术选择（如：同步率差距/能量消耗对比/漏洞识别）
3. 执行层：具体操作描写（神经接驳→能量回路→武器锁定→开火→后坐力传导→机体反馈）
4. 反馈层：战斗结果+代价量化+下一阶段悬念

禁止模式：
- “主角机甲启动，然后敌人就爆炸了”（缺省决策层和执行层细节）
- “主角越级战胜，无任何损伤”（缺省代价层）
- “战斗结束，进入日常”（缺省反馈层和悬念层）
```

---

### 3.4 章末钩子模块（通用·科武适用）

**触发条件**：每章结束前500字

```
钩子类型与动作：
1. 信息差钩子：接入未知信号/获取加密情报/技术漏洞暴露
2. 状态危机钩子：能量临界/敌对坐标锁定/阵营背叛预警/主角身体异变
3. 悬念升维钩子：发现新地图/高层势力介入/旧设定被推翻

禁止结尾类型：
- 纯抒情收尾（“夕阳下，主角望着远方的星域，心中充满了对未来的期待”）
- 日常流水账（“回到基地，队友们正在吃晚饭，主角加入了他们”）
- 开放式留白（“这个选择，究竟会带来什么？”）
```

**示例模板**：
```
章末钩子示例：
“就在能量回路即将过载的瞬间，通讯频道突然接入一段未知信号——
不是敌方的，也不是任何已知势力的加密方式。
信号来源坐标显示：正是导师消失前最后发送坐标的位置。
而那段信号的内容，只有四个字：‘别来找我。’”
```

### 3.5 存留率优化模块（科武长篇适用）

**触发条件**：每10万字节点/追读数据下滑时

```
核心原则：每10万字必须安排一次“阶段性高潮或信息释放”

动作序列：
- 阶段一（0-10万字）：建立世界观+核心冲突+金手指展示+首次越级胜利
- 阶段二（10-30万字）：地图扩展+阵营建立+中期危机+第一次大高潮
- 阶段三（30-50万字）：真相揭示+体系升级+地图升维准备
- 阶段四（50万字+）：科技树跃迁+武道境界突破+星域升维+终极对抗

每个阶段内部：每5万字至少一个小高潮，每10万字一个大高潮

数据校准：
- 追读连续3日下滑→触发章节节奏审查
- 某章节读完率低于70%→定位具体情节问题
```

## 四、平台规则转译：发布/包装/风险门禁

### 4.1 发布节奏门禁

| 规则 | 作家执行动作 |
|:---|:---|
| 日更要求 | 存稿量≥7章，断更超24小时触发“存稿预警+剧情断档复盘” |
| 数据日清 | 每日查看追读数据，数据波动触发24小时内章节复盘 |
| 章节发布前自检 | 参照“章节自检清单”执行，通过全部门禁方可发布 |

### 4.2 包装策略（科武长篇适用）

| 维度 | 执行动作 |
|:---|:---|
| 书名优化 | 核心关键词前置（如：《神经接驳：机甲战神》），副标题体现核心设定 |
| 简介优化 | 前三句抛出核心金手指+核心冲突+圈层锁定；禁止纯抒情/空泛描述 |
| 标签选择 | 锁定“科幻·星际文明+玄幻·东方玄幻”（或其他科武适配标签），避免泛标签分散受众 |
| 章节标题 | 每章标题体现“核心事件+情绪关键词”（如：第37章 接驳临界：零号机的咆哮） |

### 4.3 风险门禁（科武题材高发）

| 风险类型 | 触发条件 | 执行动作 |
|:---|:---|:---|
| 武器描写越界 | 涉及“致死性武器/大规模杀伤/战争描写”超过2000字 | 改用“机甲实战/训练模拟/技术验证”包装 |
| 政治隐喻模糊区 | 涉及“派系对立/权力斗争/星际政治” | 明确标注“虚构势力背景”，避免与现实政治映射 |
| 敏感技术描述 | 涉及“AI觉醒/基因改造/意识上传” | 强化“科幻设定背景”，增加“虚构技术说明注释” |
| 暴力阈值控制 | 单章战斗死亡人数超过特定阈值 | 改用“机甲损毁/技术失效/人员失联”代替肉体死亡描写 |

## 六、执行优先级

> **按执行顺序排列，新章节动笔前须依次完成**：

1. **更新任务卡**：填写“当前章节任务卡”字段，确认动作链+代价+反馈+钩子
2. **动笔执行**：按动作模块执行写作（开篇模块/战斗模块/升级爽点模块等）
3. **章节自检**：草稿完成后执行“章节自检清单”，通过全部通过门禁
4. **发布前检查**：确认平台规则门禁（存稿量/风险词/节点报备）
5. **数据追踪**：发布后每日追踪追读/读完率，触发预警则24小时内复盘
