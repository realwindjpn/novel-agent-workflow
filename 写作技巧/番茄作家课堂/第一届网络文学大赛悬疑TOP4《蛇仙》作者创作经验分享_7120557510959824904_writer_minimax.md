## 一、核心执行指令集（压缩为12条）

### [A-01] 大纲锁定命令
- **前置项**：主线核心、核心人设×3、力量体系边界、地图边界、战力天花板——必须动笔前敲定。
- **禁止**：边写边补力量体系、边写边加设定。
- **失败标志**：在20-50万字出现逻辑死胡同、战力崩坏、多线失控。
- **科武适配**：150-300万字架构下改为“分卷大纲+地图迭代”，每卷独立闭环，单卷50-80万字。

### [A-02] 开篇三章命令
- **动作**：抛出核心异象/悬念锚点（民俗传说+反常现象） + 建立主角行动动机 + 世界观基调。
- **禁止**：纯背景说明、纯设定堆砌。
- **达标线**：3章内必须有读者能说出的核心悬念句。
- **科武口吻模板**：
  > *（能量读数归零的第十七个基点，训练场上那道人形轮廓——不是失踪者的残影，是某种正在重写生理极限的东西。）*

### [A-03] 感官细节填充协议
- **要求**：每场景≥2种可观测感官细节（声/光/触/味）。
- **动作**：写完场景描写后追问自己——读者能闭眼复现吗？有物理锚点吗？
- **科武替代方案**：
  - 悬疑异响 → 能量过载焦糊味、磁场扭曲耳鸣、金属共振低频震颤
  - 压迫感 → 重力场异常、光谱偏移、生物电流反噬
- **禁用**：抽象形容堆砌（“可怕极了”“异常强大”）。

### [A-04] 冲突内核协议
- **悬疑逻辑**（蛇仙适用）：未知规则 + 信息壁垒 + 心理压迫 → 线索拼合释放。
- **科武逻辑**（禁用悬疑逻辑）：规则突破 + 力量迭代 + 阵营博弈 → 战力验证+资源争夺。
- **禁止**：无逻辑武力对轰、机械降神、无意义灌水。
- **冲突升级标准**：必须依赖“信息差释放”或“规则突破”，每3章至少有一次实质进展。

### [A-05] 战斗/能力动作链规范
- **必须**：起手蓄能 → 发力轨迹 → 命中/闪避 → 收势反冲，完整物理序列。
- **必须**：标注能量消耗节点、体力消耗节点。
- **必须**：伴随可观测物理现象（空气电离、金属形变、重力异常、肌肉撕裂感、能量余波）。
- **禁止**：意念流施法、抽象描写、无代价越级。

### [A-06] 代价绑定协议
- **要求**：任何越级突破、禁忌武技、科幻改造必须绑定明确代价。
- **代价类型**：寿命折损 / 神经负荷 / 资源枯竭 / 阵营反噬 / 数据侵蚀 / 进化失控。
- **兑现要求**：代价必须在3章内兑现或埋下回收线。
- **科武特殊代价**：
  - 神经同步率超载 → 意识碎片化
  - 基因强化剂 → 代谢崩溃倒计时
  - 武魂共鸣 → 灵魂共鸣侵蚀
  - 禁忌能量核心 → 空间稳定器失量
- **失败模式**：代价不兑现 → 读者视为金手指 → 代入感崩塌。

### [A-07] 节奏协议
- **悬疑节奏**（蛇仙）：慢铺垫（环境细节堆叠心理张力）+ 快释放（信息差释放后接决策推进）。
- **科武节奏**（禁用纯悬疑节奏）：快慢结合——
  - 设定铺垫慢（世界观呈现/修炼推演）
  - 战斗/破局快（决策-执行-反馈闭环）
  - 连续≥3章无实质进展 = 节奏拖沓违规。
- **读者预期管理**：每3章提供一次“预期兑现”（小高潮/设定揭秘/战力验证），严禁连续5章偏离主线预期。

### [A-08] 章末钩子规范
- **三选一**：信息缺口 / 危机逼近 / 两难选择。
- **禁止**：平淡收尾、无悬念推进。
- **核心悬念管理**：首次抛出后10章内必须完成首次回收或升级。
- **科武钩子模板**：
  > *（读数在飙升，他的神经接口却在反噬——而前方那座废弃能量塔里，有人在等他。）*
  > *（契约的代价刚刚激活，而他发现自己的对手，也是签订同一份协议的人。）*

### [A-09] 人物定稿协议
- **动作**：核心角色前置定稿（大纲剥离法：拆解《沙丘》《诡秘之主》《灵境行者》，提取力量体系+阶级跃迁+地图边界骨架）。
- **必须绑定**：强辨识度标签 + 明确软肋 + 行为逻辑。
- **禁止**：功能化工具人、无独立行为逻辑的NPC。
- **科武人物软肋模板**：
  - 武魂缺陷者 → 无法承受高阶共鸣
  - 机械改造者 → 情绪模块被屏蔽
  - 禁忌血脉 → 力量失控阈值低

### [A-10] 数据反馈响应协议
- **动作**：追热榜拆解结构 + 评论区定位漏洞。
- **评论归类**：设定漏洞 / 节奏拖沓 / 人设OOC。
- **修正要求**：3章内给出剧情修正方案。
- **科武热榜对标**：科幻/高武热榜结构验证（力量体系是否自洽？打斗是否拖沓？升级是否合理？）。

### [A-11] 日更稳定性协议
- **基准线**：日更4000-6000字。
- **科武适配**：设定推演耗时 → 预留“设定缓冲章”或采用存稿机制（30章存稿打底）。
- **平台算法加权**：断更超过3天 = 推荐池跌出。

### [A-12] 改编预留接口协议
- **影视化/漫改接口**：
  1. 高视觉奇观场景具象化（机甲/古武遗迹/能量场/基因变异体）
  2. 单元剧结构便于分季（每卷≈一季）
  3. 台词预留金句/情绪爆点
- **科武特殊接口**：战斗动作链可视化（分镜描述）、力量体系战力榜单、势力关系图谱。

## 三、章节自检清单（8条）

> 完成后逐项打勾，发现违规立即触发修正程序。

**第1条：开篇悬念**
- 3章内是否抛出核心悬念/异象？
- 读者能否用一句话说出核心悬念？

**第2条：主角动机**
- 主角行动动机是否明确且有内在逻辑？
- 是否与本卷核心卖点一致？

**第3条：感官细节**
- 本章场景是否包含≥2种可观测感官细节？
- 读者能否闭眼复现物理锚点？

**第4条：动作链完整性**（能力释放/战斗场景必检）
- 是否有“起手蓄能→发力轨迹→命中/闪避→收势反冲”完整序列？
- 是否标注能量/体力消耗节点？
- 是否有可观测物理现象（空气电离/金属形变/重力异常等）？

**第5条：代价兑现**
- 本章涉及越级突破/禁忌武技/科幻改造时，代价是否绑定？
- 代价是否在3章内兑现或埋入回收线？

**第6条：节奏进展**
- 连续3章内是否有实质进展（信息差释放/规则突破/战力验证）？
- 是否有≥1次“预期兑现”（小高潮/设定揭秘/战力验证）？

**第7条：章末钩子**
- 章末是否设置“信息缺口/危机逼近/两难选择”三选一？
- 核心悬念是否在10章内完成首次回收或升级？

**第8条：人设一致性**
- 核心角色行为是否遵循已定稿的行为逻辑？
- 软肋是否被触发但未被遗忘？

## 四、失败模式速查表

|---|---|---|
