# 《科武纪元》编辑学习官｜平台福利规则拆解与执行手册

## 1 课程核心判断（≤6条）
1. **数据驱动福利**：平台福利发放不依赖主观评价，核心锚点为“读完率”与“听读分成收益（≥100元/月）”。
2. **长篇主阵地**：全勤、完本、连载奖励均指向100w-500w字量级，平台生态以长尾连载为收益基本盘。
3. **短书期定生死**：星火/魁星/保底计划均以“短书期读完率”为触发门槛，前期留存直接决定合同类型与现金奖励。
4. **多媒介改编前置**：福利体系明确拆分“有声TTS、短剧、海外翻译”分成，文本需天然适配音频化与视频切片。
5. **分类定向倾斜**：平台资源按题材分批次开放（魁星/分成激励），全品类可参评但需主动对齐当期活动目录。
6. **更新即生产力**：4000/6000字日更是全勤硬指标，断更或字数不足直接切断当月福利与数据权重。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则提取（基于福利机制） | 长篇《科武纪元》执行 | 短故事/热点稿执行 |
|:---|:---|:---|:---|
| **开篇** | 短书期读完率决定保底/星火资格 | 前3章内抛出核心科武体系+主角生存危机，禁用纯设定铺陈 | 首章前1500字必须完成“事件触发-主角介入”，直接拉升跳出率 |
| **节奏** | 4k/6k日更对应全勤阶梯；10w字为数据考核节点 | 按“3章一小爆、10章一中爆、1卷一大爆”切分，章末必留断点 | 压缩铺垫，采用“单线强冲突+快速结算”结构，适配短周期流量 |
| **冲突** | 长尾收益依赖持续留存 | 采用“副本推进+主线伏笔”双线结构，每30w字重置冲突维度 | 聚焦单一高概念矛盾（如科技伦理/资源争夺），3-5万字内闭环 |
| **人物** | 版权分成依赖角色辨识度与群像适配 | 主角行动逻辑必须外显，配角按“功能标签”设计（适配短剧选角） | 人物关系极简，以“立场对立”替代复杂背景，降低阅读门槛 |
| **题材** | 魁星/激励计划按分类定向开放 | 科武需挂靠“科幻悬疑/都市异能/历史科幻”等当期开放赛道 | 热点稿需绑定平台实时榜单词（如“赛博修仙/废土机甲”），蹭流量池 |
| **改编** | 听读分成+短剧分成独立核算 | 场景描写具象化（声/光/材质），对话口语化，预留TTS分轨标记 | 强化“高光台词/动作场面”，直接可截取为15-30秒短视频素材 |
| **平台规则** | 10w/30w/100w/150w/300w为福利触发线 | 严格按节点规划剧情里程碑；每月收益≥100元为底线；后台读完率周复盘 | 短书期（1-10w字）集中冲读完率，达标后立即申请保底/星火转签 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点
- **长篇体量契合**：150w-300w字完美覆盖完本/连载奖励阶梯，科武升级线天然支撑长周期连载。
- **多媒介适配性强**：机甲运转、能量碰撞、武学招式自带音效与视觉张力，易触发TTS听书分成与短剧切片收益。
- **单元结构稳数据**：采用“科技试炼/遗迹探索/阵营对抗”单元副本，可稳定维持日更4k-6k，保障全勤与读完率平滑。

### ⛔ 不可硬套点
- **不可为凑500万字注水**：强行拉长支线会导致读完率断崖下跌，直接失去星火/魁星计划资格与长尾分成。
- **不可盲目套用古言/现言活动规则**：科幻需等待或主动申报“全品类/悬疑科幻”定向活动，硬蹭分类会导致审核不通过。
- **不可牺牲逻辑换短期爽点**：番茄读者对“设定崩坏/战力通胀”容忍度极低，科武体系必须自洽，否则10w字后留存必崩。

## 4 编辑检查表（10条以内）
1. [ ] 日更是否稳定≥4000字（冲刺6000进阶全勤）？
2. [ ] 首月听读分成是否突破100元福利门槛？
3. [ ] 10万字节点是否完成首轮高潮，读完率是否≥平台基准线？
4. [ ] 每章结尾是否设置明确悬念/行动钩子（防跳出）？
5. [ ] 科武设定是否已转化为可听/可视的具象描写（适配TTS/短剧）？
6. [ ] 是否按10w/30w/100w/150w节点规划剧情里程碑？
7. [ ] 题材是否匹配当期“魁星/星火”开放分类？
8. [ ] 后台数据（读完率、留存、收益）是否每周复盘并调整节奏？
9. [ ] 30万字后是否具备转保底/分成激励的申请数据基础？
10. [ ] 版权开发接口（有声分轨、短视频高光片段）是否在正文中预留？

## 5 对作家角色的输入要求
| 要素 | 平台规则映射 | 执行标准 |
|:---|:---|:---|
| **动作链** | 连载期防跳出/保读完率 | 每章必须包含“触发→决策→执行→结果”完整闭环，禁用纯心理/静态设定堆砌，确保节奏不断档。 |
| **物理反馈** | TTS听书分成+短剧适配 | 战斗/科技操作需绑定明确感官反馈（金属摩擦声、能量灼热感、骨骼负荷、光影折射），避免抽象描述。 |
| **代价** | 长线冲突维持/防战力崩坏 | 每次能力升级/科技突破必须伴随明确代价（资源枯竭、神经负荷、阵营追杀、道德妥协），维持张力。 |
| **钩子** | 读完率考核/星火计划触发 | 章末/卷末必须设置“未解变量”（新威胁、身份反转、资源争夺），直接拉升读完率，触发数据奖励。 |
| **读者预期** | 短书期验证/保底转签 | 严格遵循“承诺→兑现→升级”循环，开篇3章内明确科武体系与升级路径，后续每10万字兑现一次阶段性预期，避免数据流失。 |
