# 《科武纪元》作家OS执行补丁 v1.0

**补丁说明**：将编辑学习稿转译为作家写作时可“复制→粘贴→执行”的动作指令。去理论，纯操作。

## 一、核心执行指令（6条）

| # | 指令 | 违反代价 |
|:--|:--|:--|
| 1 | **情感先于修辞**：动笔前先问“角色此刻怕什么/想要什么”，用这个答案驱动动作，而非用形容词描述情绪 | 读者情绪断联 |
| 2 | **首300字=具象场景**：禁止以“XX纪元第三纪，宇宙面临XX危机”开篇。必须用“景/物/微动作”开场（如引擎轰鸣、舱门变形、手指颤抖） | 读者3秒弃书 |
| 3 | **每章交付一个情绪锚点**：爽/燃/暖/虐/悬念，读者追读是为这个。写完后自问：本章给读者的情绪承诺兑现了吗？ | 追读率下降 |
| 4 | **科幻设定→感官反馈**：所有科技/异能必须翻译成角色身体能感知的东西（震动/疼痛/呼吸变化），禁止“设定即生效” | 世界观悬浮 |
| 5 | **以完读率和正向评论调优**：差评≠改主线，除非核心人设/逻辑链被质疑 | 自我内耗 |
| 6 | **卡文时硬写保更**：哪怕写烂了也要更，次日精修。连载惯性>单章完美 | 读者流失 |

## 二、动作指令卡

### 【开篇动作链】
```
前置检查：确认本章核心情绪（爽/虐/燃/悬念）是什么
执行步骤：
  1. 找一个“物”：机械零件/武器/伤痕/光线/液体（科武场景可从引擎/舱壁/悬浮粒子入手）
  2. 找一个“动”：手指按压/目光扫视/身体后仰/引擎轰鸣
  3. 找一个“感”：压迫感/灼热/冰凉/震动
组合示例：推进器点火，舱壁震颤，金属粉末簌簌落在护目镜上——主角没有擦。（动作+感官+悬念）
禁止：以“XX星历，XX星系...”开篇的编年体
```

### 【节奏执行动作】
```
目标：每800-1200字必须完成一次“事件推进+情绪反馈”循环
检查点：
  - 本章是否至少有一个明确事件发生（任务/冲突/发现）？
  - 事件发生后是否有角色即时反应（心理/表情/动作/对话）？
  - 静态描写（环境/回忆/内心独白）是否≤15%？
违规处理：删除或压缩静态段落，插入动作或对话填补
```

### 【冲突设计动作】
```
优先冲突类型（按科武适配度排序）：
  1. 生存危机（资源/氧气/生命体征下降）
  2. 能力边界试探（异能透支/机甲过载）
  3. 价值抉择（任务vs队友/牺牲vs自保）
  4. 微观人际摩擦（误解/竞争/信任裂痕）
禁用冲突：宏观权谋博弈、幕后boss运筹帷幄（除非你已经写了20万字铺路）
冲突解决检查：
  - 是否符合角色性格/动机？
  - 是否付出了代价（时间/资源/关系/机会）？
  - 有无“机械降神”（意外获救/突发开挂）？
```

### 【人物执行动作】
```
核心原则：角色行为=情感逻辑×处境约束
写作前自问：
  1. 这个角色此刻最想要什么？（欲望）
  2. 他最怕失去什么？（恐惧）
  3. 他的能力/资源/信息能支撑他做什么？（约束）
  4. 他的行为会让他付出什么代价？（风险）
口吻模板：
  - 军人角色：命令式、短句、专业术语
  - 科学家角色：描述性、因果推演、冷静数据
  - 生存者角色：务实、警惕、简短
  - 青少年角色：直觉驱动、情绪外放、社交敏感
禁止替角色做决定：作者可以安排处境，但角色自己选择如何应对
```

### 【代价执行指令】
```
每项能力/科技/关键决策必须绑定一个代价类型：
  - 生理代价：体力透支、神经损伤、感知阈值提升
  - 资源代价：燃料/弹药/能量储备消耗
  - 关系代价：队友牺牲、信任破裂、秘密暴露
  - 时间代价：错过窗口、倒计时逼近
  - 道德代价：违背原则/底线/誓言
执行检查：
  - 能力使用后是否立即有负面反馈？
  - 重大决策后是否立即有代价显现（不一定要严重，但必须有）？
  - 有无“零成本开挂”？（禁用）
```

### 【章末钩子执行】
```
合格钩子类型（至少满足1条）：
  - 悬念钩：未解之谜/新信息（新线索/新威胁/新目标）
  - 节奏钩：倒计时/逼近的危机/即将到来的冲突
  - 反转钩：敌我态势变化/角色真实立场揭露/预期落空
  - 情感钩：关系临界点/情感突破/情感破裂预警
  - 升级钩：能力解锁/装备获得/任务进度更新
禁用钩子：
  - 开放式抒情（“夜深了，他独自站在甲板上，望着星空”）
  - 平淡收尾（“今天的事情暂时告一段落”）
  - 无后续预期的感叹（“这真是惊险的一天”）
```

## 三、反馈系统

### 【数据反馈】
| 数据指标 | 阈值 | 执行动作 |
|:--|:--|:--|
| 完读率 | 逐章追踪，低于30%回查开篇前500字 | 前300字是否太慢/太闷/设定太多？ |
| 正向评论率 | 维持>70% | 单条差评不改动线，多条差评查核心设定 |
| 章说互动 | 每章>10条正向评论为佳 | 观察读者情绪点，复盘后用 |
| 追读留存 | 第5章vs第1章留存应>50% | 回查前3章钩子是否足够 |

### 【读者预期管理】
```
每章交付承诺检查：
  - 本章承诺了读者什么？（情绪/爽点/信息/进度）
  - 这个承诺是否兑现？
  - 如果未兑现，下一章是否立即补偿？
未兑现处置：
  - 立即补偿（下一章开头兑现）
  - 或提前铺垫（本周内必须埋好伏笔）
```

## 四、失败模式识别

| 症状 | 诊断 | 处置 |
|:--|:--|:--|
| 写完觉得“太平淡” | 缺冲突/缺代价/缺即时反馈 | 加一个意外变量或代价触发 |
| 读者说“看不懂” | 设定输出过快/逻辑链断裂 | 拆解设定为“动作+感官+一句话解释” |
| 写崩了想删稿重写 | 完美主义发作 | 不删，继续写下一章，旧稿隔天精修 |
| 卡在某个情节点 | 角色动机不清/选项太多 | 给角色一个最强欲望，让他立刻行动 |
| 读者说“太水” | 静态描写/无效回忆过多 | 删除所有非必要描写，只留事件推进 |
| 战力/逻辑明显bug | 前期设定与后期冲突 | 找借口补救（如系统故障/信息差），下章埋入补丁 |
| 读者差评“人设崩了” | 角色行为违背核心性格/欲望 | 立刻回查角色设定，修正后续行为逻辑 |

## 五、段落节奏模板

### 【科武战斗节奏】
```
标准单元（500-800字）：
  触发（10%）→ 准备（15%）→ 对抗（40%）→ 代价（20%）→ 悬念（15%）
示例：
  [触发] 警报响起，主角伸手去够操控台
  [准备] 指尖摸到裂痕，引擎输出仅剩37%
  [对抗] 闪避/武器切换/战术选择（每100字一个动作节点）
  [代价] 过载警报、系统烧灼感、视野模糊
  [悬念] 敌方增援/系统崩溃/队友失联
```

### 【日常/文戏节奏】
```
标准单元（300-500字）：
  情境建立（20%）→ 人物互动（50%）→ 暗流涌动（20%）→ 悬念点（10%）
注意：文戏需保持“信息增量”和“关系推进”，不可纯聊天
```

### 【信息交代节奏】
```
禁用：连续3段以上的纯设定说明
可用：
  - 动作中带出设定（边修机甲边回忆背景）
  - 对话中截取设定（只取读者最需要的部分）
  - 感官化设定（用疼痛/震动/气味替代参数说明）
```

## 八、章节自检清单（10条）

```
[ ] 1. 首300字是否在“景/物/微动作”中开篇？是否跳过了世界观说明？
[ ] 2. 本章核心情绪是什么？是否交付了预期爽点/悬念/情感？
[ ] 3. 主角行为是否绑定情感逻辑（欲望/恐惧）？还是作者强行推动？
[ ] 4. 科幻设定是否转化为感官反馈（视觉/听觉/触觉）？还是大段科普？
[ ] 5. 冲突是否聚焦微观可感层面（人际/生存/抉择）？有无空泛宏大？
[ ] 6. 能力/科技/决策是否绑定明确代价？是否出现“零成本开挂”？
[ ] 7. 章节结尾钩子是否有效（悬念/反转/情感/升级/倒计时）？
[ ] 8. 逻辑链条（科技/战力/时间线）是否自洽？是否出现明显硬伤？
[ ] 9. 静态描写是否≤15%？是否有无效水文或重复回忆？
[ ] 10. 本章是否具备“分镜化”潜力（场景干净/动作明确/对话精炼）？

通过标准：10/10通过；若5-9项通过，提交前修复问题项；若<5项，重写。
```

## 九、可借点标注

### 【短故事/狼人篇可借点】

| 模块 | 借点说明 |
|:--|:--|
| 情感真实原则 | 狼人/短篇更依赖角色情感共鸣，此原则可全量移植 |
| 画面感开篇 | 短篇节奏更紧凑，“景/物/微动作”开篇可全量移植 |
| 情绪锚点交付 | 短篇必须在3000-5000字内完成情绪闭环，此要求可全量移植 |
| 微观人际摩擦 | 短篇无篇幅铺宏观线，此冲突设计原则可全量移植 |
| 代价系统 | 短篇单线叙事，代价需更即时更直观，可全量移植 |
| 章末钩子 | 短篇若为连载形式可借用；单篇完结可改为“结尾反讽”或“情感余韵” |

### 【科武长篇可借点】

| 模块 | 借点说明 |
|:--|:--|
| 科武设定感官化 | 长篇设定量大，必须翻译成感官反馈，否则读者疲惫 |
| 节奏控制 | 长篇需“任务/危机/升级”三驱动轮，避免水文泛滥 |
| 多数原则 | 长篇数据量大，决策更需基于统计而非单条差评 |
| 连载惯性 | 卡文硬写保更是核心纪律，不可因单章质量动摇 |
| 大纲前置 | 长篇需提前铺战力平衡/科技树/势力格局，不可单凭灵感 |
| 逻辑自洽门槛 | 科幻长篇逻辑漏洞是致命伤，必须设立专项自检节点 |

### 【科武长篇需补充（编辑稿未覆盖）】

| 需求 | 执行方案 |
|:--|:--|
| 宏观架构能力 | 势力格局/文明冲突需多线叙事，不能只用“微观人际”覆盖 |
| 战力平衡表 | 建立角色能力层级表，每场战斗需对照检查 |
| 科技树梳理 | 核心科技原理需自洽，避免“科学奇迹”随意出现 |
| 大纲/细纲双轨 | 至少10万字细纲+50万字大纲，更新时参照执行 |
| 伏笔管理系统 | 建立伏笔清单，每5万字对账一次 |

## 十、平台规则转译

### 【发布规则】

| 平台关注点 | 执行动作 |
|:--|:--|
| 番茄系重追读率 | 每章结尾钩子必须有效，留住读者下章回来 |
| 番茄系重情绪价值 | 章节核心情绪必须明确，读者要“爽/燃/暖/虐” |
| 章说互动价值 | 引导读者在章说互动（作话/悬念提问），提升活跃度 |
| 首章数据权重高 | 前3章决定推荐量，必须在300字内抓人 |

### 【包装规则】

| 场景 | 执行动作 |
|:--|:--|
| 书名/简介 | 体现核心卖点（爽点/类型/情感），避免抽象文艺 |
| 前3章 | 快节奏、高冲突、明确钩子，不能慢热 |
| 更新节奏 | 稳定>爆发，每日4000字优于隔日8000字 |
| 章节标题 | 可用悬念式/情感式/事件式，便于读者索引 |

### 【风险门禁】（触碰则需立即修正）

| 风险类型 | 触发条件 | 处置方案 |
|:--|:--|:--|
| 政治敏感 | 涉及时政/民族/领土争议 | 立即删除/改写，涉及历史朝代需谨慎 |
| 暴力血腥 | 过度描写酷刑/虐待/非必要血腥 | 减少细节，改用氛围暗示 |
| 抄袭风险 | 与已有作品相似度>30%（情节/人设） | 差异化改造，保留核心卖点但换表达 |
| 平台违规词 | 使用敏感词/违禁词 | 提前用违禁词检测工具过滤 |
| 逻辑bug公开化 | 读者在评论区指出硬伤 | 48小时内出补丁章（系统故障/信息差/补充设定） |
| 人设崩塌争议 | 多数读者质疑角色行为逻辑 | 立即复盘角色设定，修正后续行为，必要时道歉章说明 |
