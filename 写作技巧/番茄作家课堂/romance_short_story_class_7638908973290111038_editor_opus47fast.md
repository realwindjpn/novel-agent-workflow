# 《科武纪元》编辑规则提炼 —— 基于第二十期短故事作家课堂

> 源课为短篇言情向（甜宠/虐爽）。下文只保留对长篇科幻《科武纪元》编辑可迁移的部分，并标注"可用/不可硬套"。

---

## 1. 课程核心判断（6条）

1. **套路开局 + 反套路破局**：用读者熟悉的矛盾入场，用不合常理的人物反应破题。
2. **配角必须跳出脸谱**：恶毒工具人、雌竞对手、护短婆婆——三类配角越反向越出彩。
3. **信息差是张力发动机**：读者先知、主角后知（弹幕/读心/系统/身世）。
4. **人设 = 1核心特质 + 1反差行为**（如"微醺迷糊×坚定护妻"），便于记忆与传播。
5. **万能四段架构**：错位认知 → 极致守护或背叛 → 真相揭晓破局 → 圆满逆袭反击。
6. **情绪闭环优先于剧情花活**：误会必须有真诚弥补，背叛必须有清醒反击，付出必须有结算。

## 2. 可迁移编辑规则

### 2.1 过渡章规则
- 过渡章不得"纯交代"，必须夹带至少一个：信息差曝光、人设反差揭露、或代价兑现。
- 章末必须留 **认知钩** 或 **行动钩**（参考"章章有钩子"），但长篇可放宽到每 2 章一钩。

### 2.2 冲突规则
- 冲突点 = 经典矛盾骨架 + 微创新（替嫁→契约同修、真假千金→真假传承者等可类比）。
- 拒绝"误会型憋屈"作为主线，只能作引爆装置，三章内必须翻盘或反将一军。
- 反派要有逻辑动机：嫉妒/不甘/童年创伤/被挑唆，禁止"为坏而坏"。

### 2.3 节奏规则
- **先抑后扬的情绪曲线**：抑不得超过本卷 1/3 篇幅，扬必须卡在卷节点。
- 高光时刻精准卡点：开卷钩、卷中转、卷末爆——三处必须命中。
- 反转密度：长篇按"小反转每3章，大反转每卷一次"控制，避免短篇式过载。

### 2.4 人设规则
- 主角内核稳固、独立清醒——情感/势力关系中**始终掌握主动权**。
- 关键男/女配（盟友/对手）必须给一条"反预期行为线"。
- 标签法登记：每位有名角色卡片需写 `核心特质 + 反差行为 + 动机源`。

### 2.5 改编/借用套路规则
- 借经典套路必须当章内即植入"破"的暗线（婆婆反站儿媳即是范例）。
- "替身/白月光/破产/重生"类钩子在科武语境下可用，但须替换其**机制载体**（见 §3）。

## 3. 科武适配：可用 / 不可硬套

### ✅ 可直接迁移
| 言情技法 | 科武对应 |
|---|---|
| 弹幕/读心/系统旁白 | 脑机植入信息流、预知模块、AI 旁白、数据残响 |
| 重生/穿越身世差 | 时间线分支、记忆覆写、克隆体认知错位 |
| 替嫁/契约婚 | 势力联姻式契约同修、双修协议、家族继承绑定 |
| 真假千金 | 真假传承者、血脉/基因认证、武魂归属争议 |
| 大女主掌握情感高位 | 主角对修炼路径、阵营选择、技术路线的绝对主导 |
| 配角去脸谱 | 长老/对手势力出现"反阵营立场"的关键人物 |
| 章末钩 + 反转节拍 | 每章物理代价 + 下一步未决冲突双钩 |

### ⚠️ 不可硬套（需改写或舍弃）
- **小事发糖密集化**：长篇主线是文明级冲突，糖只能作副线调味，禁止挤占战力/世界观推进。
- **章章高密度反转**：短篇节奏会让长篇人物动机崩塌，须降密度。
- **苏感无条件护短**：男/女主"无脑站队"在科武世界会破坏阵营博弈逻辑，护必须有代价。
- **荒诞喜剧开局**（如"朝堂打架捡漏皇后"）：与科武严肃硬核基调冲突，可借神情而非情节。
- **作精配角靠他人剥蟹**：在生存/战斗世界观下显得失真，可转为"被保护的能力者"等替代设定。
- **纯情绪驱动反击**：科武反击必须由"技术/武道/势力"逻辑闭合，不可仅靠"清醒发火"。

## 4. 编辑检查表（9条）

1. 本章是否同时有 **物理冲突** 与 **认知冲突**？
2. 章末是否留至少一个 **未结算钩**（动作钩/信息钩）？
3. 信息差是否清晰：谁知道、谁不知道、读者位次？
4. 角色行动是否符合"核心特质 + 反差行为"卡片？
5. 反派/配角动机是否可一句话说清，且非工具人？
6. 本章是否兑现了上一处承诺（伏笔/代价/承诺回报）？
7. 节奏标记：本章属于"抑/转/扬"中的哪一段，是否超时？
8. 是否出现"无代价的胜利"或"无逻辑的失败"？任一项即驳回。
9. 改编/借用桥段是否完成"经典骨架 + 反套路破局"双步？

---

## 5. 对作家角色的输入要求

每章提交前，作家必须为关键场景提供下列四项可核验数据：

### 5.1 动作链（Action Chain）
- 至少 3 步连贯动作：`触发 → 应对 → 结果`。
- 每步标注使用的：武技/科技模块/资源消耗。
- 禁止跳步描述（如"他抬手击败了对方"）。

### 5.2 物理反馈（Physical Feedback）
- 任何攻击/能力/科技释放后，必须写出至少一项可感知反馈：
  - 环境（声/光/热/震/材质形变）
  - 身体（疼痛/血流/温度/呼吸/感官失灵）
  - 装备（过载/裂痕/能量条/读数）
- 强度需与设定上限一致，前后章不得自相矛盾。

### 5.3 代价（Cost）
- 每次主角"赢"必须支付一项：
  - 资源类（能量/丹药/灵晶/算力/寿元）
  - 关系类（盟友信任/势力立场/承诺背负）
  - 认知类（暴露底牌/被对手摸清套路/留下数据足迹）
- 代价须在 ≤3 章内显化为后续剧情压力，不得作废。

### 5.4 钩子（Hook）
- 章末提交 **两条候选钩**：
  - A. 行动钩：下一步要做的高风险动作。
  - B. 信息钩：读者已知、主角未察的反差/反转。
- 编辑择一上线，另一条进伏笔池备用。

---

**一句话原则**：言情短篇靠"情绪反差 + 钩子密度"取胜；《科武纪元》要的是 **"动作—代价—信息差"三件套驱动的认知反差**，言情技法只做调味，不做主轴。
