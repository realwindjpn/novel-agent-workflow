# 《科武纪元》编辑学习报告：基于《小小驱魔人》专访的规则提炼

## 1 课程核心判断（≤6条）
1. **平台趋势决定题材生命周期**：免费阅读生态下，作品需具备“长尾留存+IP改编潜力”，纯爽文易被算法淘汰，需提前布局影视/动漫分镜接口。
2. **金手指是工具而非引擎**：系统/外挂仅提供效率加成，叙事驱动力必须回归主角的“底线选择”与“主观破局”。
3. **情绪爆点依赖作者深度共情**：名场面（如传承/牺牲/群像共鸣）需作者自身先完成情感沉浸，否则无法穿透读者阈值。
4. **动作描写需影视化转译**：脱离“技能名堆砌”，转向空间调度、物理反馈与战术逻辑，依赖实地/影像采风建立肌肉记忆。
5. **长篇需“去同质化”与冷启动耐心**：新书筹备需强制清空旧作套路；免费流读者决策周期拉长至150-200万字，前期需靠稳定更新喂养算法。
6. **情感线短板会拉低作品上限**：不擅长写感情需提前明确标签（无CP/轻羁绊/战友向），避免中期读者预期错位引发反噬。

## 2 可执行编辑规则
| 维度 | 规则 |
|:---|:---|
| **开篇** | 3章内抛出“生存危机+短期目标”，禁用大段世界观说明书。首月数据低迷属免费流常态，需坚持过首秀/20万字验证期。 |
| **节奏** | 采用“刺激→成长→格局扩大”阶梯推进。每50-80章设置一次情绪/剧情小高潮（重要配角退场/据点危机/技术突破），维持追更率。 |
| **冲突** | 冲突设计服务于“人物选择”而非单纯战力碾压。外挂/科技仅提供路径，破局关键必须落在主角的决策代价与道德取舍。 |
| **人物** | 主角需绑定明确精神内核（如守护/求真/文明延续）。感情线若为弱项，需前置规划“功能性羁绊”或明确标签，禁止中期硬塞。 |
| **题材** | 科幻/科武需剥离“网游技能树”逻辑，强化规则自洽与物理推演。开新书前强制清空上一本套路，避免模式化重复。 |
| **改编** | 早期埋设2-3个“场景集中、人物关系清晰、视觉冲击强”的名场面（如仪式性集结/战术合围/文明存亡时刻），预留分镜接口。 |
| **平台规则** | 番茄免费流核心指标为“完读率+追更密度”。日更1w+需匹配剧情密度；传统长篇需利用平台扶持计划度过冷启动期，禁止断更/水文。 |

## 3 科武适配
| 可用点 | 不可硬套点 |
|:---|:---|
| ✅ “系统辅助+个人选择”模式可无缝替换为“AI推演/外骨骼/基因锁”，核心突破仍靠人类意志与科学迭代。 | ❌ 玄幻“传功系统/功法口诀”不可直译。科武需改为“数据解析/物理法则验证/工程试错”，避免唯心升级。 |
| ✅ “生存→守护→改变世界”格局升级路径，契合科幻长篇的文明演进主线。 | ❌ “横店古装武打采风”不适用。科武应转向“军事演习/工业遗址/硬核格斗视频/机甲结构图”拉片。 |
| ✅ 情绪爆点（导师牺牲/战友断后/文明存亡）是科幻长篇留存核心，需作者先共情再落笔。 | ❌ “200万字冷启动”在科幻赛道可能过长。需结合番茄科幻读者偏好（通常100-150万字见分晓）压缩验证期。 |
| ✅ 影视化分镜思维适用于科武战斗（机甲协同/能量武器/战术走位），强化空间调度与物理反馈。 | ❌ “直男不写感情”在科武中易导致人物工具化。需强化“战友羁绊/理性情感/文明传承”替代传统言情。 |

## 4 编辑检查表（10条以内）
1. 开篇3章内是否明确主角生存危机与短期目标？
2. 金手指/外挂是否仅作为“加速器”，而非解决核心冲突的唯一手段？
3. 每50章是否设置至少1个情绪锚点（牺牲/背叛/突破/群像共鸣）？
4. 战斗描写是否脱离“报技能名”，具备空间感、物理反馈与战术逻辑？
5. 主角行为是否始终受其核心信念（如守护/求真/破局）驱动？
6. 感情/羁绊线是否提前规划，避免中期突兀或长期缺失引发差评？
7. 是否预留2-3个具备强视觉冲击、适合分镜改编的“名场面”？
8. 日更量与剧情密度是否匹配平台算法推荐周期（首秀/验证期）？
9. 科幻设定是否遵循内部物理/逻辑自洽，避免“玄幻化”战力膨胀？
10. 作者是否完成“旧作套路清空”，确保新书题材/节奏独立？

## 5 对作家角色的输入要求
- **动作链**：战斗/操作必须呈现完整闭环：`环境感知 → 战术决策 → 肢体/装备执行 → 介质交互 → 结果反馈`。禁止跳跃式出招或“意念秒杀”。
- **物理反馈**：科武交锋需量化动能传递、材质形变、能量衰减与生理负荷（如肌肉撕裂、神经过载、护甲灼痕、散热阀喷气）。用环境破坏反衬战力层级。
- **代价**：每次越级突破/超载使用外挂/高风险战术，必须支付明确代价（资源枯竭、器官损伤、信任破裂、道德困境）。科技/系统不免费，代价需推动后续剧情。
- **钩子**：章末/卷末必须埋设“未解危机/身份反转/倒计时/关键参数缺失”，确保追更率。钩子需与主线强相关，拒绝无效悬念或纯情绪断章。
- **读者预期**：明确作品标签（硬核科武/轻科幻/群像/单男主）。承诺的升级路径、感情比重、世界观展开速度必须兑现。若主打“战术/机甲/文明演进”，则减少无意义日常；若主打“理性羁绊”，则避免后宫化或降智恋爱。预期管理前置，中期不违约。
