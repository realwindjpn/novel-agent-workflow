# 《科武纪元》编辑学习官：姜双鱼专访规则提炼

## 1 课程核心判断（≤6条）
1. **题材锚点源于真实细节+情绪共鸣**：专业/热点题材的吸引力不靠概念堆砌，而靠“可验证的细节”与“读者可投射的顺逆境体验”。
2. **人物驱动大纲法**：先固化角色特征与心理动机，再推演成长轨迹与情节矛盾，最后落笔成文。
3. **专业壁垒需前置建设**：垂直题材必须完成资料库搭建（视频/采访/规则/日常），否则易悬浮失重。
4. **稳态输出优于完美主义**：创作瓶颈期以“完成度”为第一指标，边写边修，断更/切书成本远高于瑕疵连载。
5. **情绪投射是留存核心**：竞技/成长类作品的粘性来自“努力-回报-受挫-支撑”的闭环映射，非单纯设定展示。
6. **完本是长线运营起点**：出版/推优/影视改编依赖完整人物弧光与稳定数据，编辑协同需贯穿至完结后。

## 2 可执行编辑规则（按原文内容提取）
| 维度 | 规则 |
|:---|:---|
| **开篇** | 前3章必须建立“专业真实感+情绪锚点”。禁用纯设定说明，改用“具体场景/动作/规则限制”快速代入。 |
| **节奏** | 采用“能力展示→受挫/代价→调整/陪伴→突破”四段节拍器。瓶颈期靠稳态日更维持读者预期，禁用情绪化断更。 |
| **冲突** | 冲突必须由人物选择或成长轨迹自然衍生（如资源断供、技术反噬、搭档信任危机），禁止外部机械降神或强行制造对立。 |
| **人物** | 先立“初始状态-核心缺陷-成长弧光”三要素。主角需保留“可投射的脆弱面”，配角需提供功能性支撑（技术/情绪/资源）。 |
| **题材** | 垂直领域需前置≥3000字规则集/资料库。细节决定可信度，专业术语必须绑定可感知的物理/生理反馈。 |
| **改编** | 影视/出版向作品需预留清晰的人物关系网与结局收束。情感线需与主线目标强绑定，避免支线稀释核心冲突。 |
| **平台规则** | 番茄生态重“情绪价值+稳定更新+完本率”。数据下滑时优先排查“情绪断点”与“节奏拖沓”，而非盲目推翻设定。 |

## 3 科武适配
### ✅ 可用点
- **人物推演法**：适用于《科武纪元》的武者/机甲师/基因改造者设定。先定“能力边界+心理执念”，再推演阵营博弈与技术突破路径。
- **前置资料库**：科武体系（能量回路、重力环境、神经接驳协议、武学流派）必须建立可验证的规则文档，避免战力崩坏。
- **情绪投射闭环**：将“体育低谷-陪伴-重回巅峰”转化为“科武瓶颈-战友/导师支撑-技术迭代/代价支付”，维持读者代入感。
- **稳态输出机制**：长篇科幻易陷入设定膨胀，需以“章节目标+情绪节拍”强制推进，遇卡文先修逻辑漏洞，不切主线。

### ⛔ 不可硬套点
- **“零失误优美动作”逻辑**：科武战斗重战术博弈、规则利用与代价支付，非纯粹美学展示。禁用“完美连招”替代“战术试错”。
- **“俱乐部放弃”体育圈逻辑**：需转化为“财阀资源断供/军方权限冻结/学院评级降级”，匹配科武世界的权力结构。
- **纯情感陪伴驱动**：科武语境下，“鼓励”必须叠加“技术共享/资源置换/阵营站队”，避免情感线削弱硬核生存压力。

## 4 编辑检查表（≤10条）
1. 题材核心设定是否完成≥3000字规则集/资料库？
2. 主角人设表是否明确“初始状态-核心缺陷-成长弧光”？
3. 前3章是否通过具体场景建立“专业真实感+情绪锚点”？
4. 主线冲突是否由人物选择自然触发，无机械降神？
5. 节奏是否遵循“展示→受挫/代价→调整→突破”循环？
6. 关键场景是否具备读者可代入的“顺逆境情绪映射”？
7. 更新期是否保持稳态输出，遇瓶颈先修逻辑后推进？
8. 完本前是否预留清晰人物关系网与结局收束路径？
9. 数据下滑时是否优先排查“情绪断点”而非盲目改设定？
10. 是否建立“阶段性目标-数据反馈-微调”编辑协同机制？

## 5 对作家角色的输入要求
> 以下参数为《科武纪元》创作强制输入规范，用于AI辅助或人工写作校准：

| 维度 | 输入要求 |
|:---|:---|
| **动作链** | 必须输出“触发条件→执行动作→环境交互→结果反馈”四步闭环。禁用模糊动词（如“爆发”“碾压”），替换为可拆解的物理/战术步骤。例：`神经接驳超载→液压阀泄压→机体重心偏移→战术翻滚卸力` |
| **物理反馈** | 所有科武设定必须绑定可感知的物理/生理反馈（重力加速度、热量堆积、材料疲劳、神经负荷、氧气阈值）。拒绝纯概念堆砌，每场战斗/训练需标注至少2项可量化反馈。 |
| **代价** | 每次能力突破/战术胜利必须支付明确代价（寿命折损、资源枯竭、阵营敌对、心理创伤、技术反噬）。禁止无成本升级，代价需在3章内显性化。 |
| **钩子** | 章末/卷末必须设置“未解变量+情绪悬置”。禁用纯悬念或抒情结尾。例：`技术反噬倒计时/盟友权限异常/规则漏洞暴露/资源链断裂预警` |
| **读者预期** | 每10章需校准一次“爽点/痛点/成长点”比例（建议 4:3:3）。确保读者投射的“努力-回报-受挫-支撑”逻辑闭环完整，设定膨胀不得稀释情绪主线。 |
