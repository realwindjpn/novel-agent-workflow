## 已证事实

1. Grok 4.6 于 2026-08-07 发布（8 月 5 日 SpaceX 2026Q2 财报电话会上马斯克预告"下周发布"），2026-08-12 在 xAI API 全量上线（官方 Release Notes 标注 August 12, 2026）。
2. 规模：1.5 万亿参数（复用 Grok 4.5 的 V9 基础），增益来自监督微调（SFT）与强化学习（RL）重构，非规模跃升。
3. 定位：面向 coding / agentic tasks / knowledge work 的 frontier 模型，官方宣称性能超越 Moonshot Kimi K3（约 2.8T 参数）、对标 Claude Opus 4.8；VentureBeat 实测"世界第三"（仅次于 GPT-5.6 Sol 等）。
4. 上下文 500K tokens；文本+图像输入，纯文本输出；reasoning effort 支持 low/medium/high/xhigh。
5. 定价：<200k prompt 时 $2/$0.50/$6（input/cached/output per 1M tokens），>200k 时 $4/$1/$12。低于 GPT-5.6 Sol 同场景 API 成本一半以上。
6. 组织变迁：2026 年 8 月 xAI 并入 SpaceX（SpaceXAI），模型训练将接入 SpaceX 成立 25 年数据；同日发布 Grok Bot（持久云电脑上的 AI 队友，含 messaging/approvals/connectors/routines）。
7. 后续路线：官方计划继续月更，下代 2.1T 参数 Grok 4.7 冲击性能天花板。
