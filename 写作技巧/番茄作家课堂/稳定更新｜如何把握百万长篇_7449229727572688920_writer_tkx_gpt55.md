# 《科武纪元》作家OS补丁  
## 课程：稳定更新｜如何把握百万长篇

版本：`OS-PATCH-LONG-001`  
用途：把“百万长篇稳定更新规则”写入《科武纪元》日常生产流程。  
核心命令：**稳种田、滚动坑、无选择题、每章有看点、爆后立刻起新钩。**

---

# 一、总执行原则

## 1. 百万长篇不是连续爆炸，是分田轮种

《科武纪元》必须同时维护四块田：

1. **科技线**：装甲、芯片、武器、实验体、AI、遗迹科技。
2. **武道线**：境界、招式、肉身进化、精神阈值、战斗体系。
3. **势力线**：军方、财阀、学院、宗门、异族、地下组织。
4. **谜团线**：文明真相、纪元断层、主角身世、禁区来源。

### 执行动作

每章至少推进一块田。  
每3—5章轮换一次重点，避免连续五章只写打斗或只写设定。

### 失败模式

- 连续设定章：读者觉得在看PPT。
- 连续打斗章：读者疲劳，爽点通胀。
- 连续日常章：主线失焦。
- 连续阴谋章：压抑、迟迟不爽。

---

# 二、章节生产硬规则

## 1. 每章必须有一个“可感看点”

从以下六类中选一个作为本章主看点：

| 看点类型 | 可执行写法 |
|---|---|
| 新科技 | 新装备、新芯片、新武器、新实验成果首次亮相 |
| 新武道 | 新招式、新境界、新身体变化、新战斗理解 |
| 新敌人 | 新异族、新杀手、新财阀打手、新污染体 |
| 新情报 | 主角得知一个局部真相，但不交底 |
| 新代价 | 主角赢了，但伤、穷、暴露、失去时间或人情 |
| 新关系 | 新同盟、新债务、新仇恨、新误会但不做道德两难 |

### 段落节奏

建议一章按以下节奏写：

1. **开头3—5段**：接上章钩子，立刻给反馈。
2. **中段**：主角行动，出现阻力。
3. **后段**：小结果兑现，产生代价。
4. **章末**：新钩子，不解释完。

---

# 三、坑位滚动规则

## 1. 每章保持“三坑结构”

每章写作时必须同时存在：

1. **大坑**：百万级谜团。  
   例：纪元断层、星门背后、主角体内源代码、旧武神失踪真相。

2. **小坑**：本卷或本段剧情问题。  
   例：谁偷走了反应炉核心？谁在学院里投放污染源？

3. **新坑**：本章新抛出的疑问。  
   例：敌人的机械臂上为什么刻着主角父亲的编号？

### 执行动作

每章至少：

- 填一个小反馈。
- 推一个旧坑。
- 挖一个新钩。

### 禁止

- 连续三章只挖不填。
- 爆发章之后不立新钩。
- 大坑提前解释干净。

# 四、前30万字节奏补丁

## 0—3万字：切入、代入、第一根钩

### 任务

让读者知道：

- 主角是谁。
- 他现在被什么压着。
- 他有什么不一样。
- 他下一步必须做什么。

### 《科武纪元》可借点

- 开篇不要从宇宙史、文明史开始。
- 从具体危机切入：考核失败、禁区事故、芯片暴走、低阶武徒被财阀实验波及。
- 科技和武道只露局部，不讲完整体系。

### 短故事/狼人篇可借点

- 开头直接给冲突身份：普通人误入狼人猎场、底层人撞见怪物换皮。
- 第一章就要有“他活不过今晚”的压力。

---

## 3万字：短期目标小爆发

### 任务

完成第一次小爽：

- 主角反杀。
- 通过考核。
- 拿到第一件装备。
- 觉醒异常能力。
- 让一个小反派吃瘪。

### 同时埋10万字伏笔

例：

- 装备编号来自禁区。
- 反派临死前说出一个组织代号。
- 主角战斗数据被未知服务器上传。

### 失败模式

只爽不留钩，后续变平。  
只埋不爽，读者没耐心。

---

## 3—10万字：分批铺人设和世界观

### 任务

- 加入学院/军团/猎荒队/地下赛场。
- 建立主角目标。
- 引出主要势力。
- 塑造1—2个有趣配角。

### 禁止

- 大段讲世界等级表。
- 一口气解释科技树、武道树、异族史。
- 提前暴露最终敌人。

---

## 10万字：第一次大爆发

### 爆发内容建议

- 主角第一次越阶杀敌。
- 禁区任务彻底失控。
- 学院/军方/财阀阴谋曝光一层。
- 主角获得力量跃迁，但付出明确代价。

### 爆后必须三章内完成

1. **给主角新动机**  
   例：不只是活下去，而是查清父亲编号。

2. **开启新地图/新势力**  
   例：进入前线战区、地下武库、旧纪元遗迹。

3. **立新钩**  
   例：主角的能力被判定为“旧纪元禁忌样本”。

---

## 10—30万字：缓而不断

### 执行频率

- 每章一个看点。
- 每3—5万字一个情绪小高潮。
- 每个小高潮必须给代价或新敌人。

### 可写内容

- 日常训练，但要有新招式或新规则。
- 队友情感，但不能拖成纯聊天。
- 势力博弈，但必须让主角有动作。
- 小副本，但必须服务主线坑。

---

## 30万字：第二次大高潮

### 任务

完成卷级收束：

- 一个中层谜团揭开。
- 一个重要反派清算。
- 主角地位或力量升级。
- 新大地图打开。

### 章末方向

不能写成“大团圆休息”。  
必须留下更高层危机。

---

# 五、冲突规则：判断题，不写选择题

## 1. 可写冲突

读者只需要判断：“这个人该不该被打死？”

### 标准模型

- 反派作恶。
- 罪证闭环。
- 主角确认。
- 清算。
- 爽。

### 《科武纪元》可用反派

- 拿平民做人体实验的财阀。
- 投敌的军官。
- 故意释放污染源的研究员。
- 吞掉战友抚恤金的高层。
- 把武者当耗材的宗门/学院。
- 侵略种族、寄生文明、旧纪元堕落AI。

---

## 2. 禁止主线选择题

以下内容不要放在主角主线：

- 救一个亲人还是救一城人。
- 女主父亲是杀父仇人。
- 反派有可怜孩子，所以杀不杀。
- AI是否有人格，主角必须亲手毁灭它。
- 文明延续必须牺牲无辜者。
- 爱情和复仇二选一。

### 修复方式

| 原危险设计 | 修复动作 |
|---|---|
| 反派有可怜孩子 | 删掉可怜孩子，或让孩子被反派利用且主角顺手救下 |
| 女主父亲是仇人 | 拆成两个角色：仇人是反派，女主父亲是被陷害者 |
| 救一人还是救万人 | 改成主角找第三条路，或责任归因给反派 |
| AI有人格要不要杀 | 放配角支线，不压主角主线爽感 |
| 反派想洗白 | 保留悲惨过去，但不抵消现时罪行 |

# 六、人物OS补丁

## 1. 主角

主角不能在“圣母”和“狠人”之间横跳。

### 主角立场

- 对恶人：证据确认后果断清算。
- 对弱者：能救则救，但不牺牲核心目标做无意义圣母。
- 对同伴：守信，但不被道德绑架。
- 对敌方可怜人：可救无辜，不赦主犯。

### 动机升级路线

不要写成道德摇摆，要写成目标扩大：

1. 活下去。
2. 变强。
3. 查清身世/事故真相。
4. 保护身边人。
5. 对抗势力黑幕。
6. 触碰文明真相。

---

## 2. 配角

10—30万字必须加入轻量情绪配角，负责缓冲阅读疲劳。

### 可用配角类型

| 类型 | 功能 |
|---|---|
| 毒舌机械师 | 吐槽科技设定，帮主角改装备 |
| 话痨队友 | 缓解压抑，制造日常笑点 |
| 冷面教官 | 给训练压力，也给隐藏认可 |
| 贪财情报贩子 | 推动线索，制造交易感 |
| 战损老兵 | 提供前线经验，承接世界残酷 |
| 小型AI助手 | 解释科技，但要有性格，不当说明书 |

### 人物口吻建议

#### 主角口吻

短、稳、带行动感。

例：

> “数据给我。”  
> “别解释，告诉我它的弱点。”  
> “人我救，账我也会算。”  
> “他不是可怜，他是该死。”

#### 毒舌机械师

技术词 + 嘲讽。

> “你这不叫战斗记录，你这叫遗体预告。”  
> “再这么烧核心，我建议你直接把自己改成一次性武器。”

#### 冷面教官

压迫、简洁、不废话。

> “站起来。敌人不会等你疼完。”  
> “你刚才赢的不是实力，是对方犯蠢。”

#### 情报贩子

滑、算账、留半句。

> “这个价，只买一个名字。想知道他背后是谁，得加钱。”  
> “我劝你别查。通常我这么说的时候，价格会翻三倍。”

---

# 七、动作、反馈、代价三件套

每章主角不能只“想”，必须“做”。

## 1. 动作链

每章写作前先列：

触发 → 决策 → 执行 → 阻力 → 结果

例：

- 触发：主角发现训练场能量读数异常。
- 决策：不等导师，私下追踪信号源。
- 执行：用残缺芯片反向定位。
- 阻力：信号源反噬，右臂神经灼伤。
- 结果：找到地下实验室入口，但身份被系统标红。

---

## 2. 物理反馈

科武文必须让力量“落地”。

### 可写反馈

- 能量读数飙升。
- 装甲温度过载。
- 骨骼裂纹。
- 神经延迟。
- 武道气血逆冲。
- 空气被震出白环。
- 地面合金板凹陷。
- 监控画面雪花化。
- 芯片报警。
- 敌人生命体征归零。

### 禁止

- “他很强。”
- “力量很恐怖。”
- “气势惊人。”
- “所有人都震惊了。”

这些必须改成可感反馈。

---

## 3. 代价

无代价的爽会导致后期通胀。

### 每章至少有一种代价

| 代价类型 | 示例 |
|---|---|
| 身体代价 | 肋骨裂、神经烧伤、精神阈值下降 |
| 资源代价 | 弹药耗尽、芯片报废、积分清零 |
| 时间代价 | 错过报名、任务倒计时减少 |
| 信息代价 | 暴露能力、被敌方记录数据 |
| 关系代价 | 欠人情、得罪势力、同伴误解 |
| 地位代价 | 被停职、被通缉、被学院重点监控 |

---

# 八、章末钩子模板

## 1. 章末钩必须独立成立

读者即使只看最后一句，也要想点下一章。

### 可用模板

#### 信息反转钩

> 屏幕上跳出的不是敌人编号，而是主角父亲的死亡档案。

#### 危机逼近钩

> 三秒后，整座训练场的门同时反锁。

#### 身份暴露钩

> 系统播报声响彻全场：“禁忌样本确认，编号K-零一。”

#### 强敌登场钩

> 那个本该死在十年前的武神，正站在尸堆尽头看着他。

#### 代价兑现钩

> 主角刚想抬手，才发现自己的右臂已经没有知觉。

#### 新地图钩

> 地图最深处亮起一行字：旧纪元地下城，已重新接入。

---

## 2. 爆发后钩子

爆发章结尾不能只写胜利。

### 正确写法

- 赢了小反派，露出幕后组织。
- 夺得装备，发现装备认主条件异常。
- 救出队友，队友带回更坏消息。
- 杀掉实验体，实验体临死叫出主角编号。

---

# 九、发布/包装/风险门禁

平台规则不直接写进剧情，转成发布动作。

## 1. 发布门禁

每章发布前必须确认：

- 章末有钩。
- 评论区能提一个互动问题。
- 本章没有主线选择题。
- 本章有一个可截图传播的看点。
- 爆发章后三章内已经安排新钩。

---

## 2. 包装动作

### 标题方向

标题尽量包含：

- 危机。
- 反杀。
- 新装备。
- 身份暴露。
- 禁区。
- 数据异常。
- 强敌登场。

例：

- 《禁区数据异常，他的编号被系统标红》
- 《第一次越阶反杀，代价是右臂报废》
- 《旧纪元芯片启动，军方档案全部锁死》

---

## 3. 评论区互动

每天固定一个互动点：

| 类型 | 示例 |
|---|---|
| 设定问答 | “你们觉得旧纪元芯片是武道外挂还是文明陷阱？” |
| 战力竞猜 | “主角现在能不能打赢三阶污染体？” |
| 阵营投票 | “军方、学院、财阀，谁最像幕后黑手？” |
| 装备命名 | “这把新武器叫什么？” |
| 伏笔提示 | “上一章有个编号不是随便写的。” |

### 风险

不要在评论区引导道德站队。  
不要问“主角该不该牺牲某某”。  
要问“谁是黑手”“装备叫什么”“下一战怎么赢”。

# 十、短故事/狼人篇可借点

## 1. 直接借用

- 无选择题。
- 反派纯恶。
- 主角目标清晰。
- 开头快速进危机。
- 每段都有小看点。
- 结尾必须有反转或追读钩。

## 2. 狼人篇适配动作

### 可写模型

1. 普通人进入封闭空间。
2. 发现规则异常。
3. 身边人逐个暴露狼性。
4. 主角找到判断狼人的硬证据。
5. 反杀或逃生。
6. 章末发现更大狼群/更高规则。

### 可借到《科武纪元》

狼人可以替换成：

- 寄生体。
- 伪装AI。
- 污染武者。
- 财阀改造人。
- 异族拟态者。

核心不变：  
**谁是怪物？怎么证明？怎么反杀？背后还有谁？**

# 十一、科武长篇可借点

## 1. 四线轮种

- 科技线负责新鲜感。
- 武道线负责成长爽。
- 势力线负责冲突。
- 谜团线负责追读。

## 2. 判断题化反派

《科武纪元》尽量让主角清算对象“该死无疑”。

### 标准罪证

- 实验记录。
- 战场录像。
- 死者名单。
- 资金流向。
- 芯片控制日志。
- 异族通讯证据。

## 3. 三层悬念

每章尽量挂靠三层之一：

| 层级 | 示例 |
|---|---|
| 下层钩 | 这一战怎么赢？ |
| 中层谜 | 谁在操控学院事故？ |
| 上层谜 | 旧纪元为什么消失？ |

# 十三、章节自检清单

发布前逐项打勾。

## 基础节奏

- [ ] 本章开头是否承接上一章钩子？
- [ ] 前5段内是否给出动作或危机？
- [ ] 本章是否至少有一个明确看点？
- [ ] 主角是否有实际行动，而不是只听别人解释？
- [ ] 中段是否有阻力？
- [ ] 结尾是否有结果或反馈？
- [ ] 章末是否有新钩？

## 科武质感

- [ ] 是否有具体物理反馈？
- [ ] 是否避免了空泛形容强大？
- [ ] 科技/武道设定是否通过动作展示，而不是整段说明？
- [ ] 本章是否有能量、伤势、装备、环境之一的可感变化？

## 坑位管理

- [ ] 当前是否保留一个大坑？
- [ ] 当前是否推进一个小坑？
- [ ] 本章是否新挖一个钩？
- [ ] 是否至少给了一个旧坑反馈？
- [ ] 爆发后是否已经安排新动机和新钩？

## 人物与冲突

- [ ] 主角立场是否稳定？
- [ ] 主角是否没有圣母/冷血横跳？
- [ ] 反派是否罪证闭环？
- [ ] 本章是否没有主线道德选择题？
- [ ] 如果有灰色议题，是否放在配角支线？
- [ ] 配角出场是否有功能，而不是闲聊？

## 爽点与代价

- [ ] 本章爽点是否兑现？
- [ ] 主角是否付出至少一种代价？
- [ ] 代价是否可量化或可感知？
- [ ] 爽点之后是否产生新问题？

## 发布风险

- [ ] 章末钩脱离上下文是否也能勾人？
- [ ] 标题是否能体现危机/反杀/新设定/身份暴露？
- [ ] 评论区互动问题是否不会引发道德站队？
- [ ] 是否没有让读者在主角主线上做痛苦选择？
- [ ] 是否适合进入连载队列？

---

# 十四、一句话执行命令

写每章前先问：

> **这一章主角做了什么？读者看到了什么新东西？主角付出了什么代价？结尾又钩住了哪个坑？**

如果答不上来，本章不开写。
