# 《科武纪元》编辑学习官：番茄作家课堂《他为什么能写出〈我祖父是朱元璋〉》拆解报告

## 1 课程核心判断（≤6条）
1. **反套路≠反逻辑，真实感源于“人物犯错-承担代价-认知迭代”的闭环。** 套路失效是因为跳过了现实检验环节。
2. **配角去工具化是留存底线。** 每个出场角色必须有独立诉求与利益计算，行为严格服从诉求，禁止为推剧情集体降智。
3. **代入感锚定微观经验。** 宏大叙事必须拆解为家庭账本、基层执行、具体技术瓶颈，读者只认“可触摸的困境”。
4. **数据焦虑是创作毒药。** 免费流算法看重长期稳定性，前30万字专注文本自洽与设定落地，成绩是水到渠成的副产品。
5. **题材破局靠“扎实考据+反刻板”。** 历史/科幻均需底层逻辑支撑，设定堆砌无法替代人物弧光。
6. **网文是手艺活，废稿即基建。** 15万字未签约文本也是笔力训练，坚持与阅读量决定职业寿命。

## 2 可执行编辑规则（按栏目实际内容提炼）
| 维度 | 规则 | 原文依据映射 |
|:---|:---|:---|
| **开篇** | 拒绝“天降金手指/满级开局”直给。用具体生活困境或反常理选择切入，3章内建立人物关系与世界观基调。 | 开篇用“财政危机+彩票提案”切入，而非直接写登基/修炼。 |
| **节奏** | 遵循“动机-行动-受挫-代价-调整”循环。连续顺境≤5章，每卷必须有一次逻辑自洽的认知反转或资源损耗。 | 主角提彩票→祖父否决→挨揍→认知修正，节奏紧凑不注水。 |
| **冲突** | 冲突不靠“反派无脑挑衅”，靠“利益/理念错位”。主角方案必须经现实检验，冲突结果必须改变人物状态或关系网。 | 祖父否决彩票因“赌博害人”，冲突源于价值观碰撞而非武力压制。 |
| **人物** | 主角必须有“可修正的缺陷”；配角建立“诉求清单”（权力/金钱/安全/情感），行为严格服从诉求。 | 明确反对“主角厉害配角无脑”，强调配角对自身现状的认知与跟随收益。 |
| **题材** | 宏大设定必须落地为“微观切口”。历史/科幻/热点均需绑定具体账本、技术瓶颈或基层执行细节。 | 朱元璋不止是皇帝，更是“如何经营家庭/应对天灾”的普通人。 |
| **改编** | 预留“短剧/影视化”钩子：强情绪场景需具象化动作与台词，减少纯心理描写，确保单场戏可独立成篇。 | “挨揍”“跪坟还债”等场景具备强视觉与情绪张力，易拆解为短剧爆点。 |
| **平台规则** | 番茄免费流算法核心是“读完率+追更率”。前3章完成“悬念抛出+情绪共鸣+明确目标”；断章处留“未解决的代价”而非纯爽点。 | 作者强调“不急着看收藏数”，但实际成功依赖稳定更新与文本质量匹配平台推荐逻辑。 |

## 3 科武适配：可用点 / 不可硬套点
| 维度 | ✅ 可用点（直接迁移至《科武纪元》） | ❌ 不可硬套点（需规避/改造） |
|:---|:---|:---|
| **设定落地** | 将“星际武道/基因改造/机甲”拆解为“训练营伙食账本/义体排异反应/底层维修工晋升配额”。 | 历史考据逻辑不能直接套科幻。科幻需“科学逻辑自洽”而非史料堆砌，硬套会导致设定臃肿、节奏拖沓。 |
| **人物驱动** | 势力林立背景下，盟友/敌人行为必须符合资源争夺逻辑（如抢夺稀有同位素、武道基因配额、信用点）。 | “家庭伦理”比重需严格控制。科武核心是生存竞争/力量体系/未知探索，家庭线仅作情感锚点，不可替代主线冲突。 |
| **节奏控制** | “犯错-代价”闭环适配科武：主角尝试激进功法/科技融合，必须付出物理/社会代价（经脉灼伤/信用冻结/阵营除名）。 | “慢热水到渠成”在免费流需提速。番茄前10万字决定生死，科武需在3万字内完成“力量体系展示+核心危机确立”，不能纯铺垫。 |

## 4 编辑检查表（8条）
1. [ ] 开篇3章是否出现具体困境/反常选择？（否→重写）
2. [ ] 主角当前行动是否伴随明确代价或风险？（无→加限制条件）
3. [ ] 配角行为是否可追溯至独立诉求清单？（否→补动机/删减）
4. [ ] 连续顺境是否超过5章？（是→插入逻辑挫折或资源损耗）
5. [ ] 核心设定是否通过“事件演示”而非“设定说明”展现？（是说明→改演示）
6. [ ] 断章处是否留下“未闭合的因果链”？（否→调整钩子结构）
7. [ ] 科幻/武道元素是否绑定可观测的物理/生理反馈？（无→补感官细节）
8. [ ] 前10万字是否完成“力量体系+核心危机+人物关系网”搭建？（否→加速主线）

## 5 对作家角色的输入要求（硬性规范）
| 模块 | 输入标准 | 违规示例 | 合格示例 |
|:---|:---|:---|:---|
| **动作链** | 禁止“意念流/瞬发”。必须拆解为：感知→决策→发力→接触→结果（5步）。 | “他挥剑斩断机甲。” | “他蹬碎合金地板借力，腕骨反关节扭转，高频刃切入关节缝隙，火花溅入面罩，液压管爆裂。” |
| **物理反馈** | 所有超常能力/科技必须绑定可观测的物理/生理反应，禁用抽象形容词。 | “基因过载让他很痛苦。” | “瞳孔骤缩至针尖，毛细血管在颧骨处破裂，体温突破41℃，冷却液从义体接缝渗出。” |
| **代价** | 每次越级/破局必须支付对等代价，分三层：生理/资源/社会。禁止无代价开挂。 | “他突破境界，毫发无损。” | “经脉灼伤需静养7日，信用点冻结30%，家族除名警告已下达。” |
| **钩子** | 章末钩子必须是“未闭合的因果链”。格式：行动A已执行→引发变量B→必须在C时间内应对→否则D后果。 | “且听下回分解。” | “跃迁引擎已点火，但冷却阀卡死，必须在30秒内手动泄压，否则反应堆熔毁。” |
| **读者预期** | 每章开头300字内必须锚定本章核心预期（复仇/解密/突围/交易）。预期必须在章内兑现或合理延宕（延宕需给明确倒计时/条件）。 | 开篇写风景，中段突然切战斗。 | “本章目标：潜入黑市换取同位素。若失败，义体排异将提前发作。” |
