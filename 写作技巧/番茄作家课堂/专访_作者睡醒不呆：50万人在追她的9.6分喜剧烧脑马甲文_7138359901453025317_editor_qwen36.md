# 《科武纪元》编辑学习官：睡醒不呆专访规则提炼

## 1 课程核心判断（≤6条）
1. **预期递进管理**：类型叠加需“伪装-揭示-再反转”（如爱情→喜剧→烧脑），利用认知差拉长追读周期。
2. **爽感受众锚定**：网感梗/流行语是双刃剑，必须明确核心受众画像（如学生群体），非目标受众的差评属正常筛选。
3. **逆袭/重生底层逻辑**：前期压抑值与后期释放值严格正相关，“憋屈”是“爽”的蓄能池。
4. **群像防同质化**：靠“语言指纹+行为惯性”区隔角色，避免中期赶更导致人设融为一锅粥。
5. **冲突推演法**：爽点生成路径为“反派设局→旁观者（读者代理）共情愤怒→主角破局”，情绪驱动优于逻辑驱动。
6. **平台算法适配**：对话流+高频段评触发点（共鸣/玩梗/悬念）直接拉升番茄推荐权重与完读率。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 前3章必须完成“核心钩子+题材基调”双交付；采用对话流切入，快速建立人物关系与冲突引信，禁用长篇背景说明。 |
| **节奏** | 严肃/沉重剧情与喜剧/轻松桥段必须交替出现（建议比例 6:4）；每10-15章设置一次类型预期反转或信息增量，防阅读疲劳。 |
| **冲突** | 采用“旁观者愤怒法”设计：先代入反派制造憋屈点→切换旁观者视角放大情绪→主角以符合人设的方式破局。破局必须伴随明确的情绪释放。 |
| **人物** | 建立“角色行为档案”：每人固定1-2个语言习惯/微动作/决策逻辑。中期每5万字进行一次“人设同质化”自查，强制差异化。 |
| **题材** | 追热点需带“复合标签”（如马甲+烧脑+喜剧）；核心题材承诺（如重生必爽、悬疑必解谜）必须在首卷内兑现，否则流失率飙升。 |
| **改编** | 场景设计预留视觉化接口：人物轮廓鲜明、表情/动作具象、情绪对比强烈；对话需短平快，便于漫画分镜与影视台词转化。 |
| **平台规则** | 优化段评触发点：每章预留1-2处“可吐槽/可玩梗/可站队”的段落；保持日更稳定，利用番茄“追更-段评-推荐”正反馈循环。 |

## 3 科武适配（《科武纪元》长篇科幻/短故事/热点稿）
### ✅ 可用点
- **类型叠加策略**：科幻设定（硬）→ 武斗/机甲（燃）→ 阴谋/烧脑（悬）递进揭示，维持长线追读。
- **旁观者愤怒法**：适用于科武冲突（如财阀压榨、AI叛乱、武道不公），将宏大设定落地为读者可共情的具体压迫。
- **群像差异化**：用“战斗流派/义体改造特征/战术语言”替代纯外貌描写，建立科武世界观下的角色识别度。
- **节奏交替**：硬核设定解说后必接实战/喜剧互动，用动作与对话稀释信息密度。

### ❌ 不可硬套点
- **网感梗滥用**：科幻沉浸感易被现实流行语破坏。需替换为“世界观内黑话/技术俚语”，实现同等段评效果。
- **纯对话流**：科武题材依赖物理空间与科技/武学规则展示，不可仅靠对话推进。必须保留环境交互与动作拆解。
- **重生憋爽公式**：若《科武纪元》非重生文，需将公式转为“系统压迫/技术瓶颈→突破反杀”，核心仍是“压抑-释放”正比。
- **沙雕喜剧基调**：科武主线需保持张力。喜剧应来自“情境错位/角色性格反差/硬核设定的荒诞应用”，而非无厘头玩梗。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章是否明确核心钩子与题材基调？无冗余设定堆砌。
- [ ] 冲突是否遵循“反派挑衅→读者共情愤怒→主角破局”路径？
- [ ] 主要角色是否有独立的语言习惯/行为特征？无同质化倾向。
- [ ] 严肃剧情与轻松节奏是否交替？防阅读疲劳。
- [ ] 核心题材承诺（科幻/武斗/悬疑）是否在首卷兑现？
- [ ] 段落是否预留段评触发点（共鸣/悬念/世界观梗）？
- [ ] 场景是否具备视觉化/改编潜力（动作清晰/表情鲜明）？
- [ ] 科幻/武学设定是否通过动作/冲突展现？非纯说明文。
- [ ] 每10章是否提供一次类型反转或信息增量？
- [ ] 数据对标：首读留存、段评率、追更率是否达平台基准线？

## 5 对作家角色的输入要求
| 维度 | 必须提供的输入标准 |
|:---|:---|
| **动作链** | 明确拆解“触发条件→决策逻辑→执行步骤→物理结果”。禁用“一招制敌/瞬间爆发”等模糊表述，需写出科武体系下的具体操作序列。 |
| **物理反馈** | 每次科技使用/武学施展必须伴随可量化的环境破坏、身体负荷、能量衰减或装备损耗。反馈需符合世界观物理/能量规则。 |
| **代价** | 破局/升级/越级必须支付明确代价（时间窗口、稀有资源、人际关系断裂、生理损伤、道德妥协）。禁止无代价开挂或机械降神。 |
| **钩子** | 每章末必须设置“信息缺口”或“行动悬念”（如未解参数、敌方底牌、装备临界值）。禁用纯情绪/风景收尾。需标注预期段评方向。 |
| **读者预期** | 提交大纲/细纲时标注：①核心爽点类型（逆袭/解谜/群像/设定碾压）②目标受众画像（硬核科幻/泛网文/学生/下沉）③预期管理策略（如硬核度占比、喜剧缓冲点位置、类型反转节点）。 |
