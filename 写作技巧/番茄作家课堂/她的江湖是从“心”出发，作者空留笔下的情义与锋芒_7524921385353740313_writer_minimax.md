## 一、写作操作系统核心指令（6条）

1. **先问命题，再开设定。** 每章动笔前用一句话说清：本章回应了哪个核心命题？读者为什么要在意？
2. **主角的双轨必须实时在场。** 手段锋芒与情感底线，任何时候拆开读都不能超过3章没有另一轨的回应。
3. **每写一个势力，先给它三条路：** 生存逻辑、核心恐惧、与其他势力的利益交割。写完势力再看主角在这三条路上怎么选。
4. **骨架前置原则。** 不管写单章还是写卷，必须先确认：本阶段的收束点是什么？延展的支线最多保留几条？超过即砍。
5. **设定为剧情打工。** 每一个科技/武道/社会设定，必须能回答：删掉它，主线会断在哪？回答不了的，删除或降权。
6. **写作期必须维持输入。** 每天至少30分钟非本品类阅读（社科/历史/新闻/技术史），用于维持语感和防止认知窄化。

| **物理反馈链** | 本章使用的超常能力/科技是否有感官细节锚定？ | 义体过载→手臂皮肤出现电弧灼痕→听觉短暂失聪→视野边缘雪花点 |

## 三、章节自检清单（动笔后、发布前各过一遍）

> 逐条通过，不通过即修改，不求完美但求不踩红线。

**基础线（不过不发布）**

- [ ] 核心命题句能一句话说清，读者能回答“主角在纠结什么”
- [ ] 开篇300字内，主角手段与底线同时在场（可以通过其中一个让另一个产生张力）
- [ ] 世界观设定（科技/武道/社会规则）有明确边界——作者自己答得出“这项能力能干什么，不能干什么”
- [ ] 冲突不是内耗型（宅斗/雌竞/无意义情感纠葛）——能说出这场冲突在打破什么旧循环

**人物线**

- [ ] 主角：每个决策能找到逻辑链（触发→决策→执行→连锁），没有机械降神或无理由开挂
- [ ] 配角：至少能说清楚一个配角的“独立动机+恐惧”，不是纯背景板
- [ ] 对话：非信息传递场景中，对话能同时传递关系张力（谁在试探谁、谁在退让谁在逼迫）
- [ ] 反派：能说清楚反派的逻辑自洽性，不能只是“因为是反派所以做坏事”

**节奏线**

- [ ] 高潮后有缓冲（情感/关系/信息整理），防止读者情绪透支
- [ ] 每10章至少兑现一次伏笔或推进主线阶段性成果
- [ ] 章末钩子已绑定：悬念/关系转折/倒计时，未绑定则重写最后一段

**代价线**

- [ ] 关键能力使用/重大决策有明确物理代价或社会代价
- [ ] 代价直接推动下一步剧情（不轻描淡写，不一次性结算后消失）

**平台适配线**

- [ ] 每章有至少一个“名场面”锚点（视觉化动作/高张力对白），可用于短视频/改编素材
- [ ] 日更节奏可控（单章字数稳定，章节之间有自然的钩子连接，防断更导致读者流失）
- [ ] 无敏感内容红线（平台规则对应项，详见第六部分）

## 四、动作-反馈-代价-失败模式速查表

### 4.1 科武长篇核心动作模式

| 动作类型 | 触发条件 | 执行逻辑 | 物理/社会反馈 | 代价类型 | 典型失败模式 |
|:---|:---|:---|:---|:---|:---|
| **义体能力激活** | 生存威胁 + 情感锚点触发 | 先评估负荷→选择性激活→监控副作用 | 皮肤电弧灼痕、肌肉痉挛、感知错位 | 生理损伤累积 / 能量储备消耗 | 过载导致关键功能锁死，拖累队友 |
| **武道突破** | 长期压抑 + 核心命题触发 | 压抑积累→临界点→代价换取突破口 | 骨骼重压感、内力暴走、体温失控 | 根基损耗 / 关系破裂 / 道德妥协 | 突破成功但失去原有人格锚点，沦为新的秩序工具 |
| **联盟缔结** | 利益互补 + 信任试探 | 小代价验证诚意→利益交换→风险共担协议 | 资源让渡记录、势力范围调整、承诺文本 | 资源消耗 / 独立性削弱 / 把柄暴露 | 联盟一方先背叛，主角被迫二选一：复仇或保全大局 |
| **系统入侵/破解** | 技术能力 + 剧情授权 | 信息收集→漏洞识别→触发连锁 | 电子噪音、界面失灵、警报触发 | 技术反噬 / 法律追责 / 身份暴露 | 破解成功但触发更高级别的追踪协议 |
| **真相揭露** | 证据链完整 + 情感准备 | 铺垫→触发点→连锁反应 | 关系重构、阵营分化、秩序动摇 | 信任损耗 / 自我怀疑 / 敌人激活 | 真相揭露后没有解决方案，主角陷入更深的道德困境 |

### 4.2 段落节奏锚定（可直接套用）

```
【标准节拍一：爆发-沉淀-再出发】
事件触发（1段）
→ 主角决策与行动（2-3段，动作链完整+感官反馈）
→ 连锁反应（1-2段，代价值即呈现）
→ 情感/关系影响（1段，底线验证）
→ 新局面确立 + 钩子（最后1段，两难/倒计时/关系转折）

【高强度章适用节拍：压缩沉淀】
连续冲突（2-3段，不给喘息）
→ 突然断裂（技术故障/外部打断，1段）
→ 主角独处时刻（1段，底线复盘）
→ 钩子（最后1段，关系或悬念）

【情感章适用节拍：留白节奏】
重要情感事件（触发）
→ 主角行动（手段+底线同时在场）
→ 对方/第三方回应（关系张力）
→ 不直接说出感受，用动作/环境/细节暗示（留白）
→ 章末钩子：关系出现新变量
```

### 4.3 人物口吻速查

| 角色类型 | 口吻特征 | 科武语境示例 | 禁区 |
|:---|:---|:---|:---|
| **主角（锋芒型）** | 短句、断点、行动先于解释；逻辑型思维但情感底线在细节中 | “我能修。但你要告诉我这东西从哪来。” | 不直接说“我很愤怒”，用肌肉紧绷、握拳、声音压低替代 |
| **主角（隐忍型）** | 留白多、自嘲、看似退让实则在划底线 | “没事。我能撑。” [下一章代价爆发] | 隐忍不等于无底线的持续受压，必须有清晰的不行动红线 |
| **配角（工具人→复杂化）** | 给他一句不属于主线任务但体现个人追求的对白 | 医疗兵在战斗间隙说：“我原本是兽医。这是我第一次给人做手术。” | 不要加背景故事，直接用一句有质感的对白或动作替代 |
| **反派（逻辑型）** | 说业务语言、用协议/系统/效率框架思考 | “你的行为符合协议第17条。现在执行第18条。” | 反派不是没有情感，是情感被更大的逻辑压制，压制本身要有代价 |
| **反派（疯子型）** | 跳跃、夸张、看似非理性实则有隐藏逻辑 | “你以为我为什么要炸掉自己的义体？因为我算过了——炸掉之后存活概率更高。” | 疯狂必须有代价，不能只是“这个人很疯所以做什么都行” |

## 五、章末钩子分类库（直接调用）

每章结束前对照，选定一种类型后，确保最后一段覆盖该类型的所有要素。

### A型：两难抉择

```
触发：主角面临两个都合理但互相排斥的选择
结构：选择一（A代价） vs 选择二（B代价）+ 隐藏的第三方变量
例：“救队友，意味着引爆已被敌方锁定的能源核心；不救队友，意味着眼睁睁看着自己的互助网络断裂。”
✅ 验收：读者能清晰说出两个选项分别牺牲什么；第三个变量在下一章必须出现
```

### B型：互助网络裂痕/重组

```
触发：信任关系出现背叛/误解/利益分歧，且主角是被动卷入方
结构：表面和平→裂痕出现→主角被迫站队→裂痕扩大
例：“队友A发现主角在上一场行动中隐瞒了关键信息——目的是保护队友B。但队友A的判断是：这种隐瞒本身就是背叛的开始。”
✅ 验收：读者对主角的选择有分歧（不是非黑即白）；裂痕在下章不能立刻修复
```

### C型：技术反噬倒计时

```
触发：主角使用的手段/能力/信息在累积负面效果，尚未爆发
结构：使用→副作用出现→主角尝试控制→控制失效→倒计时启动
例：“电磁脉冲成功摧毁了追兵系统。但主角发现自己义体的能量储备被锁死在下限——系统检测到过载后自动进入保护模式。而下一波追兵，预计在30分钟内到达。”
✅ 验收：倒计时有明确单位（时间/距离/资源）；倒计时期间主角必须有主动动作，不能只是等待
```

### D型：关系转折

```
触发：关键人物之间的关系出现不可逆变化（信任建立/崩塌/重新定义）
结构：关系基础→突发事件→重新评估→新关系定位
例：“反派说出了主角无法反驳的逻辑——主角建立的新秩序，正是用旧秩序的逻辑建立的。主角无法反驳，但也没有接受，而是选择沉默离开。”
✅ 验收：转折必须是“重新定义”而非“终结”；主角在新关系中有新的行动空间
```

## 六、平台规则 → 发布/包装/风险门禁

> 以下为最低合规门槛，发布前必须自检。平台规则有变动时在此模块更新，不影响其他模块。

### 6.1 发布前风险自检

| 风险类型 | 触发条件（自检问题） | 处理方式 |
|:---|:---|:---|
| **敏感内容红线** | 有无涉及政治隐喻、宗教煽动、血腥猎奇、色情擦边？科武语境尤其注意：AI觉醒/阶级对立/技术伦理议题是否触碰平台解读红线 | 降低直接对抗层级，改为“个体困境+系统BUG”叙事 |
| **版权风险** | 使用真实科技公司/品牌名称/已有IP衍生概念？ | 全部替换为自创名称，设定集内标注“虚构” |
| **平台推荐算法适配** | 开篇300字内是否有明确冲突钩子？章节是否有可独立传播的“名场面”？日更是否稳定？ | 每章至少留一个钩子型结尾；节奏参照平台爆款章结构做调整 |
| **读者预期管理** | 首章承诺的命题是否在中段（10-15章）兑现了阶段性成果？ | 建立“预期兑现卡”：第3章承诺→第10章兑现；第7章承诺→第15章兑现 |
| **改编预留合规** | 对白/动作是否有可拍摄的视觉化场景？（版权/形象授权问题） | 场景描述尽量用通用动作而非特定品牌/形象；对白优先选择有口语张力的短句 |

### 6.2 包装建议

- **作者品牌定位**：核心标签2个（如“科武+技术伦理+代价真实”，不是堆类型词），在简介/书名/前3章封面感中统一呈现
- **章节包装**：每章标题建议带悬念感或主题词（非目录式），结尾钩子用章节名强化
- **读者预期引导**：简介只承诺一个核心情绪，不承诺“大杂烩爽文”；文案用具体场景而非设定罗列

## 七、跨品类借用点标注

### 7.1 短故事/狼人篇可借点（单篇完整结构）

| 借用要素 | 原型来源 | 科武/长篇改造方案 | 使用场景 |
|:---|:---|:---|:---|
| **单篇命题闭环** | 课程核心命题：“从心出发”“终结仇恨循环” | 单篇章节需有独立命题（不依赖前文也能理解核心冲突） | 短故事/独立篇章/外传 |
| **人物简报法** | “主角=狠戾手段+情感软肋+行为底线”三要素 | 单篇主角控制在2-3个要素即可，不必全展开；配角用一句话锚定动机 | 短篇/单章独立情节 |
| **钩子即标题** | 章末钩子分类（A/B/C/D型） | 短篇结尾直接用钩子做标题——“两难”“背叛”“倒计时” | 短故事/番外/外传 |
| **五感锚定法** | “物理反馈链：用五感细节锚定虚构设定” | 短篇因篇幅限制，用3个感官细节即可建立可信度（如：火星、噪音、手指发麻） | 所有类型，尤其是科武设定需要“落地”的场景 |
| **快速代价结算** | “每次关键决策/能力爆发必须支付明确代价” | 短篇代价需要在情节前半段就种下，不能中段突然插入；代价与命题形成对位 | 短篇/单章 |
| **关系转折速写** | “D型钩子：关系重新定义” | 短篇关系转折只需一个“不可逆动作”或“一句说出口的话”，不需要篇幅铺垫 | 短篇/外传/人物速写 |

### 7.2 科武长篇专属可借点（需系统化适配）

| 借用要素 | 原型来源 | 长篇适配要点 | 警戒事项 |
|:---|:---|:---|:---|
| **文明命题落地** | “科幻/武侠设定需锚定当代读者可共情的现实命题” | 将技术伦理/文明冲突转化为具体的两难场景（不是概念讨论，而是角色在其中做出代价选择） | 防止“命题先于人物”——先有人物困境，再导出命题 |
| **科技树边界管理** | “世界观需划定明确边界，防中后期崩坏” | 每一卷开始前更新“科技/武道能力上限清单”，新能力加入必须有逻辑支撑和代价设计 | 每增加一项能力，删除或降权一项旧能力 |
| **势力构建法** | “每个势力需有独立人生轨迹，构建自洽微观宇宙” | 每个势力准备：①生存逻辑②核心恐惧③与其他势力的利益交割表 | 防止势力沦为“主角的对手盘”——每个势力有自己的主线 |
| **群像独立性检查** | “配角需具备独立动机与成长弧光” | 每10章给至少一个配角一个“与主线无关但体现个人追求”的场景 | 防止配角只在“与主角互动”时存在 |
| **主线收束点规划** | “严禁写到哪算哪” | 每卷结束前确认：主线推进了多远？支线消耗了多少延展空间？下一卷的收束点是什么？ | 中期检查点：50章、100章、200章各设置一次“骨架验证” |
| **改编名场面清单** | “预留视觉化名场面与关系张力点” | 每20章整理一份“可用改编场景清单”：场景描述+对白+关系张力标注 | 不要为改编强行加戏，场景必须原生于剧情 |
| **写作期输入管理** | “写作周期内保持高频阅读，维持语感与叙事节奏稳定性” | 建立“输入-输出对照表”：每周读什么→本周写了什么→语感/节奏是否有变化 | 防热情透支：用“输入质量”替代“写作时长”自我安慰 |
