# 0. 核心执行指令

> **任何章节都不能只解决旧问题。**  
> 在解决悬念A时，必须同时让悬念B升温，并让悬念C的人、物、线索至少露一次脸。

写作时默认保持：

```text
活跃悬念 ≥ 2条
潜伏悬念 ≥ 1条
主角视角 = 默认视角
评论区 = 情绪样本，不是修文指令
追更/留存/收益 = 改文依据
```

# 1. 作家OS新增规则

## 1.1 悬念交接规则

### 执行动作

每章写作前先标记三根线：

```text
A线：本章正在解决什么？
B线：本章要加热什么？
C线：本章要提前露出什么？
```

示例：

```text
A线：沈砚破解地下武库权限。
B线：他发现武库系统识别他的血。
C线：系统日志里首次出现“天穹母舰”。
```

### 禁止写法

```text
本章只把旧副本打完。
旧悬念解决后，下一章才开始新悬念。
换地图后重新介绍新势力、新城市、新规则。
```

### 正确节奏

```text
旧悬念高潮中 → 插入新悬念线索
旧悬念解决时 → 新悬念已经生效
旧地图离开前 → 新地图的人/物/威胁已压到主角身上
```

# 2. 动作、反馈、代价补丁

## 2.1 科武动作链模板

每次战斗、科技操作、武道突破，都必须写成：

```text
决策 → 执行 → 物理反馈 → 结果 → 代价 → 新问题
```

### 示例

错误：

```text
沈砚爆发武意，一拳轰碎机甲。
```

可执行版：

```text
沈砚没有后退，左手扣住外骨骼脊柱接口，强行解除安全锁。

神经针阵刺入后颈。

他的视野瞬间泛红，心跳被战斗系统拉到每分钟二百二十次。

下一秒，他把武意压进右臂助推器，肘部喷口炸开蓝白尾焰，一拳砸进机甲胸甲。

装甲凹陷，反震也顺着骨骼爬回肩膀。

咔。

他的右臂脱臼了。

机甲没有倒，反而抬起头，用沈砚父亲的声音说：

“权限确认，实验体001归档。”
```

### 本补丁强制要求

每次主角开挂，必须扣一种代价：

```text
体能代价：昏厥、抽搐、失温、肌肉撕裂
寿命代价：细胞衰变、武纹崩坏、神经烧蚀
装备代价：外骨骼报废、能源耗尽、接口污染
关系代价：队友恐惧、导师失望、组织监视
资源代价：信用点清零、药剂耗尽、权限暴露
信誉代价：被怀疑作弊、通缉、实验体身份泄露
```

# 3. 失败模式库

## 3.1 崩文失败模式

### 失败模式A：悬念真空

表现：

```text
大反派死了。
遗迹探索完了。
主角拿到奖励。
下一章开始新地图介绍。
```

风险：

```text
读者完成情绪释放后，没有继续追读理由。
```

修复动作：

```text
在大反派死前，让他吐出更大势力名。
在奖励出现时，让奖励识别主角血脉。
在遗迹关闭前，让主角看见未来灾难倒计时。
```

---

## 3.2 换地图崩文

表现：

```text
地球篇结束。
突然进入月面基地。
连续三章介绍月面城市、阶层、学院、势力。
```

风险：

```text
读者感觉换了一本书。
```

修复动作：

```text
地理可以换，核心冲突不能换。
新地图必须带着旧敌人、旧谜题、旧代价进入。
```

科武执行版：

```text
不是“沈砚去了月面基地”。
而是“追杀沈砚的天穹财团，把他的妹妹转移到了月面基地”。
```

---

## 3.3 多视角失败

表现：

```text
主角刚有代入感，突然切反派、切议会、切女主、切路人。
```

风险：

```text
读者不知道该站谁。
```

修复动作：

```text
前期数万字锁主角视角。
他人情报通过主角听到、看到、误判、调查得知。
```

允许例外：

```text
反派视角 ≤ 几百字
必须有强记忆点
必须制造压迫感
必须回扣主角危机
不能单纯解释设定
```

# 4. 人物口吻补丁

## 4.1 主角口吻

适合《科武纪元》的主角口吻：

```text
冷静、压抑、行动优先。
不长篇解释三观。
不主动炫耀设定。
用判断、动作、选择体现性格。
```

示例：

```text
“我不需要知道它为什么能活。”

沈砚把断裂的神经线咬在齿间，重新接入接口。

“我只需要知道，它现在会不会死。”
```

---

## 4.2 配角口吻

配角必须一人一口癖/思维方式。

### 科研型

```text
说话带参数、风险、实验结论。
```

示例：

```text
“你的武纹不是进化，是污染。区别在于，进化会变强，污染只会让你更像它们。”
```

### 武道型

```text
说话重感受、血性、胜负。
```

示例：

```text
“别跟我讲权限。拳头打得穿装甲，权限自然会开。”
```

### 财团/军方型

```text
说话重成本、秩序、控制。
```

示例：

```text
“沈砚不是学生，是失控资产。资产失控，就该回收。”
```

### 狼人篇可借点

狼人篇适合借：

```text
身份隐瞒
阵营怀疑
夜晚行动
群体投票/排斥
熟人变敌人
“他是不是怪物”的身份钩子
```

科武转译：

```text
狼人身份 → 实验体污染身份
满月失控 → 武纪共振失控
村民怀疑 → 学院/军方审查
银器克制 → 特定频率/神经抑制器克制
```

# 5. 段落节奏补丁

## 5.1 单章内部节奏

推荐节奏：

```text
开头30%：承接上章钩子，立刻进入行动
中段50%：冲突升级，出现物理反馈和代价
末尾20%：解决局部问题，同时抛出更大问题
```

禁止：

```text
开头大段回忆
新地图先观光
设定连续解释超过3段
主角原地思考超过500字
```

---

## 5.2 科武设定释放节奏

设定必须跟着事件出现。

错误：

```text
讲解武纪能源的历史、分类、原理。
```

可执行：

```text
主角使用武纪能源失败。
接口烧伤。
导师骂他乱接频段。
读者顺便知道武纪能源有频段限制。
```

规则：

```text
先出问题，再出设定。
先出代价，再出原理。
先让主角疼，再让读者懂。
```

# 6. 章末钩子补丁

## 6.1 每章末尾必须留一个未解项

章末钩子类型：

```text
身份钩：敌人为什么有主角基因？
危机钩：倒计时只剩十分钟。
关系钩：队友发现主角不是正常人。
资源钩：唯一药剂被抢走。
反转钩：导师其实是监控者。
地图钩：新地点不是新副本，而是旧谜题核心。
能力钩：主角新能力会吃掉记忆。
```

---

## 6.2 科武章末钩子示例

```text
沈砚终于打开了冷冻舱。

舱里没有尸体。

只有一枚还在跳动的机械心脏。

心脏外壳上，刻着他的名字。

制造日期：十七年前。
```

# 7. 评论区处理补丁

## 7.1 评论分类

收到差评后，只分两类。

### 可改类

```text
错别字
常识错误
时间线错误
前后设定冲突
人物名字写错
战斗逻辑断裂
```

动作：

```text
立即修。
不解释。
不吵架。
```

### 不可随便改类

```text
催主角立刻变强
要求马上杀女主/男配
要求提前揭晓身世
要求删虐点
要求缩短CP拉扯
要求换主线
```

动作：

```text
看追更曲线。
数据没崩，不改主线。
数据连续下滑，再查具体章节动作。
```

---

## 7.2 平台门禁

发布风险门禁：

```text
不和读者对线。
不置顶争议评论。
不在作话解释主线意图。
不因评论区高赞临时改大纲。
```

包装门禁：

```text
书名、简介、封面承诺什么，前三章必须交付什么。
简介写科武爽文，开篇不能连续三章讲设定。
简介写废土逆袭，开篇必须有压迫、反击、代价。
```

推荐节点门禁：

```text
8万字前：检查钩子库存，确保推荐期有连续追读点。
20万字前：检查是否换地图、换核心冲突、换主角目标。
每卷结束前：旧大钩收束，新大钩必须已露头。
```

# 9. 章节自检清单

写完后逐条打勾。

## 9.1 悬念检查

```text
□ 本章至少有2条活跃悬念。
□ 本章解决旧问题时，制造了新问题。
□ 下一根悬念的人/物/线索已经提前露面。
□ 章末有明确未解项。
□ 读者能用一句话说出“下一章想看什么”。
```

## 9.2 视角检查

```text
□ 前期章节默认锁主角视角。
□ 没有无意义上帝视角。
□ 配角视角若出现，控制在几百字内。
□ 配角视角不是为了解释设定，而是制造压力/危机。
□ 他人事件能否改成主角听闻、看到、调查得知？能则改。
```

## 9.3 节奏检查

```text
□ 开头没有长篇回忆。
□ 开头承接上章钩子并立刻行动。
□ 中段有冲突升级。
□ 结尾不是纯结算奖励。
□ 没有把30万字拉扯压成10万字交付。
```

## 9.4 科武质感检查

```text
□ 科技/武道动作有动作链。
□ 能力使用有物理反馈。
□ 胜利有代价。
□ 设定不是百科式讲解。
□ 设定由事件触发。
□ 环境描写没有超过事件描写。
```

## 9.5 换地图检查

```text
□ 本章若换地图，是被事件逼过去的。
□ 换地图没有换掉核心冲突。
□ 旧敌人/旧谜题/旧代价被带入新地图。
□ 没有连续观光式描写。
□ 读者记住的是主角做了什么，不是去了哪里。
```

## 9.6 评论风险检查

```text
□ 没有因评论提前揭晓大谜题。
□ 没有因读者催爽而破坏节奏。
□ 常识bug已修。
□ 主线节奏不被评论区绑架。
□ 作话不和读者对线。
```

# 10. 短故事/狼人篇可借点

适合短故事、狼人篇直接借用：

```text
1. 单场景高压结构。
2. 身份怀疑。
3. 熟人之间互相试探。
4. 每轮事件淘汰一个安全选项。
5. 夜晚行动制造未知。
6. 主角视角限制信息。
7. 章末用“谁是怪物”做钩子。
8. 群体舆论压迫主角。
```

可转成科武短篇：

```text
封闭实验站。
一人被武纪污染。
所有人都有感染嫌疑。
主角必须在天亮前找出污染源。
但最后检测结果显示：污染源是主角自己。
```

适合练习：

```text
视角锁定
悬念递进
人物口吻区分
章末反转
身份钩
小地图内高密度冲突
```

# 11. 科武长篇可借点

适合《科武纪元》长篇使用：

```text
1. 多悬念并行：科技谜题、武道成长、势力阴谋、身世真相。
2. 换地图延后：地球→轨道→月面→深空，不急着跳。
3. 地理可换，核心冲突不换。
4. 设定随事件释放。
5. 主角视角为锚点。
6. 反派/势力视角少量插入，只用来制造压迫。
7. 20万字前做悬念库存盘点。
8. 大悬念揭晓前，必须让下一大钩提前露头。
```

科武长篇推荐悬念库存：

```text
短钩：本章敌人是谁、下一击怎么躲、药剂有没有副作用。
中钩：主角武纹为什么异常、学院为什么监控他、母舰信号来自哪里。
长钩：武纪能源真相、父亲失踪真相、人类文明是否被改写。
终极钩：主角到底是人类进化样本，还是外来文明的回收坐标。
```

# 12. 发布/包装/风险门禁

## 12.1 发布前门禁

```text
□ 前三章是否交付简介承诺？
□ 第一章是否有危机、行动、反馈、钩子？
□ 是否存在连续设定解释？
□ 是否锁定主角视角？
□ 是否有明显反三观发言？
□ 章末是否能拉下一章？
```

## 12.2 推荐节点门禁

### 8万字前

```text
□ 主角目标是否明确？
□ 至少3条悬念线是否存在？
□ 推荐期是否连续有爽点/危机/反转？
□ 是否存在大段低事件密度章节？
```

### 20万字前

```text
□ 是否即将换地图？
□ 换地图是否会导致换书感？
□ 旧敌人是否随主角进入新阶段？
□ 新地图是否提前铺垫过？
□ 大悬念揭晓后是否有新大钩？
```

## 12.3 评论区风险门禁

```text
□ 不开麦。
□ 不对线。
□ 不解释伏笔。
□ 不承诺改主线。
□ 不因单条热评重写剧情。
□ 只根据追更/留存/收益判断是否调整节奏。
```

# 13. 最终执行口令

写每章前默念：

```text
我不是在移动主角。
我是在推进事件。

我不是在解释世界。
我是在让主角为理解世界付出代价。

我不是在解决悬念。
我是在交接悬念。

我不听评论区改主线。
我只看数据修节奏。
```
