## 二、核心执行补丁（动作-反馈-代价-失败模式）

### 【补丁A】开局定留存——高势能开局执行协议

**触发条件**：每一卷/每一章的首300字

**作者动作**：
1. 感知——扫描当前场景是否有「生存危机/力量体系暗示/身份张力/倒计时压迫」
2. 决策——从以下高势能模式中选1种强制植入：
   - 【苏醒型】从深空监狱/基因改造舱/废土隔离区/冬眠舱醒来（自带力量体系暗示）
   - 【倒计时型】XX分钟内不执行某操作将触发不可逆代价
   - 【身份暴露型】核心秘密被逼近曝光临界点
   - 【力量失控型】异能/义体/机甲处于临界状态
3. 执行——首句即触达冲突核心，禁止背景铺垫/世界观说明书/日常寒暄

**物理反馈**：
- 苏醒型→感官重载（重力失调/神经同步延迟/记忆碎片闪回）
- 倒计时型→身体应激反应（肾上腺素飙升/瞳孔收缩/肌肉紧绷）
- 身份暴露型→环境压迫（监控警报/追踪信号逼近/同伴质疑目光）

**代价锁定**（写前必填）：
| 开局模式 | 必须绑定的代价类型 |
|:---|:---|
| 苏醒型 | 醒来前的身份/记忆/阵营存在缺陷（例：身体被改造、记忆缺失、已被通缉） |
| 倒计时型 | 超时后果必须是「不可逆实体损失」而非「心理压力」 |
| 身份暴露型 | 暴露后必须有「第三方势力介入打破现有平衡」 |
| 力量失控型 | 失控必须有「反噬代价」（例：神经损伤、阵营敌对、道德妥协） |

**失败模式识别**：
- ❌ 首句为环境描写（"天空是灰色的..."）
- ❌ 首句为角色内心独白（"我想起过去..."）
- ❌ 首3句内出现"当时"、"曾经"、"回忆"
- ❌ 日常寒暄超过2回合（"早啊"、"吃了没"）
- → 触发自检：当前开局是否能让读者产生「我想知道接下来发生了什么」的即时好奇？

### 【补丁B】冲突推进——单章信息密度执行标准

**触发条件**：每3000字章节

**作者动作链**（四步闭环）：
```
感知→决策→执行→结果
```

**感知层**（50-100字）：
- 主角当前掌握的关键信息（敌人能力/环境变量/规则限制）
- 可用资源盘点（装备/盟友/时间窗口）
- 核心矛盾当前状态

**决策层**（50-100字）：
- 基于当前信息做出选择（攻击/防守/谈判/逃跑/启用底牌）
- 决策必须受限于「已知信息+性格标签+当前资源」
- 禁止「上帝视角决策」（主角知道读者知道但主角不该知道的信息）

**执行层**（200-400字）：
- 战斗类：启动逻辑→操作步骤→物理限制→实时反馈
- 谈判类：筹码展示→对方反应→筹码追加/缩减→僵局/突破
- 探索类：环境感知→路径选择→障碍触发→解决方案
- **科武场景特化**：
  - 义体启动需校准神经（2-3秒延迟反馈）
  - 重火力武器有冷却周期/弹药限制/过热警告
  - 战术级行动需"感知-决策-执行"时间窗口（被敌人利用的弱点）

**结果层**（100-200字）：
- 成功：收益是什么？（资源获取/信息增量/关系变化）
- 失败：代价是什么？（资源损耗/信息泄露/关系恶化）
- 平局：悬念升级是什么？（下一轮冲突筹码重置）

**信息密度门禁**（每800字检查1次）：
| 800字区间 | 最低有效信息量 |
|:---|:---|
| 0-800 | 核心冲突类型+主角当前目标 |
| 800-1600 | 冲突升级/反转/新变量介入 |
| 1600-2400 | 信息增量（敌人弱点/隐藏规则/关系变化） |
| 2400-3000 | 章末钩子铺设+下一章悬念锚定 |

**失败模式识别**：
- ❌ 单章内无任何冲突推进（全是日常互动）
- ❌ 主角决策无信息支撑（"我想了想就决定这么做"）
- ❌ 战斗场景跳过执行过程（"他一个技能秒杀了敌人"）
- ❌ 章末无钩子（纯情绪收尾/场景描写收尾）
- → 触发自检：当前章节能回答「这章解决了什么？留下了什么？」吗？

### 【补丁C】人物标签锚定——角色辨识度执行标准

**主角标签矩阵**（写前必填，至少3项）：

| 标签类型 | 示例 | 绑定规则 |
|:---|:---|:---|
| **行为锚点** | 启动义体前必校准神经/拔刀前必闭眼3秒/开火前必报坐标 | 固定动作在危机场景中反复出现，强化读者记忆 |
| **前置条件** | 只在吃饱后才做决策/受伤时脾气暴涨/面对孩子无法说谎 | 触发条件→行为变化，易制造戏剧反差 |
| **口头禅/语言风格** | "效率优先"/"数据不会骗人"/"我只看结果" | 融入对话/独白，区分其他角色 |
| **代价敏感点** | 绝不让同伴送死/不能接受欺骗/最怕记忆被篡改 | 触发角色核心恐惧，制造人物弧光 |
| **科武特化** | 义体过热时会出现机械口音/战斗时瞳孔会切换热成像/重伤时意识会接入临时AI | 科幻化行为标签，兼顾人设+科幻质感 |

**配角功能分配**（每章最多出现4个配角，禁止堆砌）：

| 功能类型 | 任务 | 禁用行为 |
|:---|:---|:---|
| **推剧情型** | 带来关键信息/开启新场景/触发新冲突 | 不允许只说台词不做事 |
| **供情绪型** | 提供笑点/泪点/爽点 | 不允许情绪无来源（作者强行煽情） |
| **造障碍型** | 设置难题/逼迫主角做出代价选择 | 不允许无脑敌对（需有合理动机） |

**科武长篇标签特化要求**：
- "人狠话不多"必须补充：**为何狠**（被机甲夺走家人）+ **代价是什么**（每杀一人神经污染加深）
- 避免扁平化：主角标签需与世界观产生化学反应（义体改造→身份认同危机、战斗能力→道德边界模糊）

**失败模式识别**：
- ❌ 读者无法用一句话描述主角特征
- ❌ 主角行为在不同章节出现矛盾（无明确性格逻辑）
- ❌ 配角功能重复（两个都是"推剧情"，无差异化）
- → 触发自检：这个角色在不使用名字的情况下，能否通过3句话被识别出来？

### 【补丁D】章末钩子——悬念闭合度执行标准

**钩子类型矩阵**（每章必须植入≥1种）：

| 类型 | 描述 | 科武场景示例 |
|:---|:---|:---|
| **危机逼近型** | 已知威胁正在接近，但细节未明 | 追踪信号锁定主角，3小时后抵达 |
| **关键道具缺失型** | 需要某物解决当前困境，但该物不在手中 | 破解密码需要XX芯片，但芯片在敌人手中 |
| **身份暴露倒计时型** | 秘密即将曝光，后果未明 | 义体留下可追溯的战斗数据，清理队已出动 |
| **二选一困境型** | 两个选项都有明确代价，无法两全 | 救队友需要暴露位置，不救队友心理崩溃 |
| **规则颠覆型** | 表面规则被打破，新规则未知 | "安全区"突然出现生物入侵，战力重新洗牌 |
| **关系逆转型** | 已知关系出现裂缝/反转 | 盟友的义体数据与敌人系统存在后门关联 |

**钩子铺设节奏**（3000字章节）：
- **章首（0-300字）**：建立本章核心期待（"这章要解决什么问题？"）
- **章中（300-2400字）**：推进冲突，逐渐逼近钩子
- **章末（2400-3000字）**：钩子曝光，但留一半（给出问题，答案在下章）
  - ✅ "追踪信号锁定了他的位置——但锁定的是哪个身份？"
  - ❌ "他发现了一个惊天大秘密"（无悬念）
  - ❌ "敌人来了，他很紧张"（情绪收尾，无事件收尾）

**科武长篇钩子特化**：
- 技术钩子：破解协议需要特殊设备/权限，但主角不具备
- 规则钩子：表面规则被证伪（如"安全区"实际是诱饵）
- 阵营钩子：盟友的忠诚存疑（义体数据泄露/通讯被监听）

| — | **物理反馈** | 每场高强度动作必须伴随环境破坏/机体负荷/感官异常，禁止空洞形容词（"很强/很痛/很快"） |
| — | **风险门禁自检** | 写前检查：标题党陷阱/无逻辑换地图/纯武力平推/标签扁平化（任一触发→重写） |

## 四、章节自检清单（科武纪元作家OS版）

**写前检查（动笔前完成）**：
- [ ] 首章前300字是否已植入高势能冲突？（无日常铺垫）
- [ ] 主角是否具备≥3项标签？（行为锚点/前置条件/口头禅/代价敏感点/科武特化）
- [ ] 本章核心交付物是否明确？（爽点/揭秘/情感/博弈）
- [ ] 章末钩子类型是否已确定？（危机/道具/身份/困境/规则/关系）

**写中检查（每800字节点）**：
- [ ] 当前800字区间是否有有效信息增量？（冲突升级/反转/新变量）
- [ ] 主角决策是否基于「已知信息+性格标签+当前资源」？（禁止上帝视角）
- [ ] 高强度动作是否伴随物理反馈？（感官异常/机体负荷/环境破坏）
- [ ] 科幻设定是否转化为具体冲突？（禁止说明书段落）

**写后检查（完稿后完成）**：
- [ ] 章末钩子是否已触发但未闭合？（给出问题，答案在下章）
- [ ] 本章代价是否已兑现？（资源损耗/信息泄露/关系恶化）
- [ ] 章首预期与章末兑现是否匹配？（禁止预期错位）
- [ ] 是否存在凑字数行为？（重复描写/无效对话/水文段落）
- [ ] 战力/科技升级是否有前置铺垫？（禁止机械降神）
- [ ] 标题是否精准提炼本章最大看点？（禁止标题党）
- [ ] 配角功能是否明确？（禁止工具人堆砌）
- [ ] 平台适配性自检：更新频率/评论区运营/风险门禁

**科武长篇特化检查项**（适用于≥30万字作品）：
- [ ] 换地图是否有逻辑支撑？（航道限制/政治博弈/跃迁成本）
- [ ] 战斗是否包含科技/战术/环境/规则四维？（禁止纯武力平推）
- [ ] 主角标签是否与世界观产生化学反应？（义体改造→身份危机/战斗能力→道德模糊）
- [ ] 势力版图/科技树是否自洽？（禁止为升级随意跳跃星系/维度）

## 五、风险门禁清单（平台规则→作家可执行触发点）

### 【门禁A】点击率门禁——标题即分发触点

**触发条件**：章节标题确定前

**执行标准**：
- 推荐标题必须精准提炼本章最大看点（悬念/反转/爽点/代价）
- 禁止：标题与内容不符（如标题写"惊天大战"实际写日常）
- 禁止：标题过于模糊（如"他的一天"、"新的开始"）
- 禁止：标题暴露全部结局（如"主角原来是他父亲"）

**正确示例**（科武场景）：
- ✅ "义体过热，他选择透支寿命换输出"
- ✅ "安全区沦陷前最后60秒"
- ✅ "通讯被截获，他有三个选择"
- ❌ "机甲之战"（泛泛而谈）
- ❌ "主角的秘密"（过于模糊）

---

### 【门禁B】完读率门禁——信息密度即留存

**触发条件**：章节撰写过程中（每800字检查1次）

**执行标准**：
- 每章必须完成≥1次有效冲突推进或信息反转
- 禁止：凑字数（重复描写/无效对话/背景复述）
- 禁止：情绪驱动替代事件驱动（"他很伤心"→"他做了什么导致悲伤的事"）
- 禁止：设定说明书（用生存压力/利益博弈包装技术逻辑）

**科武长篇特化**：
- 设定堆砌→设定服务于冲突（每段科幻描写必须推动剧情或揭示人物）
- 无效环境描写→环境作为冲突变量（如重力异常/辐射区/电磁干扰影响战斗）

---

### 【门禁C】逻辑换地图门禁——世界观自洽即长篇寿命

**触发条件**：场景切换/地图切换时

**执行标准**：
- 换地图必须有明确逻辑支撑：航道限制/政治博弈/跃迁成本/任务驱动
- 禁止：为升级随意跳跃星系/维度（读者会质疑"为什么他能去那里？"）
- 换地图后必须更新势力版图认知（新势力/新规则/新威胁）

**正确流程**：
```
触发事件（任务/追杀/机遇）→代价权衡（时间/资源/风险）→逻辑支撑（航道解锁/权限获取/向导出现）→新场景落地
```

---

### 【门禁D】纯武力平推门禁——战术纵深即科幻质感

**触发条件**：战斗场景设计时

**执行标准**：
- 战斗必须包含≥2个以下维度：科技（装备/武器/协议）/战术（走位/配合/时机）/环境（地形/天气/变量）/规则（限制/协议/代价）
- 禁止：一招秒杀/实力碾压/降智反派
- 主角越级战斗必须有明确代价（寿命折损/装备损毁/阵营敌对）

**科武战斗标准结构**：
```
感知层（探测/分析）→决策层（基于信息的战术选择）→执行层（科技操作+武技展示）→代价层（资源消耗/机体负荷/副作用）
```

---

### 【门禁E】标签扁平化门禁——人物弧光即情感深度

**触发条件**：主角/核心配角人设确定时

**执行标准**：
- 每个标签必须回答：为什么有这个标签？（动机）+ 代价是什么？（后果）
- 禁止：脸谱化（如"人狠话不多"但不知道为何狠、代价是什么）
- 标签必须与世界观产生化学反应

**示例**（"人狠话不多"→科武版）：
- 标签：杀伐果断，战斗中绝不手软
- 动机：童年目睹机甲屠杀平民，坚信"对敌人仁慈=对自己人残忍"
- 代价：每杀一人神经污染加深3%，接近失控临界点
- 冲突触发：面对投降的敌人（曾经是盟友），杀还是不杀？
