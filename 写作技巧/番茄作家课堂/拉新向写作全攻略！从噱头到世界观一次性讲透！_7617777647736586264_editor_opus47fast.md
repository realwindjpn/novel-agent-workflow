# 《科武纪元》编辑学习笔记 — 拉新向写作全攻略

> 来源：番茄作家课堂 / 品类指南 / 2026-03-18 / 主讲：爱哭的小十七
> 适用：长篇主线《科武纪元》、衍生短故事、热点稿

---

## 1 课程核心判断（6条）

1. **噱头 ≠ 脑洞**：噱头是"让划手指的人停下"的引流亮点；脑洞是它的一种实现方式，情绪反差同样算。
2. **得情绪者得天下**：噱头决定点击，情绪决定追读，男频三种情绪即可覆盖九成读者——期待、爽快、遗憾。
3. **人设要"标签化 + 反差感 + 强动机"**，复杂立体人设在拉新阶段是负资产。
4. **世界观最不重要**（开篇阶段）：宏大设定救不了前三章，难懂的自创术语只会赶人。
5. **信息差是判断噱头/人设/情绪/世界观是否合格的唯一硬指标**——主角知道而配角不知道，或读者知道而角色不知道。
6. **微创新优于大创新**：在熟体系上加一个新属性/新身份（如"国家当金手指"、"真·废材"），比另起炉灶安全且吸量。

## 2 可执行编辑规则

### 开篇（前3章 / 前2000字）
- **第1页必须出现噱头**：一句话能在抖音文案位讲清楚（反差句式或情绪句式）。
- 噱头三选一：**脑洞型**（设定反常识）/ **情绪型**（屈辱、背叛、错过）/ **身份型**（隐藏身份+错配场景）。
- 开篇禁写：世界观长篇科普、术语堆叠、多POV切换。

### 节奏
- **憋屈—爆发同章或紧邻章**：上一章受辱，下一章打脸，不让读者憋超过一章。
- 爆发场景**人越多越好**（宴会、广场、直播间、议会），围观放大爽感。
- 单章聚焦**一种情绪**，禁止悲喜混搭。
- 反派被打脸后**立即退场或降权**，不允许长期嚣张。

### 冲突
- 冲突单元四段式：**细节铺垫 → 情绪蓄力 → 极致爆发 → 余韵收尾（埋钩子）**。
- 冲突触发由**反派/配角主动挑衅**，主角被动反击，避免主角显得刻薄。
- 每次爆发必须用**信息差**收割：反派不知道主角真实身份/实力/底牌。

### 人物
- 主角：一个**强标签** + 一个**反差** + 一个**直白动机**（复仇 / 守护 / 归位）。
- 不写主角的复杂心理独白，情绪走**动作—生理反应—一句台词**。
- 配角/反派当工具人：辅助型负责崇拜，垫脚型负责被打脸，反派负责嚣张+欠揍。
- 一旦定下"爱妻 / 护短 / 独行"，后续严禁人设漂移。

### 题材
- 选熟体系打底（修仙/赘婿/重生/战神归来），在金手指或身份层做微创新。
- 金手指方向：**外部赋能型**（国家、文明、组织）当前最吃香，比"系统/法宝"新鲜。
- 题材融合优先选"玄幻 × 现实灵异"、"修仙 × 民俗"等强信息差组合。

### 改编 / 短视频化
- 立项时同步写好**抖音文案一句话**和**封面反差点**，写不出来=噱头不合格。
- 关键打脸场景按短剧节拍写：30秒一个反转、围观者表情特写、反派狼狈细节。

### 平台规则（番茄拉新向）
- 在读人数高的同期作品必须拆解（不论喜好），拆四项：噱头 / 情绪点 / 人设 / 打脸节奏。
- 男频不要堆世界观；女频可参考但情绪权重更高。
- 章节名带钩子句（如"我不给的，你不能抢！"），命中推荐位文案需求。

## 3 科武适配

### 可用点
- **"科武纪元"本身即是天然噱头型设定**：科技 vs 武道的体系冲突，开篇一句话可讲清（如"高武世界突然降临量子兵器"）。
- **金手指外部化**：可借鉴《向仙文明》——让"国家 / 科研体系 / 旧文明残骸"为主角赋能，激活集体情绪，比单人系统更燃。
- **信息差天然充足**：科技党不知武道真相、武道宗门不知科技底牌、读者上帝视角双向看戏，三层信息差是爽点矿脉。
- **反差人设**：可塑"实验室废柴 × 武道天骄"或"武道废人 × 科研鬼才"的标签化主角。
- **遗憾感落点**：前世科技文明覆灭 / 武道断代 / 同伴牺牲，单点放大即可，不要群像悲情。
- **打脸舞台**：学术会议、武道擂台、跨阵营听证会——都是"宴会厅级"高围观场景。

### 不可硬套点
- **世界观体量大**：科武双体系本身就重，绝不可前三章铺科技史+武道史，必须靠角色场景带出。
- **术语自创风险高**：能用"筑基/金丹"对应"奇点/共振"就直接用读者熟词，禁止造一堆"虚源·灵核·量场"类陌生词。
- **复杂派系/伦理冲突**：拉新阶段不写，留到中期世界观补完。
- **多线叙事 / 群像**：与"主角聚焦"原则冲突，短故事和热点稿尤其忌讳。
- **科技硬核细节**：不要为了"科幻感"上公式和论文式描写，会击穿拉新读者阈值。

## 4 编辑检查表（10条）

1. 一句话噱头是否能直接做抖音文案？
2. 前3章是否出现"被轻视/羞辱/背叛"的代入锚点？
3. 第一个爽点是否在前5章内引爆？
4. 每次冲突是否走完"铺垫—蓄力—爆发—余韵"四段？
5. 爆发场景围观者数量与反应是否写够？
6. 主角是否具备"标签 + 反差 + 强动机"三件套？
7. 反派是否做到嚣张到位、打脸后立即退场？
8. 是否存在至少一层信息差贯穿当前卷？
9. 是否避免了自造难懂术语 / 大段世界观科普？
10. 单章是否聚焦一种核心情绪，未出现情绪混乱？

## 5 对作家角色的输入要求

为保证可编辑、可拆条、可短视频化，作家提交每章/每段需附以下五项（可作为提纲模板字段）：

### ① 动作链
- 主角与对手的动作按"触发—对抗—破局"三拍列出，每拍≤2个动作。
- 禁止心理独白替代动作；情绪通过动作外化。

### ② 物理反馈
- 每次冲突给出至少一处身体级细节：呼吸、肌肉、血、温度、武器/装备的物理响应。
- 科武场景必须写出"科技装置 × 武道劲力"的可感受现象（声、光、震、热），让读者听得见看得见。

### ③ 代价
- 主角每次开金手指 / 突破 / 爆发，必须标明代价（生理、寿元、关系、信息暴露、阵营反噬）。
- 代价是后续钩子的弹药库，不写代价=透支爽感。

### ④ 钩子
- 章末一句钩子，三选一：身份将揭 / 强敌将至 / 真相反转。
- 卷末钩子需升级到阵营级或体系级。

### ⑤ 读者预期
- 写明本章想让读者产生的下一步期待（一句话）：例如"读者期待下一章主角在听证会上亮出武道身份"。
- 编辑据此核对：钩子是否兑现预期？兑现是否超出预期？未达预期即回炉。

---

**一句话编辑准则**：科武纪元的拉新写作 = **熟体系打底 + 双体系反差当噱头 + 三层信息差当弹药 + 单情绪单章节奏推进**，世界观留到稳读者后再铺。
