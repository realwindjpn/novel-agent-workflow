## 二、章节自检清单

> 完成章节后逐项核验。不合格项需在下一章修复或找到合理解释。

### 情绪代偿检验

```
□ 本章情绪波峰是否在前3章有铺垫？（预期预埋）
□ 情绪爆发是否具备“意料之外、逻辑之内”的兑现方式？
□ 爽感释放后是否立即衔接代价/反噬？（爽感不能断崖）
□ 读者是否能从主角行为中识别出“清醒的疯”逻辑？
```

### 节奏结构检验

```
□ 开篇是否在500字内完成情绪定调？（禁止先铺设定）
□ 每800字是否有一个小情绪点？（对话/动作/反杀）
□ 章末钩子是否绑定下一章情绪波峰？（禁用纯信息交代）
□ 高压场景后是否有3-5段松弛缓冲？（日常/调侃/错位互动）
□ 连续情绪释放不超过2章（需插入资源消耗/策略转换）
```

### 代价系统检验

```
□ 本章主角的“发疯/破局”是否付出具体代价？
□ 代价是否推动下一轮冲突？（不能只爽不付出）
□ 是否存在无代价的“嘴炮胜利”或“设定碾压”？（删除此类内容）
□ 配角是否也承担代价？（避免主角独爽）
```

### 二创适配检验

```
□ 本章是否有独立可传播的“切片位”？（台词金句/名场面/反杀瞬间）
□ 对话占比是否>40%？（压缩心理独白，增强画面感）
□ 名场面是否具备“强视觉+强情绪+易二创”三要素？
```

### 科武适配检验（长篇专项）

```
□ 世界观/力量体系是否通过事件自然揭示？（禁止章首设定堆砌）
□ 战术/武技是否有具体执行序列？（禁用“意念流”打斗）
□ 主角行为是否符合科武逻辑自洽？（不能仅靠情绪爆发）
□ 情感线是否为副线？（不能喧宾夺主或套用恋综框架）
```

### 平台规则检验

```
□ 章节标题是否直击情绪痛点？
□ 简介是否在10章内完成核心梗/标签绑定？
□ 是否规避平台敏感词？（涉政/涉黄/涉暴/违禁词）
```

## 三、执行动作库

### 触发-决策-执行-结果闭环模板

#### 【类型A：发疯式破局】

```
【触发】主角遭遇规训/系统压制/不公事件
  → 检测点：事件是否锚定读者真实痛点？
  → 锚定例：宗门资源垄断、技术封锁、身份歧视

【决策】主角选择“外耗”而非“隐忍”
  → 检测点：决策是否体现“清醒的疯”？（非为疯而疯）
  → 决策模板：看似荒诞的解法背后有严密逻辑支撑

【执行】打破规则/利用系统漏洞/反向操作
  → 检测点：执行是否伴随具体行为/技能/道具？（非空喊）
  → 执行要素：肢体动作+环境互动+物理反馈

【结果】爽感释放+代价反噬
  → 检测点：爽感后是否立即衔接代价？
  → 爽感结构：破局→短暂优势→新阻力/反噬→悬念
```

#### 【类型B：情绪代偿释放】

```
【触发】主角长期压抑情绪积累到阈值
  → 检测点：压抑源是否在3章前预埋？（情绪预期管理）

【决策】寻找“合规的情绪出口”（非无理爆发）
  → 检测点：出口是否具备正当性/合理性？
  → 决策模板：在读者预设的“安全出口”之外寻找意外路径

【执行】借他人场景/借题发挥/借力打力
  → 检测点：执行是否利用“错位”制造喜剧/爽感？
  → 执行要素：他人反应+环境衬托+主角掌控感

【结果】情绪释放+关系变化+新隐患
  → 检测点：是否改变主角与其他角色的关系动态？
```

### 科武长篇适配动作（替代甜宠结构）

```
【战术反常规】
  触发：遭遇力量压制/系统封锁
  决策：拒绝正面硬刚，寻找规则漏洞/环境变量/系统缺陷
  执行：利用非常规手段（信息差/道具/队友配合/地形）
  结果：战术胜利+暴露自身弱点+敌方重新评估

【系统漏洞利用】
  触发：发现规则/体系的执行缺陷
  决策：以彼之道还施彼身，用规则反杀规则
  执行：操作流程需具体可追踪（证据/流程/见证者）
  结果：短期收益+权威树敌+后续追杀/封锁

【阵营博弈破局】
  触发：被多方势力夹击/资源困局
  决策：不选边站，制造新的利益共同体或利益冲突转移
  执行：需展示信息操控/利益计算/借力过程
  结果：生存空间拓展+真相碎片+新派系忌惮
```

## 四、反馈机制

### 正向反馈（强化行为）

| 触发条件 | 反馈类型 | 执行方式 |
|:---|:---|:---|
| 主角破局成功 | 读者情绪共鸣 | 在评论区收集“高频情绪关键词”，在后续章节植入 |
| 名场面传播 | 平台数据反馈 | 记录“小盐子爆款章节”的“情绪词云”，对标使用 |
| 角色高光时刻 | 读者自发二创 | 在后续章节预留同类场景的升级版 |
| 配角/CP互动出圈 | 社交传播 | 增加配角戏份或绑定更多情绪功能 |

### 负向反馈（修正行为）

| 触发条件 | 反馈类型 | 执行方式 |
|:---|:---|:---|
| 情绪爆发后断崖 | 读者弃文 | 紧急修复：补代价+悬念，3章内回到正轨 |
| 世界观铺陈过重 | 读者跳章 | 立即压缩设定，转为“事件驱动”结构 |
| 配角工具化 | 读者无感 | 下章增加配角独立视角或情绪兜底功能 |
| 节奏高压疲劳 | 追读下滑 | 插入日常/调侃场景，配置主角自嘲/错位互动 |

### 科武长篇反馈阈值

```
【危险信号】单章打斗>2000字且无情绪释放点 → 立即切换视角或插入日常
【危险信号】连续3章无主角高光 → 第4章强制安排情绪波峰
【危险信号】配角出场<3次/10章 → 下章强制增加配角戏份
【危险信号】核心设定未解释超过5章 → 中插“碎片化揭示”章节
```

## 五、代价系统

### 代价类型矩阵

| 代价类型 | 科武适用场景 | 爽感-反噬比例 |
|:---|:---|:---|
| **资源消耗** | 能量/道具/积分/权限消耗 | 爽感70%:反噬30% |
| **生理极限** | 身体损伤/能力透支/副作用 | 爽感60%:反噬40% |
| **关系损耗** | 信任/阵营/CP羁绊动摇 | 爽感50%:反噬50% |
| **系统反噬** | 被标记/追杀/封锁/规则惩罚 | 爽感40%:反噬60% |
| **信息暴露** | 暴露实力/弱点/意图 | 爽感55%:反噬45% |

### 代价设计原则

```
【必要原则】每次情绪释放必须付出代价，禁止无代价爽感
【推动原则】代价必须创造新的冲突或障碍，推动情节前进
【可感原则】代价必须具体可感知（非“感到疲惫”“有些代价”等模糊描述）
【延迟原则】大代价可分摊至2-3章，但需明确总量与触发节点
【反噬原则】爽感越大，反噬越重（爆款章的代价量级需匹配）
```

### 科武长篇代价模板

```
【章节代价示例】
  场景：主角用系统漏洞反杀高阶对手
  代价清单：
  ├ 资源消耗：本次使用消耗70%可用能量，3章内无法使用高级技能
  ├ 系统反噬：被标记为“规则破坏者”，核心NPC好感-20
  ├ 信息暴露：暴露自身拥有漏洞利用能力，招致更高级势力觊觎
  └ 生理极限：反噬导致身体出现不可逆损伤，影响后续修炼上限
```

## 六、失败模式库

### 情绪代偿类失败

| 失败模式 | 触发场景 | 修复方案 |
|:---|:---|:---|
| **为疯而疯** | 主角行为无动机逻辑，纯粹堆砌荒诞 | 回溯角色核心诉求，赋予每种行为正当性 |
| **情绪断崖** | 高潮后无代价/无延续，直接跳回日常 | 立即补代价场景，将日常与代价绑定 |
| **代偿无效** | 情绪释放后读者无感（爽感未传达） | 检测：是否在前3章预埋情绪预期？是否兑现意外但合理？ |
| **过度代偿** | 主角持续发疯无代价，读者疲劳 | 引入“反噬阈值”，设计主角的能力边界与后果 |

### 科武长篇类失败

| 失败模式 | 触发场景 | 修复方案 |
|:---|:---|
| **战力崩坏** | 主角越级击杀无代价无铺垫 | 补充战术逻辑（信息差/道具/环境/配合） |
| **设定堆砌** | 章首大段世界观/力量体系说明 | 改为事件驱动，设定通过对话/冲突自然揭示 |
| **主线失重** | 情绪流叙事导致长篇逻辑链断裂 | 强制梳理核心设定与伏笔，3章内回收一个旧伏笔 |
| **情感线喧宾** | 恋爱桥段占比>40%，挤压主线 | 情感线降级为副线，绑定主线事件（如并肩作战/利益同盟） |
| **放弃大纲** | 依赖“自然延伸”导致剧情散漫 | 强制补全主线节点，标注已完成的伏笔与待回收的悬念 |

### 节奏类失败

| 失败模式 | 检测方法 | 修复方案 |
|:---|:---|:---|
| **高压疲劳** | 连续2章高强度冲突无缓冲 | 立即插入日常/调侃/错位互动场景 |
| **情绪疲劳** | 连续3章情绪释放无新刺激 | 切换视角/引入新角色/增加新情绪类型 |
| **钩子失力** | 章末钩子无法引发下一章期待 | 检查钩子是否绑定情绪/悬念/反杀，而非纯信息 |
| **节奏塌陷** | 中段章节情绪密度显著低于开篇 | 从当前章节挖掘新冲突源，重新设计情绪波峰 |

## 七、人物口吻模板

### 核心口吻：“清醒的疯”模板

```
【内核】
  表面：荒诞/癫狂/反常规
  底层：清醒的目标、严密的逻辑、代价可接受

【句式结构】
  句式A（破局宣言）：[荒诞行为]，因为[正当事由/逻辑支撑]
  句式B（自嘲式发疯）：[看似失控的行为]。[停顿/反转]——其实算过了。
  句式C（反杀预告）：[对方以为稳赢]。[主角冷静执行]。[对方崩溃]
```

#### 科武主角口吻示例

```
【示例1：战术破局】
  反派：你以为凭你这点修为能突破结界？
  主角（平静）：突破？我不突破。我让它自己裂开。
  （动作：激活预设的环境变量，结界因共振自行崩溃）
  主角（继续）：顺便提醒，你的结界设计漏了共振频率。
  ——口吻特征：冷静告知替代嘲讽，行为先于语言

【示例2：规则反杀】
  长老：这规矩是我定的，你凭什么违反？
  主角（微笑）：您定的。您没写禁止“用您的权限操作您的账户”。
  （动作：展示转账记录/权限记录）
  主角：所以，这不算违反，叫“执行”。
  ——口吻特征：用对方逻辑反杀，嘲讽藏在行为里

【示例3：代价宣言】
  队友：你这样做会得罪所有人。
  主角（耸肩）：我已经计算过代价。得罪他们，救她，划算。
  （代价已发生：主角当众宣战，后被孤立）
  主角（内心独白）：习惯孤独。这比看着她死好接受。
  ——口吻特征：理性计算外表，情感内敛
```

### 配角/CP口吻模板

```
【情绪兜底型】
  功能：在主角发疯后提供“理性锚点”或“情感共鸣”
  口吻：担忧但不阻止，吐槽但不否定，担忧但不阻止
  句式：
    - “你疯了。”（停顿）“……但我帮你把风。”
    - “这样做有后果的。”（停顿）“算了，后果一起扛。”

【价值观镜像型】
  功能：与主角形成对照，揭示主题深度
  口吻：提出质疑但不劝阻，展示另一种可能但不替代主角选择
  句式：
    - “如果换成我，我会……”（停顿）“但你不是我。”
    - “你想过另一种方式吗？”（主角拒绝后）“好。那就按你说的走。”
```

### 群像口吻模板（适用于“短视频切片位”）

```
【错位互动模板】
  场景：主角做出荒诞行为，旁观者反应错位
  句式：
    - 角色A（震惊）：你真的……？
    - 角色B（冷静）：她一直都这样。习惯就好。
    - 角色C（兴奋）：这可以发帖吗？
  ——口吻特征：一人震惊、一人习惯、一人蹭热度，形成喜剧效果

【反杀打脸模板】
  场景：对方嘲讽主角，主角平静执行反杀
  句式：
    - 反派：你算什么东西？
    - 主角（平静动作）
    - 环境音/结果音
    - 主角（收尾）：现在你知道了。
  ——口吻特征：少言少语，用行动打脸
```

## 八、段落节奏模板

### 情绪波峰节奏

```
【波峰结构】
  平静铺垫（200-400字）→ 小情绪点（对话/动作/错位）
      → 压抑积累（300-500字）→ 触发事件（50字以内）
      → 情绪爆发（300-800字）→ 代价衔接（100-200字）
      → 章末钩子（50-150字）

【单章节奏公式】
  开篇钩子（150字）：情绪定调，禁止铺设定
  事件推进（800-1000字）：冲突展开
  小高潮（300-500字）：解压或反杀
  过渡/缓冲（200-300字）：日常/调侃/关系编织
  核心波峰（500-800字）：情绪释放+代价
  章末钩子（50-150字）：绑定下一章情绪/悬念/反杀
```

### 科武长篇节奏适配

```
【替代甜宠节奏的科武节奏】
  主线推进（战斗/系统/谜题）: 情绪释放 ≈ 7:3
  
  【节奏示例】
    第1-3章：战斗/系统危机
    第4章：情绪释放（反杀/规则打破）
    第5章：代价承接（追杀/封锁/损失）
    第6章：喘息/日常（恢复节奏，但绑定新隐患）
    第7-8章：新冲突/新主线推进
    
  【禁忌】连续3章纯战斗无情绪释放；连续3章纯情绪流无主线推进
```

### 短视频切片节奏

```
【单场景切片节奏】
  10秒内：强台词/强动作（建立期待）
  10-20秒：错位互动/环境变化（制造意外）
  20-30秒：反杀/结果/金句收尾（情绪峰值）
  
【章节切片节奏】
  每个高潮场景后预留100-200字“独立叙事”段落
  确保切片位可从章节中独立提取，不依赖上下文
```

## 九、章末钩子模板

### 钩子类型与结构

| 钩子类型 | 结构 | 示例 |
|:---|:---|:---|
| **情绪悬念** | 当前情绪未解+新情绪入口 | “她看着那个名字，终于明白为什么所有人都在躲着她。” |
| **后果预告** | 行为中断+可预见灾难 | “他的手还停在那扇门上。门后传来脚步声——不止一个人的。” |
| **规则反转** | 常规被打破+倒计时 | “三年来，没人敢质疑这条规矩。但今天，有人开了口。倒计时开始。” |
| **反杀预告** | 对方以为胜券在握+主角留的后手 | “反派笑着离开。他没看到主角手指在袖子下轻点了一下——信号已发出。” |
| **关系悬念** | 关系变化已发生+新冲突伏笔 | “他们曾经是队友。现在不是了。但他手里的东西，是她给的。” |

### 科武章末钩子模板

```
【战斗悬念型】
  结尾：主角用未知能力逆转局势，但能力失控
  钩子：“他的手指在颤抖。那不是累，是失控。但真正的危机，是身后那群人看到了刚才的一幕。”
  
【系统反噬型】
  结尾：主角成功利用漏洞，但被系统标记
  钩子：“屏幕闪了一下。他赢了。但他看到了通知：【您的账号已被标记审查】。”
  
【阵营博弈型】
  结尾：主角借刀杀人成功，但借的刀反噬
  钩子：“他看着对面的“盟友”笑了笑。“合作愉快。”对方也笑了笑。他不知道对方在想什么，但他知道自己需要找后路了。”
```

| **章末钩子** | 情绪未解+关系悬念 | 狼人身份暴露后的关系重构；失控后的危机倒计时 |

### 📌 平台规则→发布/包装/风险门禁

| 规则类型 | 转换要点 | 执行门禁 |

```
【启动前】填写任务卡（三问+类型标记+执行清单）→ 完成度<60%禁止开写
```
