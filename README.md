# 科武纪元 · AI漫剧工作流

AI漫剧《科武纪元》的完整创作工作流体系，包含素材采集、知识库构建、六角色审核、写作执行全流程。

## 📁 目录结构

```
科武纪元/
├── 知识库/                    # 科学知识库（按科技线分类）
│   ├── INDEX.md               # 总索引+查重入口
│   ├── 量子计算/
│   ├── 核聚变能源/
│   ├── 芯片算力/
│   ├── 太空探索/
│   ├── 反导战术/
│   └── 外骨骼装备/
├── 工具脚本/                   # 自动化脚本
│   ├── orchestrator_v3.py     # 素材采集调度器
│   └── search_semantic.py     # RAG语义检索
├── 审核记录/                   # 六角色四层审核
│   ├── 四层审核包/
│   └── 六角色外审/

```

## 🔄 核心工作流

### 1. 知识库构建（查重→采集→入库）
```
查INDEX.md → 定向采集 → 生成素材卡 → 入库 → 填充RAG → 写作引用
```

### 2. 六角色四层审核
```
写作 → Git提交 → Wiki更新 → RAG扫描 → 六角色外审 → 门禁通过
```

### 3. 素材采集调度器
支持平台：微信/B站/观察者网/中科院/物理所/RSS
```bash
python3 工具脚本/orchestrator_v3.py all
```

## 📝 写作规范

- 去AI味：禁用咏叹调比喻，用物理反馈替代
- 术语融入：先讲"是什么/怎么用"，再用数据支撑
- 字数：番茄口径（去空白总字符-标题）≥2000字

## 🔧 技术栈

- 调度器：Python 3.11 + crawl4ai
- RAG：SiliconFlow bge-m3 向量索引
- 浏览器：agent-browser --session-name 持久化
