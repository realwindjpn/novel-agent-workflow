# 《科武纪元》编辑学习官｜平台规则拆解

## 1 课程核心判断（≤6条）
1. **2万字定签约**：核心考核“主角是否掌控并推动主线”，拒收无剧情流水账与设定堆砌。
2. **8万字+连更触发流量**：签约后达8万字且连续3天日更4000字，手动开启推荐，纯算法驱动。
3. **数据实时反哺内容**：推荐按“读完率/留存时长”扩圈或降权，内容修改实时生效，非人工排榜。
4. **开篇300字铁律**：必须出主角、进事件、明背景；背景交代需让位于剧情节奏。
5. **包装即转化率**：书名/简介/排版直接决定点击与签约率；简介需含剧情/人设亮点+互动小剧场。
6. **稿费结算硬门槛**：签约为前提，推荐为放大器；满100元可提，次月第二周周四结算。

## 2 可执行编辑规则
| 维度 | 规则提取（基于原文） |
|:---|:---|
| **开篇** | 300字内主角登场并切入核心事件；禁用连续超500字纯设定说明；首章末尾必留悬念钩子。 |
| **节奏** | 2万字内需完成“主角确立目标-遭遇阻力-初步破局”闭环；按手机阅读习惯分段卡点，单章信息密度需支撑连续滑动阅读。 |
| **冲突** | 主角必须对主线有明确掌控力与推动行为；冲突需具象化（环境/心理/对话/神态多维融合），杜绝无意义日常灌水。 |
| **人物** | 主角需具备“讨喜性格”或“强记忆点”；简介需前置人设亮点，强化读者初始锚点。 |
| **题材** | 必须原创中文，过安全审核；主线清晰，符合小说基本体裁要素；严禁旧稿挪用/涉黄/抄袭。 |
| **改编** | 强情绪代入、环环相扣的剧情、明确主线是IP开发基础；简介“互动小剧场”可直接转化为短视频切片/有声剧试音素材。 |
| **平台规则** | 签约后8万字+连更3天（日更4k）手动点击“开始推荐”；算法按留存/读完率扩圈；实时修改有效；稿费≥100元次月结算。 |

## 3 科武适配（长篇《科武纪元》/短故事/热点稿）
### ✅ 可用点
- **长篇《科武纪元》**：算法推荐机制要求“单主角强动机+明确升级路径”，完美契合科武“武道/科技双轨成长”主线；2万字内必须完成首次体系验证（如基因锁突破/机甲初战），避免慢热。
- **短故事**：300字开局+章末钩子规则可直接压缩为“单场景高密度冲突”；简介互动小剧场可改为“世界观微切片”，利于完读率冲刺。
- **热点稿**：实时推荐+数据反馈机制支持“追热点快速迭代”；可根据读完率下滑节点，在24小时内替换钩子密度或调整情绪落点。

### ⛔ 不可硬套点
- **“背景几笔带过”**：科武底层逻辑（力量体系/科技树/纪元编年史）不可省略，需改为**“设定碎片化嵌入动作与对话”**，而非纯删减。
- **“日更4k×3天”**：长篇科幻严谨性要求高，盲目追更易导致战力/科技线崩坏；需提前建立**设定库+大纲节点表**，预留缓冲章。
- **算法偏好“情绪爽点”**：若走“冷峻推演/群像/硬科幻”路线，开篇必须强化**单主角视角的强生存动机**，否则易被算法判定为“留存低”而降权。

## 4 编辑检查表（10条以内）
1. [ ] 前300字是否已出现主角并切入核心事件？
2. [ ] 2万字内主角是否已展现对主线的掌控力与推动行为？
3. [ ] 背景/设定是否以“剧情碎片”形式呈现，无连续超500字纯说明？
4. [ ] 每章末尾是否设置与下章冲突直接绑定的具体悬念/变量？
5. [ ] 主角是否具备清晰记忆点（性格/能力/目标）？
6. [ ] 书名/简介是否精准提炼剧情与人设亮点？（简介含互动片段）
7. [ ] 排版是否符合移动端阅读（合理分段/标点/卡点）？
8. [ ] 是否已达成8万字+连续3天日更4000字，并手动点击“开始推荐”？
9. [ ] 核心数据（读完率/留存）是否达标？未达标章节是否已针对性修改？
10. [ ] 内容是否100%原创、过安全审核、无涉黄/抄袭/旧稿挪用？

## 5 对作家角色的输入要求
| 维度 | 强制输入标准 |
|:---|:---|
| **动作链** | 每场戏必须包含“触发→决策→执行→结果”完整链条；科武战斗/科技操作需拆解为可追踪步骤，禁用“突然爆发/机械降神”。 |
| **物理反馈** | 所有能力使用/环境变化必须伴随可感知反馈（如能量过载的灼痛、机甲关节金属疲劳、重力异常的内脏压迫），强化移动端沉浸感。 |
| **代价** | 主角每次推进主线或越级破局，必须支付明确代价（资源损耗/身体损伤/阵营关系破裂/科技副作用），杜绝无成本升级。 |
| **钩子** | 章末钩子必须与下一章核心冲突直接绑定；禁用“且听下回分解”式虚钩，需抛出具体危机/反转/未解变量。 |
| **读者预期** | 开篇300字建立“生存/复仇/探索”等强动机预期；2万字内需兑现首次小高潮；推荐期严格遵循“承诺→兑现→升级”循环，数据下滑立即回调预期管理。 |
