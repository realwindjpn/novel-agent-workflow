# 《稳定更新｜如何稳住剧情节奏》编辑提炼笔记
来源：番茄作家课堂 · 徐二家的猫 · 2024-12-16
用途：长篇《科武纪元》主线、短故事、热点稿统一节奏标准

---

## 1. 课程核心判断
1. **新人写"读者要的"，不写"自己爽的"**：商品思维，作者=销售员，作品=商品。
2. **慢热不是借口**：开篇即烂果摆顶层 = 自杀；后面再好读者已走。
3. **钩子必须串联**：一钩未结束前再埋 1–2 钩，断链即流失。
4. **节奏 = 压 / 缓 / 再压 / 爆 / 埋钩 循环**，不是单点爆。
5. **复仇爽点（一巴掌打回去）一次有效，反复用即枯燥**，必须配铺垫层级。
6. **字数硬控是新人最有效的节奏训练法**，超字即查"无效剧情"。

---

## 2. 可执行编辑规则

### 开篇
- 第一章必须给出**让读者必看第二、三章的钩子**；钩子长度不得拖过当章。
- 禁止：纯辞藻、纯设定铺陈、纯日常、"先抑后扬"式毒开篇。
- 章末必留 1–2 个未解钩子叠加，钩子不能在同一章内全部回收。

### 节奏（核心方法论）
- **写前列大纲段 → 强制分配字数**（示例：交代妹妹病情+现状=4000 字）。
- 超字 → 排查冗余/无效剧情 → 删到不能再删 = 你当前节奏极限，以此为基准线。
- 主线结构模板：**埋钩 → 压 → 缓 → 再压 → 爆 → 新钩**。
- 长篇分布参考：**前 10 万字一次大爆 → 10–20 万过渡 → 30 万第二次大爆**。

### 冲突
- 压抑不可一压到底，必须穿插**会心一笑的缓冲**（兄妹乐观、相依为命等）。
- 大爆点前必须**极压 + 反差**（善对恶、生对死、希望对欺骗）。
- 爆发后立刻接新钩（漏网者、新仇人、新交易），不留情绪真空。

### 人物
- 用"生存环境"塑造氛围而非心理独白堆砌。
- 受难者保留亮色（妹妹临死仍笑），用反差替读者积压情绪。
- 主角动机要在爆发当下被环境逼到唯一出口，而不是作者强推。

### 题材
- 选**人流多的街道**=大分类、宽受众赛道；小众题材不适合新人冷启动。
- 同题材里靠"摆果顺序"（开篇钩子）差异化，而不是靠题材新奇。

### 改编 / 多形态复用
- 一段剧情产出前先写"简要大纲"，再判断它能切成几段4000字单元。
- 短故事 = 直接套用"压→缓→压→爆→钩"单循环。
- 热点稿 = 只用一个循环，钩子放标题与首段。

### 平台规则（番茄向，男频）
- 钩子密度优先于文笔密度。
- "慢热"在番茄不成立；留存看前 3 章。
- 写作单元建议以 2000–4000 字为节奏块对齐章节。

## 3. 科武适配

### 可用点（直接照搬）
- **埋钩—压—爆—再钩** 主结构 → 套到《科武纪元》的"科技 vs 武道"主线分卷。
- **字数硬控** → 每个科技解谜段 / 武道突破段先设定字数预算。
- **反差爆发**：理性科学家 vs 玄学武道的认知崩塌，可做大爆点。
- **善恶/生死反差**用于配角牺牲场景（科研伙伴、武道师门）。
- **第一卷 10 万字一次大爆**节点 = 主角第一次"科 + 武"合一觉醒。

### 不可硬套点
- "妹妹病重—被拐—血洗"是底层苦情模板，**科幻读者对纯苦情容忍度低**，需替换为**系统性压迫**（技术封锁、文明降维、规则碾压）来制造"压"。
- 男频苦情爆发=屠戮窝点；科武世界爆发要给**世界观增量**（技术揭示/法则突破），不能只给情绪宣泄。
- "一巴掌扇回去"式短爆 → 科幻长篇不宜频用，会破坏硬核感。
- "卖水果话术"类比适合通俗男频；科武需把钩子做成**谜题钩**（未知技术、未知敌人、未知法则）而非纯利益钩。

## 4. 编辑检查表（每章/每段过稿前）
1. 本章首段有没有钩子？读者为什么要翻下一章？
2. 钩子是否在本章结束前回收了全部？（若是→不合格，至少留 1 个）
3. 本段是否在大纲分配字数 ±10% 内？超出部分能否删？
4. 是否出现连续 2000 字以上的纯压抑？需否插入缓冲？
5. 爆发点前是否完成"极压 + 反差"两件套？
6. 爆发后 500 字内是否埋下新钩？
7. 苦情/复仇套路本卷是否已用过？复用是否带新变量？
8. 配角牺牲是否仅服务情绪，还是同时推进世界观？
9. 本章是否有"无效剧情"（不推动钩子、不塑造人物、不展开世界）？
10. 节奏是否符合 "压—缓—压—爆—钩" 当前所处阶段？

---

## 5. 对作家角色（你写稿时）的输入要求

写每个剧情单元前，必须先交付以下五项，缺一项不开写：

- **动作链**：主角从 A 状态到 B 状态的 3–7 步具体动作序列（含失败步），不接受"他突破了"。
- **物理反馈**：每个关键动作的环境/身体回应（雨、泥、断骨、能源读数、武道劲气反震）。科武必须有可量化的物理量或可感官的细节。
- **代价**：本段爆发或获得的对应支付（伤、人、信任、技术泄露、寿命、立场）。无代价的爽点直接驳回。
- **钩子**：本段开头钩子（why 必看）+ 结尾新钩子（≥1 个，最好 2 个层级：短期悬念 + 长期悬念）。
- **读者预期**：写下"读者读完这段会想看到什么 / 害怕看到什么"，并标明你这段是**满足、延迟、还是反转**该预期。三选一必须明确。

> 落地约束：每个剧情单元提交时附"字数预算 / 大纲段 / 五项输入"三件套；编辑按第 4 节检查表过审。
