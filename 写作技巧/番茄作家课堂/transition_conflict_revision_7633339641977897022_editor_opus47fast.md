## 1. 课程核心判断（6条）

1. **"过渡章"是伪概念**——所谓过渡，本质是"下一个期待感的铺垫工程"，不是 A→B 的位移交代。
2. **冲突强度 = 双方"不能退让的理由"之积**，缺一方动机即塌方。
3. **转折生硬的根因是视角失衡**：作者知道、读者不知道，缺一段心理过渡或内心独白。
4. **张力来自前期打压所积累的期待感**，铺垫不足时加配角与支线，但配角必须服务主角主线，否则是无效剧情。
5. **数据差章节只有两种死法**：明确毒点 / 无新增信息可摄入（跳过不影响后文）。
6. **代价必须具象**——"死""死几个""失去什么"——抽象代价等于无代价。

## 2. 编辑规则（按文章内容归档）

### 2.1 过渡章规则
- 不允许出现"纯位移/纯交代"章节。
- 过渡段必须装载至少一项：**期待感 / 危机感 / 信息差 / 对手布局 / 主角防范**。
- 可用三种合法过渡：
  - **加速过渡**：缩短平淡段，提早进入下一剧情铺垫。
  - **副CP/副线魅力点**：用讨喜配角承接读者注意力。
  - **结算时刻**：高潮后物质/情感变化、配角打脸、情绪反应集中兑现。
- 反面参照：警察抓人之前必有侦查、犯人必有反应，绝不"接到电话就出门"。

### 2.2 冲突规则
- 双方都要有**"我必须得到/我必须这么做"的动机**，且互斥。
- 把失败代价**数值化、具象化**（死、死几个、失去谁、失去多少年）。
- 冲突不够 = 铺垫不够，加铺垫优先于加战斗。

### 2.3 节奏规则
- 高潮前：狠狠打压、堆信息差、堆配角态度（看好/不看好/阴谋/助攻）。
- 高潮后：必给结算章，否则读者情绪悬空。
- 详略得当，核心剧情绝不被支线稀释。

### 2.4 人设规则
- 转折生硬时补**内心独白**，为下一步行为做预期解释（不是抒情，是动机预告）。
- 但**删多余内心戏**——故事用行为和台词推进，作者主观臆想不算内容。

### 2.5 改编（高效改文）规则
- 数据下滑章 → 找**毒点**：小问题直删，大争议精修或整段替换。
- 跳章高发段 → 衔接/配角占比过高，压缩到不影响主线即可。
- 特殊品类（如快穿换地图）的合理掉追读不必硬救，靠**强期待主线**留长线读者。
- 每章自检标准：**有内容可看 + 有信息可摄入**，二者缺一即过渡失败。

## 3. 科武适配（《科武纪元》专属判断）

### ✅ 可直接套用
| 原规则 | 科武用法 |
|---|---|
| 过渡章=期待感工程 | 星域转场、跃迁航段必须夹带敌方布局/旧伤复发/科技伦理冲突预告 |
| 双方互斥动机 | 科技派 vs 武道派、人类 vs 异种、个体突破 vs 文明存续，三组对抗轴永远预留动机 |
| 代价具象化 | 武道反噬掉境界、改造体器官坏死数量、舰队伤亡比、家族/盟约塌缩 |
| 结算时刻 | 战役后兑现：基因层级提升、装备解锁、阵营评分、配角态度翻转 |
| 内心独白做动机预告 | 主角在跃迁/闭关/调息时给一段技术+心法双线独白，预告下一步 |

### ⚠️ 不可硬套
- **副CP撑场**：科武是硬核长篇，副CP只能作调剂，不能成为过渡章主载体，否则稀释科技/武道设定密度。
- **"快穿换地图掉追读合理"**：科武是单一世界线长篇，任何掉读都必须归因，不能用品类豁免。
- **"删多余内心戏"**：科武需要保留**设定独白与原理推演**，这是品类核心爽点，不属于"主观臆想"，只删情绪反刍。
- **女频破镜重圆式情感铺垫**：可借结构，不可借调性，科武情感线必须服从文明级冲突。
- **纯爽点密集打法**：科武需"铺垫—推演—代价—兑现"四拍，不能用短打节奏取代。

## 4. 编辑检查表（10条）

- [ ] 本章是否有"读者不知道、但现在知道了"的新信息？
- [ ] 本章是否制造或推进了至少一个期待/危机/信息差？
- [ ] 冲突双方是否都写明了"不能退让的理由"？
- [ ] 失败代价是否具象到可数（数字、名字、境界、舰船数）？
- [ ] 转折前是否有一段动机性内心独白（≤200字，非抒情）？
- [ ] 配角/支线是否最终回流到主角主线？无关支线已删？
- [ ] 高潮后是否安排了结算（物质+情感+配角反应至少各一）？
- [ ] 是否存在纯位移/纯交代段落？若有，已注入布局/反派视角/伏笔？
- [ ] 内心戏是否只保留"设定推演 + 动机预告"，删除情绪反刍？
- [ ] 本章若被读者跳过，后续剧情是否会断？若不会，必须重写。

## 5. 对作家角色的输入要求

提交任意一章/任意一场冲突时，作家角色必须给出以下五件套，缺项即打回：

### 5.1 动作链（Action Chain）
- 至少 3 个连续动作节点：`触发 → 物理执行 → 反作用 → 二次决策`。
- 每个节点标注：使用的科技模块 / 武道法门 / 能量消耗等级。

### 5.2 物理反馈（Physical Feedback）
- 招式/武器/科技的可观测后果：声、光、热、震、辐射、生理损伤。
- 至少一条**违反主角预期**的反馈（制造下一步铺垫）。

### 5.3 代价（Cost）
- 具象单位：寿元 X 年 / 神经突触烧毁 X% / 战舰 X 艘 / 队友 X 人。
- 必须写明**这个代价是否可逆**、何时清算。

### 5.4 钩子（Hook）
- 章末必须留下三类钩子之一：
  - **敌方布局钩**：反派视角一句话或一次动作。
  - **代价兑付钩**：本章动作埋下的后遗症何时爆发。
  - **信息差钩**：读者已知、主角未知（或反之）的一项关键事实。

### 5.5 动机声明（Motivation Statement）
- 主角一句"我必须 X，否则 Y"。
- 对手一句"我必须 ¬X，否则 Z"。
- Y 与 Z 必须均为**具象代价**，不接受"为了正义""为了变强"。

---

> 改文优先级：**毒点 > 动机 > 代价 > 钩子 > 节奏 > 文笔**。
> 一句话总则：科武的每一章，都要让读者"摄入了新信息，且预感到了下一笔账"。
