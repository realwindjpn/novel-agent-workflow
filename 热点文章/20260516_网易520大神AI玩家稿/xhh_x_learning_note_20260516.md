# 小黑盒/X 游戏热文学习纠偏 2026-05-16

## 用户纠偏
- 最近稿件被骂：有“审核过程/来源说明/方法论”混入正文或DOCX正文的问题。
- 玩家向文章不能像工作报告，不能把“我怎么审稿”给读者看。

## 小黑盒样本规律（基于公开可检索热文/分享页摘要）
1. 标题先给玩家损益：白嫖、史低、延期、背刺、卡关、值不值、该不该买。
2. 开头直接站玩家场景，不先写活动意义。
3. 热点稿常用“我/盒友/玩家现在最烦的是……”切入。
4. 有梗、有口头禅、有不整齐表达，敢写“草、真有你的、我是真不想重来”。
5. 资料只是背后支撑，正文不出现“审核、门禁、source_notes、我采集了”。
6. 好文章会把价格、时长、卡点、掉帧、资源损失、活动截止这种具体成本写出来。
7. 评论入口要具体：你会不会信AI攻略？你最怕它答错哪一步？而不是“欢迎讨论行业趋势”。

## X 平台游戏热点样本规律（基于公开搜索到的 NetEase/AI/game snippets）
1. X 更短，更像一句判断+一个疑问：某游戏缺席阵容、某AI功能是否过度使用、某助手能否真帮玩家。
2. 海外玩家更敏感：AI生成痕迹、社区反馈跟踪、工具是否真的解决问题。
3. 适合转成国内稿的不是“AI很先进”，而是“玩家担心它会不会制造垃圾内容/错误建议”。

## 新硬规矩
- 公开交付DOCX只放正文和必要配图，不附审核过程、source_notes、五门禁。
- 审核/source_notes 单独文件留证，不塞进给小黑盒复制的正文包。
- 正文禁词：审核、门禁、我已采集、来源如下、根据资料、本文将、值得关注、生态、赋能、全面解析。
- 写前先定“玩家正在付出的成本”：钱/时间/资源/手机发热/切屏/重开/错过活动。
- 写完遮住标题自测：像不像一个盒友发帖？如果像公众号报告，重写。
