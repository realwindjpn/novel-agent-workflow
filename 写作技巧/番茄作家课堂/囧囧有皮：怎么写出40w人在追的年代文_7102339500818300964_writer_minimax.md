## 一、核心行动准则（6条铁律）

| # | 准则 | 执行动作 | 违规代价 |
|:--|:-----|:---------|:---------|
| 1 | 开篇即闸门 | 前3章必须亮出人设+目标+首个钩子 | 弃文率+30%，推荐位降级 |
| 2 | 支线30%红线 | 支线总长≤主线30%，单章纯设定≤连续2章 | 完读率下跌，平台不再推流 |
| 3 | 爽感绑定实质 | 每次爽点必须输出：关系/认知/规则/阵营演进之一 | 阅读疲劳累积，追更流失 |
| 4 | 缺陷即记忆点 | 主角必须配置"底线+缺陷+反常规表达" | 扁平人设，读者无感 |
| 5 | 代价不过夜 | 金手指破局必须在3-5章内触发连锁代价 | 逻辑崩塌，口碑反噬 |
| 6 | 钩子不过周 | 章末钩子兑现周期≤3章，需具备可验证性 | 读者预期落空，差评/弃文 |

## 二、写作前任务卡字段更新

> **每次开篇/章节前必须完成以下字段填写**

| 字段 | 要求 | 示例 |
|:-----|:-----|:-----|
| **主角核心缺陷** | 写一条"让读者又爱又恨"的缺陷 | "冲动型判断但战术嗅觉顶级" |
| **主角行事底线** | 写一条"绝不越过"的底线 | "不主动伤害无辜平民" |
| **主线目标（本章/本卷）** | 明确、可量化 | "72小时内攻破北区能源枢纽" |
| **首个冲突来源** | 内/外各一条 | 内：队友不信任；外：联邦巡逻队封锁 |
| **本章爽点类型** | 四选一：认知升级/关系破冰/规则打破/阵营演进 | "认知升级：发现敌人能源核心弱点" |
| **爽点伴随代价** | 写明代价类型及触发时间点 | "神经负荷超标→第4章反应力下降" |
| **章末钩子形式** | 信息差悬念/行动倒计时/人物反转预兆 | "倒计时：能源弹仅剩12发，48小时补给窗口" |
| **借点标注** | 短篇◎/狼人◎/科武长篇◎ | "◎科武长篇：机甲协同战术" |

## 三、章节自检清单（写后速扫）

### 3.1 基础扫描（2分钟）

- [ ] 开篇3段内是否出现主角名字+当前困境？
- [ ] 章末是否留钩子？（信息差/倒计时/人物反转）
- [ ] 本章是否有可量化的物理反馈？（破坏半径/能量衰减/感官描写）
- [ ] 金手指使用后是否标注代价或预告代价触发点？

### 3.2 人设扫描（1分钟）

- [ ] 主角是否有反常规表达？（非标准台词/非常规判断）
- [ ] 主角缺陷是否在本章显露？（哪怕暗示）
- [ ] 配角是否有独立行动逻辑？（不是纯工具人反应）

### 3.3 节奏扫描（1分钟）

- [ ] 是否存在连续3段以上纯对话/纯设定？（禁止）
- [ ] 支线篇幅是否超本章30%？
- [ ] 冲突解决后是否附带"意义交付"？（关系/认知/规则变化）

### 3.4 钩子兑现扫描（1分钟）

- [ ] 上章钩子是否在本章或下章兑现？
- [ ] 兑现是否具备"读者可预判的验证节点"？
- [ ] 本章新钩子是否与主线强绑定？

## 四、冲突爽点双引擎（可执行模板）

### 4.1 标准爽点结构

```
【触发】环境压迫/资源紧缺/信息差
    ↓
【决策】主角做出反常规/高风险判断
    ↓
【执行】动作链完整拆解（见5.1）
    ↓
【爽感】达成目标+意义交付（二选一）
    → 关系推进（信任建立/阵营归属）
    → 认知升级（发现隐藏规则/敌人弱点）
    → 规则打破（旧秩序崩塌/新秩序建立）
    → 阵营演进（势力消长/资源再分配）
    ↓
【代价】3-5章内触发连锁反应
```

### 4.2 爽感+逻辑双引擎检查

| 爽感类型 | 必须满足的逻辑条件 |
|:---------|:-------------------|
| 战斗碾压 | 能量消耗/武器过热/反应延迟有描写 |
| 智谋反转 | 提前3章埋设伏笔（参数异常/对话双关） |
| 关系破冰 | 双方存在真实利益冲突，非纯情感驱动 |
| 规则打破 | 需付出阵营代价（信任损耗/资源损失） |

### 4.3 失败模式清单

| 失败模式 | 触发特征 | 修复动作 |
|:---------|:---------|:---------|
| **纯碾压爽** | 敌人无有效反击，主角无损耗 | 增加机体负荷描写/能量衰减/判断失误 |
| **无代价金手指** | 破局后无后续影响 | 在3章内添加：关系反噬/资源枯竭/神经损伤 |
| **机械降神** | 临时引入新设定/新能力 | 提前埋设伏笔，兑现时提供"读者可验证"的逻辑链 |
| **悬浮打斗** | "光效对波"式描写，无物理反馈 | 添加：破坏半径/机体震颤/感官剥夺/能量衰减曲线 |
| **情绪收尾** | 章末纯感慨/风景/独白 | 替换为：信息差悬念/倒计时/人物反转预兆 |

## 五、动作链与物理反馈（可执行标准）

### 5.1 标准动作链模板

> **科幻战斗/操作必须包含以下环节，顺序不可跳越**

```
① 前置判断 → ② 目标锁定 → ③ 能量/武器激活 → 
④ 参数确认 → ⑤ 执行动作 → ⑥ 物理反馈 → ⑦ 结果呈现 → ⑧ 代价触发
```

**示例（正确的机甲协同攻击）：**

> ① 前置判断：林澈扫了眼能耗表，"先打右翼冷却器，诱使敌机转向"
> ② 目标锁定：指令链路同步至三号机甲火控系统，锁定标记变红
> ③ 能量激活：主炮能量槽由62%开始攀升
> ④ 参数确认："充能87%，轨道偏差值0.3以下，可以"
> ⑤ 执行动作：扳机扣下，后坐力沿脊椎传导
> ⑥ 物理反馈：右翼冷却器炸裂，弹片击穿一号机甲左肩护甲，耳鸣声充斥驾驶舱
> ⑦ 结果呈现：敌机果然向右侧闪避，露出尾部能源核心
> ⑧ 代价触发：主炮充能耗尽，18秒再装填窗口暴露——（本章未兑现，下章触发）

**禁止写法示例：**
> "林澈集中精神，主炮轰出一发，敌机应声爆炸。"

### 5.2 物理反馈量化标准

| 场景 | 必须包含的量化描写 |
|:-----|:-------------------|
| 战斗损伤 | 破坏面积比/功能损耗率/出血量/意识模糊程度 |
| 能量消耗 | 剩余百分比/衰减速率/充能时间 |
| 机甲/装备 | 过热温度/结构形变/维护周期变化 |
| 环境变化 | 毒性浓度/重力偏差/信号干扰范围 |
| 感官剥夺 | 耳鸣等级/视野模糊时间/疼痛指数 |

### 5.3 科武长篇借点：战斗场景节奏模板

```
【第1段】压迫感建立（环境/资源/时间压力）
【第2段】决策窗口（主角反常规判断+队友质疑）
【第3段】动作链展开（详见5.1，不跳越环节）
【第4段】爽感爆发（目标达成+意义交付）
【第5段】代价初显（为后续3-5章埋设伏笔）
【第6段】钩子（新的信息差/倒计时/人物反转）
```

## 六、人物口吻指南（科武风格）

### 6.1 主角口吻核心要素

| 要素 | 说明 | 示例 |
|:-----|:-----|:-----|
| **痞气底色** | 非常规表达，非标准英雄台词 | "又让我送死？行吧，反正我这命不值钱。" |
| **清醒内核** | 表面玩世不恭，决策逻辑严密 | "骂归骂，手上活别停——三秒后左舷有攻击。" |
| **反常规正义** | 不走道德高地，有自己的灰色规则 | "那小子不欠我命，他欠我解释。" |
| **缺陷外显** | 通过台词暴露性格缺陷 | "冲动了"+"我刚才是不是又犯蠢了" |

### 6.2 科武长篇借点：对话张力模板

| 对话类型 | 结构 | 示例 |
|:---------|:-----|:-----|
| **质疑型** | 队友质疑→主角反问→揭示隐藏信息 | "你怎么知道那里没人？"/"因为如果有人，我们早就死了。" |
| **倒计时型** | 紧迫感建立→决策→代价预告 | "还有三分钟"/"够了，我只需要两分钟"/"那剩下的一分钟是给我收尸的？" |
| **反转型** | 表面信息→暗层揭示→认知颠覆 | "我是来救你们的"/"（背景音：警报声）/救？你们的能源核心在隔壁。" |
| **代价型** | 能力使用→代价暴露→后果预告 | "我能黑进去"/"代价呢？"/"十二小时内我会暂时失明"/"那你打算怎么活着出来？" |

### 6.3 配角独立行动逻辑检查

每个重要配角需回答：
- [ ] 他有自己的目标吗？（与主角目标是否冲突？）
- [ ] 他在主角失败时会怎么做？（不是纯等待救援）
- [ ] 他的台词是否体现个人立场？（非传声筒式"主角说得对"）

## 七、章末钩子执行标准

### 7.1 三种可用钩子

| 钩子类型 | 结构 | 兑现周期 | 示例 |
|:---------|:-----|:---------|:-----|
| **信息差悬念** | 主角知道/读者不知道的信息 | 本章或下章 | "那串代码是旧的，但旧代码意味着——他还在。" |
| **行动倒计时** | 明确时间节点+风险 | ≤3章 | "十二小时后联邦舰队抵达，我们必须在十小时内完成任务。" |
| **人物反转预兆** | 伏笔+暗示+读者可验证逻辑 | 3-5章 | "他笑了笑，和三年前的那次一样。" |

### 7.2 禁止的章末结尾

- 纯情绪收尾（"夕阳真美"/"我的心很平静"）
- 纯风景描写
- 纯独白感慨
- 无信息量的"本章完"

### 7.3 钩子兑现自检

- [ ] 读者能否预判"这里有问题"？
- [ ] 兑现时是否有足够的伏笔铺垫？
- [ ] 兑现后是否产生新的悬念/倒计时？

## 八、平台规则→发布/包装/风险门禁

### 8.1 发布门禁

| 门禁项 | 要求 | 违规后果 |
|:-------|:-----|:---------|
| **存稿安全** | 开篇定稿前完成"无上下文盲测"；多端物理备份 | 数据丢失=停更风险 |
| **节奏响应** | 推荐期数据异动时，24小时内提速 | 错过推荐窗口 |
| **断更预案** | 断更超24小时需提前公告+补偿章 | 流量断崖，口碑崩塌 |
| **完结预留** | 主线收束后预留情感余韵/番外空间 | 长尾流量流失 |

### 8.2 包装门禁

| 门禁项 | 要求 | 违规后果 |
|:-------|:-----|:---------|
| **完读率优先** | 前10章控制支线，信息密度均匀 | 推荐位降级 |
| **改编潜力** | 强关系网+高密度冲突+可视化场景 | 影视/短剧改编受阻 |
| **人设记忆点** | 每卷需强化主角1-2个标志性特质 | 读者遗忘主角 |
| **更新节奏** | 基准日更4k-6k，稳定>爆发 | 算法权重下降 |

### 8.3 风险门禁

| 风险类型 | 触发红线 | 应对动作 |
|:---------|:---------|:---------|
| **断更风险** | 存稿＜7天量 | 立即启动存稿加速/请假公告 |
| **弃文风险** | 支线超30%/连续纯设定章节 | 砍支线，重写关键章节 |
| **口碑风险** | 无代价金手指/机械降神被指出 | 下章立即添加代价/伏笔补救 |
| **推荐中断** | 完读率低于平台均值 | 调整前10章节奏，加强钩子 |

## 九、分类借点速查

### 9.1 短故事/狼人篇可借点（直接迁移）

| 借点 | 应用场景 |
|:-----|:---------|
| 单章"爽感+实质"双引擎 | 短篇/狼人章节内的冲突设计 |
| 反常规人物特质 | 短篇主角的性格设计 |
| 章末信息差悬念 | 狼人章节结尾钩子 |
| 代价不过夜原则 | 短篇结尾的悬念设置 |
| 物理反馈量化 | 打斗/动作场景描写 |

### 9.2 科武长篇可借点（需重构）

| 借点 | 重构方向 |
|:-----|:---------|
| 年代文"活劲+烟火气" | 底层生存细节+团队羁绊+装备损耗描写 |
| 家长里短冲突 | 升维为阵营博弈/资源争夺/伦理冲突 |
| 怀旧情绪 | 替换为未来生活逻辑（能源配给/义体维护/生态舱日常） |
| 完结长尾收益 | 前期留存>押注完结，预留情感余韵 |

### 9.3 不可硬套点

| 不可硬套 | 原因 | 替代方案 |
|:---------|:-----|:---------|
| 纯自力更生+无金手指 | 科幻题材需合理外挂 | 成长型/代价型金手指 |
| 低维冲突（邻里纠纷） | 科武需高维冲突 | 资源配额/技术伦理/生存空间 |
| 完结收益翻倍算法 | 平台特定规则 | 前期留存优先，稳定更新 |
