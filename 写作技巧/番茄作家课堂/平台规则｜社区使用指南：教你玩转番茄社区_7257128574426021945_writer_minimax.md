## 【模块1】作家OS执行模块

### 1.1 社区互动模块（发布/包装/风险门禁）

#### L1 每日动作包

| 动作 | 执行标准 | 反馈 | 失败代价 |
|:---|:---|:---|:---|
| **段评回复** | 每日≥30条精选段评回复，每条≥20字，含剧情/设定/人物相关讨论 | 高赞段评→阅读器曝光→流量反哺 | 零回复→段评沉默→互动权重下降 |
| **动态更新** | 每日≥1条动态，附带设定图/书卡/创作花絮，避开正文核心剧透 | 动态曝光→粉丝群/书圈导流→追读率提升 | 剧透→读者流失→差评风暴 |
| **书圈答疑** | 每48小时内对热门帖做作者视角回应（世界观/设定/人物动机） | 答疑→社区信任→书圈活跃→推荐池权重 | 冷处理→质疑积累→舆论失控 |

#### L2 每周动作包

| 动作 | 执行标准 | 反馈 | 失败代价 |
|:---|:---|:---|
| **作者空降** | 每周≥2次书圈/粉丝群空降，形式：剧情预告/设定揭秘/角色投票 | 空降→粉丝活跃→追更率提升→推荐池加分 | 长期缺席→粉丝沉寂→书圈沦为沉默池 |
| **段评“神想法”收集** | 每周汇总高赞段评中读者的推理/猜测，评估是否纳入伏笔回收 | 采纳→读者参与感→社区黏性→免费口碑传播 | 忽视→读者热情冷却→段评沦为水文区 |
| **加精/禁言执行** | 每周加精≤10条优质书圈帖；每周禁言≤5人（持续引战/恶意刷屏账号） | 加精→内容质量锚定→书圈调性；禁言→社区秩序维护 | 禁言过度→误伤→投诉；禁言不足→引战失控→平台处罚 |

#### ⚠️ 风险门禁（零容忍红线）

| 禁止行为 | 违规代价 |
|:---|:---|
| 作者与读者对骂 | 双方同罚→账号限流/推荐降权 |
| 硬刚/夹带作者情绪进正文 | 读者差评→平台风控标记 |
| 无视举报/私了处理恶意差评 | 举报无效→违规累计→封禁风险 |
| 粉丝群无管理员/无群规 | 剧透/引战失控→书圈舆论危机 |

#### 🎯 发布包装标准动作

```
发布前检查清单（30秒完成）：
1. 动态附带图片/书卡 ✓/✗
2. 内容不含正文核心剧透 ✓/✗  
3. 语气符合"世界观架构师"身份 ✓/✗
4. 无情绪化表达 ✓/✗
```

### 1.2 创作动作模块（人物口吻/段落节奏/章末钩子）

#### 🎯 核心创作动作（每章必做）

| 动作 | 执行标准 | 适用场景 |
|:---|:---|:---|
| **段评触发点预设** | 前3章必须埋≥1处；每10章需检查更新 | 开篇/章节中段 |
| **战斗分镜设计** | 每次科武交互需含：神经接驳→能量过载→躯体反馈→武技释放（4步可拆解） | 战斗场景/机甲操作/基因觉醒 |
| **代价绑定检查** | 每种力量体系必须有明确代价（例：超频→寿命燃烧；义体→排异；算力→记忆碎片） | 设定新增/能力升级 |
| **人物标签锚定** | 每个核心角色需具备≥2个易传播标签（标志性动作/口头禅/视觉特征） | 人物出场/章节规划 |
| **章末钩子设计** | 绑定≥1个"未解变量"（未知信号/敌对底牌/系统异常） | 章节收尾 |

#### ⭐ 科武长篇专属动作

| 动作 | 执行标准 | 反馈 |
|:---|:---|:---|
| **推演空间预留** | 基因锁/机甲武学/能量回路需提供可量化对比维度 | 书圈战力排行/设定考据帖 |
| **伏笔回收留痕** | 每30章至少完成1轮伏笔回收（回收率≥70%） | 读者满意度/社区讨论热度 |
| **世界观稳定性维护** | 书圈同人/嗑CP倾向仅作参考，不干预主线剧情 | 世界观口碑/长期追读 |

#### ⚠️ 科武长篇风险门禁

| 禁止行为 | 失败后果 |
|:---|:---|
| 为段评碎片化打断硬核设定铺陈 | 长篇架构崩塌→书圈"体系崩坏"争议 |
| 将书圈同人/嗑CP倾向反向修改主线 | 世界观失信→铁粉流失 |
| 粉丝群饭圈化运营（非靠设定揭秘/技术推演维系） | 核心受众错位→长篇口碑稀释 |

### 1.3 物理反馈设计模块（战斗/交互/环境）

#### 科武交互反馈链（4步标准）

```
Step 1 → Step 2 → Step 3 → Step 4
神经接驳    能量过载    躯体反馈    武技释放

物理反馈示例（每步需包含）：
├─ 神经接驳：神经刺痛/感官过载警报
├─ 能量过载：液压关节嗡鸣/热能逸散/重力扭曲视觉
├─ 躯体反馈：肌肉撕裂灼痛/义体排异痉挛/记忆碎片闪回
└─ 武技释放：能量轨迹残像/机械结构异响/基因锁崩解光效
```

#### 环境反馈标准（每场景必须包含≥2种）

| 类型 | 示例 |
|:---|:---|
| **机械环境** | 机甲舱压失衡警报、能量护盾蜂鸣、弹药剩余计数 |
| **生物环境** | 基因药剂代谢灼痛、神经抑制剂的冰冷感、身体异变可视化 |
| **物理环境** | 重力场扭曲→视觉畸变、维度跃迁→空间撕裂感、时间流速异常→体感错位 |

## 【模块2】写作前任务卡字段更新

> 作家在动笔前必须完成以下字段自检，未达标不得进入正文写作

### 基础字段（短故事/狼人篇/科武长篇通用）

| 字段 | 要求 | 未达标处理 |
|:---|:---|:---|
| **段评触发点坐标** | 章内定位（章/节/段）≥1处，类型：悬念/反常识/高张力台词 | 不可开写，需补入 |
| **核心人物标签** | ≥2个可传播标签（动作/口头禅/视觉特征） | 人物不可出场 |
| **章末未解变量** | 绑定≥1个未解变量（信号源/底牌/异常） | 章节不可收尾 |
| **力量代价绑定** | 本章涉及的力量体系是否绑定明确代价 | 需补充代价设定 |
| **书圈钩子预留** | 本章断点/阵营选择是否可引发书圈讨论 | 需调整断点位置 |

### ⭐ 长篇专属字段

| 字段 | 要求 | 未达标处理 |
|:---|:---|:---|
| **战力推演空间** | 本章设定是否提供可量化对比维度 | 需增加推演维度 |
| **伏笔索引** | 本章是否涉及伏笔埋入或回收（记录索引） | 需更新伏笔台账 |
| **世界观一致性自检** | 本章设定是否与前文冲突（交叉核对最近3章） | 需回溯修正 |

### 任务卡格式（作家使用）

```
【章节任务卡】
章节编号：_____
段评触发点坐标：第__章 第__节 第__段（类型：____）
核心人物标签：____（标签1）/____（标签2）
章末未解变量：____
力量代价绑定：____（若无新增力量体系则填"沿用既有"）
书圈钩子：____（讨论点/投票/推理帖素材）
---
[长篇]战力推演空间：____（维度1/维度2）
[长篇]伏笔索引：埋入□ / 回收□（编号：____）
[长篇]世界观一致性：✓通过 / ⚠️需回溯
```

## 【模块3】章节自检清单

> 完成正文写作后，发布前必须逐项核验

### L1 发布前必检（5分钟）

| 序号 | 检查项 | 标准 | 结果 |
|:---|:---|:---|:---|
| 1 | **段评触发点** | 章节内≥1处（悬念/反常识/高张力台词） | □ |
| 2 | **物理反馈链** | 每处科武交互含≥2种物理反馈（视觉/听觉/体感） | □ |
| 3 | **人物标签** | 核心角色出场时标注≥2个可传播标签 | □ |
| 4 | **章末钩子** | 绑定≥1个未解变量，驱动段评/书圈讨论 | □ |
| 5 | **平台规则自检** | 无情绪化表达/无硬刚读者/无剧透核心剧情 | □ |

### ⭐ 长篇专属检查（10分钟）

| 序号 | 检查项 | 标准 | 结果 |
|:---|:---|:---|
| 6 | **战力体系一致性** | 本章战力表现与前文推演无逻辑冲突 | □ |
| 7 | **伏笔索引更新** | 本章伏笔埋入/回收已记录台账 | □ |
| 8 | **代价绑定验证** | 本章新增力量体系已绑定代价，无战力通胀风险 | □ |
| 9 | **书圈钩子有效性** | 本章断点可支撑≥3种书圈讨论方向 | □ |
| 10 | **推演空间评估** | 本章设定是否提供可量化对比维度（适配书圈战力推演） | □ |

### ⚠️ 发布风险拦截（30秒）

| 风险类型 | 拦截触发条件 | 处理方案 |
|:---|:---|:---|
| **情绪化表达** | 正文/段评/动态含“读者怎么想/读者太xxx/你们不懂” | 删除/改写 |
| **剧透核心剧情** | 动态/书圈/段评透露章节核心悬念/结局 | 撤回/替换 |
| **硬刚读者** | 正文中出现反驳/讽刺读者猜测的段落 | 删除/改写 |
| **战力通胀** | 本章力量表现超出前文代价设定范围 | 回溯修正 |

## 【模块4】借点标注

### 📌 短故事/狼人篇可借点

| 模块 | 可借动作 | 执行建议 |
|:---|:---|:---|
| **社区互动** | 段评触发点预设 | 压缩至单章内，每篇至少1处高能悬念点 |
| **创作动作** | 人物标签锚定/章末钩子设计 | 短篇更需强化核心人物≤2个标签，留强钩子驱动收藏 |
| **物理反馈** | 简化版反馈链（2步即可） | 短篇读者偏好快节奏，压缩为“操作+体感”2步 |
| **发布包装** | 动态附带书卡/避开剧透 | 短篇更依赖平台推荐流量，封面图+书卡是转化关键 |
| **风险门禁** | 三不两要 | 短篇单篇曝光，更需避免情绪化表达损口碑 |

### 📌 科武长篇可借点

| 模块 | 可借动作 | 执行建议 |
|:---|:---|:---|
| **社区互动** | 每周作者空降/段评神想法收集/伏笔回收留痕 | 长篇依赖持续互动维系铁粉，空降需常态化 |
| **创作动作** | 4步反馈链/代价绑定/推演空间预留/伏笔台账 | 长篇设定复杂度高，每章需严格对标任务卡字段 |
| **物理反馈** | 全链路反馈（神经→能量→躯体→武技） | 长篇读者偏好硬核逻辑，每处战斗需完整闭环 |
| **段落节奏** | 每10-15章设置剧情断点/阵营选择 | 长篇需定期提供书圈讨论周期，避免平铺直叙导致社区沉默 |
| **风险门禁** | 不可碎片化打断/不可迎合同人修改主线/粉丝群设定揭秘优先 | 长篇口碑依赖世界观稳定性，需严守底线 |
