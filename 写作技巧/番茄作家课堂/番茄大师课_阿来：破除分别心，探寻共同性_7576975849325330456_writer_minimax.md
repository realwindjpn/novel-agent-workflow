科武验证：
  本章涉及的能量/力量类型：___

**【科武长篇借用点】**：每卷需在任务卡基础上追加“科武融合边界确认”，明确本章中科技与武道的职责划分与交叠地带。

## 二、动作链执行标准

### 2.1 禁写清单

- ❌ “意念一动，能量涌动”
- ❌ “光效一闪，敌人倒地”
- ❌ “精神力暴涨三倍”
- ❌ “机甲瞬间进入战斗模式”

### 2.2 合规动作链模板

每个力量释放/科技应用必须按以下顺序展开：

```
【物理序列】
发力源 → 传导路径 → 作用目标 → 环境扰动

【示例-科武合规版】
液压关节解锁（发力源）→ 能量管道过载警报响起（传导路径）
→ 高频刃切入装甲接缝（作用目标）
→ 金属疲劳裂纹沿切割线蔓延，空气被热浪扭曲成琥珀色（环境扰动）
→ 操作员后颈神经接口传来2.7秒延迟反馈（物理反馈）

【示例-科武合规版·武道主导】
肌腱束瞬间绷紧（发力源）→ 气血沿经脉倒灌右手（传导路径）
→ 指尖刺入敌方护甲缝隙，无护层区域（作用目标）
→ 对方心率监测数据骤降12%（物理反馈）
```

### 2.3 失败模式识别

若出现以下特征，说明动作链断裂：

- 动作结果早于动作过程出现
- 力量释放无物理反馈（无损耗、无延迟、无代价）
- 环境描写与动作无关（如战斗双方在天台打斗，窗外永远是同一片晚霞）

**【长篇借用】**：动作链标准需扩展至“势力动作链”——每个势力/阵营的决策与执行也需遵循物理约束（资源上限、时间窗口、信息传递损耗）。

## 三、冲突设计门禁

### 3.1 通过门禁的条件

冲突必须同时满足：

1. **现实投射**：指向人性博弈 / 资源分配 / 规则漏洞 / 伦理困境之一
2. **结构可验证**：读者能预判冲突走向，但无法预判结局
3. **代价前置**：冲突代价在爆发前已有铺垫

### 3.2 门禁拒绝类型

| 拒绝类型 | 特征 | 示例 |
|:---|:---|:---|
| 纯数值碾压 | 冲突结果由境界差决定，无策略/弱点/变数 | “主角越一个大境界，一拳碾压” |
| 朝堂背诗式爽点 | 以文化优越感替代真实博弈 | “主角现场背诵《出师表》，敌将羞愧退兵” |
| 机械降神式解决 | 用外部神秘力量打破僵局 | “危急关头，天降上古机甲” |
| 无代价爽点 | 突破/胜利无生理/资源/社会代价 | “主角穿越后从未缺钱，从未受伤” |

### 3.3 合规冲突模板

```
【冲突结构-科武纪元】
主题：___（需与现实命题对应，如阶级固化/技术伦理/文明演进）
结构：[势力A] 持有 ___（资源/规则解释权）
      vs [势力B] 面临 ___（生存困境/规则漏洞）
核心矛盾：___（非善恶对立，而是方案/路径/价值观对立）
触发点：[具体事件，如技术泄露/资源争夺/权力更迭]
代价链条：___ → ___ → ___
```

**【短篇/狼人篇借用】**：冲突可简化为“单点突破”模式，但需保证冲突指向人性或资源博弈，而非数值碾压。

## 四、人物动机协议

### 4.1 禁标分类

以下标签人物禁止出现（除非作为对立面需要批判）：

- ❌ “冰冷的AI反派，只为毁灭人类”
- ❌ “嗜血妖兽，无任何情感逻辑”
- ❌ “纯粹的圣人/恶棍，无欲望/恐惧/妥协”

### 4.2 合规动机锚点

所有非人/超凡角色必须锚定于以下人类史逻辑之一：

| 人类史逻辑 | 科武转化示例 |
|:---|:---|
| 欲望 | AI追求计算资源扩展，异族渴望生存空间，武道世家追求血脉延续 |
| 恐惧 | 机甲恐惧被报废，异种恐惧被同化，超凡者恐惧失去力量 |
| 共情 | 机甲与操作员的神经同步，异族与宿主的利益绑定 |
| 妥协 | 武道派系向科技派系交出部分自主权，AI接受行为约束协议 |

### 4.3 动机验证测试

写完一个角色后，用以下问题检测：

- [ ] 该角色的核心欲望/恐惧是什么？能否用一句话概括？
- [ ] 若该角色面临“放弃核心欲望以保全重要关系”的选择，他会如何挣扎？
- [ ] 该角色的行为是否符合人类历史中类似群体的行为逻辑（可举例）？
- [ ] 读者能否在不带入“人类中心主义”的前提下理解该角色？

**【长篇借用】**：每卷需更新主要角色的“动机锚点状态”，标记其欲望/恐惧/妥协的演变轨迹。

## 五、语言尺度匹配指南

### 5.1 禁用词汇类别（科武世界观禁用）

| 禁用 | 原因 | 替换方案 |
|:---|:---|:---|
| “真气/内力/丹田” | 传统武侠语境，与科技设定割裂 | “神经脉冲/生物电场/能量回路负荷” |
| “凌空飞渡/身形一闪” | 违反科武物理约束 | “弹射轨道偏移/神经同步延迟补偿” |
| “意随心动/气随意动” | 无法验证的唯心描写 | “神经接口信号→肌腱响应→动作执行”链路 |
| “天灵盖/任督二脉” | 传统修炼体系，与科武底层冲突 | 若保留武道经脉体系，必须给出生物/神经学解释 |

### 5.2 合规描写组合

**战斗场景**：冷峻科技术语 + 具象力学反馈

```
【示例】
“突袭者从十二点钟方向切入，液压腿在地面炸出环形裂纹。
机甲护盾在0.3秒内完成偏转计算，但能量输出只来得及覆盖75%的暴露面。
碎片撕裂装甲的声音，像有人用指甲刮过金属。
操作员的脑干接口传来一阵灼烧感——神经同步过载。”
```

**日常场景**：未来感物件 + 微观观察

```
【示例】
“食堂的自动分装臂在轨道上滑行，三号窗口的机械臂比昨天慢了0.2秒。
有人在小声议论液压器老化的事。
维修预算的申请已经躺在系统里六个月了。
没有人提起那笔预算被谁批给了北区演武场。”
```

### 5.3 失败模式：皮肉分离

若出现以下特征，说明语言尺度失配：

- 用古代/传统语境描写未来/科幻设定
- 用科幻术语描写传统/玄幻设定
- 同一段落内术语体系混乱切换

**【短篇/狼人篇借用】**：语言尺度需根据世界观调整，但“术语一致性”是底线要求。

## 六、节奏控制协议

### 6.1 前三万字节奏规则

```
阶段定位：技术推进期（核心任务：建立世界观信任度）

节奏公式：动作 → 反馈 → 认知升级

禁止事项：
- 开篇议论主题（禁止“很多人说，这是一个关于___的故事”）
- 强塞设定（禁止大段背景说明，设定必须随场景自然释放）
- 爽点前置（避免开篇就碾压，打击读者对“真实挑战”的期待）

信息释放节拍：
- 第1章：3-5个核心设定（通过场景/异常/道具带出）
- 第2-3章：冲突爆发，建立规则边界
- 第4-6章：首次代价支付，角色弧光启动
- 第7章后：主题表达开始渗透（但仍依附情节）
```

### 6.2 每三万字循环

```
预期满足 → 预期升级

【示例节奏】
第10-15章：主角完成首次武道/科技突破（满足类型承诺）
第16-20章：揭示突破代价，引出更高层级冲突（升级预期）
第21-25章：代价发酵，角色面临价值抉择（主流价值渗透）
第26-30章：再次突破，进入下一循环

【长篇借用】】：每三十万字需完成一次“大循环”，并在循环末尾埋设“整体性钩子”（关联主线/人物弧光/核心规则）。
```

### 6.3 章末钩子标准

| 钩子类型 | 描述 | 禁止 |
|:---|:---|:---|
| 未解逻辑 | 基于已有规则的悬念，非机械降神 | “天降神秘老者” |
| 关系悬置 | 角色间张力未解决，非强行中断 | “突然地震，战斗中断” |
| 规则悖论 | 已有设定出现新矛盾，非外部补丁 | “凭空出现新能力” |
| 认知颠覆 | 读者对世界/角色的认知被打破，非无厘头反转 | “一切都是主角的梦” |

```
【合规钩子示例】
“能量读数指向废弃矿区，但该坐标在百年前已被官方抹除。”
（未解逻辑：坐标为何存在？谁抹除的？为什么指向这里？）

“操作员盯着神经接口的反馈数据，发现自己的心率与机甲不同步。
机甲正在读取他的恐惧。”
（规则悖论：AI不该有情绪读取能力？还是一直都有？）

“他想起失踪的姐姐留给他的最后一句话：‘别信那个数字。’”
（关系悬置 + 认知颠覆：哪个数字？为什么要信/不信？）
```

## 七、代价系统构建

### 7.1 代价前置原则

任何突破/升级必须在以下时机之一揭示代价：

- **开篇预设**：章节/卷首明确说明代价存在（如“神经同步率超过87%会引发不可逆神经损伤”）
- **同步揭示**：突破发生的同一段落内描述代价（如“突破瞬间，脊椎神经接口传来灼烧感——他知道有三根神经纤维永久休眠了”）
- **即时反馈**：代价通过物理/社会后果立即呈现（如“能量过载导致周边三个街区停电，他们的行踪暴露了”）

**禁止**：代价事后补丁（章节末尾或下一章才揭示突破的代价）

### 7.2 代价类型矩阵

| 代价类型 | 科武转化示例 | 章节落点 |
|:---|:---|:---|
| 生理损伤 | 神经接口过载 / 基因编辑不可逆 / 武道经脉灼伤 | 限制能力上限，触发新冲突 |
| 资源枯竭 | 能量储备耗尽 / 稀有材料用尽 / 人脉断裂 | 推动资源争夺线，暴露社会结构 |
| 社会关系断裂 | 被家族除名 / 被战友怀疑 / 成为系统公敌 | 孤立角色，强化内心弧光 |
| 伦理困境 | 救一人必须杀十人 / 技术发展触碰禁忌 / 背叛盟友 | 主题渗透点，提供读者共鸣锚 |

### 7.3 代价→冲突转化

```
【转化公式】
代价支付 → 新资源需求 / 新规则暴露 / 新关系张力 → 下一轮冲突

【示例】
“机甲左臂在战斗中报废”（代价）
→ 需要稀有零件修复，但零件被垄断集团控制（资源需求）
→ 发现垄断集团正是导致他家族衰落的幕后黑手（规则暴露+关系张力）
→ 他必须决定：妥协换取零件，还是用残臂对抗到底（新冲突）
```

## 八、章节自检清单

完成章节后逐项检查：

```
□ 1. 开篇是否从具体场景/物件/天气切入，无大段设定堆砌？
□ 2. 动作链是否完整？（发力源→传导路径→作用目标→环境扰动）
□ 3. 力量释放是否有物理反馈？（延迟/损耗/代价）
□ 4. 核心冲突是否指向人性/资源/规则博弈，而非纯数值碾压？
□ 5. 非人/超凡角色的动机是否符合人类情感与历史逻辑？
□ 6. 科武设定是否“通向科学”？（有底层物理/生物/社会规则支撑）
□ 7. 语言风格是否与世界观尺度匹配？无“旧词写新境”割裂感？
□ 8. 爽点是否叠加“代价/选择/价值观”维度？避免纯安慰性套路？
□ 9. 章末钩子是否基于未解逻辑/关系悬置/规则悖论/认知颠覆？
□ 10. 单章是否具备完整起承转合？能无缝拼接入整体主线？
□ 11. 是否规避“背诗/救历史人物/无脑收后宫”等陈旧网文套路？
□ 12. 主题表达是否通过情节自然生长？无作者跳出来直接议论？
□ 13. 大纲是否明确“科”与“武”的融合边界？无底层逻辑互斥？
□ 14. 代价是否前置或同步揭示？非事后补丁？
□ 15. 读者交付是否完成？（类型承诺满足 + 共鸣点预埋）
```

**【短篇/狼人篇自检】**：重点检查1、2、3、4、8、9、15。

**【科武长篇自检】**：重点检查5、6、7、12、13，并在每卷末追加“整体性拼装验证”——本章内容拆解后能否与其他章节无缝拼接。

## 九、平台规则转译：发布/包装/风险门禁

### 9.1 发布门禁

| 门禁项 | 执行标准 | 违规风险 |
|:---|:---|:---|
| 内容合规 | 规避涉政/涉黄/涉暴敏感词，可使用“规则内暗示” | 审核拦截/下架 |
| 类型标签 | 明确核心卖点标签（如：科武/升级/探索），不混搭引发误判 | 读者流失/平台降权 |
| 节奏匹配 | 前三章完读率≥平台同类均值（参考同类爆款前3章节奏） | 冷启动失败 |
| 钩子密度 | 每3-5章必须有一个“强钩子”（可量化指标：评论/追读峰值） | 读者流失 |

### 9.2 包装门禁

| 包装项 | 执行标准 | 说明 |
|:---|:---|:---|
| 书名 | 核心关键词前置（如“科武纪元之___”），符合搜索习惯 | 提升搜索曝光 |
| 简介 | 前三行必须包含“冲突悬念+类型承诺+共鸣点”，禁止纯设定罗列 | 提升点击转化 |
| 标签 | 标签体系覆盖“核心类型+辅助类型+情感调性”，避免单标签依赖 | 扩大推荐触达 |
| 更新节奏 | 稳定更新（每日/隔日），断更要提前通知 | 维持追读习惯 |

### 9.3 风险门禁

| 风险类型 | 规避策略 | 替代方案 |
|:---|:---|:---|
| 设定争议 | 敏感设定（基因编辑/意识上传）需“规则内解释”而非“作者站台” | 通过角色争论呈现 |
| 价值观冲突 | 主流价值内化于角色选择，避免说教或对立 | 让角色以代价换取价值 |
| 数据依赖 | 不以数据反馈为创作标尺，以长期IP价值为标尺 | 保持创作独立性 |
| 短期功利 | 规避“财务自由即停笔”的惰性写作 | 每卷设立新挑战目标 |

## 十、人物口吻与段落节奏模板

### 10.1 角色口吻校验

写完角色对话/独白后，用以下问题检测：

```
□ 该角色说话方式是否与他的背景/阶层/教育/地域匹配？
□ 该角色在不同情绪下（愤怒/恐惧/撒谎/安慰）语言是否变化？
□ 该角色的核心词汇是否与世界观设定一致？（避免现代口语穿越）
□ 该角色是否有“口头禅/思维惯性/语言习惯”，可在多处复现？
□ 该角色的语言是否能传达“未直接说出的信息”（潜台词）？
```

### 10.2 段落节奏模板

```
【紧张节奏模板】
动作（短句）→ 反馈（短句）→ 压缩空间（短句）→ 决定（短句）
例：
金属断裂。（动作）
他的左肩失去了知觉。（反馈）
通道在坍塌。（压缩）
他没有回头。（决定）

【缓冲节奏模板】
观察（细节）→ 回忆（关联）→ 内心冲突（悬念）→ 选择（行动）
例：
自动门的气密胶条老化了，漏出一丝硫磺味。（观察）
这和姐姐失踪的那天一样。（回忆）
他知道门的另一边是什么，但他不确定自己还能承受一次。（内心冲突）
他按下了开关。（选择）

【信息释放节奏模板】
异常（触发）→ 验证（动作）→ 规则揭示（核心）→ 悬念（钩子）
例：
能量读数出现负值。（异常）
他检查了三遍传感器。（验证）
这意味着该区域存在“能量抽取”现象，违背热力学第一定律。（规则揭示）
而官方数据库显示，该坐标不存在。（悬念）
```

## 十一、整体性拼装协议（大纲/长篇专用）

### 11.1 核心零件确认

动笔前明确以下四个零件：

| 零件 | 定义 | 科武纪元示例 |
|:---|:---|:---|
| 头（主线） | 核心冲突的核心推动力是什么？ | “武道与科技的融合边界之争” |
| 心（人物弧光） | 主角的核心变化是什么？（内外因+代价） | “从'唯力量论'到'理解代价的代价'” |
| 肝（核心规则） | 世界运转的核心规则是什么？有哪些边界/例外？ | “神经同步率超过87%会不可逆损伤，但突破极限可获得短暂跃迁” |
| 肾（主题落点） | 读者在故事结束后会思考什么问题？ | “个体突破的代价，谁来承担？” |

### 11.2 拼装验证

每完成五章，进行一次拼装自检：

```
□ 五章内容是否都能追溯到“头/心/肝/肾”四个零件之一？
□ 章节之间的逻辑链条是否清晰？（A章结果→B章原因）
□ 有无章节内容“游离于整体之外”？（无法与主线/人物/规则/主题关联）
□ 若删除这五章，整体是否仍可运转？（找出冗余章节）
□ 单章能否独立阅读，且不影响读者理解？（检验信息自洽）
```
