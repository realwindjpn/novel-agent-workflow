# 《科武纪元》编辑学习报告：基于《团宠农家小糖宝》案例的规则提炼

## 1 课程核心判断（≤6条）
1. **题材选择服从平台风向**：作者从传统种田转向“团宠/锦鲤”是基于编辑收稿偏好与读者情绪需求的主动迭代。
2. **大纲前置+碎片库管理**：动笔前完成主线推演，日常灵感/设定/台词即时归档，正文仅做“血肉填充”。
3. **文风必须匹配题材基底**：古言种田需“接地气+夸张口语化”，忌文绉绉；语言基调决定读者代入效率。
4. **人物区分靠“语言指纹+微细节”**：群像不依赖长篇背景介绍，靠说话方式、服饰、眼神/动作切片建立辨识度。
5. **更新节奏重“稳”不重“快”**：日更4-5k精修＞日更万字水文；长篇（300万字级）必须不断更以维持推荐池权重。
6. **读者互动设情感防火墙**：不随评论区分歧临时改线，优先保障叙事完整性与类型契约，数据波动靠留存而非讨好。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则提取 |
|:---|:---|
| **开篇** | 内投标准：大纲+2万字开篇。开篇需快速亮出核心设定（如“自带福气/团宠”）与情绪基调，3章内完成世界观锚点投放。 |
| **节奏** | 稳定日更4k-5k，拒绝断更；长篇需预留长线伏笔（如父母身份/隐藏势力），按“破五百→破千→首月稳定”设置数据爬坡节点。 |
| **冲突** | 冲突设计服务主线逻辑，不因读者阵营分歧（如男主归属/路线选择）临时撕裂剧情；保持作者叙事主导权。 |
| **人物** | 群像差异化三要素：①独立说话方式（语气/口头禅/专业术语）②外在标识（装备/服饰/体态）③微表情/动作切片。 |
| **题材** | 紧跟平台收稿趋势（如团宠/玄学/锦鲤）；传统基底需做“情绪降维”处理，用夸张口语化表达替代书面语，强化市井/生活气息。 |
| **改编** | 文本需具备强画面感：场景描写必须“细致烘托+直观成像”，避免抽象概念堆砌；核心梗需易转化为短视频切片/短剧分镜。 |
| **平台规则** | 番茄推荐机制公平，凭数据说话；内投是标准路径；首月日收破千是流量跃迁阈值；可叠加官方扶持计划（如魁星计划）获取保底/流量倾斜。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **大纲与设定集管理**：科幻长篇逻辑密度高，必须前置推演科技树/战力体系/势力关系，建立“碎片灵感库+回收表”。
- **人物语言指纹**：机甲师/武者/科学家需靠战术指令习惯、专业术语密度、装备操作微动作区分，避免脸谱化。
- **稳定更新策略**：科武易因设定膨胀崩盘，4-5k/日精修优于注水；不断更是维持番茄算法推荐池的基础。
- **画面感与改编接口**：战斗/跃迁/机甲启动需强视觉化描写，预留分镜切割点，适配短剧/漫画/游戏化改编。
- **平台数据节点运营**：内投2万字测试→首月留存追踪→破千阈值优化，利用番茄公平推荐机制做A/B测试。

### ❌ 不可硬套点（科武需规避）
- **“团宠/锦鲤/纯情绪爽文”基调**：科武需硬核逻辑/生存压力/规则博弈，不可用“走路捡金子”式无代价好运替代战力成长。
- **“夸张乡土口语化”文风**：科武语境需冷峻/专业/未来感，过度市井化会破坏科幻沉浸感与设定严肃性。
- **“主角未成年/长不大”节奏**：科幻需明确成长线/技术迭代/战力跃迁，拖沓易流失硬核读者与推荐权重。
- **“完全回避读者反馈”**：科幻设定易出现物理/逻辑硬伤，需适度收集技术流反馈修正漏洞，但绝不妥协主线架构。

## 4 编辑检查表（10条以内）
1. [ ] 开篇2万字是否清晰抛出核心科幻设定、主线目标与类型承诺？
2. [ ] 人物对话是否具备独立“语言指纹”（术语习惯/指令节奏/语气特征）？
3. [ ] 场景/战斗描写是否提供强视觉成像，而非纯概念/参数堆砌？
4. [ ] 日更是否稳定在4k-5k区间，无断更/水文/临时改线记录？
5. [ ] 大纲是否包含关键数据节点（首月/破千/中期转折）与伏笔回收表？
6. [ ] 文风是否契合“科武”基调（冷峻/专业/未来感），避免市井口语化？
7. [ ] 冲突设计是否服务主线逻辑，未因评论区分歧临时调整核心路线？
8. [ ] 是否预留IP改编接口（机甲分镜/高概念场景/规则可视化）？
9. [ ] 数据波动期是否优先保逻辑自洽，而非临时加糖/降智？
10. [ ] 作者是否严格执行“灵感碎片库+设定集”动笔前归档流程？

## 5 对作家角色的输入要求
| 维度 | 执行标准（科武向） |
|:---|:---|
| **动作链** | 战斗/操作必须拆解为“感知→决策→执行→结果”四步闭环，禁止跳步或机械降神。例：神经接驳延迟→手动切断备用回路→能量过载警报→战术规避。 |
| **物理反馈** | 科幻设定必须落地为五感体验。例：重力异常→骨骼压迫感/内脏位移；能量武器→空气电离味/视网膜灼斑；跃迁→前庭失衡/耳鸣。 |
| **代价** | 任何科技突破/金手指必须伴随明确损耗。例：超频算力→神经突触灼伤；基因改造→代谢加速/寿命折损；AI辅助→记忆碎片化/情感剥离。 |
| **钩子** | 每章结尾埋设“未解变量”或“规则反转”。例：看似歼灭敌军，实则触发高维文明观测协议；胜利代价是坐标暴露。禁用纯情绪断章。 |
| **读者预期** | 开篇3章内兑现类型承诺（硬核推演/热血升级/悬疑解谜）；后续不偏离契约。数据波动时优先保逻辑自洽，明确告知读者“本卷核心目标”，不临时加糖或降智迎合。 |
