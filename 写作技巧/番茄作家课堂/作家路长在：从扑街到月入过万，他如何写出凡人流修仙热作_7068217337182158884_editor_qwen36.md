# 《科武纪元》编辑学习官：路长在专访规则提炼

## 1 课程核心判断（≤6条）
1. **题材锚点**：放弃短期跟风，深耕作者擅长且具备长线生命力的垂直赛道，内容自驱力决定完本率与IP厚度。
2. **节奏规律**：传统/慢热题材需接受10-80万字的数据爬坡期，但可通过“矛盾链”维持留存，卷末高潮可提前引爆数据。
3. **剧情引擎**：严格遵循“欲望+阻碍=矛盾”公式，矛盾解决即刻埋设新矛盾，以递进式冲突替代平铺直叙。
4. **人物逻辑**：主角需“生存理性优先+人性微光保留”，99%努力+1%决定性变量，避免无敌流导致读者预期断裂。
5. **跨域重组**：人物动机与性格模板具有跨题材通用性，可从影视/现实/科幻作品中拆解逻辑，按当前世界观重组。
6. **平台生态**：免费平台对传统题材有算法耐心，需利用保底计划度过冷启动，以稳定日更换取推荐权重与长尾收益。

## 2 可执行编辑规则（按原文内容提取）
| 维度 | 编辑规则 |
|:---|:---|
| **开篇** | 内投/首秀需准备3万字完整开头；不追求开局即爆，但必须清晰展示主角初始欲望、当前阻碍与世界观核心规则。 |
| **节奏** | 采用“旧矛盾收尾前必埋新矛盾”的链式结构；接受慢热爬坡，但需在30万/60万/80万字节点规划阶段性高潮卷拉升数据。 |
| **冲突** | 冲突必须源于“欲望与阻碍的碰撞”；按矛盾深度分配篇幅，层级递进（个体生存→势力博弈→规则/文明冲突）。 |
| **人物** | 主角设定“利己保命为底色+情感锚点为变量”；配角/反派动机需现实化，禁止纯工具人，可跨媒介提取人性逻辑组装。 |
| **题材** | 核心卖点是“真实感成长”；强调资源匮乏下的步步为营、技术/能力迭代与代价交换，拒绝无脑爽与机械降神。 |
| **改编** | 强剧情反转与多线人物群像具备影视化潜力；需提前规划400万字级长线大纲，预留卷末高潮与IP开发接口。 |
| **平台规则** | 利用平台保底/扶持计划度过冷启动；首秀后关注30-100万字数据曲线，以“不断更+稳定更新量”换取算法推荐权重。 |

## 3 科武适配
### ✅ 可用点
- **矛盾链引擎**：完全适用于科武世界观下的“技术突破/资源争夺/阵营对抗”，可替换为“算力瓶颈/能源配额/AI伦理/机甲适配率”等冲突。
- **成长模型**：“99%推演/训练+1%关键变量（技术奇点/基因突变/核心代码）”符合硬科幻/科武的逻辑自洽要求。
- **跨媒介借鉴**：从《黑客帝国》等科幻影视提取人物动机与行为逻辑，天然契合科武语境，降低设定违和感。
- **长线结构**：数十万字铺垫适合科武的“科技树攀升+文明跃迁”节奏，卷末高潮可绑定“技术验证/战役节点/规则重构”。
- **平台策略**：番茄科幻频道对“逻辑严密+慢热成长”有明确受众，保底+稳定日更策略可直接复用。

### ❌ 不可硬套点
- **资源体系平移**：修仙的“丹药/秘境/闭关”不可直接替换为科武设定，必须转化为“实验室迭代/数据模拟/神经负荷/装备损耗”等物理/技术逻辑。
- **篇幅冗余风险**：400-500万字对科武可能过长，需按“技术奇点/文明跃迁/阵营洗牌”节点压缩卷幅，避免设定注水与节奏拖沓。
- **权谋语境替换**：修仙的“宗门阴谋/人情世故”需转为“企业财阀/星际联邦/科研伦理/AI博弈”，避免古风权谋与科幻基调冲突。
- **开篇容忍度差异**：番茄科幻读者对“慢热”的容忍度低于玄幻区，开篇3万字内必须植入强科幻钩子（如异常信号/技术危机/生存倒计时），不可纯靠氛围铺垫。

## 4 编辑检查表（10条以内）
1. 开篇3万字是否明确主角核心欲望与当前最大阻碍？
2. 当前卷末是否已埋设下一卷的核心矛盾钩子？
3. 主角破局是否依赖“99%技术/战术推演+1%关键变量”，而非机械降神？
4. 冲突升级是否遵循“个体生存→组织博弈→文明/规则冲突”的递进逻辑？
5. 配角/反派动机是否具备现实人性逻辑（非纯工具人）？
6. 科武设定是否通过具体物理反馈/代价呈现，而非纯设定堆砌？
7. 数据爬坡期（10-80万字）是否规划了至少2个阶段性高潮卷？
8. 日更节奏是否稳定？断更是否提前有存稿/大纲缓冲？
9. 跨题材元素是否已完成“科武语境”转译？
10. 是否保留主角成长代价与资源限制，避免无敌流倾向？

## 5 对作家角色的输入要求
| 维度 | 输入要求（科武语境） |
|:---|:---|
| **动作链** | 严格遵循“目标→决策→执行→受阻→调整→结果”闭环。科武场景需细化为“技术操作/战术机动/环境交互”的具体步骤，禁止跳跃式推进或省略关键推演环节。 |
| **物理反馈** | 所有科武设定（机甲负荷、神经接驳、能量武器、重力/真空环境）必须伴随可感知的生理/环境反馈（如骨骼震颤、视网膜数据流、金属疲劳声、氧气浓度警报、散热过载）。用感官细节替代抽象说明。 |
| **代价** | 每次技术突破/战斗胜利必须支付明确代价（如神经损伤、信用点透支、阵营信任破裂、设备不可逆损耗、伦理红线突破）。禁止“零成本升级”，代价需直接推动后续剧情或人物关系裂变。 |
| **钩子** | 每章结尾/卷末必须设置“未解矛盾+新变量”（如异常信号、技术反噬、盟友背叛倒计时、规则漏洞暴露）。钩子需与当前主线强关联，禁止为悬念而悬念或脱离科武逻辑。 |
| **读者预期** | 科武读者预期“逻辑自洽的硬核推演+小人物逆袭的真实感”。需在设定集/大纲中锚定“技术边界”与“成长上限”，避免后期战力/科技树崩坏；爽点必须建立在“合理代价后的破局”之上，维持“努力可量化、奇迹有代价”的阅读契约。 |
