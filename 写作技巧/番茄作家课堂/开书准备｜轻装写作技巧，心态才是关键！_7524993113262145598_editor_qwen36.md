# 《科武纪元》编辑学习官｜课程萃取报告

## 1 课程核心判断（≤6条）
1. **逆向选题定生死**：先完成市场调研锁定热门赛道，再改造原有构思；题材未定则跟风热点，题材已定则拆解3-5本头部作品避雷。
2. **大纲极简三要素**：仅锁定“大主线、大动机、大矛盾”（各≤3行），配套明确升级体系与前置条件，防逻辑发散与战力崩坏。
3. **包装即点击转化**：封面制造视觉锚点与纵深感，书名直给核心爽点/设定，简介精准提炼“背景+金手指+冲突”，拒绝文艺晦涩。
4. **开篇试错机制**：同一故事强制输出≥3版不同切入点开篇，以“非作者读者是否产生翻页冲动”为唯一过稿标准。
5. **干中学迭代逻辑**：写作能力依赖实际连载积累，扑街是数据反馈期；带具体问题扫榜爆款，吸收效率远高于空听理论。
6. **灵感与卡文解法**：灵感=输入积累（同类书/影视/短视频）；卡文=自我审查过载，执行“先写后改”降低启动内耗。

## 2 可执行编辑规则（按维度取舍）
| 维度 | 编辑规则（基于原文） |
|:---|:---|
| **开篇** | 首章必须抛出核心冲突/反差/钩子；禁用纯设定说明与慢热铺垫；强制3版开篇A/B测试，以“读者翻页冲动”为硬性指标。 |
| **节奏** | 以“升级体系”为节奏坐标轴；每10-15万字设置明确阶段性目标（收集/突破/破局）；严禁无铺垫越级打怪，防战力逻辑断裂。 |
| **冲突** | 大矛盾必须拆解为可执行的小矛盾驱动单元剧情；简介与开篇需在3000字内迅速交织“背景+金手指+核心冲突”。 |
| **人物** | 行为逻辑严格受“大动机”约束，规避动机断裂毒点；人设需做“微创新”碰撞（如传统体系+异质背景）；配角/反派需有独立利益诉求。 |
| **题材** | 老题材必须做背景置换/设定碰撞/视角转换；已定题材需拆解头部作品掌握“氛围感”与“堵点”，不盲目堆砌新设定。 |
| **改编** | 封面/书名/简介承担算法推荐与点击转化功能；短视频/速读/沙雕动画作为高效素材库与节奏参考源；拒绝传统文学式留白包装。 |
| **平台规则** | 标签对齐平台算法偏好（爽点前置/明确分类）；连载期以“数据反馈迭代”替代“一炮而红”预期；完本率与追读留存优先于单本爆发。 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **升级体系坐标化**：科武的“基因锁/机甲阶位/武道境界”天然契合升级逻辑，需严格列全阶位名称与突破前置条件（如能量阈值/材料收集/神经适配率），作为长篇节奏锚点。
- **微创新碰撞**：将硬核科幻设定（矩阵宇宙/AI叛变/星际殖民）与武道修炼体系结合，制造“科技降维打击+武道肉身破局”的差异化爽点。
- **开篇防设定堆砌**：利用“3版开篇测试”强制检验科幻设定的抛出效率，确保首章以“危机事件”切入，而非世界观说明书。
- **碎片化素材库**：建立“科武专属素材夹”（物理法则/机甲结构/星舰参数/冷兵器格斗视频），用短视频速读替代长篇文献查阅，降低描写内耗。

### ❌ 不可硬套点
- **拒绝纯商业跟风牺牲科幻自洽**：科武需基础科学逻辑与设定闭环，不可为迎合短期热点强行扭曲物理法则或武道体系。
- **包装不可过度网文套路化**：书名/简介需保留“纪元/矩阵/星舰/武道”等核心科幻意象，平衡“爽点直给”与“世界观厚重感”，避免廉价感。
- **长篇节奏不可套用短平快逻辑**：科武需留白构建科技树演进与势力博弈，不能为追求前三章爽点而压缩必要设定铺垫（应通过“冲突前置+设定碎片化释放”解决，而非删减）。

## 4 编辑检查表（10条以内）
1. [ ] 是否已拆解3-5本同赛道头部作品，明确核心套路与读者雷区？
2. [ ] 大纲是否仅保留“大主线、大动机、大矛盾”三要素（各≤3行）？
3. [ ] 升级体系是否列全阶位？每级突破的前置条件/阶段目标是否明确？
4. [ ] 封面是否有视觉锚点与纵深感？书名是否直给核心爽点/设定？
5. [ ] 简介是否精准包含“背景+金手指+冲突”？是否拒绝文艺晦涩？
6. [ ] 是否完成≥3版不同切入点开篇？是否经非作者读者验证“翻页冲动”？
7. [ ] 首章是否出现核心矛盾/反差？是否避免慢热与纯设定说明？
8. [ ] 是否严格遵循“同级/越级限制”？有无未铺垫的战力跳跃？
9. [ ] 是否建立分类素材库（设定/名词/场景/参考图）？能否支撑连续3万字不卡文？
10. [ ] 是否制定“数据波动期迭代预案”？是否以完本率与追读留存为考核基准？

## 5 对作家角色的输入要求
| 维度 | 编辑输入要求（硬性标准） |
|:---|:---|
| **动作链** | 必须呈现“触发事件→主角决策→执行动作→结果反馈”闭环。禁止无目的游荡或纯心理独白；每个动作需推动主线、揭示设定或改变势力格局。 |
| **物理反馈** | 科武/科幻场景需具象化感官描写（重力变化、金属应力、能量辐射、生理负荷、环境温湿度）。禁用抽象形容词（如“极强/极痛”），替换为可测量的物理/生理参数变化。 |
| **代价** | 任何金手指激活/境界突破/越级行为必须绑定明确代价（资源枯竭、神经损伤、道德妥协、阵营暴露、冷却期）。无代价爽点视为毒点，需在大纲阶段预设代价回收机制。 |
| **钩子** | 每章结尾必须埋设“未解悬念/危机逼近/选择分支/信息差反转”。开篇钩子需在3000字内抛出核心矛盾，拒绝“日常铺垫+突然转折”；钩子需与简介承诺的爽点强关联。 |
| **读者预期** | 严格对齐书名/简介/标签承诺的题材与爽点。利用升级体系提前预告下一阶段目标，实施“期待感管理”；禁止中途更换核心赛道、颠覆已建立的力量逻辑或无故降智配角。 |
