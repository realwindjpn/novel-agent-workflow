## 1. 课程核心判断（6条以内）

1. **写作是"带着问题找答案"，不是"带着答案找问题"**：大纲/人物小传是脚手架，不是解题公式。
2. **过度准备会反噬灵感**：当作者写到一半还在回忆"我大纲里这段是怎么写的"，说明已被自己捆死。
3. **遇到阻力 = 进步征兆**，不是该停笔的信号。
4. **人设三档**：优秀人设推动剧情；及格人设服务剧情；不合格人设拖垮剧情。主角变工具人 = 刚过及格线。
5. **人物扁平的根因只有两个**：人物素材积累不够、剧情设计功底不足。其余都是表象。
6. **职业作者不靠灵感写作**——灵感枯竭只是初阶问题，解法是疯狂练习 + 疯狂素材积累，不是等。

## 2. 可执行编辑规则

### 开篇
- 不允许"先写完整大纲再动笔"。短篇及单元剧：脑中有开头即开写，大纲与人设在写作过程中反向沉淀。
- 开篇必须能在后台"读完率/跟读率"上验证。开篇=钩子测试，不达标就改，不要回避数据。

### 节奏
- 不预设"剧情流"或"感情流"标签，唯一标准是"是否精彩"。任何为平衡而平衡的设计都砍掉。
- 写作中若感到滞涩，允许推翻原大纲继续往下写，保留"由心"的失控段，事后再回头补逻辑。

### 冲突
- 冲突取材回到生活原型问句：换作"我/我身边的人"在这个处境会做什么、说什么？回答越具体，对话越有撞击感。
- 冲突要给人物提供选择题（庆祝 vs 独吞型的二岔路），不要只给人物一条剧情滑轨。

### 人物
- 每个主要角色必须有"背后故事"——能解释他为什么主动出招，而不是被剧情推着出招。
- 判定标准：把这个角色抽走换成另一个性格的人，剧情还能不能成立？能 = 工具人，必须重写。
- 性格"大众化"先查两处：人物素材库（看过多少类似原型）/ 剧情设计能力，不要在文本层面打补丁。

### 题材
- 跨题材时，对标对象不变：去看同榜单同类型 Top 作品，逐条比"它好在哪、我差在哪"。优秀作品的优点是大同小异的，可迁移。
- 不要因为换了科幻/科武题材就放弃原有方法论。

### 改编 / 复盘
- 复盘工具链：后台读完率 + 跟读率 + 同类标杆对标，三件套并用，单看一个都会误判。
- 修改顺序：先修开篇吸引力 → 再修中段黏性 → 最后才动人物弧线。

### 平台规则（番茄）
- 数据是第一反馈源，不是发完就完事。"写几本没长进"这种焦虑，番茄的解法是"先写出几本来看数据"。
- 初期不以赚钱为锚，以"写作乐趣"为锚——这是平台长线作者的心态前提。

## 3. 《科武纪元》适配

### 可直接用的点
- **"先有故事再有大纲"** 适合科武世界观的支线/单元案：先写一个修炼者的具体冲突场景，再反推该势力/功法设定，避免世界观先行把人物写死。
- **背景故事撑人设**：科武主角的"科技背景 + 武道经历"必须有可被一段独白讲清楚的来路，否则升级线一开就垮成爽文工具人。
- **生活原型问句法**：把"被背叛""中彩票"换成科武版本——"师门被灭你独活""芯片植入失败队友死了"——逼出非套路化反应。
- **对标榜单**：在番茄科幻/末世/机甲分区按读完率排前 20 拆解，迁移钩子套路而非世界观。

### 不可硬套的点
- **"扔掉大纲大胆写"** 不能整本套用。长篇科武的功法体系、势力关系、时间线必须有硬骨架，否则中后段会塌。建议**章节级**可弃大纲，**卷级以上**不可弃。
- **"番茄炒蛋随便炒"** 的随性论，不适用于硬科幻设定的一致性（能量守恒、技术等级、设定不打架），这部分必须按"维修技术"对待。
- **"不分流派"** 在科武长篇里要谨慎：科 vs 武的比重、爽点节奏需要明确卷规划，不能全交给"感觉"。
- **"灵感来源于生活"** 对于异星/未来场景需二次转译，不能直接照搬日常对话腔。

## 4. 编辑检查表（10条内）

1. 这一章的主角是在"自己做决定"还是"被剧情拽着走"？
2. 把主角换成另一个性格的人，本章剧情还成立吗？
3. 本章核心冲突，是否给了人物一个有撞击力的选择题？
4. 对话是否能用"现实里我会怎么说"通过一次重写？
5. 开篇/章首是否在 3 段内出现钩子？读完率预期能扛住吗？
6. 是否出现作者"回查大纲/小传"造成的卡顿段落？标出删改。
7. 设定（功法/科技/势力）是否与前文一致？硬骨架不能让步给"感觉"。
8. 本章是否承担了一个明确功能（钩子/冲突升级/人物揭示/伏笔回收）？没有=砍。
9. 同题材榜单 Top 作品在同位置（如第 5 章）做了什么？我做了什么？差距点是什么？
10. 看完本章读者最想知道的下一个问题是什么？写得出来就保留，写不出就重写结尾。

## 5. 对作家角色（写作 Agent）的输入要求

每次提交章节/片段时，作家角色必须随稿附带以下五项结构化信息，便于编辑复核：

### ① 动作链
- 主角本章的动作序列（动词为主）：决策点 → 行动 → 结果 → 反应。
- 每个动作必须可追溯到一个动机源（人物背景/上一章遗留事件），不允许"为了推进剧情"。

### ② 物理反馈
- 科武设定下的身体/环境/技术反馈：能量消耗、伤势、装备状态、环境变化。
- 用数值或可感知描写（疼痛部位、温度、声音）落地，不许只写"他成功了"。

### ③ 代价
- 本章主角为推进剧情**失去了什么**（资源、关系、时间、原则、身体部位、信息优势）。
- 若代价 = 0，本章默认无效，需重写或合并。

### ④ 钩子
- 章末钩子明确标注类型：悬念钩 / 反转钩 / 情绪钩 / 设定钩。
- 钩子必须指向一个读者"下一章想知道答案的问题"，并写出该问题原句。

### ⑤ 读者预期
- 本章服务的读者预期是哪一条：爽点兑现 / 伏笔埋设 / 伏笔回收 / 人物揭示 / 世界观扩展。
- 与上一章预期之间的衔接关系（继承 / 反转 / 升级）。

> 五项缺一退回重写。这是把"感觉派写作"翻译成"可被编辑复核的工艺"的最小接口。
