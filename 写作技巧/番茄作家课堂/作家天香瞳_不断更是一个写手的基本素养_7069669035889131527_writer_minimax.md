## 一、核心执行动作（作家日常可直接调用）

### 🎯 开篇行动清单
```
【触发条件】新章节开始前
【执行动作】
1. 确认本章主角核心目标（≤1句描述）
2. 标注本章第一重困境/阻碍
3. 检查上章钩子是否在本章兑现或升级
4. 预埋本章视觉化冲突节点

【禁止动作】
✗ 禁止堆砌流行梗
✗ 禁止"伪爽点"（无代价的高光）
✗ 禁止不熟悉的文风尝试
```

### ⚔️ 节奏执行动作
```
【波峰-波谷结构】
危机建立 → 能力/智谋破局 → 新危机升级

【科武专项检查点】
- 每次战斗需标注：能量流转路径/机械响应步骤/身体负荷指数
- 技术博弈需呈现：路线互斥逻辑/资源消耗对比/时间窗口限制
```

### 💡 冲突制造动作
```
【身份反差】阵营对立+血缘绑定/技术路线互斥
【信息差】主角独有信息→读者已知→对手未知
【破局验证】冲突解决必须引用前文铺垫的设定编号
```

## 二、反馈系统（写时可监测）

### 感官替代表
| 原写法（抽象） | 替代写法（可观测反馈） |
|:---|:---|
| "非常强大" | 金属凹痕深度/能量输出曲线/对手反应时间 |
| "快速移动" | 残影帧数/空气撕裂声/地面震动延迟 |
| "心灵震撼" | 瞳孔收缩/手部微颤/灵能波动频率 |
| "技术先进" | 功耗比/维护周期/兼容性接口数量 |

### 物理反馈清单（科武必检）
```
□ 能量过载：热辐射扩散/设备降频/人员撤离触发
□ 机械运作：关节咬合声/润滑压力/负载警报
□ 基因/灵能：神经刺痛等级/瞳孔变色/意识剥离感
□ 环境反应：重力畸变视觉/电磁干扰/时间感知错位
```

## 三、代价机制（强制执行）

### 开大代价类型
```
1. 【体力型】战斗时长→透支→下一章基础属性下降
2. 【装备型】核心道具损伤→需维修/更换→资源消耗
3. 【寿命型】禁忌技术→细胞损伤→不可逆代价
4. 【社会型】暴露底牌→敌方针对性反制→势力重组
5. 【系统型】灵能过载→能力暂时封印/冷却倒计时
```

### 代价累积规则
```
【必须执行】
- 代价需记入"人物状态面板"（见任务卡）
- 代价需在3章内影响剧情走向
- 禁止"代价清零"（除非完成特定修复支线）
```

### ❌ 失败模式识别
```
【高频失败】
1. 机械降神：无铺垫设定突然解决冲突
2. 战力崩坏：越级战斗无代价/无铺垫
3. OOC降智：为推剧情让角色行为违背核心利益
4. 设定自矛盾：科武规则内部逻辑打脸
5. 纯意识流：心理描写无物理对应指标
```

## 四、人物口吻速查

### 科武角色语录模板
```markdown
【科学家型】"数据不会撒谎，但你的解读会。——重启第三轮推演。"
【武者型】"这招我收了。——你的关节。"（冷硬简洁）
【指挥官型】"给我十分钟，十分钟后这里只剩废墟。"
【叛逆者型】"规则是用来打破的，代价？代价是用来计算的。"
```

### 段落节奏速配
| 场景类型 | 句式长度 | 标点密度 | 留白比例 |
|:---|:---|:---|:---|
| 战斗/危机 | 短句+断句 | 高（！） | 20% |
| 技术解析 | 中长句+括号补充 | 中（，；） | 10% |
| 情感/回忆 | 长短交错 | 低（。） | 30% |
| 悬疑揭示 | 设问句+留白 | 极高（？） | 40% |

## 六、章节自检清单（输出前必过）

### ✅ 基础项（每章必检）
```
□ 开篇3章内明确主角目标+困境
□ 科武体系规则内部逻辑自洽
□ 每章有≥1个视觉化冲突节点
□ 章末钩子类型属于"未解变量"
□ 战斗/技术场景有物理反馈描写
```

### ✅ 进阶项（每5章复核）
```
□ 无战力崩坏（战力排名表对照）
□ 设定无内部矛盾（设定库交叉验证）
□ 读者爽点预期已兑现≥1次
□ 更新节奏稳定（固定时段）
```

### ✅ 完读率维护（每10万字）
```
□ 强悬念/反转/高潮节点≥1个
□ 新增人物/设定直接推动主线
□ 无无效支线占用篇幅
□ "视觉化改编接口"已预留
```

## 七、平台规则转化（发布/包装/风险门禁）

### 📤 发布门禁
| 规则项 | 转化执行动作 |
|:---|:---|
| 首章点击率 | 标题必须含"科武关键词"+冲突承诺 |
| 3万字留存 | 前3章必须完成"世界观+主角目标+第一困境" |
| 完读率 | 每章≤4000字，章末强制钩子 |
| 更新时段 | 固定时间发布（培养读者生物钟） |

### 📦 包装门禁
```
【标题公式】
{科武元素}+{冲突类型}+{悬念词}
示例：《基因锁觉醒：第37号实验体的逃亡倒计时》

【简介公式】
{主角身份}+{核心矛盾}+{独特设定}+{钩子承诺}
示例：星际罪犯觉醒武道系统，在基因改造兽的围猎中
     寻找人类最后的火种——代价是每次突破都要付出寿命。
```

### ⚠️ 风险门禁
```
【断更风险】
- 预警机制：提前2天准备存稿
- 断更24小时→主动发请假公告
- 超过3天断更→联系编辑说明原因

【内容风险】
- 禁止政治敏感设定（如真实国名/政权影射）
- 禁止低俗擦边描写
- 科武设定避免"绝对化"表述（使用"推测/可能/数据显示"）
```
