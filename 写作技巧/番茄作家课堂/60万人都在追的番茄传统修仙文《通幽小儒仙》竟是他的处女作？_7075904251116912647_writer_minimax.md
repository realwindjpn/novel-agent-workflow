# 二、动作-反馈-代价系统（核心执行层）

## 2.1 动作链四步法

每个场景必须包含以下四步，**禁止跳过中间步骤**：

```
① 决策触发 → ② 物理执行 → ③ 环境反制 → ④ 结果呈现
```

| 步骤 | 执行标准 | 失败表现 |
|:---|:---|:---|
| **①决策触发** | 明确主角的价值观/科武信条在此时点的具体作用 | "主角突然想这么做"（无底层逻辑） |
| **②物理执行** | 可拆解为≥3个物理/战术动作（位移/发力/瞄准/切换） | "一掌打出去，对方就倒了"（无过程） |
| **③环境反制** | 对手/系统/规则产生明确反制动作 | "对手毫无反应，直接领死"（无张力） |
| **④结果呈现** | 结果必须产生可观测的物理/社会/心理变化 | "赢了但什么都没改变"（无代价） |

### 科武长篇可借点：动作链必须绑定技术参数

```markdown
【错误示范】
主角启动机甲，冲向敌人，一击必杀。

【正确示范】
主角将神经同步率从72%压至89%警戒线→机甲关节液压系统过载预警（嗡鸣）→右手电热剑充能67%→突进轨迹瞄准对方能量护盾接缝（0.3秒窗口）→刺入→护盾崩解伴随蓝光溅射→对手装甲熔穿→主角右臂神经反馈刺痛（负荷代价）
```

---

## 2.2 物理反馈清单（科武必填项）

> **适用场景**：所有战斗/升级/技能施展/装备操作场面

| 反馈类型 | 必填要素 | 示例表达 |
|:---|:---|:---|
| **能量输出** | 百分比/等级/耗能数值 | "充能至73%" "灵力涌出三成" |
| **神经/肉体负荷** | 阈值/透支量/恢复周期 | "神经同步率逼近90%红线" "右臂肌肉纤维撕裂15%" |
| **空间位移** | 距离/速度/轨迹特征 | "3秒内横移12米" "弧线突刺绕后" |
| **声光变化** | 颜色/强度/持续时间 | "蓝光持续0.8秒后熄灭" "嗡鸣声震碎石壁" |
| **生理痛感** | 部位/程度/持续效应 | "太阳穴针刺感蔓延至眼球" "疼痛在3秒后消退" |
| **装备报警** | 触发条件/报警类型/系统反馈 | "左肩装甲过热红色警示" "能量核心余量不足20%" |

### 科武长篇可借点：物理反馈是科武文的"硬通货"

科武读者对"凭空施法"容忍度极低。每个技能必须回答：
- 能量从哪里来？（灵力池/核聚变/生物电池）
- 消耗了什么？（寿命/精神力/弹药量）
- 有什么副作用？（神经灼伤/过热/失控风险）

## 2.3 代价设计表

> **触发条件**：任何越级行为 / 破局决策 / 违背常规操作 / 情感爆发时刻

| 代价类型 | 科武语境表达 | 回响周期 | 回响形式 |
|:---|:---|:---:|:---|
| **寿命折损** | 基因码/细胞分裂次数/意识体存续时限 | 3-5章 | 身体指标异常/同源者预警/对手洞察 |
| **理智污染** | 神经同步率过高/AI意识侵蚀/武魂反噬 | 2-3章 | 判断失误/记忆碎片/他人察觉 |
| **资源枯竭** | 能量核心耗尽/弹药见底/材料损耗 | 1-2章 | 战力下降/装备故障/后勤危机 |
| **人际关系断裂** | 背叛/误会/价值观冲突导致的阵营分裂 | 5-10章 | 孤立无援/内鬼/复仇线 |
| **战力透支** | 越级技能的后遗症/禁忌手段的代价 | 2-4章 | 短期虚弱/永久削弱/隐藏伤病 |

### 科武长篇可借点：代价必须"可量化、可追踪"

```markdown
【错误示范】
主角透支生命击败强敌，之后再也没提这件事。

【正确示范】
主角透支10%生命源质（以端粒缩短2.7%表述）→战斗后检测报告显示"细胞活性下降17%"→3章后被对手察觉"气息不稳"→5章后因寿元不足触发晋升仪式失败→8章后需要寻找延命手段→与主线"武道天花板"形成联动
```

## 2.4 失败模式清单（红线禁区）

| 失败模式 | 特征描述 | 自检问题 |
|:---|:---|:---|
| **情绪跳跃** | 主角情绪突然转变，无铺垫 | "这个情绪从哪来的？" |
| **机械降神** | 困境突然被外部力量解决 | "这个解决方案前面埋过吗？" |
| **战力通胀** | 角色实力无代价提升，超出设定上限 | "他凭什么能赢这场？" |
| **人设崩塌** | 主角行为违背底层价值观/科武信条 | "如果他是这种人，前面为什么..." |
| **逻辑断链** | 物理/科技规则前后矛盾 | "能量守恒呢？" "这个材料能承受这个温度吗？" |
| **无代价胜利** | 重大胜利后没有产生后续负面影响 | "赢了就赢了？" |

# 三、人物口吻设计指南

## 3.1 科武语境下的口吻类型

| 口吻类型 | 适用角色 | 科武特征词 | 禁用表达 |
|:---|:---|:---|:---|
| **冷幽默型** | 主角/孤狼型配角 | "算力不够，运气来凑" "系统又给我推送bug了" | 纯吐槽无实质 |
| **战术性自嘲** | 危机中主角 | "我就知道这装甲撑不过三秒" "早说了别立flag" | 过度轻佻削弱紧张感 |
| **硬核技术型** | 科研人员/技师 | "能量转化率87.3%，理论上限" "这个参数不对，重算" | 术语堆砌无解释 |
| **官僚话术型** | 高层/势力代表 | "按程序走" "这是上面定的指标" | 空洞无物 |
| **热血/信仰型** | 武道信徒/理想主义者 | "武道不是用来杀人的" "我手中有剑，心中有道" | 过于说教 |

### 短故事/狼人篇可借点：口吻速成法

适用于短篇或需要快速立住角色时，**三句定型法**：
1. 第一句：职业/身份特征台词（技术术语/权力话术）
2. 第二句：价值观暴露台词（隐藏立场/真实想法）
3. 第三句：矛盾暴露台词（与第一句的冲突）

```markdown
示例：
"能量护盾参数没问题。（职业话术）"
"……但挡不住人心。（价值观暴露）"
"算了，能拖三秒是三秒。（矛盾暴露：明明觉得不行，还是硬撑）"
```

### 科武长篇可借点：口吻随情节演变

主角口吻需要在不同章节体现**心境变化**：
- 初期：冷幽默/自嘲为主（防御机制）
- 中期：战术性自嘲+硬核技术型混杂（能力提升）
- 后期：根据对手切换口吻（社交策略成熟）

---

## 3.2 对话去水词标准

> **核心原则**：保留"意境留白"但删除"无效信息"

| 需删除 | 保留 |
|:---|:---|
| "啊" "哦" "嗯" 等语气词（除非角色设定需要） | 关键停顿（用破折号或句号表达） |
| 重复确认："真的吗？" "是这样吗？" | 必要反问（制造信息差） |
| 无意义的寒暄 | 有目的的试探 |
| 过度解释（读者已知的背景） | 暗示性台词（为后续埋伏笔） |

# 四、段落节奏模板

## 4.1 章节类型比例参考

| 章节类型 | 建议比例 | 持续时长 | 科武语境示例 |
|:---|:---:|:---:|:---|
| **高潮段** | 30% | 3-5章/卷 | 决战/突破/真相揭露 |
| **缓冲段** | 40% | 2-3章 | 日常/训练/情报收集 |
| **过渡段** | 20% | 1-2章 | 场景切换/人物互动/伏笔铺设 |
| **信息段** | 10% | ≤1章 | 设定展示/背景说明（必须绑定情节） |

### 科武长篇可借点：高潮-缓冲-高潮的波浪式推进

```
【卷结构示例】
卷1高潮（3章）→卷1缓冲（4章）→卷1过渡（2章）
    ↓
卷2高潮（4章）→卷2缓冲（3章）→卷2过渡（2章）
    ↓
卷3高潮（5章）【大高潮需更长铺垫】
```

---

## 4.2 段落内部节奏控制

| 段落类型 | 句式特征 | 字数控制 | 自检问题 |
|:---|:---|:---:|:---|
| **紧张推进** | 短句为主，动作连贯 | 连续3句≤15字 | "这段能让读者喘气吗？" |
| **情绪爆发** | 感叹+短句+长句混用 | 爆发点≤100字 | "情绪顶点够不够高？" |
| **信息传递** | 说明+举例+对比 | 单次≤200字 | "这段能分拆到对话/动作中吗？" |
| **氛围营造** | 感官描写+意象叠加 | 独立段落≤150字 | "这段能删吗？不删能移吗？" |

### 短故事/狼人篇可借点：短篇节奏压缩

短篇（≤5万字）需将节奏压缩：
- 开篇：1章内完成"人设+世界观+入局"
- 冲突：前3章必须有核心冲突爆发
- 高潮：后1-2章连续高能
- 收束：≤1章，不拖泥带水

---

## 4.3 更新节奏管理

| 状态 | 触发条件 | 执行动作 |
|:---|:---|:---|
| **安全** | 存稿≥7天 | 正常日更3-4章 |
| **警戒** | 存稿3-6天 | 启动补存稿计划，降低日更至2章 |
| **危险** | 存稿＜3天 | 触发断更预警，停止加更，优先补存稿 |
| **已断更** | 已断更≥3天 | 复更前必须更新≥3章存稿，分段发布，避免再次断更 |

> **科武长篇可借点**：断更对科武文伤害更大（设定逻辑复杂，读者断档后难以接续），存稿底线建议提升至14天。

# 五、章末钩子设计手册

## 5.1 钩子类型分类

| 钩子类型 | 定义 | 科武语境示例 | 效果评级 |
|:---|:---|:---|:---:|
| **逻辑悬念** | 留下待验证的规则/设定问题 | "这台机甲明明没有能量了，为什么还能动？" | ★★★★★ |
| **未解变量** | 已有信息中的矛盾/漏洞 | "他记得那天是晴天，但目击者说是雨天" | ★★★★ |
| **伏笔验证** | 预告即将揭晓的伏笔 | "三年后，当他在废墟中看到那个符号时..." | ★★★★ |
| **情感钩子** | 关系/情感的重大转折预告 | "她不知道自己刚刚救的人，三天后会成为敌人" | ★★★ |
| **战力悬念** | 越级挑战/隐藏实力未展示 | "他收回拳头时，指尖还残留着蓝色的光" | ★★★ |

> **优先级**：逻辑悬念 > 未解变量 > 伏笔验证 > 情感钩子 > 战力悬念

### 科武长篇可借点：钩子必须与主线逻辑强绑定

```markdown
【错误钩子】
"他走进电梯，发现里面空无一人。"

问题：纯粹的惊悚悬念，与主线无关，难以形成长期钩子

【正确钩子】
"他走进电梯，调出能源分配面板——系统显示主舰能量储备为负12%，但三分钟前他亲眼看到能量核心还在正常运转。"

问题绑定主线：
- 涉及能源设定（科武核心系统）
- 暗示内鬼/泄漏（势力博弈线）
- 与之前"能量核心异常"伏笔呼应（伏笔验证线）
```

---

## 5.2 钩子设计三步法

```
① 回溯本章核心事件 → ② 提取其中的"未解问题"或"矛盾点" → ③ 放大而非解答
```

| 步骤 | 操作 | 示例 |
|:---|:---|:---|
| **①回溯** | 本章最重要的事件/决定是什么？ | 主角决定启动禁忌协议 |
| **②提取** | 这个事件中有什么未解释的/矛盾的信息？ | 禁忌协议明明需要三人授权，他一个人就启动了 |
| **③放大** | 将这个矛盾作为章末问题抛出 | "但他没注意到——系统日志里，多了一个他不认识的指纹" |

### 短故事/狼人篇可借点：短篇钩子要"即时兑现"

短篇无法承载长篇伏笔，钩子应在3章内解答：
- 第一章埋钩 → 第三章解答 + 新钩
- 或单章内"设问-解答"完成

# 六、读者预言管理指南

## 6.1 预言处理流程

```
评论区高频预测 → 逻辑自洽性评估 → [采纳/驳回/改造] → 回应方式确定
```

| 预测类型 | 处理策略 | 回应方式 |
|:---|:---|:---|
| **逻辑自洽型** | 采纳，转化为"猜中成就感" | 提前1-2章兑现，注明"读者猜对了" |
| **部分合理型** | 改造，保留合理部分，添加意外因素 | 在预测方向上加入反转变量 |
| **情绪宣泄型** | 过滤，不正面回应，但可转化为情节暗线 | 通过情节推进间接满足情绪需求 |
| **逻辑矛盾型** | 驳回，但不点破，保持悬念 | 在后续章节通过事件"自然否定" |

### 科武长篇可借点：科武读者预言的两大雷区

| 雷区 | 错误应对 | 正确应对 |
|:---|:---|:---|
| **技术细节预测** | "读者猜对了我的设定，所以改设定" | 技术预测需提前埋设"规则验证点"，让读者在正确方向上接近真相 |
| **战力预测** | "读者猜主角会赢，所以我让他输" | 战力结果必须服从设定，提前设计"变数"让结果可预测但不可确定 |

# 七、短故事/狼人篇可借点（汇总）

> 以下为适用于**短篇/狼人篇**的可执行规则，长篇可酌情参考

| 模块 | 可借点 | 执行动作 |
|:---|:---|:---|
| **开篇** | "3章内完成人设+入局" | 前3章必须出现核心动作+世界观初显+入局契机 |
| **人物口吻** | "三句定型法" | 用职业话术+价值观暴露+矛盾暴露快速立住角色 |
| **节奏** | "高潮-缓冲-高潮压缩版" | 1章铺垫，3章冲突，1章高潮+收束 |
| **钩子** | "即时兑现钩子" | 设问-解答在3章内完成，不留超长伏笔 |
| **冲突** | "价值观直接碰撞" | 主角与对手的理念冲突需在第2章就正面呈现 |
| **代价** | "单一代价链" | 短篇只需1条代价线，复杂代价链留给长篇 |
| **存稿** | "存稿≥2天即可" | 短篇篇幅短，断更影响相对可控，但仍需保持更新节奏 |

# 八、科武长篇可借点（汇总）

| **代价设计** | "多线代价追踪" | 寿命+理智+资源+关系多维度代价，在不同章节回响 |
| **动作链** | "四步法强制执行" | 每个场景必须包含决策→执行→反制→结果四步 |
| **节奏** | "波浪式推进" | 以卷为单位设计高潮-缓冲-过渡的循环 |
| **存稿** | "14天底线存稿" | 科武设定复杂，断更后读者难以接续，需更高存稿安全线 |

| **成长弧光** | "三轴同步成长" | 主角战力/心智/阵营立场需同步规划，形成清晰成长线 |
| **读者互动** | "评论区Top3监测" | 每日检查评论区，用逻辑自洽的预测强化粘性 |

# 九、平台规则→发布/包装/风险门禁

> 将编辑规则转化为**可直接执行的平台操作清单**

## 9.1 发布门禁（签约前后）

| 阶段 | 门禁条件 | 执行标准 | 风险后果 |
|:---|:---|:---|:---|
| **签约前** | 囤稿量 | ≥10万字存稿 | 存稿不足导致首秀断更，流量断崖 |
| **签约后** | 首次上传时效 | 48小时内上传全部存稿 | 错过首秀窗口期，算法降权 |
| **首秀期** | 更新频率 | 日更3-4章，持续7-14天 | 断更导致数据下跌，读者流失 |
| **日常** | 存稿安全线 | 始终保持≥7天（建议14天） | 突发事件导致断更 |

## 9.2 包装门禁（书名/简介/封面）

| 维度 | 门禁条件 | 执行标准 | 参考案例 |
|:---|:---|:---|:---|
| **书名** | 核心标签显性化 | 包含题材关键词+核心卖点 | 《通幽小儒仙》：通幽（小众设定）+小儒仙（身份+爽感） |
| **简介** | 三要素齐全 | 人设（谁）+冲突（遇什么）+看点（怎么爽） | 文科生穿越+以文入道+打脸爽文 |
| **封面** | 核心视觉符号 | 与主角核心能力/世界观强关联 | 笛子/机甲/剑修标志性形象 |
| **前3章** | 节奏示范 | 1章定调，2-3章入局，禁纯设定铺陈 | 红灯花船氛围→扶老人入局→儒道能力初显 |

## 9.3 风险门禁（创作红线）

| 风险类型 | 门禁条件 | 自检问题 | 风险后果 |
|:---|:---|:---|:---|
| **人设风险** | 主角行为可追溯至价值观 | "这个行为符合他的科武信条吗？" | 人设崩塌，口碑下滑 |
| **战力风险** | 任何胜利必须支付代价 | "他凭什么能赢？代价是什么？" | 战力通胀，设定崩盘 |
| **逻辑风险** | 物理/科技规则前后一致 | "能量守恒/材质强度/系统逻辑通顺吗？" | 设定矛盾，读者流失 |
| **更新风险** | 存稿充足+更新稳定 | "存稿够吗？能应对突发情况吗？" | 断更，流量断崖 |
| **平台风险** | 内容合规 | "这段是否涉及平台禁止内容？" | 屏蔽/下架 |

# 十、章节自检清单（完整版）

> **触发条件**：每章完成后发布前/每日写作结束前

## A. 基础结构检查（必做）

- [ ] **A1** 开篇3章内是否出现"主角核心动作+世界观初显+入局契机"？
- [ ] **A2** 本章是否有明确的章节目标（冲突/升级/揭示/过渡）？
- [ ] **A3** 本章结尾是否有钩子（逻辑悬念/未解变量/伏笔验证/情感钩子）？

## B. 人物与动机检查

- [ ] **B1** 主角关键行为是否可追溯至其底层价值观/科武信条？
- [ ] **B2** 主角是否有矛盾面（理性+感性）但核心动机不漂移？
- [ ] **B3** 主要NPC是否有明确的口吻特征（技术型/热血型/官僚型）？
- [ ] **B4** 主角与NPC的对话是否去水（保留实质，删除废话）？

## C. 动作与反馈检查（科武核心）

- [ ] **C1** 每个动作场景是否包含"决策→执行→反制→结果"四步？
- [ ] **C2** 是否所有技能/战斗场面都标注了物理反馈（能量/负荷/空间/声光）？
- [ ] **C3** 是否有明确的代价（寿命折损/理智污染/资源枯竭/人际关系断裂）？
- [ ] **C4** 代价是否在后续章节有回响钩子？

## D. 节奏与更新检查

- [ ] **D1** 日更是否满足3-4章基准线？
- [ ] **D2** 高潮章后是否预留了1-2章的收束/过渡段落？
- [ ] **D3** 存稿是否保持≥7天（建议14天）安全线？
- [ ] **D4** 本章属于哪种类型（高潮段/缓冲段/过渡段/信息段）？是否符合预期比例？

## E. 读者互动与预言检查

- [ ] **E1** 评论区Top3预测是否被逻辑性吸纳或明确驳回？
- [ ] **E2** 是否利用读者"预言心理"设计了可验证的伏笔？
- [ ] **E3** 是否有需要通过"作者说"管理读者预期的内容？

## F. 科武特定检查

- [ ] **F1** 战斗/升级场面是否标注了能量流向/神经负荷/装备损耗？
- [ ] **F2** 科技/武道融合点是否具备可视觉化的标志性场景？
- [ ] **F3** 是否存在物理/科技规则前后矛盾？
- [ ] **F4** 战力设定是否自洽（无代价胜利？越级挑战的代价是否明确）？

## G. 长篇结构检查（适用于每10章/每卷）

- [ ] **G1** 主角心智/战力/阵营立场是否有明确成长弧光？
- [ ] **G2** 主线逻辑线是否清晰（核心矛盾+阶段目标+最终目标）？
- [ ] **G3** 伏笔是否按计划铺设（短期伏笔3-5章/中期10-20章/长期贯穿全篇）？
- [ ] **G4** 是否存在战力/设定通胀风险？

## H. 发布前最后检查

- [ ] **H1** 内容是否涉及平台禁止内容？（低俗/政治/侵权等）
- [ ] **H2** 章节标题是否清晰传达本章核心内容？
- [ ] **H3** 章节内是否有明显错别字/病句/逻辑跳跃？
