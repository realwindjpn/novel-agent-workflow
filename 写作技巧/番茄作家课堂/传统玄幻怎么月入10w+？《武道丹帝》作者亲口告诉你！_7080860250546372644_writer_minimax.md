## ▌PATCH-01：作家OS核心执行指令

### 1.1 爽感交付协议（替代理论表述）

```
【执行命令】
触发事件 → 主角判断（≤2秒）→ 行动执行 → 结果交付 → 情绪释放
       ↑___________不许超过3章___________↑

✗ 主角被动挨打超过3章
✗ 反复纠结/内心戏替代行动

**【科武长篇可借】**：将“尊严/底线”转化为“人类文明存续/科技伦理/战友生死”。底线触发器可以是：AI觉醒禁令、基因编辑红线、星际殖民暴行、战友被生化改造。

**【短故事/狼人篇可借】**：单次冲突内完成“触犯→反击→碾压”闭环，控制在2000-3000字。底线可简化为“个人尊严/亲人被辱”。

### 1.2 冲突解决时间门禁

```
【门禁规则】
冲突爆发 → 解决窗口 ≤ 3章（长篇）/ ≤ 1章（短故事）
超时触发：读者爽感衰减 → 读完率下跌 → 流量池收缩

例外处理：
如需拉长冲突，必须在前1章末尾插入“主动升级事件”
（例：敌方援军到达/主角隐藏底牌曝光/第三方介入）
```

**【科武长篇】**：跨卷大反派可保留悬念，但单卷内小冲突必须闭环。主线悬念可跨卷，但每卷需有独立情绪收尾。

**【短故事】**：单次冲突完整闭环，章末钩子可留续集悬念但不可悬空。

### 1.3 主角人设执行锚点

```
【人设菜单·三选一强制锚定】

A型：杀伐果断+幽默轻松+单女主专情
   → 科武适配：冷峻天才+毒舌吐槽+基因伴侣羁绊
   
B型：守护文明+沉重使命+悲情英雄

C型：复仇驱动+快意恩仇+黑莲花
   → 科武适配：星际流亡者+赛博义体+暗网势力

禁止混合：选A不蹦B，选B不蹦A

**【科武长篇】**：主角行动逻辑必须与人设锚点一致。A型主角遇到威胁第一反应是吐槽+碾压，B型主角会先评估战略价值再行动。

**【短故事/狼人篇】**：可借用A型+B型组合，快速建立角色辨识度。

### 1.4 段落节奏执行标准

```
【章内节奏模板】

起（10%字数）：唤醒前情 + 本章任务明确

转（40%字数）：冲突爆发 + 行动执行 + 代价显现
合（20%字数）：爽点交付 + 章末钩子

【单章爽点密度要求】
长篇：每3章至少1个完整爽点循环
短故事：全程维持爽感，只在文末给1次情绪释放高潮
狼人篇：每2000字1个小爽点，结尾1个大爽点
```

**【科武长篇】**：科技/武道展示算爽点（首次接驳机甲、破解量子加密、基因觉醒），但需与主线冲突绑定，禁止纯炫技。

**【短故事】**：无需暗线铺垫，全程高能。

## ▌PATCH-03：章节自检清单

### 3.1 核心门禁检查（5项·一票否决制）

```
【门禁A】爽感闭环缺失
□ 本章是否完成“期待建立→冲突爆发→爽点交付”循环？
□ 否 → 本章不合格，返回重写

【门禁B】行动链断裂
□ 主角是否通过实际行动推进冲突？（非心理活动）
□ 物理反馈是否具体可感？（机体损伤/能量波动/环境破坏）
□ 否 → 补写行动+反馈

【门禁C】冲突超时
□ 本次冲突从爆发到解决是否≤3章（长篇）/ ≤1章（短故事）？
□ 超时且无主动升级事件 → 强制收尾或插入升级事件

【门禁D】战力/科技体系崩坏
□ 本章战力表现是否与已知设定自洽？
□ 新技术/能力是否有前期铺垫？
□ 否 → 回溯伏笔或修改本章战力表现

【门禁E】情绪锚点偏移
□ 本章热血基调是否≥70%？
□ 轻松吐槽是否≤20%？
□ 全程苦大仇深？→ 本章不合格
□ 全程玩梗无实质爽点？→ 本章不合格
```

## ▌PATCH-06：失败模式数据库

```
【高频失败模式·预警清单】

【F-01】节奏失控型
触发：灵感驱动写作，无大纲约束
症状：前10章节奏正常，20章后战力崩塌，30章逻辑断裂
解法：停更3天补大纲，细纲排到至少30章节点

【F-02】爽感稀释型
触发：主角被动压抑超3章
症状：读者评论区“憋屈”“想弃书”刷屏
解法：下一章强制反击+碾压，代价延后处理（3-5章）

【F-03】设定过载型
触发：开篇大量世界观输出
症状：读者“看不进去”“太复杂”反馈
解法：设定随剧情释放，每章最多2个新概念

【F-04】战力通胀型
触发：爽点无代价/主角无敌化
症状：读者“无聊”“没悬念”
解法：爽点必须带代价，后续3-5章产生连锁影响

【F-05】情绪失衡型
触发：全程苦大仇深/全程轻松玩梗
症状：读完率下跌/读者粘性降低
解法：按70%热血+20%吐槽+10%虐心配比重写

【F-06】钩子失效型
触发：章末钩子模糊/与主线弱关联
症状：读者“没什么想追的”反馈
解法：钩子具体化（倒计时/未解危机/身份悬念），绑定主角核心目标

【F-07】存稿耗尽型
触发：日更不稳定/存稿低于安全线
症状：断更→流量池收缩→推荐降级→恶性循环
解法：红色预警时停更全力存稿，恢复3万字后再开更

【F-08】人设崩转型
触发：主角行为与人设锚点不一致
症状：读者“主角精分”“不知道他想干嘛”
解法：回溯人设锚点，重写冲突场景确保行为逻辑一致

【F-09】科技逻辑断裂型（科武专有）
触发：唯心升级/无解释的战力碾压
症状：硬核读者弃书，评论区质疑声
解法：补充科技合理化手段（战术AI/降维武器/群体压制）

【F-10】感情线喧宾夺主型
触发：恋爱戏占比超30%
症状：主线拖慢，男频读者流失
解法：感情戏压缩至10%，随主线推进而非独立支线
```
