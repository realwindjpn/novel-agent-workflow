## 一、写作前任务卡字段更新

### 【新增必填字段】

| 字段名 | 定义 | 示例 |
|:---|:---|:---|
| **核心关系张力** | 两个以上角色的目标/利益/情感冲突，必须在前3章内具象化 | 竹马/死对头/天降/师徒/竞争者 |
| **短期目标钩子** | 主角本阶段最具体的行动目标，可量化/可感知失败 | "赢得机甲联赛首轮""查清导师失踪真相" |
| **能量体系边界** | 主角当前能力上限的明确限制条件 | 神经接入延迟0.3秒/外骨骼续航2分钟/内功每战耗三年寿元 |
| **核心代价** | 本卷主线推进时主角必须支付的代价类型 | 生理损伤/资源枯竭/人际关系破裂/道德困境 |
| **视觉化名场面** | 本卷必须呈现的"影视级"场景描述，需含动作/空间/情绪三要素 | 机甲在城市废墟中首次启动/武道突破时身体异变 |
| **读者预期承诺** | 本卷/本阶段向读者明确交代的交付物 | 每10章兑现小预期，每30章兑现大预期 |

## 二、作家执行模块

### 模块A：动作链（战斗/突破/危机场景）

```
执行协议：
1. 起势 → 2. 发力 → 3. 受击 → 4. 变招 → 5. 决胜
```

| 步骤 | 执行要求 | 禁用 |
|:---|:---|:---|
| **起势** | 交代物理准备动作+能量/装备状态+空间站位 | "摆出起手式"等抽象描述 |
| **发力** | 明确能量类型/强度/轨迹，主角意图外显 | "全力一击"等模糊表达 |
| **受击** | 敌方反制/环境反噬/自身局限显现，需有物理代价 | "完美闪避"等规避代价写法 |
| **变招** | 基于受击反馈调整战术，体现科武体系逻辑 | 无脑开挂/金手指触发 |
| **决胜** | 代价已支付/战术已兑现，胜负有因果链 | 机械降神/主角光环 |

### 模块B：物理反馈（科武设定可信度）

```
执行公式：超常能力 → 可感知物理代价 → 环境交互
```

| 能力类型 | 必须附带的物理反馈 |
|:---|:---|
| 外骨骼/机械战甲 | 肌肉撕裂/关节过热/重心偏移/噪音暴露 |
| 武道内功/精神力 | 气血紊乱/神经灼烧/感知过载/力竭僵直 |
| 高武科技/能量武器 | 热辐射灼伤/后坐力破坏掩体/能量涟漪误伤友军 |
| 空间/时间异能 | 时空压迫内脏/记忆混乱/存在感稀释 |

**核心原则：拒绝"无损耗施法"**

### 模块C：代价系统（剧情张力来源）

```
代价必须三要素：可量化 + 推动后续 + 非一次性消耗
```

| 代价类型 | 执行标准 |
|:---|:---|
| **生理代价** | 需有累积性（可叠加/可恶化），影响后续战斗/判断力 |
| **资源代价** | 稀缺资源需有明确消耗速度，禁用"无限补充" |
| **人际关系代价** | 关键抉择必须牺牲/疏远至少一个重要关系人 |
| **道德困境代价** | 两难选择需有短期利益与长期代价的冲突，无完美选项 |

### 模块D：失败模式（人物弧光触发）

```
失败触发器：目标受阻 → 能力局限暴露 → 核心矛盾深化 → 抉择代价
```

| 失败场景 | 执行要点 |
|:---|:---|
| 战术失败 | 体现科武体系的战术博弈，而非"实力碾压" |
| 心理失败 | 内因导致判断失误，需与人物核心驱动力冲突 |
| 关系失败 | 因果链可追溯，非"误会虐"或"工具人背叛" |
| 道德失败 | 有代价才有分量，不可逆的道德污点优于轻易和解 |

### 模块E：人物口吻（角色识别度）

```
口吻四要素：语气/词汇偏好/行为逻辑/核心恐惧
```

| 角色类型 | 口吻特征示例 |
|:---|:---|
| **热血型主角** | 短句/动词优先/用行动代替解释/对嘲讽反应激烈 |
| **克制型主角** | 长句/留白/情绪延迟释放/用沉默替代爆发 |
| **反转型角色** | 表里不一/幽默化解紧张/真实想法需读者自行解读 |
| **导师型角色** | 引导式提问/隐喻/留任务不留答案 |
| **对手型角色** | 挑衅式/利用信息差/立场鲜明不脸谱化 |

**核心原则：拒绝"标签化台词"，同一角色在不同情绪状态下口吻应有层次变化**

### 模块F：段落节奏（张弛控制）

```
节奏公式：高潮段落（3:7中的"3"）+ 日常段落（3:7中的"7"）
```

| 段落类型 | 执行标准 |
|:---|:---|
| **高潮段落** | 情绪密度拉满/句式短促/动词密集/物理反馈细节/禁用旁白解释 |
| **日常段落** | 逻辑铺垫/感情发酵/信息密度降低/可插入角色互动/为高潮蓄力 |
| **转折段落** | 情绪反噬/沉默/独处反思/为下一轮高潮蓄势 |

**张弛比3:7含义：每1000字高潮段落占300字，日常/过渡占700字**

### 模块G：章末钩子（追读引擎）

```
钩子三要素（满足其一）：信息差 + 生存危机 + 选择困境
```

| 钩子类型 | 执行要点 |
|:---|:---|
| **信息差钩子** | 读者知道的信息与主角/对手形成不对称，引出揭秘/反转 |
| **生存危机钩子** | 威胁升级/时间窗口收窄/资源枯竭/援军失联 |
| **选择困境钩子** | 两难抉择浮现/价值观冲突具象化/无完美选项 |

**禁用：无关日常/情绪抒情/纯悬念设问收尾**

## 三、章节自检清单

### 【开篇前3章必检】

| 序号 | 检查项 | 通过标准 |
|:---|:---|:---|
| 1 | 核心人物关系是否具象化？ | 至少两个角色存在明确的利益/情感/目标冲突，且在前3章内通过具体场景展现 |
| 2 | 短期目标是否明确？ | 主角有可量化的本阶段行动目标，读者能感知"他想做什么" |
| 3 | 是否有纯设定堆砌？ | 前3章禁止超过200字的设定说明/世界观旁白，必须通过动作/冲突/交互带出 |
| 4 | 主角驱动力是否成立？ | 主角行动有可理解的内因（非"系统任务"等外部强迫），且该内因与核心目标绑定 |
| 5 | 平台调性匹配？ | 番茄生态重"情绪直给+追读留存"，开篇钩子需明确，禁用"慢热铺垫"借口 |

### 【单章自检】

| 序号 | 检查项 | 通过标准 |
|:---|:---|:---|
| 1 | 本章核心事件是否推进主线/感情线之一？ | 无推进则删减/合并至前章 |
| 2 | 高潮段落是否具备情绪密度？ | 句式短促/动词密集/物理反馈细节/禁用旁白解释 |
| 3 | 日常段落是否承担逻辑铺垫或感情发酵功能？ | 纯水日常禁止，单章无功能段落不超过100字 |
| 4 | 章末钩子是否满足三要素之一？ | 信息差/生存危机/选择困境，与主线目标强绑定 |
| 5 | 是否有"机械降神"或"为虐而虐"？ | 关键转折必须有因果链，禁用作者强行干预 |
| 6 | 配角是否工具人化？ | 配角需有独立行为逻辑，不服务于主角剧情时应有独立弧光 |
| 7 | 文风是否统一？ | 同一角色口吻有连贯性，作者不强行扭转基调 |

### 【每10万字收束检查】

| 序号 | 检查项 | 通过标准 |
|:---|:---|:---|
| 1 | 主线目标是否完成/升级/重构？ | 需有可感知的进展，不可原地踏步 |
| 2 | 能量体系边界是否清晰？ | 主角当前能力上限已明确，禁用"实力突增"无铺垫 |
| 3 | 核心代价是否已支付并影响后续？ | 代价有累积性，不可一次性消耗后清零 |
| 4 | 是否有至少一个"视觉化名场面"？ | 方便版权评估的强场景描述，含动作/空间/情绪 |
| 5 | 读者预期是否已兑现？ | 每10章兑现小预期，每30章兑现大预期 |
| 6 | 资料引用是否逻辑自洽？ | 禁用"伪科学/反常识"硬伤，核心设定需交叉验证 |
