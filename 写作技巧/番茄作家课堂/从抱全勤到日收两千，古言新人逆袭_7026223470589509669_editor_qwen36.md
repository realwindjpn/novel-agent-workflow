# 《科武纪元》编辑学习官：番茄课堂《古言新人逆袭》规则提炼

## 1 课程核心判断（≤6条）
1. **数据屏蔽机制**：新人冷启动期（首月/前10万字）后台数据无参考价值，需强制隔离数据焦虑，专注完本与节奏打磨。
2. **卡文破局路径**：“硬写→复盘→删改”是唯一有效解法。停笔找灵感易导致断更，持续输出才能暴露结构问题并修正。
3. **读者反馈定位**：读者是剧情“镜子”，非“指挥棒”。批量集中吐槽需触发评估，但需过滤情绪宣泄，保留逻辑修正价值。
4. **产能纪律底线**：日更6k-7k是商业连载触发推荐池的基础门槛，需以时间块管理替代碎片化创作。
5. **收入曲线规律**：首月极低（1.97元）至次月跃升（5000+）符合平台算法冷启动与字数积累效应，非玄学，属可复现的流量爬坡模型。
6. **剧情容错原则**：核心人物命运（如致残/死亡）若引发大规模读者抵触，需快速响应调整，避免毒点发酵导致追读断崖。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则提取（基于原文） |
|:---|:---|
| **开篇** | 允许生涩试错，首章不追求完美；以“写完即复盘”替代“等灵感”，保持更新不断是开篇存活前提。 |
| **节奏** | 日更6k-7k为基准线，用持续输出倒逼节奏感；卡文时执行“先写完本段→标疑点→次日删改”，禁止停笔超24小时。 |
| **冲突** | 人物重大命运转折需预设读者情绪阈值；评论区≥30%集中吐槽同一剧情点时，启动“剧情熔断-评估-修正”流程。 |
| **人物** | 核心人物不可为制造冲突随意牺牲；读者反馈需区分“情绪不适”与“逻辑硬伤”，仅对后者进行结构性修补。 |
| **题材** | 情绪驱动型题材（古言/现言）依赖快速试错与读者共鸣，底层方法论可平移至科幻/悬疑等强设定题材。 |
| **改编** | 连载期需保留“弹性修改接口”，关键设定/人物线预留逻辑补丁空间，降低后期IP开发时的重构成本。 |
| **平台规则** | 番茄算法依赖字数积累与完读率；首月低收属正常冷启动，需扛过10万/30万字推荐节点，次月数据跃升符合流量分发逻辑。 |

## 3 科武适配（《科武纪元》长篇科幻）
### ✅ 可用点
- **硬写破卡文**：科幻设定/科武体系极易陷入“设定自洽”死循环，需先完成情节推进，再回头用“删改”修补逻辑漏洞。
- **读者反馈修正**：硬核科武设定若引发大规模阅读障碍（如术语堆砌、战力崩坏），需快速软化或增加“认知锚点”，避免追读流失。
- **产能纪律**：长篇科幻需稳定更新维持世界观沉浸感，日更6k+是维持推荐池权重的硬性指标。
- **屏蔽早期数据**：科幻受众垂直，起量周期长于古言，前20万字不看后台是必要策略。

### ❌ 不可硬套点
- **“截肢接腿”式情绪化修改**：古言可因读者情绪快速调整人物命运，但科幻科武必须遵循物理/科技底层逻辑，不可为迎合情绪推翻已建立的设定体系。
- **“追文影响创作”论断**：科幻创作需大量查阅文献/同类作品，追更同类科幻是必要输入而非干扰，需建立“资料输入-设定输出”的固定时间块。
- **古言收入曲线直接套用**：科幻冷启动期更长，次月5000+属古言情绪爆款特征，科幻需以“完读率/加入书架率”为核心指标，而非短期日收。

## 4 编辑检查表（≤10条）
1. 是否已设定“数据屏蔽期”（如前15万字不看后台/追读）？
2. 卡文时是否执行“先写完本段→标疑点→次日集中删改”流程？
3. 核心人物重大转折前，是否做过读者接受度预演或逻辑自洽推演？
4. 评论区是否出现≥30%集中吐槽同一剧情点？是则启动“剧情评估-修正”流程。
5. 日更字数是否稳定在6k+？断更是否超过24小时？
6. 科武体系/科技设定是否因追求爽感而牺牲基础物理/逻辑规则？
7. 是否保留“废稿库”用于复盘节奏断点与删改痕迹？
8. 追读/完读率数据是否在30万/50万字节点出现拐点？
9. 作者是否已建立“资料输入-设定输出”的固定时间块（非碎片化）？
10. 剧情修改是否附带“逻辑补丁”而非单纯迎合情绪？

## 5 对作家角色的输入要求（《科武纪元》专项）
| 维度 | 编辑强制输入标准 |
|:---|:---|
| **动作链** | 科武战斗/科技操作必须呈现完整步骤序列（例：神经接驳→能量充能→武器展开→反冲规避→冷却重置），禁止跨步骤跳跃或模糊处理。 |
| **物理反馈** | 每次科武交互必须绑定可量化的环境/机体/感官反馈（例：装甲过热警报阈值、骨骼负荷痛觉等级、能量溢出灼烧空气的视觉/嗅觉描写）。 |
| **代价** | 任何能力跃升/科技突破必须绑定明确代价（例：神经突触损伤、稀有同位素枯竭、阵营道德妥协、系统延迟反噬），禁止无代价开挂或机械降神。 |
| **钩子** | 每章结尾必须埋设“未解变量”驱动点击（例：异常能量读数、敌对频段截获、系统底层报错、角色生理指标反常），禁止以纯情绪收尾替代悬念。 |
| **读者预期** | 开篇3章内明确“科武”核心规则与主角初始目标；每10章兑现一次小预期（战力/科技/情报），每30章兑现一次大预期（体系升级/阵营反转），预期偏差率需控制在±15%以内。 |
