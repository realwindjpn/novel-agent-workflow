# 《科武纪元》编辑学习官｜番茄课堂《写作避雷》提炼报告

## 1 课程核心判断（≤6条）
1. **开篇定生死**：黄金三章必须完成“核心危机抛出→破局手段亮出→短期目标锚定”闭环，背景堆砌与日常流水直接劝退。
2. **设定即剧情**：世界观不靠说明文，必须通过场景细节、人物对话、战斗演示分层释放，只亮当前剧情必需规则。
3. **逻辑即人设**：角色行为必须服从预设档案，情节转折需前置铺垫，杜绝“为爽而爽”的机械降神与OOC。
4. **视角即焦点**：单场景主视角唯一，发言/心理活动聚焦核心推动者（≤3人），新手默认顺叙，禁用频繁跳切。
5. **主线即骨架**：所有支线/日常必须服务核心目标，冲突需递进叠加，爽点爆发必须遵循“压抑-铺垫-释放”完整链条。
6. **排版即体验**：移动端强制分段（3-5行/段），描写必须服务剧情/人物推进，剔除无效修饰与冗长环境。

## 2 可执行编辑规则
| 维度 | 执行标准（基于原文提炼） |
|:---|:---|
| **开篇** | 第1章切入变故/危机；第2章激活金手指/核心优势；第3章确立首个可量化短期目标。信息植入遵循“行动中交代基础，节点处揭示关键”。 |
| **节奏** | 采用“冲突-解决-新阻碍”波浪推进。关键节点前必设意外（如通道封锁、强敌拦截、规则突变）。过渡章用人物行动/心理/道具自然衔接，禁止场景硬切。 |
| **冲突** | 拒绝无阻碍顺境。冲突设计需“多重矛盾叠加”，爽点前必须有≥2处递进铺垫。打脸/逆袭以主角为绝对触发核心，禁止主角旁观他人冲突。 |
| **人物** | 建立人设档案（性格/目标/优缺点/底线）。配角（含反派/盟友）必须赋予独立动机（利益/理念/恩情/阵营），禁用纯工具人。行为决策需与档案强绑定。 |
| **题材/改编** | **长篇科幻**：优先聚焦核心规则，细节随探索解锁。**短故事/热点稿**：提取核心情绪/矛盾，压缩背景至100字内，直接切入“目标-阻碍-破局”单线结构，24小时内完成情绪释放闭环。 |
| **平台规则** | 移动端排版强制分段（3-5行/段）。标点控制呼吸感。描写字数占比≤20%，优先保证剧情推进速度。新手默认顺叙，熟练后再试非线性叙事。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接落地）
- **体系分层释放**：科武设定（基因锁/机甲参数/武道境界）开篇只亮主角当前能接触的基础规则，高阶设定随升级/副本逐步解锁。
- **金手指具象化**：系统/异能/古武传承必须在第2章危机中激活，并附带明确限制/冷却/能耗，避免战力崩坏。
- **冲突双核驱动**：将“科技逻辑/战术博弈”与“武道意志/肉身突破”结合，爽点需体现“科学验证+热血反杀”的双重满足。
- **设定场景化**：用“战斗演示/实验数据/战场简报/机甲自检日志”替代大段说明文，保持快节奏与信息密度。

### ⛔ 不可硬套点（需规避）
- **模板化危机套用**：科武题材需兼顾科幻严谨性与武道成长线。若强行塞入“穿书追杀/打脸渣男”等都市模板，会破坏世界观沉浸感。需替换为科武语境危机（如：星舰坠毁、基因反噬、武道考核生死局、AI叛变）。
- **爽点牺牲逻辑**：科幻逻辑要求因果严密，不能为追求快节奏而违背物理/能量守恒（如：无视冷却的越级反杀）。爽点必须建立在“规则利用/战术博弈/武道突破”之上。
- **配角动机扁平化**：科武世界观下的势力博弈复杂，反派不能仅用“救亲人”单一动机打发，需结合“资源争夺/理念冲突/阵营立场/技术路线分歧”构建多维动机。

## 4 编辑检查表（10条以内）
- [ ] 开篇3000字内是否已抛出核心危机并亮出破局手段？
- [ ] 世界观设定是否全部融入场景/对话/战斗演示？有无连续3段以上纯说明文字？
- [ ] 主角本章行为是否符合人设档案？有无OOC或逻辑断裂？
- [ ] 单场景主视角是否唯一？发言/心理活动是否聚焦≤3个核心角色？
- [ ] 本章是否推进了主线目标？支线/日常是否占比≤30%？
- [ ] 冲突爆发前是否有≥2处铺垫？爽点是否以主角为绝对触发核心？
- [ ] 配角（含反派）是否有独立动机与行为逻辑？是否沦为纯工具人？
- [ ] 段落长度是否控制在手机屏3-5行？有无大段环境/外貌无效描写？
- [ ] 场景转换是否有行动/心理/道具过渡？有无硬切或时空跳跃？
- [ ] 金手指/能力使用是否附带明确代价/限制？战力体系是否自洽？

## 5 对作家角色的输入要求
| 要素 | 编辑验收标准（硬性要求） |
|:---|:---|
| **动作链** | 必须呈现“意图→蓄力/发力→轨迹/接触→结果/收势”完整闭环。禁止“意念一动/瞬间完成”的模糊描写。科武场景需符合人体工学/机甲操作逻辑，动作需分步拆解（例：蹬地蓄力→关节锁死→刃口切入→反作用力卸力）。 |
| **物理反馈** | 每次交互必有环境/肉体/装备的实时反馈。如：重击后的骨骼闷响、能量过载的警报红光、护甲碎裂的应力纹路、肌肉撕裂的乳酸堆积感。反馈需量化或具象化，杜绝“毫发无损/轻松化解”的失真描写。 |
| **代价** | 所有能力使用/越级战斗必须支付明确代价。如：基因负荷导致神经灼痛、机甲冷却期暴露破绽、武道透支引发经脉暗伤、算力超载烧毁神经接口。代价需影响后续3-5章的行动选择，禁止“用完即恢复”。 |
| **钩子** | 章末/卷末必须设置“未解悬念/迫近危机/目标反转”。钩子需与主线强绑定，禁止无关日常收尾。标准结构：`[危机逼近] + [主角受限] + [未知变量介入]`。 |
| **读者预期** | 严格管理“承诺-兑现”周期。开篇抛出的设定/伏笔必须在约定篇幅内回收；爽点爆发需符合前期铺垫的情绪曲线。禁止“机械降神”或“临时改设定”破坏预期。每章提交前需自问：“读者此刻最想看什么？我是否给出了符合逻辑的回应？” |
