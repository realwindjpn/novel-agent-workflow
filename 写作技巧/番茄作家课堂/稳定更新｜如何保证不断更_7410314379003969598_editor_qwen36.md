# 《科武纪元》编辑学习报告：基于《稳定更新｜如何保证不断更》的规则提炼

## 1 课程核心判断（≤6条）
1. **更新稳定性取决于开书基建，而非写作期硬扛**：大纲、人物关系表、设定资料库是防崩盘/防断更的底层设施。
2. **开篇必须“冲突前置、信息后置”**：拒绝设定堆砌，背景与身份需通过剧情动作自然释放。
3. **节奏由“结与解”闭环驱动**：前期抛问题（结），中期多反转推进（解），结尾必须“翘起”留悬念。
4. **毒点规避是留存底线**：成长过快、报应过慢、人设OOC、单线过长、地图乱换必触发读者流失。
5. **平台算法偏好高频情绪兑现**：爽点/爆点需明确、及时，打脸/破局周期不可拖延。
6. **日更纪律依赖工具强制与标准化流程**：4000字/日为基准线，需通过码字软件/拼字机制/存稿池实现，不依赖灵感。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 编辑执行规则 |
|:---|:---|
| **开篇** | 首章3000字内必须切入具体矛盾/危机；禁用大段世界观说明；采用“破题五分法”（破题→开头→发展→高潮→结尾）压缩信息密度，用动作带设定。 |
| **节奏** | 采用“目标-障碍-行动-意外-结果”五分法拆解卷纲；单剧情线≤3万字强制收束；严格执行“结（悬念/危机）→解（反转/破局）”循环，解的过程需含≥1次逻辑反转。 |
| **冲突** | 矛盾需具象化（资源争夺/规则冲突/生存危机）；反派动机必须自洽且具备持续压迫感；冲突升级需伴随可见代价，禁用“为虐而虐”或“降智反派”。 |
| **人物** | 强制建立动态人物关系表（姓名/定位/核心诉求/与主角关系/退场节点）；主角成长需有明确阶梯；配角/群像拒绝工具人化，关键角色需有独立行为逻辑。 |
| **题材** | 融合平台近期爆款标签，但需做“旧梗新解”；科幻/武斗题材必须建立自洽底层规则（科技树/武道体系/社会结构）；微架空优于纯虚构，设定需“实”可推敲。 |
| **改编** | 影视/短剧向改编需前置“强视觉冲突+明确单集目标”；长篇需预留“地图切换”的过渡章（≤2章），避免频繁换图导致读者断层。 |
| **平台规则** | 适配番茄推荐算法：前3章留存率决定初始流量池；章节末尾必留钩子（断章在危机爆发前或反转瞬间）；日更4000字为基准，断更＞24小时触发降权；热点元素需标签化前置。 |

## 3 科武适配
### ✅ 可用点
- **大纲结构**：“目标-障碍-行动-意外-结果”完美契合科幻探索/武道升级主线，可直接映射为“技术攻关/秘境探索/势力博弈”单元。
- **结与解机制**：适用于科技瓶颈突破、武道境界跨越、异星规则破解的周期性叙事，保证长篇不疲软。
- **人物关系表**：对《科武纪元》多势力（舰队/宗门/财阀/AI阵营）群像管理至关重要，防OOC与吃书。
- **资料基建**：硬科幻需建立物理法则/能量守恒/科技演进树，课程“查资料建世界观”原则可直接转化为《科武设定集》。
- **冲突前置**：可转化为“技术故障/异星遭遇/规则反噬”开局，快速建立硬核危机感。

### ❌ 不可硬套点
- **“打脸要及时/不能忍太久”**：科幻/武斗的硬核破局需技术铺垫与逻辑推演，为爽感牺牲科学/武道逻辑会导致设定崩塌。需改为“逻辑闭环内的及时兑现”。
- **“女频/宫斗案例的情感PUA/恋爱脑”**：不适用《科武纪元》的硬核/群像/理性决策基调，需剔除情感主导的降智桥段。
- **“日更4000字纯靠手速”**：长篇科幻需严密推演，盲目追量易导致设定前后矛盾。需改为“模块化写作+7天存稿缓冲+设定校验流程”。
- **“热点元素盲目融合”**：科幻热点迭代慢，追热梗易破坏世界观统一性。热点需做“科幻化转译”（如将“逃荒”转为“星舰跃迁能源危机”）。

## 4 编辑检查表（10条以内）
1. [ ] 开篇前3000字是否以具体冲突/危机切入？（否→重写）
2. [ ] 是否附带完整人物关系表与核心设定集？（否→暂停更新）
3. [ ] 单卷是否严格遵循“目标-障碍-行动-意外-结果”结构？（否→调整大纲）
4. [ ] 是否存在“设定堆砌”替代“剧情推进”的段落？（是→删改/转化为动作）
5. [ ] 爽点/破局兑现周期是否≤3章？（是→压缩铺垫，加快节奏）
6. [ ] 反派/障碍动机是否自洽且具备持续压迫感？（否→强化逻辑链）
7. [ ] 章节末尾是否设置有效钩子（悬念/危机/反转）？（否→修改断章点）
8. [ ] 是否触碰五大重毒点（弱智/圣母/总被虐/反三观/拆CP）？（是→紧急修正）
9. [ ] 世界观规则（科技/武道）在已发布章节中是否前后一致？（否→建立设定补丁）
10. [ ] 存稿量是否≥7天更新量？（否→启动存稿/降速）

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 明确“触发条件→决策→执行动作→环境反馈→结果”。禁用模糊形容词（如“他很强/很快”），必须拆解为可观测的战术/技术动作序列（例：`能量过载→切断主回路→手动重启冷却阀→机甲右臂液压管爆裂→战术翻滚规避`）。 |
| **物理反馈** | 所有超常规能力（机甲/武道/异能/跃迁）必须伴随符合设定的物理/能量反馈（过载发热、肌肉撕裂、重力失衡、能量衰减、神经负荷）。拒绝无代价释放，反馈需可量化或可感知。 |
| **代价** | 每次破局/升级必须支付明确代价（资源消耗、身体损伤、时间窗口压缩、道德妥协、势力反噬）。代价需在前文埋线，后文兑现，禁止“机械降神”或“零成本通关”。 |
| **钩子** | 每章结尾必须抛出“未闭合信息”（技术异常、敌踪逼近、规则漏洞、信任危机）。断章点卡在“动作执行中”或“真相揭露前”，禁止在安全区/日常区收尾。 |
| **读者预期** | 开篇3章内明确“核心目标+底层规则+短期危机”。后续更新需严格对齐预期：承诺的科技树/武道体系必须按逻辑展开；爽点兑现需符合“铺垫-压抑-爆发-余波”曲线；禁用设定吃书或临时加挂。 |
