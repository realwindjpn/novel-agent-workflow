# 《科武纪元》编辑学习笔记 · 第十六期：宫斗宅斗

> 来源：番茄作家课堂 · 品类指南 · 2026-04-11
> 学习目的：抽离"女性生存博弈"叙事方法论，迁移到科武长篇 / 短故事 / 热点稿的编辑标准。

---

## 1. 课程核心判断（6条）

1. 宫斗宅斗的本质是**封闭空间内的资源博弈**（争宠、争权、争嗣、争管家权），不是谈恋爱也不是考据，是"生存+逆袭打脸"。
2. 爽点必须**差异化分流**：高位类卖"碾压感"，底层类卖"逆袭感"，两类不能混炖。
3. 爽点**密度刚性**：高位压制类爽点间隔不超过 300 字，超过即流失。
4. 人设走**标签 + 反差**双轨：先有一句可标签化的辨识度，再用一处反差立体化。
5. 外挂（系统/重生/穿书/弹幕）的作用是**降低权谋门槛**，不是炫设定；规则越少越好，能省则省。
6. 情感线是**辅助变量**：弱化恋爱脑、去霸总、男主助攻；女性互助线是新增长点。

## 2. 可执行编辑规则

### 开篇（导语）
- **三件套必出**：身份/处境定位 + 一次具体冒犯事件 + 女主的反常反应（笑、不闹、反向操作）。
- 重生文导语固定公式：**前世关键遗憾 + 复仇对象 + 复仇目标**，三句话内交付。
- 第一人称"我"主导，开篇 200 字内必须出现立场反转或目标宣告（例："我要的，从来不是萧齐安这个人"）。
- 禁止开篇做世界观铺陈、家族谱系、礼制讲解。

### 节奏
- 高位压制类：**≤300 字一个爽点**，且优先用"权力差/阶级差/礼法"直接压人，不要迂回试探。
- 底层逆袭类：可拉长智斗回合，但每回合必须有"将计就计/借刀杀人"的可视化收益。
- 设定解释**不超过两句**，靠剧情消化规则，不靠旁白。

### 冲突
- 冲突源锁死在**封闭场域的资源争夺**：宫斗=宠/位/嗣/前朝；宅斗=管家权/嫡庶/家产/外室。
- 反派必须有**明确诉求**（要情/要子/要名分），女主诉求与其**正交错位**（要权/要自由/要家族），才能形成"我赢即你输"的死锁。
- 单场冲突要给出**可量化的输赢标的**（一个位份、一张地契、一次圣旨）。

### 人物
- 女主一句话标签必填：清醒独美 / 黑莲花 / 扮猪吃虎 / 摆烂大女主 等。
- 反差点强制一处：高冷掌权者偏爱甜食 / 底层复仇者性格温柔。
- 男主功能定位为**助攻+尊重**，禁止"控制型霸总"、禁止男主推动主线。
- 女配可做**互助盟友**（嫡庶联手、姐妹情），优先于恋爱戏码。

### 题材
- 四大主类型：高位打脸 / 底层逆袭 / 复仇重生 / 脑洞。立项时必须明确归属一类，不要骑墙。
- 元素工具箱：重生、穿书、系统、弹幕、玄学、双穿、倒计时——选 1，最多 2，叠加易乱。
- 主题热点：绿茶/白月光/替身、姐妹情、换嫁、男二上位。

### 改编（迁移到非古代题材）
- 保留"封闭场域 + 资源博弈 + 信息差爽感"骨架，替换皮肤即可。
- 重生/穿书的本质是**信息差金手指**，可平替为"预知/数据库/复盘系统"。

### 平台规则
- 短故事导语承担转化率，按上述开篇三件套写。
- 爽点密度服从读者及时反馈，**字数密度优于文笔密度**。
- 考据是加分项不是门槛，**逻辑自洽 > 史实正确**。

## 3. 科武适配

### 可用点（直接迁移）
| 课堂规则 | 在《科武纪元》的落地 |
|---|---|
| 封闭场域博弈 | 把"后宫/后宅"替换为**门派内院、舰队指挥层、研究所、家族企业的科武世家** |
| 高位压制爽点 ≤300 字 | 科武高阶角色出手时，用**功法等阶差 / 科技代差**做"礼法式碾压"，省略试探 |
| 重生/穿书 = 信息差 | 平替为**轮回功法、记忆芯片、时间线回溯、模拟器推演** |
| 标签+反差人设 | "冷面科武长老爱喝奶茶""底层修士擅长黑客"——直接套用 |
| 女性互助线 | 设置**女科学家+女武修**或嫡庶式师姐妹组合，避开常见兄弟羁绊套路 |
| 反派与女主诉求正交 | 反派要"功法垄断"，女主要"技术开源"，形成结构性死锁 |
| 导语三件套 | 科武世家庶女/边缘弟子开局被冒犯，反向操作宣告目标 |

### 不可硬套点
- **300 字爽点间隔**不能整本套用：长篇科幻有世界观建构成本，应用于"宅斗式支线/单元卷"，主线节奏由科技-武道升级曲线决定。
- **第一人称导语**适合短故事/番外，长篇主线建议第三人称多 POV。
- **去恋爱脑**原则保留，但科武长篇需要**双强/同盟型情感线**作为权力结构的一部分，不能完全清空。
- **嫡庶礼仪类细节**直接照搬会出戏，必须翻译为科武体系的**门规、师承、血脉等阶**等可信细节。
- **金手指降门槛**在长篇中要克制：短故事可用系统直接给答案，长篇科幻必须给出**机制解释**，否则毁世界观。
- 宫斗的"封闭性"在科幻中容易被打破（星际尺度），需要**人为收口**（封锁的飞船、孤立站点、议会密室）才能复用其张力。

## 4. 编辑检查表（10条）

1. □ 开篇 200 字内是否出现冒犯事件 + 女主反常反应 + 目标宣告？
2. □ 本作类型归属（高位/底层/重生/脑洞）是否唯一明确？
3. □ 女主是否有一句话可复述的人设标签 + 至少一处反差？
4. □ 爽点类型是否与类型匹配（高位=碾压，底层=智斗）？
5. □ 高位压制段落爽点间隔是否 ≤300 字？
6. □ 反派诉求与女主诉求是否结构性正交，存在明确输赢标的？
7. □ 设定/金手指解释是否 ≤2 句，靠剧情消化？
8. □ 是否弱化了恋爱脑、去除了霸总控制感？
9. □ 是否至少有一条女性互助/同盟线？
10. □ 古代/世界观细节是否服务冲突，而非堆砌考据？

## 5. 对作家角色的输入要求

| 维度 | 要求 | 反例 |
|---|---|---|
| **动作链** | 每个关键场景给出 3 步以上具体动作：触发→反应→收束。例：太子妃挥鞭→女主侧脸受鞭→当众替其求情→借皇后之口定调。禁止"她冷笑一声，扳回一城"式跳跃。 | "她略施小计就赢了" |
| **物理反馈** | 冲突必须落到**身体/物件**上：鞭痕、撕纸、夺笔、握袖、流产、刀疤。抽象情绪要有锚点。科武场景额外要求**功法/装备的物理代价**（经脉损伤、能量耗尽、装备过热）。 | 仅写"她心中震怒" |
| **代价** | 每次爽必须有代价或风险敞口：求情=背骂名、保位=失自由、重生=记忆负担、金手指=冷却/反噬。无代价的爽=数据掉。 | 女主一路开挂无伤无损 |
| **钩子** | 每章结尾留**一个具体未决问题**（不是悬念形容词）：谁会来、什么物件会出现、哪句承诺会兑现。导语结尾必须有**"可不见得""凭什么让给外人"**式的反转预告句。 | "欲知后事如何，请看下章" |
| **读者预期** | 立项时写明：目标读者一句话期待（如"看清醒女主拿权不恋爱"），全文每个爽点对照此句交付；**不许中途切换合同**（如打着大女主旗号写恋爱脑）。 | 类型混搭、人设漂移 |

---

**一句话总结给写《科武纪元》的作者**：宫斗宅斗教我们的不是"古言怎么写"，而是**如何在封闭场域里用最少的设定、最高的密度、最明确的标的，交付一个不许跳票的爽感合同**——这套合同精神，直接对接科武世界的门派、舰队、世家、研究所。
