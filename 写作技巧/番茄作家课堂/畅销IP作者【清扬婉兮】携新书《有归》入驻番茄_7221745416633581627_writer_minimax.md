# 《科武纪元》作家OS补丁 v1.0

## 一、核心动作执行集

### 1. 开篇三章必杀动作清单

```
☐ 场景代入：100字内出现具体事件（禁止先写背景）
☐ 热点前置：第1章明确当下冲突/危机/困境
☐ 反常识抛出：第2章颠覆读者预期设定
☐ 目标锚定：第3章主角初始目标可量化/可视化
```

**落地示例**：
- ❌ 错误：叙述世界观设定1000字
- ✅ 正确：主角执行任务→遭遇反常识现象→被迫修改原定目标

### 2. 物理反馈四步法（强制执行）

```
【感知】目标锁定 / 距离判断 / 环境扫描
    ↓
【决策】方案选择 / 优先级排序 / 风险评估
    ↓
【执行】肢体位移 / 能量调动 / 武器轨迹
    ↓
【结果】命中判定 / 伤害反馈 / 环境改变
```

**禁用词库**：威力巨大 | 瞬间毁灭 | 强横无比 | 轻描淡写

**替代方案**：需标注具体数值/感官细节（肌肉撕裂声/骨骼压迫角度/冲击波半径）

### 3. 代价触发机制（3章内必须兑现）

| 能力/胜利类型 | 代价类型（必选一） |
|:---|:---|
| 能力跃升 | 寿命折损 / 神经负荷 / 器官透支 |
| 科技应用 | 资源枯竭 / 生态代价 / 法律追责 |
| 战术胜利 | 道德污点 / 关系破裂 / 未来隐患 |
| 认知突破 | 人格撕裂 / 认同危机 / 信任崩塌 |

**禁区**：禁止零成本通关，代价需在3章内兑现或埋下伏笔

### 4. 章末钩子五选一（必须执行）

| 钩子类型 | 执行标准 | 示例 |
|:---|:---|:---|
| **悬念钩** | 关键信息缺失 | "那不是信号，是坐标——来自七年前的自己。" |
| **反转钩** | 预期与现实偏差 | 以为是援军，实际是收割者 |
| **危机钩** | 威胁明确逼近 | 三十分钟后，轨道炮进入射程 |
| **选择钩** | 困境+二难抉择 | 炸毁实验舱救队友，还是保留样本拯救文明？ |
| **伏笔钩** | 早前细节闭环 | 呼应第3章那枚遗落的芯片 |

**主钩子**（贯穿卷）与**副钩子**（章级）分层管理，首秀期留存率锚定于副钩子密度

## 八、快速执行速查卡

### 人物口吻速查

| 角色类型 | 口吻特征 | 示例 |
|:---|:---|:---|
| 主角 | 目标导向+危机意识 | "我们没时间了，除非你能让我相信这个计划值得冒险。" |
| 配角A | 专业术语+冷静分析 | "能量输出曲线在这里出现拐点，说明有人在干预核心模块。" |
| 配角B | 战术吐槽+战场幽默 | "又来？我上次的假肢还没修好呢，长官。" |
| 反派 | 逻辑自洽+立场坚定 | "你们称我为叛徒，但，我只是提前看到了终点。" |

### 段落节奏速查

| 节奏类型 | 适用场景 | 执行比例 |
|:---|:---|:---|
| 日常切片+情绪爆点 | 人物塑造/关系推进 | 7:3 |
| 战术博弈+心理转折 | 战斗场景/决策时刻 | 6:4 |
| 信息输出+场景可视化 | 设定讲解/世界观扩展 | 5:5 |

### 章末钩子速查

```
悬念钩 → 读者问"为什么/怎么回事"
反转钩 → 读者想"不对，结果应该是..."
危机钩 → 读者紧张"这下完了"
选择钩 → 读者思考"如果是我..."
伏笔钩 → 读者回忆"原来之前那个细节是伏笔"
```
