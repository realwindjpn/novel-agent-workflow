## 一、写作前任务卡字段更新

### 1.1 任务卡标准模板

每章写作前必须完成以下字段填充：

```
【任务卡ID】: 第__卷_第__章
【字数目标】: __字（允许±500浮动）
【核心动作】: 主角当前目标 ___
【机制触发】: 本章涉及的核心规则 ___
【行为验证】: 通过___（动作）测试该规则
【物理反馈】: 观测到___（可量化现象）
【代价绑定】: 代价为___（24小时内可见）
【代价延迟】: 连锁影响在第__卷/第__章触发
【章末钩子】: ○信息钩/○状态钩/○规则钩
【缓冲段判定】: ○是（本章为缓冲段）/○否（高潮段）
【非战斗锚点】: 主角___（执念/怪癖/习惯）触发
```

### 1.2 任务卡填写检查点

| 字段 | 检查动作 | 失败标记 |
|:---|:---|:---|
| 核心动作 | 主角是否在从事“感知→决策→执行→结果”完整链？ | ⚠️无目标漂流 |
| 机制触发 | 是否明确使用哪个核心规则？ | ⚠️设定飘移 |
| 行为验证 | 规则是否通过具体行动/实验/战斗测试？ | ⚠️只抛设定 |
| 物理反馈 | 是否描写可观测的环境/躯体变化？ | ⚠️玄学输出 |
| 代价绑定 | 是否有即时代价（能量/损伤/冷却）？ | ⚠️零代价越级 |
| 代价延迟 | 延迟代价是否有记录？ | ⚠️账本缺失 |
| 章末钩子 | 是否遗留信息/状态/规则悬念？ | ⚠️情绪断章 |
| 缓冲段判定 | 高潮段后是否插入缓冲段？ | ⚠️阈值拉爆 |
| 非战斗锚点 | 主角行为是否绑定性格锚点？ | ⚠️工具人化 |

## 二、章节自检清单（10条精炼版）

### 2.1 写作中自检（每500字触发一次）

**自检A：机制验证检查**
```
□ 核心规则是否被调用？
□ 调用结果是否产生物理反馈？
□ 是否存在可观测的代价消耗？
```

**自检B：行为逻辑检查**
```
□ 主角行为是否符合其执念/怪癖/习惯？
□ 配角反应是否超出其认知边界（合理超限）？
□ 是否有逻辑断点导致跳跃？
```

**自检C：情绪节奏检查**
```
□ 是否已连续3章以上无缓冲段？
□ 当前段落是否触发读者阈值警戒线？
□ 是否有新的信息钩子？
```

### 2.2 章节完成后自检（完稿前必查）

```
□ 【开篇锚定】前300字是否亮出异常态或悬念锚点？
□ 【行为闭环】核心机制是否通过具体行动验证？
□ 【物理反馈】是否有可量化的环境/躯体变化？
□ 【代价链条】越级行为是否绑定代价？代价是否在3章内有连锁？
□ 【章末钩子】是否存在信息钩/状态钩/规则钩？（禁用纯情绪断章）
□ 【逻辑桥梁】场景/势力切换是否提供过渡逻辑？
□ 【读者预期】承诺的机制验证是否在进度内？
□ 【非战斗锚点】主角行为是否绑定人格特征？
□ 【缓冲段判定】高潮后是否插入缓冲段重置情绪？
□ 【卡文回溯】卡顿时是否优先检查未填旧坑？
```

## 三、动作-反馈-代价标准库

### 3.1 科武核心动作模板

**规则型动作链（必须包含以下四环）：**

```
【感知层】
主体：神经/传感器/意识接口
对象：规则漏洞/能量流向/对手意图
记录：数据面板/生物反馈/环境异常

【决策层】
依据：规则利用/信息差/环境适配
选项：至少2个可行性分析（代价排序）
选择：最优路径（含风险标注）

【执行层】
能量来源：生物能/机械能/场能/混合
传导路径：神经→接口→执行器→效果器
可观测输出：光/热/力/场/物质变化

【代价层】
即时代价：能量枯竭/神经负荷/装备损耗/冷却期
延迟代价：能力副作用/社会关系/规则反噬
累积代价：本卷内是否触发代价上限？
```

**禁用模糊动作词：**
| 禁用词 | 替换方案 |
|:---|:---|
| 猛击/爆发/强力 | 标注能量输出值、传导路径、效果范围 |
| 突然/瞬间 | 标注反应时间常数、神经传导延迟 |
| 强大/恐怖 | 标注可量化指标：功率/破坏力/影响范围 |
| 快速/迅速 | 标注相对速度：超越常人X倍/匹配机械响应 |

### 3.2 物理反馈标准库

**能力释放反馈模板：**

```
【能量输出类】
输出表象：光芒/热辐射/冲击波/场扭曲
环境响应：光线折射/空气电离/重力异常
躯体变化：血管/神经/机械接口的可见反应

【规则利用类】
规则表象：异常现象/超出预期/逻辑矛盾
观测记录：数据面板/检测设备/第三方视角
连锁反应：本章内/后续章的因果链

【代价反馈类】
即时表象：生理指标/机械状态/能量储备
延迟表象：能力冷却/副作用发作/环境反噬
累积表象：本卷/全书的规则边界收紧
```

### 3.3 代价设计检查表

| 代价类型 | 可量化标准 | 延迟触发窗口 |
|:---|:---|:---|
| 能量枯竭 | 剩余储备__%/容量上限__ | 下章即时 |
| 神经损伤 | 延迟__ms/准确率下降__% | 3-5章 |
| 冷却限制 | 间隔__秒/恢复条件 | 本章即时 |
| 社会代价 | 关系破裂对象/组织态度变化 | 1-2卷 |
| 规则反噬 | 触发条件/影响范围 | 全书伏笔 |

## 四、章末钩子标准库

### 4.1 三类钩子定义与模板

**【信息钩】**
```
定义：未解之谜/新势力/隐藏信息
模板：本章揭示___，但引出___未解问题
标注：○信息钩：___（悬念名称）
```

**【状态钩】**
```
定义：主角/关键人物陷入异常状态/倒计时
模板：当前状态___，威胁等级__，剩余时间__
标注：○状态钩：___（状态名称+倒计时）
```

**【规则钩】**
```
定义：设定出现反常/漏洞/新可能性
模板：已验证规则___出现异常，表现为___
标注：○规则钩：___（规则名+反常描述）
```

### 4.2 禁用钩子清单

```
⚠️ 禁用：纯情绪收尾（如“这一刻，他心中涌起无限感慨”）
⚠️ 禁用：废话断章（如“且听下回分解”“欲知后事如何”）
⚠️ 禁用：孤立悬念（无上下文铺垫的谜语）
⚠️ 禁用：虚假紧张（明确不会失败的危机）
```

## 五、人物口吻与段落节奏标准

### 5.1 科武主角口吻特征库

| 角色类型 | 口吻特征 | 触发场景 | 锚点示例 |
|:---|:---|:---|:---|
| 冷静分析型 | 短句+数据+逻辑推演 | 战斗中/危机中 | “能量残余__%，可选路径__” |
| 技术执念型 | 专业术语+狂热细节 | 装备调试/规则测试 | “这个参数偏差了0.003%...” |
| 生存驱动型 | 简洁+优先级排序+代价评估 | 高压环境 | “只能撑__秒，走哪边？” |
| 博弈型 | 试探性语句+信息验证 | 人际交互/势力周旋 | “你的条件我记下了，还有别的吗？” |

### 5.2 段落节奏模板

**高潮段节奏（3-5千字）：**
```
[激活] 核心机制启动 → 0-500字
[测试] 规则首次验证 → 500-1500字
[反馈] 可观测现象描写 → 1500-2000字
[反制] 敌方/环境响应 → 2000-3000字
[破局] 代价触发+悬念 → 3000-4000字
[收束] 信息钩/状态钩 → 4000-5000字
```

**缓冲段节奏（0.5-1千字）：**
```
[技术解析] 新装备/能力原理解构 → 300字
[日常交互] 非战斗锚点触发 → 300字
[伏笔植入] 下卷信息预告 → 200字
```

### 5.3 科武特有节奏器

| 节奏器 | 适用场景 | 操作要点 |
|:---|:---|:---|
| 数据面板 | 战斗/测试/危机 | 每30秒更新一次关键参数 |
| 能量守恒可视化 | 规则利用/代价触发 | 用具体数值替代抽象描述 |
| 技术故障 | 缓冲段/危机转折 | 用可修复的局部故障增加紧张感 |
| 神经/接口反馈 | 能力使用/情感触发 | 用生理指标替代情绪词 |
| 第三方视角 | 世界观扩展/信息交代 | 用旁观者/敌方数据补充主角视角盲区 |

## 六、失败模式与修正方案库

### 6.1 高频失败模式清单

**【模式A：设定飘移】**
```
表现：章节内核心规则未被调用，主角行为与金手指无关
检测：回溯任务卡，若核心机制未触发→本章失效
修正：补写机制测试段，或将主角行为绑定规则利用
```

**【模式B：物理反馈缺失】**
```
表现：能力释放无具体可观测现象，输出为玄学描述
检测：能否用数据/环境变化描述该效果？
修正：参照“3.2物理反馈标准库”补写可量化表象
```

**【模式C：零代价越级】**
```
表现：主角越级成功但无代价，能力使用无消耗
检测：查阅代价字段是否为空
修正：绑定即时代价（能量/损伤/冷却）或延迟代价（下章发作）
```

**【模式D：情绪断章】**
```
表现：章末仅情绪收尾，无信息/状态/规则悬念
检测：能否用一句话概括本章结尾留下的问题？
修正：参照“4.1章末钩子模板”添加钩子
```

**【模式E：工具人化】**
```
表现：主角行为无个性特征，配角反应模式化
检测：主角执念/怪癖/习惯是否触发？
修正：回顾人物档案，补写非战斗向记忆点
```

**【模式F：阈值拉爆】**
```
表现：连续3章以上高潮无缓冲，读者的情绪耐心耗尽
检测：章节计数是否超过阈值警戒线？
修正：插入技术解析/日常交互/配角支线缓冲段
```

**【模式G：逻辑断点】**
```
表现：场景/势力切换生硬，因果链断裂
检测：每段过渡是否有逻辑桥梁？
修正：补充“上一场景的收束→下一场景的激活”过渡段
```

**【模式H：卡文漂流】**
```
表现：无灵感时强行推进，章节质量下降
修正路径：
1. 回溯未填旧坑（检查坑本）
2. 触发延迟代价（利用已建立代价链）
3. 引入配角支线（借用缓冲段模板）
4. 测试规则漏洞（回到行为验证逻辑）
```

## 九、平台规则→发布/包装/风险门禁

### 9.1 番茄算法适配清单

| 指标 | 优化动作 | 检测节点 |
|:---|:---|:---|
| **读完率** | 每章必须有完整闭环，禁止开放式断章 | 完稿自检 |
| **追更率** | 章末钩子→下章开头承接，形成期待链 | 卷末检测 |
| **留存钩** | 每章至少1个明确悬念，维持阅读动力 | 章节自检 |
| **单机期留存** | 10万字单机期依赖信息悬念而非即时爽点 | 开篇3卷 |
| **验证节点** | 10-30万字完成核心机制首次完整验证 | 卷末检测 |

### 9.2 发布门禁清单

```
【发布前必查项】⚠️=门禁触发
□ ⚠️核心机制是否在开篇3章内完成“异常态展示+基础规则说明”？
□ ⚠️章末是否保留信息钩/状态钩/规则钩？（禁用纯情绪断章）
□ ⚠️越级行为是否绑定代价？代价是否可量化？
□ ⚠️章节内是否有完整的“感知→决策→执行→结果”动作链？
□ ⚠️是否有可观测的物理反馈？（禁用玄学描述）
□ ⚠️是否超过3章无缓冲段？（阈值警戒线）
□ ⚠️场景切换是否提供逻辑桥梁？
□ ⚠️科幻设定是否具备可推演逻辑？（禁用纯脑补）

【推荐期前必达项】⚠️=推荐门禁触发
```
