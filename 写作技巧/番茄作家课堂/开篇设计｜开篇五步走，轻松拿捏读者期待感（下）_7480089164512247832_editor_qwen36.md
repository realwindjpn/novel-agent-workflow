# 《科武纪元》编辑学习报告：开篇设计规则提炼

## 1 课程核心判断（≤6条）
1. **期待感三选一法则**：反套路/意外感、动作化悬念、反差人设，开篇只需精准落实其一即可有效留客。
2. **结构容量红线**：开篇2k-3k字内必须完成≥2个明确事件，主事件占比＞50%，插叙/倒叙严格≤总篇幅25%。
3. **信息释放纪律**：世界观/势力/背景必须碎片化后置，开篇单屏过半为静态描述或设定堆砌即触发读者流失。
4. **视角与人物聚焦**：主视角全程锁死主角，有名有姓角色≤4人，主角有效篇幅占比≥60%。
5. **悬念呈现铁律**：禁用上帝视角预告（如“他不知道这将引发…”），悬念必须通过“只给现象/动作，不给前因”的动作化方式呈现。
6. **避坑底线**：开篇严禁主角做出不讨喜行为（无逻辑烂好心/降智挑衅/拖后腿），严禁频繁切视角与打哑谜。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 切入点必须在事件进行中（In Media Res）。首章需完成“冲突爆发→主角行动→插叙补因→次事件承接”闭环。 |
| **节奏** | 事件间过渡段落≤200字。主事件必须造成主角人生/处境不可逆转折。插叙严格控制在300-500字内，仅用于补全反差逻辑或人设基底。 |
| **冲突** | 冲突必须紧扣核心梗。采用“预设逻辑+打破逻辑”制造反套路（如常规复仇改为直接掀桌/规则重构）。次要事件必须是主事件的前因/后果或下章引子。 |
| **人物** | 标签先行+内外反差。主角行动必须完整闭环以印证标签。配角仅保留功能性，路人无需命名。CP或单主角需具备天然冲突性（身份/性格/理念）。 |
| **题材** | 科幻/玄幻/穿书类开篇禁止事无巨细交代设定。势力分布、力量体系、穿越前史必须通过后续冲突逐层剥离展现。 |
| **改编** | 影视/短剧向需强化“动作链可视化”与“单场景高信息密度”。开篇2k字需具备至少1个可独立成片的强冲突场面，减少心理独白。 |
| **平台规则** | 番茄移动端阅读适配：连续描写＞100字即劝退。排版单屏过半无剧情推进需强制删减。开篇不写复杂群像，首章必须亮出核心卖点/爽点类型。 |

## 3 科武适配
### ✅ 可用点
- **反套路转化**：金手指不私藏，改为“接入联邦主脑/上交武道联盟/逆向破解功法协议”，打破传统升级流预期。
- **悬念具象化**：用“机甲义体排异数据异常/古武经脉逆向运转/未知能量辐射读数”替代抽象心理悬念，只给现象不给解释。
- **人设反差**：外表赛博冷感/机械改造/数据化理性，内里传统武道执念/热血/反叛精神。标签+行动反差直接落地。
- **结构套用**：开篇直切“机甲考核/武馆踢馆/星舰跃迁故障”危机，插叙“武道断代史/前世战败记录”≤300字，迅速转入次事件（如资源争夺/敌对势力介入）。

### ⛔ 不可硬套点
- **女频情感套路**：“发疯文学/打脸白月光/宅斗排挤/一夜情”等需剔除或重构为科武语境下的“规则破坏/资源碾压/理念对决/生存危机”。
- **文艺隐喻钩子**：“画中藏骷髅”等意象化伏笔不适配硬核科武，需替换为“数据乱码/功法反噬/义体过载警报/星图坐标偏移”等可量化符号。
- **慢热铺垫**：科武题材读者对“战力体系/科技树”容忍度低，开篇若用大段设定铺垫代替动作冲突，将直接触发弃书率飙升。

## 4 编辑检查表（10条以内）
1. 开篇2k-3k字内是否包含≥2个有明确因果或转折的事件？
2. 主事件篇幅是否＞50%？插叙/倒叙是否≤总字数25%？
3. 主角出场有效篇幅占比是否≥60%？有名有姓角色是否≤4人？
4. 是否出现连续＞100字的纯场景/外貌/设定描写？
5. 悬念/伏笔是否通过“动作/现象”呈现，而非上帝视角独白？
6. 主角行为是否完整闭环？是否通过动作直接体现人设标签？
7. 事件间过渡段落是否≤200字？
8. 是否规避了主角早期不讨喜行为（无逻辑烂好心/降智挑衅）？
9. 视角是否全程锁定主角？对话中是否频繁跳切？
10. 核心梗/卖点是否在开篇第一个冲突中直接亮出？

## 5 对作家角色的输入要求
| 要素 | 输入规范（科武向强制标准） |
|:---|:---|
| **动作链** | 必须呈现“触发→决策→执行→结果”完整物理链条。禁用心理活动替代动作。例：`警报响起(触发)→切断痛觉抑制器(决策)→超载推进器撞穿舱壁(执行)→失压环境暴露(结果)`。 |
| **物理反馈** | 力量/速度/能量释放必须伴随环境破坏、生理负荷或装备损耗的实时反馈。禁用“威力巨大/势不可挡”等抽象词，改用“合金装甲凹陷/肌肉纤维撕裂/冷却液喷溅/重力参数失衡”。 |
| **代价** | 每次越级行动/调用金手指必须支付即时代价（神经灼烧/信用点扣除/功法反噬/坐标暴露/义体寿命折损）。禁止无损耗开挂，代价需在当章或次章首段兑现。 |
| **钩子** | 仅允许“现象/动作”型钩子。例：只写“主角徒手捏碎S级机甲核心，指尖流出蓝色冷却液”，不解释原理，留白至后续冲突揭晓。严禁“他不知道这将引发星际战争”式预告。 |
| **读者预期** | 开篇首章必须明确交付“核心爽点类型”（硬核升级/智斗破局/反杀打脸/探索解密）。后续情节需严格对齐该预期，禁止首章写悬疑、次章转搞笑的割裂操作。预期锚点需在首章末段通过主角行动或环境变化二次确认。 |
