# 素材卡：戴森云/轨道反射镜前置技术

## 核心数据
- **Dyson Swarm（戴森云）**：独立轨道太阳能收集卫星群，非刚性球壳——比戴森球更可行的前置形态
- **建造路径**：小行星采矿→原位3D打印卫星→自复制机器人指数级扩张
- **能量中继**：微波/激光无线传输效率≥65%，太空太阳能→地面/轨道站
- **热力学约束**：Phys.org 2025论文——完整戴森云使地球升温140K，需主动热管理/轨道热盾
- **SpaceX轨道数据中心**：100万颗太阳能供电卫星节点，被动辐射散热（-270°C太空背景）
- **量子电池+AI协调**： Swarm Shell Units（SSU）分层构建，自主纳米工厂+AI驱动基础设施

## 小说映射
- **卷六→卷九**：戴森云从概念到落地的技术演进路径
- **自复制机器人**：大国争夺的"工业母机"，指数级轨道扩张能力
- **140K热失控危机**：催生"轨道热盾"工程战——能源利用与热管理的矛盾
- **轨道天火**：反射镜阵列聚焦太阳能实施定向打击，或为深空舰队无线充能
- **天基超算网**：百万节点数据中心构成"太空算力云"，支撑AI指挥与量子通信
- **《星火集》**：方宁整理的戴森球理论包含此技术路线
