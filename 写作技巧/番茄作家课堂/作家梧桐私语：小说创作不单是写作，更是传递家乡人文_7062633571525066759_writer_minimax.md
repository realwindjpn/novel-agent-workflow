# 《科武纪元》作家OS执行补丁 v2.1
**来源：梧桐私语专访规则转化 | 适配：科武长篇/狼人短篇双轨**

## 一、核心补丁：动作-反馈-代价闭环

### 【补丁1】科武战斗必须拆解为五段式
```
环境扫描（0.5秒）→ 能量/灵能调用（0.3秒）→ 神经/肌体负荷（0.2秒）→ 招式释放（0.1秒）→ 反作用承受（持续）
```
**执行标准**：
- 外骨骼启动延迟≥0.3秒（可被高手利用）
- 灵能回路单次最大吞吐量：≤总容量67%（防止无限叠）
- 神经接口过载触发条件：连续释放≥3次A级技能

**短故事可借点**：战斗场景压缩为三段式（起-承-转），保留“环境扫描+代价承受”两极

### 【补丁2】物理反馈必须可量化
| 能力/装备 | 必然反馈 | 可选叠加 |
|:---|:---|:---|
| 基因强化剂（初次） | 体温骤升至39.5℃、骨骼重塑钝痛、味觉屏蔽24h | 瞳孔色变、汗液金属味 |
| 外骨骼满功率 | 冷却液温度破百、关节伺服电机啸叫、背部散热片发红 | 视野边缘热浪扭曲 |
| 灵能爆发（S级） | 空气电离臭氧味、毛细血管破裂（眼白充血）、味觉丧失30秒 | 头发静电炸开、听力瞬间失聪 |
| 神经同步过载 | 视野马赛克化、肢体迟滞0.5秒、咀嚼肌痉挛 | 记忆片段闪回、短暂失语 |

**禁用表述**：`毫发无损`、`轻松碾压`、`仅仅……`、`略有不适`

### 【补丁3】代价支付必须直接推动后续
**代价类型与剧情绑定**：
```
能力跃迁类代价 → 解锁新限制/解锁新弱点（3章内体现）
越级反杀类代价 → 短期战力锁定/阵营关系恶化（下一章兑现）
装备过载类代价 → 核心组件损耗/维修冷却期（造成资源困境）
```

**失败模式**：代价未兑现 → 战力通货膨胀 → 读者失去紧张感

## 二、人物口吻控制

### 【补丁A】主角口吻基底
**身份标签**：改造人/觉醒者/技术遗民  
**口吻特征**：
- 对自身局限有清醒认知（不自大、不卖惨）
- 对技术细节使用第一人称陈述，不解释原理
- 情绪表达克制，用身体反馈替代台词宣泄

**示例**：
```
❌ "我不服！我一定要证明自己！"
✅ "左手无名指的神经接口还在发麻，第三指节失去触觉。
   按照老梁给的参数表，剩余战力约67%。
   够了。"
```

### 【补丁B】配角/对手口吻差异化
| 角色类型 | 口吻特征 | 科武语境示例 |
|:---|:---|:---|
| 旧武道派 | 引用古典/经验主义、质疑改造伦理 | "经脉已断，何谈武道？" |
| 技术阵营 | 数据化表达、对效率有执念 | "成功率83.7%，可以接受。" |
| 边缘遗民 | 隐喻/黑色幽默、对体制有怨气 | "体检报告说我有三成概率疯掉，运气不错。" |
| 敌对改造体 | 去人性化、机械式陈述 | "目标识别。威胁等级：低。执行清除。" |

## 三、段落节奏控制

### 【节奏公式】（科武长篇版）
```
开篇300字：世界观切片 + 核心钩子 + 主角初始处境
↓（每2000字插入）
小高潮节点：技术突破/战力验证/情报获取（任选一）
↓（每5000字插入）
认知迭代点：主角对自身/世界的理解发生位移
↓（每8000-10000字）
代价兑现/新规则揭示
```

### 【节奏公式】（狼人短篇版）
```
开篇500字：身份困境 + 核心冲突锚定
↓（每1500字）
行动-反馈循环：主角行动→明确代价→结果
↓（第3-4段）
真相揭示/身份反转
↓（末段）
钩子（悬念/情感余韵）
```

### 【节奏红线】
- ❌ 连续3段纯对话（无动作/无反馈）
- ❌ 超过500字的技术设定说明（必须分散植入行动中）
- ❌ 情绪宣泄超过2段（用身体反馈截断）
- ✅ 每章至少1处“代价已支付”标识

## 四、章末钩子模板

### 【模板1】技术谜题型（科武长篇）
```
结构：[当前状态] + [异常信号/未解数据] + [指向性悬念]
示例：
"外骨骼黑匣子的最后日志正在解码。
   时间戳显示：死亡前7分钟。
   坐标……正是我此刻站立的位置。"
```

### 【模板2】身份反转型（狼人短篇）
```
结构：[表面关系] + [裂痕信号] + [认知颠覆]
示例：
"'怪物'这个词从她嘴里说出来时，
   我注意到她的瞳孔正在收缩——
   和我变身前一模一样。"
```

### 【模板3】代价延迟型（双轨通用）
```
结构：[当前胜利] + [隐性代价] + [下一章兑现预告]
示例：
"他倒下了。我赢了。
   但胜利的代价正在从左手蔓延——
   神经接口的灼烧感告诉我，
   下一场战斗，我可能连拳头都握不住。"
```

## 六、章节自检清单（10条）

### 必检项
1. [ ] **战斗拆解**：本场战斗是否包含“环境扫描→负荷→反馈→代价”四段？
2. [ ] **代价追踪**：本章承诺的代价是否已兑现或明确延迟节点？
3. [ ] **量化反馈**：能力/装备使用是否有≥1项可量化生理/物理反馈？
4. [ ] **钩子存在**：章末是否有技术谜题/身份反转/代价悬念？
5. [ ] **节奏红线**：是否有≥3段连续对话/≥500字技术说明/≥2段情绪宣泄？

### 校准项
6. [ ] **成长弧追踪**：主角阶段性目标是否推进≥10%？
7. [ ] **改编潜力**：本章是否有≥1处可视觉化的高光场景？
8. [ ] **动机闭环**：核心冲突是否源于身份认同/理念对立而非外部强加？
9. [ ] **平台合规**：内容是否触发[血腥过滤/政治敏感/版权争议]门禁？
10. [ ] **承诺兑现**：本章是否兑现了上一章的悬念/预期？
