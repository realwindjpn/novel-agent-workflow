## 一、10条写法规则｜作家OS补丁

1. **首句30字内抛异常**
   - 格式：`主角 + 异常处境/反常动作 + 危险或疑问`
   - 禁止：天气、地名、家世、回忆、自我介绍开场。

2. **前300字必须讲清四件事**
   - 谁、在哪、做什么、对抗谁/什么。
   - 读者不能复述，说明开篇失败。

3. **开篇不铺设定，只投“米粒信息”**
   - 每次只给一粒设定。
   - 专有名词必须用动作解释，不写百科段。

4. **人设必须靠事件证明**
   - 不写“他很强/她很冷静”。
   - 改成：他在枪口下拆掉了自己的义眼，只为省0.3秒延迟。

5. **开篇200—400字必须有动作链**
   - 至少3—5个连续动作。
   - 格式：`主语 + 动词 + 对象 + 结果`
   - 禁止用心理活动替代冲突。

6. **每个关键动作都要有反馈**
   - 必带至少一种：声音、震动、温度、HUD数据、血肉反应、机械反应、敌人反应。
   - 科武场景优先用：机械反馈 / 能量反馈 / 生理反馈。

7. **每次爽点都要付代价**
   - 代价可选：体力、信用点、记忆、关系、零件、时间、身体损伤、身份暴露。
   - 无代价的爽点会显假、空、低龄。

8. **段落节奏按手机滚屏写**
   - 段落≤3行。
   - 句子尽量≤25字。
   - 爽点、奇点、悬点首章至少出现2—3次。

9. **主动埋投放素材位**
   - 必留：名场面、金句、系统/HUD提示、可截图对白、15秒可剪画面。
   - 平台门禁：首屏吸睛、画面可视、对白可截、风险不剧透核心谜题。

10. **写作前任务卡字段更新**
   - 开篇切入式：高光事件 / 人设事件 / 引子小故事  
   - 本章情绪承诺：爽 / 虐 / 奇 / 悬 / 燃  
   - 兑现位置：第几段兑现  
   - 动作链：3—5个动作  
   - 物理反馈：机械 / 能量 / 生理  
   - 爽点代价：具体损耗  
   - 可剪名场面：一句话描述  
   - 章末钩子：末段悬念一句话  
   - 下一章看点：一句话  
   - 发布风险门禁：是否剧透核心谜题 / 是否技术失真 / 是否首屏无冲突

## 二、10条章节自检清单

1. **首句是否30字内给出冲突、危险或反常？**

2. **前300字内，读者能否复述“谁在哪做什么对抗谁”？**

3. **是否出现整段世界观、职业体系、科技原理说明？**
   - 有就删、拆、后置。

4. **主角首次出场是否有反预期动作？**
   - 身份、外貌、处境与行为要形成落差。

5. **主角人设是否被动作坐实，而不是旁白宣布？**

6. **首章是否至少有2—3个反应点？**
   - 爽、笑、奇、疼、燃、悬，至少占一个强项。

7. **是否使用了投放友好修辞？**
   - 排比 / 夸张 / 数字强调，至少一种。

8. **是否有一个可截图、可漫剪、可单屏15秒成片的名场面？**

9. **章末是否留下一个未解钩子？**
   - 不是解释完，而是让读者必须看下一章。

10. **专有名词第一次出现，是否能被动作或上下文理解？**
   - 不能理解就加“自带翻译”，不要硬科普。

## 三、3条科武落地

1. **科武长篇可借点**
   - 用“科技异常 + 武力爆发”做首屏反差。
   - 示例方向：  
     `他觉醒的不是武魂，而是家族废弃服务器。`  
     `第0.03秒，机甲没启动，他的神经先燃了。`
   - 注意：不剧透底层谜题，不牺牲技术自洽，不全篇短句化。

2. **短故事 / 狼人篇可借点**
   - 借“身份错位 + 极端处境 + 反转钩子”。
   - 狼人篇适合：血统暴露、群体审判、夜晚变身、亲密关系背叛。
   - 短故事适合：前置高光、单场冲突、结尾反杀或身份翻转。

3. **发布 / 包装 / 风险门禁**
   - 发布前看三项：首屏是否有钩子、是否有15秒名场面、标题是否能提炼主角反差。
   - 包装素材预留：HUD提示、聊天记录对白、战场数字、敌我对位、人设金句。
   - 风险门禁：不为投放乱改物理规则，不提前泄露核心谜题，不用低幼毒舌系统破坏科武质感。
