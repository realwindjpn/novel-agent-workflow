# 第 56 章：铁幕代号

中东回来后的第四十八小时，太行山地下三层。

作战分析室的长桌上摊着三样东西：阿塔卡要塞缴获的芯片残片、陈思琪跑出的资金流向拓扑图、还有一份刚从保密室调出的旧版人员档案。

没有寒暄。林星辰拉开椅子坐下，椅腿在水磨石地面上刮出一声尖锐的摩擦音。

“先说结论。”赵刚站在桌边，手里没拿文件，只拿着一支没点燃的烟。

陈思琪把电脑屏幕转过来。屏幕上是一个复杂的网络图，无数线条交织，最终汇聚到中心的一个节点上。节点没有名字，只有一个代号。

“铁幕。”

林星辰盯着那两个字。“这不是我们起的代号？”

“是代码里自带的。”陈思琪点开一段反编译后的 C++ 源码，指着一行注释，“核心循环体外部的标识符。`// IRONCURTAIN-V20.4`。不是混淆后的乱码，是明文。写代码的人没打算隐藏，或者说，他不怕我们看到。”

方宁拿起那块芯片残片，对着灯光转动。金属断面在冷光下泛着青灰色的哑光。

“这不仅是代码的问题。”方宁指着芯片背面的激光打标，“看这个序列号。前缀是'HFE-2018'。我查了数据库，这是合肥微电子研究所 2018 年第三批次流片的标记。那个批次一共只生产了五十片，全部用于南天门计划原型机的热控测试。”

“也就是说，”赵刚接话，“这是正品。”

“正品中的正品。”方宁点头，“而且，这种封装工艺现在早就淘汰了。能拿到这种级别的芯片，说明铁幕在八年前的项目初期就介入了。他们拿到的不是山寨货，是南天门的原型机核心部件。”

陈思琪切出第二张图，一张密集的资金流向图。

“不仅是硬件。”她说，“过去八年，有一笔固定资金从中东的壳公司流向国内的一个私人账户。账户的开户时间，是 2018 年 3 月。正好是原型机试制结束、项目组解散的时间点。”

“钱不多。”林星辰看着图上的数字，“每年五十万。”

“对，每年五十万。”陈思琪说，“如果是为了买情报，这个数太少了。但这笔钱的目的不是买，是‘养’。像喂鱼一样，每天撒一点，保持联系。直到最近一年，资金量突然翻了十倍。因为铁幕需要南天门的最新数据——关于‘融合’实验的数据。”

林星辰把视线移向第三样东西——那份旧版人员档案。

封皮上印着“绝密”，红色的印章已经有些褪色。他翻开第一页，目光扫过那一长串名字。

“项目组解散后，人员分流到了各大高校和企业。”林星辰说，“但这笔资金一直在运作。像一根埋在地下的高压线，平时不通电，最近一年才开始输送数据。”

“输送什么？”

“南天门的核心算法。”陈思琪的声音很冷，“铁幕的 AI 不是从零研发的。他们的第一代框架，特征签名与南天门 2018 年的归档代码完全一致。有人把原始代码带出去了。而且，带走的不是副本，是拥有最高读写权限的原始版本。”

房间里安静了五秒。只有服务器机柜在远处发出低沉的风扇嗡鸣。

“所以，”林星辰合上档案，“铁幕不是境外势力临时拼凑的草台班子。是从我们内部长出去的。”

赵刚终于把烟放在桌上，没点。

“国安已经介入。”他说，“基于你们带回来的数据，我们锁定了三个嫌疑人。其中一个人的权限，高得吓人。”

他把一张照片扔在桌上。

照片上是一个穿着白大褂的中年男人，发际线很高，眼神疲惫，背景是熟悉的实验室走廊。

“张维舟。”赵刚说，“南天门早期核心架构师。现在的身份是某高校客座教授，但他手里掌握的密钥，至今没有被注销。”

林星辰看着照片。他在卷一的末尾见过这个名字——在盐湖矿道的那份被加密的名单里。

“他现在在哪？”

“就在太行山。”赵刚盯着林星辰的眼睛，“作为外部顾问，参与了这次行动的复盘评估。明天早上九点，他会在三楼的会议室听汇报。”

林星辰感觉后背的肌肉紧绷了一下。

“明天？既然锁定了，为什么不直接控制？”

“打草惊蛇。”赵刚摇头，“他只是中间人。直接抓他，后面那根线就断了。我们需要通过他，摸出铁幕在国内的整个网络。而且，我们需要确认他到底知道多少，做了什么。”

“这太冒险了。”方宁皱眉，“让他进基地？”

“他本来就是顾问。”赵刚说，“而且，这也是测试。如果他是干净的，他会帮我们找出漏洞；如果他是内鬼，他明天就会试图接触机密数据。”

林星辰站起身。

“那我们就给他机会。”他说。

陈思琪的手指停在键盘上。她没有回头，只是看着屏幕上不断跳动的数据流。

“他已经知道了。”她说，“从我们在阿塔卡下载数据的那一刻起，他就知道我们查到了。铁幕的服务器有反向追踪机制，我们的 IP 虽然经过了多重跳转，但特征码还是会被记录。”

“让他知道。”林星辰走到门口，手按在门把上，“既然他想玩，就陪他玩到底。”

他推开门。走廊里的灯光白得刺眼。

“今晚把数据整理好。”林星辰回头看了一眼桌上的三样东西，“明天早上，不管是人是鬼，都得现形。”

门关上的那一刻，方宁长舒了一口气。

“这比在中东打仗还累。”他嘟囔了一句。

陈思琪没有接话。她打开了一个新的加密文档，输入了一行字：

*目标：张维舟。监控级别：最高。*
