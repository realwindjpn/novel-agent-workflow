# 《科武纪元》编辑学习官｜《开书准备｜大纲这样写才不崩》拆解报告

## 1 课程核心判断（≤6条）
1. **输入决定输出**：定向扫文（近期30万字内首秀起量文+经典文）是掌握市场节奏、规避逻辑雷区的前提。
2. **篇幅定结构**：预估字数直接决定伏笔密度与叙事重心（百万字需深挖主副线/世界观，30万字内必须直给剧情）。
3. **人设驱动剧情**：角色必须通过行动与对话塑造，核心目标与动机需贯穿始终，人物小传是防崩人设的底线工具。
4. **市场反慢热**：快节奏环境下，开篇必须制造悬念/冲突直切核心矛盾，拒绝大段静态描写与“恋爱脑”设定。
5. **大纲重逻辑轻死板**：宏观框架（立意/背景/主线/人物）必须严密闭环，微观细纲需保留弹性以容纳创作期灵感。
6. **平台验证期铁律**：番茄首秀验证期在8万字，此前数据无参考性；坚持日更与开篇可重写性比死磕初稿更重要。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 必须制造悬念或冲突场景，迅速引出主角与核心矛盾；禁用大段环境/外貌/设定堆砌；开篇允许且应当多次重写直至逻辑自洽。 |
| **节奏** | 严格按预估字数定调：20-30万字“直给剧情不埋长线”；50-100万字“围绕主线埋浅伏笔”；100万字+“构建大世界观+主副线交织”。全程拒绝慢热与辞藻堆砌。 |
| **冲突** | 发展期需设置“阶段性小目标”，情节必须有起伏；冲突需服务于人物成长与核心立意，避免平铺直叙；配角冲突需与主角目标交织。 |
| **人物** | 禁用旁白堆砌性格；必须通过剧情/行动/对话展现；撰写人物小传（含目标/动机/背景/性格）；配角需有独立动机，拒绝工具人化。 |
| **题材** | 明确受众痛点（爽感/共鸣/猎奇/热血）；文风/用词需匹配品类；科幻/未来题材必须构建对应的科技水平、社会形态与思维模式；避免孤芳自赏，顺应市场趋势。 |
| **改编** | 书名签约后不可改，需具备强记忆点与吸睛力；封面占推流权重极高，需视觉停留设计；简介需简洁点明核心人物、核心梗与最大看点，不故弄玄虚。 |
| **平台规则** | 8万字验证期前数据平淡属常态，严禁断更；避免过度收集外部反馈导致自我怀疑；AI可用于99%设定/常识查证；细纲不宜过死，保留创作期微调空间。 |

## 3 科武适配
### ✅ 可用点
- **世界观动态化**：原文强调“未来世界需构思科技发展水平、社会形态、思维/社交模式改变”，完美契合《科武纪元》“科技+武道”底层逻辑，设定必须通过剧情冲突自然带出。
- **长篇结构规划**：百万字级长篇适用原文“深挖主副线+大世界观+简单伏笔”架构，武道升级体系与科技树可作双线推进，避免开局信息过载。
- **动机驱动叙事**：科武主角需明确贯穿始终的目标（如突破基因锁/对抗AI暴政/武道复兴），动机（仇恨/责任/探索）直接决定剧情走向，符合原文“目标与动机贯穿始终”原则。
- **开篇冲突化**：拒绝科幻设定说明书式开篇，用“机甲暴走/武道考核危机/星舰迫降”等强冲突场景切入，符合原文“开端制造悬念/冲突直切矛盾”要求。

### ⛔ 不可硬套点
- **“30万字直给不埋长线”**：科武长篇若套用此规则会导致力量体系与星际格局未展开即完结，必须严格按百万字逻辑规划长线伏笔。
- **“避免大段描写”**：科武涉及硬核设定（功法原理、机甲参数、能量回路），需必要的技术描写，但必须转化为“动态演示/实战反馈”，而非静态说明。
- **“年轻女性向热梗/沙雕风”**：若《科武纪元》定位硬核男频/正剧，需剔除过度网感化表达，保持严谨冷峻基调，原文“受众定位”原则需反向应用。
- **“细纲不宜过死”**：科武涉及复杂力量体系与科技树，核心升级路径/关键战役/势力博弈需硬细纲锁定，仅日常交互/支线探索可留白。

## 4 编辑检查表（10条以内）
- [ ] 开篇前3章是否已抛出核心悬念/冲突，并引出主角与主线矛盾？
- [ ] 预估字数与伏笔密度是否严格匹配？（百万字级是否已规划主副线架构？）
- [ ] 主角是否具备明确贯穿目标与行为动机？是否已附人物小传防OOC？
- [ ] 世界观/科技/武道设定是否通过剧情动态展现，而非开篇静态堆砌？
- [ ] 简介是否≤150字，清晰点明核心人物、核心梗与最大看点？
- [ ] 书名是否具备强记忆点/吸睛力，且签约前已做平台重名检索？
- [ ] 大纲逻辑链是否闭环？人物行为是否符合其性格与动机设定？
- [ ] 是否已规避当前市场雷区（慢热、恋爱脑、设定堆砌、逻辑漏洞）？
- [ ] 是否明确目标受众痛点，并匹配对应文风与叙事节奏？
- [ ] 是否已做好开篇可重写准备，并设定8万字验证期前不断更底线？

## 5 对作家角色的输入要求
提交稿件/大纲节点时，必须按以下维度提供结构化输入，否则退回修改：

| 维度 | 输入要求 |
|:---|:---|
| **动作链** | 关键情节必须提供“触发条件→决策动作→连锁反应→结果”的完整逻辑链。禁止跳跃式推进、机械降神或无铺垫转折。 |
| **物理反馈** | 科武战斗/科技交互场景，必须附带符合设定的物理/生理反馈（如反冲力、神经负荷、能量过载的具象化表现、环境破坏痕迹）。禁用纯数值对轰或抽象化描写。 |
| **代价** | 主角每次获取力量/情报/胜利，必须支付明确代价（资源消耗、身体损伤、道德妥协、阵营关系破裂、时间窗口关闭）。禁止无成本升级或零风险破局。 |
| **钩子** | 每章结尾必须设置“信息缺口/危机逼近/选择困境”三选一钩子。需明确标注钩子类型与预期释放章节，确保读者产生“必须翻页”的阅读惯性。 |
| **读者预期** | 开篇需明确交付类型承诺（硬核科幻/武道升级/星际争霸/废土求生），后续剧情必须兑现或合理反转该预期。禁止中期突兀切换赛道（如科幻转纯修仙、正剧转沙雕）。 |
