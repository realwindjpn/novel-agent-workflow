# 一、核心执行模块（6个原子动作）

## 模块A：触发决策执行链

```
每场冲突必须包含以下四个节点，缺一即触发“节奏断裂”警报：

① 触发事件 → ② 角色决策（含利益计算/价值观冲突）
→ ③ 执行过程（含物理反馈/代价消耗） → ④ 结果（含伏笔埋设/钩子挂载）

检查点：若跳过②直接进入③，标记为“机械降神”
若跳过③直接进入④，标记为“情绪跳跃”
```

**科武适配**：战斗/操作场景需加入能量守恒、神经负荷、环境变量参数。  
**短篇借鉴**：压缩至“触发→抉择→结果”三段式，决策即核心冲突。

## 模块B：代价即时化系统

```
代价生效规则：
1. 前3章内必须让核心代价进入“可感知状态”
2. 每次越级操作实时扣除，并附带躯体/装备/关系损耗反馈
3. 代价需形成连锁反应（不可独立消解）

代价类型矩阵：
├─ 生理代价：神经负荷/基因排异/寿命折损/感官损伤
├─ 技术代价：装备过热/能量枯竭/系统宕机/材料损耗
├─ 社会代价：阵营信任破裂/资源配额削减/通行权降级
└─ 伦理代价：同类背叛/原则崩塌/身份认同撕裂
```

**禁止项**：无代价爆发、能力凭空消失、代价单章内自动修复。

# 四、人物口吻模板

## 类型A：冷峻理性型

```
语言特征：
├─ 短句为主，信息密度高
├─ 极少使用形容词，多用动词精确描述
├─ 情感表达通过行为/生理反应间接传递
└─ 逻辑推导过程外显

示例：
"计算完毕。突破概率23.7%。可接受损耗范围：右肢义体+听觉模块。
执行。"
```

## 类型B：技术型人格

```
语言特征：
├─ 专业术语自然穿插
├─ 对非技术内容表现出轻微困惑或漠视
├─ 情感表达载体为“系统参数”或“数值变化”
└─ 倾向用类比解释抽象概念

示例：
"这不符合逻辑。她明明有更优选项，却选择了
资源消耗最高、成功率最低的方案。
除非……她的优先级函数里，
'信任'这个参数被设成了无穷大。"
```

## 类型C：阵营冲突型

```
语言特征：
├─ 立场表达通过词汇选择体现
├─ 对“他者”使用评判性措辞
├─ 核心利益冲突时语气骤然变化
└─ 逻辑与情感分割明显

示例：
"你们管这叫'解放'？
从旧世界的数据来看，这类词汇的官方定义
通常伴随大规模基础设施损毁和人口减计。
我需要更精确的描述。"
```

# 七、科武向强制规范（与古言核心差异）

## 核心差异清单

| 维度 | 《缚春情》古言模式 | 科武向调整 |
|:---|:---|:---|
| **开篇** | 核心人物可延后，保留存用“慢热+考据” | 核心悬念/金手指必须前置 |
| **节奏** | 允许慢节奏，用情感张力对冲 | 必须保持主线目标推进，慢节奏=弃读 |
| **情感线** | 主轴核心，道德线驱动 | 降级为副线，绑定主线目标 |
| **冲突** | 允许情绪化冲突 | 必须符合世界观底层逻辑 |
| **代价** | 代价可延迟消解 | 代价必须即时触发+连锁反应 |
| **改编** | 强调情感渲染 | 强调可视化动作+物理交互 |
