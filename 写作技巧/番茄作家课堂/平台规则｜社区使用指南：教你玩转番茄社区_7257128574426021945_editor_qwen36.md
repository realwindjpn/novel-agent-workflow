# 《科武纪元》编辑学习官｜社区规则提炼与执行手册

## 1 课程核心判断（≤6条）
1. **社区即留存引擎**：书圈/段评/粉丝群直接挂钩追读率与推荐池权重，互动数据正向反哺流量分发。
2. **UGC是免费宣发**：书圈打通本章讨论，鼓励同人图文/短视频二创，优质内容可跨圈层传播。
3. **红线零容忍**：严禁作者与读者对骂（双方同罚），恶意差评必须走举报/禁言流程，情绪化下场必损数据。
4. **互动需制度化**：作者空降、段评回复、动态更新是低成本维持热度的标准动作，非可选福利。
5. **私域有门槛与风控**：粉丝群需签约+1000粉，必须设管理员并定期考核，防剧透/防引战是底线。
6. **平台分发逻辑透明**：段评“神想法”获阅读器曝光，书圈内容聚合展示，互动频次决定作品社区活跃度评级。

## 2 可执行编辑规则（基于社区机制映射）
*注：原文为社区运营指南，以下规则将平台交互逻辑转化为正文创作与编辑标准。*

| 维度 | 可执行规则 |
|:---|:---|
| **开篇** | 前3章必须预留≥1处“段评触发点”（反常识设定/强悬念/高张力台词），引导读者长按发段评，激活初始互动权重。 |
| **节奏** | 每10-15章设置剧情断点或阵营选择，为书圈提供集中讨论周期；避免平铺直叙导致社区沉默。 |
| **冲突** | 剧情冲突需逻辑闭环，避免“为虐而虐”引发恶意差评；争议点通过书圈/动态理性释疑，正文绝不硬刚或夹带作者情绪。 |
| **人物** | 核心角色需具备≥2个易传播标签（标志性动作/口头禅/视觉特征），降低读者二创门槛，适配书圈生图与短视频剪辑。 |
| **题材** | 科幻/武学体系需提供“可拆解规则”（非纯黑箱），激发书圈战力推演与设定考据；短故事/热点稿需强化单点情绪爆点，适配段评碎片化传播。 |
| **改编** | 每章至少预留1个高画面感分镜或金句，天然适配书圈短视频切片；伏笔回收需留痕，便于读者在书圈做“剧情推理”长帖。 |
| **平台规则** | 严格执行“三不两要”：不互骂、不刷评、不无视举报；要定期空降答疑、要善用禁言（5人/周）与加精。后台举报单需附详细违规理由，审核判定前作者零介入。 |

## 3 科武适配：可用点、不可硬套点
**可用点**
- **科武体系天然适配书圈推演**：基因锁/机甲武学/能量回路等设定具备可量化、可对比属性，极易引发读者在书圈进行“战力排行”“机制拆解”。
- **科幻悬念驱动段评活跃**：未知文明信号、AI逻辑悖论、维度跃迁异常等设定，可直接转化为段评“神想法”与书圈推理帖，提升互动率。
- **战斗分镜反哺二创**：科武交战的机械结构、能量轨迹、躯体异变具备强视觉性，读者自发剪辑/绘图可形成免费流量矩阵。

**不可硬套点**
- ❌ 不可为迎合段评频繁打断硬核设定铺陈。科幻逻辑需完整自洽，避免“碎片化水字数”导致长篇架构崩塌。
- ❌ 不可将书圈同人/嗑CP倾向反向修改主线。科武长篇需保持世界观稳定性，读者二创仅作社区活跃参考，不干预核心剧情走向。
- ❌ 粉丝群不可饭圈化运营。科幻长篇铁粉靠“设定揭秘/世界观补完/技术推演”维系，非靠发福利或过度剧透。

## 4 编辑检查表（10条以内）
- [ ] 每章是否预留≥1处“段评触发点”（悬念/反常识/强情绪）？
- [ ] 书圈/动态是否每周≥2次作者空降或剧情答疑？
- [ ] 恶意差评是否已走后台举报流程，且作者正文/评论区零对线？
- [ ] 核心人物是否具备≥2个易传播的视觉/台词标签（适配二创）？
- [ ] 科武设定是否提供可拆解的“推演空间”（非纯黑箱）？
- [ ] 每10章是否设置书圈讨论钩子（断章悬念/阵营选择/战力突破）？
- [ ] 粉丝群是否已配置管理员并明确群规（防剧透/防引战）？
- [ ] 动态发布是否附带书卡/设定图，且避开正文核心剧透？
- [ ] 段评“神想法”是否被记录并用于后续剧情微调（非颠覆）？
- [ ] 禁言额度（5人/周）是否用于处理持续引战/恶意刷屏账号？

## 5 对作家角色的输入要求
| 维度 | 输入标准（科武向） |
|:---|:---|
| **动作链** | 战斗/操作需符合“科武逻辑链”（例：神经接驳→能量过载→肌肉撕裂→武技释放），步骤清晰可拆解，便于读者在段评逐帧分析与推演。 |
| **物理反馈** | 每次科武交互必须有可量化的环境/躯体反馈（例：机甲关节液压声、基因药剂代谢灼痛、重力场扭曲导致的视觉畸变），增强段评“画面感”与二创素材质量。 |
| **代价** | 力量体系必须绑定明确代价（例：超频燃烧寿命、义体排异、算力透支导致记忆碎片化），避免战力通胀引发书圈“体系崩坏”争议。 |
| **钩子** | 章末断点需绑定“未解变量”（例：未知信号源、敌对阵营底牌、系统异常提示），直接驱动读者进入书圈发帖推理或长按发段评。 |
| **读者预期** | 科幻长篇需维持“设定兑现率”（伏笔回收率≥70%），武学升级需符合“阶梯可测”原则；社区互动中，作者需以“世界观架构师”身份回应，而非“情绪安抚者”。 |
