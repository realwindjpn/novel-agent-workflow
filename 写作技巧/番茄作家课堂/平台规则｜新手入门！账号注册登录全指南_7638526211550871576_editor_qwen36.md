# 《科武纪元》编辑学习官｜平台规则学习报告

## 1 课程核心判断（≤6条）
1. **强实名绑定**：作者账号必须使用本人身份证办理的手机号，虚拟号/特定号段受系统风控拦截。
2. **跨端账号互通**：番茄与头条、西瓜、懂车帝等同属字节体系，关联账号封禁将直接阻断番茄作者注册。
3. **密码规范刚性**：仅支持8-20位数字+大小写字母组合，禁用任何符号。
4. **换绑分端隔离**：原号可用仅支持电脑端（需跳转头条验证）；原号停机仅支持手机端（实名找回）。
5. **防连点风控**：注册失败触发“访问频繁”时，强制冷却24小时，反复点击将延长限制。
6. **账号即资产**：注册/登录/换绑流程的稳定性直接决定长篇连载、短故事发布、热点稿追更的基建安全。

## 2 可执行编辑规则（按文章实际内容取舍）
- **平台规则**：
  - 入驻前必查关联APP（头条/西瓜/懂车帝等）状态，封禁需先解封。
  - 注册/换绑严格区分PC端与APP端权限，禁止跨端混操作。
  - 密码设置避开符号，仅用字母+数字；定期备份实名信息与找回路径。
  - 遇系统拦截立即停止操作，遵守24小时冷却期，避免触发二次风控。
- **开篇/节奏/冲突/人物/题材/改编**：
  - 本文纯为账号基建与流程指南，**未涉及**文学创作技法。按“实际内容取舍”原则，上述维度不适用本文。长篇/短故事/热点稿的创作规则需另参平台《写作技法》《推荐算法》《题材风向》专项指南。

## 3 科武适配：可用点、不可硬套点
- **可用点**：
  - **长篇连载**：账号安全=IP资产安全。实名与防封是《科武纪元》百万字连载不断更的底层保障。
  - **短故事/热点稿**：手机端APP适合碎片化排版与快速发布；电脑端适合长篇数据监控与批量换绑。按端分工可提升追热点效率。
  - **风控意识**：避免频繁修改资料、异地登录或异常操作，防止连载期被系统误判违规导致推荐断流。
- **不可硬套点**：
  - 本文无创作方法论，不可将“手机号段/密码规则/换绑流程”强行映射为科幻设定、人物动机或剧情节奏。
  - 平台注册规则不决定题材上限或改编潜力。《科武纪元》的“科幻+武道”核心需依赖内容质量、更新稳定性与算法推荐，而非账号注册流程。

## 4 编辑检查表（10条以内）
- [ ] 注册手机号是否为本人实名？是否避开170/165/147/167/171/192等受限号段？
- [ ] 头条/西瓜/懂车帝等关联账号是否处于正常状态？（无封禁/限流记录）
- [ ] 密码是否符合8-20位、仅含数字+大小写字母（无符号）？
- [ ] 换绑操作是否按“原号可用→电脑端”/“原号停机→手机端”正确分流？
- [ ] 注册遇阻是否已停止连点，并等待满24小时？
- [ ] PC端与APP端登录状态是否已做好权限区分（长篇码字用PC，短稿/互动用APP）？
- [ ] 账号实名信息是否与后续稿费结算/税务信息一致？
- [ ] 是否已备份账号找回凭证（身份证照片、原手机号、绑定邮箱）？

## 5 对作家角色的输入要求
- **动作链**：明确“触发条件→执行步骤→结果反馈”三步闭环。科武战斗/科技操作需拆解为可视觉化的连续动作，禁止用“他爆发了”“系统启动了”等模糊概括替代具体过程。
- **物理反馈**：所有超能/机甲/武道设定必须附带符合基础物理或自洽设定的感官反馈（重量、温度、阻力、痛觉、能量衰减、环境破坏），杜绝“无介质释放”与“无视惯性”。
- **代价**：每次能力跃升/关键决策必须绑定明确损耗（寿命、资源、社会关系、理智值、装备耐久）。长篇需建立“代价账本”，短故事/热点稿需在首章内亮出代价，避免战力通胀与情绪透支。
- **钩子**：每章结尾必须埋设“未解变量”（悬念/危机/反转/新线索）。短故事/热点稿需在首屏300字内抛出核心冲突或反常识设定，强制拉高停留率。
- **读者预期**：严格对齐番茄算法偏好：开篇3章定调（科幻基底+武道爽点），节奏保持“3章一小爆，10章一大爆”；短故事需单线闭环，热点稿需蹭准情绪标签（如“技术反噬/底层逆袭/规则重构”），不偏离平台主流受众的即时满足阈值。
