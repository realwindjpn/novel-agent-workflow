# 《还不会起书名吗？》编辑学习笔记 — 服务于《科武纪元》

来源：番茄作家课堂 · 写作技巧 · 2023-01-10
原文链接：https://fanqienovel.com/writer/zone/article/7186865162572267580

---

## 1. 课程核心判断（≤6条）

1. **书名 = 流量过滤器**：决定点击与否，也决定来的是不是"对的人"。宁可筛掉非目标读者，也不要拉高跳出率。
2. **强相关 > 强噱头**：标题党短期拉点击、长期掉口碑（差评+流失）。书名必须能在前3章被内容兑现。
3. **书名要在第一眼完成三件事**：交代题材/设定、抛出核心爽点或矛盾、留一个未解钩子。
4. **热词是基础设施**：题材词（重生/系统/末世）、身份词、人设词、核心梗词，是平台读者的"检索语义"，不用就等于自断流量。
5. **反差与具体数字制造记忆点**：抽象形容词易被淹没，具体数字、具体冲突、情绪词（救命！/出大事了！）更易被记住和转发。
6. **15字以内、不生僻、可口播**：标准是"读者能向别人安利出去"。

---

## 2. 可执行编辑规则

### 2.1 开篇（首章 vs 书名的契约）
- 书名抛出的"钩子点"必须在**前3章**兑现可见，否则即被判定为标题党。
- 若书名含数字/具象设定（如"修仙五分钟，无敌两千年"），首章就要给出该数字对应的物理画面，不能只在对话里提。
- 若书名带情绪词（"救命！""出大事了！"），开篇第一幕就要复现该情绪场景。

### 2.2 节奏
- 书名暗示的"低代价→高收益"对比，决定升级节奏曲线：标题越夸张，章节内的升级反馈周期越要短。
- 书名信息密度 ≈ 章节信息密度的索引；标题里塞了几个信息点，正文每章也要至少推进同等数量的钩子。

### 2.3 冲突
- 书名优先呈现"对立关系"或"身份反差"（死对头掐腰索吻、相府嫡女被退婚、史莱姆吊打巨龙）。
- 主冲突必须能用一句反差式短语概括；如果概括不出，说明主线没立住。

### 2.4 人物
- 主角"金手指/特殊能力"可直接进书名（《我的右眼是神级计算机》模式），等于把人设外置成检索词。
- 配角/关系也可作书名（"奶爸"、"娘亲"、"舅舅"），强化情感锚点。
- 人设词限定在已被市场验证的标签库内（腹黑/霸道/废柴/禁欲…）至少要命中1个。

### 2.5 题材
- 题材词必须显式出现或被强暗示：让"不爱这个题材的人"主动放弃点击，提升读完率。
- 多题材融合时，把更稀缺的那个放前面（"穿书+七零+工资数字"中，"穿书七零"先定位，"八十八份工资"做钩子）。

### 2.6 改编（标题→封面→简介→章名 一致性）
- 书名里的关键词必须复用为：封面文案主词、简介首句关键词、前5章章名中的至少2个。
- 任何宣传位（推荐位文案、短视频钩子）都从书名拆词复用，而不是另起一套。

### 2.7 平台规则（番茄取向）
- 命中"题材+身份+核心梗+人设"四类热词中**至少2类**。
- 字数 ≤ 15 字，无生僻字，口语化可读。
- 七种典型结构任选其一为骨架：人物型 / 符号型 / 主线型 / 分类型 / 悬念型 / 爽点型 / 抽象搞怪型。
- 数字、感叹号、冒号是合法且推荐的"视觉锚点"，但每个书名最多用一种。

## 3. 科武适配

### ✅ 可用点（直接照搬）
- **分类型骨架**："科武"本身就是稀缺融合题材词，应作为前缀长期复用（《科武纪元：xxx》《科武：xxx》），训练读者搜索习惯。
- **金手指入题**：主角的"科学化武道系统/数据化丹田/物理引擎化经脉"等可直接做副标题（参照《修仙，我的眼睛能看见灵药生长度》）。
- **反差对比**：科技 vs 武道、实验室 vs 宗门、公式 vs 心法，天然适合"修仙五分钟，无敌两千年"式对仗结构。
- **具体数字**：科幻自带量化优势——光年、纳米、G、瓦特、年——比玄幻的"亿万"更易制造记忆点。
- **短故事/热点稿**：用情绪词+具象冲突的女频式标题模板（"救命！我的论文导师是星际战犯"），适合站外引流稿。

### ⚠️ 不可硬套点
- **甜宠/年代/赘婿/四合院**等热词不要为了流量硬塞进《科武纪元》主书名——会污染题材定位，吸引来的读者读完率必崩。
- **抽象搞怪型**（"很合理吧？"句式）会削弱"纪元"级长篇的史诗感，仅适合衍生短篇或番外。
- **数字党噱头**在硬科幻里要守住设定自洽：写"修炼五分钟突破光年"必须有对应的物理设定支撑，否则被硬核读者一句话拆穿。
- **"出大事了！""救命！"**等女频情绪词与科武主调不符，仅留给短故事/热点稿使用，不进主作品线。

## 4. 编辑检查表（≤10条）

- [ ] 书名 ≤ 15 字，无生僻字，可口播
- [ ] 命中"题材/身份/核心梗/人设"热词至少 2 类
- [ ] 含一个具象钩子（数字/反差/金手指/情绪词），且只用一种视觉锚点
- [ ] 套用七型骨架中的明确一型，不混搭超过两型
- [ ] 钩子在前 3 章内必被正文兑现
- [ ] 与封面主词、简介首句、至少 2 个前期章名 关键词一致
- [ ] 题材定位清晰，能主动筛掉非目标读者
- [ ] 主冲突可被书名一句话概括
- [ ] 不出现污染"科武"调性的女频/年代/市井热词（短稿除外）
- [ ] 念三遍能记住，能向朋友转述

## 5. 对作家角色的输入要求

写作前由"作家角色"按书名/章名反推，向编辑提交以下五项，不达标则不进入正文：

1. **动作链**：书名钩子对应的主角动作序列（≥3 步，含触发→执行→收束），例如"扫描灵药生长度→选择最优采摘时机→兑换为修为数值"。
2. **物理反馈**：每个动作的可观察现象（声、光、热、压、数据读数），杜绝纯"气感""灵识"式抽象描写；科武世界必须能被仪器测到。
3. **代价**：高收益必须配可量化代价（寿命/算力/精神力/材料/社会关系），写明单位与回复周期。"修仙五分钟无敌两千年"式标题必须配套写出"五分钟"消耗了什么。
4. **钩子**：每章结尾留一个与书名同构的小钩子（同样的反差/数字/对立结构），形成"书名—章名—章末钩"三层共振。
5. **读者预期管理**：明确这一章兑现书名的哪一个承诺、新欠下哪一个承诺、何时偿还（章号区间）。欠账清单由编辑维护，超过 5 章未偿还即触发预警。
