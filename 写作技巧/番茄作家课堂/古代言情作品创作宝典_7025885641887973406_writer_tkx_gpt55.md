# 《科武纪元》作家OS补丁  
## 来源课程：古代言情作品创作宝典  
## 补丁目标：把“古言编辑规则”转成《科武纪元》可执行写作指令

---

## 0. 本补丁一句话

每章必须写成：

> **危机触发 → 主角决策 → 分步执行 → 物理反馈 → 付出代价 → 局部胜利/失败 → 新危机钩子**

禁止写成：

> 设定解释 → 人物聊天 → 环境铺陈 → 主角突然开挂解决。

---

# 1. 作家OS新增核心执行规则

## 1.1 开篇规则

### 执行动作

第1章必须完成以下内容：

1. 主角正在遭遇具体危机。  
   - 被追杀  
   - 机甲失控  
   - 基因检测失败  
   - 星舰坠毁  
   - 遗迹封锁  
   - 武道考核濒临淘汰  

2. 主角有一个清晰目标。  
   - 活下来  
   - 抢到名额  
   - 救出某人  
   - 修复核心  
   - 夺回身份  
   - 破解遗迹门禁  

3. 金手指/核心能力露头，但不能完全解释。  
   - AI残片短暂接管0.7秒  
   - 古武经脉异常共振  
   - 能看见能量回路裂缝  
   - 机甲同步率异常飙升  
   - 遗迹文字自动翻译一行  

4. 首章末尾必须给读者一个追读钩子。  
   - 系统提示异常  
   - 敌人身份反转  
   - 更高权限敌人出现  
   - 主角能力暴露  
   - 倒计时开启  

### 禁止动作

- 禁止先写世界观历史。
- 禁止开局介绍星域、帝国、宗门、科技树超过3段。
- 禁止人物一口气出场超过3个核心角色。
- 禁止主角首章无目标、无危机、无行动。

---

## 1.2 章节动作链规则

每个关键场景必须写成：

> **触发 → 判断 → 选择 → 执行 → 反馈 → 代价 → 结果**

### 模板

```text
触发：敌方无人机锁定主角脊柱芯片。
判断：主角发现掩体只能撑9秒。
选择：不逃，反向接入废弃炮塔。
执行：拆线、短接、压缩算力、强行开火。
反馈：掌心被电弧烧穿，炮塔轴承尖叫，墙体震裂。
代价：AI算力过载，主角视野出现黑斑。
结果：击落无人机，但暴露了非法权限。
钩子：远端主控发来一句话——“终于找到你了。”
```

### 失败模式

| 失败写法 | 修正方式 |
|---|---|
| 主角意念一动，敌人全灭 | 拆成锁定、蓄能、规避、反击、命中五步 |
| 金手指直接给答案 | 只给一半信息，剩下靠主角判断 |
| 打斗全是“很强”“恐怖”“震撼” | 写冲击波、骨裂、护甲报警、温度、血氧下降 |
| 反派突然降智 | 让反派根据已有情报做合理应对 |
| 胜利无代价 | 加资源消耗、伤势、暴露、冷却、关系破裂 |

# 2. 金手指补丁

## 2.1 金手指必须设限

每次使用金手指，至少绑定一种限制。

### 可选限制

| 金手指类型 | 限制 | 代价 |
|---|---|---|
| AI辅助 | 算力阈值、权限封锁、冷却时间 | 头痛、记忆丢帧、脑神经灼伤 |
| 机甲同步 | 能源不足、神经负荷、零件损坏 | 肌肉撕裂、反应迟钝、机体报废 |
| 古武功法 | 经脉承压、气血反噬、境界不稳 | 内伤、寿命折损、短暂失明 |
| 遗迹解析 | 语言残缺、权限不足、陷阱误导 | 被标记、触发守卫、精神污染 |
| 基因能力 | 激活时间短、环境依赖、药剂副作用 | 发热、器官衰竭、意识混乱 |

## 2.2 金手指使用节奏

### 正确节奏

```text
第一次：只救命，不解释。
第二次：发现限制。
第三次：主动设计用法。
第四次：付出更大代价换关键胜利。
第五次：能力升级，但引来更大敌人。
```

### 禁止节奏

```text
第一章获得系统。
第二章横扫同级。
第三章越级秒杀。
第四章所有人震惊。
第五章无敌。
```

# 3. 冲突补丁

## 3.1 每章冲突必须来自欲望对立

写冲突前先填：

```text
主角想要什么：
敌人想阻止什么：
双方争夺的资源是什么：
失败后主角会失去什么：
敌人为什么不能退让：
```

### 科武可用冲突源

| 冲突类型 | 可写内容 |
|---|---|
| 生存 | 氧气、能源、药剂、撤离名额 |
| 资源 | 星核、遗迹权限、武道名额、芯片数据 |
| 阶级 | 下层区无资格进入军校/上层垄断技术 |
| 技术 | AI伦理、基因改造、机甲专利封锁 |
| 文明 | 外星遗迹苏醒、星域战争、文明清洗 |
| 身份 | 主角被判定为废品、叛徒、实验体、非法AI宿主 |

## 3.2 反派行动规则

反派不能只是坏，要能推动主线。

### 反派行动阶梯

```text
轻视 → 试探 → 打压 → 封锁资源 → 借规则杀人 → 亲自下场 → 背后势力露出
```

### 反派拉仇恨动作

- 抢主角名额。
- 断主角补给。
- 拿无辜者当实验材料。
- 修改考核数据。
- 用制度合法碾压主角。
- 逼主角在“救人”和“晋级”中二选一。

### 失败模式

| 失败 | 修正 |
|---|---|
| 反派无脑挑衅 | 给他明确利益：名额、资源、遮掩罪证 |
| 反派频繁嘴炮 | 让他动手断路、封号、扣资源 |
| 反派突然变蠢 | 让他误判主角金手指，而非智商掉线 |
| 反派洗白太早 | 中前期保持压迫感，后期再补动机 |

# 4. 人物口吻补丁

## 4.1 主角口吻

《科武纪元》主角建议口吻：

> 冷静、短句、判断优先、少抒情、多行动。

### 示例

不推荐：

```text
他望着浩瀚星河，心中涌起无尽悲凉。
```

推荐：

```text
他看了一眼氧气表。
剩余四分钟。
悲伤没有用。
他拆下左臂护甲，插进了供能槽。
```

## 4.2 AI/系统口吻

### 口吻关键词

- 精准
- 冷淡
- 数据化
- 有隐瞒
- 不主动煽情

### 示例

```text
【警告：神经负荷132%。】
【继续接管将造成不可逆损伤。】
【建议：放弃当前目标。】
```

主角回应：

```text
“建议驳回。”
```

## 4.3 战友/搭档口吻

### 功能

- 不抢主角戏。
- 提供情报、战术补位、情绪对照。
- 和主角形成理念碰撞。

### 示例

```text
“你再往前一步，机甲会散架。”

“那就让它散在敌人脸上。”
```

## 4.4 反派口吻

### 中前期

- 高压
- 轻蔑
- 规则感
- 不是疯狗，是掌握资源的人

### 示例

```text
“你不是输了。”
“你只是从一开始，就没有参赛资格。”
```

## 4.5 配角口吻

配角必须有功能。

| 配角类型 | 口吻 | 功能 |
|---|---|---|
| 技术员 | 快、碎、术语多 | 给装备限制/修复倒计时 |
| 军官 | 短命令 | 推动任务/制造压力 |
| 同伴 | 情绪外放 | 衬托主角冷静 |
| 老师/导师 | 留半句话 | 给线索，不直接解答 |
| 黑市商人 | 算账口吻 | 提供资源，也制造债务 |

# 5. 段落节奏补丁

## 5.1 移动端段落规则

### 每段建议

- 1到3行。
- 动作段短。
- 信息段拆碎。
- 对话不要连续闲聊超过5轮。
- 每800到1200字要有一次变化：发现、受挫、反击、信息差、代价。

## 5.2 场景节奏模板

### 战斗段

```text
短句。
动作。
警报。
反馈。
再动作。
代价。
反转。
```

示例：

```text
红点锁上眉心。

陆沉侧滚，肩甲擦过地面，火星拉出半米。

第一枪落空。

第二枪提前封路。

他没有再躲，左手插进破损炮塔的控制槽。

【非法接入。】
【倒计时：3秒。】

“够了。”
```

### 解谜段

```text
线索出现 → 主角误判 → 小代价验证 → 找到规则 → 反向利用 → 引出更大谜团
```

### 升级段

```text
突破诱因 → 身体/装备承压 → 差点失败 → 找到关键变量 → 成功一半 → 留下隐患
```

### 感情/羁绊段

```text
共同危机 → 战术互补 → 一方承担代价 → 信任增加 → 不表白，先并肩活下来
```

# 6. 章末钩子补丁

## 6.1 每章结尾必须选一种钩子

| 钩子类型 | 用法 |
|---|---|
| 危机钩 | 门开了，里面站着更强敌人 |
| 信息钩 | 主角发现自己的编号在死亡名单上 |
| 身份钩 | AI说：你不是第一次来这里 |
| 倒计时钩 | 反应堆将在十分钟后熔毁 |
| 背叛钩 | 队友通讯记录被篡改 |
| 奖励钩 | 遗迹权限开放，但只开放了“囚笼区” |
| 代价钩 | 主角赢了，但右手失去知觉 |
| 地图钩 | 星图亮起一片从未记录的区域 |

## 6.2 章末句式模板

```text
就在这时，沉寂三年的AI忽然开口。

【检测到原始宿主。】

陆沉停住。

屏幕上，弹出了他的尸检报告。
```

或：

```text
他刚走出考场，所有灯光同时转红。

广播响起。

“编号D-77，违规觉醒。”
“即刻清除。”
```

# 7. 发布/包装/风险门禁补丁

平台规则不写成理论，转成发布前检查。

## 7.1 书名门禁

### 书名必须包含

- 题材元素
- 主角核心能力
- 爽点方向
- 冲突目标

### 可用方向

```text
废土机甲：我用古武破解星舰
基因废体觉醒后，AI叫我原始宿主
星际武道：从修复破机甲开始登神
被逐出军校后，我接管了遗迹主脑
```

### 禁止方向

```text
星河旧梦
长夜微光
他从尘埃中来
归墟之上
```

问题：太文艺，题材和爽点不直给。

## 7.2 简介门禁

简介必须回答：

```text
主角是谁？
开局遭遇什么危机？
获得/暴露什么能力？
要完成什么目标？
最大看点是什么？
```

### 简介模板

```text
陆沉，边境矿区最低等维修兵，因基因评级为F被军校除名。

星兽潮爆发当夜，他被困在报废机甲里，意外唤醒一枚旧纪元AI核心。

AI只给了他0.7秒接管权限。

0.7秒，够他躲过死亡。
也够他看见这个时代最大的谎言。

从废机甲到星舰核心，从古武经脉到文明遗迹。
他要用被淘汰的身体，撕开被垄断的星空。
```

## 7.3 标签门禁

标签必须和正文一致。

### 可选标签

- 科幻
- 星际
- 机甲
- 武道
- 升级
- 热血
- 废柴逆袭
- 遗迹
- AI
- 基因进化
- 学院/军校
- 战争

### 风险

| 风险 | 门禁 |
|---|---|
| 标签写机甲，正文长期宅斗/聊天 | 下架重改标签或重写正文节奏 |
| 简介承诺复仇，正文20章不复仇 | 前10章必须推进复仇线 |
| 写升级文，10章无战力变化 | 每3到5章给一次能力/资源/地位变化 |
| 感情线压过主线 | 感情只服务于任务、代价、选择 |
| 大段设定说明 | 拆进战斗、考核、交易、审判中 |

# 9. 章节自检清单

每章写完后检查。

## 9.1 基础通过线

- [ ] 本章是否有明确事件，而不是只聊天/铺设定？
- [ ] 主角是否有目标？
- [ ] 本章是否出现阻力？
- [ ] 主角是否做了关键选择？
- [ ] 是否写出执行过程，而不是一句话跳过？
- [ ] 是否有装备、身体、环境、数据反馈？
- [ ] 是否有代价？
- [ ] 是否有结果变化？
- [ ] 是否推进主线？
- [ ] 章末是否有钩子？

## 9.2 科武质感检查

- [ ] 有没有机甲/武道/AI/基因/遗迹等核心元素参与剧情？
- [ ] 有没有用动作和数据代替空泛形容？
- [ ] 金手指有没有冷却、限制或副作用？
- [ ] 战斗是否分步：锁定、移动、防御、反击、命中？
- [ ] 设定是否嵌入冲突，而不是单独讲课？
- [ ] 科技和武道规则是否前后一致？
- [ ] 升级是否有资源消耗？
- [ ] 敌人是否根据利益行动？
- [ ] 搭档是否辅助主角而非抢戏？
- [ ] 感情/羁绊是否服务主线？

## 9.3 留存检查

- [ ] 开头300字是否有危机/目标/异常？
- [ ] 每1000字内是否有一次新变化？
- [ ] 本章是否兑现一个小爽点？
- [ ] 本章是否留下一个新问题？
- [ ] 读者是否有理由点下一章？

# 10. 短故事/狼人篇可借点

## 10.1 可借点

### 1. 开篇即危机

狼人篇适合直接开：

```text
月圆夜。
主角发现自己手上有血。
门外，猎狼人已经开始敲门。
```

对应科武短篇：

```text
警报响起。
主角发现自己的基因编号被改成了“非人类”。
清除队已经到门口。
```

### 2. 身份悬念

狼人篇可用：

- 谁是狼人？
- 主角是不是狼人？
- 队友是否被感染？
- 村庄规则是否在撒谎？

科武可转成：

- 谁是AI宿主？
- 主角是不是实验体？
- 队友是否被遗迹污染？
- 联邦规则是否在掩盖真相？

### 3. 倒计时结构

狼人篇：

```text
天亮前必须找出狼人。
```

科武短篇：

```text
反应堆熔毁前必须找出内鬼。
```

### 4. 小场景高压

狼人篇适合封闭空间：

- 古堡
- 村庄
- 雪夜旅店
- 地下祭坛

科武可替换：

- 坠毁星舰
- 废弃空间站
- 封锁实验室
- 遗迹隔离区

### 5. 章末钩子

狼人篇可用钩子：

```text
尸体旁边，留下了主角自己的牙印。
```

科武可替换：

```text
监控回放里，杀人的那台机甲，驾驶员编号是主角。
```

## 10.2 不可硬套

- 不要把狼人篇写成纯悬疑慢推理。
- 不要长时间无行动。
- 不要只靠气氛吓人。
- 每一段恐怖/悬疑都要变成具体威胁：感染、追杀、封锁、倒计时、身份暴露。

# 11. 科武长篇可借点

## 11.1 金字塔升级

长篇必须有阶梯。

### 示例

```text
矿区维修兵
↓
军校候补生
↓
机甲实战兵
↓
遗迹权限持有者
↓
星舰指挥官
↓
星域战争核心人物
↓
旧纪元真相继承者
↓
文明天花板挑战者
```

## 11.2 阶段任务串联

每卷一个大目标，每3到5章一个小目标。

### 卷结构模板

```text
第一卷：活下来，进入军校
第二卷：拿到机甲资格，发现AI异常
第三卷：进入遗迹，破解旧纪元权限
第四卷：星域战争，主角身份曝光
第五卷：文明真相，挑战技术垄断
第六卷：终局回收，主角重构文明规则
```

## 11.3 长篇防崩规则

| 风险 | 控制方式 |
|---|---|
| 战力崩坏 | 每个境界/科技代差提前设天花板 |
| 地图乱跳 | 换地图必须由任务触发 |
| 主线变散 | 每卷目标都服务终极目标 |
| 反派断档 | 反派势力阶梯化：个人→学院→军部→财团→文明级 |
| 金手指太强 | 每次升级同步增加代价和敌人等级 |
| 设定太多 | 每章最多投放1到3个设定点 |

# 12. 可直接复制的章节生成指令

写章节时，可直接调用：

```text
请按《科武纪元》作家OS补丁生成本章。

要求：
1. 开场300字内出现危机、目标或异常。
2. 使用“触发→判断→选择→执行→反馈→代价→结果”动作链。
3. 金手指必须有限制、冷却或副作用。
4. 至少写出3类物理反馈：装备、身体、环境、数据。
5. 主角口吻冷静短句，AI口吻数据化，反派口吻高压且有利益目的。
6. 每800到1200字出现一次变化。
7. 章末必须留下危机/信息差/倒计时/身份反转钩子。
8. 禁止大段设定说明、无代价开挂、反派降智、感情线喧宾夺主。
```

# 13. 最终执行口令

以后写《科武纪元》章节时，默认执行：

```text
不开局讲设定。
不无代价开挂。
不让反派降智。
不让感情压主线。
不让胜利无损耗。

每章必须有：
危机、目标、动作链、物理反馈、代价、收益、钩子。
```

核心节奏：

```text
压迫 → 判断 → 行动 → 受损 → 破局 → 暴露更大危机
```
