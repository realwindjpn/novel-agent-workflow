# 第 58 章：数据追踪

第二天早上八点，南天门计划内部服务器。

陈思琪的手指在键盘上敲下最后一行查询指令。回车。

屏幕上的进度条瞬间跑满。

“权限数据库访问中……正在匹配特征……"

她面前的桌上放着两样东西：一杯已经凉透的速溶咖啡，还有一张刚刚打印出来的嫌疑人名单。

名单很薄，只有三行字。

但在这一千多人的基地里，这三行字重得像铅块。

林星辰推门进来，身上还带着早操后的汗味。

“找到了？”

“找到了。”陈思琪把屏幕推过去，“我用了五个交叉条件进行过滤。”

屏幕上显示着五个漏斗状的筛选层：

1. **2018 年合肥项目组核心成员**（基数：42 人）
2. **目前仍在基地内任职**（剩余：18 人）
3. **持有三级及以上数据访问权限**（剩余：9 人）
4. **过去三个月内访问过‘融合实验’相关日志**（剩余：4 人）
5. **访问时间与铁幕服务器活跃时间重叠**（剩余：1 人）

漏斗的最底下，只有一个名字。

**方致远。**

林星辰盯着这个名字看了三秒。

“方致远。”他念了一遍，“方宁的哥哥？”

“对。”陈思琪点开那个人的档案，“方致远的职位是热控测试组高级工程师。他的权限是他弟弟方宁申请的——理由是‘协助调试原型机散热参数’。”

“方宁知道这事吗？”

“申请表上是方宁的电子签名。但我查了审批日志，那个签名是在凌晨两点提交的。而那个时间点，方宁正在医院陪他母亲做透析。他不可能操作终端。”

“盗用签名。”林星辰的声音冷了下来，“或者是方宁根本没仔细看就签了字。”

“不管哪种情况，方致远都越界了。”

陈思琪调出访问日志。

“看这里。昨晚凌晨一点到三点，也就是我们在阿塔卡要塞下载数据的同时，基地的 FS-07 号服务器上也有一个外部连接请求。请求的来源 IP 被伪装成了内网的打印机，但 MAC 地址指向方致远的工作站。”

“他在偷数据。”

“不仅如此。”陈思琪又拉出一张图表，“过去半年里，方致远的工作站每隔六周就会向外发送一次加密数据包。大小都在 50MB 左右。正好是一块核心芯片的设计图纸大小。”

林星辰拉过椅子坐下。

“六周一次。这就是铁幕的‘心跳’。”

“对。每六周更新一次南天门的最新进展。这次我们要下载的‘融合’数据，正好赶上了下一个心跳周期。”

“他想偷我们的核心成果。”

“他想偷，我们就给他。”陈思琪转过头，看着林星辰，“但不是真的数据。”

林星辰明白了她的意思。

“你要做诱饵。”

“对。”陈思琪从抽屉里拿出一张空的加密硬盘，“我准备一份假的‘融合’数据包。里面的参数我会微调——把散热阈值调低 5%，把能效比调高 10%。看起来更完美，但一旦用于实际制造，会让芯片在满负荷运行时过热熔断。”

“这能追踪到他？”

“这份假数据里，我会埋一个水印。不是普通的水印，是频域水印。只要他打开文件，水印就会触发一个隐蔽的后台进程，记录他的操作习惯、键盘指纹，甚至是通过摄像头捕捉他的面部特征。”

“这能作为法庭证据吗？”

“能不能作为证据不重要。”陈思琪把硬盘在手里转了一圈，“重要的是，这能帮我们摸出他背后的上线。方致远只是个搞技术的，他没能力把数据送出太行山。他一定有个‘快递员’。”

林星辰点了点头。

“赵刚那边我去说。今晚就开始放诱饵。”

他站起身，准备离开。走到门口时，他停了一下。

“陈思琪。”

“嗯？”

“这件事，暂时别告诉方宁。”

陈思琪的手指停在键盘上。

“我知道。”她说，“他是方宁的哥哥。但在国安介入之前，他首先是一个嫌疑人。”

林星辰没再说话，推门出去了。

陈思琪看着屏幕上那个名字，轻轻叹了口气。

她把那份只有三行字的名单折好，放进口袋。

猎杀开始了。
