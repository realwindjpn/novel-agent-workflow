## 1. 课程核心判断（≤6条）

1. **悬疑爆款 = 反常切入 + 高密度危机 + 闭环反转 + 沉浸压迫**，四要素缺一即掉档。
2. **反常必须挂在日常上**：纯猎奇不抓人，"日常场景里的一处错位"才能瞬间立悬念。
3. **节奏靠"死亡循环"驱动**：危险→排查→再险→深查，循环即节奏，背景与环境描写要为它让路。
4. **反转必须前置伏笔、首尾闭环**，否则就是烂尾；真相揭晓位建议落在结尾 1/3 处。
5. **氛围由空间和视线制造**：封闭/半封闭空间 + 主观视角的虚实错觉 = 心理恐惧的标准配方。
6. **环境细节要参与解谜**，不能只做背景板；空间细节即线索是高级感的分水岭。

## 2. 可执行编辑规则

### 开篇（前 300 字内必须完成）
- 第一屏出现**一处反常**：时间错位、人物认知错位、空间错位、身份错位，任选其一。
- 反常的**载体必须是日常物件/行为**：外卖、短信、视频电话、搬家、过马路、考场、机场。
- 反常呈现方式两选一：
  - **被动得知**（电话/旁人/档案/新闻告知）；
  - **主角主动行为**触发悬念（开窗、回头、查看手机）。
- 第一屏内必须出现**第一次代价**（死亡、被抓、被否定身份均可），不要铺垫。

### 节奏
- 采用 **"危险降临→线索排查→再度遇险→深度排查"** 四拍循环，每拍升级一次危机等级。
- 一个短故事内**至少 3 轮死亡/濒死循环**；递进式（升级）与循环式（重置）可叠加。
- **砍掉一切与"解谜+求生"无关的信息**：人物背景、世界观铺陈、环境抒情，能删则删。
- 信息密度判断：每 500 字必须有一次"新疑点 / 新代价 / 新反转"。

### 冲突
- 冲突源头双轨：**外部递进危机**（事件升级）+ **认知撕裂**（主角所见 ≠ 他人所见）。
- 不要写"调查冲突"，要写"求生冲突"——主角不是侦探，是猎物。
- 每轮冲突后必须有**新增疑点 + 排除疑点**，让读者感到"在前进"。

### 人物
- 主角需要**清晰的行动目标**（找人、回家、活下去），不能被动观察。
- 强化主角**自身能力/行动力**，避免靠路人给答案推动剧情。
- 配角功能化：要么递送反常信息，要么承担"权威否定"（警察/老师/档案）制造撕裂。

### 题材
- 优选**带话题性的日常场景**：高考、支教、返乡、婚礼、加班、毕业、过年。
- 反常方向优先级：①生死循环 ②身份/存在否定 ③时空错位 ④群体消失。
- 借社会热点 / 节日 / 民俗包壳，自带流量与代入。

### 改编（短→长 / 长→短）
- 短故事的反转密度不可直接搬入长篇，长篇需把"四拍循环"拉成**章节循环**而非段落循环。
- 短故事砍背景的原则**反向不适用**于长篇——长篇必须给世界观留位。
- 短故事的"闭环反转"做长篇时，应转化为**单元卷的小闭环**，主线另设。

### 平台规则（番茄短故事品类）
- 导语（前 5 段）即"试读决定追读"，反常必须前置到导语内。
- 标题=钩子：**身份+反常事件+结果反转**结构（参考"支教八年…警察：你的学生不是人"）。
- 立意升华放结尾，但不允许牺牲反转冲击力换鸡汤。

## 3. 科武适配

### 可用点（直接吸收）
- **反常切入法**：科武世界里"修武者日常"+ 一处规则错位（功法反噬、识海异声、师门档案不符），是悬疑卷开篇模板。
- **死亡循环节奏**：适用于"秘境卷""试炼塔卷""幻阵卷"，每层一次濒死+一次线索升级。
- **认知撕裂**：主角看见的宗门 / 他人记忆中的宗门不一致——可承载"历史被改写"的科幻硬核设定。
- **空间细节即线索**：丹炉裂纹、阵旗朝向、星图缺位，作为解谜钩子比口述设定高级。
- **结尾立意升华**：科武体系的"代价观"（修为=寿元、科技=人性）天然适配反转后的人性收束。

### 不可硬套点
- ❌ **整篇砍背景**：科武是长篇 + 自洽体系小说，砍掉功法/科技/势力会塌世界观，只能在悬疑单元卷内局部加速。
- ❌ **导语强行车祸/重生**：短故事的极端反常（瞬死重生）放到长篇主线会破坏修武成长曲线，仅适合支线短篇或番外。
- ❌ **闭环反转 = 主角已死/被弃**类底牌：科武主角承担成长主线，不能用"其实早死了"的反转骨架，可改造为"其实是某段记忆/某具化身"。
- ❌ **纯心理恐惧封闭空间**：与科武"战斗+探索"基调冲突，应改造为"封闭秘境/废弃科研舰"等带战斗出口的半封闭。
- ❌ **配角功能化到底**：长篇需要群像，不可全部沦为反常信息播报器。

## 4. 编辑检查表（10 条以内）

- [ ] 导语 300 字内是否出现"日常载体 + 一处反常"？
- [ ] 第一屏是否已出现首次代价（死亡 / 否定 / 撕裂）？
- [ ] 全文是否有 ≥3 次危机循环，且每次升级？
- [ ] 每 500 字是否至少 1 个新疑点/新反转/新代价？
- [ ] 是否删除了与"解谜 + 求生"无关的描写？
- [ ] 主角是否有明确行动目标，而非被动接受信息？
- [ ] 真相揭晓是否落在结尾 1/3，且前文存在可追溯伏笔？
- [ ] 场景是否为封闭/半封闭，且空间细节参与解谜？
- [ ] 是否存在"主角所见 ≠ 他人所见"的认知撕裂？
- [ ] 结尾立意是否在不削弱反转的前提下完成升华？

## 5. 对作家角色的输入要求

> 给写手交稿前必须自检以下五项，缺项打回。

### 动作链
- 每个悬念节点必须由**主角的一个具体动作**触发或终结：开窗、回头、摸手串、打电话、过马路。
- 禁止"心想 / 觉得 / 似乎"推动剧情；用动作驱动认知变化。

### 物理反馈
- 反常感必须落到**可感知的身体反应**：手串温度、视频里的蓝天、凌晨一点的窗外、车祸的冲击。
- 心理恐惧需有外化锚点（视线感、温度、声音、光影），不允许纯内心独白堆叠。

### 代价
- 每一轮循环都要写出**明确代价**：死亡、记忆抹除、身份注销、亲人异变。
- 代价必须**不可逆或需高昂赎回**；零代价的悬念会让读者出戏。

### 钩子
- 章末/段末挂钩三选一：**新尸体 / 新身份否定 / 新反常物件**。
- 标题与导语必须形成**身份 + 反常事件 + 结果反转**的三段结构。

### 读者预期
- 前期预期：**"接下来谁会死 / 死法是什么"**——必须满足。
- 中期预期：**"真相到底是什么"**——靠拼图式线索逐步喂。
- 结尾预期：**"反转 + 情感冲击"**——反转必须呼应前文，情感必须承担立意而非取代反转。
- 严禁三种掉粉操作：①真相靠新角色嘴炮揭晓 ②反转无伏笔 ③结尾鸡汤盖过悬念。
