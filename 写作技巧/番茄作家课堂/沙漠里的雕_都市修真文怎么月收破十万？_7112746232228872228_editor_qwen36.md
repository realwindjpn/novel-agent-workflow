# 《科武纪元》编辑学习报告：基于《沙漠里的雕》专访提炼

## 1 课程核心判断（≤6条）
1. **单体系优于双体系**：并行两套力量/境界体系极易造成读者认知混乱，坚持单一主线升级是长篇留存的基础。
2. **人设需“极致+反差”**：核心性格标签必须写到极致（如极端洁癖/极致沙雕），同时内核需具备杀伐果断的爽感支撑。
3. **完读率具长尾增长性**：传统长篇/非脑洞类完读率非开局定型，可通过节点运营与内容质量实现滞后拉升。
4. **开篇必须“强轰动”**：首章需以反常识事件或高视觉冲击设定破局，快速建立阅读期待。
5. **数据驱动与编辑协同**：平台推荐逻辑依赖完读率与在读数据，编辑的数据判断比作者主观感觉更准确，需依数据定去留/完结节点。
6. **创作目标具象化**：以收入/物质目标替代抽象字数目标，能有效维持长篇连载的持续输出动力。

## 2 可执行编辑规则（按原文内容提取）
| 维度 | 规则 | 原文依据 |
|:---|:---|:---|
| **开篇** | 前3章必须抛出“轰动性事件/反常识设定”，快速建立核心悬念与金手指预期。 | “开篇一定要轰动…设定把学校给炸了” |
| **节奏** | 10万/30万/50万字节点前1-2万字必须前置小高潮；卡点断章配合强引导标题。 | “提前一两万字布置小高潮”“标题加‘必看’‘暴露身份’” |
| **冲突** | 剧情卡顿直接引入新反派/新势力推动；严禁双体系并行导致战力/设定混乱。 | “不知道怎么写了的时候，就再蹦出来一个反派”“下次只写一个境界” |
| **人物** | 主角标签极致化+内核杀伐果断；配角/反派需有鲜明记忆点，避免扁平。 | “性格写到极致”“沙雕+讲段子，但杀伐果断” |
| **题材** | 贴合平台风向（幽默玩梗+升级流）；设定做减法，优先保障阅读流畅度。 | “番茄读者喜欢搞笑幽默带点梗”“传统类完读涨空间大” |
| **平台规则** | 分成签约初期数据低属正常；完读率需隔期观察；依据编辑数据建议决定切书/完结时机。 | “日收几分到几十块”“传统完读隔一段时间再看才准”“编辑看数据很准，劝切或劝留” |
| **改编** | 原文未涉及影视/短剧改编逻辑，暂不提取。 | - |

## 3 科武适配：可用点 vs 不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **力量体系收敛**：科武背景易陷入“科技树+武道境界”双轨并行。需明确主升级轴（如：基因锁/灵能同步率/机甲阶位），另一体系仅作环境设定或辅助手段。
- **节点运营策略**：10w/30w/50w卡点前置高潮、标题强引导词，完全适用于科幻长篇的算法推荐与留存拉升。
- **人设反差构建**：科幻主角可设定“极致理性/数据控/强迫症”，但内核保留“果断破局/护短/反杀”的爽点；幽默可转化为“硬核物理梗/工程吐槽/AI冷幽默”。
- **开篇奇观化**：用“轨道电梯崩塌/深空信号劫持/古武遗迹现世”替代都市文的“炸学校”，3章内抛出核心危机与金手指。

### ❌ 不可硬套点（需规避）
- **“随时蹦反派”推进剧情**：科幻长篇依赖严密的世界观、科技演进逻辑与伏笔回收。随机添加反派极易导致战力通胀、逻辑崩坏。
- **“不写大纲/细纲”**：科武设定涉及物理规则、势力博弈、技术迭代，纯靠灵感开车必崩。必须保留设定集、科技树演进表与主线细纲。
- **过度沙雕玩梗**：科幻/科武需保持一定的严肃性与设定自洽。梗密度需控制在20%以内，避免削弱史诗感与硬核氛围。

## 4 编辑检查表（10条以内）
1. [ ] 开篇前3章是否出现“强视觉奇观/反常识危机”并明确抛出核心悬念？
2. [ ] 科武/科技体系是否单一清晰？有无双轨并行导致读者认知混乱？
3. [ ] 主角核心标签是否“极致化”？是否具备“表面特质+内核杀伐”的反差？
4. [ ] 10万/30万/50万字节点前1-2万字是否已埋设小高潮/爆点？
5. [ ] 关键章节标题是否使用强引导词（如“必看/真相/突破/反杀”）？
6. [ ] 剧情卡顿处是否通过“新势力介入/旧伏笔回收”推进，而非机械降神？
7. [ ] 玩梗/幽默元素是否控制在合理比例，不破坏科幻世界观严肃性？
8. [ ] 每章结尾是否留有明确钩子（悬念/危机/奖励预告）？禁用开放式抒情断章。
9. [ ] 数据反馈（完读率/在读）是否处于平台推荐期正常波动？有无盲目切书？
10. [ ] 是否定期与编辑对齐数据节点，依据留存曲线调整后续节奏与完结时机？

## 5 对作家角色的输入要求
| 维度 | 输入要求（科武向） |
|:---|:---|
| **动作链** | 战斗/升级场景必须呈现“感知→决策→执行→结果”完整物理/能量交互链条。禁用“意念秒杀”，需拆解科武交锋步骤（例：锁定目标→能量过载→装甲承压→破甲→反冲）。 |
| **物理反馈** | 每次技能释放/境界突破必须伴随可量化的环境/躯体反馈（重力异常、金属疲劳、神经灼痛、辐射读数飙升、冷却液沸腾）。用硬反馈替代空泛的“气势爆发”。 |
| **代价** | 升级/使用底牌必须支付明确代价（寿命折损、装备报废、阵营暴露、理智值下降、资源枯竭）。代价需在前文铺垫，并在后续3-5章内产生连锁剧情影响。 |
| **钩子** | 章末钩子需绑定“即时悬念”或“利益预期”（倒计时3秒/未知信号接入/资源点坐标解锁/敌舰跃迁波动）。严禁情绪化断章或无指向性留白。 |
| **读者预期** | 严格遵循“铺垫→兑现→超预期”循环。科幻读者预期“设定自洽+逻辑推演”，需3章内建立规则，10章内首次兑现；后续每次破局需比预期多一层反转（例：以为靠武力破局，实为利用物理定律/信息差/系统漏洞）。 |
