# 热点文章：Cursor 锁死模型入口 × 算力垄断现实版

## 事实核查（用于支撑文章，防喷）
1. **事件**：Cursor 限制/移除自定义模型（Custom Model）选项，用户无法再随意接入第三方或本地模型。
2. **背景**：2026年3月，Cursor 被曝旗下"自研模型"疑似套壳国产开源模型 Kimi（Moonshot AI），创始人回应称"忘记更新说明"。此前2025年11月，Composer 1 也被指与 DeepSeek 高度相似。
3. **推论**：平台限制自定义模型，是为了强制用户使用其"自研"（实为低成本套壳）模型，从而最大化利润并控制数据流向。用户失去了选择权，变成了平台算力网络上的"数字矿工"。
4. **小说关联**：《科武纪元》第460/476章——天算集团从"开放接入"到"算力私有化"，切断用户选择权，建立封闭的算力帝国。

## 小黑盒版本（约500字，有理有据）

### 标题
Cursor 限制自定义模型了？这剧情我在小说里刚写过

### 正文
昨天想切个本地模型跑点私密代码，发现 Cursor 的自定义模型入口灰了。

一开始以为是 Bug，后来去翻社区和更新日志，确认不是偶然故障，而是官方动作：第三方模型接入通道被彻底关死。以后只能用平台指定的那几家，或者它自家的"Cursor Model"。

这事结合最近的几个新闻看，味道就不对了。

**事实一：套壳风波**
3月21日，Cursor 被社区扒出，其号称"自研"的模型，底层疑似是国产开源的 Kimi。创始人回应"忘记更新说明"。这已经是第二次了，去年11月的 Composer 1 也被指跟 DeepSeek 高度相似。

**事实二：计费变更**
去年6月，Cursor 改成了按 Token 用量计费。这本来是好事，但结合"限制自定义模型"来看，逻辑就通了：平台先用低价的套壳模型跑你的请求，收你 Pro 版的钱，赚中间的差价。

如果允许你自定义模型，你自己接 OpenRouter 或者本地 Ollama，成本可能只有几分钱，Cursor 就赚不到这个差价了。

**这不就是我小说《科武纪元》里写的剧情吗？**
卷十里，天算集团一开始也是打着"开放算力网络"的旗号，吸引所有人接入。等生态建成了，开始搞"标准认证"，最后直接把公共接口关了，只留自己的私有通道。

当时有读者留言："太科幻了，哪有这么蠢的垄断。"

现在看，现实比小说走得更快。垄断不需要动武，只需要在软件的设置里，把一个选项灰掉。

当你的 IDE、代码补全、甚至代码审查，都只能调用平台指定的模型时，你以为你在写代码，其实你是在给平台的算力帝国打工。你产生的每一行代码、每一个 Prompt，都成了训练它下一个"套壳模型"的燃料。

我不是反对商业化，企业赚钱天经地义。但作为开发者，我们确实正在失去对工具的控制权。

最好的科幻不是预测未来，是把正在发生的事提前写出来。这大概就是《科武纪元》能写到现在的原因。

你们用 Cursor 的，有没有觉得最近模型变"笨"了？或者发现只能用它指定的模型了？评论区聊聊。
