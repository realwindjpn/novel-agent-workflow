## 一、核心执行指令（即时可用的动作规范）

### 1. 动作链闭环四步法
```
意图宣告 → 发力执行 → 传导呈现 → 结果验收
```
**操作规程**：
- 每场战斗/操作必须走完四步，禁用三步以内
- 意图宣告：角色说出或显化目标（"我要击穿XX护甲"/基因链锁定XX序列）
- 发力执行：具体施为过程（非"威力巨大"，需是"主炮充能87%→光束聚焦→瞄准接点偏移0.3°"）
- 传导呈现：能量/力量/信息的传递路径（能量流向、裂纹扩展、神经信号传导时间戳）
- 结果验收：可量化后果（护甲形变率、伤亡数字、战术态势变化）

**禁用词库**：`极大`、`极快`、`威力惊人`、`一瞬间`、`轻松`（替换为具体参数）

**失败模式**：缺少传导步骤 → 读者感知"突然赢了/突然输了" → 爽感断档

---

### 2. 物理反馈双轨制
每次力量释放/机甲碰撞/武技施展，必须同时呈现：
| 物理反馈轨 | 要求 |
|:---|:---|
| **直接破坏面** | 装甲形变率（%）、裂纹深度（cm）、能量烧蚀痕迹、破片飞散轨迹 |
| **间接环境响应** | 重力场扭曲读数、大气电离浓度、地面承压超标警报、附近设备过载状态 |

**最低触发阈值**：≥2项可观测反馈
**检查点**：写完动作后追问"读者能看见什么具体变化？"

**科武长篇借点**：科幻设定中"技术参数"天然适配此规则，可直接引入设定集参数

---

### 3. 代价绑定即时制
所有越级/爆发/高阶科技使用，必须在当章或下一章兑现代价，禁用"记账式代价"。

| 代价类型 | 兑现时限 | 示例 |
|:---|:---|:---|
| **冷却代价** | 当章内 | 神经链路过载→3分钟内无法二次同步 |
| **损耗代价** | 次章内 | 超频输出→基因链断裂前兆（后续3章战力减半伏笔） |
| **战术暴露** | 当章内 | 特殊机甲模式激活→敌我识别码暴露 |
| **资源枯竭** | 当章内 | 核心能源消耗30%→后续战役资源调度受限 |
| **装备过载** | 下一章前 | 重型装甲极限负荷→关节驱动单元需大修 |

**绝对禁区**：无代价开挂（读者会直接弃文并在评论区定性为"毒点"）

**短故事借点**：短篇需代价更集中、更即时，单章内必须闭环

---

### 4. 章末钩子四选一强制
每章末尾必须抛出以下类型钩子之一，禁用纯情绪留白：

| 钩子类型 | 科武向变体 | 兑现时限 |
|:---|:---|:---|
| **信息差悬念** | 新技术/秘密/势力意图首次透露 | 3-5章内必须反转或追加信息 |
| **资源争夺** | 关键物资/地盘/人才的争夺态势 | 下一章必须推进争夺进程 |
| **阵营异动** | 势力关系变化/背叛/结盟动向 | 3章内必须有实质动作 |
| **技术瓶颈** | 科研节点/突破临界点/实验失败 | 5章内必须给进展或新障碍 |

**兑现铁律**：钩子不在承诺时限内兑现，读者会定性为"挖坑不填" → 评分下滑 → 推荐降权

---

### 5. 短平快清障节奏法
核心冲突/误会/小反派必须遵循：
- **小副本/支线**：3章内解决
- **中型误会/信息差**：5章内收束或反转
- **拒绝模式**：`误会拖几百章`、`同一个坑绊倒三次`

**例外申报**：若需延长冲突，必须有明确"正当理由"（如：世界观需要、埋伏笔节奏需要）且需在当章内给读者明确预期

## 二、写作前任务卡字段更新

在开写新章节/副本/卷之前，必须填充以下字段：

### 【必填项】

| 字段名 | 填写内容 | 验收标准 |
|:---|:---|:---|
| **本章节核心动作链** | 写清楚意图→发力→传导→结果 | 四步齐全，无模糊词 |
| **物理反馈清单** | 列出本章节≥2项可观测反馈 | 具体参数/破坏面 |
| **代价绑定点** | 标注本章节/下章节代价兑现位置 | 代价类型+时限 |
| **章末钩子类型** | 四选一 + 预计兑现章节 | 兑现时间不超过5章 |
| **避雷检查** | 自查：降智反派/虐主/机械降神/战力崩坏 | 无四项毒点 |

### 【增补项-科武向】

| 字段名 | 填写内容 |
|:---|:---|
| **战力锚定点** | 本章涉及的战力等级/科技层级（对照设定集） |
| **逻辑自洽承诺** | 本章是否有新设定/例外？需在设定集中预留逻辑接口 |
| **评论区预警词** | 本章是否涉及读者高频投诉点？（战力崩塌、逻辑漏洞） |

## 三、章节自检清单

每章完成后，对照以下10条逐项检查：

- [ ] **1. 四步闭环**：意图→发力→传导→结果，是否每步都有？是否有禁用词（极大/极快/一瞬间）？
- [ ] **2. 双轨反馈**：是否提供≥2项可观测的物理反馈（参数/破坏面/环境响应）？
- [ ] **3. 代价兑现**：本章代价是否在当章或下一章兑现？类型是否明确？
- [ ] **4. 钩子检查**：章末钩子是否为四选一类型？是否标注兑现时限？
- [ ] **5. 毒点扫描**：是否出现降智反派/虐主/机械降神/无代价开挂？
- [ ] **6. 节奏验证**：核心冲突/误会是否在5章内可收束或反转？
- [ ] **7. 战力锚定**：本章战力表现是否与设定集一致？无越级？
- [ ] **8. 信息密度**：开篇3章是否直击核心卖点？无冗余背景说明？
- [ ] **9. 悬念衔接**：本章钩子是否与下章开头衔接顺畅？
- [ ] **10. 读者预期**：本章是否兑现了开篇承诺（不降智、不拖沓）？

## 五、平台规则转译

### 5.1 发布策略

| 现言规则 | 科武向转译 |
|:---|:---|
| 稳定更新是算法喂养前提 | 科武读者对"断更/请假"容忍度更低，稳定日更+固定时间（如晚8点） |
| 推荐期前数据无参考价值 | 科武前10万字数据是逻辑自洽的试金石，有预警价值但需屏蔽焦虑 |
| 评论区高频词影响推荐池 | 科武读者高频词：硬核、逻辑自洽、爽点密集、设定严谨 → 需在行文中前置满足 |

### 5.2 包装要点

| 维度 | 科武向包装要求 |
|:---|:---|
| **书名** | 类型标签+核心卖点（例：《星际武神：从废铁到神》），15字内，含关键词 |
| **简介** | 核心冲突+力量体系+爽点承诺（不降智、不拖沓），200字内，禁用"详见正文" |
| **封面** | 视觉冲击力优先（机甲/战斗/星际场景），避免纯人物特写（科武读者偏好场景） |
| **标签** | 科幻/玄幻/热血+核心元素标签，蹭热点标签但需与正文匹配 |

### 5.3 风险门禁

| 风险类型 | 触发条件 | 应对策略 |
|:---|:---|:---|
| **战力崩坏** | 读者评论出现"战力崩塌"关键词 | 当章或次章必须给出解释/限制条件 |
| **逻辑漏洞** | 设定前后矛盾被读者指出 | 24小时内响应，设定集修正，后续章节打补丁 |
| **断更降权** | 超过48小时无更新 | 提前存稿支撑，请假条需给读者明确复更时间 |
| **毒点扩散** | 评论区出现"虐主/降智"高频投诉 | 当机立断修正，后续章节调整人设/情节 |
| **同质化风险** | 读者反馈"和XX文太像" | 检查元素组合，强制加入差异化设定 |
