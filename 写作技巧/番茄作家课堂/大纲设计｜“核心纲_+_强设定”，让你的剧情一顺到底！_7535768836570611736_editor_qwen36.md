# 《科武纪元》编辑学习官：大纲设计规则提炼

## 1 课程核心判断（≤6条）
1. **大纲即导航底线**：合格大纲为500-2000字精炼主线，必须明确“开篇状态-核心目标-终局状态”，字数/势力膨胀后无大纲必致逻辑失控。
2. **核心纲分表里**：表层是剧情骨架（防跑偏），里层是核心卖点/读者安利标签（定调性），动笔前必须双轨锁定。
3. **设定即强规则**：世界观为第一优先级，所有设定为主观强加的铁律，抛出后不可自我反驳（吃书）。
4. **OKR路径唯一性**：目标(O)拆解的关键结果(KR)必须满足“可见、可实现、必要性”，按KR顺序推进必能达成O，剔除一切无效支线。
5. **剧情推进双引擎**：长线用OKR正向规划（如百万字节点），单卷/高潮用“倒推法”逆向填充铺垫，先定爆点再补逻辑。
6. **大纲非束缚是约束**：大纲不限制灵感，而是划定行文边界；所有情节必须在框架内产生张力，偏离即需修正导航。

## 2 可执行编辑规则
| 维度 | 规则（基于原文逻辑提取） |
|:---|:---|
| **开篇** | 前3章必须亮出“表层核心纲”（主角初始困境+明确目标+核心驱动力），禁止无效日常铺垫；开篇即定里层卖点标签。 |
| **节奏** | 采用“OKR节点控制法”：每10-30万字设一个阶段性O，拆解为3-5个KR。KR完成即节奏换挡，避免流水账；前10万字必须完成首个KR闭环。 |
| **冲突** | 冲突设计必须服务于KR。所有阻碍、反派、危机均为“完成O的必要途径”，剔除与主线目标无关的支线冲突；高潮需提前用倒推法预设。 |
| **人物** | 人物行为逻辑绑定“里层核心纲”。主角动机需与核心卖点强绑定；配角功能化，仅作为KR推进的“资源/阻碍/催化剂”存在。 |
| **题材** | 强设定优先于体系堆砌。先立世界观铁律，再填修炼/科技树；设定一旦抛出不可吃书，所有力量体系必须服从底层逻辑。 |
| **改编** | 核心纲的“里层卖点”需具备短剧/热点可视化潜力（强目标、强反转、高概念）；大纲需预留“名场面/情绪爆点”供分镜转化。 |
| **平台规则** | 匹配番茄推荐算法：首秀期（前10万字）KR达成速度直接挂钩留存率；每3-5万字设小高潮，10万字大闭环，断更/拖沓将触发流量断崖。 |

## 3 科武适配
### ✅ 可用点
* **OKR完美契合科武研发/突破逻辑**：如 `O=突破基因锁` → `KR1=获取稀有同位素` → `KR2=完成神经接驳手术` → `KR3=实战压力测试`。路径清晰，天然具备阶段性爽点。
* **强设定适用于底层法则**：科武世界需确立“能量守恒/技术代差/肉体改造率”等铁律，设定即伪科学自洽框架，后期不可随意推翻，保障硬核质感。
* **里层核心纲精准引流**：可定位为“硬核机甲+古武复苏的阶级逆袭”或“生物算法+武道进化的文明跃迁”，便于平台标签匹配与读者预期管理。

### ❌ 不可硬套点
* **玄幻KR模板不可直搬**：“游历大陆/结婚联姻/秘境夺宝”等需替换为“数据破解/资源争夺/阵营博弈/技术迭代”，科武冲突需基于利益链与技术壁垒。
* **境界体系易显儿戏**：避免纯数值膨胀（如“筑基→金丹”）。需转化为“技术权限等级/肉体改造阈值/算力代差”，否则破坏科幻严肃性。
* **百万字节点防设定堆砌**：科武长篇易陷入“抛设定-解释设定”死循环。需用“技术奇点/文明跃迁/阵营洗牌”替代传统换地图，控制信息密度。

## 4 编辑检查表（10条以内）
1. [ ] 核心纲是否≤2000字？是否清晰包含“开篇困境-核心目标-终局状态”？
2. [ ] 里层卖点是否可提炼为1句读者安利语？（如“硬核机甲+古武复苏的阶级逆袭”）
3. [ ] 世界观是否已确立3条以上“不可违背”的铁律？有无自相矛盾处？
4. [ ] 当前卷/阶段O是否明确？拆解的KR是否全部为达成O的“必要路径”？有无废笔？
5. [ ] 前10万字是否已闭环第一个KR？主角驱动力是否在开篇3章内具象化？
6. [ ] 预设高潮是否已用“倒推法”完成铺垫埋线？伏笔回收路径是否清晰？
7. [ ] 冲突设计是否剔除“为打而打”？所有反派/危机是否直接阻碍KR推进？
8. [ ] 科武设定是否完成“伪科学自洽”校验？（能量来源/技术瓶颈/社会结构）
9. [ ] 节奏节点是否匹配平台推荐周期？（每3-5万字设小高潮，10万字大闭环）
10. [ ] 大纲是否预留“短剧/热点改编接口”？（强视觉名场面、情绪爆点、话题标签）

## 5 对作家角色的输入要求
| 维度 | 输入标准（科武语境强制要求） |
|:---|:---|
| **动作链** | 必须提供“目标触发→决策→执行→受阻→破局”完整逻辑链。禁止跳跃式推进。科武场景需明确“技术/武技调用顺序”（例：扫描弱点→启动外骨骼→过载引擎→近身斩击）。 |
| **物理反馈** | 必须量化/具象化科武交互结果。禁止“光效一闪敌人倒地”。需写明“装甲凹陷深度/神经负荷值/能量溢出轨迹/环境破坏参数”，强化硬科幻质感。 |
| **代价** | 每次KR推进或越级破局必须支付明确代价。科武语境下为“硬件损耗/基因崩溃率/信用点透支/阵营信任破裂”，禁止无代价开挂或机械降神。 |
| **钩子** | 每章末/每卷末必须设置“悬念钩子”或“利益钩子”。需绑定未完成的KR分支（例：核心数据缺失/敌对势力突袭/技术反噬倒计时），强制拉动追读。 |
| **读者预期** | 开篇需通过“强设定+核心纲”建立明确预期（例：“期待主角用古武破解机甲防御”）。行文必须持续兑现或合理颠覆该预期，禁止中途更换核心卖点导致预期断裂。 |
