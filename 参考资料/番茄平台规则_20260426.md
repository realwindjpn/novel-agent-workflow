# 番茄小说平台规则与运营指南

> 学习日期：2026-04-26
> 学习模型：qwen3.6-plus
> 来源：Web搜索整理

---

## 1. 推荐算法机制

### 首秀机制
- **触发条件**：连载至 **8万~10万字** 时触发
- **流量测试**：推给初始流量（几千到几万人），数据表现决定生死

### 核心考核指标（按重要性排序）
1. **读完率/留存率**：最核心。重点考核读完第1章、第10章、第50章的比例
2. **加入书架率**：长期阅读意愿
3. **追读率**：每天阅读最新章节的人数占比。追读下滑→流量池停止晋级
4. **阅读时长**：单用户平均停留时间

### 推荐池晋级逻辑
初始流量池 → 10万量级池 → 50万量级池 → 100万+全站爆款池
每一级都是"赛马"，数据达标自动晋级，不达标则断流（切书）

## 2. 投稿要求和限制

### 字数要求
- **申请签约**：满 1万字 即可申请
- **正式审核**：通常写到 2万字 左右等待系统+人工审核
- **章节长度**：单章建议 **2000~3000字**（过长稀释完读率）

### 更新频率
- **保底**：每天至少1章
- **推荐**：日更 **4000字**（2章）
- **冲刺**：日更 6000~8000字
- **断更**：超过3天，算法判定作品进入休眠，流量大幅暴跌

### 敏感词与红线
- 涉政、涉黄、血腥暴力、邪教、反人类
- AI机器拦截+人工复审
- 同人/版权需授权

## 3. 读者画像和偏好

### 用户画像
- 核心用户涵盖全年龄段，下沉市场占比高
- 一二线年轻用户快速增长
- **阅读场景**：碎片化时间（通勤、睡前、如厕）
- **听书流量**：占总流量 **30%+**（AI听书+真人听书）

### 受欢迎题材
- 都市神豪、脑洞修仙、规则怪谈、年代重生、系统爽文、大女主复仇/搞钱
- **节奏**：极快。黄金三章必须出金手指/核心冲突，拒绝慢热
- **情绪价值**：主打"爽"，即时反馈，讨厌压抑和憋屈

### 常见毒点
- 水字数（无意义环境描写、重复心理活动）
- 虐主/送女
- 逻辑崩坏/烂尾
- **文青病**：作者过度炫技、辞藻堆砌（番茄大忌）

## 4. 签约和稿费规则

### 签约模式
- **分成签约**：绝大多数新人选择
- **买断/保底**：仅头部大神或历史成绩好者

### 收入构成
1. **广告分成**：核心收入，约 0.01~0.05元/有效阅读
2. **全勤奖**：月更12万字（日更4000字），普通600元/月，优质1000~1500元/月
3. **礼物打赏/付费章节**：头部书有

### 分成比例
- 净收益：**作者50% : 平台50%**

## 5. 对AI生成内容的态度

- **必须标注**：使用AI辅助创作必须勾选标注（中国《生成式人工智能服务管理暂行办法》要求）
- **严禁纯AI一键生成**：缺乏人工润色、逻辑混乱的"AI水文"会被算法识别并限制推荐
- **版权风险**：AI生成内容版权归属灰色，签约作者必须对原创性负全责
- **内容同质化**：AI写的书套路高度一致→读者疲劳→差评→算法降权
- **平台建议**：鼓励AI作为灵感辅助/大纲梳理/资料查询工具，**正文必须人工重写、润色和情感注入**

## 6. 对《科武纪元》的启示

| 规则 | 对我们的要求 |
|------|-------------|
| 每章2000-3000字 | 当前3000+字，符合最佳实践 |
| 快节奏/黄金三章 | "番茄里的起点文"定位需平衡：起点质量感+番茄节奏感 |
| 去AI腔 | 不仅审美，平台会天然降权同质化AI内容 |
| 每章末钩子 | 已执行，继续保持 |
| 30%+听书流量 | **短句+少长修饰=更适合朗读**，与莫仁风完全一致 |
| 日更4000字 | 我们的修改计划需考虑更新频率 |
| AI必须标注 | 我们使用AI辅助但正文人工重写，符合要求 |
