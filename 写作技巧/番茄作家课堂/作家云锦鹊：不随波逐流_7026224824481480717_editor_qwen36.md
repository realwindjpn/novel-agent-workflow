# 《科武纪元》编辑学习报告：基于《作家云锦鹊：不随波逐流》

## 1 课程核心判断（≤6条）
1. **反套路金手指＞满级开局**：带缺陷/故障的外挂（如死机系统）能天然制造阻力，延长成长线，提升长期留存。
2. **灵感需具象化落地**：宏大设定必须通过生活化细节（如卖方便面解困）切入，避免悬浮与空洞。
3. **细纲是长篇基建**：依赖备忘录+细纲管理剧情节点，是维持稳定更新、降低卡文焦虑的工程化手段。
4. **情绪重置优于硬写**：卡文期需主动切换输入源（喜剧/曲艺等）切断焦虑循环，而非强行推进剧情。
5. **算法逻辑匹配内容垂直度**：平台推荐机制重“完读率+互动”，不随波逐流、保持个人表达反而能跑出精准长尾流量。
6. **长篇是心态管理工程**：戒数据浮躁、抗波动、保完本率，是商业写作的基础纪律。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则提取 | 执行标准 |
|:---|:---|:---|
| **开篇** | 困境具象化+微创新破局 | 前3章必须呈现明确生存/资源困境，破局手段需“非标准”（如民用技术改装/低配工具），禁用天降神兵或一键满级。 |
| **节奏** | 阶梯式积累循环 | 采用“小胜→故障/反噬→解决→资源升级”循环节奏；每10-15章设置一次能力边界测试，避免跳跃式升级。 |
| **冲突** | 限制型阻力设计 | 冲突核心源于“金手指罢工/资源短缺/规则限制”，而非反派降智送人头；每次破局需付出可见成本。 |
| **人物** | 保留性格毛边 | 主角需有“非完美特质”（如战术偏执/偶尔误判/生活化习惯），通过“憋屈→试错→破局”建立成长弧光。 |
| **题材** | 垂直切口＞追热点 | 融合作者真实兴趣/生活经验做差异化（如美食/曲艺/手工），在主流赛道中做“微创新”而非全盘跟风。 |
| **改编** | 预留视听切片点 | 强视觉/强生活感设定（如故障提示音、改装过程、市井交易）需高频出现，便于短视频切片与有声化降维传播。 |
| **平台规则** | 算法加权三要素 | ①日更稳定（断更需提前留缓冲章）②前3章完读率定生死③题材标签垂直不跳频。数据波动期不盲目改大纲。 |

## 3 科武适配
### ✅ 可用点（直接迁移至《科武纪元》）
- **故障型外挂**：初代机甲引擎过热、AI战术模块延迟、义体神经排异、能量核心冷却死机，完美替代“死机系统”。
- **细纲+备忘录**：适用于管理科武长篇的硬核设定（科技树迭代、势力版图、武道境界、物理法则限制）。
- **生活化破局**：将“卖方便面”转化为“民用技术军用化/土法炼钢”（如用老式电磁炉改装聚变点火器、用废弃义体零件拼装外骨骼）。
- **不随波逐流**：避开纯赛博/废土/系统签到红海，聚焦“武道肉身+硬科幻装备”的融合逻辑，建立类型护城河。

### ⛔ 不可硬套点（需规避或重构）
- **市井赚钱逻辑**：“几钱几钱”“开面馆”不能直接套入星际/高武经济体系，需重构为“信用点配额/能量块黑市/军工订单竞标”。
- **古灵精怪迷糊人设**：若用于科武主线男主/群像，易削弱战斗严肃性与战术可信度；需调整为“技术宅偏执/战术冷静/实战经验型”。
- **纯生活灵感依赖**：听评弹/相声属个人解压习惯，科武创作需依赖科学推演、工程逻辑与资料库验证，不可用“生活灵感”替代设定严谨性。

## 4 编辑检查表（10条以内）
1. 开篇3章是否出现具象化困境及“非标准”破局手段？
2. 金手指/外挂是否存在明确限制或故障机制？
3. 细纲是否覆盖至30万字节点？科技树/武力升级是否有阶梯逻辑？
4. 主角性格是否有“毛边”（非模板化龙傲天/傻白甜）？
5. 每章结尾是否埋设明确钩子（悬念/危机/新线索）？
6. 科幻设定是否通过可感知的物理/生活细节落地（避免纯名词堆砌）？
7. 更新频率是否稳定？断更是否提前报备并留缓冲章？
8. 题材是否避开当前平台同质化红海（如纯系统签到/无脑爽文）？
9. 核心冲突是否源于“能力/资源受限”而非“反派强行送人头”？
10. 是否预留短视频/有声改编的高光切片点（强动作/强反转/强设定展示）？

## 5 对作家角色的输入要求
| 维度 | 编辑输入指令（写作执行标准） |
|:---|:---|
| **动作链** | 严格遵循“触发条件→执行动作→环境交互→结果输出”。禁止“意念一动直接生效”。例：启动义体→神经接驳痛感→能量过载警报→强制冷却。 |
| **物理反馈** | 所有超常能力必须伴随可观测的物理/生理反馈。例：高频振动刀切割装甲需描写金属疲劳纹路、反作用力震裂虎口、冷却液泄漏气味、骨骼微震。 |
| **代价** | 每次越级使用能力/科技必须支付明确代价（能量枯竭、器官负荷、信用点扣除、AI逻辑锁死）。代价需累积并强制影响后续剧情走向，不可“用完即忘”。 |
| **钩子** | 章末必须抛出“未闭合信息环”。例：系统死机前闪现的乱码坐标、敌方机甲残骸上的非制式徽记、主角体内突然激活的未知协议、资源配额突然清零。 |
| **读者预期** | 开篇承诺“科武融合+硬核成长”，中期兑现“技术迭代+战术博弈”，后期收束“世界观揭秘”。严禁中途切换为纯恋爱/无脑爽文，保持类型契约一致性；数据波动期不盲目迎合短期热点，以完本率为核心指标。 |
