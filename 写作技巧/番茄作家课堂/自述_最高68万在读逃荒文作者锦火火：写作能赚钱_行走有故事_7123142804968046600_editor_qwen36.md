# 《科武纪元》编辑学习官：锦火火创作方法论提炼

## 1 课程核心判断（≤6条）
1. **爆款非灵感驱动**：依赖“大纲前置+10万存稿+人设打磨”的工业化流程，拒绝“脑子一拍开书”。
2. **平台匹配决定流量基盘**：免费流量平台重“首日留存+连续追读”，需以读者视角预判题材市场容量。
3. **人设立住靠反差与细节**：成功人设=反套路标签（如穷世子/病娇皇帝）+剧情动作烘托，禁用白描堆砌。
4. **角色数量必须克制**：超百人必致笔墨稀释、伏笔断裂与读者流失，核心聚焦是长篇续航底线。
5. **开篇节奏决定生死**：主角成长线/核心冲突需极速前置，编辑反馈“节奏再快一点”是免费平台通用铁律。
6. **数据稳定后屏蔽焦虑**：推荐期后不看后台，专注剧情推进；以段评/章说反哺灵感，不盲改核心风格。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则 |
|:---|:---|
| **开篇** | 禁用易触发道德反感的陈旧套路（如“父不详”萌宝）；前2万字必须切入主线危机或核心设定展示；首日推荐需具备强情绪钩子或差异化标签。 |
| **节奏** | 存稿≥10万字防断更；连载期保持日更稳定；卡文时立即补细纲梳理前期伏笔；每3-5章设小高潮，每10章设大转折。 |
| **冲突** | 采用“反其道而行之”制造天然反差冲突；冲突解决需干脆利落（有仇当场报），符合爽文逻辑；避免长期压抑无释放。 |
| **人物** | 核心人物通过“特有动作/语言/性格”在剧情中反复强化；配角/龙套需有独立记忆点（一句话/一动作），但主线聚焦角色严格≤15人。 |
| **题材** | 热门基底（逃荒/种田/末世）需叠加差异化元素（特种兵穿越/反套路人设）；保留作者个人风格（脑洞大/元素融合），不因单点吐槽改核心设定。 |
| **改编** | 预留“情感爆点”章节（如异世相认/牺牲/突破）用于短视频切片/有声剧高潮；场景描写需具象化（风土/地貌/器物），便于视觉化转译。 |
| **平台规则** | 免费平台算法重“完读率+追读连续性”；开篇需强标签化适配推荐池；积极参与站内活动/大赛获取额外流量倾斜。 |

## 3 科武适配
### ✅ 可用点
- **大纲前置+存稿机制**：科幻设定复杂，必须提前构建世界观/武力体系/科技树，存稿防设定崩塌与后期吃书。
- **反套路人设**：替换“龙傲天/苦大仇深”标配，设计“高武低配/科技反噬/赛博修仙”等反差主角，制造天然戏剧张力。
- **节奏与开篇**：强制“动作开场+危机前置”，3章内展现科武核心冲突（如机甲vs古武、基因改造代价、星域资源争夺）。
- **人物控制**：科幻群像易臃肿，严格限制核心阵营人数，用“标志性装备/招式/战术习惯”强化记忆点。
- **平台逻辑迁移**：将逃荒文的“生存压力”替换为“资源枯竭/高维入侵/文明存续”，保留“强目标+快节奏+情绪爆点”的流量结构。

### ❌ 不可硬套点
- **萌宝/古言情感逻辑**：科武受众偏理性/硬核，过度依赖“亲情/萌宝”易显低幼，需替换为“战友羁绊/技术信仰/文明契约”。
- **无边界脑洞混搭**：科幻需基础逻辑自洽，不能纯靠“天马行空”堆砌，需有伪科学/物理规则/能量守恒支撑。
- **完全不看后台数据**：科幻连载试错成本高，需更频繁关注“追读率/段评/设定接受度”，及时调整硬核程度与解释密度。
- **行走采风直接套用**：科幻需“技术推演/文献调研/科学顾问”，非纯风景游记能支撑世界观可信度。

## 4 编辑检查表（10条以内）
1. 开篇前3章是否已抛出核心危机/科武设定，无冗长背景说明或设定倾倒？
2. 主角人设是否具备“反套路标签”且通过剧情动作而非旁白展现？
3. 核心出场角色是否≤15人？配角是否有独立记忆点且不喧宾夺主？
4. 是否存在易引发读者道德反感或逻辑断裂的陈旧套路？
5. 节奏是否满足“每3-5章一小高潮，每10章一大转折”？
6. 情感爆点是否预留了短视频/有声切片潜力（强情绪/强画面）？
7. 世界观/武力体系是否在前5万字内完成基础闭环，无后期吃书？
8. 存稿量是否≥10万字？大纲是否包含主线伏笔与细纲卡文预案？
9. 平台标签（科幻/高武/末世）是否与开篇内容强匹配，利于算法推荐？
10. 作者是否屏蔽数据焦虑，专注剧情推进，并定期收集段评优化后续？

## 5 对作家角色的输入要求
| 维度 | 输入规范（科武向） |
|:---|:---|
| **动作链** | 禁止“意念/对话”推动关键剧情。必须提供“环境触发→肢体反应→技能/武器释放→结果反馈”的完整物理链条。例：科武对决需写明“神经接驳延迟0.3秒→肌肉过载撕裂→机甲关节锁死→反冲力震碎护盾”。 |
| **物理反馈** | 所有超能/科技/武技必须伴随可感知的生理/环境代价。例：基因强化后需描写“体温骤升/血管凸起/代谢加速导致的饥饿感”；能量武器开火需有“后坐力传导/空气电离味/视网膜灼伤”。 |
| **代价** | 每次力量跃升或关键决策必须支付明确代价（非口头说明）。例：突破境界需“献祭某项感官/永久损伤神经突触/背负文明债务”；战术胜利需“牺牲僚机/暴露坐标/透支寿命”。 |
| **钩子** | 每章结尾必须埋设“未解悬念/即时危机/反常细节”。禁用“且听下回分解”。例：“他按下引爆器，但倒计时停在00:01——舱门外传来的是己方识别码的敲击声。” |
| **读者预期** | 开篇需明确承诺“核心爽点/主线目标”（如“30章内夺回母星控制权/揭开高维入侵真相”），并在后续每10章兑现一次阶段性预期。禁止“换地图重置战力”或“长期压抑无释放”。 |
