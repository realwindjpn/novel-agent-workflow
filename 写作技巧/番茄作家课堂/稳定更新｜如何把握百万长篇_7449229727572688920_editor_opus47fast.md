# 《稳定更新｜如何把握百万长篇》编辑学习笔记
> 主讲：徐二家的猫｜番茄作家课堂 2024-12-17｜适配项目：《科武纪元》长篇 + 短故事 + 热点稿

---

## 1. 课程核心判断（6条）

1. **新人崩盘的根因是"开局亢奋"**：把所有爆点、钩子一次性甩出，三十万字后必然思维枯竭、被迫降速，前后节奏断层导致弃书。
2. **节奏稳 > 节奏猛**：宁可牺牲前期密度，也要给读者一个可持续的阅读环境；高密度连读同样制造疲劳。
3. **百万长篇是"种植"而非"收割"**：分季节、分品种播种，让每个区段都有产出，而不是逼读者熬过三个季度只为一次大爆发。
4. **坑要双层嵌套滚动**：大坑套小坑，填一挖二，保证"前方有坑，手中有铲"——任何时点都可挖可填。
5. **不要给读者出选择题**：道德两难=强制读者站队，每道选择题=一次大规模流失。一本书20道选择题，流失可达80%+。
6. **"深度"是笔力够才能用的奢侈品**：没苦硬吃地拔高级感，是新人长篇的头号死法。

## 2. 可执行编辑规则

### 2.1 开篇（1–5章）
- 第1–3章：用**新奇切入点**完成代入，不堆设定。
- 第4–5章：**适度抛设定**，让世界观开始具象，但不交底。
- 评估口径：第一章是否有"读者愿意点下一章"的钩，而不是"作者觉得炸"的爆。

### 2.2 节奏（前30万字模板）
| 区间 | 任务 | 编辑动作 |
|---|---|---|
| 0–3w | 切入＋代入＋第一根钩 | 检查切入点新奇度、信息密度 |
| 3w | **短期目标式小爆发**，埋10w伏笔 | 验收：是否生出新的好奇 |
| 3–10w | 分批完善人设/世界观，氛围渐紧 | 不许塞大爆点 |
| 10w | **第一次大爆发** | 紧接重启新钩+给主角新动机+日常缓冲 |
| 10–30w | 略缓但不松；**每3–5w一个情绪小高潮，每章一个看点** | 章节级看点检查 |
| 30w | 第二次大高潮 | 自然过渡到30–50w |

### 2.3 冲突（判断题 ≠ 选择题）
- **可写**：A作恶证据闭环 → 主角清算 = 判断对错。读者只需点头。
- **不可写**：仇人有可怜娃、女主父亲是杀父仇人、爱情vs复仇——任何会让评论区分裂成两派的设置。
- **修复手法**：
  - 删掉那个"可怜的小孩/女主父亲"——让反派纯粹该死。
  - 把两难拆成两个独立角色：一个该杀的反一 + 一个共同复仇的同盟。
  - 道德灰色想保留？把它放进**配角支线**而非主角主线。

### 2.4 人物
- 主角不做"圣母 vs 狠人"反复横跳的事；其立场在每个冲突节点应**与多数读者同向**。
- 性格弧光走"动机升级"而不是"道德摇摆"。
- 添加**有趣配角**用于10–30w日常缓冲段，承担轻量情绪价值。

### 2.5 题材（男频向，女频参考）
- 设定分批释放，禁止"设定倾倒章"。
- 高频提供"小看点"——奇物、奇人、奇景、奇规则任选其一/章。

### 2.6 改编/热点稿迁移
- **短故事**：直接采用"无选择题"原则——反派纯恶、主角纯爽，最大化转化。
- **热点稿**：取课程"每段单拎都有看点"为段落级KPI；首段=切入钩，中段=小爆发，尾段=新钩留追。

### 2.7 平台规则（番茄向）
- 追读率依赖**评论区每日互动**与**固定花样**（梗、彩蛋、设定问答）。
- 章末钩 ≥ 每章一个；爆发后必须立刻起新钩，否则疲劳期=弃书期。
- 读完率守护线：全书零选择题 + 节奏不断层。

## 3. 科武适配

### ✅ 可用点
- **分批播种**契合科武体系：科技线、武道线、势力线、谜团线四田轮种，避免单线疲劳。
- **10w/30w 爆发模板**可直接做卷结构：第一卷收束=第一次力量/真相跃迁。
- **判断题化反派**：科武题材天然有"侵略种族/黑科技财阀/堕落宗门"等无争议恶役，用足。
- **坑套坑**适配科幻悬念：上层谜（文明真相）+ 中层谜（势力阴谋）+ 下层钩（本章战斗），三层滚动。
- **每章看点**用"新设定/新科技/新招式/新情报"硬性兑现。

### ⚠ 不可硬套点
- 科幻常用的**道德两难**（救一人 vs 救千万、AI是否有人格、文明取舍）= 选择题地雷，主线慎用，可降级到番外/配角支线。
- "高级感、文学性留白"在前百万字不要硬上，等到读者基本盘稳定后再做。
- 切入点"新奇"≠"硬核设定开场"——科武开篇仍要给读者**可代入的人和事**，而不是世界观PPT。
- 男主"蒙面式小聪明"在科武里很容易变成"理性算计反被读者骂冷血"，避开。

## 4. 编辑检查表（10条）

1. 第1–3章是否有"新奇切入点"且无设定倾倒？
2. 3w字处是否有短期目标式小爆发，并埋下10w伏笔？
3. 10w字爆发后，是否在3章内重启新钩+给主角新动机？
4. 10–30w段，平均每3–5w是否有一个情绪小高潮？
5. 是否做到**每章一个看点**（设定/招式/情报/角色任一）？
6. 当前章是否同时存在：未填的大坑×1、未填的小坑×1、新挖的坑×1？
7. 本卷有没有出现"道德两难型选择题"？若有，能否删可怜方/拆成两角色？
8. 主角立场在每个冲突点是否与多数读者直觉同向？
9. 反派是否"罪证闭环、该死无疑"？有无被强行洗白的描写？
10. 章末钩是否独立成立（脱离上下文也能勾人）？

## 5. 对作家角色的输入要求

为保证编辑可按上述规则审稿，作家在交稿时必须随章节附下列五项：

- **动作链**：本章主角动作序列（触发→决策→执行→结果），每步一句话，便于核对节奏与"无选择题"原则。
- **物理反馈**：科武体系下的具体可感反馈（能量读数、身体损伤、环境变化、设备状态），用于验证设定可信度与"看点"是否落地。
- **代价**：本章主角/势力付出的可量化代价（资源、关系、信息、伤势、时间）。无代价的爽 = 后期通胀。
- **钩子**：章末钩一句话 + 它对应的是**哪个坑**（大坑/小坑/新坑）+ 预计在第几章兑现。
- **读者预期**：本章想让读者产生的情绪（爽/紧张/好奇/温情/愤怒）+ 想让读者下一章期待的事件。若预期是"摇摆/分裂"，触发选择题预警，必须重写。

> 交付格式建议：每章附 5 行元数据头，编辑按检查表 1–10 逐项打勾后方可入连载队列。
