# 《科武纪元》编辑学习官｜格非《小说创作的“真”与“美”》萃取报告

## 1 课程核心判断（≤6条）
1. **“真”已非事实还原，而是观念博弈**：当代信息过载使小说丧失“真相传递”功能，拼凑新闻/现实无法支撑长篇厚度，必须回归“诚”（虚己、不预判、不替人物代言）。
2. **写实主义能量耗尽，同质化经验失效**：碎片化、内卷化生存无法提供托尔斯泰式的生命厚度，依赖媒体二手素材的写作必然丧失痛感。
3. **“美”的本质是陌生化/异质性**：剥离事物的工具属性，写出“第一次见到”的质感；时间距离与情感沉淀能催化陌生化，但创作需主动捕捉非常规视角。
4. **小说是“空的空间”，非观念传声筒**：真相与张力诞生于多元声音碰撞（复调），作者强行定调善恶或灌输立场会扼杀文本生命力。
5. **真与美互为表里**：无“诚”则美流于炫技与悬浮，无“陌生化”则真沦为流水账与说教。
6. **贴人物写，不贴自我写**：清空作者成见，让人物基于自身经验与局限做决策，苦难与不公需被诚实凝视而非粉饰。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 编辑规则（落地动作） |
|:---|:---|
| **开篇** | 首章必须交付1个“陌生化”场景或细节（反套路视角/非常规物象）。禁用抽象世界观说明书，用具体动作+感官反馈替代设定堆砌。钩子需携带情感振动或认知撕裂。 |
| **节奏** | 砍掉“同质化经验填充”（重复升级、无效日常、套路打脸）。节奏推进依赖“异质性事件”触发认知/情感转折，每3章必须有一次“认知刷新”防平台留存衰减。 |
| **冲突** | 摒弃脸谱化善恶对立。冲突内核设为“立场/认知碰撞”，让反派逻辑自洽、主角动机存疑。真相在交锋中浮现，禁止作者借角色之口强行输出价值观。 |
| **人物** | 拦截“贴自我写”段落。人物决策必须源于其自身经验、恐惧与欲望。编辑需标注“作者越界干预”痕迹，强制人物按自身逻辑行动。 |
| **题材** | 科幻/武学体系必须“落地于肉身与情感”。技术/功法禁止纯数值化或说明书式抛出，需通过陌生化细节（如梵高鞋写法）绑定角色生命史。 |
| **改编/平台规则** | 番茄算法重完读与互动。将“虚己/留白”转化为“高密度悬念+强情绪反馈”。长篇需保留“复调碰撞”内核，但必须压缩进单章强冲突中，避免纯文学式慢热导致跳出率飙升。 |

## 3 科武适配
### ✅ 可用点
- **武学/科技体系陌生化**：将灵能、机甲、基因锁等常见设定剥离“工具属性”，绑定生理代价、环境畸变与情感记忆，制造“第一次见到”的阅读震颤。
- **阵营博弈去脸谱化**：科武纪元多方势力采用“善中藏恶，恶中含善”逻辑。权谋线不靠降智推动，靠信息差与立场碰撞制造复调张力。
- **高概念落地于“诚”**：宏大科幻设定必须靠物理痛感、生理负荷、情感震颤锚定。不回避苦难与代价，拒绝悬浮爽感。

### ❌ 不可硬套点
- **“反全景叙事/写实主义耗尽”**：网文长篇需明确主线与阶段性目标，不能完全放弃结构规划与升级路径。需在“陌生化”与“清晰进度条”间找平衡。
- **“绝对留白/慢热复调”**：番茄平台要求快节奏强钩子，不能照搬纯文学的“空的空间”。需将“多元碰撞”转化为高密度剧情冲突，留白仅限章末悬念。
- **“时间距离生美”**：网文是即时消费，不能依赖“二十年后的回忆滤镜”。必须在当下章节制造“即时陌生化”与情绪冲击，延迟满足需控制在3章内。

## 4 编辑检查表（10条以内）
1. [ ] 首章是否出现≥1个“陌生化”细节/视角？（非套路设定堆砌）
2. [ ] 冲突双方是否具备自洽逻辑？有无作者强行降智/定调善恶？
3. [ ] 人物决策是否源于其自身经验与局限？有无“贴作者自我”的越界表达？
4. [ ] 科幻/武学设定是否绑定具体肉身反馈与情感代价？（非说明书）
5. [ ] 连续3章内是否有“同质化经验填充”（重复水字数、无效日常）？
6. [ ] 核心悬念/钩子是否携带“情感振动”或“认知刷新”？
7. [ ] 场景/物象描写是否剥离“工具性”，呈现承载的生命印记/历史感？
8. [ ] 多视角/多势力叙事是否形成“复调碰撞”？有无单一声音垄断真相？
9. [ ] 节奏推进是否依赖“异质性事件”而非机械堆叠任务？
10. [ ] 全文是否贯彻“诚”（不回避苦难/代价，不粉饰逻辑漏洞）？

## 5 对作家角色的输入要求
| 维度 | 输入规范（编辑下发标准） |
|:---|:---|
| **动作链** | 必须呈现 `意图→执行→环境交互→受阻/变轨→结果` 完整链路。禁止跳跃式动作或纯意念推动。每个动作需留下物理痕迹（如地面裂纹、气流扰动、肌肉代偿）。 |
| **物理反馈** | 武学/科技施展必须伴随明确的生理/物理代价。用感官细节（痛觉、温度、气味、失衡感、神经灼烧）替代抽象数值。反馈需与设定强度正相关，禁止“无损耗释放大招”。 |
| **代价** | 任何力量获取、阵营选择、关键决策必须支付**不可逆代价**。代价需具象化（失去某项能力、人际关系断裂、认知崩塌、器官/义体损毁）。禁止“零成本升级”或“系统兜底”。 |
| **钩子** | 格式：`[反常细节/违背预期的行为] + [未解的物理/情感后果] + [迫使翻页的即时悬念]`。钩子必须基于“陌生化认知”或“情感撕裂”，禁用纯信息预告或空洞威胁。 |
| **读者预期** | 明确每章交付的“预期管理”。承诺升级则给阶段性反馈，承诺悬疑则给线索拼图。禁止“预期欺诈”（如铺垫宏大却用机械降神收尾）。预期满足需带“异质性转折”（意料之外，情理之中），并在章末重置新预期。 |
