# 《科武纪元》编辑学习官：桩桩冷门题材创作课提炼

## 1 课程核心判断（≤6条）
1. **冷门必须嫁接大众情绪**：小众题材需绑定成熟类型标签（如竞技+甜宠/亲情/逆袭），以情感驱动替代专业堆砌。
2. **专业知识需降维翻译**：技术细节、规则说明必须转化为可视化动作或人物动机，严控占比，避免阅读断层。
3. **冲突锚定普世诉求**：将“小众规则/行业壁垒”转化为“人际博弈/利益分配/家族荣誉”，避免陷入纯技术内耗。
4. **高光场景双达标**：核心爽点必须同时满足“情绪释放顶点”与“动作/规则通俗化”，裁判/评分描写需服务剧情而非科普。
5. **平台算法偏好复合标签**：冷门题材存活依赖“主类型+情绪词+细分词”标签组合，靠高频情绪钩子维持完读率。
6. **结构迭代是刚需**：小众题材无法一稿成型，需通过多轮修改平衡专业准确性与网文节奏，完稿即重构。

## 2 可执行编辑规则（按原文内容提炼）
| 维度 | 编辑规则 |
|:---|:---|
| **开篇** | 情绪/目标前置，设定后置。首章必须出现“人物困境+行动选择”，禁用百科式世界观抛出。冷门元素通过角色“急需解决的问题”自然带出。 |
| **节奏** | 采用“专业事件（30%）+情感/关系推进（50%）+悬念钩子（20%）”配比。每3章必有一次情绪释放或局势反转，避免连续技术描写。 |
| **冲突** | 将小众规则转化为利益/情感博弈。例：比赛积分→资源分配权；训练瓶颈→师徒信任危机；个人梦想→团队荣誉绑定。 |
| **人物** | 主角成长线必须与“掌握冷门技能”强绑定，但核心驱动力需为情感/执念。对手/导师承担“镜像缺陷”或“试炼阶梯”功能。 |
| **题材** | 执行“冷门舞台+热门内核”公式。科幻/竞技/职业仅作背景板，内核必须是升级、逆袭、群像或悬疑。 |
| **改编** | 场景设计需具备镜头感。动作描写拆解为“起势-发力-受击-反馈”，对话保留潜台词，便于影视化分镜与版权评估。 |
| **平台规则** | 番茄算法重“完读率+标签匹配”。前3章定生死，章末必留钩；标签采用“主类型+情绪词+冷门词”组合，更新节奏需稳定以喂养推荐池。 |

## 3 科武适配
### ✅ 可用点
- **降维翻译策略**：《科武纪元》的机甲参数/武道境界/星际物理法则，需转化为“视觉化战斗表现+角色生理反馈”，禁用论文式设定。
- **情感驱动内核**：科武题材天然硬核，必须绑定“家族传承/阵营忠诚/生存底线/师徒羁绊”等普世情绪，否则易流失大众读者。
- **节奏复用**：体育竞技的“训练-受挫-突破-高光”结构可直接迁移至科武的“装备调试/功法推演-实战受挫-战术迭代-战役决胜”。
- **标签复合**：采用“科幻热血+机甲逆袭+硬核设定”或“科武群像+悬疑破局+冷兵器复兴”，匹配平台推荐逻辑。

### ❌ 不可硬套点
- **“竞技+甜宠”轻喜剧内核**：原文为冬奥青春向，若《科武纪元》基调为史诗/废土/硬核战争，强行插入甜宠会撕裂世界观与读者预期。
- **回合制/积分制逻辑**：体育比赛的规则化、可量化逻辑不适用于星际歼灭/武道死斗的“生存/斩首/资源掠夺”逻辑，需重构胜负判定标准。
- **影视化优先思维**：网文连载需优先保障“章末留存+爽点密度”，不可为迎合剧本三幕剧结构牺牲连载节奏或压缩升级线。

## 4 编辑检查表（10条以内）
1. 前3章是否完成“核心困境+行动目标+类型标签”落地？
2. 专业/设定描写是否≤15%/章，且全部嵌入动作或对话？
3. 每场核心冲突是否绑定普世情绪（亲情/荣誉/生存/背叛）？
4. 科武战斗/技能释放是否具备清晰“规则-代价-反馈”闭环？
5. 节奏是否遵循“高压事件→情感缓冲→悬念钩子”循环？
6. 高光场景是否实现“情绪释放+动作可视化”双达标？
7. 对手/导师是否承担主角“缺陷镜像”或“试炼阶梯”功能？
8. 章末是否设置明确留存钩（反转/危机/情感爆发）？
9. 标签组合是否匹配平台算法（主类型+情绪词+细分词）？
10. 场景分镜是否具备影视化潜力（动作拆解清晰/对话留白）？

## 5 对作家角色的输入要求
| 维度 | 输入标准 |
|:---|:---|
| **动作链** | 必须呈现完整因果序列：`输入（决策/蓄力）→执行（招式/技能释放）→作用（命中/环境交互）→反作用（受击/硬直/资源消耗）`。禁用“意念秒杀”或无铺垫越级，逻辑需自洽于科武世界观。 |
| **物理反馈** | 强调感官具象化：肌肉撕裂感、机甲过载警报、能量反冲震颤、装甲形变、环境破坏痕迹。用物理反馈替代抽象数值，让读者“体感”战斗强度。 |
| **代价** | 每次爆发/越级必须支付明确成本：体力透支、冷却期、装备损毁、阵营暴露、道德妥协、寿命折损。代价需直接推动后续剧情或人物关系变化。 |
| **钩子** | 每章/每卷开头300字内抛出“未解危机/反常现象/情感悬念”；冷门设定通过“角色急需解决的问题”自然带出，章末必留“行动中断/信息反转/情绪断崖”。 |
| **读者预期** | 严格兑现标签承诺（如“热血科武”需在第3章前出现首次实战/能力展示）；设定伏笔3-5章内必回收；保持“新奇感+熟悉感”7:3比例，避免纯自嗨设定或长期压抑无释放。 |
