# MiroFish素材融入口径修正：500章总盘，300章阶段目标

时间：2026-06-06

## 用户纠偏

《科武纪元》不是300章截止。全书仍按500章总盘理解。

300章只是当前阶段目标：完成素材消化与阶段准备后，先把正文推进到300章。

因此：

- 不得把“能否支撑300章”作为素材融入门禁。
- 不得把“是否影响2029结局”作为硬门槛。
- 不得误杀只对中段/近段/支线/人物成长有价值的素材。

## 正确融入门槛

素材经过推演后，只判断它对小说是否有正增益：

1. 是否让大纲更完整。
2. 是否让相关情节更精彩。
3. 是否补强人物选择、势力反应、技术约束、伏笔、场景压力。
4. 是否与后续500章长期逻辑兼容。
5. 是否有负影响：偏离主线、抢戏、新闻堆砌、破坏设定、科学硬伤、让角色工具化。

## 正确三态

### OUTLINE_PATCH
会改变大纲、章节功能、冲突链、人物选择、势力关系。可融入大纲候选。

### CHAPTER_PREP_ONLY
不改大纲，但能强化某章细节、场景、技术约束、台词、伏笔或人物压力。进入章节准备包。

### ARCHIVE_WITH_REASON
没有明显正增益，或负影响大于收益。归档并说明原因。

## 2029与300章的正确用法

- 2029：长期一致性校验尺，不是硬门槛。
- 300章：近期阶段推进目标，不是全书截止。
- 500章：全书结构总盘。

MiroFish输出应改成：

- 适配区间：近段 / 中段 / 远段 / 终局前 / 全书设定层。
- 阶段建议：135-160 / 161-220 / 221-300 / 301-500。
- 融入价值：强 / 中 / 弱 / 负。
- 融入方式：改大纲 / 进准备包 / 设定备用 / 归档。
