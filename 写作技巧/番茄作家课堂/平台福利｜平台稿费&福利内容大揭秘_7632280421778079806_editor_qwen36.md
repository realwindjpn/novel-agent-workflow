# 《科武纪元》编辑学习官：平台福利与稿费逻辑拆解

## 1 课程核心判断（≤6条）
1. **收益本质是广告分成**：听读收益占主体，收入直接挂钩读者阅读深度与广告转化效率，非单纯按字数结算。
2. **全勤与星火计划绑定数据门槛**：2026年全勤需满足“签约次月+有效字数≥10万+听读分成≥500元+日更4k/6k”；星火计划核心考核“自然月末7日万字读完率周均值”。
3. **互动收益为七三分成且按月结算**：打赏需扣除运营商渠道费（iOS/安卓费率不同），统一于次月第二个周四24点前结算，不单独发放。
4. **版权与渠道收益已自动化分发**：集团渠道（头条/抖音/畅听/红果短剧等）与外部渠道/版权（有声/短剧/游戏/出海等）按合同自动分成，后台可溯源。
5. **数据异常与黑产零容忍**：跳章、刷量、恶意刷听读收益将触发数据剔除，直接取消全勤/星火资格及后续福利权限。
6. **合规与审核时效决定福利发放**：次月1日修改章节易导致审核未通过/字数不计入；违规下架或停止推荐直接丧失当月福利资格。

## 2 可执行编辑规则（按文章实际内容取舍）
*注：原文为平台收益与福利规则，以下规则均从“数据考核/分成逻辑/合规要求”反推至创作执行层。*

| 维度 | 可执行规则 |
|:---|:---|
| **开篇** | 前3章必须完成核心设定抛出+首个强冲突，确保首读留存率，直接决定广告曝光基数与“万字读完率”初始值。 |
| **节奏** | 严格匹配日更4000/6000字产能规划；每章结尾预留次日可接续的悬念或进度节点，避免断更或节奏塌陷导致听读分成跌破500元门槛。 |
| **冲突** | 冲突需具备“可量化推进性”（战力/资源/情报阶梯），防止读者因信息冗余跳章；跳章行为将被星火计划判定为数据异常并剔除奖励。 |
| **人物** | 主角/核心配角需具备明确的情感锚点或价值观输出，驱动读者产生自愿打赏行为（互动收益），但禁止诱导性话术。 |
| **题材** | 仅限“独家原创首发55分成非同人”可参与星火计划；长篇科幻需控制硬核设定密度，避免前期劝客导致读完率不达标。短故事/热点稿需压缩铺垫，直接切入高转化场景。 |
| **改编** | 章节结构需预留“场景切片化”可能（如单章可独立成短视频/短剧片段）；动作/对话占比需适配有声录制节奏，以激活集团版权收益。 |
| **平台规则** | ①首月有效过审字数必须≥10万，严禁月底极限打卡；②次月1日禁止修改已发布章节；③严禁任何刷量/黑产操作；④稿费发放日为次月第二周四（遇节假日顺延）。 |

## 3 科武适配
| 维度 | 说明 |
|:---|:---|
| **可用点** | ①“科武”体系天然适合阶梯式战力/科技树推进，易维持日更4k/6k的稳定节奏与高读完率；②机甲/异能/星际战场等强视觉场景可直接切片用于红果短剧/有声改编，激活集团版权收益；③科幻设定可结合热点（如AI伦理、深空探索）做短故事/番外引流，反哺主书听读分成。 |
| **不可硬套点** | ①不可为冲“万字读完率”牺牲科幻逻辑自洽，导致后期崩盘被平台判定为“缺乏发展潜力”拒发星火奖励；②不可用“刷量/买量”手段伪造听读数据，2026年风控已覆盖异常转化模型；③不可将短故事节奏硬套长篇主线，长篇需保证≥10万字的有效世界观铺垫，否则无法触发全勤资格。 |

## 4 编辑检查表（10条以内）
- [ ] 签约次月有效过审字数是否≥10万？
- [ ] 自然月内听读分成收益是否≥500元？
- [ ] 每日有效更新是否稳定4000/6000字且无次月1日修改？
- [ ] 万字读完率周均值是否平稳（无跳章/断更/数据断崖）？
- [ ] 是否存在刷量、互刷、异常转化等黑产风险？
- [ ] 章节结尾是否设置明确钩子保障次日打开率？
- [ ] 互动打赏设计是否自然（无诱导/无违规话术）？
- [ ] 多平台分发/有声/短剧适配场景是否预留？
- [ ] 内容是否通过审核且未处于停止推荐/下架状态？
- [ ] 稿费结算日（次月第二周四24点前）是否已核对后台明细？

## 5 对作家角色的输入要求
| 输入项 | 执行标准（对接平台数据逻辑） |
|:---|:---|
| **动作链** | 每章需提供≥1条完整“触发-执行-结果”因果链，确保阅读深度连续，降低跳章率，保障广告有效曝光。 |
| **物理反馈** | 科武设定中的能量消耗、装备损耗、环境交互需具象化呈现，避免“唯心升级”导致读者预期断裂，影响读完率。 |
| **代价** | 每次战力突破/情报获取必须绑定明确资源/时间/风险成本，维持节奏张力，支撑≥500元听读分成所需的持续追读。 |
| **钩子** | 章末必须输出可验证的悬念（未解危机/新坐标/敌我反转），驱动次日自然打开，直接拉升听读收益与星火计划数据置信度。 |
| **读者预期** | 严格对齐“科幻+武道”类型承诺，不跨题材硬蹭热点；长篇需保证世界观递进逻辑，短故事/热点稿需在3章内完成闭环，避免数据异常被平台剔除奖励。 |
