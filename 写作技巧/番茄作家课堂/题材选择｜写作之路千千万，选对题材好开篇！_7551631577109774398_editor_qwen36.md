# 《科武纪元》编辑学习官｜课程拆解与执行手册

## 1 课程核心判断（≤6条）
1. **题材锚定**：初阶作者应优先选择“阅读积累深+直觉有灵感”的大类题材，忌盲目追热点；单赛道深耕优于泛题材试水。
2. **开篇即契约**：摒弃背景说明书式铺陈，首章必须切入具象冲突，3000字内亮出主角核心目标。
3. **冲突降维**：避开宽泛的“抽象生死局”，聚焦可感知的人性/利益/立场博弈，以“小切口”制造强代入。
4. **人设剧情化**：人设不靠小传堆砌，必须通过极端情境下的选择、代价与配角拉扯自然显现。
5. **多圆心发散**：以核心事件为轴，赋予各角色独立动机与隐秘诉求，利用信息差与利益冲突拉升张力。
6. **商业优先逻辑**：前期重“抓留存”轻“文学性”，先完成阅读预期交付，再逐步叠加设定深度与表达。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则要点 | 执行标准 |
|:---|:---|:---|
| **开篇** | 禁大段设定/环境/心理独白；首章必须出现“事件触发” | 3000字内完成：危机出现→主角介入→目标抛出 |
| **节奏** | 砍掉无效打斗/场景描写；每章必须有主线推进或冲突升级 | 情节功能二选一：①推动目标 ②揭示人物/伏笔；否则删减 |
| **冲突** | 冲突需“具体可感+附带后果”；忌开局宏大叙事 | 采用“资源/立场/道德”三选一模型；冲突结果必须改变局势 |
| **人物** | 废除纯设定式人设；用“选择+反应”立人设 | 关键节点必须给出角色决策，决策需暴露性格底色并引发连锁反应 |
| **题材** | 锁定1个主赛道；热点梗（重生/系统等）仅作工具嵌入 | 题材标签≤2个；热点元素必须服务主线，不喧宾夺主 |
| **改编** | 核心事件需具备“多视角动机发散”空间 | 同一事件下，至少3个角色持有不同利益诉求与行动逻辑 |
| **平台规则** | 番茄算法重“首章留存+追读率”；期待感＞未知感 | 开篇建立明确阅读契约（爽点/悬念/成长路径）；数据差则快速调整钩子密度 |

## 3 科武适配（长篇科幻《科武纪元》/短故事/热点稿）
### ✅ 可用点
- **目标前置**：科幻设定复杂，但必须用“具体任务/倒计时/技术危机”带出主线（如：破解初代基因锁/抢夺跃迁核心），忌说明书式抛设定。
- **冲突具象化**：将“星际存亡/武道巅峰”降维到“小队资源分配/阵营背叛/科技伦理抉择”，增强短平快代入感。
- **人设靠选择**：用“战术抉择/科技副作用承受/武道信念碰撞”立人设，参数与装备仅作为冲突载体。
- **多圆心结构**：围绕核心科技/武道传承，给军方、财阀、主角、AI赋予不同利益诉求，制造连环博弈。
- **跨格式缩放**：短故事/热点稿直接套用“单事件+多圆心+强钩子”模型；长篇则将此模型作为卷/章单元循环使用。

### ⛔ 不可硬套点
- **“狗血/市井伦理”直译**：婆媳落水式生活冲突会割裂科幻沉浸感。需转化为“科幻语境等价冲突”（如：救战友还是保跃迁引擎/保平民还是保火种库）。
- **“完全放弃文学性”**：科武需维持硬核质感与世界观氛围。不能牺牲基础逻辑与科幻美学，需平衡“快节奏抓人”与“设定合理性”。
- **“单赛道绝对化”**：《科武纪元》本质是融合题材（科幻舞台+武道内核）。需明确主次（如：以武道升级为主线，科幻为规则与资源池），避免标签混乱导致推荐池错位。

## 4 编辑检查表（10条以内）
- [ ] 开篇3000字内是否已切入核心冲突事件？（无背景说明书）
- [ ] 主角的阶段性/终极目标是否已明确抛出？（读者知道“为何而战”）
- [ ] 冲突是否具体可感？（避开抽象生死局，聚焦利益/人性/立场博弈）
- [ ] 人设是否通过“极端情境下的选择”展现？（非外貌/心理直述）
- [ ] 核心事件是否具备多角色动机发散空间？（各怀诉求/利益冲突）
- [ ] 节奏是否紧凑？（每章是否有推进主线或升级冲突的有效情节）
- [ ] 科幻/武道设定是否“剧情化”呈现？（设定服务于冲突，非独立科普）
- [ ] 开篇是否建立明确阅读预期？（爽点/悬念/成长路径清晰）
- [ ] 是否剔除无效打斗/场景描写？（所有动作必带后果或信息）
- [ ] 题材定位是否清晰？（主赛道明确，热点元素仅作辅助工具）

## 5 对作家角色的输入要求
生成《科武纪元》内容时，必须严格遵循以下参数输入：

| 参数 | 定义与执行标准 |
|:---|:---|
| **动作链** | 必须呈现完整闭环：`触发信号 → 战术/武道决策 → 执行动作 → 物理/局势结果`。例：侦测到敌袭→启动武装机甲→能量过载警告→强制突破限制→击毁目标但暴露坐标。 |
| **物理反馈** | 所有科武交互必须伴随符合设定的物理/生理反馈。例：神经接驳的刺痛、机甲关节的金属疲劳声、重力场下的骨骼压迫感、能量反噬的灼烧感、武道经脉的撕裂与重组。 |
| **代价** | 每次关键行动/升级必须支付明确代价（资源、寿命、信任、道德底线、身体损伤、阵营关系）。杜绝无成本开挂；代价必须影响后续剧情走向。 |
| **钩子** | 章末/卷末必须埋设“未解危机/反转信息/目标升级”，与开篇主线目标强关联。采用“九连环”结构：解旧钩必出新钩，悬念不断层。 |
| **读者预期** | 开篇3章内必须兑现“题材承诺”（科武的硬核战斗/科技奇观/升级路径）。后续按`小目标达成 → 新危机出现 → 能力/认知迭代`循环推进，保持期待感不落地，不偏离核心契约。 |
