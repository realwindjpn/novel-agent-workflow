# 《科武纪元》编辑学习官｜阿来大师课规则提炼

## 1 课程核心判断（≤6条）
1. **写作首先是技术活**：思想与境界是辅助，必须优先夯实场景构建、信息释放、动作描写等叙事技术。
2. **意义从具象中自然生长**：摒弃强行拔高主题，通过“眼前场景、具体事物、天气及场外事”的微观观察，自然推导宏观意义。
3. **架空/科幻必须“通向科学”且具现实感**：异质设定需有物理/社会规则支撑，所有非人角色最终必须回归人类的情感、意志与历史逻辑。
4. **类型文成于套路，破局于主流价值**：纯“安慰/迷醉型”套路会被淘汰；能留存的作品必在类型框架内叠加人性探讨、资源分配或社会治理等现实命题。
5. **语言必须匹配世界观尺度**：忌用传统/旧有语汇硬套新世界观，否则“皮肉分离”；修辞与审美需随设定同步进化。
6. **强调整体性构想**：创作前需确立“核心零件”（主线、人物弧光、规则、主题），由整体牵引局部，确保拆解后仍可拼装为完整有机体。

## 2 可执行编辑规则（按栏目分类）
| 维度 | 编辑规则（基于原文提炼） |
|:---|:---|
| **开篇** | 禁大段设定说明。必须从具体场景/物件/天气切入，用“显微镜式”细节（如异常读数、环境扰动）自然牵引世界观与悬念。 |
| **节奏** | 前3万字以“技术推进”为绝对核心。信息释放遵循“动作→反馈→认知升级”链条，主题表达让位于情节密度，避免开篇议论。 |
| **冲突** | 冲突内核需具备现实投射。摒弃纯数值碾压或“朝堂背诗”式爽点；设计指向人性博弈、规则漏洞、资源分配或伦理困境的结构性矛盾。 |
| **人物** | 剥离“神性/兽性”标签。AI、异族、超凡者的行为动机必须符合人类史逻辑（欲望、恐惧、共情、妥协），确保读者可代入、可共情。 |
| **题材** | 科幻/科武需“通向科学”。允许保留类型文的“安慰功能”，但必须叠加主流价值观（责任、代价、文明演进），实现“类型上升”。 |
| **改编** | 预留“整体性零件”。大纲阶段明确头（主线）、心（人物弧光）、肝（核心规则）、肾（主题落点），确保单章可独立阅读，拼装后逻辑自洽，适配多媒介转化。 |
| **平台规则** | 顺应商业属性但拒绝短期功利化。数据用于优化钩子与节奏，而非迎合低质套路；以长期留存与IP价值为标尺，避免“财务自由即停笔”的创作惰性。 |

## 3 科武适配：可用点 vs 不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **科武底层逻辑**：武道修炼/科技赋能必须绑定可验证的物理/生物规则（如能量守恒、神经负荷、材料疲劳），杜绝“唯心突破”。
- **冲突现实化**：将“科武升级”与社会结构绑定（如技术垄断导致的阶级固化、武道普及引发的治安重构），契合阿来“关注社会分配/治理”的要求。
- **语言尺度匹配**：战斗描写采用“冷峻科技术语+具象力学反馈”组合，避免用传统武侠的“气韵/意境”生搬硬套未来战场。
- **整体性拼装**：明确“科”与“武”的融合边界（如：科技是外骨骼/能量源，武道是神经控制/战术本能），确保设定不互斥。

### ⛔ 不可硬套点（需规避的误读）
- **忌强求“传统文学式慢节奏”**：阿来认可《乡村教师》语言粗糙但尺度匹配。科武需保持网文推进效率，不必强求“农民过日子式”的细腻铺陈。
- **忌将“现实感”等同于“当代都市生活”**：科武的现实感体现在“人类面对未知技术/力量时的社会演变与心理反应”，而非照搬当下职场/家庭矛盾。
- **忌价值观外挂说教**：主流价值必须内化于角色的生死选择与剧情代价中，不可脱离情节单独成段议论，否则破坏类型文阅读契约。

## 4 编辑检查表（≤10条）
- [ ] 开篇3章是否从具体场景/物件切入，无大段设定堆砌？
- [ ] 核心冲突是否指向人性/资源/规则博弈，而非纯数值碾压？
- [ ] 非人/AI/超凡角色的动机是否符合人类情感与历史逻辑？
- [ ] 科武设定是否“通向科学”（有底层物理/生物/社会规则支撑）？
- [ ] 语言风格是否与世界观尺度匹配，无“旧词写新境”割裂感？
- [ ] 爽点是否叠加“代价/选择/价值观”维度，避免纯安慰性套路？
- [ ] 单章是否具备完整起承转合，且能无缝拼接入整体主线？
- [ ] 是否规避“背诗/救历史人物/无脑收后宫”等陈旧网文套路？
- [ ] 主题表达是否通过情节自然生长，无作者跳出来直接议论？
- [ ] 大纲是否明确“科”与“武”的融合边界，无底层逻辑互斥？

## 5 对作家角色的输入要求
| 维度 | 输入标准（技术级指令） |
|:---|:---|
| **动作链** | 摒弃“意念一动/光效一闪”。必须写出“发力源→传导路径→作用目标→环境扰动”的物理序列。例：机甲出招需明确液压启动、能量回路负载、关节扭矩释放顺序。 |
| **物理反馈** | 每次力量释放/科技应用必须伴随可观测反馈。例：高频刃切割装甲需描写金属疲劳裂纹、热浪扭曲空气、操作者神经负荷飙升，杜绝“无损耗施法”。 |
| **代价** | 任何突破/升级必须绑定明确代价（生理损伤、资源枯竭、社会关系断裂、伦理困境）。代价需前置或同步揭示，作为推动下一轮冲突的燃料，而非事后补丁。 |
| **钩子** | 章末/卷末钩子必须基于“未解的现实逻辑”而非机械降神。例：不写“天降神器”，写“能量读数异常指向废弃矿区，但该坐标在百年前已被官方抹除”。 |
| **读者预期** | 明确交付类型承诺（科武升级/探索未知）的同时，预埋主流共鸣点（文明存续代价/个体在系统中的挣扎）。每3万字完成一次“预期满足+预期升级”循环，避免纯消耗型疲劳。 |
