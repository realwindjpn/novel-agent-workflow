## 二、章节自检清单（每章完成后强制执行）

### 【检查A】开篇/钩子检查（必须全部通过）

- [ ] **钩子存在性**：本章结尾是否有“信息差悬念”或“行动迫近点”？禁止纯情绪/风景收尾
- [ ] **钩子有效性**：钩子是否与下章核心冲突直接绑定？读者能否明确预期？
- [ ] **开篇冲击**：前3章是否抛出核心悬念/设定+首个具体事件？是否避免了世界观说明书？
- [ ] **首段引力**（短故事/狼人篇）：首段是否建立强冲突或反常识钩子？

### 【检查B】逻辑闭环检查（逻辑断裂是长篇崩盘主因）

- [ ] **力量体系一致性**：本章涉及的机甲/武道/科技设定是否符合【卡3】底层规则？
- [ ] **代价兑现**：本章任何能力使用/突破/决策是否伴随明确代价？
- [ ] **代价合理性**：代价是否与行为强度匹配？禁止无代价升级
- [ ] **伏笔回收登记**：本章是否回收伏笔？若未回收，是否在【卡4】计划内？
- [ ] **物理反馈存在性**：高强度行为后是否有具体损耗描写？（禁止“光效一闪”“意念一动”）

### 【检查C】人物弧光检查

- [ ] **主角行动性**：主角是否主动行动破局？禁止抱怨/等待/作者代入式扁平化
- [ ] **动机明确性**：主角每章行动是否追溯到【卡2】核心动机？
- [ ] **内在矛盾激活**：本章是否触及主角的内在冲突？（如力量渴望vs恐惧）
- [ ] **配角独立性**：关键配角是否有独立动机？不是主角的工具人

### 【检查D】冲突设计检查

- [ ] **表层冲突绑定**：表层冲突（战斗/科技/博弈）是否绑定深层冲突（价值观/伦理/内心）？
- [ ] **冲突导向明确**：本冲突是否有明确结论或推进？禁止为冲突而冲突
- [ ] **悬念管理**：读者预期是否被满足或合理颠覆？禁止偏离主线超过3章

### 【检查E】情感线检查

- [ ] **情感自然度**：情感线是否通过事件自然流露？禁止突兀表白/强行煽情
- [ ] **比例控制**（科武长篇）：情感戏份是否不超过主线篇幅的20%？禁止喧宾夺主
- [ ] **价值观渗透**：三观是否通过角色选择/世界规则/代价自然呈现？禁止说教

### 【检查F】细节真实性检查

- [ ] **专业术语核实**：涉及物理/生物/战术/心理的描述是否经基础核实？
- [ ] **场景具象化**：场景是否可被读者想象出具体画面？可预留视听化改编空间
- [ ] **动作链完整性**：战斗/修炼/科技操作是否呈现“意图→发力→轨迹→结果→反作用”完整链条

### 【检查G】平台适配检查

| 检查项 | 免费平台要求 | 付费平台要求 |
|:---|:---|:---|
| **前三章留存** | 前3章必须包含强冲突/核心悬念/首个高潮点 | 前3章必须展示主角核心竞争力+独特世界观 |
| **章节钩子密度** | 每章必须留悬念/反转/危机，禁止断崖式收尾 | 每3章需有至少1个情绪高潮点 |
| **节奏控制** | 每章至少推进1个核心问题 | 每章需有信息增量（情节/人物/世界观） |
| **风险门禁** | 禁止触碰审核红线（三观虚无/过度血腥/政治敏感） | 需预留付费解锁钩子（核心悬念延后揭示） |

## 三、科武长篇专项可借点

### 【借点1】单元结构平移法

| 原型（《风雨如书》） | 科武转化 |
|:---|:---|
| “颜色主题单元”（蓝血案/红颜祸/白夜行） | “科技纪元/武道境界/星域势力”单元 |
| 每单元独立起承转合 | 每卷独立事件闭环 |
| 单元结束时留下悬念锚点 | 卷末留下主线伏笔与新单元开启缺口 |

**执行动作**：
- 在【卡4】中为每个单元命名（例：“能源争夺卷”“星域外交卷”“文明存续卷”）
- 每个单元必须有“本卷核心问题→单元内解决→新问题抛出”的闭环结构
- 单元内必须设置“阶段性高潮事件”（战斗/谈判/突破/背叛）

### 【借点2】逻辑自洽校验链

| 层级 | 校验内容 |
|:---|:---|
| **底层规则层** | 能量守恒/武道法则/科技边界是否有明确成文规定？ |
| **应用层** | 每场战斗/每次突破是否严格遵守底层规则？ |
| **反噬层** | 违反规则的代价是否明确且被触发？ |
| **漏洞检测** | 本章是否出现“逻辑漏洞”或“机械降神”？（一旦发现直接打回重写） |

**失败模式预警**：
- “主角在绝境中突然发现残骸内部有未知能源”——若之前未埋设伏笔，视为机械降神
- “反派战力忽高忽低”——若未给出合理理由（如药物刺激/隐藏实力/情报误导），视为逻辑断裂

### 【借点3】代价触发机制

**强制执行规则**：所有力量升级/关键决策/道德选择必须触发代价

| 升级类型 | 代价示例 |
|:---|:---|
| 武道境界突破 | 寿命折损/羁绊断裂/记忆封印/战力封印 |
| 科技研发成功 | 资源枯竭/盟友牺牲/道德争议/规则反噬 |
| 关键决策 | 阵营对立/信任崩塌/宿命锁定/预言应验 |
| 道德选择 | “救一人vs救苍生”类困境必须承担被救方的后续反应 |

**反馈机制**：
- 每次代价触发后，必须在后续3章内展现代价的具体影响
- 禁止“代价已付但无后续”的空洞化处理

### 【借点4】专业背书+现实映射

**科武长篇必须引入的现实议题**：

| 科武设定 | 现实映射 | 呈现方式 |
|:---|:---|:---|
| 机甲能源分配 | 资源分配不公/阶级固化 | 底层流民无机甲可用→精英垄断→冲突爆发 |
| 武道境界封锁 | 教育/阶层流动困难 | 突破需要稀有资源→资源被势力垄断→普通人无上升通道 |
| 外星文明接触 | 殖民历史/文化冲突 | 高阶文明“保护”低阶文明→实际控制→主角发现真相 |
| 人体改造技术 | 医疗伦理/生命商品化 | 改造可提升战力→但需牺牲寿命/情感→主角面临选择 |

**执行动作**：
- 每个单元至少解决或深化一个现实议题
- 议题必须通过角色选择与事件后果自然呈现，禁止作者说教

### 【借点5】跨媒介改编预留

**场景具象化要求**：
- 每场战斗必须给出：空间结构（战场布局）、物理条件（重力/介质）、动作目标（攻击弱点）、反馈细节（损伤累积）
- 示例：“机甲左腿液压泄漏导致重心偏移0.3度→被迫改变移动轨迹→被对手预判落点→必须用右臂格挡→格挡导致右臂装甲过热”

**季播结构适配**：
- 每12-15章为一个完整季（参照【卡4】单元划分）
- 每季必须有明确的主线任务/核心对抗/阶段性结局
- 季末钩子必须与下季核心冲突直接绑定

**首段钩子公式**（必须在第一句/第一段完成）：
- 反常识型：“狼人不怕银”
- 强冲突型：“他在猎杀自己的同类”
- 悬念型：“第三个满月，死的是猎手”

**执行动作**：
- 首段必须包含：主角身份暗示+核心冲突+情绪基调
- 禁止以背景介绍/世界观说明/环境描写开篇

### 【借点C】人物口吻设计

**狼人篇口吻特征**：

| 角色类型 | 口吻特征 | 示例句式 |
|:---|:---|:---|
| 狼人（内心） | 压抑/本能撕裂/身份认同挣扎 | “他闻到了血腥味——那是三十年前他们离开时，自己留下的味道” |
| 猎手（理性） | 冷静分析/职业惯性/隐忍痛苦 | “根据伤口撕裂角度，凶手惯用左手——和我一样” |
| 受害者（临终） | 释然/揭露/控诉 | “你以为你在拯救我们？不，你只是在重复他们的错误” |

### 【借点D】章末钩子类型（短篇可借用单篇结尾）

| 钩子类型 | 适用场景 | 短篇结尾示例 |
|:---|:---|:---|
| **信息差悬念** | 身份/动机/规则未揭示 | “猎手不知道，他放走的那只狼人，正是下一个满月他要猎杀的目标” |
| **行动迫近点** | 危机倒计时/决定性时刻 | “月亮正在升起——而他口袋里还揣着那枚没来得及使用的银弹” |
| **情感反转** | 信任崩塌/真相逆转 | “临死前他才明白：不是狼人要杀他，是他当年抛弃的孩子，要杀他” |

### 【借点E】世界观简化原则

短篇/狼人篇必须遵循“冰山一角”原则：
- 规则只展示与本篇相关的部分
- 禁止扩展说明（如“狼人社会有ABC三族，D族已消亡”）
- 若必须引用背景，通过角色反应/对话暗示，而非说明书

## 五、平台规则转化：发布/包装/风险门禁

### 【发布策略卡】

| 平台类型 | 核心指标 | 作家执行动作 |
|:---|:---|:---|
| **免费平台** | 前三章留存率 | 前3章必须包含：①核心悬念抛出②首个高潮事件③主角核心竞争力展示 |
| **免费平台** | 追读率 | 每章必须留钩子，禁止“今日份更新结束”的纯情绪收尾 |
| **付费平台** | 章节完读率 | 每章必须有信息增量（情节推进/人物揭示/世界观扩展） |
| **付费平台** | 付费转化点 | 在关键悬念处设置“付费解锁钩子”（如：真相延后1-2章揭示） |

### 【包装指南】

| 包装要素 | 要求 | 科武长篇示例 |
|:---|:---|:---|
| **书名** | 必须包含核心卖点词 | “废土机师”“武道至尊”“星域战纪” |
| **简介** | 必须包含：主角+核心冲突+悬念+情绪基调 | “废土流民林渊意外激活禁忌机甲，却不知每启动一次，寿命便少一天。当星域战争逼近，他必须抉择：是用命换和平，还是保存实力复仇？” |
| **章节标题** | 前30章必须有明确章节名（帮助读者定位进度） | “第一章：残骸觉醒”“第五章：代价初现”“第十章：师门秘密” |

### 【风险门禁清单】（触碰即死，零容忍）

| 风险类型 | 绝对禁止内容 | 替代方案 |
|:---|:---|:---|
| **政治红线** | 影射现实政权/领导人/敏感历史事件 | 用虚构文明/星际政治替代 |
| **血腥暴力** | 过度详细的血腥描写/酷刑细节 | 用“能量灼伤”“经脉断裂”等科武术语替代 |
| **价值观虚无** | 主角无底线作恶无代价/反派无理由邪恶 | 任何行为必须有代价，主角必须有底线 |
| **抄袭风险** | 与热门作品核心设定高度雷同 | 差异化核心元素（如能量来源/力量体系/社会结构） |
| **平台封禁词** | 使用平台敏感词（需定期更新自查） | 提前建立本作品的“敏感词库”并替换 |

### 【48小时热点稿特殊规则】（适用于蹭热点/时事类创作）

| 时间节点 | 必须完成 |
|:---|:---|
| **0-6小时** | 事件分析（提取核心冲突）+ 科武/狼人设定匹配 |
| **6-24小时** | 完成“事件爆发-情绪峰值”两段 |
| **24-48小时** | 完成“快速收束”+ 章末钩子 + 发布 |
| **超时处理** | 超过48小时放弃热点稿，时效性价值归零 |

## 六、人物口吻与段落节奏指南

### 【口吻设计模板】

| 角色处境 | 口吻特征 | 句子结构 | 示例 |
|:---|:---|:---|:---|
| **绝境中破局** | 冷静/克制/技术性 | 短句为主+专业术语 | “能量余量12%，够一次爆发。右腿关节有裂纹，承受不住反震。换策略，近身。” |
| **情感撕裂** | 断续/矛盾/自我质疑 | 长短交错+内心独白比例增加 | “他又救了所有人。用命。就像那个人当年一样——我恨他，恨他总是这样，恨他从来不问我愿不愿意被救。” |
| **反派正当性** | 理性/自洽/悲剧感 | 平稳句式+因果链条清晰 | “你们说我疯了。为了能源杀人。但你们知道上一个纪元，'理性'的文明是什么下场吗？灭绝。资源枯竭，一滴不剩。” |
| **导师遗言** | 简洁/浓缩/信息密度高 | 短句+关键信息+余韵 | “机甲不是你的命。你是。别让它成了别人的坟。” |

### 【段落节奏控制】

| 场景类型 | 推荐节奏 | 段落长度 | 句子特征 |
|:---|:---|:---|:---|
| **战斗/对抗** | 快节奏 | 短段落（1-3句） | 主谓宾结构+动词高权重+省略修饰 |
| **内心/情感** | 慢节奏 | 中长段落（5-10句） | 修饰语增加+内心独白+隐喻 |
| **信息揭示** | 中等节奏 | 中段落（3-6句） | 清晰逻辑链+因果关系明显 |
| **高潮/转折** | 变速 | 短句冲击→长句余震 | “他死了。”（短）“所有人都说他死了。但没有人知道，他在最后一秒把自己上传进了残骸的备用意识核——而那个核体，正在被敌人捡走。”（长） |

## 七、章末钩子设计手册

### 【钩子类型矩阵】

| 钩子类型 | 定义 | 科武长篇示例 | 短篇/狼人篇示例 |
|:---|:---|:---|:---|
| **信息差悬念** | 读者知道的信息 < 角色知道的信息 | “他不知道自己启动的机甲，正是三十年前屠灭故乡的那一台” | “猎人不知道，他咬死的狼人，是当年救过他的那只” |
| **行动迫近** | 读者知道危机将至，角色尚不知 | “敌方舰队将在6小时后进入射程——而他们还不知道叛徒就在指挥舱” | “满月升起还有三小时——而他手里的银弹只剩一颗” |
| **身份反转** | 读者对角色认知被颠覆 | “他一直以为导师是为保护他而死，直到他发现那份'牺牲协议'的签署日期——是导师被杀前十年” | “他追杀了三年的狼人，原来一直在保护这个镇子” |
| **代价预兆** | 读者看到代价正在累积 | “能量余量12%。够用吗？不够也得够。” | “这是第三只被他亲手杀的狼人。每杀一只，他的梦里就多一双黄色的眼睛” |
| **选择锁定** | 角色被迫做出不可逆选择 | “要么交出机甲，要么看着整个星域陪葬。他没有第三种选择” | “要么开枪，要么看着狼人咬死孩子。他没有第三种选择” |

### 【钩子绑定规则】

**强制规则**：每个章末钩子必须与下章第一个事件直接绑定

| 章末钩子 | 下章开头必须 |
|:---|:---|
| “敌方舰队将在6小时后进入射程” | 直接进入备战/策略/内鬼排查 |
| “满月升起还有三小时” | 直接进入倒计时/猎手准备/狼人视角 |
| “他不知道自己启动的机甲正是屠灭故乡的那台” | 直接进入机甲操控/记忆闪回/真相片段 |

**失败模式**：章末钩子与下章开头脱节——读者感到“被骗”，追读意愿下降
