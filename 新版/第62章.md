# 第 62 章：审讯

审讯持续了三天。

不是那种拍桌子瞪眼的审，而是漫长的、细致的、如同剥洋葱般的逻辑推演。

陈思琪负责技术侧，赵刚负责心理侧。两人轮流上阵，把方致远的记忆像挤海绵一样一点点挤出来。

第三天晚上。

赵刚推开门走进休息室，把一份打印出来的银行流水图拍在方致远面前。

“这是你过去五年的所有海外汇款记录。”赵刚拉过椅子坐下，“每一笔都是通过‘新加坡离岸金融中心’的壳公司转出的。公司名字叫‘北极星咨询’。听起来很像搞投资的对吧？”

方致远缩在椅子里，双手交叉抵着下巴。他的胡茬已经长出来了，眼里的神采比第一天亮了一些——那是知道女儿安全后的放松，也是彻底交代后的释然。

“我知道那个公司。”他声音沙哑，“但我只负责收钱和发数据。我没见过他们的人。”

“怎么联系？”陈思琪坐在角落的电脑前，没抬头，“邮件？暗网？还是死信箱？”

“都有。”方致远闭上眼，像是在回忆某种令他恐惧的程序，“最开始是暗网论坛的私信。后来，‘老鬼’给了我一个加密聊天软件的 ID。每次上线，他都会换头像。我只能通过 ID 确认是他。”

“他说的是什么语言？”

“英语。但语法结构很奇怪。”方致远皱了皱眉，“有些词汇的用法，不像是母语者。更像是……用翻译软件转写过的。”

陈思琪的手指停住了。

“翻译软件？”

“对。比如他经常把‘项目’翻译成'Project'，但在中文语境里，我们通常叫它‘活儿’或者‘任务’。而且，他偶尔会打错字，把'Intel'打成'Inel'——这是拼音输入法里常见的错误，如果是母语者，很少会犯这种错。”

赵刚和陈思琪对视了一眼。

“你是说，‘老鬼’可能是个中国人？或者在中国待过很久？”

“有可能。”方致远点头，“还有一点。每次我发送完数据，他确认收到后，都会问一句：‘基地的食堂今天有红烧肉吗？’"

陈思琪猛地转过身。

“这是暗号？”

“不像。”方致远摇头，“更像是……某种试探。或者是随口一问。但我每次都很害怕，不敢多回。”

“基地食堂的红烧肉……"陈思琪喃喃自语。

这句话像是一道闪电，在她脑子里瞬间照亮了一些被忽略的细节。

太行山基地的食堂，每周三和周五晚餐会有红烧肉。这是后勤部的固定菜谱，外人根本不知道。除非——

“除非他在基地里有眼线。”陈思琪站起来，“或者，他曾经在这里生活过，对这里的作息和菜谱有极深的印象。”

“能追踪那个加密软件的 IP 吗？”赵刚问。

“难。”陈思琪坐回电脑前，“那软件自带洋葱路由，IP 跳板遍布全球。但如果是用拼音输入法，那他大概率是在国内，或者至少有一个中文输入环境。”

“方致远。”赵刚身体前倾，“除了‘老鬼’，你还知道谁？”

方致远犹豫了一下。

“有一次，大概是半年前。‘老鬼’让我把一份数据交给一个来基地参观的访问学者。那个学者是来听关于‘高超声速风洞’的讲座的。”

“名字？”

“我不知道名字。但他给我看了一张照片。”方致远指着桌上的笔，“他穿一件灰色的夹克，戴眼镜，左手手腕上有一块很旧的老式机械表。”

赵刚的眼神沉了下去。

“灰色夹克，机械表。”

“对。他说只要我把数据盘放在洗手间的水箱后面就行。那个人会来取。”

“你放了？”

“放了。”方致远低下头，“但我没敢看那个人是谁。我放下就走了。”

陈思琪立刻调出半年前的访客记录。

“高超声速风洞讲座……那是去年十一月的事。访客名单有三个人。”

屏幕上跳出三张照片。

第一张：某高校教授。
第二张：某研究所工程师。
第三张：某科技公司代表。

赵刚指着第三张照片。

“灰色夹克。”

虽然照片里的人穿的是西装，但在领口处，隐约露出了一截灰色的内搭衣领。更重要的是，他的左手手腕上，确实戴着一块表。

表盘很大，皮质表带已经磨损。

“这个人是谁？”赵刚问。

陈思琪输入名字查询。

结果跳出来。

**李国强。**
身份：某科技公司代表。
备注：曾于 2018 年在南天门计划合肥基地担任安保主管。

“安保主管。”赵刚冷笑了一声，“原来是监守自盗。”

他站起身，拿起对讲机。

“通知门岗，封锁所有出口。查一下这个叫李国强的人，最近有没有申请进入基地的权限。”

对讲机里传来电流声。

“赵队，查到了。李国强……就在现在的访客大厅。他是来送设备的。”

赵刚的嘴角勾起一抹冰冷的弧度。

“这就对了。”

“三天前他送来了服务器备件。今天，他是来取回‘那个’东西的。”

林星辰推门而入。

“准备好了吗？”他问。

赵刚站起来，整理了一下衣领。

“走吧。去会会老朋友。”
