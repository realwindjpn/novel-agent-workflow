# 《科武纪元》编辑学习官：空留专访规则提炼

## 1 课程核心判断（≤6条）
1. **内核优先于类型标签**：复仇/武侠/仙侠仅为叙事架构，真正留存读者的是能回应时代情绪的核心命题（如终结仇恨循环、建立互助秩序）。
2. **人物需“锋芒与底线”双轨并行**：主角可狠戾复杂，但必须有明确的情感锚点与行为边界，杜绝无逻辑黑化或扁平圣母。
3. **世界观拒绝“身边即世界”**：群像与势力构建需突破作者生活经验局限，赋予每个角色独立人生轨迹，构建自洽的微观宇宙。
4. **动笔前必建“骨架”与“延展性”**：严禁“写到哪算哪”，需提前规划主线收束点、支线承载力与核心表达，防中后期崩盘。
5. **功能性设定严格服从剧情逻辑**：性别错位、身份伪装、特殊职业等仅为解决叙事合理性服务，不喧宾夺主，不堆砌噱头。
6. **创作期需“文本包裹”与持续输入**：写作周期内保持高频阅读，维持语感与叙事节奏的稳定性，防热情透支导致结构失控。

## 2 可执行编辑规则
| 维度 | 规则要点 |
|:---|:---|
| **开篇** | 摒弃纯设定/背景堆砌。首章必须亮出“核心情感命题+具体生存困境”，并展现主角“手段锋芒”与“底线雏形”的初次碰撞。 |
| **节奏** | 采用“骨架牵引法”。每卷/阶段预设明确目标与收束点；高潮后必接情感缓冲或关系推进，形成“爆发-沉淀-再出发”的循环节奏。 |
| **冲突** | 升级冲突维度。用“理念博弈/事业竞争/生存资源争夺”替代低效内耗（如宅斗/雌竞）；冲突设计必须服务于“打破旧循环/建立新秩序”的内核。 |
| **人物** | 建立“复杂性档案”。主角=狠戾手段+情感软肋+行为底线；群像需具备独立动机与成长弧光，拒绝纯工具人/背景板。 |
| **题材** | 类型融合需“命题落地”。科幻/武侠等设定必须锚定当代读者可共情的现实命题（如技术伦理、信任重建、代价权衡），避免悬浮。 |
| **改编** | 预留“视觉化名场面”与“关系张力点”。影视/短剧看重人物弧光与群像互动，减少抽象内心独白，强化可拍摄的动作/对话冲突。 |
| **平台规则** | 适应“低粘性、高选择”环境。强化“作者品牌辨识度”（固定叙事风格/核心母题）；利用编辑反馈校准节奏，保持日更稳定性与预期管理。 |

## 3 科武适配
### ✅ 可用点
- **“心出发”的江湖观** → 科武世界的阵营/法则由核心信念（人类存续、技术伦理、武道传承）驱动，而非纯武力值或科技碾压。
- **“终结仇恨循环”内核** → 完美契合科武题材的“文明冲突/人机对立/阶级固化”破局，用“互助/共生/规则重构”替代零和博弈。
- **“骨架与延展性”控制** → 科武长篇极易设定膨胀，必须提前划定科技树边界、武道体系上限、资源消耗逻辑与主线收束点。
- **“配角服从逻辑”** → AI、改造人、外星种族、财阀等设定，需严格服务于剧情推进与世界观自洽，删去不影响主线则视为冗余。

### ⛔ 不可硬套点
- **“女性互助/反雌竞”作为唯一主线** → 科武核心是“文明演进与技术伦理”，性别议题需自然融入世界观，不可生搬硬套削弱科幻硬核感与格局。
- **“古风身份伪装套路”** → 科武背景下的身份设定需符合科技/社会逻辑（如基因编辑、意识上传、阶级通行证、神经伪装），不可直接套用古代权谋。
- **“传统武侠快意恩仇”** → 科武的“侠”应转化为“技术伦理坚守者/文明拓荒者”，传统江湖的“凭心而动”需让位于“理性计算、代价权衡与系统博弈”。

## 4 编辑检查表（10条以内）
1. 核心命题是否可用一句话清晰概括？（能否回应时代情绪？）
2. 开篇3章是否已建立主角“手段锋芒”与“行为底线”的初次验证？
3. 世界观是否划定明确边界？（科技/武力上限、资源逻辑是否防后期崩坏？）
4. 冲突是否脱离低效内耗？（是否转向理念/生存/事业维度的明面博弈？）
5. 群像角色是否具备独立动机与人生轨迹？（拒绝纯工具人）
6. 剧情推进是否严格遵循预设骨架？（有无偏离主线的设定堆砌或冗余支线？）
7. 功能性设定（AI/改造/身份）是否具备剧情必要性？（删掉是否影响主线？）
8. 节奏是否设置“高潮-缓冲-关系推进”循环？（防读者疲劳与情绪透支）
9. 是否预留影视化/短故事改编的“名场面”与“关系张力点”？
10. 作者近期输入是否匹配当前题材？（语感、节奏、逻辑是否稳定？）

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 明确“触发事件→决策逻辑→执行动作→连锁反应”。科武背景下，动作必须结合科技/武道规则（例：义体过载→战术规避→能量反噬→环境破坏），杜绝无逻辑开挂或机械降神。 |
| **物理反馈** | 所有超常能力/科技应用必须伴随可感知的物理代价与环境交互（例：高频刃切割的火花与噪音、神经接驳的肌肉痉挛、重力井的骨骼压迫感）。用五感细节锚定虚构设定，防悬浮。 |
| **代价** | 每次关键抉择/能力爆发必须支付明确代价（资源消耗、信任损耗、生理损伤、道德妥协）。代价需直接推动后续剧情或改变人物关系，禁止一次性结算或轻描淡写。 |
| **钩子** | 章末/卷末钩子必须绑定“未解悬念”或“关系转折”。避免纯设定揭秘，优先使用“人物面临两难选择”“互助网络出现裂痕/重组”“技术反噬倒计时”。 |
| **读者预期** | 开篇承诺的“核心命题”（如破局/共生/技术伦理）必须在每卷中段兑现阶段性成果。预期管理：不承诺“无敌爽文”，承诺“智性博弈、代价真实、情感共振”。每10章需有一次预期校准（伏笔回收或关系升级）。 |
