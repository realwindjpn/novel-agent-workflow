# 《科武纪元》编辑学习官｜课程萃取报告
**源文档**：《大神答疑｜新手写作第一步？先动笔再说！》（番茄作家课堂）
**适用体裁**：长篇科幻《科武纪元》、短故事、热点稿
**萃取原则**：剔除动员性表述，仅保留可量化、可校验的编辑规则。

---

## 1 课程核心判断（≤6条）
1. **节奏≠删减**：紧凑感由“因果逻辑完整度+有效细节密度”决定，非单纯压缩篇幅。
2. **伏笔保鲜期**：核心悬念/伏笔兑现周期≤3-5章；超期必须通过环境/对话/道具高频强化，否则期待感清零。
3. **人物即逻辑**：情节推进必须服从角色身份/职业/性格设定，OOC（脱离人设）即毒点。
4. **支线容错机制**：允许支线暂时游离，但必须预留汇合接口；读者留存率优先于大纲严丝合缝。
5. **长篇成长降速**：连载期主角能力/地位成长需刻意放缓，以维持剧情张力与篇幅延展。
6. **情感＞辞藻**：代入感源于日常细节与真实情绪反应，华丽文笔非必需项。

---

## 2 可执行编辑规则（按维度取舍）
| 维度 | 规则（基于原文） |
|:---|:---|
| **开篇** | 不依赖完整大纲，以核心灵感/高概念片段直接切入；首章必须用具体行为/选择立人设，禁用纯设定堆砌。 |
| **节奏** | 大事件必写前因后果；用心理描写与性格驱动替代流水账；伏笔3-5章内必回收或强化提示。 |
| **冲突** | 冲突设计贴合人物身份与目的；严禁“不该发生在此人身上的事发生”；用现实摩擦/资源争夺引发情绪共振。 |
| **人物** | “小事显性格”原则（如消费选择、微习惯）；主角可缺席2-3章，但配角/反派戏份必须服务主线逻辑；长篇主角成长曲线需平缓。 |
| **题材** | 现实/群像以“身边琐事+普通人真实反应”为情绪引擎；多灵感可融合为单元事件，通过人物关系网嵌入主线。 |
| **改编** | 情节需具备强视觉锚点与情绪爆点；用具体行为/物件替代抽象心理，便于短剧/漫画分镜转化。 |
| **平台规则** | 番茄算法重留存与互动；利用评论区长评反哺剧情走向；支线可灵活调整，以读者追读/段评数据为准绳。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **伏笔3-5章回收**：适用于科技树解锁、武道境界瓶颈、外星遗迹坐标、机甲核心参数等硬设定。
- **人物锚定/OOC规避**：驾驶员/修士的行为必须符合其训练体系、生理极限与阵营立场，禁用“为爽而越权”。
- **支线容错与汇合**：多星球/多舰队/多宗门叙事可分线推进，但需通过“核心能源/武道传承/共同危机”强制收束。
- **成长降速**：用“技术冷却/资源配额/神经负荷/法则反噬”拖慢升级节奏，防止战力通胀。
- **细节驱动节奏**：硬核设定（如跃迁原理、灵能回路）需用因果逻辑写透，避免“设定跳过”导致节奏虚浮。

### ⛔ 不可硬套点（需科幻化改造）
- **“现实题材琐事代入”**：科幻需将“日常琐事”升维为“生存/资源/技术伦理冲突”，直接套用职场压榨会削弱科武质感。
- **“主角连续缺席2-3章”**：长篇科幻若主角长期掉线易导致世界观失焦；需改为“主角视角受限（如休眠/通讯静默/意识上传）但暗线同步推进”。
- **“不写大纲想到哪写到哪”**：科幻长篇涉及严密设定与科技树，完全无大纲易导致逻辑崩坏；需保留“核心设定锚点+动态大纲（每10章校准一次）”。

## 4 编辑检查表（10条以内）
- [ ] 本章核心事件是否具备完整前因后果？有无为赶进度跳过关键逻辑链？
- [ ] 伏笔/悬念是否超3章未提及？若超期，是否已用环境/对话/道具进行二次强化？
- [ ] 角色行为是否严格匹配其当前身份/职业/性格设定？有无OOC强行推进剧情？
- [ ] 人物塑造是否通过具体行为/选择展现？有无直接使用形容词贴标签？
- [ ] 支线剧情是否预留了与主线汇合的接口（如共享道具/信息/危机）？
- [ ] 主角战力/能力成长是否受限于当前资源/技术/生理代价？有无越级碾压？
- [ ] 连续2章以上无主角视角时，配角/反派行动是否直接推动主线核心矛盾？
- [ ] 科幻/武道设定描写是否转化为可感知的物理反馈或行为代价？有无纯设定说明？
- [ ] 章末是否设置明确钩子（悬念/危机/选择）以承接下章？
- [ ] 评论区读者核心诉求/疑问是否已在本章或下章大纲中安排回应？

## 5 对作家角色的输入要求
| 要素 | 编辑输入标准（作家交稿前自检） |
|:---|:---|
| **动作链** | 必须呈现“触发条件→决策依据→执行步骤→直接结果”闭环。科武场景需明确能量流转/机械运作/招式衔接的物理步骤，禁止跳跃式动作。 |
| **物理反馈** | 任何超常能力/科技装备生效时，必须伴随可量化的环境破坏、机体负荷、感官变化（如金属疲劳、重力异常、神经刺痛、灵能灼烧）。 |
| **代价** | 每次关键行动/升级必须支付明确代价（冷却时间、资源消耗、器官损伤、道德妥协、阵营信誉下降）。禁止无损耗开挂。 |
| **钩子** | 章末必须抛出“未解变量”（如异常读数、敌袭预警、背叛线索、技术反噬征兆），且需与当前人物目标强绑定，禁用空泛悬念。 |
| **读者预期** | 需提前3章内通过细节/对话建立预期（如“该机甲未测试过跃迁”“此功法反噬经脉”），并在兑现时提供符合逻辑的惊喜或反转。禁止机械降神。 |
