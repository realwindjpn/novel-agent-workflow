# 《科武纪元》编辑学习官｜课程提炼与执行手册

## 1 课程核心判断（≤6条）
1. **节奏即主线推进率**：无关描写必须剔除，每章需绑定明确目标与冲突锚点，杜绝纯设定铺陈。
2. **规则一致性是类型文底线**：核心设定（能量/战力/科技树）需清单化管理，关键情节强制对照，严禁前后吃书。
3. **冲突需三段式闭环**：前置铺垫（3-5章线索）→爆发对抗→后置余波（1-2章世界线/人设/势力变动），孤立高潮无效。
4. **爽点必须“先抑后扬+快反馈”**：遵循“小冲突→快解决→强反馈”周期，延迟兑现≤3章，否则流失率陡增。
5. **爽点需矩阵化分布**：打脸/升级/智斗/逆袭/情感需交替出现，单一模板堆砌必致审美疲劳。
6. **主角必须是冲突与爽点的绝对触发核心**：拒绝旁观式铺垫，所有事件必须转化为主角的行动跳板。

## 2 可执行编辑规则（按文章逻辑取舍）
| 维度 | 规则指令 |
|:---|:---|
| **开篇** | 3章内必须切入主线冲突或生存危机；禁用纯世界观说明书；首章结尾需抛出核心悬念或阶段性目标。 |
| **节奏** | 执行“目标-阻碍-破局”单章循环；场景/情节转换必须通过人物行动、心理变化或道具线索自然衔接；每章结尾强制留钩子。 |
| **冲突** | 高潮前3-5章埋设递进线索（反常行为/道具信息/规则漏洞）；高潮后1-2章强制描写“高潮带来的实质改变”（主线推进/战力重构/关系洗牌）。 |
| **人物** | 能力突破必须绑定“前置资源获取+规则契合”；反派需具备逻辑动机与阶段性压制力，拒绝无脑工具人；主角成长需伴随认知/战术迭代。 |
| **题材** | 建立“核心规则清单”（能量守恒/武道境界/科技代差），写作中逐项核对；奇观/设定必须服务于冲突推进，禁止独立展览。 |
| **改编** | 提取“主角核心触发”原则：删减支线旁观剧情，将多线事件收束至主角决策链；保留“多重矛盾叠加”结构，适配影视/短剧的快节奏爆点需求。 |
| **平台规则** | 严格遵循3-5章一小爽周期；爽点爆发必须伴随具象化反馈（地位跃升/资源到账/数据面板/他人反应）；主角脱离主线剧情不得超过2章。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移）
- **规则清单化**：完美契合《科武纪元》的“科技树+武道体系”双轨设定，可建立《科武设定校验表》（如：灵能回路负载阈值、机甲能源衰减曲线、境界突破前置条件）。
- **先抑后扬+快反馈**：适用于科武越级反杀、装备迭代、战术破解等场景，能快速建立“技术/武道压制→破局→战利品/数据反馈”的爽感闭环。
- **高潮后置影响**：适合描写星际战役/武道大比后的势力版图重组、科技专利垄断、武道法则公开等长线剧情推进。
- **主角核心触发**：科武文最忌“战力悬浮”，强制主角主导破局可避免机械降神与体系崩坏。

### ⛔ 不可硬套点（需类型化改造）
- **“3-5章一小爽”频率**：长篇科武需拉长为“副本/卷”节奏，高频打脸会稀释科幻史诗感与武道厚重感；短故事/热点稿可保留原频率。
- **“他人震惊”反馈模板**：硬核科武需将情绪化震惊转化为“战术推演验证/物理现象观测/系统数据跳变/武道威压具象化”，避免都市小白文质感。
- **都市/娱乐圈打脸逻辑**：不可直接套用于星际战争或高维武道对决；需替换为“科技代差碾压/武道法则破解/资源链切断/规则级反制”。

## 4 编辑检查表（10条以内）
1. 本章是否推动主线？有无≥1个明确目标？
2. 场景/情节转换是否有行动、心理或道具过渡？
3. 核心设定（能量/战力/科技）是否前后一致？有无吃书？
4. 冲突爆发前3-5章是否埋设有效线索链？
5. 高潮结束后1-2章是否描写了势力/人设/世界观的实质改变？
6. 爽点是否遵循“先抑后扬”？延迟兑现是否≤3章？
7. 爽点类型是否≥2种（智斗/逆袭/资源/情感等）？
8. 主角是否为当前冲突/爽点的绝对触发核心？
9. 反馈是否具象化（地位/资源/数据/物理现象）？
10. 是否已删除与主线无关的纯设定说明或日常流水账？

## 5 对作家角色的输入要求
| 维度 | 执行标准（基于课程逻辑） |
|:---|:---|
| **动作链** | 必须呈现“情报获取→战术决策→执行受阻→变招/代价支付→破局”完整逻辑链；禁用“意念一动/突然爆发/天降神兵”跳过过程。 |
| **物理反馈** | 科武交互必须伴随可观测的物理/能量现象（装甲形变、灵能逸散、重力异常、神经负荷、数据跳变）；禁用纯形容词堆砌战力。 |
| **代价** | 每次越级破局或爽点爆发必须支付明确代价（能源枯竭、装备损毁、境界反噬、势力仇恨升级、规则反噬）；杜绝无成本开挂。 |
| **钩子** | 章末必须抛出“未解变量”（新威胁/规则漏洞/身份疑云/资源倒计时/战术盲区）；禁用“本章完/休息/日常收尾”式断章。 |
| **读者预期** | 铺垫期明确承诺“破局路径/收益类型”，兑现期严格匹配预期；若需反转，必须在预期框架内提供更高阶逻辑支撑（如科技降维/武道法则克制），禁止脱离设定的机械降神。 |
