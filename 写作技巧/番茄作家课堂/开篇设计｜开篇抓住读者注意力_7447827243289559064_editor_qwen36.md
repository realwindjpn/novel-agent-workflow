# 《科武纪元》编辑学习官｜《开篇设计》课程萃取

## 1 课程核心判断（≤6条）
1. **开篇首选剧情切入**：以危机/阻力直接制造紧张感，场景切入仅适合文笔极强的作者，新人强推剧情切入保读完率。
2. **设定后置原则**：严禁开篇堆砌世界观/体系说明书，所有设定必须依附于“危机解决过程”自然释放。
3. **主动引爆逻辑**：剧情不能平铺，必须采用“小异常铺垫→好奇升级→直接引爆”的阶梯式结构。
4. **角色功能化铁律**：前五章出场角色必须携带明确功能（推剧情/塑情绪/助主角），无作用者直接删除。
5. **极简主线+强能动性**：开篇只留一条清晰主线，主角必须“知境遇、明目标、有动作”，拒绝多线杂糅与被动游荡。
6. **钩子循环定生死**：节奏核心是“钩子起势→叙事推进→悬念/情绪收尾→新钩子”，利用反差与锚点维持追读预期。

## 2 可执行编辑规则
| 维度 | 编辑执行标准 |
|:---|:---|
| **开篇** | 首章前300字内必须出现明确危机/异常事件；禁止纯环境渲染或设定科普；采用“对话/突发状况/金手指降临”直接切入。 |
| **节奏** | 执行“三章一循环”：Ch1抛危机+留钩子；Ch2推演+情绪压制+新伏笔；Ch3-4破局+高潮+次级悬念。每章结尾必须切断在“未解变量”处。 |
| **冲突** | 冲突必须阶梯升级（物理阻碍→逻辑反常→生存威胁）；利用“常识与异常的反差”制造张力，禁止一次性抛出所有矛盾。 |
| **人物** | 实行“角色功能审查制”：每个出场人物需标注【剧情作用/情绪价值/资源关联】；主角必须具备主动决策链，禁止“等救援/纯观察”。 |
| **题材** | 悬疑/科幻/都市通用“主动引爆”模型；历史/穿越可叠加“身份认知差+玩梗锚点”快速建立期待；短故事需压缩铺垫期，首章即引爆。 |
| **改编** | 开篇需预留“视觉化锚点”（如特殊装备/异常体征/标志性动作），便于后续漫画/短剧分镜提取；避免纯内心独白或抽象概念。 |
| **平台规则** | 适配番茄算法：前三章决定推荐池；段落≤4行，长句拆分；信息密度高但阅读门槛低；钩子设计直接拉升“读完率”与“加入书架率”。 |

## 3 科武适配
### ✅ 可用点
- **危机切入直接转化**：开篇即遭遇科武体系下的生存危机（如机甲能源骤降、基因链排异、星舰气闸失效），符合“剧情切入”保读完率逻辑。
- **设定动作化释放**：通过主角调试外骨骼、重写武学代码、排查辐射泄漏等“操作流”动作，自然带出科武纪元底层规则，规避说明书式开篇。
- **阶梯冲突适配**：物理危机（断能/缺氧）→ 逻辑危机（AI指令与人类战术冲突）→ 生存危机（敌对机甲/异种逼近），完美契合“铺垫-升级-引爆”模型。
- **反差锚点构建**：在“高科技/重火力压制”环境下，主角使用“原始武道/冷兵器/肉身极限”破局，形成强视觉与认知反差，拉升期待值。

### ❌ 不可硬套点
- **纯悬疑恐怖元素**：原文“猫眼/血手/拖拽”等灵异氛围不可直接照搬，需转化为“科幻逻辑下的未知威胁”（如暗物质泄漏、神经接口劫持、逻辑死循环）。
- **玩梗/历史反差**：硬科幻语境下玩梗易出戏，需替换为“科武常识与主角行为的认知差”（如全员依赖义体，主角徒手拆解核心回路）。
- **情绪驱动替代物理逻辑**：科武题材严禁为追求快节奏牺牲设定自洽；所有破局必须遵循能量守恒/机械负载/生理极限，代价与反馈必须严谨可量化。

## 4 编辑检查表（10条）
1. [ ] 首章前300字是否已出现明确危机/异常事件？（否→打回）
2. [ ] 开篇是否包含＞200字纯世界观/体系设定说明？（是→删减并融入动作）
3. [ ] 冲突是否呈现“铺垫→升级→引爆”阶梯结构？（否→调整事件顺序）
4. [ ] 前五章出场角色是否均标注明确功能？（无→删除或合并）
5. [ ] 主角是否具备清晰当前目标与主动破局行为？（否→增加决策链）
6. [ ] 每章结尾是否设置有效钩子（悬念/危机/新线索）？（否→重写章末）
7. [ ] 是否存在“主角被动等待/漫无目的游荡”＞500字？（是→强制介入事件）
8. [ ] 科武设定是否通过“操作/战斗/故障排查”动作展现？（否→打回）
9. [ ] 读者心理路径是否清晰：遇险→难解→破局→留疑？（否→梳理主线）
10. [ ] 移动端适配：段落≤4行？长句拆分？无大段心理描写？（否→排版优化）

## 5 对作家角色的输入要求
提交开篇稿件时，必须同步提供以下结构化输入，否则不予进入审稿流程：

| 模块 | 输入要求 |
|:---|:---|
| **动作链** | 必须提供完整闭环：`触发事件 → 主角决策 → 执行动作 → 结果反馈`。禁止纯心理推演或旁观描写。动作需符合科武物理逻辑（如关节扭矩阈值、能量回路负载、神经传导延迟）。 |
| **物理反馈** | 每次关键动作必须附带环境/机体/肉体的实时反馈。需具象化或量化（如：装甲警报频闪频率、肌肉撕裂的乳酸堆积感、能量过载的焦糊味、重力失衡的眩晕秒数）。支撑科幻真实感。 |
| **代价** | 破局必须支付明确代价。禁止“无损耗开挂”。代价需直接推动后续剧情或限制主角能力（如：消耗稀有同位素、神经接口灼伤致短期失明、暴露跃迁坐标、牺牲备用维生能源）。 |
| **钩子** | 每章末必须提交1个“未解变量”。需与主线强关联，标注【悬念类型/预期回收章节】。禁止为悬而悬或脱离科武逻辑的机械降神。 |
| **读者预期** | 需在细纲中标注本章“预期情绪曲线”（紧张→释放→好奇）及“核心看点”（如：反杀/智破/设定揭露）。确保读者心理路径严格遵循“遇险-难解-破局-留疑”模型，偏离需附逻辑说明。 |
