## 一、补丁核心指令（5条铁律）

| # | 指令 | 违规后果 |
|:---|:---|:---|
| 1 | **每一份爽感必须明码标价**——读者享受主角的强大，必须看到等价的痛苦与代价 | 爽感变空转，读者弃文 |
| 2 | **主角可以讨人厌，但动机必须透明**——让读者皱眉的同时能说"我理解" | 人设崩塌，追读断裂 |
| 3 | **形容词是奢侈品**——每用1个形容词，必须配套1个具体物理反馈 | 文字发飘，代入稀释 |
| 4 | **冲突必须从土壤里长出来**——规则碰撞、利益分歧、理念撕裂，拒绝作者强行制造 | 冲突虚假，逻辑崩塌 |
| 5 | **钩子必须指向下一章的具体行动**——读者看完必须知道主角接下来要做什么 | 断章断在空气里，读者流失 |

## 二、可执行动作清单

### 【开篇动作集】

```
✦ 禁做：英雄模板开场（高大上+正能量金句）
✦ 必做：抛出一个具体的"生存困境/性格缺陷/规则冲突"

执行模板：
[处境]（什么人/什么处境）+ [具体威胁/缺陷]（什么要命的事）+ [行动悬念]（他现在要做什么）
```

**示例：**
> 债主的电话打到第三遍，我才把藏在枕头底下的刀片往手腕比了比。
> 不是自杀，是练习。——如果还不上钱，明天就该轮到他们练我了。

| 标注 | 说明 |
|:---|:---|
| 🐺短篇/狼人篇 | 困境可更个人化、情绪化，如"身份认同危机""情感撕裂" |
| ⚔️科武长篇 | 困境必须绑定世界观规则，如"基因资质D级""阵营归属冲突""资源匮乏" |

---

### 【战斗动作链模板】

```
✦ 禁用："突然爆发""莫名其妙反杀""眼神杀人"
✦ 必做：完整逻辑链——触发条件→态势评估→资源调用→执行路径→结果判定
```

**执行模板：**
```
1. 触发：敌人做了什么动作/我感知到什么信号
2. 评估：（我当前状态：体能__成/能量__格/装备__）
3. 调用：我决定用___（技能/装备/环境物）
4. 路径：具体操作——手怎么动/脚怎么移/能量怎么流
5. 判定：（代价）这一招打完，我会___
```

**示例：**
> 触发：他的拳头带着蓝光朝我面门砸来。
> 评估：闪避来不及了，左肩还有旧伤，能量只剩两格。
> 调用：只能用那招——把能量集中在右臂硬接。
> 路径：身体下沉，重心后压，右臂内侧神经接口过载0.3秒——
> 判定：他的拳劲被卸掉七成，但我的前臂骨裂了。下一招，我只能用左手了。

| 标注 | 说明 |
|:---|:---|
| ⚔️科武长篇 | 战斗必须绑定规则体系——能量消耗/冷却时间/装备过热/身体负荷 |
| 🐺短篇/狼人篇 | 战斗可简化，重点放在心理博弈与即时选择 |

---

### 【心理反馈动作】

```
✦ 禁用：空泛情绪词（"他很愤怒""她很悲伤"）
✦ 必做：用生理/行为/环境反应替代情绪描写
```

**执行模板：**
```
情绪→ 身体反应 + 行为动作 + 环境变化（三选二）
```

**示例：**
> 他说"我们分手吧"。
> 我没有哭，只是发现自己在拆第五包烟。烟灰缸满了，我才意识到已经过了两个小时。

## 三、代价系统

### 【能力代价矩阵】

| 能力类型 | 必须绑定的代价 | 副作用连锁 |
|:---|:---|:---|
| 能量型超能 | 神经负荷/体能透支/过热 | 下一场战斗能力下降 |
| 科技装备 | 资源消耗/过热/电磁暴露 | 关键时刻没电/被黑 |
| 武技强化 | 肌肉撕裂/骨骼损伤/内脏压迫 | 长期使用导致不可逆损耗 |
| 精神类能力 | 意识模糊/记忆碎片/情感剥离 | 可能波及身边人 |

**执行检查点：** 每当主角使用能力超过2次，立即追问——
> "这次用了，他接下来要付出什么代价？"

---

### 【关键抉择代价】

```
✦ 禁用：主角做重大选择时没有代价/代价被遗忘
✦ 必做：每个关键抉择必须支付三类代价之一
```

| 代价类型 | 示例 | 后续连锁 |
|:---|:---|:---|
| **资源型** | 消耗了唯一的弹药/能量/情报 | 下一阶段资源紧张 |
| **关系型** | 背叛了盟友/伤害了队友/暴露了身份 | 人际网络受损 |
| **道德型** | 杀了不该杀的人/撒了关键谎言/放弃原则 | 心理负担/被抓住把柄 |

**执行模板：**
```
[抉择内容] = [获得什么] + [失去什么] + [这个失去会在第__章引发什么]
```

## 四、失败模式识别清单

> 写完一段后，逐条检查——

### 【爽感空转】
- [ ] 这一段的"爽"有没有配套的代价描写？
- [ ] 主角的强大有没有明确的边界/限制？
- [ ] 读者感受到的情绪有没有物理/行为落点？

### 【人设自相矛盾】
- [ ] 主角的行为和心理动机是否一致？
- [ ] 这个角色此刻的行为，和他前面的人设是否冲突？
- [ ] 如果这个角色让读者讨厌，读者能理解他为什么这么做吗？

### 【冲突虚假】
- [ ] 这个冲突是不是"规则碰撞/利益分歧/理念撕裂"？
- [ ] 反派有没有独立的、合理的行动逻辑？
- [ ] 这个冲突能不能用反派的视角写一遍？

### 【节奏拖沓】
- [ ] 这一段删掉，对主线有没有影响？
- [ ] 有没有超过3行的纯环境描写/情绪描写？
- [ ] 场景切换是否遵循"上一事件已解决/已升级/已揭示"原则？

### 【钩子断裂】
- [ ] 章末最后一句是否指向下一章的具体行动？
- [ ] 读者能不能说出"主角接下来要做什么"？
- [ ] 这个钩子是不是"意外"而不是"悬念"？

## 五、人物口吻模板库

### 【主角口吻】

```
✦ 核心原则：动机透明 + 不美化 + 有缺陷但不讨厌
✦ 句式特点：短句为主/疑问句自问/拒绝鸡汤金句
```

**现实主义型口吻：**
```
"我不信命。但我信概率。"
"他说的对，我没资格怨。我只是……还想再试一次。"
"不是因为我想当好人，是因为当坏人更累。"
```

**科武长篇型口吻：**
```
"能量守恒。我能打出去的能量，一定是我先扛进来的。"
"这世上没有免费的强化，只有还没结清的债。"
"他们说我冷血。我只是把热血留给了值得的东西。"
```

---

### 【反派口吻】

```
✦ 核心原则：有独立逻辑 + 动机可追溯 + 不是纯恶
✦ 句式特点：冷静陈述/哲学化表达/对主角有"合理质疑"
```

**模板：**
```
"我不是因为你坏才杀你，是因为你挡路。"
"你的正义感很感人。但正义不能当饭吃。"
"你以为你在反抗什么？你只是在按剧本演。"
```

---

### 【工具人检测】

```
✦ 问题：如果删掉这个角色，对故事有没有影响？
✦ 解决方案：给每个配角增加一个"只有他会做的事"
```

**示例：**
> 原设定：张三是个普通队友。
> 升级：张三是个普通队友，但他知道城西黑市的情报渠道，这是主角唯一的资源。

## 六、段落节奏模板

### 【日常/过渡段】

```
节奏公式：2:1:1
2句环境/状态 + 1句心理/反思 + 1句悬念推进

目的：建立存在感，但不超过300字必须进入下一个事件
```

### 【冲突升级段】

```
节奏公式：短句×3 + 长句×1
短句：营造压迫感/快速动作
长句：代价揭示/心理转折

目的：让读者喘不过气来
```

**示例：**
> 他逼过来。我退。退到墙角。
> 他笑了，笑得像是已经赢了一样。
> 然后他的枪口抵上了自己的下巴。
> "你想知道真相？那就让真相只剩你一个人知道。"

### 【低潮/沉淀段】

```
节奏公式：慢环境 + 心理自问 + 新线索
目的：给读者喘息空间，同时埋下下一波冲突的种子
长度：单次不超过800字
```

### 【高潮段】

```
节奏公式：快节奏 + 明确代价 + 悬念钩子
禁用：超过3个形容词/情绪渲染超过物理描写
```

**执行：**
```
动作（10字内）+ 反应（10字内）+ 代价（15字内）+ 悬念（20字内）
```

## 七、章末钩子生成器

### 【钩子类型与句式模板】

| 类型 | 句式结构 | 示例 |
|:---|:---|:---|
| **未解冲突** | "他不知道的是___" | "他以为解决了最大的麻烦，不知道真正的麻烦正在他身后醒来。" |
| **认知反转** | "但真相是___" | "她以为自己在保护他，却发现她才是被利用的那个棋子。" |
| **生存危机** | "现在他只有___时间" | "弹药只剩三发，而他们至少还有二十个人。" |
| **规则漏洞** | "他发现了___" | "他终于明白，为什么每次规则都刚好留了一个口子——因为有人想让他赢。" |

### 【禁用钩子】

```
✦ 情绪宣泄型："他的心碎成了玻璃渣"（没有行动指向）
✦ 断章取义型："而这，仅仅是开始"（没有悬念内容）
✦ 纯恐怖型："黑暗中有什么东西在靠近"（无法引导下一章行动）
```

### 【钩子检查三问】

1. **具体性**：读者能不能说出"主角接下来要做什么"？
2. **必然性**：这个悬念是前面情节的必然延伸，还是强行制造的？
3. **代价关联**：这个悬念是否与主角当前的资源/状态/处境绑定？

本补丁基于京祺"写的就是生活"方法论，将编辑规则转译为可执行的作家操作指令。

- **短篇/狼人篇**可借用：心理反馈动作、人设灰度原则、代价系统、人物口吻
- **科武长篇**必须全用：战斗逻辑链、能力代价矩阵、规则体系钩子、长篇防崩机制
- **平台规则**全需转化：作为发布前检查门禁，而非写作时干扰项

**本补丁是工具，不是束缚。** 当你写嗨了忘了一两条，不致命。但当你卡住了、崩了、读者跑了——回去翻对应章节。
