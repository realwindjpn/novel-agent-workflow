# 《科武纪元》作家OS补丁  
## Patch：不满意稿件五步质感提升版

版本：CW-WriterOS-v1.7  
适用：短故事 / 狼人篇 / 科武长篇 / 番茄发布前自检  
核心目标：把“写得不满意”转成可执行修稿动作，而不是陷入空想、重写、查大纲。

---

## 0. 总执行原则

### 写作时默认开启三条规则

1. **先让人物动起来，再反推设定**
   - 不先铺世界观。
   - 不先解释体系。
   - 先写：谁被逼到什么处境，他现在必须做什么选择。

2. **卡住不是停笔信号，是升级信号**
   - 卡住时不回去翻大纲半小时。
   - 先问：  
     > “此刻人物如果真活着，他最不甘心失去什么？”
   - 用这个答案推动下一段。

3. **章节必须付代价**
   - 没有损失的胜利 = 轻飘。
   - 没有后果的冲突 = 水文。
   - 没有选择的行动 = 工具人。

# 一、五步执行补丁

---

## Step 1：开篇钩子补丁

### 写作动作

每章开头前三段必须完成至少一件事：

- 有人正在承受危险。
- 有秘密即将暴露。
- 有利益马上失去。
- 有人做出反常行为。
- 有旧认知被打碎。
- 有身体 / 装备 / 环境出现异常反馈。

### 禁止开头

- 大段设定说明。
- 人物静态回忆。
- “某某世界，强者为尊”式泛化开场。
- 主角醒来、走路、看天、感叹命运，但没有即时问题。
- 先交代组织、境界、科技史，再进入事件。

### 可执行模板

```text
【异常】先写不该发生的事。
【反应】主角立刻判断。
【代价预告】如果不处理，会失去什么。
```

### 示例节奏

```text
不是警报响了。
是他体内那枚早该报废的武神芯片，忽然开始倒计时。

三十秒。

林烬第一反应不是逃，而是按住右臂经脉。
因为上一次倒计时结束，死的是他的师父。
```

### 失败模式

| 失败表现 | 说明 | 修正动作 |
|---|---|---|
| 开头太稳 | 没有读者必须往下看的问题 | 加一个异常或损失倒计时 |
| 先讲背景 | 作者想解释，读者还没关心 | 背景拆成冲突里的反应 |
| 主角旁观 | 主角没有被事件咬住 | 让事件直接损害主角利益 |
| 钩子虚 | 只说“出事了”但不具体 | 写出具体反馈：疼、裂、响、掉线、流血 |

### 可借点

- **短故事 / 狼人篇可借点**：开头直接给尸体、投票、背叛、身份暴露风险。不要先讲村规。
- **科武长篇可借点**：开头直接给功法异常、芯片失控、战甲锁死、异能污染、师门追杀。

---

## Step 2：人物主动性补丁

### 写作动作

每章主角必须有一条清晰动作链：

```text
动机源 → 决策点 → 行动 → 结果 → 反应 → 下一步选择
```

### 判断标准

把主角换成另一个性格的人，如果剧情还能照样发生，说明主角是工具人。

### 人物必须带一个“背后故事按钮”

不是长篇回忆，而是能解释他为什么这样做的一句话。

例如：

```text
他不是不怕死。
他只是十七岁那年亲眼看见，犹豫三秒的人，会害死整支小队。
```

### 主角口吻要求

《科武纪元》主角口吻建议：

- 冷静但不麻木。
- 能计算代价，但不是机器。
- 面对强敌不嘴炮求饶，先观察破绽。
- 情绪压在动作里，而不是长篇喊出来。
- 爽点来自“判断准 + 下手狠 + 付得起代价”。

### 可用句式

```text
“我知道这不划算。”
“但如果今天退了，明天就没人敢站在这里。”

“别给我讲胜率。”
“告诉我，哪一条路能让他们付出代价。”
```

### 失败模式

| 失败表现 | 修正动作 |
|---|---|
| 主角一直被通知、被安排、被带走 | 给他一个违背安排的主动决定 |
| 主角做事只因剧情需要 | 补一个过往伤口或当下执念 |
| 主角没有独特反应 | 写出他区别于普通人的选择 |
| 主角只会喊狠话 | 让狠话后面立刻跟行动和代价 |

### 可借点

- **短故事 / 狼人篇可借点**：每个玩家发言都要服务个人立场。狼人不能只是“坏”，好人不能只是“正义”。
- **科武长篇可借点**：主角每次升级、战斗、救人、背叛，都要和他的科技背景 / 武道经历有关。

---

## Step 3：冲突选择题补丁

### 写作动作

冲突不要写成单轨任务，要写成选择题。

错误：

```text
主角必须去救人。
```

正确：

```text
主角可以救人，但会暴露隐藏身份。
主角可以不救，但会失去唯一知道真相的人。
```

### 每章至少设计一个二岔路

常用二岔路：

| 选择A | 选择B |
|---|---|
| 救人 | 保密 |
| 复仇 | 活命 |
| 拿资源 | 守原则 |
| 完成任务 | 保护队友 |
| 公开真相 | 暂时背锅 |
| 使用禁术 | 保住身体 |
| 信任敌人 | 独自硬扛 |

### 冲突写法模板

```text
1. 把主角逼到不能两全的处境。
2. 让他选择。
3. 立刻给结果。
4. 给结果附带代价。
5. 让旁人对他的选择产生新判断。
```

### 物理反馈要求

科武文不能只写“他赢了”。

必须写：

- 伤到了哪里。
- 装备损坏到什么程度。
- 能量消耗多少。
- 环境被破坏成什么样。
- 身体是否出现后遗症。
- 技术是否留下痕迹。
- 敌人是否获得情报。

### 示例

```text
林烬一刀斩断机械脊椎。

代价是右臂经脉被反震撕开，武神芯片温度飙到九十七度。
他闻到皮肉被烫熟的味道。

系统弹出警告：

【再调用一次，你会永久失去右手精细控制。】
```

### 失败模式

| 失败表现 | 修正动作 |
|---|---|
| 主角一路顺 | 加资源损耗、身体伤势、关系破裂 |
| 冲突只是打架 | 加选择题：打赢也要失去某物 |
| 敌人像靶子 | 给敌人判断、反制、目标 |
| 选择没后果 | 下一章必须承接本章代价 |

### 可借点

- **短故事 / 狼人篇可借点**：投票即选择题。每票都要牺牲信任、暴露立场或换取信息。
- **科武长篇可借点**：战斗不只是赢，还要损耗功法根基、科技装备、人脉、情报优势。

---

## Step 4：段落节奏补丁

### 基础段落节奏

推荐使用：

```text
短句制造冲击。
中句承接判断。
长句用于情绪或信息压缩。
```

### 战斗段节奏

```text
动作 → 反馈 → 判断 → 反制 → 代价
```

示例：

```text
刀落。

护盾没有碎，只是凹进去一寸。

林烬眼神一沉。
不是能量盾，是力场折叠。

他立刻收刀，反手把半截刀柄钉进地面。
下一秒，整条街的重力翻转。
```

### 对话段节奏

每轮对话必须有变化：

```text
试探 → 撞击 → 暴露 → 反转
```

不要写成互相解释设定。

### 对话修正原则

写完后问：

> “如果这是现实中的人，他会这么说吗？”

如果不会，就改短、改狠、改具体。

### 人物口吻区分

| 角色 | 口吻 |
|---|---|
| 主角 | 冷静、压怒、判断优先 |
| 老师 / 前辈 | 少解释，多点破 |
| 科技派反派 | 用数据、概率、实验称呼人 |
| 武道派反派 | 用境界、血性、传承压人 |
| 狼人篇角色 | 每句话都可能在藏身份、带节奏、试探别人 |
| 队友 | 不只捧主角，要有自己的恐惧、误判、底线 |

### 失败模式

| 失败表现 | 修正动作 |
|---|---|
| 段落全一样长 | 战斗和惊变处改短句 |
| 对话像作者讲课 | 每句对话加目的：试探、威胁、遮掩、求救 |
| 情绪靠喊 | 改成动作反馈：手抖、闭眼、停顿、错杀 |
| 信息塞太多 | 拆进动作、物件、伤口、误会里 |

---

## Step 5：章末钩子补丁

### 章末必须留下一个明确问题

章末钩子不是“欲知后事如何”，而是让读者产生一句具体问题：

```text
他为什么没死？
芯片里到底是谁的声音？
队友为什么投了主角？
敌人为什么提前知道他的路线？
主角这次使用禁术会付出什么后果？
```

### 钩子类型

| 类型 | 用法 |
|---|---|
| 悬念钩 | 揭出未知信息，但不解释 |
| 反转钩 | 当前胜利变成新危机 |
| 情绪钩 | 人物关系爆裂，读者想看回应 |
| 设定钩 | 世界规则出现异常，读者想知道真相 |
| 危机钩 | 下一章开局必须处理的危险 |

### 章末模板

```text
【表面结果】主角似乎解决了当前问题。
【异常反馈】某个细节不对。
【新问题】更大的危险或真相浮出。
```

### 示例

```text
林烬拔出断刀，确认那具机械尸体已经停止供能。

可下一秒，他的私人频道亮了。

频道编号来自三年前。
发送人：师父。

只有一句话——

“别相信现在的我。”
```

### 失败模式

| 失败表现 | 修正动作 |
|---|---|
| 章末只是睡觉、回家、结束 | 加异常、追兵、信息、关系爆点 |
| 钩子和主线无关 | 钩子必须指向下一章行动 |
| 钩子太模糊 | 写出读者问题原句 |
| 每章都靠新敌人 | 交替使用情绪钩、设定钩、代价钩 |

### 可借点

- **短故事 / 狼人篇可借点**：章末落在“票型反常 / 身份疑点 / 死者遗言 / 预言家真假”。
- **科武长篇可借点**：章末落在“芯片异常 / 功法反噬 / 势力背叛 / 科技真相 / 境界代价”。

# 三、章节自检清单

写完一章后，逐项打钩。

## A. 开篇检查

- [ ] 前三段是否出现钩子？
- [ ] 是否有具体异常、危险、秘密或损失？
- [ ] 是否避免了大段世界观说明？
- [ ] 读者是否能在一分钟内知道“现在出了什么事”？

## B. 人物检查

- [ ] 主角本章是否主动做出决定？
- [ ] 这个决定是否来自他的背景、执念或上一章遗留事件？
- [ ] 把主角换成别人，本章剧情是否会明显不同？
- [ ] 配角是否有自己的目的，而不是只负责解释或捧主角？

## C. 冲突检查

- [ ] 本章是否有一个不能两全的选择题？
- [ ] 主角是否为选择付出代价？
- [ ] 敌人是否有反制能力？
- [ ] 冲突是否推动了剧情，而不是原地打斗？

## D. 反馈检查

- [ ] 战斗 / 行动后是否有身体反馈？
- [ ] 装备、芯片、功法、环境是否产生变化？
- [ ] 胜利是否留下后遗症？
- [ ] 失败是否造成下一章必须处理的问题？

## E. 节奏检查

- [ ] 战斗段是否短句更密？
- [ ] 信息是否拆进动作和对话，而不是集中讲解？
- [ ] 对话是否有试探、威胁、隐瞒、反击？
- [ ] 是否删掉了不推动剧情、不揭示人物、不制造情绪的段落？

## F. 章末检查

- [ ] 章末是否有钩子？
- [ ] 钩子类型是否明确？
- [ ] 是否写得出读者下一章想问的问题？
- [ ] 下一章是否能立刻承接这个问题？

## G. 科武设定检查

- [ ] 功法消耗是否稳定？
- [ ] 科技等级是否前后一致？
- [ ] 势力行为是否符合利益逻辑？
- [ ] 是否为了爽点破坏了世界规则？
- [ ] 如果破坏规则，是否给出代价或伏笔？

## H. 发布门禁

- [ ] 章节名是否有冲突感？
- [ ] 是否适合移动端阅读，段落不过长？
- [ ] 是否存在平台敏感风险？
- [ ] 开篇是否适合读完率测试？
- [ ] 章末是否适合提升跟读？

# 四、短故事 / 狼人篇专项可借点

## 1. 开局

狼人篇不要慢热。第一屏必须出现：

- 死人。
- 票型异常。
- 身份暴露风险。
- 关键角色撒谎。
- 主角被迫站队。

## 2. 人物

每个角色发言前先写清楚：

```text
他想让谁相信他？
他想让谁被怀疑？
他真正害怕暴露什么？
```

## 3. 冲突

狼人篇核心不是“谁是狼人”，而是：

```text
谁在控制信息？
谁在制造错误共识？
谁被迫用真话撒谎？
```

## 4. 章末钩子

优先使用：

- 票型反转。
- 死者遗言。
- 双预言家对跳。
- 主角发现自己身份牌不对。
- 所有人都说谎，但有一个人说的谎不为活命。

---

# 五、科武长篇专项可借点

## 1. 可弃的是章节小路，不可弃的是卷级骨架

允许临场调整：

- 单章冲突顺序。
- 配角临时反应。
- 战斗细节。
- 某个小反转。
- 支线进入方式。

不可随便推翻：

- 境界体系。
- 科技上限。
- 大势力利益关系。
- 主角长期目标。
- 关键伏笔。
- 卷终爆点。

## 2. 科武比例要按卷规划

每卷提前确认：

```text
本卷偏科：科技阴谋、芯片、实验、机甲、数据污染。
本卷偏武：境界突破、宗门、传承、肉身极限、武道意志。
本卷融合点：科技解释武道，或武道反制科技。
```

## 3. 科武人物不能只有战力标签

每个重要角色至少有：

```text
一个技术/武道立场。
一个私人伤口。
一个不愿退让的底线。
一个会影响剧情的错误判断。
```

## 4. 升级必须有代价

禁止：

```text
突破了。
变强了。
众人震惊。
```

必须补：

```text
突破消耗什么？
身体坏了哪里？
谁因此盯上主角？
主角获得力量后失去什么选择？
```

# 六、平台规则转化为发布 / 包装 / 风险门禁

## 1. 发布门禁

发布前检查：

- 开篇是否能承接读完率。
- 章末是否能承接跟读率。
- 本章是否有可截图传播的爽点 / 反转 / 金句。
- 是否连续两章没有有效代价。
- 是否连续两章只铺设定不推进事件。

若出现以下情况，暂缓发布：

```text
前三段无钩子。
主角无主动选择。
本章无代价。
章末无问题。
设定与前文冲突。
```

## 2. 包装门禁

章节名优先突出：

- 危机。
- 反转。
- 身份。
- 代价。
- 爽点。

示例：

```text
《武神芯片开始倒计时》
《他投了自己一票》
《禁术启动，代价是右手》
《师父的尸体发来了消息》
```

避免：

```text
《新的开始》
《前往学院》
《初见》
《修炼》
《会议》
```

## 3. 风险门禁

涉及以下内容时要降级处理：

- 过度血腥细节。
- 极端暴力宣泄。
- 现实敏感影射。
- 未成年人极端伤害描写。
- 过度阴暗无出口。
- 违法行为被美化且无后果。

处理方式：

```text
血腥细节 → 改成结果反馈。
极端暴力 → 改成战斗后果。
敏感影射 → 架空化、势力化、技术化。
阴暗情绪 → 给人物行动出口。
违法行为 → 给代价、惩罚或道德反噬。
```

# 七、作家OS执行口令

写作时遇到“不满意”，不要重开文档，按以下顺序排查：

```text
1. 开头有没有钩子？
2. 主角有没有主动选择？
3. 冲突有没有二岔路？
4. 行动有没有物理反馈？
5. 胜利有没有代价？
6. 对话有没有目的？
7. 章末有没有下一章问题？
```

如果任意一项没有，优先补这一项，不要先重写整章。

# 八、最终补丁规则

以后《科武纪元》每章默认执行：

```text
无钩子，不开章。
无选择，不成戏。
无反馈，不落地。
无代价，不算赢。
无问题，不收章。
```

该补丁适用于短篇爆点、狼人身份局、科武长篇章节推进。短篇可以大胆由心写；长篇只允许章节级失控，卷级骨架必须稳定。
