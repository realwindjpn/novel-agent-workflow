# 一、核心写作指令更新

## 1. 开篇150字执行令

每章/短篇开头必须快速交付：

> 身份反差 + 反常事件 + 外部挑衅 + 可量化伤害 + 反击悬念物

### 可直接套用句式

#### 科武长篇可借点

- “我是联邦最年轻的灵能审计员，却在武院考核当天，被人当众撕毁了我的义体产权证明。”
- “我只是边境矿区的废脉武徒，可议会今天要收走我父亲留下的轨道居住权。”
- “我的AI辅修系统沉默了三年，直到同门抢走我的专利锁，它第一次在脑中开口：‘允许反击。’”

#### 短故事/狼人篇可借点

- “我是狼人族最弱的灰毛雌性，却在满月祭当天，听见首领宣布要把我的兽印转让给妹妹。”
- “全族都说我没有狼魂，直到未婚夫当众把我的巢穴钥匙递给了白月光。”
- “他们让我跪下认错，可我低头看见祖母留下的银牙吊坠正在发烫。”

# 二、冲突单元补丁

## 每个冲突必须写成“四件套”

| 字段 | 必填内容 | 示例 |
|---|---|---|
| 挑衅 | 反派当众夺走/羞辱/伤害 | 抢专利、撕契约、夺能源配额、废武籍 |
| 忍 | 主角暂时不反击，但必须有理由 | 证据未齐、身份不能暴露、系统冷却、要引蛇出洞 |
| 爆 | 主角用具体物/机制反击 | 专利锁反噬、审计令、义体权限覆写、兽印觉醒 |
| 兑现 | 反派付出可视代价 | 当众跪、账户冻结、武脉崩裂、身份曝光 |

# 三、动作链补丁

## 禁止写法

- “后来我反击了。”
- “于是他们付出了代价。”
- “我冷笑一声，所有人都震惊了。”

## 必须写成连续动作

每个冲突场景至少3步动作。

### 科武动作链模板

> 擦掉嘴角血迹 → 扫描被撕毁的契约碎片 → 启动备份审计权限 → 三秒后，反派义体锁死在众人面前。

### 狼人/短故事动作链模板

> 捡起被踩碎的兽印牌 → 咬破指尖滴血 → 银牙吊坠发烫 → 祖灵狼影从祭坛后站起。

### 现实痛点短故事动作链模板

> 拍下对方砸门视频 → 第二天去管理处调监控 → 当晚律师函送到门口 → 第三天新门禁刷脸系统上线。

# 四、反馈描写补丁

## 1. 伤害必须有物理反馈

不要只写“我很痛苦”。

要写：

- 嘴角血滴在白色考核服上。
- 契约纸被撕成两半，芯片裸露出烧焦的铜线。
- 义体过载，膝盖关节发出“咔”的一声。
- 狼爪划破掌心，血顺着银牙吊坠往下滴。
- 能源阀关闭后，舱室温度从21度跌到3度。

## 2. 情绪描写比例

动作：反馈：情绪 = 5：3：2

### 可执行规则

每写1句“我愤怒/委屈/心寒”，前后必须配2句动作或物件变化。

# 五、代价补丁

## 主角反击前，必须先埋代价

无代价反击 = 爽感变薄。

### 可选代价库

#### 科武长篇可借点

- 暴露隐藏身份。
- 损耗灵能核心。
- 启动一次性审计权限。
- 失去武院参赛资格。
- 义体进入72小时冷却。
- 与家族/军部/财团彻底撕破脸。
- 引来更高层势力追查。

#### 短故事/狼人篇可借点

- 狼魂提前觉醒，寿命缩短。
- 与族群断亲。
- 失去旧巢穴继承权。
- 祖灵契约反噬。
- 当众挑战首领，输了会被逐出领地。
- 撕毁婚约后失去保护身份。

### 代价埋法

反击前1—2段必须出现：

> “这枚审计令只能用一次。”  
> “一旦开启祖狼印，我就再也不是这个族群的人。”  
> “义体核心还没修好，强行覆写权限，我可能三天不能动武。”

# 六、失败模式补丁

以下情况进入重写。

## 1. 世界观先行失败

### 错误

开头三段都在讲联邦、武道等级、旧纪元历史。

### 修正

先写：

> 谁被欺负？  
> 被抢了什么？  
> 凭什么反击？  
> 反击要付出什么？

世界观只允许夹在动作里释放。

---

## 2. 抽象冲突失败

### 错误

“他们看不起我。”  
“命运不公。”  
“体制压迫普通人。”

### 修正

必须落成具体物：

- 居住权。
- 能源配额。
- 武院名额。
- 专利归属。
- 义体权限。
- 狼族兽印。
- 婚前财产。
- 祖屋地契。
- 铁盒/吊坠/芯片/契约书。

---

## 3. 嘴炮反击失败

### 错误

主角用一段话骂赢全场。

### 修正

反击必须可视化：

- 账户冻结。
- 门禁失效。
- 义体锁死。
- 审计投影公开证据。
- 能源墙启动。
- 兽印转移失败。
- 反派跪地吐血。
- 被夺走的东西自动回归主角名下。

---

## 4. 反派虚化失败

### 错误

反派是“联盟”“天道”“世俗眼光”。

### 修正

必须落成具体人：

- 同门师兄。
- 武院导师。
- 财团代表。
- 继母。
- 未婚夫。
- 族长。
- 首领白月光。
- 审判席上的议员。

---

## 5. 反差不足失败

### 错误

主角只是“很强”“很惨”“很聪明”。

### 修正

加两级反差：

- 废脉武徒 + 灵能专利持有人。
- 边境矿奴 + 联邦审计官遗孤。
- 义体残废 + 旧纪元武神适配者。
- 灰毛狼人 + 祖狼真血。
- 被退婚雌性 + 狼王契约真正继承人。
- 奶弱外表 + 成人意识/非人智核。

# 七、人物口吻补丁

## 1. 科武主角口吻

关键词：冷、准、克制、带技术判断。

### 示例

- “你撕的不是废纸，是联邦第七类灵能专利原件。”
- “三秒后，你的义体会跪下。不是因为我强，是因为权限属于我。”
- “我可以忍羞辱，但你不该动我父亲留下的居住权。”
- “审计开始。所有伪造记录，公开投影。”

## 2. 狼人/短故事主角口吻

关键词：狠、直、情绪浓、带血性。

### 示例

- “你可以不要我，但不能拿我的兽印去讨好她。”
- “我跪过祖灵，跪过母亲坟前，唯独不会跪你。”
- “满月之前，我给你们留脸。满月之后，我让全族看清谁才是野种。”
- “这枚银牙发烫的时候，你们就该闭嘴了。”

## 3. 反派口吻

关键词：当众羞辱、具体夺取、逼迫主角低头。

### 示例

- “一个废脉，也配占着武院名额？”
- “签了这份转让书，你还能留在矿区当条狗。”
- “灰毛狼没有配偶权，你的巢穴以后归她。”
- “你父亲坐了二十年牢，他留下的东西也该脏。”

## 4. 配角口吻

### 忠犬型

- “你下令，我动手。”
- “他们要你跪，我就拆了这座祭台。”

### 引导型

- “别急着杀他，先让证据自己开口。”
- “你不是没有路，你只是还没打开那只铁盒。”

### 病娇反派型

- “他们欺负你，我很高兴。这样你就只能来找我了。”

# 八、段落节奏补丁

## 短故事/狼人篇节奏

适合快节奏、强情绪、强钩子。

### 单章结构

1. 0—150字：身份反差 + 当众羞辱。
2. 150—500字：主角忍，出现具体被夺之物。
3. 500—900字：第一次小反击，反派不服。
4. 900—1300字：代价揭露，主角加码。
5. 1300—1800字：名场面兑现。
6. 章末：更大身份/血脉/契约反转。

### 场景切换

每300字左右换一次视觉重心：

- 祭台。
- 巢穴。
- 族长席。
- 祖灵碑。
- 满月林地。

## 科武长篇节奏

适合“冲突单元 + 世界观碎片 + 主线升级”。

### 单章结构

1. 0—150字：具体不公。
2. 150—400字：主角身份反差露一点。
3. 400—800字：反派加压，伤害量化。
4. 800—1200字：主角启动机制反击。
5. 1200—1800字：反击兑现，代价显现。
6. 章末：牵出上层势力/隐藏真相/非人视角。

### 世界观释放规则

每次只放一个设定，并绑定动作。

错误：

> “联邦分为七大星域，灵能体系起源于……”

正确：

> 审计投影亮起的瞬间，七大星域通用的红色封禁标识，压在了导师的名字上。

# 九、章末钩子补丁

## 每章结尾必须留一种钩子

### 1. 身份钩

> 审计令弹出最后一行字：  
> 【权限源：旧纪元武神遗产第一继承人。】

### 2. 真相钩

> 铁盒里没有钱，只有一张二十年前的判决书。  
> 原告签名，是我母亲。

### 3. 更大敌人钩

> 导师跪下的同一秒，议会大楼顶层，有人关掉了我的公民编号。

### 4. 非人视角钩

> 我以为系统终于醒了。  
> 可它说的第一句话是：  
> “纠正一下，我不是系统。我是你被封存的另一半尸体。”

### 5. 狼人钩

> 满月升起时，全族兽印同时熄灭。  
> 只有我掌心那枚灰色狼印，变成了金色。

# 十、微创新变量补丁

## 一篇只许有一个核心变量

不要同时写：重生 + 系统 + 读心 + 末世 + 狼人 + 真假千金。

### 可选变量

#### 短故事/狼人篇可借点

- 兽印不能继承，只会认真正救过族群的人。
- 灰毛狼其实是祖狼返祖。
- 满月祭上，所有谎言会被狼魂复述。
- 被抢走的巢穴会自动记录进入者气味。
- 伴侣契约转让失败会反噬背叛者。

#### 科武长篇可借点

- 专利锁：谁偷用技术，义体自动锁死。
- 灵能产权：武技不是秘籍，而是可审计资产。
- 非人视角：主角是武魂载体/智械意识/培养舱胚胎。
- 护体力场审计：攻击者会被记录并自动追责。
- 能源配额墙：蹭能源的人会被公开标红。
- 协议层覆写：主角能修改被伪造的权限链。

# 十二、发布/包装/风险门禁

平台规则不写成剧情口号，改成发布检查。

## 1. 包装门禁

发布前检查标题、简介、前150字是否明确：

- 主角是谁。
- 被夺走什么。
- 反击物是什么。
- 爽点在哪里。
- 是否有改编画面。

### 标题方向

#### 短故事/狼人篇

- 《满月祭上，他把我的兽印给了白月光》
- 《灰毛狼被退婚后，祖灵碑裂了》
- 《我被逐出狼群那夜，全族兽印熄灭》

#### 科武长篇/衍生短篇

- 《他们夺我灵能专利后，义体全跪了》
- 《废脉武徒的审计令》
- 《轨道城收走我家居住权那天，旧纪元系统醒了》

## 2. 节日热点门禁

节日只能做外壳，不可替代冲突。

可用：

- 元宵：灯会审判、家族团圆局撕契约。
- 妇女节：女性事业线、特殊职业反杀。
- 清明：祖坟、遗嘱、旧案、铁盒。
- 愚人节：假退婚、假身份、真证据反转。
- 春分：祭祀、分田、分配额、族群仪式。

禁用：

- 只有节日氛围，没有具体冲突。
- 用节日强行煽情，不推进反击。

## 3. 正向价值门禁

反杀必须站在合法/道义侧。

允许：

- 维权。
- 夺回产权。
- 公开证据。
- 揭露侵占。
- 反制背叛。
- 按规则审计/挑战/决斗。

慎用：

- 黑吃黑。
- 无证据杀人。
- 主角主动虐弱者。
- 为爽而违法且无代价。
- 把反派写成单纯体制，不落到具体责任人。

## 4. 改编门禁

每篇至少预留3个可拍画面。

填写格式：

- 画面1：反派当众羞辱。
- 画面2：具体物被夺/被毁。
- 画面3：主角启动反击物。
- 画面4：反派身体/身份/资产受罚。
- 画面5：章末悬念物出现。

# 十四、章节自检清单

写完每章后逐条勾选。

## 开篇检查

- [ ] 前150字内出现主角身份。
- [ ] 前150字内出现反常事件。
- [ ] 三段内出现外部挑衅。
- [ ] 伤害可量化。
- [ ] 导语末尾有反击预告或悬念物。

## 人设检查

- [ ] 主角不是单一标签。
- [ ] 至少有“两级反差”。
- [ ] 主角反击方式和职业/能力绑定。
- [ ] 主角没有无意义圣母、恋爱脑、被动受虐。

## 冲突检查

- [ ] 冲突围绕具体物/具体权利。
- [ ] 反派是具体人。
- [ ] 反派有当众羞辱或当众施压。
- [ ] 反击不是嘴炮。
- [ ] 反击有物证/规则/技术/契约依据。

## 动作反馈检查

- [ ] 每个冲突场景有至少3步动作链。
- [ ] 伤害有身体或物件反馈。
- [ ] 反击有可视化结果。
- [ ] 情绪描写没有超过动作描写三分之一。

## 代价检查

- [ ] 主角反击前埋了代价。
- [ ] 代价在剧情中真实发生或即将发生。
- [ ] 代价能引出后续冲突。

## 节奏检查

- [ ] 本章完成“忍—爆—兑现”至少一轮小闭环。
- [ ] 没有超过两段前情回忆。
- [ ] 世界观没有专章灌输。
- [ ] 每300—500字有一个小钩子。
- [ ] 场景切换适合改编镜头。

## 改编检查

- [ ] 本章至少有1个名场面。
- [ ] 全篇累计预留3—5个可拍画面。
- [ ] 章末有身份/真相/悬念反转。
- [ ] 主线可以拆成短剧/漫剧单元。
- [ ] 保留一条可拓展支线。

## 发布风险检查

- [ ] 反杀立场合法/正向。
- [ ] 没有黑吃黑爽点失控。
- [ ] 没有纯靠体制/天道做反派。
- [ ] 节日热点只是包装，不是剧情主体。
- [ ] 标题、简介、开篇爽点一致。

# 十六、本补丁一句话执行口令

写《科武纪元》时，不要先端世界观。  
先端出：

> 一个具体被抢的东西，  
> 一个具体欺负主角的人，  
> 一个具体能反击的物件，  
> 一个必须付出的代价，  
> 一个章末翻盘钩子。
