# 科武纪元·写作规范

## 一、基本规则
- **前作禁用"女娲系统"**：技术体系为南天门计划/方舟协议/流云算法
- **续作系统名"灵犀"**：前作不得出现
- 陈墨叫"苏灵兮"全名（续作角色，前作不出现）
- 沈同父沈和（续作角色，前作不直接出场）
- 1-15章不可修改（已发布）
- 16-60章已发布但可微调（保持核心情节不变）

## 二、字数标准
- **每章≥3200字**，不超过5000字
- 关键突破章（32/50/93/150/200/260/300/350/400/450/480）可4000-4500字
- 过渡章≥2800字
- **注水红线**：删掉某段后不影响后续理解 = 该删

## 三、语句与错字审校（强制执行）
- **每次改稿后，必须连带复查上下两段**，不得只改用户指出的那一句
- **审校顺序**：先读通顺，再查错字，再看语气，最后才看是否有AI腔
- 发现“句意能猜到但读起来别扭”的句子，按病句处理，必须重写
- 禁止放过以下问题：主谓不顺、承接断裂、词义误用、同音错字、口语硬拼书面句
- 章内出现关键术语调整（如境界名、设定名）时，必须全文联查，避免前后不一致
- 同步到已投稿目录前，至少再做一遍**纯读者视角通读**，专抓：不通顺/错别字/重复句式/残尾
- 用户指出的错句，修完后要主动检查同段与同章相邻位置，避免“修一处漏三处”

## 四、去AI味规则（严格执行）

### 绝对禁用词（出现即改）
微微、淡淡、不禁、嘴角微微上扬、缓缓开口、目光深邃、一股暖流、心中一颤、若有若无

### 高风险词（最小化，每万字≤1次）
真正的、忽然觉得、说不出的、不由自主、轻轻点头、缓缓起身、目光如炬、深邃的眼眸

### 替代原则：用具体动作/数据/物理反应代替抽象感受
| ❌ 禁止 | ✅ 替代 |
|---------|---------|
| 淡淡一笑 | 嘴角动了动，没说话 |
| 一股暖流涌遍全身 | 经脉里的算力像被点燃，从丹田窜到指尖 |
| 心中微微一震 | 手停了半秒 |
| 他感到一阵愤怒 | 他攥紧拳头，指甲嵌进掌心 |
| 缓缓开口 | 顿了两秒才说 |
| 目光深邃 | 眼睛眯起来，像在算什么 |

## 四、开篇三章铁律
- **黄金300字**：第一段必须有冲突或悬念，禁止天气/风景/自我介绍式开头
- 第一章3000字内完成：主角出场、核心困境、至少一次反转
- 读者不知道为什么要翻页 = 失败

## 五、节奏控制

### 三拍节奏
每章遵循「起→承→转」：
1. **起**：切入场景，抛出问题或动作
2. **承**：推进展开，加入新信息
3. **转**：反转/悬念/意外，驱动翻页

### 全局节奏
- 连续≥3章无冲突 = 拖沓，必须插入摩擦点
- 连续≥3章纯打斗 = 疲劳，必须插入安静场景
- 情绪曲线：高潮前必须有压抑，反弹高度取决于下压深度

### 钩子规范
- 钩子**必须从场景动作中自然生长**，禁止硬贴末尾
- 不是每章都要悬念钩子——有时一个收束比悬念更好
- 钩子类型轮换（禁止连续同类型）：

| 类型 | 示例 | 频率 |
|------|------|------|
| 悬念型 | "门后的声音，不是他预期的任何一种。" | 常用 |
| 信息型 | "数据意味着一件事：被跟踪了三天。" | 适度 |
| 危机型 | "散热系统温度还在升。方宁还有四分钟。" | 适度 |
| 情感型 | "苏雨晴没回头。袖子里的手攥得发白。" | 少用 |
| 伏笔型 | 一个不起眼的物件或细节 | 少用 |

**禁止**：文艺范结尾（"秘密在沉默中等待"等抽象抒情）

## 六、人物塑造

### 角色区分三维度
1. **语言习惯**：口头禅、句式长短、用词风格
2. **行为模式**：遇危机第一反应（冲/逃/算/忍）
3. **价值观**：关键抉择时暴露真实立场

### 对话规范
- 去掉名字标签后能认出说话人
- 每句对话≤15字（军人/技术风格）
- 对话推动剧情或揭示性格，**至少满足一项**
- 禁止说明书式对话（借角色嘴科普超过3句）
- 用动作打断长对话
- ❌ "量子芯片采用3纳米工艺，功耗降低40%……"
- ✅ "别问原理。只管用——插上这东西，他快了三倍。"

### 群像管理
- 每卷核心角色≤6人，超过则轮换登场
- 配角每次出场至少一个辨识动作或特征
- 配角要有自己的事做，不要全员围主角转

### 反派设计
- 必须有合理动机（站在他的角度说得通）
- 反派智商决定作品质感
- 禁止「为坏而坏」的纸片反派

## 七、五感与细节

### 感官调用
每章至少覆盖**两种以上感官**：
- 战斗章：触觉+听觉（金属撞击、骨骼震动、耳鸣）
- 训练章：嗅觉+触觉（汗水、金属味、肌肉酸痛）
- 太空章：视觉+听觉缺失的反差（真空无声、星光刺眼）
- 日常章：味觉/嗅觉（紧张时嘴里的铁锈味、机房的臭氧味）

### 细节选择
- 选不寻常的细节（所有人都能想到的 = 废话）
- 一个精准细节 > 三段形容词
- 细节服务于情绪或暗示，不是装饰

## 八、世界观呈现

### 冰山法则
- 设定写进文档，不写进正文
- 正文中通过角色行为和结果暗示设定
- 每次解释世界观不超过3句，分散在不同章节

### 信息释放节奏
- 前10章：只释放主角生存必需的设定
- 10-30章：逐步展开世界规则
- 30章后：才允许系统性说明（仍然要短）

❌ "灵境体系分为九重，每重又有初阶中阶高阶……"（百科词条）
✅ "出拳速度比上周快了一截——突破灵境二重后，肌肉反应阈值降了三成。"（融入动作）

## 九、心理描写
- 主角每章必须有内心活动
- 不用"他想""他感到"，用动作和反应间接表达
- 安静时刻比爆发时刻更难写、也更打动人
- 禁止：强行卖惨、滥用内心独白解释情绪、死亡当廉价催泪工具

## 十、技能代价
- 每次使用能力必须体现代价
- 算力消耗→头痛/疲惫/经脉灼热
- 墭界突破→短期虚弱/身体异变
- 人机融合→意识模糊/身份困惑

## 十一、冲突设计

### 冲突层次
| 层级 | 例子 | 驱动力 |
|------|------|--------|
| 生存 | 被追杀、缺资源 | 本能 |
| 利益 | 争地盘、抢技术 | 贪欲 |
| 信念 | 路线之争、善恶抉择 | 价值观 |
| 命运 | 对抗预言/宿命 | 意志 |

每章至少涉及一层冲突。连续无冲突 = 注水。

## 十二、敏感词规避
- 不用"省钱""白嫖""免费"等营销词
- 台海相关只用"和平收复""文明整合"，不写战争
- 中东/非洲冲突用虚构势力，不点名真实国家领导人
- 联合国场景用法理框架叙事，不评价体制

## 十三、番茄小说平台审核规范（2026-04-22官方版）

### 绝对红线（触碰即封）
以下内容**绝对不得出现**，无论任何情节需要：
- 煽动或宣扬抗拒/破坏宪法、法律、行政法规实施
- 危害国家统一、主权和领土完整，泄露国家秘密，危害国家安全，损害国家尊严、荣誉和利益
- 宣扬恐怖主义、极端主义
- 煽动民族仇恨、民族歧视，歪曲民族历史，损害革命领袖、英雄烈士形象
- 宣扬邪教、封建迷信
- 散播谣言扰乱社会秩序，宣扬淫秽色情、赌博、吸毒，渲染暴力、恐怖
- 侵害未成年人合法权益或身心健康
- 侵害他人名誉权、肖像权、知识产权、商业秘密

### 军事题材特别说明
- **军人形象**：不得出现正式军人，或对军人侮辱/歧视
- **武器**：禁止出现手枪、管制刀具等现代武器（古代刀剑除外）
- **政治符号**：禁止天安门、警车、政府机构大门、国旗国徽等
- **战争/对抗**：允许商业竞争、资源争夺、技术对抗等非政治性冲突
- **地名**：真实地名（刚果/帕米尔/南海等）可保留，帮助读者定位
- **国名**：真实国名可用，但不得有明确政治立场倾向（赞美/批评/煽动）；反派功能由"对方"、"某势力"、"某阵营"等虚构代号承担

### 番茄实测安全写法
| 场景 | 合规写法 | 风险写法 |
|------|---------|---------|
| 海上对抗 | "多支不明无人艇在争议海域勘探" | "XX国入侵XX海域" |
| 境外矿区 | "某境外势力控制的矿区" | "XX国掠夺资源" |
| 国际冲突 | "商业勘探方 vs 防卫方" | "XX国 vs XX国战争" |
| 科技竞争 | "算力垄断 vs 技术共享" | "XX国芯片战争" |

### 发布前自检三问
1. 本章是否有触碰绝对红线的内容？
2. 军事/对抗场景是否停留在商业/技术层面而非政治层面？
3. 是否有现实国家名称直接参与军事冲突？

## 十四、自主成长原则
- 主角团突破必须是"大胆想象，小心实践"的自我探索结果
- 体现国家培养体系支持（南天门计划/少年班），但不直接说教
- "人人如龙"：每个角色都有独立专业能力和成长弧光

## 十五、人物描写标准

### 女性角色魅力描写（重点执行）
**核心原则：五感+行为+反应，不写"她很美"**

**外貌描写**：
- 一句话点出最显著特征（颧骨/下巴/颈线/肤色）
- 避免具体尺寸，用对比（"比他矮小半个头"）
- 眼睛：颜色+光泽+神情（黑曜石/寒星/秋水）
- 嘴唇：颜色+质地（淡红/玫瑰/微微翘起）
- 皮肤：质感（蜜色/瓷白/透明感）+ 情绪时的变化（颊边淡红）

**身材描写**：
- 不写罩杯/三围，写轮廓和线条（胸线挺拔/腰身收紧/腹肌轮廓/腿部线条）
- 用具体动作暗示（抬手时肌肉起伏/跑步时腰部摆动）
- 穿训练服/练功服时的身体线条（弹性面料贴身的轮廓）

**穿着描写**：
- 面料质感（弹力面料/丝绸/棉麻/军装呢料）
- 颜色+剪裁（深蓝/灰/黑 + 贴身/收腰/束口）
- 细节（拉链/武装带/领口/袖口/马尾/发尾位置）
- 穿着时的状态（汗湿贴在身上/被风吹拂/衣摆扬起）

**行为动作**：
- 站姿/走姿/坐姿的辨识度（重心在前脚掌/后脚跟）
- 出手/抛物/接物的动作（精准/利落/像投球）
- 表情变化的前兆（眼神/嘴角/手指的细微变化）
- 身体的小习惯（咬唇/撩发/抱臂/踮脚）

**声音描写**：
- 音色（磁性/沙哑/清脆/低沉）
- 语速（快/慢/顿挫/短促）
- 语气（冷/柔/硬/调侃）
- 笑时的声音（轻哼/嗤笑/闷笑）

**男性视角反应（自然即可，无需克制）**：
- 看到美女正常反应：心跳加速/呼吸变浅/喉结动/耳根热/移不开眼/愣住/手心出汗
- 这些是正常生理反应，读者能代入，不需要回避，不需要解释
- 禁止：流鼻血/勃起/过度YY/意淫式描写
- 风格：点到即止，一句话带过，不渲染不展开
- 例子："他的喉结动了一下" / "耳根有点热" / "手心全是汗" / "目光从锁骨滑到腰线"

**差异化标签（每个女主必须有）**：
- 苏雨晴：冷而稳 + 声音带磁性 + 手指有茧 + 体温略高
- 陈思琪：硬下巴 + 蜜色皮肤 + 声音沙哑 + 眼神如黑曜石

**反差感塑造**：
- 外表硬核 + 某个瞬间的柔软（眼神的空/某个小动作）
- 强者 + 弱点/伤口（不接受反驳的下巴/强撑的疲惫）
- 不解释"她很美"，写别人愣住/移不开目光/说话卡壳

**参考作品**：《乱世书》《娱乐春秋》（姬叉）——女性角色各有独占锚点，情感线有迹可循，不写"美"字但让读者感受美

### 外貌：委婉描述（身高/五官特征/服装剪裁），避免具体尺寸
### 气质：通过动作和神态展现，而非数据化描述
### 技术细节：真实可推演，避免玄幻

## 十六、断章与期待

### 断章艺术
- 在最高潮处断，不在总结处断
- 在选择瞬间断，不在选择之后断
- 在信息半透明处断（读者知道有事，不知道什么事）

### 期待管理
- 每5章制造一个中期期待
- 每20章制造一个大期待
- 期待必须兑现，否则透支信任

## 十七、修改自检清单
- [ ] 全文搜索禁用词，归零
- [ ] 对话去名字后能认出说话人？
- [ ] 连续两段无动作/对话 = 可能注水？
- [ ] 末尾钩子从场景生长的？还是硬贴的？
- [ ] 删掉某段后影响后续理解？不影响 = 该删
- [ ] 本章至少涉及一层冲突？
- [ ] 五感覆盖≥2种？
- [ ] 番茄红线自检：无绝对违规内容？
- [ ] 番茄安全自检：军事/对抗是否停留在商业/技术层面？
- [ ] 番茄地名自检：是否有现实国家直接参与军事冲突？

## 十八、章节衔接
- 每章开头回顾前章关键事件（1-2句融入叙事）
- 不在场景中间断章
