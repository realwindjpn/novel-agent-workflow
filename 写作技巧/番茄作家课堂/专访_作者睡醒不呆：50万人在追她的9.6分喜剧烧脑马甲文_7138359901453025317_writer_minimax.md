# 三、动作执行模块库

## ⚡ 模块1：旁观者愤怒法（冲突设计）

**触发条件**：需要设计反派压迫场景

**执行步骤**：

```
Step 1 → 反派设局
   描写反派的具体压迫行为（非抽象描述）
   格式：[动作] + [对主角的影响] + [旁观者可见度]
   示例："拍卖师敲下第三锤，机甲核心的价格停在680万。
          林野的竞拍牌还攥在手里，但账户余额只够买半个传导模块。"
   ↑ 压迫行为具体，读者可直接代入

Step 2 → 旁观者共情愤怒
   切换到旁观者视角，放大情绪感染
   格式：[旁观者反应] + [情绪标签词] + [对比强化]
   示例："周围响起零星嘘声。有人低声骂了句'黑市惯用伎俩'。
          一个穿校服的少年攥紧了拳头——那是林野的同校学弟。"
   ↑ 旁观者情绪具象化，读者通过第三方产生愤怒

Step 3 → 主角破局
   主角行动必须符合人设，不得机械降神
   格式：[决策逻辑] + [执行步骤] + [物理结果]
   示例："林野没有拍桌。他翻开战术终端，调出一个黑市算法接口。
          '这台机甲的传动模块有问题。'他把数据投影到公屏上，
          '想赌的，现在跟我出价。'
          算法自动锁定三个漏洞参数。拍卖师的脸色变了。"
   ↑ 有逻辑、有步骤、有物理结果

Step 4 → 情绪释放
   必须伴随三维变化中至少两项
   示例：
   - 物理：拍卖师被系统强制调查，机甲被扣押审查
   - 社会：校服少年开始传播林野的战斗数据
   - 认知：围观者发现林野不是"穷学生"而是"数据高手"
```

**反馈机制**：
- 段评中出现"憋屈""心疼""爽"关键词→执行正确
- 段评中出现"主角开挂""反派太弱"→执行过度或不足

**代价记录**：
- 主角暴露了黑市算法接口→后续可能被财阀追杀
- 主角与校服少年建立弱连接→后续可召唤为群像资源

  "这个街区的每一台机甲，每年都要向武盟缴纳维护费。
  你以为那些免费的底层改造技术，是怎么来的？"
  他笑了。
  "是我们在买单。你享受了服务，却忘了付费。
  这不叫效率。这叫——欠债。"

  "我给你一周时间。"
  他站起身，拍了拍衣摆上不存在的灰尘。
  "一周后，如果你还没有【足够诚意】的还款方案，
  我会建议武盟对你的义体改造资质进行……复核。"
  复核两个字咬得很重。
  "你应该知道这意味着什么。"
```

```
压抑区（渐强）          释放区（爆发）         钩子区（悬念）
─────────────→          ──────────────→        ──────────────→

1-3段               5-8段                 9-11段             12段

压迫事件            旁观者愤怒            主角破局            章末钩子

节奏比例：压抑:释放:钩子 = 4:5:1

**科武纪元适配节奏表**：

| 段落位置 | 内容类型 | 节奏指令 | 段评预期 |
|:---|:---|:---|:---|
| 第1段 | 场景建立 | 快，切入冲突引信 | — |
| 第2-3段 | 压迫事件 | 中，用动作/对话展示 | 憋屈/愤怒 |
| 第4段 | 旁观者视角 | 快，情绪放大 | 代入 |
| 第5-7段 | 主角准备 | 慢，铺垫决策逻辑 | 紧张/期待 |
| 第8-10段 | 破局执行 | 快，动作+结果 | 爽 |
| 第11段 | 释放收尾 | 快，物理+社会+认知变化 | 尖叫/鼓掌 |
| 第12段 | 钩子 | 快，新信息/悬念植入 | 啊啊啊/想看 |
