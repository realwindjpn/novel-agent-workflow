# 三、节奏控制系统

## 3.1 章节内节奏模板

```
【高压段】探索/战斗/技术突破 → 200-500字
    ↓ 转折信号：环境变化/敌方动作/突发状况
【缓冲段】战术复盘/团队互动/技术沉淀 → 300-800字
    ↓ 情绪锚点：幽默/温情/小胜利
【升温段】决策落定/下一个威胁显现 → 100-300字
    ↓ 章末钩子强制植入
【钩子段】未解变量/意外信息/关系转折 → 50-150字
```

## 3.2 卷内节奏模板

```
第1-3章：建置（设定+人物+首个危机）
第4-8章：发展（第一个中等目标+配角高光线）
第9-12章：高潮（伏笔回收+名场面）
第13-15章：新钩子（开启下一卷核心冲突）
```

## 3.3 日更安全阈值

| 字数区间 | 风险等级 | 适用场景 |
|:---:|:---:|:---|
| 4k±500 | ✅ 安全 | 常规日更 |
| 6k+ | ⚠️ 警告 | 仅限高潮章节/爆更活动 |
| <3k | ❌ 禁止 | 长期低字数=推荐权重自杀 |

# 四、冲突设计系统

## 4.1 底线原则（必须满足）

| 角色类型 | 底线要求 | 违规示例 |
|:---|:---|:---|
| 反派 | 有合理动机+行为边界 | "我就是坏"无因反派 |
| 配角 | 独立高光线+功能定位 | 仅当主角工具人 |
| 主角 | 动机-动作-代价闭环 | 无代价越级/被保护 |

## 4.2 爽感来源替换表

| ❌ 禁用 | ✅ 启用 | 效果 |
|:---|:---|:---|
| 无脑打脸 | 规则利用/科技代差 | 合理爽感 |
| 越级碾压 | 战术博弈/信息差 | 智性爽感 |
| 被动挨打 | 主动破局/反将一军 | 主控爽感 |
| 机械降神 | 回填伏笔/前期铺垫 | 逻辑自洽爽感 |

## 4.3 冲突场景检查

- [ ] 敌方是否有明确动机？（不是"天生仇敌"）
- [ ] 主角是否有可执行的破局路径？（不是靠运气）
- [ ] 是否有配角独立高光？（男二破案线/后勤逆袭线等）
- [ ] 代价是否明确且影响后续？（不是一次性消耗）

> **📌 科武长篇可借点**：敌方动机必须关联科技树/资源争夺/阵营立场

# 六、反馈-代价系统（硬性规则）

## 6.1 物理反馈清单（战斗/突破必检）

| 类型 | 必需要素 | 禁用描述 |
|:---|:---|:---|
| 武器/机甲 | 后坐力、能量消耗、弹药/能源读数 | "强大无比" |
| 身体反馈 | 肌肉撕裂感、神经负荷、感官超载 | "略感疲惫" |
| 环境交互 | 地形破坏、声响传导、连锁反应 | "尘土飞扬" |
| 时间成本 | 行动耗时、冷却等待、副作用延迟 | 瞬发无代价 |

## 6.2 代价触发规则

```
代价类型 → 后续影响
─────────────────────────────────
寿命折损 → 加速关键决择/产生伦理冲突
装备报废 → 资源争夺线开启/技术升级需求
阵营敌对 → 政治博弈线加入/盟友分裂
道德困境 → 人设深化+读者争议话题
能力反噬 → 新技能学习受阻/必须付出额外代价
```

**代价书写模板**：
```
触发动作 → 获得收益 → 即时代价 → 延迟代价
    ↓
主角获得"过载加速"能力
    ↓
神经负荷+15%（即时）
    ↓
72小时内第二次使用将导致不可逆感官损伤
（延迟代价锁定下一阶段剧情走向）
```

# 七、章末钩子系统

## 7.1 钩子类型分级

| 等级 | 类型 | 强度 | 示例 |
|:---:|:---|:---:|:---|
| S | 主线转折 | 极高 | "她发现那份战术报告上的签名……是自己父亲的" |
| A | 冲突升级 | 高 | "舰长权限被强制转移至……AI核心" |
| B | 悬念维持 | 中 | "通讯器里传来的是敌方加密信号——却用了他们的老暗号" |
| C | 情绪延续 | 低 | "他看着她的背影，想起出发前她说的话……" |

## 7.2 钩子检查（章末必检）

- [ ] 是否与主线强关联？（拒绝"她今天心情不好"类情绪留白）
- [ ] 是否提供新信息变量？（不是重复已知信息）
- [ ] 是否触发下一个预期？（读者知道"我要看XX如何应对"）
- [ ] 字数是否控制在50-150字？（过长=节奏拖沓，过短=张力不足）

## 7.3 禁用钩子清单

```
❌ 纯情绪留白："她不知道该不该相信他……"
❌ 无效悬念："原来，一切都有预兆……"
❌ 重复已知信息："她不知道危险正在逼近……"（读者早知道）
❌ 机械降神暗示："就在这时，意外发生了……"
```

> **📌 科武长篇可借点**：S级钩子必须关联"技术瓶颈/敌对势力动向/核心成员背叛"
