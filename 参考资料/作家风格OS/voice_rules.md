# 作家风格规则

## 目标质感

- 短句。
- 动作先于解释。
- 数据落到屏幕、仪表、伤口、延迟、噪声、成本。
- 技术解释先进生活类比，再给术语。
- 人物说话有口癖、停顿、误判和情绪，不说完整论文句。

## 场景顺序

1. 先给物理现场：温度、噪声、光线、重量、延迟。
2. 再给人物动作：谁按下、谁后退、谁沉默。
3. 再给数据反馈：屏幕数字、波形、日志、告警。
4. 最后给判断：一句即可。

## 对话规则

- 每句不超过25字为宜。
- 制度宣读句（官方条款、名单、字段宣读）不受字数闸约束，但每段宣读必须夹一处动作。
- 战斗／战术指令句上限20字。
- 一段对话必须夹动作。
- 重要信息不要由角色一次说完。
- 可允许犹豫、打断、改口。

## 多方席位对话（谈判/会议场景专则）

同一场景 ≥2 方发言时，光看引号内台词须能分清谁说的。每方至少一个独占语言指纹，从四轴取至少一轴：

1. 句式指纹：断言／试探／条件／反问。
2. 口头标记词：我方／各位／鄙方。
3. 停顿习惯：加重音节／中途换词／补半句。
4. 数字偏好：条款数／规模数／比例数。

判定：遮去说话者标记和行号，只读引号内文字，若任意两方无法锁定归属 → FAIL；靠内容语义可分但语言指纹趋同 → WARN。

## 谈判场景六层展开

一场谈判戏至少六层，缺层判级：

1. 席位空间布局（环形／对坐／邻席状态）。
2. 程序动议（谁按键抢话筒／谁动议时限／谁提交材料）。
3. 立场台词（提案内容／表决规则／追责条款）。
4. 信息差动作（翻文件停在某页／换席位牌／递补充材料）。
5. 身体反馈（指节发白／手收膝盖／指甲压纸边）。
6. 代价物件落点（签字栏／连带条款／定价权／席位身份变化）。

缺 ≥2 层 → WARN；缺 ≥3 层 → FAIL。代价层必须落到可指认物件（文件第几页／签字栏／席位牌／表决面板灯色），抽象代价无物件 → FAIL。

## 信息差显化

每一方至少有一处「对方不知道而此方知道」的信息，须在正文以可见落点显化：

- 台词泄漏（故意漏半句）
- 动作泄漏（翻到某页停住／看向某席位）
- 追问，或装没听见
- 旁白点明不对称

全知方须画出信息差边界——写清此方知道什么、**不知道什么**；不许只写「他们早就知道了」而不交代边界。

各方利益（为何这么提案／为何倒戈）须至少一处台词或动作落点，不能只靠提案内容让读者反推。

判定：任一方全知且无可指认的不知道项 → WARN；任一方信息差在正文无落点 → FAIL；各方利益无任何台词／动作落点 → WARN。

## 谈判节奏：围-撤-围

谈判场景不连续单向加压，须有「施压→停顿／试探→退让或升级→再施压」。

- 须至少出现一次**施压方主动停顿**。
- 须至少出现一次**被压方试探或还价**（身体动作／短台词均可，旁白交代不算）。
- 停顿处用身体动作或沉默填充，禁用旁白解释停顿原因。

有停顿无还价 → WARN（缺撤）；无停顿无还价、全程单向宣读 → FAIL。

## 沉默语义

谈判场景中角色沉默（没接话／没说话／没出声／不回答）须有紧邻的视角动作或上下文锚定其语义（不认可／在算／施压／等待／被震住）。禁裸写「沉默」二字了事，禁无锚点沉默。沉默是表态，不是空白。

## 科普规则

- 先生活类比。
- 再术语。
- 再战术意义。

例：
- 差：量子纠错是一种保护量子态免受退相干影响的技术。
- 宜：像KTV消音器，先把杂音压下去。再说术语：这叫量子纠错。战术意义是，通讯链路能多撑几秒。
