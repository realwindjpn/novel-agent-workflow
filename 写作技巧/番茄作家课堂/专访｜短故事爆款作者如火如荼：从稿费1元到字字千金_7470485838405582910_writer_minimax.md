## 一、核心补丁指令（6条铁律）

### 🔴 铁律1：冲突前置，设定退后
> **执行**：[短故事/狼人篇]首段必须切入冲突，禁止场景铺陈。[科武长篇]第1章必须用“科技危机/武道崩溃/能量异变”制造生存压力，世界观随危机展开。

### 🔴 铁律2：大纲颗粒度≥90%
> **执行**：10万字细纲必须包含每章情节点、情绪爆点、数据预期。科武需将科技树/武道境界/能量守恒写入大纲，避免后期战力崩坏。

### 🔴 铁律3：节奏节拍器
> **执行**：[科武长篇]每3章小高潮/每10章大转折；[短故事]长驱直入，删减所有过渡性描写，直奔主线。

### 🔴 铁律4：单一极致冲突
> **执行**：长篇可多线交织但必须有主轴牵引；短篇冲突必须闭环于单篇内。冲突需源于“科学规律/武道代价/资源博弈”，禁止狗血误会。

### 🔴 铁律5：代价即时兑现
> **执行**：每次核心能力突破/越级战斗/科技跃迁必须支付明确代价（寿命折损/理智侵蚀/资源枯竭/情感剥离）。代价需前置预告并在剧情中兑现。

### 🔴 铁律6：数据驱动改文
> **执行**：建立追读/完读率/章评监控机制，低于阈值立即改文，禁止凭感觉硬撑。

## 三、章节自检清单（每章完成后执行）

### ✅ 基础检查（必须通过）
- [ ] 首段是否切入冲突？（禁止世界观/背景铺陈）
- [ ] 冲突是否单一且极致？（禁止多线并行导致焦点模糊）
- [ ] 动作链是否闭环？（触发→决策→执行→物理结果）
- [ ] 物理反馈是否具象？（用五感描写替代抽象形容词）
- [ ] 章末钩子是否有效？（信息差/危机倒计时/情感反转/设定伏笔）

### ✅ 节奏检查
- [ ] 本章是否有情绪波动？（禁止平铺直叙）
- [ ] 若为第3章，是否有小高潮？
- [ ] 若为第10章，是否有大转折/卷末钩子？
- [ ] 冲突是否推进？（禁止原地打转）

### ✅ 科武专项检查
- [ ] 科技/武道操作是否符合设定物理法则？（禁止意念流/无逻辑瞬发）
- [ ] 设定是否作为冲突催化剂？（禁止堆砌设定不服务剧情）
- [ ] 代价是否前置预告并兑现？（禁止机械降神）

### ✅ 数据检查 [长篇连载]
- [ ] 是否记录追读率/完读率？
- [ ] 章评是否反馈问题？
- [ ] 数据低于阈值是否启动改文流程？

### ✅ 改编接口检查 [科武长篇]
- [ ] 场景数量≤3个？
- [ ] 台词驱动≥60%？
- [ ] 是否有视觉化强的画面？
- [ ] 每章末是否有情绪爆点或反转？

## 四、动作-反馈-代价闭环模板

### ⚡ 模板A：科技操作闭环
```
【触发】主角激活能量护盾抵挡攻击
【决策】系统提示能量不足，主角选择降低护盾功率
【执行】护盾收缩至核心区域
【物理结果】能量过载警报解除，但护盾覆盖率下降37%，左肩暴露
【代价兑现】后续战斗中左肩被贯穿，血量下降至32%
```

### ⚡ 模板B：武道战斗闭环
```
【触发】对手释放必杀技"星爆斩"
【决策】主角感知能量波动，预测攻击轨迹，选择侧身闪避而非硬接
【执行】肌肉记忆驱动身体向右侧倾斜，同时激活腿部推进器
【物理结果】斩击从胸前划过，衣角被削去，但核心区域未受伤
【代价兑现】推进器过载导致腿部关节磨损，后续战斗机动性下降
```

### ⚡ 模板C：人物决策闭环
```
【触发】敌方提出交易：用核心技术换取主角团队安全撤离
【决策】主角评估技术价值与团队存亡，权衡背叛代价
【执行】主角接受交易，但在交接时植入后门程序
【物理结果】敌方获得技术但系统存在漏洞，为后续反击埋下伏笔
【代价兑现】团队成员质疑主角决策，信任度下降，内部矛盾爆发
```

## 五、人物口吻设计指南

### 🗣️ 科武人物口吻原则
| 类型 | 口吻特征 | 示例场景 |
|:---|:---|:---|
| **科研型** | 冷静、术语化、用数据说话 | "能量转化效率下降至12%，预计维持时间：47秒。" |
| **武道型** | 简洁、力量感、结果导向 | "再来。"（擦去嘴角血迹，再次摆出起手式） |
| **指挥官型** | 果断、层级感、任务优先 | "全员撤离，我来断后。这是命令。" |
| **叛逆型** | 反讽、挑战规则、用行动说话 | "规则是给没能力打破的人准备的。" |

### 🗣️ 情绪转折口吻（对话体现心理变化）
```
【平静→动摇】"我可以处理。" → "等等，这数据不对……"
【坚定→质疑】"我能做到。" → "凭什么是我？"
【冷漠→共情】"无关紧要。" → "……你也是受害者。"
```

## 八、平台规则 → 发布/包装/风险门禁

### 🚫 风险门禁1：书名/简介
- **规则**：书名/简介需在动笔前规划，由编辑/市场数据优化
- **转译为门禁**：
  - ❌ 未确定核心卖点前不开书
  - ❌ 书名不可模糊（如"星际纪元""武道之路"）
  - ✅ 书名必须含核心钩子+情绪词（如"基因崩溃：我被迫成为实验体""武道的代价：每一次突破都在失去人类身份"）

### 🚫 风险门禁2：前10万字书测
- **规则**：严格遵循10万字书测机制，前10万字大纲完整度≥90%
- **转译为门禁**：
  - ❌ 大纲未完成不开书
  - ❌ 每3章不检查数据不开新卷
  - ✅ 10万字前完读率需达阈值，否则立即复盘前10章

### 🚫 风险门禁3：标签/垂直赛道
- **规则**：题材垂直，放弃泛写，深耕单一情绪赛道
- **转译为门禁**：
  - ❌ 标签堆砌超过5个
  - ❌ 核心情绪不明确（如同时写"甜宠+复仇+热血"）
  - ✅ 标签≤3个，情绪指向单一（如"科幻+基因+代价"）

### 🚫 风险门禁4：短剧/动漫改编接口
- **规则**：预留改编接口，对标短剧/IP偏好结构
- **转译为门禁**：
  - ❌ 单章场景超过5个
  - ❌ 大量内心独白无法视觉化
  - ✅ 每章保留"可截图画面"（冲突高潮帧）

### 🚫 风险门禁5：数据监控与改文机制
- **规则**：数据驱动迭代，低于阈值立即改文
- **转译为门禁**：
  - ❌ 连续3章数据下跌不分析原因
  - ❌ 章评负面反馈不处理
  - ✅ 建立数据表格，每周复盘
