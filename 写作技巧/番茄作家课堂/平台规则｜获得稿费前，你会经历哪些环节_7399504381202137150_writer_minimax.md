## 模块A：写作前任务卡字段更新

> 每次开写前必须完成的字段校验清单。

### A1. 场景任务卡（每场戏前）

| 字段 | 校验标准 | 科武长篇 | 短故事 | 热点稿 |
|:---|:---|:---|:---|:---|
| **触发事件** | 必须是主角可感知、可行动的具体事件，禁止"氛围描写"式触发 | ✓ | ✓ | ✓ |
| **主角决策** | 必须体现主角性格/能力/目标，禁止第三方代做决定 | ✓ | ✓ | ✓ |
| **执行步骤** | ≥3个可追踪步骤（触发→行动→反馈），禁用"然后爆发"式跳跃 | ✓ | ✓ | ✗（需压缩） |
| **物理反馈** | 每步需有可感知反馈（痛觉/视觉/听觉/环境变化） | ✓ | ✓ | ✓ |
| **代价结算** | 明确标注本次行动的资源损耗/风险/后续代价 | ✓ | ✓ | ✓ |
| **钩子变量** | 场景末尾必须抛出下一章可接的具体变量（事件/信息/关系） | ✓ | ✓（单章闭环） | ✓ |

## 模块B：作家动作指令集

> 嵌入写作时的即时动作模板。

### B1. 开篇300字指令（第一句到第三句）

```
□ 动作：主角名字 + 所处场景 + 进行中的事件（非待机状态）
□ 动作：主角遭遇第一层阻力（人/物/信息缺口），触发决策
□ 动作：主角做出第一个主动选择（不是被迫应对），明确目标
□ 禁止：不做环境描写、不做能力展示、不做背景交代
□ 章末：抛出"已知变量A + 未知变量B"的钩子格式
```

**钩子格式示例**：

> 科武长篇用："林澈看着全息屏上的红色警报，指尖却停在启动键上方——如果启动，下一次基因锁突破就要推迟三周。"
> 短故事用："她刚要开口，却发现对方面具下露出的那道疤，和她记忆里的一模一样。"
> 热点稿用："他赢了比赛，却发现自己的机甲日志显示——这根本不是他操控的。"

### B2. 冲突编织指令

```
□ 每场冲突必须包含：
  - 显性阻力（对手/环境/时间）
  - 隐性阻力（主角自身缺陷/资源不足/信息差）
  - 可视化代价（不是"付出代价"，而是"代价导致的具体后果"）

□ 冲突密度公式：
  新冲突节点 = 每800-1200字一个
  节奏加速公式：越接近大高潮，节点间距缩短至500-600字
```

### B3. 物理反馈指令（科武专属）

> 替代"他很强/很痛/很震撼"的抽象描写。

```
□ 能量使用反馈：消耗量→感官信号→身体反应→环境变化
  示例："第三次基因强化启动的瞬间，脊骨的灼烧感直冲颅顶，视野边缘泛起白色噪点。能量计从87%跌至12%。"

□ 科技设备反馈：操作→响应延迟→功能实现→副作用
  示例："机甲关节的金属疲劳在弯曲时发出刺耳的嘎吱声，左臂响应速度比右臂慢了0.3秒——刚好够对手捕捉到破绽。"

□ 环境压迫反馈：物理定律改变→身体承受→决策限制
  示例："重力异常让血液向双腿汇聚，头颅供血不足导致的眩晕让她的瞄准镜持续晃动。"
```

### B4. 代价植入指令

```
□ 每次主角推动主线或越级破局后，必须结算：
  1. 资源损耗（能量/装备/时间/盟友关系）
  2. 身体代价（可量化的损伤，不只是"疲惫"）
  3. 信息代价（新信息暴露了新弱点）
  4. 关系代价（谁因为这次行动改变了态度？）

□ 禁止：无成本升级、"休息一下就好了"式代价规避

□ 代价延迟机制：可接受当前用未来代价替代，但不能不用
  示例："这次突破让他获得了瞬移能力，但代价在六个月后才显现——每次使用后，听力损失0.5%。"
```

### B5. 人物口吻指令

```
□ 每章必须出现：
  - 主角的标志性语言习惯（口头禅/逻辑框架/情感表达模式）
  - 至少一个配角对主角行为的反应（验证人设是否可信）

□ 科武长篇口吻要求：
  主角需有"技术思维语言"——用系统/数据/逻辑解构情感
  示例："他将她的笑容标记为'信任等级+15%'，却无法解释为什么这个数据让他的呼吸频率异常了2%。"
```

### B6. 段落节奏指令

```
□ 手机阅读分段标准：
  - 每段≤150字（移动端最优阅读量）
  - 超过150字自动拆分或加入过渡句
  - 对话每句独立成段（除非是连续短句追问）

□ 节奏卡点位置：
  - 章首：第一个事件触发点（300字内）
  - 章中：每600-800字设置"情绪电梯"（上升或下降）
  - 章末：钩子前最后一个动作必须是"已发生"而非"即将发生"
```

### B7. 章末钩子指令

```
□ 钩子类型与格式：

  【危机钩子】已有信息 + 新威胁
    "他完成了任务，却在撤离时发现——目标体内嵌着的芯片，和他的一样。"

  【信息钩子】已知事实 + 颠覆性新信息
    "三年的战友告诉他，那个叛徒是唯一阻止战争的人。"

  【选择钩子】两个已知选项 + 第三选项涌现
    "他可以选择交出情报保住妹妹，或者交出妹妹保住情报——但他发现自己是人造人的档案，让这两个选项都失去了意义。"

  【反转型钩子】正序事件 + 颠覆结果
    "他杀死了boss，却发现boss是他失散多年的父亲，而父亲刚才把解药给了他。"

□ 禁止格式：
  ✗ "且听下回分解"式虚钩
  ✗ "突然发生了一件大事"——无具体变量
  ✗ 与本章冲突无直接绑定的远期悬念
```

## 模块C：失败模式图谱

> 常见拒稿/降权原因及自查定位。

### C1. 开篇失败模式

| 失败类型 | 错误写法 | 正确写法 | 自查问题 |
|:---|:---|:---|:---|
| 主角未登场 | "这个世界分为五大区域..." | 直接写"陈墨在第三次基因检测仪前停下脚步..." | 是否在300字内写了主角名字？ |
| 待机状态 | "他是一个普通少年..." | "他蹲在废墟里，等待机甲巡逻队离开——还有四分钟。" | 主角在做什么具体的事？ |
| 背景洪水 | 前500字全是设定 | "父亲留下的机甲残骸还冒着烟，上面的编号他能倒背如流——GX-7，是当年追击他的型号。" | 设定是否裹在动作里？ |

### C2. 主线失败模式

| 失败类型 | 错误写法 | 正确写法 | 自查问题 |
|:---|:---|:---|:---|
| 主角被动 | 主角总是被推着走 | "陈墨点击确认键的瞬间，张远的表情变了——他早就知道这个选择会导致什么。" | 主角是否在做主动选择？ |
| 冲突无代价 | 打赢了没事 | "战斗结束后的三个小时，他的右眼视野开始模糊——视网膜过载的代价。" | 每个冲突后是否有可感知的代价？ |
| 情节灌水 | 大段日常描写 | "吃饭时他注意到菜单上多了一道新菜——标注是'变异生物肉'——这个细节让他决定换一家店。" | 这段是否能用一句话替代或删除？ |

### C3. 平台规则失败模式

| 失败类型 | 触发后果 | 自查问题 |
|:---|:---|:---|
| 未达8万字触发推荐 | 流量窗口期延误 | 每日写作量是否≥4000字？连续性记录是否≥3天？ |
| 完读率<40% | 算法降权，推荐位断崖 | 前三章读完率是否≥60%？章节内是否有多处"可停下"点？ |
| 内容修改延迟 | 数据持续低迷 | 是否有24小时内响应数据下滑的机制？ |
| 涉黄/抄袭/旧稿挪用 | 直接封禁/永久拒稿 | 发布前是否通过安全审核自查？ |

> 每章发布前/修改前的强制校验流程。

### D1. 一级门禁（任何情况下不可跳过）

```
☐ 1. 前300字主角已登场并进入核心事件（非待机状态）
```

## 模块E：平台规则→作家行动映射

> 原编辑稿中平台规则转化为可直接执行的动作。

### E1. 签约规则（2万字定签）

```
□ 行动：2万字内完成"目标确立→阻力→破局"闭环
□ 行动：每章至少一个"主角掌控主线"的证据场景
□ 行动：删除所有"无剧情推动"的流水账段落
□ 行动：确保主角是事件推动者，而非事件见证者
□ 禁忌：设定堆砌、背景说明、无升级路径的日常
```

### E2. 推荐规则（8万字+连更）

```
□ 行动：每日写作量必须≥4000字（预留缓冲）
□ 行动：连续3天日更4000字后，手动点击"开始推荐"
□ 行动：推荐期内严格遵守"承诺→兑现→升级"循环
□ 行动：数据下滑节点（读完率<40%），24小时内修改
□ 禁忌：连更期断更、冒险追热点导致质量波动
```

### E3. 数据反哺规则

```
□ 行动：每章发布后48小时内检查核心数据
□ 行动：读完率<50%的章节，定位"可停下"点并修改
□ 行动：留存时长下滑时，加强章末钩子密度
□ 行动：算法实时生效意味着"写完即改，改完即发"
□ 禁忌：修改后不发布、等待审核导致时效损失
```

### E4. 包装转化规则

```
□ 行动：书名必须包含核心元素（题材+冲突+情绪）
  示例：《基因武道：我能看见进化线》《机甲战神：她杀死了指挥官》
□ 行动：简介必须含"剧情钩子+人设亮点+互动小剧场"
□ 行动：简介小剧场可直接转化为短视频/有声剧素材
□ 禁忌：简介写"讲述了..."、"这是一个关于..."的抽象描述
```

### E5. 稿费结算规则

```
□ 行动：签约是前提，未签约章节不计稿费
□ 行动：满100元可提，次月第二周周四结算
□ 行动：每次提现前确认绑定账户信息无误
□ 禁忌：以为"发布就有钱"、忽视签约与结算门槛
```

## 模块F：科武长篇专属执行补丁

> 针对《科武纪元》世界观与长篇体量的补充指令。

### F1. 设定碎片化嵌入规则

```
□ 禁用：连续超500字的纪元编年史/力量体系说明
□ 替代方案：
  - 技能解释→动作分解（"他启动第二层基因锁，脊椎的骨刺穿透皮肤——剧痛，但力量来了。"）
  - 世界观展示→道具/场景细节（"街角的广告屏循环播放着'第37次基因改良计划'的宣传，语气像是在卖早餐。"）
  - 科技说明→对话/吐槽（"这机甲的系统还是第32代的？"）
```

### F2. 战力平衡执行指令

```
□ 每场战斗/能力使用后，必须更新：
  - 本次消耗量：____
  - 恢复所需时间：____
  - 副作用：____

□ 禁止：无限续杯的能力、被打败后满血复活的设定

□ 示例：
  "基因锁突破让他获得了速度优势，但代价在六小时内显现——视野边缘持续闪烁的警告，意味着视网膜细胞正在加速凋亡。这场战斗用掉了他本周所有的再生配额。"
```

### F3. 节奏规划指令（长篇连载）

```
□ 8万字前：完成"世界观展示→首次体系验证→第一个大高潮"
□ 8-20万字：完成"势力格局→第一次大失败→重建→升级"
□ 20万字后：完成"终极冲突铺垫→多线收束→终局"

□ 连更缓冲章：至少预留3章"可插入的过渡章节"以应对意外断更
```

### F4. 单主角视角强动机指令

```
□ 若走"冷峻推演/群像/硬科幻"路线，开篇必须强化：
  - 生存动机（"如果不在三天内突破，他会被基因锁反噬"）
  - 情感锚点（"妹妹的病只有他能救"）
  - 信息差动机（"他发现了一个所有人都不知道的真相"）

□ 禁止：开篇用"全知视角"展示宏观格局，然后才进入主角
□ 禁止：主角缺乏明确动机，靠"作者安排"推动剧情
```

## 模块G：短故事/狼人篇可借用点

> 针对短篇故事的规则适配。

### G1. 可直接借用的规则

| 规则 | 借用方式 |
|:---|:---|
| 开篇300字铁律 | 压缩为"300字内主角登场并进入核心冲突" |
| 章末钩子格式 | 转为"单章闭环钩子"，可用反转型/选择型 |
| 冲突密度公式 | 800-1200字一个节点，适用于6000-15000字的短篇 |
| 物理反馈指令 | 增强感官密度，短篇需要更强烈的即时反馈 |
| 代价植入指令 | 短篇可"一步到位"，代价更直接、更致命 |
| 简介互动小剧场 | 改为"世界观微切片"，突出悬念感 |

### G2. 短篇不可硬套的点

- **连更节奏**：短篇无连更需求，但需考虑"单次完读率"
- **战力平衡**：短篇通常无体系验证，但需有"能力代价"机制
- **长篇伏笔**：短篇要求"信息完整"，禁止埋伏笔不开

### G3. 狼人篇/都市异能短篇模板

```
□ 开头公式：
  主角身份（表面）→ 触发事件 → 异能耗出 → 代价显现

□ 冲突公式：
  已知敌人 → 新信息揭露 → 主角选择 → 代价结算 → 反转

□ 结尾公式：
  核心悬念闭环 + 留一个"更大谜团"的钩子（若做系列）
```

## 模块H：热点稿专属执行补丁

> 针对追热点/快速迭代的规则适配。

### H1. 热点响应机制

- **连续更新**：热点稿通常单篇/短系列，不依赖连更机制

## 附录：快速查阅卡

> 写作时快速调用的核心指令。

### A. 开篇检查（300字内）

```
□ 主角名字出现了吗？
□ 主角在做什么具体的事？
□ 遇到了什么阻力？
□ 主角做了什么主动选择？
□ 是否建立了"如果...就..."的预期？
```

### B. 章末检查

```
□ 本章推动了主线吗？（是/否）
□ 主角支付了代价吗？（具体是什么？）
□ 钩子有具体变量吗？（能回答"接下来会发生什么"吗？）
□ 章节在哪个点可以停下来？（优化"可停下"位置）
```

### C. 发布前检查

```
□ 签约了吗？
□ 达到8万字了吗？
□ 连续3天日更4000字了吗？
□ 手动点击"开始推荐"了吗？
□ 数据达标了吗？
□ 安全审核通过了吗？
□ 稿费够100了吗？
```
