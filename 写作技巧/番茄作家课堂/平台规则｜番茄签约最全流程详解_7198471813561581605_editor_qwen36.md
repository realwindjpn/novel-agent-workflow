# 《科武纪元》编辑学习官｜番茄签约规则提炼

## 1 课程核心判断（≤6条）
1. **签约是流量与收益的唯一前置条件**：未签约作品无推荐、无打赏、无稿费，签约后需稳定更新承接8万字推荐节点。
2. **机会有限且不可逆**：2万/5万/8万字各1次申请机会，共3次；3次全败永久封签，失败后必须精修达标方可进入下一节点。
3. **审核双轨制**：先过安全审核（内容/格式/导向，工作日7天内），再过编辑评估（题材/节奏/人物/开篇/代入感/主线/故事性）。
4. **题材适配度优先于文笔**：平台明确将“题材是否适合签约”列为评估第一维度，非大众化/易读性弱的题材易被筛除。
5. **底线问题一票否决**：不安全、低俗、言语不通、故事性不强、侵权等直接导致评估失败。
6. **短故事与长篇流程一致但入口独立**：结构要求不同，但签约节点、合同流程、实名校验标准完全统一。

## 2 可执行编辑规则
| 维度 | 规则（基于原文评估标准与流程约束） |
|:---|:---|
| **开篇** | 前2万字必须完成“核心悬念抛出+主角动机确立+基础世界观落地”，禁止纯设定堆砌或慢热铺垫，直接对标“开篇、代入感”评估项。 |
| **节奏** | 严格卡点2万/5万/8万字节点：每1-2万字需有一次情绪/剧情小高潮，5万字前完成首次主线阶段性收束，匹配平台字数评估节奏。 |
| **冲突** | 冲突必须具象化、可感知，对话与行动需直接推动剧情；严禁“言语不通”或逻辑断裂导致的故事性薄弱，触碰底线直接拒签。 |
| **人物** | 主角行为逻辑需与当前阶段能力/资源严格匹配，避免工具人化；人物设定需服务于主线推进，满足“人物设定”评估要求。 |
| **题材** | 需具备明确商业类型标签（如升级、悬疑、热血、群像），避开低俗/负面导向/侵权红线；科幻需做“可读性降维”包装。 |
| **改编** | 短故事需单线闭环、结构紧凑；长篇需预留8万字推荐前的数据爬坡期，不可用短篇节奏写长篇架构。 |
| **平台规则** | ①严格分段排版，避开安全审核格式雷区；②合同实名/银行卡/手机号100%一致；③利用3次机会前完成精修，失败不可逆。 |

## 3 科武适配
**✅ 可用点**
- **开篇强代入**：用具体科武场景（如义体过载、基因锁开启、星舰跃迁故障）替代理论说明，快速建立“代入感”。
- **节奏卡点**：将2/5/8万字节点与科武体系突破/关键战役绑定，天然契合平台字数评估节奏。
- **主线清晰**：科武融合的核心目标（如“破解古武基因序列”“对抗机械飞升”）需贯穿始终，满足“主线”评估。
- **安全底线**：科幻设定需规避现实敏感映射、低俗描写，确保通过安全审核。

**❌ 不可硬套点**
- **“题材适合签约”偏向大众化**：硬科幻/慢热哲学探讨需做类型化改造，不可直接套用平台易读标准。
- **“短故事流程一致”≠结构一致**：《科武纪元》为长篇，不可用短篇单线闭环逻辑写长篇，需按节点规划多线伏笔。
- **“无强制更新”≠可断更**：科武长篇依赖世界观连续性与设定记忆，断更极易导致读者流失，数据断崖将直接影响推荐池。

## 4 编辑检查表（10条以内）
1. [ ] 2万/5万/8万字节点前是否完成对应精修与错漏排查？
2. [ ] 前3章是否抛出核心冲突并建立主角明确动机？
3. [ ] 能否用一句话概括前5万字的核心目标与主线走向？
4. [ ] 每1-2万字是否安排一次剧情/情绪小高潮？
5. [ ] 是否已排查低俗、敏感、侵权、未分段等安全审核雷区？
6. [ ] 对话是否推动剧情？有无“言语不通”或逻辑断层？
7. [ ] 主角行为是否符合当前科武阶段的能力与资源限制？
8. [ ] 是否具备平台易读的商业类型标签（非纯设定流）？
9. [ ] 作者资料、实名信息、银行卡号是否100%一致？
10. [ ] 签约后能否保证稳定更新以承接8万字推荐流量？

## 5 对作家角色的输入要求
- **动作链**：场景推进必须遵循“触发→决策→执行→结果”闭环，禁止用心理独白或设定说明替代动作推进；每场戏需有明确因果链。
- **物理反馈**：科武战斗/修炼需具象化感官反馈（如肌肉撕裂感、能量过载的灼痛、机械义肢的延迟、神经接驳的眩晕），杜绝抽象数值堆砌。
- **代价**：每次能力突破、战术选择或阵营站队必须伴随明确代价（资源枯竭、身体损伤、信任破裂、时间窗口关闭），维持故事张力与逻辑自洽。
- **钩子**：每章结尾必须埋设未解悬念或危机预告（如“警报骤响，舱门外传来非人频率的敲击声”），强制拉动追读率，匹配平台“代入感”评估。
- **读者预期**：严格兑现开篇承诺的类型标签（如“科武升级”需明确成长路径，“悬疑”需按时回收伏笔），禁止中期随意切换赛道导致代入感断裂与数据流失。
