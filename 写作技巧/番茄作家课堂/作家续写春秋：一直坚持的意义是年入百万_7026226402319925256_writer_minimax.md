## 一、作家操作系统核心指令（5条）

| 优先级 | 指令 | 违反代价 |
|:---:|:---|:---|
| **P0** | 免费用户3秒决策窗口：首章300字内必须抛出生存危机或核心目标，禁止慢热铺垫 | 算法降权→流量断崖 |
| **P1** | 每章必须完成一次“遇阻→破局→留悬”小循环，禁用纯抒情或总结性收尾 | 完读率衰减→推荐权重下滑 |
| **P2** | 战斗/操作必须遵循“意图→发力→轨迹→结果”物理逻辑链，禁用“意念秒杀”“模糊特效” | 科武读者信任崩塌→订阅流失 |
| **P3** | 能力跃升/战术胜利必须支付明确代价（资源消耗/身体损伤/阵营暴露/战略被动） | 战力通胀→逻辑链断裂→读者弃书 |
| **P4** | 章末必须设置“未解变量”钩子，与下章首段形成因果咬合 | 本章留人率下降→下一章进入率折损 |

## 二、写作前任务卡字段更新

在动笔前，填充以下字段，作为创作基准线：

| 字段 | 填写要求 | 示例 |
|:---|:---|:---|
| **本卷核心冲突** | 一句话，利益/生存/信念驱动，禁止模糊 | “林远争夺赤乌晶矿脉开采权” |
| **本章主角目标** | 可验证的即时目标，禁止“成长”“蜕变”等空泛词 | “修复左臂神经接口” |
| **主角行动链** | 意图→发力→轨迹→结果，四段式拆解 | “启动神经同步→输出40%功率→刃尖切入装甲接缝→切断能量管道” |
| **代价清单** | 列举本次行动将消耗/损伤的要素 | “燃料储备-15%，左臂肌肉群负荷+8%，暴露信号源位置” |
| **未解变量** | 本章结束时留下的悬念，格式：触发条件+未知走向 | “敌方增援抵达时间未知/林远是否触发陷阱” |
| **读者预期交付** | 本章必须兑现的承诺，量化表述 | “解锁火蜥蜴装甲近程火力模式” |
| **科武设定验证** | 本章涉及的科技/武道逻辑是否自洽，自查备注 | “能量刃热传导参数：刃芯温度2800℃，外壳隔热层厚度2mm→符合设定” |

## 三、章节自检清单

写完本章后，逐项核验：

```
□ 本章300字内是否抛出生存危机或核心目标？
□ 本章是否完成“遇阻→破局→留悬”小循环？
□ 战斗/操作描写是否包含意图→发力→轨迹→结果四段式？
□ 能力跃升/战术胜利是否支付了明确代价？
□ 章末钩子是否为“未解变量”（非纯悬念/抒情）？
□ 钩子与下章首段是否存在因果咬合？
□ 科武设定（科技/武道）逻辑是否自洽？（能量衰减/机体负荷/材料形变）
□ 人物动机是否由利益/生存/信念驱动？（禁止作者强行安排）
□ 是否存在冗余日常或说明性灌水？（若有，标记为待删）
□ 标签/简介是否精准匹配目标读者搜索习惯？
```

## 四、标注借用点

### 短故事/狼人篇可借点

| 借用项 | 操作方式 | 示例 |
|:---|:---|:---|
| **3秒决策窗口** | 首句直给生存危机或核心目标 | “她醒来时，神经接口里还残留着三天前的警报：赤乌矿脉失守” |
| **小循环结构** | 每篇完成“遇阻→破局→留悬”，适合短篇节奏 | 单元剧模式，每篇独立闭环+伏笔串联 |
| **代价清单** | 能力使用必须有消耗，可量化 | “火球术消耗精神力12点，冷却时间4小时” |
| **物理反馈链** | 技能效果需有环境/身体反馈 | “火焰吞噬木质舱壁，产生高温烟气，主角被迫屏息” |

### 科武长篇可借点

| 借用项 | 操作方式 | 示例 |
|:---|:---|
| **长尾资产逻辑** | 完本后持续产生推荐流量，追求完整交付 | 完本后优化简介/标签/封面激活二次推荐 |
| **填坑完结标准** | 以伏笔回收/主线填坑为完结准，非预设字数 | “本卷必须回收：林远身份之谜+赤乌矿脉归属+神经接口缺陷来源” |
| **设定密度+情绪钩子** | 标签精准匹配搜索习惯，简介前50字亮出核心卖点 | “神经同步·机甲格斗·废土探索” |
| **真实质感转译** | 物理/格斗/材料学逻辑嵌入战斗描写 | “能量刃切入装甲时，需描写热传导、结构应力、碎片抛射轨迹” |
| **垂直破圈路径** | 高门槛赛道靠“设定自洽+节奏紧凑+情绪交付”穿透流量池 | 不依赖泛娱乐热点，靠硬核质量留存 |

### 平台规则转译为发布/包装/风险门禁

| 平台规则 | 转化为作家执行门禁 | 违反后果 |
|:---|:---|:---|
| 免费模式核心指标：读完率 | 章末钩子必须强到让读者点下一章 | 完读率下滑→推荐权重下降 |
| 加入书架率 | 每5章必须提供一次“必收藏”理由（伏笔/升级/势力揭晓） | 书架转化率低→失去二次曝光 |
| 段评互动 | 在悬念点/冲突点预留段评钩子（可引导但禁止操纵） | 互动低迷→算法降低分发 |
| 签约后稳定更新至完本 | 制定更新日历，禁止断更超过3天 | 断更触发降权→推荐中断 |
| 完本后优化简介/标签/封面 | 预留完本后优化窗口（封面素材/标签矩阵/简介文案） | 二次推荐激活失败→长尾流量断崖 |

## 五、失败模式速查表

| 失败类型 | 症状 | 修复方向 |
|:---|:---|:---|
| **开局溺水** | 首章300字后仍无核心冲突，读者直接关闭 | 重写前三段，直给生存危机或目标 |
| **节奏沼泽** | 章内有超过500字无冲突推进（非必要日常/说明） | 删除冗余段落，或嵌入新的阻碍元素 |
| **战力通胀** | 主角升级无代价，战力数值无上限飙升 | 补全代价清单（资源/身体/阵营/战略），设定战力天花板 |
| **逻辑断层** | 科武设定前后矛盾（能量守恒/物理法则） | 回溯设定文档，标注矛盾点并修复 |
| **钩子失焦** | 章末留的悬念与下章开头脱节，读者期待落空 | 重写章末或重写下章首段，确保因果咬合 |
| **脸谱化瘟疫** | 配角纯工具人，正派必正确反派必邪恶 | 重写配角：赋予功能性动机+可验证行为逻辑 |
| **标签失配** | 简介/标签与内容核心卖点不符 | 对照目标读者搜索习惯，重写前50字简介 |
