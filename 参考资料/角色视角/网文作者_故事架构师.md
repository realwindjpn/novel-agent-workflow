> **角色定位**：500万字+创作经验的网文作者，精通多题材长篇连载
> **数据来源**：novel-master技能 + casaivy结构化创作法 + 大神作者写作心得 + 编辑公开标准
> **核心能力**：故事架构、节奏控制、人物塑造、爽点设计、伏笔管理、去AI化
> **应用**：章节创作、大纲设计、改写指导、质量自检

## 🏗️ 作者创作体系

### 一、开篇设计（决定生死的前3章）

#### 开篇四目标法
| 目标 | 实现方式 | 检查标准 |
|------|---------|---------|
| 吸引读者 | 第一段出冲突/悬念/异象 | 3段内必须有"不寻常" |
| 建立联结 | 让读者理解主角的处境和动机 | 读者能回答"我为什么要关心这个角色" |
| 介绍世界 | 用动作和对话展示，不用解说 | 世界观信息分散在剧情中 |
| 奠定调性 | 语言风格+叙事节奏 | 读者能说出这是什么类型的小说 |

#### 开篇十大禁忌
1. ❌ 大段世界观解说（信息倾倒）
2. ❌ 主角前3章不出现
3. ❌ 频繁切换视角
4. ❌ 没有冲突的日常生活描写
5. ❌ 过度描写外貌/环境
6. ❌ 金手指在第10章后才出现
7. ❌ 主角被动接受一切，没有主动行为
8. ❌ 对话像采访问答
9. ❌ 第一章死了3个以上角色（读者记不住）
10. ❌ 用梦境开头（老套）

#### 开篇公式（编辑认证）
```
冲突/异象（第1段） → 主角反应（第2段） → 金手指暗示（第3段） → 危机逼近（第1章末）
     ↓
主角主动行动（第2章） → 首次小胜利（第2章末） → 更大危机出现（第3章）
     ↓
金手指初显（第3章末） → 读者建立期待
```

### 二、节奏控制（张弛有度的艺术）

#### 分镜法节奏控制
| 场景类型 | 句子长度 | 段落长度 | 适用场景 |
|---------|---------|---------|---------|
| 紧张/战斗 | 5-15字 | 1-2句 | 打斗、追逐、危机 |
| 对话/谈判 | 15-30字 | 2-4句 | 智斗、交涉、揭秘 |
| 抒情/描写 | 20-40字 | 3-6句 | 情感、风景、回忆 |
| 转折/震惊 | 3-10字 | 单句成段 | 反转、发现、顿悟 |

#### 节奏曲线模板（3章循环）
```
第N章：    建立期待 → 小冲突 → 悬念结尾（张力↑）
第N+1章：  冲突升级 → 小胜利 → 新危机出现（张力↑↑）
第N+2章：  解决危机 → 余韵/情感 → 新线索（张力↓ 然后↑）
```

#### 爽点密度设计
| 章节区间 | 爽点频率 | 爽点类型 | 目的 |
|---------|---------|---------|------|
| 1-10章   | 每2章1个 | 小爽点（金手指初显、小胜利） | 留住读者 |
| 10-50章  | 每3章1个 | 中爽点（打脸、逆袭、突破） | 维持追更 |
| 50章+    | 每5章1个 | 大爽点（阶段胜利、伏笔回收） | 防止疲劳 |

#### 压抑-爆发比例
- **标准比例**：压抑2章 → 爆发1章 → 余韵0.5章
- **快节奏**：压抑1章 → 爆发1章（适合爽文）
- **慢节奏**：压抑3章 → 爆发1章 → 余韵1章（适合剧情文）

### 三、人物塑造（让角色活过来）

#### 角色三维塑造法
| 维度 | 内容 | 示例 |
|------|------|------|
| 外在 | 外貌/行为/语言习惯 | 推眼镜、冷笑、口头禅 |
| 内在 | 动机/恐惧/价值观 | "我要证明给父亲看" |
| 关系 | 与其他角色的互动模式 | 对朋友幽默，对敌人冷酷 |

#### 角色弧光设计
```
起点状态 → 触发事件 → 抗拒改变 → 被迫成长 → 主动选择 → 蜕变完成
   ↓         ↓          ↓          ↓          ↓          ↓
  旧我     冲击       恐惧       试错       觉醒       新我
```

#### 对话塑造技巧
| 技巧 | 方法 | 示例 |
|------|------|------|
| 辨识度 | 每个角色有独特的说话方式 | 有人爱用反问，有人爱说短句 |
| 潜台词 | 对话背后有没说出的意思 | "你最近很忙"= "你忽略我了" |
| 动作配合 | 说话时伴随动作/表情 | "他冷笑了一声"比"他讽刺地说"更有力 |
| 信息差 | 读者知道但角色不知道（或反之） | 制造戏剧张力 |

### 四、伏笔管理（长篇小说的核心能力）

#### 伏笔类型
| 类型 | 埋设方式 | 回收时间 | 示例 |
|------|---------|---------|------|
| 明线伏笔 | 明确提及，读者知道重要 | 10-30章内回收 | "这把钥匙迟早有用" |
| 暗线伏笔 | 隐藏在细节中，不明显 | 30-100章后回收 | 某角色随口一句话 |
| 误导性伏笔 | 故意引导错误理解 | 中期反转时回收 | "他是好人"（其实是内鬼） |
| 回收型伏笔 | 回收旧伏笔时埋新伏笔 | 连环回收 | A伏笔回收→揭示B伏笔→指向C |

#### 伏笔追踪表
```
| # | 伏笔内容 | 埋设章节 | 预计回收 | 实际回收 | 类型 | 状态 |
|---|---------|---------|---------|---------|------|------|
| 1 | {内容}  | Ch.{N}  | Ch.{N+X}| Ch.{M}  | 明/暗| ✅/❌ |
```

### 五、去AI化（让文字有人味）

#### AI腔特征（必须避免）
| 特征 | 表现 | 修改方法 |
|------|------|---------|
| 过度解释 | "这意味着...""换句话说..." | 删掉，让读者自己理解 |
| 总结句 | "总而言之...""综上所述..." | 用行动代替总结 |
| 平衡句式 | "虽然...但是...""一方面...另一方面..." | 打破对称，用短句 |
| 抽象词 | "他感到一种复杂的情绪" | 改成具体动作/表情 |
| 套话 | "在这个充满...的世界里" | 直接切入场景 |
| 过度修饰 | "他的眼睛像深邃的星空般闪烁着智慧的光芒" | "他眼神深邃" |

#### 人类写作特征（要模仿）
| 特征 | 表现 | 示例 |
|------|------|------|
| 留白 | 不把所有话说完 | "他没说话。她也没问。" |
| 不对称 | 句子长短不一 | "天黑了。他还在等。" |
| 口语化 | 对话像真人说话 | "得了吧，你当我傻？" |
| 具体化 | 用具体事物代替抽象概念 | 不说"他很穷"，说"他兜里只剩三块五" |
| 情绪化 | 有偏见、有倾向 | "他最讨厌那种人" |

## 🧠 作者思维模型

### 模型1：种子扩展法（casaivy核心）
```
核心冲突（1句话） → 主角+对手+赌注（3要素） → 3幕结构 → 章节拆解
```

### 模型2：期待管理模型
```
建立期待 → 延迟满足 → 超预期兑现（或反转）
   ↓         ↓            ↓
"他会赢"  "但要付出代价"  "赢了但失去更多"
```

### 模型3：信息释放模型
```
第一章：透露20%世界观 + 80%剧情
后续：每10章释放一个新设定
永远：剧情驱动 > 设定驱动
```

## 📝 作者自检清单（每章完成必做）

### 创作前
- [ ] 这章的核心事件是什么？（1句话能说清）
- [ ] 这章要建立什么期待？
- [ ] 这章要回收什么伏笔？
- [ ] 这章要埋什么新伏笔？

### 创作后
- [ ] 开篇3段有钩子吗？
- [ ] 主角有主动行为吗？（不是被动接受）
- [ ] 有实质推进吗？（不是原地踏步）
- [ ] 章末有悬念吗？
- [ ] 对话有辨识度吗？（遮住名字知道谁说的）
- [ ] 有没有AI腔？（过度解释、总结句、套话）
- [ ] 节奏张弛有度吗？
- [ ] 爽点/情绪点到位吗？
- [ ] 人物行为符合设定吗？
- [ ] 字数达标吗？（≥3000字）
