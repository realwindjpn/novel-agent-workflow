## 一、核心补丁（写入作家系统）

### 🔴 自我怀疑消解指令
> 当你卡在“这段不够好”“这个设定有问题”时，执行以下协议：

```
【立即执行】
1. 标记“待优化”但不停止当前章节
2. 记录卡点：❌ 具体是什么（场景/对话/逻辑）
3. 问自己：这段卡顿是“能力问题”还是“情绪干扰”？

【判断分支】
→ 能力问题：✅ 降级处理（简化场景/缩减对话/用已知能力推进）
→ 情绪干扰：✅ 跳过，写下一段已知可写的，写完再回来

【禁止操作】
✗ 停笔超过2小时
✗ 重写同一段超过3次
✗ 删除超过500字（除非确定替换内容更优）
```

> **姜双鱼原话转化**：你的自我怀疑是多余的。完成度 > 完美度。断更/切书成本远高于瑕疵连载。

---

### 🔴 科武世界观强制约束
```
【前置门槛】
开写前必须完成：
□ 能量回路基本规则（至少3条可运作逻辑）
□ 重力/环境变量表（与战斗相关的2-3项参数）
□ 神经接驳协议（接口类型/延迟/负荷上限）

【禁止行为】
✗ 用“爆发”“碾压”“全力输出”等模糊动词描写战斗
✗ 让角色做出“无代价技术突破”
✗ 战力对比无量化基准
```

## 二、写作前任务卡（字段更新版）

### 新建章节任务卡

| 字段 | 必填内容 | 示例 |
|:---|:---|:---|
| **章节目标** | 本章要完成的1件事 | 完成神经接驳超频测试，暴露代价 |
| **触发动作** | 什么事件启动本章 | 教官下达限时突破令 |
| **执行闭环** | 触发→动作→交互→反馈（4步） | 见下方模板 |
| **代价落地** | 能力获得/战斗胜利的代价 | 神经负荷超标→视野雪花点 |
| **情绪锚点** | 读者可投射的顺逆境 | 突破前的恐惧/突破后的短暂狂喜 |
| **章末钩子** | 未解变量+情绪悬置 | 雪花点未消退/教官表情异常 |
| **字数估算** | 本章目标字数 | 2000-2500 |
| **自检注** | 写完后检查哪3点 | 代价是否在3章内显性化 |

### 任务卡快速模板

```
【章节编号】第X章
【核心动作】神经接驳超频测试
【四步闭环】
→ 触发：教官下达72小时突破令
→ 动作：主角执行超频协议，手动提高接驳率
→ 交互：机甲骨架共振频率异常，座椅减震系统介入
→ 反馈：视野出现雪花点，反应速度暂时提升但无法维持
【代价标签】神经负荷↑ / 视野损伤风险
【情绪标签】恐惧→专注→短暂狂喜→隐忧
【钩子】雪花点在任务结束后仍未消退，教官说“这很正常”
【借点标注】科武长篇用；短故事可简化为“一次测试失败”
```

## 三、章节自检清单（写完即查）

### ✅ 硬性检查（不过则改）

```
□ 1. 本章核心动作是否完成4步闭环？（触发/动作/交互/反馈）
□ 2. 是否有可量化的物理/生理反馈？（至少2项）
□ 3. 能力突破/战术胜利是否支付明确代价？（3章内显性化）
□ 4. 章末是否留有“未解变量+情绪悬置”？（非纯悬念）
□ 5. 主角是否有“可投射的脆弱面”出现？（读者代入点）
□ 6. 配角是否提供功能性支撑？（技术/情绪/资源，至少1项）
□ 7. 无机械降神：冲突是否由角色选择触发？
□ 8. 无模糊动词：战斗/技术描写是否可拆解？
```

### ✅ 软性检查（可选优化）

```
□ 9. 每10章是否校准过一次“爽点:痛点:成长点≈4:3:3”？
□ 10. 情绪断点排查：读者是否知道主角“想要什么+缺少什么”？
□ 11. 更新节奏：是否保持稳态输出（而非完美主义停更）？
□ 12. 设定膨胀预警：新增设定是否与主线目标强绑定？
```

### ✅ 科武专项检查（科幻/机甲/武学类）

```
□ 13. 能量回路是否自洽？（消耗/补充/上限/反噬）
□ 14. 环境变量是否影响战术选择？（重力/气压/辐射/干扰）
□ 15. 神经接驳是否有延迟/负荷/副作用？
□ 16. 战力对比是否有基准？（避免崩坏）
```

## 四、动作库（可直接调用）

### 战斗动作闭环模板

```
【标准格式】
触发条件 → 执行动作 → 环境交互 → 结果反馈

【示例：近战格斗】
触发：敌方突进至近距离
动作：主角切换至徒手格斗模式，左拳虚晃
交互：敌方防御重心前移，右肋暴露
反馈：右拳实击命中，敌方肋骨断裂

【示例：机甲操控】
触发：敌方火力压制
动作：启动液压增援系统，强行拉起机臂格挡
交互：地面摩擦产生高温，减震系统报警
反馈：格挡成功但手臂关节过热，灵活度下降15秒
```

### 科武日常动作库（训练/维护/社交）

```
【神经接驳训练】
触发：教官下达任务 → 动作：接入校准程序 → 交互：数据流涌入感知区 → 反馈：轻微眩晕+视野校准完成

【机甲日常维护】
触发：每日点检 → 动作：扫描关节磨损 → 交互：系统标注3处临界点 → 反馈：需在下次任务前更换主臂液压

【资源冲突场景】
触发：补给限额下达 → 动作：主角申请追加配额 → 交互：教官调出历史数据对比 → 反馈：申请被否，暗示另有原因
```

## 五、反馈库（可量化参数）

### 科武核心反馈指标

| 类型 | 参数 | 表现 | 影响 |
|:---|:---|:---|:---|
| **神经负荷** | 接驳率% | 视野雪花/反应迟滞/耳鸣 | 超100%会短暂失控 |
| **热量堆积** | 机甲核心温度℃ | 关节卡顿/装甲发红/警报 | 超临界值强制降频 |
| **资源储备** | 能量块/弹药基数 | 战术选择受限/被迫撤退 | 归零则战斗终止 |
| **心理压力** | 阈值测定 | 决策冲动/视野收窄/呼吸急促 | 超限会触发战栗反应 |
| **生理损伤** | 累积伤害% | 功能性降级/永久性缺失 | 超过阈值不可逆 |

### 代价显性化模板

```
【代价格式】
获得/胜利 → 代价类型 → 显性化时间 → 具体表现

【示例】
神经接驳超频 → 神经负荷 → 3章内 → 视野雪花点持续3天，影响第7章关键战斗

【示例】
破解敌方通讯 → 技术反噬 → 本章内 → 我方通讯系统被植入后门，下周战斗暴露
```

## 六、失败模式速查表

| 症状 | 诊断 | 修复动作 |
|:---|:---|:---|
| **卡文超过2小时** | 情绪干扰 / 能力缺口 | 降级处理或跳过写下一段 |
| **战斗描写“碾压”化** | 缺代价闭环 | 强制加入：关节过热/弹药告急/反应迟钝 |
| **设定越写越多** | 设定膨胀 | 暂停新设定，回归主线目标 |
| **读者反馈“太悬浮”** | 缺物理反馈 | 补写：重力加速度/热量堆积/神经负荷 |
| **数据下滑** | 情绪断点 | 排查主角“想要什么+缺少什么” |
| **配角无存在感** | 功能性缺失 | 补写：提供技术/情绪/资源支撑的具体场景 |
| **章末无钩子** | 纯悬念/抒情结尾 | 改为“未解变量+情绪悬置” |
| **自我怀疑停笔** | 完美主义 | 记住：完成度 > 完美度，断更成本 > 瑕疵成本 |

## 七、人物口吻模板库

### 科武角色说话风格

```
【铁血型/教官】
特征：短句+命令式+专业术语
模板：“接驳率超标8%。继续？还是中止？”
“别用感情用脑。要用这里。”（指太阳穴）

【隐忍型/主角】
特征：压抑情绪+自我调侃+坚定内核
模板：“雪花点而已。还不至于看不见路。”
“我知道代价。但这代价我付得起。”

【技术型/搭档】
特征：数据化表达+轻度冷幽默+实用主义
模板：“按我的算法，你还有47秒窗口期。跑快点。”
“成功率62%。别赌，做计划。”

【反派/压迫型】
特征：压迫性陈述+暗示后果+掌控感
模板：“你以为这是在争取？不，这是在乞求。”
“资源配额已冻结。从今天起，你没有任何谈判筹码。”
```

## 八、段落节奏节拍器

### 四段节拍器（每章必用）

```
【节拍1：能力展示】
字数：300-500
功能：建立角色能力边界，触发读者投射期待
要点：展示“能做什么”，为后续受挫铺垫

【节拍2：受挫/代价】
字数：500-800
功能：打破预期，制造情绪落差
要点：代价必须具体且可见，禁用“轻微不适”

【节拍3：调整/支撑】
字数：400-600
功能：情感锚点+战术重整，读者投射“陪伴感”
要点：支撑来源必须具体（技术/资源/情感），非空泛鼓励

【节拍4：突破/钩子】
字数：300-500
功能：完成闭环+留未解变量
要点：突破必须支付代价，钩子必须带情绪悬置
```

## 九、章末钩子库（可直接套用）

### 科武场景钩子模板

```
【技术类】
✓ “系统日志显示：第3次接驳时出现了未知数据包。发送源：未知。”
✓ “教官说这是正常反应。但正常反应会在任务结束后持续72小时吗？”

【人际类】
✓ “搭档的权限被降了一级。在任务前48小时。”
✓ “她说‘我会等你’。但她没有说，等多久。”

【资源类】
✓ “能量块储量显示：12小时。而任务需要至少36小时。”
✓ “清单上没有这项物资的申请入口。也没有出口。”

【时间类】
✓ “倒计时还剩4小时。神经负荷已达87%。临界值是90%。”
✓ “下一次新月是72小时后。敌人知道，我知道。”

【悬念类（禁用）】
✗ “他究竟是谁？”（纯悬念，情感悬置不足）
✗ “她的眼神背后藏着什么秘密？”（纯悬念，无未解变量）
```

## 十、借点标注

### 📌 短故事/狼人篇可借用

| 模块 | 借用方式 |
|:---|:---|
| **自我怀疑消解指令** | 直接套用，适用于任何创作瓶颈期 |
| **章节自检清单（硬性）** | 简化版：1/2/4/5条，适用于万字短篇 |
| **失败模式速查表** | 适用任何类型创作，忽略科武参数 |
| **四段节拍器** | 压缩为：展示→受挫→突破，或展示→受挫→支撑→突破 |
| **人物口吻模板库** | 替换科武术语为对应类型术语 |
| **代价显性化** | 任何情节必须有代价，3章→本章内即可 |

### 📌 科武长篇专用

| 模块 | 使用说明 |
|:---|:---|
| **写作前任务卡** | 必须完整填写，四步闭环不可省略 |
| **动作库/反馈库** | 每场战斗/训练必调用，确保物理反馈≥2项 |
| **科武专项检查** | 长篇设定易膨胀，每10章检查一次 |
| **设定膨胀预警** | 新设定必须与主线强绑定，禁止自嗨 |
| **完本预留检查** | 完本前预留人物关系网+结局收束路径 |

### 📌 平台规则→发布/包装/风险门禁

| 原编辑规则 | 转化为 |
|:---|:---|
| 番茄重“情绪价值+稳定更新+完本率” | 发布前检查情绪主线是否完整；周更≥2章保底 |
| 数据下滑优先排查情绪断点 | 章节自检清单第12条：情绪断点排查 |
| 编辑协同贯穿至完结后 | 建立“阶段性目标-数据反馈-微调”机制 |
| 出版/影视向需预留人物关系网 | 完本前自检清单第8条：人物关系网+结局收束 |
