# 《科武纪元》编辑学习官｜平台规则提取报告

## 1 课程核心判断（≤6条）
1. **规则前置**：90%以上创作/运营问题可通过帮助中心自助检索解决，人工反馈为兜底机制。
2. **状态即流量**：“安全可推荐/隐藏/下架”状态直接决定作品能否进入推荐池与搜索可见。
3. **反馈结构化**：有效反馈必须包含“书名+具体位置+自查结论+关键截图”，缺失则处理降级。
4. **收益双轨制**：全勤与奖金结算依赖“日更≥4000字”与“听书+阅读分成≥100元”双指标。
5. **时效纪律**：工作时间内提交、禁止重复刷屏是提升平台响应率的唯一可控变量。
6. **合规底线**：内容安全（无抄袭/无违规映射）是触发推荐与结算的硬性前置条件。

## 2 可执行编辑规则（按原文实际内容取舍）
> 注：原文为纯平台运营与客服指南，未涉及写作技法。以下规则按“平台合规与流量运作”维度提取，严格对应所要求类目：

| 类目 | 可执行规则（基于原文） |
|:---|:---|
| **开篇** | 发布后24小时内必做“搜索可见性测试”与“安全可推状态核对”，异常立即按SOP反馈，避免开篇流量断档。 |
| **节奏** | 更新节奏强制绑定“日更4000字”门槛，断更或字数不足将直接触发全勤扣除与推荐流降权。 |
| **冲突** | 无直接规则。但涉及现实映射/科技伦理/敏感设定的冲突描写，需提前检索帮助中心“审核标准”，规避触发“审核不通过”或“下架”。 |
| **人物** | 无直接规则。需确保人物设定、背景描述无版权争议或洗稿嫌疑，否则影响“安全可推荐”状态判定。 |
| **题材** | 科幻/短故事/热点稿均需通过平台内容安全红线。题材标签与简介需与正文一致，避免“标题党”导致搜索算法降权。 |
| **改编** | 无直接规则。若涉及IP改编或同人衍生，需确保授权链路清晰，否则平台有权直接下架并冻结收益。 |
| **平台规则** | ① 遇问题先搜帮助中心，后提交反馈；② 反馈必带书名/章节/站内信/截图；③ 收益结算以听书+阅读双端数据为准；④ 状态异常自查实名认证、隐藏设置、违规记录。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接落地）
- **长篇连载《科武纪元》**：建立“发布前状态自查→日更4000字打卡→收益面板核对”的标准化运营流，保障长篇推荐池不断档。
- **短故事**：利用帮助中心搜索“短篇审核/敏感词库”，提前过滤科幻设定中的现实政治/伦理争议，确保一次性过审。
- **热点稿**：热点时效性强，发布后若遇“搜索无结果”，立即按原文示例二格式提交工单，缩短流量拦截时间。

### ❌ 不可硬套点（需剥离）
- **不可将“客服反馈流程”等同于“内容质量评判”**：平台规则只解决合规与流量分发，不评判科幻逻辑自洽性、世界观展开节奏或短篇结构完整性。
- **不可为凑“日更4000字”牺牲设定严谨度**：科幻长篇的硬核推演需独立于字数门槛之外，断更可补更，但逻辑崩坏不可逆。
- **不可依赖平台事后审核兜底**：“安全可推”是底线，非创作上限。科幻题材的先锋性/实验性需作者自行把控尺度，不能以“等审核反馈”代替发布前自查。

## 4 编辑检查表（10条以内）
- [ ] 发布前确认作品状态为“安全可推荐”，非隐藏/审核中/下架
- [ ] APP内搜索书名/核心关键词，确认结果可见且排序正常
- [ ] 当日更新字数≥4000字，无断更/漏更记录
- [ ] 核对当月听书+阅读分成收益是否≥100元（全勤触发线）
- [ ] 内容无抄袭/洗稿/未授权引用，符合平台内容安全规范
- [ ] 遇审核/流量异常，先检索帮助中心对应规则，不盲目提交
- [ ] 提交反馈必含：书名+章节/问题点+自查结论+站内信/状态截图
- [ ] 工单提交时间优先工作日9:00-18:00，避开非工作时间排队
- [ ] 同一问题不重复提交，不刷屏催促，保留平台处理周期

## 5 对作家角色的输入要求
> 基于原文平台逻辑，将创作概念转化为**可量化、可追踪的系统输入项**：

| 维度 | 输入要求（作家必须交付/执行） |
|:---|:---|
| **动作链** | 规则检索 → 状态核对 → 稳定更新 → 异常定位 → 结构化反馈（严格按帮助中心目录与示例模板执行） |
| **物理反馈** | 平台系统返回的明确信号：站内信通知、搜索可见性结果、状态标签（安全可推/下架）、收益数据面板、工单处理进度 |
| **代价** | 违规/断更/格式错误的直接后果：推荐流切断、全勤扣除、账号限流、反馈工单被驳回或延迟处理、收益结算冻结 |
| **钩子** | 触发平台流量分配的前置条件：日更4000+激活推荐池、收益≥100元解锁全勤、标题/简介/标签匹配搜索算法、内容安全过审 |
| **读者预期** | 平台规则塑造的体验底线：内容无违规断更、更新稳定可预测、搜索可直达、听书/阅读双端数据同步、无版权争议干扰阅读 |
