# 《科武纪元》编辑学习官：《玄幻作品创作宝典》萃取报告

## 1 课程核心判断（≤6条）
1. **品类定节奏**：传统流重慢热长线、体系铺陈；脑洞流重快节奏、密集爽点。定位偏差直接导致留存率断崖。
2. **体系即骨架**：力量/经济/势力等多维设定必须逻辑自洽，决定故事容量与防崩盘能力。
3. **人物去脸谱**：主角需带微瑕特质，反派/配角需智商在线且动机独立，群像关系网是长篇续航核心。
4. **期待感＞纯升级**：通过信息差、长线目标、阶段性奖励制造持续阅读动力，避免“为升级而升级”的数值堆砌。
5. **开篇定算法**：前3章必须切入核心剧情/危机，设定后置；书名与内容强绑定以契合平台推荐池抓取逻辑。
6. **套路是基建**：新手应先吃透成熟范式（废柴逆袭/重生/系统等），在框架内做微创新，而非盲目求新。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 1-3章内抛出核心危机或金手指；出场人物≤3个；剧情先行，世界观/设定以“碎片化”方式随剧情自然带出，禁止开篇大段说明书。 |
| **节奏** | 传统长篇：阶梯式升级，每卷设明确目标与地图边界，控制战力膨胀；脑洞/短篇：压缩修炼过程，用“系统/选择/奇遇”直接交付结果，爽点密度≥1/3章。严禁系统与主角无效对话拖慢节奏。 |
| **冲突** | 依赖信息差与身份反转（扮猪吃虎/降维打击）。反派需配置背景网络，击败小怪必须引出大怪或新势力。长线冲突需提前埋设“倒计时/契约/宿敌”锚点。 |
| **人物** | 主角拒绝伟光正，赋予1-2个接地气缺点（贪财/嘴贱/过度谨慎等）。配角需独立行为逻辑，形成利益/情感关系网。反派智商≥主角，胜利需靠谋略/代价而非纯数值碾压。 |
| **题材** | 明确分类标签，文风与设定严格贴合标签。科幻/科武需将“修炼体系”转译为“科技/基因/机甲/能量”逻辑，保持底层规则一致。 |
| **改编** | 长篇：预留“地图扩展/势力更迭/体系升维”接口，利用支线人物引出新剧情线；短篇：聚焦单一核心脑洞，砍掉冗余支线，结尾留反转或悬念，不追求宏大收束。 |
| **平台规则** | 书名必须直白对应核心卖点/脑洞，利于算法抓取；标签选择精准，避免跨品类误导推荐池；首秀期（前10万字）保持日更稳定，断更/水文直接触发推荐降权。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移/转译）
- **体系自洽逻辑**：将“灵气/境界”替换为“基因锁/义体改造/能量阈值/科技树”，保持升级阶梯清晰、命名易记。
- **期待感管理**：用“技术突破倒计时/星际远征目标/机甲迭代路线/资源配额”替代“三年之约”等传统锚点。
- **群像与反派网络**：科武世界天然适合多势力（财阀/军方/科研院/星际海盗/AI矩阵）博弈，配角可承载不同科技路线与利益诉求。
- **开篇危机切入**：以“实验事故/机甲失控/基因崩溃/资源争夺/轨道打击”开局，快速建立生存压力与行动动机。
- **节奏分层**：长篇走“技术积累→实战验证→体系跃迁”循环；短篇走“单点黑科技→极限应用→逻辑反转破局”。

### ❌ 不可硬套点（需规避/重构）
- **修仙玄学术语**：如“天道/因果/渡劫/法宝认主/顿悟”等，与科武的“物理法则/科学验证/工程逻辑”冲突，需彻底转译或舍弃。
- **无脑系统爽**：科武强调“技术代价/资源限制/物理反馈”，系统奖励必须符合能量守恒、研发周期或材料稀缺性，禁止“凭空造物/无视冷却”。
- **迪化流脑补搞笑**：科武基调偏硬核/冷峻，过度依赖配角脑补会削弱科技设定的严肃性与逻辑张力，易造成战力体系崩坏。
- **武侠中低武映射**：科武战力跨度极大（单兵→舰队→行星级），不能套用“凡人江湖”的武力天花板，需重新定义破坏尺度与战术边界。

## 4 编辑检查表（10条以内）
- [ ] 前3章是否已抛出核心危机/金手指？出场人物是否≤3人？
- [ ] 力量/科技体系是否有清晰阶梯（大/小境界）且命名易记、无生造词堆砌？
- [ ] 主角是否具备1-2个非完美特质？反派/配角是否有独立动机与智商？
- [ ] 当前章节是否推进了主线/支线？有无纯设定说明或系统废话拖节奏？
- [ ] 爽点是否依赖“信息差/身份反转/阶段性成果”而非纯数值碾压？
- [ ] 地图/势力边界是否明确？有无提前规划下一卷扩展接口？
- [ ] 书名是否精准匹配核心题材/脑洞？标签选择是否无跨类混淆？
- [ ] 长篇是否埋设了≥1个长线期待锚点（目标/宿敌/技术瓶颈）？
- [ ] 科武设定是否通过物理反馈/资源代价/工程逻辑自洽？有无玄学漏洞？
- [ ] 更新节奏是否匹配品类预期？首秀期有无断更/水文风险？

## 5 对作家角色的输入要求
| 维度 | 必须交付的输入标准（科武向） |
|:---|:---|
| **动作链** | 提供“触发条件→执行步骤→环境交互→结果输出”完整序列。科武场景需明确技术/装备介入节点（例：神经接驳启动→义体过载阈值→战术规避→能量释放）。禁止跳跃式描写或“意念一动”式施法。 |
| **物理反馈** | 每次能力释放/装备使用必须附带可量化的环境/生理反馈（例：装甲温度飙升、骨骼微裂、重力场扭曲、数据流延迟、辐射残留）。反馈需严格匹配当前科技树设定，禁止无损耗操作。 |
| **代价** | 明确每次升级/越级战斗的硬性代价（资源消耗、基因排异、冷却周期、社会关系破裂、技术反噬、伦理审查）。代价必须推动后续剧情（例：为修复义体被迫接黑市任务/暴露坐标）。 |
| **钩子** | 每章结尾必须设置“未解危机/技术悬念/身份反转/资源缺口”之一。钩子需与主线强关联，禁止纯情绪断章。长篇需每10万字重置一次钩子层级，保持期待感迭代。 |
| **读者预期** | 开篇3章内需明确交付“核心卖点承诺”（如：硬核机甲对战/基因进化路线/星际生存法则）。后续剧情必须按承诺兑现，升级/破局需符合已建立的科学/逻辑框架，禁止机械降神或临时改设定。 |
