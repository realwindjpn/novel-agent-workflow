# 《科武纪元》编辑学习官｜番茄课堂规则提炼

## 1 课程核心判断（≤6条）
1. **10万字前数据无效**：未达推荐阈值前，算法不介入分发，点击/留存数据无参考价值，核心指标仅为“稳定完本至10万字”。
2. **卡文本质是结构缺失**：写不长主因非笔力不足，而是大纲未立、世界观尺度失衡（过大无血肉/过小无延展）、细节过度内耗。
3. **长篇续航靠循环拆解**：10万字需拆分为10个“1万字剧情单元”，每单元必须包含铺垫-发展-高潮-影响闭环。
4. **体系设定决定篇幅上限**：境界/科技树/势力/规则等底层框架必须前置搭建，否则剧情必然在几万字后枯竭。
5. **热梗需经延展性验证**：网络梗/热点必须通过“能否支撑3+大情节、是否递进/反转、主线是否连贯”三问，否则不可作为开篇支点。
6. **断更即破坏算法权重**：2万字签约、10万字推荐是平台铁律；断更超1天触发惰性循环，且易错过题材热度窗口，直接导致入池失败。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 禁止宏大设定堆砌或单一热梗直开。先明确核心脑洞与主角人设，以具体事件/冲突切入，再逐步释放世界观。 |
| **节奏** | 采用“万字循环法”：每1万字完成一次完整剧情弧。卡文时直接删除非核心细节/台词，优先推动主线，完稿后再精修。 |
| **冲突** | 冲突必须由人物行动逻辑自然衍生，禁止为爽而爽。情节需层层递进或带反转，杜绝同质化套娃。 |
| **人物** | 强制撰写人物小传（动机/缺陷/行为模式）。主角与配角的行动关联构成剧情推力，人设不稳必致逻辑崩盘。 |
| **题材** | 长篇需前置搭建“可延展体系”（境界划分、科技/武道规则、势力版图）。体系厚度直接决定剧情可写长度。 |
| **改编/热点** | 热点素材必须转化为“完整主线接口”。开书前自问：能否衍生3个以上大情节？是否具备递进/反转结构？画风是否统一？ |
| **平台规则** | 2万字签约门槛，10万字触发算法推荐。10万字前保持日更稳定，屏蔽无效数据焦虑，专注进度与结构完整。 |

## 3 科武适配（《科武纪元》）
### ✅ 可用点
- **体系前置**：科武题材天然依赖“科技树+武道境界+能量源/机甲等级”，直接套用“体系支撑篇幅”规则，提前划定升级路径与势力版图。
- **结构拆解**：10万字拆为10个“技术突破/武道试炼/阵营博弈”循环，符合长篇连载的阶段性目标管理。
- **人物驱动**：科武易陷入“设定碾压剧情”，强制人物小传可确保科技/武道进展由角色动机推动，而非作者强行推进。
- **平台入池**：番茄对科幻/高武标签有独立分发池，10万字前稳定更新是触发算法推荐的唯一硬性条件。

### ⛔ 不可硬套点
- **“跳过细节继续写”**：科武战斗/科技应用依赖硬核逻辑与物理反馈，关键机制（如能量回路、重力参数、武道经脉）不可盲目跳过，需保留核心逻辑链。
- **“热梗情绪化套用”**：科武非纯情绪爽文，热点需转化为“科学假说/技术奇点/武道哲学”，不能仅追求短期情绪刺激而牺牲世界观自洽。
- **“每万字必高潮”**：科幻长篇需留白与伏笔回收，不能机械追求每万字情绪爆点，需平衡“探索/铺垫期”与“爆发/验证期”。

## 4 编辑检查表（8条）
- [ ] 核心脑洞是否可用一句话概括主线目标与最终阻力？
- [ ] 主角及3名核心配角是否已完成人物小传（动机/缺陷/行动逻辑）？
- [ ] 科武体系（境界/科技/势力/规则）是否已列出基础框架与升级路径？
- [ ] 10万字是否已拆解为10个“铺垫-发展-高潮-余波”剧情单元？
- [ ] 开篇是否避开设定堆砌，以具体事件/冲突切入并明确类型承诺？
- [ ] 当前情节是否满足“递进/反转”，无重复套娃或逻辑断裂？
- [ ] 是否已建立防断更机制（存稿/日更目标/阶段性奖励）？
- [ ] 10万字前是否已屏蔽无效数据焦虑，专注结构完整与进度推进？

## 5 对作家角色的输入要求
| 维度 | 输入要求（写作时必须落实） |
|:---|:---|
| **动作链** | 每章必须包含“触发事件→角色决策→执行动作→直接结果”完整链条。禁止用纯心理描写、设定说明或旁白替代角色行动。 |
| **物理反馈** | 科武交互需具象化感官反馈（如能量过载的神经灼痛、机甲关节液压声、重力异常的内脏压迫、武道反噬的肌肉撕裂）。用可感知的物理细节替代抽象形容词。 |
| **代价** | 每次突破/胜利必须伴随明确损耗（资源枯竭、身体损伤、阵营信任破裂、道德妥协、技术反噬）。杜绝无代价升级或机械降神。 |
| **钩子** | 章末必须留悬念（未解危机/新线索/角色反常行为/体系规则异动）。确保读者有翻页动力，支撑日更留存率。 |
| **读者预期** | 开篇3章内明确“核心目标+主要阻力+体系基础规则”。10万字内完成首次大循环闭环，兑现类型承诺（科幻的探索验证感/武道的成长突破感），不偏离主线轨道。 |
