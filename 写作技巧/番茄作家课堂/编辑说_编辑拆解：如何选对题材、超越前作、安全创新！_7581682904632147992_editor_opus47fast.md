## 1. 课程核心判断（6条）

1. **成神率 ≫ 题材新鲜度**：作者熟悉度（自己写过/自己看过）比题材本身的市场热度更能决定第一本能否起来。
2. **读者画像决定三观红线**：同一设定（如疯批男主）在学生向是爽点，在中老年向是雷点；分类切换=读者切换=三观切换。
3. **前台故事 > 后台故事**：开篇必须给"对抗钩子"，世界观与人物深挖是第二顺位，不能用"精品感"挤掉入门钩子。
4. **套路与创新非二元**：套路是几十年沉淀的"包装技术"，创新是切入点；正确比例≈ 90%套路 + 10%创新，成名后再升到 80/20。
5. **纯创新 ≈ 高赔率赌博**：抛弃全部套路写法的纯创新作品，编辑端看到的成功概率极低，会反噬作者道心。
6. **学爆款=学本质，不是学剧情**：要看"为什么讨喜/用什么情绪驱动（仇恨流/温馨流/期待感）"，而不是抄人设和主线。

## 2. 可执行编辑规则

### 开篇
- 必须有"前台故事"——一个可在第1章用一句话说清的**对抗式钩子**（例：女主拼命攻略 vs 男主拼命想杀）。
- 世界观、人物深层动机延后释放，绝不在开篇堆砌。
- 接地气优先于高大上：哪怕世界观再宏大，开篇情境必须让读者"一眼看懂冲突双方在抢什么"。

### 节奏
- 前台冲突先行，后台伏笔慢慢铺；伏笔可埋但当前章必须有当前章的爽点/钩子。
- 学长篇节奏要看**完整百万字**作品，只看10个开篇会导致中后期崩文。

### 冲突
- 优先采用**对抗型双主体冲突**（目标互斥、立场互斥），而非单方面成长冲突。
- 在套路冲突结构里换"新切入点"，而不是换"冲突机制本身"。

### 人物
- 人设讨喜度是可以反推的：先问"这个人设为什么讨喜"，再决定要不要用。
- 三观必须对齐目标读者年龄段（中年向避免疯批/无底线，少年向避免说教/婆妈）。
- 人物冲突手法沿用已验证的成功技巧，不要和世界观一起创新。

### 题材选择
- **老作者**：深耕原分类，做"设定矩阵"——同一题材轮换子设定（年代替嫁→年代姐妹同嫁→年代重生复仇）。
- **新作者**：选"自己看得最多的分类"，而不是"现在最火的分类"。
- 切忌跨分类追热点：不熟分类=不懂读者三观=高崩率。

### 改编/精品化
- 不要在第二本就奔着"影视改编/精品感"去写——会牺牲前台故事。
- 精品化是火了之后做的事；先解决"被读者看到"，再解决"被行业看到"。

### 平台规则（番茄向）
- 免费市场扩张 → 读者年龄跨度极大（几岁～80岁），"烂大街"对新用户=新设定，套路仍然有效。
- 平台编辑端可直接横向比较"创新比例 vs 数据"，因此创新激进度建议保守、阶梯式上调。
- 学习火文≠抄火文：连环撞梗（主线+人物关系一致，仅换称谓性别）平台会判融梗/高仿。

### 学习火文的方法
- 同一流派至少**3本对比**，提取"共通元素"才算套路；只看1本照着写=撞梗。
- 学"为什么"，不学"是什么"：拉仇恨？温馨升级？期待感？情绪驱动机制才是要抄的"作业"。
- 看完整长篇，不止看开篇。

## 3. 《科武纪元》适配性分析

### ✅ 可直接用的点
- **前台故事先行**：科武世界观再硬核，开篇必须落到一个"两个人/两股势力当下就要互掐"的具象冲突上。例如主角第1章就被一个明确敌人盯上，而不是先讲"科武体系起源"。
- **对抗式双主体钩子**：科武题材天然适合"修行流派对立 / 科学派 vs 武道派 / 体制内 vs 散修"这种立场互斥钩子。
- **共通点抽取法**：找3本头部科幻向/科武向/赛博修真，提取共通套路（金手指节奏、第一次实战出现章节、第一个反派死亡时点）作为骨架。
- **设定矩阵**：科武纪元主线之外，可衍生短故事——同一世界观换子设定（年代式：第一代拓荒者 / 学院新生 / 黑市散修），降低读者迁移成本。
- **90/10 创新比例**：科武的"新瓶"是世界观（科技+武道融合），"旧酒"必须是网文成熟的成长线、打脸节奏、情绪曲线。
- **三观对齐**：明确科武纪元目标读者年龄段，再决定主角狠度、感情线浓度、暴力描写尺度。

### ⚠️ 不可硬套的点
- **"深耕老分类"建议**对科武不完全适用——科武本身是融合题材，没有现成的单一读者池；要把"老分类"理解为"科幻读者+硬核成长流读者"两个池子分别研究，而不是只锚定一个。
- **女频爆款经验（疯批/攻略/替嫁）**不能直接平移到科武主线，但可在短故事/支线CP里有限借用。
- **"先火再创新"**对长篇科幻不完全成立——科武纪元世界观本身就是创新主体，无法降到10%；应对策略：**世界观可创新到30-40%，但人物/冲突/节奏严格保留90%套路**。
- **百万字学习样本**：纯硬科幻长篇样本稀缺，需用"科幻+网文混血"作品（如赛博修真、星际种田）作为节奏教材，而非传统科幻。
- **影视改编思维**要克制，但科武世界观天然有IP属性，可在大纲层保留改编潜力，**不要在正文表达层为改编做妥协**。

## 4. 编辑检查表（每章/每篇过一遍）

1. 本章是否有"一句话能讲清的前台冲突"？
2. 是否存在"为了铺世界观而拖慢当前冲突"的段落？删。
3. 当前章是否有钩子指向下一章（悬念/翻转/未兑现的代价）？
4. 主角的目标和反派的目标是否互斥、且在本章有正面碰撞？
5. 出现的新设定是套路改造（新瓶旧酒）还是纯原创？纯原创比例是否>10%（长篇科武放宽到30%）？
6. 人设讨喜点能不能用一句话说出"为什么讨喜"？说不出=未成立。
7. 本章三观是否匹配目标读者年龄段？有无中年雷点/少年腻点？
8. 是否在学习参考作品时只参考了1本？若是，强制再加2本做共通点比对。
9. 是否出现"主线+人物关系"与参考作高度同构？若是，重构关系拓扑。
10. 章末是否同时给到：**情绪兑现 + 新钩子**？缺一不可。

## 5. 对"作家角色"的输入要求

写作Agent在生成《科武纪元》正文/短故事/热点稿时，**输出必须显式包含以下5要素**，缺项即驳回重写：

### ① 动作链（Action Chain）
- 每个关键场景输出**≥3步可视化动作**：起手 → 接触 → 结果。
- 禁止用"他打败了对方"概括；必须有招式名/科武机制/环境互动。
- 动作链需标注**因果连接词**（因此/导致/反弹），不允许跳步。

### ② 物理反馈（Physical Feedback）
- 任何招式/科技使用后必须给出**身体或环境的可感反馈**：体温、血氧、装备过热、空间震荡、对手姿态变化。
- 反馈要量化或具象（"护甲表面温度升至灼手" > "护甲很热"）。

### ③ 代价（Cost）
- 主角每次获得能力跃迁/胜利时，必须同步标注**等价或非对称代价**：寿元、记忆、关系、信誉、装备损耗、世界线变化。
- 代价必须在**后续章节兑现**，不能只口头承诺。

### ④ 钩子（Hook）
- 每章/每段结尾输出一个**明确指向未来的未决项**：未现身的人、未解的谜、已触发但未结算的因果。
- 钩子需分级标注：**章钩 / 卷钩 / 主线钩**，避免全是小钩子稀释主线张力。

### ⑤ 读者预期（Reader Expectation）
- 每段输出需附**目标读者情绪标签**：爽 / 燃 / 揪心 / 期待 / 反差 / 解谜。
- 标签需与目标读者画像（年龄段、阅读偏好）对齐，禁止情绪混搭导致读者错位（如同一段既要中年共鸣又要少年中二）。
- 套路/创新比例需显式标注：`[套路:创新 = X:Y]`，长篇科武主线 ≥70:30，短故事/热点稿 ≥90:10。
