# 《科武纪元》编辑学习官｜钩子设计实战规则提取

## 1 课程核心判断（≤6条）
1. **钩子本质是期待感管理**：涵盖伏笔、悬念、情绪、目标等一切驱动读者翻页的元素，无钩子=无留存。
2. **开篇必须零铺垫直给**：黄金三章禁用世界观说明书，依赖信息差、强人设、新脑洞或明确目标强行抓眼。
3. **悬疑开篇绑定题材预期**：风格突变将触发高弃书率，钩子类型需与主线类型强一致。
4. **人设开篇容错率高但门槛高**：主角需具备“反常理+强反差+不讨人厌”特质，读者为人设买单可容忍剧情平淡。
5. **章末钩子需动态调节**：平淡期加猛料，高频期留轻悬，断章疲劳直接拉低追读。
6. **钩子有效性取决于兑现节奏**：无规划、无线索回收的钩子等于透支信任，必须附带可验证路径。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 规则 | 适用载体 |
|:---|:---|:---|
| **开篇** | 首章前500字必须抛出核心钩子（四选一：硬悬疑/人设/脑洞/目标），禁用背景铺陈与设定堆砌。 | 长篇/短故事/热点稿 |
| **节奏** | 章末悬念强度与近期剧情密度反比挂钩；连续2章无实质推进，第3章末必植入突发事件或信息反转。 | 长篇连载 |
| **冲突** | 钩子需绑定具体行动目标或即时威胁，呈现逻辑为“结果前置+过程留白”，拒绝抽象情绪拉扯。 | 短故事/热点稿 |
| **人物** | 开篇3000字内完成主角“反常行为+合理动机”展示，建立情感锚点；后续人设不崩可对冲剧情平淡。 | 长篇/短故事 |
| **题材** | 悬疑/科幻/系统类开篇钩子需与主线类型强绑定；跨类型转换需在10章内完成平滑过渡，否则弃书率飙升。 | 长篇科幻 |
| **平台规则** | 匹配番茄“滑动阅读”习惯：每章保留1个可即时验证的悬念点；黄金三章决定首推流量池，钩子密度需≥1/章。 | 全平台网文 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **脑洞/系统式开篇**：直接展示科武核心机制（如“义体排异率突破临界值”“古武基因链异常激活”“机甲同步率倒挂”），用信息差制造悬念，替代冗长设定说明。
- **目标/复仇式铺垫**：绑定科武晋升路径或生存危机（如“限时清除污染区”“偿还机甲改装债务”“破解敌对财阀追杀令”），提供长线驱动力。
- **章末动态调节**：科幻长篇易陷入技术说明或战斗推演，需用章末钩子（未知信号接入/系统报错/敌袭预警）打断说明文节奏，强制翻页。
- **人设锚点**：主角在科武体系下的“反常选择”（如拒绝主流神经接驳、选择冷兵器古武/旧时代机械），快速建立辨识度与追读粘性。

### ❌ 不可硬套点
- **纯硬悬疑开篇**（如“参加自己葬礼”）：科武长篇需逻辑自洽与物理规则支撑，纯悬疑易与硬核设定冲突，后期圆回成本极高，易导致风格割裂。
- **独立情感/约定式钩子**（如“战后娶你”）：科武读者核心预期为“战力成长/科技解密/生存博弈”，情感钩子必须依附于具体任务或生存危机，不可作为独立驱动力。
- **高频断章/猛料堆砌**：科武战斗与科技展开需一定篇幅建立严谨性，过度使用“章末猛料”会破坏体系沉浸感，导致读者疲劳弃书。

## 4 编辑检查表（10条以内）
- [ ] 首章前500字是否已抛出明确钩子（悬疑/目标/人设/脑洞）？
- [ ] 钩子是否做到“零铺垫直给”，无世界观/设定说明书？
- [ ] 主角是否在开篇展现“反常行为+合理动机”，具备记忆点？
- [ ] 章末是否保留至少1个未解悬念或突发事件？
- [ ] 近期剧情若偏平淡（连续2章无推进），章末是否已植入“猛料”？
- [ ] 钩子类型是否与《科武纪元》主线风格（科幻/战斗/成长）强绑定？
- [ ] 是否存在“为悬而悬”的无效断章？（断章需有后续3章内可验证的线索）
- [ ] 目标/复仇类钩子是否附带清晰的时间/条件限制？
- [ ] 情感/约定类钩子是否已前置足够的剧情与人设支撑？
- [ ] 钩子兑现节奏是否匹配滑动阅读习惯（每章有即时反馈点）？

## 5 对作家角色的输入要求
| 要素 | 强制输入标准 |
|:---|:---|
| **动作链** | 必须提交“触发事件→主角决策→执行动作→即时结果”完整闭环；禁用纯心理描写或旁白替代动作推进。 |
| **物理反馈** | 科武设定下，每次力量/科技介入需附带可量化的环境/躯体反馈（如“神经接驳灼痛指数+15%”“液压过载警报”“重力场扭曲致玻璃碎裂”），拒绝抽象战力描述。 |
| **代价** | 钩子兑现或能力使用必须绑定明确代价（资源消耗/躯体损伤/阵营暴露/时间倒计时），禁止无成本开挂或机械降神。 |
| **钩子** | 每章提交时需标注：①钩子类型 ②预期兑现章节 ③线索埋设位置（精确到段落）；未标注视为无效钩子。 |
| **读者预期** | 明确本章钩子旨在满足何种预期（如“期待反杀/期待解密设定/期待人设反转”），章末附1句话自检：“本章是否偏离该预期？若偏离，修正路径为何？” |
