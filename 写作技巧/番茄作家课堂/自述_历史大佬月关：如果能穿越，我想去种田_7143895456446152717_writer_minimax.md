## 一、核心动作指令（可直接执行）

### ▶ 动作1：章末钩子三选一强制植入
```
每章结尾必须植入以下类型之一：
├─ 数据悬念型：倒计时归零/资源濒临耗尽/系统警告激活
├─ 关系断点型：盟友背叛征兆/核心人物立场模糊/情感承诺动摇
└─ 信息增量型：隐藏设定露出冰山一角/敌方势力真实意图初露
禁用：纯情绪断句、无后续关联的开放式结局
```

### ▶ 动作2：冲突触发四步闭环
```
触发事件 → 主角决策（可推断但非显而易见） → 执行（伴随代价消耗） → 结果（未完成/代价超预期/新变量介入）
```
**执行检查**：若跳过任何一步，冲突张力断裂。

### ▶ 动作3：设定输出物理化转译
```
抽象设定必须转化为五感可感知的物理反馈：
├─ 神经接驳 → 耳鸣/视野闪烁/肢体延迟感
├─ 真气涌动 → 筋膜撕裂感/空气灼热/重力扭曲
├─ 科技突破 → 能量波动/设备过载警报/环境异变
└─ 境界跨越 → 感官过载/意识短暂断片/身体不可逆改变
```

### ▶ 动作4：代价强制账单
```
每次核心能力使用/突破/升级必须明确：
├─ 即时代价：资源消耗/身体损伤/关系损耗
├─ 滞后代价：势力反噬/技术反噬/人性代价（如：杀伐决断动摇盟友信任）
└─ 禁止项：零成本能力、无后遗症的武力碾压
```

### ▶ 动作5：预期线索提前3-5章埋设
```
每10章必须完成一组预期-兑现闭环：
├─ 线索埋设：[科技图纸残页/武道试炼封印/神秘势力暗桩] → 隐于日常章节
├─ 钩子强化：线索触发事件使读者产生强烈追读欲
└─ 超预期兑现：满足或反转读者预期（二选一，禁止平兑）
```

### ▶ 动作6：读者评论分级过滤
```
├─ 逻辑/设定漏洞 → 必改（72小时内评估）
├─ 短期情绪宣泄 → 过滤（不反驳、不调整方向）
└─ 有理有据建议 → 评估（符合主线则采纳，不符合则存档）
```

### ▶ 动作7：大纲20%弹性预留
```
大纲结构：
├─ 核心主线节点（不可动）
├─ 关键人物弧光节点（轻微弹性）
└─ 支线/灵感接入区（预留20%空间，供读者反馈与创作灵感触发）
```

### ▶ 动作8：世界观锚点首章必完
```
首章3000字内必须完成：
├─ 世界观锚点：科技层级+武道体系+势力格局（一句话）
├─ 主角核心动机：我要什么/我怕失去什么
└─ 首个冲突/钩子：主角面临的第一道选择题
```

## 四、失败模式识别（避坑指南）

### ⚠ 模式1：免费午餐型金手指
```
触发条件：主角能力/突破无代价
特征：无消耗/无后遗症/无边界
后果：战力体系崩，读者弃
```

### ⚠ 模式2：情绪断句式章末
```
触发条件：章末仅输出情绪/感慨，无悬念变量
特征：以感叹号/疑问句结束，但无实质信息增量
后果：追更欲望清零
```

### ⚠ 模式3：逻辑跳跃式冲突
```
触发条件：跳过决策或代价环节
特征：冲突突然发生又突然结束，主角行为不可预测
后果：读者信任崩塌，人设OOC
```

### ⚠ 模式4：工具人堆砌
```
触发条件：配角/反派仅服务剧情，无独立动机
特征：反派随时出现随时消失，配角零台词零弧光
后果：世界真实感归零，IP改编价值归零
```

### ⚠ 模式5：文青化标题/简介
```
触发条件：标题/简介使用暗示性/文学性表述
特征：读者预期与实际内容错位
后果：跳出率↑，定位标签失效
```

### ⚠ 模式6：连续3章水化
```
触发条件：连续3章无新冲突/无信息增量
特征：日常堆砌/设定说明/角色对话无推进
后果：完读率雪崩，编辑介入干预
```

## 五、人物口吻模板

### ◆ 主角口吻（科武向）
```
决策句式：[现状分析] + [资源盘点] + [风险预估] + [决策]
例："义体能源还剩17%，追踪者距离800米。
     正面硬刚耗能，绕路会暴露。
     先引开再伏击，赌他们的反应延迟。"
情绪句式：[物理反应] + [情绪标签]
例："胸腔传来义体过载的灼痛，手指不自觉颤抖。
     但我不能退。"
```

### ◆ 反派/配角口吻
```
逻辑型："利益→行动"链条清晰
例："这份技术报告价值三座城。
     我不关心你的正义，只关心我的筹码。"
情感型："动机→行为"基于情感/信念
例："十年前你们毁了这里。
     现在轮到你们尝尝。"
```

### ◆ 科技/武道描述转译模板
```
科技奇观：[设备名] + [运作状态] + [五感反馈] + [环境异变]
例："量子推进器嗡鸣骤停，蓝光熄灭的瞬间，
     舱室陷入漆黑，耳膜被真空吸力撕扯。"
武道力学：[动作] + [能量路径] + [物理效果] + [代价信号]
例："真气沿经脉逆冲右拳，筋骨发出金属般啸响，
     轰出的拳风将空气撕裂——但膝盖传来骨裂的闷响。"
```

## 六、段落节奏模板

### ◆ 标准章节结构（3000字级）
```
┌─ 开篇（前300字）：延续上章钩子或启动新变量
│  └─ 立即进入冲突/决策/动作，禁止铺垫
├─ 中段（2400字）：冲突展开→代价消耗→信息增量
│  └─ 每800字插入一个小高潮/转折点
└─ 章末（300字）：钩子三选一 + 下一章悬念锚定
```

### ◆ 高能章节结构（开局/关键节点）
```
┌─ 开篇（前200字）：首个冲突/选择已发生
├─ 中段（2600字）：快节奏决策+执行闭环×2-3次
│  └─ 每500字一个微型转折
└─ 章末（200字）：重大悬念/代价显现/关系断点
```

### ◆ 过渡章节结构（信息铺垫/情感蓄力）
```
┌─ 开篇（前300字）：日常/内心独白，锚定情绪
├─ 中段（2200字）：穿插小冲突/伏笔触发/关系深化
│  └─ 至少1个"意外变量"打断平静
└─ 章末（500字）：平静打破，钩子升级为危机
```

## 七、章末钩子模板库

### ▶ 钩子类型A：数据悬念
```
倒计时型：
"能量核心的温度指数还在攀升。
  系统提示剩余时间：[0:47]......
  而出口的光点还在两公里之外。"

资源濒临型：
"备用能源只剩最后一次脉冲。
  而追踪信号正在逼近——
  不止一个。"
```

### ▶ 钩子类型B：关系断点
```
背叛征兆型：
"通讯器里传来战友的声音：
 '我已经把坐标发了出去。'
 他站在原地，看着屏幕上的敌人定位信号——
 来自己方阵地。"

立场模糊型：
"'你知道我不会放弃他。'
 她没有回答，只是将手中的芯片
 悄悄滑进了他的口袋。"
```

### ▶ 钩子类型C：信息增量
```
设定初露型：
"屏幕上闪过一行从未见过的代码：
 '████████协议激活。
  警告：此操作不可逆。'"

势力暴露型：
"投影中浮现出那枚徽章——
 他见过。在父亲二十年前的机密档案里。
 而那页档案的标题是：'已死亡'。"
```

## 十一、平台规则转译（发布/包装/风险门禁）

### ◆ 发布门槛

| 规则 | 作家执行动作 |
|:---|:---|
| **前30章完读率**决定流量池层级 | 优化前三章钩子密度，确保1000字/章内有一个有效悬念点 |
| **追更率**是推荐核心指标 | 每章结尾必须有强追更钩子，禁止开放性平淡结尾 |
| **章说互动**是留存抓手 | 在章节内预留1-2个"争议点/情绪触发点"诱导读者互动 |

### ◆ 包装门禁

| 门禁项 | 要求 | 规避风险 |
|:---|:---|:---|
| **标题** | 科武核心元素+悬念词/情绪词 | 禁用文青/文学隐喻，导致类型错位 |
| **简介** | 主角+核心冲突+悬念钩子（80字内） | 禁用背景罗列/设定堆砌 |
