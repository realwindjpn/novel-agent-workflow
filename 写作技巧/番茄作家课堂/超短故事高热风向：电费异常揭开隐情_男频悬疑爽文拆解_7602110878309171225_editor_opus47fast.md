# 《超短故事高热风向：电费异常揭开隐情》课程拆解笔记
栏目：品类指南 | 日期：2026-02-02 | 用途：服务于《科武纪元》及短故事/热点稿编辑

---

## 1. 课程核心判断（6条）

1. **男频超短爽文 = 代入感 × 信息差 × 情绪闭环**，三者缺一不可，其它都是装饰。
2. **冲突必须从日常细节起跳**（电费、月饼、购物卡、租房、库管角落的旧机器），不能从宏大设定起跳。
3. **主角默认"被低估的中年/边缘男性"**，反派默认"占据道德/权力高位的得意者"——身份势能差是爽点燃料。
4. **钩子要分层**：事件钩（What）→ 手法钩（How）→ 情绪钩（When 真相揭晓），不是单线悬念。
5. **反派要有"可被部分读者理解"的内在逻辑**，纯恶反派会让张力垮掉。
6. **结局必须闭环 + 反向碾压**（房东开门看到毛坯、员工堵门求换购物卡），没有"反向打脸的具体画面"=没有爽点交付。

## 2. 可执行编辑规则

### 开篇（前 100–200 字内必须完成）
- 第一句给身份+处境（"我被国企下岗了""我租这房子三年"），不要环境描写。
- 第二段抛出**核心异常物**（电费账单、360万废铁、5000块暖气费、网暴视频）。
- 200 字内出现一次**身份反差暗示**或**反派得意嘴脸**，让读者立刻站队。

### 节奏
- 段落控制在 1–3 行；长段必须拆。
- 强对话推进，禁用心理独白堆叠。
- 每 300–500 字一个钩或一个小反转，不允许"过渡段"独立存在。

### 冲突
- 主题锁定四象限：**权力 / 尊严 / 公平 / 背叛**，至少命中两个。
- 冲突升级路径：日常细节 → 利益冲突 → 身份/认知崩塌 → 反制。
- 禁止"误会型冲突"独立成线，必须叠加信息差。

### 人物
- 男主：能力被低估 + 思维定势（这条很关键，思维定势是信息差的来源，不是缺点）。
- 反派/女主：动机要"既要又要"（既要稳定又要刺激；既要面子又要钱），不要单一恶。
- 配角的"知情却旁观"是隐形钩子（保安偷笑的细节就是教科书）。

### 题材
- 来源必须是**作者本人能拍照举证的生活场景**（账单、App、租房、车间），二手题材不收。
- 与平台近期情绪风向叠加（信息差/身份反转/小事梗），单挂热点不要做。

### 改编（短→长 / 长→短）
- 短故事改编要素：单一核心异常物 + 单一反派阵营 + 三层钩 + 一次反向碾压。
- 长篇截短篇：抽出"一个异常物+一次身份反转"做独立闭环，不要带主线背景。

### 平台规则（番茄男频超短）
- 标题公式：**触发事件 + 行为反差 + 对方崩溃态**（"上秒缴费下秒搬走？我直接让你豪房变毛坯，房东傻眼了"）。
- 标题必须含具体名词（月饼/购物卡/电费/铁疙瘩），禁用抽象词。
- 简介前 3 行 = 开篇前 3 段，直接复用。

## 3. 《科武纪元》适配

### 可用点
- **"被低估的修理工"母题**可直接迁移：科武世界里"会修古武机甲/失传科武器"的边缘技师，是高复用人设。
- **三层钩结构**适合科武单元案：表层异能事件 → 中层手法揭秘 → 底层势力/身份揭晓。
- **日常异常物切入**：能源读数异常、护符灵力账单、灵植耗水量——把"电费梗"科武化，是短篇番外的现成模板。
- **反派"既要又要"动机**：豪门修家既要灵脉又要凡间话语权，可作为长篇配角群塑造原则。
- **配角知情旁观制造耻感**——适用于宗门/同僚的群像戏。

### 不可硬套点
- 男频超短的"一章爽完"节奏不能套到长篇主线，主线需要延迟满足与代价积累。
- "纯善恶报"结局会破坏科武世界观的灰度，长篇里反派不应被一次性碾压。
- "中年职场感"语气不要污染主角少年/修行者的语体。
- 短故事的"信息差靠生活常识"在科武中不成立，必须先立设定再制造差，否则读者无法参与推理。
- 标题的现实痛点公式（房东/下岗/网暴）不适用长篇章节名，仅适用于做拉新短故事或外站投流稿。

## 4. 编辑检查表（10 条）

1. 开篇 200 字内是否出现"身份+异常物+反派态度"三要素？
2. 是否存在至少一个具体可视化的"异常物"贯穿全文？
3. 钩子是否分了事件层 / 手法层 / 情绪层？少于两层退稿。
4. 反派动机能否用一句话写出"既要X又要Y"？不能则补。
5. 男主的"思维定势/认知盲区"是否被明确写出？这是信息差锚点。
6. 是否有至少一处"配角知情而男主不知"的旁观细节？
7. 每 500 字内是否有钩/反转/对抗推进？有无纯过渡段？
8. 结局是否有**画面化的反向碾压瞬间**（开门傻眼、堵门求换）？无则不爽。
9. 标题是否包含具体名词 + 行为反差 + 对方崩溃态？
10. 题材是否能溯源到具体生活细节或平台近期热点？纯脑补退。

## 5. 对作家角色的输入要求

提交人物卡/章节大纲时，必须含以下五栏：

| 栏目 | 要求 |
|---|---|
| **动作链** | 角色从触发事件到反击的 5–8 步具体动作，每步一个动词+一个对象（如"查电费App→截图→静默打包→换锁→开门"）。禁止"他决定反击"类抽象动作。 |
| **物理反馈** | 每个关键动作要写出环境/他人/身体的可观察反应（车间瞬间安静、房东僵在门口、监控室保安偷笑）。无物理反馈=无爽感。 |
| **代价** | 角色为推进剧情付出的具体损失（押金、面子、时间、灵力、寿元），必须可量化或可视化。无代价的反转视为悬浮。 |
| **钩子** | 标明本节属于主钩/次钩/情绪钩的哪一层；如果是新钩，需注明何时回收。未回收钩子上限 = 2。 |
| **读者预期** | 一句话写出本节希望读者产生的情绪态势（疑虑 / 同情 / 愤怒 / 期待揭晓 / 爽感释放），并标注该情绪在全篇曲线中的位置。 |

> 凡缺任一栏的稿件/大纲，编辑环节直接打回，不进入内容讨论。
