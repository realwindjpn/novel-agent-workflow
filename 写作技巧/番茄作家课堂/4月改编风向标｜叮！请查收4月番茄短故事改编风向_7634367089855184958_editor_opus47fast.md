## 1. 课程核心判断（6条）

1. **改编池在"短剧/短漫剧"两条赛道**筛稿，看的是**前3秒钩子 + 单集爽点密度**，不是文学性。
2. **女频主线已从"霸总救我"切到"清醒大女主+情感平权"**；男频从"恋爱脑复仇"切到"理性撤资/降维打击"。掌控感取代占有感。
3. **"反套路微创新"是入选门槛**：经典题材（替婚/逆袭/团宠/仙侠）必须叠加一个差异化设定才有改编价值。
4. **现实痛点（婚姻背叛、银发尊严、合伙人坑骗、职场不公）是情绪入口**；解决方式必须"冷静取证→精准反击"，禁用一哭二闹。
5. **主角必须自带"翻盘资产"**（房产证、隐藏身份、满级实力、商业资本），蛰伏蓄力可以，但不能真弱。
6. **情感线做减法**：女频弱化恋爱脑、男频弱化讨好型；爱情若存在，必须势均力敌。

## 2. 可执行编辑规则

### 开篇（前300字）
- **一句话冲突落地**：参照《我爸群发祝福》——一条错发消息直接引爆。开篇必须有一个**可截图传播的强信息**。
- **导语必须出现身份反差**（蛊人王/总裁/退休金8000的妈/合伙人）+ **被冒犯事件** + **主角一句冷反应**。
- 避免环境描写、avoid 内心独白开场。

### 节奏
- **打脸/反击点必须在前30%内首次释放**，不能全文铺垫到结尾。
- 关键情节"释放及时，情绪反馈快"（《说好对半分》模板）——主角拿钱当晚就行动，不隔几章。
- 长链憋屈剧情=改编淘汰项。

### 冲突
- 用**结构性冲突**（资本/血缘/法理/产权）取代口角冲突。
- 反派的"理直气壮"要写足（如发小那句"你就是出个力"），打脸才有重量。
- 冲突解决靠**主角已持有的硬通货**（房本、撤资权、武力值、蛊术），不靠天降贵人。

### 人物
- 女主：清醒、智商在线、爱憎分明；可走黑莲花/疯批/觉醒主妇/硬核武力四个标签。
- 男主：冷面理性、内敛深情、满级大佬回归；**禁恋爱脑、禁过度隐忍、禁卑微讨好**。
- 配角反差（凶人变护崽狂魔）用于喜剧调剂。

### 题材
- 女频优选：错位替婚（甜爽）/ 母女互助（现实）/ 硬核古言（漫剧）/ 团宠+灵宠（漫剧）。
- 男频优选：商战撤资 / 银发维权 / 合伙创业逆袭 / 玄幻迪化无敌幕后流 / 经典IP配角视角。

### 改编
- 短故事字段要为"分镜"服务：每个场景给**1个画面记忆点+1句金句**。
- 标题党：把"行为+反差结果"写进标题（《未婚妻与他人领证，我撤资离场》《四十五岁，我妈离婚了》）。
- 衍生IP需"尊重原属性"，不可强行OOC。

### 平台规则
- 4月节点叠加**劳动节热点**：职场虐渣 / 家庭女性现实困境。
- 题材落到"乡村邻里、生活日常"等接地气场景，比悬浮豪门更易过审改编。
- 正向价值底线：解气可以，反社会不行。

## 3. 科武适配

### 可用点（直接抄进《科武纪元》）
- **"满级大佬回归新手村"=** 科武世界里资深武修/科研者隐藏修为入低位场域，开篇被轻视→精准降维。天然契合"科+武"双体系。
- **结构性冲突模板**：把"房产证"替换为"核心技术专利/武道传承/能源密钥"，主角蛰伏时已握有翻盘资产。
- **冷面理性主角**：科幻题材天然适配冷静智性人设，避免恋爱脑稀释科技感。
- **配角视角解锁IP**（菩提祖师式）：科武世界可派生短篇——次要人物（一个NPC科学家、一个边缘武者）的独立故事池，反哺主IP。
- **女性互助/势均力敌CP**：科武双修设定下，男女主可一科一武对等，禁单方拯救。
- **开篇可截图强信息**：用一条"系统播报/全球公告/泄露的实验录像"作为引爆点，比内心独白强。

### 不可硬套点
- **替婚、白月光、儿媳掀桌、合伙人黑钱**——属于短剧情绪糖，搬进长篇科幻会"塑料感"，最多用于科武的**番外短故事**而非主线。
- **前30%必爆打脸**：长篇科幻需要世界观铺设，节奏规则要松绑，但**章节级钩子密度**应保留。
- **银发家庭伦理 / 货运创业**等下沉题材与科武调性冲突，仅可做**热点稿单篇试水**，不并入主线。
- **"疯批/黑莲花"标签**慎用于核心女主，可放在反派或阶段性面具，避免主角长线形象失衡。
- **节日热点强植入**：长篇不要为劳动节改章节，短故事/热点稿可以。

## 4. 编辑检查表（10条）

- [ ] 开篇300字内是否有"身份反差+被冒犯事件+冷反应"三件套？
- [ ] 主角是否自带翻盘资产（实体/身份/能力），不依赖天降？
- [ ] 第一次打脸/反击是否落在前30%？
- [ ] 反派的"理直气壮"是否写足，让反击有重量？
- [ ] 主角全程是否清醒理智，无恋爱脑/卑微讨好/无意义隐忍？
- [ ] 是否在经典套路上叠加了至少1个"微创新设定"？
- [ ] 冲突解决是否走"取证—精准反击"，避免哭闹狗血？
- [ ] CP关系是否势均力敌，情感线是否做了减法？
- [ ] 标题是否包含"行为+反差结果"，可独立传播？
- [ ] 每个关键场景是否提供了1画面记忆点+1句金句（改编分镜友好）？

## 5. 对作家角色的输入要求

**动作链**
- 每个反击场景必须写出**3步以上的具体动作序列**（取证→留存→出手→收尾），禁用"她冷冷一笑然后赢了"式跳跃。
- 科武场景：技能释放要拆"启动—传导—命中—代价"四拍。

**物理反馈**
- 反派的崩溃要有**身体细节**（《说好对半分》："砸烂方向盘""脸瞬间惨白"）。
- 科武对抗要写**环境受损、装备过载、生理代偿**，让爽感落地不悬浮。

**代价**
- 主角的胜利必须标价：撤资=失去联姻资源；带走房本=与子断亲；蛊术杀人=世人骂名。
- 科武主角的"降维打击"要给出能耗/寿元/关系网代价，避免无敌流空心化。

**钩子**
- 章节末固定埋一个：身份揭露 / 关键道具出现 / 反派下一步动作 / 信息差倒计时。
- 短故事级：每800字一个小反转；长篇级：每章一个待解信息。

**读者预期**
- 明确承诺三件事：**我会爽、我会被打脸的人疼、我不会被狗血恶心到**。
- 凡是会让读者出戏的设定（圣母、降智、强行误会），在交稿前自查删除。
- 科武读者额外预期：**科技逻辑自洽 + 武道体系有规则**，爽点不可破坏世界观。

---

**一句话总线**：清醒主角 + 硬通货底牌 + 前段释放 + 反套路微创新 + 可截图开篇——这是4月改编池的共同公约数，科武主线吸收"结构"，科武短故事/热点稿直接套"模板"。
