# 《科武纪元》编辑学习官：知更专访规则提炼

## 1 课程核心判断（≤6条）
1. **大时代是小人物成长的逻辑支点**：宏观背景不是装饰，而是人物命运转折、动机成立的必要条件。
2. **真实感源于“缺陷+底线+闪光点”**：拒绝完美人设，角色必须“阳光下有影子”，具备独立决策逻辑。
3. **人物驱动情节**：故事由角色视角碰撞自然生成，作者不充当提线木偶师。
4. **大纲即地基**：长篇动笔前需数月打磨大纲与人设，想清楚再写远优于边写边改。
5. **情绪锚点切中社会痛点**：共鸣来自对现实困境（迷茫/躺平/抉择）的精准映射，并提供可执行的破局路径。
6. **生活素材经戏剧化加工更具张力**：观察、记录、提炼真实事件，比纯虚构更易构建可信冲突。

## 2 可执行编辑规则
| 维度 | 规则 |
|:---|:---|
| **开篇** | 3章内完成“时代特征切片+主角核心困境”绑定。用具体生活/职业危机切入（如失业、技术淘汰、资源断供），禁用宏大设定空转或纯背景说明。 |
| **节奏** | 采用“困境→刹车/躺平→触发事件→跃起”循环。允许主角阶段性停滞，但必须设置明确的外部变量或内部觉醒点打破僵局，保持推进势能。 |
| **冲突** | 冲突必须同时作用于“外部生存压力”与“内部价值观撕裂”。禁用为冲突而冲突，所有矛盾需服务于人物成长弧光与世界观规则验证。 |
| **人物** | 建立“缺陷（行为惯性）+底线（不可妥协项）+闪光点（破局能力）”铁三角。赋予角色独立视角，情节发展由角色选择自然推导。 |
| **题材** | 执行“大时代+小切口”策略。将宏观背景降维投射至具体职业、家庭、小镇或边缘群体，用微观抉择折射宏观浪潮。 |
| **改编** | 预留影视/短剧接口：场景集中化、人物关系网清晰、核心矛盾具象化。设计强视觉符号与标志性动作（如砸墙、换鞋），强化情绪记忆点。 |
| **平台规则** | 对齐平台扶持标签（如#时代浪潮 #底层逆袭 #现实共鸣）。内容需提供“希望感”而非空洞说教，便于算法推荐、奖项申报与IP孵化。 |

## 3 科武适配
| 维度 | 可用点 | 不可硬套点 |
|:---|:---|:---|
| **结构** | “大时代（科武融合/技术奇点/星际拓荒）+小人物（底层武者/边缘研究员/废土拾荒者）”框架完全适用。 | 现实题材的“慢节奏生活流”不可直接套用。科幻需保持设定推进与悬念密度，避免过度沉溺日常琐碎导致主线失焦。 |
| **人设** | 拒绝龙傲天/完美人设，强调缺陷与底线，契合科幻长篇的厚重感与生存逻辑。 | “返乡/冬奥”等具体现实热点需转化为科幻等效物（如星门关闭/母星枯竭/赛博贫民窟），不可生搬硬套现实政策或新闻。 |
| **情绪** | 在硬核设定中注入“迷茫-抉择-破局”普世情感，有效降低科幻阅读门槛。 | “正能量/希望感”需通过技术突破/文明存续/个体抗争体现，而非单纯的情感抚慰或口号式升华。 |
| **创作流** | 大纲前置、人物驱动、生活观察提炼，对百万字长篇防崩盘至关重要。 | 科幻需额外增加“设定自洽推演”环节，现实逻辑不能直接替代物理/能量/武道规则。 |

## 4 编辑检查表（10条以内）
1. 开篇3章内是否明确交代“时代背景特征”与“主角当前核心困境”？
2. 主角人设是否具备“明显缺陷+不可妥协的底线+独特闪光点”？
3. 情节推进是否由主角的主动选择驱动，而非作者/外力强行安排？
4. 冲突设计是否同时作用于“外部生存压力”与“内部价值观撕裂”？
5. 宏观科武设定是否已降维落实到具体场景/道具/职业中？
6. 每卷是否预留“低谷-刹车-转折-跃起”的节奏节点，避免平铺直叙？
7. 是否剔除“全知全能/无代价开挂”倾向，确保能力成长有逻辑支撑？
8. 核心情绪线是否切中当代读者痛点并提供具象化破局路径？
9. 关键场景是否具备强视觉符号与动作记忆点（便于后续IP改编）？
10. 大纲是否经过至少3轮逻辑推演，确保人物动机与科武规则自洽？

## 5 对作家角色的输入要求
| 模块 | 执行标准 |
|:---|:---|
| **动作链** | 严格遵循“触发事件→心理权衡→肢体/语言动作→环境反馈→结果”。禁用模糊过渡（如“他想了想然后做了”），必须呈现决策的因果链条。 |
| **物理反馈** | 科武体系下，任何能力释放/战斗/科技操作必须伴随可量化的物理/生理反馈（如肌肉撕裂、神经负荷、能量过载、环境破坏痕迹、冷却期）。 |
| **代价** | 每次关键抉择或能力突破必须支付明确代价（资源消耗、人际关系破裂、身体损伤、道德妥协、规则反噬）。禁止无代价升级或机械降神。 |
| **钩子** | 章末/卷末必须设置“未解悬念/反常现象/角色关系突变/倒计时危机”。钩子需与主线强相关，拒绝为悬而悬或脱离当前情境的硬切。 |
| **读者预期** | 核心设定/伏笔需提前3-5章铺垫。兑现预期时必须“意料之外，逻辑之中”。情绪释放点（爽点/泪点）必须建立在前期压抑与代价积累之上，禁止情绪透支。 |
