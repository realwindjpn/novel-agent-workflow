# 《年度最受欢迎书籍作家驾到：人物塑造》编辑学习笔记

来源：番茄作家课堂 2023-02-25 · 男女频年度最受欢迎作家集稿
对接项目：长篇科幻《科武纪元》/ 短故事 / 热点稿

---

## 1. 课程核心判断（6条）

1. **人物 = 一个被放大的特征 + 一条被卡住的追求**。其余都是装饰。
2. **性格必须单一且稳定**：除非剧情级变故，禁止前后摇摆；多重性格只给主角且要分回合释放。
3. **反差不是分裂**：反差必须仍然落在"人设逻辑"内（正义男背地里玩消消乐 ≠ 正义男忽然下毒）。
4. **配角也是自己世界的主角**：每个出场人物都要有"上中下"三层关系压力（参照岁月神偷的李景隆模型：对上、对中、对下）。
5. **情节与人物互为因果**：人物在情节中做出符合设定的事，情节再反过来强化设定；写错一次设定就崩。
6. **细节 > 形容词**：一颗痣+一根毛、记得被打过几个耳光、饼里只有女主那块加馅——具体动作/数字/物件，比"英俊潇洒"有效十倍。

## 2. 可执行编辑规则

### 开篇（人物首秀）
- 首次出场用 1 个**动作特征 + 1 个标志物**锁定记忆点，禁止从头到脚白描。
- 主角首章必须暴露"追求"或"伤口"其中之一，让读者知道他想要什么 / 怕失去什么。
- 配角首秀就要交代"上中下"压力中的至少一层，否则不出场。

### 节奏
- 一个性格特征必须在前 3 次出场内被**重复放大**（妖夜《武碎星河》杀神小队全员单标签法）。
- 反差点不要在首秀给，留到读者已经"以为他是 X"之后再翻面（《见野》江野模式）。
- 多人物出场时用"分批轰炸"，单章引入新角色不超过 2 个有名有姓的。

### 冲突
- 冲突生成公式：**追求 × 障碍 = 掀桌子**。没有掀桌子的章节就是水。
- 障碍要踩在人物**最在意的那条线**上（拜金女被断财路、良心党被买良心），不要踩无关痛痒处。
- 反派的恶要有"上中下"逻辑支撑，不写无动机恶。

### 人物
- 一人一标签：娇小+暴躁、冷、傻白甜、憨防御——能用一个词概括，就别用两个。
- 性格变化必须由**剧情级事件**触发（亲人死、世界观崩塌、被背叛），日常对话改不动性格。
- 主角必须有"小自私 + 大作为"两层，纯善或纯狠都立不住（《天灾》苏念模型）。
- 男主/导师对女主/徒弟的偏爱用**细节差异化**呈现（一块饼里只有她那块有馅），不写"他对她特别好"。

### 题材（科幻/科武适配）
- 科幻里"身份背景"= 阵营、出身星域、改造等级、师门技术流派。性格必须与之自洽：贫民窟出身的改造人面对世家子弟必然有姿态差。
- 设定堆砌不能替代人物——再硬核的科技点也要落到"某个人因此而做了某件事"。

### 改编（短故事/热点稿）
- 短故事砍人物：留 1 主 + 1 反 + 1 反差配角，最多 3 个有名字的人。
- 热点稿借人物：抽取主角的**最强单一标签**做切口（如"杀伐果断"或"恩怨分明"），别把人物全貌塞进 2000 字。
- 改编时只允许"细节加密"，不允许"性格改写"，否则原作粉会喷。

### 平台规则（番茄向）
- 男频要"爽不憋屈"：主角特点必须是读者代入后**不会窝火**的（小殇殇明确点出）。
- 女频要"爽+反差萌"：女主标签 + 一个反向小缺陷（女侠是财迷、精明者是路痴）。
- 长篇出场人物上百，**作者自己要做角色表**（竹报平安方法），混人设是大忌。

## 3. 《科武纪元》适配

### ✅ 可用点
- **单一特征 + 物件锚定**：科武世界适合用"武器/义体部件/口头禅"做记忆点（例：某角色总在战前擦护腕里的旧弹壳）。
- **上中下三层压力模型**：天然契合科武的门派/势力/家国结构，每个有戏份的人物都按此建档。
- **追求驱动 + 不断掀桌**：科武长线主线可拆为"主角的科学追求 vs 武道追求"的反复冲撞，每卷给一次掀桌时刻。
- **反差不分裂**：硬核武修偷偷养猫、冷面工程师写诗——增加人味，不削弱战斗力人设。
- **细节差异化偏爱**：师门发放装备、配给物资时用差异凸显师徒/同门关系。
- **女频反差萌**逻辑可用于科武女性角色：顶尖战力 + 一个无害弱点（味觉迟钝、认路废）。

### ❌ 不可硬套点
- **"性格越极致越好"** 在硬科幻语境里要克制：纯莽撞 / 纯蠢人物在高技术决策场合会让世界观掉智商，需用"专业领域极致 + 非专业领域笨拙"替代。
- **"主角不能憋屈"** 不能全盘照搬：科武需要硬核挫败感来撑科技/武道升级的代价感，可保留短期憋屈，但要在同卷内兑现。
- **女频"爹系老公"式人设** 不适配主线男性角色，可下放给某个配角调剂。
- **"性格一成不变"** 不适合长篇科幻主角：科幻人物常因认知升级而蜕变，应明确蜕变节点（接触新文明、目睹文明覆灭），而非禁止变化。
- **多角色单标签法**在群像科幻里若用力过猛会变"番剧化"，需保证每个标签角色至少有一次"上中下压力"展示。

## 4. 编辑检查表（10条以内）

- [ ] 主角的"追求"是否在前 3 章被读者明确感知？
- [ ] 每个有名字的角色，是否能用一句话写出他的单一标签 + 一个标志动作/物件？
- [ ] 本章是否出现"掀桌子"（追求被卡 → 行动反弹）？没有则视为水章。
- [ ] 人物的言行是否匹配其出身/阵营/技术等级？有无"贫民花钱不心疼"式破绽？
- [ ] 反差点是否仍在人设逻辑内？是否在"读者已固化印象之后"才抛出？
- [ ] 配角是否具备"上中下"三层压力中的至少一层？否则砍戏或合并。
- [ ] 是否用细节差异（而非形容词）表达关系亲疏？
- [ ] 性格如有变化，是否有剧情级事件作为触发器？
- [ ] 出场新角色本章是否 ≤2 个？人物表是否同步更新？
- [ ] 男频章节读完是否"爽不憋屈"？女频章节是否有反差萌或细节偏爱？

## 5. 对作家角色卡的输入要求

每位有戏份的角色，作家必须在开写前提交以下 5 项：

### ① 动作链（Action Chain）
- 角色在 **战斗 / 决策 / 私下独处** 三种情境下各 1 个标志性动作。
- 动作必须可被复用（每出场至少触发一次），用于建立条件反射式记忆。
- 例：李景隆"摸痣捋毛"思害人；科武角色"扣三下护腕"启动义体战斗模式。

### ② 物理反馈（Physical Feedback）
- 角色身体上的**可见痕迹/旧伤/装备磨损**，对应过去某次事件。
- 受伤、疲惫、过载后的具体反应（出血点、义体噪音、神经抽搐），禁止"他感到一阵痛"这种抽象描写。
- 每次使用能力 / 武力，必须给出对应的身体代价描写。

### ③ 代价（Cost）
- 角色每一次重大行动必须对应**可量化的失去**：寿命、信用、关系、阵营立场、肢体、记忆。
- 代价要在事后章节被反复提及（被打过几个耳光那种记账感）。
- 没有代价的胜利不允许写。

### ④ 钩子（Hook）
- 每个角色必须带 1 个**未解之谜钩**（身世/旧账/隐藏目标）+ 1 个**反差钩**（与表面标签矛盾的小爱好/弱点）。
- 钩子必须在出场前 5 章内埋下首个伏笔，**不允许只在作者脑内**。

### ⑤ 读者预期（Reader Expectation）
- 明确写出：希望读者读到这个角色时**期待什么、害怕什么、不能容忍什么**。
- 角色行为要么**满足**这个预期（爽点），要么**打破**这个预期（反差/反转），禁止"既不满足也不打破"的中间态——那就是水戏。
- 男频角色重"爽不憋屈"红线；女频/感情线角色重"细节偏爱"红线。

---
**一句话总纲**：单一标签立人 → 三层压力立场 → 追求被卡掀桌 → 细节代偿形容词 → 反差落在逻辑内 → 每场戏给代价。
