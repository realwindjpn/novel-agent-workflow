## 10条写法规则

1. **首屏先扔噱头**
   - 第1页必须出现一句可做短视频文案的反差句。
   - 模板：`别人练武靠气血，我靠国家实验室给我开挂。`
   - 失败模式：先讲纪元史、科技史、宗门史。

2. **单章只打一种情绪**
   - 本章只选一个核心情绪：期待 / 爽快 / 遗憾 / 屈辱。
   - 段落节奏：短句推进，动作优先，少心理解释。
   - 失败模式：一章里又搞笑、又悲情、又科普、又打脸。

3. **冲突用四拍写**
   - `细节铺垫 → 情绪蓄力 → 极致爆发 → 余韵钩子`
   - 每拍必须有动作，不用内心独白凑字。
   - 爆发后给围观反馈：倒吸气、沉默、弹幕炸裂、仪器报警。

4. **主角人设只保留三件套**
   - `强标签 + 反差 + 直白动机`
   - 例：武道废人 × 科研鬼才 × 我要救回战死的妹妹。
   - 失败模式：开篇解释主角复杂童年、哲学观、阵营立场。

5. **打脸必须靠信息差收割**
   - 反派不知道主角真实实力 / 身份 / 底牌。
   - 读者可以提前知道一点，等反派撞上去。
   - 人物口吻：反派嚣张直白，主角少说狠话，用结果说话。

6. **憋屈不能超过一章**
   - 本章受辱，下一章必须反击；最好同章小爆一次。
   - 爽点舞台尽量公开：擂台、听证会、直播间、学术会、宗门广场。
   - 失败模式：反派连续嚣张三五章，主角一直忍。

7. **动作—反馈—代价三连写**
   - 每次开挂 / 爆发 / 突破都要写：
     - 动作：主角做了什么；
     - 反馈：身体、装备、空间如何变化；
     - 代价：伤、暴露、寿命、关系、阵营压力。
   - 代价必须变成后续钩子。

8. **章末钩子三选一**
   - 身份将揭：有人认出主角真实档案。
   - 强敌将至：更高层敌人盯上主角。
   - 真相反转：刚赢下的胜利其实暴露了更大危机。
   - 章节名可直接写钩子句：`我不给的，你不能抢。`

9. **短故事 / 狼人篇可借点**
   - 借：身份错配、公开处刑、反差打脸、强情绪单点爆破。
   - 不借：复杂世界观、群像多线、长铺垫。
   - 狼人篇适合用：隐藏身份、夜间失控、族群误判、伴侣/同伴背叛。

10. **发布包装先过门禁**
   - 发布前必须有：一句话噱头、封面反差点、章节名钩子、前3章爽点规划。
   - 风险门禁：禁术语堆叠、禁论文式科幻、禁前三章多POV、禁长期憋屈。
   - 写作前任务卡字段更新：
     - 本章噱头：
     - 核心情绪：
     - 主角动作链：触发 / 对抗 / 破局
     - 物理反馈：
     - 信息差：
     - 爆发代价：
     - 章末钩子：
     - 读者下一章期待：
     - 可短视频文案：
     - 风险点：

## 10条自检清单

1. 首屏是否出现一句能让读者停下来的噱头？
2. 前3章是否有被轻视 / 羞辱 / 背叛 / 错过等代入锚点？
3. 第一个爽点是否在前5章内爆出来？
4. 本章是否只服务一个核心情绪？
5. 冲突是否完整走完：铺垫、蓄力、爆发、余韵？
6. 主角是否有清晰的标签、反差、动机？
7. 反派是否主动挑衅，主角是否被动反击，避免显得刻薄？
8. 爆发场景是否有足够围观者和明确反馈？
9. 每次开挂 / 突破 / 亮底牌是否写了代价？
10. 章末是否留下身份将揭 / 强敌将至 / 真相反转之一？

## 3条科武落地

1. **科武长篇可借点：双体系反差当主噱头**
   - 科技党不懂武道真相，武道宗门不懂科技底牌。
   - 主角夹在中间，用信息差打脸。
   - 开篇不要讲纪元史，直接写一场公开测试 / 擂台 / 听证会。

2. **金手指外部化**
   - 不优先写系统，优先写国家实验室、旧文明数据库、军方项目、科研团队。
   - 爽点不是“我一个人无敌”，而是“整个文明在我背后开火”。
   - 代价：主角被监控、身份暴露、身体过载、阵营争夺。

3. **科武场景必须可感知**
   - 每场冲突都写出：声、光、震、热、血、装备反应。
   - 示例节奏：
     - 武道劲力轰入外骨骼；
     - 传感器全线飙红；
     - 地面震裂；
     - 反派笑容僵住；
     - 主角咳血，暴露第二套能量波形。
   - 禁止用公式、术语、设定表代替现场冲突。
