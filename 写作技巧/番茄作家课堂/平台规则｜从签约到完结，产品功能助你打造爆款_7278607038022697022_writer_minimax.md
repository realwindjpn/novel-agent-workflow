## 一、写作前任务卡字段更新

### 【核心设定层】
| 字段 | 必填项 | 验证标准 |
|:---|:---|:---|
| **科武体系核心冲突** | 一句话概括：___vs.___（例：算力霸权vs武道逆袭） | 可被15字拆解为头条标题 |
| **力量代价矩阵** | 每次突破必须附带：资源消耗（___）+ 身体代价（___）+ 阵营代价（___） | 代价需可量化，禁止"努力就能变强" |
| **物理反馈锚点** | 每个技能/装备需绑定具体物理表现（例：过载→装甲熔毁；经脉超频→器官内出血） | 读者闭眼能想象出画面 |
| **题材标签组合** | 平台稀缺组合：___+___+___（例：硬科幻+古武+星际） | 需在前3章正文或简介中埋设关键词 |

### 【节奏规划层】
| 字段 | 节点要求 | 交付物 |
|:---|:---|:---|
| **3万字节点** | 书荒话题匹配触发 | 检查：简介+前3章是否包含3个高频低供关键词 |
| **8-10万字节点** | 首推开启+大流量池跃迁死线 | 检查：世界观是否落地？核心悬念是否已抛？ |
| **20万字节点** | 多书名实验窗口 | 检查：是否备好3组差异化书名/封面？ |
| **100万字节点** | 二次实验窗口 | 检查：是否预留IP向改编潜力？ |

### 【钩子储备层】
| 字段 | 每章必须交付 | 提取标准 |
|:---|:---|:---|
| **章末钩子** | 1个可被15-30字概括的悬念/反转 | 能直接填入推书文案"悬念"位 |
| **卷末钩子** | 1个颠覆性反转（科技碾压/武道反杀/理性vs人性） | 需触发算法"冲突点"抓取 |
| **推书文案素材包** | 每卷至少3组可提取的"概念+冲突+数字"组合 | 用于书荒推书/头条标题A/B测试 |

## 二、章节自检清单

### 【每次提交前必检】

| 序号 | 检查项 | 通过标准 | 不通过后果 |
|:---|:---|:---|:---|
| 1 | **代价是否落地？** | 本章主角有任何收获/突破时，是否同步写出资源/身体/阵营损耗？ | 算法降权：被判定"无损耗升级"，完读率下滑 |
| 2 | **物理反馈是否具象？** | 力量变化/技能释放/装备运转是否有可感知画面？（禁止"他变强了"类抽象描述） | 读者代入断裂，留存节点流失 |
| 3 | **钩子是否前置？** | 章末最后300字是否包含可提取为15-30字标题的悬念/反转？ | 无法进入书荒推书池，流量断崖 |
| 4 | **冲突是否显眼？** | 本章核心矛盾是否在前500字内被抛出，而非中后段才揭示？ | 平台"对比反转"抓取失败，推荐量锐减 |
| 5 | **行动链是否完整？** | "触发条件→科武行为→结果反馈"链条是否有断裂？（禁止纯心理描写填充） | 算法判定"水文"，降低推荐权重 |
| 6 | **人物动机是否可提炼？** | 本章主角行动理由是否能用一句话向读者解释清楚？ | 无法触发话题匹配，3万字节点失效 |
| 7 | **标题合规性** | 章节标题是否含"第X章"？是否有震惊体/违规词？ | 头条推荐审核直接拒绝 |
| 8 | **互动触发点** | 本章是否设置了1-2个可引发评论的争议点/选择点？ | 互动UV无法达标，粉丝榜激活失败 |
| 9 | **更新节奏承诺** | 是否在3日内有更新记录？（断更即切断流量池） | 推荐资格丧失，实验功能锁定 |
| 10 | **标签兑现** | 本章内容是否对齐简介/标签承诺的科武基调？ | 读者预期错位，跳出率飙升 |

## 三、可执行动作库

### 【动作：开篇三屏】

```
执行动作：头条标题反推法
1. 提炼本章核心冲突 → 写成15-30字短句
2. 检查是否含：画面感 + 数字/悬念 + 核心矛盾
3. 禁止：震惊体、"第X章"、复杂科武术语（算法无法识别长尾词）
```

| 场景 | 正确示范 | 错误示范 |
|:---|:---|:---|
| 长篇首章 | "算力霸权下的最后一台生物机甲，在经脉核爆中觉醒" | "第1章：命运的齿轮开始转动" |
| 短故事开篇 | "他把寿命折现给AI，换来三秒的真气护盾——值吗？" | "震惊！原来武侠还能这么写！" |
| 卷末钩子 | "跃迁坐标锁定母星坟场，他才发现战争从未结束" | "第XX章 未完待续..." |

```

□ 资源消耗（能量块/材料/稀有配额）
□ 身体代价（经脉负荷/器官损伤/寿命折损）
```

## 四、失败模式速查表

| 失败症状 | 触发原因 | 立即修复动作 |
|:---|:---|:---|
| **完读率断崖** | 每章超过2000字无行动/冲突推进；大量纯心理描写 | 立即插入一场"触发→行为→结果"的完整战斗或谈判 |
| **推荐量归零** | 断更超过3天；标题含"第X章"；内容含违规词 | 补更并删除所有章节号；全稿过审合规筛查 |
| **互动UV不足** | 章内无争议性选择/角色立场对立；无读者情感锚点 | 修改最近3章，添加"两难抉择"或"阵营对立"触发点 |
| **标签匹配失效** | 前3章未出现简介承诺的科武基调关键词 | 在第3章末尾强制插入核心标签场景 |
| **大流量池跃迁失败** | 10万字节点前未完成世界观落地；核心悬念未抛 | 立即补写世界观奠基章；重新评估悬念前置位置 |
| **多书名实验无数据** | 20万字节点无3组差异化书名/封面备选 | 紧急制作3组封面+书名上线测试 |
| **粉丝群无法激活** | 1000粉门槛未达；私域话术未规划 | 提前设计"粉丝称号体系"与"专属剧情互动"话术 |

## 五、人物口吻&段落节奏模板

### 【科武纪元专属口吻模板】

| 角色类型 | 说话风格 | 关键词频率 | 禁止句式 |
|:---|:---|:---|:---|
| **算力派** | 冷静、数据化、略带机械感 | "概率/阈值/能耗/系统反馈" | "我觉得/我感到" |
| **武道派** | 力量感、身体感知、简洁 | "经脉/气血/劲力/破" | "计算显示/数据显示" |
| **中间派** | 两难感、挣扎感、自我怀疑 | "但是/可是/代价" | 过于绝对的判断句 |
| **反派/AI** | 绝对理性、无情感波动 | "效率/最优解/资源比" | "或许/可能"等模糊词 |

### 【段落节奏快切板】

```
每300字内需完成：
□ 一个动作/决策
□ 一个物理反馈/感官描写
□ 一个立场/信息推进

```

| 节奏型 | 适用场景 | 结构 |
|:---|:---|:---|
| **爆发型** | 战斗/突破/科技展示 | 短句堆叠+数字轰炸+身体反应 |
| **对峙型** | 谈判/价值观冲突 | 长短句交替+沉默描写+眼神/小动作 |

| **情感锚定型** | 角色成长/牺牲/抉择 | 慢节奏感官描写+快节奏行动链+开放式结尾 |

## 六、平台规则→发布/包装/风险门禁

### 【发布门禁】

| 门禁类型 | 触发条件 | 通过标准 |
|:---|:---|:---|
| **标题审核** | 每次发布/修改章节标题 | 禁止"第X章"；禁震惊体；禁违规词；15-30字含画面+悬念 |
| **内容审核** | 每次发布章节正文 | 全文无敏感词；无负向价值观暗示；无抄袭内容 |
| **封面审核** | 每次更换封面 | 与内容标签匹配；无违规元素；CTR预判合格 |
| **书名变更** | 20万字后启动多书名实验 | 需备好3组差异化书名同时上线，CTR数据决策 |

### 【包装门禁】

| 包装类型 | 执行要求 | 适配工具 |
|:---|:---|:---|
| **书荒推书包装** | "概念+冲突+数字/悬念"结构 | 推书文案素材包#001-#003 |
| **头条标题包装** | 15-30字含画面感/数字/核心矛盾 | 每章末尾钩子提炼 |
| **简介包装** | 前3章兑现承诺的科武基调 | 标签兑现自检表 |
| **私域话术包装** | 粉丝称号+专属互动+剧情预告 | 1000粉门槛提前规划 |

### 【风险门禁】

| 风险类型 | 触发后果 | 规避动作 |
|:---|:---|:---|
| **断更风险** | 切断流量池跃迁；推荐资格丧失 | 更新日历强制执行；断更前发布"请假公告"触发算法保护 |
| **违规风险** | 全书下架/账号处罚 | 每章过审合规筛查；敏感章节提前报备 |
| **数据误导风险** | 首推数据不佳误判死刑 | 制定"拉长篇幅至20w+解锁更多工具"续写策略 |
| **读者预期错位风险** | 简介承诺与正文不符，跳出率飙升 | 前3章严格对齐标签，前3万字必须交付核心体验 |

## 七、快速执行指令卡
