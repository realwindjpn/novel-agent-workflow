# 科武纪元·作家风格OS

用途：把“去AI味”从禁词检查升级为作家风格培养。

## 原则

- 去AI化只是底线。
- 作家风格是目标。
- 素材卡负责事实和细节。
- 作家风格OS负责表达方式。
- 作者角色写正文前必须读入本目录核心卡。

## 四件事

1. `voice_rules.md`：风格规则。
2. `bad_phrases.md`：禁用词/替代表达。
3. `scene_method.md`：场景展开方法。
4. `author_prompt_patch.md`：给作者角色注入的短提示。

## 与素材/学习关系

- SenseNova/采集资料：提供“写什么”。
- 知识库素材卡/RAG：提供事实、数字、来源。
- 写作角色OS：把采集学习经验蒸馏为动作、反馈、代价、失败模式、口吻。
- 作家风格OS：规定小说“怎么写”。
- 六角色审核：判断“能不能过”。

## 前置注入

作者角色写正文前，除本目录核心卡外，还必须读：

- `/root/workspace/写作角色OS/writer_role_core.md`
- `/root/workspace/写作角色OS/experience_distillation_rules.md`
