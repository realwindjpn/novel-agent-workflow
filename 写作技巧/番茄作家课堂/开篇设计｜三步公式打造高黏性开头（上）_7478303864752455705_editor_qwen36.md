# 《科武纪元》编辑学习报告：开篇设计三步公式

## 1 课程核心判断（≤6条）
1. **开篇本质是情绪植入**：核心功能不是交代设定，而是用矛盾细节制造“情感病毒”，在打破预期与制造成瘾之间拉扯多巴胺。
2. **无主线不写开篇**：纯噱头/单梗开局必然后继无力；动笔前必须明确故事主线、立意与整体脉络。
3. **钩子前置定生死**：前三章必须埋下贯穿主线的核心悬念/目标，以此对冲中后期节奏放缓的流失风险。
4. **结构可公式化**：高黏性开篇遵循“突发事件制造混乱→人物反应暴露性格→记忆碎片暗示过往→抛出钩子引出主线”四步逻辑。
5. **代入感靠功能性细节**：环境/天气/动作/微表情必须100%服务情绪或伏笔，禁用脱离剧情的纯描写或大段说明。
6. **开篇忌信息过载**：出场人物需严格聚焦核心矛盾，禁用路人视角发散或群像铺陈。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 禁用背景说明/世界观科普切入；首章必须以“突发事件”引爆，3000字内完成“事件-反应-钩子”闭环。 |
| **节奏** | 钩子前置可托底追读；信息释放必须“事件驱动”，每章末尾需留预期违背点或信息增量，禁止平铺直叙。 |
| **冲突** | 冲突起点必须是具象化混乱（如跳楼/袭击/系统崩溃）；人物反应需直接暴露立场/性格缺陷，避免和稀泥式对话。 |
| **人物** | 人设靠“动作链+微表情+关键道具”侧写；禁用作者旁白定性（如“他是个渣男”），改用行为自证。 |
| **题材** | 公式具跨题材通用性，但需替换内核载体（女频情感拉扯→男频科幻/武道危机/技术反噬/身份谜局）。 |
| **改编** | 开篇场景需具备强视觉化潜力（天气隐喻、道具特写、肢体微表情天然适配影视/漫画分镜），禁用抽象心理流。 |
| **平台规则** | 番茄前三章完读率是生死线；开篇需强情绪牵引（爽/虐/悬疑），慢热、设定轰炸、多线并行直接判死刑。 |

## 3 科武适配
### ✅ 可用点
- **结构平移**：“突发事件→反应立人设→记忆碎片→核心钩子”完美契合科武类“危机降临-机体/功法应激-旧时代线索浮现-主线目标锁定”的开局逻辑。
- **细节替换**：原文“老旧银镯子”可替换为“义体接口灼痕/初代机甲铭牌/基因锁残片”，作为贯穿全文的线索道具；“雨伞倾斜”可替换为“能量护盾偏转/重力靴失衡”，用物理状态映射人物立场。
- **氛围渲染**：天气描写可转化为“酸雨腐蚀装甲/辐射尘暴遮蔽霓虹/零重力环境下的失重感”，以环境物理法则烘托危机情绪，替代纯抒情。

### ❌ 不可硬套点
- **情感逻辑**：女频“替身/追妻火葬场”的纯情绪拉扯不可直接套用于硬科幻/武道升级主线；科武开篇需以“生存压力/技术伦理/力量体系规则”为情绪底座。
- **惨感渲染**：原文“写惨就要惨到极致”需转化为“物理/规则层面的极限压迫”，禁用脱离世界观的无逻辑卖惨。
- **路人视角**：科幻/科武开篇极易陷入“世界观名词轰炸”，原文“路人反应发散”在科武题材中会直接导致信息过载，必须严格规避。

## 4 编辑检查表（10条以内）
1. 开篇前3章是否已明确故事主线与核心立意？有无偏离主线的废情节？
2. 是否以“突发事件”而非“背景/设定介绍”作为第一幕切入点？
3. 主角/核心配角的首次应激反应是否直接暴露性格或立场？
4. 是否埋下至少1个具象化核心钩子（物品异常/身份错位/规则漏洞）？
5. 环境/天气描写是否100%服务于情绪或伏笔？有无脱离剧情的纯写景？
6. 人物塑造是否依赖“动作链+微表情+关键道具”，而非作者旁白定性？
7. 开篇出场人物是否控制在3人以内？有无冗余路人或群像视角？
8. 信息释放是否遵循“事件驱动”原则？有无连续200字以上的设定说明？
9. 情绪节奏是否完成“打破预期→制造悬念→期待反转”的闭环？
10. 场景是否具备强视觉化/分镜感，便于后续IP改编或短视频切片？

## 5 对作家角色的输入要求
- **动作链**：必须提供连贯、有因果逻辑的物理动作序列（例：`收拢破损护盾→踩碎能量结晶→反手扣住敌腕→关节过载爆响`），禁用跳跃式动作或纯心理活动替代。
- **物理反馈**：每个关键动作需附带符合科武世界观的物理/生理反馈（例：`金属摩擦的焦糊味/神经接驳的刺痛感/旧物表面氧化层的剥落触感/重力异常导致的内脏压迫`）。
- **代价**：角色行动必须伴随即时或潜在的代价（例：`能量回路烧毁/信用点扣除/信任链断裂/规则反噬`），禁用无损耗的“平推式”破局。
- **钩子**：开篇3000字内必须抛出1个具象化悬念，并明确其与主线的绑定路径（例：`“初代引擎的启动密钥为何刻在主角的脊椎上？”`），禁用模糊的“命运感”或空泛悬念。
- **读者预期**：需预设读者情绪轨迹（如：`震惊→疑惑→期待反转/技术解密`），并在每章末尾设置“预期违背点”或“信息增量”，强制拉动追读；禁止在钩子未回收前切换主线视角。
