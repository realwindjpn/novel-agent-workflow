## Patch：题材选择 / 前台冲突 / 安全创新 / 平台风险门禁

> 执行口号：**前台先勾住，套路打地基，创新做切片，代价兑钩子。**

---

## 0. 作家OS总规则更新

### 新增硬规则

1. **每章必须先有前台冲突**
   - 不能先讲世界观。
   - 不能先讲体系史。
   - 不能先讲主角内心独白。
   - 必须先让读者看到：  
     **谁和谁在抢什么？谁会吃亏？马上会爆什么？**

2. **冲突优先级高于设定**
   - 科武设定再酷，也必须服务当前章冲突。
   - 每个新设定出现时，必须立刻改变局面。

3. **创新只创新切入点，不创新所有东西**
   - 长篇《科武纪元》：  
     `套路:创新 ≥ 70:30`
   - 短故事 / 狼人篇 / 热点稿：  
     `套路:创新 ≥ 90:10`

4. **主角每次赢，都必须付代价**
   - 代价类型：身体损伤、装备损耗、信用下降、关系破裂、记忆缺失、身份暴露、世界线污染。
   - 代价必须在后文兑现，不许假代价。

5. **章末必须同时有两个东西**
   - 情绪兑现：这一章读者爽到 / 燃到 / 揪心到。
   - 新钩子：下一章必须想看。

# 2. 题材选择执行补丁

## 写之前先问三句

1. **我看过最多的类型是什么？**
   - 不熟的分类，不追热点。
   - 不懂读者三观，就容易把爽点写成雷点。

2. **这个题材里读者最想看什么情绪？**
   - 升级？
   - 打脸？
   - 复仇？
   - 破案？
   - 小队羁绊？
   - 黑市生存？
   - 阵营战争？

3. **我这次只创新哪10%到30%？**
   - 不许人物、冲突、节奏、世界观一起创新。
   - 《科武纪元》允许世界观创新较高，但人物讨喜、冲突节奏必须用成熟写法。

---

## 《科武纪元》长篇可借点

### 可借

- **科学派 vs 武道派**
- **体制内执法队 vs 黑市散修**
- **学院名额争夺**
- **禁术芯片使用代价**
- **主角被明确敌人盯上**
- **第一次实战提前出现**
- **小队副本式升级**
- **强者压迫下的生存反杀**
- **金手指有副作用**
- **每卷一个明确敌对势力**

### 禁止

- 第一章讲科武体系起源。
- 第一章讲百年战争史。
- 第一章堆术语。
- 主角没有敌人，只是在修炼。
- 战斗只写“他爆发力量，击败敌人”。
- 代价只喊口号，不兑现。

---

## 短故事 / 狼人篇可借点

### 可借

- **强前台身份冲突**
  - 例：狼人必须隐藏身份，但同伴正在用科武仪器筛查异种血脉。

- **双主体对抗**
  - 狼人想救人。
  - 猎杀队想当场处决。
  - 双方都不是纯傻坏，都有理由。

- **疯批元素可少量支线化**
  - 可用于狼人篇的反派、实验体、黑市医生。
  - 不宜直接给长篇主角做无底线疯批。

- **身份暴露钩子**
  - 章末：仪器响了。
  - 章末：队友闻到了血味。
  - 章末：主角伤口没有愈合，而是长出了银色狼毛。

- **短篇必须更快兑现**
  - 第1段给冲突。
  - 第2段给异常。
  - 第3段给代价。
  - 结尾给反转或身份暴露。

### 狼人篇推荐节奏

```text
第1段：正常任务中出现筛查/围捕。
第2段：主角必须隐藏狼人特征。
第3段：为了救人被迫动用异种能力。
第4段：能力救场，但留下证据。
第5段：队友/敌人发现异常。
结尾：身份钩子或更高阶狼人登场。
```

## 每章开头禁止写法

```text
三百年前，科武纪元开启。
自从灵能粒子降临后，人类文明……
在这个世界，武者分为九阶……
主角站在窗前，回忆起自己的过去。
```

---

## 每章开头推荐写法

```text
警报响起时，林昼的右臂还插在非法义体接口里。

门外，执法队的破甲锤已经砸穿第一层合金门。

他只剩十二秒，要么拔掉芯片，放弃救人；要么完成同步，成为通缉犯。
```

### 这个开头完成了什么

- 有人追。
- 有时间限制。
- 有选择。
- 有代价。
- 有科武设定。
- 不需要先解释世界观。

# 4. 冲突模板补丁

## 模板1：救人 vs 执法

```yaml
主角目标：用违规科武技术救人
对手目标：阻止违规技术扩散
抢夺物：病人的命 / 禁用芯片 / 现场证据
失败代价：主角入狱，病人死亡
章末钩子：被救者体内出现不属于人类的第二心跳
适合：科武长篇 / 短故事
```

---

## 模板2：学院名额争夺

```yaml
主角目标：拿到唯一实战考核名额
对手目标：让主角失去资格
抢夺物：入院名额 / 资源 / 身份
失败代价：主角失去进入核心体系机会
章末钩子：考核名单里出现已死亡的人
适合：科武长篇
```

---

## 模板3：狼人身份隐藏

```yaml
主角目标：隐藏狼人血统并完成任务
对手目标：用检测仪筛出异种
抢夺物：身份安全 / 队友信任 / 任务目标
失败代价：暴露、处决、被实验室回收
章末钩子：检测仪显示“非人类波形匹配度99.7%”
适合：狼人篇 / 短故事
```

---

## 模板4：黑市交易翻车

```yaml
主角目标：买到救命义体或功法残片
对手目标：黑吃黑，夺走主角身上的科武核心
抢夺物：义体 / 残片 / 资金 / 命
失败代价：主角暴露金手指
章末钩子：黑市老板跪下喊出主角父亲的旧称号
适合：科武长篇 / 短故事
```

---

## 模板5：科学派与武道派对立

```yaml
主角目标：证明科技可以辅助武道突破
对手目标：证明主角的路线是污染和歪道
抢夺物：路线合法性 / 资源 / 学院话语权
失败代价：主角研究被封，队友受牵连
章末钩子：反对者偷偷使用了更危险的禁用科技
适合：科武长篇
```

# 5. 人物口吻补丁

## 主角口吻

### 适合《科武纪元》主角

- 冷静但不冷血。
- 会算代价，但关键时刻愿意扛。
- 不说大空话。
- 说话带行动导向。

```text
“给我十秒。”

“十秒后，如果我还没拔线，你就砍掉我的右臂。”

“别问值不值。现在病人还活着，这就够了。”
```

### 禁止

```text
“我要改变整个世界！”
“这就是我的命运！”
“你们都不懂真正的力量！”
```

除非是中二少年向角色，否则少用。

---

## 反派口吻

### 好反派

- 不是单纯嘴臭。
- 有明确目标。
- 他的目标和主角互斥。
- 他的话能制造压力。

```text
“我不在乎你救了谁。”

“我只知道，三年前有一座城，就是从一枚违规芯片开始失控的。”

“把手从接口里拿出来。否则，我连你和病人一起封存。”
```

---

## 狼人篇角色口吻

### 狼人主角

- 克制。
- 本能在身体里翻涌。
- 语言短，动作多。

```text
“别靠近我。”

“我说了，别靠近。”

他的犬齿已经刺破下唇，血腥味让瞳孔一点点竖了起来。
```

### 猎杀者

```text
“异种不会无辜。”

“你现在还能说人话，不代表你明天不会咬断同伴的喉咙。”
```

# 6. 段落节奏补丁

## 标准动作段节奏

每个战斗/冲突段按这个顺序写：

```text
1. 目标：主角此刻要做什么。
2. 阻碍：谁阻止他，阻止方式是什么。
3. 起手动作：主角怎么动。
4. 接触反馈：碰撞后身体/装备/环境有什么变化。
5. 反制：对手如何改变局面。
6. 代价：主角赢或推进后损失什么。
7. 小钩子：新的异常出现。
```

---

## 示例段落

```text
林昼没有退。

他把右臂义体插进病床下方的备用能源口，掌心的神经针一根根弹出，刺入自己的腕骨。

因此，原本供给病人的冷核电流被强行转接进他的经络。

第一秒，他右臂皮肤变成铁灰色。

第三秒，义体外壳温度升到七十八度，烫得袖口卷曲发黑。

第五秒，门外的执法队长抬手，破甲锤第二次落下。

合金门凹陷，冲击波震碎病房灯管。

林昼咬碎一颗牙，借着电流反冲，把病人体内那枚失控芯片压回心脏下方。

仪器重新响起心跳声。

但同一时间，墙上的检测屏跳出一行红字：

【非法科武共生反应确认。上传执法总网。】
```

### 这个段落必须保留的点

- 有动作链。
- 有物理反馈。
- 有量化细节。
- 有胜利。
- 有代价。
- 有章末钩子。

# 7. 动作链补丁

## 禁止概括

```text
他爆发力量，打败了敌人。
两人激战许久。
主角凭借强大意志撑了下来。
```

---

## 必须写成

```yaml
起手：
  林昼左脚踩碎地面感应砖，把身体重心压低。

接触：
  他用义体右臂硬接破甲锤，同时启动腕骨里的磁轨线圈。

反馈：
  破甲锤表面火花倒卷，义体外壳裂开三道白纹。

反制：
  执法队长顺势松锤，膝撞顶向林昼腹部的冷核接口。

结果：
  林昼被撞退两米，接口偏移，病人的心跳波形瞬间下坠。
```

# 11. 失败模式补丁

写完后出现以下情况，直接判定需要重写。

## 失败模式1：精品感挤掉前台故事

### 表现

- 第一章很美。
- 设定很完整。
- 语言很有电影感。
- 但没人打架，没人追杀，没人抢东西。

### 修复

- 加一个当场冲突。
- 加一个明确敌人。
- 加一个倒计时。
- 把世界观塞进动作结果里。

---

## 失败模式2：纯创新赌博

### 表现

- 世界观新。
- 人物关系新。
- 战斗机制新。
- 叙事结构也新。
- 读者不知道该期待什么。

### 修复

- 保留一个成熟骨架：
  - 学院考核
  - 黑市交易
  - 追杀逃亡
  - 小队副本
  - 复仇打脸
- 只在科武机制上创新。

---

## 失败模式3：只有后台，没有前台

### 表现

```text
主角其实背负巨大秘密。
这个组织其实暗中操控世界。
科武体系其实来自远古文明。
```

但当前章没人发生直接碰撞。

### 修复

把后台变成当前章抢夺物：

```text
不是“组织暗中操控世界”，
而是“组织的人现在要抢走主角手里的证据”。
```

---

## 失败模式4：人设不讨喜

### 表现

- 主角狠，但没有底线。
- 主角冷，但不救人。
- 主角强，但不付代价。
- 主角嘴硬，但不做事。

### 修复

给主角一个可见讨喜点：

```text
他算计所有人，但不算计救命钱。
他嘴冷，但关键时刻先挡刀。
他不信规则，但愿意承担破规则的后果。
```

---

## 失败模式5：章末只有钩子，没有兑现

### 表现

- 每章都吊胃口。
- 但读者没有爽点。
- 没有赢一次。
- 没有解决一个小问题。

### 修复

每章至少兑现一个：

```text
打倒一个小敌人。
救下一个人。
拿到一个线索。
证明一次自己。
让反派吃一次亏。
解开一个局部谜题。
```

然后再抛新钩子。

---

# 12. 平台规则转化：发布 / 包装 / 风险门禁

## A. 发布门禁

发布前检查：

```yaml
是否像读者熟悉的类型：
  是/否

前三章是否能看懂：
  是/否

第一章是否有明确对抗：
  是/否

是否有成熟套路骨架：
  是/否

创新比例是否过高：
  长篇科武 ≤30%优先
  短篇/狼人篇 ≤10%优先

是否需要重写开头：
  是/否
```

### 不通过则不发布

尤其是以下情况：

- 开篇三千字全是设定。
- 第一章没有敌人。
- 主角目标不清。
- 读者不知道爽点是什么。
- 参考作品只看了一本，关系结构高度相似。

---

## B. 包装门禁

标题、简介、标签必须突出前台冲突，不突出抽象世界观。

### 不推荐包装

```text
《科武纪元》
一个关于科技与武道融合、人类文明进化的宏大史诗。
```

太空，太后台。

### 推荐包装

```text
《科武纪元：我用禁忌义体救人，被全城通缉》
```

或者：

```text
他只是想救妹妹，却在病房里接入了军方封存三十年的禁忌芯片。
十二秒后，执法队破门而入。
检测仪显示：
他已经不属于人类。
```

### 包装关键词

```text
禁忌义体
全城通缉
非法芯片
学院考核
黑市散修
科学派叛徒
武道异端
狼人体征
身份暴露
代价升级
```

---

## C. 风险门禁

### 撞梗风险

检查：

```yaml
是否只参考一本火文：是/否
主线是否相似：是/否
人物关系是否相似：是/否
关键桥段是否相似：是/否
只是换称谓/性别/背景：是/否
```

如果出现：

```text
主线相似 + 人物关系相似 + 桥段相似
```

判定高危，必须重构。

### 重构方式

- 换冲突场域：学院 → 黑市 / 战场 /医院 / 边境站。
- 换关系拓扑：师徒 → 互相利用的通缉犯与执法者。
- 换抢夺物：功法 → 芯片 / 证据 / 身份 / 病人生命。
- 换代价系统：灵力耗尽 → 记忆缺失 / 义体损毁 / 血脉污染。

# 13. 章节自检清单

每章写完后逐项打勾。

## 基础冲突

- [ ] 本章能用一句话说清前台冲突。
- [ ] 主角目标明确。
- [ ] 对手目标明确。
- [ ] 双方目标互斥。
- [ ] 当前章有人抢东西、救东西、阻止东西或隐藏东西。
- [ ] 读者不用懂完整世界观也能看懂这一章。

## 节奏

- [ ] 开头500字内出现冲突或倒计时。
- [ ] 没有连续三段纯设定。
- [ ] 设定通过行动、后果、对话释放。
- [ ] 本章至少有一次局势变化。
- [ ] 本章至少兑现一个小爽点。
- [ ] 章末有新钩子。

## 动作链

- [ ] 关键场景有起手。
- [ ] 有接触。
- [ ] 有反馈。
- [ ] 有反制。
- [ ] 有结果。
- [ ] 没有用“打败了”“激战许久”代替动作。

## 物理反馈

- [ ] 科武能力使用后有身体反馈。
- [ ] 有装备反馈或环境反馈。
- [ ] 至少一个反馈具象或量化。
- [ ] 反馈会影响后续行动。

## 代价

- [ ] 主角推进目标后付出代价。
- [ ] 代价具体，不是口号。
- [ ] 代价记录到后续章节。
- [ ] 代价会制造新冲突。

## 人物

- [ ] 主角有讨喜点。
- [ ] 主角不是无底线疯批。
- [ ] 反派不是纯工具人。
- [ ] 对手有自己的合理目标。
- [ ] 人物口吻符合年龄段和目标读者。

## 创新比例

- [ ] 长篇科武套路比例不低于70%。
- [ ] 短篇/狼人篇套路比例不低于90%。
- [ ] 本章只创新一个主要点。
- [ ] 没有同时创新世界观、人物、结构、节奏。

## 钩子

- [ ] 章末有情绪兑现。
- [ ] 章末有未决事项。
- [ ] 钩子指向下一章。
- [ ] 卷钩或主线钩有被轻微推进。
- [ ] 没有只吊胃口不兑现。

## 平台风险

- [ ] 没有主线+人物关系同时撞火文。
- [ ] 没有照搬标志性桥段。
- [ ] 简介突出前台冲突。
- [ ] 标题/标签让读者知道看点。
- [ ] 三观与目标读者匹配。

