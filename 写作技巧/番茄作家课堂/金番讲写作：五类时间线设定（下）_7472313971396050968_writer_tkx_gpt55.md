# 《科武纪元》作家OS补丁  
## 来源课：金番讲写作：五类时间线设定（下）  
## 补丁名：循环 / 多线并行执行模块 v1.0

---

## 0. 总执行原则

写循环，不写“重复”；写多线，不写“乱切”。

每章必须让读者看到：

> 主角做了新动作 → 世界给出新反馈 → 主角付出新代价 → 旧判断被推翻 → 章末出现新钩子。

---

# 1. 循环时间线执行模块

## 1.1 适用场景

### 短故事 / 狼人篇可借点

适合用于：

- 一夜狼人杀循环。
- 狼人身份反复误判。
- 村民、女巫、预言家每轮行为不同。
- 主角只有自己记得上一轮。
- 每轮结尾死人或身份翻车。

可借结构：

> 第一轮：主角被杀。  
> 第二轮：主角以为狼人是A，结果A死了。  
> 第三轮：主角强保B，结果B才是狼。  
> 第四轮：主角发现自己每次救人都会害死另一个人。

---

### 科武长篇可借点

适合用于：

- 训练舱循环。
- 武道闭关循环。
- 科技实验事故循环。
- 战场模拟循环。
- 主角保留记忆，但身体 / 精神 / 现实关系持续损耗。

推荐主结构：

> 现实线顺叙推进，训练舱 / 闭关线循环重置。  
> 舱内可以重来，舱外不可逆。

核心矛盾：

> 主角在模拟里越来越强，但现实里的身体、信用、阵营关系、实验资源正在持续崩坏。

---

## 1.2 循环开篇硬规则

### 动作要求

前1—2章必须完成一次：

1. 主角进入循环周期。
2. 主角执行目标。
3. 主角死亡 / 失败 / 实验崩盘。
4. 时间重置。
5. 主角意识到“只有我记得”。

### 禁止

- 禁止前3章只铺世界观。
- 禁止只说“他感觉似曾相识”，但不重置。
- 禁止循环规则拖到十章后才解释。

### 推荐章末钩子

第一章末：

> 他明明已经被实验舱的高温烧穿胸腔。  
> 可下一秒，他又听见导师说出那句熟悉的话：  
> “第七号实验体，准备入舱。”

---

## 1.3 每轮循环必填动作链

每次循环至少写3步动作：

### 标准动作链模板

> 尝试新方案 → 遭遇新阻碍 → 获得新线索 → 付出新代价 → 推翻旧判断。

### 示例：科武实验事故循环

第一轮：

- 潜入实验室。
- 发现反应堆过载。
- 强行关闭失败。
- 被能量冲击震碎经脉。
- 重置。

第二轮：

- 提前替换冷却芯。
- 发现冷却芯本身被人动过手脚。
- 怀疑设备组。
- 被安保系统锁定。
- 重置。

第三轮：

- 绕开设备组，追踪权限日志。
- 发现导师账号曾在事故前登录。
- 主角以为导师是凶手。
- 结果导师提前死亡。
- 重置。

---

## 1.4 每轮循环必须新增的信息

每一轮必须做到：

| 项目 | 要求 |
|---|---|
| 新线索 | 至少1条 |
| 旧判断推翻 | 至少1条 |
| 代价 | 至少1个 |
| 主角策略升级 | 必须有 |
| 章末钩子 | 必须有 |

### 禁止水文模式

以下写法判定为水：

- 每轮只是换个死法。
- 主角重复问同一个人。
- 同一个线索反复解释。
- 配角每轮反应完全一样。
- 主角没有策略升级。

---

## 1.5 循环冲突升级链

循环不是“多试几次”，而是主角越来越极端。

### 标准升级链

1. 劝说  
2. 阻拦  
3. 欺骗  
4. 强制控制  
5. 自我牺牲  
6. 反向加害  
7. 发现真正死结不是眼前目标

### 科武写法示例

目标：阻止导师进入实验舱。

第一轮：

> 主角劝导师推迟实验。

第二轮：

> 主角伪造设备故障报告。

第三轮：

> 主角破坏实验舱能源接口。

第四轮：

> 主角击晕导师，强行拖走。

第五轮：

> 主角发现导师不进舱，整座研究所会被反噬波摧毁。

第六轮：

> 主角亲手把导师送进舱，但提前替换了核心参数。

章末反转：

> 导师进舱前看了他一眼：  
> “你终于循环到这一步了。”

---

## 1.6 循环代价模块

循环不能免费。

### 可用代价

#### 身体代价

- 经脉裂纹增加。
- 神经烧蚀。
- 义体接口过热。
- 脑内时间感紊乱。
- 肌肉记忆残留导致现实误伤。

#### 精神代价

- 记忆缺片。
- 对配角产生信任疲劳。
- 分不清哪一次对话真实发生过。
- 情绪钝化。
- 对死亡麻木。

#### 现实代价

- 实验权限降低。
- 同伴信任值下降。
- 设备损耗不可恢复。
- 阵营敌意上升。
- 现实时间继续流逝。

#### 科武专属代价

- 内息污染。
- 丹田过载。
- 武道意志被模拟敌人反向侵蚀。
- 战斗本能盖过理性判断。
- 现实肉身跟不上模拟境界。

---

## 1.7 循环人物口吻

### 主角初期口吻

特点：震惊、急切、解释欲强。

示例：

> “不对，这句话你刚才说过。”  
> “你现在别碰那个阀门，三十秒后它会爆。”  
> “我知道你不信，但我已经死过一次了。”

### 主角中期口吻

特点：克制、疲惫、开始预判别人。

示例：

> “你接下来会说权限不够。”  
> “别浪费时间，我只问三个问题。”  
> “这次我不救他，我救反应堆。”

### 主角后期口吻

特点：冷硬、近乎残酷。

示例：

> “你死过四次了，只是你不记得。”  
> “我不需要你相信我，我只需要你按我说的做。”  
> “如果杀你能让这一轮多撑十分钟，我会动手。”

---

## 1.8 循环段落节奏

### 单章推荐节奏

1. 300字内给出本轮目标。
2. 800字内出现第一次阻碍。
3. 中段给出新线索。
4. 后段推翻旧判断。
5. 章末死亡 / 失败 / 重置 / 新变量出现。

### 段落写法

循环文要短段、强反馈。

少写：

> 他陷入了深深的思考。

多写：

> 第三秒，警报响。  
> 第七秒，导师回头。  
> 第十二秒，反应堆温度突破红线。  
> 和上一轮一样。  
> 不一样的是，这次死的人不是导师。  
> 是他自己。

---

## 1.9 循环章末钩子库

可直接套用：

1. 死亡钩子  
   > 他闭眼前，看见凶手摘下面罩。那张脸，是他自己。

2. 重置钩子  
   > 钟声再次响起。可这一次，倒在地上的不是实验员，而是导师。

3. 线索钩子  
   > 他醒来第一件事，就是翻开掌心。那里多了一行上一轮没有的血字。

4. 规则钩子  
   > 第七次重置后，系统第一次开口：本轮死亡不可回档。

5. 人物钩子  
   > 她看着他，轻声说：“你也回来了？”

# 2. 多线并行执行模块

## 2.1 定义修正

这里的多线并行不是简单插叙。

它指：

> 同一世界观内，同时存在两种时间机制。

例如：

- 现实线：正常顺叙，不可逆。
- 模拟线：循环重置，可反复尝试。
- 梦境线：一夜等于异界三年。
- 读档线：只能回到固定节点。
- 闭关线：失败重来，但现实寿命消耗。

---

## 2.2 开篇硬规则

前3章必须写清：

| 项目 | 必须让读者知道 |
|---|---|
| 线A | 现实线怎么流动 |
| 线B | 异界 / 模拟线怎么流动 |
| 差异 | 是否重置、是否同步、流速比例 |
| 互通 | 记忆、伤势、资源、身份是否能带回 |
| 风险 | 哪条线的代价不可逆 |

### 禁止

- 禁止大段设定说明。
- 禁止读者三章后还不知道哪条线是真的。
- 禁止两条线都高强度战斗，导致疲劳。

---

## 2.3 科武推荐双线结构

### 现实线

身份：

> 底层研究员 / 实验助理 / 低阶武者。

特点：

- 资源少。
- 权限低。
- 被导师、财团、军方压制。
- 现实不可逆。
- 负责压迫感和主线阴谋。

### 模拟线 / 闭关线

身份：

> 武道宗师 / 战场编号 / 模拟冠军 / 失落纪元传人。

特点：

- 能反复试错。
- 战力提升快。
- 有马甲。
- 能获得技术、功法、战斗经验。
- 负责爽点和成长。

### 双线互斥目标

现实线目标：

> 保住实验资格，查出事故真相。

模拟线目标：

> 继续循环，刷出完整武道模型。

互斥点：

> 主角越依赖模拟线，现实身体越崩；  
> 主角越想保护现实同伴，就越不能在模拟里无限重来。

---

## 2.4 双身份反差写法

必须显性写出两套人格。

### 现实人格

关键词：

- 谨慎
- 隐忍
- 算资源
- 怕暴露
- 说话留余地

口吻示例：

> “这份申请我可以再改。”  
> “权限不够，我不碰核心舱。”  
> “数据异常可能只是偶发波动。”

### 模拟 / 马甲人格

关键词：

- 果断
- 强势
- 敢赌
- 下令
- 不解释

口吻示例：

> “开阵。”  
> “三息之内，不退者死。”  
> “我不需要你们理解，只需要执行。”

### 读者要感受到

同一个人，在两条线里不是换衣服，而是换生存规则。

---

## 2.5 多线章节比例

现实线与模拟线比例不要失衡。

推荐：

- 2章现实 + 3章模拟
- 3章现实 + 2章模拟
- 一章现实危机，一章模拟破法，再回现实验证

### 禁止

- 连续10章只写模拟，不管现实。
- 连续10章只写现实压抑，不给爽点。
- 两条线没有因果互通。

---

## 2.6 多线反馈机制

每次切线必须带回影响。

### 模拟线影响现实

- 带回战斗经验。
- 带回技术公式。
- 带回敌人情报。
- 现实身体出现模拟伤痕。
- 主角现实行为变得不正常，引起怀疑。

### 现实线影响模拟

- 现实设备损坏，导致模拟难度升高。
- 现实权限升级，开放新副本。
- 现实敌人篡改模拟参数。
- 现实身体状态差，模拟同步率下降。
- 现实情绪影响模拟武道心境。

---

## 2.7 多线章末钩子库

1. 现实线钩模拟线  
   > 他刚在模拟里斩杀的黑甲武者，现实中正坐在评审席上。

2. 模拟线钩现实线  
   > 训练舱弹开，主角胸口多了一道模拟里才有的刀痕。

3. 身份钩子  
   > 她递交的报告上写着：申请调查编号“玄武七号”的真实身份。

4. 资源钩子  
   > 现实实验室宣布停电维护。可模拟世界的太阳，也在同一刻熄灭了。

5. 阵营钩子  
   > 主角以为自己在模拟里救的是NPC。直到现实军方为那个人立了档案。

# 3. 平台规则转发布 / 包装 / 风险门禁

## 3.1 发布门禁

上线前必须检查：

1. 前3章是否出现循环 / 双线规则。
2. 第一章末或第二章头是否有死亡 / 失败 / 重置。
3. 前10章是否预告两线交汇。
4. 每章末是否有明确钩子。
5. 是否避免设定倾倒。

不满足以上任意2条，暂缓发布。

---

## 3.2 包装建议

### 循环类标题关键词

可用：

- 重启
- 死亡回档
- 七日
- 训练舱
- 第九次
- 无限闭关
- 我又死了

科武包装示例：

- 《第九次闭关后，我发现导师也在循环》
- 《训练舱死亡七次，我带回了宗师记忆》
- 《实验事故前一小时，我无限重启》

---

### 多线类标题关键词

可用：

- 双身份
- 模拟宗师
- 现实废柴
- 编号马甲
- 两界时间差
- 舱内无敌，舱外濒死

科武包装示例：

- 《现实月薪三千，舱内武道宗师》
- 《我的实战编号，成了全军禁忌》
- 《训练舱里三百年，现实只过一夜》

---

## 3.3 风险门禁

### 结构风险

| 风险 | 处理 |
|---|---|
| 循环太长 | 控制在1日 / 5日 / 7日 |
| 规则太晚 | 前3章必须说明 |
| 主角太无敌 | 每轮增加不可逆代价 |
| 双线混乱 | 每次切线标清时间、地点、身份 |
| 两线割裂 | 每次切线必须带回影响 |

### 调性风险

科武长篇慎用：

- 纯爱“老公出门必死”模板。
- 失忆恋爱循环作为主线。
- 轻飘飘游戏删档梗。
- 无代价无限刷副本。
- 两条线全是高密度打斗。

# 4. 写作前任务卡字段更新

写循环 / 多线章节前，任务卡新增以下字段。

## 4.1 基础字段

| 字段 | 填写要求 |
|---|---|
| 本章所属时间线 | 现实线 / 模拟线 / 闭关循环 / 异界线 |
| 时间机制 | 顺叙 / 循环 / 读档 / 时间差 |
| 当前轮次 | 第几轮循环；非循环填“无” |
| 周期长度 | 1日 / 5日 / 7日 / 其他 |
| 本章目标 | 主角一句话目标 |
| 本章失败条件 | 什么情况算本章失败 |
| 本章不可逆代价 | 身体、资源、信任、权限、寿元等 |
| 本章新线索 | 至少1条 |
| 本章推翻旧判断 | 至少1条 |
| 本章章末钩子 | 1悬念 + 1预告 |

---

## 4.2 动作链字段

必须填写：

> 主角动作1 → 反馈1 → 主角动作2 → 反馈2 → 主角动作3 → 反馈3 → 失败 / 反转 / 新变量。

示例：

> 潜入冷却室 → 护具被冻裂 → 替换冷却芯 → 反应堆温度反升 → 追查权限日志 → 发现导师账号登录 → 导师却已在十分钟前死亡。

---

## 4.3 物理反馈字段

每个动作必须有可感知反馈。

可写：

- 疼痛。
- 温度。
- 噪声。
- 血。
- 内息紊乱。
- 设备过热。
- 护甲开裂。
- 时间错位眩晕。

禁止：

- “他很震惊。”
- “他感觉不对。”
- “情况很危险。”

改成：

> 颈后的神经接口烫得像烙铁，视野右下角跳出红字：同步率跌破41%。

---

## 4.4 人物口吻字段

每章标注主角当前状态：

| 状态 | 口吻 |
|---|---|
| 初入循环 | 急、解释、慌 |
| 多轮失败 | 短句、预判、疲惫 |
| 接近破局 | 冷、狠、不解释 |
| 双身份现实线 | 谨慎、低姿态 |
| 双身份模拟线 | 命令式、压迫感 |

---

## 4.5 读者预期管理字段

必须填写：

> 读者会以为X，实际发生Y。

示例：

- 读者以为导师是凶手，实际导师也是循环受害者。
- 读者以为模拟伤不会带出现实，实际主角胸口出现刀痕。
- 读者以为主角只要阻止实验即可，实际实验不启动会导致城市级灾难。

---

# 5. 章节自检清单

提交章节前逐条检查。

## 5.1 循环章节自检

1. [ ] 本章是否明确这是第几轮循环？
2. [ ] 主角本轮目标是否一句话能说清？
3. [ ] 本轮是否有至少3步动作链？
4. [ ] 每个关键动作是否有身体 / 环境反馈？
5. [ ] 本轮是否新增至少1条线索？
6. [ ] 本轮是否推翻至少1条旧判断？
7. [ ] 主角策略是否比上一轮升级？
8. [ ] 是否出现不可逆代价？
9. [ ] 是否避免机械重复上一轮内容？
10. [ ] 章末是否留下1个当前悬念？

# 6. 《科武纪元》推荐落地方案

## 主结构

> 现实顺叙 + 训练舱循环。

现实线：

- 主角是低阶研究员。
- 被体制压制。
- 实验资格随时被取消。
- 现实资源不可逆。

训练舱线：

- 主角进入古武战场模拟。
- 每次死亡后重启同一段闭关 / 战役。
- 记忆保留，身体逐渐损耗。
- 获得武道经验和失落科技参数。

---

## 主冲突

> 主角必须靠训练舱循环变强，才能解决现实危机；  
> 但每多循环一次，现实身体和权限就更接近崩溃。

---

## 单章执行样例

### 本章目标

主角要在第六次模拟中救下“玄甲女将”，获取失落武道公式。

### 动作链

1. 主角提前埋伏敌军侧翼。  
2. 敌军阵型改变，上一轮经验失效。  
3. 主角强行开启过载步法。  
4. 腿部经脉撕裂，但追上女将。  
5. 女将却反手刺穿他胸口。  
6. 主角死亡前发现她使用的是现实军方禁术。

### 新线索

玄甲女将会现实军方禁术。

### 推翻旧判断

她不是普通模拟NPC。

### 不可逆代价

现实中主角右腿神经同步率下降12%。

### 章末钩子

悬念：

> 模拟NPC为什么会现实禁术？

预告：

> 主角出舱后，在现实评审名单上看见了玄甲女将的脸。

# 7. 最终写作指令

以后写循环 / 多线章节时，默认执行以下命令：

> 不重复上一轮。  
> 不免费重来。  
> 不空切时间线。  
> 不让主角白赢。  
> 每章必须有动作、反馈、代价、反转、钩子。  
> 舱内可以重启，舱外必须不可逆。
