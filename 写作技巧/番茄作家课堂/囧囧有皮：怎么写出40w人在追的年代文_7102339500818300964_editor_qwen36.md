# 《科武纪元》编辑学习官：番茄年代文爆款拆解与规则迁移

## 1 课程核心判断（≤6条）
1. **开篇即流量闸门**：开篇争议或信息过载会直接触发弃文率飙升；存稿安全与开篇定稿优先级高于一切。
2. **长篇存活靠“控支线”**：支线篇幅超主线30%或行文繁复冗杂，是免费平台弃文率攀升的核心诱因。
3. **“爽”必须绑定实质内核**：纯情绪宣泄易致阅读疲劳；爽点需同步输出价值观、关系推进或世界观演进。
4. **人物多面性＞完美性**：跨频性格移植（如女频女主植入男频痞气/反常规正义）能有效打破同质化，提升角色记忆点。
5. **题材生命力在“活劲”与“烟火气”**：无论年代或科幻，读者买单的是“积极破局的生活意志”与“可触摸的真实细节”。
6. **平台算法重稳定与长尾**：推荐期需提速响应；免费模式依赖完读率与完结后算法加权，断更=流量断崖。

## 2 可执行编辑规则（按文章实际内容提取）
| 模块 | 编辑执行规则 |
|:---|:---|
| **开篇** | 前3章必须亮出核心人设、主线目标与首个悬念；禁止堆砌背景设定；开篇定稿前需做“无上下文盲测”，存稿必须多端物理备份。 |
| **节奏** | 基准日更4k-6k；推荐期数据异动时需在24小时内提速响应；单章信息密度需均匀，禁止连续3章纯对话或纯设定说明。 |
| **冲突** | 冲突解决必须附带“意义交付”（如团队凝聚、规则打破、认知升级）；避免纯碾压式爽点，设计“爽感+逻辑自洽”双引擎。 |
| **人物** | 主角需配置“明确底线+合理缺陷+幽默/反常规表达”；禁止扁平圣母或无代价龙傲天；配角需具备独立行动逻辑，非纯工具人。 |
| **题材** | 用具体物件、生理反应、时代/科技细节替代宏大空泛描写；主线聚焦“生存/奋斗/羁绊”，弱化悬浮感。 |
| **改编** | 影视/短剧改编潜力取决于“强关系网+高密度冲突+可视化场景”；年代文家长里短需转化为科武中的“阵营博弈/资源争夺/伦理冲突”。 |
| **平台规则** | 番茄免费模式以“完读率”为推荐核心指标；完结后收益呈长尾爬坡，需预留情感余韵或番外承接流量；严禁断更，断更超24小时需提前公告+补偿章。 |

## 3 科武适配：可用点、不可硬套点
| 维度 | 可用点（直接迁移） | 不可硬套点（需重构） |
|:---|:---|:---|
| **人物塑造** | 女主/男主可植入“痞气+清醒+底线”特质，打破科幻冰冷感；允许非绝对正义的灰度人设。 | 年代文“靠女主纯自力更生/无金手指”不可照搬；科武需合理外挂（科技/基因/系统），但必须设为“成长型/代价型”。 |
| **冲突设计** | “爽点+实质意义”双引擎适用于科武战斗/科技突破；可绑定人性探讨或阵营规则演进。 | “婶子大战/邻里纠纷”式低维冲突不可直接套用；需升维为“资源配额争夺/技术伦理博弈/生存空间挤压”。 |
| **节奏与结构** | 支线严控≤30%，防设定堆砌导致弃文；推荐期提速机制完全通用。 | 年代文“完结收益翻倍”属平台特定算法红利；科武长篇更依赖前期留存，不可盲目押注完结长尾。 |
| **质感营造** | “活劲”与“烟火气”可对冲科幻硬核感；用底层生存细节、团队羁绊、装备损耗增强代入。 | 怀旧情绪不可依赖“年代滤镜”；科武需构建“未来生活逻辑”（如能源配给、义体维护、生态舱日常）。 |

## 4 编辑检查表（10条以内）
- [ ] 开篇前3章是否明确核心人设、主线目标与首个悬念？无背景堆砌？
- [ ] 支线篇幅是否≤主线30%？有无连续2章以上纯设定/对话拖慢节奏？
- [ ] 每次冲突/爽点是否附带价值观输出、关系推进或世界观演进？
- [ ] 主角是否具备“缺陷+底线+反常规表达”？是否避免完美扁平？
- [ ] 科幻设定是否通过具体动作/物理反馈/生活细节落地？（非纯说明）
- [ ] 更新节奏是否匹配平台推荐期？有无断更风险预案？
- [ ] 金手指/越级破局是否绑定明确代价？代价是否在3-5章内产生连锁反应？
- [ ] 章末是否设置“信息差悬念”或“行动倒计时”？兑现周期≤3章？
- [ ] 主角是否在困境中展现积极破局意志（活劲）？而非纯被动挨打？
- [ ] 主线收束后是否预留情感余韵/番外空间以承接完结长尾流量？

## 5 对作家角色的输入要求
| 维度 | 强制输入规范（科武向） |
|:---|:---|
| **动作链** | 必须提供“动机→决策→执行→结果”完整闭环；科幻战斗/操作需拆解为可验证的步骤序列（如：锁定目标→能量充能→轨道修正→命中判定→反冲位移），禁止跳跃式推进或“意念决胜”。 |
| **物理反馈** | 每次科技应用/武力交锋必须伴随可量化描写：环境破坏半径、机体负荷阈值、能量衰减曲线、感官剥夺（耳鸣/失重/灼痛）；杜绝“光效对波”式空洞打斗。 |
| **代价** | 金手指/越级破局必须绑定明确代价（寿命折损、资源枯竭、道德妥协、阵营反噬、神经负荷）；代价需在后续3-5章内触发连锁反应，禁止“一次性消耗无后患”。 |
| **钩子** | 章末必须设置“信息差悬念”或“行动倒计时”；钩子需与主线目标强绑定，兑现周期≤3章；禁止纯情绪/风景收尾；钩子需具备“可验证性”（读者能预判验证节点）。 |
| **读者预期** | 每卷/每阶段开篇需明确“本阶段核心爽点/成长目标”；行文严格对齐预期；若需反转，必须提前3章埋设逻辑伏笔（如参数异常、对话双关、装备隐患）；严禁机械降神或临时改设定。 |
