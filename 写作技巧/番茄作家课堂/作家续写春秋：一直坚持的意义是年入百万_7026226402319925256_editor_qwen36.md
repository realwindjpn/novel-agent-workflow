# 《科武纪元》编辑学习报告：基于《作家续写春秋：一直坚持的意义是年入百万》

## 1 课程核心判断（≤6条）
1. **免费+算法是核心分发逻辑**：平台以“低门槛阅读+算法推荐”替代传统编辑推荐，作品生命周期由数据（完读率/留存率）决定。
2. **完本即资产起点**：算法持续推荐使存量作品产生长尾复利，完本后收益不衰减，倒逼作者追求“完整交付”而非“断更止损”。
3. **质量密度＞题材热度**：平台缺优质作者而非读者，垂直/小众题材只要叙事完整、逻辑自洽，仍可穿透流量池。
4. **篇幅服从剧情闭环**：拒绝预设字数与注水，以“伏笔回收/主线填坑”为完结标准，节奏紧凑度直接挂钩推荐权重。
5. **真实经验需类型化转译**：个人经历/实地采风必须经过戏剧结构重组，保留质感但强化可读性，不可直接堆砌素材。
6. **坚持的本质是系统信任**：非盲目日更，而是“信任算法长尾机制+稳定输出完整作品”的工业化写作策略。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则（基于原文逻辑推导） |
|:---|:---|
| **开篇** | 免费用户决策窗口≤3秒。首章必须直给核心设定/生存危机/明确目标，禁用冗长背景铺陈或慢热抒情。 |
| **节奏** | 以“填坑/推进主线”为章节节点，每章需完成一次小循环（遇阻-破局-留悬）。算法推荐依赖完读率，冗余日常/说明性段落直接降权。 |
| **冲突** | 不依赖跟风热点，冲突需由人物真实动机（利益/生存/信念）与情境限制自然碰撞产生，避免作者强行降智或机械推进。 |
| **人物** | 拒绝脸谱化。主角需具备可验证的行为逻辑与成长弧光；配角需承担功能性（信息/阻力/资源）而非纯工具人。 |
| **题材** | 小众题材突围靠“设定密度+情绪钩子”。标签需精准匹配搜索习惯，简介前50字必须亮出核心卖点与阅读预期。 |
| **改编** | 现实素材/个人经历需做“类型化转译”：提取真实细节，嵌入标准叙事框架（如公路文→星际迁徙/废土探索），保留质感但强化戏剧张力。 |
| **平台规则** | 免费模式核心指标：读完率、加入书架率、段评互动。签约后需稳定更新至完本；完本后优化简介/标签/封面以激活二次算法推荐。 |

## 3 科武适配（《科武纪元》专项）
### ✅ 可用点
- **长尾逻辑契合**：科武世界观庞大、设定严谨，完本后易形成“设定集/战力体系/势力谱”长尾搜索流量，适合算法持续推荐。
- **反注水刚需**：科武依赖科技树与武道体系自洽，灌水会直接破坏逻辑链，原文“填坑完结”原则可直接作为科武节奏标尺。
- **真实质感转译**：科武的“武”可嫁接现实物理/格斗/材料学逻辑，增强战斗可信度；“科”需做通俗化降维，避免学术堆砌。
- **垂直破圈路径**：科武属高门槛垂直赛道，靠“设定密度+节奏紧凑+情绪交付”穿透免费流量池，不依赖泛娱乐热点。

### ❌ 不可硬套点
- **“不跟风/不蹭热度”**：科幻需基础科学共识或流行科技梗作为读者入口，完全脱离易成作者自嗨；需在“硬核设定”与“大众认知锚点”间找平衡。
- **“公路文/个人经历直接套用”**：科武需类型化框架（如深空探索/废土迁徙/文明跃迁），个人游记需重构为“任务驱动+环境压迫”叙事，不可散文化。
- **“清流/纯文学化节奏”**：番茄免费平台要求强情绪钩子与明确类型标签，科武若过度追求文学留白或慢热铺垫，将直接流失算法推荐权重。

## 4 编辑检查表（10条以内）
1. [ ] 首章3000字内是否抛出核心设定/生存危机/明确目标？
2. [ ] 每章结尾是否设置“未解变量”（新威胁/反转线索/倒计时），保障算法完读率？
3. [ ] 剧情推进是否以“填坑/解局”为节点，无冗余日常或说明性灌水？
4. [ ] 科武设定（科技/武道）是否具备可验证的物理/逻辑反馈链？
5. [ ] 人物动机是否由利益/生存/信念驱动，而非作者强行安排？
6. [ ] 标签/简介是否精准匹配目标读者搜索习惯（适配算法分发）？
7. [ ] 完本规划是否以“主线闭环+伏笔回收”为准，而非预设字数？
8. [ ] 前10章是否完成“世界观展示-冲突爆发-首次破局”免费模式标准结构？
9. [ ] 数据监控是否聚焦“读完率/加入书架率/段评互动”，而非单纯追更字数？
10. [ ] 完本后是否预留番外/设定集/修订空间以激活二次推荐？

## 5 对作家角色的输入要求
| 维度 | 执行标准（科武向） |
|:---|:---|
| **动作链** | 战斗/操作必须遵循“意图→发力→轨迹→结果”物理逻辑。禁用“意念秒杀”“模糊特效”等无过程描写，需拆解为可追踪的战术步骤。 |
| **物理反馈** | 科武交互必须呈现环境破坏、能量衰减、机体负荷、材料形变等可量化反馈。例：能量刃劈中装甲需描写热传导、结构应力、碎片抛射轨迹。 |
| **代价** | 每次能力跃升/战术胜利需支付明确代价：资源消耗（燃料/算力/弹药）、身体损伤（神经负荷/骨骼微裂）、阵营暴露、道德妥协或战略被动。 |
| **钩子** | 章末必须设置“未解变量”（倒计时启动/新势力介入/伏笔触发/战力失衡），禁用纯抒情或总结性收尾。钩子需与下一章首段形成因果咬合。 |
| **读者预期** | 免费读者预期“每章有进展”，科武读者预期“设定自洽+战力不崩”。需在更新中明确交付进度条（如：本卷回收3个伏笔/解锁1项科技/推进1条势力线），避免信息断层或战力通胀。 |
