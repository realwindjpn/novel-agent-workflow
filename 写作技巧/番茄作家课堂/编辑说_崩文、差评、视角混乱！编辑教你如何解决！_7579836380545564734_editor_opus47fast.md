## 1. 课程核心判断（6条）

1. **崩文的本质是悬念交接失败**，而非"换地图"本身——读者流失发生在第1悬念揭晓与第2悬念尚未生效的真空期。
2. **铺垫必须超前一棒**：当前悬念进行时就要埋下下一悬念的人/物/线索，而不是等本悬念收尾时再启动。
3. **任意时刻保持 ≥1.75 根悬念线**在拉读者；单线小说是高风险结构。
4. **读者评论 ≠ 修文指令**。读者要"立刻爽"，作者的KPI是"节奏不烂"，两者天然对抗。
5. **改文的唯一客观依据是数据**（追更/留存/收益），不是评论区情绪。常识/逻辑bug可改，主线节奏不可让步。
6. **小说的"上帝视角"是电视剧迁移过来的伪能力**；前期多视角=多个小地图割裂=代入感死亡。

## 2. 可执行编辑规则

### 2.1 开篇
- 前期数万字锁定**单一主角视角**；他人事件须以"主角在场"或"主角听闻"的方式过滤进入。
- 黄金三百字 → 黄金三章 → 8万字推荐 → 20万字换图风险点，是四个独立检查节点，每个节点都要重新校验悬念结构。

### 2.2 节奏
- 在悬念1的故事里**穿插悬念2的事件 + 悬念3人物的露面/提及**；写悬念2时再向下推一层。
- 真正必须换地图时，**尽量往后拖**——字数越长读者沉没成本越高，弃文率越低；即使崩也接近完本，损失可控。
- 不要把30万字的拉扯压成10万字交付。

### 2.3 冲突
- **冲突走人物，不走背景**。换场景写"拿到东西"本身，不写赶路心理、不写新环境观光。
- 弱化"位移感"，强化"事件进度感"——读者应记得"主角做了几件事"，而不是"主角去了几个地方"。

### 2.4 人物
- 主角视角是默认锚点；配角视角章节是**奢侈品**，单次≤几百字，且要求该配角的记忆点强于当前主角段落，否则直接弃文。
- 主角发表"反三观"言论是高风险动作，要么不放，要么承担差评+数据反噪。

### 2.5 题材边界
- 新人最稳的做法是**"不换地图"**：校园文锁校园、宅斗文锁宅院；进职场/朝堂/战场即换赛道，难度跳级。

### 2.6 改编/听取意见
- 可改：常识错误、错别字、设定漏洞、逻辑bug。
- 不可改：主线节奏、悬念时序、CP拉扯长度、虐点保留与否。
- 决策器：**追更曲线 > 评论区音量**。

### 2.7 平台规则（番茄侧暗规则）
- 8万字上推荐是数据节点；20万字左右是崩文高发段；这两段前必须重新审视悬念库存。
- 评论区差评热度是双刃——和读者对线会把差评顶上书籍首页，二次毒化新读者。**不开麦**是平台环境下的最优解。

## 3. 科武适配

### ✅ 可用点
- **多悬念叠铺**对长篇科幻天然契合：科技谜题 / 武道境界 / 阴谋势力 / 身世线，本就该≥3线并行，正好满足"1.75根钩子"。
- **冲突走人物不走背景**：科武世界设定密集，最容易掉进"百科式描写"陷阱。规则可直接翻译为"设定随事件释放，不开专章"。
- **换地图后拖**：从地球→近地轨道→深空→异星，分段释放，每段先把人物事件做完再迁移，避免"换星球=换书"。
- **主角视角锁定**：科幻多POV是英美套路，番茄读者吃不消，前期严格单视角。
- **数据驱动改稿**：科武类差评常见"设定看不懂/装逼/掉书袋"，先看追更数据再决定要不要降设定密度。

### ⚠️ 不可硬套点
- "新人不换地图" → 科幻天然要换世界，**不能完全照搬**；折中方案：把"地图"理解为"核心冲突阵营"，阵营不换、地理可换。
- "悬念越快越好" → 科幻硬核谜题（如世界规则真相）揭晓过早会塌世界观，需要比言情更长的悬念周期，照搬"读者催就给"的反例对科武尤其致命。
- "配角视角少用" → 科武的反派/势力线偶尔需要切视角推动宏观威胁感；可保留，但严格压缩在"几百字、有记忆点、推主线"三条件内。
- 女频言情的"虐点拉扯"模型不要硬移植到科武主线，可用于副CP或情感支线。

## 4. 编辑检查表（10条）

1. 当前章节里，是否同时存在 ≥2 条活跃悬念线？
2. 下一根悬念的人物/物件，是否已在前3章露过面？
3. 本次"换地图"是事件驱动还是作者驱动？读者会察觉吗？
4. 本章环境/设定描写是否超过事件描写篇幅？超过即砍。
5. 是否出现非主角视角？若出现，长度是否≤几百字、是否推主线？
6. 主角是否全程在场或在感知范围内？
7. 评论区差评属于"常识bug"还是"节奏施压"？后者一律忽略。
8. 追更/留存曲线是否在本卷出现下滑？下滑点对应哪个剧情动作？
9. 大悬念揭晓章的下一章，是否已经有新钩子起势？
10. 是否在20万字左右的高危段做了悬念库存盘点？

## 5. 对作家角色的输入要求

写作时每个关键场景需向编辑提交以下五元组，缺一不可：

| 维度 | 要求 | 科武示例 |
|---|---|---|
| **动作链** | 主角动作必须是连续可分解的"决策→执行→结果"序列，不允许跳步 | 启动外骨骼→锁定标靶→武意灌注→击发→后坐反震 |
| **物理反馈** | 任何科技/武道动作必须有可感知的身体或环境回馈，禁止抽象描述 | 神经接口过载→视野泛红→鼻血→冷却液气化 |
| **代价** | 每次能力使用、每次胜利必须扣血（体能/寿命/装备/关系/信誉/资源） | 一次"武纪共振"=三天瘫痪 + 武纹折损1阶 |
| **钩子** | 章末必留一个未解项（小钩），每3–5章推进一个中钩，每卷收束一个大钩并开新大钩 | 章末：发现敌方尸体里有自己的基因序列 |
| **读者预期** | 明确告知编辑：本章要让读者"想看下一章的是什么问题"，一句话写清 | "读者此刻最想知道：母舰里那道声音到底是不是父亲" |

> 提交标准：任一章节如无法填满上述五格，视为草稿，不进入编辑评估。
