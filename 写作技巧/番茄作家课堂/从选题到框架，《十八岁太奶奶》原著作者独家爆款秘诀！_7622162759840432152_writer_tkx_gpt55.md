## 0. 本补丁一句话

**写每章时，不先解释世界观，先让人物带着标签、反差、冲突和代价做事；每章必须产出一个情绪峰值和一个能接下一章的钩子。**

---

# 1. 作家OS核心更新

## 1.1 选题启动规则

### 必填判断

每个新篇章/新副本/短故事开写前，先回答：

1. **这篇的主情绪是什么？**  
   - 爽 / 燃 / 虐 / 暖 / 悬 / 反转  
   - 只能主打一个，其他为辅。

2. **主角一句话标签是什么？**  
   - 格式：  
     **身份标签 + 能力标签 + 反差标签**  
   - 例：  
     “禁区科学家 × 近战武者 × 害怕失控”  
     “狼化少年 × 失忆猎手 × 不敢杀人”

3. **核心冲突是否低门槛？**  
   - 读者不用看设定说明，也能懂：  
     谁欺负谁？  
     谁背叛谁？  
     谁要救谁？  
     谁必须付出代价？

4. **场景是否集中？**  
   - 短故事：1–2个核心场景。  
   - 狼人篇：村镇 / 地下室 / 森林 / 审判场，最多3个。  
   - 科武长篇单卷：基地 / 城邦 / 遗迹，默认≤3个常驻地。

5. **有没有可截图名场面？**  
   - 每10–15章必须预埋1个。  
   - 短故事至少1个。  
   - 狼人篇必须有“变身/审判/猎杀/身份揭穿”类场面。  
   - 科武长篇必须有“突破/对轰/献祭/文明抉择”类场面。

# 2. 写作执行动作

## 2.1 开篇300字动作补丁

开篇300字必须交付：

| 项目 | 执行动作 |
|---|---|
| 主角标签 | 用动作暴露身份，不用介绍 |
| 反差点 | 让主角做一个与身份不匹配的动作 |
| 可视化冲突 | 出现能看见的压迫、伤害、威胁或对撞 |
| 情绪方向 | 让读者知道这一章是爽、燃、虐、暖还是悬 |
| 设定植入 | 设定只能藏在动作、台词、伤痕、装备、环境反应里 |

### 禁止开篇

- 禁止大段世界观。
- 禁止主角站着想。
- 禁止回忆开头超过3行。
- 禁止“很多年前”“这个世界分为……”式说明。
- 禁止先讲体系，再讲人。

### 推荐开篇句式

- “警报响起时，林烬还在给自己的断骨上螺丝。”
- “所有人都以为她是废武者，直到测试舱被她一拳打穿。”
- “狼人跪在神父面前，嘴里却叼着审判官的银戒。”
- “基地第七层爆炸，唯一没逃的人，是那个被判定为文职的科学家。”

# 3. 动作链补丁

## 3.1 每个关键冲突必须写成“三段动作链”

格式：

> **动作 → 对方反应 → 新动作升级**

### 示例：科武长篇

- 动作：主角关闭反应炉，徒手接住暴走能量。  
- 反应：守卫以为他叛变，枪口全部转向他。  
- 新动作：他把能量压进断臂义肢，义肢当场熔化，却挡住了爆炸。

### 示例：短故事/狼人篇

- 动作：少女在月圆夜锁住自己。  
- 反应：村民听见屋内兽吼，举火把围门。  
- 新动作：她咬断锁链，却没有扑向人群，而是扑向屋顶真正的怪物。

---

## 3.2 禁止用心理独白替代动作

### 错误写法

> 他很痛苦。他知道自己不能输。他想起师父的话，心中燃起斗志。

### OS修正

> 他咬碎了半颗牙，把断裂的刀柄塞进掌心。血顺着刀纹亮起，师父刻下的旧阵第一次被激活。

# 4. 物理反馈补丁

## 4.1 科武体系必须有反馈

每次出招、突破、受伤、觉醒，都必须至少写一种反馈：

| 类型 | 可写反馈 |
|---|---|
| 身体反馈 | 骨裂、内脏震荡、神经灼痛、失明、脱力、记忆缺损 |
| 环境反馈 | 墙体龟裂、金属熔化、地面结晶、空气电离、仪器爆表 |
| 能量反馈 | 光纹逆流、武脉断续、反应堆过载、污染指数上升 |
| 关系反馈 | 被怀疑、被隔离、失去信任、欠下人情、暴露身份 |
| 规则反馈 | 触发禁令、违反军规、引来监察、开启旧时代封锁 |

### 硬规则

**没有反馈的力量 = 没有重量。**

# 5. 代价补丁

## 5.1 每个胜利必须付费

胜利后必须回答：

| 胜利类型 | 必须付出的代价 |
|---|---|
| 打赢敌人 | 受伤 / 暴露底牌 / 损坏装备 / 激怒更强敌 |
| 救下同伴 | 耽误任务 / 欠下承诺 / 被迫牺牲资源 |
| 获得力量 | 身体反噬 / 精神污染 / 伦理边界动摇 |
| 揭开真相 | 关系破裂 / 信仰崩塌 / 被势力追杀 |
| 完成突破 | 消耗寿命 / 失控风险 / 留下不可逆痕迹 |

### 章内最低要求

一章至少出现一个明确代价，哪怕只是埋伏笔。

### 代价句模板

- “他赢了，但右手再也握不稳刀。”
- “基地保住了，监察名单上却多了他的名字。”
- “她救回了弟弟，也让全村知道了自己是狼人。”
- “那一拳打碎了敌人的护甲，也打碎了他最后一层人类神经屏障。”

# 6. 人物口吻补丁

## 6.1 每个核心人物只保留2–3个标签

格式：

> **人物名：身份标签 / 行为标签 / 反差标签**

### 科武长篇可用模板

| 类型 | 标签组合 | 口吻 |
|---|---|---|
| 科学家武者 | 理论派 / 近战狠人 / 害怕失控 | 冷静、短句、常用数据压情绪 |
| 旧时代守护者 | 古武遗民 / 规则执念 / 对新人心软 | 像训话，带旧时代词汇 |
| 女指挥官 | 军纪铁血 / 护短 / 私下嘴毒 | 命令式，少解释 |
| 反派研究员 | 理性极端 / 救世妄想 / 不承认自己残忍 | 温和礼貌，但内容冷酷 |
| 少年武者 | 热血 / 不服输 / 害怕被抛弃 | 句子冲，常顶嘴 |

### 狼人篇可用模板

| 类型 | 标签组合 | 口吻 |
|---|---|---|
| 狼人主角 | 野性 / 自责 / 护短 | 压着怒气，嗅觉、血味词多 |
| 猎人 | 冷硬 / 职业洁癖 / 旧伤 | 短句，判断句多 |
| 村民领袖 | 伪善 / 恐惧 / 控制欲 | 站在“大家好”的道德高地说话 |
| 被保护者 | 天真 / 依赖 / 关键时刻勇敢 | 前期软，后期一句话刺破真相 |

---

## 6.2 反差必须落在行为上

### 弱反差

> 他其实很温柔。

### 强反差

> 他刚把敌人的喉骨捏碎，转身却用沾血的手背挡住孩子的眼睛。

### 科武反差可借点

- 科学家不讲理论，直接上战场肉搏。
- 最强武者看见实验舱会手抖。
- 冷血指挥官偷偷修改阵亡名单，让牺牲者家属多拿补偿。
- 反派救世者杀人前会认真道歉。

### 狼人篇可借点

- 狼人闻到血味会失控，却主动咬住自己的手腕。
- 猎人最痛恨怪物，却替狼人隐瞒身份。
- 被献祭的少女不是猎物，而是猎杀者。
- 村民口口声声要正义，真正怪物却藏在人群里。

# 7. 段落节奏补丁

## 7.1 单章节奏结构

推荐章内比例：

| 段落 | 功能 | 字数占比 |
|---|---|---|
| 1 | 直接入冲突，给情绪方向 | 15% |
| 2 | 动作链推进，人物做选择 | 35% |
| 3 | 冲突升级，出现代价或反噬 | 30% |
| 4 | 情绪峰值，名句/名场面 | 15% |
| 5 | 章末钩子，指向下一章 | 5% |

---

## 7.2 段落长度控制

### 动作段

- 句子短。
- 多动词。
- 少形容。
- 一段不超过4行。

### 情绪段

- 可以慢半拍。
- 用身体反应承接情绪。
- 不要连续抒情超过2段。

### 设定段

- 最多3行。
- 必须夹在动作后。
- 设定出现后，立刻用后果验证。

### 对话段

- 每句尽量短。
- 保留冲突。
- 不让角色互相讲百科。

# 8. 章末钩子补丁

## 8.1 钩子三选一

| 类型 | 用法 | 示例 |
|---|---|---|
| 信息缺口 | 揭一半，留一半 | “检测报告最后一栏写着：样本来源——林烬本人。” |
| 情绪悬置 | 人物关系卡住 | “她终于喊了他一声师父，却是在举刀之前。” |
| 即将冲突 | 下一章马上打/审/逃/揭穿 | “门外，监察队的枪口已经对准了病房。” |

---

## 8.2 禁止空钩子

### 禁止

- “真正的风暴才刚刚开始。”
- “一切都变得扑朔迷离。”
- “没人知道，危险正在靠近。”

### 改成

- “三分钟后，第一台失控机甲撞进了他们所在的楼层。”
- “她刚关上门，门外就响起了父亲的声音：‘把狼交出来。’”
- “通讯器亮起，里面传来已死师兄的声音。”

# 9. 名场面补丁

## 9.1 名场面判定

一个场面能不能留，问四个问题：

1. 能不能截图传播？
2. 有没有一句短、狠、有反差的台词？
3. 有没有强动作或强画面？
4. 是否贴合本卷内核，而不是单纯耍帅？

---

## 9.2 科武长篇可借点

### 名场面类型

- 科学家脱下白大褂，露出满身武纹。
- 主角用实验公式破解敌人拳法。
- 城邦上空，旧时代武碑重新亮起。
- 主角突破成功，但污染指数同步飙升。
- 师父用最后一口气，把武脉传承烧进主角骨头。
- 主角站在反应炉中心，对全城说：“今天开始，力量不再属于神。”

### 可用台词

- “我不是来证明武道正确，我是来证明你错了。”
- “数据不会骗人，但人会为了数据杀人。”
- “这一拳的代价，我付得起。”
- “旧时代没死，只是轮到我们还债了。”
- “别叫我救世主，我只是还没找到更便宜的办法。”

---

## 9.3 短故事/狼人篇可借点

### 名场面类型

- 月圆夜，主角主动锁住自己，却被人类打开锁链。
- 狼人跪在神像前，影子却是巨狼。
- 猎人把银弹从枪里退出来，递给狼人。
- 村民审判狼人时，真正的怪物在人群中变形。
- 主角咬断自己的兽爪，换回最后一句人话。
- 小孩抱住狼人，说：“你身上不是怪物的味道，是回家的味道。”

### 可用台词

- “我怕的不是变成狼，是你们一直都是人。”
- “银弹杀不了怪物，只能杀掉你们想杀的人。”
- “今晚如果我失控，别救我，跑。”
- “我闻得见谎言，比血更腥。”
- “怪物在月亮下变形，人在人群里变形。”

# 10. 平台规则 → 发布/包装/风险门禁

## 10.1 发布门禁

发布前检查：

| 项目 | 通过标准 | 风险 |
|---|---|---|
| 价值导向 | 守护、传承、成长、责任、女性力量、家国大爱 | 纯黑暗、纯报复、无正向落点 |
| 情爱比例 | 情感线服务主线 | 情爱喧宾夺主，冲淡科武/热血/亲情 |
| 逆袭逻辑 | 能力有来源，升级有代价 | 无脑开挂，悬浮爽 |
| 暴力描写 | 有剧情功能，不猎奇 | 过度血腥、虐杀细节堆砌 |
| 伦理冲突 | 有反思，有后果 | 把危险实验、牺牲他人合理化 |
| 人设包装 | 标签清晰，反差可见 | 标签过多，记不住 |
| 封面/标题 | 突出冲突和反差 | 标题过玄、世界观词太多 |

---

## 10.2 包装建议

### 科武长篇标题/简介关键词

可用：

- 科学家
- 武者
- 禁区
- 旧时代
- 反应炉
- 传承
- 失控
- 文明代价
- 城邦守护
- 机甲/武脉/遗迹

避免：

- 过多专有名词。
- 一句话塞三层设定。
- 标题只讲世界，不讲人。

### 短故事/狼人篇包装关键词

可用：

- 月圆夜
- 狼人
- 猎人
- 审判
- 村庄秘密
- 银弹
- 变身
- 人性反转
- 被献祭的新娘/少女/孩子

避免：

- 纯怪物猎奇。
- 无情感锚点。
- 没有身份反差。

# 12. 章节自检清单

每章交稿前逐条打勾。

## 12.1 基础通过线

- [ ] 前300字内，主角已经在做事。
- [ ] 前300字内，出现了可视化冲突。
- [ ] 没有用大段世界观开篇。
- [ ] 本章主情绪明确：爽 / 燃 / 虐 / 暖 / 悬 / 反转。
- [ ] 本章至少有一个动作链：动作 → 反应 → 升级动作。
- [ ] 本章至少有一个物理反馈。
- [ ] 本章至少有一个代价。
- [ ] 本章结尾有具体钩子，不是空泛预告。
- [ ] 下一章开头能直接承接本章钩子。
- [ ] 本章截出来给陌生读者，3分钟内能感受到情绪冲击。

---

## 12.2 人物检查

- [ ] 核心人物标签≤3个。
- [ ] 主角反差点通过行为表现出来。
- [ ] 配角不是纯工具人，至少有一个可记忆标签。
- [ ] 反派/对手有自己的逻辑，不只是坏。
- [ ] 人物口吻区分明显。

---

## 12.3 科武长篇专项检查

- [ ] 能力有来源。
- [ ] 升级有代价。
- [ ] 科技/武道设定通过动作或台词呈现。
- [ ] 本章没有为了爽点破坏设定自洽。
- [ ] 冲突不只停留在打赢，还推动了文明、势力、伦理或传承线。
- [ ] 场景没有无意义扩张。
- [ ] 本卷常驻地仍控制在3个左右。
- [ ] 每10–15章有一个名场面规划。

---

## 12.4 短故事/狼人篇专项检查

- [ ] 场景集中，读者不用记复杂地图。
- [ ] 身份反差清晰：人/狼、猎人/保护者、怪物/受害者。
- [ ] 至少有一个身份揭穿或误解逆转。
- [ ] 狼化/猎杀/审判场面有视觉冲击。
- [ ] 恐怖或血腥描写服务情绪，不做猎奇堆砌。
- [ ] 结尾有情绪落点，不只是反转。

---

## 12.5 发布/包装风险门禁

- [ ] 标题/简介能看出人物反差和核心冲突。
- [ ] 没有堆专有名词。
- [ ] 没有无来源开挂。
- [ ] 没有把危险实验、牺牲无辜写成理所当然。
- [ ] 没有让情爱线压过主线。
- [ ] 没有过度狗血或价值观偏移。
- [ ] 正向落点明确：守护、传承、责任、成长、家国、女性力量等。

# 13. 最终执行口令

写作时按这条跑：

> **标签出场 → 反差动作 → 可视冲突 → 动作链升级 → 物理反馈 → 胜利付费 → 情绪峰值 → 具体钩子。**

如果某章写不动，优先补这四个：

1. 主角现在要做什么？
2. 谁阻止他？
3. 他赢或输要付出什么？
4. 结尾让读者担心/期待下一章的具体事件是什么？
