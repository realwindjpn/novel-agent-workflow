# 《科武纪元》编辑学习手册：基于《冰糖炖雪梨》入驻专访的实战提炼

## 1 课程核心判断（≤6条）
1. **题材孵化公式**：核心人物关系梗（如竹马→死对头→天降）+ 时代/热点锚点（如冬奥契机）= 高转化题材。
2. **高门槛题材红线**：竞技/科幻/强设定类严禁新人首开，需先跑通“剧情线+感情线+底层逻辑”的融合能力。
3. **细节真实来源**：“观察派”优于“体验派”。真实感不依赖亲历，依赖对现实行为、物理交互、情绪反应的拆解与重组。
4. **大纲动态属性**：前期重灵感推进，中后期为运营/版权/长篇结构补写大纲。大纲是导航仪，不是铁轨。
5. **情绪价值优先**：读者体验（爽/燃/甜）是核心交付物，主题表达是副产品。强行说教或扭转天然文风必崩盘。
6. **版权前置思维**：创作期即预留影视化接口（强视觉场景、清晰人物弧光、单元式高潮），中后期按版权方需求结构化。

## 2 可执行编辑规则
| 模块 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 3章内亮出“核心关系张力+短期目标”。禁用设定说明书，用具体场景（训练/冲突/危机）带出世界观。 |
| **节奏** | 高潮段落（比赛/战斗/突破）必须“带激情写”（情绪密度拉满、句式短促、动词密集）；日常段落负责逻辑铺垫与感情发酵，张弛比控制在 3:7。 |
| **冲突** | 剧情戏与感情戏必须同频共振。冲突设计需严格遵循“人设动机+物理/社会逻辑”，禁用机械降神或为虐而虐。 |
| **人物** | 拒绝现实原型照搬。主角需具备“迎难而上”的核心驱动力；配角功能明确（顾问/对照/推手），不抢主线叙事带宽。 |
| **题材** | 跨界融合需先跑通基础类型逻辑，再叠加新元素。资料查阅需“买书+深度检索+交叉验证”，禁用碎片化网文拼凑。 |
| **改编** | 每卷预留2-3个“强视觉/强动作”名场面；人物弧光需完整（起点-受挫-蜕变-兑现）；中后期补写“主线任务+副本结构”大纲以对接版权评估。 |
| **平台规则** | 番茄生态重“情绪直给+追读留存”。开篇钩子需明确，评分/在读数据反哺内容微调。接受“非全员喜欢”，聚焦核心受众基本盘。 |

## 3 科武适配：可用点、不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **观察派资料法**：科幻设定/武道体系需查阅硬核文献（材料学/流体力学/运动生理学/军事战术），用现实物理逻辑支撑幻想，增强“科武”可信度。
- **动态大纲机制**：科幻长篇易卡设定，前期可随灵感推进单章，但每10万字必须收束为“主线目标+能量体系边界+势力格局”结构化大纲，防断更。
- **情绪优先原则**：科武文易陷“设定说明书”陷阱。需将科技突破/武道境界转化为“角色生存/尊严/羁绊”的直接冲突，用情绪带设定。
- **热点锚定策略**：结合AI自主进化、近地轨道资源争夺、基因编辑伦理等现实科技议题，赋予“科武”时代共鸣与话题性。

### ❌ 不可硬套点（需规避或改造）
- **“甜而不腻/佛系心态”**：科武文需强目标感与生存压力。过度轻松/随缘会削弱史诗感与危机张力，需改为“高压下的克制幽默”或“战友羁绊”。
- **“不写大纲/随时改”**：科幻长篇逻辑链极长，随意推翻核心设定会导致战力崩坏/前后矛盾。必须“核心设定锁死，情节大纲弹性”。
- **“竞技激情写法”直接平移**：科武战斗需兼顾“物理规则/能量体系/战术博弈”。纯情绪渲染易变“对波流水账”，需加入“环境交互/装备损耗/战术反制”。

## 4 编辑检查表（10条以内）
1. 前3章是否出现“核心人物关系+明确短期目标”？无纯设定堆砌。
2. 科幻/武道设定是否通过“动作/冲突/环境交互”自然展现，而非旁白解说？
3. 高潮段落是否具备情绪密度与可感知的物理反馈细节？
4. 感情线/剧情线是否同频推进？有无割裂或工具人化配角？
5. 资料引用是否经过逻辑自洽处理？有无“伪科学/反常识”硬伤？
6. 主角驱动力是否贯穿始终？有无“被动推剧情”或“降智妥协”？
7. 单元结构是否预留“视觉化/影视化”强场景？（便于版权评估）
8. 每章结尾是否设置有效钩子（悬念/反转/危机升级）？禁用纯抒情收尾。
9. 文风是否统一？有无作者强行扭转基调导致割裂？
10. 数据反馈（读完率/段评/追读）是否指向明确问题？有无针对性微调？

## 5 对作家角色的输入要求
| 维度 | 执行标准（科武向） |
|:---|:---|
| **动作链** | 战斗/突破必须拆解为“起势-发力-受击-变招-决胜”完整链条。禁用“一招秒杀”或“意念对波”。需体现科武体系的战术博弈与能量流转路径。 |
| **物理反馈** | 所有超常能力/科技装备必须附带可感知的物理代价与环境交互（例：外骨骼过载致肌肉撕裂、重力场扭曲引发内脏压迫、能量武器后坐力破坏掩体）。拒绝“无损耗施法”。 |
| **代价** | 每次力量跃升/关键抉择必须支付明确代价（生理损伤、资源枯竭、人际关系破裂、道德困境）。代价需推动后续剧情，非一次性消耗品。 |
| **钩子** | 章末钩子需满足“信息差+生存危机+选择困境”三要素之一。必须与主线目标强绑定，禁用无关日常或情绪抒情收尾。 |
| **读者预期** | 明确本卷/本阶段核心承诺（如：机甲首战/武道破境/阵营反转）。每10章兑现一次小预期，每30章兑现大预期。严禁“预告欺诈”或“无限延期”。 |
