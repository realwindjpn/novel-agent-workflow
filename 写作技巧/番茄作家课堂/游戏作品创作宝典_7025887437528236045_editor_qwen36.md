# 《科武纪元》编辑学习官：《游戏作品创作宝典》规则提炼

## 1 课程核心判断（≤6条）
1. **故事性＞设定堆砌**：世界观与规则必须依附情节推进，开篇严禁说明书式输出，需通过事件/任务自然带出。
2. **爽感前置与具象化**：前三章必须完成金手指激活与小高潮闭环；每次升级需绑定明确目标、具象奖励及对比衬托。
3. **人物弧光＞数值膨胀**：成长线不可沦为“升级机器”，需通过进程映射主角心智、价值观或现实处境的蜕变。
4. **类型定调决定写法**：虚拟网游重规则新奇与反差；游戏异界重生存逻辑与代入；竞技重现实逻辑与群像热血；轻小说重二次元画风、心理细腻与轻松节奏。
5. **设定降维与共识借用**：复杂体系需做减法，优先使用读者已有认知框架（如系统面板、常见术语）降低理解成本，新设定随剧情按需释放。
6. **平台向节奏与价值观**：行文需快节奏、强钩子，紧跟热点/网感；核心基调必须积极向上，避免无意义戾气或过度致郁。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提取） |
|:---|:---|
| **开篇** | 禁用纯设定说明。采用“新奇/诡异事件切入”或“直接执行任务”带出规则；仅解释当前情节强相关的1-2个核心术语，其余延后。 |
| **节奏** | 第3章前必须触发金手指并完成首次破局/打脸小高潮；升级周期需压缩，避免单一等级线拖沓；轻小说/热点稿需加快场景切换频率。 |
| **冲突** | 以“信息差/资源差/金手指独特性”构建对比爽感；每次冲突需绑定明确奖励与下一阶段目标，杜绝无目的游荡。 |
| **人物** | 长篇/竞技需设计“跌落-重塑-登顶”或“天才-受挫-蜕变”的曲折成长线；配角需具备功能性（如战术支点）；轻小说主角需强化青春期心理描写与标签化特质。 |
| **题材** | 鼓励“系统/面板+X”融合（如科武+科幻/玄幻）；异界类需强化生存法则合理性；竞技类需贴近现实逻辑与生活化共鸣桥段。 |
| **改编** | 优先保留高视觉化、强规则感的场景（如面板提示、技能特效、战术博弈）；弱化纯心理独白与抽象设定，强化动作链与空间调度。 |
| **平台规则** | 首屏/前三章留存率定生死；金手指需“独特且直观”；尺度把控：主体积极向上，玩梗需紧跟时事但避免低俗或过度解构。 |

## 3 科武适配
### ✅ 可用点
- **系统面板/数据化转化**：可直接映射为《科武纪元》的“基因锁同步率/义体算力/武学算法”，利用游戏文的“共识术语”降低科幻设定理解门槛。
- **节奏与爽感结构**：前三章金手指破局、升级奖励具象化、术语随剧情释放等规则，完全适配长篇科幻武道的连载留存逻辑。
- **人物弧光绑定**：用“科技迭代/武道心境”替代纯战力堆叠，纠正科武文常见的“唯数值论”，符合原文“成长≠升级”的核心判断。
- **高视觉化战斗**：规则化战斗（如能量阈值、战术配合、技能CD）天然契合科武的机甲/古武/异能描写，利于IP改编与画面呈现。

### 🚫 不可硬套点
- **“虚拟网游现实界限清晰”**：科武需现实与高武/科幻世界深度交织，危机必须具现实破坏力，不可用“登出/下线/安全区”消解张力。
- **轻小说“日常少戾气”基调**：科武长篇需维持生存压迫感与史诗尺度，过度玩梗或降智日常会破坏科幻武道的严肃性与世界观厚度。
- **竞技类“多人团队体育逻辑”**：若《科武纪元》侧重个人武道突破或星际单兵作战，强行套用电竞团队配合/教练战术会偏离主线。
- **“游戏共识术语”直接套用**：科武自创的“灵能/曲率引擎/基因序列”需建立独立逻辑，不能简单替换网游黑话，否则会产生严重出戏感。

## 4 编辑检查表（10条以内）
1. [ ] 开篇前3000字是否无大段设定/术语堆砌？核心规则是否通过事件/动作自然展现？
2. [ ] 第3章前是否完成金手指激活+首次小高潮（破局/越级/打脸）？
3. [ ] 每次升级/突破是否附带明确奖励、目标及对比衬托（爽感可视化）？
4. [ ] 主角成长是否体现心智/价值观/现实处境的弧光，而非纯数值叠加？
5. [ ] 新术语/新设定是否仅在当前情节必需时解释，且单次≤2个？
6. [ ] 冲突是否绑定清晰目标与代价？是否存在无目的游荡或水字数？
7. [ ] 战斗/行动描写是否具备高视觉化与空间调度感（适配改编潜力）？
8. [ ] 整体基调是否积极向上？玩梗/热点是否自然且不破坏主线严肃性？
9. [ ] 配角是否具备独立功能或成长线？（长篇/群像向必查）
10. [ ] 章节末尾是否设置有效钩子（悬念/危机/奖励预告）以拉动追读？

## 5 对作家角色的输入要求
| 维度 | 输入规范（强制） |
|:---|:---|
| **动作链** | 必须明确“触发条件→执行序列→结果判定”闭环。科武战斗禁止“对波式”抽象描写，需拆解为“侦察/起手/变招/反制/终结”的物理步骤，每一步需符合当前科技/武道设定逻辑。 |
| **物理反馈** | 强制绑定感官数据与力学现象。如义体过载的神经痛觉、重力场变形的骨骼压迫、能量武器击穿护甲的冲击波扩散。用具体物理现象替代“威力巨大”“非常强”等虚词。 |
| **代价** | 必须标注“能力/突破的硬性限制”。金手指或高阶武技不可无消耗使用，需明确冷却期、资源枯竭、基因反噬、现实牵连等代价，确保冲突有真实风险与博弈空间。 |
| **钩子** | 每章末/关键节点预设“未闭合信息”。形式可为：突发危机倒计时、隐藏面板提示、敌对势力动向、未兑现的奖励承诺。钩子必须与下一章核心动作直接挂钩，禁止断在情绪平复处。 |
| **读者预期** | 前置“类型承诺”。开篇3章内必须兑现科武核心卖点（科幻设定+武道爽感），后续可在此基础上做合理反转或升维，严禁前期承诺“硬核科幻”后期滑向“纯玄幻修仙”导致预期违约。 |
