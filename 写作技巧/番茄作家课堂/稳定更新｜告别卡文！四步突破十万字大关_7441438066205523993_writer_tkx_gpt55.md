# 《科武纪元》作家OS补丁  
## 稳定更新｜四步突破十万字大关

> 补丁目标：防卡文、防水文、防断更，把“灵感写作”改成“结构推进”。

---

## 0. 核心执行令

### 写作中遇到卡文时，不许做：

- 不许水日常。
- 不许让角色原地聊天解释设定。
- 不许反复内心独白。
- 不许用“他震惊了”“众人骇然”凑爽点。
- 不许为了换地图而换地图。

### 卡文时立刻做：

1. **检查当前目标是否完成。**
   - 完成了：立刻放出更大敌人、更高文明、更深真相。
   - 没完成：增加倒计时、损失、背叛、外部干扰。

2. **检查本章是否有动作链。**
   - 没有动作链：补一个“侦测→判断→出手→反馈→代价”。

3. **检查是否该换模块。**
   - 当前场景榨干：换地理空间、势力空间、身份空间、科技层级。
   - 换地图必须由冲突驱动。

4. **检查是否兑现上一章钩子。**
   - 没兑现：本章至少兑现一半。
   - 不能连续三章只埋不拆。

# 1. 四步突破十万字：作家OS执行版

## 第一步：开局抛包袱，但不立刻拆

### 执行动作

章首300字内必须出现以下至少一种：

| 类型 | 执行动作 |
|---|---|
| 信息异常 | 主角发现旧时代遗迹数据与官方历史冲突 |
| 身体异常 | 主角武道检测值失真，仪器报警 |
| 敌意出现 | 某势力突然封锁考场、矿区、学院、星港 |
| 规则破裂 | 常识中的科技/武道法则被现场打破 |
| 代价预告 | 主角赢了，但监测器显示寿命、神经、能量出现不可逆损耗 |

### 科武写法示例

不要写：

> 林曜感觉这件事不简单。

改成：

> 检测舱红光连闪三次。  
> 屏幕上，林曜的气血值停在“12.7”。  
> 下一秒，数字被系统强行抹除，替换成一行灰色警告：  
> 【该样本不允许公开评级。】

### 失败模式

- 开篇解释世界观三页。
- 开篇主角醒来、洗漱、上学、闲聊。
- 开篇给出谜团，下一段马上解释干净。
- 开篇没有危险、没有欲望、没有异常。

### 章首节奏

推荐节奏：

> 异常出现 → 角色误判 → 更强反馈 → 暂不解释 → 推进事件

## 第二步：爽点重笔，过渡压缩

### 执行动作

每章判断场景性质：

| 场景 | 字数策略 |
|---|---|
| 突破、战斗、打脸、揭真相 | 重笔，细写动作、反馈、代价 |
| 赶路、说明、普通对话 | 压缩，一段带过 |
| 设定首次出现 | 用感官化解释，不写百科 |
| 章节过渡 | 只保留必要信息 |

### 爽点必须包含四件事

1. **动作链**
   - 蓄力→踏碎地面→破盾→反震→吐血→再压一步。

2. **物理反馈**
   - 温度、声音、震动、读数、裂痕、血氧、神经负荷。

3. **旁观者误判**
   - 敌人以为主角只能挡一击，结果主角反向吞噬能量。

4. **代价账单**
   - 胜利后能源归零、经脉裂开、身份暴露、高维注视降临。

### 科武长篇可借点

- 武道突破必须让读者“看见”：
  - 骨骼震鸣。
  - 气血沸腾。
  - 纳米护甲熔边。
  - 力场读数爆表。
  - 监控系统误判为小型爆炸。

- 科技压制必须让读者“看懂”：
  - 敌方护盾数值下降。
  - 算力被抢占。
  - 能量回路被反写。
  - 武道动作绕开科技预判。

### 失败模式

- 爽点一笔带过。
- 反派只会震惊。
- 主角胜利无代价。
- 能力没有环境反馈。
- 设定只靠名词堆砌。

## 第三步：目标完成后，立刻制造更大困境

### 执行动作

每个小目标完成后，必须接一个升级冲突。

| 已完成目标 | 立刻接上的更大困境 |
|---|---|
| 主角赢下学院考核 | 被军方/财阀/研究所盯上 |
| 主角杀死低级反派 | 发现对方只是实验体 |
| 主角获得遗迹技术 | 技术带有定位信标 |
| 主角突破境界 | 引发旧纪元封印响应 |
| 主角救下同伴 | 同伴体内藏着敌方协议 |
| 主角逃出城市 | 城外才是真正实验场 |

### 科武主循环

推荐循环：

> 目标 → 行动 → 胜利 → 代价 → 暴露 → 更高层敌人 → 新目标

示例：

> 林曜突破“钢骨境”  
> → 击穿装甲兽  
> → 救下矿区少年  
> → 右臂神经烧毁17%  
> → 旧时代芯片自动上线  
> → 卫星捕捉到禁忌频段  
> → 星环议会将他列为“文明污染源”。

### 短故事/狼人篇可借点

可借：

- **单一目标强推进**：狼人篇适合“一夜内找出狼人/活下去/反杀”。
- **身份反转**：谁是狼人、谁是猎人、谁被感染。
- **有限场景高压**：村庄、古堡、实验站、飞船密闭舱。
- **章末钩子密集**：每章死一个人、发现一个谎言、身份翻一次。

不可直接硬套到科武长篇：

- 不要让全书只靠“谁是内鬼”撑。
- 不要每章都靠死亡制造刺激，长篇要靠升级、势力、技术、文明谜团扩容。

### 失败模式

- 一个仇报完，故事没了。
- 打完副本，主角没有新目标。
- 反派被击败后不引出上层势力。
- 地图换了，但冲突没有升级。

|---|---|
| 正文 | 至少完成1章或半章 |

| 复盘 | 标记本章兑现了什么、埋了什么 |
| 存稿 | 至少保留3-7章安全垫 |

### 日更作业格式

每天结束前必须留下：

```text
明日章：
目标：
开篇钩子：
动作链：
爽点：
代价：

```

### 卡文急救指令

如果写不下去，按顺序执行：

1. 让敌人提前出现。
2. 让代价提前爆发。
3. 让配角暴露隐藏身份。
4. 让主角拿到的奖励变成危险源。
5. 换到更高压地图。
6. 砍掉解释段，改成现场测试。
7. 把对话改成冲突对话。
8. 让上一章钩子在本章兑现一半。

# 2. 《科武纪元》动作、反馈、代价标准

## 2.1 动作链标准

每个关键场面必须能写成：

```text
观察 → 判断 → 出手 → 碰撞 → 反馈 → 代价 → 新变化
```

### 示例

```text
扫描敌方护盾 → 判断频率漏洞 → 气血灌入右臂 → 拳锋切入力场 → 护盾读数暴跌 → 主角腕骨裂开 → 敌方主机锁定主角基因
```

### 禁止

```text
主角很强。
这一击恐怖如斯。
众人都惊呆了。
```

---

## 2.2 物理反馈标准

能力、科技、武道出手时，必须至少出现两类反馈：

| 类型 | 可写反馈 |
|---|---|
| 身体反馈 | 骨裂、耳鸣、血氧下降、神经过载、肌肉撕裂 |
| 环境反馈 | 地面塌陷、空气扭曲、金属熔化、灯光熄灭 |
| 仪器反馈 | 护盾读数、温度曲线、能量阈值、警报等级 |
| 敌人反馈 | 防御变形、战术失效、动作迟滞、意识断层 |
| 旁观反馈 | 误判、恐惧、沉默、转变立场 |

---

## 2.3 代价标准

爽点后必须结账。

| 爽点 | 代价 |
|---|---|
| 越级杀敌 | 身体损伤、身份暴露 |
| 获得技术 | 被技术反向定位 |
| 武道突破 | 境界不稳、寿命燃烧 |
| 救下同伴 | 引来追杀、失去资源 |
| 打脸权贵 | 被规则围剿 |
| 解开真相 | 发现自己也是实验一环 |

### 失败模式

- 主角一直赢，没人能制衡。
- 获得神器后无副作用。
- 反派只负责送资源。
- 代价只停留在“有点累”。

# 3. 人物关系补丁

## 3.1 必须有“又爱又恨”的角色

### 可用人物类型

| 类型 | 功能 |
|---|---|
| 敌对导师 | 欣赏主角天赋，但必须按制度处置他 |
| 财阀继承人 | 和主角利益冲突，但曾被主角救过 |
| 旧时代AI | 帮主角升级，也在改写他的选择 |
| 同源实验体 | 和主角来自同一项目，却走向敌方 |
| 亲近队友 | 忠诚但隐瞒关键身份 |
| 反派科学家 | 手段残酷，但掌握人类存续真相 |

### 人物口吻要求

不同人物说话要有不同“立场味”。

#### 主角林曜类

- 口吻：冷静、短句、行动优先。
- 句式：少解释，多判断。
- 示例：

> “别争。”  
> 林曜扣紧护臂。  
> “护盾还能撑九秒。九秒后，我开路。”

#### 军方角色

- 口吻：命令、编号、风险等级。
- 示例：

> “目标林曜，风险等级暂定B+。”  
> “允许接触，不允许放任。”

#### 科研者

- 口吻：数据、样本、验证。
- 示例：

> “他不是突破。”  
> “他是在复现一套已经失传的进化协议。”

#### 财阀/权贵

- 口吻：资源、规则、交易。
- 示例：

> “你能打穿护盾，不代表你能打穿秩序。”

#### 旧时代AI

- 口吻：平静、非人、提示代价。
- 示例：

> 【本次增幅将烧毁右臂32%的神经束。】  
> 【是否继续？】

---

## 3.2 配角预埋包袱

每个重要配角至少有一个未拆项：

| 配角 | 未拆包袱 |
|---|---|
| 队友 | 为什么能识别旧纪元文字 |
| 导师 | 为什么阻止主角参加高阶测试 |
| 反派 | 为什么不杀主角，只捕获 |
| AI | 为什么对主角基因权限过高 |
| 财阀少女/少主 | 为什么知道灾变前坐标 |
| 流民少年 | 为什么能免疫污染区辐射 |

### 失败模式

- 配角只负责夸主角。
- 配角只负责送装备。
- 配角无秘密、无欲望、无选择。
- 所有人都用同一种语气说话。

# 4. 段落节奏补丁

## 4.1 战斗段

推荐节奏：

```text
短句起手 → 动作连续 → 反馈插入 → 敌人反应 → 主角付代价 → 反转
```

示例：

> 林曜没有退。  
> 他右脚踏碎地砖，气血沿脊柱冲上肩胛。  
> 第一拳砸在护盾上。  
> 蓝色力场只凹陷了一寸。  
> 敌方机甲的炮口已经转向他的胸口。  
> 【神经负荷：71%。】  
> 林曜咬碎口中的血。  
> 第二拳，打在同一个点。

## 4.2 设定段

禁止百科式：

> 星环议会成立于多少年前，拥有多少席位……

改成现场化：

> 星环议会的标志亮起时，整座矿城的通讯都安静了。  
> 连黑市频道都自动切断。  
> 老矿工脸色发白：  
> “别说话。议会在听。”

## 4.3 对话段

对话必须带冲突，不写闲聊。

普通对话：

> “你为什么帮我？”  
> “因为我相信你。”

改成：

> “你为什么帮我？”  
> “因为你死了，我体内那枚定位芯片也会启动。”  
> 她抬起手腕，皮肤下有红光一闪。  
> “林曜，我们现在是一条绳上的两个诱饵。”

# 5. 章末钩子补丁

每章结尾必须留下一个未解项。

## 5.1 三类钩子

| 类型 | 用法 |
|---|---|
| 信息钩 | 揭出半个真相，隐藏关键答案 |
| 行动钩 | 敌人抵达、倒计时开始、主角必须选择 |
| 情感钩 | 同伴背叛、导师隐瞒、亲人关联曝光 |

## 5.2 科武可用章末钩子库

- 检测报告最后一行显示：主角样本编号早在三百年前已登记。
- 敌人临死前说：“你以为你是第一个成功体？”
- 旧时代AI提示：【权限不足。请完成第一次文明级献祭。】
- 星港封锁，通缉令上的罪名不是杀人，而是“非法进化”。
- 主角刚突破，天穹外出现一只观测他的机械眼。
- 同伴摘下面具，露出和主角相同的实验编号。
- 导师烧掉档案，只留下一句话：“别去北境遗迹。”
- 反派被击败后，体内弹出倒计时：00:59:59。
- 获得的武器自动绑定主角生命体征，并开始上传坐标。
- 城市广播响起：“污染等级提升，允许清除所有未登记武者。”

## 5.3 失败模式

- 章末无新问题。
- 钩子和本章内容无关。
- 连续只埋不拆。
- 钩子靠故弄玄虚，不给读者明确期待。

# 7. 章节自检清单

写完每章后，按以下清单检查。

## 7.1 必过项

1. □ 前300字是否出现异常、危险、冲突或悬念？
2. □ 本章是否推进主线，或拆/埋一个重要钩子？
3. □ 本章是否有明确动作链？
4. □ 关键能力/科技是否有物理反馈？
5. □ 爽点是否重笔写，而不是一句带过？
6. □ 胜利后是否付出代价？
7. □ 是否兑现上一章至少一个期待？
8. □ 章末是否留下新期待？
9. □ 是否出现人物关系变化？
10. □ 是否有水文段落，可删则删？

## 7.2 科武专项

1. □ 新术语是否通过场景解释，而不是百科解释？
2. □ 武道力量是否有身体反馈？
3. □ 科技力量是否有读数、系统、装置或环境响应？
4. □ 多势力博弈是否有利益逻辑？
5. □ 主角升级是否引来更高层注意？
6. □ 地图变化是否由冲突驱动？
7. □ 配角是否保留至少3个未拆包袱？
8. □ 反派是否有目的，而不是单纯送经验？
9. □ 本章是否避免“众人震惊”式空爽？
10. □ 本章是否能用一句话说清“发生了什么变化”？

## 7.3 删改判断

出现以下情况，直接删或重写：

- 本章删掉后，主线不受影响。
- 本章没有目标、阻碍、变化。
- 本章只有解释，没有行动。
- 本章只有聊天，没有冲突。
- 本章爽点没有反馈和代价。
- 本章章末没有期待。

# 8. 短故事/狼人篇可借点

## 可借点

1. **密闭空间压迫感**
   - 用于科武中的实验站、遗迹、星舰、地下矿城。

2. **身份怀疑**
   - 谁被污染？
   - 谁是实验体？
   - 谁是AI代理人？
   - 谁携带旧纪元协议？

3. **倒计时机制**
   - 氧气剩余。
   - 护盾崩溃。
   - 感染扩散。
   - 轨道炮锁定。
   - 遗迹自毁。

4. **每章一个反转**
   - 死者不是死于狼人，而是死于队友武器。
   - 猎人其实早被感染。
   - 安全屋才是诱捕舱。

5. **有限人物强关系**
   - 每个人都有秘密。
   - 每个人都有动机。
   - 每个人都可能害主角，也可能救主角。

## 用在《科武纪元》的方式

狼人篇：

> 村庄里有人变成狼人。

科武改法：

> 遗迹小队十人进入禁区。  
> 三小时后，外部系统显示：队伍里多出第十一道生命信号。  
> 但监控画面里，仍然只有十个人。

# 9. 科武长篇可借点

## 9.1 大框架前置

```text
第一阶段：城市/学院/矿区觉醒
第二阶段：区域势力冲突
第三阶段：旧纪元遗迹真相
第四阶段：星环/高等文明介入
第五阶段：主角身份反转或文明级危机
```

## 9.2 换地图机制

地图升级建议：

```text
贫民区/矿城
→ 武道学院/军方基地
→ 污染荒原/旧纪元遗迹
→ 轨道城/星港
→ 外星战场/文明边境
→ 高维实验场
```

每次换地图必须带着：

- 新规则。
- 新敌人。
- 新资源。
- 新代价。
- 新身份压力。

## 9.3 支线储备

可延展支线：

- 旧时代遗民。
- 财阀科技垄断。
- 军方人体实验。
- 武道境界被篡改的历史。
- AI文明残响。
- 星环议会隐藏协议。
- 污染区异变种群。
- 同源实验体不同路线。
- 主角父辈/导师旧案。
- 高维文明观察人类进化。

# 10. 平台规则转化：发布/包装/风险门禁

## 10.1 发布门禁

每章发布前必须检查：

```text
□ 标题无错字
□ 正文无明显错别字
□ 段落不大坨
□ 对话换行清晰
□ 前300字有钩子
□ 章末有钩子
□ 本章无明显水文
□ 本章没有违规描写
□ 本章没有照搬其他作品桥段
□ 本章三观不崩
```

## 10.2 包装门禁

作品包装必须突出：

| 项目 | 要求 |
|---|---|
| 书名 | 能看出科武、升级、纪元感 |
| 简介 | 前100字给出主角异常、世界危机、核心爽点 |
| 标签 | 科幻、武道、进化、热血、升级、文明 |
| 开篇 | 不慢热，直接给异常检测/生死危机/禁忌技术 |
| 卖点 | 科技与武道结合，不只写传统玄幻换皮 |

### 简介方向示例

> 灾变三百年后，人类以武道驾驭科技，以血肉对抗星空。  
> 林曜只是矿城底层武徒，却在一次气血检测中，被系统判定为“不允许公开评级”。  
> 从那天起，军方、财阀、旧纪元AI同时盯上了他。  
> 他们说，他不是天才。  
> 他是三百年前那场文明实验，唯一活到今天的样本。

## 10.3 风险门禁

禁止项：

- 高仿热门作品核心设定。
- 明显抄袭桥段。
- 大段无意义水文。
- 人设毒点：
  - 主角懦弱拖沓。
  - 主角无底线作恶却被强行洗白。
  - 女角色工具化严重。
  - 队友集体降智。
- 逻辑毒点：
  - 主角无理由获得神器。
  - 反派无理由放水。
  - 势力无利益逻辑。
  - 科技设定前后矛盾。
- 发布毒点：
  - 错别字多。
  - 排版混乱。
  - 开篇慢热。
  - 章末无钩子。
