# NASA DSS-14 天线事故 Type A mishap

## 事实核

- 事件：NASA Deep Space Station 14（DSS-14）天线发生 Type A mishap。
- 时间：事故发生 2025-09-16；调查最终报告 2026-04 完成。
- 地点：Goldstone Deep Space Network Complex, Barstow, California。
- 设备：DSS-14，70 m（230 ft）深空通信天线。
- 事故时任务：追踪 Juno 探测器。
- 直接后果：天线过度旋转，导致电缆/结构支撑损坏，消防水管破裂并严重漏水；无人员伤亡。
- 等级：NASA Type A mishap。
- 根因链：软件弱点 + 人为排障绕过软硬件保护 + 液压限位系统旧损伤长期未检测 + 工作压力文化促使操作越界。
- 系统背景：DSN 三站（加州、澳洲、西班牙）共 14 面天线，事故时服务 40+ 任务；其余 13 面维持运行。
- 修复计划：约 $4.1–4.6M；与原定延长维护/升级合并；预计 2028-10 完成。

- 深空通信单点故障：70m级关键天线故障导致任务窗口被迫重排。

- 组织压力：操作员不是“犯蠢”，而是在赶工文化与任务压力下越界。
