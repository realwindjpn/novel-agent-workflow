# 《科武纪元》编辑学习官｜《开篇设计》课程提炼报告

## 1 课程核心判断（≤6条）
1. **开篇即定调**：前3000字必须完成“类型确认+核心人设+情绪锚点”交付，拒绝慢热与设定堆砌。
2. **钩子事件化**：悬念/金手指/冲突必须以“具体事件”形态在首段抛出，用动态推进替代静态说明。
3. **情绪即留存**：主角动机需锚定大众普世价值（复仇/逆袭/守护/求生），开篇反社会/降智/争议性设定直接劝退。
4. **节奏闭环化**：单章必须跑通“切入事件→展现特质→制造落差→留下引子”的完整循环，信息密度决定读完率。
5. **引子强绑定**：章末悬念必须与主线核心矛盾直接挂钩，解决表层问题但暴露深层危机，杜绝“为悬而悬”。
6. **风格一致性**：行文基调（轻松/肃杀/硬核/悬疑）需在开篇确立并贯穿始终，禁止中途调性断裂。

## 2 可执行编辑规则（按文章实际内容取舍）
| 维度 | 执行规则 |
|:---|:---|
| **开篇** | 三选一入口：①场景白描（≤3句定氛围）②对话交锋（直接暴露关系/矛盾）③悬念叙事（离奇现象/倒计时）。禁用世界观/历史/力量体系说明书。 |
| **节奏** | 结构配比：事件切入(10%)→冲突爆发(40%)→主角应对/特质展现(30%)→悬念钩子(20%)。短句为主，段落≤3行，单句≤20字，去冗余修饰词。 |
| **冲突** | 必须具象化、可感知。采用“强冲突开局”或“反差/先抑后扬”。冲突解决需留尾巴（引子），禁止“一次性清空矛盾”。 |
| **人物** | 3000字内通过“应激反应”立人设（如挨打必还手、遇险必护短、资源被夺必反击）。禁用旁白贴标签，用行为逻辑证明性格。 |
| **题材** | 场景/道具/对话必须100%贴合题材标签。简介承诺与开篇内容必须一致，禁止“挂羊头卖狗肉”导致标签流量反噬。 |
| **短故事/热点稿** | 单章闭环+情绪极致化。开篇直接对标社会情绪痛点/热点梗，3000字内完成“起承转合+情绪释放”，钩子转为“现实映射/话题争议”。 |
| **平台规则** | 番茄算法核心指标：首章读完率、追更率。移动端适配：单视角聚焦、多线叙事后置、预留“短剧切片”潜力（强画面/强反转/易传播）。 |

## 3 科武适配：可用点 vs 不可硬套点
### ✅ 可用点（直接迁移）
- **悬念钩/金手指开局**：科武的“基因锁激活”、“高维残片认主”、“古武神经接驳”可完美替代传统金手指，开局即抛设定+期待。
- **反差/先抑后扬**：适用于“底层拾荒者评级F→觉醒古武回路”、“退役机甲师被贬→重获初代引擎”等经典科武路径，快速建立升级期待。
- **情绪共鸣锚点**：科武的“生存资源争夺”、“阶级固化突围”、“文明存续危机”天然具备强共鸣，开篇聚焦个体在宏大背景下的挣扎即可。
- **设定渗透法则**：严格执行“事件驱动设定”。用战斗/逃亡/实验事故带出科技树/武道体系，杜绝开篇“百科式”科普。

### ❌ 不可硬套点（需改造）
- **古言/宅斗式冲突模板**：“退婚/极品亲戚/宅斗”需升级为科武逻辑下的“资源配额剥夺”、“基因评级降级”、“舰队强制征召”、“义体排异危机”。生搬硬套会严重破坏科幻质感。
- **纯情绪流/慢热日常**：科武长篇需维持“科技迭代+武力升级”的硬核推进。开篇若过度侧重日常/感情拉扯，会稀释科幻张力与追读动力。
- **“三观绝对正确”的刻板化**：科幻可合理探讨灰色道德（如AI伦理、生存电车难题、阵营背叛）。开篇可保留合理争议性，但需确保主角“核心动机”不反人类/不降智，规避平台审核红线。

## 4 编辑检查表（10条以内）
- [ ] 首段是否直接抛出事件/悬念/金手指？（无大段背景/设定铺垫）
- [ ] 前3000字是否明确故事类型与行文基调？（标签与内容100%一致）
- [ ] 主角是否通过具体动作/应激反应展现核心特质？（非作者旁白说明）
- [ ] 核心冲突是否具象化且与主线强相关？（非抽象矛盾/日常琐事）
- [ ] 行文是否去冗余？（段落≤3行，单句精炼，无重复表意）
- [ ] 主角动机/三观是否具备大众共鸣基础？（无开局毒点/反社会倾向）
- [ ] 章末是否留下与主线绑定的未解引子？（非断章式/为悬而悬）
- [ ] 世界观/力量体系是否通过情节自然渗透？（无“说明书式”科普）
- [ ] 情绪曲线是否完整？（压抑/期待/爽感至少完成一次小循环）
- [ ] 是否预留短剧/短视频传播钩子？（强画面感、强反转、易切片）

## 5 对作家角色的输入要求
| 要素 | 输入规范（作家交付标准） |
|:---|:---|
| **动作链** | 必须提供“触发条件→决策逻辑→执行动作→即时结果”的完整链条。禁用“突然爆发/天降神兵”。科武需体现操作细节（如神经接驳延迟、能量回路超载、招式拆解步骤）。 |
| **物理反馈** | 动作必须伴随可量化/可感知的物理与生理反馈（如骨骼错位声、机甲警报频闪、肌肉撕裂痛感、能量反噬灼伤、冷却液泄漏）。禁用抽象形容词堆砌，用感官数据替代情绪渲染。 |
| **代价** | 每次核心行动必须支付明确代价（如寿命折损、信用点清零、装备损毁、阵营暴露、基因污染）。代价需与后续剧情形成因果链，禁止“零成本开挂”或“代价虚化”。 |
| **钩子** | 必须提供“表层解决+深层危机”双层结构。表层钩子（本章事件收尾）干净利落；深层钩子（新线索/倒计时/身份反转/系统提示）直指主线核心矛盾，且具备至少3章的延展空间。 |
| **读者预期** | 开篇需明确交付“情绪承诺”（如复仇爽感、探索未知、逆袭打脸、硬核升级）。后续3章内必须兑现首次预期，禁止“预期欺诈”。科武需强化“科技/武力升级路径”的可视化预期（如明确下一阶段目标/瓶颈/资源缺口）。 |
