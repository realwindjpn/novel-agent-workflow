# 《科武纪元》编辑学习官：大纲设计规则提取报告

## 1 课程核心判断（≤6条）
1. **感情线核心是“拉扯感”**：依赖“单核误会衍生链”维持悬念，解铃只需破局初始误会，避免反复制造新误会导致主角降智。
2. **事业线唯一核心是“升级”**：无论种田/宫斗/脑洞/男频，本质均为“从无到有至行业巅峰”的阶梯式跃迁（财力/身份/能力/势力）。
3. **冲突是节奏调节器与人设试金石**：必须按“受挫-反抗-亮牌-补偿”逻辑递进，无冲突的顺境剧情会导致人设扁平、情绪疲软。
4. **期待感源于“信息差底牌”**：主角与读者共知、反派不知的隐藏优势；爽感落地于“出风头（地位/声望）+实质补偿（物质/精神/权限）”。
5. **大纲是“车站地图”**：将大剧情拆解为可复用、可伸缩的模块化情节点，用于实时追踪进度、控制行文节奏、预防卡文。
6. **底层公式全平台通用**：题材差异仅体现在“升级标的”与“冲突载体”的替换，核心叙事逻辑（目标-阻碍-破局-收益）可跨性别/跨品类复用。

## 2 可执行编辑规则
| 维度 | 规则（基于原文提炼） |
|:---|:---|
| **开篇** | 首章必须亮出“升级标的”或“关系初始态”，3000字内完成首次小目标确立，并埋下首个“信息差底牌”或“误会引信”。 |
| **节奏** | 采用“阶梯-冲突-补偿”循环。每完成一个事业/感情节点，必插入一次阻力；爽感释放频率需匹配平台数据（长篇每3-5章一小爽，短故事单章内闭环）。 |
| **冲突** | 遵循“单核衍生”原则。所有矛盾必须锚定同一初始信息差或利益点，禁止为冲突而冲突；冲突强度需与主角当前能力匹配，失败需付出明确代价。 |
| **人物** | 人设通过“抗压反应”立住。主角破局必须依赖自身底牌/决策，配角行为需符合利益逻辑；感情线拒绝“为虐而虐”，误会解除需有逻辑支点。 |
| **题材** | 替换“升级维度”即可跨题材复用。科幻/科武将“赚钱/身份”转为“技术突破/势力版图/武道阶位”，底层公式不变。 |
| **改编/平台** | 番茄算法偏好“高密度期待-兑现”循环。大纲需预留“数据反馈接口”（如某节点追读下滑，可快速插入补偿剧情）；短故事压缩至“1冲突+1亮牌+1补偿”单线；热点稿需将社会情绪转化为“事业线升级阻力”。 |

## 3 科武适配
**✅ 可用点**
- “升级”内核直接映射武道境界/科技树/势力版图扩张，阶梯清晰，便于长篇连载控盘。
- “信息差底牌”完美适配隐藏古武残卷、未公开机甲图纸、战术AI漏洞或物理法则盲区。
- “冲突-补偿”循环可无缝嵌入资源争夺、擂台赛、星际商战或宗门/财阀博弈。
- 模块化大纲有效对冲长篇科武“设定膨胀”导致的节奏失控，便于按卷/章拆解与数据调优。

**❌ 不可硬套点**
- 女频“误会叠加链”在硬核科武中易显降智。情感拉扯需转化为“理念分歧/阵营对立/生存抉择/战术误判”，而非人际八卦或情绪内耗。
- “种田式第一桶金”节奏过缓。科武需压缩为“首战破局/核心装备获取/功法初成”并立即投入实战检验，拒绝漫长积累期。
- “物质补偿”爽感在宏大叙事中易单薄。需升级为“技术垄断权/规则制定权/文明跃迁契机/武道真意领悟”，以匹配科武格局与读者阈值。

## 4 编辑检查表（10条以内）
1. 核心目标是否明确为“单一升级维度”（境界/科技/势力/情感信任度）？
2. 开篇3000字内是否确立初始目标并埋下首个“信息差底牌”？
3. 每个大剧情节点是否严格遵循“目标-阻力-受挫-亮牌-补偿”结构？
4. 冲突是否源自同一初始信息差/利益点，而非随机生成新矛盾？
5. 主角破局是否依赖自身决策/底牌，而非天降外力或反派降智？
6. 爽感落地是否包含“出风头（地位/声望提升）+实质补偿（资源/权限/情感确认）”？
7. 感情线误会是否具备“可追溯逻辑支点”，解除后不反复消耗同一设定？
8. 大纲是否标注“期待感释放节点”与“数据回调预案”（如追读低谷插入补偿）？
9. 科武设定是否避免“纯种田节奏”，首桶金/首突破是否具备即时战术/战略价值？
10. 短故事/热点稿是否完成“单冲突-单亮牌-单补偿”闭环，无冗余支线？

## 5 对作家角色的输入要求
- **动作链**：明确“触发-决策-执行-结果”四步闭环。禁止跳跃式推进，每个关键转折需有连续动作支撑（例：探测敌情→计算胜率→启动底牌→反制）。
- **物理反馈**：科武场景必须具象化能量/物质交互。底牌释放需伴随可观测的物理现象（机甲过载警报、经脉灼痛、空间扭曲参数、动能反冲），杜绝“意念秒杀”或抽象描述。
- **代价**：每次亮牌/破局必须支付对等代价（资源枯竭、寿命折损、阵营信任破裂、技术反噬、武道根基受损）。无代价的爽感视为大纲缺陷，需强制补全。
- **钩子**：章末/卷末必须设置“未兑现底牌”或“新信息差”。钩子需与当前主线强绑定，禁止无关悬念堆砌；钩子强度需与下一章期待值正相关。
- **读者预期**：明确标注“读者此刻应期待什么”（如：期待主角反杀/期待误会解除/期待技术突破）。正文兑现率需≥80%，偏离预期需提前3章铺垫逻辑转向或提供替代性补偿。
