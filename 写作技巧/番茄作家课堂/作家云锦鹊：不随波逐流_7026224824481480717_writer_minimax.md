## 一、核心执行指令（写作动作清单）

### 【开篇必杀动作】前3章必须完成

```
□ 触发条件：主角必须遭遇可量化的生存困境
□ 执行动作：困境必须具象化呈现（不是"很穷"，是"能量块只够撑3小时"）
□ 环境交互：破局手段必须"非标准"，禁止直接调用金手指
□ 结果输出：读者必须看到主角用"低配工具/民用改装/资源整合"解决当前问题
```

### 【节奏循环动作】每3-5章执行一次

```
□ 小胜触发：主角通过技巧/资源整合取得局部胜利
□ 故障激活：金手指/外挂/能力出现限制或故障
□ 代价输出：能力使用后必须付出可观测代价（能量消耗/身体损伤/资源枯竭）
□ 解决动作：主角被迫重新整合资源或调整战术
□ 资源升级：小胜积累到阈值后解锁新装备/技能/情报
```

### 【代价激活动作】每次能力使用时必须触发

```
能力使用前检查：
├─ 是否设置了能量/体力/精神消耗？
├─ 是否有冷却时间/使用次数限制？
├─ 是否有副作用/反噬机制？
└─ 代价是否累积影响后续剧情？

禁止：能力使用后"毫无消耗""随时可用""用完即忘"
```

### 【钩子埋设动作】每章章末必检

```
□ 信息缺口钩：抛出一个角色/读者都未知的线索
□ 时间压力钩：设定倒计时或紧迫时限
□ 身份谜团钩：暗示角色背景/动机存在隐藏面
□ 势力介入钩：引入新的利益方或冲突因子
□ 系统异常钩：外挂/金手指出现未解析的错误/提示
```

## 二、物理反馈模型（科武长篇可直接套用）

### 【故障型金手指模板】

```
模板：启动指令 → 系统接驳 → 物理反馈 → 故障告警 → 强制限制

例1（义体神经接驳）：
启动义体手臂 → 神经接驳刺痛（3-5秒适应期）→ 握力传感器校准中 → 
力量输出延迟0.3秒 → 高频振动刀启动需等待系统自检

例2（AI战术模块）：
语音指令"战术分析" → 全息界面投影 → 模块加载中 → 
⚠️ WARNING: 能量供应不稳定 → 分析精度下降至67% → 建议降低运算负荷

例3（机甲动力核心）：
启动引擎 → 能量波动警报 → 冷却系统响应延迟2.1秒 → 
核心温度持续上升中 → 输出功率上限锁定60%
```

### 【能力使用代价清单】

```
| 能力类型 | 代价模板 | 累积机制 |
|:---|:---|:---|
| 义体强化 | 神经负荷/肌肉疲劳/感知过载 | 连续使用导致接驳疼痛加剧，触发系统保护锁死 |
| 高频武器 | 能量消耗/散热需求/共振反馈 | 能量块储量下降，战斗后必须冷却否则过热 |
| 战术AI | 算力占用/数据延迟/逻辑锁死 | 复杂分析触发过热保护，冷却期间无法使用 |
| 超频感知 | 精神负荷/感官扰动/短暂失明 | 使用后陷入感官过载，需要静默恢复期 |
| 身体强化 | 体能透支/细胞损伤/加速衰老 | 突破临界值触发不可逆损伤，影响后续成长上限 |

## 三、失败模式字典

### 【主角失败模式】非龙傲天式失败

```
模式1：战术误判型失败
触发：主角基于不完整情报制定战术
代价：付出额外资源/暴露行踪/队友受伤
后续：必须通过复盘/学习调整策略

模式2：资源透支型失败
触发：强行使用超出当前承载力的能力/装备
代价：能力系统进入冷却/保护性锁死/身体损伤
后续：必须寻找替代方案或等待恢复期

模式3：信任陷阱型失败
触发：基于错误信息源做出决策
代价：被误导进入埋伏/情报泄露/战术暴露
后续：被迫重新建立情报网络

模式4：性格缺陷型失败
触发：主角的"毛边"特质导致决策失误（如战术偏执导致冒进、经验主义导致误判）
代价：阶段性目标失败/团队信任受损
后续：通过失败累积教训，形成成长弧光
```

### 【金手指故障模式】

```
故障类型 → 触发条件 → 强制限制 → 破局导向

类型A：能量供应型
条件：能量低于20%
限制：所有强化型功能强制关闭
破局导向：被迫使用基础装备/近战/陷阱战术

类型B：系统冲突型
条件：同时运行多个模块
限制：触发逻辑锁死，需重启自检
破局导向：必须选择性关闭次要功能，保留核心能力

类型C：过载保护型
条件：单次使用超出设计阈值
限制：强制进入冷却模式，最少需要X分钟恢复
破局导向：冷却期间必须近身肉搏/躲避/等待增援

类型D：未知协议型（剧情伏笔）
条件：触发特定场景/关键词/生物特征
限制：系统异常响应，功能不稳定
破局导向：引出主角身世/世界观的深层谜团
```

## 四、人物口吻模板库

### 【主角口吻类型】

```
类型1：技术宅冷静型
特征：专业术语穿插、数据化思维、客观陈述
模板：
"能量转化效率下降7.3%，按照当前消耗速率，剩余续航时间不超过12分钟。"
"这不是bug，是系统设计层面的逻辑矛盾——我能证明。"
"如果继续超频输出，核心温度会在四分三十七秒后突破临界值。"

类型2：战术偏执型
特征：反复推演、成本核算、风险厌恶
模板：
"等等，让我再确认一遍地图。全员撤进掩体的时间窗口只有23秒。"
"没有backup的方案不叫战术，叫送死。"
"代价太大了。我们需要换一个成功率超过78%的方案。"
```

### 【反派/势力口吻】

```

"根据第七版能量管理条例第34条，你的行为已触发自动制裁协议。"

类型B：野生势力狡诈型
特征：生存智慧、灰色交易、江湖规矩
模板：
"规矩？有本事的人才有资格谈规矩，没本事的人只能被规矩谈。"

"黑市的规矩很简单——出了这个门，刚才谈的一切都不作数。"
```

## 九、借点标注

### 📌 短故事/狼人篇可借点

```
【可迁移模块】

1. 故障型金手指 → 狼人觉醒失控型金手指
   - 转化：变身能力不稳定/月光阈值触发/控制力缺陷
   - 节奏模式可套用"小胜→故障→代价→解决"

2. 代价累积机制 → 狼人身份代价
   - 转化：每次变身消耗生命力/月圆失控风险、人际代价（身份暴露）
   - 代价需累积影响后续剧情，不能"用完即忘"

3. 生活化破局 → 人类世界生存技巧
   - 转化：用人类技能（烹饪/手工艺/专业知识）解决超自然困境

4. 人物毛边 → 狼人性格缺陷
   - 转化：控制欲偏执/社群信任缺失/狂暴冲动等

5. 章末钩子 → 短篇悬念结尾
   - 模板：身份谜团/时间压力/势力介入（猎人组织/狼族议会）
```

### 📌 科武长篇可借点

```
【直接套用模块】

1. ✅ 故障型外挂全模板
   - 义体神经排异、AI战术模块延迟、能量核心冷却死机
   - 可直接代入机甲/武道/科技融合世界观
