# 《科武纪元》编辑学习官：旧题材翻新与长篇实操规则

## 1 课程核心判断（≤6条）
1. **旧题材破局不靠新设定堆砌，靠“反套路人设+现实逻辑注入”**。经典桥段保留骨架，替换血肉变量即可刷新阅读体验。
2. **主角去光环化是建立共鸣的最短路径**。保留私心、防备、计算与成长弧光，比完美人设更具留存力。
3. **配角需剥离工具人属性**。用独立动机与正向/复杂关系网替代狗血对立，冲突源转向价值观碰撞与现实困境。
4. **长篇大纲必遇“后劲乏力”节点**。激情期（3-5万字）后需强制进行框架重构与人设细化，拆分主线为情绪单元推进。
5. **平台算法重“完读率+追更粘性”**。稳定更新是基础，但“质量+情感羁绊”可对冲断更风险；数据下滑优先调优情绪钩子而非盲目改设定。
6. **作者生命体验是文本厚度的底层燃料**。幻想题材必须锚定现实情感逻辑，困境/疾病/情绪需转译为角色动机与剧情推力。

## 2 可执行编辑规则
| 维度 | 规则要点 | 适用场景 |
|:---|:---|:---|
| **开篇** | 首章3000字内必须抛出“反常识设定”或“去光环化主角状态”。用具体行为/决策替代背景说明，禁用套路化开局（如直接无敌/天降金手指）。 | 长篇/短故事/热点稿通用 |
| **节奏** | 前5万字为“设定验证期”，10万字节点强制进行“框架复盘”。将主线拆分为“情绪单元（3-5章）+现实目标（10-15章）”双线交替，防止大纲透支。 | 长篇核心 |
| **冲突** | 摒弃“为虐而虐”的降智对立。冲突必须源于角色内在矛盾/资源争夺/规则限制，用“和解/代价/成长”替代“打脸/碾压”。 | 长篇/短故事 |
| **人物** | 主角设置“初始缺陷+合理动机”，配角设置“独立使命+关系润滑”。人物弧光必须与核心主题绑定，禁止无功能出场。 | 全类型 |
| **题材** | 旧题材翻新公式：`经典桥段 × 现实变量 = 新体验`。保留类型爽点骨架，替换底层逻辑（如言情“假昏迷”→科武“真意识休眠/基因崩溃”）。 | 长篇/热点稿 |
| **改编** | 影视/短剧适配需提前预埋“强关系网+高共鸣场景”。弱化硬设定解释，强化人物互动、战术博弈与情感递进，确保关键场景可视觉化。 | 长篇/短故事 |
| **平台规则** | 番茄重“首秀完读率+追更留存”。断更需提前报备+加更补偿；利用章说/段评收集共鸣点反哺剧情；数据下滑时优先调整“情绪钩子密度”而非推翻主线。 | 全类型 |

## 3 科武适配
| 维度 | 可用点（直接迁移） | 不可硬套点（需规避/转译） |
|:---|:---|:---|
| **人设逻辑** | 去光环化主角、保留战术计算/资源焦虑/道德灰度；配角具备独立阵营使命与关系润滑功能。 | 甜宠/豪门情感基调；“家有一老如有一宝”传统伦理（科武侧重生存法则/科技伦理/阵营博弈）。 |
| **冲突构建** | 冲突源于资源匮乏/规则限制/内在理念碰撞；用“代价/妥协/进化”替代无脑碾压。 | 言情式“误会-和解”循环；狗血婆媳/雌竞模板（需替换为科武语境下的“权限争夺/技术路线分歧/生存配额博弈”）。 |
| **题材翻新** | “经典桥段×现实变量”公式可直接套用（如机甲觉醒、武道突破、星际殖民）。 | 直接照搬现实情感经历映射。科武需经过“物理规则/科技逻辑/社会结构”转译，禁止脱离世界观的情感悬浮。 |
| **节奏与平台** | 情绪单元拆分、框架迭代机制、章说反哺、断更预案管理完全适用。 | 过度依赖“作者个人感动”驱动剧情。科武需以“目标-阻碍-反馈”为引擎，情感仅作为推力而非核心卖点。 |

## 4 编辑检查表（10条以内）
- [ ] 开篇3000字内是否出现“反常识设定”或“主角去光环化行为”？
- [ ] 核心冲突是否源于角色内在矛盾/现实困境，而非外部降智反派？
- [ ] 配角是否具备独立动机与功能性，关系网呈正向/复杂化而非脸谱化？
- [ ] 大纲是否在10万字节点预留“情绪单元”拆分与框架迭代空间？
- [ ] 科武设定是否遵循“现实变量+逻辑自洽”，有无金手指滥用或规则崩坏？
- [ ] 每章结尾是否设置“未兑现的物理/战术反馈”或“预期违背”，保障追更率？
- [ ] 断更/卡文预案是否包含“章说互动补偿”与“核心主线不偏移”机制？
- [ ] 读者预期管理是否明确（爽点类型/成长路径/世界观边界），每3万字是否交付一次兑现+新变量？
- [ ] 改编潜力评估：关键场景是否具备强视觉化/高共鸣对话特征，弱化纯设定解说？
- [ ] 文本是否剥离“作者自我感动”段落，确保所有描写服务于剧情推进或人物弧光？

## 5 对作家角色的输入要求
| 维度 | 执行标准（科武语境） |
|:---|:---|
| **动作链** | 严格遵循`触发条件→决策逻辑→执行动作→结果反馈`闭环。禁止跳跃式行为；科武场景需符合战术推演/物理法则/能量守恒逻辑，动作必须有前置铺垫与后置影响。 |
| **物理反馈** | 每次战斗/科技使用/武学突破必须伴随可量化的环境/机体/能量反馈（如装甲损耗率、神经负荷阈值、重力异常、资源枯竭、冷却周期）。反馈需直接推动下一决策。 |
| **代价** | 任何能力获取/剧情推进必须支付明确代价（时间、资源、人际关系、生理极限、道德妥协、阵营信任）。禁止无成本升级或“天降解围”。代价需与角色弧光绑定。 |
| **钩子** | 章末/卷末钩子需绑定“未兑现的物理反馈”或“角色预期违背”，禁用纯悬念堆砌。钩子必须与主线目标强关联，且在下3-5章内完成逻辑回收。 |
| **读者预期** | 开篇明确“科武融合基调”（硬核生存/机甲武道/星际殖民等），每3万字交付一次“预期兑现+新变量引入”。禁止中途切换核心爽点类型；利用章说数据校准预期偏差，动态微调节奏而非推翻主线。 |
