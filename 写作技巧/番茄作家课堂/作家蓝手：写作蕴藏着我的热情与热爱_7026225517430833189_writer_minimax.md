## 4. 可执行规则集（作者 OS 直接调用）  

### 4.1 开篇指令  
- **动作**：`起势` → `危机/任务` + `情绪钩子`（前 3 章必完成）  
- **反馈**：首句即给出主角**目标/危机**，禁止慢热铺垫  
- **失败模式**：若 3 章仍未抛核心冲突 → **自动插入倒计时**  

### 4.2 节奏指令  
- **结构**：**短单元 6‑8 万字** + **长线伏笔**（30%/60%/90% 回收）  
- **段落节奏**：`起（100‑200 字） → 承（200‑400 字） → 转（400‑600 字） → 合（100‑200 字）`  
- **失败模式**：单元内注水 >3 章 → **触发“节奏压缩”提示**  

### 4.3 冲突指令  
- **首选**：作者最擅长的冲突模式（情感/动作/智斗）  
- **执行**：单元冲突 **闭环**；跨单元冲突 **仅服务主角终极动机**  
- **失败模式**：冲突偏离主线 >3 章 → **强制回收或重新定位**  

### 4.4 代价指令  
- **代价列表**（任选其一或组合）：  
  - 神经负荷 / 寿命折损 / 资源枯竭 / 阵营敌对  
- **执行**：每次越级/外挂使用 **立即触发代价描述**（≥20% 能量/资源削减）  
- **失败模式**：无代价升级 → **系统回滚并补代价**  

### 4.5 钩子指令  
- **信息差悬念**：`谁/何时/怎样` 未揭示的关键信息  
- **生存危机倒计时**：时间/阶段/资源递减  
- **章末钩子**：必须与下章细纲 **强绑定**，禁止开放式抒情  
- **失败模式**：钩子与下章不匹配 → **自动补足**  

### 4.6 情绪闭环指令  
- **触发**：重要配角/导师退场后 3 卷内出现 **记忆唤醒/传承/平行补偿**  
- **实现方式**：数据重构、武道传承、意识上传等 **逻辑自洽**  
- **失败模式**：超 3 卷仍未闭环 → **触发“情绪代偿”警告**  

### 4.7 口吻与节奏（角色口吻、段落节奏）  
- **口吻**：主角保持 **坚定/冷峻**（可随情境微调），配角 **鲜明标签**（如“狂笑老兵”“机警少女）  
- **段落节奏**：**快‑慢‑快‑快** 循环，避免单调；高潮段保持 **连续动作** 密集  
- **失败模式**：口吻统一性缺失 → **自动校正**（情感词汇替换）
