### 补丁1：旧题材翻新 — “骨架保留，血肉替换”动作包

| 操作动作 | 执行步骤 | 失败模式 |
|:---|:---|:---|
| **识别经典桥段** | ①列出本类型TOP3套路骨架（如机甲觉醒/废柴逆袭/星际流亡） ②标注骨架核心爽点 ③检索近期同题材扑街原因 | ❌ 只换皮不换核 → 读者识别为换皮水文 |
| **注入现实变量** | ①选一个现实痛点（资源焦虑/健康危机/身份认同/职场PUA） ②将其转译为科武语境变量 ③将变量嵌入经典桥段触发条件 | ❌ 变量与世界观脱节 → 科幻皮言情骨 |

> **📌 科武长篇可借点**：需构建变量库（资源稀缺表/技术路线图/阵营博弈网），每10万字至少迭代一次变量组合

### 补丁2：主角去光环化 — 5个立即可写的具体行为

```
☐ 主角在第一场冲突前先做一次"自私但合理"的决策
☐ 主角有且必须有"当前能力边界"的明确描写（写不擅长的比写擅长的更重要）
☐ 主角的每一次判断都有可追溯的利弊分析（哪怕是错误的）
☐ 主角遭遇挫折后优先"算账"而非"发怒"或"找人倾诉"
☐ 主角的成长弧光用"代价换能力"而非"顿悟突升"
```

| 人物口吻示例（去光环化） | 对比（光环化） |
|:---|:---|
| “这具装甲的输出上限是7.2吨，我目前神经承载只能稳定5.8吨，多余的0.4吨需要用反应堆分流，但那会缩短核心寿命30%。” | “虽然我实力还不够强，但我相信只要努力……” |
| “我不打算帮他们。理由：第一，我没义务；第二，我资源只够我自己用；第三，帮了也未必能换来等价回报。” | “大家都是同伴，我怎么能见死不救！” |

> **📌 科武长篇可借点**：主角口吻必须带“计算感”，哪怕是情感爆发场景也要先过一遍利弊
>
> **📌 短故事/狼人篇可借点**：去光环化不等于“丧”，主角可以是“精致的利己主义者但有底线”，便于快速立人设

### 补丁3：配角脱离工具人 — 三步动机锚定法

```
第一步：给每个配角填写"独行动机卡"
  - 他/她当前最想要什么？（必须是主角之外的目标）
  - 阻碍他实现目标的最大障碍是什么？
  - 他需要主角吗？如果需要，为什么？

第二步：检查关系网是否"非零和"
  - 配角之间是否存在"合作增益"或"路线分歧"？
  - 避免：所有配角都是为了"和主角作对"或"爱上主角"而存在

第三步：分配"润滑功能"
  - 谁负责提供信息/资源？
  - 谁负责制造"价值观冲突"推动主角成长？
  - 谁负责"反向激励"（用自身选择衬托主角的立场困境）？
```

| 失败模式 | 自检 |
|:---|:---|
| 配角A：反派工具人，只有“为阻挡主角而存在”的功能 | 检查：A有没有自己的目标？那个目标是否与主角目标冲突但逻辑自洽？ |
| 配角B：主角附庸，所有行动都是为了衬托主角英明 | 检查：B是否有“主角不在场时他/她自己的剧情线”？ |
| 配角C：脸谱化（纯善/纯恶） | 检查：C是否存在道德灰色抉择？哪怕是微小的灰色 |

> **📌 科武长篇可借点**：阵营设计用“路线分歧”替代“正邪对立”，配角团长/指挥官需有独立阵营战略
>
> **📌 短故事/狼人篇可借点**：短篇配角精简至2-3人，但每人必须有“独立动机卡”+“与主角的关系润滑点”

### 补丁4：长篇框架迭代 — “后劲乏力”预防动作

```
【3-5万字节点：激情期复盘】

  ☐ 埋线：下一阶段核心冲突是什么？主角当前目标与新冲突的关联度？

【10万字节点：框架重构】
  ☐ 将主线拆解为"情绪单元（3-5章）"列表
    - 单元1：____情绪→目标→阻碍→代价→结果
    - 单元2：____情绪→目标→阻碍→代价→结果
  ☐ 检查每个情绪单元是否都有"物理/战术反馈"作为收尾

### 补丁6：生命体验锚定 — 科武语境转译方法

```
【第一步：找痛点】
  从自身/身边人/社会新闻中提取：
  - 资源焦虑？（房子/工作/医疗/教育）
  - 健康危机？（慢性病/亚健康/精神压力）
  - 身份认同？（阶层滑落/职业瓶颈/家庭角色冲突）

【第二步：科武转译】
  资源焦虑 → 星际殖民配额争夺/机甲维修资源危机
  健康危机 → 基因崩溃/神经负荷阈值/意识休眠代价
  身份认同 → 义体化后的人类身份争议/阵营归属困境

【第三步：绑定角色动机】
  主角的"初始缺陷"必须源于某个现实变量
  例：主角"不敢信任他人"→因转译为"父亲因资源争夺牺牲→主角对联盟忠诚存疑"
```

| 失败模式 | 自检 |
|:---|:---|
| 现实体验与科武设定“油水分离” | 检查：情感逻辑是否经过“物理规则/科技逻辑”转译？是否有设定支撑情感合理性？ |
| 情感描写沦为“作者自我感动” | 检查：每一段情感描写是否服务于“动机强化”或“冲突推进”？删除纯感怀段落 |

> **📌 科武长篇可借点**：每20万字需进行一次“现实锚点回顾”，确保主角成长弧光仍与初始痛点相关联
>
> **📌 短故事/狼人篇可借点**：短篇可直接使用现实情感逻辑，无需复杂转译（读者代入门槛低）

## 三、章节自检清单（作家OS标准格式）

### 3.1 开篇自检（前3000字）

```
□ 开篇300字内是否出现"反常识设定"或"去光环化主角行为"？
  - 反常识示例："这具机甲的瞄准系统坏了，但客户的投诉单比敌方的炮火更致命"
  - 去光环化示例："主角的第一反应是'这单我赔不起'而非'我要打败敌人'"

□ 是否用具体行为/决策替代背景说明？
  - 禁止：内心独白式背景介绍（"他从小就梦想成为机甲师……"）
  - 必须：决策式背景（"他选择接这单维修，因为联盟积分还差300才能续租维修舱"）

□ 前3段是否完成"科武基调锚定"？（硬核生存/机甲武道/星际殖民等）
□ 开篇爽点是否清晰？（读者在前300字内知道"这文看什么"）
```

### 3.2 动作链自检（全程）

```
□ 主角每个行动是否有"触发条件→决策逻辑→执行动作→结果反馈"闭环？
  - 常见错误：跳跃式行为（"他决定冒险→直接成功"）
  - 正确示范："触发：敌方装甲露出破绽→决策：计算胜率38%→执行：启动冷却中的推进器→反馈：机体过载警报响起，但争取到3秒窗口"

□ 科武设定是否遵循物理法则/能量守恒/资源限制？
  - 禁止：天降解围（"突然爆发→无视任何限制"）
  - 必须：每一次能力使用都有可量化的代价

□ 每次战斗/科技使用/武学突破是否伴随环境/机体/能量反馈？
  - 反馈必须直接推动下一决策（形成闭环）
```

### 3.3 冲突自检

```
□ 核心冲突是否源于"角色内在矛盾/资源争夺/规则限制"？
  - 禁止：为虐而虐的降智对立（"反派就是看他不顺眼"）
  - 必须：冲突有逻辑支撑（资源匮乏/阵营分歧/价值观碰撞）

□ 冲突解决是否用"和解/代价/成长"替代"打脸/碾压"？
□ 配角是否具备独立动机与功能性，关系网是否正向/复杂化？
□ 冲突过程中是否产生"可量化代价"？（时间/资源/关系/生理/道德）
```

### 3.4 人物自检

```
□ 主角是否有"初始缺陷+合理动机"？
□ 主角弧光是否与核心主题绑定？
□ 配角是否每人都有一张"独立动机卡"？
  - 检查：配角是否有"主角不在场时他/她自己的剧情线"？
□ 人物口吻是否符合科武基调？
  - 去光环化口吻示例："这具装甲的输出上限是7.2吨……"
  - 禁止：言情式口吻（"他深情地看着我，仿佛全世界都不重要"）
```

### 3.5 节奏自检

```
□ 章末是否设置"未兑现的物理/战术反馈"或"角色预期违背"？
□ 钩子是否与主线目标强关联？（<60%→重设）
□ 每3万字是否交付一次"预期兑现+新变量引入"？
□ 情绪单元（3-5章）是否有清晰的起承转合？
□ 章节收尾是否"有余味"但"不悬空"？（下3-5章内可逻辑回收）
```

### 3.6 题材翻新自检（适用时）

```
□ 是否使用"经典桥段×现实变量"公式？
  - 示例：言情"假昏迷"→科武"真意识休眠/基因崩溃"
□ 变量是否经过"物理规则/科技逻辑/社会结构"转译？
□ 情感逻辑是否锚定现实情感？（而非"作者自我感动"）
```

### 3.7 平台规则自检（发布前必查）

```
□ 首章完读率预估是否≥40%？（不达标→开篇急救三动）
□ 断更预案是否包含"核心悬念吊住"机制？
□ 章说/段评是否有置顶互动？（建立共鸣点收集渠道）
□ 数据下滑时是否优先调整"情绪钩子密度"而非改设定？
□ 发布封面/摘要是否包含本章核心冲突词？
□ 章节更新频率是否稳定？（断更需提前24小时报备）
```

### 3.8 改编潜力自检（长篇建议检查）

```

### 每日写作执行链

```
【写作启动三问】
  1. 本章主角的核心决策是什么？（决策→行动→反馈）
  2. 本章配角是否有独立动机？（配角动机卡）

【写作中三查】
  1. 动作链是否跳跃？（补全闭环）
  2. 情感描写是否服务剧情？（删除纯感怀）
  3. 科武设定是否自洽？（能量/资源/物理逻辑）

【章节收尾三确】
  1. 章末钩子是否与主线强关联？
  2. 下章是否有"预期违背"预告？
  3. 本章代价是否已计入角色状态表？
```

## 五、补丁使用说明

```
【首次使用】
  1. 通读全文，理解6个核心补丁的逻辑关系
  2. 填写"写作前任务卡"（每章必填）
  3. 完成后使用"章节自检清单"逐一核验

【日常使用】
  - 每日写作：参考"每日写作执行链"
  - 卡文时：调用"卡文急救包"
  - 数据下滑：执行"平台规则自检"
  - 每10万字：执行"长篇框架迭代"动作

【长篇专项】
  - 3-5万字节点：执行激情期复盘
  - 10万字节点：执行框架重构
  - 每20万字：执行现实锚点回顾

【短篇/狼人篇】
  - 精简使用：跳过"长篇框架迭代"动作
  - 核心聚焦：开篇自检 + 动作链自检 + 冲突自检
  - 配角卡：保留1-2张核心配角动机卡即可
```
