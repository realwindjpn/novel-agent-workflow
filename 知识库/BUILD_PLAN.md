## 工作流程

### Step 1: 查重（采集前必做）

```
新素材 → 在知识库INDEX中搜索关键词
  ├─ 已有 → 跳过或增量补充
  └─ 没有 → 进入Step 2
```

### Step 2: 定向采集

根据大纲缺口，按优先级采集：
- P0: 量子计算/AI芯片/核聚变（核心科技线）
- P1: 外骨骼/脑机接口/新能源（战斗/装备线）
- P2: 太空探索/FAST天眼（远景线）

### Step 3: 生成素材卡

每张素材卡包含：
```markdown
# 素材卡: {标题}
- 来源: {平台+URL}
- 采集日期: {YYYY-MM-DD}
- 可信度: A(官方论文)/B(权威媒体)/C(自媒体)

## 科学事实
- 核心数据
- 关键技术

## 小说映射
| 现实技术 | 小说映射 | 适用章节 |

## 小说化表达示例
（200-300字对话/场景）
```

### Step 4: 入库去重

1. 素材卡写入 `知识库/{科技线}/`
2. 更新 `知识库/INDEX.md`（标题+科技线+来源+日期）
3. 同步到 RAG `rag_kb/science/cards/`（填充content+novel_use）
4. 原始正文归档到 `硬科学素材/采集_YYYYMMDD/raw/`

### Step 5: 写作引用

写作时按大纲章节查询知识库：
```
第XX章需要 {科技线} 素材
  → 查 知识库/INDEX.md
  → 找到对应素材卡
  → 引用科学事实+小说化表达
  → 标注来源（避免编造）
```

## 查重规则

| 维度 | 规则 |
|------|------|
| 标题相似度 | >70% 判定重复 |
| 核心数据 | 同一实验/装置/参数 → 合并 |
| 来源不同 | 同一事件多源报道 → 保留最详实版本 |
| 时间差 | 旧版被新版覆盖 → 标记"已更新" |
