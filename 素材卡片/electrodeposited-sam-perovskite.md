# 电沉积自组装分子助力钙钛矿光伏

**来源:** [Nature](https://www.nature.com/articles/s41586-026-10844-6)  
**来源类型:** 官方预印本（unedited manuscript）  
**采集时间:** 2026-07-05 21:55

## 核心发现

- **方法:** 电位循环电沉积（potential-cycled electrodeposition），促进分子重排与再锚定，在 ITO 基底上形成均匀致密自组装分子层（SAM）
- **后续功能化:** 电化学氧化偶联合成定制化耦合咔唑膦酸 SAM
- **性能:**
  - 实验室小电池 PCE = **26.8%**
  - 模组（65 cm²）PCE = **21.3%**
- **关键优势:** 解决传统溶液法 SAM 脱落问题，提升覆盖均匀性与锚定鲁棒性
