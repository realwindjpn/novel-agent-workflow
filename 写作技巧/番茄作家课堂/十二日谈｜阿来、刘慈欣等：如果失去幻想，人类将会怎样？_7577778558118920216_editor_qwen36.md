# 《科武纪元》编辑学习官：课程提炼与执行标准

## 1 课程核心判断（≤6条）
1. **科幻本质是思想实验**：将现实的人置于非现实环境，核心命题是人性、社会结构与生存伦理，而非技术预测。
2. **网文需“先爽后深”**：以脑洞/欲望投射切入抓留存，中后期再铺陈硬核设定与哲思，完成类型溢出。
3. **AI时代创作分水岭**：AI擅长“有中生有”（套路重组），人类核心竞争力是“无中生有”（留白、肉身经验、不可计算的审美与情感震颤）。
4. **想象力必须锚定现实**：无论场景推至多远，底层逻辑必须源于人类经验与科学规律，脱离现实根基的设定易悬浮。
5. **创作常态即瓶颈**：高阶设定（如高维规则对抗）需接受“抓影子”的试错过程，不可强求一次性逻辑闭环。
6. **数据反馈是校准器非方向盘**：网文依赖实时段评/追读调整节奏，但核心力量体系与人物弧光不可被碎片化反馈驯化。

## 2 可执行编辑规则
| 维度 | 执行规则 |
|:---|:---|
| **开篇** | 前3章必须抛出核心“脑洞/金手指”并绑定主角当下现实欲望（如阶层跃迁、生存危机）。禁止纯设定说明书式开篇，首章需完成一次“能力验证/预期交付”。 |
| **节奏** | 采用“快钩子-稳留存-深主题”波浪结构。前期高频释放小目标/战力突破维持追读；每30-50章插入一次“现实映射/人性困境”缓坡，避免连续设定堆砌导致疲劳断更。 |
| **冲突** | 技术/环境冲突仅为外壳，内核必须指向资源分配、认知边界、阶层固化或生存伦理。冲突解决需依赖“规则破解/代价交换”，而非单纯数值碾压。 |
| **人物** | 拒绝“未来工具人”。主角动机需扎根当下现实困境（职场压抑、身份焦虑、守护执念），行为逻辑符合人类经验。配角需具备独立利益诉求，避免沦为剧情推进器。 |
| **题材** | 允许“中式科幻现实感”。将本土社会结构、市井细节、历史记忆无缝嵌入科武框架。硬核内容可后置，但必须与前期爽点形成逻辑回环。 |
| **改编** | 预留“视听转化接口”。科武战斗、高维场景需具备明确的空间坐标、能量轨迹与环境交互描写，便于后续VR/短剧/漫画分镜拆解。 |
| **平台规则** | 建立“段评-内容”校准闭环：段评激增处保留并放大情绪价值；追读断崖处快速切线或回收伏笔。但核心主线、力量体系、人物底线不可因单章数据妥协。 |

## 3 科武适配
### ✅ 可用点
- **“现实人+非现实环境”推演**：将武道修炼体系视为“人体科技/基因进化/神经接口”的具象化，探讨力量获取的代价与社会阶层重塑。
- **“先爽后深”商业结构**：前期以“科武金手指/战力突破/资源掠夺”满足升级爽感；中后期引入“AI武道替代/高维规则降临/人类定义危机”完成主题升维。
- **“留白与肉身震颤”**：武道意境、生死搏杀的物理反馈、意志突破极限的不可计算性，是AI难以生成的核心壁垒，需作为文本重点打磨。
- **现实锚点映射**：科武世界的财阀垄断、底层晋升通道、功法专利化，直接对标现实教育/职场/资源焦虑，增强共鸣厚度。

### ⛔ 不可硬套点
- **纯文学慢热节奏**：不可照搬传统科幻“十年磨一剑”的学术探讨或大段哲学独白，科武需保持商业连载的推进密度。
- **技术宿命论基调**：科武核心是“人定胜天/肉身成圣”，需将AI/高维危机转化为“人类武道独特性（情感/意志/经验）的试金石”，而非陷入悲观虚无。
- **段评改主线/吃书**：科武力量体系需严密自洽，不可因读者短期爽感需求随意叠加设定、崩坏战力逻辑或推翻前期伏笔。

## 4 编辑检查表（10条以内）
- [ ] 开篇3章是否明确抛出核心脑洞/金手指，并绑定主角当下现实欲望？
- [ ] 科武设定是否遵循“现实逻辑推演”，有无脱离物理/科学常识的悬浮解释？
- [ ] 冲突内核是否超越“打怪升级”，触及资源、阶层、认知或人性困境？
- [ ] 主角行为动机是否扎根人类经验（恐惧、贪婪、守护、尊严），而非绝对理性？
- [ ] 高维/规则级战斗是否做到“不可理解但可感知”，有无具象化物理反馈？
- [ ] 节奏是否呈现“快钩子-稳留存-深主题”结构，有无连续3章纯设定说明？
- [ ] 文本是否保留“留白”与“弦外之音”，避免AI式过度解释与套路化辞藻？
- [ ] 数据反馈是否用于微调支线节奏，而非动摇核心力量体系与主线逻辑？
- [ ] 科武元素是否实现“类型溢出”，在爽感之外提供对“人类定义/生命进化”的追问？
- [ ] 阶段性收尾是否提出开放性问题或留下认知余震，而非单纯战力碾压闭环？

## 5 对作家角色的输入要求
| 维度 | 交付标准 |
|:---|:---|
| **动作链** | 必须呈现“意图-发力-轨迹-命中/落空-反作用力”完整传导。禁止“意念一动，敌人灰飞烟灭”。科武战斗需拆解为肌肉收缩、神经电信号、外骨骼/灵能回路过载、环境介质交互的连续帧，确保逻辑可追溯。 |
| **物理反馈** | 力量释放必须伴随可量化的环境破坏与躯体代价（如骨骼微裂、体温骤升、重力场扭曲导致的视觉畸变、空气电离的臭氧味）。高维打击需通过“感官错位”（时间流速异常、空间折叠眩晕）具象化，杜绝抽象形容词堆砌。 |
| **代价** | 任何科武突破/金手指使用必须绑定明确代价（寿命折损、基因崩溃、社会性死亡、认知污染、情感剥离）。代价需随剧情推进呈指数级放大，建立“力量-代价”动态平衡表，严禁无消耗升级。 |
| **钩子** | 每章结尾必须设置“信息差悬念”或“状态临界点”（如：功法反噬倒计时、敌对文明规则降临前兆、关键道具异常读数）。钩子需与核心脑洞强关联，禁止无关日常断章或情绪断崖。 |
| **读者预期** | 明确交付“确定性爽感”（战力验证/资源获取/破局）与“不确定性探索”（规则破解/文明真相/人性抉择）。前期预期以“逆袭/掌控”为主，中后期转向“生存/定义/超越”。严禁预期欺诈（如铺垫科技侧却突然转入玄幻修仙无逻辑解释）。 |
