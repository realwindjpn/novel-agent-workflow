## 一、写作前任务卡字段（更新版）

每章开写前，填充以下字段，确保创作过程始终锚定在“执行层”而非“想”。

| 字段 | 内容 | 自查标准 |
|:---|:---|:---|
| **本章核心目标** | 主角要做什么？得到什么？ | ≤15字；必须是动词 |
| **爽点类型** | 科技碾压 / 武道反杀 / 智斗逆转 / 阵营博弈 | 只能选1个 |
| **代价锚点** | 本章金手指/越级行为必须付出的代价是什么？ | 写进大纲，否则禁用 |
| **物理反馈** | 这章能力释放/机甲启动/基因激活的感官细节？ | 至少2处具体描写 |
| **章末钩子** | 本章最后一句留下的悬念是什么？ | 必须和下一章开头强连接 |
| **数据验证节点** | 本卷第X万字看追读/完读数据 | 标注在细纲里 |

## 二、章节自检清单（写完过一遍）

**核心检查**（有问题直接打回）：
- [ ] **3000字内**，本章核心设定/金手指/反常事件是否已抛出？
- [ ] 主角是否展现了**明确的缺陷**（≥1）+**不可逾越的底线**（≥1）？
- [ ] 本章冲突是否依赖**“代价/选择”**驱动，而非纯战力碾压？
- [ ] 动作链是否完整：**感知→决策→执行→结果**，禁止“一键秒杀”描写？
- [ ] 能力释放/机甲启动是否伴随**≥2个感官反馈**（声音/触感/警报/破坏痕迹）？

**节奏检查**：
- [ ] 每3-5章是否设置至少**1个情绪钩子**或剧情转折？
- [ ] 是否有**支线冗余**拖慢节奏？（卡文即砍支线保主线）
- [ ] 章末钩子是否用**疑问句/未解危机/身份反转**结尾，禁止总结式收尾？

**世界观检查**：
- [ ] 新设定是否通过**剧情自然带出**，而非大段说明书式输出？
- [ ] “离谱”设定是否有**底层科学/物理/规则自洽**支撑？（科武底线）
- [ ] 战力体系是否有**明确上限和限制条件**标注在细纲？

**改编潜力检查**：
- [ ] 场景描写是否具备**视觉化潜力**（契约/机甲启动/名场面）？
- [ ] 对话是否足够**网感化**（埋梗/吐槽/反套路）便于分镜转化？

**平台合规检查**：
- [ ] 更新节奏是否符合**日更≥6k**基准？
- [ ] 章节结尾是否在**情绪最高点/悬念点**断开，诱导追读？

## 三、段落节奏模板（直接套用）

### A. 战斗/操作段落结构

```
【感知层】敌人动作/机甲警报/环境变化
  ↓
【决策层】主角判断依据（战力评估/环境利用/战术选择）
  ↓
【执行层】具体操作描写（装备启动/能量释放/武技施展）
  ↓
【代价层】立即付出的代价（后坐力/能量过载/暴露位置）
  ↓
【结果层】敌方反应+我方损失+悬念留白
```

### B. 日常/对话段落结构

```
【身份反差】主角市井行为 vs 科武身份落差
  ↓
【吐槽/梗植入】用网感对话制造记忆点
  ↓
【功能推进】触发新线索/埋伏笔/建立关系
  ↓
【代价暗示】当前安全状态背后的隐性代价（欠债/暴露风险/阵营冲突）
```

### C. 章末钩子模板（选一）

1. **未解危机型**：“他刚转身，身后的机甲残骸里传来一阵诡异的自检启动声——”
2. **身份反转型**：“三秒前还在嘲笑他的人，现在正跪在他面前——而他的手，刚刚按下了一个不该按的按钮。”
3. **阵营博弈型**：“他以为是友军发来的通讯，但通讯频段编号……不属于任何一个已知阵营。”
4. **代价延迟型**：“他赢了。但他没有注意到自己的视觉系统右上角，多了一个从未见过的警告图标。”

## 五、平台规则 → 发布/包装/风险门禁

### 发布规则门禁

| 门禁类型 | 要求 | 未达标处置 |
|:---|:---|:---|
| **更新节奏** | 日更≥6k；首秀期不断更 | 断更一次，推荐位掉一档；超过3天断更，算法重新计算 |
| **追读率** | 首秀期目标≥15% | 未达标需压缩章节节奏，增加钩子密度 |
| **完读率** | 前5章完读率≥40% | 未达标需重写开篇，避免说明书式背景 |
| **章节断裂点** | 必须卡在情绪高点/悬念点 | 总结式收尾按不合格处理，打回重写 |

### 包装规则门禁

| 门禁类型 | 要求 |
|:---|:---|
| **书名/简介** | 核心爽点前置；避免抽象概念词；示例：《一个史莱姆吊打巨龙很合理吧？》=核心设定+反套路预期 |
| **章节标题** | 带悬念词/情绪词；禁止纯章节序号（如“第三章”直接淘汰） |
| **封面图** | 主角形象+核心场景元素+视觉冲击点 |
| **标签** | 匹配平台算法分类；科武标签：科幻/玄幻/都市异能/系统流，视平台而定 |

### ⚠️ 风险门禁（踩线即死）

| 风险类型 | 门禁红线 |
|:---|:---|
| **政治敏感** | 涉及现实政权/宗教/领土主权的一律禁 |
| **平台限流** | 暴力血腥过度描写/擦边内容；每章触发平台审核即降权 |
| **版权风险** | 禁用真实品牌名/知名IP关联元素 |
| **战力崩坏** | 科武题材核心风险：越级战斗必须有明确代价，且战力体系必须有上限标注 |
| **设定自相矛盾** | 《科武纪元》无存稿+随意推翻大纲 = 设定打架 = 读者流失 = 推荐终止 |

## 六、科武长篇专属补充指令

**以下规则仅适用于《科武纪元》宇宙，不得与三风11课程原版混用：**

- 脑洞必须受限于**物理规则/能量守恒/机甲性能上限**，不可用系统降智或玄学解释
- 科技树解锁必须有**递进逻辑链**（例：底层技术→实验型号→成熟量产→逆向破解），禁止跳跃式解锁
- 世界观设定写入**主细纲文档**，每次推翻需同步更新，避免前后矛盾
- 每卷至少预留**1个高视觉化名场面**（机甲合體/武技觉醒/科技奇观），便于后期改编触达
- 科幻读者容忍度低于都市脑洞，**逻辑自洽优先于爽感输出**，牺牲一个爽点换逻辑闭环是可接受的选择
