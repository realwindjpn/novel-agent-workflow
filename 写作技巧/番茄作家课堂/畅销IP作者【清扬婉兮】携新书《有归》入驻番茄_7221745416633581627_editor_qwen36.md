# 《科武纪元》编辑学习官：清扬婉兮《有归》入驻专访拆解

## 1 课程核心判断（≤6条）
1. **IP向创作逻辑**：版权开发（影视/动漫）优先于纯流量逻辑，选题需前置评估市场缺口与改编可行性。
2. **选题“采玉”机制**：结合社会热点/科技趋势做差异化切入，反刻板印象设定是破局关键。
3. **现实题材爽感补偿**：用轻喜剧基调、强人设或高密度情绪爆点对冲“说教感”与“平淡感”，实现“有意义+有意思”。
4. **影视改编核心指标**：强社会共鸣＞猎奇设定；人物动机需具备普世情感锚点。
5. **价值观交付原则**：呈现多元选择，剥离作者道德审判，将评判权交还读者。
6. **创作路径策略**：深耕擅长领域“稳中求胜”，微创新优于盲目跨界；慢工细磨需匹配明确的数据/完读目标。

## 2 可执行编辑规则（按模块取舍）
| 模块 | 规则 |
|:---|:---|
| **开篇** | 前3章必须完成“热点/痛点前置+反常识设定抛出+主角初始目标锚定”。禁用纯世界观说明书式开篇，用具体场景/事件带出设定。 |
| **节奏** | 现实/科幻题材采用“日常切片+情绪爆点”交替推进；每3-5万字设置一次关系转折或局势升级，维持平台完读率曲线。 |
| **冲突** | 摒弃机械降神与纯武力碾压，转向“立场/伦理/生存困境”交织；冲突解决必须依赖人物主动选择与明确代价。 |
| **人物** | 群像去标签化，核心配角需具备独立动机、行为逻辑与至少1次高光时刻；主角成长弧光需与核心议题强绑定。 |
| **题材** | 热点稿/短故事需做“社会切片”，长篇需预留“议题纵深”；避免宏大叙事悬浮，所有设定必须落地于具体生活/战斗场景。 |
| **改编** | 预留影视/游戏接口：场景集中化、对话可表演化、情感主副线分明；规避审查红线，敏感议题做隐喻化处理。 |
| **平台规则** | 番茄生态重“情绪价值+首秀留存”；现实/科幻需在前10万字建立强钩子与类型承诺；利用编辑协同与推荐节点配合题材热点投放。 |

## 3 科武适配：可用点 / 不可硬套点
### ✅ 可用点（直接迁移至《科武纪元》）
- **选题采玉逻辑**：科幻科武需绑定前沿科技热点（脑机接口、聚变能源、深空殖民）与人类共性困境（阶级固化、技术伦理、文明存续），做差异化设定。
- **冲突降维**：用“技术路线之争/资源分配伦理/进化代价”替代纯战力比拼；科武体系需服务于人物抉择。
- **群像塑造**：去工具人化，配角需有独立科技树/战术立场与高光战役；避免主角单刷。
- **改编预留**：科武战斗场景模块化（便于分镜/游戏化）、能量体系可视化、情感主线清晰（战友/阵营/文明羁绊）。
- **节奏控制**：硬核设定“软着陆”，用强悬念/战术博弈稀释信息密度，防长篇劝退。

### ❌ 不可硬套点（需规避或转化）
- **纯现实议题平移**：婚恋/养老等不能直接套用，需转化为科幻语境下的“基因延续/意识上传/文明火种”命题。
- **轻喜剧全局覆盖**：《科武》基调偏硬核/史诗，轻喜剧/麻辣气质仅限局部调剂（如日常交互/战术吐槽），不可冲淡主线严肃性。
- **慢节奏生活流**：现实题材可铺陈日常，科幻长篇开篇需更快建立危机感与世界观运转规则。
- **家庭伦理共鸣**：影视改编的“强共鸣”在科武中需升维为“人类共同命运/技术奇点焦虑/生存底线”，而非微观家庭矛盾。

## 4 编辑检查表（10条以内）
- [ ] 核心选题是否具备科技/社会热点映射与影视化潜力？
- [ ] 前3章是否抛出反常识设定/核心悬念，并建立主角初始目标？
- [ ] 科幻/科武设定是否“软着陆”，避免连续3章纯设定堆砌？
- [ ] 冲突是否源于人物立场/价值观碰撞，而非机械降神或纯武力碾压？
- [ ] 主要配角是否具备独立动机、行为逻辑与至少1次高光时刻？
- [ ] 价值观输出是否保持中立呈现，避免作者直接说教或道德审判？
- [ ] 每3-5万字是否设置情绪爆点或关系/局势转折，维持完读率？
- [ ] 场景与对话是否具备可表演性/可视化，预留影视/漫改接口？
- [ ] 科武体系是否明确“使用代价”与“物理反馈”，杜绝无成本开挂？
- [ ] 平台数据节点（首秀、推荐期）前，是否完成核心钩子铺设与预期管理？

## 5 对作家角色的输入要求
| 维度 | 执行标准 |
|:---|:---|
| **动作链** | 禁止“意念/瞬发”式描写。关键行为必须拆解为`感知→决策→执行→结果`四步，明确空间位移、肢体发力顺序与环境交互（如：锁定目标→调整重心→肌肉收缩→武器轨迹偏移→命中反馈）。 |
| **物理反馈** | 科武/科幻设定必须伴随可量化的物理表现。禁用“威力巨大”“瞬间毁灭”等模糊词。需标注能量过载的肌肉撕裂声、重力改变的骨骼压迫感、护盾碎裂的冲击波半径等。 |
| **代价** | 任何能力跃升、科技应用或战术胜利必须绑定明确代价（寿命折损、神经负荷、资源枯竭、道德污点或关系破裂）。代价需在3章内兑现或埋下伏笔，禁止“零成本通关”。 |
| **钩子** | 每章结尾必须设置“未闭合信息环”（悬念、反转、危机逼近或选择困境）。禁用纯抒情/总结性结尾。主钩子（贯穿卷）与副钩子（章级）需分层管理，确保首秀期留存率。 |
| **读者预期** | 开篇1万字内明确交付类型承诺（硬核推演/热血科武/悬疑解谜）。后续情节必须“超预期但不违背承诺”，禁止中途切换核心赛道、降智处理已建立的规则或临时添加机械降神。 |
