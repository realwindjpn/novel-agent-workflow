# 《科武纪元》编辑学习官：神无踪专访规则提炼

## 1 课程核心判断（≤6条）
1. **流量即算法**：免费/广告分成模式下，收入天花板由推荐点击率（CTR）与章节完读率决定，平台算法对垂直品类（含硬科幻）具备公平分发能力。
2. **标题即分发触点**：单章推荐标题是算法抓取的第一钩子，需精准提炼冲突/悬念，拒绝无效标题党。
3. **开局定留存**：平淡日常开局必死，高势能/强反差开局（如“出狱”替代“机场”）能瞬间拉升首章留存。
4. **人设靠标签锚定**：核心人物需绑定1-2个高辨识度行为/性格标签，降低读者记忆与传播成本。
5. **节奏拒水文**：冲突推进与地图/势力升级是骨架，日更需保证信息密度，拒绝为凑字数牺牲叙事效率。
6. **爆款可逆向拆解**：头部作品必有可复用的结构/情绪逻辑，跨平台试水是突破流量瓶颈的有效路径。

## 2 可执行编辑规则（按栏目取舍）
| 维度 | 规则 |
|:---|:---|
| **开篇** | 首章前300字必须切入核心冲突/高势能场景/生存危机。禁用背景铺垫、世界观说明书、日常寒暄。 |
| **节奏** | 每章（3000字）至少完成1次有效冲突升级或信息反转；章末留钩，章首承接。事件驱动＞情绪驱动。 |
| **冲突** | 冲突需具象化、可视觉化。都市类靠“换地图+实力碾压”，科武类需转化为“规则对抗/技术代差/环境绞杀”。 |
| **人物** | 主角配置“行为锚点”（固定动作/前置条件/口头禅）；配角功能明确（推剧情/供情绪/造障碍），禁用工具人堆砌。 |
| **题材** | 科幻/悬疑等垂直品类具备长尾爆发力，但必须将“硬核设定”降维为“通俗冲突”（用生存压力/利益博弈包装技术逻辑）。 |
| **改编** | 章节标题需独立成“微广告”，提炼本章最大看点（悬念/反转/爽点/代价），适配信息流推荐与短故事切片逻辑。 |
| **平台规则** | 免费模式核心指标=点击率×完读率×广告曝光。更新稳定（日更3k）+ 标题优化 + 评论区核心期待埋线是基础运营动作。 |

## 3 科武适配
### ✅ 可用点（直接迁移）
- **高势能开局**：将“出狱”转化为“从深空监狱/基因改造舱/废土隔离区/冬眠舱苏醒”，自带悬念与力量体系暗示。
- **行为标签化**：科武主角绑定科幻化动作锚点（如“启动义体前必校准神经”“拔刀前必闭眼3秒”“开火前必报坐标”）。
- **拒水文/快节奏**：科武长篇易陷入设定堆砌，需严格遵循“设定服务于冲突”，用战斗/探索/生存危机驱动剧情，单章信息密度对标商业爽文。
- **章标题优化**：将科武的“技术突破/星图解锁/机甲对决”提炼为强情绪/强悬念标题，提升信息流CTR与短故事传播率。

### 🚫 不可硬套点（需规避）
- **无逻辑换地图**：科武世界观需科技树/势力版图自洽，不能为升级随意跳跃星系/维度，需有明确的跃迁成本、航道限制或政治博弈。
- **纯武力平推**：科武战斗必须结合科技、战术、环境、规则。过度简化反派或降智会破坏“科”的硬核质感与“武”的战术纵深。
- **标签扁平化**：“人狠话不多”在科武语境中需补充“为何狠/代价是什么”，否则易沦为脸谱化爽文，削弱科幻人性博弈厚度。

## 4 编辑检查表（10条以内）
- [ ] 首章前300字是否已切入核心冲突/高势能场景？（无日常铺垫）
- [ ] 本章推荐标题是否精准提炼了最大悬念/爽点/反转？（非标题党）
- [ ] 主角是否具备≥1个高辨识度行为/性格标签？（读者能复述）
- [ ] 单章（3k字）是否完成至少1次有效冲突推进或信息增量？
- [ ] 科幻设定是否已转化为具体冲突/生存压力？（无纯说明书段落）
- [ ] 章末是否留有明确钩子（悬念/危机/选择/倒计时）？
- [ ] 是否存在为凑字数重复描写/无效对话？（信息密度达标）
- [ ] 战力/科技体系升级是否有前置铺垫与逻辑支撑？（非机械降神）
- [ ] 平台适配：更新频率是否稳定？评论区核心争议/期待是否已埋入后续大纲？

## 5 对作家角色的输入要求
| 维度 | 交付标准 |
|:---|:---|
| **动作链** | 战斗/操作必须拆解为“感知→决策→执行→结果”四步。禁止“意念一动直接秒杀”。科武场景需体现科技装备/武技的启动逻辑、冷却周期与物理限制。 |
| **物理反馈** | 每次高强度动作/能量释放必须伴随环境破坏、机体负荷、感官异常（如耳鸣、肌肉撕裂、义体过热、重力失衡、辐射灼痛）。用物理反馈替代空洞形容词。 |
| **代价** | 任何越级战斗/技术突破/越权操作必须支付明确代价（寿命折损、资源枯竭、阵营敌对、神经污染、道德妥协、装备损毁）。无代价的升级视为水文，直接打回。 |
| **钩子** | 每章结尾必须设置“未闭合事件”（危机逼近/关键道具缺失/身份暴露倒计时/二选一困境）。禁止平淡收尾或纯抒情断章。 |
| **读者预期** | 明确本章核心交付物（爽点释放/设定揭秘/情感铺垫/战术博弈），并在章首300字内建立预期，章末兑现或升级预期。严禁预期错位（如预告大战却写日常）。 |
