# 素材卡：Anthropic收购Stainless——AI开发者工具链闭环

日期：2026-05-19
来源：https://techcrunch.com/2026/05/18/anthropic-has-acquired-the-dev-tools-startup-used-by-openai-google-and-cloudflare/
类型：产业/AI/制度
可信度：primary

## 一句话
Anthropic以超$3亿收购Stainless（SDK自动生成工具），OpenAI、Google、Cloudflare等竞争对手失去关键基础设施供应商。

## 关键事实
- 收购方：Anthropic；被收购方：Stainless（2022年成立，创始人Alex Rattray，前Stripe工程师）
- 投资者：Sequoia Capital、Andreessen Horowitz；收购价：超$3亿（The Information报道）
- 产品功能：将API规格自动转换为Python/TypeScript/Kotlin/Go/Java等多语言SDK，并随API变化自动更新
- 客户覆盖：OpenAI、Google、Cloudflare、Replicate、Runway等；Anthropic自初版API起使用Stainless
- 战略影响：Anthropic将停运公共SDK生成器；现有用户保留已有SDK的所有权
- AI Agent生态：SDK是AI agent连接外部软件、执行自主任务的基础设施

## 可用细节
- 角色能看见：API文档自动生成SDK；多语言SDK版本一致性检查；SDK废弃警告
- 角色能付出：迁移自托管SDK；重写已有工具链；放弃竞争对手平台
- 角色能损失：SDK停更导致安全漏洞；多语言支持断裂；AI agent无法调用特定API
- 角色能操作：AI agent自动生成适配新API的SDK；SDK版本锁定防止破坏性更新
