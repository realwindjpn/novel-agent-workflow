# 《科武纪元》编辑学习官｜《钩子设计（上）》课程萃取

## 1 课程核心判断（≤6条）
1. **钩子本质是期待感管理**：非单纯悬念或反转，而是驱动读者翻页的持续动力。
2. **开篇必须“露一藏九”**：以信息差切入冲突中段，严禁设定集式平铺；未知即好奇源头。
3. **结构钩是叙事灯塔**：明确的目标指引（短/长线交替），断钩或改道必损留存。
4. **钩子非欺骗性鱼饵**：必须兑现正向反馈（实力/资源/信息/情感），努力需有回报。
5. **悬念依赖信息差调度**：读者＞角色（期待掉马/破局）或读者＜角色（延迟披露/反转），未知维持张力。
6. **冰山法则**：完整剧情仅露10%，剩余90%靠钩子牵引读者自行补全与追更。

## 2 可执行编辑规则（按原文逻辑提取）
| 维度 | 规则 |
|:---|:---|
| **开篇** | 首章必须切入事件中段或冲突爆发点；世界观/力量体系随剧情碎片化释放；禁用“背景说明书”式开篇。 |
| **节奏** | 结构钩间隔不可过长（建议3-5章一小兑现，10-20章一大兑现）；短线钩嵌套长线钩，保持期待感连续输出。 |
| **冲突** | 冲突需自带未解信息（如异常现象、反常行为）；冲突结果必须导向新钩子或明确目标，禁止无效打斗/对话。 |
| **人物** | 人物核心动机需绑定明确结构钩（如“为某人治病/复仇”）；行为反常需预留解释空间，形成人物专属悬念。 |
| **题材** | 男频侧重目标达成与升级反馈，女频侧重情感悬念与关系张力；钩子类型可跨题材复用，但兑现方式需贴合受众爽点。 |
| **连载/平台** | 番茄算法重“完读率”与“追更率”，钩子密度需匹配推荐机制；开篇3000字内必须抛出核心钩；断更/卡文处需提前埋补偿性伏笔防流失。 |

## 3 科武适配：《科武纪元》专项
### ✅ 可用点
- **科幻设定天然契合悬念钩**：高维投影、物理常数异常、倒计时、未知文明信号等，可直接转化为“露一藏九”的开篇钩。
- **科武体系适配结构钩**：武学突破/科技迭代可作短线钩（如“掌握曲率引擎”“突破基因锁”），文明跃迁/星际远征作长线钩，长短交替推进。
- **信息差调度空间大**：利用“科学原理未解/武学古籍残篇”制造读者＜角色的延迟披露；利用“主角隐藏身份/暗线协议”制造读者＞角色的掉马期待。

### ⛔ 不可硬套点
- **忌硬核设定直接当钩子**：相对论、量子纠缠等理论不可作为“信息差”硬塞，必须转化为角色可感知的物理冲突或生存危机。
- **忌纯情绪钩支撑长篇**：科武题材需逻辑与物理锚点，系统/重生类钩子若与硬科幻基调冲突，需做科幻化包装（如“神经接口协议重置”“时间线坍缩回溯”）。
- **忌钩子脱离代价体系**：科武力量升级若无视能量守恒/肉体负荷，结构钩将失去“灯塔”属性，沦为机械降神。

## 4 编辑检查表（8条）
1. [ ] 首章是否以冲突/异常事件开场？世界观交代占比是否≤10%？
2. [ ] 核心钩子是否在3000字内明确抛出？
3. [ ] 当前章节是否包含至少1个未兑现的短线结构钩？
4. [ ] 结构钩目标是否清晰？读者能否预判下一阶段方向？
5. [ ] 钩子兑现是否提供明确正向反馈（实力/资源/信息/阵营优势）？
6. [ ] 悬念是否利用信息差（读者知/角色知比例）制造期待？
7. [ ] 连续3章无新钩子或旧钩未推进？（触发预警）
8. [ ] 科幻/武学设定是否转化为角色可感知的冲突与代价？

## 5 对作家角色的输入要求
作家提交细纲/正文前，必须按以下维度结构化输入，否则退回修改：

| 维度 | 输入要求（基于钩子逻辑） |
|:---|:---|
| **动作链** | 标注关键场景的“触发条件→执行动作→直接结果”三步链。剔除过渡性动作，确保每一步直接推动钩子或冲突。 |
| **物理反馈** | 科武设定下，所有超常动作/科技应用必须附带可观测的物理反馈（如能量溢出轨迹、重力畸变参数、神经负荷阈值）。禁止唯心/模糊描写。 |
| **代价** | 每次钩子兑现或能力突破，必须明确标注“代价”（资源消耗、肉体损伤、阵营暴露、时间窗口压缩）。代价是维持长线结构钩张力的核心锚点。 |
| **钩子** | 每章结尾需明确标注当前“主钩/副钩”类型（开篇/结构/悬念）及预期兑现章节。禁止无指向性留白或“为悬念而悬念”。 |
| **读者预期** | 提交时需附“预期管理表”：①当前钩子类型 ②信息差配置（读者知/角色知比例） ③预期情绪（紧张/好奇/爽感/释然） ④防崩预案（若提前揭晓如何补偿）。 |
