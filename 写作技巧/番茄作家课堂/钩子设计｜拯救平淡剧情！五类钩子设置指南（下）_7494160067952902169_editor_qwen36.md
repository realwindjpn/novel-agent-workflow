# 《科武纪元》编辑学习官｜钩子设计课程提炼报告

## 1 课程核心判断（≤6条）
1. **钩子本质是期待感载体**：所有钩子（章节/道具/场景/对话/感官等）的唯一功能是拉升并维持读者期待感，非单纯制造悬念。
2. **章末断章铁律**：永远不在单章内交付完整事件结果。采用“80%本章+20%下章”或“120%本章（含下章开头）”结构切割。
3. **结构绝对优先于字数**：为保钩子完整性，允许单章字数浮动；严禁为凑整2000字破坏断章节奏。
4. **藏九露一与留白机制**：作者掌握全貌，但仅释放10%表象，剩余90%交由读者脑补；留白是期待感发酵的核心。
5. **伏笔必兑现原则**：场景/道具/感官描写一旦落笔即成契约，后续必须回收；无效闲笔直接稀释期待感。
6. **未知坑属高危禁术**：严禁挖作者自身无解的设定坑；长篇连载需大纲锚定，填不上即崩盘。

## 2 可执行编辑规则（按文章实际内容取舍）

| 维度 | 编辑规则 |
|:---|:---|
| **开篇** | 首章必须植入1个强感官/场景钩；前3章内必须抛出核心道具或目标钩，建立基础期待轴。 |
| **节奏** | 采用“生长开花在本章，结果在下章”切割法；事件高潮、危机爆发、关键抉择点强制置于章末。 |
| **冲突** | 冲突描写止于“动作起手式”或“局势临界点”，不写收招/胜负/后果；对话钩用于前置危机预警或势力博弈暗线。 |
| **人物** | 人物动机通过“未兑现承诺/信息误会”延宕；感官钩绑定角色生理/心理特质（如特定气味、重复梦境、义体痛觉）。 |
| **题材** | 科幻/高武向优先使用“道具钩（未知科技/功法副作用）”与“场景钩（异常环境/遗迹）”；避免滥用传统“错过钩”。 |
| **改编** | 钩子需具备强视听转化潜力（如拔刀上桌、染血刀、低频呼吸声、闪烁倒计时），便于后续影视/漫画分镜提取。 |
| **平台规则** | 番茄算法重读完率与次日留存，章钩直接挂钩数据；字数服从结构，允许±10%浮动；章章卡文易引发读者反噬，需控制密度。 |

## 3 科武适配：可用点 vs 不可硬套点

| 维度 | 可用点（直接迁移） | 不可硬套点（需改造/禁用） |
|:---|:---|:---|
| **设定融合** | 科技/武道天然适配“道具钩”（未激活神经义体、反噬型基因药剂、残缺高维功法） | 传统玄幻“错过钩/狗血误会”在硬核科武中显拖沓，需转为“通讯延迟/逻辑误判/信息差” |
| **环境叙事** | “场景钩”契合废土/高维遗迹/异常空间（悬浮残骸、倒计时终端、锁链兽型机甲） | 纯静态风景描写不可作钩子；必须绑定“异常物理现象/未解科技痕迹” |
| **感官系统** | “感官钩”可结合赛博/高武设定（义体过载焦糊味、精神波低频干扰、战术目镜雪花噪点） | 纯心理独白/抽象情绪不可作钩子；必须具象为可观测的物理/生理反馈 |
| **悬念控制** | “藏九露一”完美匹配科幻悬疑叙事，适合铺设世界观底层逻辑与战力体系 | “禁术挖坑”在科武长篇中致命（设定需自洽/物理法则需闭环），严禁无大纲挖未知科技坑 |
| **断章逻辑** | 章钩绑定“生存危机/战力突破/阵营对抗/科技解锁”等强驱动事件 | 章钩不可用于“纯设定解说/日常过渡/战力碾压收尾”，否则期待感断裂 |

## 4 编辑检查表（10条以内）
- [ ] 章末是否截断在“动作起手/危机爆发/关键抉择”瞬间，而非事件收尾？
- [ ] 本章是否至少埋设1个明确指向下章/后续剧情的钩子（道具/场景/对话/感官）？
- [ ] 钩子是否具备“可兑现性”？（已埋线索是否有明确回收节点规划）
- [ ] 是否遵循“藏九露一”？（本章信息量是否保留20%悬念至下章）
- [ ] 钩子是否直接服务于核心期待（战力/生存/真相/阵营）？有无无效闲笔？
- [ ] 感官/场景描写是否具备“伏笔属性”？（如出现必有用，否则删）
- [ ] 对话是否包含潜台词/预警/势力博弈信息？（避免纯信息交代）
- [ ] 是否避免“章章卡文”？（钩子密度是否控制在3-4章1个强钩，1章1个弱钩）
- [ ] 科幻/高武设定是否通过钩子具象化？（避免纯文本设定堆砌）
- [ ] 字数是否服从结构？（允许±150字浮动保钩子完整，不强行凑整）

## 5 对作家角色的输入要求

| 维度 | 输入规范（科武向） |
|:---|:---|
| **动作链** | 必须呈现“起手-发力-未落定”三段式。例：`义体充能→刃光撕裂空气→刀锋距颈0.5cm（断章）`。禁止写收招/倒地/胜负判定。 |
| **物理反馈** | 钩子触发需绑定可观测的物理/生理反应。例：`战术目镜过载红光、肌肉纤维撕裂痛感、空气电离焦糊味、低频精神波耳鸣`。拒绝纯心理独白。 |
| **代价** | 每个钩子必须预设“使用/触发代价”，并在后续3-5章内兑现。例：`未知药剂提升战力但引发神经排异；场景遗迹激活但引来高维扫描波`。 |
| **钩子** | 提交时需明确标注类型（道具/场景/对话/感官/章断），附`预期回收章数`与`核心期待指向`。禁止无指向悬念或纯氛围描写。 |
| **读者预期** | 每章附“预期管理表”：①本章已满足什么期待？②章末钩子拉高什么新期待？③下章首段如何承接并释放20%悬念？确保期待轴不断裂。 |
